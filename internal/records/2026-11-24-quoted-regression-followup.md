## Owning-layer repair and local regression evidence

The follow-up repair changes the shared Web positioning host's captured-scroll fallback. It repositions only when the actual scroll origin is a document or a strict composed ancestor of that lease's reference or floating box. An internal Content scroll no longer starts an unnecessary intrinsic measurement that removes the Content's available-height cap. Genuine ancestor movement still invalidates positioning, including an outer floating panel that moves an inner popup's reference.

The host follows slot and shadow-host ancestry, captures non-composed scrolls within the relevant ShadowRoots, refreshes those roots on an existing position/update entry, and disposes all its listeners with the lease. ## Second-stage repair: retain the cap during certified geometry refreshes

The shared host now retains one bounded natural-size measurement per lease. Reuse requires a currently owned projection, observable overflow and unchanged recorded input facts. The reference coordinates are always measured again. Only the first Floating UI rectangle measurement substitutes the previously measured floating width/height; the size middleware and any subsequent rectangle reset read the real constrained DOM box. This preserves collision/flip decisions without removing the live cap for a reference-only refresh.

Content mutations, authored style changes, font/load events and changed geometry inputs invalidate reuse. The observer distinguishes its own position/available-space outputs from authored style inputs, including asynchronously delivered mutation records. Semantically equivalent same-target connection updates can reuse a valid measurement; explicit `requestUpdate()`, changed configuration, root-space updates and size matching retain their fresh-measurement paths. Every added observer/listener is retired with its lease, and stale generations cannot commit cached dimensions.

Independent review identified two further certification risks during implementation. `F-INTRINSIC-001` required checking side-dependent CSS and scroll extent before certifying natural dimensions against the final projection. `F-INTRINSIC-002` required binding the dimensions to the input context immediately before measurement, after strategy pinning, and rejecting certification when reference size, viewport, ancestor context or offset parent changes across the awaited computation. Both have source-level corrections and focused controls. The final asynchronous-input control was not executed as a negative test on the earlier ddbe candidate; that distinction is preserved.

The [second-stage local evidence](evidence/2026-11-24-quoted-regression-followup/intrinsic-measurement-local/manifest.json) retains the old b110 failures: two of three new core controls failed, and the independently authored mutation/resize-echo control reset the modeled offset from 80 to 0 while two existing-behavior controls passed. These are explicitly modeled DOM/layout observations, not native wheel results. The final frozen source, rerun after test formatting, passes **26 files / 337 tests**; the workspace typecheck with a 4 GiB heap and Prettier both exit 0. The [independent verification addendum](evidence/2026-11-24-quoted-regression-followup/intrinsic-measurement-local/independent-intrinsic-continuity-validation-addendum.md) checks all sixteen referenced validation files, seven frozen source hashes and actual completion receipts. The source recorder now includes all seventeen relevant source/test paths. No page CSS, Brutalist decoration, anchor translation policy or scroll offset is rewritten by this repair. Uncertified input changes still take the existing fresh-measurement path; this is not a universal promise to preserve every offset through arbitrary content, stylesheet or layout changes.
