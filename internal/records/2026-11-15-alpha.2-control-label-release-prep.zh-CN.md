# 0.3.0-alpha.2 Control Label 修复准备

本记录保留当前修复候选的版本决定与诊断边界，不构成语义规范或发布凭证。

## 版本决定

当前用户要求判断问题归属、完成修复并自行 bump。依照 `D-GLOBAL-RELEASE-VERSION-0001` 与 `internal/governance/release-workflow.md`，本轮开启 draft `V-PROTO-UI-0011` / `0.3.0-alpha.2`，精确对齐全部 47 个公开 `@proto.ui/*` package、BOM 与 package-local 版本投影。`@proto.ui/compiler` 是私有工具，仍不带独立公开发行版本。既有 stable `0.2.0` 与先前版本实体保持历史原貌。

这次 bump 准备下一条 alpha release train，不代表 npm 发布、tag、dist-tag、GitHub Release、不可变 snapshot 或 ordinary entity stable admission。网站与公开可用性说明继续指向最后一次已核验发行；package-local README 中的 alpha.2 安装命令仅为明确标注尚未发布的待发布示例。

## 失败归因

以 PR #1460 的 `ce56274971f51590c8bccb33c1a2763637a88fc5` 编译器分别读取当前真实 Base 定义与 `7d30a788f4bd79189cbe2dd499ded9ff22ba91e1` 的同路径定义，四个 Web source profile 得到一致区分：

- Button 的旧定义均可编译，新增 `asControlLabel` 后均以 `PUI1003` 拒绝。这是编译器尚未实现合法关联能力而导致的新增组合回归。
- Toggle 的旧定义已在 `ConditionalExpression` 上以 `PUI1004` 拒绝。
- Toggle Group Root/Item 的旧定义已在 `shared.ts` 顶层运行时绑定上以 `PUI1004` 拒绝。
- Label 的旧定义已在公开 `CONTROL_LABEL_SELECTION_POLICIES` 枚举导入上以 `PUI1003` 拒绝。

因此修复需要共享定义中可独立实现的关联边界、通用 compiler lowering 及真实 consumer 的交叉证据。已有 parser 缺口不能伪称为这次引入的回归，也不能用删掉 Prototype 行为来绕过。

本轮修复最终以 Button、Toggle、Label 的四个 Web source profile 和 mixed Runtime/compiled consumer 为边界。Toggle Group Root/Item 的既有 typed collection、反射与函数队列语言需要单独定义和实现；保留其明确诊断，不把拒绝结果算作已编译支持，也不加入未检查 callable 来伪造通过。

## 生命周期与验证边界

完整编译器回归还发现私有 Web Component SSR 实验被过宽的 ControlLabel SSR 拒绝条件拦截。定义中声明 target 能力不等于服务端已经绑定引用；但直接删除拒绝也不成立，因为旧 SSR helper 没有真实协议实现。本轮增加明确的 `controlLabelHydration: 'client-only'` 私有选项，使用同一套完整 native helper 保留未关联的 server Button，并在客户端 hydration 后通过独立 `instanceAssociations` 输入真实配对。服务端 Props、options、HTML 属性、carrier 及隐式 Anatomy 配对继续明确拒绝，不传输不透明引用，也不扩大公开 SSR profile。

该兼容修复已保留并通过原有 40 个 Button SSR 行为用例、8 个 server/evidence/type 用例及新增 16 个关联边界用例。生成证据精确增加 ownership 与 ControlLabel 两个真实 helper，完整生成图的严格类型检查和无 browser globals 的 Node 渲染均通过，没有删减原有语义断言或替换真实 Prototype。

正常 uid 1000、`chromiumSandbox: true` 的远端候选已完成 24/24 个四 Web 原生消费用例，包含实际 pointer/keyboard 输入、浏览器可访问名称、controlled/disabled、引用替换和焦点重入。该次记录绑定的是未冻结候选，最终集成源码仍须在冻结后重新运行并绑定最终源哈希；它不构成 OS assistive-technology、Toggle Group 或全部后端接纳。

本轮 disposition 仅覆盖 Control Label 的 Contract、Module、Host Capability、Test 与 Base Label/Button/Toggle/Toggle Group，保留其 draft 状态。`C-CONTROL-LABEL-0001-Q-EVIDENCE` 指出的完整 paired Web input、lifetime、projection 与 assistive-technology 接纳仍须独立评审。其余 draft 未经此次 review，不复制旧 train 的 disposition 来伪造完整 inventory 已通过。

版本准备使用官方 `stamp-version`、`release:sync-metadata`、`release:bom` 及仓库声明的 pnpm 刷新投影。最终修复的检查结果由最终候选上的实际运行记录提供；此记录不会把版本文件对齐等同于 compiler、原生浏览器或发行验收通过。
