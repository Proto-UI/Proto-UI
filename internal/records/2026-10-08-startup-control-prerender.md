The two Button keys explicitly request detached event/trigger identity to evaluate their existing initial rules; no input is dispatched and no browser command is claimed. - Search has same-source disabled Button paint and the existing Lucide search shape before scripts. It has no activation listener, is disabled and labelled loading, and keeps the no-JS documentation link. Its only allowed paint state change is the public disabled opacity 0.5 becoming ready opacity 1. - Code frame/toolbar use static Surface output on an absolute passive plane. Family-scoped inherited inputs retain nearest-family precedence. The parser fails closed on unsupported CSS forms/properties rather than silently losing rules. Publication replaces only decoration; native code/source/text are not cloned, moved or replaced. CSS snapshots do not repeat the global compiler reset, which could otherwise reset earlier same-layer token rules.

This is Runtime-based build-time prerender. It is **not** the private Compiler's SSR output, nor universal same-node adoption by ordinary Adapters. Search's unfocusable disabled server command is retired on atomic publication; menu focus handoff uses its existing explicit controller. These bounded exceptions must not be generalized into replacing focused user content.
