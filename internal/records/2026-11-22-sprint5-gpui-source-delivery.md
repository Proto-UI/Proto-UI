## Representation and implementation

| Family | Current concrete representation | Boundary retained |
| --- | --- | --- |
| Numeric and boolean literals, arithmetic, comparisons, conditions and logical expressions | `f64` / `bool` in proven scalar expressions and lexical storage; ordered once-only argument evaluation | NaN, signed zero, scientific/subnormal constants and short-circuit effects follow authored semantics |
| Captured mutable scalar locals | `Rc<RefCell<f64/bool>>` | Separate lexical cells retain identity and mutable captures; no snapshot substitution |
| Proven ordinary scalar callables | Typed Rust `Rc<dyn Fn>` arguments/results; a stable ordinary callable bridge allocated with the function | Aliases, public records, callable unions and default parameters preserve one callable identity; optional/undefined slots remain explicit |
| Strings | Lossless UTF-16 values at ordinary boundaries, including a lone code unit or malformed multi-unit sequence | Ordering, equality, concatenation, `String`, indexing/length, error messages and numeric coercion do not silently round-trip through lossy UTF-8; a nonrepresentable UTF-8 host/data export fails explicitly |
| Templates and native children | Existing `NativeSnapshot` and native GPUI factories | No reintroduced `Value::Template` paint interpreter; normal GPUI `Entity` / `AnyView` composition remains the consumer path |
| Records, arrays, JSON/public data and dynamically typed values | Identity-preserving ordinary `Value` storage and explicit boundary conversion | Complete per-field native record/array lowering remains unfinished; this patch does not call dynamic containers fully typed |
| Support and capability demand | Existing transitive demand controls reached functions, calls and capability initialization; one content-bound shared SDK | Full helper source selection and optimized retained-link cost remain separate unfinished work; fixed aggregate SDK source is not evidence of zero cost |

Finite-string `array.includes` now uses once-only receiver/needle evaluation and strict membership without coercion. Its admitted string domain makes strict equality equivalent to SameValueZero. Fresh plain-record `Object.assign` evaluates every argument/property before applying ordered last-write-wins assignment, preserving nested aliases and stopping on the original exception. It does not admit arbitrary targets, setters or prototype effects. GPUI `String()` admits zero arguments or a proven scalar argument; structured/unknown coercion keeps its explicit unsupported diagnostic.

Caught values are not nominal exception objects. The shared expression refinement now treats a caught value as dynamically typed for supported `typeof` and literal comparisons, retaining conservative unknown/exception behavior for unsupported narrowing. Independent positive and negative tests cover this correction.

The private SDK version remains `0.2.0`, with a content identity checked across generated crates. The implementation's SDK content hash is `1a791c161d174b4863abe54d83627af4398414c81cbf43eccd2079a514d90244`. Regenerate dependent components together; matching the version string alone does not authorize mixing different SDK contents.

## Actual authored Button is an explicit unfinished consumer

The current source `packages/prototypes/base/src/button/button.proto.ts` is compiled unchanged by the producer as a negative consumer. It reports PUI4003 for `hook.asControlLabel`, `controlLabel.target` and `controlLabelRequest.isCurrent`. Its source hash and diagnostics are retained in the producer receipt; replacing it with an older Button or deleting the hook is not accepted.

[C-CONTROL-LABEL-0001](../../spec/contracts/C-CONTROL-LABEL-0001.yaml) explicitly admits the current private Compiler association path only for standalone Web Button/Toggle/Label. Its nominal interoperability ABI is in an ECMAScript realm, and its dedicated `InstanceAssociations` channel cannot be serialized as ordinary Props. [HC-CONTROL-LABEL-0001](../../spec/host-caps/HC-CONTROL-LABEL-0001.yaml) describes native action intent but does not establish a Rust nominal reference/pair ABI or cross-lane native tree ownership. A GPUI implementation therefore needs an explicit native association boundary, native naming and activation leases, and duplicate/reentrant/detach/dispose evidence. It cannot be supplied by an empty hook or an application listener. This remains an owned #1056/#1144 consumer package, coordinated with the ControlLabel definition owner and the independent #687 Adapter owner.

The other profile exclusions remain `controlLabel.label`, `controlLabel.sync`, `eventControl.requestDefaultActionPrevention`, the four `hook.asFocusEntry` / `focusEntry.*` operations, and `accessible.part`. The separately admitted default-prevention operation is not evidence for these excluded APIs. A missing pinned GPUI focus-entry primitive is still explicit; no physical focus or accessibility result is inferred from the framework test platform.
