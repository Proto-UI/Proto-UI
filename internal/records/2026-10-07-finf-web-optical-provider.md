## Implementation and decisions

- Reuse the exact `88f681ab7035fd55b04f63edff1841e32c4199e9` liquidGL shader bytes from #809. A generator verifies both audited hashes and carries the complete MIT license. The V1 owned-scene/Button compiler stays unchanged.
- A separate V2 host program maps only static/finite press and regular/clear intent. Regular preserves the #809 prefilter, refraction, bevel, magnification and fixed specular profile. The inherited reversed-edge smoothstep requires exact-engine evidence; retaining bytes is no portability proof. Clear skips source prefiltering. Dark tint is host-owned and still passes rendered-contrast admission.
- Final governed tokens and an explicit current palette establish opaque fallback ownership. CSS only verifies final host delivery, foreground and geometry. Framework EffectsPort requests are not DOM acknowledgments: exact delivered tokens are required before rendering, and the current source/palette/view are checked again before publication.
- One WebGL rendering context is shared per Document, with per-view resource ownership; an unrelated fallback consumer cannot retire another surface’s current GPU resource. Mocked two-surface context-loss/restoration is covered.
- Static surfaces use a shared event-driven geometry observer, not a perpetual per-surface RAF. Source animation stops for paused, hidden/offscreen, reduced-motion or retired scenes. The browser fixture includes >16 surfaces, upload/context counters, encode/render timings and a static no-render window; those measurements remain pending official CI.
- The complete fallback token IR stays on the host. One owned inline background-color suppresses the proven fill property while enhanced; it is not a concurrently painted extra layer. Relinquishing ownership therefore restores current legal fallback without an asynchronous framework token round trip.
- Optical output occupies only the host's background paint. It creates no slot child, native input replacement, event listener or competing semantic owner. Inline and diagnostic cleanup uses compare-and-restore ownership.
- The in-app source is the visible application canvas itself. It has monotonic revisions, immutable copied pixels, frame-bound geometry and explicit revocation. It is not a hidden static texture relabeled as live DOM. Painted ancestors, overlap, cross-scope portals, stale dimensions/DPR and unsupported composed transforms withdraw eligibility.
- The Previewer lazily installs the provider for Liquid Glass content; other families do not eagerly acquire it. A transparent passive canvas shell keeps the live background visible instead of pretending that glass can see through an unrepresented opaque ancestor.
- Button replaces stage-0 CSS alpha/blur Rules with explicit V2 candidates; opaque/prominent retain zero-candidate fallback. Surface may request static optics independently of Button. Base input remains authoritative.
