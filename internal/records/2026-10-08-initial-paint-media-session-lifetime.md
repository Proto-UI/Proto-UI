# Initial optical paint: native media session lifetime

This is a test-driver correction for PR #872, based on the official `8e8c4ca21801378c11ea055f8f39796f86eeeda6` source. Run `37816158074` passed the light real-GPU producer, static no-script seed and native Tab/Enter, then failed because the reduced-transparency consumer still displayed the seed. The driver had detached its CDP media session immediately after setting preferences. It did not retain `matchMedia` observations. That result cannot establish a product CSS root cause. Its red result remains historical evidence; later cases did not run.

The correction holds one media session through navigation, CSS assertions, keyboard actions and screenshots, then detaches during case cleanup. Before checking the original CSS/geometry/quality assertions, it records every requested media value and all supported competing values from actual `matchMedia`, plus viewport, DPR and URL. Unsupported, reset or conflicting media values fail the harness instead of being mistaken for the intended preference. The failing case also retains its actual CSS state before cleanup. No production CSS, renderer, receipt, acceptance threshold or original preference assertion changes.

Acquisition and emulation share a five-second deadline, actual media observation has a five-second deadline, and detach has a one-second cleanup deadline. Late acquisition is detached without sending a new override. Cleanup or reporting failure does not replace a primary protocol error. These are protocol bounds, not physical filesystem or total-test time guarantees. The source binding now includes the media helper's actual bytes. The official source gate also runs its controls.

Validation: nine focused lifecycle/media controls and eight fixture binding controls pass; eighteen workflow controls pass. A canonical-options `allowJs:false` targeted TypeScript closure passes. The controls cover retained session ownership, idempotent cleanup, stuck send/detach, late acquisition, throwing cleanup/reporting, stuck observation, unsupported/reset/conflicting media values and the valid counterpart. Full workspace checks and official native re-execution are still pending. This change establishes no new GPU, no-script, first-frame, Liquid Card or visual acceptance.
