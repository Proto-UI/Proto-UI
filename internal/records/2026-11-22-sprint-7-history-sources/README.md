# Public historical GitHub source archive

This archive contains only publicly readable Proto-UI/Proto-UI PR metadata, review submissions, full commit messages, changed-file boundaries, head check/status records, and inline review comments. No private DCBot source or environment data is included.

Concatenate the ordered parts in index.json, verify each part and whole-archive SHA-256, gunzip, then resolve exact one-key objects $s7text from the strings table and $s7commit as {commit: resolved value} from the commits table. Every restored original PR and inline-comment value was compared to its raw capture before archiving. Raw HTTP wire-byte identity is not claimed.

Current fetches are not original body/edit history, platform approval is not current independent acceptance, and merge state is not proof that all retained original conditions were fulfilled. The Sprint 7 decision ledger separately records those boundaries.
