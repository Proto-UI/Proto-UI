## Combined semantics

- Preserve the standalone `asInputEditor` hook, public handle projection and full `asInputRoot` composition with a real ControlLabel. Add the other candidate's non-string reset refusal, reentrant snapshot read and mounted view reset guards. Both reset test families remain executable.
- Preserve readonly lexical permissions while using the stronger closed-call JSON provenance proof at outward events. Hidden enumerable undefined, capability fields, aliases, helper results and later writes remain subject to independent source/IR checks. The scalar contracts retain their distinct IDs and draft status; the input-boundary contract now links the wider scalar target/evaluation definition.
- Retain conservative branch effect histories and continuing-scope normalization. Both terminal-branch fixture families remain. Keep the existing Web conditional State lowering, WC empty renderer handling, DOM reset/change-only lifecycle and portable Rust data scalar lowering.
- Retain original callable identity through the checked renderer adapter and distinct Definition/Run/Render owner facets. The new full Base Input renderer capture and the original scalar/native/public alias tests coexist.
- Incorporate direct native ControlLabel associations, physical occurrence and window leases, authored assistive activation, input modifiers, move binding registration and the post-dispatch sequential focus default with App-local owner registration and scope/IME/prevention checks.
- Preserve pending event notifications independently from ordinary repaint dirtiness, including a publication followed by an authored exception. Native rendering consumes repaint dirtiness; the separate pending-event flag wakes a retained consumer after the draw lease without an observer/repaint loop. Physical focus/blur wakeups and cold/double-draw hover reconciliation remain. A guarded physical leave also retires ControlLabel pointer activation.
- Keep the independent `gpui-text-selection-notification` feature. Without that extension the focused editor still invalidates character coordinates and refreshes; the existing real next-frame native input-query regression remains. Selecting a modern Element ABI alone does not imply this extension.
- Use one scroll module for the new retained `NativeScrollTarget` binding and the existing `ScrollEngineLease` compatibility API. They are mutually exclusive on an owner and cannot retire a successor. The retained-target API remains unavailable after release until explicit restoration, while the compatibility lease preserves its declared restoration of the original compiler viewport. Both retire queued requests before changing targets. Measurement follows slot prepaint, and callback-only axis sync consumes disallowed-axis growth without replay. A new generated SDK regression checks the interaction of the two actual lease APIs.
