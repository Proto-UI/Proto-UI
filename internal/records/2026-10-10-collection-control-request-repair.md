# Collection control requests and effective disabled

Date: 2026-10-10 UTC. Base `ce9b96d0f18e9635552efb3a075753bc38486d2c`, PR #872. This is a bounded local repair record, not a normative family definition or full-delivery acceptance.

## Authority, accepted boundaries and ownership

`P-BASE-BUTTON` is draft. Its disabled input, exposure, transient cleanup, activation suppression and focus rejection criteria apply to existing ButtonProps consumers. `C-AS-FOCUSABLE-0001`, `C-AS-HOOK-0007`, `C-AS-COLLECTION-0001` and `C-EXPOSE-EVENT-0001` are draft. `C-PROPS-0014` is active and keeps owner input separate from runtime update effects. Resizable, Carousel and Tree have no family-specific P entities; `T-COLLECTION-CONTROL-REQUESTS-0001` therefore records bounded regression cases rather than asserting nonexistent family conformance. The independently reproduced review and current owner-directed repair scope establish the requested correction, not an automatic spec promotion.

- Resizable Root owns request normalization and outward proposal progression. A private cursor remembers the last normalized proposal, not a committed fact. Controlled `value`, Context and panel sizes remain owner-owned. Update the cursor before outward callbacks so synchronous owner acceptance and request reentry cannot overwrite newer intent. Reset on meaningful owner value/mode/constraint or disabled/readOnly changes and view detach; unrelated props preserve it. An accepted commit request retains `valueCommit`, and ends its request stream unless a newer reentrant request has already taken over. This lets a later interaction retry a rejected value.
- Carousel navigation merges local disabled, Root disabled and its existing count/index/loop boundary. TreeToggle merges local disabled, Root disabled and the target entry's disabled fact from Root's existing `getTree` snapshot. Both continue to use the one nested `as-button` capture and the reused privileged Focus handle. Their own `press.commit` listeners recheck that same source predicate because suppressing Button's outward click alone does not suppress another listener. Effective disabling also clears Button's existing hover/press facts.
- Tree readOnly still allows expansion. Leaf, missing target and invalid graph requests remain rejected by Root. Their separate toggle disabled/tabstop UX is not defined and is not added here. Node-key changes, removal/insertion and nested Root ownership are checked without inventing those policies.
- No shared Focus, Trigger, Anatomy, Axis Input, Runtime, Compiler, CLI, style recipe, package API or dependency source is changed. AlertDialog belongs to another repair owner.

R2 remains **open and unchanged**: defaultIndex=99 with two slides leaves no active slide. Blindly clamping when the first slide registers loses the legal defaultIndex=1 when a second slide follows. `C-AS-COLLECTION-0001` does not signal that all future registrations are complete. No delay, queueMicrotask, arbitrary sleep, speculative collection API or replay of defaultIndex on dynamic insertion is added. The valid defaultIndex=1 control and invalid99 red remain visible.

The original R4 leaf/missing disabled/tab assertions were proposed UX oracles, not existing normative checks. They are excluded from acceptance here, while no-expansion negatives remain. AlertDialog fallback and later modal/dismiss claims are outside this packet; nothing here closes them.

## Executed evidence and limits

The new WC fixture exercises owner rejection, immediate/deferred/late acceptance, normalization and collapse, same-proposal deduplication, per-request commit signals, nested request reentry, meaningful versus unrelated props, controlled exit, disabled/readOnly interruption, and terminal callable behavior. Carousel covers both directions and initial/dynamic local disabled, Root/boundary/loop changes, transient cleanup, real synthetic WC click routing, positive/negative Enter/Space and synchronous outward-click disabling. Tree adds Root/node/local sources, readOnly expansion, target-key changes, insertion/removal, invalid graph and nested Root routing. A separate real RuntimeSession fixture retains one setup/owner across detach/remount and verifies cursor release.

Evidence is source-bound and does not establish full browser paint, native event authenticity, all-Adapter conformance, packed/compiled/native GPUI behavior or full family semantics. Independent review and exact published-commit visual evidence remain separate. The only production edits are the three local Base entry files.

Fixture corrections are retained transparently: the first draft injected a DOM CustomEvent named `press.commit`, which WC does not accept as protocol input; it now uses actual WC `.click()` routing and independent positive keyboard controls. Its stale callable expectation now honors AdapterHost terminal-disposal rejection. The nested-root event recorder filters by actual event target so bubbling from an inner Root is not mistaken for an outer request. Initial Runtime harness failure was a missing Anatomy host capability, not a product failure. Initial type-check failure was missing workspace dependency links; the existing shared offline dependencies were linked without installing or changing versions.
