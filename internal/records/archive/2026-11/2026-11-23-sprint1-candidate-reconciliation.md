## Bounded Anatomy change

`packages/modules/anatomy/src/impl.ts` replaces wrapper allocation, index tie-breaking and unwrap mapping with `claims.slice().sort(...)`. Stable sorting preserves registration order when comparisons return zero; copying retains the input claim inventory. Existing live host getters, pair-comparison caching, callback reentry, target replacement and notification lifetime behavior remain in place.

A proposed whole-order cache was rejected: sampling each claim once can miss a comparator replacement triggered by a repeated host getter read for a later recipient. No such cache is included. The added four-claim regression exercises that repeated-read replacement; a separate control covers equal and unavailable targets. Existing order, domain and lifecycle controls remain selected under the draft mappings [T-ANATOMY-0004](../../../../spec/tests/T-ANATOMY-0004.yaml) and [T-ANATOMY-ORDER-0001](../../../../spec/tests/T-ANATOMY-ORDER-0001.yaml).
