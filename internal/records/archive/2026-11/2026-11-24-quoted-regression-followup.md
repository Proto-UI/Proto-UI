The reference coordinates are always measured again. Content mutations, authored style changes, font/load events and changed geometry inputs invalidate reuse. It uses Floating UI DOM's actual synchronous dimension provider. Only the first rectangle calculation receives those natural dimensions; the size middleware and subsequent resets continue to read the actual constrained box. Empty, interrupted or partially restored transactions do not authorize offset compensation. The host restores only the offsets captured from that live element, and only if the transaction changed its owned styles and the offsets actually changed. Explicit instant behavior prevents authored smooth scrolling from delaying that restoration.
