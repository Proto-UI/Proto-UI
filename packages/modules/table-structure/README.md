# @proto.ui/module-table-structure

Portable semantic owner for Proto UI's draft passive Base Table structure.

It consumes current nearest-domain Anatomy order and Maker-authored spans/header keys to produce a read-only two-dimensional topology, structural diagnostics, coordinates, and ordered opaque A11y relationships. It introduces no Table-specific Host Capability.

This package does not provide data records, sorting, selection, pagination, virtualization, editing, fetching, keyboard-grid behavior, focus policy, layout-table behavior, design-language styles, or host materialization guarantees.

Authority: `M-TABLE-STRUCTURE-0001`, `C-TABLE-STRUCTURE-0001`, and `D-BASE-TABLE-STRUCTURE-0001`. All remain draft; official Adapter support is a separately evidenced checkpoint.
