# Tabs projection

Draft Root/List/Trigger/Content projection of the existing Base Tabs contract. The default Liquid Glass recipe uses a rounded translucent segmented surface, with the existing material declaration and ordinary style fallback. `appearance="underline"` on List and Trigger is the opt-in Runtime Box recipe; that recipe does not activate the material effect.

Root selection, manual/automatic activation, disabled, roving focus and panel relations remain owned by the Base hooks. No additional keyboard/press owner. The inherited contract is `spec/prototypes/P-BASE-TABS*.yaml`; this addition does not revise that contract or its lifecycle. Same-state browser screenshots and native material verification remain pending. This is an authored projection, not a claim of an official Apple Tabs implementation.
