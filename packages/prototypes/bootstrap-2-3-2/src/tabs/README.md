# Tabs projection

Draft Root/List/Trigger/Content projection of the existing Base Tabs contract. The default Bootstrap 2.3.2 recipe uses the bordered navigation-tab treatment; `appearance="underline"` on List and Trigger is an opt-in Runtime Box recipe. Root selection, manual/automatic activation, disabled, roving focus and panel relations remain owned by the Base hooks. No additional keyboard/press owner.

The inherited contract is `spec/prototypes/P-BASE-TABS*.yaml`; this addition does not revise that contract or its lifecycle. Visual browser verification of this new recipe remains pending. Bootstrap 2.3.2 visual reference is the repository's existing Apache-2.0 reference; no third-party runtime is executed.
