# Tabs projection

Draft Root/List/Trigger/Content/Indicator projection of the existing Base Tabs contract. The default Bootstrap 2.3.2 recipe uses the bordered navigation-tab treatment; `appearance="underline"` on List and Trigger is an opt-in Runtime Box recipe. The Indicator is a semantic-only part: 2.3.2 nav-tabs marks selection on the Trigger's own border treatment, so the part keeps the real Base protocol (derived value/activeValue/orientation) with no paint. Root selection, manual/automatic activation, disabled, roving focus and panel relations remain owned by the Base hooks. No additional keyboard/press owner.

The default nav-tab recipe follows [`less/navs.less`](https://github.com/twbs/bootstrap/blob/b4c4072679943773a7582daa63f545ba818fa627/less/navs.less) and [`less/variables.less`](https://github.com/twbs/bootstrap/blob/b4c4072679943773a7582daa63f545ba818fa627/less/variables.less): 12px/8px padding, 2px inter-tab spacing, -1px panel-edge overlap, 4px upper corners, 14px/20px typography, #ddd list/active borders, #08c links, #555 active text, #eee hover/focus fill and #999 disabled text. These source dimensions retain pixel units, independent of the root font size. Stronger visible-focus outlines and Root's shrinkable grouping remain Proto presentation choices. This is the top-nav treatment, not every Bootstrap left/right/below placement or native anchor API.

The inherited contract is `spec/prototypes/P-BASE-TABS*.yaml`; this addition does not revise that contract or its lifecycle. Exact-source browser paint verification remains a separate acceptance prerequisite. The existing Apache-2.0 notices remain required; no third-party runtime is executed.
