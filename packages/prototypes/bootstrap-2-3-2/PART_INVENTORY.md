# Bootstrap 2.3.2 part and motion inventory

This is the 2026-11-22 Sprint 6 source inventory for [#1148](https://github.com/Proto-UI/Proto-UI/issues/1148), [#1467](https://github.com/Proto-UI/Proto-UI/issues/1467) and the Bootstrap half of [#799](https://github.com/Proto-UI/Proto-UI/issues/799). It records **237 named authored Prototypes in 205 `.proto.ts` files, across 54 source groups**. These are part identities, not 237 distinct widgets or accepted targets. Every entry remains draft. A source count, catalog relation, unit result or one composed navbar does not satisfy full-family visual/input/lifecycle/Compiler/native acceptance.

The fixed upstream revision is [`twbs/bootstrap@b4c4072679943773a7582daa63f545ba818fa627`](https://github.com/twbs/bootstrap/tree/b4c4072679943773a7582daa63f545ba818fa627) (2.3.2). Each part keeps its existing Base protocol; modern components are Proto UI extensions using that vocabulary. Bootstrap 2.3.2 has no standard dark theme. The paired dark semantic palette, stronger focus feedback, wrapping and mobile target adaptations stay explicit. In particular, Switch, Calendar, DatePicker, Drawer and other extension identities must not be reported as original upstream widgets.

## Motion and disclosure obligations

The distinction below is between authored behavior and accepted execution. “Declared” means the source has that recipe; actual interrupted enter/leave, native inputs, cleanup and preference results still come from the relevant exact-source target artifacts.
