# Native DOM support compilation

`plan.ts` maps the target's reached operation graph to host implementation units. Each unit declares its helper imports, native resources, and release obligations. The transitive feature closure determines both the emitted ES module graph and external packages. Component names, source filenames, and unreachable function bodies do not participate in selection.

`dom-interaction.template.ts` and `dom-modules.template.ts` are the canonical host source templates. Their `__nativeFeature` calls are compiler directives, with a closed vocabulary checked by `specialize.ts`. The compiler folds those guards, narrows the public capability surface, and takes a TypeScript-symbol dependency closure over declarations. Lexical shadowing and shorthand properties use the TypeScript checker, rather than source-text searches. No feature evaluator, operation table, AST, or semantic IR is emitted to the consumer.

`web-host-primitives.ts` packages the existing neutral Web Axis Input, available-region and constrained-layout algorithms into standalone host modules. Their canonical sources are also used by the runtime host. `scripts/compiler/generate-web-host-sources.mjs` records an explicit source list, complete bytes and SHA-256 values in `web-host-sources.generated.ts`; `--check` verifies that the packaged inputs remain current. Compilation consumes this closed asset instead of reading arbitrary repository files. It retargets only explicit module/type edges and selects the finite public host type declarations. Emitted JavaScript imports no Proto Runtime or Adapter. `nativeSupport.inputs` records the canonical source paths and digests alongside the checked generated artifact inventory.

The `axis-input` unit resolves its declared input and nearest same-family geometry owner through native Anatomy identity. The shared host owns contact capture, normalized geometry, directional recognition and extent-change cancellation. Authored code retains domain steps, preview, commit, rollback and keyboard policy. Losing the owner, view, anatomy association or contact configuration cancels the old lease. The `available-space` unit leases the actual root-content region and feeds the unchanged neutral layout algebra; its state inputs are read-only host observations, never new geometry State. Layout and presence presentation use the same `translation-composition-v1` module and release their own contribution independently. These bounded source implementations do not promote the draft contracts or imply another native provider.

The separately reached `target-alignment` unit packages the canonical Overlay safe-part binding, numerical solver, Web geometry lease and border-box/style ownership implementations. Its private bridge supplies the existing native Anatomy domain and part identities, current physical targets and an implicit Boundary-root lease. Authored code continues to select the semantic target. Rebinding retires stale callbacks; detached views suspend the physical region and geometry while retaining logical intent; terminal disposal removes target subscriptions and declarations. The canonical source paths and hashes are recorded alongside the other native support inputs.

The ordinary `anatomy.descendantsOf` query uses the same current-domain membership and strict logical ancestry as that bridge. It returns ordered safe Parts without requiring mounted host targets; nested same-family domains and forged, foreign, reparented-out or retired ancestors cannot contribute results. Its source operation is a runtime read, available to callbacks and readonly rendering, and does not add a host escape hatch.

Root keyboard samples are listened for on the physical root before host composition can stop bubbling. Global handlers remain on the global input scope, with a guarded active-element fallback for samples dispatched directly there. A sample already delivered on the root cannot deliver that root's semantic key/press path twice. Overlay open observations retain the dismissal reason and the logical owner's notification lifetime across a detached physical view. Bound Presence retains portal, geometry and modal leases through its leaving interval; logical closing still removes the dismissal candidate and applies configured focus restoration. A `focus.outside` close preserves the current external focus destination instead of restoring the previous entry. `asHitParticipation(patch)` forwards the optional declaration patch through the same configure path as the public hook.

Boundary admits both pointer presses and host-proven current focus moves. A document-scoped pointer sequence preserves its initial stack owner across synchronous focus changes and prevents a boundary from emitting a second outside intent for the same unreleased press. Fresh presses, keys, release/cancel and window blur retire that suppression. Focus sampling checks the current deepest observable active element, and unknown or stale samples cannot become outside. Ordinary Boundary observers do not enter the dismissal stack implicitly; Overlay activation controls its own rank, which survives physical suspension until logical deactivation or disposal. View listeners and scope memberships are released independently of retained declarations.

Text Control accepts both input and change candidates in uncontrolled mode and restores rejected controlled candidates after the native callback. Physical and event generations protect composition facts from a replaced lease or a reentrant event. An omitted value patch retains the previous owner value. React supplies canonical text only in initial server markup; once mounted, its private commit handoff reapplies the native control's editing/default fields without requesting a template or host render. This preserves first-paint values, composition, caret and reset defaults while keeping one value owner.

`resetValue` replaces the mounted Text Control's physical event lease, retires composition and stale restoration work, and returns whether it changed the uncontrolled canonical value. Controlled reset retains the current owner value and returns false. `registerSelfRegion` retains a logical, owner-relative Hit Participation declaration and resolves it against each current physical root. Its options are read before selecting the declaration list, releases are idempotent, conflicting replacements roll back, detached views release physical claims, and terminal disposal prevents reacquisition. Web source profiles admit role, mode and metadata; static hit insets remain a compile-time diagnostic rather than being silently dropped.

The live React source profile admits Core's `renderer.svg.root` and `renderer.svg.path` constructors with their finite scalar property schemas, required fields and normal template-child normalization. They create actual native SVG nodes and cannot introduce arbitrary DOM attributes or event handlers through template props. Other SVG constructors and source profiles remain outside this bounded admission.

`artifacts.ts` assembles ordinary ES modules with explicit imports. Capability factories receive only their reached closure. Logical identity must also compose between different closures, so shared registries have stable, separate ABIs:

| Module                  | Shared identity                                           |
| ----------------------- | --------------------------------------------------------- |
| `ownership-v2`          | Logical owners, physical roots, Anatomy parts, host IDs   |
| `focus-ownership-v2`    | Active scopes, request arbitration, entry intent          |
| `boundary-ownership-v2` | Boundary stack, per-sample arbitration and pointer intent |
| `overlay-ownership-v2`  | Modal host locks                                          |
| `hit-ownership-v2`      | Shared physical hit claims                                |
| `table-ownership-v2`    | Table membership/projection records                       |

Only reached registry modules are emitted. Mutable shared counters live in an explicit state record, so separately emitted factories cannot each acquire an independent copy. Plan-specific native/module files use a deterministic plan ID; the generated provenance records its version, ID, and features for exact closure verification and library linking.

`legacy-text-v1.template.ts` and the separate `native-support-legacy.ts` retain historical compatibility bytes. They are not alternative implementations for new compilation. New Text and Image combinations use the canonical templates, which also preserves request-bound image completion, immediate cached-image facts, physical event containment, and cleanup for mixed-capability consumers.

Verification lives in `test/native-support-plan.test.ts` and `test/native-support-capabilities.test.ts`. It checks strict emitted TypeScript for every unit, reached/unreached controls across the four Web emitters, source bytes, production-retained bundles, actual state/listener registration, and view/terminal cleanup. Bundle measurements retain the exported capability factory and include Floating UI when positioning is reached; source size alone is not treated as tree-shaking evidence.
