# V2 Web optical source and emitted-runtime consumer

This fixture uses the owned Previewer material scene and the actual four Web Adapters, mounted directly without the website runtime registry. It compares the source package graph with an emitted public-package graph, while retaining the explicit private Liquid Glass Prototype source. That family is not represented as a published package. The packed build rejects any accidental public-package `/src/` input and records its complete package input graph plus bundled-asset hash.

The background is the visible app-owned canvas, not a DOM screenshot or hidden texture. The fixed audited static shader used by #809 and the separately identified first-party continuous-contact derivative are selected through the V2 host interface. This test does not reinterpret V1 as V2, grant arbitrary capture access, exercise native rendering or claim full Compiler equivalence.

Build with `node --import tsx experiments/material-v2/build-browser.mjs /tmp/pui-material-v2-source`. Build emitted public dependencies first and add `--packed` for the second graph. Run through the existing repository browser harness with `node --import tsx experiments/material-v2/browser.test.mjs <fixture-dir> <evidence-dir>`. The page permits only its localhost origin, has no account data, and is not deployed. The official `V2 Web optical artifact evidence` workflow retains exact-head screenshots and result metadata.

Local source and packed bundles have compiled. Actual GPU execution is pending official CI; the existing local Chromium socket restriction is not bypassed. The separate website material fixture owns deeper zero-refraction/opaque image comparison, >16-surface performance measurements, context loss, source overlap, DPR and preference controls. Neither fixture alone establishes subjective material quality; inspect the actual evidence before acceptance.

## Continuous contact evidence

`continuous-browser.test.mjs` adds a separate exact-bundle run; it does not replace the original light/dark suite. The fixture uses a 32px gap and 28px padding to keep each admitted expanded paint footprint separate from neighboring controls. This is an explicit owned-canvas layout requirement, not an exception to the source guard. Internal observation imports use the same source/emitted graph as the consumer and the packed graph check remains mandatory.

The new run exercises real mouse down/move/out/in/up, release/repress, browser touch cancellation, a fixture-requested real capture loss, window blur, and reduced motion on all four Web Adapters. It measures rAF paint identity, native event trust, image decode/resource counters, source revocation during delayed real decode, resize, actual WebGL context loss/recovery, and disposal. Matched real WebGL images retain full, zero-refraction, zero-deformation, and zero-aberration outputs. Diagnostic control renders are distinct from the real-component screenshots. The first Web Component interaction also retains a CDP frame sequence with native capture timestamps and an MP4 when the runner has ffmpeg. Capture cadence and aggregate timing during screenshots/interruptions do not establish 60fps or perceptual quality.

Run `node --import tsx experiments/material-v2/continuous-browser.test.mjs <fixture-dir> <evidence-dir>` against both source and emitted fixture directories. The official workflow uploads both outputs even after failure. Browser failures preserve the source hash, partial observations and failure image. Local build/type/consumer checks are not browser passes: the current local launcher is blocked by socket permissions, and the separate cloud UI browser cannot reach this executor's localhost. No security setting, alternate socket, or browser URL policy is bypassed. Exact-head official CI and visual inspection remain required. This scope does not establish GPUI, other Prototype controls, the website route, or whole-family Finf completion.
