## Installation

The 0.2.0 stable package exports all five parts from `@proto.ui/prototypes-base/tabs`, and the CLI target `base-tabs` generates `Root`, `List`, `Trigger`, and `Content` (`Indicator` can be imported directly from the package). For styled versions, see [Shadcn Tabs](/en/ui-libraries/shadcn/tabs/) or [Brutalist Tabs](/en/ui-libraries/brutalist/components/tabs/).

## Usage

### Parts

- **Root** (1): Manages selected `value` / `defaultValue`, `orientation`, and `activationMode`, emitting `valueChange`. Pass `value` for controlled mode.
- **List** (0–1): Manages roving focus with orientation-aware arrow navigation, `Home`/`End`, optional wrapping (`loop`), and `a11yLabel`.
- **Trigger** (0+): Declares its `value` and `disabled` state and requests tab activation.
- **Content** (0+): Pairs with `Trigger` by exact `value` (keeping keys like `a+b` and `a b` distinct) and exposes `current` / `hidden`. Inactive panels unmount content when closed (set `keepMounted` to keep the hidden node mounted while hidden from assistive technology).
- **Indicator** (optional): Presentational part exposing current value, active value, and orientation for styled indicator bars.

### Activation modes and accessibility

- `activationMode="automatic"` (default) activates tabs as focus moves; `activationMode="manual"` separates keyboard focus from selection. Disabled triggers are skipped.
- ARIA `tablist`, `tab`, and `tabpanel` links are automatically managed and cleaned up on unmount while preserving caller-provided host IDs. Rely on `value` rather than generated DOM ID formats.

Pass `value` to control the active tab; changes emit `valueChange`.

### Part Props

- **List**: `orientation` (default `'horizontal'`), `loop` (default `false`), `a11yLabel` (default `''`).
- **Trigger**: `value` (default `''`), `disabled` (default `false`).
- **Content**: `value` (default `''`), `keepMounted` (default `false`).
- **Indicator**: No additional props.
