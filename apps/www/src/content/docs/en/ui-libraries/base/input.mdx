Base Input (`base-input-root`) renders a single native `<input type="text">` on the Web, providing controlled/uncontrolled value handling, IME composition events, focus methods, and accessibility props without built-in styling.

## Installation

Available starting in `0.3.0-rc.1` and later releases. Import the default Root, `inputRoot`, or `asInputRoot` from `@proto.ui/prototypes-base/input`. For a styled version, see [Shadcn Input](../../shadcn/input/).

## Usage

### Value ownership and events

- **Uncontrolled**: initialize with `defaultValue`; later updates to unrelated props preserve user edits.
- **Controlled**: pass `value` so edits emit `valueChange` proposals and only commit when your application passes the new `value` back. Ownership mode is fixed at instance creation.
- **Event payloads**: `valueChange` carries `{ value, composing, data, inputType }`, `change` carries `{ value }`, and `compositionStart` / `compositionUpdate` / `compositionEnd` carry `{ value, data }`.

### Resetting the editor (`resetValue`)

Mounted instances expose `resetValue(value?: string): boolean` to reset the active editing and IME composition session without synthesizing `valueChange`, `change`, or `compositionEnd`:

- **Uncontrolled with a string**: resets the text to the supplied string (with CR/LF line breaks stripped) and returns `true`.
- **Uncontrolled with no argument (or `undefined`)**: resets to the latest `defaultValue` (normalized to a single line) and returns `true`.
- **Controlled**: clears any active IME composition session while retaining the controlled `value`, returning `false`. Calling `resetValue` on an unmounted/detached view or with a non-string value also returns `false`.

Use **Set latest default**, **Reset to default**, **Reset to sample**, and **Try controlled reset** in the preview to inspect these behaviors.

### Focus and exposed state

Exposed APIs include `focusSelf()`, `blurSelf()`, and `resetValue(value?)`, plus the `value`, `disabled`, `readOnly`, `focused`, `focusVisible`, and `composing` states. Use `inputMode` and `enterKeyHint` to provide virtual-keyboard hints.
