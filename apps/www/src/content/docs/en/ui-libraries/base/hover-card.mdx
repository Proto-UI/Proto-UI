Base Hover Card displays supplementary preview content after a configurable hover or focus delay. Composed of `Root`, `Trigger`, and `Content`, it provides portal rendering, anchor positioning with collision handling, and unmount-after-transition lifecycle management.

## Installation

Available starting in `0.3.0-rc.1` and later releases. In the workspace, the CLI target is `base-hover-card`.

## Usage

### Anatomy and interaction

- **`Root`**: manages open state (controlled `open` or uncontrolled `defaultOpen`), `openDelay` / `closeDelay`, and `openChange`, and exposes `openHoverCard()`, `close()`, `toggle()`, and the part-coordination method `releaseInteraction(part, contributionId)`.
- **`Trigger`**: opens the card on hover or focus; set `disabled={true}` to suppress opening.
- **`Content`**: renders inside a Portal with `side`/`align` placement, numeric offsets, and collision avoidance, unmounting only after leave transitions finish.

### Controlled state and remounting

- Pass `open` for controlled mode: after `openDelay` or `closeDelay`, `Root` emits `openChange` so your application can update `open`.
- Unmounting or remounting `Trigger` or `Content` clears only that part's active hover/focus contribution without replaying stale hover state.

## API

### Root Props

Passing `open` selects controlled mode.

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'open', type: 'boolean', default: '—' },
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'openDelay', type: 'number', default: '700' },
    { name: 'closeDelay', type: 'number', default: '300' },
  ]}
/>

### Other parts

- **Trigger**: `disabled` defaults to `false`.
- **Content**: accepts Transition props; defaults `side` to `'bottom'`, `align` to `'center'`, `sideOffset` to `4`, `alignOffset` and `collisionPadding` to `0`, and `avoidCollisions` to `true`.
