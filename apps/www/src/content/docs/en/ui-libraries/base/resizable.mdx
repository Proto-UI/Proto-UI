Splits a container into two or more percentage-sized panels separated by draggable, keyboard-accessible resize handles, supporting constraints, collapse stops, and nested panel groups.

## Installation

Available starting in `0.3.0-rc.1` and later releases.

## Usage

Compose `Root`, `Panel`, and `Handle`:

- **Indexing panels and handles**: Provide `N` panels with `index: 0..N-1` and `N-1` handles with `index: 0..N-2`. Each `Handle` adjusts only its adjacent pair of panels while preserving every other panel's size, and carries the default accessible name `Resize panels`.
- **Sizing and layout**: `sizes` / `defaultSizes` hold the full percentage array summing to `100` (the legacy two-panel `value` / `defaultValue` props remain supported, with `sizes` taking precedence when supplied). Each `Panel` exposes a dimensionless `size` state consumed by static CSS rules via `--pui-size`; drag normalization uses total panel border-box length, excluding fixed handle widths.
- **Constraints and interaction**: Pointer dragging, arrow keys, `Home`/`End`, `Shift` acceleration, and collapse stops share the same constraint solver. Pass per-panel `constraints` with `min` (default `0`), `max` (default `100`), `collapsible` (default `false`), and `collapsedSize` (default `0`). Infeasible layouts keep the previous valid sizes, and collapse stops respect adjacent panel maximums.
- **Controlled mode and nesting**: Pass `sizes` for controlled layouts and listen to `sizesChange` / `sizesCommit` (payload `{ sizes }`). Update `sizes` to accept a proposal or keep the existing value to reject it; canceled gestures do not emit `sizesCommit`. Nested `Root` instances manage independent ratios, orientations, and constraints.

## API

### Root

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'defaultValue', type: 'number', default: '50' },
    { name: 'min', type: 'number', default: '10' },

    { name: 'step', type: 'number', default: '1' },
    { name: 'collapsible', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'readOnly', type: 'boolean', default: 'false' },
    { name: 'orientation', type: "'horizontal' | 'vertical'", default: 'horizontal' },
    { name: 'direction', type: "'ltr' | 'rtl'", default: 'ltr' },
  ]}
/>

Multi-panel mode also accepts `sizes`, `defaultSizes`, and `constraints`. `Panel` and `Handle` accept `index` (default `0`).

- **Exposed state and methods**: Read `sizes`, or call `requestResize(index, nextSize, commit)` / `requestSizes(nextSizes, commit)`.
- **Events**: `sizesChange`, `sizesCommit` (payload `{ sizes }`).
