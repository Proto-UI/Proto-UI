Base Calendar is an unstyled Gregorian calendar supporting `single` (default), `multiple`, and `range` selection modes. Dates use `YYYY-MM-DD` and the visible `month` uses `YYYY-MM`, with independent controlled state for both selection and month.

## Usage

### Anatomy

Compose ten parts: `Root`, `Caption`, `Heading`, `Previous`, `Next`, `Grid`, `Weekdays`, `Weekday`, `Row`, and `Day`.

- Place seven `Weekday` parts (`offset` `0`–`6`) inside `Weekdays`, and up to six indexed `Row` parts (`index` `0`–`5`) containing `Day` parts (`offset` `0`–`41`) inside `Grid`.
- By default, Calendar renders only the 4, 5, or 6 weeks needed for the visible month; set `fixedWeeks={true}` to always reserve six weeks. Unused rows and day cells are hidden and excluded from focus.
- Weekday labels and date ordering follow `weekStartsOn` (`0` = Sunday) and `locale`. `direction="rtl"` mirrors Left/Right arrow navigation.

### Selection modes and controlled state

- **Single (`single`)**: controlled via `value` / `defaultValue` (`YYYY-MM-DD`); emits `onValueChange({ value })`.
- **Multiple (`multiple`)**: controlled via `values` / `defaultValues` (deduplicated, sorted date array); emits `onValuesChange({ values })`. Constrain selection size with `minSelected` and `maxSelected`.
- **Range (`range`)**: controlled via `range` / `defaultRange` (`{ from?, to? }`); emits `onRangeChange({ range })`. The first click sets `{ from }`, the second completes an ordered inclusive `{ from, to }`, and `{}` clears it. Use `minNights` / `maxNights` to constrain the interval between endpoints (`minNights=0` allows a same-day range).

`min`, `max`, and `Root` `unavailable` apply across all modes. A range crossing an unavailable date is rejected while keeping its start anchor. `readOnly` disables selection while still allowing month navigation.

### Clock and caption composition

- Calendar never reads the system clock directly: pass `today` as a `YYYY-MM-DD` string to mark the current day (`aria-current="date"`).
- Initial visible month resolves in order: `month` → `defaultMonth` → active mode's selected date → `today` → `1970-01`.
- For month/year dropdowns, compose real family Select controls inside `Caption` and wire them with `bindCalendarCaption(source, { month, year })` using Calendar's public month state and `requestMonth` (call `dispose()` on teardown).

### Exposed state and methods

- `Root` exposes `mode`, `weekCount`, `selectedCount`, `rangeComplete`, plus `requestMonth`, `requestValue(date)`, `requestValues(dates)`, `requestRange(range)`, `getValues()`, and `getRange()`.
- `Day` exposes `selected`, `rangeStart`, `rangeEnd`, `rangeMiddle`, and `rangePending`. `Grid` sets `aria-multiselectable` in `multiple` and `range` modes.

### Other parts

- **Day**: `date` defaults to `''`, `offset` to `0`, and `disabled` to `false`.
- **Row**: `index` (no default).
- **Caption**: `a11yLabel` defaults to `'Calendar navigation'`.
- **Previous / Next**: accept Button props; `a11yLabel` defaults to `'Previous month'` and `'Next month'`.
- **Weekday**: `offset` defaults to `0`.
- **Grid, Heading, Weekdays**: no props.
