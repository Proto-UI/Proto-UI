## Usage

### Anatomy

Compose `Root`, `Item`, and `All`:

- `Root` manages the selected string array (`value` / `defaultValue`), `disabled` / `readOnly` policies, and `ariaLabel`. Calling `getValue()` returns a copy of the array.
- `Item` binds an option by unique `value` and supports its own `disabled` prop. Duplicate item values ignore ambiguous toggles.
- `All` derives checked/mixed state from all enabled items and preserves disabled items' selections when toggling.

### Controlled state, keyboard, and forms

- Pass `value` for controlled mode: user toggles emit `valueChange` without mutating the controlled prop directly.
- Each item is its own Tab stop and toggles on `Space` (`Enter` does not toggle).
- Inside a `Field` or `FormField`, `Root` integrates with label activation, required validation, form serialization, and reset.

- **Item**: accepts `value` and `disabled`.
- **All**: no props; automatically tracks enabled items in the group.
