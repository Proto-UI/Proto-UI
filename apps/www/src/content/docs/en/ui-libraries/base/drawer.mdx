## Usage

### Sizing and scroll layout

- `top` / `bottom` drawers size to their content by default within the safe available height; `left` / `right` drawers use fractional width (default max of 20 `root-text` units).
- Configure drawer dimensions via `Content` `minExtent` and `maxExtent` (rather than standalone CSS width/height) using `'logical'`, `'root-text'`, `'available'`, or `'available-minus-root-text'` units—for example `maxExtent={{ unit: 'logical', value: 480 }}`.
- `Content` acts as an `overflow-y-auto` scroll container so long content remains scrollable inside the sheet.
- When placing `Root` directly inside a CSS grid, set `hostStyle={{ display: 'contents' }}` in React (or `display: contents` on Web Components) to avoid an empty grid track.

### Drag dismissal and snap points

- Passing a non-empty array of fractions in `(0, 1]` to `snapPoints` enables multi-stop snapping (automatically sorted and deduplicated). Omitting `snapPoints` on `top` / `bottom` keeps content-fit sizing.
- Control snap positions via `defaultSnapPoint` (uncontrolled) or `snapPoint` + `snapPointChange` (controlled). Explicit snap mode gives `Handle` named separator semantics with arrow keys and `Home` / `End`; content-fit mode keeps `Handle` as a pointer drag affordance.
- Set `dragDismissible={false}` on `Content` to disable drag dismissal while retaining `Close`, `Escape`, and outside-click dismissal.
- Pass `open` for controlled mode: interrupted drags or rejected close requests smoothly return to the current committed state.

### Other parts

- **Mask**: `passthrough` defaults to `false`, plus Transition props.
- **Content**: `side` defaults to `'bottom'`, plus `minExtent`, `maxExtent`, `snapPoints`, `snapPoint`, `defaultSnapPoint`, `dragDismissible`, and Transition props.
- **Handle**: `disabled` defaults to `false`, `a11yLabel` defaults to `'Resize drawer'`.
- **Trigger, Title, Description, Header, Footer, Close, AcceptedSide**: no props.
