Base Label binds one-to-one with a target control through an explicit reference—no manual DOM IDs required—giving you independent control over accessible `naming` and pointer `activation`.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import from `@proto.ui/prototypes-base/label` or generate wrappers in the workspace with the `base-label` CLI target (`wc`, `react`, `vue`, `vue2`).

## Usage

### Independent naming and activation

- **`naming`** (default `true`): associates the target control's accessible name with the rendered Label (if the target already provides a non-empty `ariaLabel` / `labelledBy`, that explicit name takes precedence).
- **`activation`** (default `true`): clicking a paired Label triggers the target's native action—toggling Checkbox / Switch, selecting a Radio Group Item, or focusing Input / Textarea (including read-only inputs). Set `activation={false}` for passive naming only.
- **`selection`** (default `'policy'`): prevents accidental text selection on actionable labels; set `selection="text"` if the label text should remain copyable.
- Label adds no `button` role or extra Tab stop, and ignores nested interactive elements, modified clicks, drags, and canceled clicks.

### Pairing a label and control

Create a stable reference with `createControlLabelRef()` from `@proto.ui/core` for each label–control pair (each reference pairs one live Label with one live target):

- **React / Vue / Vue 2**: pass `instanceAssociations: { controlLabel: ref }` to both components (handled at the adapter boundary outside ordinary props).
- **Web Components**: call `setElementAssociations(el, { controlLabel: ref })` from `@proto.ui/adapter-web-component` on both the target and the Label.

Supported target controls: `Checkbox`, `Switch`, `Radio Group Item`, `Input`, `Textarea`, `Button`, `Toggle`, and `Toggle Group Item`.
