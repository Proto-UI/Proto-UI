## Usage

### Anatomy

Compose `Root`, `Input`, `Content`, `Item`, `Empty`, and `Trigger`:

- `Root` tracks both the committed `value` and the live query `inputValue`.
- Choosing a suggestion commits its `textValue`; pressing `Enter` with no active match commits the current free text.
- Built-in filtering matches `textValue` and `keywords` case- and diacritic-insensitively. Set `filter={false}` to supply pre-filtered items from your application.
- `Empty` reflects whether any items match; disabled and duplicate-valued items cannot be committed.

### Controlled state and keyboard behavior

- `value`, `inputValue`, and `open` can each be controlled independently via their matching change events.
- `Input` keeps focus during arrow-key navigation, and active IME composition never triggers selection.

### Other parts

- **Input**: `placeholder`, `a11yLabel`, and `name` default to `''`.
- **Content**: `side` defaults to `'bottom'`, `align` to `'start'`, `sideOffset` to `4`, and `collisionPadding` to `8`.
- **Item**: `value`, `textValue`, and `keywords` default to `''`; `disabled` defaults to `false`.
- **Empty**: no props.
- **Trigger**: `disabled` defaults to `false`.
