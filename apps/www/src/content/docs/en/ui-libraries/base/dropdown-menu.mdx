Base Dropdown Menu is a button-triggered action menu. `Root` manages visibility, item ordering, and focus entry policy, while `Content` handles overlay positioning, transitions, keyboard navigation, and typeahead.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import from `@proto.ui/prototypes-base/dropdown` or use the workspace CLI target `base-dropdown` to generate `Root`, `Trigger`, `Content`, and `Item` (`Group`, `Label`, `Separator`, and `Shortcut` are exported directly from the package).

## Usage

### Anatomy

- **`Root`**: manages open state and item collection, exposing `openDropdown()`, `close()`, `toggle()`, `requestOpen()`, and `openChange`. In controlled mode, pass `open` to commit visibility changes.
- **`Trigger`**: button that opens or toggles the menu.
- **`Content`**: floating surface providing positioning, transitions, arrow navigation, and typeahead.
- **`Item`**: executable command item that emits `select` on activation. Closing the menu clears transient active state so reopening always follows the configured `openEntry` policy.
- **`Group`, `Label`, `Separator`, `Shortcut`**: passive grouping and labelling parts (`Shortcut` renders a visual key hint without registering global keybindings).

### Guidelines

Use Dropdown Menu for button-opened actions and commands rather than primary navigation or persistent selection. For a styled implementation, see [Brutalist Dropdown Menu](/en/ui-libraries/brutalist/components/dropdown-menu/).

### Other parts

- **Trigger**: no props.
- **Content**: accepts Transition props; defaults `side` to `'bottom'`, `align` to `'center'`, `sideOffset` to `4`, `alignOffset` and `collisionPadding` to `0`, `avoidCollisions` to `true`, and `excludeAnchorTranslation` to `false`.
- **Item**: `disabled` defaults to `false`, `value` and `textValue` default to `''`; optional `closeOnCommit` overrides the `Root` policy.
- **Group**: `a11yLabel` defaults to `''`.
- **Label, Separator, Shortcut**: no props.
