`base-async-region-root` is a lightweight async accessibility container that synchronizes `aria-busy` from its `busy` prop and exposes a `busy` state handle.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. In the workspace, the CLI target is `base-async-region`.

## Usage

`base-async-region-root` accepts a single `busy` prop (default `false`) and keeps both `aria-busy` and `getExposes().busy` in sync:

- `busy={false}` (default): sets `aria-busy="false"`.
- `busy={true}`: sets `aria-busy="true"`.

### Preserving children and focus

When updating props, your child elements and current focus stay intact. For example, during an inbox refresh you can keep a draft input and a Retry button inside the same Async Region and simply toggle `busy`:

- Setting `busy={true}` does not disable inner controls or make the region inert—disable specific controls in your application when needed.
- For spoken status updates, compose a Live Region in your application and clear `busy` once content updates finish.

## API

These props belong to `Root` (`base-async-region-root`), which also exposes the live state handle via `getExposes().busy`.
