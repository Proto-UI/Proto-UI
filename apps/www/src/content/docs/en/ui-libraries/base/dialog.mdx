The Dialog family provides protocol-layer building blocks for modal windows. Root owns the open state; this page does not introduce a non-modal `modal` switch.

- **dialog-root**: Holds the `open` state and provides context to all child parts.
- **dialog-trigger**: Opens or toggles the dialog on click.
- **dialog-mask**: Renders the backdrop mask and follows the open state for enter/leave transitions.
- **dialog-content**: Handles focus trapping, overlay dismissal strategies (ESC, outside press), and enter/leave transitions.
- **dialog-title**: Semantic title automatically linked to content via `aria-labelledby`.
- **dialog-description**: Semantic description automatically linked to content via `aria-describedby`.
- **dialog-close**: Closes the dialog on click.

Pass `alert` to `dialog-root` to turn it into an alert dialog: it sets `role="alertdialog"` and disables outside-press dismissal while keeping ESC close.

## Draft workspace Mask behavior

The workspace revision of `P-BASE-DIALOG-MASK-DEFAULT-ACTION` keeps Content as the independent focus/dismissal owner. A participating Mask requests default-action prevention for its root-scoped `pointer.down`, so the background pointer default cannot overwrite Content's close-time focus restoration. A Mask with `passthrough=true` does not request this prevention. Mask does not take over dismissal, propagation or keyboard handling, and does not promise to distinguish arbitrary native descendants that lack an independent interaction owner inside it.

This is the draft workspace behavior introduced by [PR #777](https://github.com/Proto-UI/Proto-UI/pull/777), not a claim about the previously published 0.2 package. A decorative [Surface](/en/ui-libraries/base/surface/) can consume existing Transition facts for paint; it must not become another Dialog, focus or dismissal owner.

## API

Dialog is workspace source. There is no public `proto-ui add` target. Passing `open` selects controlled mode.

These props belong to Root. Mask accepts `passthrough` (`false`) plus the Transition props. Content defaults `focusEntry` to `auto` and also accepts the Transition props. Trigger, Title, Description and Close have no props.
