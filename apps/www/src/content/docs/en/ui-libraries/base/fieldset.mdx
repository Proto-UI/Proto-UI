## Installation

Available starting in `0.3.0-rc.1` and later releases.

## Usage

### Anatomy

Compose `Root`, `Legend`, and `Description`:

- **`Root`**: declares the `group` role and computes effective `disabled`, named by `ariaLabel` or a child `Legend`.
- **`Legend`** (optional): passive group heading automatically linked via `aria-labelledby`, adding no extra Tab stop.
- **`Description`** (optional): passive help text automatically linked via `aria-describedby`.
- Each group allows at most one `Legend` and one `Description`; nested Fieldsets keep their naming and description links isolated.

### Nested disabled inheritance

`disabled` propagates downward to nested Fieldsets and participating `Field` controls (including any field placed inside a `Legend`):

- Disabling an outer Fieldset disables all nested groups inside it.
- If a middle group is also disabled and the outer group is re-enabled, the middle and inner groups stay disabled.
- A group becomes enabled only when both its ancestors and its own `disabled` prop are `false`.
