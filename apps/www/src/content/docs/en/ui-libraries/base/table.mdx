## Usage

### Parts

| Part | Cardinality | Responsibility |
| --- | --- | --- |
| `Root` | 1 | Establishes an independent table domain and maintains its structural snapshot. |
| `Caption` | 0–1 | Provides the accessible table caption. |
| `Row` | 1+ | Represents an ordered logical row (containing at least one `HeaderCell` or `Cell`). |
| `HeaderCell` | 1+ | Declares a column or row header (`headerKind`), domain-unique `headerKey`, and spans. |
| `Cell` | 1+ | Declares spans and an ordered list of associated header keys (`headers`). |

`Caption`, `HeaderCell`, and `Cell` render your children unchanged through their default slot. For sorting, row selection, pagination, virtualization, or keyboard grid navigation, compose on top of [Data Table](../data-table/).

### Topology and header resolution

- **Deterministic placement**: Rows and cells follow their mounted order. The first cell in a row starts at column `0`, and each subsequent cell places at the first available slot at or after the previous cell's end—never backfilling earlier holes out of order. `rowSpan` and `columnSpan` are positive safe integers defaulting to `1` and must not overlap occupied cells or exceed the row count.
- **Multi-header and layered headers**: Each `HeaderCell` declares a non-empty, table-unique `headerKey` and `headerKind` (`'column' | 'row'`), and may reference upstream headers in `headers` for layered headers. Each `Cell` lists one or more `headerKey` values in `headers`, which automatically project to ARIA row/column counts, indices, spans, and ordered header references.
- **Isolation and live updates**: Header resolution stays strictly within the nearest `Root` so nested or sibling tables never collide. Inserting, removing, or reordering parts recomputes the snapshot; if structure is temporarily invalid, structural roles and coordinates are cleared while preserving your children until valid structure is restored.

## API

### Root

<ApiPropsTable headers={{ name: 'Prop', type: 'Type', default: 'Default' }} rows={[]} />

### Part Props

- **Caption**, **Row**: No additional props.
- **Cell**: `headers` (default `[]`), `rowSpan` (default `1`), `columnSpan` (default `1`).
- **HeaderCell**: `headerKey` (default `''`), `headerKind` (default `'column'`), `headers` (default `[]`), `rowSpan` (default `1`), `columnSpan` (default `1`).
