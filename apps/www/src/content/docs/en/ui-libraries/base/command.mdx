Base Command renders an inline, searchable list of executable commands. Pressing `Enter` or clicking an item emits `execute` with the selected command for your application to handle.

## Installation

Available starting in `0.3.0-rc.1` and later releases.

## Usage

### Anatomy

Compose `Root`, `Input`, `Content`, `Item`, and `Empty`:

- The command list stays inline and open by default (`defaultOpen={true}`); typing filters items without executing them.
- Built-in filtering matches `textValue` and `keywords` case- and diacritic-insensitively. Set `filter={false}` to filter items yourself.
- `Empty` reflects whether any items match; disabled and duplicate-valued items cannot execute.

### Controlled state and keyboard behavior

- `value`, `inputValue`, and `open` can each be controlled independently.
- `Input` keeps focus during arrow-key navigation, and active IME composition never triggers command execution.

### Other parts

- **Input**: `placeholder`, `a11yLabel`, and `name` default to `''`.
- **Content**: `side` defaults to `'bottom'`, `align` to `'start'`, `sideOffset` to `4`, and `collisionPadding` to `8`.
- **Item**: `value`, `textValue`, and `keywords` default to `''`; `disabled` defaults to `false`.
- **Empty**: no props.
