`base-live-region-root` is a lightweight accessibility container that synchronizes `role`, `aria-live`, and `aria-atomic` from its `politeness` and `atomic` props.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. In the workspace, the CLI target is `base-live-region`.

## Usage

Render your dynamic announcement text as child content inside `base-live-region-root`. The container maps its two props directly to ARIA live-region attributes:

- **`politeness`**: `'polite'` (default) sets `role="status"` and `aria-live="polite"`; `'assertive'` sets `role="alert"` and `aria-live="assertive"`.
- **`atomic`**: `true` (default) sets `aria-atomic="true"` (announcing the whole region on change); `false` sets `aria-atomic="false"`.

When updating props, all three ARIA attributes update synchronously while preserving your child content. For async loading workflows, compose Live Region alongside [Async Region](../async-region/).
