## Usage

Compose `Root`, `Trigger`, `Content`, and `Item`:

- **Panel pairing**: `Root` manages the active panel state via `value`, pairing each `Trigger` and `Content` that share the same `value`.
- **Controlled and uncontrolled**: Pass `value` for controlled mode (interactions emit change requests without mutating external state), or use `defaultValue` for an uncontrolled initial panel.
- **Keyboard and focus**: The bar uses a single roving tab stop with Left/Right movement across triggers, `ArrowDown`/`ArrowUp` to enter a panel, and vertical navigation with typeahead inside menus. `Escape` closes the panel and restores focus to its trigger; outside press and item selection also dismiss the panel.

Pass `value` to control the active panel identifier.

### Part Props

- **Trigger**: `value` (default `''`), `disabled` (default `false`).
- **Content**: `value` (default `''`), `a11yLabel` (default `''`), `sideOffset` (default `4`).
- **Item**: `value` (default `''`), `textValue` (default `''`), `disabled` (default `false`), `closeOnSelect` (default `true`).
