## Installation

Available starting in `0.3.0-rc.1` and later releases.

## Usage

Compose `Root`, `Item`, `Group`, and `Toggle`:

- **Keys and branch hierarchy**: Each node declares a tree-unique `nodeKey` and optional `parentKey` (duplicate keys, missing parents, and cycles are ignored without corrupting valid state). Give each `TreeGroup` the same `nodeKey` as its owning branch `Item` and place child items inside it with `parentKey` pointing to that branch.
- **Keyboard navigation and RTL**: `ArrowUp`/`ArrowDown`, `Home`/`End`, and typeahead move focus in logical visible order. In LTR mode, `ArrowRight` expands or enters a child and `ArrowLeft` collapses or returns to the parent; setting `direction="rtl"` swaps horizontal keys automatically (and styled group indentation follows writing direction).
- **Collapse and focus safety**: Scoped `aria-controls` and `aria-labelledby` links between `Item` and `Group` are maintained and cleaned up automatically. Collapsing a branch hides its `Group` while preserving the hierarchy; if focus was inside the collapsed branch, focus moves to the nearest visible ancestor without disturbing focus outside the tree.
- **Controlled and read-only**: Pass `value` or `expandedKeys` for controlled mode. `readOnly` blocks selection changes while keeping navigation and expansion enabled. Adding, moving, or removing items updates the hierarchy without emitting synthetic user selection events.

  ]}

Pass `value` or `expandedKeys` to control selection or expanded branches.

### Part Props

- **Item**: `nodeKey` (default `''`), `parentKey` (default `''`), `textValue` (default `''`), `disabled` (default `false`).
- **Group**: `nodeKey`.
- **Toggle**: Also accepts `Button` props.
