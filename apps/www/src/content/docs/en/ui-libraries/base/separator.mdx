## Installation

The 0.2.0 stable package exports `separatorRoot` and `asSeparatorRoot()` from `@proto.ui/prototypes-base/separator`, with CLI target `base-separator`. For a styled version, see [Brutalist Separator](/en/ui-libraries/brutalist/components/separator/).

## Usage

- **Orientation and accessibility**: Set `orientation` to `'horizontal'` or `'vertical'`, and choose whether the divider is purely decorative (`decorative={true}`, hidden from the accessibility tree) or meaningful (`decorative={false}`, rendering `role="separator"` with its orientation).
- **Contentless boundary**: `separatorRoot` exposes no focus stop, events, or child slot so decorative dividers cannot accidentally hide your content from assistive technology.
