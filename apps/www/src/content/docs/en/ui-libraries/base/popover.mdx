## Usage

Compose `Root`, `Trigger`, `Content`, `Title`, `Description`, and `Close`:

- **Positioning and non-modal behavior**: `Content` positions relative to `Trigger` with `side`, `align`, `sideOffset`, `alignOffset`, and `collisionPadding`. Because it is non-modal, background scrolling stays active and `Tab` focus is not trapped.
- **Dismissal and focus**: Outside press, focus leaving `Trigger` and `Content`, `Escape`, and `Close` all request dismissal. Moving focus between `Trigger` and portalled `Content` counts as internal interaction; closing due to focus leaving keeps focus on the newly focused outside element instead of pulling it back to `Trigger`.
- **Controlled and uncontrolled**: Use `defaultOpen` for uncontrolled state, or pass `open` and handle `openChange` for controlled state (focus-only dismissal requests report `focusReason` as `'programmatic'`). If a controlled handler declines a `focus.outside` request, `Content` stays visible without trapping focus and later interactions can still request dismissal. Disabled triggers do not activate.

Pass `open` to control the open state.

### Part Props

- **Content**: Accepts `Transition` props plus `side` (default `'bottom'`), `align` (default `'center'`), `sideOffset` (default `4`), `alignOffset` (default `0`), and `collisionPadding` (default `8`).
- **Trigger**, **Title**, **Description**, **Close**: No additional props.
