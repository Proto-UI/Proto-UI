An unstyled single-selection dropdown following the APG select-only combobox pattern: `Trigger` exposes `combobox`, `Content` exposes `listbox`, `Item` exposes `option`, and `Value` renders the selected label or placeholder automatically.

## Installation

Available starting in `0.3.0-rc.1` and later releases (CLI target: `base-select`).

The preview code panels use `@proto.ui/cli`, `@proto.ui/prototypes-base`, `@proto.ui/prototypes-lucide`, and the matching host Adapter package (Vue 2 uses Vue `>=2.6.0 <2.7`):

| Host           | Adapter package                   | Example file  |
| -------------- | --------------------------------- | ------------- |
| Web Components | `@proto.ui/adapter-web-component` | `index.html`  |
| React          | `@proto.ui/adapter-react`         | `src/App.tsx` |
| Vue            | `@proto.ui/adapter-vue`           | `src/App.vue` |
| Vue 2          | `@proto.ui/adapter-vue2`          | `src/App.vue` |

For first-time setup, run the matching CLI to generate `src/styles/proto-ui-style.css` (keep a single import if your app entry already loads it):

```sh
node node_modules/@proto.ui/cli/bin/proto-ui.js init --yes --no-interactive --prototypes shadcn
```

In each host, Web Components supply `accessibleLabel`, `placeholder`, and item values via `setElementProps` before connecting elements; React passes `createPortal` from `react-dom` to `createReactAdapter` for `Content` portalling; Vue and Vue 2 register each component part. Set `accessibleLabel` on `Trigger` to keep the accessible name independent of the selected option.

## Usage

### Parts

- `select-root`: Manages controlled or uncontrolled `open`, `value`, and `textValue` and arbitrates change requests.
- `select-trigger`: Command surface providing combobox ARIA and pointer/keyboard toggle handling.
- `select-value`: Renders `displayValue` or `placeholder` automatically via explicit updates without requiring manual text rendering.
- `select-content`: Composes overlay, transition, roving focus, and anchor positioning.
- `select-item`: Renders an option that keeps transient navigation focus (`active`) distinct from committed selection (`selected`).
- **Optional grouping and layout parts**: `select-surface`, `select-viewport`, and `select-item-text` provide explicit alignment structure; `select-group` and `select-label` scope accessible group labels (missing or duplicate labels are ignored, and nested selects stay isolated); `select-separator` renders a decorative, accessibility-hidden divider (return an empty renderer when composing `asSelectSeparator`). These also export `asSelectGroup`, `asSelectLabel`, and `asSelectSeparator`.

### Keyboard, pointer, and touch interaction

Opening the listbox focuses the currently selected item (or the boundary item when unselected) and supports arrow keys, `Home`/`End`, and typeahead. `Escape`, `Tab`, and outside press dismiss the popup and restore focus as appropriate.

Pass `open` or `value` to control popup visibility or the selected value.

### Part Props

- **Trigger**: `accessibleLabel` (default `''`).
- **Value**: `placeholder` (default `''`).
- **Content**: Accepts `Transition` props plus `position` (default `'popper'`), `side` (default `'bottom'`), `align` (default `'center'`), `sideOffset` (default `4`), `alignOffset` (default `0`), `avoidCollisions` (default `true`), and `collisionPadding` (default `10`).
- **Item**: `disabled` (default `false`), `value` (default `''`), `textValue` (default `''`), `closeOnSelect` (inherits `Root` when omitted).
- **Group**, **Label**, **Surface**, **ItemText**, **Viewport**, **Separator**: No additional props.
