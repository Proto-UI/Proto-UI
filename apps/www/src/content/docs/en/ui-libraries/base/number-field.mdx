## Installation

Available starting in `0.3.0-rc.1` and later releases.

## Usage

Compose `Root`, `Label`, `Input`, `Control`, `Increment`, and `Decrement`:

- **Editing and stepping**: `Root` manages the `number | null` value. `Input` provides a spinbutton text editor that preserves incomplete drafts while typing and commits a valid number (or restores the last accepted value) on blur or `Enter`. `Increment`/`Decrement` and `ArrowUp`/`ArrowDown` step by `step` (`Shift` multiplies by 10); `Home`/`End` jump to bounds when set, or keep native cursor movement when unbounded. Pass `value` for controlled mode.
- **Formatting and IME**: `locale` and `formatOptions` support decimal, currency, and percent formatting and parsing (including localized separators, digits, and signs) without altering underlying numeric precision. Invalid formatting options set `formatInvalid` and fall back to ungrouped decimals. Active IME composition pauses parsing, commits, stepping, and scrubbing while preserving composition text across locale changes.
- **Nullable values**: Explicit `null` represents an empty value, and `value={null}` stays controlled. Set `allowEmpty` to request `null` when clearing and committing the input. Read `getValue(): number | null` and `empty` for exact state (the compatibility numeric `value` readout reflects the number when `empty` is `false`, while events and `Field`/`Form` always receive `null`). Stepping from `null` initializes at snapped `0` within bounds.
- **Label scrubbing**: Enable `scrub` to adjust the value continuously by dragging `Label`. `scrubSteps` (default `100`) sets the number of steps per initial label width, and `direction="rtl"` reverses horizontal drag direction. Releasing after a change commits once; canceling restores the uncontrolled start value while keeping normal text selection in the input.
- **Form integration**: Use `Control` instead of `Input` inside `Field`/`FormField` to integrate `FieldLabel`, `required`, numeric validation, serialization, and reset. Use `Label` with standalone `Input`.

`Label`, `Input`, `Control`, `Increment`, and `Decrement` add no props of their own.

- **Bounds and snapping**: Omitted `min`/`max` default to `0`/`100`; pass `null` to remove a bound. Setting `snapToStep={false}` preserves finite initial and edited values while `step` still controls increments.
- **Required resolution**: `required` combines with any enclosing `Field` requirement and applies to both the native editor and accessibility attributes.
