## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release (workspace CLI target: `base-text`). Import `textRoot` (along with `asTextRoot`, `TextRootProps`, and `TextRootExposes`) from `@proto.ui/prototypes-base/text` or the package root.

## Usage

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { textRoot } from '@proto.ui/prototypes-base/text';

const Text = createReactAdapter(React)(textRoot, { rootTag: 'span' });

export function SectionTitle() {
  return (
    <h1>
      <Text size="4xl" font="heading" weight="semibold" leading="tight" tracking="tight">
        Account settings
      </Text>
    </h1>
  );
}
```

### Semantic wrappers and typography rules

- **Keep native document semantics**: `rootTag: 'span'` is a Web Adapter option. Keep headings (`<h1>`), paragraphs (`<p>`), labels (`<label htmlFor>`), and links (`<a href>`) on native host elements; `Text` adds no focus stop or activation handler.
- **Foreground inheritance**: Set `tone="inherit"` on styled `Text` inside `solid` or `accent` `Surface` containers so it inherits the enclosing foreground color.
- **Size and line height**: Removing a prop restores its default. An initially invalid `size` falls back to `'base'`, while an invalid update after a valid value retains the previous value. `leading="size"` keeps the size's built-in line box (in Shadcn and Brutalist, `xs` through `5xl` map to `1rem`, `1.25rem`, `1.5rem`, `1.75rem`, `1.75rem`, `2rem`, `2.25rem`, `2.5rem`, and `1`); `leading="tighter"` selects `1.1` and `tracking="tighter"` selects `-0.05em`.
