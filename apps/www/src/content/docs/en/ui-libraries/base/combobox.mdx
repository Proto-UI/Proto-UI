Base Combobox pairs a single-line search input with a filterable option list. The selected option key (`value`) stays separate from the editable query text (`inputValue`), so unmatched text is never silently committed as an option.

## Installation

Available starting in `0.3.0-rc.1` and later releases.

## Usage

### Anatomy

Compose `Root`, `Input`, `Content`, `Item`, `Empty`, and `Trigger`:

- `Root` tracks the selected item key (`value`), editable query (`inputValue`), and popup state (`open`).
- Built-in filtering matches `textValue` and `keywords` case- and diacritic-insensitively. Set `filter={false}` to filter items in your application.
- `Empty` reflects whether any items match; disabled and duplicate-valued options cannot be committed.

### Controlled state and keyboard behavior

- `value`, `inputValue`, and `open` can each be controlled independently via their change events.
- `Input` retains focus during arrow-key navigation, and active IME composition never triggers selection.

### Other parts

- **Input**: `placeholder`, `a11yLabel`, and `name` default to `''`.
- **Content**: `side` defaults to `'bottom'`, `align` to `'start'`, `sideOffset` to `4`, and `collisionPadding` to `8`.
- **Item**: `value`, `textValue`, and `keywords` default to `''`; `disabled` defaults to `false`.
- **Empty**: no props.
- **Trigger**: `disabled` defaults to `false`.
