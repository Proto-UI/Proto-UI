Base Input OTP provides a one-time code input backed by a single native text editor—preserving native selection, paste, deletion, `one-time-code` autofill, and IME composition—while rendering each character in passive `Slot` readouts.

## Usage

### Anatomy

Compose `Root`, `Input` (or `Control` inside a form), `Slot`, and `Separator`:

- **`Root`**: manages `value` / `defaultValue`, code `length` (`1`–`32`, default `6`), `pattern` (`'numeric'` or `'alphanumeric'`), `disabled`, `readOnly`, `name`, and `ariaLabel`.
- **`Input`**: single underlying text editor that strips disallowed characters and enforces `length` once composition settles. Emits `valueChange` on edits and `completed` once for each accepted full-length code.
- **`Slot`**: passive, `aria-hidden` readout indexed by `index` without adding extra editors or Tab stops. When the editable input is focused, active slot highlights track the real caret or selected range.
- **`Control` (form integration)**: use `Control` instead of `Input` inside `Field` / `FormField` to connect `FieldLabel`, validation, form serialization, and reset.

### Other parts

- **Input**: optional `placeholder` (no default).
- **Slot**: `index` defaults to `0`.
- **Control, Separator**: no props.
