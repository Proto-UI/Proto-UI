Carousel composes a current slide, viewport and bounded Previous/Next controls. index can be controlled; loop is optional. Keyboard navigation and thresholded swipe use the same selection requests. This slice never starts autoplay or invents a timer.

This is a WIP source checkpoint. Full Adapter/Compiler, native GPUI, package consumer, accessibility and commit-bound visual acceptance remain pending.

## API

Carousel is workspace source. There is no public `proto-ui add` target. Passing `index` selects controlled mode. Viewport has no props. Slide `index` defaults to `0`.
