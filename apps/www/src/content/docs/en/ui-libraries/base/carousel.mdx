Base Carousel pairs an equal-size slide strip with a continuously scrollable viewport and Previous/Next controls. Pointer/touch dragging, wheel/trackpad scrolling, and keyboard navigation all snap to the nearest reachable slide boundary.

## Usage

### Responsive viewport capacity

Use `slidesPerView` (default `1`) to cap the maximum visible equal-size items and `minSlideSize` (default `0`, in logical pixels) to set their minimum extent. Narrowing the viewport reduces visible capacity while keeping every slide's layout extent intact. `Root` exposes `visibleSlides` and `maxIndex`, and the final snap aligns cleanly to the end of the strip without empty trailing space.

### Controlled index and interaction state

- Pass `index` for controlled mode. Drag release and navigation emit `indexChange` with the proposed index; the committed `index` remains unchanged while dragging until the owner updates it.
- `Viewport` exposes `dragging`, `scrolling`, and normalized `scrollPosition`. `Slide` exposes `current` (matching the committed snap index) and `hidden` (tracking offscreen visibility without removing layout space).
- When using `orientation="vertical"`, give the viewport an explicit height. Horizontal `direction="rtl"` reverses physical dragging and arrow keys while keeping logical item order.
- Setting `loop={true}` wraps index navigation between the first and last reachable positions without cloning slides.
