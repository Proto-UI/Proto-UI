## Installation

The 0.2.0 stable package exports `@proto.ui/prototypes-base/toggle` (`base-toggle` and `asToggle()`), with CLI target `base-toggle`. For styled versions, see [Shadcn Toggle](/en/ui-libraries/shadcn/toggle/) or [Brutalist Toggle](/en/ui-libraries/brutalist/components/toggle/).

## Usage

- **Controlled and uncontrolled**: Use `defaultActive` for uncontrolled mode, where activation flips `active` locally. Pass `active` for controlled mode so activation emits `activeChange` with `{ active }` while external state stays authoritative.
- **Single-control scope and accessibility**: `base-toggle` renders button semantics with pressed state on Web; place icons or labels directly as your children. `disabled` suppresses activation and clears transient press state. For grouped single or multiple toggles, use [Toggle Group](../toggle-group/).
