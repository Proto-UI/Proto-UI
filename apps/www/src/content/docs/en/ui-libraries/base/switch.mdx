## Installation

The 0.2.0 stable package exports `switchRoot`, `switchThumb`, `asSwitchRoot()`, and `asSwitchThumb()` from `@proto.ui/prototypes-base/switch`, with CLI target `base-switch`. For styled versions, see [Shadcn Switch](/en/ui-libraries/shadcn/switch/) or [Brutalist Switch](/en/ui-libraries/brutalist/components/switch/).

## Usage

### Parts

- `base-switch-root`: The single focusable interactive control, managing `checked`, activation, and `role="switch"` accessibility semantics.
- `base-switch-thumb` (optional): A presentational indicator that reads state from `Root` without becoming a separate focus or activation target.

### Controlled and uncontrolled

- Use `defaultChecked` for uncontrolled state; activation commits the next value locally and emits `checkedChange`.
- Pass `checked` for controlled state; activation emits `checkedChange` and keeps the caller-supplied value until updated.
- `Switch` represents a binary on/off toggle. Use `Checkbox` when you need a mixed/indeterminate state.
