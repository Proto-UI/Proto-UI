## Usage

### Anatomy

Compose `Root`, `Field`, `Submit`, and `Reset`:

- **`Root`**: collects uniquely named enabled `Field` controls and emits form values keyed by field name on `submit` once validation passes. Disabled fields (including those inside a disabled `Fieldset`) are omitted, and duplicate names ignore invalid serialization.
- **`Field`**: registers a named control for validation, serialization, and reset.
- **`Submit` / `Reset`**: handle pointer and keyboard activation and expose `disabled`, `hovered`, `pressed`, `focused`, `focusVisible`, and `focusSelf()`.

### Implicit submit, async validation, and reset

- Pressing `Enter` inside a focused single-line `Field`, `Number Field`, or `Input OTP` triggers form submission (excluding IME composition, modifier keys, and repeated keydown events).
- Async validation awaits current results and automatically discards stale replies after edits, unmounts, cancellations, or newer submit attempts.
- `requestReset()` restores uncontrolled initial values, requests initial values from controlled owners, cancels pending validation, and emits `reset`. `resetValidation()` clears validation state only.
