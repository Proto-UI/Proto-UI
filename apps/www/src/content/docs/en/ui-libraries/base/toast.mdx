## Usage

Compose `Root`, `Viewport`, `Title`, `Description`, `Action`, and `Close`:

- **Timing and pause**: `Root` stays open for `5000ms` by default (set `duration={0}` to keep it open indefinitely). Hovering the toast or focusing `Action`/`Close` pauses the remaining timer until interaction leaves.
- **Dismissal and actions**: `Close`, pressing `Escape` while focused, and `Action` all request dismissal while leaving action side effects to your application. In controlled mode (`open`), timeout emits one dismissal request until the caller updates `open`.
- **Shortcuts and politeness**: `Viewport` provides a focus shortcut (`F8` by default, configurable via `hotkey`), and `politeness` (`'polite'` or `'assertive'`) sets the live-region announcement priority.

Pass `open` to control visibility.

### Part Props

- **Viewport**: `a11yLabel` (default `'Notifications'`), `hotkey` (default `'F8'`).
- **Action**: `disabled` (default `false`), `a11yLabel` (optional).
- **Close**: `disabled` (default `false`).
- **Title**, **Description**: No additional props.
