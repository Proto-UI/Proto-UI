Root defaults open for 5000ms. duration=0 remains open; hover and focus in Toast Action/Close pause the remaining duration. Controlled open emits one timeout request until the owner changes state. Close, focused Escape and Action request dismissal; action side effects belong to the app. Viewport provides the F8 focus shortcut. No global queue or external notification transport is implied.

Parts: Root, Viewport, Title, Description, Action, Close.

Draft source; native/GPUI, compiler, packed consumer, screenshots and full independent acceptance remain pending.

## API

Toast is workspace source. There is no public `proto-ui add` target. Passing `open` selects controlled mode.

These props belong to Root. Viewport defaults `a11yLabel` to `Notifications` and `hotkey` to `F8`. Title and Description have no props. Action defaults `disabled` to `false`; `a11yLabel` has no default. Close defaults `disabled` to `false`.
