Available starting in `0.3.0-rc.1` and later releases.

## Usage

### Single, range, and multiple selection

- **Single mode**: requests closing the popover once an accepted date is selected.
- **Range mode (`mode="range"`)**: uses `range` / `defaultRange`. Selecting the first endpoint keeps the popover open; selecting the second accepted endpoint completes the range and requests closing once.
- **Multiple mode (`mode="multiple"`)**: uses `values` / `defaultValues`. The popover stays open as dates are toggled and closes through normal Popover dismissal.
- Selection callbacks, date constraints (`min`, `max`, `unavailable`), and count/night limits (`minSelected`, `maxSelected`, `minNights`, `maxNights`) are inherited directly from [Calendar](../calendar/).

### Formatted display and focus

- `Value` displays a single ISO date, a comma-separated sorted list for multiple dates, `from …` for a pending range, `from – to` for a completed range, or `placeholder` when empty.
- Popover manages dismissal and focus restoration; in controlled `open` mode, your application can still approve or ignore close requests.
