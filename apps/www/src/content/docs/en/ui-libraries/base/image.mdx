Base Image (`base-image-root`) renders a native `<img>` target on the Web, managing image `source`, `fit` mode, explicit accessibility semantics, and live loading status transitions.

## Installation

Available starting in `0.3.0-rc.1` and later releases. Generate wrappers in the workspace with `proto-ui add react base-image` (supports `react`, `vue`, `vue2`, and `wc`), or import `imageRoot` and `asImageRoot` directly from `@proto.ui/prototypes-base/image`.

## Usage

### Basic example

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { imageRoot } from '@proto.ui/prototypes-base/image';

const Image = createReactAdapter(React)(imageRoot);

export function Cover() {
  return (
    <Image
      source="/images/cover.jpg"
      a11yMode="informative"
      alternativeText="A mountain ridge reflected in a lake"
      fit="cover"
      surfaceStyle={{ width: '100%', height: '240px' }}
    />
  );
}
```

For other hosts, use `createVueAdapter(Vue)(imageRoot)` (Vue 3), `createVue2Adapter(...)(imageRoot)` (Vue 2), or `AdaptToWebComponent(imageRoot, { registerAs: 'app-image' })` with `setElementProps()` before mounting.

### Accessibility and loading status

- **`a11yMode` and `alternativeText`**: informative images (`a11yMode="informative"`, default) require non-empty `alternativeText`; decorative images should set `a11yMode="decorative"` with an omitted or empty `alternativeText` (producing an empty `alt`).
- **Loading status**: exposes `source`, `fit`, and `loadingStatus` (`'idle' | 'loading' | 'loaded' | 'error'`), emitting `loadingStatusChange` with payload `{ status, previousStatus, source }`.
- Omitting or clearing `source` sets status to `'idle'`. Replacing `source` clears the previous visual and retires any in-flight request; render custom fallback or retry UI in your application when status becomes `'error'`.

### Sizing and composition

`Root` takes no child elements—your application controls dimensions, framing, and captions. In Web Components, apply styling to the inner image using `surfaceClassName` and `surfaceStyle`. Derived prototypes composing `asImageRoot` must also forward its static `modules`:

```ts
import { definePrototype } from '@proto.ui/core';
import { asImageRoot } from '@proto.ui/prototypes-base/image';

const framedImage = definePrototype({
  name: 'framed-image',
  modules: asImageRoot.modules,
  setup() {
    asImageRoot();
  },
});
```
