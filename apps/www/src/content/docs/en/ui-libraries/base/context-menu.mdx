## Installation

Available starting in `0.3.0-rc.1` and later releases.

## Usage

### Anatomy

Compose `Root`, `Trigger`, `Content`, and `Item`:

- `Root` manages open state (`open` / `defaultOpen`), `disabled`, and `closeOnItemCommit`.
- `Trigger` opens on right-click, `ContextMenu` / `Shift+F10`, or a 600 ms touch/pen hold within movement tolerance, suppressing the native context menu while leaving ordinary clicks and scrolling untouched.
- `Content` handles overlay positioning, focus navigation, typeahead, and transitions (default placement `bottom` / `start`). Right-click and long-press anchor to the pointer location, while keyboard activation and programmatic `openContextMenu()` fall back to the trigger region.

### Controlled state and focus return

- Pass `open` for controlled mode: accepted trigger gestures still suppress the native context menu while letting your application decide whether to open.
- Dismissing with `Escape` or selecting an item restores focus to the trigger.

### Other parts

- **Trigger**: no props.
- **Content**: accepts Transition props; defaults `side` to `'bottom'`, `align` to `'start'`, `sideOffset` and `alignOffset` to `0`, `avoidCollisions` to `true`, `collisionPadding` to `0`, and `excludeAnchorTranslation` to `false`.
- **Item**: `disabled` defaults to `false`, `value` and `textValue` default to `''`; optional `closeOnCommit` overrides the `Root` policy.
