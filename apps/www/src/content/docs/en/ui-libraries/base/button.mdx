Base Button is a focusable command control for one discrete action. It owns activation, disabled gating, focus, transient interaction facts and the outward `click` signal. The application supplies its visual presentation.

## Preview

The same composition contains “Run action” and “Disabled” in each host. The website preview uses workspace source; Vue 2 is the Vue 2.6 source profile, not part of the stable 0.2.0 install below.

## Install

First [initialize an existing application](/en/start-here/quick-start/). For the published 0.2.0 Web Component baseline:

<InstallCommandCard command="npx @proto.ui/cli@0.2.0 add wc base-button" manager="npm" />

With pnpm:

```sh
pnpm dlx @proto.ui/cli@0.2.0 add wc base-button
```

Replace `wc` with `react` or `vue` for the stable React or Vue 3 facade. The CLI installs `@proto.ui/prototypes-base` and the corresponding `@proto.ui/adapter-web-component`, `@proto.ui/adapter-react` or `@proto.ui/adapter-vue` at its own exact version. It generates the local `BaseButton` export or `proto-ui-base-button` custom element.

The Vue 2 example requires the matching workspace 0.3 CLI/Adapter source and Vue `>=2.6.0 <2.7`. The published stable CLI does not accept `vue2`; do not substitute `@latest` and assume that it installs the source preview. A workspace manifest version is not proof of registry publication.

## Usage

Start with the matching existing bundler application. Copy the host's files below and keep the application’s framework mount entry. For Web Components, add the HTML to the existing document and load `src/main.ts` once. The registration import uses the CLI-generated tag, rather than the website's private `wc-base-button` preview tag.

Both controls match the preview composition. The small stylesheet is application-owned presentation and requires no Tailwind setup. If the application already imports `proto-ui-style.css`, keep that import in one place.

<CodeExample files={baseButtonFiles} initialHost="wc" label="Base Button complete host usage" />

Tab to “Run action” and activate it with Enter, Space or a pointer. “Disabled” must suppress activation and active focus requests; fading it with CSS alone would not disable it. Accessible names come from the authored text.

## Protocol and events

`P-BASE-BUTTON` catalogs two authoring entries for the same protocol:

- the direct `base-button` Prototype, exported as `button` from `@proto.ui/prototypes-base/button`;
- the authored `asButton()` hook for a derived Prototype that needs Button semantics.

The only current Base prop is `disabled`. Exposed facts are `disabled`, `hovered`, `focused`, `focusVisible` and held-down `pressed`; `focusSelf()` requests focus. Successful activation emits the `click` outward signal. Framework facades translate that signal to their listener syntax (`onClick` in React, `@click` in Vue); it is not an `onClick` Prototype prop. The Web Component facade projects the signal as a custom event, separately from native DOM input.

Space participates in the press lifecycle and prevents its scrolling default. A disabled Button clears transient interaction state and emits no activation signal. Form submission, `type`, `name`, loading state and visual variants are outside the current Base guarantee. Application-owned busy behavior must drive the actual `disabled` input and expose meaningful progress/status; a spinner or opacity change alone is insufficient.

Use a native anchor with a real `href` for navigation. Do not nest it inside Button or replace its navigation with a click handler. Styled projections are documented separately: [Shadcn Button](/en/ui-libraries/shadcn/button/) and [Brutalist Button](/en/ui-libraries/brutalist/components/button/).

## Delivery, lifecycle and evidence

The stable 0.2.0 package exports `@proto.ui/prototypes-base/button` and its CLI exposes `base-button`. The website's four-host source preview and the older stable package are separate delivery surfaces. `P-BASE-BUTTON` remains **draft**; publication does not freeze its protocol or prove current browser/assistive-technology acceptance.
