Base Button is a focusable command control for triggering a single discrete action. It handles activation, disabled gating, focus, and press states while leaving visual presentation up to your application.

## Installation

First [initialize your project](/en/start-here/quick-start/), then add Base Button using the 0.2.0 CLI:

<InstallCommandCard
  commands={{
    npm: 'npx @proto.ui/cli@0.2.0 add wc base-button',
    pnpm: 'pnpm dlx @proto.ui/cli@0.2.0 add wc base-button',
  }}
  manager="npm"
/>

Replace `wc` with `react` or `vue` for React or Vue 3 projects. The CLI installs matching versions of `@proto.ui/prototypes-base` and the host adapter, generating a local `BaseButton` export or `proto-ui-base-button` custom element. Vue 2 (`vue2`) support is currently available from workspace source only.

### Interaction and events

- Focus the button with `Tab` and activate it with `Enter`, `Space`, or a pointer. `Space` participates in the press lifecycle and prevents default page scrolling.
- Successful activation emits the `click` signal, which each adapter exposes idiomatically (`onClick` in React, `@click` in Vue, and a custom event in Web Components).
- Setting `disabled` blocks activation, clears transient press/hover states, and rejects focus requests. Always drive the `disabled` prop rather than relying on CSS opacity alone.
- Exposed state includes `disabled`, `hovered`, `focused`, `focusVisible`, `pressed`, and the `focusSelf()` method. The accessible name comes from the button's text content.
- Use a native `<a>` with a real `href` for navigation. For styled variants, see [Shadcn Button](/en/ui-libraries/shadcn/button/) and [Brutalist Button](/en/ui-libraries/brutalist/components/button/).

### Authoring entries

`@proto.ui/prototypes-base/button` exports both the standalone `button` prototype and the `asButton()` hook for derived components.

Workspace source also includes an opt-in `asFocusRetainedVisibility` hook (with `FocusRetainedVisibilityProps`). Composed with `asButton()`, it takes `requestedVisible?: boolean` (default `false`) and keeps the control visible while focused even after `requestedVisible` turns `false`—useful for floating actions such as "Jump to latest".
