Base provides unstyled, cross-framework component primitives focused on interaction behavior, state management, and accessibility. Styled libraries such as Shadcn and Brutalist build their visual designs on top of Base.

## Installation

Initialize Proto UI in an existing project and add a published 0.2.0 component (for example, the Web Component Button):

```sh
npx @proto.ui/cli@0.2.0 init
npx @proto.ui/cli@0.2.0 add wc base-button
```

Or with pnpm:

```sh
pnpm dlx @proto.ui/cli@0.2.0 init
pnpm dlx @proto.ui/cli@0.2.0 add wc base-button
```

Replace `wc` with `react` or `vue` for React or Vue 3 projects. Follow [Quick Start](/en/start-here/quick-start/) to import the generated style entry and component wrapper, then see the full [Button guide](./button/).
