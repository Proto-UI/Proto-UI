Base AlertDialog interrupts the user for an explicit confirmation before a sensitive or irreversible action. It blocks outside dismissal and focuses the cancel action by default to prevent accidental confirmation.

## Usage

### Anatomy

Compose `Root`, `Trigger`, `Mask`, `Content`, `Title`, `Description`, `Cancel`, and `Action`:

- `Root` manages open state with alertdialog semantics.
- `Mask` renders the modal backdrop; `Content` traps focus, blocks outside-click dismissal, and focuses `Cancel` first when available.
- Activating `Action` emits the `action` event before requesting close; your application handles the underlying side effect.
- Pressing `Escape` or activating `Cancel` requests dismissal.

### Controlled and uncontrolled state

- Pass `open` for controlled mode: listen to `openChange` and supply the next boolean value to commit state changes.
- Omit `open` for uncontrolled mode and optionally pass `defaultOpen`.
- Setting `disabled` prevents command activation.

### Other parts

- **Mask**: accepts `passthrough` (default `false`) plus the Transition props.
- **Content**: accepts the Transition props.
- **Trigger, Title, Description, Cancel, Action**: no props.
