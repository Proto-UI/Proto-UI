A passive visual container that standardizes surface variants, corner radius, borders, elevation, and visual interaction states while letting styled components own the actual paint.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release (workspace CLI target: `base-surface`). Import `surfaceRoot` (along with `SurfaceRootProps`, `SurfaceRootExposes`, `asSurfaceRoot`, and `SurfaceRootAsHookContract`) from `@proto.ui/prototypes-base/surface` or the package root.

## Usage

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { surfaceRoot } from '@proto.ui/prototypes-base/surface';

const Surface = createReactAdapter(React)(surfaceRoot);

export function Summary() {
  return (
    <Surface variant="muted" radius="md" border="none">
      <div style={{ padding: '1rem' }}>Saved locally</div>
    </Surface>
  );
}
```

### Passive visual inputs

- Pass `hovered`, `focusVisible`, `pressed`, and `current` from an enclosing interactive component. `Surface` itself adds no event listeners, tab stops, accessible roles, or activation handlers.
- Removing a prop restores its default value. Content layout and padding belong to the caller; set `tone="inherit"` on nested styled `Text` elements when they should inherit the enclosing `Surface` foreground color.
- When you need real button or link semantics, use `Button` or a native `<a>` element rather than attaching click handlers to `Surface`.

### Following an existing Transition

- Set `fade={true}` to map `transitionState` (supplied by [Transition](/en/ui-libraries/base/transition/)) to opacity in styled components: `closed` and `leaving` map to `0`, while `entering` and `entered` map to `1`.
- On Web, pass a finite non-negative duration via the `--pui-surface-transition-duration` CSS variable (defaults to `0ms`).
- `variant="scrim"` applies a standard backdrop dimming surface. Zero opacity is purely visual; presence, inertness, and focus management remain with the enclosing `Dialog` or `Transition`.
