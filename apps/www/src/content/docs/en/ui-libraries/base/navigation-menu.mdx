## Usage

Compose `Root`, `Trigger`, `Content`, `Item`, and `Link`:

- **Roles and state**: `Root` acts as a `navigation` landmark and manages the single open panel via `value`. `Trigger` toggles a panel, and `Content` renders a labelled region. Pass `value` for controlled mode.
- **Commands and native links**: `Item` triggers a command, while `Link` renders a real anchor with `href`, `target`, `rel`, and `current` (`aria-current` for the current page). URL previews, `Enter` activation, modifier/middle-click opening, and navigation are handled natively by the browser.
- **Navigation events and dismissal**: After native activation, `Link` emits a read-only `navigate` event with `{ href, target, rel, modified }`. Standard same-window navigation closes the open panel unless `closeOnSelect={false}`; modified clicks, middle clicks, and `target="_blank"` keep the panel open. Disabling `Link` removes its destination and prevents activation.
- **Host rendering**: React, Vue, and Vue 2 render a native anchor root; Web Components wrap your children in an internal anchor that carries focus, styling, and accessibility attributes.

Pass `value` to control the open panel identifier.

### Part Props

- **Trigger**: `value` (default `''`), `disabled` (default `false`).
- **Content**: `value` (default `''`), `a11yLabel` (default `''`), `sideOffset` (default `4`).
- **Item**: `value` (default `''`), `textValue` (default `''`), `disabled` (default `false`), `closeOnSelect` (default `true`).
- **Link**: `href` (default `''`), `rel` (default `''`), `current` (default `false`), `target` (default `'_self'`).
