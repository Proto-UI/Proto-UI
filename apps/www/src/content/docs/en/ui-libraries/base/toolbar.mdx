## Installation

Available starting in `0.3.0-rc.1` and later releases.

## Usage

Compose `Root`, `Button`, and `Separator`:

- **Focus and navigation**: `Root` manages `disabled`, `orientation`, `loop`, and `a11yLabel`. Only one enabled command participates in normal `Tab` order, while arrow keys move focus across buttons inside the toolbar.
- **Actions and separators**: Activating an enabled `Button` emits an `action` event carrying its `value`; `Separator` automatically aligns along the cross axis.
