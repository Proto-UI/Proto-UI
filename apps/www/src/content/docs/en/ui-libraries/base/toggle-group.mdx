Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

Compose `Root` and `Item`:

- **Single and multiple selection**: `value` and `defaultValue` are always string arrays. With `multiple={false}` (default), at most one value stays active and pressing it again clears selection; set `multiple={true}` to allow multiple active items.
- **Controlled mode and navigation**: Pass `value` for controlled mode so `valueChange` emits proposed value arrays without mutating external state. Arrow keys move focus across items without toggling selection; disabled, read-only, and duplicate-valued items do not commit changes.
