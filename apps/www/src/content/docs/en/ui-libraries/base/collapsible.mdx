Base Collapsible provides a single expandable disclosure panel. `Root` manages the open state, `Trigger` toggles it, and `Content` controls content visibility and mounting.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. In the workspace, generate host components with the matching CLI:

```sh
proto-ui add react base-collapsible
# Also supports vue, vue2, and wc
```

React, Vue, and Vue 2 generate `BaseCollapsibleRoot`, `BaseCollapsibleTrigger`, and `BaseCollapsibleContent`; Web Components register `proto-ui-base-collapsible-{root,trigger,content}`. You can also import `collapsibleRoot`, `collapsibleTrigger`, `collapsibleContent`, and `asCollapsible*` hooks directly from `@proto.ui/prototypes-base/collapsible`.

## Usage

### Anatomy

Each `Root` contains one `Trigger` and one `Content` (nested `Root` instances stay isolated):

- **Root**: manages open state and exposes `openCollapsible`, `close`, `toggle`, and the `openChange` event.
- **Trigger**: button semantics in natural Tab order with `Enter` / `Space` activation, derived `expanded` and effective `disabled` states, and `focusSelf()`.
- **Content**: syncs `open` / `hidden` state. Unmounts content when closed by default; set `keepMounted` to keep the node mounted and hidden while preserving child state.

### Code example

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import {
  collapsibleRoot,
  collapsibleTrigger,
  collapsibleContent,
} from '@proto.ui/prototypes-base/collapsible';

const adapt = createReactAdapter(React);
const BaseCollapsibleRoot = adapt(collapsibleRoot);
const BaseCollapsibleTrigger = adapt(collapsibleTrigger);
const BaseCollapsibleContent = adapt(collapsibleContent);

export function ControlledDisclosure() {
  const [open, setOpen] = React.useState(false);
  return (
    <BaseCollapsibleRoot open={open} onOpenChange={(request) => setOpen(request.open)}>
      <BaseCollapsibleTrigger>Details</BaseCollapsibleTrigger>
      <BaseCollapsibleContent keepMounted>Additional details</BaseCollapsibleContent>
    </BaseCollapsibleRoot>
  );
}

export function UncontrolledDisclosure() {
  return (
    <BaseCollapsibleRoot defaultOpen>
      <BaseCollapsibleTrigger>Details</BaseCollapsibleTrigger>
      <BaseCollapsibleContent>Additional details</BaseCollapsibleContent>
    </BaseCollapsibleRoot>
  );
}
```

### Controlled state and accessibility

- Pass `open` for controlled mode: requests emit `openChange` with `{ open, reason }` (`reason` is `'pointer'`, `'keyboard'`, or `'programmatic'`). Supply the new `open` prop to commit the change.
- Disabling either `Root` or `Trigger` blocks activation; disabling an open panel keeps it open.
- `Trigger` automatically manages `aria-expanded` and `aria-controls`, cleaning up ARIA links whenever `Content` unmounts or is disposed.

## API

### Root Props

Passing `open` selects controlled mode.

### Other parts

- **Trigger**: `disabled` defaults to `false`.
- **Content**: `keepMounted` defaults to `false`.
