The tooltip family provides hover-and-focus-based tooltip behavior.

- **tooltip-root**: Holds the `open` state, manages hover/focus tracking via context, and provides `openTooltip`/`close`/`toggle` methods.
- **tooltip-trigger**: The element that triggers the tooltip on hover or focus.
- **tooltip-content**: The floating content, positioned via overlay. Hidden when closed.

Pass `open` to control the tooltip externally, or `defaultOpen` for uncontrolled usage. Use `delay` to configure the show delay in milliseconds.

The demo includes an open-state label so you can observe the state transition directly. Collision-aware placement, arrows, and portal behavior are intentionally left to host runtimes or adapters.
