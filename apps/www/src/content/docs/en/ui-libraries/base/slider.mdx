## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the scalar Slider parts or the six `sliderValues*` multi-value entries from `@proto.ui/prototypes-base/slider`.

## Usage

### Single-thumb composition

Compose `Root`, `Label`, `Track`, `Indicator`, `Thumb`, `FieldThumb`, and `Value`:

- **Dragging and keyboard stepping**: `Root` manages value, bounds, and orientation. `Track` handles pointer and touch dragging; `Thumb` supports arrow keys, `Shift` ×10 steps, `PageUp`/`PageDown`, and `Home`/`End`, reversing horizontal arrows in `rtl` mode. Values clamp to `[min, max]` and snap from `min` by `step`.
- **Controlled mode and commits**: Pass `value` for controlled mode (interactions emit `valueChange` without overwriting external state). `valueCommit` fires when a drag or keyboard edit completes; canceling a drag restores the uncontrolled start value.
- **Form integration**: Use `FieldThumb` instead of `Thumb` inside `Field`/`FormField` to bridge `FieldLabel`, numeric validation, serialization, and reset. Use `Label` with standalone `Thumb`.

### Range and multiple values (`sliderValues*`)

Import the six `sliderValues*` entries from `@proto.ui/prototypes-base/slider`, pass an array such as `defaultValue={[20, 80]}` on `Values Root`, and place one indexed `Thumb` per value inside `Values Track`:

- **Track interaction and collisions**: Clicking the track seeks the nearest editable thumb, and off-center thumb grabs preserve the initial pointer offset. `thumbCollisionBehavior` accepts `'push'`, `'swap'`, or `'none'` (`'swap'` transfers active focus while keeping capture on the track).
- **Form integration**: `Values Root` works directly inside `Field`/`FormField`, reporting a `number[]` value, initial baseline, and group focus (`FieldLabel` focuses the first editable thumb). Resetting cancels any active drag and requests the initial baseline.
