The Slider prototype provides a headless value-selection control with configurable min, max, and step.

- **value**: controlled via `value` prop, or uncontrolled via `defaultValue`.
- **min / max / step**: define the value range and increment.
- **disabled**: suppresses value changes.
- **orientation**: `"horizontal"` (default) or `"vertical"`.

The slider emits a `valueChange` event whenever the value changes. Host adapters should dispatch `slide.commit` events to drive the slider.
