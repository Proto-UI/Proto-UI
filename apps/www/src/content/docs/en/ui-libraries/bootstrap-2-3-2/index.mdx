The archived 2.3.2 gradient, raised-control, field, and divider language, with all interaction and value ownership inherited from Base.

The implemented draft subset contains Button, Checkbox Root / Indicator, Switch Root / Thumb, Toggle, Input, Textarea, and Separator: seven component kinds and nine prototype parts. This is a partial family, not the complete Bootstrap or Base component set, and it is not offered by the homepage full-family selector.

Switch and Toggle are design-language extensions, not original Bootstrap 2.3.2 components. Checkbox uses custom Root / Indicator parts rather than reproducing the archived native checkbox. No legacy jQuery runtime or Glyphicons are bundled.

Use the page runtime selector to run the same shared demo recipes through Web Components, React, Vue 3, or Vue 2. The archived light palette remains fixed in dark hosts. The source package is private and unreleased; these draft Web projections do not establish general Prototype Compiler or GPUI, Flutter, or Qt conformance.
