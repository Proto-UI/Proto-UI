## Usage

```tsx
import {
  BootstrapLabelRoot,
  BootstrapRadioGroupIndicator,
  BootstrapRadioGroupItem,
  BootstrapRadioGroupRoot,
} from '../proto-ui/components/react';

export function RadioGroupUsage() {
  return (
    <BootstrapRadioGroupRoot defaultValue="comfortable" a11yLabel="Display density">
      <div className="flex items-center gap-2">
        <BootstrapRadioGroupItem value="default">
          <BootstrapRadioGroupIndicator />
        </BootstrapRadioGroupItem>
        <BootstrapLabelRoot>Default</BootstrapLabelRoot>
      </div>
      <div className="flex items-center gap-2">
        <BootstrapRadioGroupItem value="comfortable">
          <BootstrapRadioGroupIndicator />
        </BootstrapRadioGroupItem>
        <BootstrapLabelRoot>Comfortable</BootstrapLabelRoot>
      </div>
      <div className="flex items-center gap-2">
        <BootstrapRadioGroupItem value="compact">
          <BootstrapRadioGroupIndicator />
        </BootstrapRadioGroupItem>
        <BootstrapLabelRoot>Compact</BootstrapLabelRoot>
      </div>
    </BootstrapRadioGroupRoot>
  );
}
```

### Styling & Accessibility

- Unchecked indicators display an inset beveled light well (`#f5f5f5` → `#f9f9f9`), switching to the classic `#0088cc` → `#0077b3` vertical gradient with a 6px white center dot when checked.
- Keyboard focus displays the classic soft blue focus glow (`rgba(82, 168, 236, 0.6)`) alongside forced-colors outline preservation.
- Arrow keys move roving focus and select across enabled items; `Home` / `End` jump to the first and last enabled items; `Space` selects the focused item.

### Indicator, Events & Methods

- **Indicator**: No props; mirrors checked and disabled state from its parent `Item`.
- **Events**: `valueChange` (`{ value: string }`) on Root; `select` (`{ value: string }`) on Item.
- **Methods**: `requestValue(value)`, `resetValue()`, `focusFirst()`, `focusLast()`, `focusNext()`, `focusPrev()`, `focusSelected()`, `focusSelf()` on Root.
