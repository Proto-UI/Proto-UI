## Usage

Compose `Root`, `Label`, `Track`, `Indicator`, `Thumb` (or `FieldThumb` inside `Field` / `FormField`), and `Value`:

- **Pointer and keyboard**: Drag along `Track` with mouse or touch, or focus `Thumb` to adjust via arrow keys, `Shift` (10× step), `PageUp`/`PageDown`, and `Home`/`End` (horizontal `direction="rtl"` mirrors Left/Right). Values snap from `min` by `step` and clamp to `[min, max]`.
- **Change vs. commit**: Controlled sliders emit `valueChange` proposals without mutating caller state; `valueCommit` fires when an interaction completes, and cancelled drags restore the uncontrolled start value.
- **Form integration**: Use `FieldThumb` instead of `Thumb` inside `Field` or `FormField` to bridge `FieldLabel`, validation, `Form` serialization, and reset.

## API

| Part | Props / Events | Description |
| --- | --- | --- |
| `Root` | `value` / `defaultValue` | Controlled or initial slider value |
| `Root` | `min` / `max` / `step` | Range bounds and step increment |
| `Root` | `disabled` / `readOnly` / `orientation` / `direction` | State flags, orientation, and text direction |
| `Root` | `valueChange` / `valueCommit` | Continuous change proposals and completion event |
| `Label` / `Track` / `Indicator` / `Thumb` / `FieldThumb` / `Value` | — | Label, track, fill, thumb (`FieldThumb` in forms), and passive value display |
