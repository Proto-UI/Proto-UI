Bootstrap 2.3.2 Slider pairs the classic 20px recessed gradient track, blue gradient fill, and raised 20px button thumb with single-value and multi-thumb range selection plus built-in `Field` and `Form` support.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import scalar slider parts and multi-value `sliderValues*` parts from `@proto.ui/prototypes-bootstrap-2-3-2/slider`.

## Usage

```tsx
import {
  Bootstrap232SliderRoot,
  Bootstrap232SliderTrack,
  Bootstrap232SliderIndicator,
  Bootstrap232SliderThumb,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <Bootstrap232SliderRoot defaultValue={33} min={0} max={100} step={1}>
      <Bootstrap232SliderTrack>
        <Bootstrap232SliderIndicator />
        <Bootstrap232SliderThumb />
      </Bootstrap232SliderTrack>
    </Bootstrap232SliderRoot>
  );
}
```

- **Anatomy**: Compose `Root`, `Label`, `Track`, `Indicator`, `Thumb` (or `FieldThumb` inside `Field` / `FormField`), and `Value`; use `sliderValues*` entries for multi-thumb ranges.
- **Pointer and keyboard**: Drag along `Track` with mouse or touch, or focus `Thumb` to step with arrow keys, `Shift` (10× step), `PageUp`/`PageDown`, and `Home`/`End` (mirrored in horizontal RTL).
- **Controlled and Form**: Controlled sliders emit `valueChange` proposals and `valueCommit` on completion; `FieldThumb` and `Values Root` integrate with `FieldLabel`, validation, and form reset.
