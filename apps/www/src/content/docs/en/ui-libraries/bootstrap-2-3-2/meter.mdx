Bootstrap 2.3.2 Meter displays a scalar measurement within a known range—such as disk usage, quota, or score—and classifies readings using `low`, `high`, and `optimum` thresholds.

```ts
import {
  meterRoot,
  meterLabel,
  meterTrack,
  meterIndicator,
  meterValue,
} from '@proto.ui/prototypes-bootstrap-2-3-2/meter';
```

## Usage

Compose `Root`, `Label`, `Track`, `Indicator`, and `Value`:

- **Bounded values**: `Root` clamps `value` between `min` (default `0`) and `max` (default `100`). When `min` equals `max`, the computed percentage is `0`.
- **Threshold classification**: Providing `low`, `high`, and `optimum` derives `status` as `'optimal'`, `'suboptimal'`, or `'critical'` without altering the numeric value.
- **Read-only display**: `Label` names the gauge, `Track` and `Indicator` render the fill bar, and `Value` displays `valueText` or the formatted number. Meter is passive and adds no Tab stop.

## API

| Part | Props / States | Description |
| --- | --- | --- |
| `Root` | `value` / `min` / `max` | Numeric reading and bounds (`min=0`, `max=100` by default) |
| `Root` | `low` / `high` / `optimum` | Thresholds classifying `status` as `optimal`, `suboptimal`, or `critical` |
| `Root` | `ariaLabel` / `valueText` | Accessible name and custom display text |
| All parts | `value` / `percentage` / `indeterminate` / `status` | Synchronized read-only measurement states |
| `Label` / `Track` / `Indicator` / `Value` | — | Label, track container, fill indicator, and value readout |
