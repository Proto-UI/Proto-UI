## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the meter parts from `@proto.ui/prototypes-bootstrap-2-3-2/meter`:

```ts
import {
  meterRoot,
  meterLabel,
  meterTrack,
  meterIndicator,
  meterValue,
} from '@proto.ui/prototypes-bootstrap-2-3-2/meter';
```

## Usage

```tsx
import { AdaptToReact } from '@proto.ui/adapter-react';
import {
  meterRoot,
  meterLabel,
  meterTrack,
  meterIndicator,
  meterValue,
} from '@proto.ui/prototypes-bootstrap-2-3-2/meter';

const MeterRoot = AdaptToReact(meterRoot);
const MeterLabel = AdaptToReact(meterLabel);
const MeterTrack = AdaptToReact(meterTrack);
const MeterIndicator = AdaptToReact(meterIndicator);
const MeterValue = AdaptToReact(meterValue);

export function BootstrapStorageMeter() {
  return (
    <MeterRoot value={32} min={0} max={100} low={50} high={80} optimum={20} valueText="32%">
      <div className="flex items-center justify-between gap-2">
        <MeterLabel>Storage used</MeterLabel>
        <MeterValue />
      </div>
      <MeterTrack>
        <MeterIndicator />
      </MeterTrack>
    </MeterRoot>
  );
}
```

### Anatomy and thresholds

- **Root**: Clamps `value` within `[min, max]` (defaulting to `0..100`) and computes `0` percentage when `min === max`.
- **Label / Value**: `Label` provides the accessible name; `Value` renders `valueText` or the normalized numeric reading with `tabular-nums`.
- **Track / Indicator**: Preserves Bootstrap 2.3.2's 20px track height, 4px corners, and inset depth while mapping `optimal`, `suboptimal`, and `critical` to the classic `success` (green), `warning` (amber), and `danger` (red) bar gradients.
- Meter is passive (`role="meter"`) with no keyboard tab stop, exposing synchronized read-only state across all parts.
