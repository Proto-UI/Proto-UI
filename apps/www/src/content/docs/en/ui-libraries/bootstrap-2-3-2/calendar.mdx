Bootstrap 2.3.2 Calendar provides `single` (default), `multiple`, and `range` date selection. As Bootstrap 2.3.2 did not ship a native calendar, this family extension applies its classic 4px framed surfaces, raised button gradients, and condensed table typography.

## Installation

Available starting in `0.3.0-rc.1` and later releases (`@proto.ui/prototypes-bootstrap-2-3-2/calendar`).

## Usage

```tsx
import {
  CalendarRoot,
  CalendarCaption,
  CalendarPrevious,
  CalendarHeading,
  CalendarNext,
  CalendarGrid,
  CalendarWeekdays,
  CalendarWeekday,
  CalendarRow,
  CalendarDay,
} from '@proto.ui/prototypes-bootstrap-2-3-2/calendar';

export function BootstrapCalendarExample() {
  return (
    <CalendarRoot mode="single" defaultMonth="2026-10" defaultValue="2026-10-12" today="2026-10-08">
      <CalendarCaption>
        <CalendarPrevious a11yLabel="Previous month" />
        <CalendarHeading />
        <CalendarNext a11yLabel="Next month" />
      </CalendarCaption>
      <CalendarGrid>
        <CalendarWeekdays>
          {Array.from({ length: 7 }, (_, offset) => (
            <CalendarWeekday key={offset} offset={offset} />
          ))}
        </CalendarWeekdays>
        {Array.from({ length: 6 }, (_, row) => (
          <CalendarRow key={row} index={row}>
            {Array.from({ length: 7 }, (_, col) => (
              <CalendarDay key={col} offset={row * 7 + col} />
            ))}
          </CalendarRow>
        ))}
      </CalendarGrid>
    </CalendarRoot>
  );
}
```

### Anatomy, clock ownership, and caption pickers

- Compose `Calendar` from ten parts: `Root`, `Caption`, `Heading`, `Previous`, `Next`, `Grid`, `Weekdays`, `Weekday`, `Row`, and `Day`.
- Dates use `YYYY-MM-DD` and visible months use `YYYY-MM`, controllable independently. The grid renders 4–6 complete weeks by default; pass `fixedWeeks={true}` to reserve 6 rows.
- Calendar never reads the system clock directly: pass a `YYYY-MM-DD` `today` string from your host to highlight today (`aria-current="date"`).
- `direction="rtl"` mirrors Left/Right arrow keys automatically. Connect family `Select` controls using `bindCalendarCaption(source, { month, year })` (and call `dispose()` on teardown).

### Selection modes

| Mode       | Controlled / initial props                       | Change event                 |
| ---------- | ------------------------------------------------ | ---------------------------- |
| `single`   | `value` / `defaultValue` (`YYYY-MM-DD`)          | `onValueChange({ value })`   |
| `multiple` | `values` / `defaultValues` (`readonly string[]`) | `onValuesChange({ values })` |
| `range`    | `range` / `defaultRange` (`{ from?, to? }`)      | `onRangeChange({ range })`   |

### Events, methods, and exposed states

- **Events (Root)**: `onValueChange({ value })`, `onValuesChange({ values })`, `onRangeChange({ range })`, `onMonthChange({ month })`.
- **Methods (Root)**: `requestValue(date)`, `requestValues(dates)`, `requestRange(range)`, `requestMonth(month)`, `getValues()`, `getRange()`.
- **Exposed states**: Root exposes `value`, `mode`, `selectedCount`, `rangeComplete`, `month`, `weekCount`, `disabled`, `direction`; Day exposes `date`, `selected`, `rangeStart`, `rangeEnd`, `rangeMiddle`, `rangePending`, `today`, `outside`, `disabled`, `hidden`.
