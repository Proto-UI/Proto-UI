Bootstrap 2.3.2 Input applies classic `forms.less` field styling (4px radius, inset shadow, blue focus glow, and `#eee` disabled/read-only fill) to [Base Input](../../base/input/), while preserving the archived light control palette in dark hosts.

## Installation

Currently available from workspace source and not yet included in the 0.2.0 stable release; import from `@proto.ui/prototypes-bootstrap-2-3-2/input`. [Browse the implemented subset](../).

## Usage

```tsx
import { Bootstrap232InputRoot } from '@/components/ui/bootstrap-2-3-2-input';

export function Example() {
  return <Bootstrap232InputRoot placeholder="Type something..." ariaLabel="Basic input" />;
}
```

- **Values and events**: Supports controlled `value` and uncontrolled `defaultValue`, along with normalized editing and IME composition events.
- **Read-only and disabled**: `readOnly` keeps the input focusable and selectable without editing; `disabled` prevents focus and edits, both styled with the classic `#eee` fill.
- **Field composition**: Pair with Bootstrap 2.3.2 `Field` when you need labels, helper descriptions, or red validation highlights.
