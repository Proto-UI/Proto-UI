## Usage

- **Values and events**: Supports controlled `value` and uncontrolled `defaultValue`, along with normalized editing and IME composition events.
- **Read-only and disabled**: `readOnly` keeps the input focusable and selectable without editing; `disabled` prevents focus and edits.
- **Field composition**: Pair with `Field` when you need labels, helper descriptions, or validation errors.

## API

| Category | Members | Description |
| --- | --- | --- |
| Value & state | `value` / `defaultValue`, `disabled`, `readOnly`, `placeholder` | Controlled/uncontrolled text and editing flags |
| Form & hints | `name`, `required`, `autoComplete`, `minLength`, `maxLength`, `inputMode`, `enterKeyHint` | Native editing hints and constraints |
| Accessibility | `ariaLabel`, `labelledBy`, `describedBy` | Accessible naming and description links |
| Events & methods | `valueChange`, `change`, composition events, `focusSelf()`, `blurSelf()` | Change notifications and focus methods |
