Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Grouping and decoration**: Pair `Group` with `Label` to name related actions for assistive technologies. Use `Separator` to divide sections and `Shortcut` to show shortcut labels.
- **Passive presentation**: `Separator` and `Shortcut` stay outside keyboard navigation; `Shortcut` is display-only and does not register global keybindings.
- The demo illustrates a `160px` menu with Account and Resources groups plus a disabled API item.

## API

| Part        | Description                                                |
| ----------- | ---------------------------------------------------------- |
| `Group`     | Groups related menu items and associates them with a label |
| `Label`     | Passive heading for a menu group                           |
| `Separator` | Visual divider between menu sections                       |
| `Shortcut`  | Trailing display hint for keyboard shortcuts               |
