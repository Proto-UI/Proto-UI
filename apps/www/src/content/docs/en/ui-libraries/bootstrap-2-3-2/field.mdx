Bootstrap 2.3.2 Field groups a label, input control, muted helper description, error message, and validity reader into one cohesive unit with classic 4px corners, inset shadows, blue focus glow, and optional horizontal row alignment.

## Installation

Currently available from workspace source. Import core parts and bound controls from `@proto.ui/prototypes-bootstrap-2-3-2/field`:

```ts
import {
  fieldRoot,
  fieldLabel,
  fieldControl,
  fieldDescription,
  fieldError,
  fieldValidity,
  fieldTextarea,
  fieldSelectTrigger,
  fieldSwitch,
} from '@proto.ui/prototypes-bootstrap-2-3-2/field';
```

## Usage

```tsx
import {
  FieldRoot,
  FieldLabel,
  FieldControl,
  FieldDescription,
  FieldError,
} from '@proto.ui/prototypes-bootstrap-2-3-2/field';

export function AccountField() {
  return (
    <FieldRoot required minLength={3}>
      <FieldLabel>Username</FieldLabel>
      <FieldControl placeholder="Max Leiter" />
      <FieldDescription>Choose a unique username for your account.</FieldDescription>
      <FieldError />
    </FieldRoot>
  );
}
```

### Composition and validation

- **Automatic ARIA wiring**: Links and cleans up `aria-labelledby`, `aria-describedby`, and (only while invalid) `aria-errormessage` without manual DOM IDs.
- **Bound controls**: Alongside the default single-line `Control`, compose with `fieldTextarea`, `fieldSelectTrigger`, and `fieldSwitch`, or bridge custom controls via Base `asFieldControl`.
- **Built-in and async checks**: Supports `required`, `minLength`, `maxLength` (UTF-16 code units), `validationMode` (`'onBlur'` / `'onChange'` / `'manual'`), controlled `invalid`, and `externalValidation`. Compose with [Fieldset](../fieldset/) or [Form](../form/) for group disabling or form submission.

### Control & other parts

- **Control**: `value` / `defaultValue`, `disabled`, `readOnly`, `required`, `placeholder`, `name`, `autoComplete`, `inputMode`, `enterKeyHint`, `ariaLabel`.
- **Bound controls**: `fieldTextarea`, `fieldSelectTrigger`, `fieldSwitch`.
- **Label**: `activation?: boolean` (default `true`).
- **Error**: `message?: string`, `keepMounted?: boolean` (default `false`).
- **Methods & events (Root)**: `validate(reason?)`, `resolveValidation(requestId, result)`, `cancelValidation()`, `resetValidation()`, `focusControl(options?)`, `getValidity()`; events `validityChange`, `validationRequest`.
