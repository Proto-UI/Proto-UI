Bootstrap 2.3.2 Fieldset groups related form fields with a semantic heading, helper text, and cascading disabled state using Bootstrap 2.3.2's borderless block container and bottom-bordered legend styling.

## Usage

```tsx
import {
  FieldsetRoot,
  FieldsetLegend,
  FieldsetDescription,
} from '@/components/bootstrap-2-3-2/fieldset';
import { FieldRoot, FieldLabel, FieldControl } from '@/components/bootstrap-2-3-2/field';

export function Example() {
  return (
    <FieldsetRoot>
      <FieldsetLegend>Address Information</FieldsetLegend>
      <FieldsetDescription>We need your address to deliver your order.</FieldsetDescription>
      <FieldRoot required>
        <FieldLabel>Street Address</FieldLabel>
        <FieldControl placeholder="123 Main St" />
      </FieldRoot>
    </FieldsetRoot>
  );
}
```

Compose `Root` with an optional `Legend` and `Description`:

- **Cascading disabled state**: A group is disabled whenever its own `disabled` prop or any enclosing `Fieldset` is disabled. Re-enabling an outer group preserves any local `disabled` flags on inner groups. Contained `Field` controls—including fields inside `Legend`—automatically inherit the disabled state.
- **Automatic ARIA wiring**: `Root` exposes the `group` role and automatically links its scoped `Legend` and `Description` without manual DOM IDs. Include at most one `Legend` and one `Description` per group; duplicate targets ignore invalid configuration and stay inactive.
- **Visual styling**: `Root` renders as a borderless block group; `Legend` uses a full-width `21px` heading (`40px` line height, `20px` bottom margin) with a theme-aware `border-border` bottom rule; `Description` renders `14px` (`20px` line height) muted, wrapping helper text.
