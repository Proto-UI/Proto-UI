Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

Compose `Root` with an optional `Legend` and `Description`:

- **Cascading disabled state**: A group is disabled whenever its own `disabled` prop or any enclosing `Fieldset` is disabled. Re-enabling an outer group preserves any local `disabled` flags on inner groups. Contained `Field` controls—including fields inside `Legend`—automatically inherit the disabled state.
- **Automatic ARIA wiring**: `Root` exposes the `group` role and automatically links its scoped `Legend` and `Description` without manual DOM IDs. Include at most one `Legend` and one `Description` per group; duplicate targets ignore invalid configuration and stay inactive.
- **Visual styling**: `Root` renders as a borderless block group; `Legend` uses a full-width `1.3125rem` heading with a `2.5rem` line height and bottom border; `Description` renders muted, wrapping helper text.

## API

| Part | Props / States | Description |
| --- | --- | --- |
| `Root` | `disabled` | `boolean`, default `false`; cascades disabled state to nested groups and fields |
| `Root` | `ariaLabel` | `string`, default `""`; accessible group name when `Legend` is omitted |
| `Legend` | — | Optional passive heading; exposes read-only effective `disabled` state |
| `Description` | — | Optional passive help text; exposes read-only effective `disabled` state |
