Virtual List decouples a stable logical key sequence from mounted DOM rows, rendering only items in the visible viewport and overscan buffer. The Bootstrap 2.3.2 projection pairs classic 4px rounded borders, a subtle inset bevel, and 14px/20px Helvetica typography with bounded virtualization.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototypes from `@proto.ui/prototypes-bootstrap-2-3-2/virtual-list` and connect a Web scroll container through `@proto.ui/prototypes-base/virtual-list/web`.

## Usage

Virtual List consists of `Root`, `Viewport`, and `Content`: `Root` tracks the ordered `itemKeys` sequence and outer container border, `Viewport` handles scrolling and inset focus feedback, and `Content` hosts materialized row elements.

```ts
import { AdaptToWebComponent, setElementProps } from '@proto.ui/adapter-web-component';
import {
  virtualListRoot,
  virtualListViewport,
  virtualListContent,
} from '@proto.ui/prototypes-bootstrap-2-3-2/virtual-list';
import { attachWebVirtualList } from '@proto.ui/prototypes-base/virtual-list/web';

AdaptToWebComponent(virtualListRoot);
AdaptToWebComponent(virtualListViewport);
AdaptToWebComponent(virtualListContent);

const list = document.querySelector('bootstrap-2-3-2-virtual-list-root')!;
const viewport = document.querySelector('bootstrap-2-3-2-virtual-list-viewport')!;
const content = document.querySelector('bootstrap-2-3-2-virtual-list-content')!;

setElementProps(list, {
  itemKeys: Array.from({ length: 1000 }, (_, i) => `event-${i + 1}`),
  overscanItems: 3,
  maxMaterializedItems: 60,
});

const host = attachWebVirtualList({
  viewport,
  content,
  collection: list.getExposes().getCollection(),
  estimateSize: 62,
  renderItem(key) {
    const row = document.createElement('div');
    row.className = 'border-b border-border px-3 py-2 text-[14px] leading-[20px]';
    row.textContent = key;
    return row;
  },
});

// Scroll to a key on demand and dispose on teardown
host.ensureVisible('event-250', 'center');
// host.dispose();
```

### Anatomy & Accessibility

- `Root` sets `role="region"` with `a11yLabel`, 4px rounded corners, a 1px semantic border, and `overflow-hidden` clipping.
- `Viewport` enables `overflow-auto` scrolling out of the box and renders a clean 2px inset focus ring on keyboard focus.
- `Content` sets `role="list"`, and mounted rows automatically receive `role="listitem"`, `aria-posinset`, and `aria-setsize`.

### Advanced: Custom Materializers

- Each logical list allows one active materializer at a time; `attachWebVirtualList` manages the lease automatically and cleans up rows and observers when `Root` unmounts or disposes.
- Dispose an active materializer before attaching a replacement. Non-Web hosts can integrate through `collection.acquireMaterializer(onRetired)`.
