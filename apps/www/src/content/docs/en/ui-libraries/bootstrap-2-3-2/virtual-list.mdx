Virtual List decouples a stable logical key sequence from rendered DOM nodes, mounting only items in the visible viewport plus an overscan buffer for smooth scrolling over large datasets.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Bounded rendering model**: The host-neutral core tracks stable logical keys, item-count `overscan`, and a maximum materialized item cap so application content is created only for the visible window.
- **Web integration**: The `virtual-list/web` entry measures variable item heights, manages scroll spacers, reuses keyed nodes, scrolls to any key on demand, and cleans up listeners on teardown.

## API

| Capability / Entry | Description |
| --- | --- |
| Core model | Tracks stable logical keys, item-count `overscan`, and max materialized count |
| `virtual-list/web` | Measures variable extents, manages spacers, supports scroll-to-key, and cleans up listeners |
