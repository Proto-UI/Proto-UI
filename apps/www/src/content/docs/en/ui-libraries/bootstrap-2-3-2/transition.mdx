Bootstrap 2.3.2 Transition exposes a transparent five-phase presence state machine (`closed → preparing → entering → entered → leaving`) while deliberately leaving the choice between classic `.fade` (150ms linear opacity) and `.collapse` (height expansion) to the caller.

## Preview

The example below pairs `bootstrap-2-3-2-transition` with a classic Bootstrap 2.3.2 `.well` stage, `.alert-info` surface, and 150ms linear `.fade` opacity across Web Components, React, Vue 3, and Vue 2.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release or CLI targets. Import directly from workspace source:

```ts
import { transition } from '@proto.ui/prototypes-bootstrap-2-3-2/transition';
```

## Usage

```html
<wc-bootstrap-2-3-2-transition default-open appear class="bs-fade-host">
  <div class="rounded-[4px] border border-[#bce8f1] bg-[#d9edf7] px-4 py-3.5 text-[#3a87ad]">
    <strong>Workspace synced</strong> — Your classic alert surface stays mounted until leaving ends.
  </div>
</wc-bootstrap-2-3-2-transition>

<style>
  .bs-fade-host > * {
    transition: opacity 0.15s linear;
  }
  .bs-fade-host[data-transition-state='leaving'] > *,
  .bs-fade-host[data-transition-state='closed'] > * {
    opacity: 0;
  }
  @media (prefers-reduced-motion: reduce) {
    .bs-fade-host > * {
      transition: none;
    }
  }
</style>
```

- **Transparent slot by design**: `bootstrap-2-3-2-transition` emits zero default paint tokens and retains Base timing defaults so callers can author either `.fade` or `.collapse` recipes without conflicts.
- **Classic Bootstrap 2.3.2 metrics**: Combine with 4px radii, fixed 14px/20px typography, and classic `#d9edf7` / `#f5f5f5` surfaces.
- **Reduced motion & Base semantics**: Under `prefers-reduced-motion: reduce`, automatic waits collapse to `0ms` while preserving event and detachment order. Core behavior is inherited from [Base Transition](/en/ui-libraries/base/transition/).
