Bootstrap 2.3.2 Hover Card pairs Base Hover Card's delayed open/close and collision-aware positioning with archived Bootstrap 2.3.2 `#08c` / `#005580` link colors, 276px max-width `.popover` shell geometry, and a 150ms linear opacity fade.

## Preview

Hover or focus `@proto-ui` for 150ms to open the Bootstrap 2.3.2 popover card. Moving into the card keeps it open while hovered.

## Installation

<InstallCommandCard
  command="npx @proto.ui/cli@latest add wc bootstrap-2-3-2-hover-card"
  manager="npm"
/>

Replace `wc` with `react`, `vue`, or `vue2` to generate the local facade for your framework.

## Usage

```tsx
import {
  BootstrapHoverCardRoot,
  BootstrapHoverCardTrigger,
  BootstrapHoverCardContent,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <BootstrapHoverCardRoot openDelay={150} closeDelay={250}>
      <BootstrapHoverCardTrigger>@proto-ui</BootstrapHoverCardTrigger>
      <BootstrapHoverCardContent side="bottom" align="center" sideOffset={6}>
        Host-neutral interaction protocols rendered with Bootstrap 2.3.2 popover chrome.
      </BootstrapHoverCardContent>
    </BootstrapHoverCardRoot>
  );
}
```

### Composition and styling

```text
BootstrapHoverCardRoot
├── BootstrapHoverCardTrigger
└── BootstrapHoverCardContent
```

- Trigger uses Bootstrap 2.3.2 `@linkColor` (`#08c`) and darkened `@linkColorHover` (`#005580`) with underline in light mode, automatically adapting hover/focus ink for dark hosts.
- Content projects the archived `.popover` shell (`max-width: 276px`, `6px` border radius, `9px 14px` inner padding) with a `150ms` linear fade.
