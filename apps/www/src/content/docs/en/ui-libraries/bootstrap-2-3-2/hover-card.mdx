Bootstrap 2.3.2 Hover Card pairs Base Hover Card's delayed open/close and collision-aware positioning with Bootstrap link styling, a 276px max-width `.popover` shell and a 150ms linear opacity fade.

## Preview

Hover or focus `@proto-ui` for 150ms to open the Bootstrap 2.3.2 popover card. Moving into the card keeps it open while hovered.

## Installation

Use `@proto.ui/prototypes-bootstrap-2-3-2/hover-card` and your host adapter from the same workspace revision. The React example adapts the exported prototypes directly with `@proto.ui/adapter-react`.

## Usage

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import * as proto from '@proto.ui/prototypes-bootstrap-2-3-2/hover-card';

const adapt = createReactAdapter(React);
const BootstrapHoverCardRoot = adapt(proto.hoverCardRoot);
const BootstrapHoverCardTrigger = adapt(proto.hoverCardTrigger);
const BootstrapHoverCardContent = adapt(proto.hoverCardContent);

export function Example() {
  return (
    <BootstrapHoverCardRoot openDelay={150} closeDelay={250}>
      <BootstrapHoverCardTrigger>@proto-ui</BootstrapHoverCardTrigger>
      <BootstrapHoverCardContent side="bottom" align="center" sideOffset={6}>
        Host-neutral interaction protocols rendered with Bootstrap 2.3.2 popover chrome.
      </BootstrapHoverCardContent>
    </BootstrapHoverCardRoot>
  );
}
```

### Composition and styling

```text
BootstrapHoverCardRoot
├── BootstrapHoverCardTrigger
└── BootstrapHoverCardContent
```

- Trigger uses the Bootstrap 2.3.2 link color (`#08c`) at rest. Hover and focus apply the theme foreground and an underline in both color schemes.
- Content projects the archived `.popover` shell (`max-width: 276px`, `6px` border radius, `9px 14px` inner padding) with a `150ms` linear fade.
