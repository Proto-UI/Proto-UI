## Usage

```tsx
import {
  Bootstrap232CarouselRoot,
  Bootstrap232CarouselViewport,
  Bootstrap232CarouselSlide,
  Bootstrap232CarouselPrevious,
  Bootstrap232CarouselNext,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <Bootstrap232CarouselRoot className="mx-auto w-full max-w-lg">
      <Bootstrap232CarouselViewport>
        <Bootstrap232CarouselSlide>Slide 1</Bootstrap232CarouselSlide>
        <Bootstrap232CarouselSlide>Slide 2</Bootstrap232CarouselSlide>
      </Bootstrap232CarouselViewport>
      <Bootstrap232CarouselPrevious aria-label="Previous slide">‹</Bootstrap232CarouselPrevious>
      <Bootstrap232CarouselNext aria-label="Next slide">›</Bootstrap232CarouselNext>
    </Bootstrap232CarouselRoot>
  );
}
```

- **Classic glyph controls**: `Previous` and `Next` are sized for single `‹` / `›` glyphs (`60px` light typography inside `40×40px` rings); always pair them with `sr-only` text or `aria-label` instead of visible multi-word strings.
- **Responsive sizing and snapping**: Configure `slidesPerView` (default `1`) and `minSlideSize` (default `0`) to show multiple equal-width slides; set an explicit bounded height on `Viewport` for `orientation="vertical"`.
- **Controlled index**: Pass `index` and listen to `indexChange` for controlled updates, or set `loop={true}` to wrap between the first and last reachable stops.
