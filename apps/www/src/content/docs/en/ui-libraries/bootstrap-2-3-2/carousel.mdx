Carousel pairs an equal-size slide strip with a continuously scrollable viewport and Previous/Next controls. Pointer drag, touch drag, wheel/trackpad scrolling, and keyboard navigation all snap to the nearest reachable slide boundary.

## Usage

### Responsive viewport and snapping

- Set `slidesPerView` (default `1`) for the maximum equal items shown at once and `minSlideSize` (default `0`, logical pixels) for each slide's minimum extent. Narrower viewports automatically reduce capacity, and the final snap aligns flush with the strip end.
- The preview above requests 2 slides per view with a `180` minimum size.
- Set an explicit bounded height on the viewport when using `orientation="vertical"`. Horizontal `direction="rtl"` mirrors dragging and arrow keys while preserving logical slide order.
- Setting `loop` wraps navigation between the first and last reachable indices without cloning slides.

### Controlled index

- Pass `index` to control the active slide externally and handle `indexChange` proposals.
- While dragging, the committed `index` remains unchanged; on release it moves to the proposed index if accepted by the parent, or snaps back to the current index.

## API

| Part | Props / States | Description |
| --- | --- | --- |
| `Root` | `slidesPerView` / `minSlideSize` | Defaults `1` / `0`; responsive capacity and minimum slide extent |
| `Root` | `index` / `indexChange` | Controlled snap index and change request event |
| `Root` | `orientation` / `direction` / `loop` | Axis, text direction, and boundary wrapping |
| `Root` | `visibleSlides` / `maxIndex` | Read-only states derived from the viewport |
| `Viewport` | `dragging` / `scrolling` / `scrollPosition` | Live drag/scroll state and normalized scroll position |
| `Slide` | `current` / `hidden` | Tracks the active snap and offscreen visibility without removing layout extent |
