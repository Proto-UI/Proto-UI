## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

Compose `Root`, `Trigger`, `Content`, `Item`, and `Link`:

- **Landmark structure**: `Root` provides a `navigation` landmark and tracks the single open panel via `value`. `Trigger` toggles the panel and `Content` renders a labelled region.
- **Commands and native links**: Use `Item` for menu commands and `Link` for real `<a>` destinations supporting `href`, `target`, `rel`, and `current` (`aria-current`). Disabled links clear their target and block activation.
- **Navigation observation**: After native link activation, `Link` emits a read-only `navigate` event (`{ href, target, rel, modified }`). Normal same-window clicks close the panel unless `closeOnSelect={false}`, while modifier/middle-clicks and `_blank` links keep the panel open.

## API

| Part | Props / Events | Description |
| --- | --- | --- |
| `Root` | `value` | Key of the currently open navigation panel |
| `Trigger` | — | Disclosure button for a navigation panel |
| `Content` | — | Labelled panel region |
| `Item` | — | Command action inside a panel |
| `Link` | `href` / `target` / `rel` / `current` / `disabled` / `closeOnSelect` | Native anchor props; `current={true}` marks the current page |
| `Link` | `navigate` | Read-only event emitted with `{ href, target, rel, modified }` after activation |
