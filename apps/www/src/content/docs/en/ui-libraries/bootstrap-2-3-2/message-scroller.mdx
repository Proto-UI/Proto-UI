Message Scroller keeps chat and activity feeds anchored to the bottom as new messages arrive, pauses auto-follow while reading older items, and lets users jump back to the latest entry on demand.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **End-follow behavior**: Appended content stays in view only when the user is already at the bottom. Scrolling away preserves the reading position until the user explicitly triggers Jump to latest, which scrolls down without stealing keyboard focus.
- **New content count**: Pass `newContentCount` from your application state rather than letting the scroller guess unread semantics.
- **Accessible region**: Set `a11yLabel` on `Root` to name the scrollable region (defaults to `'Messages'`).

## API

| Part   | Prop              | Default      | Description                                       |
| ------ | ----------------- | ------------ | ------------------------------------------------- |
| `Root` | `a11yLabel`       | `'Messages'` | Accessible name for the scrollable message region |
| `Root` | `newContentCount` | —            | Application-supplied count of new appended items  |
