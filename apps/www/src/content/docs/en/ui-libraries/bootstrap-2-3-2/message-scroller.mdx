Message Scroller pairs sticky bottom-follow behavior with classic Bootstrap 2.3.2 4px panel framing, subtle inset shadows, and beveled button chrome. Appended items scroll into view while the reader is at the bottom, pause while browsing history, and resume on demand via the floating Jump control.

## Installation

Available starting in `0.3.0-rc.1` and later releases. Import the prototypes directly from `@proto.ui/prototypes-bootstrap-2-3-2/message-scroller` and adapt them for your target runtime.

```ts
import {
  messageScrollerRoot,
  messageScrollerViewport,
  messageScrollerJump,
} from '@proto.ui/prototypes-bootstrap-2-3-2/message-scroller';
```

## Usage

Place `Root` inside a fixed-height container so `Viewport` scrolls vertically and `Jump` floats above the lower-right corner:

```tsx
<div className="h-72 w-full max-w-lg">
  <Bootstrap232MessageScrollerRoot a11yLabel="Release room messages">
    <Bootstrap232MessageScrollerViewport>
      <div className="flex flex-col pb-12">
        {messages.map((message) => (
          <div key={message.id}>{message.text}</div>
        ))}
      </div>
    </Bootstrap232MessageScrollerViewport>
    <Bootstrap232MessageScrollerJump>Jump to latest ↓</Bootstrap232MessageScrollerJump>
  </Bootstrap232MessageScrollerRoot>
</div>
```

### Behavior Notes

- **End-follow policy**: Appended entries stay in view only while the reader is already at the bottom. Scrolling up preserves reading position until the user explicitly jumps back.
- **Focus preservation**: Clicking `Jump` scrolls to the end without stealing keyboard focus.
- **Count and region naming**: Pass `newContentCount` from your own application state, and use `a11yLabel` on `Root` to name the scrollable region (defaults to `'Messages'`).
