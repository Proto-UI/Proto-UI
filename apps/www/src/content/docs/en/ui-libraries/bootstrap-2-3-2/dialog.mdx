## Installation

Use `@proto.ui/prototypes-bootstrap-2-3-2/dialog` and your host adapter from the same workspace revision. The React example adapts the exported prototypes directly with `@proto.ui/adapter-react`.

## Usage

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import * as proto from '@proto.ui/prototypes-bootstrap-2-3-2/dialog';

const adapt = createReactAdapter(React);
const BootstrapDialogClose = adapt(proto.dialogClose);
const BootstrapDialogCloseIcon = adapt(proto.dialogCloseIcon);
const BootstrapDialogContent = adapt(proto.dialogContent);
const BootstrapDialogDescription = adapt(proto.dialogDescription);
const BootstrapDialogFooter = adapt(proto.dialogFooter);
const BootstrapDialogHeader = adapt(proto.dialogHeader);
const BootstrapDialogMask = adapt(proto.dialogMask);
const BootstrapDialogRoot = adapt(proto.dialogRoot);
const BootstrapDialogTitle = adapt(proto.dialogTitle);
const BootstrapDialogTrigger = adapt(proto.dialogTrigger);

export function BootstrapDialogExample() {
  return (
    <BootstrapDialogRoot a11yLabel="Edit profile">
      <BootstrapDialogTrigger>Open Dialog</BootstrapDialogTrigger>
      <BootstrapDialogMask />
      <BootstrapDialogContent>
        <BootstrapDialogHeader>
          <BootstrapDialogTitle>Edit profile</BootstrapDialogTitle>
        </BootstrapDialogHeader>
        <div className="px-[15px] py-[15px]">
          <BootstrapDialogDescription>
            Make changes to your profile here. Click save when you&apos;re done.
          </BootstrapDialogDescription>
        </div>
        <BootstrapDialogFooter>
          <BootstrapDialogClose>Close</BootstrapDialogClose>
        </BootstrapDialogFooter>
        <BootstrapDialogCloseIcon />
      </BootstrapDialogContent>
    </BootstrapDialogRoot>
  );
}
```

### Composition

```text
BootstrapDialogRoot
├── BootstrapDialogTrigger
├── BootstrapDialogMask
└── BootstrapDialogContent
    ├── BootstrapDialogHeader
    │   └── BootstrapDialogTitle
    ├── BootstrapDialogDescription
    ├── BootstrapDialogFooter
    │   └── BootstrapDialogClose
    └── BootstrapDialogCloseIcon
```

### Visual and behavioral details

- **Classic motion**: `Content` runs Bootstrap 2.3.2's 300 ms opacity and `-25% -> 10%` top slide presence transition, paired with a 150 ms backdrop fade to 80% black opacity.
- **Layering & chrome**: `Mask` (`z-40`) and `Content` (`z-50`) maintain predictable stacking; `Header` applies `9px 15px` padding and a hairline divider, while `Footer` restores the classic `inset 0 1px 0 #fff` top highlight.
- **Accessibility**: Full focus trapping, trigger focus restoration, `Escape` and outside-press dismissal, and live `aria-labelledby` / `aria-describedby` links.
