## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

Compose `Root`, `Trigger`, `Mask`, `Content`, `Title`, `Description`, `Cancel`, and `Action`:

- **Modality and focus**: `Mask` renders the modal backdrop; `Content` traps focus, ignores outside clicks, and focuses `Cancel` first when available.
- **Actions and dismissal**: Activating `Action` emits `action` before requesting close so application code runs the actual effect. `Escape` and `Cancel` request dismissal directly.
- **Controlled state**: Pass `open` and listen to `openChange` for controlled usage, or use `defaultOpen` for uncontrolled state. Disabled actions do not activate.

## API

| Part | Props / Events | Description |
| --- | --- | --- |
| `Root` | `open` / `defaultOpen` | Controlled or initial open state |
| `Root` | `openChange` | Emitted when the dialog requests an open/close change |
| `Trigger` | — | Opens the dialog |
| `Mask` | — | Modal overlay backdrop |
| `Content` | — | Dialog surface with alert semantics and focus trapping |
| `Title` / `Description` | — | Accessible dialog heading and supporting text |
| `Cancel` | — | Dismisses the dialog; preferred initial focus target |
| `Action` | `action` | Emits `action` and requests close |
