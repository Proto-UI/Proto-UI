Bootstrap 2.3.2 AlertDialog pairs classic `.modal.fade` and `.modal-backdrop.fade` chrome and motion with alert-dialog focus safety, focusing `Cancel` first and blocking outside-click dismissal.

## Installation

Available starting in `0.3.0-rc.1` and later releases (`@proto.ui/prototypes-bootstrap-2-3-2`).

## Usage

```tsx
import {
  BootstrapAlertDialogRoot,
  BootstrapAlertDialogTrigger,
  BootstrapAlertDialogMask,
  BootstrapAlertDialogContent,
  BootstrapAlertDialogTitle,
  BootstrapAlertDialogDescription,
  BootstrapAlertDialogFooter,
  BootstrapAlertDialogCancel,
  BootstrapAlertDialogAction,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <BootstrapAlertDialogRoot>
      <BootstrapAlertDialogTrigger>Show Dialog</BootstrapAlertDialogTrigger>
      <BootstrapAlertDialogMask />
      <BootstrapAlertDialogContent>
        <BootstrapAlertDialogTitle>Are you absolutely sure?</BootstrapAlertDialogTitle>
        <BootstrapAlertDialogDescription>
          This action cannot be undone. This will permanently delete your account.
        </BootstrapAlertDialogDescription>
        <BootstrapAlertDialogFooter>
          <BootstrapAlertDialogCancel>Cancel</BootstrapAlertDialogCancel>
          <BootstrapAlertDialogAction>Continue</BootstrapAlertDialogAction>
        </BootstrapAlertDialogFooter>
      </BootstrapAlertDialogContent>
    </BootstrapAlertDialogRoot>
  );
}
```

### Parts

Compose `Root`, `Trigger`, `Mask`, `Content`, `Title`, `Description`, `Footer`, `Cancel`, and `Action`:

- **Modality and motion**: `Mask` renders the 0.8-opacity backdrop with a 150ms linear fade; `Content` runs the 300ms Bootstrap modal drop-in and fade transition, traps focus, blocks outside-click dismissal, and focuses `Cancel` first.
- **Footer**: Passive Bootstrap `.modal-footer` band with top divider and right-aligned action buttons.
- **Actions and variants**: Activating `Action` emits `action` before requesting close; `Escape` and `Cancel` request dismissal directly. Both `Trigger` and `Action` accept classic Bootstrap button variants such as `variant="danger"`.
