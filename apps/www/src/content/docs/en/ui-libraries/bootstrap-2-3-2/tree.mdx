Tree renders nested hierarchies with classic Bootstrap 2.3.2 `.well` / `.nav-list` navigation styling and `.btn-mini` disclosure toggles, supporting single selection, expandable branches, RTL mirroring, and full tree-view keyboard navigation.

## Installation

Available starting in `0.3.0-rc.1` and later releases. Import the prototypes from `@proto.ui/prototypes-bootstrap-2-3-2/tree` and adapt them for your target runtime:

```ts
import {
  treeRoot,
  treeItem,
  treeGroup,
  treeToggle,
} from '@proto.ui/prototypes-bootstrap-2-3-2/tree';
```

## Usage

```tsx
<Bootstrap232TreeRoot defaultValue="button" defaultExpandedKeys={['src', 'components']}>
  <div className="flex items-center gap-1.5">
    <Bootstrap232TreeToggle nodeKey="src">▾</Bootstrap232TreeToggle>
    <Bootstrap232TreeItem nodeKey="src" textValue="src" className="flex-1">
      src/
    </Bootstrap232TreeItem>
  </div>
  <Bootstrap232TreeGroup nodeKey="src">
    <Bootstrap232TreeItem nodeKey="button" parentKey="src" textValue="button.tsx">
      button.tsx
    </Bootstrap232TreeItem>
  </Bootstrap232TreeGroup>
</Bootstrap232TreeRoot>
```

### Structure & Semantics

- **Explicit hierarchy & grouping**: Give each `Item` a unique `nodeKey` and set `parentKey` to its parent branch. Place children inside a `TreeGroup` with the parent's `nodeKey` so `aria-controls` and `aria-labelledby` stay synchronized.
- **Historical visual projection**: `Root` uses the inset `.well` container (`#f5f5f5`), `Item` uses `.nav-list` `#08c` links, `#eee` hover/focus fill, and active `#08c` highlight, while `Toggle` renders a tactile `.btn-mini` button.
- **Keyboard & RTL**: Up/Down, `Home`/`End`, and first-letter typing move focus in visual order; `direction="rtl"` mirrors the 15px group indentation and swaps Left/Right arrow mappings.
