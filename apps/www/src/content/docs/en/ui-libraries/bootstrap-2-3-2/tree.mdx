## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Explicit hierarchy**: Give every node a unique `nodeKey` and point child nodes to their parent via `parentKey`. Duplicate keys, missing parents, and cycles ignore invalid configuration and stay inactive.
- **Keyboard navigation**: Up/Down arrows, `Home`/`End`, and first-letter typing move focus; Right arrow expands a collapsed node or moves to its first child, while Left arrow collapses an expanded node or moves to its parent.
- **Controlled state**: Both `value` (selected key) and `expandedKeys` support controlled usage via change requests.

## API

| Prop           | Description                                   |
| -------------- | --------------------------------------------- |
| `nodeKey`      | Unique identifier for each node in the tree   |
| `parentKey`    | Key of the node's parent                      |
| `value`        | Selected node key (supports controlled mode)  |
| `expandedKeys` | Expanded node keys (supports controlled mode) |
