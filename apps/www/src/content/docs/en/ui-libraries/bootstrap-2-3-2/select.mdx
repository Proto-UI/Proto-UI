Bootstrap 2.3.2 Select is a design-language extension over Base Select inspired by Bootstrap 2.3.2's button-dropdown visuals, offering controlled single selection, keyboard navigation, and collision-aware positioning.

## Usage

### Composition and interaction

Compose `Root`, `Trigger`, `Value`, `Content`, and `Item`:

- **Root manages the state**: Control `open` and `value` independently, or initialize uncontrolled state with `defaultOpen` and `defaultValue`.
- **Keyboard and pointer**: Click `Trigger` to toggle, press `Enter`/`Space` to open, or press `ArrowDown`/`ArrowUp` to open at the selected or first/last enabled option. Highlighting items never commits; pointer click, `Enter`, or `Space` commits an enabled `Item`. `Escape` cancels and restores focus to `Trigger`; `Tab` and outside clicks close the list.
- **Label display and wrapping**: `Value` falls back from selected text → raw `value` → `placeholder` → empty, updating automatically when the selected item's `textValue` changes. Long labels wrap cleanly and the popup stays bounded by the viewport.
- **Visual styling**: Because archived Bootstrap 2.3.2 relied on native HTML `<select>`, this component adapts its button-dropdown styling (4px trigger corners, 6px panel corners, rem-scaled padding, and a darkened blue highlight for crisp white text contrast).

See [Base Select](/en/ui-libraries/base/select/) for shared single-selection details.

## API

| Part | Props / Events | Description |
| --- | --- | --- |
| `Root` | `open` / `defaultOpen`, `value` / `defaultValue` | Independently controlled open state and selected value |
| `Root` | `disabled` / `closeOnSelect` | Disables the select / closes automatically after selection |
| `Root` | `openChange` / `valueChange` | Open state and value change request events |
| `Trigger` | — | Combobox trigger button |
| `Value` | `placeholder` | Displays selected text or placeholder fallback |
| `Content` | `side` / `align` / `sideOffset` / `alignOffset` / `avoidCollisions` / `collisionPadding` | Anchored listbox positioning and collision handling |
| `Item` | `value` / `textValue` / `disabled` / `select` | Option entry and selection event |
