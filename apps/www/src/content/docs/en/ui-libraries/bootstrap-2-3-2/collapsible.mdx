## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

```ts
import {
  collapsibleRoot,
  collapsibleTrigger,
  collapsibleContent,
} from '@proto.ui/prototypes-bootstrap-2-3-2/collapsible';
```

## Usage

- **Three-part composition**: Place one `Trigger` and one `Content` inside each `Root`. Nested and sibling collapsibles manage state independently.
- **Root manages the state**: Pass `open` for controlled mode and respond to `openChange` (`{ open, reason }`) to accept changes. Disabling blocks new toggles without closing already open content.
- **Content lifecycle**: Unmounts content when closed; set `keepMounted` on `Content` to keep it mounted while hidden.
- **Responsive styling**: Labels and long words wrap naturally, padding scales in `rem` with text size, and surrounding containers should leave room for focus rings.

See [Base Collapsible](/en/ui-libraries/base/collapsible/) for the shared disclosure protocol.

## API

| Part | Props / Methods / Events | Description |
| --- | --- | --- |
| `Root` | `open` / `defaultOpen` / `disabled` | Controlled or initial open state and disabled flag |
| `Root` | `openCollapsible()` / `close()` / `toggle()` | Programmatic open, close, and toggle requests |
| `Root` | `openChange` | Emitted with `{ open, reason }` on state requests |
| `Trigger` | `disabled` / `focusSelf()` | Disclosure button with natural Tab order and `Enter`/`Space` activation |
| `Content` | `keepMounted` | Defaults to `false`; keeps hidden content mounted when `true` |
