Bootstrap 2.3.2 Collapsible expands and collapses a single content section, pairing authentic Bootstrap 2.3.2 pixel borders, link colors, and a 350ms height collapse transition with [Base Collapsible](/en/ui-libraries/base/collapsible/) disclosure semantics.

## Installation

Currently available from workspace source. Import the parts directly from `@proto.ui/prototypes-bootstrap-2-3-2/collapsible`:

```ts
import {
  collapsibleRoot,
  collapsibleTrigger,
  collapsibleContent,
} from '@proto.ui/prototypes-bootstrap-2-3-2/collapsible';
```

## Usage

```tsx
import {
  Bootstrap232CollapsibleRoot,
  Bootstrap232CollapsibleTrigger,
  Bootstrap232CollapsibleContent,
} from '@/components/ui/collapsible';

export function Example() {
  return (
    <Bootstrap232CollapsibleRoot>
      <Bootstrap232CollapsibleTrigger>Order #4189 — Product details</Bootstrap232CollapsibleTrigger>
      <Bootstrap232CollapsibleContent>
        Status: Shipped · 100 Market St, San Francisco · 2x Studio Headphones.
      </Bootstrap232CollapsibleContent>
    </Bootstrap232CollapsibleRoot>
  );
}
```

### Parts and Classic Metrics

```text
CollapsibleRoot
├── CollapsibleTrigger
└── CollapsibleContent
```

- **Fixed pixel proportions and link ink**: preserves Bootstrap 2.3.2's `14px`/`20px` type scale, `4px` radius, `15px × 8px` trigger padding, `15px × 9px` inner body padding, and classic `#08c` link ink shifting to `#005580` underlined on hover/press (with readable dark-mode border and ink fallbacks).
- **350ms height collapse**: `Content` binds `asTransition()` to animate `blockSize` smoothly while keeping inner border and padding on the child wrapper so closed height collapses cleanly to zero.
- **Controlled and mount lifecycle**: pass `open` and handle `openChange` (`{ open, reason }`) for controlled state; `Content` unmounts when closed unless `keepMounted={true}` is set.
