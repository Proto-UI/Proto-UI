## Installation

Available starting in `0.3.0-rc.1` and later releases via `@proto.ui/prototypes-bootstrap-2-3-2/form`.

## Usage

```tsx
import {
  Bootstrap232FormRoot,
  Bootstrap232FormField,
  Bootstrap232FormSubmit,
  Bootstrap232FormReset,
  Bootstrap232FieldLabel,
  Bootstrap232FieldControl,
  Bootstrap232FieldError,
} from '../proto-ui/components/react';

export function ExampleBootstrapForm() {
  return (
    <Bootstrap232FormRoot ariaLabel="Profile form" onSubmit={({ values }) => console.log(values)}>
      <Bootstrap232FormField name="username" required>
        <Bootstrap232FieldLabel>Username</Bootstrap232FieldLabel>
        <Bootstrap232FieldControl placeholder="ada_lovelace" />
        <Bootstrap232FieldError />
      </Bootstrap232FormField>
      <div className="flex items-center gap-2 border-t border-border pt-3">
        <Bootstrap232FormSubmit variant="primary">Save changes</Bootstrap232FormSubmit>
        <Bootstrap232FormReset variant="default">Cancel</Bootstrap232FormReset>
      </div>
    </Bootstrap232FormRoot>
  );
}
```

### Anatomy & Behavior

- **Validation and submission**: `Root` validates all registered `FormField` controls and emits `submit` with values keyed by field name once every enabled field passes. Disabled fields are excluded, and duplicate field names throw `FORM_DUPLICATE_NAME` during serialization. Async validations wait for the latest result and cancel stale submissions on edit, cancel, or unmount.
- **Implicit Enter submit**: Pressing `Enter` inside a focused single-line `Field`, `Number Field`, or `Input OTP` submits the form (excluding IME composition, modifier keys, and key repeats).
- **Disabled state and reset**: Setting `disabled` on `Root` cascades to contained fields and buttons. `FormReset` or `requestReset()` restores uncontrolled initial values, proposes resets to controlled fields, cancels pending edits/validation, and emits `reset`. Call `resetValidation()` to clear errors without touching values.
- **Action buttons**: `FormSubmit` and `FormReset` apply Bootstrap 2.3.2 4px radius, gradients, and inset shadows, supporting `variant` (`default`, `primary`, `danger`, `success`, `info`, `warning`, `inverse`).
