## Usage

Compose `Root`, `FormField`, `FormSubmit`, and `FormReset`:

- **Validation and submission**: `Root` validates all registered `FormField` controls and emits form values keyed by field name on `submit` once every enabled field passes. Disabled fields are excluded, and duplicate field names block serialization. Async validations wait for current results and cancel stale submissions on value change, removal, or unmount.
- **Implicit Enter submit**: Pressing `Enter` inside a focused single-line `Field`, `Number Field`, or `Input OTP` submits the form (excluding IME composition, modifier keys, and repeated keydown events).
- **Disabled state and reset**: Setting `disabled` on `Root` cascades to contained fields. `FormReset` or `requestReset()` restores initial uncontrolled values, proposes reset changes for controlled fields, cancels pending edits/validation, and emits `reset`. Call `resetValidation()` to clear errors without touching values.
- **Action buttons**: `FormSubmit` and `FormReset` apply Bootstrap 2.3.2 button visuals and expose `disabled`, `hovered`, `pressed`, `focused`, `focusVisible`, and `focusSelf()`. Handle network requests in your `submit` listener.

## API

| Part | Props / Methods / Events | Description |
| --- | --- | --- |
| `Root` | `disabled` | Disables the form and all contained fields |
| `Root` | `submit` / `reset` | Emits keyed field values on valid submit / emits on reset |
| `Root` | `requestReset()` / `resetValidation()` | Resets values and validation / clears validation only |
| `FormField` | — | Registers a named field with the form |
| `FormSubmit` | `focusSelf()` | Validates and submits the form |
| `FormReset` | `focusSelf()` | Resets the form |
