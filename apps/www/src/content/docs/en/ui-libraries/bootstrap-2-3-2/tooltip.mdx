## Installation

Bootstrap 2.3.2 Tooltip is available from workspace source via `@proto.ui/prototypes-bootstrap-2-3-2/tooltip` (`tooltipGroup`, `tooltipRoot`, `tooltipTrigger`, `tooltipContent`) for use with any Proto UI host adapter.

## Usage

```tsx
import {
  BootstrapTooltipGroup,
  BootstrapTooltipRoot,
  BootstrapTooltipTrigger,
  BootstrapTooltipContent,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <BootstrapTooltipGroup>
      <BootstrapTooltipRoot>
        <BootstrapTooltipTrigger>Account</BootstrapTooltipTrigger>
        <BootstrapTooltipContent side="top">View account settings</BootstrapTooltipContent>
      </BootstrapTooltipRoot>
    </BootstrapTooltipGroup>
  );
}
```

### Composition

```text
TooltipGroup (optional)
└── TooltipRoot
    ├── TooltipTrigger
    └── TooltipContent
```

- `Group` coordinates cold hover delay (`700ms`), close delay (`100ms`), and warm sibling handoff (`300ms`).
- `Trigger` remains chromeless with a classic focus outline; `Tab` focus opens immediately and `Escape` dismisses while preserving trigger focus.
- `Content` renders in a portal with automatic `aria-describedby` / `role="tooltip"` wiring and disables transitions when reduced motion is preferred.

### Events, States & Methods

- **Root**: Exposes read-only state `open`, event `openChange` (`{ open, reason }`), and methods `openTooltip(reason?)`, `close(reason?)`, `toggle(reason?)`.
- **Trigger**: Exposes read-only states `disabled`, `hovered`, `focused`, `focusVisible`, and method `focusSelf(options?)`.
- **Content**: Exposes read-only state `open` and Transition handles (`transitionState`, `isPresent`, `controls`).
