Surface is a visual-only container implementing [Base Surface](/en/ui-libraries/base/surface/) in Bootstrap 2.3.2 styling. It applies backgrounds, borders, corners, and elevation while leaving semantics, focus, and pointer handling to your interactive controls.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { surfaceRoot } from '@proto.ui/prototypes-bootstrap-2-3-2/surface';

const Surface = createReactAdapter(React)(surfaceRoot);

export function Summary() {
  return (
    <Surface variant="muted" radius="md" border="none">
      <div style={{ padding: '1rem' }}>Saved locally</div>
    </Surface>
  );
}
```

## Usage

- **Passive presentation**: `hovered`, `focusVisible`, `pressed`, and `current` are display inputs supplied by an enclosing semantic control. Surface adds no ARIA role, event handler, or Tab stop—compose real `Button` or native `<a>` elements for interaction. Use `tone="inherit"` on nested `Text` children to inherit foreground color.
- **Bootstrap 2.3.2 presets**:
  - `actionProfile="button"`: Applies passive button styling while the enclosing control owns interaction.
  - `colorContext="navbar"`: Switches transparent surfaces (`variant="transparent"`, `actionProfile="none"`) to white ink and a white focus ring for Bootstrap 2.3.2's blue navbar; ignored by other variants and `actionProfile="button"`.
- **Fade transitions**: Pass `fade={true}` alongside `transitionState` from [Transition](/en/ui-libraries/base/transition/) to map `closed`/`leaving` to opacity `0` and `entering`/`entered` to opacity `1`. Set `--pui-surface-transition-duration` (default `0ms`) to control duration; opacity changes do not unmount or disable content on their own.

## API

| Prop | Values | Default | Description |
| --- | --- | --- | --- |
| `variant` | `transparent` \| `outline` \| `secondary` \| `muted` \| `accent` \| `solid` \| `scrim` | `outline` | Background and foreground treatment |
| `radius` | `default` \| `none` \| `sm` \| `md` \| `lg` \| `xl` \| `full` | `default` | Corner radius token |
| `border` | `all` \| `bottom` \| `none` | `all` | Border placement |
| `elevation` | `none` \| `raised` | `none` | Shadow elevation |
| `transitionState` | `closed` \| `entering` \| `entered` \| `leaving` | `entered` | Phase supplied by an enclosing Transition |
| `fade` | `boolean` | `false` | Maps `transitionState` to opacity |
| `hovered` / `focusVisible` / `pressed` / `current` | `boolean` | `false` | Externally supplied visual states |
| `actionProfile` | `none` \| `button` | `none` | Bootstrap 2.3.2 preset for passive button paint |
| `colorContext` | `default` \| `navbar` | `default` | Bootstrap 2.3.2 preset for white ink/focus on blue navbars |
