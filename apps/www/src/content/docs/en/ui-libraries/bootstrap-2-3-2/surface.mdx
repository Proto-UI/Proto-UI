Surface is a visual-only container implementing [Base Surface](/en/ui-libraries/base/surface/) in classic Bootstrap 2.3.2 styling, supporting 4px corners, raised thumbnails, bevelled button paint, and blue navbar context adaptation while keeping semantics and interaction on the enclosing control.

## Installation

Available inside the workspace from `@proto.ui/prototypes-bootstrap-2-3-2/surface` (or the package root); not published to the public CLI registry.

## Usage

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { surfaceRoot } from '@proto.ui/prototypes-bootstrap-2-3-2/surface';

const Surface = createReactAdapter(React)(surfaceRoot);

export function Summary() {
  return (
    <Surface variant="outline" elevation="raised">
      <div className="p-4">Saved locally</div>
    </Surface>
  );
}
```

### Presets and passive boundaries

- `hovered`, `focusVisible`, `pressed`, and `current` are visual inputs supplied by an enclosing control. Surface adds no ARIA role, event listener, or Tab stop; pass `tone="inherit"` to nested `Text` children to inherit foreground color.
- `actionProfile="button"` applies passive `.btn` / `.btn-primary` gradient styling (`solid` selects primary paint; other opaque variants select default `.btn` paint).
- `colorContext="navbar"` applies only when `variant="transparent"` and `actionProfile="none"`, switching to white text, dark translucent hover/pressed fills, and a white focus ring for blue navbars.
- Enable `fade` to map `transitionState` from [Transition](/en/ui-libraries/base/transition/) to opacity (`closed` and `leaving` -> `0`; `entering` and `entered` -> `1`) using `--pui-surface-transition-duration` (default `0ms`).
