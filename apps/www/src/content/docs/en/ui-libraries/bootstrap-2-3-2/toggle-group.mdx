## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

Compose `Root` and `Item`:

- **Single and multiple selection**: `value` and `defaultValue` are string arrays. When `multiple={false}`, at most one item stays pressed and clicking it again clears the selection; when `multiple={true}`, multiple items can stay pressed simultaneously.
- **Controlled state and keyboard**: Controlled usage emits `valueChange` without mutating caller state. Arrow keys move focus without toggling selection; disabled, read-only, and duplicate-valued items cannot commit.

## API

| Part   | Props / Events           | Description                                  |
| ------ | ------------------------ | -------------------------------------------- |
| `Root` | `value` / `defaultValue` | `string[]` of active item values             |
| `Root` | `multiple`               | `boolean` enabling multi-selection           |
| `Root` | `disabled` / `readOnly`  | Group disabled or read-only flags            |
| `Root` | `valueChange`            | Emitted when selection changes are requested |
| `Item` | `value` / `disabled`     | Unique item value and per-item disabled flag |
