## Installation

Available starting in `0.3.0-rc.1` and later releases. Import the prototypes directly from `@proto.ui/prototypes-bootstrap-2-3-2/toggle-group` and adapt them for your target runtime.

## Usage

```tsx
import { BootstrapToggleGroupItem, BootstrapToggleGroupRoot } from '../proto-ui/components/react';

export function Example() {
  return (
    <BootstrapToggleGroupRoot defaultValue={['left']} a11yLabel="Text alignment">
      <BootstrapToggleGroupItem value="left">Left</BootstrapToggleGroupItem>
      <BootstrapToggleGroupItem value="middle">Middle</BootstrapToggleGroupItem>
      <BootstrapToggleGroupItem value="right">Right</BootstrapToggleGroupItem>
    </BootstrapToggleGroupRoot>
  );
}
```

### Composition

```text
ToggleGroupRoot
├── ToggleGroupItem
└── ToggleGroupItem
```

- **Classic joined geometry**: Outer endpoints carry `4px` / `6px` / `3px` corners matched to the button size while interior seams collapse by `-1px`; hovered, focused, and active items elevate to `z-[2]`.
- **Selection & keyboard**: `value` and `defaultValue` are always string arrays. Arrow keys move focus without toggling; `Space` or `Enter` toggles the focused button. Pass `value` for controlled mode and handle `valueChange`.
