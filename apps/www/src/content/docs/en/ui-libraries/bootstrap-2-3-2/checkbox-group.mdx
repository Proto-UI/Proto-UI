Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

Compose `Root`, `Item`, and an optional `All` control:

- **State management**: `Root` manages a `string[]` via `value` / `defaultValue`. In controlled mode it emits `valueChange` without mutating caller state; `getValue()` returns a copy. Duplicate item values are ignored.
- **Select all**: `All` reflects checked, mixed (dash), or unchecked across enabled items and toggles only enabled items while preserving disabled selections.
- **Keyboard and visuals**: Each item has its own Tab stop and toggles with `Space` (`Enter` does not toggle). The decorative indicator uses check, dash, and empty box shapes so state is not conveyed by color alone.
- **Form integration**: Inside `Field` or `FormField`, `Root` automatically participates in label activation, required validation, form serialization, and reset.

## API

| Part | Props / Events / Methods | Description |
| --- | --- | --- |
| `Root` | `value` / `defaultValue` | `string[]` of selected item values |
| `Root` | `disabled` / `readOnly` / `ariaLabel` | Group disabled, read-only, and accessible name props |
| `Root` | `valueChange` / `getValue()` | Change request event and copy reader |
| `Item` | `value` / `disabled` | Unique item key and per-item disabled flag |
| `All` | — | Toggles all enabled items and reflects mixed state |
