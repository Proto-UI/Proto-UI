Bootstrap 2.3.2 Checkbox Group coordinates a set of checkboxes sharing a string-array value, preserving classic 14px/20px form proportions, inset borders, primary gradient fills, select-all/mixed state, and direct `Field` / `Form` integration.

## Installation

Available starting in `0.3.0-rc.1` and later releases.

## Usage

```tsx
import {
  Bootstrap232CheckboxGroupRoot,
  Bootstrap232CheckboxGroupAll,
  Bootstrap232CheckboxGroupItem,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <Bootstrap232CheckboxGroupRoot defaultValue={['email']} ariaLabel="Notification channels">
      <Bootstrap232CheckboxGroupAll>All notifications</Bootstrap232CheckboxGroupAll>
      <Bootstrap232CheckboxGroupItem value="email">Email updates</Bootstrap232CheckboxGroupItem>
      <Bootstrap232CheckboxGroupItem value="sms">SMS alerts</Bootstrap232CheckboxGroupItem>
    </Bootstrap232CheckboxGroupRoot>
  );
}
```

### Anatomy and keyboard

- **Root**: Manages a `string[]` value (`value` / `defaultValue`), `orientation` (`horizontal` maps to `.checkbox.inline` layout), `disabled`, `readOnly`, and `ariaLabel`.
- **Item**: Individual option with a unique `value` and optional `disabled` flag. Each item has its own `Tab` stop and toggles with `Space` (`Enter` does not toggle).
- **All**: Reflects checked, mixed (dash), or unchecked across enabled items and toggles only enabled items while preserving disabled selections.
- **Forms**: Inside `Field` or `FormField`, `Root` participates in label activation, required validation, form serialization, and reset.

### Events, Methods, and States

- **Root events**: `valueChange` (payload `{ value: string[] }`).
- **Root methods**: `getValue(): string[]`, `resetValue(): boolean`, `focusSelf(): void`.
- **Exposed states**: Root exposes `checked`, `indeterminate`, `disabled`, `readOnly`; Item and All expose `checked`, `indeterminate`, `disabled`, `readOnly`, `focused`, `focusVisible`.
