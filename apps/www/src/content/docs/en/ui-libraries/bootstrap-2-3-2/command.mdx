## Installation

Currently available from workspace source (`@proto.ui/prototypes-bootstrap-2-3-2/command`); not yet included in the 0.2.0 stable release.

## Usage

```tsx
import {
  commandRoot,
  commandInput,
  commandContent,
  commandItem,
  commandEmpty,
} from '@proto.ui/prototypes-bootstrap-2-3-2/command';
```

### Composition

```text
CommandRoot
├── CommandInput
└── CommandContent
    ├── CommandItem
    └── CommandEmpty
```

- **Classic styling**: Retains the 30px input height, `#52a8ec` focus glow, 6px dropdown panel shadow, and `#08c -> #0077b3` active highlight gradient with a bounded `300px` scrollable list.
- **Filtering and execution**: Matches `textValue` and `keywords` case- and diacritic-insensitively, or set `filter={false}` for external filtering. Pressing `Enter` or clicking an item emits `execute`.
- **Keyboard and IME**: Focus stays in `Input` during arrow navigation, IME composition never triggers selection, and disabled or duplicate-valued items cannot execute.

### Other Parts & Events

- **Input**: `placeholder`, `a11yLabel`, and `name` default to `''`.
- **Content**: `side="bottom"`, `align="start"`, `sideOffset={4}`, `collisionPadding={8}`.
- **Item**: `value`, `textValue`, and `keywords` default to `''`; `disabled` defaults to `false`.
- **Empty**: No props; shown when no commands match.
- **Events**: `Root` emits `execute`, `valueChange`, `inputValueChange`, and `openChange`.
