## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

Compose `Root`, `Input`, `Content`, `Item`, and `Empty`:

- **Executing commands**: The list stays inline and open. Pressing `Enter` or clicking an item emits `execute` with the selected command so your application handles the action; typing a query never executes anything.
- **Filtering and empty state**: Built-in filtering matches `textValue` and `keywords` case- and diacritic-insensitively, or set `filter={false}` for caller-filtered children. `Empty` renders when no commands match.
- **Keyboard and IME**: Focus stays in `Input` during Arrow navigation, and IME composition never triggers selection. Disabled and duplicate-valued items cannot commit.

## API

| Part | Props / Events | Description |
| --- | --- | --- |
| `Root` | `value` / `inputValue` / `open` / `filter` | Controlled state inputs and built-in/external filter toggle |
| `Root` | `execute` | Emitted when a command item is activated |
| `Input` | — | Single-line command search input |
| `Content` | — | Inline command list container |
| `Item` | `value` / `textValue` / `keywords` / `disabled` | Individual command entry |
| `Empty` | — | Displayed when no commands match |
