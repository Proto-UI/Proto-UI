Bootstrap 2.3.2 Image preserves the archived `.img-rounded`, `.img-polaroid`, and `.img-circle` image treatments while delegating source management, object-fit sizing, accessibility modes, and live loading status events to Base Image.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import `imageRoot` (aliased as `bootstrap232ImageRoot`) and `Bootstrap232ImageRootProps` directly from `@proto.ui/prototypes-bootstrap-2-3-2/image`.

## Usage

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { bootstrap232ImageRoot } from '@proto.ui/prototypes-bootstrap-2-3-2/image';

const BootstrapImage = createReactAdapter(React)(bootstrap232ImageRoot);

export function FramedPortrait() {
  return (
    <BootstrapImage
      source="/images/base-image/portrait.svg"
      a11yMode="informative"
      alternativeText="Portrait framed with Bootstrap 2.3.2 polaroid trim"
      fit="cover"
      appearance="polaroid"
      surfaceStyle={{ width: '160px', height: '160px' }}
    />
  );
}
```

- **Appearances (`appearance`)**:
  - `default`: Responsive borderless image (`max-w-full h-auto align-middle border-0`).
  - `rounded`: Classic `6px` rounded corners (`.img-rounded`).
  - `polaroid`: `4px` white frame padding, `1px rgba(0, 0, 0, 0.2)` border, and subtle drop shadow (`.img-polaroid`).
  - `circle`: Historical `500px` radius (`.img-circle`); pair with a 1:1 square container for a true circular crop.
- **Accessibility and loading**: `a11yMode`, `alternativeText`, `fit`, `loadingStatus`, and `loadingStatusChange` are inherited directly from [Base Image](/en/ui-libraries/base/image/).
