Bootstrap 2.3.2 Checkbox adapts the archived visual language with a custom `Root` and `Indicator` anatomy—it is not the archived native checkbox, and requires no legacy Bootstrap JavaScript or Glyphicons.

## Usage

- **Root manages the state**: Supports controlled and uncontrolled `checked` and `indeterminate`, pointer and `Space` activation, disabled handling, focus, and the `checkbox` role with `mixed` state.
- **Indicator**: Place inside `Root` to render the tick or dash automatically; `indeterminate` takes visual precedence over `checked`.
- **Palette**: Keeps the archived Bootstrap 2.3.2 light palette even in dark hosts.

## API

| Part | Props / Events | Description |
| --- | --- | --- |
| `Root` | `checked` / `defaultChecked` | Controlled or initial checked state |
| `Root` | `indeterminate` / `defaultIndeterminate` | Controlled or initial mixed state |
| `Root` | `disabled` | Prevents interaction when enabled |
| `Root` | `checkedChange` / `indeterminateChange` | Change events for checked and indeterminate state |
| `Indicator` | — | Derived tick/dash indicator placed inside `Root` |
