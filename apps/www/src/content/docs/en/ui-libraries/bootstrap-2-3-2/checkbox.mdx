Bootstrap 2.3.2 Checkbox adapts the classic 14px beveled gradient control and blue focus glow with a custom `Root` and `Indicator` anatomy—requiring no legacy Bootstrap JavaScript or Glyphicons.

## Usage

```tsx
import {
  Bootstrap232CheckboxIndicator,
  Bootstrap232CheckboxRoot,
  Bootstrap232LabelRoot,
} from '@proto.ui/prototypes-bootstrap-2-3-2';

export function Example() {
  return (
    <div className="flex items-center gap-2.5">
      <Bootstrap232CheckboxRoot defaultChecked>
        <Bootstrap232CheckboxIndicator />
      </Bootstrap232CheckboxRoot>
      <Bootstrap232LabelRoot>Accept terms and conditions</Bootstrap232LabelRoot>
    </div>
  );
}
```

- **Root manages the state**: Supports controlled and uncontrolled `checked` and `indeterminate`, pointer and `Space` activation, disabled and read-only policies, focus, and the `checkbox` role with `mixed` state.
- **Indicator**: Place inside `Root` to render the dark tick or dash automatically; `indeterminate` takes visual precedence over `checked`.
- **Classic feedback and palette**: Hover and press use Bootstrap 2.3.2 beveled gradients, keyboard focus displays the `#52a8ec` glow, and the control keeps its classic light face even in dark hosts.

## API

### Root

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'checked', type: 'boolean | undefined', default: 'uncontrolled' },
    { name: 'defaultChecked', type: 'boolean', default: 'false' },
    { name: 'indeterminate', type: 'boolean | undefined', default: 'uncontrolled' },
    { name: 'defaultIndeterminate', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'readOnly', type: 'boolean', default: 'false' },
    { name: 'required', type: 'boolean', default: 'false' },
  ]}
/>

`Root` exposes `checked`, `indeterminate`, `disabled`, `readOnly`, `required`, `hovered`, `focused`, `focusVisible`, and `pressed` states, `focusSelf(options?)` and `resetValue()` methods, and `checkedChange` (`{ checked, indeterminate }`) and `indeterminateChange` (`{ indeterminate }`) events.

### Indicator

`Indicator` declares no props of its own. Place it inside `Root` to sync checked and mixed marks automatically; it exposes `checked`, `indeterminate`, `isChecked()`, and `isIndeterminate()`.
