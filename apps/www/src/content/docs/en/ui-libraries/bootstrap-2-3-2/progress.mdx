## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the parts from `@proto.ui/prototypes-bootstrap-2-3-2/progress`:

```ts
import {
  progressRoot,
  progressLabel,
  progressTrack,
  progressIndicator,
  progressValue,
} from '@proto.ui/prototypes-bootstrap-2-3-2/progress';
```

## Usage

Compose `Root`, `Label`, `Track`, `Indicator`, and `Value`. Place `Label` and `Value` before `Track` for an inline header row above the bar:

```tsx
<Bootstrap232ProgressRoot variant="success" value={60} valueText="60%" className="w-full max-w-sm">
  <Bootstrap232ProgressLabel>Upload progress</Bootstrap232ProgressLabel>
  <Bootstrap232ProgressValue />
  <Bootstrap232ProgressTrack>
    <Bootstrap232ProgressIndicator />
  </Bootstrap232ProgressTrack>
</Bootstrap232ProgressRoot>
```

```text
ProgressRoot
├── ProgressLabel
├── ProgressValue
└── ProgressTrack
    └── ProgressIndicator
```

- **Contextual variants**: `Root` and `Indicator` support `default`, `info`, `success`, `warning`, and `danger` classic Bootstrap 2.3.2 gradients with the 600ms CSS ease width transition (respecting reduced-motion preferences).
- **Determinate and indeterminate**: `value` clamps to `[min, max]` (equal bounds evaluate to `0%`). Omitting `value` or setting `indeterminate={true}` enters indeterminate mode and omits `aria-valuenow`.
- **Read-only display**: Progress adds no Tab stop, and every part exposes synchronized `value`, `percentage`, `indeterminate`, and `status` states.

### Indicator and exposed states

- `ProgressIndicator` accepts an optional `variant` override (`'default' | 'info' | 'success' | 'warning' | 'danger' | 'inherit'`, default `'inherit'`).
- All parts expose synchronized read-only states: `value`, `percentage`, `indeterminate`, and `status`.
