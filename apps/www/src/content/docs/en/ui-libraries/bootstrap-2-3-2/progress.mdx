## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

```ts
import {
  progressRoot,
  progressLabel,
  progressTrack,
  progressIndicator,
  progressValue,
} from '@proto.ui/prototypes-bootstrap-2-3-2/progress';
```

## Usage

Compose `Root`, `Label`, `Track`, `Indicator`, and `Value`:

- **Determinate and indeterminate**: `Root` clamps `value` between `min` (default `0`) and `max` (default `100`), returning `0` percentage when `min === max`. Omit `value` or set `indeterminate={true}` for unknown progress without reporting a numeric percentage.
- **Read-only display**: `Label` names the bar, `Track` and `Indicator` render the fill, and `Value` shows `valueText` or the formatted number. Progress is passive and adds no Tab stop.

## API

| Part | Props / States | Description |
| --- | --- | --- |
| `Root` | `value` / `min` / `max` | Current progress and bounds (`0`–`100` by default) |
| `Root` | `indeterminate` | Set `true` (or omit `value`) for indeterminate state |
| `Root` | `ariaLabel` / `valueText` | Accessible name and custom display string |
| All parts | `value` / `percentage` / `indeterminate` / `status` | Synchronized read-only progress states |
| `Label` / `Track` / `Indicator` / `Value` | — | Label, track, fill indicator, and value readout |
