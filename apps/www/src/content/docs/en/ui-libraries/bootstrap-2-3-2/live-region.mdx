Bootstrap 2.3.2 Live Region inherits ARIA live-region semantics from [Base Live Region](/en/ui-libraries/base/live-region/), projecting `role`, `aria-live`, and `aria-atomic` as an unboxed semantic container rather than styling itself as a Bootstrap visual alert box.

## Installation

Currently available from workspace source only; not included in the 0.2.0 stable release or CLI targets. Import `liveRegionRoot` from `@proto.ui/prototypes-bootstrap-2-3-2/live-region`:

```ts
import { liveRegionRoot } from '@proto.ui/prototypes-bootstrap-2-3-2/live-region';
```

## Usage

```tsx
import { AdaptToReact } from '@proto.ui/adapter-react';
import { liveRegionRoot } from '@proto.ui/prototypes-bootstrap-2-3-2/live-region';

const BootstrapLiveRegionRoot = AdaptToReact(liveRegionRoot);

export function StatusBanner({ message }: { message: string }) {
  return (
    <BootstrapLiveRegionRoot politeness="polite" atomic>
      {message}
    </BootstrapLiveRegionRoot>
  );
}
```

- **Politeness levels**: `politeness="polite"` (default) sets `role="status"` and `aria-live="polite"`; `politeness="assertive"` sets `role="alert"` and `aria-live="assertive"`.
- **Atomic updates**: `atomic={true}` (default) sets `aria-atomic="true"` so the entire message is announced together; set `false` to announce only mutated child text.
- **Unboxed semantic role**: `Root` inherits readable typography from its surrounding container without adding Bootstrap `.alert` fills, borders, or dismiss chrome, so you can place it inside classic wells, form feedback rows, or `.sr-only` containers.
