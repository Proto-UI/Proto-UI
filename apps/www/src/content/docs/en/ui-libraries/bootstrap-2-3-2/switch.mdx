Bootstrap 2.3.2 Switch is a design-language extension that adapts classic beveled gradients and inset track depth into a `Root` / `Thumb` anatomy while inheriting Base Switch keyboard semantics, RTL mirroring, and optional pointer dragging.

## Installation

Currently available from workspace source via `@proto.ui/prototypes-bootstrap-2-3-2/switch`. [Browse the implemented subset](../).

## Usage

```tsx
import { switchRoot, switchThumb } from '@proto.ui/prototypes-bootstrap-2-3-2/switch';
```

```html
<proto-ui-bootstrap-2-3-2-switch-root default-checked>
  <proto-ui-bootstrap-2-3-2-switch-thumb></proto-ui-bootstrap-2-3-2-switch-thumb>
  <span class="sr-only">Release alerts</span>
</proto-ui-bootstrap-2-3-2-switch-root>
```

- **Root manages the state**: Supports controlled `checked` and uncontrolled `defaultChecked`, click and keyboard activation, beveled hover/active feedback, focus, and disabled state.
- **Derived Thumb**: Place inside `Root` to track on/off state, live drag percentage, and `direction`, with automatic `prefers-reduced-motion: reduce` suppression.
