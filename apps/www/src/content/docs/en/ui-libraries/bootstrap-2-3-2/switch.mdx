This Switch is a design-language extension, not an original Bootstrap 2.3.2 component. Its Root / Thumb anatomy borrows the archived raised-control language while preserving Base Switch semantics.

Base Switch owns the persistent on/off `checked` value, controlled and uncontrolled ownership, activation, disabled behavior, and focus. Thumb reads the nearest Root context and owns no independent value or events.

Use the page runtime selector to compare Web Components, React, Vue 3, and Vue 2. Activate the first two switches and verify that the disabled switch stays unchanged.

## API

- Root: `checked` / `defaultChecked` and `disabled`
- Root emits the inherited `checkedChange` signal
- Thumb: derived display inside its Root
