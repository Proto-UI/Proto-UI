Bootstrap 2.3.2 Switch is a design-language extension, not an original Bootstrap 2.3.2 component. It adapts the archived raised-control look into a `Root` / `Thumb` anatomy while inheriting Base Switch semantics and keeping the classic light palette.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. [Browse the implemented subset](../).

## Usage

- **Root manages the state**: Supports controlled `checked` and uncontrolled `defaultChecked`, activation, disabled state, and keyboard focus.
- **Thumb**: Place inside `Root` to automatically reflect the current on/off state.

## API

| Part    | Props / Events               | Description                                     |
| ------- | ---------------------------- | ----------------------------------------------- |
| `Root`  | `checked` / `defaultChecked` | Controlled or initial on/off state              |
| `Root`  | `disabled`                   | Prevents toggling when enabled                  |
| `Root`  | `checkedChange`              | Emitted when the switch requests a state change |
| `Thumb` | —                            | Derived visual thumb placed inside `Root`       |
