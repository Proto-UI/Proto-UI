Bootstrap 2.3.2 `Label` preserves classic `14px / 20px` Helvetica Neue regular typography while pairing accessible naming (`naming`) and pointer activation (`activation`) with target controls through an explicit reference.

> For form fields, use the [Field](../field/) component for automatic `FieldLabel`, `FieldDescription`, and `FieldError` associations and validation.

## Installation

Currently available from workspace source. Import directly from the workspace package:

```ts
import { labelRoot } from '@proto.ui/prototypes-bootstrap-2-3-2/label';
```

## Usage

Create one stable reference per pair with `createControlLabelRef()` from `@proto.ui/core` and pass it through the adapter association channel:

```tsx
import { useMemo } from 'react';
import { createControlLabelRef } from '@proto.ui/core';
import {
  BootstrapCheckboxIndicator,
  BootstrapCheckboxRoot,
  BootstrapLabelRoot,
} from '../proto-ui/components/react';

export function TermsCheckbox() {
  const termsRef = useMemo(() => createControlLabelRef(), []);

  return (
    <div className="flex items-center gap-2">
      <BootstrapCheckboxRoot instanceAssociations={{ controlLabel: termsRef }}>
        <BootstrapCheckboxIndicator />
      </BootstrapCheckboxRoot>
      <BootstrapLabelRoot instanceAssociations={{ controlLabel: termsRef }}>
        Accept terms and conditions
      </BootstrapLabelRoot>
    </div>
  );
}
```

In Web Components, bind both elements with `setElementAssociations()` from `@proto.ui/adapter-web-component`:

```ts
import { createControlLabelRef } from '@proto.ui/core';
import { setElementAssociations } from '@proto.ui/adapter-web-component';

const termsRef = createControlLabelRef();
setElementAssociations(checkboxEl, { controlLabel: termsRef });
setElementAssociations(labelEl, { controlLabel: termsRef });
```

### Naming, activation, and layout

- **`naming` (default `true`)**: Links the target control to the rendered `Label` as its accessible name. If the control already sets a non-empty `ariaLabel` or `labelledBy`, set `naming={false}` for activation-only pairing.
- **`activation` (default `true`)**: Clicking a paired `Label` invokes the target's existing operation (toggling `Checkbox`/`Switch`, selecting a `Radio Group Item`, or focusing `Input`/`Textarea`). Set `activation={false}` for a passive naming-only label.
- **`selection` (default `'policy'`)**: Prevents accidental text selection on actionable labels by default; use `'text'`, `'auto'`, or `'none'` to override explicitly.
- **Alignment and safety**: Uses `inline-flex` without an unconditional bottom margin so inline choice rows stay vertically centered while stacked layouts remain controlled by their container. Adds no extra `Tab` stop and ignores nested links/buttons, modified clicks, and drags.

### Association helpers

- `createControlLabelRef()`: Imported from `@proto.ui/core` to create a stable one-to-one pair reference.
- `instanceAssociations`: Adapter prop accepting `{ controlLabel: ref }` in React, Vue, and Vue 2.
- `setElementAssociations(element, { controlLabel: ref })`: Imported from `@proto.ui/adapter-web-component` for Web Components.
