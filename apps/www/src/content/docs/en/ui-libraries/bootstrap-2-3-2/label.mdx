## Usage

### Explicit pairing

Instead of guessing nearby DOM nodes or requiring string IDs, create one stable reference per pair with `createControlLabelRef()` from `@proto.ui/core`:

- **React / Vue / Vue 2**: Pass `instanceAssociations: { controlLabel: ref }` to both the Label and its target control.
- **Web Components**: Call `setElementAssociations(target, { controlLabel: ref })` from `@proto.ui/adapter-web-component` on both elements.

Each reference pairs one live Label with one live target in the same document and tree root; missing or duplicate endpoints ignore invalid configuration and stay inactive.

### Independent naming and activation

- **`naming` (default `true`)**: Links the target control to the rendered Label as its accessible name. If the control already sets a non-empty `ariaLabel` or `labelledBy`, keep that name and set `naming={false}` on the Label for activation-only pairing.
- **`activation` (default `true`)**: Clicking a paired Label triggers the target's existing operation (toggling Checkbox/Switch, selecting Radio Item, or focusing Input/Textarea). Set `activation={false}` for a passive naming-only label.
- **Selection and interaction safety**: Label adds no Tab stop and ignores nested interactive elements, drags, cancelled pointers, and modified clicks. Use `selection="policy"` to prevent accidental text selection on short actionable labels, or `selection="text"` to keep text copyable.

## API

| Prop / Helper | Default | Description |
| --- | --- | --- |
| `naming` | `true` | Supplies the paired control's accessible name |
| `activation` | `true` | Forwards eligible clicks to the paired control's default action |
| `selection` | `'policy'` | `'policy'` (prevents accidental selection) or `'text'` (copyable) |
| `createControlLabelRef()` | — | Imported from `@proto.ui/core` to create a stable pair reference |
| `instanceAssociations` | — | Adapter prop accepting `{ controlLabel: ref }` in React, Vue, and Vue 2 |
| `setElementAssociations()` | — | Imported from `@proto.ui/adapter-web-component` for Web Components |
