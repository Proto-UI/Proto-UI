## Installation

Currently available from workspace source only; not yet included in the 0.2.0 stable release. Import `textRoot` (also exported as `bootstrap232TextRoot` and `Bootstrap232TextRoot`) from `@proto.ui/prototypes-bootstrap-2-3-2/text`, or generate workspace facades with the `bootstrap-2-3-2-text` CLI target.

## Usage

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { bootstrap232TextRoot } from '@proto.ui/prototypes-bootstrap-2-3-2/text';

const Text = createReactAdapter(React)(bootstrap232TextRoot, { rootTag: 'span' });

export function PageHeading() {
  return (
    <h2>
      <Text size="2xl" font="heading" weight="bold" leading="relaxed">
        Overview
      </Text>
    </h2>
  );
}
```

### Preserved Bootstrap 2.3.2 metrics and semantics

- **Archived scale & rhythm**: `size="2xl"` maps to `1.53125rem` (`24.5px` at a 16px root); `leading="normal"` uses the classic `20/14` (`1.4286`) ratio; pairing `size="2xl"` with `leading="relaxed"` resolves to `2.5rem` (`40px`). All metrics scale cleanly in `rem`.
- **Leading precedence & defaults**: Explicit `leading` values override the composite line-height implied by `size`, while `leading="size"` preserves each size's line box. `leading="tighter"` maps to `1.1` and `tracking="tighter"` maps to `-0.05em`. Removing any prop restores its default.
- **Color inheritance & selection**: Set `tone="inherit"` inside colored surfaces or buttons so text inherits foreground ink and text-shadow cleanly. Text never overrides `user-select`, keeping prose selectable while respecting interactive control selection policies.
- **Native semantics**: Wrap with native `h1`–`h6`, `p`, `label`, `a`, or `button` elements for document and interactive semantics.
