## Usage

- **Typography precedence**: An explicit `leading` overrides the default line-height associated with `size`; removing a prop restores its default.
- **Color inheritance and selection**: Pass `tone="inherit"` inside a colored `Surface` or button to inherit its foreground ink. Text never overrides `user-select`, preserving natural document selection and control-specific selection policies.
- **HTML semantics**: Text is purely typographic; wrap or pair with native `h1`, `p`, `label`, `a`, or `button` elements for document and interactive semantics.

## API

| Prop | Values | Default |
| --- | --- | --- |
| `size` | `xs` \| `sm` \| `base` \| `lg` \| `xl` \| `2xl` \| `3xl` \| `4xl` \| `5xl` | `base` |
| `tone` | `default` \| `muted` \| `inherit` | `default` |
| `weight` | `normal` \| `medium` \| `semibold` \| `bold` | `normal` |
| `font` | `body` \| `heading` \| `mono` | `body` |
| `leading` | `tight` \| `snug` \| `normal` \| `relaxed` | `normal` |
| `tracking` | `normal` \| `tight` | `normal` |
| `emphasis` | `normal` \| `italic` | `normal` |
| `decoration` | `none` \| `underline` \| `line-through` | `none` |
