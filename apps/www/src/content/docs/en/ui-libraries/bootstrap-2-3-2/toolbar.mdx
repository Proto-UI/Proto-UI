## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototypes directly from `@proto.ui/prototypes-bootstrap-2-3-2/toolbar` and adapt them for your target framework:

```ts
import {
  toolbarRoot,
  toolbarButton,
  toolbarSeparator,
} from '@proto.ui/prototypes-bootstrap-2-3-2/toolbar';
```

## Usage

```tsx
import {
  BootstrapToolbarRoot,
  BootstrapToolbarButton,
  BootstrapToolbarSeparator,
} from '../proto-ui/components/react';

export function EditorToolbar() {
  return (
    <BootstrapToolbarRoot a11yLabel="Document actions">
      <BootstrapToolbarButton value="undo">Undo</BootstrapToolbarButton>
      <BootstrapToolbarButton value="redo">Redo</BootstrapToolbarButton>
      <BootstrapToolbarSeparator />
      <BootstrapToolbarButton value="save" variant="primary">
        Save
      </BootstrapToolbarButton>
    </BootstrapToolbarRoot>
  );
}
```

Compose `Root`, `Button`, and `Separator`:

- **Classic Bootstrap surface**: `Button` keeps the v2.3.2 top-to-bottom gradients, hover background shift, and inset pressed shadow while suppressing duplicate focus outlines with a single clear focus ring.
- **Roving keyboard focus**: Only one enabled button participates in the page `Tab` order; arrow keys navigate commands and wrap when `loop` is enabled (default).
- **Cross-axis dividers**: `Separator` automatically switches between a 1px vertical or horizontal divider based on `Root`'s orientation.

### Separator and Events

- **Separator**: Takes no additional props and renders a 1px cross-axis divider automatically.
- **Events and exposes**: `Button` emits `action` (`{ value: string }`) on activation. `Root` exposes `disabled`, `focusFirst()`, `focusLast()`, and `setCurrent(id)`; `Button` exposes `disabled`, `focused`, `focusVisible`, and `focusSelf(options)`.
