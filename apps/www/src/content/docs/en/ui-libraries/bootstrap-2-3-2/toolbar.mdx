## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

Compose `Root`, `Button`, and `Separator`:

- **Roving focus**: Only one enabled button participates in the page Tab order; arrow keys move focus across commands, wrapping when `loop` is enabled.
- **Actions and dividers**: Activating an enabled `Button` emits `action` with its `value`. `Separator` automatically aligns perpendicular to the toolbar orientation.

## API

| Part | Props / Events | Description |
| --- | --- | --- |
| `Root` | `disabled` / `orientation` / `loop` / `a11yLabel` | Disabled flag, orientation, focus wrap, and accessible toolbar name |
| `Button` | `value` / `action` | Command value and activation event |
| `Separator` | — | Divider aligned along the toolbar's cross axis |
