## Usage

### Composition

Compose `Root` → `Item` → `Heading` → `Trigger`, with `Content` placed alongside `Heading`:

- **Root**: Manages the set of open items. Nested roots maintain independent state.
- **Item**: Requires a unique, stable, non-empty `value`.
- **Heading**: Sets the heading level and wraps only its controlling `Trigger`. Place persistent secondary actions beside `Heading`.
- **Trigger**: Derives expanded and disabled state from `Item` and `Root`.
- **Content**: Unmounts content when closed; set `keepMounted` to keep the node mounted while hidden.

### Controlled and uncontrolled state

- Use `defaultOpenItems` for uncontrolled initialization, or pass `openItems` to control state externally.
- In controlled mode, `Root` emits `openChange` with `{ openItems, value, open, reason }` and updates only when the parent passes the next `openItems`.
- In `single` mode, only the first unique key is kept open. Keys for items not yet mounted are retained until those items register.

### Keyboard and accessibility

- Enabled triggers and focusable elements inside your content stay in the natural Tab order.
- `Enter` and `Space` toggle the focused item. Arrow keys move focus across enabled headers (Up/Down vertically, Left/Right horizontally with RTL reversal), and `Home` / `End` jump to the first or last header without changing open state.
- When `allowEmpty={false}`, the last remaining open trigger stays focusable and sets `aria-disabled` to prevent collapsing.
- `Trigger` automatically links `aria-controls` and labels its `Content`. Opt into a landmark region selectively with `region={true}` on `Content`.

## API

| Part | Props | Defaults and behavior |
| --- | --- | --- |
| `Root` | `mode` | `'single'` (default) or `'multiple'` |
| `Root` | `openItems` / `defaultOpenItems` | `string[]`; passing `openItems` enables controlled mode |
| `Root` | `allowEmpty` | `boolean`, default `true`; set `false` to prevent closing the last open item |
| `Root` | `disabled` | `boolean`, default `false`; suppresses activation without changing values |
| `Root` | `orientation` / `direction` / `loop` | Defaults `'vertical'`, `'ltr'`, `true`; affects header navigation only |
| `Item` | `value` / `disabled` | Required unique non-empty `value`; `disabled` defaults to `false` |
| `Heading` | `level` | Integer `1`–`6`, default `3` |
| `Trigger` | — | Derives state from `Item` and `Root` |
| `Content` | `keepMounted` / `region` | Both default to `false` |

- **Methods & properties**: `Root` exposes `getOpenItems()` (returns a copy), `openCount`, and `requestOpen(value, open, reason?)`.
- **Events**: `openChange` with payload `{ openItems, value, open, reason }`, where `reason` is `'pointer'`, `'keyboard'`, or `'programmatic'`.
