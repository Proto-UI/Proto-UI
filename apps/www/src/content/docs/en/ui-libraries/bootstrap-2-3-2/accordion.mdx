## Installation

Available from workspace source by importing the five prototypes from `@proto.ui/prototypes-bootstrap-2-3-2/accordion`:

```ts
import {
  accordionRoot,
  accordionItem,
  accordionHeading,
  accordionTrigger,
  accordionContent,
} from '@proto.ui/prototypes-bootstrap-2-3-2/accordion';
```

## Usage

```tsx
import {
  Bootstrap232AccordionRoot,
  Bootstrap232AccordionItem,
  Bootstrap232AccordionHeading,
  Bootstrap232AccordionTrigger,
  Bootstrap232AccordionContent,
} from '@/components/proto-ui/react';

export function BootstrapAccordionUsage() {
  return (
    <Bootstrap232AccordionRoot defaultOpenItems={['item-1']}>
      <Bootstrap232AccordionItem value="item-1">
        <Bootstrap232AccordionHeading level={3}>
          <Bootstrap232AccordionTrigger>Collapsible Group Item #1</Bootstrap232AccordionTrigger>
        </Bootstrap232AccordionHeading>
        <Bootstrap232AccordionContent>
          Classic Bootstrap 2.3.2 collapsible panel with smooth 350ms height transitions.
        </Bootstrap232AccordionContent>
      </Bootstrap232AccordionItem>
    </Bootstrap232AccordionRoot>
  );
}
```

### Anatomy

```text
AccordionRoot
└── AccordionItem
    ├── AccordionHeading
    │   └── AccordionTrigger
    └── AccordionContent
```

- **Root**: Manages open item keys and navigation axis; nested roots stay independent.
- **Item**: Styled after `.accordion-group` (4px radius, `#e5e5e5` light border / dark-adapted border, themed background). Requires a unique non-empty `value`.
- **Heading**: Declares heading level (default `3`) and wraps only its controlling `Trigger`.
- **Trigger**: Classic link-styled header without a disclosure chevron (`#08c` resting, `#005580` underline hover, high-contrast link color in dark mode), with clear disabled and collapse-blocked cues.
- **Content**: Binds `asTransition` for 350ms `blockSize` presence animation; unmounts when closed unless `keepMounted` is set.

### Keyboard and accessibility

- Enabled triggers and focusable elements inside open content remain in the natural `Tab` sequence; `Enter` and `Space` toggle the focused item.
- `ArrowUp` / `ArrowDown` (vertical) or `ArrowLeft` / `ArrowRight` (horizontal, reversed in RTL) plus `Home` / `End` move focus between enabled headers without changing open state.
- When `allowEmpty={false}`, the last remaining open header remains focusable with `aria-disabled` preventing collapse.

### Methods and events (Root)

- **Methods & properties**: `getOpenItems()` returns a copy of open keys; `openCount` reports open key count; `requestOpen(value, open, reason?)` requests an open or close change.
- **Events**: `openChange` emits `{ openItems, value, open, reason }` (`reason` is `'pointer'`, `'keyboard'`, or `'programmatic'`).
