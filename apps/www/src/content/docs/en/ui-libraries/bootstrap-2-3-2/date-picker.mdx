## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. `Date Picker` composes Bootstrap 2.3.2 `Popover` and `Calendar` parts directly from the workspace.

## Usage

```tsx
import {
  Bootstrap232DatePickerRoot,
  Bootstrap232DatePickerTrigger,
  Bootstrap232DatePickerValue,
  Bootstrap232DatePickerContent,
  Bootstrap232DatePickerDay,
  Bootstrap232CalendarCaption,
  Bootstrap232CalendarPrevious,
  Bootstrap232CalendarHeading,
  Bootstrap232CalendarNext,
  Bootstrap232CalendarGrid,
  Bootstrap232CalendarWeekdays,
  Bootstrap232CalendarWeekday,
  Bootstrap232CalendarRow,
} from '../proto-ui/components/react';

export function BootstrapDatePickerExample() {
  return (
    <Bootstrap232DatePickerRoot defaultMonth="2026-10">
      <Bootstrap232DatePickerTrigger className="w-56">
        <Bootstrap232DatePickerValue placeholder="Pick a date" />
        <span aria-hidden="true">▾</span>
      </Bootstrap232DatePickerTrigger>
      <Bootstrap232DatePickerContent side="bottom" align="start" sideOffset={10}>
        <Bootstrap232CalendarCaption>
          <Bootstrap232CalendarPrevious a11yLabel="Previous month">‹</Bootstrap232CalendarPrevious>
          <Bootstrap232CalendarHeading />
          <Bootstrap232CalendarNext a11yLabel="Next month">›</Bootstrap232CalendarNext>
        </Bootstrap232CalendarCaption>
        <Bootstrap232CalendarGrid>
          <Bootstrap232CalendarWeekdays>
            {[0, 1, 2, 3, 4, 5, 6].map((offset) => (
              <Bootstrap232CalendarWeekday key={offset} offset={offset} />
            ))}
          </Bootstrap232CalendarWeekdays>
          {[0, 1, 2, 3, 4, 5].map((row) => (
            <Bootstrap232CalendarRow key={row} index={row}>
              {[0, 1, 2, 3, 4, 5, 6].map((col) => (
                <Bootstrap232DatePickerDay key={col} offset={row * 7 + col} />
              ))}
            </Bootstrap232CalendarRow>
          ))}
        </Bootstrap232CalendarGrid>
      </Bootstrap232DatePickerContent>
    </Bootstrap232DatePickerRoot>
  );
}
```

- **Classic Bootstrap 2.3.2 chrome**: The trigger uses the `.btn` top-to-bottom gradient, bevel highlight, and pressed inset shadow; the popup uses `.popover` `6px` corners, `14px / 9px` inner padding, and a `150ms` opacity fade; selected days use `.btn-primary` blue gradient fills.
- **Range and multiple modes**: Pass `mode="range"` with `range` / `defaultRange`, or `mode="multiple"` with `values` / `defaultValues`. All date eligibility, count, and night rules match [Calendar](/en/ui-libraries/bootstrap-2-3-2/calendar/).
- **Dismissal behavior**: `single` mode requests closing on an accepted pick; `range` mode stays open on the first endpoint and closes once the second endpoint completes the range; `multiple` mode stays open for consecutive toggles.
- **Formatted display**: `Value` renders an ISO date, a sorted comma-separated list, `from …` for an unfinished range, `from – to` for a completed range, or `placeholder` when empty.
