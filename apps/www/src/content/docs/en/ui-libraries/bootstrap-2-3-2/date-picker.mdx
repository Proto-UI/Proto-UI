Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Popup composition**: Use any `Calendar` grid, row, heading, and navigation parts inside the popup content. `open`, selection, and `month` each retain independent controlled/uncontrolled boundaries.
- **Range and multiple modes**: Pass `mode="range"` with `range` / `defaultRange`, or `mode="multiple"` with `values` / `defaultValues`. All date eligibility, count, and night rules match [Calendar](/en/ui-libraries/bootstrap-2-3-2/calendar/).
- **Dismissal behavior**:
  - In `single` mode, an accepted selection requests closing the popup.
  - In `range` mode, the first endpoint keeps the popup open and the second accepted endpoint requests a single close.
  - In `multiple` mode, the popup stays open for additional toggles until dismissed via Popover interactions.
- **Formatted display**: `Value` renders a single ISO date, a comma-separated sorted list, `from …` for an unfinished range, `from – to` for a completed range, or `placeholder` when empty.

## API

| Prop                       | Description                                      |
| -------------------------- | ------------------------------------------------ |
| `mode`                     | `'single'` (default), `'range'`, or `'multiple'` |
| `open` / `defaultOpen`     | Controlled or initial popup open state           |
| `value` / `defaultValue`   | Single selected date (`YYYY-MM-DD`)              |
| `range` / `defaultRange`   | Selected range (`{ from?, to? }`)                |
| `values` / `defaultValues` | Multiple selected dates (`string[]`)             |
| `month` / `defaultMonth`   | Visible month (`YYYY-MM`)                        |
| `placeholder`              | Fallback text shown by `Value` when empty        |
| `disabled` / `readOnly`    | Disables interaction or prevents editing         |
