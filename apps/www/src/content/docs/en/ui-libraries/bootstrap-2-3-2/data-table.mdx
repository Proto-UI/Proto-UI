Data Table builds stable sorting, global and per-column filtering, column visibility, pagination, and row or page selection on top of semantic table structure with authentic Bootstrap 2.3.2 `8px` cell spacing, horizontal rules, `.info` selection tint, and classic gradient `.btn` pagination controls.

## Usage

```tsx
import {
  Bootstrap232DataTableCaption,
  Bootstrap232DataTableCell,
  Bootstrap232DataTableHeader,
  Bootstrap232DataTableHeaderRow,
  Bootstrap232DataTableNext,
  Bootstrap232DataTablePrevious,
  Bootstrap232DataTableRoot,
  Bootstrap232DataTableRow,
} from '../proto-ui/components/react';

const rows = [
  { id: 'm5gr84i9', status: 'Success', email: 'ken99@example.com', amount: 316 },
  { id: '3u1reuv4', status: 'Success', email: 'abe45@example.com', amount: 242 },
];

export function Example() {
  return (
    <Bootstrap232DataTableRoot rows={rows} pageSize={4}>
      <Bootstrap232DataTableCaption>Recent payments.</Bootstrap232DataTableCaption>
      <Bootstrap232DataTableHeaderRow>
        <Bootstrap232DataTableHeader headerKey="status">Status</Bootstrap232DataTableHeader>
        <Bootstrap232DataTableHeader headerKey="email">Email</Bootstrap232DataTableHeader>
        <Bootstrap232DataTableHeader headerKey="amount" className="text-right">
          Amount
        </Bootstrap232DataTableHeader>
      </Bootstrap232DataTableHeaderRow>
      {[0, 1].map((index) => (
        <Bootstrap232DataTableRow key={index} index={index}>
          <Bootstrap232DataTableCell columnKey="status" headers={['status']} />
          <Bootstrap232DataTableCell columnKey="email" headers={['email']} />
          <Bootstrap232DataTableCell
            columnKey="amount"
            headers={['amount']}
            className="text-right"
          />
        </Bootstrap232DataTableRow>
      ))}
      <div className="table-caption caption-bottom">
        <div className="flex justify-end gap-2 pt-3">
          <Bootstrap232DataTablePrevious>Previous</Bootstrap232DataTablePrevious>
          <Bootstrap232DataTableNext>Next</Bootstrap232DataTableNext>
        </div>
      </div>
    </Bootstrap232DataTableRoot>
  );
}
```

### Structure & Behavior

- **Records and row slots**: Provide a unique `id` on every data row. Body rows (`DataTableRow`) map to the active page by `index`, and cells read their field via `columnKey`. Hidden columns and empty slots automatically withdraw `table-row` / `table-cell` display so hidden rows collapse cleanly.
- **Sortable headers and hover feedback**: Place sortable column headers in `DataTableHeaderRow`. Interactive rows use Bootstrap 2.3.2's `#f5f5f5` hover highlight and `.info` selection palette.

### Events, Methods & Exposed States

- **Events (Root)**: `sortChange`, `pageChange`, `selectionChange`.
- **Methods (Root)**: `getRows()`, `getRecord(id)`, `getSelectedKeys()`, `requestSort(key)`, `requestPage(next)`, `requestSelection(id)`, `requestPageSelection(selected?)`.
- **Exposed States**: Root exposes `filteredCount` and `pageSelection`; Row exposes `rowKey`, `selected`, `focused`, and `focusVisible`; Header exposes `sort`; Cell exposes `displayValue`.
