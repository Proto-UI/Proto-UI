## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Records and row slots**: Provide a unique `id` on every data row. Body rows (`DataTableRow`) map to the current page by `index`, and cells render their field via `columnKey`, updating real table content on sort.
- **Sortable headers**: Place sortable header triggers inside `DataTableHeaderRow` so header rows remain distinct from body record slots (`DataTableRow`).
- **Scope**: Data fetching, inline cell editing, and column reordering are left to application code.

## API

| Part / Prop          | Description                                           |
| -------------------- | ----------------------------------------------------- |
| `DataTableHeaderRow` | Header row container for sortable column triggers     |
| `DataTableRow`       | Page-indexed body row slot bound to the active record |
| `id` / `columnKey`   | Unique record identifier and cell column key          |
