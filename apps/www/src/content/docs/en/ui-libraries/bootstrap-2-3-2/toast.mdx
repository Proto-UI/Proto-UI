Toast displays brief, non-blocking notifications styled with Bootstrap 2.3.2 `.alert` surfaces, supporting auto-dismiss timers, hover or focus pause, a top-right `×` close control, and link actions.

## Installation

Available starting in `0.3.0-rc.1` and later releases. Import the prototypes directly from `@proto.ui/prototypes-bootstrap-2-3-2/toast` and adapt them for your target runtime.

```ts
import {
  toastViewport,
  toastRoot,
  toastTitle,
  toastDescription,
  toastAction,
  toastClose,
} from '@proto.ui/prototypes-bootstrap-2-3-2/toast';
```

## Usage

Follow Bootstrap 2.3.2's `.alert` markup convention by placing `Close` (`×`) first inside `Root` so its float offsets align with the top-right corner:

```tsx
<Bootstrap232ToastViewport a11yLabel="Notifications">
  <Bootstrap232ToastRoot defaultOpen={false} duration={5000}>
    <Bootstrap232ToastClose>×</Bootstrap232ToastClose>
    <Bootstrap232ToastTitle>Event has been created</Bootstrap232ToastTitle>
    <Bootstrap232ToastDescription>
      Sunday, December 03, 2023 at 9:00 AM
    </Bootstrap232ToastDescription>
    <Bootstrap232ToastAction a11yLabel="Undo event creation">Undo</Bootstrap232ToastAction>
  </Bootstrap232ToastRoot>
</Bootstrap232ToastViewport>
```

- **Timing and pause**: `Root` stays open for `5000ms` by default; pass `duration={0}` to keep it open indefinitely. Hovering over the toast or focusing `Action` / `Close` pauses the remaining timer.
- **Actions and dismissal**: `Close`, pressing `Escape` while focused, and `Action` all request dismissal, while your application handles any side effects from `Action`. In controlled `open` mode, timeout emits a single dismissal request until the parent updates state.
- **Shortcut**: `Viewport` binds `F8` to move keyboard focus to the notification region.

Events and exposed methods:

- **Events**: `Root` emits `openChange` (`{ open: boolean; reason: string }`); `Action` emits `action` (`void`).
- **Methods**: `Root` exposes `openToast()`, `close(reason?)`, `pause()`, and `resume()`; `Viewport` exposes `focusFirst()`.
