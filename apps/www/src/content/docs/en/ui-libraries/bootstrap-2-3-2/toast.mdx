Toast displays brief, non-blocking notifications that auto-dismiss after a configurable duration, pause on hover or focus, and support explicit actions.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

Compose `Root`, `Viewport`, `Title`, `Description`, `Action`, and `Close`:

- **Timing and pause**: `Root` stays open for `5000ms` by default; pass `duration={0}` to keep it open indefinitely. Hovering over the toast or focusing `Action` / `Close` pauses the remaining timer.
- **Actions and dismissal**: `Close`, pressing `Escape` while focused, and `Action` all request dismissal, while your application handles any side effects from `Action`. In controlled `open` mode, timeout emits a single dismissal request until the parent updates state.
- **Shortcut**: `Viewport` binds `F8` to move keyboard focus to the notification region.

## API

| Part | Prop | Default | Description |
| --- | --- | --- | --- |
| `Root` | `open` | — | Controlled visibility state |
| `Root` | `duration` | `5000` | Auto-dismiss duration in milliseconds (`0` disables auto-dismiss) |
| `Viewport` | — | — | Toast container region with `F8` focus shortcut |
| `Title` / `Description` | — | — | Notification heading and message body |
| `Action` / `Close` | — | — | Action trigger and dismiss button |
