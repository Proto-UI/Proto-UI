## Usage

Compose `Root`, `Label`, `Input` (or `Control` inside `Field` / `FormField`), `Increment`, and `Decrement`:

- **Editing and stepping**: Incomplete text drafts remain editable until blur or `Enter`, which commits valid numbers or restores the last accepted value. `Increment`/`Decrement` and Up/Down arrows step by `step` (`Shift` multiplies by 10), and `Home`/`End` jump to `min`/`max`. IME composition pauses parsing and stepping.
- **Locale formatting**: Pass `locale` and `formatOptions` for decimal, currency, or percent display and parsing without rounding away underlying precision. Invalid options set `formatInvalid` and fall back to ungrouped decimals.
- **Empty values**: Set `allowEmpty={true}` (default `false`) to allow clearing to `null` (`value={null}` stays controlled). Read exact `number | null` via `getValue()` and check `empty`; stepping from `null` starts from clamped zero.
- **Label scrubbing**: Enable `scrub` to drag across `Label` for continuous adjustment (`scrubSteps` defaults to `100` steps per label width; `direction="rtl"` mirrors horizontal drag). Releasing commits once; cancelling restores the starting value.
- **Form integration**: Use `Control` in place of `Input` inside `Field` or `FormField` to connect `FieldLabel`, numeric validation, `Form` serialization, and reset.

## API

| Part | Props / Methods / States | Description |
| --- | --- | --- |
| `Root` | `value` / `defaultValue` | Controlled or initial `number \| null` value |
| `Root` | `min` / `max` / `step` | Bounds and increment (`0`, `100`, `1` by default) |
| `Root` | `allowEmpty` | Defaults to `false`; allows committing `null` when cleared |
| `Root` | `locale` / `formatOptions` | Locale-aware decimal, currency, and percent formatting |
| `Root` | `scrub` / `scrubSteps` / `direction` | Enables label drag scrubbing (`scrubSteps` default `100`) |
| `Root` | `disabled` / `readOnly` / `name` / `ariaLabel` | State flags, field name, and accessible name |
| `Root` | `getValue()` / `empty` / `formatInvalid` | Exact `number \| null` reader, emptiness flag, and format status |
| `Label` / `Input` / `Control` / `Increment` / `Decrement` | — | Label, editor (`Control` inside forms), and stepper buttons |
