## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the parts directly from `@proto.ui/prototypes-bootstrap-2-3-2/number-field`:

```ts
import {
  numberFieldRoot,
  numberFieldLabel,
  numberFieldInput,
  numberFieldControl,
  numberFieldIncrement,
  numberFieldDecrement,
} from '@proto.ui/prototypes-bootstrap-2-3-2/number-field';
```

## Usage

```tsx
<Bootstrap232NumberFieldRoot defaultValue={12} min={0} max={100} step={1} ariaLabel="Quantity">
  <Bootstrap232NumberFieldLabel>Quantity</Bootstrap232NumberFieldLabel>
  <Bootstrap232NumberFieldDecrement>
    <span aria-hidden="true">−</span>
    <span className="sr-only">Decrease Quantity</span>
  </Bootstrap232NumberFieldDecrement>
  <Bootstrap232NumberFieldInput />
  <Bootstrap232NumberFieldIncrement>
    <span aria-hidden="true">+</span>
    <span className="sr-only">Increase Quantity</span>
  </Bootstrap232NumberFieldIncrement>
</Bootstrap232NumberFieldRoot>
```

- **Editing and stepping**: Incomplete text drafts remain editable until blur or `Enter` commits valid numbers or restores the last accepted value. Stepper buttons restore classic Bootstrap 2.3.2 hover and active inset-shadow feedback; `ArrowUp` / `ArrowDown` step by `step` (`Shift` multiplies by 10), and `Home` / `End` jump to `min` / `max`. IME composition pauses parsing and stepping.
- **Locale formatting**: Pass `locale` and `formatOptions` for decimal, currency, or percent display and parsing without rounding away underlying precision.
- **Empty values and forms**: Enable `allowEmpty` so clearing commits `null`; use `Control` in place of `Input` inside `Field` or `FormField` to connect `FieldLabel`, numeric validation, serialization, and reset.
