Bootstrap 2.3.2 Context Menu opens a classic `dropdown-menu` surface (6px radius, subtle 20% border shadow, `#08c` to `#0077b3` hover gradient) on right-click, a 600 ms touch/pen long press, or `ContextMenu` / `Shift+F10`, with keyboard navigation and typeahead search built in.

## Installation

Available starting in `0.3.0-rc.1` and later releases (available in workspace source).

## Usage

```tsx
import {
  BootstrapContextMenuContent,
  BootstrapContextMenuItem,
  BootstrapContextMenuRoot,
  BootstrapContextMenuTrigger,
} from '@/components/proto-ui';

export function Example() {
  return (
    <BootstrapContextMenuRoot>
      <BootstrapContextMenuTrigger className="flex h-36 w-72 items-center justify-center rounded border border-dashed border-border bg-secondary text-sm">
        Right click here
      </BootstrapContextMenuTrigger>
      <BootstrapContextMenuContent>
        <BootstrapContextMenuItem value="back">Back</BootstrapContextMenuItem>
        <BootstrapContextMenuItem value="forward" disabled>
          Forward
        </BootstrapContextMenuItem>
        <BootstrapContextMenuItem value="reload">Reload</BootstrapContextMenuItem>
      </BootstrapContextMenuContent>
    </BootstrapContextMenuRoot>
  );
}
```

### Composition

```text
ContextMenuRoot
├── ContextMenuTrigger
└── ContextMenuContent
    ├── ContextMenuItem
    └── ContextMenuItem
```

- **Opening and anchoring**: Right-click and a 600 ms touch/pen hold anchor to the pointer; `ContextMenu`, `Shift+F10`, and programmatic `openContextMenu()` anchor to the trigger while suppressing the native context menu.
- **Historical timing and controlled mode**: Preserves Bootstrap 2.3.2's instant 0 ms menu transitions. Supply `open` for controlled mode; pressing `Escape` or selecting an item restores focus to the trigger.
