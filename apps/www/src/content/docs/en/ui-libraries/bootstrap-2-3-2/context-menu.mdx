Root supports open/defaultOpen, disabled and closeOnItemCommit. Trigger opens on context.menu or ContextMenu/Shift+F10 and suppresses the native context menu for that handled request; ordinary left click does not open it. Content inherits real Overlay/Focus/Transition navigation, typeahead and controlled dismissal. This source anchors to the trigger region. Pointer-location virtual anchoring and touch long-press await portable host support; no raw DOM-coordinate escape is used.
