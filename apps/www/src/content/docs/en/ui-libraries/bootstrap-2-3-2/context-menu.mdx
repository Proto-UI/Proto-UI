## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

Compose `Root`, `Trigger`, `Content`, and `Item`:

- **Opening and anchoring**: Right-click and touch/pen long-press (`600ms` within movement tolerance) open at the pointer position; `ContextMenu`, `Shift+F10`, and programmatic `openContextMenu()` anchor to the trigger region (default `bottom`/`start`). Regular left clicks and scrolling pass through normally.
- **Native menu suppression**: When an enabled `Root` handles a request, it suppresses the browser context menu (and compatibility click for long-press). Moving, releasing, disabling, or unmounting cancels a pending hold.
- **Controlled state**: Supply `open` to control visibility externally. Pressing `Escape` or selecting an item closes the menu and restores focus to `Trigger`.

## API

| Part | Props / Methods | Description |
| --- | --- | --- |
| `Root` | `open` / `defaultOpen` | Controlled or initial open state |
| `Root` | `disabled` | Disables opening the menu |
| `Root` | `closeOnItemCommit` | Controls whether choosing an item closes the menu |
| `Root` | `openContextMenu()` | Opens the menu anchored to the trigger |
| `Trigger` | — | Region listening for context menu, long-press, and keyboard shortcuts |
| `Content` | — | Floating menu panel with keyboard navigation and typeahead |
| `Item` | — | Individual menu command |
