Bootstrap 2.3.2 Combobox pairs the classic `.input-append` joined text field and button trigger with an anchored dropdown menu while keeping the committed option key (`value`) distinct from the live query (`inputValue`).

## Installation

Combobox is currently available from workspace source (`@proto.ui/prototypes-bootstrap-2-3-2/combobox`) and is not yet included in the `0.2.0` stable CLI registry.

## Usage

```tsx
import {
  comboboxRoot,
  comboboxInput,
  comboboxTrigger,
  comboboxContent,
  comboboxItem,
  comboboxEmpty,
} from '@proto.ui/prototypes-bootstrap-2-3-2/combobox';
```

```html
<bootstrap-2-3-2-combobox-root a11y-label="Framework">
  <bootstrap-2-3-2-combobox-input
    placeholder="Select a framework..."
  ></bootstrap-2-3-2-combobox-input>
  <bootstrap-2-3-2-combobox-trigger>▾</bootstrap-2-3-2-combobox-trigger>
  <bootstrap-2-3-2-combobox-content>
    <bootstrap-2-3-2-combobox-item value="next.js" text-value="Next.js"
      >Next.js</bootstrap-2-3-2-combobox-item
    >
    <bootstrap-2-3-2-combobox-item value="sveltekit" text-value="SvelteKit"
      >SvelteKit</bootstrap-2-3-2-combobox-item
    >
    <bootstrap-2-3-2-combobox-item value="astro" text-value="Astro"
      >Astro</bootstrap-2-3-2-combobox-item
    >
    <bootstrap-2-3-2-combobox-empty>No frameworks found.</bootstrap-2-3-2-combobox-empty>
  </bootstrap-2-3-2-combobox-content>
</bootstrap-2-3-2-combobox-root>
```

- **Separate value and query**: `value` represents the selected option key while `inputValue` holds editable search text. Unmatched text is never silently committed as an option.
- **Filtering and empty state**: Built-in filtering matches `textValue` and `keywords` case- and diacritic-insensitively. Pass `filter={false}` to supply pre-filtered items.
- **Classic Bootstrap 2.3.2 styling**: Joined 30px `.input-append` bar with `#52a8ec` focus glow, gradient active highlight, and bold blue selected-option state.
