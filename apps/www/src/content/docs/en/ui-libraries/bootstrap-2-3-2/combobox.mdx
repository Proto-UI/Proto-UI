Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

Compose `Root`, `Input`, `Trigger`, `Content`, `Item`, and `Empty`:

- **Separate value and query**: `value` represents the selected option key while `inputValue` holds editable search text. Unmatched text is never silently committed as an option.
- **Filtering and empty state**: Built-in filtering matches `textValue` and `keywords` case- and diacritic-insensitively. Pass `filter={false}` to supply pre-filtered items. `Empty` displays when nothing matches.
- **Keyboard and IME**: Focus remains in `Input` while navigating with Arrow keys, and IME composition never selects an option. Disabled and duplicate-valued items cannot commit.
- **Independent control**: `open`, `value`, and `inputValue` can each be controlled independently through their change requests.

## API

| Part | Props | Description |
| --- | --- | --- |
| `Root` | `value` / `inputValue` / `open` | Independently controlled option value, query text, and open state |
| `Root` | `filter` | Toggle built-in filtering; set `false` for externally filtered items |
| `Input` | — | Single-line search input |
| `Trigger` | — | Toggles the option list |
| `Content` | — | Option list container |
| `Item` | `value` / `textValue` / `keywords` / `disabled` | Individual selectable option |
| `Empty` | — | Rendered when no items match the query |
