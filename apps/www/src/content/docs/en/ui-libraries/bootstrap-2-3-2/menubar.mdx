## Installation

Available starting in `0.3.0-rc.1` and later releases; import the prototypes from `@proto.ui/prototypes-bootstrap-2-3-2/menubar` and adapt them for your target runtime.

## Usage

```tsx
import {
  Bootstrap232MenubarRoot,
  Bootstrap232MenubarTrigger,
  Bootstrap232MenubarContent,
  Bootstrap232MenubarItem,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <Bootstrap232MenubarRoot a11yLabel="Application menu">
      <Bootstrap232MenubarTrigger value="file">File</Bootstrap232MenubarTrigger>
      <Bootstrap232MenubarContent value="file" a11yLabel="File menu">
        <Bootstrap232MenubarItem value="new-tab">New Tab</Bootstrap232MenubarItem>
        <Bootstrap232MenubarItem value="print">Print...</Bootstrap232MenubarItem>
      </Bootstrap232MenubarContent>
    </Bootstrap232MenubarRoot>
  );
}
```

### Composition

```text
MenubarRoot
├── MenubarTrigger (value="file")
├── MenubarContent (value="file")
│   ├── MenubarItem
│   └── MenubarItem
├── MenubarTrigger (value="edit")
└── MenubarContent (value="edit")
    └── MenubarItem
```

- `Root`: Classic Bootstrap 2.3.2 navbar surface managing the active panel and roving focus.
- `Trigger`: Top-level menu item paired with `Content` by `value`, showing a recessed active state when expanded.
- `Content`: Dropdown panel with 6px radius and drop shadow (`sideOffset` defaults to `2`).
- `Item`: Highlights with the signature `#0088cc → #0077b3` blue gradient, or a classic red danger gradient when `variant="destructive"`.

### Keyboard and accessibility

- Uses a single roving `Tab` stop across the bar; `ArrowLeft` and `ArrowRight` move between triggers.
- `ArrowDown` and `ArrowUp` open panels and move through commands, with character typeahead support.
- Pressing `Escape` closes the panel and restores focus to its `Trigger`; outside clicks and command selection dismiss the active panel by default.
