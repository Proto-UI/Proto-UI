## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

Compose `Root`, `Trigger`, `Content`, and `Item`:

- **Panel pairing**: `Root`'s `value` identifies the active panel, matching `Trigger.value` and `Content.value`. In controlled mode it emits change requests without mutating caller state.
- **Keyboard navigation**: Uses a single roving Tab stop across the bar. Left/Right arrows move between triggers, Up/Down arrows open and navigate commands, and typing jumps to matching items.
- **Dismissal and focus**: Pressing `Escape` closes the panel and restores focus to its `Trigger`; outside clicks and item selection dismiss the active panel.

## API

| Part      | Props   | Description                                        |
| --------- | ------- | -------------------------------------------------- |
| `Root`    | `value` | Active open panel key (supports controlled mode)   |
| `Trigger` | `value` | Menubar trigger paired with the matching `Content` |
| `Content` | `value` | Dropdown command panel                             |
| `Item`    | —       | Individual command inside a panel                  |
