Bootstrap 2.3.2 Tabs adapts the archived Bootstrap 2.3.2 tab styling (4px upper corners and rem-scaled padding) over [Base Tabs](/en/ui-libraries/base/tabs/) for accessible keyboard navigation and controlled selection.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

```ts
import {
  tabsRoot,
  tabsList,
  tabsTrigger,
  tabsContent,
} from '@proto.ui/prototypes-bootstrap-2-3-2/tabs';
```

## Usage

Compose `Root`, `List`, `Trigger`, and `Content`:

- **Selection and activation**: `Root` manages the active tab via `value` or `defaultValue`. Arrow keys and `Home` / `End` move across enabled triggers; with manual activation (`activationMode="manual"`), pressing `Enter` or `Space` commits the selection so arrow browsing does not prematurely remount panels.
- **Underline variant**: Set `appearance="underline"` on `List` and `Trigger` for a transparent, text-width underline style instead of the default Bootstrap 2.3.2 tab chrome.
- **Content lifecycle**: Inactive panels unmount content by default; set `keepMounted` on `Content` to keep hidden panels mounted.

## API

| Part | Props | Description |
| --- | --- | --- |
| `Root` | `value` / `defaultValue` | Controlled or initial active tab key |
| `Root` | `activationMode` / `orientation` | Automatic/manual activation and horizontal/vertical layout |
| `List` | `appearance` | Pass `'underline'` for the underline preset |
| `Trigger` | `value` / `disabled` / `appearance` | Tab key, disabled flag, and appearance preset |
| `Content` | `value` / `keepMounted` | Matching panel key; retains hidden content when `keepMounted` is set |
