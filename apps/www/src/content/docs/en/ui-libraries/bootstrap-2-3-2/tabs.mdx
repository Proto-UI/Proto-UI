Bootstrap 2.3.2 Tabs reproduces classic Bootstrap 2.3.2 `nav-tabs` pixel metrics (`12px`/`8px` padding, `4px` upper/left corners, `14px`/`20px` type, `#08c`/`#005580` hover links) with dark-mode adaptation over [Base Tabs](/en/ui-libraries/base/tabs/) keyboard and selection semantics.

## Installation

Available directly from workspace source at `@proto.ui/prototypes-bootstrap-2-3-2/tabs`.

```ts
import {
  tabsRoot,
  tabsList,
  tabsTrigger,
  tabsContent,
  tabsIndicator,
} from '@proto.ui/prototypes-bootstrap-2-3-2/tabs';
```

## Usage

```html
<wc-bootstrap-2-3-2-tabs-root default-value="overview">
  <wc-bootstrap-2-3-2-tabs-list>
    <wc-bootstrap-2-3-2-tabs-trigger value="overview">Overview</wc-bootstrap-2-3-2-tabs-trigger>
    <wc-bootstrap-2-3-2-tabs-trigger value="analytics">Analytics</wc-bootstrap-2-3-2-tabs-trigger>
  </wc-bootstrap-2-3-2-tabs-list>
  <wc-bootstrap-2-3-2-tabs-content value="overview"
    >Overview content.</wc-bootstrap-2-3-2-tabs-content
  >
  <wc-bootstrap-2-3-2-tabs-content value="analytics"
    >Analytics content.</wc-bootstrap-2-3-2-tabs-content
  >
</wc-bootstrap-2-3-2-tabs-root>
```

### Composition

```text
TabsRoot
├── TabsList
│   ├── TabsTrigger
│   └── TabsTrigger
├── TabsContent
└── TabsContent
```

- **Selection & keyboard**: `Root` manages controlled `value` or uncontrolled `defaultValue`. Arrow keys and `Home` / `End` move focus across enabled triggers; `activationMode="manual"` commits switches on `Enter` or `Space`.
- **Dark-mode adaptation**: Light mode retains authentic `#ddd` borders and `#08c` / `#005580` / `#555` text; dark mode adapts cleanly onto theme surface and border tokens.
