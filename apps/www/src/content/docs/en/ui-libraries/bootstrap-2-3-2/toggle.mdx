This Toggle is a design-language extension, not an original Bootstrap 2.3.2 component or a port of its jQuery button plugin. It combines the archived button appearance with the independent Base Toggle protocol.

Base Toggle owns persistent `active` state, controlled and uncontrolled ownership, activation, disabled behavior, focus, and pressed accessibility. The visual layer does not maintain another active state or reinterpret this control as a Switch or Checkbox.

Use the page runtime selector to compare Web Components, React, Vue 3, and Vue 2. Bold starts inactive, Italic starts active, and the disabled example cannot toggle.

## API

- `active` / `defaultActive`: controlled or initial active state
- `disabled`: inherited disabled behavior
- `activeChange`: inherited outward signal
