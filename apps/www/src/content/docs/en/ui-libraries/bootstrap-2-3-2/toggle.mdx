## Installation

Available starting in `0.3.0-rc.1` and later releases. [Browse the implemented subset](../).

## Usage

```tsx
import { BootstrapToggle } from '../proto-ui/components/react';
```

```tsx
<BootstrapToggle variant="primary" defaultActive>
  Bold
</BootstrapToggle>
```

- **Classic variants & sizes**: Supports all seven Bootstrap 2.3.2 color variants (`default`, `primary`, `success`, `info`, `warning`, `danger`, `inverse`) and four classic pixel sizes (`mini`, `small`, `default`, `large`).
- **Controlled & uncontrolled**: Supports controlled `active` and uncontrolled `defaultActive`, pointer and `Enter` / `Space` activation, disabled suppression, and `aria-pressed` semantics.
- **Grouped toggles**: For coordinated sets of toggle buttons, use [Toggle Group](/en/ui-libraries/bootstrap-2-3-2/toggle-group/).

## API

The following props belong to `Root` (pass `active` for controlled mode):

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'active', type: 'boolean | undefined', default: 'uncontrolled' },
    { name: 'defaultActive', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    {
      name: 'variant',
      type: "'default' | 'primary' | 'warning' | 'danger' | 'success' | 'info' | 'inverse'",
      default: "'default'",
    },
    { name: 'size', type: "'default' | 'large' | 'small' | 'mini'", default: "'default'" },
  ]}
/>

- **Events**: `activeChange` (payload `{ active: boolean }`).
- **Methods**: `focusSelf(options?)` (no-op while disabled).
- **Exposed states**: `active`, `disabled`, `hovered`, `focused`, `focusVisible`, `pressed`.
