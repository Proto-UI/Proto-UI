Bootstrap 2.3.2 Toggle is a design-language extension, not an original Bootstrap 2.3.2 component. It pairs the archived button appearance with Base Toggle's pressed-state protocol while keeping the classic light palette in dark hosts.

## Preview

Bold starts inactive, Italic starts active, and the disabled toggle cannot be activated.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. [Browse the implemented subset](../).

## Usage

- Supports controlled `active` and uncontrolled `defaultActive`, pointer/keyboard activation, disabled state, and pressed accessibility semantics.
- For coordinated sets of toggle buttons, use [ToggleGroup](/en/ui-libraries/bootstrap-2-3-2/toggle-group/).

## API

| Prop / Event               | Description                           |
| -------------------------- | ------------------------------------- |
| `active` / `defaultActive` | Controlled or initial pressed state   |
| `disabled`                 | Prevents interaction when enabled     |
| `activeChange`             | Emitted when the active state changes |
