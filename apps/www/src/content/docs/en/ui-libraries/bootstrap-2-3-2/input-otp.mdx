Bootstrap 2.3.2 Input OTP pairs one real text input with classic inset-shadow slots and Bootstrap's `#52a8ec` focus glow, preserving native paste, selection, deletion, and browser `one-time-code` autofill.

## Installation

Available starting in `0.3.0-rc.1` and later releases.

## Usage

```tsx
import {
  Bootstrap232InputOtpRoot,
  Bootstrap232InputOtpInput,
  Bootstrap232InputOtpSlot,
  Bootstrap232InputOtpSeparator,
} from '../proto-ui/components/react';

export function BootstrapVerificationCode() {
  return (
    <Bootstrap232InputOtpRoot length={6}>
      <Bootstrap232InputOtpInput placeholder="123456" />
      <div className="inline-flex items-center gap-1.5">
        <Bootstrap232InputOtpSlot index={0} />
        <Bootstrap232InputOtpSlot index={1} />
        <Bootstrap232InputOtpSlot index={2} />
      </div>
      <Bootstrap232InputOtpSeparator>–</Bootstrap232InputOtpSeparator>
      <div className="inline-flex items-center gap-1.5">
        <Bootstrap232InputOtpSlot index={3} />
        <Bootstrap232InputOtpSlot index={4} />
        <Bootstrap232InputOtpSlot index={5} />
      </div>
    </Bootstrap232InputOtpRoot>
  );
}
```

- **Single editor, visual slots**: Editing, selection, paste, and IME composition stay in one real input, sanitizing characters (`numeric` or `alphanumeric`) and clamping length to `1`–`32` (default `6`).
- **Classic Bootstrap 2.3.2 states**: Rest slots keep 4px corners, 1px `#ccc` borders, and subtle inset shadows; active slots use the `#52a8ec` blue focus glow; disabled cells use `#eee`; invalid cells follow `.control-group.error` crimson styling.
- **Form integration**: Swap `Input` for `Control` inside `Field` or `FormField` to bridge `FieldLabel`, validation, serialization, and reset.
