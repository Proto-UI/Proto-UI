## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

Compose `Root`, `Input` (or `Control` inside `Field` / `FormField`), `Slot`, and optional `Separator`:

- **Single editor, visual slots**: Editing, selection, paste, and IME composition happen in one real input. After composition ends, disallowed characters are stripped (numeric or alphanumeric) and clamped to `length` (`1`–`32`, default `6`). Each `Slot` is decorative (`aria-hidden`) and highlights based on the real caret or selection while focused and editable.
- **Completion**: Controlled inputs emit `valueChange` proposals; `completed` fires once for each accepted full-length code so your application can trigger verification.
- **Form integration**: Replace `Input` with `Control` inside `Field` or `FormField` to bridge `FieldLabel`, validation, IME handling, `Form` serialization, and reset.

## API

| Part | Props / Events | Description |
| --- | --- | --- |
| `Root` | `value` / `defaultValue` | Controlled or initial OTP string |
| `Root` | `length` | Number of characters, `1`–`32` (default `6`) |
| `Root` | `disabled` / `readOnly` / `name` / `ariaLabel` | State flags, field name, and accessible name |
| `Root` | `valueChange` / `completed` | Value change proposal and full-code completion event |
| `Input` / `Control` | — | Real text editor (use `Control` inside `Field`/`FormField`) |
| `Slot` / `Separator` | — | Passive character slots and optional visual divider |
