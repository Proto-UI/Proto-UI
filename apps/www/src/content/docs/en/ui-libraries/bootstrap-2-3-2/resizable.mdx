A Bootstrap 2.3.2 extension built on Base Resizable: handles feature the classic `#fff → #e6e6e6` bevel gradient, inset highlight, optional recessed grip badge, and `#52a8ec` focus glow, with full multi-panel ratios, collapsing, RTL, and nested layouts.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototypes directly from `@proto.ui/prototypes-bootstrap-2-3-2/resizable` and adapt them for your target runtime:

```ts
import {
  resizableRoot,
  resizablePanel,
  resizableHandle,
} from '@proto.ui/prototypes-bootstrap-2-3-2/resizable';
```

## Usage

```tsx
import {
  Bootstrap232ResizableRoot,
  Bootstrap232ResizablePanel,
  Bootstrap232ResizableHandle,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <Bootstrap232ResizableRoot
      defaultSizes={[50, 50]}
      className="h-56 w-full max-w-md rounded-[4px] border border-[#ccc] bg-background shadow-[0_1px_3px_rgb(0_0_0/5.5%)] overflow-hidden"
    >
      <Bootstrap232ResizablePanel index={0}>One</Bootstrap232ResizablePanel>
      <Bootstrap232ResizableHandle index={0} withHandle />
      <Bootstrap232ResizablePanel index={1}>Two</Bootstrap232ResizablePanel>
    </Bootstrap232ResizableRoot>
  );
}
```

### Composition

```text
Bootstrap232ResizableRoot
├── Bootstrap232ResizablePanel (index: 0)
├── Bootstrap232ResizableHandle (index: 0, withHandle?)
└── Bootstrap232ResizablePanel (index: 1)
```

- **Indexed panels and handles**: render `N` `Panel` parts (`index: 0..N-1`) and `N - 1` `Handle` parts (`index: 0..N-2`). Each handle resizes only its adjacent pair and defaults its accessible name to `Resize panels`.
- **Classic Bootstrap 2.3.2 cues**: directional `ew-resize` / `ns-resize` cursors, `#52a8ec` focus glow on keyboard focus, and flat `#e6e6e6` `opacity-65` styling when disabled.
- **Constraints and controlled state**: configure per-panel `min`, `max`, `collapsible`, and `collapsedSize` via `constraints`; supply `sizes` for controlled mode and listen to `sizesChange` / `sizesCommit`.

### Panel & Handle

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'Panel.index', type: 'number', default: '0' },

- **Exposed states**: Root exposes `value` and `sizes`; Panel exposes `size`; Handle exposes `value`, `focusVisible`, and `disabled`.
- **Events & methods**: Root emits `sizesChange`, `sizesCommit`, `valueChange`, and `valueCommit`, and exposes `requestResize(index, next, commit?)`, `requestSizes(next, commit?)`, `requestValue(next, commit?)`, and `cancelResize()`.
