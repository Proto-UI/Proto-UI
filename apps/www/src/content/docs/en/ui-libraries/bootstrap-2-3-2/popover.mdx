Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

Compose `Root`, `Trigger`, `Content`, `Title`, `Description`, and `Close`:

- **Positioning**: `Content` anchors to `Trigger` and supports `side`, `align`, `sideOffset`, `alignOffset`, and `collisionPadding`.
- **Dismissal and focus**: Outside clicks, focus leaving `Trigger` and `Content`, `Escape`, and `Close` all request dismissal. Moving focus between `Trigger` and portalled `Content` stays inside; when closed by moving focus to an outside control, focus remains on that outside control.
- **Controlled state**: Pass `open` and handle `openChange` for controlled usage, or use `defaultOpen` for uncontrolled state. Refusing a focus-outside close keeps `Content` visible without trapping focus.

## API

| Part | Props / Events | Description |
| --- | --- | --- |
| `Root` | `open` / `defaultOpen` | Controlled or initial open state |
| `Root` | `openChange` | Emitted on open/close requests |
| `Trigger` | — | Anchor button toggling the popover |
| `Content` | `side` / `align` / `sideOffset` / `alignOffset` / `collisionPadding` | Placement and collision padding options |
| `Title` / `Description` | — | Accessible popover heading and description |
| `Close` | — | Button requesting popover dismissal |
