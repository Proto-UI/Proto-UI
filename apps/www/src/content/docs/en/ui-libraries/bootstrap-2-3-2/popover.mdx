## Installation

Bootstrap 2.3.2 Popover is currently available from the workspace source and not yet included in the 0.2.0 stable CLI release. Import the prototypes directly from `@proto.ui/prototypes-bootstrap-2-3-2/popover` and adapt them for your target runtime:

```ts
import {
  popoverRoot,
  popoverTrigger,
  popoverContent,
  popoverTitle,
  popoverDescription,
  popoverClose,
} from '@proto.ui/prototypes-bootstrap-2-3-2/popover';
```

## Usage

```tsx
<BootstrapPopover>
  <BootstrapPopoverTrigger>Open Popover</BootstrapPopoverTrigger>
  <BootstrapPopoverContent>
    <BootstrapPopoverTitle>Popover title</BootstrapPopoverTitle>
    <BootstrapPopoverDescription>
      And here is some helpful contextual information anchored to the right.
    </BootstrapPopoverDescription>
  </BootstrapPopoverContent>
</BootstrapPopover>
```

### Composition

```text
BootstrapPopoverRoot
├── BootstrapPopoverTrigger
└── BootstrapPopoverContent
    ├── BootstrapPopoverTitle
    ├── BootstrapPopoverDescription
    └── BootstrapPopoverClose
```

- **Classic defaults**: Preserves Bootstrap 2.3.2 defaults with `side="right"`, `sideOffset={10}`, a `276px` max-width shell, `6px` radius, `#ebebeb` title divider, and a `150ms` linear fade transition.
- **Dismissal & focus**: Outside clicks, focus leaving `Trigger` and `Content`, `Escape`, and `Close` all request dismissal. When dismissed by focus moving outside, focus stays on that external control.
