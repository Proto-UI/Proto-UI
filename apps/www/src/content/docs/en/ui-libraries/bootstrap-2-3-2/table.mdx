Bootstrap 2.3.2 Table layers the archived `.table` typography (`14px/20px`), `8px` cell padding, and top-rule rhythm over [Base Table](/en/ui-libraries/base/table/), with optional classic variants for `.table-bordered`, `.table-condensed`, `.table-striped`, `.table-hover`, and contextual row tones.

For sorting, filtering, pagination, and row selection, use [Data Table](/en/ui-libraries/bootstrap-2-3-2/data-table/).

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the parts from `@proto.ui/prototypes-bootstrap-2-3-2/table`:

```ts
import {
  tableRoot,
  tableCaption,
  tableRow,
  tableHeaderCell,
  tableCell,
} from '@proto.ui/prototypes-bootstrap-2-3-2/table';
```

## Usage

```html
<div class="w-full overflow-x-auto">
  <bootstrap-2-3-2-table-root>
    <bootstrap-2-3-2-table-caption>A list of your recent invoices.</bootstrap-2-3-2-table-caption>
    <bootstrap-2-3-2-table-row section="header">
      <bootstrap-2-3-2-table-header-cell
        header-key="invoice"
        header-kind="column"
        style="width: 100px"
      >
        Invoice
      </bootstrap-2-3-2-table-header-cell>
      <bootstrap-2-3-2-table-header-cell header-key="status" header-kind="column"
        >Status</bootstrap-2-3-2-table-header-cell
      >
      <bootstrap-2-3-2-table-header-cell header-key="method" header-kind="column"
        >Method</bootstrap-2-3-2-table-header-cell
      >
      <bootstrap-2-3-2-table-header-cell
        header-key="amount"
        header-kind="column"
        style="text-align: end"
      >
        Amount
      </bootstrap-2-3-2-table-header-cell>
    </bootstrap-2-3-2-table-row>
    <bootstrap-2-3-2-table-row section="body">
      <bootstrap-2-3-2-table-header-cell header-key="inv001" header-kind="row"
        >INV001</bootstrap-2-3-2-table-header-cell
      >
      <bootstrap-2-3-2-table-cell>Paid</bootstrap-2-3-2-table-cell>
      <bootstrap-2-3-2-table-cell>Credit Card</bootstrap-2-3-2-table-cell>
      <bootstrap-2-3-2-table-cell style="text-align: end">$250.00</bootstrap-2-3-2-table-cell>
    </bootstrap-2-3-2-table-row>
  </bootstrap-2-3-2-table-root>
</div>
```

### Composition

```text
Root
├── Caption
├── Row (section="header")
│   └── HeaderCell (headerKind="column")
├── Row (section="body")
│   ├── HeaderCell (headerKind="row")
│   └── Cell (headers=[...])
└── Row (section="footer")
    ├── HeaderCell (headerKind="row")
    └── Cell (headers=[...])
```

- Baseline `.table` styling omits the top border on first-row column headers and keeps `8px` cell padding by default.
- Cell dividers bind to the theme `border-border` token so both light and dark hosts maintain legible contrast alongside `text-foreground`.
