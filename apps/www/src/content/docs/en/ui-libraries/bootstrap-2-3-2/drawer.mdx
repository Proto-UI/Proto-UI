Content.side accepts top, right, bottom or left. The panel uses the available host region, contains long-content scrolling, traps focus and restores the trigger on dismissal. This initial source does not yet implement dragging, snapping or swipe dismissal.

Root supports controlled open or uncontrolled defaultOpen. Disabled commands do not activate. Supplying open leaves the committed value with the owner; listen to openChange and provide the next value.

Parts: Root, Trigger, Content, Title, Description, Close, Mask.
