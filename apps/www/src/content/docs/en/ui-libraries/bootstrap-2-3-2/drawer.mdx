Bootstrap 2.3.2 Drawer brings classic 6px-rounded modal box chrome (ruled header, right-aligned muted footer, and beveled buttons) to an edge-attached drawer supporting all four sides, internal scrolling, and draggable snap points.

## Installation

Currently available from workspace source (`@proto.ui/prototypes-bootstrap-2-3-2/drawer`); not yet published in the 0.2.0 stable CLI release.

## Usage

```tsx
import {
  BootstrapDrawerRoot,
  BootstrapDrawerTrigger,
  BootstrapDrawerMask,
  BootstrapDrawerContent,
  BootstrapDrawerHandle,
  BootstrapDrawerHeader,
  BootstrapDrawerTitle,
  BootstrapDrawerDescription,
  BootstrapDrawerFooter,
  BootstrapDrawerClose,
} from '../proto-ui/components/react';
```

```tsx
<BootstrapDrawerRoot>
  <BootstrapDrawerTrigger>Open Drawer</BootstrapDrawerTrigger>
  <BootstrapDrawerMask />
  <BootstrapDrawerContent side="bottom">
    <BootstrapDrawerHandle />
    <BootstrapDrawerHeader>
      <BootstrapDrawerTitle>Workspace Preferences</BootstrapDrawerTitle>
      <BootstrapDrawerDescription>
        Review default notification and digest rules for this project.
      </BootstrapDrawerDescription>
    </BootstrapDrawerHeader>
    <div className="p-[15px]">{/* Body content */}</div>
    <BootstrapDrawerFooter>
      <BootstrapDrawerClose>Close</BootstrapDrawerClose>
    </BootstrapDrawerFooter>
  </BootstrapDrawerContent>
</BootstrapDrawerRoot>
```

### Composition

```text
DrawerRoot
├── DrawerTrigger
├── DrawerMask
└── DrawerContent
    ├── DrawerHandle
    ├── DrawerHeader
    │   ├── DrawerTitle
    │   └── DrawerDescription
    └── DrawerFooter
        └── DrawerClose
```

- **Sizing and scrolling**: Top and bottom drawers fit their content height up to the safe viewport region; left and right drawers default to a `20` `root-text` cap. Wrap scrollable content in `flex-1 overflow-y-auto` between `Header` and `Footer`.
- **Extent bounds and snap points**: Configure `minExtent`, `maxExtent`, and `snapPoints` directly on `Content`. Passing `(0, 1]` fractions enables explicit snap stops with keyboard arrow and `Home`/`End` support on `Handle`.
- **Transitions**: `Content` slides over 300ms and `Mask` fades over 150ms, automatically honoring `prefers-reduced-motion`.

## API

### Root

Pass `open` for controlled mode and subscribe to `openChange`. Exposes `openDrawer()`, `close()`, and `toggle()`.

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'open', type: 'boolean', default: '—' },
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'a11yLabel', type: 'string', default: "''" },
  ]}
/>

### Content

Exposes `open`, `snapPoint`, `dragging`, `dragProgress`, `offsetPercentage`, `extentValid`, `requestSnapPoint()`, and `snapPointChange`.
