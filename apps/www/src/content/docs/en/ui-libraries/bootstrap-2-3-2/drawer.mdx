## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Sizing and scrolling**: Top and bottom drawers fit their content height up to the safe available viewport height and scroll internally (`overflow-y-auto`) when content overflows; left and right drawers default to a `20rem` cap.
- **Extent bounds**: Pass `minExtent` and `maxExtent` on `Content` using neutral length objects (`unit`: `'logical'` | `'root-text'` | `'available'` | `'available-minus-root-text'`, nonnegative finite `value`). Minimums above the safe cap clamp automatically; invalid runtime updates set `extentValid={false}` and keep the last valid size.
- **Snap points**: Omit `snapPoints` (or pass an empty array) for content-fit mode where `Handle` acts as a pointer-only drag affordance. Pass an array of fractions in `(0, 1]` to enable explicit snapping, with keyboard arrow and `Home`/`End` resizing on `Handle`.
- **Dismissal and controlled state**: Supply `open` to control visibility externally; refused close requests spring back to the current state. Set `dragDismissible={false}` to disable drag dismissal while keeping Close buttons, `Escape`, and outside-click dismissal.

## API

| Part | Props / Events / States | Description |
| --- | --- | --- |
| `Root` | `open` / `defaultOpen` | Controlled or initial open state |
| `Root` | `snapPoints` | Array of fractions in `(0, 1]` enabling explicit snap stops |
| `Root` | `snapPoint` / `defaultSnapPoint` / `snapPointChange` | Controlled/initial active snap point and change event |
| `Content` | `minExtent` / `maxExtent` | Minimum and maximum extent bounds |
| `Content` | `dragDismissible` | Defaults to `true`; disables drag dismissal when `false` |
| `Content` | `extentValid` | Indicates whether the active extent configuration is valid |
| `Handle` | — | Drag handle; adds named `separator` role and keyboard resize in snap mode |
