Bootstrap 2.3.2 Separator reproduces the archived two-edge etched rule (`#eeeeee` recessed edge paired with `#ffffff` highlight) for both horizontal and vertical dividers while Base Separator manages orientation and decorative accessibility semantics.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import `separatorRoot` from `@proto.ui/prototypes-bootstrap-2-3-2/separator`. [Browse the implemented subset](../).

```ts
import { separatorRoot } from '@proto.ui/prototypes-bootstrap-2-3-2/separator';
```

## Usage

```tsx
import { BootstrapSeparatorRoot } from '../proto-ui/components/react';
```

```tsx
<BootstrapSeparatorRoot />
```

- **Etched bevel rule**: Horizontal rules render a `1px #eeeeee` top edge and `1px #ffffff` bottom edge; vertical rules pair left/right bevel edges and stretch automatically across flex containers (`self-stretch`).
- **Decorative vs. semantic**: Decorative separators (`decorative={true}`, default) stay hidden from the accessibility tree. Pass `decorative={false}` to expose `role="separator"` and `aria-orientation`.
- **Layout**: Separator is contentless and passive with no built-in margin; length and spacing belong to the surrounding container.
