Separator carries the archived divider language while Base owns orientation and decorative semantics. `orientation` defaults to `horizontal`; `decorative` defaults to `true`.

Decorative separators are hidden from the accessibility tree without a role. Setting `decorative={false}` exposes the `separator` role and matching `aria-orientation`. The vertical treatment is a design-language adaptation of the archived horizontal rule.

The prototype is contentless and passive: it has no focus, tab stop, event, activation, or mutable value. Length and spacing come from the surrounding composition. Use the page runtime selector to compare Web Components, React, Vue 3, and Vue 2.

## API

- `orientation`: `horizontal` / `vertical`
- `decorative`: `true` by default; set `false` for semantic separation
- The demo includes horizontal, vertical, and semantic examples
