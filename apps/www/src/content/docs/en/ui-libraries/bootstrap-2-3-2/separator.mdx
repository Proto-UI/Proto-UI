## Usage

- **Decorative vs. semantic**: Decorative separators (`decorative={true}`, the default) are hidden from the accessibility tree. Set `decorative={false}` to expose the `separator` role and matching `aria-orientation`.
- **Layout**: Separator is passive with no Tab stop or children; its length and spacing come from your surrounding layout. Vertical styling adapts the archived horizontal rule.

## API

| Prop | Values | Default | Description |
| --- | --- | --- | --- |
| `orientation` | `'horizontal'` \| `'vertical'` | `'horizontal'` | Divider orientation |
| `decorative` | `boolean` | `true` | Set `false` to expose semantic `separator` accessibility |
