## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

<InstallCommandCard
  command="npx @proto.ui/cli@latest add wc bootstrap-2-3-2-button"
  manager="npm"
/>

Replace `wc` with `react`, `vue`, or `vue2` to generate the facade for your framework.

## Usage

Web Components:

```html
<wc-bootstrap-2-3-2-button variant="primary">Continue</wc-bootstrap-2-3-2-button>
<wc-bootstrap-2-3-2-button disabled>Unavailable</wc-bootstrap-2-3-2-button>
```

React:

```tsx
import { BootstrapButton } from '../proto-ui/components/react';

export function Example() {
  return <BootstrapButton variant="primary">Continue</BootstrapButton>;
}
```

Vue 3:

```vue
<template>
  <BootstrapButton variant="primary">Continue</BootstrapButton>
</template>

<script setup>
import { BootstrapButton } from '../proto-ui/components/vue';
</script>
```

Vue 2:

```vue
<template>
  <BootstrapButton variant="primary">Continue</BootstrapButton>
</template>

<script>
import { BootstrapButton } from '../proto-ui/components/vue2';

export default {
  components: { BootstrapButton },
};
</script>
```

### Styling and accessibility

- The archived style uses fixed pixel dimensions rather than scaling with root font size, and keeps its classic light palette even in dark hosts.
- Accessible naming comes from the button's children; keyboard activation, focus handling, and disabled suppression are inherited from Base Button.

## API

| Prop | Values | Default | Description |
| --- | --- | --- | --- |
| `variant` | `default` \| `primary` \| `warning` \| `danger` \| `success` \| `info` \| `inverse` | `default` | Button color variant |
| `size` | `default` \| `large` \| `small` \| `mini` | `default` | Button size |
| `disabled` | `boolean` | `false` | Prevents pointer and keyboard activation when enabled |
