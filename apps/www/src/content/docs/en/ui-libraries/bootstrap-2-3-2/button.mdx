## API

- variant: default / primary
- disabled: boolean, default false
- Activation, focus, keyboard and disabled behavior are inherited from Base Button; the visual layer owns no second interaction state.

Button is registered now. Other Base parts are being added explicitly, never aliased to another family. General Compiler and full GPUI/Flutter/Qt realization remain unverified. The source package is private and unreleased.
