A Bootstrap 2.3.2 button uses the archived gradient, border and inset-shadow treatment while Base Button owns activation, keyboard input, focus and disabled behavior.

The example below shows the supported variants, four sizes and a disabled button. Use the runtime selector to run the same prototype with Web Components, React, Vue 3 or Vue 2.

## Install

<InstallCommandCard
  command="npx @proto.ui/cli@latest add wc bootstrap-2-3-2-button"
  manager="npm"
/>

Replace `wc` with `react`, `vue` or `vue2` to generate the corresponding facade. This is a draft, private, unreleased source projection; the command describes the workspace delivery path, not a claim that this family is published as a stable package.

## Usage

Web Components:

```html
<wc-bootstrap-2-3-2-button variant="primary">Continue</wc-bootstrap-2-3-2-button>
<wc-bootstrap-2-3-2-button disabled>Unavailable</wc-bootstrap-2-3-2-button>
```

React:

```tsx
import { BootstrapButton } from '../proto-ui/components/react';

export function Example() {
  return <BootstrapButton variant="primary">Continue</BootstrapButton>;
}
```

Vue 3:

```vue
<template>
  <BootstrapButton variant="primary">Continue</BootstrapButton>
</template>

<script setup>
import { BootstrapButton } from '../proto-ui/components/vue';
</script>
```

Vue 2:

```vue
<template>
  <BootstrapButton variant="primary">Continue</BootstrapButton>
</template>

<script>
import { BootstrapButton } from '../proto-ui/components/vue2';

export default {
  components: { BootstrapButton },
};
</script>
```

## Variants and sizes

- `variant`: `default`, `primary`, `warning`, `danger`, `success`, `info` or `inverse`.
- `size`: `default`, `large`, `small` or `mini`.
- `disabled`: `false` by default. Disabled buttons do not emit activation requests.

The archived recipe uses fixed pixel dimensions. It does not rescale with the document's root font size, and this Web demo is not GPUI, Flutter or Qt conformance evidence.

## Accessibility

Button naming comes from its content. Keyboard activation, focus and disabled suppression are inherited from Base Button; the Bootstrap projection adds no second interaction state.
