Bootstrap 2.3.2 Button preserves the archived linear gradients, text shadows, borders, and fixed pixel metrics while inheriting activation, keyboard handling, focus, and disabled behavior from Base Button.

Currently available from workspace source:

<InstallCommandCard
  commands={{
    npm: 'npx @proto.ui/cli@latest add wc bootstrap-2-3-2-button',
    pnpm: 'pnpm dlx @proto.ui/cli@latest add wc bootstrap-2-3-2-button',
  }}

Replace `wc` with `react`, `vue`, or `vue2` to generate the facade for your framework.

## Usage

```tsx
import { BootstrapButton } from '../proto-ui/components/react';

export function Example() {
  return <BootstrapButton variant="primary">Continue</BootstrapButton>;
}
```

- **Fixed pixel metrics & palette**: Preserves Bootstrap 2.3.2 pixel padding, font sizes, and border radii independent of root font scaling, keeping its classic light palette even in dark hosts.
- **Hover motion & accessibility**: Applies the classic 100ms linear `background-position` entry transition on hover or focus (resetting immediately on leave and respecting reduced motion). Keyboard activation, focus-visible rings, and disabled semantics come from [Base Button](../base/button/).
