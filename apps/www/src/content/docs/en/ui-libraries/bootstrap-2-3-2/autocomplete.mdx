Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

Compose `Root`, `Input`, `Trigger`, `Content`, `Item`, and `Empty`:

- **Committed value vs. query**: `value` holds the committed text while `inputValue` holds the live query. Picking a suggestion commits its `textValue`; pressing `Enter` with no active suggestion commits the typed text.
- **Filtering and empty state**: Built-in filtering matches `textValue` and `keywords` case- and diacritic-insensitively. Pass `filter={false}` to render pre-filtered items. `Empty` appears automatically when zero items match.
- **Keyboard and IME**: Focus stays in `Input` while navigating with Arrow keys, and IME composition never prematurely commits an item. Disabled and duplicate-valued items cannot be committed.
- **Independent control**: `open`, `value`, and `inputValue` can each be controlled independently via their change events.

## API

| Part | Props | Description |
| --- | --- | --- |
| `Root` | `value` / `inputValue` / `open` | Independently controlled committed text, query, and open state |
| `Root` | `filter` | Toggle built-in filtering; set `false` for externally filtered children |
| `Input` | — | Single-line text input that keeps keyboard focus during navigation |
| `Trigger` | — | Toggles the suggestion list |
| `Content` | — | Suggestion list container |
| `Item` | `value` / `textValue` / `keywords` / `disabled` | Individual suggestion entry |
| `Empty` | — | Displayed when no suggestions match |
