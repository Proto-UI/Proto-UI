Textarea applies the Bootstrap 2.3.2 field language to one Base Textarea Root. The current Web profile materializes one native multiline editor.

Base owns controlled and uncontrolled values, normalized input, change and IME events, native properties, disabled and read-only behavior, accessible naming, and focus. Appearance is projected onto that same editor. Authored children never become another editor, and this slice adds no form workflow, validation message, auto-resize, or rich text.

Use the page runtime selector to compare Web Components, React, Vue 3, and Vue 2. Edit the release note, focus the read-only editor, and compare the disabled editor.

## API

- `value` / `defaultValue`, `disabled`, `readOnly`, and `placeholder`
- `rows`, `wrap`, `maxLength`, `minLength`, `name`, `required`, and `autoComplete`
- `ariaLabel`, `labelledBy`, and `describedBy`
- Inherited `valueChange`, `change`, composition events, `focusSelf`, and `blurSelf`

This is a draft, private, unreleased source projection. The archived light palette stays fixed in dark hosts. The Web demo does not establish general Prototype Compiler or GPUI, Flutter, or Qt conformance. [Browse the implemented subset](../).
