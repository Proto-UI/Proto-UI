Bootstrap 2.3.2 Textarea applies archived Bootstrap 2.3.2 field styling (4px radius, inset shadow, `#52a8ec` focus glow, and `#eee` disabled fill) to Base Textarea, rendering a single native multiline editor on the Web while preserving the classic light palette in dark hosts.

## Installation

Available from workspace source via `@proto.ui/prototypes-bootstrap-2-3-2/textarea` (and `@proto.ui/prototypes-bootstrap-2-3-2/field` for form composition). [Browse the implemented subset](../).

## Usage

```tsx
import { Bootstrap232TextareaRoot } from '../proto-ui/components/react';
```

```tsx
<Bootstrap232TextareaRoot placeholder="Type your message here." rows={4} />
```

- **Values and events**: Supports controlled `value` and uncontrolled `defaultValue`, normalized `valueChange`, `change`, and IME composition events, plus `resetValue()`, `focusSelf()`, and `blurSelf()`.
- **Rows and wrapping**: Configure `rows` and `wrap` to control visible lines and wrapping behavior; ships with a 64px minimum height and vertical resize (`resize-y`).
- **Field composition**: Pair `FieldTextarea` with `Field`, `FieldLabel`, `FieldDescription`, and `FieldError` for accessible associations and classic `#953b39` / `#d59392` error styling.

## API

The following props belong to `Root` (pass `value` for controlled mode; `minLength` and `maxLength` default to `-1` when unlimited):

    { name: 'readOnly', type: 'boolean', default: 'false' },
    { name: 'placeholder', type: 'string', default: "''" },
    { name: 'rows', type: 'number', default: '2' },

    { name: 'maxLength', type: 'number', default: '-1' },

- **Exposed states**: `value`, `disabled`, `readOnly`, `focused`, `focusVisible`, `composing` (plus `invalid` and `pending` on `FieldTextarea`).
- **Exposed methods**: `focusSelf(options?)`, `blurSelf()`, `resetValue()`.
- **Events**: `valueChange`, `change`, `compositionStart`, `compositionUpdate`, `compositionEnd`.
