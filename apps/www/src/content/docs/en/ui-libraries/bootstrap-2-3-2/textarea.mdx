Currently available from workspace source; not yet included in the 0.2.0 stable release. [Browse the implemented subset](../).

## Usage

- **Values and events**: Supports controlled `value` and uncontrolled `defaultValue`, along with normalized `input`, `change`, and IME composition events.
- **Rows and wrapping**: Configure `rows` and `wrap` to control visible lines and wrapping behavior.
- **Field composition**: Pair with `Field` when you need labels, helper descriptions, or validation errors.

## API

| Category | Members | Description |
| --- | --- | --- |
| Value & state | `value` / `defaultValue`, `disabled`, `readOnly`, `placeholder` | Controlled/uncontrolled multiline text and state flags |
| Layout & constraints | `rows`, `wrap`, `minLength`, `maxLength`, `name`, `required`, `autoComplete` | Native multiline attributes |
| Accessibility | `ariaLabel`, `labelledBy`, `describedBy` | Accessible naming and description links |
| Events & methods | `valueChange`, `change`, composition events, `focusSelf()`, `blurSelf()` | Change notifications and focus methods |
