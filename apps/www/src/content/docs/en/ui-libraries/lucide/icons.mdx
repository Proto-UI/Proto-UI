This page lists the currently enabled Lucide icons in Proto UI. Each card supports:

- Copying an `asHook` usage snippet.
- Copying an inline `render` snippet.
- Lazy loading icon module code only when the card enters the viewport.

## Use an icon

Fixed-glyph prototypes accept `size`, `strokeWidth`, `stroke` and `fill`; the name-based entry also accepts `name`. Gallery fragments are Prototype-authoring snippets rather than complete host applications. Follow the [Lucide library guide](../) for exact package names, full WC/React/Vue/Vue 2 source examples, defaults, decorative visibility and the current accessible-name boundary.
