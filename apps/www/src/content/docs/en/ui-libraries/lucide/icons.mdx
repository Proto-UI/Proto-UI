## Usage

Fixed-glyph prototypes accept `size`, `strokeWidth`, `stroke`, and `fill`; the name-based entry also accepts `name`. Card snippets are intended for prototype authoring inside a setup or render callback.

See the [Lucide Icon Library guide](../) for package installation, full Web Components / React / Vue / Vue 2 examples, prop defaults, and accessibility guidance.
