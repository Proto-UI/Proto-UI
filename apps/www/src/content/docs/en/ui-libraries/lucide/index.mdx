Proto UI generates on-demand Lucide icon prototypes from `lucide-static`. Search icons directly below, open any card to inspect its import path, and copy an `asHook` or inline `render` snippet.

Each icon ships as an independent entry point for tree-shakeable imports, and the gallery lazy-loads SVGs as cards approach the viewport.

## Installation

Install the 0.2.0 stable packages for Web Components in a bundled application:

```sh
npm install @proto.ui/prototypes-lucide@0.2.0 @proto.ui/adapter-web-component@0.2.0
```

Or with pnpm:

```sh
pnpm add @proto.ui/prototypes-lucide@0.2.0 @proto.ui/adapter-web-component@0.2.0
```

- **React**: use `@proto.ui/adapter-react@0.2.0`
- **Vue 3**: use `@proto.ui/adapter-vue@0.2.0`
- **Vue 2.6** (`>=2.6.0 <2.7`): `@proto.ui/adapter-vue2` is currently available from workspace source; available starting in `0.3.0-rc.1` and later releases.

### Prototype authoring

When authoring a custom prototype, you can reuse any icon in two ways:

- `asLucideCheckIcon()`: compose the fixed glyph as a prototype hook.
- `renderLucideCheckIcon(renderer, { size: 18 })`: append the SVG inside a prototype's `render` callback.

All SVGs use `viewBox="0 0 24 24"`. The name-based `lucideIcon` / `asLucideIcon` entry accepts a `name` prop (falling back to `circle` when invalid), whereas fixed-glyph entries such as `lucideCheckIcon` keep their own glyph and ignore `name`.

## API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `string` | `'circle'` | Supported by `lucideIcon` / `asLucideIcon` only; invalid names fall back to `circle` |
| `size` | positive finite number | `24` | Width and height; invalid or non-positive values fall back to default |
| `strokeWidth` | positive finite number | `2` | Stroke width; invalid or non-positive values fall back to default |
| `stroke` | `string` | `'currentColor'` | Stroke color |
| `fill` | `string` | `'none'` | Fill color |

Icon prototypes do not include built-in `decorative`, `title`, `role`, or accessible-label props; configure accessibility attributes on the host wrapper or owning control.

Glyph assets are derived from `lucide-static@1.8.0`. Retain the [Lucide/Feather notices](https://github.com/Proto-UI/Proto-UI/blob/main/packages/prototypes/lucide/THIRD_PARTY_NOTICES.md) and [source manifest](https://github.com/Proto-UI/Proto-UI/blob/main/packages/prototypes/lucide/src/manifest.generated.ts) when redistributing.
