Proto UI is not one component library. It is a foundation for choosing the visual language that fits your product while keeping reusable interaction protocols underneath.

The 0.3 release scope is Base, Shadcn, Brutalist (Neo-Brutalism), and Lucide. Bootstrap 2.3.2, Liquid Glass, and other UI libraries remain **WIP / Experimental**, tracked for 0.4 rather than promised as stable 0.3 coverage. A library being in the release scope does not itself promote its draft prototypes or prove acceptance.

The entries below use each component library’s own prototypes. Lucide uses a neutral carrier for its icons. Credits distinguish the design references and icon sources from the Proto UI implementation.
