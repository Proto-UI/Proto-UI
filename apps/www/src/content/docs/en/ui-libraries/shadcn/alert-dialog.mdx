A modal confirmation dialog for important or destructive actions, with safe initial focus on the cancel button and outside dismissal disabled. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Currently available from workspace source (`@proto.ui/prototypes-shadcn`); not yet included in the 0.2.0 CLI stable release.

## Usage

```tsx
import {
  ShadcnAlertDialogRoot,
  ShadcnAlertDialogTrigger,
  ShadcnAlertDialogMask,
  ShadcnAlertDialogContent,
  ShadcnAlertDialogHeader,
  ShadcnAlertDialogTitle,
  ShadcnAlertDialogDescription,
  ShadcnAlertDialogFooter,
  ShadcnAlertDialogCancel,
  ShadcnAlertDialogAction,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <ShadcnAlertDialogRoot styleProfile="rhea">
      <ShadcnAlertDialogTrigger variant="outline">Show Dialog</ShadcnAlertDialogTrigger>
      <ShadcnAlertDialogMask />
      <ShadcnAlertDialogContent>
        <ShadcnAlertDialogHeader>
          <ShadcnAlertDialogTitle>Are you absolutely sure?</ShadcnAlertDialogTitle>
          <ShadcnAlertDialogDescription>
            This action cannot be undone. This will permanently delete your account.
          </ShadcnAlertDialogDescription>
        </ShadcnAlertDialogHeader>
        <ShadcnAlertDialogFooter>
          <ShadcnAlertDialogCancel>Cancel</ShadcnAlertDialogCancel>
          <ShadcnAlertDialogAction>Continue</ShadcnAlertDialogAction>
        </ShadcnAlertDialogFooter>
      </ShadcnAlertDialogContent>
    </ShadcnAlertDialogRoot>
  );
}
```

### Composition

```text
AlertDialogRoot
├── AlertDialogTrigger
├── AlertDialogMask
└── AlertDialogContent
    ├── AlertDialogHeader
    │   ├── AlertDialogTitle
    │   └── AlertDialogDescription
    └── AlertDialogFooter
        ├── AlertDialogCancel
        └── AlertDialogAction
```

- **Root**: Manages open state with `alertdialog` modality always enabled.
- **Trigger / Cancel / Action**: Each retains its own Base command state and supports `variant`, `size`, `wrap`, and `disabled`. Activating `Action` emits `action` before requesting close.
- **Mask / Content**: Provides the modal backdrop, focus trap, and 150ms enter/leave transitions; focuses `Cancel` first on open and blocks outside-click dismissal.
- **Style presets (`styleProfile`)**: Supports `vega`, `nova`, `maia`, `lyra`, `mira`, `luma`, `sera`, `rhea`, and `new-york-v4` (`new-york` alias). When omitted, parts inherit from the nearest [Style Scope](../style-scope/).

### Keyboard & Accessibility

- `Escape` and `Cancel` request dismissal and restore focus to the trigger.
- `Tab` / `Shift + Tab` loops focus strictly within `Content`.
- Initial focus targets the safe `Cancel` button by default; disabled commands do not activate.
