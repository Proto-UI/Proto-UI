Groups a single form control with its label, help text, and validation errors, automatically wiring accessible relationships and supporting built-in, controlled, and asynchronous validation. The examples on this page use the **Shadcn Rhea** style preset.

Replace `wc` with `react`, `vue`, or `vue2` to generate the local facade for your framework.

You can also import `fieldRoot`, `fieldLabel`, `fieldControl`, `fieldDescription`, `fieldError`, and `fieldValidity` directly from `@proto.ui/prototypes-shadcn/field`.

## Usage

### Anatomy

Place one `Control` inside `Root`, along with an optional `Label`, `Description`, `Error`, and any number of passive `Validity` readers (nested `Root` instances keep independent scopes; duplicate singleton roles are ignored):

- **Root**: Manages validation state (`invalid`, `pending`, `dirty`, `touched`, `filled`, `focused`) and `disabled`, `readOnly`, and `required` policies.
- **Control**: Renders a single-line text editor by default. To connect custom value controls, report values via `asFieldControl` and wire label focusing with `asControlLabel().target(..., FIELD_LABEL_PAIR)`.
- **Label**: Automatically names the field's `Control` and focuses it on click (disable with `activation={false}`).
- **Description**: Passive help text linked via `aria-describedby`.
- **Error**: Linked via `aria-errormessage` only while the field is invalid. It unmounts content when hidden (set `keepMounted` to keep it mounted) and automatically links and cleans up ARIA attributes. Pair with [Live Region](../live-region/) if you want automatic screen-reader announcements.
- **Validity**: Passive reader exposing `getValidity()`.

### Synchronous and asynchronous validation

- **Built-in rules**: `required` treats `null`, `false`, `''`, and `[]` as empty (`0` and whitespace count as filled). `minLength` and `maxLength` count UTF-16 code units and skip optional empty strings. Built-in flags are `valueMissing`, `tooShort`, and `tooLong`; external errors use `customError`.
- **Triggers**: `validationMode` supports `'onBlur'` (default), `'onChange'` (waits for IME `compositionend`), and `'manual'`.
- **Async validation**: With `externalValidation={true}`, passing built-in checks emits `validationRequest` (`{ requestId, value, reason }`). Call `resolveValidation(requestId, { invalid, errors })` once your check completes; stale replies from superseded edits, state changes, `cancelValidation()`, or `resetValidation()` are ignored automatically.
- **Controlled validity**: Pass `invalid` and `errors` to manage validity externally; `validityChange` emits proposed updates.
- **Form integration**: `resetValidation()` clears validation and `touched` without changing the control's value. For submission, serialization, and full form reset, compose with [Form](../form/) and [Fieldset](../fieldset/).

### Other parts

- **Control**: `value` / `defaultValue`, `disabled`, `readOnly`, `required`, `placeholder`, `name`, `autoComplete`, `inputMode`, `enterKeyHint`, `ariaLabel` (local flags cannot override an active `Root` constraint).
- **Label**: `activation?: boolean` (default `true`).
- **Description**: No props.
- **Error**: `message?: string` (explicit localized override), `keepMounted?: boolean` (default `false`).
- **Validity**: No props.

### Methods and events (Root)

- **Methods**: `validate(reason?)`, `resolveValidation(requestId, result)`, `cancelValidation()`, `resetValidation()`, `focusControl(options?)`, `getValidity()`.
- **Events**: `validityChange` (validation snapshot), `validationRequest` (`{ requestId, value, reason }`).
