Toast displays brief, non-blocking notifications with auto-dismiss timers that pause on hover or focus, keyboard navigation shortcuts, and optional action buttons. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototypes directly from `@proto.ui/prototypes-shadcn/toast` and adapt them for your target runtime.

```ts
import {
  toastViewport,
  toastRoot,
  toastTitle,
  toastDescription,
  toastAction,
  toastClose,
} from '@proto.ui/prototypes-shadcn/toast';
```

## Usage

```tsx
<ShadcnToastViewport a11yLabel="Notifications">
  <ShadcnToastRoot defaultOpen={false} duration={5000}>
    <ShadcnToastTitle>Event has been created</ShadcnToastTitle>
    <ShadcnToastDescription>Sunday, December 03, 2023 at 9:00 AM</ShadcnToastDescription>
    <ShadcnToastAction a11yLabel="Undo event creation">Undo</ShadcnToastAction>
    <ShadcnToastClose>Dismiss</ShadcnToastClose>
  </ShadcnToastRoot>
</ShadcnToastViewport>
```

Toast consists of `Root`, `Viewport`, `Title`, `Description`, `Action`, and `Close`:

- `Root` stays open for `5000ms` by default before requesting dismissal; set `duration={0}` to keep a notification open until explicitly dismissed.
- Hovering over the toast or focusing `Action` or `Close` pauses the remaining timer until the pointer or focus leaves.
- Clicking `Close`, pressing `Escape` while focused, or activating `Action` requests dismissal; your application handles the action's side effects.
- In controlled mode (`open` supplied), reaching the timeout emits a single dismissal request until your state updates.
- `Viewport` labels the notification region (default `Notifications`) and provides the `F8` shortcut to jump focus directly to the viewport. Managing a queue of multiple toasts stays in your application state.

Events and exposed methods:

- **Events**: `Root` emits `openChange` (`{ open: boolean; reason: string }`); `Action` emits `action` (`void`).
- **Methods**: `Root` exposes `openToast()`, `close(reason?)`, `pause()`, and `resume()`; `Viewport` exposes `focusFirst()`.
