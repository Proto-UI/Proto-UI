Virtual List decouples a complete logical key sequence from physical DOM nodes, creating item views only for the visible window and overscan buffer so large, variable-height lists stay responsive. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Available starting in `0.3.0-rc.1` and later releases. Import the prototypes from `@proto.ui/prototypes-shadcn/virtual-list` and connect a Web scroll container through `@proto.ui/prototypes-base/virtual-list/web`.

## Usage

Virtual List is composed of `Root`, `Viewport`, and `Content`: `Root` tracks the ordered `itemKeys` sequence and provides the family style scope, `Viewport` handles scrolling and keyboard focus, and `Content` hosts the materialized row elements.

```ts
import { AdaptToWebComponent, setElementProps } from '@proto.ui/adapter-web-component';
import {
  virtualListRoot,
  virtualListViewport,
  virtualListContent,
} from '@proto.ui/prototypes-shadcn/virtual-list';
import { attachWebVirtualList } from '@proto.ui/prototypes-base/virtual-list/web';

AdaptToWebComponent(virtualListRoot);
AdaptToWebComponent(virtualListViewport);
AdaptToWebComponent(virtualListContent);

const list = document.querySelector('shadcn-virtual-list-root')!;
const viewport = document.querySelector('shadcn-virtual-list-viewport')!;
const content = document.querySelector('shadcn-virtual-list-content')!;

setElementProps(list, {
  styleProfile: 'rhea',
  itemKeys: Array.from({ length: 1000 }, (_, i) => `event-${i + 1}`),
  overscanItems: 3,
  maxMaterializedItems: 60,
});

const host = attachWebVirtualList({
  viewport,
  content,
  collection: list.getExposes().getCollection(),
  estimateSize: 64,
  renderItem(key) {
    const row = document.createElement('div');
    row.className = 'border-b border-border/60 px-4 py-3 text-sm';
    row.textContent = key;
    return row;
  },
});

// Programmatically scroll to a key and dispose on teardown
host.ensureVisible('event-250', 'center');
// host.dispose();
```

### Anatomy & Accessibility

- `Root` sets `role="region"` with `a11yLabel` and adapts its radius, border, and surface ring to the active `styleProfile`.
- `Viewport` inherits `Scroll Area` scrolling and focus handling, displaying a clipped inset focus ring on keyboard focus.
- `Content` sets `role="list"`; each mounted row receives `role="listitem"`, `aria-posinset`, and `aria-setsize` automatically.

### Advanced: Custom Materializers

- Each logical list allows one active materializer at a time; `attachWebVirtualList` manages the lease automatically and cleans up rendered rows and its `ResizeObserver` when `Root` unmounts or disposes.
- Call `dispose()` on an active materializer before attaching a replacement. Non-Web hosts can integrate directly through `collection.acquireMaterializer(onRetired)`.
