Coordinates validation, submission, and reset across form fields, supporting both synchronous and asynchronous checks, named serialization, and nested fieldset disabling. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Available starting in `0.3.0-rc.1` and later releases via `@proto.ui/prototypes-shadcn/form`.

## Usage

```tsx
import {
  ShadcnFormRoot,
  ShadcnFormField,
  ShadcnFormSubmit,
  ShadcnFormReset,
  ShadcnFieldLabel,
  ShadcnFieldControl,
  ShadcnFieldError,
} from '../proto-ui/components/react';

export function ExampleForm() {
  return (
    <ShadcnFormRoot
      styleProfile="rhea"
      ariaLabel="Account settings"
      onSubmit={({ values }) => console.log(values)}
    >
      <ShadcnFormField styleProfile="rhea" name="username" required>
        <ShadcnFieldLabel styleProfile="rhea">Username</ShadcnFieldLabel>
        <ShadcnFieldControl styleProfile="rhea" placeholder="ada_lovelace" />
        <ShadcnFieldError styleProfile="rhea" />
      </ShadcnFormField>
      <div className="flex items-center gap-2">
        <ShadcnFormSubmit styleProfile="rhea">Save</ShadcnFormSubmit>
        <ShadcnFormReset styleProfile="rhea" variant="outline">
          Reset
        </ShadcnFormReset>
      </div>
    </ShadcnFormRoot>
  );
}
```

### Anatomy

- **Root**: Collects explicitly registered `FormField` parts, validates enabled fields, and emits `submit` with form values keyed by field name once all checks pass. Disabled fields (including those inside a disabled `Fieldset`) are excluded, and duplicate field names throw `FORM_DUPLICATE_NAME` during serialization. Setting `disabled` on `Root` cascades to all contained fields and actions.
- **Field**: Extends `FieldRoot` with a submission `name`. Standalone `Checkbox`, `RadioGroup`, and `Switch` controls stay independent unless wrapped with `fieldCheckbox`, `fieldRadioGroup`, or `fieldSwitch` from `@proto.ui/prototypes-shadcn/field`.
- **Submit / Reset**: Styled with matching button presets (`variant`, `size`, and `styleProfile`), supporting pointer and keyboard activation and exposing `disabled`, `hovered`, `pressed`, `focused`, `focusVisible`, and `focusSelf()`.

### Keyboard & Accessibility

- **Implicit Enter submit**: Pressing `Enter` inside a focused single-line `Field`, `Number Field`, or `Input OTP` submits the form (ignoring IME composition, modifier keys, and key repeat).
- **Focus on invalid**: When validation fails, `invalid` is emitted and focus moves to the first invalid field control.
- **Reset vs clear validation**: `Reset` or `requestReset()` restores uncontrolled initial values, proposes initial values to controlled owners, cancels pending validation, and emits `reset`. Call `resetValidation()` to clear validation errors without modifying field values.
