A segmented one-time password input backed by a single real text control so pasting, deletion, caret selection, and `one-time-code` autofill work naturally. The examples on this page use the **Shadcn Rhea** style preset.

## Usage

```tsx
import {
  ShadcnInputOtpRoot,
  ShadcnInputOtpInput,
  ShadcnInputOtpSlot,
  ShadcnInputOtpSeparator,
} from '../proto-ui/components/react';

export function VerificationCode() {
  return (
    <ShadcnInputOtpRoot styleProfile="rhea" length={6}>
      <ShadcnInputOtpInput styleProfile="rhea" placeholder="123456" />
      <div className="inline-flex items-center">
        <ShadcnInputOtpSlot styleProfile="rhea" index={0} first />
        <ShadcnInputOtpSlot styleProfile="rhea" index={1} />
        <ShadcnInputOtpSlot styleProfile="rhea" index={2} last />
      </div>
      <ShadcnInputOtpSeparator styleProfile="rhea">–</ShadcnInputOtpSeparator>
      <div className="inline-flex items-center">
        <ShadcnInputOtpSlot styleProfile="rhea" index={3} first />
        <ShadcnInputOtpSlot styleProfile="rhea" index={4} />
        <ShadcnInputOtpSlot styleProfile="rhea" index={5} last />
      </div>
    </ShadcnInputOtpRoot>
  );
}
```

```text
InputOtpRoot
├── InputOtpInput (or InputOtpControl inside Field / Form)
├── InputOtpSlot (index 0..2)
├── InputOtpSeparator
└── InputOtpSlot (index 3..5)
```

### Anatomy and interaction

- **Root**: Manages `value` / `defaultValue`, `length` (`1`–`32`, default `6`), `pattern` (`'numeric'` or `'alphanumeric'`), `disabled`, `readOnly`, `invalid`, `name`, and `ariaLabel`.
- **Input / Control**: Provides the single underlying text editor, stripping disallowed characters and clamping length after IME composition finishes. Use `Input` standalone, or replace it with `Control` inside a [Field](../field/) or [Form](../form/) for label focus, validation, serialization, and reset.
- **Slot / Separator**: Passive `aria-hidden` readouts indexed by `index` without extra tab stops. While editable and focused, active slot highlights track the real caret or selection range. For split groups around a `Separator`, pass `first` and `last` on group endpoints to round each group cleanly.
- **Events and validation**: Edits emit `valueChange`, and `completed` fires once each time a complete valid code is accepted. Inside a form, `Control` triggers automatic `onChange` validation only after an accepted value change.

### Events & Methods

- **Root events**: `valueChange` (`{ value: string }`), `completed` (`{ value: string }`).
- **Root states & methods**: states `value`, `complete`, `disabled`, `readOnly`, `focused`; methods `requestValue(value)`, `clear()`, `resetValue()`, `focusInput()`.
- **Slot states**: `character`, `active`, `filled`.
