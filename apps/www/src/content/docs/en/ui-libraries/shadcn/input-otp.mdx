## Usage

Currently available from workspace source; not yet included in the 0.2.0 stable release.

### Anatomy

Compose `Input OTP` from `Root`, `Input` (standalone) or `Control` (inside a form), `Slot`, and `Separator`:

- **Root**: Manages `value` / `defaultValue`, `length` (`1`–`32`, default `6`), `pattern` (`'numeric'` or `'alphanumeric'`), `disabled`, `readOnly`, `name`, and `ariaLabel`.
- **Input / Control**: Provides the single underlying text editor, stripping disallowed characters and clamping length after IME composition finishes. Use `Input` standalone, or replace it with `Control` inside a [Field](../field/) or [Form](../form/) for label focus, validation, serialization, and reset.
- **Slot / Separator**: Passive, `aria-hidden` readouts indexed by `index` without extra tab stops. While editable and focused, active slot highlights track the real caret or selection range (clearing on blur, `disabled`, or `readOnly`).

### Events and validation

- In controlled mode (`value` provided), edits emit `valueChange` proposals. `completed` fires once each time a complete valid code is accepted.
- Inside a form, `Control` triggers automatic `onChange` validation only after an accepted value change; rejected or filtered no-op edits skip redundant validation, and reset or unmount cancels queued checks.

## API

Passing `value` selects controlled mode. `Input` accepts an optional `placeholder` with no default.
