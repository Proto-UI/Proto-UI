## Installation

Currently available from workspace source and not yet included in the 0.2.0 stable release; import the prototypes from `@proto.ui/prototypes-shadcn/menubar` and adapt them for your target runtime.

## Usage

```tsx
import {
  ShadcnMenubarRoot,
  ShadcnMenubarTrigger,
  ShadcnMenubarContent,
  ShadcnMenubarItem,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <ShadcnMenubarRoot styleProfile="rhea" a11yLabel="Project commands">
      <ShadcnMenubarTrigger value="file">File</ShadcnMenubarTrigger>
      <ShadcnMenubarContent value="file" a11yLabel="File commands">
        <ShadcnMenubarItem value="new">New Tab</ShadcnMenubarItem>
        <ShadcnMenubarItem value="open">New Window</ShadcnMenubarItem>
        <ShadcnMenubarItem value="delete" variant="destructive">
          Delete
        </ShadcnMenubarItem>
      </ShadcnMenubarContent>
    </ShadcnMenubarRoot>
  );
}
```

### Composition

```text
MenubarRoot
├── MenubarTrigger (value="file")
├── MenubarContent (value="file")
│   ├── MenubarItem
│   └── MenubarItem
├── MenubarTrigger (value="edit")
└── MenubarContent (value="edit")
    └── MenubarItem
```

- `Root` owns the active panel identifier (`value`) and coordinates roving keyboard focus across triggers.
- `Trigger` and `Content` pair through matching `value` props.
- `Item` represents an actionable command with `inset` alignment, `variant="destructive"` styling, and `closeOnSelect={false}` persistence.

### Controlled and uncontrolled

Pass `value` and listen to `valueChange` to control the open panel externally, or pass `defaultValue` for uncontrolled state.

### Keyboard and accessibility

- The bar exposes a single roving `Tab` stop; use `ArrowLeft` and `ArrowRight` to move between triggers.
- Press `ArrowDown` or `ArrowUp` to open a panel and move vertically through items, or type characters for typeahead jump.
- Press `Escape` to close the open panel and return focus to its trigger; outside clicks and command selection also dismiss the panel by default.
