## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

Menubar consists of four parts: `Root`, `Trigger`, `Content`, and `Item`:

- `Root` manages the currently open panel identifier (`value`).
- `Trigger` and `Content` pair via matching `value` props.
- `Item` represents an actionable command inside a panel and supports `inset` alignment as well as `variant="destructive"` styling.

### Controlled and uncontrolled

Pass `value` to control the open panel externally and respond to change requests, or use `defaultValue` for uncontrolled state.

### Keyboard and accessibility

- The bar exposes a single roving `Tab` stop; use `ArrowLeft` and `ArrowRight` to move between triggers.
- Press `ArrowDown` or `ArrowUp` to open a panel and navigate items vertically, or type characters for typeahead jump.
- Press `Escape` to close the open panel and return focus to its trigger; outside clicks and command selection also dismiss the panel.

### Style presets

Switch visual presets with `styleProfile`: `rhea`, `new-york-v4` (alias `new-york`), `vega`, `nova`, `maia`, `lyra`, `mira`, `luma`, and `sera`. Unknown presets are ignored so the active configuration remains intact, and changing presets preserves value, events, and behavior.

Other part defaults:

- `Trigger`: `disabled` defaults to `false`.
- `Content`: `sideOffset` defaults to `4`.
- `Item`: `closeOnSelect` defaults to `true`.
