Scroll Area pairs native host scrolling—wheel, touch, keyboard, inertia, and overscroll—with styled custom scrollbar tracks and thumbs. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

CLI support for this component will be available starting in `0.3.0-rc.1` and later releases. To reproduce the workspace preview in an application before then, build the CLI, Shadcn prototypes and target adapter from the same revision, initialize with that CLI, then generate the facade locally.

<InstallCommandCard command="npm exec -- proto-ui add wc shadcn-scroll-area" manager="npm" />

Replace `wc` with `react`, `vue`, or `vue2` to generate the facade for your target framework.

## Usage

```ts
import {
  ShadcnScrollAreaRoot,
  ShadcnScrollAreaViewport,
  ShadcnScrollAreaScrollbar,
  ShadcnScrollAreaThumb,
} from '@proto.ui/prototypes-shadcn/scroll-area';
```

```html
<proto-ui-shadcn-scroll-area-root class="h-72 w-48 rounded-md border bg-background">
  <proto-ui-shadcn-scroll-area-viewport>
    <div class="p-4">Your scrollable content here.</div>
  </proto-ui-shadcn-scroll-area-viewport>
  <proto-ui-shadcn-scroll-area-scrollbar orientation="vertical">
    <proto-ui-shadcn-scroll-area-thumb></proto-ui-shadcn-scroll-area-thumb>
  </proto-ui-shadcn-scroll-area-scrollbar>
</proto-ui-shadcn-scroll-area-root>
```

### Composition

```text
Root
├── Viewport
└── Scrollbar
    └── Thumb
```

- `Root` provides the outer clipped frame and establishes a `styleProfile` scope without imposing fixed dimensions.
- `Viewport` wraps the scrollable content, joins the `Tab` order only when scrollable overflow exists, and renders an inset focus-visible ring with forced-colors support.
- `Scrollbar` renders a vertical or horizontal track based on `orientation` and hides gracefully when a host selects system scrollbars.
- `Thumb` tracks scroll progress and supports pointer dragging; it stays outside the tab order, hides when there is no overflow, and keeps a visible outline in forced-colors mode.
- When both vertical and horizontal tracks are rendered, they automatically reserve their corner intersection transparently and release that space when either track unmounts.

## API

### Props

All four parts accept `styleProfile` (or inherit it from `Root` / `ShadcnStyleScope`); `orientation` belongs to `Scrollbar`:

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    {
      name: 'orientation (Scrollbar)',
      type: "'vertical' | 'horizontal'",
      default: "'vertical'",
    },
    {
      name: 'styleProfile (all parts)',
      type: "'new-york-v4' | 'vega' | 'nova' | 'maia' | 'lyra' | 'mira' | 'luma' | 'sera' | 'rhea'",
      default: "'new-york-v4'",
    },
  ]}
/>

### Exposed States

- **Viewport**: `focused`, `focusVisible`, `scrollAxes`, `scrolling`, `scrollProjection`, `scrollXPosition`, `scrollXVisibleRatio`, `canScrollLeft`, `canScrollRight`, `scrollYPosition`, `scrollYVisibleRatio`, `canScrollUp`, `canScrollDown`.
- **Scrollbar**: `orientation`.
