A command menu opened at the pointer or trigger via right-click, touch/pen long press, or keyboard shortcuts (`ContextMenu` / `Shift+F10`), with keyboard navigation, typeahead, and collision-aware positioning. The examples on this page use the **Shadcn Rhea** style preset.

## Usage

Currently available from workspace source; not yet included in the 0.2.0 stable release.

### Anatomy

Compose `ContextMenu` from `Root`, `Trigger`, `Content`, and `Item`:

- **Trigger**: Opens on right-click, `ContextMenu` / `Shift+F10`, or a 600 ms touch/pen hold within movement tolerance (moving, releasing, or cancelling aborts the hold; ordinary left clicks and scrolling stay untouched).
- **Content**: Anchors to the pointer point for right-click and long press, and to the trigger region for keyboard or programmatic `openContextMenu` calls. Supports arrow-key navigation, typeahead, and collision flipping.
- **Item**: Executes a menu command and closes the menu by default (set `closeOnItemCommit={false}` to keep it open).

### Controlled state and focus return

- Pass `open` to control visibility externally: an enabled `Trigger` suppresses the browser's native context menu when delivering the open request, while letting your application decide whether to open.
- Dismissing with `Escape` or selecting an item restores focus to the trigger.

## API

Passing `open` selects controlled mode.

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'closeOnItemCommit', type: 'boolean', default: 'true' },
    {
      name: 'openEntry',
      type: "'active-or-first' | 'first' | 'last' | 'value-or-first'",
      default: 'active-or-first',
    },
    { name: 'openEntryValue', type: 'string', default: "''" },
  ]}
/>

These props belong to `Root`. `Content` defaults to `side="bottom"`, `align="start"`, `sideOffset={0}`, `alignOffset={0}`, `avoidCollisions={true}`, `collisionPadding={0}`, and `excludeAnchorTranslation={false}`.
