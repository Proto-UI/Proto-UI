Displays a floating command menu opened via right-click, a 600 ms touch/pen long press, or keyboard shortcuts (`ContextMenu` / `Shift+F10`), with arrow-key navigation, typeahead, and collision-aware positioning. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

This component is currently available from the workspace source and is not yet included in the 0.2.0 stable CLI registry.

## Usage

```tsx
import {
  ShadcnContextMenuContent,
  ShadcnContextMenuItem,
  ShadcnContextMenuRoot,
  ShadcnContextMenuTrigger,
} from '@/components/proto-ui';

export function Example() {
  return (
    <ShadcnContextMenuRoot styleProfile="rhea">
      <ShadcnContextMenuTrigger className="flex h-36 w-72 items-center justify-center rounded-xl border border-dashed text-sm">
        Right click here
      </ShadcnContextMenuTrigger>
      <ShadcnContextMenuContent>
        <ShadcnContextMenuItem value="profile">Profile</ShadcnContextMenuItem>
        <ShadcnContextMenuItem value="billing">Billing</ShadcnContextMenuItem>
        <ShadcnContextMenuItem value="team">Team</ShadcnContextMenuItem>
        <ShadcnContextMenuItem value="subscription">Subscription</ShadcnContextMenuItem>
      </ShadcnContextMenuContent>
    </ShadcnContextMenuRoot>
  );
}
```

### Composition

```text
ContextMenuRoot
├── ContextMenuTrigger
└── ContextMenuContent
    ├── ContextMenuItem
    └── ContextMenuItem
```

- **Triggers and anchoring**: Right-click and a 600 ms touch/pen hold within movement tolerance anchor the menu to the pointer location (moving, releasing, or cancelling aborts the hold; ordinary left clicks and scrolling pass through). Pressing `ContextMenu` / `Shift+F10` or calling `openContextMenu()` anchors to the trigger region.
- **Controlled state and focus return**: Pass `open` to control visibility externally; an enabled trigger suppresses the browser context menu while forwarding the open request. Dismissing with `Escape` or selecting an item restores focus to the trigger.
