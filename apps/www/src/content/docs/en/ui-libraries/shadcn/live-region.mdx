## Installation

Available starting in `0.3.0-rc.1` and later releases. Import `liveRegionRoot` from `@proto.ui/prototypes-shadcn` or `@proto.ui/prototypes-shadcn/live-region` and mount it with your framework adapter:

```ts
import { liveRegionRoot } from '@proto.ui/prototypes-shadcn/live-region';
```

## Usage

```tsx
import { AdaptToReact } from '@proto.ui/adapter-react';
import { liveRegionRoot } from '@proto.ui/prototypes-shadcn/live-region';

const LiveRegionRoot = AdaptToReact(liveRegionRoot);

export function StatusAnnouncement({ message }: { message: string }) {
  return (
    <LiveRegionRoot politeness="polite" atomic>
      {message}
    </LiveRegionRoot>
  );
}
```

`Live Region` consists of a single `Root` part. Your children form the announcement payload — update the rendered text to deliver a new announcement:

- `politeness="polite"` (default): Applies `role="status"` and `aria-live="polite"` for non-interruptive status updates.
- `politeness="assertive"`: Applies `role="alert"` and `aria-live="assertive"` for urgent messages or validation errors.
- `atomic={true}` (default): Sets `aria-atomic="true"` so the entire region is announced together; set `false` to announce only mutated descendant text.
- `Root` applies only readable neutral ink and bounded width (`min-w-0 max-w-full text-foreground`), adds no borders, focus stops, events, or exposes, and pairs cleanly with [Async Region](../async-region/) or form error feedback.
