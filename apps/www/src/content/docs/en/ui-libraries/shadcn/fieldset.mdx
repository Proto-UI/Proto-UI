Groups related form fields under one accessible `group` container, propagates `disabled` down through nested groups, and automatically links its legend and description. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Available starting in `0.3.0-rc.1` and later releases.

## Usage

```tsx
import { FieldsetRoot, FieldsetLegend, FieldsetDescription } from '@/components/shadcn/fieldset';
import { FieldRoot, FieldLabel, FieldControl } from '@/components/shadcn/field';

export function Example() {
  return (
    <FieldsetRoot>
      <FieldsetLegend>Address Information</FieldsetLegend>
      <FieldsetDescription>We need your address to deliver your order.</FieldsetDescription>
      <FieldRoot required>
        <FieldLabel>Street Address</FieldLabel>
        <FieldControl placeholder="123 Main St" />
      </FieldRoot>
    </FieldsetRoot>
  );
}
```

### Anatomy

Compose `Fieldset` from `Root`, `Legend`, and `Description`:

- **Root**: Unboxed vertical flex container (`gap-6` on `rhea`, `vega`, `maia`, `luma`, `sera`, and `new-york-v4`; `gap-4` on `nova`, `lyra`, and `mira`) declaring the `group` role and effective `disabled` policy.
- **Legend**: Optional medium-weight group title supporting `variant="legend"` (default) and `variant="label"`, automatically linked via `aria-labelledby`.
- **Description**: Optional muted help text automatically linked via `aria-describedby`.

Both `Legend` and `Description` are passive and add no tab stops. Provide at most one `Legend` and one `Description` per group (duplicate parts are ignored), and nested groups never borrow each other's labels or descriptions.

### Nested disabled inheritance

Effective `disabled` combines a `Root`'s own `disabled` prop with any enclosing `Fieldset`. For `outer` → `middle` → `inner`:

- Disabling `outer` disables all three.
- Disabling `middle` and then re-enabling `outer` keeps `middle` and `inner` disabled.
- Re-enabling `middle` re-enables `inner` unless `inner` has `disabled={true}`.

Participating [Field](../field/) components inside the group (including any placed inside `Legend`) inherit the effective disabled state automatically. Form submission and reset belong to [Form](../form/).
