Radio Group lets users choose one option from a mutually exclusive set, with full `radiogroup`/`radio` accessibility semantics, roving focus, and focus-ring/disabled styling. The examples on this page use the **Shadcn Rhea** style preset.

## Usage

Import `shadcnRadioGroupRoot`, `shadcnRadioGroupItem`, and `shadcnRadioGroupIndicator` from `@proto.ui/prototypes-shadcn/radio-group` (or the package root) and adapt them to your runtime:

| Part | Props | Responsibility |
| --- | --- | --- |
| `Root` | `value?`, `defaultValue?`, `disabled?`, `readOnly?`, `a11yLabel?` | Manages the selected value and the collection of items. |
| `Item` | `value` (required), `disabled?` | Represents an option, requests selection, and derives checked/disabled states. |
| `Indicator` | None | Optional decorative indicator rendered inside an `Item` when checked. |

### Labeling and accessibility

- Provide a meaningful `a11yLabel` on `Root` and a unique, non-empty `value` on each `Item`.
- Pair each `Item` with `labelRoot` from `@proto.ui/prototypes-shadcn/label` using a shared reference from `createControlLabelRef()` passed via `InstanceAssociations.controlLabel`. The visible label serves as the accessible name and activates the item on click (set `activation={false}` on `Label` for naming only).

### Controlled and uncontrolled

- Uncontrolled mode initializes from `defaultValue` and emits `valueChange` on selection.
- Passing `value` switches to controlled mode: `Root` emits change requests while your app provides the next `value`. Empty or unmatched values are preserved, and a selected item remains checked if it becomes disabled.
- `readOnly` preserves roving focus while preventing value changes; `disabled` removes focus participation as well.

### Keyboard interaction

- Pressing `Tab` focuses the selected enabled `Item`.
- Arrow keys move focus and select while wrapping across enabled items; `Home` and `End` jump to the first and last enabled items, skipping disabled ones.
- `Space` selects the focused item; `Enter` does not.

### Form integration

An ordinary `Root` does not auto-register with a form. Inside `FormField`, use `fieldRadioGroup` from `@proto.ui/prototypes-shadcn/field` to wire up required validation, Label/Description/Error associations, and `resetValue()`. See the [Form choice recipe](../form/) for a full example.

## API

The following props belong to `Root` (pass `value` for controlled mode):

- `Item`: `value` (required), `disabled` (defaults to `false`).
- `Indicator`: no props.
