Radio Group lets users choose one option from a mutually exclusive set, with full `radiogroup` / `radio` accessibility semantics, roving focus, and focus-ring/disabled styling. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

This component is available from workspace source. In your application, install the CLI, Shadcn prototypes and target adapter built from the same workspace revision, then initialize the project with that CLI. Run the locally installed CLI to generate the facade.

<InstallCommandCard command="npm exec -- proto-ui add wc shadcn-radio-group" manager="npm" />

Replace `wc` with `react`, `vue`, or `vue2` to generate the facade for your target framework.

## Usage

```tsx
import {
  ShadcnLabelRoot,
  ShadcnRadioGroupIndicator,
  ShadcnRadioGroupItem,
  ShadcnRadioGroupRoot,
} from '../proto-ui/components/react';

export function RadioGroupUsage() {
  return (
    <ShadcnRadioGroupRoot styleProfile="rhea" defaultValue="option-one" a11yLabel="Options">
      <div className="flex items-center gap-3">
        <ShadcnRadioGroupItem styleProfile="rhea" value="option-one">
          <ShadcnRadioGroupIndicator styleProfile="rhea" />
        </ShadcnRadioGroupItem>
        <ShadcnLabelRoot styleProfile="rhea">Option One</ShadcnLabelRoot>
      </div>
      <div className="flex items-center gap-3">
        <ShadcnRadioGroupItem styleProfile="rhea" value="option-two">
          <ShadcnRadioGroupIndicator styleProfile="rhea" />
        </ShadcnRadioGroupItem>
        <ShadcnLabelRoot styleProfile="rhea">Option Two</ShadcnLabelRoot>
      </div>
    </ShadcnRadioGroupRoot>
  );
}
```

### Composition

```text
RadioGroupRoot
├── RadioGroupItem
│   └── RadioGroupIndicator
└── RadioGroupItem
    └── RadioGroupIndicator
```

- **Labeling**: Provide a meaningful `a11yLabel` on `Root` and a unique, non-empty `value` on each `Item`. Pair each `Item` with `shadcn-label-root` via `createControlLabelRef()` bound to `InstanceAssociations.controlLabel` so the visible label both names and activates the option (set `activation={false}` on `Label` for naming only).
- **Controlled & uncontrolled**: Initialize uncontrolled mode with `defaultValue`, or pass `value` for controlled mode where `Root` emits `valueChange` requests. `readOnly` preserves roving focus while preventing value changes; `disabled` removes items from focus order.
- **Keyboard interaction**: `Tab` focuses the selected enabled `Item`; arrow keys wrap and select across enabled items; `Home` / `End` jump to the first and last enabled items; `Space` selects the focused item (`Enter` does not).
- **Form integration**: Inside `FormField`, use `fieldRadioGroup` from `@proto.ui/prototypes-shadcn/field` to wire up required validation, Label / Description / Error associations, and `resetValue()`. See the [Form choice recipe](../form/).

### Indicator

`Indicator` accepts no props; it derives `checked` and `disabled` state from its enclosing `Item` and renders the selection dot.

### Events & Methods

- **Root events**: `valueChange` (`{ value: string }`)
- **Item events**: `select` (`{ value: string }`)
- **Root methods**: `requestValue(value)`, `resetValue()`, `focusFirst()`, `focusLast()`, `focusNext()`, `focusPrev()`, `focusSelected()`, `focusSelf()`
