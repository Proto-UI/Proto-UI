`Input Shell` separates an input's outer frame (border, background, corner radius, invalid feedback, and optional focus ring) from the editing control inside it. Pair `inputShell` with `inputShellControl` for single-line text inputs, or with `commandInput` inside [Command](/en/ui-libraries/shadcn/command/). Examples on this page use the **Shadcn Rhea** style unless demonstrating another preset.

## Installation

Currently available from workspace source (not yet included in the 0.2.0 stable CLI registry). Import from `@proto.ui/prototypes-shadcn/input-shell` or the package root:

```ts
import {
  inputShell,
  inputShellControl,
  bindInputShellControl,
  INPUT_SHELL_PROJECTED_STYLES,
} from '@proto.ui/prototypes-shadcn/input-shell';
import type {
  InputShellProps,
  InputShellControlProps,
  InputShellControlExposes,
  InputShellOwner,
  InputShellTarget,
  InputShellControlInstance,
} from '@proto.ui/prototypes-shadcn/input-shell';
```

| Export | Responsibility |
| --- | --- |
| `inputShell` (`shadcn-input-shell`) | Passive frame container with a single content slot and no editor or tab stop of its own. |
| `inputShellControl` (`shadcn-input-shell-control`) | Borderless single-line editor inheriting the full [Base Input](/en/ui-libraries/base/input/) protocol. |
| `bindInputShellControl(owner, target, control)` | Syncs the control's `focusVisible` and `disabled` states to the shell with explicit view-lifetime cleanup. |

## Usage

Wrap `inputShell` in an outer [Style Scope](/en/ui-libraries/shadcn/style-scope/) so both the shell and the inner editor inherit the same style preset:

```tsx
<ShadcnStyleScope styleProfile="rhea">
  <ShadcnInputShell focusIndicator="ring">
    <ShadcnInputShellControl ariaLabel="Note title" placeholder="Untitled note" />
  </ShadcnInputShell>
</ShadcnStyleScope>
```

Once the real shell and control instances are mounted, call `bindInputShellControl` to project `focusVisible` and `disabled` onto the shell while preserving authored shell props inside `setFacts`:

```ts
import { setElementProps } from '@proto.ui/adapter-web-component';
import {
  bindInputShellControl,
  type InputShellControlInstance,
  type InputShellOwner,
  type InputShellProps,
} from '@proto.ui/prototypes-shadcn/input-shell';

export function attachShell(
  shell: HTMLElement,
  control: InputShellControlInstance,
  shellProps: InputShellProps = { styleProfile: 'inherit', focusIndicator: 'ring' }
) {
  let current = true;
  const cleanups: VoidFunction[] = [];
  const owner: InputShellOwner = {
    isCurrent() {
      return current;
    },
    onDispose(dispose) {
      cleanups.push(dispose);
      return function remove() {
        const index = cleanups.indexOf(dispose);
        if (index >= 0) cleanups.splice(index, 1);
      };
    },
  };

  bindInputShellControl(
    owner,
    {
      instance: shell,
      setFacts(facts) {
        setElementProps(shell, { ...shellProps, ...facts });
      },
    },
    control
  );

  return function detach() {
    if (!current) return;
    current = false;
    for (const dispose of cleanups.splice(0)) dispose();
  };
}
```

Key guidelines:

- **Merge authored shell props on every update**: Keep `styleProfile`, `focusIndicator`, and `invalid` inside `setFacts` so prop writes never clear them.
- **Keep interaction props on the control**: Set `disabled`, `readOnly`, and accessible naming (`ariaLabel` / `labelledBy` / `describedBy`) on the inner control, and place exactly one inline editor inside each shell. For a standalone input, use [Input](/en/ui-libraries/shadcn/input/).
- **Binding lifecycle**: At most one active binding may reserve a shell or control at a time. The returned handle exposes `sync()`, `replace(nextControl)`, and an idempotent `dispose()`; unmounting or a control `disconnect` event retires the binding automatically.

### Switching style presets

Both parts default to `styleProfile="inherit"` (local override → nearest `Style Scope` → `new-york-v4`; `new-york` normalizes to `new-york-v4`) and map all 9 Shadcn style presets. Switching the outer scope preserves the editor node, value, selection, and focus:

| Preset | Outer `inputShell` | Inner `inputShellControl` |
| --- | --- | --- |
| `rhea` | `h-8`, theme `radius-2xl`, transparent resting border, `bg-input/50`, 200ms transition; focus `border-ring ring-3 ring-ring/30`. | `h-8`, `px-2.5 py-1`, transparent borderless editor. |
| `new-york-v4` / `new-york` | `h-9`, `rounded-md`, `border-input`, `shadow-xs` (`bg-input/30` in dark mode); focus `border-ring ring-3 ring-ring/50`. | `h-9`, `px-3 py-1`, transparent borderless editor. |
| `vega` | `h-9`, `rounded-md`, `border-input`, `shadow-xs` (`bg-input/30` in dark mode); focus `border-ring ring-3 ring-ring/50`. | `h-9`, `px-2.5 py-1`. |

| `lyra` | `h-8`, `rounded-none`, `border-input` (disabled `bg-input/50`, dark `bg-input/80`); focus `border-ring ring-1 ring-ring/50`. | `h-8`, `px-2.5 py-1`, `text-xs`. |
| `mira` | `h-7`, `rounded-md`, `border-input`, `bg-input/20`; focus `border-ring ring-2 ring-ring/30`. | `h-7`, `px-2 py-0.5`, `text-sm`. |
| `luma` | `h-9`, theme `radius-4xl`, transparent resting border, `bg-input/50`; focus `border-ring ring-3 ring-ring/30`. | `h-9`, `px-3 py-1`. |
| `sera` | `h-10`, `rounded-none`, bottom border `border-b-input`; focus `border-b-ring`. | `h-10`, `px-0 py-1`. |

Body text tightens automatically at `viewport.width >= 768`. Disabled opacity (`opacity-50`) is applied solely by the inner control so the shell never double-dims, while the shell applies `cursor-not-allowed` (plus disabled surface tinting on `nova` and `lyra`).

`InputShellControlExposes` preserves the full `InputRootExposes` surface from [Base Input](/en/ui-libraries/base/input/):

- **State**: `value`, `disabled`, `readOnly`, `focused`, `focusVisible`, `composing`.
- **Methods**: `focusSelf(options?)`, `blurSelf()`, `resetValue(value?: string): boolean`.
- **Events**: `valueChange`, `change`, `compositionStart`, `compositionUpdate`, `compositionEnd`.

### `bindInputShellControl(owner, target, control)`

Returns `{ sync(), replace(nextControl), dispose() }` to project control facts onto the passive shell across the view lifetime and cleanly release all subscriptions on replacement or unmount.
