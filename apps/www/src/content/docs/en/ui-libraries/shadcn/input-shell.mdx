`Input Shell` separates an input’s outer frame (border, background, radius, and optional focus ring) from the editing control inside it. Pair `inputShell` with `inputShellControl` for ordinary single-line text inputs, or with `commandInput` inside `Command`.

## Installation and imports

Currently available from workspace source; not yet included in the 0.2.0 stable release.

Import from `@proto.ui/prototypes-shadcn/input-shell` (or the package root):

```ts
import {
  inputShell,
  inputShellControl,
  bindInputShellControl,
  INPUT_SHELL_PROJECTED_STYLES,
} from '@proto.ui/prototypes-shadcn/input-shell';
import type {
  InputShellProps,
  InputShellControlProps,
  InputShellControlExposes,
  InputShellOwner,
  InputShellTarget,
  InputShellControlInstance,
} from '@proto.ui/prototypes-shadcn/input-shell';
```

| Export | Responsibility |
| --- | --- |
| `inputShell` (`shadcn-input-shell`) | Passive frame container with a single content slot and no editor or tab stop of its own. |
| `inputShellControl` (`shadcn-input-shell-control`) | Borderless single-line editor inheriting the full [Base Input](/en/ui-libraries/base/input/) protocol. |
| `bindInputShellControl(owner, target, control)` | Syncs the control’s `focusVisible` and `disabled` states to the shell with explicit view-lifetime cleanup. |

## Usage

### Composing a standard text input

Wrap `inputShell` in an outer [Style Scope](/en/ui-libraries/shadcn/style-scope/) so both the shell and the editor inherit the same preset (setting `styleProfile` directly on `inputShell` only styles the shell itself). Example in Web Components:

```ts
import { AdaptToWebComponent, setElementProps } from '@proto.ui/adapter-web-component';
import { styleScope } from '@proto.ui/prototypes-shadcn/style-scope';
import {
  inputShell,
  inputShellControl,
  bindInputShellControl,
  type InputShellProps,
  type InputShellOwner,
} from '@proto.ui/prototypes-shadcn/input-shell';

const Scope = AdaptToWebComponent(styleScope);
const Shell = AdaptToWebComponent(inputShell);
const Control = AdaptToWebComponent(inputShellControl);

export function mountTitleInput(host: HTMLElement) {
  const scope = new Scope();
  const shell = new Shell();
  const control = new Control();
  const shellProps: InputShellProps = {
    styleProfile: 'inherit',
    focusIndicator: 'ring',
  };

  setElementProps(scope, { styleProfile: 'rhea' });
  setElementProps(shell, shellProps);
  setElementProps(control, {
    ariaLabel: 'Note title',
    placeholder: 'Untitled note',
    defaultValue: '',
  });
  shell.append(control);
  scope.append(shell);
  host.append(scope);

  let current = true;
  const disposers = new Set<() => void>();
  const owner: InputShellOwner = {
    isCurrent: () => current,
    onDispose(dispose) {
      disposers.add(dispose);
      return () => {
        disposers.delete(dispose);
      };
    },
  };

  bindInputShellControl(
    owner,
    {
      instance: shell,
      setFacts(facts) {
        setElementProps(shell, { ...shellProps, ...facts });
      },
    },
    control
  );

  return () => {
    if (!current) return;
    current = false;
    try {
      for (const dispose of [...disposers]) dispose();
    } finally {
      disposers.clear();
      scope.remove();
    }
  };
}
```

Key guidelines:

- **Merge existing shell props on every update**: Because `setElementProps` replaces the full prop object, merge `shellProps` inside `setFacts` to preserve `styleProfile` and `focusIndicator`.
- **Keep interaction props on the control**: Set `disabled`, `readOnly`, and accessible naming (`ariaLabel` / `labelledBy` / `describedBy`) on the inner control, and place exactly one inline editor inside each shell. For a standalone input, use [Input](/en/ui-libraries/shadcn/input/).

### Style presets

Both parts default to `styleProfile="inherit"` (local override → nearest `Style Scope` → `new-york-v4`; `new-york` normalizes to `new-york-v4`). Switching presets preserves the editor element, value, selection, and focus:

| Preset | Outer `inputShell` | Inner `inputShellControl` |
| --- | --- | --- |
| `new-york-v4` / `new-york` | `h-9`, `rounded-md`, `border-input`, `shadow-xs` (`bg-input/30` in dark mode); keyboard focus uses `border-ring ring-3 ring-ring/50`. | `h-9`, `px-3 py-1`, borderless and ringless inner surface. |
| `rhea` | `h-8`, theme `radius-2xl`, transparent resting border, `bg-input/50`, 200ms transition; keyboard focus uses `border-ring ring-3 ring-ring/30`. | `h-8`, `px-2.5 py-1`, transparent borderless inner surface. |

Both presets switch body text to small at `viewport.width >= 768`, and disabled opacity is applied solely by the editor so the shell does not double-dim it.

### Composing with Command

Inside [Command](/en/ui-libraries/shadcn/command/), keep `commandInput` rather than switching to `inputShellControl`. Place the shell inside `commandInputWrapper`, bind `commandInput` with `bindInputShellControl`, and set `focusIndicator="none"`.

### Binding lifecycle

- Call `bindInputShellControl` only after the real shell and control instances exist, with at most one active binding per shell or control.
- The returned handle exposes `sync()`, `replace(nextControl)`, and an idempotent `dispose()`. Unmounting or a control `disconnect` event retires the binding automatically so stale writes never occur.

## API

### `inputShell` props

| Prop             | Type                            | Default     |
| ---------------- | ------------------------------- | ----------- |
| `styleProfile`   | `ShadcnStyleChoice`             | `'inherit'` |
| `focusVisible`   | `boolean` (synced from control) | `false`     |
| `disabled`       | `boolean` (synced from control) | `false`     |
| `focusIndicator` | `'ring' \| 'none'`              | `'ring'`    |

### `inputShellControl` props, state, and events

`InputShellControlProps` is `InputRootProps & ShadcnStyleProps` and `InputShellControlExposes` is `InputRootExposes`, preserving the full [Base Input](/en/ui-libraries/base/input/) surface:

- **Props**: `value`, `defaultValue`, `disabled`, `readOnly`, `placeholder`, `required`, `name`, `autoComplete`, `minLength`, `maxLength`, `inputMode`, `enterKeyHint`, `ariaLabel`, `labelledBy`, `describedBy`.
- **State and methods**: `value`, `disabled`, `readOnly`, `focused`, `focusVisible`, `composing`, plus `focusSelf()` and `blurSelf()`.
- **Events**: `valueChange`, `change`, `compositionStart`, `compositionUpdate`, `compositionEnd`.
