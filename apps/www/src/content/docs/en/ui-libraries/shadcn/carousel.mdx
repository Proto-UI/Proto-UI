## Usage

```tsx
import {
  ShadcnCarouselRoot,
  ShadcnCarouselViewport,
  ShadcnCarouselSlide,
  ShadcnCarouselPrevious,
  ShadcnCarouselNext,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <ShadcnCarouselRoot styleProfile="rhea" className="mx-auto w-full max-w-xs">
      <ShadcnCarouselViewport>
        <ShadcnCarouselSlide>1</ShadcnCarouselSlide>
        <ShadcnCarouselSlide>2</ShadcnCarouselSlide>
        <ShadcnCarouselSlide>3</ShadcnCarouselSlide>
      </ShadcnCarouselViewport>
      <ShadcnCarouselPrevious aria-label="Previous slide">‹</ShadcnCarouselPrevious>
      <ShadcnCarouselNext aria-label="Next slide">›</ShadcnCarouselNext>
    </ShadcnCarouselRoot>
  );
}
```

### Composition

```text
CarouselRoot
├── CarouselViewport
│   ├── CarouselSlide
│   └── CarouselSlide
├── CarouselPrevious
└── CarouselNext
```

- **Responsive viewport and snapping**: `slidesPerView` caps the maximum equal-sized slides shown at once (default `1`), while `minSlideSize` sets the minimum logical pixel extent per slide (default `0`). Narrowing the viewport reduces visible capacity automatically, and the final snap aligns flush with the strip end.
- **Keyboard and accessibility**: While the viewport is focused, use `ArrowLeft` / `ArrowRight` (`ArrowUp` / `ArrowDown` in vertical mode), `Home`, and `End` to navigate. Always supply an accessible name via `sr-only` text or `aria-label` on icon-only navigation buttons.
- **Controlled index**: Pass `index` and listen to `indexChange` to own the committed snap position externally. Live drag previews never overwrite the committed index prematurely.

### Exposed states, methods, and events

- **Root**: states `index`, `slideCount`, `visibleSlides`, `maxIndex`; method `requestIndex(next)`; event `indexChange` (`{ index }`).
- **Viewport**: states `focusVisible`, `dragging`, `scrolling`, `scrollPosition`.
- **Slide**: states `current`, `hidden`, `basis`, `minSize`.
