## Usage

Currently available from workspace source; not yet included in the 0.2.0 stable release.

### Responsive viewport and snapping

- Set `slidesPerView` on `Root` for the maximum equal-sized slides to display (default `1`), and `minSlideSize` for the minimum slide extent in logical pixels (default `0`). Narrowing the viewport reduces visible capacity automatically while allowing partial peeks.
- Pointer or touch dragging moves the strip live; releasing or finishing native scroll snaps to the nearest reachable boundary. The final snap aligns flush with the strip end without trailing whitespace.
- Read `visibleSlides` and `maxIndex` from `Root` to inspect the live viewport capacity.

### Controlled and uncontrolled index

- Pass `index` to control the active snap position externally; `indexChange` emits proposed indexes. While dragging, the committed `index` remains unchanged until release and either adopts the synchronous update or returns to the committed position.
- `Viewport` exposes `dragging`, `scrolling`, and normalized `scrollPosition`. Each `Slide` exposes `current` and offscreen `hidden` (keeping its layout box intact).

### Orientation and looping

- When using `orientation="vertical"`, give the viewport container an explicit height.
- In horizontal mode, `direction="rtl"` reverses physical dragging and Left/Right arrow keys while preserving logical slide order.
- Setting `loop={true}` wraps index requests between the first and last reachable positions without cloning slide nodes.

## API

Passing `index` selects controlled mode. `Viewport` takes no props; omitting `Slide`'s `index` uses its document order.
