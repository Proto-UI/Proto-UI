Ordinary demos on this page explicitly use **Shadcn Rhea**, with matching examples. This does not change public compatibility defaults or imply complete browser, native-host or visual acceptance. Neutral Surface/Text atoms retain their own public semantics; the consumer composition supplies the family presentation theme.

Calendar is a single-date Gregorian control. `value` uses YYYY-MM-DD; the canonical visible `month` uses YYYY-MM. Selection and month can each be controlled. A successful `requestMonth` means a proposal was emitted, not that the owner accepted it. Refused or pending cross-month keyboard navigation keeps the current valid Tab entry; accepted navigation materializes and focuses only after canonical month changes and current availability is checked. Focus is not stolen back from an external control.

## Composition and clock ownership

The ten atoms are Root, Caption, Heading, Previous, Next, Grid, Weekdays, Weekday, Row and Day. Compose seven Weekday atoms with offsets 0–6 inside Weekdays, then optionally retain six indexed Rows (`index` 0–5) of Day atoms with offsets 0–41 as capacity. By default the canonical month displays the minimum complete 4, 5 or 6 weeks; Root `fixedWeeks=true` explicitly reserves six. Root exposes `weekCount`; indexed unused Rows and unused offset Days expose `hidden` and are hidden/disabled off the focus path. Unindexed rows and explicit dates remain application-authored. Weekday labels and date order follow Root `weekStartsOn` (0 = Sunday) and `locale`; full localized civil dates name the grid cells. `direction="rtl"` mirrors Left/Right navigation, leaving Up/Down and week boundaries unchanged. Navigation controls accept `a11yLabel` for icon-only accessible naming.

The host supplies `today` as a civil-date string. Base never reads a clock or timezone: no `today` means no current-date marker. Today and selected are independent, including unavailable dates; today projects `aria-current="date"`. Initial month priority is explicit `month`, explicit `defaultMonth`, selected `value`/`defaultValue`, supplied `today`, then deterministic 1970-01. Later clock updates do not silently navigate. `unavailable` is a string array; invalid inputs retain their prior valid value/default. Root disabled combines with local Day/Previous/Next disabled policy; readOnly blocks selection while allowing browsing.

## Explicit month/year caption composition

The demo uses real family Select controls and `bindCalendarCaption(source, {month, year})` through public Calendar month/disabled state and `requestMonth`. Caption itself is only a semantic group. Month and year selectors are application composition, not an internal Calendar Select dependency. The helper always restores canonical control values after rejection or pending acceptance, subscribes to later commits, and exposes `dispose()` for teardown. The demo owns an explicit year option list (not a Calendar limit), local-clock today, midnight/visibility refresh and complete controlled prop records. The Month and Year triggers pass stable names through the public Select `accessibleLabel` prop; Select Value independently displays the current month or year. The demo does not write Adapter-owned ARIA attributes. Computed accessible names, name stability after selection, keyboard interaction and focus return still require current-source browser evidence; screen-reader acceptance remains separate.

The Shadcn demo restores the upstream example’s current-year-minus-100 through current-year list (101 options), without truncating it to disguise collection cost. Other families retain an explicitly application-chosen ±10-year sample. Caption month labels use the host’s `Intl` short-month format by default; `createCalendarDemo(family, {captionLocale})` can choose that host boundary separately from English weekday labels. The user’s Chinese month / English weekday example can therefore be composed explicitly. Our family Select popup is not the official page’s native-select popup and is not claimed to match native platform pixels.

The page selects Rhea's 32px date/navigation cells (`h-8 w-8`) and `p-3` layout at a 16px root font, from the [Rhea style source](https://github.com/shadcn-ui/ui/blob/3d98900e9b73c45f035f8109e9d41ba6a51685e7/apps/v4/registry/styles/style-rhea.css). The separate [base-nova registry](https://ui.shadcn.com/r/styles/base-nova/calendar.json), observed on 2026-10-10, retains its 28px/p-2 compatibility recipe. Neither recipe is enlarged merely to match a screenshot. Actual focus and selection remain independent Base facts; this is not complete react-day-picker compatibility or native visual acceptance.
