## Usage

Currently available from workspace source; not yet included in the 0.2.0 stable release.

### Anatomy

Compose `Calendar` from ten parts: `Root`, `Caption`, `Heading`, `Previous`, `Next`, `Grid`, `Weekdays`, `Weekday`, `Row`, and `Day`:

- Place seven `Weekday` parts (`offset` `0`–`6`) inside `Weekdays`, and up to six indexed `Row` parts (`index` `0`–`5`) containing `Day` cells (`offset` `0`–`41`).
- By default, `Calendar` renders the minimum 4, 5, or 6 complete weeks needed for the visible month; set `fixedWeeks={true}` to always render six rows. Unused rows and cells are hidden and excluded from focus. Read the active row count from `Root`'s `weekCount`.
- Weekday labels and column order follow `weekStartsOn` (`0` = Sunday) and `locale`. Each day cell receives a full localized civil date as its accessible name.
- Pass `a11yLabel` to `Previous` and `Next` when rendering icon-only navigation buttons. `direction="rtl"` mirrors Left/Right arrow navigation while preserving vertical and week-boundary behavior.

### Selection modes

| Mode       | Controlled / initial value                    | Change event                 |
| ---------- | --------------------------------------------- | ---------------------------- |
| `single`   | `value` / `defaultValue`: `YYYY-MM-DD` string | `onValueChange({ value })`   |
| `multiple` | `values` / `defaultValues`: date array        | `onValuesChange({ values })` |
| `range`    | `range` / `defaultRange`: `{ from?, to? }`    | `onRangeChange({ range })`   |

- **Multiple mode**: Activating a day toggles it in a deduplicated, ascending-sorted array. Use `minSelected` (default `0`) and `maxSelected` to constrain the count; `requestValues(dates)` validates the entire array against both bounds.
- **Range mode**: The first selection sets `{ from }`, the second completes an inclusive `{ from, to }` (automatically ordering reversed endpoints), and a subsequent click starts a new range. Pass `{}` to clear. `minNights` (default `0`, allowing single-day ranges) and `maxNights` constrain the number of days between endpoints.
- **Range states**: `Day` exposes `rangeStart`, `rangeEnd`, `rangeMiddle`, and `rangePending` alongside `selected`. `Grid` automatically sets `aria-multiselectable` in `multiple` and `range` modes.

### Availability and `today`

- `min`, `max`, and `Root`'s `unavailable` array apply to all selected dates; completing a range across an unavailable date is rejected while keeping the start anchor. Local `Day` `disabled` disables only that cell. `Root`'s `readOnly` blocks selection changes while allowing month browsing.
- `Calendar` does not read the system clock directly: pass a `YYYY-MM-DD` `today` string from your host to mark the current date with `aria-current="date"`.
- Initial visible month precedence: `month` → `defaultMonth` → active selection → `today` → `1970-01`.

### Controlled month and caption pickers

- Selection (`value` / `values` / `range`) and the visible `month` (`YYYY-MM`) can be controlled independently.
- `Root` exposes `requestValue(date)`, `requestValues(dates)`, `requestRange(range)`, `requestMonth(month)`, `getValues()`, `getRange()`, `mode`, `selectedCount`, and `rangeComplete`.
- To wire month and year dropdowns into `Caption`, compose `Select` with `bindCalendarCaption(source, { month, year })` (and call `dispose()` on cleanup). Pass `accessibleLabel` to the month and year `Select` triggers so their accessible names stay stable as values change.
- The Shadcn Rhea preset uses 32px (`h-8 w-8`) day and navigation buttons with `p-3` padding and an independent focus ring over `selected`.

## API

Passing `value`, `values`, `range`, or `month` controls the corresponding state. Omitting `today` hides the current-date marker.
