A Gregorian calendar component supporting `single`, `multiple`, and `range` date selection, localized weekday headers, RTL keyboard navigation, and composable month/year pickers. The examples on this page use the **Shadcn Rhea** style preset.

## Usage

```tsx
import {
  CalendarRoot,
  CalendarCaption,
  CalendarPrevious,
  CalendarHeading,
  CalendarNext,
  CalendarGrid,
  CalendarWeekdays,
  CalendarWeekday,
  CalendarRow,
  CalendarDay,
} from '@proto.ui/prototypes-shadcn/calendar';

export function ExampleCalendar() {
  return (
    <CalendarRoot
      styleProfile="rhea"
      mode="single"
      defaultMonth="2026-10"
      defaultValue="2026-10-12"
      today="2026-10-08"
      className="rounded-lg border border-border"
    >
      <CalendarCaption>
        <CalendarPrevious a11yLabel="Previous month" />
        <CalendarHeading />
        <CalendarNext a11yLabel="Next month" />
      </CalendarCaption>
      <CalendarGrid>
        <CalendarWeekdays>
          {Array.from({ length: 7 }, (_, offset) => (
            <CalendarWeekday key={offset} offset={offset} />
          ))}
        </CalendarWeekdays>
        {Array.from({ length: 6 }, (_, row) => (
          <CalendarRow key={row} index={row}>
            {Array.from({ length: 7 }, (_, col) => (
              <CalendarDay key={col} offset={row * 7 + col} />
            ))}
          </CalendarRow>
        ))}
      </CalendarGrid>
    </CalendarRoot>
  );
}
```

### Anatomy and keyboard navigation

- Compose `Calendar` from ten parts: `Root`, `Caption`, `Heading`, `Previous`, `Next`, `Grid`, `Weekdays`, `Weekday`, `Row`, and `Day`.
- By default, `Calendar` renders the minimum 4–6 complete weeks for the visible month; pass `fixedWeeks={true}` to always show six rows. Unused rows and cells hide automatically off the focus path.
- Arrow keys navigate continuously across months, `Home`/`End` jump to week boundaries, and `PageUp`/`PageDown` move by month (`Shift` by year). `direction="rtl"` mirrors Left/Right arrows automatically.
- `Calendar` never reads the system clock directly: pass a client-resolved `YYYY-MM-DD` `today` string to mark the current date (`aria-current="date"`) without SSR timezone hydration drift.
- Pair with `Date Picker` to build a popover date input, or connect family `Select` dropdowns to the caption using `bindCalendarCaption(source, { month, year })` (and call `dispose()` on cleanup).

### Selection modes

| Mode       | Controlled / initial value                      | Change event                 |
| ---------- | ----------------------------------------------- | ---------------------------- |
| `single`   | `value` / `defaultValue`: `YYYY-MM-DD`          | `onValueChange({ value })`   |
| `multiple` | `values` / `defaultValues`: `readonly string[]` | `onValuesChange({ values })` |
| `range`    | `range` / `defaultRange`: `{ from?, to? }`      | `onRangeChange({ range })`   |

### Events, methods, and exposed states

- **Events (Root)**: `onValueChange({ value })`, `onValuesChange({ values })`, `onRangeChange({ range })`, `onMonthChange({ month })`.
- **Methods (Root)**: `requestValue(date)`, `requestValues(dates)`, `requestRange(range)`, `requestMonth(month)`, `getValues()`, `getRange()`.
- **Exposed states**: Root exposes `value`, `mode`, `selectedCount`, `rangeComplete`, `month`, `weekCount`, `disabled`, `direction`; Day exposes `date`, `selected`, `rangeStart`, `rangeEnd`, `rangeMiddle`, `rangePending`, `today`, `outside`, `disabled`, `hidden`.
