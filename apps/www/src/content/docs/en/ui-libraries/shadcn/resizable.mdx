## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototypes directly from `@proto.ui/prototypes-shadcn/resizable` and adapt them for your target runtime:

```ts
import {
  resizableRoot,
  resizablePanel,
  resizableHandle,
} from '@proto.ui/prototypes-shadcn/resizable';
```

## Usage

```tsx
import {
  ShadcnResizableRoot,
  ShadcnResizablePanel,
  ShadcnResizableHandle,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <ShadcnResizableRoot
      orientation="horizontal"
      defaultSizes={[50, 50]}
      className="h-56 max-w-md rounded-lg border border-border overflow-hidden"
    >
      <ShadcnResizablePanel index={0}>One</ShadcnResizablePanel>
      <ShadcnResizableHandle index={0} withHandle />
      <ShadcnResizablePanel index={1}>Two</ShadcnResizablePanel>
    </ShadcnResizableRoot>
  );
}
```

### Composition

Proto UI's `resizableRoot`, `resizablePanel`, and `resizableHandle` correspond to upstream shadcn/ui's `ResizablePanelGroup`, `ResizablePanel`, and `ResizableHandle`:

```text
ResizableRoot
├── ResizablePanel (index: 0)
├── ResizableHandle (index: 0)
└── ResizablePanel (index: 1)
```

- Place `N` `Panel` elements (`index: 0..N-1`) and `N - 1` `Handle` elements (`index: 0..N-2`). Each `Handle` resizes only its adjacent pair while preserving their combined size and every other panel.
- Each `Panel` exposes its dimensionless percentage through `--pui-size` for static `flex-basis` layout rules. Drag deltas normalize against panel extents, excluding fixed handle widths.
- Pass `constraints` for per-panel `min` (`0`), `max` (`100`), `collapsible` (`false`), and `collapsedSize` (`0`). Pass `sizes` for controlled mode and handle `sizesChange` / `sizesCommit`.
- Supports arrow keys, `Shift` 10× acceleration, `Home` / `End`, and `Enter` collapse toggles. Each `Handle` defaults its accessible name to `Resize panels`.

### Panel & Handle

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}

    { name: 'Panel.index', type: 'number', default: '0' },
    { name: 'Panel.styleProfile', type: 'ShadcnStyleId', default: "'new-york-v4'" },

- **Exposed states**: Root exposes `value` and `sizes`; Panel exposes `size`; Handle exposes `value`, `focusVisible`, and `disabled`.
- **Events**: Root emits `sizesChange` / `sizesCommit` (`{ sizes }`) and legacy two-panel `valueChange` / `valueCommit` (`{ value }`). Cancelled drags emit no `*Commit`.
- **Methods**: Root exposes `requestResize(index, next, commit?)`, `requestSizes(next, commit?)`, `requestValue(next, commit?)`, and `cancelResize()`.
