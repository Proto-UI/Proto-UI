Resizable composes two ratio-sized panels with one focusable separator. value is the first panel percentage; min/max, collapse, controlled updates, arrow keys, Home/End and Shift acceleration share one request path. Pointer input uses the shared dimensionless Axis Input host capability.

This is a WIP source checkpoint. Full Adapter/Compiler, native GPUI, package consumer, accessibility and commit-bound visual acceptance remain pending.

Panel exposes its dimensionless size through the existing exposed-state projection. Web CSS uses a static flex-basis recipe consuming --pui-size, so arbitrary ratios do not depend on runtime-generated CSS tokens.

## API

Resizable is workspace source. There is no public `proto-ui add` target. Passing `value` selects controlled mode. The anatomy requires two panels and one handle. Handle has no props; its accessible name is `Resize panels`.
