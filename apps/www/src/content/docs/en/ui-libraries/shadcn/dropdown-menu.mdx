A trigger-opened command menu built on Base semantics with keyboard navigation, accessible group labeling, destructive styling, and inset alignment. The examples on this page use the **Shadcn Rhea** style preset.

## Preview

The default demo shows grouped actions, labels, keyboard shortcut hints, and a disabled item:

<PrototypePreviewer demoId="demo-shadcn-dropdown-menu" initialRuntime="wc" />

### Destructive actions

Following the `DropdownMenuWithDestructive` pattern, items pair 16px Lucide icons with `variant="destructive"` on Delete (10% tint in light mode, 20% in dark mode). The trailing **Delete (disabled)** row demonstrates focusable-disabled behavior without selecting or closing the menu.

<PrototypePreviewer demoId="demo-shadcn-dropdown-destructive" initialRuntime="wc" />

### Inset alignment

Following `DropdownMenuWithInset`, set `inset={true}` on iconless `Item` or `Label` rows to align their text with icon-bearing siblings:

- **Shadcn Rhea**: `8px` horizontal padding when `inset={false}`; `28px` left / `8px` right when `inset={true}`.
- **New York compatibility preset**: `0.5rem` horizontal padding when `inset={false}`; physical-left `2rem` / right `0.5rem` when `inset={true}`.

Use **Toggle inset** in the demo and reopen the menu to compare both states.

<PrototypePreviewer demoId="demo-shadcn-dropdown-inset" initialRuntime="wc" />

## Installation

<InstallCommandCard command="npx @proto.ui/cli@latest add wc shadcn-dropdown" manager="npm" />

Replace `wc` with `react`, `vue`, or `vue2` to generate the facade for your framework. Note that the CLI registry ID is `shadcn-dropdown`.

The CLI target generates facades for `Root`, `Trigger`, `Content`, and `Item`. Import `Group`, `Label`, `Separator`, and `Shortcut` directly from `@proto.ui/prototypes-shadcn/dropdown`.

## Usage

- **Groups and passive parts**: `Group` and `Label` maintain an accessible group-naming relation automatically; `Separator` and `Shortcut` are passive visual parts (`Shortcut` displays a text hint without registering global keybindings).
- **Demo sources**: [My Account](https://github.com/Proto-UI/Proto-UI/blob/main/apps/www/src/content/docs/zh-cn/demo-shadcn-dropdown-menu.demo.ts), [destructive actions](https://github.com/Proto-UI/Proto-UI/blob/main/apps/www/src/content/docs/demo-shadcn-dropdown-destructive.demo.ts), and [inset actions](https://github.com/Proto-UI/Proto-UI/blob/main/apps/www/src/content/docs/demo-shadcn-dropdown-inset.demo.ts).
- **Note**: Submenus and checkbox/radio items are planned for a future update.
