## Usage

Single-value Slider consists of `Root`, `Label`, `Track`, `Indicator`, `Thumb`, `FieldThumb`, and `Value`:

- `Root` manages the numeric value, bounds (`min`/`max`), `step`, orientation, direction, and interactive state.
- `Track` handles pointer and touch dragging; `Thumb` is the focusable slider control supporting arrow keys, `Shift` (10× step), `PageUp`/`PageDown`, and `Home`/`End` (horizontal `rtl` reverses left/right keys).
- Values clamp to `[min, max]` and snap to `step` from `min`. In controlled mode, interactions emit `valueChange` without overwriting your value directly; `valueCommit` fires on completion, and canceling restores the starting value in uncontrolled mode.
- `disabled` dims the control and disables interaction; `readOnly` keeps focus and hover feedback while preventing value edits.

### Form integration

Inside `Field` or `FormField`, use `FieldThumb` instead of `Thumb` to wire up `FieldLabel` activation, numeric validation, serialization, and reset. Use `SliderLabel` with standalone `Thumb`.

### Range and multiple values

For range selection or multiple thumbs, import the six `sliderValues*` entries from `@proto.ui/prototypes-shadcn/slider`:

<PrototypePreviewer

- Pass an array via `defaultValue={[20, 80]}` (or controlled `value`) on Values `Root`, and render one indexed `Thumb` per value inside Values `Track`.
- Clicking the track moves the nearest editable thumb, while grabbing a thumb off-center preserves the grab offset. Configure `thumbCollisionBehavior` as `push`, `swap` (which moves focus along with the swapped thumb), or `none`.
- A complete Values `Root` also works as a grouped `Field`/`FormField` control reporting `number[]`, with `FieldLabel` focusing the first editable thumb.
