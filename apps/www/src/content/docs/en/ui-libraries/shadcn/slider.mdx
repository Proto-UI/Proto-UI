Slider lets users select a single value or multiple range values along a continuous track using pointer drag, touch, or keyboard navigation. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import scalar slider parts and multi-value `sliderValues*` parts from `@proto.ui/prototypes-shadcn/slider`.

## Usage

```tsx
import {
  ShadcnSliderRoot,
  ShadcnSliderTrack,
  ShadcnSliderIndicator,
  ShadcnSliderThumb,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <ShadcnSliderRoot defaultValue={33} min={0} max={100} step={1}>
      <ShadcnSliderTrack>
        <ShadcnSliderIndicator />
        <ShadcnSliderThumb />
      </ShadcnSliderTrack>
    </ShadcnSliderRoot>
  );
}
```

- **Anatomy**: Single-value Slider composes `Root`, `Label`, `Track`, `Indicator`, `Thumb`, `FieldThumb`, and `Value`; multi-thumb range sliders use the six `sliderValues*` entries.
- **Pointer and keyboard**: `Track` handles mouse and touch dragging; `Thumb` supports arrow keys, `Shift` (10× step), `PageUp`/`PageDown`, and `Home`/`End` (horizontal `rtl` mirrors Left/Right).
- **Controlled state**: Pass `value` for controlled mode. Interactions emit `valueChange` proposals and fire `valueCommit` on completion; cancelling restores the starting value in uncontrolled mode.
- **Form integration**: Inside `Field` or `FormField`, replace `Thumb` with `FieldThumb` to connect `FieldLabel` focusing, numeric validation, serialization, and reset. A complete `Values Root` integrates directly as a grouped `number[]` control.
