Message Scroller is designed for chat feeds and live logs, automatically following newly appended messages when the reader is at the bottom and letting them jump back to the latest entry on demand. The examples on this page use the **Shadcn Rhea** style preset.

## Usage

Message Scroller consists of `Root`, `Viewport`, and `Jump`:

- Newly appended items scroll into view automatically while the reader stays at the end of the list.
- When the reader scrolls up into history, auto-follow pauses; clicking `Jump` explicitly resumes at the latest item without stealing focus.
- Pass `newContentCount` from your application state to display new-item indicators rather than inferring unread state automatically.
- Use `a11yLabel` on `Root` to name the scrollable region (defaults to `Messages`).

### Stable-key position and selection restoration

To restore reading position by stable key or preserve text selection across updates, compose the public Base `asMessageScrollerReading` hook after the Shadcn `Viewport`. The hook coordinates anchor capture, exact-key or predecessor restoration, and selection restoration on the same scroll surface, while your application keeps control of content IDs, DOM/Range work, and storage. See [Base Message Scroller](/en/ui-libraries/base/message-scroller/) for details.
