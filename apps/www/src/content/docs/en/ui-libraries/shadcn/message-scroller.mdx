Message Scroller is built for chat feeds and streamed replies. It automatically follows newly appended items while the reader is at the bottom, holds position when the reader scrolls up into history, and provides a floating jump button to return on demand. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototypes directly from `@proto.ui/prototypes-shadcn/message-scroller` and adapt them for your target runtime.

```ts
import {
  messageScrollerRoot,
  messageScrollerViewport,
  messageScrollerJump,
} from '@proto.ui/prototypes-shadcn/message-scroller';
```

## Usage

`Message Scroller` fills its parent, so wrap it in a height-constrained container:

```tsx
<div className="flex h-80 flex-col overflow-hidden rounded-xl border border-border">
  <ShadcnMessageScrollerRoot styleProfile="rhea" a11yLabel="Assistant conversation">
    <ShadcnMessageScrollerViewport styleProfile="rhea">
      <div className="flex flex-col gap-3 p-4 pb-14">
        {messages.map((message) => (
          <div key={message.id}>{message.text}</div>
        ))}
      </div>
    </ShadcnMessageScrollerViewport>
    <ShadcnMessageScrollerJump styleProfile="rhea">
      <span aria-hidden="true">↓</span>
      <span className="sr-only">Jump to latest</span>
    </ShadcnMessageScrollerJump>
  </ShadcnMessageScrollerRoot>
</div>
```

### Anatomy & Behavior

Message Scroller consists of `Root`, `Viewport`, and `Jump`:

- **Follow only while at the bottom**: Newly appended messages scroll into view automatically when the reader is already at the end. Scrolling up pauses auto-follow immediately and preserves reading position.
- **Focus-preserving Jump button**: Activating `Jump` scrolls back to the latest entry and re-engages end-follow without stealing keyboard focus from composers or other controls. Use the default `size="icon"` for compact icon buttons or `size="pill"` for text labels and unread counts.
- **Application-owned unread count**: Pass `newContentCount` from your own application state rather than letting the container guess unread semantics.
- **Accessible naming**: Set `a11yLabel` on `Root` to label the scrollable region (defaults to `'Messages'`).
- **Style presets (`styleProfile`)**: All three parts support `vega`, `nova`, `maia`, `lyra`, `mira`, `luma`, `sera`, `rhea`, and `new-york-v4`, inheriting the nearest [Style Scope](../style-scope/) when omitted or set to `inherit`.

### Stable-key position and selection restoration

To restore reading position by stable key or preserve text selection across updates, compose the public Base `asMessageScrollerReading` hook after the Shadcn `Viewport`. The hook coordinates anchor capture, exact-key or predecessor restoration, and selection restoration on the same scroll surface, while your application keeps control of content IDs, DOM/Range work, and storage. See [Base Message Scroller](/en/ui-libraries/base/message-scroller/) for details.
