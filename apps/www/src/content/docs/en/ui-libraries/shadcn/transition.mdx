Transition drives a transparent enter/leave phase machine (`closed → preparing → entering → entered → leaving`) around your children, letting your application or `Surface` control the visual animation styles. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- Control visibility with `open` (controlled) or `defaultOpen` (uncontrolled); set `appear={true}` to run the enter transition on initial mount.
- Configure timings and interruption behavior with `enterDuration` (default `300ms`), `leaveDuration` (default `200ms`), and `interrupt` (`'reverse' | 'wait' | 'immediate'`, default `'reverse'`).
- Read `transitionState` and `isPresent`, and listen to `beforeEnter`, `afterEnter`, `beforeLeave`, and `afterLeave` lifecycle events.
- Drive transitions imperatively via `enter`, `leave`, and `complete` (also exposed on `controls`), where `complete` advances `entering` to `entered` or `leaving` to `closed`.
