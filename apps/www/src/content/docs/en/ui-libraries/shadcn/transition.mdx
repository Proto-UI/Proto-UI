Transition drives a transparent five-phase presence state machine (`closed → preparing → entering → entered → leaving`) around your children, binding bounded endpoint opacity while letting your application define easing and choreography. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release or `@proto.ui/cli` add targets. Import directly from workspace source:

```ts
import { transition } from '@proto.ui/prototypes-shadcn/transition';
```

## Usage

```tsx
import { useState } from 'react';
import { ShadcnButton, ShadcnStyleScope, ShadcnTransition } from '../proto-ui/components/react';

export function NotificationTransition() {
  const [open, setOpen] = useState(true);

  return (
    <ShadcnStyleScope styleProfile="rhea" className="contents">
      <ShadcnTransition
        open={open}
        appear
        className="block transition-opacity duration-300 ease-out motion-reduce:transition-none"
      >
        <div className="rounded-lg border border-border bg-card p-5 text-card-foreground shadow-sm">
          Workspace synced
        </div>
      </ShadcnTransition>
      <ShadcnButton styleProfile="rhea" onClick={() => setOpen((value) => !value)}>
        Toggle
      </ShadcnButton>
    </ShadcnStyleScope>
  );
}
```

- **Bounded endpoint opacity**: `shadcn-transition` applies `opacity-100` during `entering` and `entered`, and `opacity-0` during `closed`, `preparing`, and `leaving`, keeping the caller slot transparent. Pair it with CSS `transition-opacity` or `[data-transition-state]` selectors for smooth interpolation.
- **Five phases & cold preparation**: The standard flow is `closed → entering → entered → leaving → closed`. Higher-level compositions opting into `coldEntryPreparation` and `capturePreparation()` pause in `preparing` before entering so layout measurements can settle.
- **Reduced motion**: When the host declares `prefers-reduced-motion: reduce`, automatic fallback waits collapse to `0ms` while preserving phase ordering, boundary events, and view detachment; pair with `motion-reduce:transition-none` in application CSS.
- **Shared semantics**: Phase sequencing, presence retention, and interruption policies are inherited from [Base Transition](/en/ui-libraries/base/transition/).

## Examples

### Controlled Mode & `transitionend` Sync

Pass `open` for controlled mode. Fallback timers (`enterDuration` / `leaveDuration`) settle transitions automatically, or call `controls.complete()` on `transitionend` to synchronize with host CSS animations.

### Interruption Policies (`interrupt`)

Compare `'reverse'` (flip direction immediately), `'wait'` (finish the current phase before transitioning to the latest target), and `'immediate'` (cut directly to the new phase) during mid-flight toggles.
