The projection is transparent: the authored slot's presence is governed by the exact Base phase machine (`closed → preparing → entering → entered → leaving`), phases are observable through the `transitionState` expose and `isPresent`, and `beforeEnter`/`afterEnter`/`beforeLeave`/`afterLeave` events mark the boundaries. `enter`/`leave`/`complete` commands (also reachable as `controls`) drive the machine; `complete` advances `entering → entered` or `leaving → closed`. `open` (controlled) or `defaultOpen: false` starts the presence; `appear` (default `false`) enables an entry on first mount; `enterDuration` (default 300), `leaveDuration` (default 200) and `interrupt: 'reverse' | 'wait' | 'immediate'` (default `reverse`) shape the attempt. The projection adds no host animation engine or Shadcn motion paint — visual motion stays an application concern.
