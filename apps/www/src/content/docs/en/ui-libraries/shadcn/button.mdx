## Install

First [initialize an existing application](/en/start-here/quick-start/). The published stable 0.2.0 baseline uses:

<InstallCommandCard command="npx @proto.ui/cli@0.2.0 add wc shadcn-button" manager="npm" />

```sh
pnpm dlx @proto.ui/cli@0.2.0 add wc shadcn-button
```

Replace `wc` with `react` or `vue` for those stable hosts. The CLI installs `@proto.ui/prototypes-shadcn` and the corresponding Adapter at its own exact version and generates the local facade. Vue 2.6 (`>=2.6.0 <2.7`) and the named style profiles shown below require matching workspace 0.3 CLI/Adapter/Prototype source. Stable `@latest` does not establish that delivery; the workspace `0.3.0-alpha.1` manifest does not establish registry publication.

## Usage and presentation

Each Code panel includes registration/imports and the application's example stylesheet. Keep the generated `proto-ui-style.css` import in one application entry. WC uses the generated `proto-ui-shadcn-button` tag; React exports a named example to render from the existing app, and Vue examples are single-file components. Adjust relative paths to the initialized project's layout. The small layout and visually hidden-label rules are application-owned and do not require Tailwind.

The examples request `styleProfile="rhea"` explicitly, matching the preview's public Shadcn style scope. Current source recognizes `vega`, `nova`, `maia`, `lyra`, `mira`, `luma`, `sera`, `rhea` and `new-york-v4`; `new-york` is the legacy alias. Omission or `inherit` uses the nearest scope and then the Button's Rhea fallback. These examples demonstrate Rhea, not visual acceptance of every profile or component.

### Sizes

Use `sm`, `default`, `lg`, `icon` or the compact `icon-compact` extension. `icon-compact` is a fixed 1.75rem square, including when `wrap` is enabled.

Both icon-size examples keep “Add” as visually hidden content and hide the decorative plus from the accessibility tree. The Button emits its ordinary `click` signal; the consuming application owns the action. A glyph alone is not an accessible label.

## Navigation, groups and busy state

Use a native anchor for navigation, preserving its actual URL and full text: [Read Quick Start](/en/start-here/quick-start/). The equivalent application composition is:

```html
<a href="/en/start-here/quick-start/">Read Quick Start</a>
```

Do not put an anchor inside Button or invent `asChild`, `href`, `loading` or `isLoading` props. Base remains the activation and disabled owner. For a real asynchronous action, the application owns pending state, drives `disabled`, keeps a meaningful name and reports progress/completion. A spinner alone is not a busy-state or activation guard.

Ordinary layout can group independent actions. Use the documented [Toolbar](../toolbar/) when its keyboard model is the intended composition. A dedicated Button Group API, loading/spinner composition, icon-and-text matrix, all-profile evidence and native-link visual comparison are still separate conditions in [#1042](https://github.com/Proto-UI/Proto-UI/issues/1042); this pilot does not claim them complete.
