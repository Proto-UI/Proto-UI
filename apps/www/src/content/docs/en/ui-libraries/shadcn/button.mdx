Shadcn Button inherits activation, keyboard handling, focus, and disabled semantics from Base Button while adding six variants, a complete size scale, and selectable style profiles. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Use the stable 0.2.0 CLI to [initialize your application](/en/start-here/quick-start/) and add the button. The preview shows the workspace Button, including its Rhea style and extended sizes. For Vue 2.6, install matching prerelease or workspace versions of the CLI, adapter and prototype packages.

<InstallCommandCard
  commands={{
    npm: 'npx @proto.ui/cli@0.2.0 add wc shadcn-button',
    pnpm: 'pnpm dlx @proto.ui/cli@0.2.0 add wc shadcn-button',
  }}
  manager="npm"
/>

Replace `wc` with `react` or `vue` to generate the facade for your target framework. The CLI installs the matching `@proto.ui/prototypes-shadcn` and adapter packages alongside the generated styles.

## Usage

Import the generated `proto-ui-style.css` once at your application entry point, then render the button:

```tsx
import { ShadcnButton } from '../proto-ui/components/react';

export function Example() {
  return <ShadcnButton variant="outline">Button</ShadcnButton>;
}
```

- **Keyboard & accessibility**: Inherited from [Base Button](../../base/button/), supporting `Enter` and `Space` activation, focus-visible rings, and disabled suppression. For icon-only buttons, include a visually hidden label (`sr-only`) so assistive technology announces a clear name.
- **Cursor**: Following Tailwind v4's convention, buttons do not force `cursor: pointer` by default. To opt into pointer cursors across enabled buttons, add the following rule to your global stylesheet:

```css
@layer base {
  button:not(:disabled),
  [role='button']:not([aria-disabled='true']) {
    cursor: pointer;
  }
}
```

## Common patterns

- **Navigation**: Render a native `<a>` element with a real `href` for links so semantic link roles and browser navigation behavior are preserved.
- **Grouping actions**: Use standard flex containers for independent buttons, or [Toolbar](../toolbar/) when roving arrow-key navigation is needed.
