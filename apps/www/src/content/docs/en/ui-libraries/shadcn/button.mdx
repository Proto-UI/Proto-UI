Ordinary demos on this page explicitly use **Shadcn Rhea**, with matching examples. This does not change public compatibility defaults or imply complete browser, native-host or visual acceptance. Neutral Surface/Text atoms retain their own public semantics; the consumer composition supplies the family presentation theme.

`size="icon-compact"` is an explicit Proto UI extension: a fixed 1.75rem square, including when `wrap` is enabled. It maps the upstream Blocks toolbar’s `size-7` usage, not the upstream 2rem `icon-sm` API. Existing sizes and defaults are unchanged.

The Button prototype keeps one canonical demo per supported runtime. Use the adapter selector in the page chrome to compare the same semantic surface across implementations.
