## Usage

Navigation Menu consists of `Root`, `Trigger`, `Content`, `Item`, and `Link`:

- `Root` acts as a `navigation` landmark and manages the currently open panel via `Root.value`.
- `Trigger` renders the disclosure button and `Content` renders the labelled panel region.
- `Item` triggers a menu command.
- `Link` renders a native anchor with `href`, `target`, `rel`, and current-page semantics (`current` maps to `aria-current`).

### Native links and navigation events

- URL previews, `Enter` activation, and modifier-key or middle-click tab opening are handled natively by the browser.
- After native activation, `Link` emits a read-only `navigate` event with `{ href, target, rel, modified }` for observation or analytics.
- Standard same-window navigation closes the open panel unless `closeOnSelect={false}`; modifier clicks, middle-clicks, and `target="_blank"` keep the panel open on the current page.
- Disabling a `Link` removes its destination and prevents activation.
- React, Vue, and Vue 2 render a native anchor root; Web Components keep your children inside an owned local anchor so focus, styling, and accessibility attributes stay aligned.

Other part defaults:

- `Trigger`: `disabled` defaults to `false`.
- `Content`: `sideOffset` defaults to `4`.
- `Item`: `closeOnSelect` defaults to `true`.
- `Link`: `href` and `rel` default to `''`, `current` defaults to `false`, and `target` defaults to `'_self'`.
