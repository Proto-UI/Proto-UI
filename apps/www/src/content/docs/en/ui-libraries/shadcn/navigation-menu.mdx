## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototypes directly from `@proto.ui/prototypes-shadcn/navigation-menu` and adapt them for your target runtime:

```ts
import {
  navigationMenuRoot,
  navigationMenuTrigger,
  navigationMenuContent,
  navigationMenuItem,
  navigationMenuLink,
} from '@proto.ui/prototypes-shadcn/navigation-menu';
```

## Usage

```tsx
import {
  ShadcnNavigationMenuRoot,
  ShadcnNavigationMenuTrigger,
  ShadcnNavigationMenuContent,
  ShadcnNavigationMenuItem,
  ShadcnNavigationMenuLink,
} from '../proto-ui/components/react';

export function SiteNav() {
  return (
    <ShadcnNavigationMenuRoot styleProfile="rhea" a11yLabel="Main navigation">
      <ShadcnNavigationMenuTrigger value="getting-started">
        Getting started
      </ShadcnNavigationMenuTrigger>
      <ShadcnNavigationMenuContent value="getting-started" a11yLabel="Getting started">
        <ShadcnNavigationMenuLink href="/docs" current>
          Introduction
        </ShadcnNavigationMenuLink>
        <ShadcnNavigationMenuItem value="search" textValue="Search docs">
          Search docs
        </ShadcnNavigationMenuItem>
      </ShadcnNavigationMenuContent>
    </ShadcnNavigationMenuRoot>
  );
}
```

### Composition

```text
NavigationMenuRoot (navigation)
├── NavigationMenuTrigger (button, paired by value)
└── NavigationMenuContent (region, paired by value)
    ├── NavigationMenuLink (native <a>)
    └── NavigationMenuItem (command action)
```

### Native Links & Keyboard

- **Native anchor semantics**: URL previews, `Enter` activation, and modifier-key or middle-click tab opening are handled natively by the browser. React, Vue, and Vue 2 render a native `<a>` root; Web Components keep children inside an owned anchor element so focus, styles, and accessibility stay aligned.
- **Read-only `navigate` event**: After native activation, `Link` emits a read-only `navigate` event with `{ href, target, rel, modified }` for observation or analytics.
- **Dismissal policy**: Ordinary same-window activations close the open panel unless `closeOnSelect={false}`. Modifier clicks, middle-clicks, and `target="_blank"` keep the current page's panel open. Disabling a `Link` removes its destination and blocks activation.
- **Keyboard roving**: Arrow keys move across top-level triggers, `ArrowDown` / `ArrowUp` open the panel and focus its first or last entry, and `Escape` closes the panel and restores focus to the trigger.
