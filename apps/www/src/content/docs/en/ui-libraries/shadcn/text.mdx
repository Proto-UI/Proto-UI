Text inherits the [Base Text](/en/ui-libraries/base/text/) typography contract and applies Shadcn font, size, line-height, tracking, and ink tokens while leaving document semantics to surrounding native elements. The examples on this page use the **Shadcn Rhea** style preset.

## Usage

Import `shadcnTextRoot` (also exported as `textRoot` and `ShadcnTextRoot`) from `@proto.ui/prototypes-shadcn/text` or the package root, and configure the host element tag through your Adapter:

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { shadcnTextRoot } from '@proto.ui/prototypes-shadcn/text';

const Text = createReactAdapter(React)(shadcnTextRoot, { rootTag: 'span' });

export function SectionTitle() {
  return (
    <h1>
      <Text size="4xl" font="heading" weight="semibold" leading="tight" tracking="tight">
        Account settings
      </Text>
    </h1>
  );
}
```

### Semantics and color inheritance

- `rootTag: 'span'` is a Web Adapter option rather than a component prop. Keep document and interactive semantics—such as `h1`, `p`, `label` (`htmlFor`/`for`), and `a` (`href`, `target`, `download`)—on the enclosing native elements.
- Use `tone="inherit"` when rendering text inside a `solid` or `accent` `Surface` so it inherits the enclosing container's foreground color.

### Line height and tracking scale

- `leading="size"` uses the built-in line height for each size step: `xs` (`1rem`), `sm` (`1.25rem`), `base` (`1.5rem`), `lg` (`1.75rem`), `xl` (`1.75rem`), `2xl` (`2rem`), `3xl` (`2.25rem`), `4xl` (`2.5rem`), and `5xl` (`1`).
- `leading="tighter"` maps to `1.1`, and `tracking="tighter"` maps to `-0.05em`.
- Removing a prop restores its default. An invalid initial `size` falls back to `base`, while an invalid update retains the previous valid value.
- Inside Shadcn action compositions, `actionProfile="rhea"` and `"luma"` consistently apply `1.25rem` line height.

## API

The following props belong to `Root`:

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}

    { name: 'tone', type: "'default' | 'muted' | 'inherit'", default: 'default' },
