Text inherits the eight independent presentation axes of [Base Text](/en/ui-libraries/base/text/) and applies Shadcn typography and ink tokens while leaving document structure and interaction semantics to enclosing native elements. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Initialize your app via the [Quick Start guide](/en/start-here/quick-start/), then add `shadcn-text` (draft capabilities are also available directly from workspace source):

<InstallCommandCard
  commands={{
    npm: 'npx @proto.ui/cli@latest add wc shadcn-text',
    pnpm: 'pnpm dlx @proto.ui/cli@latest add wc shadcn-text',
  }}
  manager="npm"
/>

Replace `wc` with `react`, `vue`, or `vue2` to generate the local facade for your target framework.

## Usage

Compose the generated `ShadcnTextRoot` component inside native `h1`–`h4`, `p`, `blockquote`, `code`, `label`, or `a` elements:

```tsx
import { ShadcnTextRoot } from '../proto-ui/components/react';

export function SectionTitle() {
  return (
    <h1>
      <ShadcnTextRoot size="4xl" font="heading" weight="bold" leading="tight" tracking="tight">
        Account settings
      </ShadcnTextRoot>
    </h1>
  );
}
```

You can also import `shadcnTextRoot` (aliased as `textRoot` and `ShadcnTextRoot`) from `@proto.ui/prototypes-shadcn/text` with `{ rootTag: 'span' }` on your Web Adapter, and optionally apply the immutable `SHADCN_TYPOGRAPHY` preset (Geist paired with platform and CJK fallbacks; font delivery and licensing stay with the host app):

```ts
import { shadcnTextRoot, SHADCN_TYPOGRAPHY } from '@proto.ui/prototypes-shadcn/text';
```

### Semantics and typography rules

- **Native semantic ownership**: Text adds no ARIA role, tab stop, or event handler. Keep heading levels, `label` (`htmlFor`/`for`), and anchor (`href`, `target`, `download`) semantics on the surrounding native elements.
- **Size-owned line boxes & tight steps**: `leading="size"` retains each size token's built-in line height (`xs` `1rem`, `sm` `1.25rem`, `base` `1.5rem`, `lg` `1.75rem`, `xl` `1.75rem`, `2xl` `2rem`, `3xl` `2.25rem`, `4xl` `2.5rem`, `5xl` `1`). `leading="tighter"` maps to `1.1`, and `tracking="tighter"` maps to `-0.05em`.
- **Defaults and fallback**: Removing any prop restores its default. An invalid initial `size` falls back to `base`, while an invalid update after a valid value retains the previous valid value.
- **Action typography (`actionProfile`)**: Defaults to `'none'` and never subscribes implicitly to `shadcn-style-scope`. Passing an explicit preset applies its action line box (`1.25rem` for `rhea`, `luma`, `vega`, `nova`, `maia`, `new-york-v4`; `1rem` for `lyra` and `sera`; `1.625` for `mira`, with uppercase and wide tracking for `sera`).
