A searchable dropdown that separates the committed option key (`value`) from the editable query string (`inputValue`). The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Combobox will be available starting in `0.3.0-rc.1` and later releases (`@proto.ui/prototypes-shadcn/combobox`).

## Usage

```tsx
import {
  comboboxRoot,
  comboboxInput,
  comboboxTrigger,
  comboboxContent,
  comboboxItem,
  comboboxEmpty,
} from '@proto.ui/prototypes-shadcn/combobox';
```

```html
<shadcn-combobox-root a11y-label="Framework">
  <shadcn-combobox-input placeholder="Select a framework..."></shadcn-combobox-input>
  <shadcn-combobox-trigger>▾</shadcn-combobox-trigger>
  <shadcn-combobox-content>
    <shadcn-combobox-item value="next.js" text-value="Next.js">Next.js</shadcn-combobox-item>
    <shadcn-combobox-item value="sveltekit" text-value="SvelteKit">SvelteKit</shadcn-combobox-item>
    <shadcn-combobox-item value="astro" text-value="Astro">Astro</shadcn-combobox-item>
    <shadcn-combobox-empty>No frameworks found.</shadcn-combobox-empty>
  </shadcn-combobox-content>
</shadcn-combobox-root>
```

### Anatomy

```text
ComboboxRoot
├── ComboboxInput
├── ComboboxTrigger (optional)
└── ComboboxContent
    ├── ComboboxItem
    └── ComboboxEmpty (optional)
```

- `Root`'s `value` stores the selected option key, while `inputValue` tracks the live search text. Unmatched input text is never silently accepted as an option.
- If you want users to submit arbitrary free text, use [Autocomplete](../autocomplete/) instead.
- **Built-in filtering**: Matches case- and diacritic-insensitively against `textValue` and `keywords`. Set `filter={false}` to supply your own pre-filtered items.
- **Keyboard and IME**: Focus stays in the single-line input during arrow-key navigation, and IME composition never selects an option.
