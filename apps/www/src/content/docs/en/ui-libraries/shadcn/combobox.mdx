## Usage

Currently available from workspace source; not yet included in the 0.2.0 stable release.

### Anatomy

Compose `Combobox` from `Root`, `Input`, `Content`, `Item`, `Empty`, and `Trigger`:

- `Root`'s `value` stores the selected option key, while `inputValue` tracks the live search text. Unmatched input text is never silently accepted as an option.
- If you want users to submit arbitrary free text, use [Autocomplete](../autocomplete/) instead.

### Filtering and interaction

- **Built-in filtering**: Matches case- and diacritic-insensitively against `textValue` and `keywords`. Set `filter={false}` to supply your own pre-filtered items.
- **Empty and disabled states**: `Empty` reflects the real match count; disabled items and duplicate-valued options cannot be committed.
- **Keyboard and IME**: Focus stays in the single-line input during arrow-key navigation, and IME composition never selects an option.
- **Controlled state**: `open`, `value`, and `inputValue` can each be controlled independently with their corresponding change events.

## API

Passing `value`, `inputValue`, or `open` enables controlled mode for that state.

These props belong to `Root`. Other part defaults:

- **Input**: `placeholder`, `a11yLabel`, and `name` default to `''`.
- **Content**: `side="bottom"`, `align="start"`, `sideOffset={4}`, `collisionPadding={8}`.
- **Item**: `value`, `textValue`, and `keywords` default to `''`; `disabled` defaults to `false`.
- **Trigger**: `disabled` defaults to `false`.
