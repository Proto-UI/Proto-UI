This page targets **Shadcn Rhea** and explicitly selects it for profile-aware parts. The headless trigger/action-body gap below remains open; this is not yet a fully unified Rhea demonstration. This does not change public compatibility defaults or imply complete browser, native-host or visual acceptance. Neutral Surface/Text atoms retain their own public semantics; the consumer composition supplies the family presentation theme.

This draft family contains Group, Root, Trigger, and Content. Base Tooltip remains the sole owner of open state, controlled ownership, disabled behavior, pointer and focus intent, delay and dismissal sequencing, `aria-describedby`, presence, Escape handling, renderer-owned Portal projection, and anchored positioning. The shadcn layer adds only Group layout, Trigger feedback, and a compact Content surface.

The historical API comparison is shadcn-ui/ui `f31ed81983653919dd4fe77aee4b4859f610f1dc`, `apps/v4/registry/new-york-v4/ui/tooltip.tsx`; it is not this page's selected visual profile. Its Provider defaults pointer delay to 0ms; Proto UI retains Base Group's 700ms open, 100ms close and 300ms skip. Its Content defaults sideOffset to 0; Proto UI retains 4. Portal remains renderer-owned and Arrow remains unavailable without a governed geometry channel.

Content selects the [Rhea style source](https://github.com/shadcn-ui/ui/blob/3d98900e9b73c45f035f8109e9d41ba6a51685e7/apps/v4/registry/styles/style-rhea.css): inline-flex, fit-content width, a 20rem maximum, 6px gap and `rounded-xl`, with foreground/background theme colors inverted for the tooltip surface. The 2026-10-10 [base-nova snapshot](https://ui.shadcn.com/r/styles/base-nova/tooltip.json) (SHA256 `2f55867faecee2d3616cfd8c6a80b538909a21e62fdfa2788b1ead56093e5395`) is retained only as the unscoped compatibility reference. Trigger is a headless semantic owner with existing Proto feedback, not a Button. A reusable Rhea passive action-body composition is still needed to replace the demo's historical authored trigger paint without adding a second focus/activation owner. Arrow, transform-origin, directional motion, kbd descendant styling and native visual acceptance remain open.

Import the family from `@proto.ui/prototypes-shadcn/tooltip`, or generate its React facade with `proto-ui add react shadcn-tooltip`. Content remains supplementary, non-focusable, and non-essential; interactive task content belongs to Popover or a non-modal Dialog.

## Suggested acceptance path

1. Hover Account and confirm the cold Tooltip opens after about 700ms; leave early and confirm no flash appears.
2. Move to Notifications before the 300ms warm window expires and confirm the sibling opens immediately with one active owner.
3. Tab to either Trigger and confirm immediate opening, a visible focus ring, and no button role.
4. Confirm Content is portaled outside the preview frame, remains linked by `aria-describedby`, and contains no focusable control or Arrow.
5. Press Escape and confirm Content closes while focus remains on Trigger.
6. Repeat in Web Components, React, Vue, and Vue 2, in both Light and Dark.

The related entities are `draft`; this page describes the current cataloged direction, not a stable compatibility guarantee.

## API

Passing `open` on Root selects controlled mode. Group delays apply when Root does not set its own.

`openDelay`, `closeDelay`, and `skipDelay` belong to Group. `side` through `collisionPadding` belong to Content. Trigger only adds `disabled`.
