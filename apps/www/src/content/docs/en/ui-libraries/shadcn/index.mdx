Proto UI’s independently maintained Shadcn-styled component library: Base prototypes provide consistent interaction and accessibility semantics, while the Shadcn layer adds styled presentation across Web Components, React, Vue 3, and Vue 2.

## Installation and setup

Initialize an existing project and add a component (shown with the 0.2.0 stable CLI):

```sh
npx @proto.ui/cli@0.2.0 init
npx @proto.ui/cli@0.2.0 add wc shadcn-button
```

With pnpm:

```sh
pnpm dlx @proto.ui/cli@0.2.0 init
pnpm dlx @proto.ui/cli@0.2.0 add wc shadcn-button
```

Replace `wc` with `react` or `vue` to generate local facades for those frameworks, and import the generated `proto-ui-style.css` once at your application entry point. See [Quick Start](/en/start-here/quick-start/) for setup details and [Button](./button/) for side-by-side host examples. Vue 2.6 support and named style presets such as **Shadcn Rhea** are currently available from workspace source.

## Design notes

- Every component inherits its keyboard navigation, focus handling, and accessibility semantics from its Base counterpart. For example, [Button](./button/) keeps command semantics on `variant="link"`, while navigation uses native `<a>` elements.
- Style preset support is defined per component; wrap a subtree in [Style Scope](./style-scope/) to configure presets for a section of your UI.
