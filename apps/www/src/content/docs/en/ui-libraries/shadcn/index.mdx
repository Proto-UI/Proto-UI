The Shadcn library projects a familiar, crisp, and practical product interface style over Base interaction protocols. This page is a quick index: each prototype shows only its first basic demo, without API tables or code examples.

The Shadcn catalog entities currently remain in the draft lifecycle. This page reflects the current official implementation rather than a frozen stable guarantee.

## Passive atoms

[Text](/en/ui-libraries/shadcn/text/) and [Surface](/en/ui-libraries/shadcn/surface/) are draft reusable presentation atoms in this workspace. They preserve the existing semantic owner and do not establish complete family or native/Compiler coverage.

[Collapsible (Draft)](/en/ui-libraries/shadcn/collapsible/) provides Root, Trigger and Content projections over the shared Base disclosure protocol.
