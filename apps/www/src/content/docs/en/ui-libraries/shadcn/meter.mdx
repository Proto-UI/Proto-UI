Meter displays a known numerical measurement within a bounded range—such as disk usage, quota balance, or charge level—and classifies readings against optional thresholds. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Available starting in `0.3.0-rc.1` and later releases. Import the meter parts directly from `@proto.ui/prototypes-shadcn/meter`:

```ts
import {
  meterRoot,
  meterLabel,
  meterTrack,
  meterIndicator,
  meterValue,
} from '@proto.ui/prototypes-shadcn/meter';
```

## Usage

```tsx
import { AdaptToReact } from '@proto.ui/adapter-react';
import {
  meterRoot,
  meterLabel,
  meterTrack,
  meterIndicator,
  meterValue,
} from '@proto.ui/prototypes-shadcn/meter';

const MeterRoot = AdaptToReact(meterRoot);
const MeterLabel = AdaptToReact(meterLabel);
const MeterTrack = AdaptToReact(meterTrack);
const MeterIndicator = AdaptToReact(meterIndicator);
const MeterValue = AdaptToReact(meterValue);

export function StorageMeter() {
  return (
    <MeterRoot value={32} min={0} max={100} low={50} high={80} optimum={20} valueText="32%">
      <div className="flex items-center justify-between gap-2">
        <MeterLabel>Storage used</MeterLabel>
        <MeterValue />
      </div>
      <MeterTrack>
        <MeterIndicator />
      </MeterTrack>
    </MeterRoot>
  );
}
```

### Anatomy

- **Root**: Manages the finite `[min, max]` bounds, clamped `value`, and threshold classification. Equal bounds produce `0` percentage.
- **Label**: Names the meter through `aria-labelledby`; pass `ariaLabel` when rendering without a visible `Label`.
- **Track / Indicator**: Visualize `--pui-percentage` and adjust the indicator fill across `optimal`, `suboptimal`, and `critical` zones.
- **Value**: Displays `valueText` when provided, otherwise falls back to the normalized numeric value.

### Thresholds and accessibility

- `low`, `high`, and `optimum` classify readings as `optimal`, `suboptimal`, or `critical` without altering the numeric value. Place `optimum` below `low` when lower readings are better (disk usage), or above `high` when higher readings are better (battery charge).
- Meter is a read-only display (`role="meter"`) with no keyboard tab stop. `Root` and its parts expose synchronized `value`, `percentage`, `indeterminate`, and `status` states.

### Style presets (`styleProfile`)

Supported presets are `vega`, `nova`, `maia`, `lyra`, `mira`, `luma`, `sera`, `rhea`, and `new-york-v4` (`new-york` alias). When omitted or set to `'inherit'`, parts inherit from the nearest [Style Scope](../style-scope/) (wrapped in `rhea` on this page) and fall back to `luma` when mounted standalone.
