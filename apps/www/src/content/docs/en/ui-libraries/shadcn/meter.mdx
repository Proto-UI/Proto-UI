Meter displays a known numerical measurement within a bounded range—such as disk usage, quota balance, or strength—and classifies it against optional thresholds. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

After registering the package entry, import `meterRoot`, `meterLabel`, `meterTrack`, `meterIndicator`, and `meterValue` from the `meter` subpath:

- `Root` manages the finite range and status calculation.
- `Label` provides the accessible name.
- `Track` and `Indicator` visualize the current proportion within the range.
- `Value` displays `valueText`, or falls back to the normalized numeric value.

### Range and threshold classification

- Values are clamped within `[min, max]`; when `min` equals `max`, the percentage is `0`.
- `low`, `high`, and `optimum` classify the reading as `optimal`, `suboptimal`, or `critical` without altering the numeric value.
- Meter is a read-only display with no keyboard tab stop. `Root` and its parts expose `value`, `percentage`, `indeterminate`, and `status`, updating together whenever props change.
