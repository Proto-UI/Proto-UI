A modal drawer that slides in from any of the four viewport edges, supporting content-fit sizing, vertical scrolling, and draggable snap points. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Currently available from workspace source (`@proto.ui/prototypes-shadcn/drawer`); not yet published in the 0.2.0 stable CLI release.

## Usage

```tsx
import {
  ShadcnButton,
  ShadcnDrawerRoot,
  ShadcnDrawerTrigger,
  ShadcnDrawerMask,
  ShadcnDrawerContent,
  ShadcnDrawerHandle,
  ShadcnDrawerHeader,
  ShadcnDrawerTitle,
  ShadcnDrawerDescription,
  ShadcnDrawerFooter,
  ShadcnDrawerClose,
} from '../proto-ui/components/react';
```

```tsx
<ShadcnDrawerRoot styleProfile="rhea">
  <ShadcnDrawerTrigger styleProfile="rhea">
    <ShadcnButton styleProfile="rhea" variant="outline">Open Drawer</ShadcnButton>
  </ShadcnDrawerTrigger>
  <ShadcnDrawerMask styleProfile="rhea" />
  <ShadcnDrawerContent styleProfile="rhea" side="bottom">
    <ShadcnDrawerHandle styleProfile="rhea" />
    <ShadcnDrawerHeader styleProfile="rhea">
      <ShadcnDrawerTitle styleProfile="rhea">Move Goal</ShadcnDrawerTitle>
      <ShadcnDrawerDescription styleProfile="rhea">
        Set your daily activity goal.
      </ShadcnDrawerDescription>
    </ShadcnDrawerHeader>
    <div className="flex-1 overflow-y-auto px-4">{/* Content */}</div>
    <ShadcnDrawerFooter styleProfile="rhea">
      <ShadcnButton styleProfile="rhea">Submit</ShadcnButton>
      <ShadcnDrawerClose styleProfile="rhea">
        <ShadcnButton styleProfile="rhea" variant="outline">Cancel</ShadcnButton>
      </ShadcnDrawerClose>
    </ShadcnDrawerFooter>
  </ShadcnDrawerContent>
</ShadcnDrawerRoot>
```

### Composition

```text
DrawerRoot
├── DrawerTrigger
├── DrawerMask
└── DrawerContent
    ├── DrawerHandle
    ├── DrawerHeader
    │   ├── DrawerTitle
    │   └── DrawerDescription
    └── DrawerFooter
        └── DrawerClose
```

- **Trigger and Close**: Under modern presets like `rhea`, `Trigger` and `Close` stay headless so you can nest a public `Button` directly inside them. Under `new-york-v4`, they retain outline button paint (with optional `wrap` for long labels).
- **Extent bounds**: Use `minExtent` and `maxExtent` on `Content` with neutral units (`'logical'`, `'root-text'`, `'available'`, or `'available-minus-root-text'`). Vertical drawers fit their content height within the safe viewport cap; horizontal drawers default to a `20` `root-text` cap.
- **Snapping and accessibility**: Passing a non-empty `snapPoints` array in `(0, 1]` enables named `separator` semantics on `Handle` with Arrow keys and `Home`/`End` resizing. Pressing `Escape` or clicking the backdrop dismisses the drawer and restores focus to the trigger.

## API

### Root

Pass `open` for controlled mode and subscribe to `openChange`. Exposes `openDrawer()`, `close()`, and `toggle()` methods.

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'open', type: 'boolean', default: '—' },
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'a11yLabel', type: 'string', default: "''" },
    { name: 'styleProfile', type: 'ShadcnStyleProfile', default: "'inherit'" },
  ]}
/>

### Content

Exposes `open`, `snapPoint`, `dragging`, `dragProgress`, `offsetPercentage`, `extentValid`, `requestSnapPoint()`, and the `snapPointChange` event.

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
