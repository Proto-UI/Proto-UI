## Usage

Currently available from workspace source; not yet included in the 0.2.0 stable release.

### Composition and triggers

- **Trigger and Close**: Under Rhea, `Trigger` and `Close` stay headless; nest a public `Button` (such as an outline button, with `wrap` for long labels) directly inside them so the button supplies the physical focus/activation surface while forwarding the effective `disabled` state.
- **Grid layouts**: `Root` renders a wrapper element. When placing it directly inside a CSS Grid, pass `hostStyle={{ display: 'contents' }}` in React (or `display: contents` on Web Components) to avoid an extra grid row.
- **Visual structure**: Rhea `Content` wraps its inset popover surface (capped at 24px radius) with transparent `p-4` outer padding, and renders a 100px × `0.375rem` drag `Handle` with a `1rem` top margin.

### Sizing (`minExtent` / `maxExtent`)

Use `minExtent` and `maxExtent` on `Content` instead of raw CSS widths:

- Accepted units are `logical`, `root-text`, `available`, and `available-minus-root-text` with a nonnegative finite `value` (for example, `maxExtent={{ unit: 'logical', value: 480 }}`).
- Top and bottom drawers fit their content height by default (bounded by the safe available area); left and right drawers use fractional width capped at 20 `root-text` units unless overridden with `maxExtent`.
- Invalid runtime extent updates are ignored while retaining the last valid sizing intent (`extentValid` becomes `false`).

### Snap points and drag dismissal

- **Content-fit mode**: When `snapPoints` is omitted or empty on top/bottom drawers, `Handle` acts as a pointer-only drag affordance.
- **Explicit snaps**: Pass an array of fractions in `(0, 1]` (sorted and deduplicated automatically) and manage the active snap with `defaultSnapPoint` or controlled `snapPoint` / `snapPointChange`. In this mode, `Handle` also supports arrow keys and `Home`/`End`.
- Set `dragDismissible={false}` to disable drag-to-close while keeping `Close`, `Escape`, and outside clicks active. If a controlled close request is rejected, drag preview settles back to the current open state.

## API

Passing `open` selects controlled mode.

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'a11yLabel', type: 'string', default: "''" },
  ]}
/>

These props belong to `Root`. Other part defaults:

- **Content**: `side` defaults to `'bottom'` (`'top' | 'right' | 'bottom' | 'left'`), plus `minExtent`, `maxExtent`, `snapPoints`, `snapPoint`, `defaultSnapPoint`, and `dragDismissible`.
- **Trigger / Close**: `disabled` defaults to `false`.
- **Handle**: `disabled` defaults to `false`; `a11yLabel` defaults to `'Resize drawer'`.
- **Overlay**: `passthrough` defaults to `false`.
- **Title / Description / Header / Footer**: No props.
