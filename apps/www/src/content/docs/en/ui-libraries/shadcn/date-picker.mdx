## Range and multiple selection

Pass `mode="range"` with `range` / `defaultRange`, or `mode="multiple"` with `values` / `defaultValues`. These are the same Calendar inputs, callbacks, methods and eligibility rules documented on the Calendar page, including range-interior availability and count/night limits.

The first range endpoint keeps the popup open. The second accepted endpoint completes the range and requests one close. A rejected or pending controlled request leaves the popup open; matching later owner acceptance closes it only within the same open session. Closing/reopening, unmounting, mode changes, disabled/readOnly changes and replacement owner selections retire stale completion. External value changes alone do not close the popup. Controlled `open` can still refuse the close request. Multiple selections keep it open for further toggles; use the normal Popover dismissal behavior to finish.

Value displays one ISO civil date, a comma-separated sorted list, `from …` for an unfinished range, or `from – to` for a complete range. An empty selection uses `placeholder`. Calendar Day facts and family range painting are inherited directly. Popover continues to own focus return and dismissal.

## API

Date Picker is workspace source. There is no public `proto-ui add` target. Open stays on Popover; mode, value/values/range, selection constraints and month stay on Calendar. The only Date Picker prop is on Value.
