A date picker that composes `Popover` and `Calendar` with single, multiple, and range selection while keeping `open`, selection value, and visible `month` independently controllable. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Available starting in `0.3.0-rc.1` and later releases. `Date Picker` is composed from [Popover](../popover/) and [Calendar](../calendar/) parts imported directly from the workspace.

## Usage

```tsx
import {
  ShadcnDatePickerRoot,
  ShadcnDatePickerTrigger,
  ShadcnDatePickerValue,
  ShadcnDatePickerContent,
  ShadcnDatePickerDay,
  ShadcnCalendarCaption,
  ShadcnCalendarPrevious,
  ShadcnCalendarHeading,
  ShadcnCalendarNext,
  ShadcnCalendarGrid,
  ShadcnCalendarWeekdays,
  ShadcnCalendarWeekday,
  ShadcnCalendarRow,
} from '../proto-ui/components/react';

export function DatePickerExample() {
  return (
    <ShadcnDatePickerRoot defaultMonth="2026-10" styleProfile="rhea">
      <ShadcnDatePickerTrigger className="w-56">
        <ShadcnDatePickerValue placeholder="Pick a date" />
        <span aria-hidden="true">▾</span>
      </ShadcnDatePickerTrigger>
      <ShadcnDatePickerContent side="bottom" align="start" sideOffset={6}>
        <ShadcnCalendarCaption>
          <ShadcnCalendarPrevious a11yLabel="Previous month">‹</ShadcnCalendarPrevious>
          <ShadcnCalendarHeading />
          <ShadcnCalendarNext a11yLabel="Next month">›</ShadcnCalendarNext>
        </ShadcnCalendarCaption>
        <ShadcnCalendarGrid>
          <ShadcnCalendarWeekdays>
            {[0, 1, 2, 3, 4, 5, 6].map((offset) => (
              <ShadcnCalendarWeekday key={offset} offset={offset} />
            ))}
          </ShadcnCalendarWeekdays>
          {[0, 1, 2, 3, 4, 5].map((row) => (
            <ShadcnCalendarRow key={row} index={row}>
              {[0, 1, 2, 3, 4, 5, 6].map((col) => (
                <ShadcnDatePickerDay key={col} offset={row * 7 + col} />
              ))}
            </ShadcnCalendarRow>
          ))}
        </ShadcnCalendarGrid>
      </ShadcnDatePickerContent>
    </ShadcnDatePickerRoot>
  );
}
```

### Composition

```text
DatePickerRoot
├── DatePickerTrigger
│   └── DatePickerValue
└── DatePickerContent
    ├── CalendarCaption
    │   ├── CalendarPrevious
    │   ├── CalendarHeading
    │   └── CalendarNext
    └── CalendarGrid
        ├── CalendarWeekdays -> CalendarWeekday (0..6)
        └── CalendarRow (0..5) -> DatePickerDay (0..41)
```

### Selection modes and dismissal

- **Single and range modes**: `mode="single"` requests closing the popover once a date is accepted. `mode="range"` keeps the popover open after choosing the start date and requests one close when the second endpoint completes the range. If a controlled selection request is rejected or pending, the popover stays open.
- **Multiple mode**: `mode="multiple"` keeps the popover open so users can toggle several dates, then close it via outside click or `Escape`.
- **Formatted display (`Value`)**: Empty selections render `placeholder` with muted placeholder text styling; single mode formats `YYYY-MM-DD`, multiple mode formats a sorted comma-separated list, and range mode formats `from …` while incomplete or `from – to` once complete.
- **Keyboard and accessibility**: Dismissal and focus restoration are managed by `Popover`; grid arrow navigation, unavailable date skipping, and localized labels are inherited from [Calendar](../calendar/).

## API

`Date Picker` consists of `DatePickerRoot`, `DatePickerTrigger`, `DatePickerValue`, `DatePickerContent`, and `DatePickerDay`, reusing `Calendar` caption, navigation, and grid parts inside the popup.

  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}

    { name: 'values / defaultValues', type: 'readonly string[]', default: '[]' },

    { name: 'minSelected / maxSelected', type: 'number', default: '—' },
    { name: 'minNights / maxNights', type: 'number', default: '—' },
    { name: 'locale', type: 'string', default: "'en-US'" },
    { name: 'direction', type: "'ltr' | 'rtl'", default: "'ltr'" },

  ]}
