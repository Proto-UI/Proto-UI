## Usage

Currently available from workspace source; not yet included in the 0.2.0 stable release.

### Selection modes and dismissal

- **Single and range modes**: `mode="single"` requests closing the popover once a date is accepted. `mode="range"` keeps the popover open after choosing the start date and requests one close when the second endpoint completes the range. If a controlled selection request is rejected or pending, the popover stays open.
- **Multiple mode**: `mode="multiple"` keeps the popover open so users can toggle several dates, then close it via outside click or `Escape`.
- **Shared calendar rules**: `range` / `defaultRange`, `values` / `defaultValues`, availability constraints (`min`, `max`, `unavailable`), and count/night limits work identically to [Calendar](../calendar/).

### Formatted display (`Value`)

The `Value` part formats the current selection automatically:

- Single: one ISO date (`YYYY-MM-DD`);
- Multiple: a sorted, comma-separated list;
- Range: `from …` while incomplete, or `from – to` when complete;
- Empty: renders `placeholder`.

Popover dismissal and focus restoration remain handled by `Popover`.
