Manages a related set of checkboxes as a string array, with built-in select-all/indeterminate state, vertical or horizontal layout, and direct `Field` / `Form` integration. The examples on this page use the **Shadcn Rhea** style preset.

## Usage

```tsx
import {
  ShadcnCheckboxGroupRoot,
  ShadcnCheckboxGroupAll,
  ShadcnCheckboxGroupItem,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <ShadcnCheckboxGroupRoot
      styleProfile="rhea"
      defaultValue={['email']}
      ariaLabel="Notification channels"
    >
      <ShadcnCheckboxGroupAll>All notifications</ShadcnCheckboxGroupAll>
      <ShadcnCheckboxGroupItem value="email">Email updates</ShadcnCheckboxGroupItem>
      <ShadcnCheckboxGroupItem value="sms">SMS alerts</ShadcnCheckboxGroupItem>
    </ShadcnCheckboxGroupRoot>
  );
}
```

### Anatomy and keyboard

- **Root**: Coordinates the selected `string[]` value (`value` / `defaultValue`), `orientation`, `disabled`, `readOnly`, and `ariaLabel`.
- **Item**: Individual option with a unique `value` and optional `disabled` flag. Each enabled item has its own `Tab` stop and toggles on `Space` (`Enter` does not toggle).
- **All**: Derives checked, mixed (`aria-checked="mixed"`), or unchecked state across enabled items and toggles only enabled items while preserving disabled selections.
- **Forms and accessibility**: Decorative `aria-hidden` SVG indicators render check, dash, or empty states, focus rings target the checkbox indicator directly, and `Field` / `FormField` automatically connect label activation, required validation, serialization, and reset.

### Events, Methods, and States

- **Root events**: `valueChange` (payload `{ value: string[] }`).
- **Root methods**: `getValue(): string[]` (defensive copy), `resetValue(): boolean`, `focusSelf(): void`.
- **Root states**: `checked`, `indeterminate`, `disabled`, `readOnly` (plus `invalid`, `fieldRequired`, `fieldDisabled`, `fieldReadOnly` from `Field` binding).
- **Item / All states**: `checked`, `indeterminate`, `disabled`, `readOnly`, `focused`, `focusVisible`.
