## Usage

Currently available from workspace source; not yet included in the 0.2.0 stable release.

### Anatomy

Compose `Checkbox Group` from `Root`, `Item`, and `All`:

- **Root**: Manages the selected `string[]` value (`value` / `defaultValue`), `disabled`, `readOnly`, and `ariaLabel`.
- **Item**: Individual option with `value` and `disabled`. Each item has its own `Tab` stop and toggles on `Space` (`Enter` does not toggle).
- **All**: Summarizes enabled items as checked, mixed, or unchecked, and toggles all enabled items while preserving disabled selections.

### Controlled state and form integration

- Pass `value` to control the selection externally: user changes emit `valueChange` without mutating external state. `getValue()` returns a copy of the array, and duplicate item values are rejected.
- Inside a `Field` or `FormField`, `Root` automatically connects to label activation, required validation, form serialization, and reset.
- Styled `Item` and `All` render decorative `aria-hidden` state icons (checkmark, dash for mixed, or empty box) so state is never conveyed by color alone.

## API

Passing `value` selects controlled mode.
