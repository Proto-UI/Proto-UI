## Installation

This component is available from workspace source. In your application, install the CLI, Shadcn prototypes and target adapter built from the same workspace revision, then initialize the project with that CLI. Run the locally installed CLI to generate the facade.

<InstallCommandCard command="npm exec -- proto-ui add wc shadcn-collapsible" manager="npm" />

Replace `wc` with `react`, `vue`, or `vue2` to generate the local facade for your framework.

You can also import the parts directly from `@proto.ui/prototypes-shadcn/collapsible`:

```ts
import {
  collapsibleRoot,
  collapsibleTrigger,
  collapsibleContent,
} from '@proto.ui/prototypes-shadcn/collapsible';
```

## Usage

```tsx
import {
  ShadcnCollapsibleRoot,
  ShadcnCollapsibleTrigger,
  ShadcnCollapsibleContent,
} from '@/components/ui/collapsible';

export function Example() {
  return (
    <ShadcnCollapsibleRoot>
      <ShadcnCollapsibleTrigger>Can I use this in my project?</ShadcnCollapsibleTrigger>
      <ShadcnCollapsibleContent>
        Yes. Free to use for personal and commercial projects.
      </ShadcnCollapsibleContent>
    </ShadcnCollapsibleRoot>
  );
}
```

### Composition

```text
CollapsibleRoot
├── CollapsibleTrigger
└── CollapsibleContent
```

Place one `Trigger` and one `Content` inside each `Root`. Nested and sibling `Root` instances maintain independent state:

- **Root**: Manages open state via `open`, `defaultOpen`, `disabled`, and `styleProfile`. Exposes `open`, methods `openCollapsible()`, `close()`, and `toggle()`, and `openChange` with payload `{ open, reason }`.
- **Trigger**: Accessible toggle button supporting `disabled`, `variant` (`default` | `ghost` | `outline` | `plain`), and `size` (`default` | `sm` | `icon`), with natural `Tab` order, `Enter`/`Space` activation, open-state feedback, and `focusSelf()`.
- **Content**: Unmounts content when closed by default (set `keepMounted={true}` to keep the hidden node mounted) and supports `variant="plain"` for seamless card, settings, and file-tree compositions.

### Controlled State

Pass `open` and handle `openChange` to control expansion externally. Setting `disabled={true}` prevents toggling without closing content that is already open.

```tsx
import { useState } from 'react';

export function ControlledExample() {
  const [open, setOpen] = useState(false);

  return (
    <ShadcnCollapsibleRoot open={open} onOpenChange={(req) => setOpen(req.open)}>
      <ShadcnCollapsibleTrigger>Toggle details</ShadcnCollapsibleTrigger>
      <ShadcnCollapsibleContent>Panel content</ShadcnCollapsibleContent>
    </ShadcnCollapsibleRoot>
  );
}
```

For multi-item groups with arrow-key header navigation, use [Accordion](../accordion/). See [Base Collapsible](/en/ui-libraries/base/collapsible/) for the shared protocol details.

### Events and Methods

- **Root events**: `openChange` with payload `{ open: boolean, reason: 'pointer' | 'keyboard' | 'programmatic' }`
- **Root methods**: `openCollapsible(reason?)`, `close(reason?)`, `toggle(reason?)`
- **Trigger methods**: `focusSelf(options?)`
