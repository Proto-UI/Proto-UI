A single-panel disclosure component composed of `Root`, `Trigger`, and `Content` with controlled state and explicit mount lifecycle behavior. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

<InstallCommandCard command="npx @proto.ui/cli@latest add wc shadcn-collapsible" manager="npm" />

Replace `wc` with `react`, `vue`, or `vue2` to generate the local facade for your framework.

You can also import the parts directly from `@proto.ui/prototypes-shadcn/collapsible`:

```ts
import {
  collapsibleRoot,
  collapsibleTrigger,
  collapsibleContent,
} from '@proto.ui/prototypes-shadcn/collapsible';
```

## Usage

### Anatomy

Place one `Trigger` and one `Content` inside each `Root` (nested and sibling `Root` instances keep independent state):

- **Root**: Manages open state via `open`, `defaultOpen`, and `disabled`. Exposes `open`, methods `openCollapsible`, `close`, and `toggle`, and `openChange` with payload `{ open, reason }`.
- **Trigger**: Accepts its own `disabled` prop and automatically handles expanded/disabled states, button accessibility, natural `Tab` order, `Enter`/`Space` activation, and `focusSelf`.
- **Content**: Unmounts content when closed by default; set `keepMounted={true}` to keep the hidden node mounted.

### Controlled and disabled behavior

- Pass `open` to control expansion externally: interaction emits `openChange` without changing the panel until you pass back the updated `open` value.
- Setting `disabled={true}` prevents toggling without closing content that is already open.
- Built-in styles handle narrow containers, long-word wrapping, and auto content height. For multi-item groups with arrow-key header navigation, use [Accordion](../accordion/). See [Base Collapsible](/en/ui-libraries/base/collapsible/) for the shared protocol details.

## API

Passing `open` selects controlled mode.

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
  ]}
/>

These props belong to `Root`. `Trigger` defaults `disabled` to `false`; `Content` defaults `keepMounted` to `false`.
