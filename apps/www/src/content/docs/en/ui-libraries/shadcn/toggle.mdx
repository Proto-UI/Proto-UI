## Usage

```tsx
import { ShadcnToggle } from '../proto-ui/components/react';
```

```tsx
<ShadcnToggle variant="outline">Toggle</ShadcnToggle>
```

- **Variants & sizes**: Choose `'default'` or `'outline'` with `variant`, and `'sm'`, `'default'`, or `'lg'` with `size`.
- **Style presets (`styleProfile`)**: Supports `vega`, `nova`, `maia`, `lyra`, `mira`, `luma`, `sera`, `rhea`, and `new-york-v4` (inherits the nearest [Style Scope](../style-scope/) when omitted).
- **Controlled & uncontrolled**: Pass `active` and handle `activeChange` for controlled state, or use `defaultActive` for uncontrolled initialization.
- **Keyboard & accessibility**: Activates with click, `Enter`, or `Space` and reflects persistent state through `aria-pressed`. Icon-only toggles should include a visually hidden text label for screen readers. For coordinated sets of toggles, use [Toggle Group](../toggle-group/).

## API

The following props belong to `Root` (pass `active` for controlled mode):

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'active', type: 'boolean | undefined', default: 'uncontrolled' },
    { name: 'defaultActive', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'variant', type: "'default' | 'outline'", default: "'default'" },
    { name: 'size', type: "'default' | 'sm' | 'lg'", default: "'default'" },
    {
      name: 'styleProfile',
      type: "'inherit' | 'vega' | 'nova' | 'maia' | 'lyra' | 'mira' | 'luma' | 'sera' | 'rhea' | 'new-york-v4'",
      default: "'inherit' → nearest scope → 'new-york-v4'",
    },
  ]}
/>

- **Events**: `activeChange` (payload `{ active: boolean }`).
- **Methods**: `focusSelf(options?)` (no-op while disabled).
- **Exposed states**: `active`, `disabled`, `hovered`, `focused`, `focusVisible`, `pressed`.
