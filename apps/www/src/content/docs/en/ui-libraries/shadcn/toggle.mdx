Toggle is a two-state button that switches between active (pressed) and inactive states, commonly used in formatting bars and option strips. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

<InstallCommandCard command="npx @proto.ui/cli@latest add wc shadcn-toggle" manager="npm" />

Replace `wc` with `react`, `vue`, or `vue2` to generate the facade for your target framework.

## Usage

- Choose `'default'` or `'outline'` via `variant`, and `'default'`, `'sm'`, or `'lg'` via `size`.
- Under the **Shadcn Rhea** preset, `default`, `sm`, and `lg` heights are `2rem`, `1.75rem`, and `2.25rem`, with shadowless `outline` borders and muted hover/pressed surfaces. Under `new-york-v4`, heights are `36px` / `32px` / `40px` with accent active styling.
- Pass `active` and listen to `activeChange` for controlled state, or use `defaultActive` for uncontrolled state.

## API

The following props belong to `Root` (pass `active` for controlled mode):

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'active', type: 'boolean | undefined', default: 'uncontrolled' },
    { name: 'defaultActive', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'variant', type: "'default' | 'outline'", default: 'default' },
    { name: 'size', type: "'default' | 'sm' | 'lg'", default: 'default' },
  ]}
/>

`Root` exposes `active`, `disabled`, `hovered`, `focused`, `focusVisible`, and `pressed`, and emits `activeChange`.
