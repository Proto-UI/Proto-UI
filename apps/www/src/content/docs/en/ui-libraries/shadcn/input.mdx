Ordinary demos on this page explicitly use **Shadcn Rhea**, with matching examples. This does not change public compatibility defaults or imply complete browser, native-host or visual acceptance. Neutral Surface/Text atoms retain their own public semantics; the consumer composition supplies the family presentation theme.

This entry shows Proto UI's draft Shadcn Base Input projection with the public Rhea profile selected explicitly. Its modern style reference is the [Rhea style source](https://github.com/shadcn-ui/ui/blob/3d98900e9b73c45f035f8109e9d41ba6a51685e7/apps/v4/registry/styles/style-rhea.css). The separate [base-nova snapshot](https://ui.shadcn.com/r/styles/base-nova/input.json) retrieved on 2026-10-10 (SHA256 `bbad1bba130ac9750a61844eeb8f043e8a710846e07689fa85398b80a46c2741`) remains the unscoped compatibility reference, not the appearance selected by this page. This is an independent Proto UI implementation, not an upstream package or endorsement.

Base Input owns the single-line text value, controlled/uncontrolled behavior, normalized editing and IME events, native text properties, textbox naming and description, disabled/read-only state, and focus/blur. The Shadcn layer consumes that protocol and adds a bounded field surface, focus-visible ring, disabled treatment, and dark-scheme background. Exactly one host-owned `input[type="text"]` is rendered.

The selected Rhea recipe uses `h-8`, the family `radius-2xl`, `bg-input/50`, a transparent resting border and `px-2.5 py-1`; that is a 32px height and 10px inline padding at a 16px root font. Its focus treatment is `border-ring ring-3 ring-ring/30`, with the public viewport rule reducing base text to small text from 768 logical pixels. These are source recipe facts, not native geometry acceptance. The standalone selection colors remain an explicit Proto UI extension. Base Input still has no invalid state; Field Control supplies its own invalid fact. This projection adds no arbitrary input type, form workflow, selection API or second editor. Placeholder styling and full upstream/browser parity remain separate gaps.
