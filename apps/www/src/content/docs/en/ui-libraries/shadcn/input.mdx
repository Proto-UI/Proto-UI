A single-line text input built on [Base Input](../../base/input/) with controlled and uncontrolled values, normalized IME composition events, disabled/read-only handling, and accessible naming, rendered as a native `input[type="text"]` on Web. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

<InstallCommandCard command="npx @proto.ui/cli@latest add wc shadcn-input" manager="npm" />

Replace `wc` with `react`, `vue`, or `vue2` to generate the local facade for your framework. You can also import `shadcnInputRoot` directly from `@proto.ui/prototypes-shadcn/input`.

## Usage

- **Style preset**: Under **Shadcn Rhea**, the input uses `h-8` (32px height), `radius-2xl`, `bg-input/50`, `px-2.5 py-1`, and a `border-ring ring-3 ring-ring/30` focus ring, scaling text down to small at viewports `>= 768px`. Without an enclosing [Style Scope](../style-scope/), it retains its default compatibility styling.
- **Validation and labels**: Standalone `Input` handles text editing without built-in validation state; pair with [Field](../field/) for validation errors, descriptions, and label wiring.
- **Resetting values**: `Root` exposes `resetValue(value?: string): boolean` from [Base Input](../../base/input/) to reset the editor to its initial or supplied value.

## API

Passing `value` selects controlled mode. `inputMode` and `enterKeyHint` are optional with no default.
