A single-line text input for forms and user data entry built on [Base Input](../../base/input/), providing controlled and uncontrolled value management, normalized IME composition events, disabled and read-only handling, and accessible naming. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

This component is available from workspace source. In your application, install the CLI, Shadcn prototypes and target adapter built from the same workspace revision, then initialize the project with that CLI. Run the locally installed CLI to generate the facade.

<InstallCommandCard command="npm exec -- proto-ui add wc shadcn-input" manager="npm" />

Replace `wc` with `react`, `vue`, or `vue2` to generate the local facade for your framework. You can also import `shadcnInputRoot` directly from `@proto.ui/prototypes-shadcn/input`.

## Usage

```tsx
import { ShadcnInputRoot } from '@/components/ui/shadcn-input';

export function Example() {
  return <ShadcnInputRoot placeholder="Enter text" ariaLabel="Text input" />;
}
```

- **Style presets**: Switch presets via an enclosing [Style Scope](../style-scope/) or `styleProfile`. Under **Shadcn Rhea**, the input uses `h-8` (32px), `radius-2xl`, `bg-input/50` (`bg-input/30` in dark mode), and a `border-ring ring-3 ring-ring/30` focus ring, scaling text to small at viewports `>= 768px`.
- **Validation and labels**: Standalone `Input` focuses on text editing; pair with [Field](../field/) for label focus forwarding, helper descriptions, and validation error styling.
- **Accessibility and methods**: `Root` exposes `focusSelf()`, `blurSelf()`, and `resetValue(value?: string)`, along with `ariaLabel`, `labelledBy`, and `describedBy`.

- **States**: `value`, `disabled`, `readOnly`, `focused`, `focusVisible`, `composing`
