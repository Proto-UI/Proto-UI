This entry shows Proto UI's draft Shadcn-style Base Input projection. The visual reference is the [base-nova Input registry](https://ui.shadcn.com/r/styles/base-nova/input.json) snapshot retrieved on 2026-10-10 (registry SHA256 bbad1bba130ac9750a61844eeb8f043e8a710846e07689fa85398b80a46c2741). It replaces the earlier new-york reference for this draft. This is an unofficial Proto UI implementation, not an upstream package or endorsement.

Base Input owns the single-line text value, controlled/uncontrolled behavior, normalized editing and IME events, native text properties, textbox naming and description, disabled/read-only state, and focus/blur. The Shadcn layer consumes that protocol and adds a bounded field surface, focus-visible ring, disabled treatment, and dark-scheme background. Exactly one host-owned `input[type="text"]` is rendered.

The bounded recipe uses a 32px height, rounded-lg corners, 10px horizontal padding, no resting shadow, and the source disabled/dark palette. Current real-browser visual acceptance remains pending. The existing static `selection:bg-primary selection:text-primary-foreground` palette is retained as an explicit Proto UI extension; it is absent from this base-nova recipe. Other style variants such as upstream `placeholder:*` and responsive `md:*` remain unsupported. Upstream does not set a custom text cursor or caret color, so those remain native browser behavior here as well. Base Input has no invalid state, and this projection exposes neither arbitrary `type`, caller `className`, nor `data-slot`. It adds no form/validation workflow, selection API, or second editor.
