The family keeps the exact Base Table anatomy: Root owns the independent Table domain, Caption supplies the authored purpose, Row establishes one ordered logical row, HeaderCell declares a `headerKey` and `headerKind: 'column' | 'row'`, and Cell carries an ordered set of `headers` keys. `rowSpan` and `columnSpan` are positive integers defaulting to one. The shadcn layer adds only upstream paint — collapsed borders, cell paddings, header emphasis and muted footer — plus two visual-only props on Row: `section: 'header' | 'body' | 'footer'` (default `body`) and `lastInSection` (default `false`) drive the border rules. Neither prop declares a row-group or changes accessibility; an external scrolling container stays consumer-owned. Table itself adds no sorting, selection, editing, data operations, or keyboard-grid behavior.

Parts: Root, Caption, Row, HeaderCell, Cell.
