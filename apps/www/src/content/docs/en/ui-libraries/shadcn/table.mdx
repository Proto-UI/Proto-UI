Table presents structured tabular data over the [Base Table](/en/ui-libraries/base/table/) protocol, adding Shadcn collapsed borders, cell padding, header emphasis, and muted footer styling. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

Table consists of five parts: `Root`, `Caption`, `Row`, `HeaderCell`, and `Cell`:

- `Root` creates the table scope and `Caption` describes the table's purpose.
- `Row` defines an ordered logical row and accepts two styling props to drive borders: `section` (`'header' | 'body' | 'footer'`, default `'body'`) and `lastInSection` (default `false`).
- `HeaderCell` declares `headerKey` and `headerKind` (`'column' | 'row'`); `Cell` references its headers via an ordered `headers` key list and supports positive integer `rowSpan` and `columnSpan` (defaulting to `1`).
- Wrap `Table` in an outer scroll container if horizontal scrolling is needed. For sorting, filtering, or row selection, use Data Table.

## API

`Root` (`TableRootProps`) has no props. Part props include:

- `Row`: `section` (`'header' | 'body' | 'footer'`, default `'body'`), `lastInSection` (`boolean`, default `false`).
- `HeaderCell`: `headerKey` (`string`), `headerKind` (`'column' | 'row'`), `rowSpan` (default `1`), `columnSpan` (default `1`).
- `Cell`: `headers` (ordered header keys), `rowSpan` (default `1`), `columnSpan` (default `1`).
