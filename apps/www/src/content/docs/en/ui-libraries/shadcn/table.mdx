Table presents structured tabular data over the [Base Table](/en/ui-libraries/base/table/) protocol, adding Shadcn collapsed borders, cell padding, row hover and selected highlights, and muted footer styling. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Available starting in `0.3.0-rc.1` and later releases. Import the parts from `@proto.ui/prototypes-shadcn/table`:

```ts
import {
  tableRoot,
  tableCaption,
  tableRow,
  tableHeaderCell,
  tableCell,
} from '@proto.ui/prototypes-shadcn/table';
```

## Usage

```html
<div class="w-full overflow-x-auto">
  <shadcn-table-root style-profile="rhea">
    <shadcn-table-caption>A list of your recent invoices.</shadcn-table-caption>
    <shadcn-table-row section="header" last-in-section>
      <shadcn-table-header-cell header-key="invoice" header-kind="column" style="width: 100px">
        Invoice
      </shadcn-table-header-cell>
      <shadcn-table-header-cell header-key="status" header-kind="column"
        >Status</shadcn-table-header-cell
      >
      <shadcn-table-header-cell header-key="method" header-kind="column"
        >Method</shadcn-table-header-cell
      >
      <shadcn-table-header-cell header-key="amount" header-kind="column" style="text-align: end">
        Amount
      </shadcn-table-header-cell>
    </shadcn-table-row>
    <shadcn-table-row section="body" last-in-section>
      <shadcn-table-header-cell header-key="inv001" header-kind="row"
        >INV001</shadcn-table-header-cell
      >
      <shadcn-table-cell>Paid</shadcn-table-cell>
      <shadcn-table-cell>Credit Card</shadcn-table-cell>
      <shadcn-table-cell style="text-align: end">$250.00</shadcn-table-cell>
    </shadcn-table-row>
  </shadcn-table-root>
</div>
```

### Composition

```text
Root
├── Caption
├── Row (section="header")
│   └── HeaderCell (headerKind="column")
├── Row (section="body")
│   ├── HeaderCell (headerKind="row")
│   └── Cell (headers=[...])
└── Row (section="footer")
    ├── HeaderCell (headerKind="row")
    └── Cell (headers=[...])
```

- `Root` creates the table structure scope and exposes `getStructure()`; wrap it in an outer `overflow-x-auto` container for horizontal scrolling.
- `Row` accepts visual-only `section`, `lastInSection`, and `selected` props to control borders and row highlights without synthesizing row-group roles or selection state.
- `HeaderCell` uses logical `text-start` alignment so RTL layouts mirror naturally; align trailing numeric columns with `text-align: end`.
- `rowSpan` and `columnSpan` project accessible span metadata. For sorting, filtering, pagination, or row selection, use [Data Table](/en/ui-libraries/shadcn/data-table/).
