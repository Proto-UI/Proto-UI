The region owns one `busy` prop (default `false`) that projects `aria-busy` on the region element and exposes the same fact through `getExposes().busy`. Busy is a semantic fact, not a spinner: the projection adds no role, accessible name, loading timers, replacement state machine, announcement channel, or focus path. Authored descendants stay mounted and keep focus across prop-only transitions. For announcements, compose with Live Region at the application layer.
