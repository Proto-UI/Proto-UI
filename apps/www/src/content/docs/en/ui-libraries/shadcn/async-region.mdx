## Usage

Currently available from workspace source; not yet included in the 0.2.0 stable release.

`Async Region` consists of a single `Root` part:

- Setting `busy={true}` reflects `aria-busy` on the region element and exposes the same state through `getExposes().busy`.
- When updating props, your children stay mounted and preserve their focus.
- Render your own loading indicator inside or beside the region as needed. To announce status updates to assistive technology, pair it with [Live Region](../live-region/) at the application layer.
