Marks a region of your UI with `aria-busy` semantics during asynchronous updates without imposing a built-in spinner or disturbing focus. While `shadcn-async-region-root` itself is a neutral semantic container, the accompanying controls on this page use the **Shadcn Rhea** style preset.

## Installation

Available starting in `0.3.0-rc.1` and later releases (currently available from workspace source). Import the prototype directly from its package entry:

```ts
import { asyncRegionRoot } from '@proto.ui/prototypes-shadcn/async-region';
```

## Usage

```tsx
import { useState } from 'react';
import { AdaptToReact } from '@proto.ui/adapter-react';
import { asyncRegionRoot } from '@proto.ui/prototypes-shadcn/async-region';

const ShadcnAsyncRegionRoot = AdaptToReact(asyncRegionRoot);

export function ActivityFeed() {
  const [busy, setBusy] = useState(false);

  return (
    <ShadcnAsyncRegionRoot busy={busy}>
      <p>Existing feed items stay mounted while refreshing.</p>
    </ShadcnAsyncRegionRoot>
  );
}
```

`Async Region` consists of a single `Root` (`shadcn-async-region-root`) part:

- **Synchronized busy semantics**: Setting `busy={true}` synchronously reflects `aria-busy="true"` on the region element and exposes the same boolean through `getExposes().busy`, with neutral block layout and foreground ink (`block min-w-0 max-w-full text-foreground`).
- **Preserved children and focus**: Prop-only transitions keep authored descendants mounted and focused. Setting `busy={true}` never makes the subtree inert or automatically disables inner controls.
- **Consumer-owned loading UI**: No extra `data-busy` hook, skeleton, or spinner is injected. Style busy transitions via the standard `[aria-busy="true"]` attribute selector and compose your own loading indicators or [Live Region](../live-region/) announcements as needed.

```css
shadcn-async-region-root[aria-busy='true'] {
  opacity: 0.65;
}
```
