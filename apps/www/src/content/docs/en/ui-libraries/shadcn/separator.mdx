Ordinary demos on this page explicitly use **Shadcn Rhea**, with matching examples. This does not change public compatibility defaults or imply complete browser, native-host or visual acceptance. Neutral Surface/Text atoms retain their own public semantics; the consumer composition supplies the family presentation theme.

This entry shows the current `shadcn` separator implementation in Proto UI.

Base Separator owns the protocol: `orientation` defaults to `horizontal`, and `decorative` defaults to `true`. A decorative separator stays hidden from the accessibility tree with no role, while `decorative={false}` projects the `separator` role and a matching `aria-orientation`. The shadcn layer adds presentation only — the border color and the 1px hairline geometry that follows the inherited orientation.

The separator is contentless and declares no focus, tab stop, or event channel. Length comes from the surrounding layout, and spacing stays with the composition.

The demo is one column: a horizontal rule, a row of vertical rules, then a non-decorative horizontal rule that exposes `separator`.
