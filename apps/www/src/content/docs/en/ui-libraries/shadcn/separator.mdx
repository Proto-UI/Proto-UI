Separator renders a 1px horizontal or vertical divider to separate content visually or semantically. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

<InstallCommandCard command="npx @proto.ui/cli@latest add wc shadcn-separator" manager="npm" />

Replace `wc` with `react`, `vue`, or `vue2` to generate the facade for your target framework.

## Usage

- `orientation` defaults to `'horizontal'`; set it to `'vertical'` for a vertical rule. Length is determined by the surrounding layout container, and spacing is controlled by your composition.
- `decorative` defaults to `true`, hiding the divider from assistive technologies. Set `decorative={false}` to expose `role="separator"` and the matching `aria-orientation`.
- Separator is contentless—it takes no children and does not participate in focus or events.
