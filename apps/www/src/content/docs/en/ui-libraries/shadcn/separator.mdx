Separator renders a 1px horizontal or vertical hairline to visually or semantically separate adjacent content. The examples on this page use the **Shadcn Rhea** style preset.

## Usage

```tsx
import { ShadcnSeparatorRoot } from '../proto-ui/components/react';
```

```tsx
<ShadcnSeparatorRoot styleProfile="rhea" />
```

- `orientation` defaults to `'horizontal'`; pass `'vertical'` for a vertical rule. Modern presets (such as `rhea` and `nova`) stretch automatically along flex cross-axes (`self-stretch`), while `new-york-v4` retains `h-full`.
- `decorative` defaults to `true`, hiding the divider from assistive technologies. Pass `decorative={false}` to expose `role="separator"` and the matching `aria-orientation`.
- Separator is contentless and non-interactive—it accepts no children, takes no focus stop, and delegates spacing to the surrounding layout.

## API

The following props belong to `Root`:

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default', description: 'Description' }}
  rows={[
    {
      name: 'orientation',
      type: "'horizontal' | 'vertical'",
      default: "'horizontal'",
      description: 'Divider orientation',
    },
    {
      name: 'decorative',
      type: 'boolean',
      default: 'true',
      description:
        'Hides the rule from assistive technology when true; exposes role="separator" and aria-orientation when false',
    },
    {
      name: 'styleProfile',
      type: "'inherit' | 'vega' | 'nova' | 'maia' | 'lyra' | 'mira' | 'luma' | 'sera' | 'rhea' | 'new-york-v4' | 'new-york'",
      default: "'inherit'",
      description: 'Visual preset; falls back to new-york-v4 outside a Style Scope',
    },
  ]}
/>

Exposes read-only `orientation` and `decorative` states with no interaction events or focus methods.
