Number Field provides a `spinbutton` numeric input supporting increment/decrement buttons, keyboard stepping, `Intl` locale formatting, nullable values, and label drag-to-scrub. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the parts directly from `@proto.ui/prototypes-shadcn/number-field`:

```ts
import {
  numberFieldRoot,
  numberFieldLabel,
  numberFieldInput,
  numberFieldControl,
  numberFieldIncrement,
  numberFieldDecrement,
} from '@proto.ui/prototypes-shadcn/number-field';
```

## Usage

Compose `Root`, `Label`, `Input`, `Control`, `Increment`, and `Decrement`:

```tsx
<ShadcnNumberFieldRoot defaultValue={12} min={0} max={100} step={1} ariaLabel="Quantity">
  <ShadcnNumberFieldLabel>Quantity</ShadcnNumberFieldLabel>
  <ShadcnNumberFieldDecrement>
    <span aria-hidden="true">−</span>
    <span className="sr-only">Decrease Quantity</span>
  </ShadcnNumberFieldDecrement>
  <ShadcnNumberFieldInput />
  <ShadcnNumberFieldIncrement>
    <span aria-hidden="true">+</span>
    <span className="sr-only">Increase Quantity</span>
  </ShadcnNumberFieldIncrement>
</ShadcnNumberFieldRoot>
```

Inside `Field` or `FormField`, replace `Input` with `Control` to connect `FieldLabel`, validation errors, form serialization, and reset automatically:

```tsx
<ShadcnFieldRoot required>
  <ShadcnFieldLabel>Quantity</ShadcnFieldLabel>
  <ShadcnNumberFieldRoot defaultValue={1} min={1} max={99}>
    <ShadcnNumberFieldDecrement>−</ShadcnNumberFieldDecrement>
    <ShadcnNumberFieldControl />
    <ShadcnNumberFieldIncrement>+</ShadcnNumberFieldIncrement>
  </ShadcnNumberFieldRoot>
  <ShadcnFieldError />
</ShadcnFieldRoot>
```

- **Keyboard and editing**: Incomplete drafts stay editable until `Enter` or blur commits a valid number or restores the last accepted value. `ArrowUp` / `ArrowDown` step by `step` (hold `Shift` for 10× steps), and `Home` / `End` jump to `min` / `max`. Parsing, commits, stepping, and scrubbing pause during IME composition.
- **Localized formatting**: Configure `locale` and `formatOptions` for decimal, currency, and percent display and parsing without rounding away underlying precision. Invalid options expose `formatInvalid` and fall back to ungrouped decimals.
- **Empty values and scrubbing**: Enable `allowEmpty` so clearing the field commits `null` (read exact `number | null` via `getValue()` and check `empty`). Enable `scrub` to drag horizontally across `Label` for continuous adjustment.
