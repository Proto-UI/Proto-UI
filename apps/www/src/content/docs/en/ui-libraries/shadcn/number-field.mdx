Number Field provides a `spinbutton` numeric input supporting increment/decrement buttons, keyboard stepping, locale-aware formatting, nullable values, and drag-to-scrub on its label. The examples on this page use the **Shadcn Rhea** style preset.

## Usage

Number Field consists of `Root`, `Label`, `Input`, `Control`, `Increment`, and `Decrement`:

- `Root` manages the `number | null` value, bounds (`min`/`max`, defaulting to `0`/`100`), positive `step` (`1`), and disabled/read-only state.
- Use `Input` with `NumberFieldLabel` for standalone fields; inside `Field` or `FormField`, use `Control` instead so `FieldLabel`, validation, IME cancellation, serialization, and form reset connect automatically.
- `Increment` and `Decrement` share the same stepping logic as keyboard arrow keys.

### Editing and keyboard stepping

- Incomplete drafts stay intact while typing; pressing `Enter` or blurring commits a valid number or restores the last accepted value.
- `ArrowUp` / `ArrowDown` step by `step`, holding `Shift` multiplies by 10, and `Home` / `End` jump to `min` / `max`.
- Pass `value` to enter controlled mode—user interactions emit update requests without overwriting the controlled value directly.
- During IME composition, parsing, commits, stepping, and scrubbing pause automatically; changing `locale` preserves ongoing composition text.

### Localized formatting

Use `locale` and `formatOptions` for decimal, currency, and percent formatting as well as parsing localized digits, separators, and signs. Display rounding never mutates underlying numeric precision, including commits without edits. Invalid format options set `formatInvalid` and fall back to ungrouped decimals.

### Empty values

- Explicit `null` represents an empty field, and `value={null}` remains controlled.
- `allowEmpty` defaults to `false`; enable it to allow clearing the input and committing `null`.
- `getValue()` on `Root`, `Input`, and `Control` returns `number | null`, while `empty` flags emptiness. The compatibility numeric `value` getter holds the last finite number while empty; events and Field/Form integrations always receive actual `null`.
- The first step from `null` initializes to snapped `0` within bounds.

### Label scrubbing

Enable `scrub` to adjust the value continuously by dragging across `Label`:

- `scrubSteps` (default `100`) defines how many steps correspond to dragging across one initial label width; `direction="rtl"` reverses horizontal movement.
- Releasing after a change commits once; canceling restores the starting value in uncontrolled mode. Text selection inside the input remains unaffected.
