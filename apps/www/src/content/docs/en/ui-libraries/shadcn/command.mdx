## Usage

Currently available from workspace source; not yet included in the 0.2.0 stable release.

### Anatomy

Compose `Command` from `Root`, `Input`, `Content`, `Item`, and `Empty` (`Command` stays inline and has no `Trigger`):

- The list opens inline by default (`defaultOpen={true}`). Typing updates the filter without executing any command.
- Pressing `Enter` or clicking an item emits `execute` with the selected item so your application can perform the action.

### Filtering and interaction

- **Built-in filtering**: Matches case- and diacritic-insensitively over `textValue` and `keywords`. Set `filter={false}` to render pre-filtered children.
- **Empty and disabled states**: `Empty` reflects the live match count; disabled items and duplicate-valued items cannot execute.
- **Keyboard and IME**: Focus stays in the input during arrow-key navigation, and IME composition never triggers execution.
- **Controlled state**: `open`, `value`, and `inputValue` can each be controlled independently.

## API

Passing `value`, `inputValue`, or `open` enables controlled mode for that state. Because the command list stays inline, `defaultOpen` defaults to `true`.

These props belong to `Root`. Other part defaults:

- **Input**: `placeholder`, `a11yLabel`, and `name` default to `''`.
- **Content**: `side="bottom"`, `align="start"`, `sideOffset={4}`, `collisionPadding={8}`.
- **Item**: `value`, `textValue`, and `keywords` default to `''`; `disabled` defaults to `false`.
