A searchable command palette with real-time filtering and keyboard navigation. Clicking an item or pressing `Enter` emits an `execute` event for your application to handle. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Available starting in `0.3.0-rc.1` and later releases (`@proto.ui/prototypes-shadcn/command`).

## Usage

```tsx
import {
  commandRoot,
  commandInputWrapper,
  commandInput,
  commandContent,
  commandItem,
  commandEmpty,
  commandDialogContent,
  commandDialogMask,
} from '@proto.ui/prototypes-shadcn/command';
import { inputShell } from '@proto.ui/prototypes-shadcn/input-shell';
```

### Composition

```text
CommandRoot
├── CommandInputWrapper
│   └── InputShell (focusIndicator="none")
│       └── CommandInput
└── CommandContent
    ├── CommandItem
    └── CommandEmpty
```

- **Inline by default**: `defaultOpen` defaults to `true`. Typing filters matching items without executing anything; activating an item via click or `Enter` emits `execute`.
- **Command dialog**: Compose `DialogRoot`, `DialogTrigger`, `CommandDialogMask`, and `CommandDialogContent` with matching `enterDuration` and `leaveDuration` for the selected profile (`100` for Rhea, `200` for New York).
- **Filtering and keyboard**: Matches case- and diacritic-insensitively over `textValue` and `keywords`, or set `filter={false}` for caller-filtered children. Focus remains in the input during arrow navigation and IME composition never triggers execution.

## API

### Root

Pass `value`, `inputValue`, or `open` to control each state independently. Use `styleProfile` directly or via an outer `shadcn-style-scope` to select among all 9 built-in styles.

### Other Parts & Events

- **InputWrapper**: Passive input container supporting `styleProfile` and `presentation` (`'default' | 'menu'`).
- **Input**: `placeholder`, `a11yLabel`, and `name` default to `''`.
- **Content**: `side="bottom"`, `align="start"`, `sideOffset={4}`, `collisionPadding={8}`.
- **Item**: `value`, `textValue`, and `keywords` default to `''`; `disabled` defaults to `false`.
- **Empty**: No props; reflects the live match count.
- **DialogContent / DialogMask**: Requires `enterDuration: number` and `leaveDuration: number`; `DialogContent` also accepts `styleProfile` and `presentation`.
- **Events**: `Root` emits `execute`, `valueChange`, `inputValueChange`, and `openChange`.
