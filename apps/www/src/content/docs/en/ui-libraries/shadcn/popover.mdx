Content is positioned against Trigger, with side, align, sideOffset, alignOffset and collisionPadding. It is not modal and does not lock background scrolling or trap Tab. Outside press, focus moving beyond Trigger and Content, Escape and Close request dismissal. Moving focus between Trigger and portalled content stays inside. A focus-outside close leaves focus on the outside control; it does not restore focus to Trigger.

Root supports controlled open or uncontrolled defaultOpen. Disabled commands do not activate. Supplying open leaves the committed value with the owner; listen to openChange and provide the next value. Refusing a focus.outside request keeps Content present and does not trap focus. A later interaction can request dismissal again. Focus-only requests report focusReason as programmatic because the neutral focus observation does not identify an input device.

Parts: Root, Trigger, Content, Title, Description, Close.

## API

Passing `open` selects controlled mode. Content placement defaults are separate from Root.

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'open', type: 'boolean | undefined', default: 'uncontrolled' },
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'a11yLabel', type: 'string', default: "''" },
    { name: 'side', type: "'top' | 'right' | 'bottom' | 'left'", default: 'bottom' },
    { name: 'align', type: "'start' | 'center' | 'end'", default: 'center' },
    { name: 'sideOffset', type: 'number', default: '4' },
    { name: 'alignOffset', type: 'number', default: '0' },
    { name: 'collisionPadding', type: 'number', default: '8' },
    { name: 'presentation', type: "'default' | 'navigation'", default: 'default' },
  ]}
/>

`side` through `collisionPadding` belong to Content. `presentation` is the Shadcn Trigger and Content paint prop. Root exposes `open`, `openPopover`, `close`, `toggle`, and `openChange`.
