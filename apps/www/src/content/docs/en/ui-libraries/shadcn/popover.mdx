Popover displays a non-modal floating surface anchored to a trigger, suited for quick settings, compact forms, or lightweight navigation panels. The examples on this page use the **Shadcn Rhea** style preset.

## Usage

Popover consists of `Root`, `Trigger`, `Content`, `Title`, `Description`, and `Close`:

- `Content` positions itself relative to `Trigger` using `side`, `align`, `sideOffset`, `alignOffset`, and `collisionPadding`.
- Because Popover is non-modal, background scrolling remains unlocked and `Tab` navigation is not trapped.
- Pressing outside, moving focus out of `Trigger` and `Content`, pressing `Escape`, or activating `Close` requests dismissal. Moving focus between `Trigger` and portalled `Content` counts as staying inside; closing due to focus moving outside leaves focus on that external element.

### Controlled and uncontrolled

- `Root` supports controlled `open` and uncontrolled `defaultOpen`.
- In controlled mode, listen to `openChange` and provide the next value. Rejecting a `focus.outside` request keeps `Content` visible without trapping external focus. Focus-only outside dismissals report `focusReason` as `'programmatic'`.

### Navigation presentation

Set `presentation="navigation"` on `Trigger` and `Content` to render a scrollable anchored navigation panel where native links keep standard browser behavior:

## API

Pass `open` for controlled mode. `Root` exposes `open`, `openPopover`, `close`, `toggle`, and `openChange`:

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'open', type: 'boolean | undefined', default: 'uncontrolled' },
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'a11yLabel', type: 'string', default: "''" },
    { name: 'side', type: "'top' | 'right' | 'bottom' | 'left'", default: 'bottom' },
    { name: 'align', type: "'start' | 'center' | 'end'", default: 'center' },
    { name: 'sideOffset', type: 'number', default: '4' },
    { name: 'alignOffset', type: 'number', default: '0' },
    { name: 'collisionPadding', type: 'number', default: '8' },
    { name: 'presentation', type: "'default' | 'navigation'", default: 'default' },
  ]}
/>

Prop ownership:

- `open`, `defaultOpen`, `disabled`, and `a11yLabel` belong to `Root`.
- `side`, `align`, `sideOffset`, `alignOffset`, and `collisionPadding` belong to `Content`.
- `presentation` belongs to `Trigger` and `Content`.
