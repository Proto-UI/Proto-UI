Popover displays rich non-modal content anchored to a trigger, suited for quick settings, compact forms, or lightweight navigation panels. Examples on this page use the **Shadcn Rhea** style preset.

## Installation

Popover will be available starting in `0.3.0-rc.1` and later releases (currently available from workspace source). Import the prototypes directly from `@proto.ui/prototypes-shadcn/popover` and adapt them to Web Components, React, Vue 3, or Vue 2:

```ts
import {
  popoverRoot,
  popoverTrigger,
  popoverContent,
  popoverTitle,
  popoverDescription,
  popoverClose,
} from '@proto.ui/prototypes-shadcn/popover';
```

## Usage

```tsx
<Popover styleProfile="rhea">
  <PopoverTrigger>Open Popover</PopoverTrigger>
  <PopoverContent align="start">
    <PopoverTitle>Dimensions</PopoverTitle>
    <PopoverDescription>Set the dimensions for the layer.</PopoverDescription>
  </PopoverContent>
</Popover>
```

### Composition

```text
PopoverRoot
├── PopoverTrigger
└── PopoverContent
    ├── PopoverTitle
    ├── PopoverDescription
    └── PopoverClose
```

- **Positioning & collisions**: `Content` anchors relative to `Trigger` with `side`, `align`, `sideOffset`, `alignOffset`, and `collisionPadding`.
- **Non-modal focus & dismissal**: Background scrolling stays unlocked and `Tab` navigation is not trapped. Pressing outside, pressing `Escape`, activating `Close`, or moving focus outside both `Trigger` and `Content` requests dismissal. When dismissed by focus leaving, focus remains on the newly focused external element.
- **Style presets**: Supports `vega`, `nova`, `maia`, `lyra`, `mira`, `luma`, `sera`, `rhea`, and `new-york-v4`, inherited from `shadcn-style-scope` or set per part via `styleProfile`.

## API

`Root` exposes read-only state `open`, methods `openPopover`, `close`, and `toggle`, and the `openChange` event.
