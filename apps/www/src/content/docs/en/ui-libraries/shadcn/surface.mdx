Surface is a passive visual container inheriting the [Base Surface](/en/ui-libraries/base/surface/) input contract, applying Shadcn backgrounds, borders, radii, and elevation from props supplied by the enclosing component. The examples on this page use the **Shadcn Rhea** style preset.

## Usage

Import `surfaceRoot` from `@proto.ui/prototypes-shadcn/surface` (or the package root) and adapt it to your runtime:

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { surfaceRoot } from '@proto.ui/prototypes-shadcn/surface';

const Surface = createReactAdapter(React)(surfaceRoot);

export function Summary() {
  return (
    <Surface variant="muted" radius="md" border="none">
      <div style={{ padding: '1rem' }}>Saved locally</div>
    </Surface>
  );
}
```

### Visual states and composition

- `hovered`, `focusVisible`, `pressed`, and `current` are visual inputs forwarded from an enclosing interactive component; Surface does not listen for pointer, focus, or keyboard events and adds no ARIA role. Use a Button component or native `<a>` element when you need interactive behavior.
- Outer layout and inner padding belong to your composition. When a nested `Text` should inherit foreground contrast from a `solid` or `accent` Surface, pass `tone="inherit"` to `Text`.
- With the default `actionProfile="none"`, `pressed` does not translate the surface. Opting into `rhea` or `luma` action appearance enables the 1px press offset.

### Fading with Transition

- Enable `fade` to map `transitionState` from [Base Transition](/en/ui-libraries/base/transition/) to opacity (`closed` and `leaving` -> `0`, `entering` and `entered` -> `1`).
- On the Web, fade duration reads the `--pui-surface-transition-duration` CSS variable (default `0ms`), which your composition can populate with a finite non-negative millisecond duration.
- `scrim` provides a standard dimming backdrop. Opacity `0` affects visuals only; interaction gating, unmounting, and focus management stay with the enclosing Dialog or Transition.

## API

The following props belong to `Root` (removing a prop restores its default):

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    {

    {
      name: 'radius',
      type: "'default' | 'none' | 'sm' | 'md' | 'lg' | 'xl' | 'full'",

    { name: 'border', type: "'all' | 'bottom' | 'none'", default: 'all' },
    { name: 'elevation', type: "'none' | 'raised'", default: 'none' },

    },

    { name: 'current', type: 'boolean', default: 'false' },
  ]}
