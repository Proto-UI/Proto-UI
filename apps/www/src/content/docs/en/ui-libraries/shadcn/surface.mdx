Surface is a passive visual container inheriting the [Base Surface](/en/ui-libraries/base/surface/) input contract, applying Shadcn backgrounds, borders, radii, elevation, and state paint while leaving semantic and interaction ownership to the enclosing control. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

This component is available from workspace source. In your application, install the CLI, Shadcn prototypes and target adapter built from the same workspace revision, then initialize the project with that CLI. Run the locally installed CLI to generate the facade.

<InstallCommandCard command="npm exec -- proto-ui add wc shadcn-surface" manager="npm" />

Replace `wc` with `react`, `vue`, or `vue2` to generate the facade for your target framework.

## Usage

Import `surfaceRoot` from `@proto.ui/prototypes-shadcn/surface` (or the package root) and adapt it to your runtime:

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { surfaceRoot } from '@proto.ui/prototypes-shadcn/surface';

const Surface = createReactAdapter(React)(surfaceRoot);

export function Summary() {
  return (
    <Surface variant="muted" radius="md" border="none">
      <div className="p-4">Saved locally</div>
    </Surface>
  );
}
```

### Passive boundaries and composition

- `hovered`, `focusVisible`, `pressed`, and `current` are forwarded from an enclosing interactive component; Surface registers no event listeners, tab stops, or ARIA roles. Compose `Button` or a native `<a>` element whenever you need interactive semantics.
- Outer layout and inner padding stay with your composition. Pass `tone="inherit"` to nested `Text` children so they inherit foreground contrast from `solid` or `accent` surfaces.
- Enable `fade` to map `transitionState` from [Base Transition](/en/ui-libraries/base/transition/) to opacity (`closed` and `leaving` map to `0`; `entering` and `entered` map to `1`), reading `--pui-surface-transition-duration` (default `0ms`) on Web.

## API

The following props belong to `Root` (removing a prop restores its default):

  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}

    {
      name: 'radius',
      type: "'default' | 'none' | 'sm' | 'md' | 'lg' | 'xl' | 'full'",

    { name: 'pressed', type: 'boolean', default: 'false' },
    { name: 'current', type: 'boolean', default: 'false' },
