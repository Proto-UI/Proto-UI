Select renders an accessible single-selection dropdown with shared selection, focus, typeahead, and ARIA behavior across Web Components, React, Vue, and Vue 2. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

This command uses the stable 0.2.0 CLI. Vue 2.6 requires a matching prerelease or workspace CLI, adapter and prototype build. The preview uses the workspace version.

<InstallCommandCard command="npx @proto.ui/cli@0.2.0 add wc shadcn-select" manager="npm" />

Replace `wc` with `react` or `vue` to generate the facade for your target framework.

## Usage

Select consists of:

- `Root`, `Trigger`, `Value`, `Content`, `Surface`, `Viewport`, `Item`, `ItemText`, `Group`, `Label`, and `Separator`.
- `Group` organizes related options, `Label` names its group, and `Separator` renders a contentless decorative divider. Every part—including portalled content—inherits the style scope from `Root`.

### Appearance and positioning

- `Trigger` accepts `size="sm | default"` and `appearance`. Use `appearance="default"` with `styleProfile="rhea"` and other modern presets; `appearance="ghost"` is supported only with `new-york-v4` (alias `new-york`).
- `Content` accepts `position="item-aligned | popper"`, defaulting to `item-aligned`. Composing `Surface` → `Viewport` → `Item` → `ItemText` enables full item-aligned positioning, while `popper` positioning is also supported.

### Pointer, keyboard, and touch interaction

The scrollable example below separates highlighted focus from committed selection: mouse movement without held buttons navigates options, while touch, pen, and drag scrolling do not trigger hover selection. In controlled mode, declining an update preserves the currently committed value.
