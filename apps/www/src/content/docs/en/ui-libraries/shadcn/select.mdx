Select renders an accessible single-selection dropdown with shared selection, focus, typeahead, and ARIA behavior across Web Components, React, Vue, and Vue 2. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

This command uses the stable 0.2.0 CLI. Vue 2.6 requires a matching prerelease or workspace CLI, adapter and prototype build. The preview uses the workspace version.

<InstallCommandCard command="npx @proto.ui/cli@0.2.0 add wc shadcn-select" manager="npm" />

Replace `wc` with `react` or `vue` to generate the facade for your target framework.

## Usage

```tsx
import {
  ShadcnSelectContent,
  ShadcnSelectGroup,
  ShadcnSelectItem,
  ShadcnSelectItemText,
  ShadcnSelectLabel,
  ShadcnSelectRoot,
  ShadcnSelectSurface,
  ShadcnSelectTrigger,
  ShadcnSelectValue,
  ShadcnSelectViewport,
} from '../proto-ui/components/react';

export function ThemeSelect() {
  return (
    <ShadcnSelectRoot styleProfile="rhea">
      <ShadcnSelectTrigger styleProfile="rhea" className="w-48" accessibleLabel="Theme">
        <ShadcnSelectValue styleProfile="rhea" placeholder="Theme" />
      </ShadcnSelectTrigger>
      <ShadcnSelectContent styleProfile="rhea">
        <ShadcnSelectSurface styleProfile="rhea">
          <ShadcnSelectViewport styleProfile="rhea">
            <ShadcnSelectGroup styleProfile="rhea">
              <ShadcnSelectLabel styleProfile="rhea">Theme</ShadcnSelectLabel>
              <ShadcnSelectItem styleProfile="rhea" value="light" textValue="Light">
                <ShadcnSelectItemText styleProfile="rhea">Light</ShadcnSelectItemText>
              </ShadcnSelectItem>
              <ShadcnSelectItem styleProfile="rhea" value="dark" textValue="Dark">
                <ShadcnSelectItemText styleProfile="rhea">Dark</ShadcnSelectItemText>
              </ShadcnSelectItem>
            </ShadcnSelectGroup>
          </ShadcnSelectViewport>
        </ShadcnSelectSurface>
      </ShadcnSelectContent>
    </ShadcnSelectRoot>
  );
}
```

### Composition

Compose all eleven parts to enable modern translucent presets such as `rhea` and item-aligned positioning:

```text
SelectRoot
├── SelectTrigger
│   └── SelectValue
└── SelectContent
    └── SelectSurface
        └── SelectViewport
            ├── SelectGroup
            │   ├── SelectLabel
            │   └── SelectItem
            │       └── SelectItemText
            └── SelectSeparator
```

- **Keyboard & accessibility**: Click or press `Enter`, `Space`, `ArrowDown`, or `ArrowUp` to open. Navigate with arrow keys or typeahead, press `Enter` or `Space` to commit, and press `Escape` to cancel and return focus to `Trigger`. Provide an accessible name via `accessibleLabel` or a composed `Field`.
- **Style presets**: Accepts `styleProfile` (`new-york-v4` / `new-york`, `vega`, `nova`, `maia`, `lyra`, `mira`, `luma`, `sera`, `rhea`). Portalled content inherits the scope from `Root`. `Trigger` `appearance="ghost"` is supported under `new-york-v4`.
