## Style Profile preset exhibition

The upstream Shadcn Registry defines multiple style profiles for Tabs (`vega`, `nova`, `maia`, `lyra`, `mira`, `luma`, `sera`, `rhea`, `new-york-v4`). Only `nova`, `rhea`, and `new-york-v4` currently have bounded text-default projection (see `internal/fixtures/shadcn-tabs-style/coverage.json`); unsupported profiles are rejected at runtime.

The three examples below use **identical children, defaultValue, and disabled state**, changing only `styleProfile`, to demonstrate that preset switching does not reset value, focus, or children. Each example renders independently and does not share runtime instances.

## Content mount policy

`TabsContent` uses a lazy L1 view by default:

- only the current panel materializes a host view;
- an inactive panel detaches its view while preserving its Proto instance, state, and exposes;
- `keepMounted={true}` is the only view-retention option and keeps the complete inactive view mounted.

Web Component keeps the custom element as the owner and hides that owner while its internal view is detached. Reactivating the panel materializes a new view inside the same Proto instance owner.

## Install

<InstallCommandCard command="npx @proto.ui/cli@latest add wc shadcn-tabs" manager="npm" />

Replace `wc` with `react`, `vue` or `vue2` to generate the facade for that host.

## API

Passing `value` selects controlled mode.

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'defaultValue', type: 'string', default: "''" },
    { name: 'orientation', type: "'horizontal' | 'vertical'", default: 'horizontal' },
    { name: 'activationMode', type: "'automatic' | 'manual'", default: 'automatic' },
  ]}
/>

These props belong to Root. List defaults `orientation` to `horizontal`, `loop` to `false`, and `a11yLabel` to `''`. Trigger defaults `value` to `''` and `disabled` to `false`. Content defaults `value` to `''` and `keepMounted` to `false`.
