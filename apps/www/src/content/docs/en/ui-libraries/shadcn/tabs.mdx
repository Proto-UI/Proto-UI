Tabs organizes related views into switchable panels displaying one active panel at a time, supporting horizontal or vertical orientation, line styling, and automatic or manual keyboard activation. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

This command uses the stable 0.2.0 CLI. Vue 2.6 requires a matching prerelease or workspace CLI, adapter and prototype build. The preview uses the workspace version.

<InstallCommandCard command="npx @proto.ui/cli@0.2.0 add wc shadcn-tabs" manager="npm" />

Replace `wc` with `react` or `vue` to generate the facade for your target framework.

## Usage

```tsx
import {
  ShadcnTabsContent,
  ShadcnTabsList,
  ShadcnTabsRoot,
  ShadcnTabsTrigger,
} from '../proto-ui/components/react';
```

```tsx
<ShadcnTabsRoot styleProfile="rhea" defaultValue="account">
  <ShadcnTabsList styleProfile="rhea">
    <ShadcnTabsTrigger styleProfile="rhea" value="account">
      Account
    </ShadcnTabsTrigger>
    <ShadcnTabsTrigger styleProfile="rhea" value="password">
      Password
    </ShadcnTabsTrigger>
  </ShadcnTabsList>
  <ShadcnTabsContent styleProfile="rhea" value="account">
    Make changes to your account here.
  </ShadcnTabsContent>
  <ShadcnTabsContent styleProfile="rhea" value="password">
    Change your password here.
  </ShadcnTabsContent>
</ShadcnTabsRoot>
```

### Composition

```text
TabsRoot
├── TabsList
│   ├── TabsTrigger
│   └── TabsTrigger
├── TabsContent
└── TabsContent
```

- **Keyboard & accessibility**: Use `ArrowLeft` / `ArrowRight` in horizontal mode or `ArrowUp` / `ArrowDown` in vertical mode along with `Home` / `End` to move focus across enabled triggers; disabled triggers are skipped automatically.
- **Panel mounting**: Inactive `TabsContent` unmounts its content by default; pass `keepMounted={true}` to keep hidden panels mounted.

### Style Presets & Live Switching

Tabs supports eight modern presets (`vega`, `nova`, `maia`, `lyra`, `mira`, `luma`, `sera`, `rhea`) plus `new-york-v4`. Updating the surrounding `shadcn-style-scope` changes appearance live while preserving selection and focus (press `Alt+1`, `Alt+2`, or `Alt+3` while focused to switch via keyboard).
