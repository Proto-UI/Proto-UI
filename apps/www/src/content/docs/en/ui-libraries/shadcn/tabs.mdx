Tabs organizes related views into switchable panels with one active panel at a time, supporting horizontal or vertical orientation and automatic or manual keyboard activation. The examples on this page use the **Shadcn Rhea** style preset.

## Usage

### Style presets and live switching

Tabs supports eight modern presets (`vega`, `nova`, `maia`, `lyra`, `mira`, `luma`, `sera`, `rhea`) along with `new-york-v4`; unknown preset IDs are rejected rather than falling back silently.

In the interactive example below, select **Password** and then switch between Nova, Rhea, and New York v4. Updating the enclosing style scope preserves the selected tab and child nodes on the same Tabs instance. To switch presets while a tab holds keyboard focus, press **Alt+1**, **Alt+2**, or **Alt+3** inside the demo.

### Panel mounting policy

`TabsContent` unmounts inactive panel content by default (set `keepMounted={true}` to keep hidden panels mounted):

- Only the active panel mounts its content nodes; inactive panels unmount their view while keeping the underlying component instance, state, and exposed handles intact.
- On Web Components, the custom element host stays mounted and hidden while inactive, then re-renders its inner view inside the same host when reactivated.

## API

The following props belong to `Root` (pass `value` for controlled mode):

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'defaultValue', type: 'string', default: "''" },
    { name: 'orientation', type: "'horizontal' | 'vertical'", default: 'horizontal' },
    { name: 'activationMode', type: "'automatic' | 'manual'", default: 'automatic' },
  ]}
/>

Other part defaults:

- `List`: `orientation` defaults to `'horizontal'`, `loop` to `false`, and `a11yLabel` to `''`.
- `Trigger`: `value` defaults to `''` and `disabled` to `false`.
- `Content`: `value` defaults to `''` and `keepMounted` to `false`.
