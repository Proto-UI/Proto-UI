A modal dialog built on [Base Dialog](../../base/dialog/) with focus trapping, dismissal handling, live accessible naming, and enter/leave transitions, styled with a centered panel, backdrop, and replaceable close icon. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Initialize your project and import the generated `proto-ui-style.css` once as shown in the [Quick Start](../../../start-here/quick-start/), then generate the Dialog facade:

<InstallCommandCard command="npx @proto.ui/cli@0.2.0 add wc shadcn-dialog" manager="npm" />

The published `0.2.0` CLI supports `wc`, `react`, and `vue`; replace `wc` with `react` or `vue` for those hosts. It generates the compound parts from `@proto.ui/prototypes-shadcn/dialog`, including both the convenience `ShadcnDialogContent` (with a default close icon) and `ShadcnDialogContentRaw`.

Vue 2.6 (`>=2.6.0 <2.7`), the Rhea preset, and the Mask pointer-default behavior described below require the matching `0.3.0` workspace CLI, adapters, and prototype source. Keep this workspace preview separate from the pinned stable installation above.

## Usage

```tsx
import {
  ShadcnButton,
  ShadcnDialogContent,
  ShadcnDialogDescription,
  ShadcnDialogHeader,
  ShadcnDialogMask,
  ShadcnDialogRoot,
  ShadcnDialogTitle,
  ShadcnDialogTrigger,
} from '@/components/proto-ui/shadcn';

export function DialogExample() {
  return (
    <ShadcnDialogRoot>
      <ShadcnDialogTrigger>
        <ShadcnButton variant="outline">Open</ShadcnButton>
      </ShadcnDialogTrigger>
      <ShadcnDialogMask />
      <ShadcnDialogContent>
        <ShadcnDialogHeader>
          <ShadcnDialogTitle>Are you absolutely sure?</ShadcnDialogTitle>
          <ShadcnDialogDescription>
            This action cannot be undone. This will permanently delete your account and remove your
            data from our servers.
          </ShadcnDialogDescription>
        </ShadcnDialogHeader>
      </ShadcnDialogContent>
    </ShadcnDialogRoot>
  );
}
```

### Composition

```text
ShadcnDialogRoot
├── ShadcnDialogTrigger
├── ShadcnDialogMask
└── ShadcnDialogContent
    ├── ShadcnDialogHeader
    │   ├── ShadcnDialogTitle
    │   └── ShadcnDialogDescription
    ├── ShadcnDialogFooter
    │   └── ShadcnDialogClose
    └── ShadcnDialogCloseIcon
```

### Behavior and customization

- **Trigger & close wrappers**: `ShadcnDialogTrigger` and `ShadcnDialogClose` stay unstyled; wrap a `ShadcnButton` child inside to keep button styling and a single `Tab` stop.
- **Customizing the close icon**: `ShadcnDialogContent` includes `ShadcnDialogCloseIcon` by default. Replace it via a direct child, React `close` prop, or Vue `#close` slot, or omit it via `close={null}`, an empty `#close` slot, `data-pui-no-default-close`, or `ShadcnDialogContentRaw`.
- **Focus & dismissal**: Focus loops inside the panel while open and returns to the trigger when dismissed. Press `Escape` or click outside to close; set `alert={true}` on `ShadcnDialogRoot` for `role="alertdialog"` to block outside-click dismissal.
- **Accessible naming**: `Title` and `Description` automatically wire `aria-labelledby` and `aria-describedby`. Provide `a11yLabel` on `Root` as a fallback when no `Title` is mounted.
