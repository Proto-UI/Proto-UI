A modal dialog built on [Base Dialog](../../base/dialog/) with focus trapping, dismissal handling, live accessible naming, and enter/leave transitions, styled with a centered panel, backdrop, and replaceable close icon. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Initialize your project and import the generated `proto-ui-style.css` once as shown in the [Quick Start](../../../start-here/quick-start/), then generate the Dialog facade:

<InstallCommandCard command="npx @proto.ui/cli@0.2.0 add wc shadcn-dialog" manager="npm" />

The published `0.2.0` CLI supports `wc`, `react`, and `vue`; replace `wc` with `react` or `vue` for those hosts. It generates the compound parts from `@proto.ui/prototypes-shadcn/dialog`, including both the convenience `ShadcnDialogContent` (with a default close icon) and `ShadcnDialogContentRaw`.

Vue 2.6 (`>=2.6.0 <2.7`), the Rhea preset, and the Mask pointer-default behavior described below require the matching `0.3.0-alpha.2` workspace CLI, adapters, and prototype source. Keep this workspace preview separate from the pinned stable installation above.

## Usage

### Anatomy

| Export | Responsibility |
| --- | --- |
| `ShadcnDialogRoot` | Manages controlled or uncontrolled `open`, `disabled`, `alert` mode, fallback `a11yLabel`, and open/close/toggle methods. |
| `ShadcnDialogTrigger` | Unstyled open-command wrapper; place a `ShadcnButton` child inside for a visible trigger. |
| `ShadcnDialogMask` | Modal backdrop overlay with a 150 ms leave transition. |
| `ShadcnDialogContentRaw` | Centered modal panel with a 200 ms leave transition, focus trap, and dismissal handling, without a default close button. |
| `ShadcnDialogContent` | CLI convenience wrapper over `ContentRaw` that includes a replaceable `ShadcnDialogCloseIcon`. |
| `ShadcnDialogHeader` / `ShadcnDialogFooter` | Optional layout groups for the header and action bar. |
| `ShadcnDialogTitle` / `ShadcnDialogDescription` | Automatically linked to `Content` via `aria-labelledby` and `aria-describedby`. |
| `ShadcnDialogClose` | Unstyled close-command wrapper; place a button inside for a visible action. |
| `ShadcnDialogCloseIcon` | Accessible top-right `X` close button (`Close` accessible name). |

### Customizing the default close button

`ShadcnDialogContent` supports three modes for its built-in close icon:

- **Default**: Renders `ShadcnDialogCloseIcon` automatically.
- **Replace**: Provide a direct `ShadcnDialogCloseIcon` child, React `close` prop, or Vue `#close` slot.
- **Omit**: Pass React `close={null}`, an empty Vue `#close` slot, or the Web Component attribute `data-pui-no-default-close`, or use `ShadcnDialogContentRaw` directly.

### Focus, dismissal, and alert mode

- `Content` traps and loops focus while open, then restores focus to the trigger when dismissed.
- Standard dialogs dismiss on `Escape` or outside clicks. Set `alert={true}` on `ShadcnDialogRoot` for `role="alertdialog"`, which keeps `Escape` dismissal while blocking outside clicks (pair it with a `Description` containing the primary message).
- Use `a11yLabel` on `Root` as a fallback accessible name when no `Title` is rendered.
- `Mask` and `Content` remain mounted until their 150 ms and 200 ms leave transitions finish, and a participating `Mask` prevents pointer defaults from stealing restored focus.

### Compatibility and accessibility coverage

[Current Dialog content coverage](https://github.com/Proto-UI/Proto-UI/blob/main/spec/tests/T-BASE-DIALOG-CONTENT-0001.yaml) records the checked behavior and remaining browser work. The complete keyboard flow across all four preview hosts, controlled refusal, responsive/theme/locale combinations, and installed-package integrations still have outstanding checks. Screen-reader behavior needs separate validation with the browser and assistive-technology combination used by your application.

Compose the separate Mask and Content parts; upstream `asChild` and `modal` are not supported props. Header and Footer provide layout; the application owns validation and persistence and decides when an operation has succeeded and the dialog should close.
