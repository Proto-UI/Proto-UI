Toggle Group organizes a set of two-state buttons into a keyboard-navigable group supporting single or multiple active values. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototypes directly from `@proto.ui/prototypes-shadcn/toggle-group` and adapt them for your target runtime.

## Usage

```tsx
import { ShadcnToggleGroupItem, ShadcnToggleGroupRoot } from '../proto-ui/components/react';

export function Example() {
  return (
    <ShadcnToggleGroupRoot variant="outline" defaultValue={['a']}>
      <ShadcnToggleGroupItem value="a">A</ShadcnToggleGroupItem>
      <ShadcnToggleGroupItem value="b">B</ShadcnToggleGroupItem>
      <ShadcnToggleGroupItem value="c">C</ShadcnToggleGroupItem>
    </ShadcnToggleGroupRoot>
  );
}
```

### Composition

```text
ToggleGroupRoot
├── ToggleGroupItem
└── ToggleGroupItem
```

- **Selection mode**: Both `value` and `defaultValue` are string arrays (`readonly string[]`). With `multiple={false}` (default), at most one item stays active and pressing the active item again clears selection. Set `multiple={true}` to allow multiple active items.
- **Controlled updates**: Pass `value` for controlled mode; interactions emit `valueChange` (`{ value: readonly string[] }`) without mutating external state directly.
- **Keyboard & accessibility**: Arrow keys move roving focus along the active `orientation` without toggling selection; press `Space` or `Enter` to toggle the focused item. Icon-only items should include visually hidden text (such as `sr-only`) for an accessible label.
- **Style presets**: Supports `vega`, `nova`, `maia`, `lyra`, `mira`, `luma`, `sera`, `rhea`, and `new-york-v4` via `styleProfile` or an enclosing [Style Scope](../style-scope/).
