Toggle Group organizes a set of toggle buttons into a keyboard-navigable group supporting either single or multiple active values. The examples on this page use the **Shadcn Rhea** style preset.

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

Toggle Group consists of `Root` and `Item`:

- Both `value` and `defaultValue` are string arrays (`readonly string[]`).
- With `multiple={false}` (default), at most one item stays active, and pressing the active item again clears selection. Set `multiple={true}` to allow multiple active items.
- Pass `value` for controlled mode—interactions emit `valueChange` requests without mutating your state directly.
- Disabled, read-only, and duplicate-valued items do not commit changes.
- Arrow keys move roving focus across items without toggling them; `Space` or `Enter` toggles the focused item.
