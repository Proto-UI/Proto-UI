Tree displays nested hierarchies—such as file browsers or document outlines—with single selection, expandable branches, and full keyboard navigation. The examples on this page use the **Shadcn Rhea** style preset.

## Usage

Tree consists of `Root`, `Item`, `Group` (`TreeGroup`), and `Toggle`:

- Give each `Item` a unique `nodeKey` and set `parentKey` to its parent branch's key. Invalid configurations such as duplicate keys, missing parents, or cycles are ignored so the active tree stays valid.
- Place child items inside a `TreeGroup` whose `nodeKey` matches its branch `Item`; Tree automatically links and cleans up `aria-controls` and `aria-labelledby` attributes as nodes mount and unmount.
- Collapsing a branch hides its `TreeGroup` without removing the underlying hierarchy. If focus was inside the collapsed branch, focus moves to the visible ancestor without stealing focus from outside the tree.

### Embedded appearance and writing direction

- For file navigation inside a sidebar or existing surface, set `appearance="embedded"` on both `Root` and `Item` to enable a subtle selected background and text wrapping at enlarged font sizes.
- Setting `direction="rtl"` on `Root` mirrors group indentation and swaps Left/Right keyboard mappings (Left expands or enters children; Right collapses or moves to the parent). Up/Down, `Home`/`End`, and first-letter typeahead continue following visual order.

### Controlled and read-only

- Pass `value` or `expandedKeys` for controlled selection or expansion; inserting, moving, or removing items updates the hierarchy without emitting spurious selection events.
- `readOnly` blocks selection changes while keeping navigation and branch expansion enabled.

## API

The following props belong to `Root` (pass `value` or `expandedKeys` for controlled mode):

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'defaultValue', type: 'string', default: "''" },
    { name: 'defaultExpandedKeys', type: 'readonly string[]', default: '[]' },
    { name: 'direction', type: "'ltr' | 'rtl'", default: 'ltr' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'readOnly', type: 'boolean', default: 'false' },
    { name: 'a11yLabel', type: 'string', default: 'Tree' },
  ]}
/>

Other part props:

- `Item`: `nodeKey`, `parentKey`, and `textValue` default to `''`; `disabled` defaults to `false` (also supports `appearance="embedded"`).
- `Group`: accepts `nodeKey`.
- `Toggle`: accepts Button props.
