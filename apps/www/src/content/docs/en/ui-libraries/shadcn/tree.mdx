Tree displays nested hierarchies—such as file browsers or document outlines—with single selection, expandable branches, and full keyboard navigation. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Available starting in `0.3.0-rc.1` and later releases. Import the prototypes from `@proto.ui/prototypes-shadcn/tree` and adapt them for your target runtime:

```ts
import { treeRoot, treeItem, treeGroup, treeToggle } from '@proto.ui/prototypes-shadcn/tree';
```

## Usage

```tsx
<ShadcnTreeRoot defaultValue="button" defaultExpandedKeys={['src', 'components']}>
  <div className="flex items-center gap-1">
    <ShadcnTreeToggle nodeKey="src" size="icon">
      ▾
    </ShadcnTreeToggle>
    <ShadcnTreeItem nodeKey="src" textValue="src" className="flex-1">
      src/
    </ShadcnTreeItem>
  </div>
  <ShadcnTreeGroup nodeKey="src">
    <ShadcnTreeItem nodeKey="button" parentKey="src" textValue="button.tsx">
      button.tsx
    </ShadcnTreeItem>
  </ShadcnTreeGroup>
</ShadcnTreeRoot>
```

### Structure & Accessibility

- Give each `Item` a unique `nodeKey` and set `parentKey` to its parent branch's key. Invalid configurations such as duplicate keys, missing parents, or cycles are ignored so the active tree stays valid.
- Place child items inside a `TreeGroup` whose `nodeKey` matches its branch `Item`; Tree automatically links and cleans up `aria-controls` and `aria-labelledby` attributes as nodes mount and unmount.
- Collapsing a branch hides its `TreeGroup` without removing the underlying hierarchy. If focus was inside the collapsed branch, focus moves to the visible ancestor without stealing focus from outside the tree.
- **Keyboard navigation**: `ArrowUp` / `ArrowDown`, `Home` / `End`, and first-letter typeahead move focus in visual order. In LTR mode, `ArrowRight` expands a branch or enters its first child and `ArrowLeft` collapses or moves to the parent; `direction="rtl"` mirrors indentation guides and swaps horizontal arrow mappings.

### Style Profiles (`styleProfile`)

Supports `vega`, `nova`, `maia`, `lyra`, `mira`, `luma`, `sera`, `rhea`, and `new-york-v4` (`new-york` alias). When omitted or set to `inherit`, components inherit from the nearest [Style Scope](../style-scope/) or fall back to `nova`.
