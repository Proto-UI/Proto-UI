Toolbar groups related action buttons and dividers into a single accessible container with one `Tab` entry point and arrow-key navigation. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototypes directly from `@proto.ui/prototypes-shadcn/toolbar` and adapt them for Web Components, React, Vue 3, or Vue 2:

```ts
import { toolbarRoot, toolbarButton, toolbarSeparator } from '@proto.ui/prototypes-shadcn/toolbar';
```

## Usage

```tsx
import {
  ShadcnToolbarRoot,
  ShadcnToolbarButton,
  ShadcnToolbarSeparator,
} from '../proto-ui/components/react';

export function EditorToolbar() {
  return (
    <ShadcnToolbarRoot styleProfile="rhea" a11yLabel="Document actions">
      <ShadcnToolbarButton value="undo">Undo</ShadcnToolbarButton>
      <ShadcnToolbarButton value="redo">Redo</ShadcnToolbarButton>
      <ShadcnToolbarSeparator />
      <ShadcnToolbarButton value="save" variant="default">
        Save
      </ShadcnToolbarButton>
    </ShadcnToolbarRoot>
  );
}
```

Toolbar is composed of `Root`, `Button`, and `Separator`:

- **Roving keyboard focus**: Only one enabled `Button` participates in the page `Tab` sequence at a time. Left/Right arrow keys navigate horizontal toolbars, Up/Down arrow keys navigate vertical toolbars, and `loop={true}` (default) wraps from end to start.
- **Command activation**: Activating an enabled `Button` emits an `action` event carrying `{ value: string }`.
- **Cross-axis divider**: `Separator` automatically aligns perpendicular to `Root`'s `orientation`.

### Style Presets (`styleProfile`)

`Root`, `Button`, and `Separator` support all nine Shadcn style presets (`vega`, `nova`, `maia`, `lyra`, `mira`, `luma`, `sera`, `rhea`, and `new-york-v4`, with `new-york` as a compatibility alias). When omitted or set to `inherit`, parts inherit from the nearest `StyleScope` or `Root` and otherwise fall back to `rhea`.

## Examples

### Variants

`Button` supports `ghost` (default), `outline`, `secondary`, `default`, and `destructive` variants to distinguish standard commands, primary submissions, and destructive actions inside one toolbar.

### Sizes and Icon Buttons

Use `sm`, `default`, `lg`, or square `icon` sizes. For icon-only commands, pair an `aria-hidden="true"` glyph with a visually hidden `sr-only` label so assistive technologies announce the action clearly.

### Vertical Orientation

Setting `orientation="vertical"` stacks commands vertically, switches `Separator` to a horizontal rule, and maps roving keyboard navigation to Up/Down arrow keys.

### Disabled and Non-Looping Navigation

Setting `disabled={true}` on `Root` disables every command in the toolbar. Setting `loop={false}` stops arrow-key navigation at the first and last enabled commands while skipping individually disabled buttons.

### Events and Exposes

- **Button `action` event**: Emitted on enabled activation with payload `{ value: string }`.
- **Root exposes**: `disabled` state and `focusFirst()`, `focusLast()`, and `setCurrent(id)` methods.
- **Button exposes**: `disabled`, `focused`, and `focusVisible` states plus `focusSelf(options)`.
