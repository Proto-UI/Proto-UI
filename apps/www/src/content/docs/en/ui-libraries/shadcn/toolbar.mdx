Toolbar groups related action buttons and dividers into a single accessible container with one `Tab` entry point and arrow-key navigation. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

Toolbar consists of `Root`, `Button`, and `Separator`:

- `Root` manages `disabled`, `orientation`, `loop`, and the toolbar's accessible name (`a11yLabel`).
- Only one enabled button participates in the page `Tab` sequence at a time; arrow keys move focus across buttons within the toolbar.
- Activating an enabled `Button` emits an `action` event carrying its `value`.
- `Separator` renders along the toolbar's cross axis automatically.

## API

The following props belong to `Root` (`Separator` adds no props):

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'orientation', type: "'horizontal' | 'vertical'", default: 'horizontal' },
    { name: 'loop', type: 'boolean', default: 'true' },
    { name: 'a11yLabel', type: 'string', default: "''" },
  ]}
/>

`Button` defaults `disabled` to `false` and `value` to `''`.
