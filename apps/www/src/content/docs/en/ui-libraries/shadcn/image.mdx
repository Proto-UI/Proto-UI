## Usage

Currently available from workspace source; not yet included in the 0.2.0 stable release.

`Image` consists of a single `Root` part (rendered as a native `<img>` on Web):

- **Source and sizing**: Set `source` to the image URL and `fit` to `'contain'` (default), `'cover'`, or `'fill'`.
- **Accessibility mode**: Use `a11yMode="informative"` (default) with `alternativeText` for meaningful images, or `a11yMode="decorative"` when surrounding text already conveys the meaning.
- **Loading status**: Read `loadingStatus` (`'idle'`, `'loading'`, `'loaded'`, `'error'`) and listen to `loadingStatusChange` (with previous and next states) to drive your own placeholder or fallback UI.
