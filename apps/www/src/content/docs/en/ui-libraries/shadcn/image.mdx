A responsive image component with profile-aware corner framing, explicit informative/decorative accessibility modes, `fit` sizing, and live loading status reporting. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import `imageRoot` (aliased as `shadcnImageRoot`) and its types directly from `@proto.ui/prototypes-shadcn/image`.

## Usage

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { imageRoot } from '@proto.ui/prototypes-shadcn/image';

const ShadcnImage = createReactAdapter(React)(imageRoot);

export function CoverPhoto() {
  return (
    <ShadcnImage
      styleProfile="rhea"
      source="/images/base-image/landscape.svg"
      a11yMode="informative"
      alternativeText="Mountain ridge bathed in morning sunlight"
      fit="cover"
      radius="default"
      surfaceStyle={{ width: '100%', height: '220px' }}
    />
  );
}
```

`Image` consists of a single `Root` part (rendered as a native `<img>` on Web):

- **Responsive framing and corners**: Ships with `block max-w-full h-auto` by default. `radius="default"` follows the active `styleProfile` (`rounded-xl` for `rhea`, `maia`, and `luma`; `rounded-lg` for `nova`; `rounded-md` for `vega`, `mira`, and `new-york-v4`; `rounded-none` for `lyra` and `sera`), or pass an explicit radius token.
- **Fit and accessibility**: Choose `'contain'` (default), `'cover'`, or `'fill'` via `fit`. Use `a11yMode="informative"` with descriptive `alternativeText` for meaningful imagery, or `a11yMode="decorative"` when adjacent text carries the meaning.
- **Loading and fallback**: Observe `loadingStatus` (`'idle' | 'loading' | 'loaded' | 'error'`) and `loadingStatusChange` to drive your own placeholder or retry fallback UI.
