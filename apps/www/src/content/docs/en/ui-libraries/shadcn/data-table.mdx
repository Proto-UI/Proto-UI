## Usage

```tsx
import {
  ShadcnDataTableCaption,
  ShadcnDataTableCell,
  ShadcnDataTableHeader,
  ShadcnDataTableHeaderRow,
  ShadcnDataTableNext,
  ShadcnDataTablePrevious,
  ShadcnDataTableRoot,
  ShadcnDataTableRow,
} from '../proto-ui/components/react';

const rows = [
  { id: 'm5gr84i9', status: 'Success', email: 'ken99@example.com', amount: 316 },
  { id: '3u1reuv4', status: 'Success', email: 'abe45@example.com', amount: 242 },
];

export function Example() {
  return (
    <ShadcnDataTableRoot rows={rows} pageSize={4} className="rounded-md border border-border">
      <ShadcnDataTableCaption>Recent payments.</ShadcnDataTableCaption>
      <ShadcnDataTableHeaderRow>
        <ShadcnDataTableHeader headerKey="status">Status</ShadcnDataTableHeader>
        <ShadcnDataTableHeader headerKey="email">Email</ShadcnDataTableHeader>
        <ShadcnDataTableHeader headerKey="amount" className="text-right">
          Amount
        </ShadcnDataTableHeader>
      </ShadcnDataTableHeaderRow>
      {[0, 1].map((index) => (
        <ShadcnDataTableRow key={index} index={index}>
          <ShadcnDataTableCell columnKey="status" headers={['status']} />
          <ShadcnDataTableCell columnKey="email" headers={['email']} />
          <ShadcnDataTableCell columnKey="amount" headers={['amount']} className="text-right" />
        </ShadcnDataTableRow>
      ))}
      <div className="table-caption caption-bottom">
        <div className="flex justify-end gap-2 pt-3">
          <ShadcnDataTablePrevious>Previous</ShadcnDataTablePrevious>
          <ShadcnDataTableNext>Next</ShadcnDataTableNext>
        </div>
      </div>
    </ShadcnDataTableRoot>
  );
}
```

### Structure & Accessibility

- **Record identity and row slots**: Every record in `rows` requires a unique non-empty `id`. Body slots (`DataTableRow`) map to the active page by `index`, and each `DataTableCell` renders the matching `columnKey` so sorting and paging update real table content.
- **Headers and keyboard interaction**: Place sortable column headers inside passive `DataTableHeaderRow` containers. Pressing `Enter` or `Space` on a focused sortable header cycles sorting, and on a focused row toggles selection.
- **Style presets (`styleProfile`)**: Supports `vega`, `nova`, `maia`, `lyra`, `mira`, `luma`, `sera`, `rhea`, and `new-york-v4`; omitting it or setting `inherit` follows the nearest `Style Scope` before falling back to the default profile.

### Events, Methods & Exposed States

- **Events (Root)**: `sortChange` (`{ sortKey, sortDirection }`), `pageChange` (`{ page }`), `selectionChange` (`{ selectedKeys }`).
- **Methods (Root)**: `getRows()`, `getRecord(id)`, `getSelectedKeys()`, `requestSort(key)`, `requestPage(next)`, `requestSelection(id)`, `requestPageSelection(selected?)`.
- **Exposed States**: Root exposes `filteredCount` and `pageSelection` (`'none' | 'some' | 'all'`); Row exposes `rowKey`, `selected`, `focused`, and `focusVisible`; Header exposes `sort`; Cell exposes `displayValue`.
