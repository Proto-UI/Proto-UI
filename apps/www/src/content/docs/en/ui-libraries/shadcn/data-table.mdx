## Usage

Currently available from workspace source; not yet included in the 0.2.0 stable release.

### Structure and data model

- Provide `rows` with unique record `id` values. Rows act as indexed slots for the current page, and each cell reads its `columnKey` from the active record so sorting updates real table content.
- Place sortable headers inside `DataTableHeaderRow`, and use `DataTableRow` for body record slots.

### Filtering, visibility, and selection

- **Filtering**: Non-empty entries in `columnFilters` combine with `Root`'s global `filter` before sorting and pagination run.
- **Column visibility**: `columnVisibility` hides the matching column's headers and cells (excluding them from sorting focus and assistive technology) while preserving their identity when shown again.
- **Row and page selection**: `requestPageSelection()` toggles selection only for the current filtered page while preserving selections on other pages, and exposes `pageSelection` as `'none'`, `'some'`, or `'all'`. Setting `readOnly={true}` blocks selection changes while still allowing sorting and pagination.
- **Custom cell formatting**: Set `renderValue={false}` on `Cell` to render your own children and subscribe to `displayValue` for live record updates.

## API

Passing `sortKey`, `sortDirection`, `page`, or `selectedKeys` controls the corresponding state independently.

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'rows', type: 'readonly DataRecord[]', default: '[]' },
    { name: 'defaultSortKey', type: 'string', default: "''" },
    { name: 'defaultSortDirection', type: "'none' | 'ascending' | 'descending'", default: 'none' },
    { name: 'filter', type: 'string', default: "''" },
    { name: 'columnFilters', type: 'Readonly<Record<string, string>>', default: '{}' },
    { name: 'columnVisibility', type: 'Readonly<Record<string, boolean>>', default: '{}' },
    { name: 'defaultPage', type: 'number', default: '0' },
    { name: 'pageSize', type: 'number', default: '10' },
    { name: 'defaultSelectedKeys', type: 'readonly string[]', default: '[]' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'readOnly', type: 'boolean', default: 'false' },
  ]}
/>

These props belong to `Root`. Other part defaults:

- **Row**: `index` defaults to `0`, `header` defaults to `false`.
- **Cell**: `columnKey` defaults to `''`, `renderValue` defaults to `true`.
- **Header**: `sortable` defaults to `true`.
- **Previous / Next**: Accept the same props as `Button`.
