Switch toggles a setting between on and off with keyboard support, size and style presets, field choice-card compositions, RTL mirroring, and optional pointer dragging. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

This command uses the stable 0.2.0 CLI. Vue 2.6 requires a matching prerelease or workspace CLI, adapter and prototype build. The preview uses the workspace version.

<InstallCommandCard command="npx @proto.ui/cli@0.2.0 add wc shadcn-switch" manager="npm" />

Replace `wc` with `react` or `vue` to generate the facade for your target framework.

## Usage

```tsx
import { ShadcnSwitch } from '@/components/ui/switch';
```

```tsx
<ShadcnSwitch defaultChecked />
```

- **Anatomy & state**: `Root` owns controlled `checked`, uncontrolled `defaultChecked`, `Space` key toggling, focus, and disabled state. `Thumb` derives its checked state, size, style preset, and direction from its owning `Root` with no extra props.
- **Sizes & presets**: Switch between `size="sm"` and `size="default"`, and choose among `rhea`, `nova`, `vega`, `maia`, `lyra`, `mira`, `luma`, `sera`, and `new-york-v4` via `styleProfile` or an ancestor `StyleScope`.
- **Styling the generated Web Component**: The generated `ShadcnSwitchElement` registers as `<proto-ui-shadcn-switch>` with its default `Thumb`, whereas the raw `Root` registers as `<proto-ui-shadcn-switch-root>`. Target `proto-ui-shadcn-switch` in CSS when customizing the composed track, and see the [Web Component styling guide](https://github.com/Proto-UI/Proto-UI/blob/main/packages/adapters/web-component/README.md#styling-the-composed-host) for custom sizing examples.

## API

The following props and events belong to `Root` (`shadcn-switch-root` / `shadcn-field-switch`; `Thumb` has no props):

<ApiPropsTable
  headers={{ name: 'Prop / Event', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'checked', type: 'boolean | undefined', default: 'uncontrolled' },
    { name: 'defaultChecked', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'draggable', type: 'boolean', default: 'false' },
    { name: 'direction', type: "'ltr' | 'rtl'", default: "'ltr'" },
    { name: 'size', type: "'default' | 'sm'", default: "'default'" },
    {
      name: 'styleProfile',
      type: "'inherit' | 'new-york-v4' | 'vega' | 'nova' | 'maia' | 'lyra' | 'mira' | 'luma' | 'sera' | 'rhea'",
      default: "'inherit'",
    },
    { name: 'checkedChange', type: 'event ({ checked: boolean })', default: '—' },
    { name: 'focusSelf', type: 'method (options?: FocusRequestOptions) => void', default: '—' },
  ]}
/>

When composed as `shadcn-field-switch` inside `shadcn-field-root`, the switch also inherits `invalid`, `readOnly`, `disabled`, and label association from its owning `Field`.
