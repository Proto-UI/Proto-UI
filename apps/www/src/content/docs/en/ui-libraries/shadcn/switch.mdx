This entry shows the current `shadcn` switch implementation in Proto UI.

Set `size="sm"` on the Root for the small recipe; omit `size` or use `size="default"` for the default recipe. The Thumb derives size from its actual logical Switch Root and has no size prop. Changing size does not change the checked value or emit `checkedChange`.

The [pinned New York source](https://github.com/shadcn-ui/ui/blob/02cad61166c4c20edbc8a3f71bd720eed4c1f49b/apps/v4/registry/new-york-v4/ui/switch.tsx) uses rem dimensions: default Root 2rem × 1.15rem with a 1rem Thumb; small Root 1.5rem × 0.875rem with a 0.75rem Thumb. Checked travel is the used Thumb width minus 2px. These source dimensions do not establish cross-target rendered parity; full upstream transition channels and API parity remain incomplete.
