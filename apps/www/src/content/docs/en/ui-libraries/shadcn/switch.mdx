Switch toggles a setting between on and off with keyboard support, size presets, choice-card compositions, and optional pointer dragging. The examples on this page use the **Shadcn Rhea** style preset.

## Usage

### Sizes and presets

- Set `size="sm"` on `Root` for the compact switch, or omit `size` / pass `size="default"` for the standard size. `Thumb` derives its dimensions automatically from its `Root` and takes no `size` prop.
- Changing `size` updates visuals only and does not alter `checked` or emit `checkedChange`.
- Under the **Shadcn Rhea** preset, the default switch measures `2rem × 1.25rem` (`1rem` thumb) and the small switch measures `1.5rem × 1rem` (`0.75rem` thumb). The `new-york-v4` preset uses `2rem × 1.15rem` and `1.5rem × 0.875rem`.

### Compositions and optional drag

Switches toggle via click or `Space` by default; pass `draggable={true}` to opt into pointer dragging. Set `direction="rtl"` to mirror the thumb's positions and movement in either mode; direction defaults to `ltr` independently of the surrounding document. The example below pairs Switch with Field `Label`, `Description`, and Choice Cards: clicking the open area of a card toggles the switch while nested links such as “Learn more” keep their own navigation. Highlight styling follows the committed `checked` state, and `disabled` / `readOnly` switches ignore toggle attempts.

### Styling the generated Web Component

- The generated `ShadcnSwitchElement` registers as `<proto-ui-shadcn-switch>` and includes its default `Thumb`. Target `proto-ui-shadcn-switch` in CSS when styling the composed track.
- The separately exported raw `Root` registers as `<proto-ui-shadcn-switch-root>`, so selectors targeting that tag will not match the composed element.
- When customizing dimensions, keep Root size, Thumb size, and checked travel distance in sync; see the [Web Component styling guide](https://github.com/Proto-UI/Proto-UI/blob/main/packages/adapters/web-component/README.md#styling-the-composed-host) for a full LTR example. When using built-in presets, set `styleProfile` and `size` on `Root` so `Thumb` stays aligned automatically.
