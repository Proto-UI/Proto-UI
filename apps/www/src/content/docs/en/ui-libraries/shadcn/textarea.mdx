Textarea wraps a native multiline text editor with controlled and uncontrolled value management, normalized IME events, accessibility attributes, and Shadcn border and focus-ring styling. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

CLI support for this component will be available starting in `0.3.0-rc.1` and later releases. To reproduce the workspace preview in an application before then, build the CLI, Shadcn prototypes and target adapter from the same revision, initialize with that CLI, then generate the facade locally.

<InstallCommandCard command="npm exec -- proto-ui add wc shadcn-textarea" manager="npm" />

Replace `wc` with `react`, `vue`, or `vue2` to generate the facade for your target framework.

## Usage

```tsx
import { ShadcnTextareaRoot } from '../proto-ui/components/react';
```

```tsx
<ShadcnTextareaRoot placeholder="Type your message here." rows={4} />
```

- **Native editing semantics**: Textarea manages a single native `<textarea>` without child content, supporting standard attributes such as `rows`, `maxLength`, `minLength`, `wrap`, `placeholder`, `readOnly`, and `disabled`.
- **Style presets (`styleProfile`)**: Supports `vega`, `nova`, `maia`, `lyra`, `mira`, `luma`, `sera`, `rhea`, and `new-york-v4` (`new-york` alias). When omitted or set to `inherit`, it resolves from the nearest [Style Scope](../style-scope/) or falls back to `new-york-v4`.
- **Reset and focus methods**: Call `resetValue()` to restore the initial value in uncontrolled mode or request a reset in controlled mode (callable even while `readOnly` or `disabled`, retiring any active IME composition). Use `focusSelf()` and `blurSelf()` for programmatic focus control.
- **Form field composition**: Inside a form, import `fieldTextarea` from `@proto.ui/prototypes-shadcn/field` and compose it with `Field`, `FieldLabel`, `FieldDescription`, and `FieldError` for automatic labeling and validation; see the [Form recipe](../form/).

## API

The following props belong to `Root` (pass `value` for controlled mode; `minLength` and `maxLength` default to `-1` when unlimited):

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    {
      name: 'styleProfile',
      type: "'inherit' | 'vega' | 'nova' | 'maia' | 'lyra' | 'mira' | 'luma' | 'sera' | 'rhea' | 'new-york-v4' | 'new-york'",
      default: "'inherit' → nearest scope → 'new-york-v4'",
    },
    { name: 'value', type: 'string | undefined', default: 'uncontrolled' },
    { name: 'defaultValue', type: 'string', default: "''" },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'readOnly', type: 'boolean', default: 'false' },
    { name: 'placeholder', type: 'string', default: "''" },
    { name: 'rows', type: 'number', default: '2' },
    { name: 'required', type: 'boolean', default: 'false' },
    { name: 'name', type: 'string', default: "''" },
    { name: 'autoComplete', type: 'string', default: "''" },
    { name: 'minLength', type: 'number', default: '-1' },
    { name: 'maxLength', type: 'number', default: '-1' },
    { name: 'wrap', type: "'soft' | 'hard'", default: "'soft'" },
    { name: 'ariaLabel', type: 'string', default: "''" },
    { name: 'labelledBy', type: 'string', default: "''" },
    { name: 'describedBy', type: 'string', default: "''" },
  ]}
/>

- **Exposed states**: `value`, `disabled`, `readOnly`, `focused`, `focusVisible`, `composing` (plus `invalid` and `pending` on `FieldTextarea`).
- **Exposed methods**: `focusSelf(options?)`, `blurSelf()`, `resetValue()`.
- **Events**: `valueChange`, `change`, `compositionStart`, `compositionUpdate`, `compositionEnd`.
