Textarea wraps a native multiline text editor with controlled and uncontrolled value management, normalized IME events, accessibility attributes, and Shadcn border and focus-ring styling. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

<InstallCommandCard command="npx @proto.ui/cli@latest add wc shadcn-textarea" manager="npm" />

Replace `wc` with `react`, `vue`, or `vue2` to generate the facade for your target framework.

## Usage

- Textarea manages a single native multiline editor without child content, supporting standard attributes such as `rows`, `maxLength`, `minLength`, `wrap`, `placeholder`, `readOnly`, and `disabled`.
- Call `resetValue()` to restore the initial value in uncontrolled mode or request a reset in controlled mode. Reset remains callable while `readOnly` or `disabled` and ends any active IME composition.
- Inside a form, import `fieldTextarea` from `@proto.ui/prototypes-shadcn/field` to connect labels, descriptions, error messages, and validation; see the [Form recipe](../form/).

## API

The following props belong to `Root` (pass `value` for controlled mode; `minLength` and `maxLength` default to `-1` when unlimited):

`Root` exposes `value`, `disabled`, `readOnly`, `focused`, `focusVisible`, `composing`, and `resetValue()`, and emits `valueChange`, `change`, and IME composition events.
