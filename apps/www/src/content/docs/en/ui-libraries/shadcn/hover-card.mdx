Ordinary demos on this page explicitly use **Shadcn Rhea**, with matching examples. This does not change public compatibility defaults or imply complete browser, native-host or visual acceptance. Neutral Surface/Text atoms retain their own public semantics; the consumer composition supplies the family presentation theme.

This entry shows the current `shadcn` hover-card implementation in Proto UI. It supports the official controlled/uncontrolled Root API, `openDelay`, `closeDelay`, and the Content `side`/`align` subset while matching the official width, popover colors, border, shadow, and direction-aware motion. Portal, collision handling, Arrow, forceMount, and numeric offsets are not yet supported by the Base layer.
