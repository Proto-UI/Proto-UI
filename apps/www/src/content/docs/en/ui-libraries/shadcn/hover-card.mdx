For sighted users to preview rich content available behind a link or handle, with configurable open/close delays and collision-aware placement. The examples on this page use the **Shadcn Rhea** style preset.

## Preview

Hover or focus `@proto-ui` for 150ms to open the preview card. Moving the pointer into the card keeps it open; leaving closes it after 200ms.

## Installation

This command uses the stable 0.2.0 CLI. Vue 2.6 requires a matching prerelease or workspace CLI, adapter and prototype build. The preview uses the workspace version.

<InstallCommandCard command="npx @proto.ui/cli@0.2.0 add wc shadcn-hover-card" manager="npm" />

Replace `wc` with `react` or `vue` to generate the local facade for your framework.

## Usage

```tsx
import {
  ShadcnHoverCardRoot,
  ShadcnHoverCardTrigger,
  ShadcnHoverCardContent,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <ShadcnHoverCardRoot openDelay={150} closeDelay={200}>
      <ShadcnHoverCardTrigger>@proto-ui</ShadcnHoverCardTrigger>
      <ShadcnHoverCardContent side="bottom" align="center">
        Host-neutral interaction protocols for adaptable UI components.
      </ShadcnHoverCardContent>
    </ShadcnHoverCardRoot>
  );
}
```

### Composition

```text
ShadcnHoverCardRoot
├── ShadcnHoverCardTrigger
└── ShadcnHoverCardContent
```

- **Root**: Coordinates open state (controlled `open` or uncontrolled `defaultOpen`), `openDelay` / `closeDelay` timers, and shared `disabled` gating.
- **Trigger**: Requests preview open on pointer hover or keyboard focus without overriding click navigation semantics.
- **Content**: Renders an anchored portal panel with placement, alignment, offsets, collision avoidance, and a pointer hover bridge.

## API

### Root

Passing `open` enables controlled mode. Delays must be non-negative finite numbers; invalid values fall back to the defaults.

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'open', type: 'boolean | undefined', default: 'uncontrolled' },
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'openDelay', type: 'number', default: '700' },
    { name: 'closeDelay', type: 'number', default: '300' },
    {
      name: 'styleProfile',
      type: "'inherit' | 'vega' | 'nova' | 'maia' | 'lyra' | 'mira' | 'luma' | 'sera' | 'rhea' | 'new-york-v4'",
      default: "'new-york-v4'",
    },
  ]}
/>

- **Exposed states**: `open: boolean`
- **Exposed methods**: `openHoverCard(reason?)`, `close(reason?)`, `toggle(reason?)`
- **Exposed events**: `openChange` (`{ open: boolean; reason: string | null }`)
