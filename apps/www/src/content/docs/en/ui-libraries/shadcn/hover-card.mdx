A floating card that previews rich content when hovering or focusing a trigger, with configurable open/close delays and collision-aware placement. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

This command uses the stable 0.2.0 CLI. Vue 2.6 requires a matching prerelease or workspace CLI, adapter and prototype build. The preview uses the workspace version.

<InstallCommandCard command="npx @proto.ui/cli@0.2.0 add wc shadcn-hover-card" manager="npm" />

Replace `wc` with `react` or `vue` to generate the local facade for your framework.

## Usage

Compose `Hover Card` from `Root`, `Trigger`, and `Content`:

- **Root**: Manages open state (controlled `open` or uncontrolled `defaultOpen`) and `openDelay` / `closeDelay`.
- **Trigger**: Requests opening on hover or focus; accepts its own `disabled` prop.
- **Content**: Keeps the card open while hovered and supports placement, alignment, offsets, and viewport collision avoidance.

## API

Passing `open` selects controlled mode. Delays must be finite numbers greater than or equal to `0`; invalid values fall back to the defaults.

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'open', type: 'boolean | undefined', default: 'uncontrolled' },
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'openDelay', type: 'number', default: '700' },
    { name: 'closeDelay', type: 'number', default: '300' },
    { name: 'side', type: "'top' | 'right' | 'bottom' | 'left'", default: 'bottom' },
    { name: 'align', type: "'start' | 'center' | 'end'", default: 'center' },
    { name: 'sideOffset', type: 'number', default: '4' },
    { name: 'alignOffset', type: 'number', default: '0' },
    { name: 'avoidCollisions', type: 'boolean', default: 'true' },
    { name: 'collisionPadding', type: 'number', default: '0' },
  ]}
/>

- `open`, `defaultOpen`, `disabled`, `openDelay`, and `closeDelay` belong to `Root`. `Root` exposes `open`, `openHoverCard`, `close`, `toggle`, and `openChange`.
- `side` through `collisionPadding` belong to `Content`.
- `Trigger` accepts `disabled` (default `false`).
