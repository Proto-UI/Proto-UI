Progress displays task completion across a bounded numeric range and supports an indeterminate state when completion percentage is unknown. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. After registering the package entry, import the parts from `@proto.ui/prototypes-shadcn/progress`:

```ts
import {
  progressRoot,
  progressLabel,
  progressTrack,
  progressIndicator,
  progressValue,
} from '@proto.ui/prototypes-shadcn/progress';
```

## Usage

Compose `Root`, `Track`, and `Indicator` for a minimal bar. To display an inline header row above the track, place `Label` and `Value` before `Track`:

```tsx
<ShadcnProgressRoot styleProfile="rhea" value={56} valueText="56%" className="w-full max-w-sm">
  <ShadcnProgressLabel styleProfile="rhea">Upload progress</ShadcnProgressLabel>
  <ShadcnProgressValue styleProfile="rhea" />
  <ShadcnProgressTrack styleProfile="rhea">
    <ShadcnProgressIndicator styleProfile="rhea" />
  </ShadcnProgressTrack>
</ShadcnProgressRoot>
```

```text
ProgressRoot
├── ProgressLabel
├── ProgressValue
└── ProgressTrack
    └── ProgressIndicator
```

- **Range and indeterminate mode**: `value` clamps to `[min, max]` (equal bounds evaluate to `0%`). Omitting `value` or setting `indeterminate={true}` enters indeterminate mode and omits `aria-valuenow`.
- **Style presets and RTL**: Supports `styleProfile` (`vega`, `nova`, `maia`, `lyra`, `mira`, `luma`, `sera`, `rhea`, `new-york-v4` / `new-york`, or `inherit`) plus `dir="ltr" | "rtl"` with logical inline-end alignment (`ms-auto`).
- **Accessibility and exposed state**: Progress is a passive read-only display with no keyboard tab stop. Every part exposes synchronized `value`, `percentage`, `indeterminate`, and `status` states, with `--pui-percentage` driving smooth reduced-motion-aware width transitions.

### Sub-parts and exposed states

- `ProgressLabel`, `ProgressTrack`, `ProgressIndicator`, and `ProgressValue` each accept an optional `styleProfile` override.
- All parts expose synchronized read-only states: `value` (`number`), `percentage` (`number`, `0–100`), `indeterminate` (`boolean`), and `status` (`'indeterminate' | 'loading' | 'complete'`).
