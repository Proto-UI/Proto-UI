Progress visualizes task completion across a bounded range, and supports an indeterminate state when completion percentage is unknown. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

After registering the package entry, import `progressRoot`, `progressLabel`, `progressTrack`, `progressIndicator`, and `progressValue` from the `progress` subpath:

- `Root` manages the finite range and progress state.
- `Label` provides the accessible name.
- `Track` holds `Indicator` to visualize the current percentage.
- `Value` displays `valueText`, or falls back to the normalized numeric value.

### Range and indeterminate state

- Values clamp within `[min, max]`; when `min` equals `max`, the percentage is `0`.
- Omit `value` or set `indeterminate={true}` to represent unknown progress; in this state, no current numeric value is reported to assistive technologies.
- Progress is a read-only display with no keyboard tab stop. `Root` and its parts expose `value`, `percentage`, `indeterminate`, and `status`, updating together whenever props change.
