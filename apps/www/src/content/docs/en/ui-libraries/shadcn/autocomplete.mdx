## Installation

Autocomplete is currently available from workspace source (`@proto.ui/prototypes-shadcn/autocomplete`) and is not yet included in the 0.2.0 stable release.

## Usage

```html
<proto-ui-shadcn-autocomplete-root a11y-label="Framework">
  <proto-ui-shadcn-autocomplete-input
    placeholder="Search frameworks…"
  ></proto-ui-shadcn-autocomplete-input>
  <proto-ui-shadcn-autocomplete-trigger size="icon">
    <span class="sr-only">Toggle suggestions</span>
  </proto-ui-shadcn-autocomplete-trigger>
  <proto-ui-shadcn-autocomplete-content>
    <proto-ui-shadcn-autocomplete-item value="next" text-value="Next.js" keywords="react ssr">
      Next.js
    </proto-ui-shadcn-autocomplete-item>
    <proto-ui-shadcn-autocomplete-item value="astro" text-value="Astro" keywords="islands static">
      Astro
    </proto-ui-shadcn-autocomplete-item>
    <proto-ui-shadcn-autocomplete-empty>No matching frameworks.</proto-ui-shadcn-autocomplete-empty>
  </proto-ui-shadcn-autocomplete-content>
</proto-ui-shadcn-autocomplete-root>
```

### Anatomy and interaction

- **Parts**: Compose `Root`, `Input`, `Trigger`, `Content`, `Item`, and `Empty`. All parts inherit `styleProfile` from `Root` or an enclosing [Style Scope](../style-scope/).
- **Committed value vs. query**: `value` holds the committed text while `inputValue` holds the live query. Selecting a suggestion commits its `textValue`; pressing `Enter` without an active match commits the typed free text.
- **Built-in filtering and empty state**: Matches case- and diacritic-insensitively across `textValue` and `keywords`. Set `filter={false}` to render pre-filtered items. `Empty` reflects real match counts; disabled and duplicate-valued items cannot be committed.
- **Keyboard and IME**: Focus stays inside the single-line input during arrow navigation, and IME composition never prematurely commits an item.

### Root events and methods

- **Events**: `valueChange` (`{ value, textValue, reason }`), `inputValueChange` (`{ value, composing }`), `openChange` (`{ open, reason }`).
- **Methods**: `openPopup()`, `close()`, `setInputValue(value, composing?)`, `select(value, reason?)`.
