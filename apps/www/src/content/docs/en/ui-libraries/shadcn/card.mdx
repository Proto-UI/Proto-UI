A passive, four-part container for grouping related content into `Root`, `Header`, `Content`, and `Footer` sections. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

This component is available from workspace source. In your application, install the CLI, Shadcn prototypes and target adapter built from the same workspace revision, then initialize the project with that CLI. Run the locally installed CLI to generate the facade.

<InstallCommandCard
  manager="npm"
  commands={{
    pnpm: 'pnpm exec proto-ui add wc shadcn-card',
    npm: 'npm exec -- proto-ui add wc shadcn-card',
    yarn: 'yarn exec proto-ui add wc shadcn-card',
    bun: 'bun run proto-ui add wc shadcn-card',
  }}
/>

Replace `wc` with `react`, `vue`, or `vue2` to generate the local facade for your framework. You can also import `ShadcnCardRoot`, `ShadcnCardHeader`, `ShadcnCardContent`, and `ShadcnCardFooter` (or their lowercase aliases) directly from `@proto.ui/prototypes-shadcn/card`.

<h2 id="card-contract">Usage</h2>

```tsx
import {
  ShadcnCardRoot,
  ShadcnCardHeader,
  ShadcnCardContent,
  ShadcnCardFooter,
} from '@proto.ui/prototypes-shadcn/card';
```

```tsx
<ShadcnCardRoot styleProfile="rhea">
  <ShadcnCardHeader>
    <h3 className="text-base font-medium">Card Title</h3>
    <p className="text-sm text-muted-foreground">Card Description</p>
  </ShadcnCardHeader>
  <ShadcnCardContent>
    <p className="text-sm">Card Content</p>
  </ShadcnCardContent>
  <ShadcnCardFooter>
    <p className="text-sm">Card Footer</p>
  </ShadcnCardFooter>
</ShadcnCardRoot>
```

Composition:

```text
ShadcnCardRoot
├── ShadcnCardHeader
├── ShadcnCardContent
└── ShadcnCardFooter
```

- **Structure and typography**: `Header`, `Content`, and `Footer` manage horizontal insets and section rhythm. Render native headings and paragraphs inside them, or compose [Text](../text/) with `size="base"`, `weight="medium"`, `tone="inherit"` for titles and `size="sm"`, `tone="muted"` for secondary descriptions.
- **Style presets**: Without an explicit selection, `Root` inherits the nearest [Style Scope](../style-scope/) and falls back to `new-york-v4` (`rounded-xl`, border, 24px spacing, 8px Header gap). Under **Shadcn Rhea**, it uses a hairline foreground ring, theme-capped 24px radius, 20px default spacing, and compact 16px `sm` density.
- **Passive semantics**: All four parts are purely presentational with no extra ARIA roles, focus stops, or events; links, inputs, and buttons inside the card keep their own behavior.
