A passive, four-part container for grouping related content into `Root`, `Header`, `Content`, and `Footer` sections. The examples on this page use the **Shadcn Rhea** style preset.

## Installation

<InstallCommandCard command="npx @proto.ui/cli@latest add wc shadcn-card" manager="npm" />

Replace `wc` with `react`, `vue`, or `vue2` to generate the local facade for your framework.

You can also import `ShadcnCardRoot`, `ShadcnCardHeader`, `ShadcnCardContent`, and `ShadcnCardFooter` (or their lowercase aliases) directly from `@proto.ui/prototypes-shadcn/card`.

<h2 id="card-contract">Usage</h2>

- **Structure and typography**: `Header`, `Content`, and `Footer` each manage their own section spacing. Compose native headings and paragraphs inside them, or pair with [Text](../text/) using `tone="inherit"` for titles/body and `tone="muted"` for secondary descriptions.
- **Style presets**: Without an explicit selection, `Root` inherits the nearest [Style Scope](../style-scope/) and falls back to New York (`rounded-xl`, border, 24px gap/padding, 8px Header gap). Under **Shadcn Rhea**, it uses a foreground ring, theme-capped radius, 20px gap/padding, and a 6px Header gap.
- **Passive semantics**: All four parts are purely presentational with no extra ARIA roles, focus stops, or events; links and buttons inside the card keep their own behavior.

## API

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'size', type: "'default' | 'sm'", default: 'default' },
    { name: 'divider', type: 'boolean', default: 'false' },
  ]}
/>

- `size` belongs to `Root`.
- `divider` belongs to `Header` and `Footer`.
- `Content` has no additional props, and none of the four parts emit events.
