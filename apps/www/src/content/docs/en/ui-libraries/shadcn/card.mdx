The ordinary demo on this page explicitly selects the **Shadcn Rhea** presentation profile. This does not change public compatibility defaults or imply complete browser, native-host or visual acceptance. Neutral Surface/Text atoms retain their own public semantics; the consumer composition supplies the family presentation theme.

Shadcn Card is a draft, passive four-part styled surface. It has no Base Card counterpart.

<h2 id="card-contract">Card contract</h2>

- Import `ShadcnCardRoot`, `ShadcnCardHeader`, `ShadcnCardContent`, and `ShadcnCardFooter` from `@proto.ui/prototypes-shadcn/card`; lowercase facade aliases are also exported.
- Both profiles use `bg-card`, `text-card-foreground` and a small shadow. Without an explicit selection, Root inherits the nearest style scope; an unscoped Card retains its New York compatibility default.
- New York uses `rounded-xl`, an explicit theme border, 24px default gap/padding and an 8px Header grid gap. Rhea uses no border, a foreground ring, a theme-capped radius, 20px default gap/padding and a 6px Header grid gap. Header, Content and Footer retain ownership of their part spacing.
- Title and description remain ordinary content. Compose native headings and paragraphs where appropriate; nested Shadcn Text title/body must use `tone: 'inherit'`. Muted descriptions intentionally use `tone: 'muted'`.
- All four parts remain roleless and non-focusable. Anchors and controls retain their own navigation and activation; Card adds no events or state.
- This subset intentionally omits upstream CardTitle, CardDescription, CardAction, action-dependent columns, header container-query markers, border-presence selectors and `asChild`. It does not claim full upstream compatibility.

The New York comparison source is [shadcn/ui Card at f31ed819](https://github.com/shadcn-ui/ui/blob/f31ed81983653919dd4fe77aee4b4859f610f1dc/apps/v4/registry/new-york-v4/ui/card.tsx), under its [MIT notice](https://github.com/shadcn-ui/ui/blob/f31ed81983653919dd4fe77aee4b4859f610f1dc/LICENSE.md). Proto UI is an independent implementation; the profile notes above describe its bounded Card subset, not complete Rhea source parity. Native screenshot, first-frame and cross-host acceptance remain separate gates; this draft is not stable or a completed Finf goal.

## Install

<InstallCommandCard command="npx @proto.ui/cli@latest add wc shadcn-card" manager="npm" />

Replace `wc` with `react`, `vue` or `vue2` to generate the facade for that host.

`size` belongs to Root. `divider` belongs to Header and Footer. Content adds no props of its own. None of the four parts expose events.
