`Label` pairs accessible naming (`naming`) and pointer activation (`activation`) with a target control through an explicit reference, without manual DOM IDs or implicit ancestor lookups. The examples on this page use the **Shadcn Rhea** style preset.

> For form fields, use the [Field](../field/) component, which includes built-in `FieldLabel`, `FieldDescription`, and `FieldError` wiring and validation.

## Installation

This component is available from workspace source. In your application, install the CLI, Shadcn prototypes and target adapter built from the same workspace revision, then initialize the project with that CLI. Run the locally installed CLI to generate the facade.

Replace `wc` with `react`, `vue`, or `vue2` to generate the local facade for your framework. You can also import `labelRoot` directly from `@proto.ui/prototypes-shadcn/label`.

## Usage

Create one stable reference per pair with `createControlLabelRef()` from `@proto.ui/core` and pass it through the adapter association channel (outside JSON props):

```tsx
import { useMemo } from 'react';
import { createControlLabelRef } from '@proto.ui/core';
import {
  ShadcnCheckboxIndicator,
  ShadcnCheckboxRoot,
  ShadcnLabelRoot,
} from '../proto-ui/components/react';

export function TermsCheckbox() {
  const termsRef = useMemo(() => createControlLabelRef(), []);

  return (
    <div className="flex items-center gap-2">
      <ShadcnCheckboxRoot styleProfile="rhea" instanceAssociations={{ controlLabel: termsRef }}>
        <ShadcnCheckboxIndicator styleProfile="rhea" />
      </ShadcnCheckboxRoot>
      <ShadcnLabelRoot styleProfile="rhea" instanceAssociations={{ controlLabel: termsRef }}>
        Accept terms and conditions
      </ShadcnLabelRoot>
    </div>
  );
}
```

In Web Components, bind the same reference with `setElementAssociations()` from `@proto.ui/adapter-web-component`:

```ts
import { createControlLabelRef } from '@proto.ui/core';
import { setElementAssociations } from '@proto.ui/adapter-web-component';

const termsRef = createControlLabelRef();
setElementAssociations(checkboxEl, { controlLabel: termsRef });
setElementAssociations(labelEl, { controlLabel: termsRef });
```

### Naming, activation, and accessibility

- **`naming` (default `true`)**: Associates the rendered label with its paired control so assistive technology announces it automatically. If the target already sets a non-empty `ariaLabel` or `labelledBy`, set `naming={false}` for an activation-only label.
- **`activation` (default `true`)**: Clicking the paired label invokes the control's existing action in the same turn — toggling `Checkbox`/`Switch`, selecting a `Radio Group Item`, or focusing `Input`/`Textarea` without altering text or selection. Set `activation={false}` for a passive naming-only label.
- **`selection` (default `'policy'`)**: Suppresses accidental text selection on actionable labels while keeping naming-only labels copyable. Set `selection="text"` if an actionable label should remain copyable.
- **Keyboard and pointer safety**: `Label` adds no extra `Tab` stop, and ignores clicks on nested links/buttons, modified clicks, cancelled pointers, and drag gestures.
- **Supported targets**: `Checkbox`, `Switch`, `Radio Group Item`, `Input`, `Textarea`, `Button`, `Toggle`, `Toggle Group Item`, standalone `Select Trigger`, and `Number Field Input`.
- **Style presets (`styleProfile`)**: Supports `vega`, `nova`, `maia`, `lyra`, `mira`, `luma`, `sera`, `rhea`, and `new-york-v4`; the default `'inherit'` reads the nearest [Style Scope](../style-scope/) and falls back to `new-york-v4`.

### Association helpers

- `createControlLabelRef()`: Imported from `@proto.ui/core` to create a stable one-to-one opaque reference.
- `instanceAssociations`: Adapter prop accepting `{ controlLabel: ref }` in React, Vue, and Vue 2.
- `setElementAssociations(element, { controlLabel: ref })`: Imported from `@proto.ui/adapter-web-component` for Web Components.
