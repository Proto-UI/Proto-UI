Connects accessible naming (`naming`) and pointer activation (`activation`) to a paired control using an explicit reference, without manual DOM IDs or implicit ancestor lookups. The examples on this page use the **Shadcn Rhea** style preset.

## Usage

### Independent naming and activation

- **`naming` (default `true`)**: Associates the rendered label with its paired control so assistive technology announces it automatically. If the target already sets a non-empty `ariaLabel` or `labelledBy`, set `naming={false}` for an activation-only label.
- **`activation` (default `true`)**: Clicking the paired label invokes the control’s action in the same click turn — toggling `Checkbox`/`Switch`, selecting a `Radio Group Item`, or focusing `Input`/`Textarea` without altering text or selection. Set `activation={false}` for a passive naming-only label.
- **`selection` (default `'policy'`)**: Suppresses accidental text selection on actionable labels while keeping naming-only labels copyable. Set `selection="text"` if an actionable label should also allow text selection.
- `Label` adds no extra `Tab` stop, and ignores clicks on nested links/buttons, modified clicks, cancelled pointers, and drag gestures.

### Wiring an explicit association

Create one stable reference per label/control pair with `createControlLabelRef()` from `@proto.ui/core` and pass it through the adapter association channel (outside JSON props):

- **React / Vue / Vue 2**: Pass `instanceAssociations: { controlLabel: ref }` to both the label and its target control.
- **Web Components**: Call `setElementAssociations(element, { controlLabel: ref })` from `@proto.ui/adapter-web-component` on both elements.
- **DemoSpec**: Declare `associations: { controlLabel: 'row-key' }` for data-only pairing.

Each reference supports one live label and one live target within the same document/shadow root; missing, duplicate, or stale endpoints are ignored. Supported targets are `Checkbox`, `Switch`, `Radio Group Item`, `Input`, `Textarea`, `Button`, `Toggle`, and `Toggle Group Item` (including icon-only buttons).
