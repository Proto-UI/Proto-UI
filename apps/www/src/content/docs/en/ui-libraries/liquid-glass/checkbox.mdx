Liquid Glass Checkbox pairs a 20px concentric-radius control surface with restrained optical refraction and selection tinting, supporting unchecked, checked, and `indeterminate` (`mixed`) states with high-contrast opaque fallbacks.

## Installation

Liquid Glass Checkbox is currently available from workspace source. Import `checkboxRoot` and `checkboxIndicator` from `@proto.ui/prototypes-liquid-glass` or `@proto.ui/prototypes-liquid-glass/checkbox`.

## Usage

```tsx
import {
  LiquidGlassCheckboxIndicator,
  LiquidGlassCheckboxRoot,
  LiquidGlassLabelRoot,
} from '@proto.ui/prototypes-liquid-glass';

export function Example() {
  return (
    <div className="flex items-center gap-3">
      <LiquidGlassCheckboxRoot defaultChecked>
        <LiquidGlassCheckboxIndicator />
      </LiquidGlassCheckboxRoot>
      <LiquidGlassLabelRoot>Subscribe to release notes</LiquidGlassLabelRoot>
    </div>
  );
}
```

### Material hierarchy and accessibility

- **Optical surface and selection tint**: `material="auto"` requests backdrop refraction where supported and applies a primary fill tint (`tint: 'style-fill'`) when checked or indeterminate. `Indicator` stays passive with no secondary glass layer, avoiding glass-on-glass stacking.
- **Automatic preference fallbacks**: Reduced transparency, increased contrast, forced colors, and disabled states automatically resolve to readable opaque fills, while reduced motion disables press deformation.
- **Explicit opaque mode**: Set `material="opaque"` for dense forms or solid panels where translucent material is unnecessary.

## API

### Root

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'material', type: "'auto' | 'opaque'", default: "'auto'" },
    { name: 'checked', type: 'boolean | undefined', default: 'uncontrolled' },
    { name: 'defaultChecked', type: 'boolean', default: 'false' },
    { name: 'indeterminate', type: 'boolean | undefined', default: 'uncontrolled' },
    { name: 'defaultIndeterminate', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'readOnly', type: 'boolean', default: 'false' },
    { name: 'required', type: 'boolean', default: 'false' },
  ]}
/>

`Root` exposes `checked`, `indeterminate`, `disabled`, `readOnly`, `required`, `hovered`, `focused`, `focusVisible`, and `pressed` states, `focusSelf(options?)` and `resetValue()` methods, and `checkedChange` (`{ checked, indeterminate }`) and `indeterminateChange` (`{ indeterminate }`) events.

### Indicator

`Indicator` declares no props and no optical material of its own. It mirrors the enclosing `Root` state and exposes `checked`, `indeterminate`, `isChecked()`, and `isIndeterminate()`.
