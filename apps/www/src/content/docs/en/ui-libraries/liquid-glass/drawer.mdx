## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Sizing and scrolling**: top and bottom drawers fit their content height by default up to the safe available region; left and right drawers use a capped `20rem` width. `Content` renders as an `overflow-y-auto` scroll container so long content and the close control stay accessible.
- **Extent bounds**: `Content.minExtent` and `maxExtent` accept neutral length objects (`unit`: `'logical' | 'root-text' | 'available' | 'available-minus-root-text'` and a non-negative finite `value`). Minimums above the safe cap clamp to the cap; invalid runtime updates expose `extentValid={false}` and retain the last valid extent.
- **Snap points (`snapPoints`)**: omit, pass `null`, or pass `[]` for content-fit mode; pass a non-empty array of fractions in `(0, 1]` (sorted and deduplicated against the full safe cap) for explicit snapping. In snap mode, `Handle` exposes a named `separator` with arrow-key and Home/End resizing; in content-fit mode, `Handle` is a pointer-only `aria-hidden` drag handle.
- **Controlled state and dismissal**: `Root` supports controlled `open` or uncontrolled `defaultOpen`, plus controlled `snapPoint` / `snapPointChange` and uncontrolled `defaultSnapPoint`. Set `Content.dragDismissible={false}` to disable drag-to-close while keeping Close, Escape, and outside dismissal. Interrupted gestures and rejected controlled requests restore the committed state.

## API

| Part | Prop | Description |
| --- | --- | --- |
| Root | `open`, `defaultOpen` | Controlled / uncontrolled visibility |
| Root | `snapPoints` | Non-empty array of `(0, 1]` fractions; omit or pass `[]` for content-fit mode |
| Root | `snapPoint`, `defaultSnapPoint` | Controlled / uncontrolled snap stop; pairs with `snapPointChange` |
| Content | `minExtent`, `maxExtent` | Neutral length bounds (`unit` + non-negative finite `value`) |
| Content | `dragDismissible` | Set to `false` to prevent closing via drag |
| Content (exposed) | `extentValid` | Indicates whether the active extent constraints are valid |
