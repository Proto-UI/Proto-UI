Liquid Glass Command renders an always-open searchable command list. Typing filters commands without running side effects; pressing Enter or clicking an enabled item emits `execute` for your application to handle.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Parts**: `Root`, `Input`, `Content`, `Item`, `Empty`.
- **Filtering and keyboard**: matches `textValue` and `keywords` case- and diacritic-insensitively, or set `filter={false}` for caller-filtered lists. Arrow navigation keeps focus in `Input`, and IME composition never executes a command.
- **Controlled state**: `open`, `value`, and `inputValue` can each be controlled independently. `Empty` reflects actual matches; disabled or duplicate-valued items cannot execute.

## API

| Part | Prop / Event | Description |
| --- | --- | --- |
| Root | `value`, `inputValue`, `open` | Independently controllable command and query state |
| Root | `filter` | Set to `false` to provide pre-filtered items |
| Root / Item | `execute` | Emitted when an enabled command is activated |
| Item | `textValue`, `keywords`, `disabled` | Command text, search keywords, and disabled flag |
| Empty | — | Displayed when no commands match |
