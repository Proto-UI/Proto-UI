Liquid Glass Command provides a searchable command menu with concentric corner radii and clear visual hierarchy. The inline command list stays opaque so placing it inside a floating Liquid Glass `Dialog` never stacks glass on glass.

## Installation

Currently available from workspace source (`@proto.ui/prototypes-liquid-glass/command`); not yet included in the 0.2.0 stable release.

## Usage

```tsx
import {
  commandRoot,
  commandInput,
  commandContent,
  commandItem,
  commandEmpty,
} from '@proto.ui/prototypes-liquid-glass/command';
```

### Composition

```text
CommandRoot
├── CommandInput
└── CommandContent
    ├── CommandItem
    └── CommandEmpty
```

- **Material layering & concentric radii**: `CommandContent` stays an ordinary opaque surface (`rounded-2xl` with `p-1`) pairing concentrically with `rounded-xl` items. Place `Command` inside `liquid-glass-dialog-content` for a floating translucent sheet without glass-on-glass stacking.
- **Accessibility preferences**: Disabled entries use semantic muted foreground ink rather than translucent opacity, transitions respect `prefers-reduced-motion`, and reduced-transparency preferences preserve a crisp solid fallback.
- **Filtering and keyboard**: Matches `textValue` and `keywords` case- and diacritic-insensitively, or set `filter={false}` for external filtering. Focus stays in `Input` during arrow navigation and IME composition never executes.

### Other Parts & Events

- **Input**: `placeholder`, `a11yLabel`, and `name` default to `''`.
- **Content**: `side="bottom"`, `align="start"`, `sideOffset={4}`, `collisionPadding={8}`.
- **Item**: `value`, `textValue`, and `keywords` default to `''`; `disabled` defaults to `false`.
- **Empty**: No props; shown when no commands match.
- **Events**: `Root` emits `execute`, `valueChange`, `inputValueChange`, and `openChange`.
