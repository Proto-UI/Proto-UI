Liquid Glass Radio Group pairs translucent material boundaries, crisp edge elevation, and concentric circular dot proportions (`size-2` indicator inside a `size-5` item) with `regular` / `prominent` hierarchy and explicit `material="opaque"` opt-out, while Base Radio Group owns all selection and roving focus semantics.

## Installation

Liquid Glass Radio Group is currently provided from workspace source. Import `radioGroupRoot`, `radioGroupItem`, and `radioGroupIndicator` from `@proto.ui/prototypes-liquid-glass/radio-group` and adapt them to your target runtime.

## Usage

```tsx
import {
  LiquidGlassLabelRoot,
  LiquidGlassRadioGroupIndicator,
  LiquidGlassRadioGroupItem,
  LiquidGlassRadioGroupRoot,
} from '../proto-ui/components/react';

export function RadioGroupUsage() {
  return (
    <LiquidGlassRadioGroupRoot defaultValue="comfortable" a11yLabel="Display density">
      <div className="flex items-center gap-3">
        <LiquidGlassRadioGroupItem value="default">
          <LiquidGlassRadioGroupIndicator />
        </LiquidGlassRadioGroupItem>
        <LiquidGlassLabelRoot>Default</LiquidGlassLabelRoot>
      </div>
      <div className="flex items-center gap-3">
        <LiquidGlassRadioGroupItem value="comfortable">
          <LiquidGlassRadioGroupIndicator />
        </LiquidGlassRadioGroupItem>
        <LiquidGlassLabelRoot>Comfortable</LiquidGlassLabelRoot>
      </div>
      <div className="flex items-center gap-3">
        <LiquidGlassRadioGroupItem value="compact">
          <LiquidGlassRadioGroupIndicator />
        </LiquidGlassRadioGroupItem>
        <LiquidGlassLabelRoot>Compact</LiquidGlassLabelRoot>
      </div>
    </LiquidGlassRadioGroupRoot>
  );
}
```

### Material Hierarchy & Accessibility

- **Never stack glass on glass**: Only individual `Item` controls declare Liquid Glass material; `Root` and `Indicator` remain passive without material layers. When placing radio options inside an elevated glass sheet or card, pass `material="opaque"` on `Item` to keep surface layering legible.
- **Prominence hierarchy**: Use `variant="regular"` for standard choices and `variant="prominent"` to accentuate primary options with tinted styling.
- **Adaptive fallbacks**: Reduced transparency, reduced motion, increased contrast, forced colors, or missing backdrop providers automatically fall back to high-contrast opaque fills and foregrounds. Disabled items withdraw optical material without dimming via `opacity-50`, preserving crisp readability.

### Indicator, Events & Methods

- **Indicator**: No props; inherits `currentColor` from its parent `Item` to draw the concentric dot.
- **Events**: `valueChange` (`{ value: string }`) on Root; `select` (`{ value: string }`) on Item.
- **Methods**: `requestValue(value)`, `resetValue()`, `focusFirst()`, `focusLast()`, `focusNext()`, `focusPrev()`, `focusSelected()`, `focusSelf()` on Root.
