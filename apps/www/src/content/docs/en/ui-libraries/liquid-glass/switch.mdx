Liquid Glass Switch pairs a capsule track with a concentric sliding thumb, applying a tinted on-state fill with optional pointer dragging, RTL mirroring, and an explicit `material="opaque"` fallback mode.

## Installation

Currently available from Proto UI workspace source via `@proto.ui/prototypes-liquid-glass/switch`.

## Usage

```tsx
import { switchRoot, switchThumb } from '@proto.ui/prototypes-liquid-glass/switch';
```

```html
<proto-ui-liquid-glass-switch-root default-checked>
  <proto-ui-liquid-glass-switch-thumb></proto-ui-liquid-glass-switch-thumb>
  <span class="sr-only">Enable notifications</span>
</proto-ui-liquid-glass-switch-root>
```

- **Material & layering**: `material="auto"` requests `liquid-glass` when an in-app backdrop source is available. Set `material="opaque"` inside glass containers or dense forms to avoid stacking glass on glass.
- **Accessibility & fallbacks**: Track and thumb transitions automatically disable under `prefers-reduced-motion: reduce`. Disabled switches withdraw optical material while preserving legible opaque contrast, and Reduced Transparency / Increased Contrast automatically fall back to the opaque surface.
