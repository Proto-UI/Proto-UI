Liquid Glass Autocomplete pairs a single-line text input with filterable suggestions. Selecting a suggestion commits its `textValue`, while pressing Enter with no active suggestion commits free text.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Parts**: `Root`, `Input`, `Content`, `Item`, `Empty`, `Trigger`.
- **Independent state**: `Root` tracks committed text (`value`), live query (`inputValue`), and popup visibility (`open`), each controllable independently through its corresponding change request.
- **Filtering and keyboard**: built-in filtering matches `textValue` and `keywords` case- and diacritic-insensitively; pass `filter={false}` to supply pre-filtered items. Arrow navigation keeps focus in `Input`, and IME composition never selects an option.
- **Validation**: `Empty` reflects actual match count; disabled or duplicate-valued items cannot commit.

## API

| Part | Prop | Description |
| --- | --- | --- |
| Root | `value`, `inputValue`, `open` | Independently controllable committed text, query text, and popup state |
| Root | `filter` | Built-in filtering by default; set `false` for caller-filtered items |
| Item | `textValue`, `keywords`, `disabled` | Option text, search keywords, and disabled flag |
| Empty | — | Displays fallback content when no items match |
