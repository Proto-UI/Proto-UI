Liquid Glass Textarea follows the Apple Liquid Glass Human Interface Guidelines separation between the opaque Content Layer and floating Liquid Glass controls: the editor renders on a high-legibility opaque surface (`bg-background`, `rounded-2xl`, crisp border) without applying translucent glass directly onto editable text, pairing cleanly with prominent Liquid Glass action buttons.

## Installation

Available from workspace source via `@proto.ui/prototypes-liquid-glass/textarea` (and `@proto.ui/prototypes-liquid-glass/field` for form composition).

## Usage

```tsx
import { LiquidGlassTextareaRoot } from '../proto-ui/components/react';
```

```tsx
<LiquidGlassTextareaRoot placeholder="Type your message here." rows={4} />
```

- **Content Layer hierarchy**: Text editing stays on an opaque, readable surface rather than stacking glass on content; pairing the editor's `rounded-2xl` geometry inside a `rounded-3xl` container preserves concentric corner radii.
- **Accessibility and state styling**: Keyboard focus shows a `forced-colors`-aware outer focus ring; disabled state uses semantic `bg-muted` and `text-muted-foreground` fills rather than lowering element opacity so fallback contrast stays readable; invalid state renders a semantic destructive border and halo via `FieldTextarea`.
- **Inherited semantics**: Controlled/uncontrolled values, IME composition events, `resetValue()`, `focusSelf()`, and `blurSelf()` are owned by [Base Textarea](/en/ui-libraries/base/textarea/).

## API

The following props belong to `Root` (pass `value` for controlled mode; `minLength` and `maxLength` default to `-1` when unlimited):

- **Exposed states**: `value`, `disabled`, `readOnly`, `focused`, `focusVisible`, `composing` (plus `invalid` and `pending` on `FieldTextarea`).
- **Exposed methods**: `focusSelf(options?)`, `blurSelf()`, `resetValue()`.
- **Events**: `valueChange`, `change`, `compositionStart`, `compositionUpdate`, `compositionEnd`.
