Liquid Glass Toggle inherits persistent selection semantics from [Base Toggle](/en/ui-libraries/base/toggle/). Inactive toggles render neutral `regular` glass, while active toggles switch to a primary-tinted glass treatment with a symmetrically reserved `currentColor` check mark that keeps labels centered and pill geometry stable.

## Usage

```tsx
import { LiquidGlassToggle } from '../proto-ui/components/react';
```

```tsx
<LiquidGlassToggle defaultActive>Italic</LiquidGlassToggle>
```

### Material and Accessibility

- **Glass & opaque fallback**: `material="auto"` requests optical refraction when the host provides a valid backdrop source; `material="opaque"`, disabled state, reduced transparency, increased contrast, and forced colors fall back to high-contrast opaque color pairs without lowering whole-control opacity.
- **Reduced motion**: Disables elastic press deformation while keeping static optics intact.
- **Avoid glass-on-glass**: Do not nest glass toggles inside another glass surface, and keep spacing between adjacent glass controls so expanded optical paint never overlaps.
- **Accessible naming**: Supply an explicit accessible name (such as a visually hidden label or `aria-labelledby`) for icon-only toggles. Design choices follow Apple's [Materials](https://developer.apple.com/design/human-interface-guidelines/materials) and [Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/) guidance.

## API

The following props belong to `Root` (pass `active` for controlled mode):

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'active', type: 'boolean | undefined', default: 'uncontrolled' },
    { name: 'defaultActive', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'material', type: "'auto' | 'opaque'", default: "'auto'" },
    { name: 'size', type: "'sm' | 'default' | 'lg'", default: "'default'" },
  ]}
/>

- **Events**: `activeChange` (payload `{ active: boolean }`; listen via `onActiveChange` in host adapters).
- **Methods**: `focusSelf(options?)` (no-op while disabled).
- **Exposed states**: `active`, `disabled`, `hovered`, `focused`, `focusVisible`, `pressed`.
