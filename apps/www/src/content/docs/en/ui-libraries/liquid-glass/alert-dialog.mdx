Liquid Glass Alert Dialog interrupts the user for important or destructive confirmations. It traps focus, prevents outside-click dismissal, and focuses `Cancel` first when available.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Parts**: `Root`, `Trigger`, `Content`, `Title`, `Description`, `Cancel`, `Action`, `Mask`.
- **Modality and focus**: `Root` sets alert dialog semantics, `Mask` handles modality, and `Content` traps focus while starting on `Cancel`. Escape and `Cancel` request dismissal.
- **Explicit action**: `Action` emits `action` before requesting close; your application performs the actual side effect.
- **Controlled state**: pass `open` and listen to `openChange` for controlled visibility, or pass `defaultOpen` for uncontrolled usage. Disabled triggers and actions do not activate.

## API

| Part | Prop / Event | Description |
| --- | --- | --- |
| Root | `open`, `defaultOpen` | Controlled / uncontrolled open state |
| Root | `openChange` | Emitted when opening or dismissing is requested |
| Action | `action` | Emitted on confirmation before requesting dismissal |
| Mask / Content | — | Provides modal backdrop, focus trap, and initial focus on `Cancel` |
