Liquid Glass Alert Dialog interrupts the user for important or destructive confirmations. The floating dialog sheet pairs concentric `rounded-3xl` geometry and translucent material intent with crisp non-glass pill controls inside, focusing `Cancel` first and preventing outside-click dismissal.

## Installation

Available starting in `0.3.0-rc.1` and later releases (`@proto.ui/prototypes-liquid-glass`).

## Usage

```tsx
import {
  LiquidGlassAlertDialogRoot,
  LiquidGlassAlertDialogTrigger,
  LiquidGlassAlertDialogMask,
  LiquidGlassAlertDialogContent,
  LiquidGlassAlertDialogTitle,
  LiquidGlassAlertDialogDescription,
  LiquidGlassAlertDialogCancel,
  LiquidGlassAlertDialogAction,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <LiquidGlassAlertDialogRoot>
      <LiquidGlassAlertDialogTrigger>Show Dialog</LiquidGlassAlertDialogTrigger>
      <LiquidGlassAlertDialogMask />
      <LiquidGlassAlertDialogContent>
        <div className="grid gap-1.5">
          <LiquidGlassAlertDialogTitle>Are you absolutely sure?</LiquidGlassAlertDialogTitle>
          <LiquidGlassAlertDialogDescription>
            This action cannot be undone. This will permanently delete your account.
          </LiquidGlassAlertDialogDescription>
        </div>
        <div className="flex flex-wrap-reverse items-center justify-end gap-2.5 pt-1">
          <LiquidGlassAlertDialogCancel>Cancel</LiquidGlassAlertDialogCancel>
          <LiquidGlassAlertDialogAction>Continue</LiquidGlassAlertDialogAction>
        </div>
      </LiquidGlassAlertDialogContent>
    </LiquidGlassAlertDialogRoot>
  );
}
```

### Material & Layering

- **Single translucent sheet**: `Content` declares `liquid-glass` material intent while open with paired semantic fallback fill and foreground colors; `Mask` remains an ordinary dimming scrim.
- **No glass-on-glass stacking**: `Cancel` and `Action` sit inside `Content` as opaque/tinted pill capsules using `regular`, `prominent`, and `destructive` prominence rather than nested glass layers.
- **Accessibility fallbacks**: Pass `material="opaque"` to opt out explicitly; reduced-transparency and high-contrast preferences fall back automatically to the style-owned opaque palette. Disabled controls stay legible without muting fallback opacity.
