The Button projection currently uses a stage-0 fallback: translucent fill and 4px backdrop blur, gated by live preferences and explicit host support. This is ordinary translucency and blur, not Apple Liquid Glass lensing. Shape-dependent refraction, responsive highlights, adaptive appearance and liquid shape transitions remain unimplemented. Unknown or reduced/contrast settings restore an opaque surface.

Button, Surface, Text, Label, Collapsible, Accordion and the five-part Select now have separate direct Base projections. Select Trigger/Content declare shared explicit optical intent with opaque fallback; that intent is separate from Button's adaptive translucency and is not proof of optical painting. Other Base parts are being added explicitly, never aliased to another family. General Compiler and full GPUI/Flutter/Qt realization remain unverified. The source package is private and unreleased.
