An independently implemented functional-surface glass direction. Translucent fill and 4px backdrop blur require affirmative live preference and host-support facts; unknown or reduced/contrast settings restore the opaque fallback. This is not Apple’s native material engine.

Button is registered now. Other Base parts are being added explicitly, never aliased to another family. General Compiler and full GPUI/Flutter/Qt realization remain unverified. The source package is private and unreleased.
