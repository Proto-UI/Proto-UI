Stage-0 fallback for the planned Liquid Glass family: translucent fill and 4px backdrop blur, gated by live preferences and explicit host support. This is ordinary translucency and blur, not Apple Liquid Glass lensing. Shape-dependent refraction, responsive highlights, adaptive appearance and liquid shape transitions remain unimplemented. Unknown or reduced/contrast settings restore an opaque surface.

Button is registered now. Other Base parts are being added explicitly, never aliased to another family. General Compiler and full GPUI/Flutter/Qt realization remain unverified. The source package is private and unreleased.
