**WIP / Experimental — 0.4 workstream, outside the 0.3 release commitment.** Existing source and previews remain available for evaluation; they are not stable 0.3 support claims.

V2 Liquid Glass intent is connected to an opt-in self-optical Web provider. The Previewer supplies a visible, dynamic application-owned canvas as the exact sampled background. Arbitrary DOM and browser-compositor capture are not supported: intervening paint, cross-scope portals or unavailable source/preferences retain readable fallback. Reduced motion uses static optics. Exact-head browser evidence is required before admitting this draft provider; native, Apple-private, group/morph and full Compiler equivalence remain unverified.

Button, Surface, Text, Label, Collapsible, Accordion and the five-part Select now have separate direct Base projections. Select Trigger/Content declare shared explicit optical intent with opaque fallback; exact-head optical painting still requires accepted browser evidence. Other Base parts are being added explicitly, never aliased to another family. General Compiler and full GPUI/Flutter/Qt realization remain unverified. The source package is private and unreleased.

[Toggle (Draft)](/en/ui-libraries/liquid-glass/toggle/) adds a direct Base persistent-active projection: both states use regular material; selection uses bounded style tint and a fixed-space checkmark. Tint must preserve structured backdrop response, and selection does not resize the control. This is a Proto extension, not exact Apple parity.

## Hover and press (draft)

Button, Toggle, Form Submit/Reset, Accordion Trigger, Collapsible Trigger, Select Trigger and Dropdown Trigger use the same static hover foundation over Base-owned states. Hover, press, persistent selection and keyboard focus stay distinct; disabled or blocked controls stay quiet. The recipe adds restrained elevation and an inner edge without resizing the control. It is a Proto design choice informed by [iPadOS 26 pointer guidance](https://developer.apple.com/videos/play/wwdc2025/208/?time=560), not Apple's moving refractive highlight platter. Existing held-pointer contact remains separate, with safe fallback when its expanded paint bounds cannot be sampled. Exact-head visual acceptance is pending. Form actions retain a single Base Form owner, inherited render and auto/opaque material defaults; disabled actions suppress requests without fading the whole control. This Form extension depends on separate CLI borrowed-state closure. The remaining family roles are later slices.
