Liquid Glass Text realizes [Base Text](/en/ui-libraries/base/text/) across all eight independent typography axes using system sans and monospace font stacks and crisp foreground tokens, staying purely typographic with no glass material or interaction ownership of its own.

## Installation

Currently available from workspace source only; available starting in `0.3.0-rc.1` and later releases. Import `textRoot` (also exported as `liquidGlassTextRoot` and `LiquidGlassTextRoot`) from `@proto.ui/prototypes-liquid-glass/text`, or generate workspace facades with the `liquid-glass-text` CLI target.

## Usage

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { liquidGlassTextRoot } from '@proto.ui/prototypes-liquid-glass/text';

const Text = createReactAdapter(React)(liquidGlassTextRoot, { rootTag: 'span' });

export function SheetHeading() {
  return (
    <h2>
      <Text size="2xl" font="heading" weight="semibold" leading="tight" tracking="tight">
        Display &amp; Clarity
      </Text>
    </h2>
  );
}
```

### Liquid Glass layering and legibility guidelines

Following Apple's [Materials](https://developer.apple.com/design/human-interface-guidelines/materials) and [Typography](https://developer.apple.com/design/human-interface-guidelines/typography) guidelines:

- **Keep text off stacked glass**: Long-form reading and page headings belong on the opaque content canvas. Labels inside a floating Liquid Glass control or bar use `tone="inherit"` to pick up crisp foreground ink—never turn Text itself into a glass surface or stack glass on glass.
- **Regular vs. prominent contrast**: Inside a regular translucent surface (`material="auto"`), pair inherited primary ink with `tone="muted"` captions; inside a prominent tinted surface (`solid`), use `tone="inherit"` so primary white ink remains legible.
- **Reduced transparency and increased contrast**: When users enable reduced transparency or increased contrast—or when a host opts into `material="opaque"`—semantic foreground variables paired with `tone="inherit"` preserve strong legibility without opacity washout.
- **Leading, tracking, and selection**: `leading="size"` keeps each size token's built-in line box, `leading="tighter"` maps to `1.1`, and `tracking="tighter"` maps to `-0.05em`. Text never overrides `user-select`; wrap with native `h1`, `p`, `label`, `a`, or `button` elements for document or interactive semantics.
