Liquid Glass Text builds on [Base Text](/en/ui-libraries/base/text/) (via `asTextRoot()`) with all eight independent typography axes and a content slot. It handles typography presentation only, leaving heading levels, links, labels, buttons, and editing semantics to native elements or interactive controls.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

```ts
import { textRoot, LiquidGlassTextRoot } from '@proto.ui/prototypes-liquid-glass/text';
```

## Usage

- An explicit `leading` prop takes precedence over the composite line-height implied by `size`; removing any prop restores its default.
- Set `tone="inherit"` when placing Text inside a surface or control whose foreground color you want to preserve.
- Text never overrides `user-select`: document prose stays naturally selectable, while text inside interactive controls inherits the control's selection behavior.
- Wrap or pair with native `h1`, `p`, `label`, `a`, or `button` elements when semantic roles or navigation are needed.

The Liquid Glass theme defines `body`, `heading`, and `mono` font stacks along with `default` and `muted` ink colors without bundling third-party font files.

## API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `'xs' \| 'sm' \| 'base' \| 'lg' \| 'xl' \| '2xl' \| '3xl' \| '4xl' \| '5xl'` | `'base'` | Font size scale |
| `tone` | `'default' \| 'muted' \| 'inherit'` | `'default'` | Text color tone |
| `weight` | `'normal' \| 'medium' \| 'semibold' \| 'bold'` | `'normal'` | Font weight |
| `font` | `'body' \| 'heading' \| 'mono'` | `'body'` | Font family stack |
| `leading` | `'tight' \| 'snug' \| 'normal' \| 'relaxed'` | `'normal'` | Line height; overrides the composite size line-height when set |
| `tracking` | `'normal' \| 'tight'` | `'normal'` | Letter spacing |
| `emphasis` | `'normal' \| 'italic'` | `'normal'` | Font style |
| `decoration` | `'none' \| 'underline' \| 'line-through'` | `'none'` | Text decoration |
