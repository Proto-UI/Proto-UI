## Inputs

- `size`: xs, sm, base, lg, xl, 2xl, 3xl, 4xl, 5xl (default base)
- `tone`: default, muted, inherit (default default)
- `weight`: normal, medium, semibold, bold (default normal)
- `font`: body, heading, mono (default body)
- `leading`: tight, snug, normal, relaxed (default normal)
- `tracking`: normal, tight (default normal)
- `emphasis`: normal, italic (default normal)
- `decoration`: none, underline, line-through (default none)

Explicit leading takes precedence over composite size line-height; removing props restores defaults. `tone="inherit"` follows the surrounding owner ink. Text never sets user-select: document content retains natural selection and text inside a control follows that actual control’s policy. Native h1, p, label, a and button elements retain semantics, for/href and input behavior.

## Workspace source

```ts
import { textRoot, LiquidGlassTextRoot } from '@proto.ui/prototypes-liquid-glass/text';
```

The package remains private/unreleased; its CLI Text entry requires workspace source mode for WC, React, Vue and Vue 2 facades. The family theme provides body/heading/mono font stacks and default/muted ink without bundling third-party fonts. Real four-Adapter synthetic-DOM checks and compiler mappings are separate evidence; they do not prove native paint or GPUI typography parity. The GPUI CLI host remains explicitly unsupported.
