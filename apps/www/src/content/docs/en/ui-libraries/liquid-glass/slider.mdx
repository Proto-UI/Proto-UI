Liquid Glass Slider pairs a slim continuous track with an elevated capsule thumb for single-value and multi-thumb range selection, offering transient Liquid Glass refraction during active drag plus `Field` / `Form` integration.

## Installation

Available starting in `0.3.0-rc.1` and later releases. Import scalar slider parts and multi-value `sliderValues*` parts from `@proto.ui/prototypes-liquid-glass/slider`.

## Usage

```tsx
import {
  LiquidGlassSliderRoot,
  LiquidGlassSliderTrack,
  LiquidGlassSliderIndicator,
  LiquidGlassSliderThumb,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <LiquidGlassSliderRoot defaultValue={33} min={0} max={100} step={1}>
      <LiquidGlassSliderTrack>
        <LiquidGlassSliderIndicator />
        <LiquidGlassSliderThumb />
      </LiquidGlassSliderTrack>
    </LiquidGlassSliderRoot>
  );
}
```

- **Material layering**: Scalar `Thumb` and `FieldThumb` stay crisp opaque capsules at rest and request transient `liquid-glass` material only during active press/drag. Set `material="opaque"` when embedding a slider inside an already-glass toolbar or sheet to avoid stacking glass on glass, and disabled or reduced-transparency states keep a readable opaque fallback.
- **Pointer and keyboard**: `Track` handles mouse and touch dragging; `Thumb` supports arrow keys (mirrored in horizontal RTL), `Shift` ×10 stepping, `PageUp`/`PageDown`, and `Home`/`End`.
- **Field and Form integration**: Replace `Thumb` with `FieldThumb` inside [Field](/en/ui-libraries/liquid-glass/field/) or [Form](/en/ui-libraries/liquid-glass/form/), or mount a grouped `Values Root` reporting `number[]`.
