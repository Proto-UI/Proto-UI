## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Parts**: `Root`, `Label`, `Track`, `Indicator`, `Thumb`, `FieldThumb`, `Value`.
- **Dragging and keyboard**: `Track` handles pointer and touch dragging, while `Thumb` provides a focusable slider supporting arrow keys (mirrored in horizontal RTL), `Shift` ×10 stepping, `PageUp`/`PageDown`, and `Home`/`End`. Values snap from `min` by `step` and clamp to `[min, max]`.
- **Controlled state**: pass `value` and handle `valueChange` for controlled mode; `valueCommit` fires when an interaction finishes, and cancelling an uncontrolled drag restores its starting value.
- **Field and Form integration**: replace `Thumb` with `FieldThumb` inside [Field](/en/ui-libraries/liquid-glass/field/) or [Form](/en/ui-libraries/liquid-glass/form/) to bridge `FieldLabel`, numeric validation, serialization, and reset.

## API

| Part | Prop / Event | Description |
| --- | --- | --- |
| Root | `value`, `defaultValue` | Controlled / uncontrolled numeric value |
| Root | `min`, `max`, `step` | Numeric bounds and step increment |
| Root | `disabled`, `readOnly`, `orientation`, `direction` | Interaction state, axis, and reading direction |
| Root | `valueChange`, `valueCommit` | Live change proposal / interaction completion event |
| Track / Indicator / Label / Value | — | Interactive track, filled range, label, and passive readout |
| Thumb / FieldThumb | — | Standalone focusable thumb / Field- and Form-integrated thumb |
