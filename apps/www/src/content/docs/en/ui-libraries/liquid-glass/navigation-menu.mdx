Liquid Glass Navigation Menu pairs a floating capsule bar with open-gated Liquid Glass V2 panels (avoiding glass-on-glass stacking), concentric corner radii (`rounded-2xl` + `p-1` outer panel with `rounded-xl` inner items), real native `<a>` links, and complete opaque accessibility fallbacks.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototypes directly from `@proto.ui/prototypes-liquid-glass/navigation-menu`:

```ts
import {
  navigationMenuRoot,
  navigationMenuTrigger,
  navigationMenuContent,
  navigationMenuItem,
  navigationMenuLink,
} from '@proto.ui/prototypes-liquid-glass/navigation-menu';
```

## Usage

```tsx
import {
  LiquidGlassNavigationMenuRoot,
  LiquidGlassNavigationMenuTrigger,
  LiquidGlassNavigationMenuContent,
  LiquidGlassNavigationMenuItem,
  LiquidGlassNavigationMenuLink,
} from '../proto-ui/components/react';

export function LiquidGlassSiteNav() {
  return (
    <LiquidGlassNavigationMenuRoot a11yLabel="Main navigation">
      <LiquidGlassNavigationMenuTrigger value="getting-started" prominence="prominent">
        Getting started
      </LiquidGlassNavigationMenuTrigger>
      <LiquidGlassNavigationMenuContent value="getting-started" a11yLabel="Getting started">
        <LiquidGlassNavigationMenuLink href="/docs" current>
          Introduction
        </LiquidGlassNavigationMenuLink>
        <LiquidGlassNavigationMenuItem value="quick-search" textValue="Quick search">
          Quick search
        </LiquidGlassNavigationMenuItem>
      </LiquidGlassNavigationMenuContent>
    </LiquidGlassNavigationMenuRoot>
  );
}
```

### Composition

```text
NavigationMenuRoot (navigation capsule)
├── NavigationMenuTrigger (regular | prominent pill, paired by value)
└── NavigationMenuContent (liquid-glass | opaque region, paired by value)
    ├── NavigationMenuLink (native <a>, concentric rounded-xl)
    └── NavigationMenuItem (command action, concentric rounded-xl)
```

### Material Hierarchy & Native Links

- **Single floating glass layer**: Only the open `Content` panel requests the `liquid-glass` material candidate while inner `Item` and `Link` rows use subtle semantic highlights instead of stacking glass-on-glass. Pass `material="opaque"` on `Content` to opt out into the solid fallback surface explicitly.
- **Prominence & readability**: `Trigger` supports `prominence="regular"` and `prominence="prominent"`. Disabled controls withdraw elevation rather than fading opaque foreground contrast.
- **Native links & dismissal**: `Link` renders a real anchor with `href`, `target`, `rel`, `current` (`aria-current="page"`), and `closeOnSelect` (owned by `Item` and `Link`, defaulting to `true`). After native activation, `Link` emits a read-only `navigate` event; modifier clicks, middle clicks, and `_blank` targets keep the current panel open.
