## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Parts**: `Root`, `Trigger`, `Content`, `Item`, `Link`.
- **Panels and commands**: `Root.value` identifies the single open named `region` panel, `Trigger` toggles it, and `Item` emits an application command.
- **Native links**: `Link` renders a real anchor (`href`, `target`, `rel`, and `current` for `aria-current`) in React, Vue, Vue 2, and inside an owned local anchor in Web Components. Disabled links remove their destination and prevent activation.
- **Navigation observation**: `Link` emits a read-only `navigate` event (`href`, `target`, `rel`, `modified`) after native activation. Ordinary same-window navigations close the panel unless `closeOnSelect={false}`; modifier clicks, middle clicks, and `_blank` targets leave the panel open.

## API

| Part | Prop / Event | Description |
| --- | --- | --- |
| Root | `value`, `closeOnSelect` | Active panel key / whether same-window link activation closes the panel |
| Trigger / Content | — | Disclosure button and labelled navigation `region` |
| Item | — | Actionable navigation item |
| Link | `href`, `target`, `rel`, `current`, `disabled` | Native link attributes and current-page state; emits read-only `navigate` |
