Liquid Glass Tooltip reveals concise supplementary descriptions on hover or keyboard focus. Following Apple Liquid Glass layering guidance, non-interactive tooltip content uses a crisp opaque surface with concentric `rounded-xl` geometry and a specular hairline edge instead of stacking glass on top of Liquid Glass controls.

## Installation

Liquid Glass Tooltip is available from workspace source via `@proto.ui/prototypes-liquid-glass/tooltip` (`tooltipGroup`, `tooltipRoot`, `tooltipTrigger`, `tooltipContent`) for use with any Proto UI host adapter.

## Usage

```tsx
import {
  LiquidGlassTooltipGroup,
  LiquidGlassTooltipRoot,
  LiquidGlassTooltipTrigger,
  LiquidGlassTooltipContent,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <LiquidGlassTooltipGroup>
      <LiquidGlassTooltipRoot>
        <LiquidGlassTooltipTrigger>Account</LiquidGlassTooltipTrigger>
        <LiquidGlassTooltipContent side="top">View account settings</LiquidGlassTooltipContent>
      </LiquidGlassTooltipRoot>
    </LiquidGlassTooltipGroup>
  );
}
```

### Composition

```text
TooltipGroup (optional)
└── TooltipRoot
    ├── TooltipTrigger
    └── TooltipContent
```

### Materials & Accessibility

- **No Glass-on-Glass**: Optical Liquid Glass is reserved for functional navigation and action controls; non-interactive tooltip copy uses a legible standard opaque surface with a subtle inset highlight.
- **Concentric Geometry**: `rounded-xl` corners pair cleanly with pill-shaped Liquid Glass controls across Light and Dark themes.
- **System Fallbacks**: Respects `prefers-reduced-transparency` and `forced-colors` by switching to a high-contrast solid border without shadow, and respects `prefers-reduced-motion` by disabling enter/exit animation.

### Events, States & Methods

- **Root**: Exposes read-only state `open`, event `openChange` (`{ open, reason }`), and methods `openTooltip(reason?)`, `close(reason?)`, `toggle(reason?)`.
- **Trigger**: Exposes read-only states `disabled`, `hovered`, `focused`, `focusVisible`, and method `focusSelf(options?)`.
- **Content**: Exposes read-only state `open` and Transition handles (`transitionState`, `isPresent`, `controls`).
