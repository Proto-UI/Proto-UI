Liquid Glass Input is built on [Base Input](../../base/input/). Following Apple Liquid Glass layer separation, inline text editors stay on a crisp, legible opaque content surface with concentric rounded geometry instead of stacking glass-on-glass, pairing naturally with floating glass controls.

## Installation

Currently available from Proto UI workspace source and not yet published to the CLI; import directly from `@proto.ui/prototypes-liquid-glass/input`.

## Usage

```tsx
import { LiquidGlassInputRoot } from '@/components/ui/liquid-glass-input';

export function Example() {
  return <LiquidGlassInputRoot placeholder="Enter text" ariaLabel="Text input" />;
}
```

- **Layer hierarchy and legibility**: Uses `h-11`, `rounded-2xl`, a clear border, and an opaque semantic background so text stays sharp against rich backdrops. Pointer focus displays a subtle accent ring, while keyboard focus shows a high-contrast offset ring with forced-colors support.
- **State clarity**: `readOnly` and `disabled` differentiate via semantic muted fills and ink without washing out contrast with low opacity.
- **Composition**: Pair with Liquid Glass `Label`, `Field`, or floating Liquid Glass `Button` controls for forms and search bars.
