Liquid Glass Surface builds on [Base Surface](/en/ui-libraries/base/surface/) (via `asSurfaceRoot()`) to provide a single-slot passive container with radii, borders, elevation, optional optical material, and fade support. It handles presentation only; interaction, focus, and semantics remain on the owning control.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import `surfaceRoot` from `@proto.ui/prototypes-liquid-glass/surface` (or the package root).

## Usage

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { surfaceRoot } from '@proto.ui/prototypes-liquid-glass/surface';

const Surface = createReactAdapter(React)(surfaceRoot);

export function Summary() {
  return (
    <Surface variant="muted" radius="md" border="none">
      <div style={{ padding: '1rem' }}>Saved locally</div>
    </Surface>
  );
}
```

### Opting into glass material

Surface renders with ordinary opaque paint by default (`material="opaque"`). For functional or navigation shells, pass `material="auto"` to request `regular` Liquid Glass optics:

- Only `outline`, `secondary`, and `muted` participate in glass material requests; `transparent`, `accent`, `solid`, and `scrim` always use ordinary paint.
- When optical support, a valid backdrop source, contrast, or accessibility preferences do not allow glass, Surface keeps its readable opaque styling. Setting `material="opaque"` or removing the prop returns to ordinary paint.
- When nesting styled Text inside Surface, set `tone="inherit"` on Text to keep the enclosing foreground color.
- Compose real interactive controls (such as Button or a native `<a>`) rather than attaching roles or click handlers to Surface.

### Coordinating with Transition

Pass the phase from an external [Transition](/en/ui-libraries/base/transition/) to `transitionState` with `fade={true}` to map `closed` and `leaving` to opacity `0` and `entering` and `entered` to opacity `1`. On Web, forward a finite non-negative millisecond duration via the `--pui-surface-transition-duration` CSS variable (default `0ms`).

`fade` affects opacity only and does not alter interactivity, mounting, or focus. The `scrim` variant renders standard dimming paint without blur or refraction.

## API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'transparent' \| 'outline' \| 'secondary' \| 'muted' \| 'accent' \| 'solid' \| 'scrim'` | `'outline'` | Visual surface variant |
| `radius` | `'default' \| 'none' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| 'full'` | `'default'` | Corner radius |
| `border` | `'all' \| 'bottom' \| 'none'` | `'all'` | Border placement |
| `elevation` | `'none' \| 'raised'` | `'none'` | Elevation level |
| `material` | `'auto' \| 'opaque'` | `'opaque'` | Set to `'auto'` to opt eligible variants into glass material |
| `transitionState` | `'closed' \| 'entering' \| 'entered' \| 'leaving'` | `'entered'` | Phase from an external Transition |
| `fade` | `boolean` | `false` | Enables opacity mapping for `transitionState` |
| `hovered` | `boolean` | `false` | External hover visual state |
| `focusVisible` | `boolean` | `false` | External focus-visible visual state |
| `pressed` | `boolean` | `false` | External pressed visual state |
| `current` | `boolean` | `false` | External current-item visual state (visual only; does not set `aria-current`) |

Removing any prop restores its default. Surface exposes no states, events, or methods.
