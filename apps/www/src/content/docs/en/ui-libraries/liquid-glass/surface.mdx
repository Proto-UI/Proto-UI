Liquid Glass Surface builds on [Base Surface](/en/ui-libraries/base/surface/) to provide a passive visual container with concentric `12px` (`rounded-xl`) default corners, readable opaque defaults, and explicit opt-in glass material (`material="auto"`) for functional floating shells. Interaction and semantic ownership remain with the enclosing control.

## Installation

Available inside the workspace from `@proto.ui/prototypes-liquid-glass/surface` (or the package root); not published to the public CLI registry.

## Usage

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { surfaceRoot } from '@proto.ui/prototypes-liquid-glass/surface';

const Surface = createReactAdapter(React)(surfaceRoot);

export function FloatingPanel() {
  return (
    <Surface variant="outline" material="auto" elevation="raised">
      <div className="p-1">
        <Surface variant="secondary" material="opaque" radius="lg" border="none">
          <div className="p-3">Opaque content nested with concentric corners</div>
        </Surface>
      </div>
    </Surface>
  );
}
```

### Optical material and layering

- Surface defaults to ordinary opaque paint (`material="opaque"`). Opt into `material="auto"` only on eligible floating navigation or functional shells—never stack glass on glass.
- Only `outline`, `secondary`, and `muted` participate in `regular` Liquid Glass material requests; `transparent`, `accent`, `solid`, and `scrim` always remain ordinary paint. Reduced-transparency, increased-contrast, and contrast checks automatically preserve readable opaque fallbacks.
- Maintain concentric corner radii (`outer = inner + padding`), such as an outer `radius="xl"` (`12px`) shell with `p-1` (`4px`) around an inner `radius="lg"` (`8px`) opaque card.
- Enable `fade` to map `transitionState` from [Transition](/en/ui-libraries/base/transition/) to opacity (`closed` and `leaving` -> `0`; `entering` and `entered` -> `1`), reading `--pui-surface-transition-duration` (default `0ms`) on Web.
