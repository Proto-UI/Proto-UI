Liquid Glass Dialog builds on [Base Dialog](../../base/dialog/) with a floating `liquid-glass` sheet surface, subtle inset rim highlight, concentric pill actions, fluid presence transitions, and automatic opaque fallbacks for reduced-transparency and high-contrast environments.

## Installation

Currently available from workspace source (`@proto.ui/prototypes-liquid-glass/dialog`). Generate runtime facades inside the workspace with `proto-ui add <wc|react|vue|vue2> liquid-glass-dialog`.

## Usage

```tsx
import {
  LiquidGlassDialogClose,
  LiquidGlassDialogContent,
  LiquidGlassDialogDescription,
  LiquidGlassDialogMask,
  LiquidGlassDialogRoot,
  LiquidGlassDialogTitle,
  LiquidGlassDialogTrigger,
} from '@/components/proto-ui/liquid-glass';

export function LiquidGlassDialogExample() {
  return (
    <LiquidGlassDialogRoot a11yLabel="Edit profile">
      <LiquidGlassDialogTrigger>Open Dialog</LiquidGlassDialogTrigger>
      <LiquidGlassDialogMask />
      <LiquidGlassDialogContent>
        <LiquidGlassDialogTitle>Edit profile</LiquidGlassDialogTitle>
        <LiquidGlassDialogDescription>
          Make changes to your profile here. Click save when you&apos;re done.
        </LiquidGlassDialogDescription>
        <div className="flex justify-end gap-2">
          <LiquidGlassDialogClose prominence="regular">Cancel</LiquidGlassDialogClose>
          <LiquidGlassDialogClose prominence="prominent">Save changes</LiquidGlassDialogClose>
        </div>
      </LiquidGlassDialogContent>
    </LiquidGlassDialogRoot>
  );
}
```

### Composition

```text
LiquidGlassDialogRoot
├── LiquidGlassDialogTrigger
├── LiquidGlassDialogMask
└── LiquidGlassDialogContent
    ├── LiquidGlassDialogTitle
    ├── LiquidGlassDialogDescription
    └── LiquidGlassDialogClose
```

### Material and accessibility guidelines

- **Never stack glass-on-glass**: Only `Content` declares `liquid-glass` material; inner `Close` pill buttons remain crisp non-glass surfaces so contrast and hierarchy stay legible.
- **Prominence hierarchy & concentric radii**: `Trigger` supports `regular` and `prominent`; `Close` supports `regular`, `prominent`, and `destructive`. `rounded-full` pills nest concentrically within the `rounded-2xl` sheet padding.
- **Motion & fallbacks**: Enter/leave transitions (200 ms / 150 ms) respect `prefers-reduced-motion`. Disabled controls withdraw elevation rather than dimming opacity, preserving readability under opaque fallback, and `material="opaque"` provides an explicit per-dialog opt-out.
