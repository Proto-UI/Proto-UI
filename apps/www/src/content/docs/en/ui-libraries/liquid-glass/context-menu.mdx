Liquid Glass Context Menu places the open menu strictly in the floating control layer above content, pairing a `16px` outer radius and `4px` inset with concentric `12px` items. `Trigger` remains an ordinary non-glass surface to avoid stacking glass-on-glass, and `Content` falls back cleanly to a high-contrast opaque surface under reduced-transparency, increased-contrast, or `material="opaque"`.

Available starting in `0.3.0-rc.1` and later releases (available in workspace source).

## Usage

```tsx
import {
  LiquidGlassContextMenuContent,
  LiquidGlassContextMenuItem,
  LiquidGlassContextMenuRoot,
  LiquidGlassContextMenuTrigger,
} from '@/components/proto-ui';

export function Example() {
  return (
    <LiquidGlassContextMenuRoot>
      <LiquidGlassContextMenuTrigger className="h-36 w-72 border-dashed">
        Right click here
      </LiquidGlassContextMenuTrigger>
      <LiquidGlassContextMenuContent>
        <LiquidGlassContextMenuItem value="back">Back</LiquidGlassContextMenuItem>
        <LiquidGlassContextMenuItem value="forward" disabled>
          Forward
        </LiquidGlassContextMenuItem>
        <LiquidGlassContextMenuItem value="reload">Reload</LiquidGlassContextMenuItem>
      </LiquidGlassContextMenuContent>
    </LiquidGlassContextMenuRoot>
  );
}
```

### Composition

```text
ContextMenuRoot
├── ContextMenuTrigger (ordinary surface)
└── ContextMenuContent (Liquid Glass floating layer)
    ├── ContextMenuItem (concentric rounded-xl)
    └── ContextMenuItem (concentric rounded-xl)
```

- **Layering and concentric geometry**: `Trigger` stays on the content layer without material intent, while `Content` requests `liquid-glass` only while open. Disabled items use muted ink rather than opacity dimming so opaque fallbacks stay legible.
- **Motion and preference fallbacks**: Open/close transitions automatically yield to `reducedMotion`, and `material="opaque"` lets any surface opt out of translucency explicitly.
