Liquid Glass Transition coordinates a transparent five-phase presence lifecycle (`closed → preparing → entering → entered → leaving`) for floating Liquid Glass surfaces over rich backdrop content. It binds endpoint opacity (`opacity-100` / `opacity-0`) without adding a material carrier of its own, preventing glass-on-glass stacking.

The floating translucent surface rests above a colorful gradient canvas with concentric radii and crisp edge highlights. Use `Enter`, `Leave`, and `Complete` to inspect the live five-phase strip and presence badge.

## Installation

Currently available from workspace source; not yet included in `@proto.ui/cli` add targets. Import directly from workspace source:

```ts
import { transition } from '@proto.ui/prototypes-liquid-glass/transition';
```

## Usage

```tsx
import { useState } from 'react';
import { LiquidGlassButton, LiquidGlassTransition } from '../proto-ui/components/react';

export function FloatingGlassPanel() {
  const [open, setOpen] = useState(true);

  return (
    <div className="rounded-2xl bg-gradient-to-br from-sky-500/25 via-indigo-500/20 to-fuchsia-500/25 p-5">
      <LiquidGlassTransition
        open={open}
        appear
        className="block transition-opacity duration-300 ease-out motion-reduce:transition-none"
      >
        <div className="rounded-2xl border border-white/55 bg-white/70 p-4 shadow-lg backdrop-blur-xl">
          Floating Liquid Glass overlay
        </div>
      </LiquidGlassTransition>
      <div className="mt-4">
        <LiquidGlassButton variant="prominent" onClick={() => setOpen((value) => !value)}>
          Toggle Panel
        </LiquidGlassButton>
      </div>
    </div>
  );
}
```

## Material & Accessibility

Design choices follow Apple Human Interface Guidelines for [Materials](https://developer.apple.com/design/human-interface-guidelines/materials):

- **Never stack glass on glass**: `liquid-glass-transition` stays transparent with no material carrier of its own, wrapping floating glass controls and panels cleanly.
- **Concentric geometry & prominence**: Match nested radii concentrically (`rounded-2xl` outer container + inner padding + `rounded-xl` inner pill) and reserve `prominent` tinting for a single primary action or overlay in a group.
- **Accessibility fallbacks**: Pair floating surfaces with high-contrast opaque fallbacks (`material="opaque"`) for Reduce Transparency and Increase Contrast preferences. Under `prefers-reduced-motion: reduce`, Transition collapses fallback waits to `0ms` while keeping phase and event ordering intact.
- **Shared semantics**: All phase sequencing, presence retention, and interruption behavior is inherited from [Base Transition](/en/ui-libraries/base/transition/).
