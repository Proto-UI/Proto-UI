## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Parts**: `Root`, `Trigger`, `Content`, `Item`.
- **Panel pairing**: `Root.value` identifies the single open panel, matching a `Trigger.value` to its `Content.value`. Controlled `value` emits requests without mutating caller state.
- **Keyboard navigation**: the bar uses one roving Tab stop. Left/Right move across top-level triggers, Up/Down enter and navigate menu items, and typeahead jumps to matching commands. Escape restores focus to the active trigger; outside clicks and item selection dismiss the panel.

## API

| Part    | Prop    | Description                                                       |
| ------- | ------- | ----------------------------------------------------------------- |
| Root    | `value` | Identifier of the currently open panel (supports controlled mode) |
| Trigger | `value` | Panel identifier paired with `Content`                            |
| Content | `value` | Command panel paired with `Trigger`                               |
| Item    | —       | Actionable menu command                                           |
