A Liquid Glass horizontal menu bar with concentric corner radii (`rounded-2xl` outer containers with `p-1` padding and `rounded-xl` inner controls), applying optical glass material exclusively to open floating panels to avoid glass-on-glass stacking while preserving high-contrast opaque fallbacks.

## Installation

Currently available from workspace source and not yet included in the 0.2.0 stable release; import the prototypes from `@proto.ui/prototypes-liquid-glass/menubar` and adapt them for your target runtime.

## Usage

```tsx
import {
  LiquidGlassMenubarRoot,
  LiquidGlassMenubarTrigger,
  LiquidGlassMenubarContent,
  LiquidGlassMenubarItem,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <LiquidGlassMenubarRoot a11yLabel="Workspace menu">
      <LiquidGlassMenubarTrigger value="file">File</LiquidGlassMenubarTrigger>
      <LiquidGlassMenubarContent value="file" a11yLabel="File menu">
        <LiquidGlassMenubarItem value="new-tab">New Tab</LiquidGlassMenubarItem>
        <LiquidGlassMenubarItem value="print">Print...</LiquidGlassMenubarItem>
      </LiquidGlassMenubarContent>
    </LiquidGlassMenubarRoot>
  );
}
```

### Composition & Material Hierarchy

```text
MenubarRoot (rounded-2xl p-1)
├── MenubarTrigger (rounded-xl, prominent active fill)
├── MenubarContent (rounded-2xl p-1, liquid-glass material when open)
│   ├── MenubarItem (rounded-xl concentric highlight)
│   └── MenubarItem
└── ...
```

- `Root` and `Trigger` stay ordinary non-glass controls so glass is never stacked on glass; expanded triggers elevate into a prominent primary fill.
- `Content` declares a `liquid-glass` material candidate with a subtle inset specular rim when open and `material="auto"`, or renders its complete opaque surface when `material="opaque"`.
- `Item` uses concentric `rounded-xl` geometry and preserves opaque readable text when disabled rather than dimming the entire surface with `opacity-50`.

### Keyboard and accessibility

- The bar uses a single roving `Tab` stop; `ArrowLeft` and `ArrowRight` move across top-level triggers.
- `ArrowDown` and `ArrowUp` open and navigate menu items vertically, with typeahead character jump.
- Pressing `Escape` dismisses the panel and returns focus to its active trigger; outside clicks and command selection close the panel by default.
