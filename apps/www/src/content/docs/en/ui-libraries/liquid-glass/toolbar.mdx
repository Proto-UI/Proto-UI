Liquid Glass Toolbar applies translucent glass strictly to the floating `Root` layer and hosts borderless concentric pill buttons inside—avoiding glass-on-glass stacking while providing single-Tab roving focus and arrow-key navigation.

## Installation

Available starting in `0.3.0-rc.1` and later releases. Import the prototypes directly from `@proto.ui/prototypes-liquid-glass/toolbar` and adapt them for your target framework:

```ts
import {
  toolbarRoot,
  toolbarButton,
  toolbarSeparator,
} from '@proto.ui/prototypes-liquid-glass/toolbar';
```

## Usage

```tsx
import {
  LiquidGlassToolbarRoot,
  LiquidGlassToolbarButton,
  LiquidGlassToolbarSeparator,
} from '../proto-ui/components/react';

export function FloatingToolbar() {
  return (
    <LiquidGlassToolbarRoot a11yLabel="Document actions">
      <LiquidGlassToolbarButton value="undo">Undo</LiquidGlassToolbarButton>
      <LiquidGlassToolbarButton value="redo">Redo</LiquidGlassToolbarButton>
      <LiquidGlassToolbarSeparator />
      <LiquidGlassToolbarButton value="publish" variant="prominent">
        Publish
      </LiquidGlassToolbarButton>
    </LiquidGlassToolbarRoot>
  );
}
```

### Material Hierarchy and Accessibility

- **No glass-on-glass stacking**: Only `Root` declares the `liquid-glass` material surface (opt out anytime via `material="opaque"`). Child `Button` and `Separator` parts stay optically neutral so foreground labels remain legible.
- **Concentric geometry and prominence**: Horizontal toolbars pair a capsule (`rounded-full`) container with concentric pill controls, while vertical toolbars use `rounded-2xl`. Reserve `variant="prominent"` for the primary action and use borderless `regular` pills for secondary commands.
- **System preference fallbacks**: Reduced transparency and forced-colors preferences switch to crisp opaque surfaces with visible focus outlines; reduced motion disables transitions; disabled buttons preserve readable contrast without washing out fallback text via opacity fading.

### Separator and Events

- **Separator**: Takes no additional props, aligns along the cross axis automatically, and never declares nested glass material.
- **Events and exposes**: `Button` emits `action` (`{ value: string }`) on activation. `Root` exposes `disabled`, `focusFirst()`, `focusLast()`, and `setCurrent(id)`; `Button` exposes `disabled`, `focused`, `focusVisible`, and `focusSelf(options)`.
