## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Parts**: `Root`, `Button`, `Separator`.
- **Navigation and actions**: only one enabled command participates in Tab order while arrow keys navigate across enabled commands (configured by `orientation` and `loop`). Activating an enabled `Button` emits `action` with its `value`. `Separator` aligns along the cross axis.

## API

| Part | Prop / Event | Description |
| --- | --- | --- |
| Root | `disabled`, `orientation`, `loop`, `a11yLabel` | Toolbar disable state, axis, focus looping, and accessible name |
| Button | `value`, `action` | Command identifier and activation event |
| Separator | — | Passive divider rendered along the cross axis |
