Liquid Glass Data Table layers stable sorting, global filtering, pagination, and row selection onto semantic table topology. Sorting and pagination update actual cell content per row slot so document order always matches visual order.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Row slots and cells**: give every item in `rows` a unique `id`. Body rows use `DataTableRow` indexed within the active page, and cells read their field via `columnKey`.
- **Sortable headers**: place sortable column headers inside `DataTableHeaderRow`, which keeps passive table-row semantics without creating a competing selection or trigger owner so multiple sort triggers can live in one header row.
- Data Table focuses on local sorting, filtering, pagination, and row selection; data fetching, inline editing, and column reordering are managed by your application.

## API

| Part | Key Prop | Description |
| --- | --- | --- |
| DataTableRoot | `rows` | Array of data records with unique `id` values |
| DataTableHeaderRow | — | Passive header row container supporting multiple sort triggers |
| DataTableRow | `index` | Page-indexed body record slot |
| DataTableCell | `columnKey` | Field key rendered from the row slot's current record |
