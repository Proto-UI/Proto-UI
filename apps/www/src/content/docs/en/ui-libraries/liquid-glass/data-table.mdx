Liquid Glass Data Table separates dense tabular data from floating glass chrome: rows and cells stay on a clean, high-legibility content layer (never stacking glass-on-glass), while toolbar actions and capsule `Previous`/`Next` controls use the `liquid-glass` control layer with `regular` and `prominent` prominence and automatic opaque fallbacks for reduced-transparency or high-contrast preferences.

## Usage

```tsx
import {
  LiquidGlassDataTableCaption,
  LiquidGlassDataTableCell,
  LiquidGlassDataTableHeader,
  LiquidGlassDataTableHeaderRow,
  LiquidGlassDataTableNext,
  LiquidGlassDataTablePrevious,
  LiquidGlassDataTableRoot,
  LiquidGlassDataTableRow,
} from '../proto-ui/components/react';

const rows = [
  { id: 'm5gr84i9', status: 'Success', email: 'ken99@example.com', amount: 316 },
  { id: '3u1reuv4', status: 'Success', email: 'abe45@example.com', amount: 242 },
];

export function Example() {
  return (
    <LiquidGlassDataTableRoot rows={rows} pageSize={4}>
      <LiquidGlassDataTableCaption>Recent payments.</LiquidGlassDataTableCaption>
      <LiquidGlassDataTableHeaderRow>
        <LiquidGlassDataTableHeader headerKey="status">Status</LiquidGlassDataTableHeader>
        <LiquidGlassDataTableHeader headerKey="email">Email</LiquidGlassDataTableHeader>
        <LiquidGlassDataTableHeader headerKey="amount" className="text-right">
          Amount
        </LiquidGlassDataTableHeader>
      </LiquidGlassDataTableHeaderRow>
      {[0, 1].map((index) => (
        <LiquidGlassDataTableRow key={index} index={index}>
          <LiquidGlassDataTableCell columnKey="status" headers={['status']} />
          <LiquidGlassDataTableCell columnKey="email" headers={['email']} />
          <LiquidGlassDataTableCell
            columnKey="amount"
            headers={['amount']}
            className="text-right"
          />
        </LiquidGlassDataTableRow>
      ))}
      <div className="table-caption caption-bottom">
        <div className="flex justify-end gap-2 pt-3">
          <LiquidGlassDataTablePrevious>Previous</LiquidGlassDataTablePrevious>
          <LiquidGlassDataTableNext variant="prominent">Next</LiquidGlassDataTableNext>
        </div>
      </div>
    </LiquidGlassDataTableRoot>
  );
}
```

### Layering & Material Guidelines

- **Content vs. control separation**: `DataTableRoot` renders as a clean `rounded-2xl` elevated content sheet so dense text remains readable without glass-on-glass stacking; selected rows use a vibrant translucent tint (`bg-primary/15`).
- **Floating pagination commands**: `DataTablePrevious` and `DataTableNext` render as capsule pills (`rounded-full`) supporting `variant="regular" | "prominent"` and `material="auto" | "opaque"`. Disabled controls withdraw optical glass while keeping opaque text legible.

### Events, Methods & Exposed States

- **Events (Root)**: `sortChange`, `pageChange`, `selectionChange`.
- **Methods (Root)**: `getRows()`, `getRecord(id)`, `getSelectedKeys()`, `requestSort(key)`, `requestPage(next)`, `requestSelection(id)`, `requestPageSelection(selected?)`.
- **Exposed States**: Root exposes `filteredCount` and `pageSelection`; Row exposes `rowKey`, `selected`, `focused`, and `focusVisible`; Header exposes `sort`; Cell exposes `displayValue`.
