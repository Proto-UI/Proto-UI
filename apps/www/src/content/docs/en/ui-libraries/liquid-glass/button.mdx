Liquid Glass Button distinguishes floating controls from content using capsule geometry, edge contrast, and V2 optical material intent: `regular` for everyday actions, `prominent` for a single selective primary action, and `destructive` for irreversible actions, with interaction and accessibility owned by Base Button.

## Usage

```tsx
import { LiquidGlassButton } from '../proto-ui/components/react';

export function Example() {
  return (
    <div className="flex items-center gap-4">
      <LiquidGlassButton>Cancel</LiquidGlassButton>
      <LiquidGlassButton variant="prominent">Continue</LiquidGlassButton>
    </div>
  );
}
```

### Material hierarchy & accessibility (Apple Liquid Glass HIG)

Design choices follow Apple's [Materials](https://developer.apple.com/design/human-interface-guidelines/materials), [Color](https://developer.apple.com/design/human-interface-guidelines/color), and [Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons) guidance:

- **Prominence hierarchy**: Reserve `variant="prominent"` for one primary action per group and keep remaining controls `regular`. Never stack glass buttons directly on top of another glass surface.
- **Optical intent & opt-out**: `material="auto"` submits V2 liquid-glass optical intent with press deformation when the host supports a visible backdrop; `material="opaque"` explicitly opts into the high-contrast opaque surface.
- **Accessibility preferences**: Reduced motion disables transitions and elastic press deformation while keeping static material. Reduced transparency, increased contrast, and forced colors fall back to readable opaque surfaces. Disabled buttons preserve full label and border legibility without fading the whole host.
