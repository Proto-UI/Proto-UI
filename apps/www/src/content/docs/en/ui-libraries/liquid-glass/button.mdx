V2 Liquid Glass intent is connected to an opt-in self-optical Web provider. The Previewer supplies a visible, dynamic application-owned canvas as the exact sampled background. Arbitrary DOM and browser-compositor capture are not supported: intervening paint, cross-scope portals or unavailable source/preferences retain readable fallback. Reduced motion uses static optics. Exact-head browser evidence is required before admitting this draft provider; native, Apple-private, group/morph and full Compiler equivalence remain unverified.

## API

- variant: regular / prominent; material: auto / opaque
- disabled: boolean, default false
- Activation, focus, keyboard and disabled behavior are inherited from Base Button; the visual layer owns no second interaction state.

Button is registered now. Other Base parts are being added explicitly, never aliased to another family. General Compiler and full GPUI/Flutter/Qt realization remain unverified. The source package is private and unreleased.
