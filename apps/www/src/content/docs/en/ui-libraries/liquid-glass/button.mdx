Liquid Glass Button uses soft edge highlights and background refraction to distinguish controls from content. Use the regular style for secondary actions such as Back, and the prominent tint for the primary action. Both styles keep the same size.

## Material and accessibility

The default `regular` material suits everyday actions; reserve `variant="prominent"` for the primary action in a group, and avoid stacking glass buttons on top of glass containers. Design choices follow Apple's [Materials](https://developer.apple.com/design/human-interface-guidelines/materials), [Color](https://developer.apple.com/design/human-interface-guidelines/color), and [Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons) guidance.

- `material="auto"` enables optical refraction when the host supports it over a visible canvas backdrop; over ordinary DOM backgrounds, intervening content, or with `material="opaque"`, the button retains a readable opaque surface.
- Reduced motion disables elastic deformation while keeping static material. Reduced transparency, increased contrast, and forced colors use an accessible opaque fallback.
- Disabled buttons keep their label and outline without accepting activation.

## API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'regular' \| 'prominent'` | `'regular'` | Regular glass or prominent tinted style |
| `material` | `'auto' \| 'opaque'` | `'auto'` | Set to `'opaque'` to use an opaque surface instead of optics |
| `disabled` | `boolean` | `false` | Disables button activation |

Activation, focus, keyboard, and disabled behavior are managed by [Base Button](/en/ui-libraries/base/button/).
