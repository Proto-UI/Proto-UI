Liquid Glass Table provides a crisp, restrained **content-layer** presentation over [Base Table](/en/ui-libraries/base/table/). Following Apple's Liquid Glass material hierarchy, tables and data rows stay non-glass and opaque so tabular data remains highly legible while floating Liquid Glass controls—such as toolbars, buttons, and action menus—elevate cleanly above it without stacking glass on glass.

For sorting, filtering, pagination, and row selection, use [Data Table](/en/ui-libraries/liquid-glass/data-table/).

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the parts from `@proto.ui/prototypes-liquid-glass/table`:

```ts
import {
  liquidGlassTableRoot,
  liquidGlassTableCaption,
  liquidGlassTableRow,
  liquidGlassTableHeaderCell,
  liquidGlassTableCell,
} from '@proto.ui/prototypes-liquid-glass/table';
```

## Usage

```html
<div class="w-full overflow-x-auto">
  <liquid-glass-table-root>
    <liquid-glass-table-caption>A list of your recent invoices.</liquid-glass-table-caption>
    <liquid-glass-table-row section="header" last-in-section>
      <liquid-glass-table-header-cell
        header-key="invoice"
        header-kind="column"
        style="width: 100px"
      >
        Invoice
      </liquid-glass-table-header-cell>
      <liquid-glass-table-header-cell header-key="status" header-kind="column"
        >Status</liquid-glass-table-header-cell
      >
      <liquid-glass-table-header-cell header-key="method" header-kind="column"
        >Method</liquid-glass-table-header-cell
      >
      <liquid-glass-table-header-cell
        header-key="amount"
        header-kind="column"
        style="text-align: end"
      >
        Amount
      </liquid-glass-table-header-cell>
    </liquid-glass-table-row>
    <liquid-glass-table-row section="body" last-in-section>
      <liquid-glass-table-header-cell header-key="inv001" header-kind="row"
        >INV001</liquid-glass-table-header-cell
      >
      <liquid-glass-table-cell>Paid</liquid-glass-table-cell>
      <liquid-glass-table-cell>Credit Card</liquid-glass-table-cell>
      <liquid-glass-table-cell style="text-align: end">$250.00</liquid-glass-table-cell>
    </liquid-glass-table-row>
  </liquid-glass-table-root>
</div>
```

### Content Layer & Material Hierarchy

```text
Root (content layer, no glass material)
├── Caption (caption-bottom + mt-4)
├── Row (section="header")
│   └── HeaderCell (align-middle + text-start)
├── Row (section="body")
│   ├── HeaderCell (headerKind="row")
│   └── Cell (headers=[...])
└── Row (section="footer")
    ├── HeaderCell (headerKind="row")
    └── Cell (headers=[...])
```

- **No glass-on-glass**: Table parts intentionally omit translucent blur and optical material carriers so dense data stays sharp underneath floating Liquid Glass overlays.
- **Alignment & accessibility fallbacks**: Cells use `align-middle` so inline action triggers align cleanly; reduced-motion disables row hover transitions, and forced-colors mode promotes row dividers to `border-foreground`.
- **Logical direction**: `Caption` and `HeaderCell` align via `text-start` for automatic RTL mirroring.
