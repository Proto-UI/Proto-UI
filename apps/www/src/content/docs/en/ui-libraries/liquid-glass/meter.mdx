Liquid Glass Meter displays a scalar measurement within a known range (such as disk usage, quota balance, or battery level) and classifies readings as `optimal`, `suboptimal`, or `critical` using `low`, `high`, and `optimum` thresholds. Following Apple's Liquid Glass layering guidance, the track and indicator render as crisp nonmaterial content-layer gauges rather than floating glass slabs.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the meter parts from `@proto.ui/prototypes-liquid-glass/meter`:

```ts
import {
  meterRoot,
  meterLabel,
  meterTrack,
  meterIndicator,
  meterValue,
} from '@proto.ui/prototypes-liquid-glass/meter';
```

## Usage

```tsx
import { AdaptToReact } from '@proto.ui/adapter-react';
import {
  meterRoot,
  meterLabel,
  meterTrack,
  meterIndicator,
  meterValue,
} from '@proto.ui/prototypes-liquid-glass/meter';

const MeterRoot = AdaptToReact(meterRoot);
const MeterLabel = AdaptToReact(meterLabel);
const MeterTrack = AdaptToReact(meterTrack);
const MeterIndicator = AdaptToReact(meterIndicator);
const MeterValue = AdaptToReact(meterValue);

export function LiquidGlassStorageMeter() {
  return (
    <MeterRoot value={32} min={0} max={100} low={50} high={80} optimum={20} valueText="32%">
      <div className="flex items-center justify-between gap-2">
        <MeterLabel>Storage used</MeterLabel>
        <MeterValue />
      </div>
      <MeterTrack>
        <MeterIndicator />
      </MeterTrack>
    </MeterRoot>
  );
}
```

### Material layering and anatomy

- **Nonmaterial content-layer gauge**: Per Apple HIG Materials guidance, Liquid Glass belongs to the floating functional control and navigation layer above content. Meter's `Track` and `Indicator` remain nonmaterial content-layer elements with concentric capsule rounding (`rounded-full`), crisp borders, and high-contrast semantic fills—keeping readouts legible and preventing glass-on-glass stacking beside floating Liquid Glass controls.
- **Bounds and parts**: `Root` clamps values to `[min, max]` (equal bounds yield `0%`); `Label` names the meter; `Value` formats `valueText` or the normalized number with `tabular-nums`; `Indicator` distinguishes `optimal`, `suboptimal`, and `critical` zones.
- Meter is a passive readout (`role="meter"`) with no keyboard tab stop; every part exposes synchronized state as props update.
