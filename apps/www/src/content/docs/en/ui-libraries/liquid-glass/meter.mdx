Liquid Glass Meter displays a scalar measurement within a known range (such as disk usage or quota) and classifies readings as `optimal`, `suboptimal`, or `critical` using `low`, `high`, and `optimum` thresholds.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import `meterRoot`, `meterLabel`, `meterTrack`, `meterIndicator`, and `meterValue` from the `meter` subpath.

## Usage

- **Parts**: `Root` manages bounds, `Label` names the meter, `Track` holds `Indicator`, and `Value` renders `valueText` or the canonical number.
- **Clamping and thresholds**: values clamp to `[min, max]` (equal bounds yield `0%`). `low`, `high`, and `optimum` classify `status` without modifying the numeric value.
- Meter is a passive readout with no Tab stop or editing events; updating props keeps every part synchronized.

## API

| Part | Prop / Exposed State | Defaults and notes |
| --- | --- | --- |
| Root | `value` | Measured value, clamped to `[min, max]` |
| Root | `min`, `max` | `0`, `100` |
| Root | `low`, `high`, `optimum` | Range thresholds classifying `status` as `optimal`, `suboptimal`, or `critical` |
| Root | `ariaLabel`, `valueText` | Accessible label and formatted display text |
| Root / Parts (exposed) | `value`, `percentage`, `indeterminate`, `status` | Clamped value, percentage, and derived classification |
