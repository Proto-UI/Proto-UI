Liquid Glass Tree manages an explicitly keyed hierarchy with single selection, expandable branches, and full keyboard and RTL navigation. Following Apple Liquid Glass HIG, tree content remains on a neutral legible surface rather than stacking glass-on-glass inside list rows, paired with concentric corner radii (`rounded-2xl` outer container, `p-2` inset, `rounded-lg` rows) and readable disabled contrast.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototypes from `@proto.ui/prototypes-liquid-glass/tree` and adapt them for your target runtime:

```ts
import { treeRoot, treeItem, treeGroup, treeToggle } from '@proto.ui/prototypes-liquid-glass/tree';
```

## Usage

```tsx
<LiquidGlassTreeRoot defaultValue="button" defaultExpandedKeys={['src', 'components']}>
  <div className="flex items-center gap-1.5">
    <LiquidGlassTreeToggle nodeKey="src" size="icon">
      ▾
    </LiquidGlassTreeToggle>
    <LiquidGlassTreeItem nodeKey="src" textValue="src" className="flex-1">
      src/
    </LiquidGlassTreeItem>
  </div>
  <LiquidGlassTreeGroup nodeKey="src">
    <LiquidGlassTreeItem nodeKey="button" parentKey="src" textValue="button.tsx">
      button.tsx
    </LiquidGlassTreeItem>
  </LiquidGlassTreeGroup>
</LiquidGlassTreeRoot>
```

### Layering & Interaction Semantics

- **Neutral content layer & concentric radii**: Because Tree presents scrollable/hierarchical content rather than floating chrome, it intentionally stays material-neutral (no glass-on-glass) while aligning outer container corners (`rounded-2xl` with `p-2`) concentrically with inner item rows (`rounded-lg`) and capsule disclosure toggles (`rounded-full`).
- **Accessibility & contrast**: Focus uses an inset ring with `forced-colors` outline fallback; disabled rows switch to semantic muted ink rather than washing out opacity so contrast stays legible under opaque and high-contrast preferences.
- **Keyboard & RTL**: Up/Down, `Home`/`End`, and first-letter typeahead move focus in visual order; `direction="rtl"` mirrors group indent guides and swaps Left/Right arrow keys.
