## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Explicit hierarchy**: identify each node with a unique `nodeKey` and reference its parent via `parentKey`; duplicate keys, missing parents, and cycles are ignored safely.
- **Keyboard navigation**: Up/Down, `Home`/`End`, and first-letter typing move focus across visible nodes; Left/Right collapse or move to the parent, and expand or move to the first child.
- **Controlled state**: `value` (selected node) and `expandedKeys` (expanded node keys) both support controlled request mode.

## API

| Prop           | Description                                  |
| -------------- | -------------------------------------------- |
| `value`        | Controlled `nodeKey` of the selected node    |
| `expandedKeys` | Controlled list of expanded node keys        |
| `nodeKey`      | Unique identifier for a node within the tree |
| `parentKey`    | `nodeKey` of the parent node                 |
