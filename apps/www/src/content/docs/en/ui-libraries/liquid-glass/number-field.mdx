## Usage

- **Parts**: `Root`, `Label`, `Input`, `Control`, `Increment`, `Decrement`.
- **Editing and stepping**: incomplete drafts are tolerated while typing; blur or Enter commits a valid number or restores the last accepted value. Buttons and Up/Down arrows step by `step` (`Shift` multiplies by 10; `Home`/`End` jump to `min`/`max`). Controlled mode proposes updates without overwriting caller state.
- **Formatting and IME**: `locale` and `formatOptions` support decimal, currency, and percent display and localized parsing without altering underlying precision. Invalid options set `formatInvalid` and fall back to ungrouped decimals. IME composition pauses parsing, commits, stepping, and scrubbing.
- **Empty values**: set `allowEmpty={true}` to allow clearing the input and committing `null`. Read real `number | null` values via `getValue()` alongside `empty`; stepping from `null` initializes snapped `0` within bounds.
- **Label scrubbing**: enable `scrub` to drag across `Label` to adjust the value (`scrubSteps` defaults to `100`; `direction="rtl"` mirrors horizontal dragging). Releasing after a change commits once, and cancelling restores the starting value.
- **Field and Form integration**: use `Control` instead of `Input` inside [Field](/en/ui-libraries/liquid-glass/field/) or [Form](/en/ui-libraries/liquid-glass/form/) to connect `FieldLabel`, validation, serialization, and reset.

## API

| Part | Prop / Method / State | Defaults and notes |
| --- | --- | --- |
| Root | `value`, `defaultValue` | `number \| null`; `value={null}` stays controlled |
| Root | `min`, `max`, `step` | `0`, `100`, `1` (positive step) |
| Root | `allowEmpty` | `false`; enables clearing to `null` |
| Root | `locale`, `formatOptions` | Localized decimal, currency, or percent formatting |
| Root | `scrub`, `scrubSteps`, `direction` | Label drag scrubbing (`scrubSteps` default `100`) |
| Root | `disabled`, `readOnly`, `name`, `ariaLabel` | Interaction state, field name, and accessible label |
| Root / Input / Control | `getValue()`, `empty`, `formatInvalid` | Returns `number \| null`, empty flag, and formatting validity |
