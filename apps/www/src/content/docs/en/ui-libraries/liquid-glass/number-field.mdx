Liquid Glass Number Field provides a `spinbutton` numeric editor with increment/decrement buttons, keyboard stepping, `locale` / `formatOptions` formatting and parsing, optional `null` emptiness, and label scrubbing.

Following Apple Liquid Glass hierarchy guidance, content-layer numeric editors and their inline steppers stay legible opaque surfaces rather than stacking glass-on-glass, paired with `44×44` minimum stepper hit targets, tactile hover/press feedback, high-contrast muted disabled fills (without fading opacity), and Forced Colors focus outlines.

## Installation

Available starting in `0.3.0-rc.1` and later releases. Import the parts directly from `@proto.ui/prototypes-liquid-glass/number-field`:

```ts
import {
  numberFieldRoot,
  numberFieldLabel,
  numberFieldInput,
  numberFieldControl,
  numberFieldIncrement,
  numberFieldDecrement,
} from '@proto.ui/prototypes-liquid-glass/number-field';
```

## Usage

```tsx
<LiquidGlassNumberFieldRoot defaultValue={12} min={0} max={100} step={1} ariaLabel="Quantity">
  <LiquidGlassNumberFieldLabel>Quantity</LiquidGlassNumberFieldLabel>
  <LiquidGlassNumberFieldDecrement>
    <span aria-hidden="true">−</span>
    <span className="sr-only">Decrease Quantity</span>
  </LiquidGlassNumberFieldDecrement>
  <LiquidGlassNumberFieldInput />
  <LiquidGlassNumberFieldIncrement>
    <span aria-hidden="true">+</span>
    <span className="sr-only">Increase Quantity</span>
  </LiquidGlassNumberFieldIncrement>
</LiquidGlassNumberFieldRoot>
```

- **Surface hierarchy and accessibility**: Content-layer editing remains an opaque high-contrast surface; disabled controls switch to a legible muted fill instead of opacity dimming, and keyboard focus emits an offset ring plus a Forced Colors outline fallback.
- **Editing and stepping**: Incomplete drafts stay intact while typing; blur or `Enter` commits a valid number or restores the last accepted value. Buttons and Up/Down arrows step by `step` (`Shift` multiplies by 10; `Home` / `End` jump to `min` / `max`). IME composition pauses parsing, commits, stepping, and scrubbing.
- **Field and Form integration**: Use `Control` instead of `Input` inside [Field](/en/ui-libraries/liquid-glass/field/) or [Form](/en/ui-libraries/liquid-glass/form/) to connect `FieldLabel`, invalid error rings, serialization, and reset.
