Liquid Glass Async Region inherits `aria-busy` and focus-preservation semantics from [Base Async Region](/en/ui-libraries/base/async-region/) as a restrained content-layer container designed to sit cleanly beneath floating Liquid Glass controls.

## Installation

Currently available from workspace source; not yet included in the `0.2.0` stable release or CLI registry. Import directly from the workspace subpath:

```ts
import { asyncRegionRoot } from '@proto.ui/prototypes-liquid-glass/async-region';
```

## Usage

```tsx
import { useState } from 'react';
import { AdaptToReact } from '@proto.ui/adapter-react';
import { asyncRegionRoot } from '@proto.ui/prototypes-liquid-glass/async-region';

const LiquidGlassAsyncRegionRoot = AdaptToReact(asyncRegionRoot);

export function FeedContent() {
  const [busy, setBusy] = useState(false);

  return (
    <LiquidGlassAsyncRegionRoot busy={busy}>
      <p>Content-layer descendants and focus stay intact during refresh.</p>
    </LiquidGlassAsyncRegionRoot>
  );
}
```

### Material Layering & Accessibility

Layering follows Apple [Materials](https://developer.apple.com/design/human-interface-guidelines/materials) guidance:

- **Content stays off the glass layer**: Translucent Liquid Glass belongs strictly to floating navigation and controls layers above content—never to underlying content containers and never stacked glass-on-glass. Accordingly, `liquid-glass-async-region-root` applies only `block min-w-0 max-w-full text-foreground` with no optical material carrier or `backdrop-*` tokens.
- **Control hierarchy & concentric geometry**: Keep Async Region on an opaque, readable content surface with concentric radii (`rounded-2xl` outer card pairing with `rounded-xl` nested panels) and trigger updates using floating `variant="prominent"` (primary) and `variant="regular"` (secondary) Liquid Glass buttons.
- **Vibrancy & accessibility fallbacks**: Neutral family foreground tokens remain legible across light mode, dark mode, reduced transparency, increased contrast, and reduced motion preferences without introducing motion chrome.
