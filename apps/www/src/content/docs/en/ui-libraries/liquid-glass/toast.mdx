## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Parts**: `Root`, `Viewport`, `Title`, `Description`, `Action`, `Close`.
- **Timing and pause**: `Root` stays open for `5000ms` by default; pass `duration={0}` to disable auto-dismiss. Hovering the toast or focusing `Action` / `Close` pauses the remaining timer. In controlled mode, timeout emits one close request until you update `open`.
- **Dismissal and shortcuts**: `Close`, focused Escape, and `Action` request dismissal while leaving action side effects to your application. `Viewport` provides the `F8` focus shortcut. Multi-toast queueing is left to your application.

## API

| Part | Prop | Defaults and notes |
| --- | --- | --- |
| Root | `open`, `duration` | Controlled open state / auto-dismiss duration in ms (default `5000`; `0` stays open) |
| Viewport | — | Notification container with `F8` focus shortcut |
| Title / Description | — | Notification heading and message body |
| Action / Close | — | Action button and dismiss button |
