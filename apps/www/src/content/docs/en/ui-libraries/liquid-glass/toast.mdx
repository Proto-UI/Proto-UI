Liquid Glass Toast pairs a single floating `liquid-glass` banner surface and inset specular rim with concentric capsule controls—never stacking glass-on-glass—while providing opaque fallbacks, auto-dismiss pause on hover or focus, and the `F8` viewport shortcut.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototypes directly from `@proto.ui/prototypes-liquid-glass/toast` and adapt them for your target runtime.

```ts
import {
  toastViewport,
  toastRoot,
  toastTitle,
  toastDescription,
  toastAction,
  toastClose,
} from '@proto.ui/prototypes-liquid-glass/toast';
```

## Usage

```tsx
<LiquidGlassToastViewport a11yLabel="Notifications">
  <LiquidGlassToastRoot defaultOpen={false} duration={5000}>
    <LiquidGlassToastTitle>Event has been created</LiquidGlassToastTitle>
    <LiquidGlassToastDescription>Sunday, December 03, 2023 at 9:00 AM</LiquidGlassToastDescription>
    <LiquidGlassToastAction a11yLabel="Undo event creation">Undo</LiquidGlassToastAction>
    <LiquidGlassToastClose>Dismiss</LiquidGlassToastClose>
  </LiquidGlassToastRoot>
</LiquidGlassToastViewport>
```

- **Parts**: `Root`, `Viewport`, `Title`, `Description`, `Action`, `Close`. Only `Root` declares the `liquid-glass` material candidate; inner capsule buttons use distinct opaque fills so glass is never stacked on glass.
- **Opaque opt-out**: Set `material="opaque"` to withdraw the glass candidate while preserving high-contrast separation between the toast banner and its inner controls.
- **Timing and pause**: `Root` stays open for `5000ms` by default; pass `duration={0}` to disable auto-dismiss. Hovering the toast or focusing `Action` / `Close` pauses the remaining timer. In controlled mode, timeout emits one close request until you update `open`.
- **Dismissal and shortcuts**: `Close`, focused `Escape`, and `Action` request dismissal while leaving action side effects to your application. `Viewport` provides the `F8` focus shortcut. Multi-toast queueing stays in your application.

Events and exposed methods:

- **Events**: `Root` emits `openChange` (`{ open: boolean; reason: string }`); `Action` emits `action` (`void`).
- **Methods**: `Root` exposes `openToast()`, `close(reason?)`, `pause()`, and `resume()`; `Viewport` exposes `focusFirst()`.
