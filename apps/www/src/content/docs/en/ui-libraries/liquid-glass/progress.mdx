## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import `progressRoot`, `progressLabel`, `progressTrack`, `progressIndicator`, and `progressValue` from the `progress` subpath.

## Usage

- **Parts**: `Root` manages bounds, `Label` names the bar, `Track` contains `Indicator`, and `Value` displays `valueText` or the canonical number.
- **Determinate and indeterminate**: values clamp to `[min, max]` (equal bounds yield `0%`). Omitting `value` or passing `indeterminate={true}` represents unknown progress and omits the current accessible value.
- Progress is a passive readout with no Tab stop; updating props synchronizes every part.

## API

| Part | Prop / Exposed State | Defaults and notes |
| --- | --- | --- |
| Root | `value` | Current completion value; omit for indeterminate mode |
| Root | `min`, `max` | `0`, `100` |
| Root | `indeterminate` | `false`; marks progress as unknown |
| Root | `ariaLabel`, `valueText` | Accessible label and human-readable value text |
| Root / Parts (exposed) | `value`, `percentage`, `indeterminate`, `status` | Clamped value, percentage, and derived status |
