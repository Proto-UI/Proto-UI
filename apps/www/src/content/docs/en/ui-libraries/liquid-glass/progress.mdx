Liquid Glass Progress visualizes task completion across a finite range or in an indeterminate state. Following layered content-vs-chrome guidance, it uses a translucent concentric capsule track with a subtle inset rim and high-contrast fill rather than stacking glass-on-glass inside content.

## Installation

Available starting in `0.3.0-rc.1` and later releases. Import the parts from `@proto.ui/prototypes-liquid-glass/progress`:

```ts
import {
  progressRoot,
  progressLabel,
  progressTrack,
  progressIndicator,
  progressValue,
} from '@proto.ui/prototypes-liquid-glass/progress';
```

## Usage

Compose `Root`, `Label`, `Track`, `Indicator`, and `Value`. Place `Label` and `Value` before `Track` for an inline header row above the capsule track:

```tsx
<LiquidGlassProgressRoot
  prominence="prominent"
  value={74}
  valueText="74%"
  className="w-full max-w-sm"
>
  <LiquidGlassProgressLabel>Downloading system update</LiquidGlassProgressLabel>
  <LiquidGlassProgressValue />
  <LiquidGlassProgressTrack>
    <LiquidGlassProgressIndicator />
  </LiquidGlassProgressTrack>
</LiquidGlassProgressRoot>
```

```text
ProgressRoot
├── ProgressLabel
├── ProgressValue
└── ProgressTrack
    └── ProgressIndicator
```

- **Layered prominence and concentric geometry**: Use `prominence` (`regular`, `prominent`, `destructive`) to distinguish standard, featured, and quota-warning progress bars. Track and indicator share concentric `rounded-full` capsule geometry with adaptive translucent tracks and inset hairlines that remain legible over light, dark, and colorful backdrops without stacking nested glass materials.
- **Motion and accessibility**: Width updates use shared resident motion (`300ms`) that automatically respects reduced-motion preferences. Values clamp to `[min, max]`; omitting `value` or setting `indeterminate={true}` omits `aria-valuenow`. Progress is a passive readout with no Tab stop.

### Sub-parts and exposed states

- `ProgressTrack` and `ProgressIndicator` accept an optional `prominence` override (`'regular' | 'prominent' | 'destructive' | 'inherit'`, default `'inherit'`).
- All parts expose synchronized read-only states: `value`, `percentage`, `indeterminate`, and `status`.
