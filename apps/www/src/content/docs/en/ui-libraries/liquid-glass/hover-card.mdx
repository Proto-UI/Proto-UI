Liquid Glass Hover Card pairs a quiet non-glass link trigger with a layered translucent floating preview panel, offering regular and prominent surface hierarchy, concentric corner radii, and automatic opaque fallbacks for accessibility preferences.

## Installation

Liquid Glass Hover Card is currently available from workspace source in Proto UI and is not yet distributed via the CLI. Import or adapt the workspace prototype directly for your target framework.

## Usage

```tsx
import {
  LiquidGlassHoverCardRoot,
  LiquidGlassHoverCardTrigger,
  LiquidGlassHoverCardContent,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <LiquidGlassHoverCardRoot openDelay={150} closeDelay={200}>
      <LiquidGlassHoverCardTrigger>@proto-ui</LiquidGlassHoverCardTrigger>
      <LiquidGlassHoverCardContent variant="regular" material="auto" side="bottom" align="center">
        Host-neutral interaction protocols layered over translucent Liquid Glass surfaces.
      </LiquidGlassHoverCardContent>
    </LiquidGlassHoverCardRoot>
  );
}
```

### Composition and material guidance

```text
LiquidGlassHoverCardRoot
├── LiquidGlassHoverCardTrigger
└── LiquidGlassHoverCardContent
```

- **No glass-on-glass stacking**: `Trigger` stays a lightweight non-glass link affordance while only the open `Content` surface requests Liquid Glass material.
- **Concentric geometry & hierarchy**: `Content` pairs an outer `rounded-2xl` radius and `p-4` padding with `rounded-xl` nested detail blocks. Use `variant="prominent"` selectively for primary callout previews, or pass `material="opaque"` to opt out of optical glass.
- **Accessibility fallbacks**: Reduced transparency, forced colors, and reduced motion automatically resolve to crisp opaque surfaces and static presentation; disabled triggers preserve text contrast instead of fading opacity.
