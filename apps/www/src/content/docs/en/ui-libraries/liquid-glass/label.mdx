Liquid Glass `Label` inherits the Base Label protocol as content-layer typography paired with translucent Liquid Glass controls, separating accessible naming (`naming`) from click activation (`activation`) with `primary` and `secondary` ink hierarchy.

> For form fields, use the [Field](../field/) component for automatic `FieldLabel`, `FieldDescription`, and `FieldError` associations and validation.

## Installation

Currently available from workspace source. Import directly from the workspace package:

```ts
import { labelRoot } from '@proto.ui/prototypes-liquid-glass/label';
```

## Usage

Create one stable reference per pair with `createControlLabelRef()` from `@proto.ui/core` and pass it through the adapter association channel:

```tsx
import { useMemo } from 'react';
import { createControlLabelRef } from '@proto.ui/core';
import {
  LiquidGlassCheckboxIndicator,
  LiquidGlassCheckboxRoot,
  LiquidGlassLabelRoot,
} from '../proto-ui/components/react';

export function TermsCheckbox() {
  const termsRef = useMemo(() => createControlLabelRef(), []);

  return (
    <div className="flex items-center gap-2">
      <LiquidGlassCheckboxRoot instanceAssociations={{ controlLabel: termsRef }}>
        <LiquidGlassCheckboxIndicator />
      </LiquidGlassCheckboxRoot>
      <LiquidGlassLabelRoot instanceAssociations={{ controlLabel: termsRef }}>
        Accept terms and conditions
      </LiquidGlassLabelRoot>
    </div>
  );
}
```

In Web Components, bind both elements with `setElementAssociations()` from `@proto.ui/adapter-web-component`:

```ts
import { createControlLabelRef } from '@proto.ui/core';
import { setElementAssociations } from '@proto.ui/adapter-web-component';

const termsRef = createControlLabelRef();
setElementAssociations(checkboxEl, { controlLabel: termsRef });
setElementAssociations(labelEl, { controlLabel: termsRef });
```

### Content-layer material and accessibility

- **Never stack glass on glass**: Following Apple Liquid Glass HIG, plain control labels live in the content layer and never render a Liquid Glass plate next to translucent controls.
- **Foreground hierarchy (`tone`)**: Defaults to `tone="primary"` (`text-foreground`) with `tone="secondary"` (`text-muted-foreground`) for quieter labels, maintaining legible opaque ink under Reduce Transparency, Increase Contrast, and Forced Colors.
- **Independent naming, activation, and selection**: Configure `naming` (default `true`), `activation` (default `true`), and `selection` (default `'policy'`) independently. `Label` adds no extra `Tab` stop and ignores nested links/buttons, modified clicks, and drags.

### Association helpers

- `createControlLabelRef()`: Imported from `@proto.ui/core` to create a stable one-to-one opaque reference.
- `instanceAssociations`: Adapter prop accepting `{ controlLabel: ref }` in React, Vue, and Vue 2.
- `setElementAssociations(element, { controlLabel: ref })`: Imported from `@proto.ui/adapter-web-component` for Web Components.
