Liquid Glass Label inherits the Base Label protocol, separating accessible naming and click-to-activate into two independent controls linked through an explicit reference rather than DOM IDs.

## Usage

### Independent naming and activation

- **`naming`** (default `true`): links the target control to the rendered Label through an accessibility relationship without duplicating hidden text. If the target already declares a non-empty `ariaLabel` or `labelledBy`, that explicit name keeps ownership and a conflict is diagnosed; set `naming={false}` when you only want activation.
- **`activation`** (default `true`): once paired, an eligible click or trusted non-pointer activation invokes the target's existing operation (Checkbox and Switch keep their controlled/disabled rules; Radio Group Item delegates to its Group; Input and Textarea request focus without altering text or selection). Set `activation={false}` for a passive naming-only label. Unpaired labels never search for nearby controls.
- Label adds no button role or Tab stop, leaving keyboard interaction on the control. Nested links/buttons, modified clicks, drags, and cancelled click events are never forwarded.
- Naming-only labels and long descriptions remain copyable. With `selection="policy"`, actionable labels avoid accidental text selection; set `selection="text"` when an actionable label should also be copyable.

### Pairing with an explicit reference

Create one stable reference per label/control pair with `createControlLabelRef()` from `@proto.ui/core`:

- **React / Vue / Vue 2**: pass `instanceAssociations: { controlLabel: ref }` to both components. The adapter strips this field before resolving ordinary component Props.
- **Web Components**: call `setElementAssociations(el, { controlLabel: ref })` from `@proto.ui/adapter-web-component` on both the target and the Label.

Each reference supports one live Label and one live target within the same Document and tree root on Web; missing, duplicate, or stale endpoints are ignored rather than guessing by DOM order.

Supported targets: Checkbox, Switch, Radio Group Item, Input, Textarea, Button, Toggle, and Toggle Group Item (including icon-only commands).

## API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `naming` | `boolean` | `true` | Provides the accessible name for the paired target |
| `activation` | `boolean` | `true` | Forwards eligible clicks to the paired target's default action |
| `selection` | `'policy' \| 'text'` | `'policy'` | Text-selection behavior; set `'text'` to keep actionable labels copyable |
