Liquid Glass Combobox combines an editable search field with a popup listbox. Unlike Autocomplete, `Root.value` always represents a committed option key while `inputValue` tracks editable text—unmatched input is never silently accepted as a selection.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Parts**: `Root`, `Input`, `Content`, `Item`, `Empty`, `Trigger`.
- **Independent state**: `open`, `value` (selected key), and `inputValue` (search query) can each be controlled independently with their respective change requests.
- **Filtering and keyboard**: built-in filtering matches `textValue` and `keywords` case- and diacritic-insensitively; set `filter={false}` to render caller-filtered items. Focus stays in `Input` during arrow navigation, IME composition never selects, `Empty` tracks actual matches, and disabled or duplicate-valued items cannot commit.

## API

| Part | Prop | Description |
| --- | --- | --- |
| Root | `value`, `inputValue`, `open` | Independently controllable option key, search text, and popup visibility |
| Root | `filter` | Set to `false` to provide pre-filtered items |
| Item | `textValue`, `keywords`, `disabled` | Option label, search keywords, and disabled flag |
| Empty | — | Rendered when no items match the current query |
