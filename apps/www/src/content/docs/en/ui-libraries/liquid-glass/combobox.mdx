Liquid Glass Combobox pairs a legible content-layer search field with a floating translucent suggestion popup using concentric radii (`rounded-2xl` outer surface with `p-1` and `rounded-xl` items), while keeping the committed option key (`value`) separate from `inputValue`.

## Installation

Combobox is currently available from workspace source (`@proto.ui/prototypes-liquid-glass/combobox`) and is not yet included in the `0.2.0` stable CLI registry.

## Usage

```tsx
import {
  comboboxRoot,
  comboboxInput,
  comboboxTrigger,
  comboboxContent,
  comboboxItem,
  comboboxEmpty,
} from '@proto.ui/prototypes-liquid-glass/combobox';
```

```html
<liquid-glass-combobox-root a11y-label="Framework">
  <liquid-glass-combobox-input placeholder="Select a framework..."></liquid-glass-combobox-input>
  <liquid-glass-combobox-trigger>▾</liquid-glass-combobox-trigger>
  <liquid-glass-combobox-content>
    <liquid-glass-combobox-item value="next.js" text-value="Next.js"
      >Next.js</liquid-glass-combobox-item
    >
    <liquid-glass-combobox-item value="sveltekit" text-value="SvelteKit"
      >SvelteKit</liquid-glass-combobox-item
    >
    <liquid-glass-combobox-item value="astro" text-value="Astro">Astro</liquid-glass-combobox-item>
    <liquid-glass-combobox-empty>No frameworks found.</liquid-glass-combobox-empty>
  </liquid-glass-combobox-content>
</liquid-glass-combobox-root>
```

- **Single glass layer**: Only the open `Content` surface requests `liquid-glass` material; `Input`, `Trigger`, and `Item` remain solid content-layer surfaces so glass is never stacked on glass.
- **Fallback and opt-out**: Automatically falls back to a high-contrast opaque surface when glass material is unavailable or when `material="opaque"` is set. Disabled states use muted opaque colors rather than reducing opacity.
- **Independent state and filtering**: `open`, `value`, and `inputValue` can each be controlled independently; built-in filtering matches `textValue` and `keywords` case- and diacritic-insensitively.
