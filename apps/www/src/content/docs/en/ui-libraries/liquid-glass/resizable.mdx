Liquid Glass Resizable splits a container into two or more percentage-sized panels separated by indexed drag handles. Each handle resizes only its adjacent pair through pointer drag, arrow keys, Home/End, Shift acceleration, and optional collapsing.

The preview nests a two-panel vertical group inside a three-panel horizontal layout. Each panel exposes its dimensionless size via `--pui-size` for static `flex-basis` styling.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Panels and handles**: provide `N` `Panel` parts (`index: 0..N-1`) and `N - 1` `Handle` parts (`index: 0..N-2`). Each handle keeps the pair total and all other panels unchanged, with default accessible name `Resize panels`.
- **Constraints and collapsing**: pass per-panel `constraints` (`min: 0`, `max: 100`, `collapsible: false`, `collapsedSize: 0`). Ratios normalize to `100`, and infeasible layouts retain the previous valid state. Collapsing acts as a discrete stop and respects the neighbor's `max`.
- **Controlled mode and nesting**: pass `sizes` for controlled mode and handle `sizesChange` / `sizesCommit` with payload `{ sizes }` (cancelled drags emit no commit). The legacy two-panel `value` / `defaultValue` props remain supported when `sizes` is omitted. Nested Roots maintain independent layouts and constraints, and dragging normalizes against panel border-box extent without counting fixed handle widths.

## API

| Part | Prop / Method / Event | Defaults and notes |
| --- | --- | --- |
| Root | `sizes`, `defaultSizes` | Controlled / uncontrolled percentage array totaling `100` (takes precedence over `value` / `defaultValue`) |
| Root | `constraints` | Per-panel `{ min, max, collapsible, collapsedSize }` (defaults `0`, `100`, `false`, `0`) |
| Root | `requestResize(index, nextSize, commit)`, `requestSizes(nextSizes, commit)` | Programmatically propose panel resize updates |
| Root | `sizesChange`, `sizesCommit` | Emitted during resize and on commit with `{ sizes }` |
| Panel | `index` | Panel index (`0..N-1`); exposes dimensionless `size` (`--pui-size`) |
| Handle | `index` | Separator index (`0..N-2`) referencing its preceding panel |
