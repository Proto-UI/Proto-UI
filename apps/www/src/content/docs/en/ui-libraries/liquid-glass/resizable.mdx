A Liquid Glass resizable panel group that keeps content panes neutral without stacking nested chrome: the outer frame uses a concentric `rounded-2xl` translucent surface (with `variant="nested"` for inner groups), handles support `regular` and `prominent` capsule grabbers, and reduced-transparency, forced-colors, or `material="opaque"` settings cleanly fall back to solid contrast-preserving fills.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototypes directly from `@proto.ui/prototypes-liquid-glass/resizable` and adapt them for your target runtime:

```ts
import {
  resizableRoot,
  resizablePanel,
  resizableHandle,
} from '@proto.ui/prototypes-liquid-glass/resizable';
```

## Usage

```tsx
import {
  LiquidGlassResizableRoot,
  LiquidGlassResizablePanel,
  LiquidGlassResizableHandle,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <div className="w-full max-w-lg rounded-2xl bg-gradient-to-br from-sky-500/20 via-indigo-500/15 to-fuchsia-500/20 p-6">
      <LiquidGlassResizableRoot defaultSizes={[50, 50]} className="h-56 w-full">
        <LiquidGlassResizablePanel index={0}>One</LiquidGlassResizablePanel>
        <LiquidGlassResizableHandle index={0} withHandle />
        <LiquidGlassResizablePanel index={1}>Two</LiquidGlassResizablePanel>
      </LiquidGlassResizableRoot>
    </div>
  );
}
```

### Composition

```text
LiquidGlassResizableRoot (variant="default" | "nested", material="auto" | "opaque")
├── LiquidGlassResizablePanel (index: 0)
├── LiquidGlassResizableHandle (index: 0, withHandle?, prominence?, material?)
└── LiquidGlassResizablePanel (index: 1)
```

- **Hierarchy & concentric geometry**: content panels stay neutral while the outer `Root` supplies a `rounded-2xl` shell. Pass `variant="nested"` on inner split groups to prevent stacked frames; enable `withHandle` on `Handle` to display a centered `rounded-full` capsule grabber.
- **Accessible fallbacks**: `material="auto"` enables translucent layering only when reduced-transparency and forced-colors preferences are inactive; passing `material="opaque"` forces solid fills. Disabled handles preserve opaque legibility without dimming the surface with `opacity`.
- **Multi-panel, constraints & keyboard**: supports `sizes` / `defaultSizes`, per-panel `constraints`, pointer drag, arrow keys, `Shift` acceleration, `Home` / `End`, and `Enter` collapsing, with `Resize panels` as the default handle label.

- **Exposed states**: Root exposes `value` and `sizes`; Panel exposes `size`; Handle exposes `value`, `focusVisible`, and `disabled`.
- **Events & methods**: Root emits `sizesChange`, `sizesCommit`, `valueChange`, and `valueCommit`, and exposes `requestResize(index, next, commit?)`, `requestSizes(next, commit?)`, `requestValue(next, commit?)`, and `cancelResize()`.
