Liquid Glass Collapsible composes Root, Trigger, and Content on top of [Base Collapsible](/en/ui-libraries/base/collapsible/), with Root managing expansion state and Trigger applying Liquid Glass material styling.


## Usage

- **Composition**: place one `Trigger` and one `Content` inside each `Root`; nested and sibling disclosures maintain independent state.
- **Controlled and disabled**: in controlled mode, requests emit `openChange` without mutating state until you pass the new `open` prop. `disabled` blocks new toggles while keeping already-open content visible.
- **Mounting and layout**: Content unmounts when closed by default (set `keepMounted={true}` to keep a hidden node mounted). Layouts shrink cleanly, wrap long labels and words, and avoid fixed content heights; leave room outside the control for the focus ring.
- **Material**: only `Trigger` declares `liquid-glass` optical intent with press deformation; `Root` and `Content` remain opaque and readable, and hosts without optical support use the declared opaque fallback. See [Apple's Materials guidance](https://developer.apple.com/design/human-interface-guidelines/materials).

## API

| Part | Prop | Defaults and notes |
| --- | --- | --- |
| Root | `open`, `defaultOpen` | Controlled open state / initial uncontrolled state |
| Root | `disabled` | `false`; suppresses toggle requests without closing open content |
| Trigger | `disabled` | `false`; locally disables the button; supports natural Tab order and Enter / Space |
| Content | `keepMounted` | `false`; keeps the hidden node mounted when closed |

### Events and methods

- Root exposes: `open` state, `openCollapsible()`, `close()`, `toggle()`, and `openChange` with payload `{ open, reason }`.
- Trigger exposes: expanded, effective disabled, hover, press, focus states, and `focusSelf()`.
- Content exposes: derived `open` and `hidden` states.
