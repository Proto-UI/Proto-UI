Liquid Glass Collapsible composes `Root`, `Trigger`, and `Content` on top of [Base Collapsible](/en/ui-libraries/base/collapsible/). Only the interactive `Trigger` declares Liquid Glass optical intent, while `Root` and reading `Content` remain opaque so glass is never stacked on glass.

## Installation

Currently available from workspace source. Import the parts directly from `@proto.ui/prototypes-liquid-glass/collapsible`:

```ts
import {
  collapsibleRoot,
  collapsibleTrigger,
  collapsibleContent,
} from '@proto.ui/prototypes-liquid-glass/collapsible';
```

## Usage

```tsx
import {
  LiquidGlassCollapsibleRoot,
  LiquidGlassCollapsibleTrigger,
  LiquidGlassCollapsibleContent,
} from '@/components/ui/collapsible';

export function Example() {
  return (
    <LiquidGlassCollapsibleRoot>
      <LiquidGlassCollapsibleTrigger variant="regular">
        Order #4189 — Product details
      </LiquidGlassCollapsibleTrigger>
      <LiquidGlassCollapsibleContent>
        Status: Shipped · Content stays opaque for crisp legibility.
      </LiquidGlassCollapsibleContent>
    </LiquidGlassCollapsibleRoot>
  );
}
```

### Layering and Optical Guidance

```text
CollapsibleRoot          (opaque container)
├── CollapsibleTrigger   (liquid-glass control, regular | prominent, material auto | opaque)
└── CollapsibleContent   (opaque reading surface — never glass on glass)
```

- **Single-layer glass**: only `Trigger` declares `liquid-glass` optical intent with press deformation; `Root` and reading `Content` stay opaque to preserve legibility and avoid stacking glass on glass.
- **Prominence and opaque opt-out**: `Trigger` supports `variant="regular"` and `variant="prominent"` (primary tinted glass), plus `material="opaque"` to opt out of optical intent while retaining the full opaque surface.
- **Concentric radii and accessible fallbacks**: outer containers pair `rounded-2xl` with `rounded-xl` inner controls; disabled triggers withdraw optical candidates and elevation without dimming whole-host opacity, and hosts without optical support render the declared opaque fallback. See [Apple's Materials guidance](https://developer.apple.com/design/human-interface-guidelines/materials).
