Liquid Glass Toggle Group applies optical glass exclusively to the floating `Root` container while rendering borderless inner segments so glass never stacks on glass, maintaining concentric corner radii in both horizontal and vertical layouts.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototypes directly from `@proto.ui/prototypes-liquid-glass/toggle-group` and adapt them for your target runtime.

## Usage

```tsx
import {
  LiquidGlassToggleGroupItem,
  LiquidGlassToggleGroupRoot,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <LiquidGlassToggleGroupRoot defaultValue={['week']} a11yLabel="Calendar range">
      <LiquidGlassToggleGroupItem value="day">Day</LiquidGlassToggleGroupItem>
      <LiquidGlassToggleGroupItem value="week">Week</LiquidGlassToggleGroupItem>
      <LiquidGlassToggleGroupItem value="month">Month</LiquidGlassToggleGroupItem>
    </LiquidGlassToggleGroupRoot>
  );
}
```

### Material Hierarchy & Accessibility

- **Single glass layer**: Only `Root` declares v2 `liquid-glass` material and specular rim highlights; inner items stay borderless segments so glass is never stacked on glass.
- **Concentric geometry**: Horizontal groups pair a capsule container with capsule segments (`rounded-full`); vertical groups pair a `rounded-2xl` (16px) frame and `p-1.5` (6px) inset with concentric `rounded-[10px]` items (16px − 6px).
- **Fallbacks & reduced motion**: Setting `material="opaque"` or enabling reduced transparency or forced colors preserves high-contrast opaque surfaces. Disabled items retain readable contrast without whole-surface opacity reduction, and color transitions disable automatically under reduced motion.
