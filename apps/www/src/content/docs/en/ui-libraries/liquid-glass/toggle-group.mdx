## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Parts**: `Root`, `Item`.
- **Single and multiple modes**: `value` and `defaultValue` are always string arrays. With `multiple={false}`, at most one item stays active and clicking it again clears the selection. Controlled mode emits `valueChange` proposals without mutating caller state.
- **Keyboard and guards**: arrow keys move roving focus without toggling; disabled, read-only, and duplicate-valued items cannot commit.

## API

| Part | Prop / Event | Description |
| --- | --- | --- |
| Root | `value`, `defaultValue` | Controlled / uncontrolled array of pressed values |
| Root | `multiple` | Enables multiple selection; `false` allows at most one active value |
| Root | `disabled`, `readOnly`, `valueChange` | Interaction state and selection proposal event |
| Item | `value`, `disabled` | Unique item value and per-item disabled flag |
