## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Host-neutral model and Web helper**: item-count overscan, maximum materialized count, revisions, and generation-bound commits live in the host-neutral model. On Web, the explicit `virtual-list/web` entry measures variable item sizes, manages spacers and DOM nodes, preserves keyed views, supports scrolling to a key, and cleans up listeners on teardown.
- **Bounded rendering**: application content is created only for the active visible window while keeping keyed view instances stable across scrolls.

## API

- **Core model**: stable logical key sequence, item-count overscan, maximum materialized item cap, and revision tracking.
- **Web host entry (`virtual-list/web`)**: variable-extent measurement, spacer management, keyed view reuse, scroll-to-key navigation, and listener cleanup.
