Liquid Glass Select builds on [Base Select](/en/ui-libraries/base/select/) with eleven composable parts—Root, Trigger, Value, Content, Surface, Viewport, Item, ItemText, Group, Label, and Separator—providing controlled or uncontrolled single selection and a glass popup surface.

## Usage

### Composition and part roles

Compose the popup as `Content > Surface > Viewport > Item > ItemText`, placing `Group` (with `Label` and `Item` children) and `Separator` inside `Viewport` when grouping options:

- **Root**: manages `open`, `value`, selected text, and the option collection; `open` and `value` can be controlled independently.
- **Trigger & Value**: `Trigger` provides `combobox` semantics—click toggles, Enter/Space opens, and ArrowDown/ArrowUp opens at the selected or first/last enabled item. `Value` resolves selected text, raw value, `placeholder`, or empty content in order.
- **Content / Surface / Viewport**: `Content` handles portal mounting, collision positioning, and dismissal without painting a surface; `Surface` owns the popup paint and glass material slot; `Viewport` is the scroll container with room so item focus rings are not clipped.
- **Item / ItemText / Group / Label / Separator**: pointer click, Enter, or Space commits an enabled item (hover and arrow navigation never commit, and disabled items are skipped). Updating the selected item's `textValue` refreshes `Value`. Escape closes and restores Trigger focus; Tab and outside press close.

### Layout and material

- Long labels wrap and shrink cleanly, popup dimensions stay within available host bounds, and text alignment and trailing indicators follow logical reading direction. Leave outer room around `Trigger` for its focus ring.
- `Trigger` and open `Surface` request `liquid-glass` optics and automatically fall back to readable opaque styling whenever backdrop, overlap, contrast, or accessibility preferences disallow glass.
- Select is a single-selection dropdown; for searchable options or free text, use [Combobox](/en/ui-libraries/liquid-glass/combobox/) or [Autocomplete](/en/ui-libraries/liquid-glass/autocomplete/).

## API

| Part | Prop / Event | Defaults and notes |
| --- | --- | --- |
| Root | `open`, `defaultOpen`, `value`, `defaultValue` | Independently controlled or uncontrolled visibility and selection |
| Root | `disabled`, `closeOnSelect` | Disables interaction / closes automatically after selection |
| Root | `openChange`, `valueChange` | Visibility and selection proposal events |
| Value | `placeholder` | Fallback text shown when no option is selected |
| Content | `position`, `side`, `align`, `sideOffset`, `alignOffset`, `avoidCollisions`, `collisionPadding` | Positioning mode (default `'popper'`, also supports `'item-aligned'`) and collision options |
| Item | `value`, `textValue`, `disabled`, `select` | Option identifier, display text, disabled flag, and selection event |
