Liquid Glass Select builds on [Base Select](/en/ui-libraries/base/select/) with eleven composable parts. Glass material requests belong exclusively to `Trigger` and open `Surface` with concentric corner geometry and high-contrast opaque fallbacks, never stacking glass on glass.

## Installation

Currently available from workspace source. Import all eleven parts from `@proto.ui/prototypes-liquid-glass/select`:

```ts
import {
  selectRoot,
  selectTrigger,
  selectValue,
  selectContent,
  selectSurface,
  selectViewport,
  selectItem,
  selectItemText,
  selectGroup,
  selectLabel,
  selectSeparator,
} from '@proto.ui/prototypes-liquid-glass/select';
```

## Usage

```tsx
import {
  LiquidGlassSelectContent,
  LiquidGlassSelectGroup,
  LiquidGlassSelectItem,
  LiquidGlassSelectItemText,
  LiquidGlassSelectLabel,
  LiquidGlassSelectRoot,
  LiquidGlassSelectSurface,
  LiquidGlassSelectTrigger,
  LiquidGlassSelectValue,
  LiquidGlassSelectViewport,
} from '../proto-ui/components/react';

export function FruitSelect() {
  return (
    <LiquidGlassSelectRoot defaultValue="apple">
      <LiquidGlassSelectTrigger className="w-48" accessibleLabel="Fruit selector">
        <LiquidGlassSelectValue placeholder="Select a fruit" />
      </LiquidGlassSelectTrigger>
      <LiquidGlassSelectContent>
        <LiquidGlassSelectSurface>
          <LiquidGlassSelectViewport>
            <LiquidGlassSelectGroup>
              <LiquidGlassSelectLabel>Fruits</LiquidGlassSelectLabel>
              <LiquidGlassSelectItem value="apple" textValue="Apple">
                <LiquidGlassSelectItemText>Apple</LiquidGlassSelectItemText>
              </LiquidGlassSelectItem>
              <LiquidGlassSelectItem value="banana" textValue="Banana">
                <LiquidGlassSelectItemText>Banana</LiquidGlassSelectItemText>
              </LiquidGlassSelectItem>
            </LiquidGlassSelectGroup>
          </LiquidGlassSelectViewport>
        </LiquidGlassSelectSurface>
      </LiquidGlassSelectContent>
    </LiquidGlassSelectRoot>
  );
}
```

### Composition & material principles

```text
SelectRoot
├── SelectTrigger (liquid-glass slot)
│   └── SelectValue
└── SelectContent (portal & placement frame)
    └── SelectSurface (sole popup liquid-glass slot, rounded-2xl)
        └── SelectViewport (p-2 scrollport)
            ├── SelectGroup
            │   ├── SelectLabel
            │   └── SelectItem (rounded-lg concentric radius)
            │       └── SelectItemText
            └── SelectSeparator
```

- **Single glass surface & concentric radii**: `Content` owns portal mounting and collision positioning without painting glass. `Surface` is the sole popup material owner (`rounded-2xl` with `p-2` `Viewport` and `rounded-lg` `Item` concentric corners plus a subtle inset specular rim).
- **Accessibility & preference fallbacks**: Pointer press deformation automatically withdraws when `prefers-reduced-motion: reduce` is active. Disabled controls and items withdraw glass optics and stay legible with semantic foreground fallbacks rather than whole-host opacity.
- For searchable options or free text, use [Combobox](/en/ui-libraries/liquid-glass/combobox/) or [Autocomplete](/en/ui-libraries/liquid-glass/autocomplete/).
