## Installation

Currently available from workspace source. Import core parts and bound controls from `@proto.ui/prototypes-liquid-glass/field`:

```ts
import {
  fieldRoot,
  fieldLabel,
  fieldControl,
  fieldDescription,
  fieldError,
  fieldValidity,
  fieldTextarea,
  fieldSelectTrigger,
  fieldSwitch,
} from '@proto.ui/prototypes-liquid-glass/field';
```

## Usage

```tsx
import {
  FieldRoot,
  FieldLabel,
  FieldControl,
  FieldDescription,
  FieldError,
} from '@proto.ui/prototypes-liquid-glass/field';

export function ProfileField() {
  return (
    <FieldRoot required minLength={3}>
      <FieldLabel>Username</FieldLabel>
      <FieldControl placeholder="Max Leiter" />
      <FieldDescription>Choose a unique username for your account.</FieldDescription>
      <FieldError />
    </FieldRoot>
  );
}
```

### Material and hierarchy notes

- **Static editing surface with opaque fallback**: `Control` declares a static `liquid-glass` material candidate while retaining explicit `bg-background` and `text-foreground` fallback styling. Disabled states switch to `bg-muted` and `text-muted-foreground` rather than reducing surface opacity so fallback legibility stays intact.
- **Semantic vibrancy**: Helper descriptions and validity text use muted secondary ink (`text-muted-foreground`), while invalid states use `text-destructive` and `border-destructive`.
- **Automatic ARIA wiring**: Links and cleans up `aria-labelledby`, `aria-describedby`, and (while invalid) `aria-errormessage` without manual DOM IDs. Pair with [Fieldset](../fieldset/) and [Form](../form/) for group disabling or form submission.

### Control & other parts

- **Control**: `value` / `defaultValue`, `disabled`, `readOnly`, `required`, `placeholder`, `name`, `autoComplete`, `inputMode`, `enterKeyHint`, `ariaLabel`.
- **Bound controls**: `fieldTextarea`, `fieldSelectTrigger`, `fieldSwitch`.
- **Label**: `activation?: boolean` (default `true`).
- **Error**: `message?: string`, `keepMounted?: boolean` (default `false`).
- **Methods & events (Root)**: `validate(reason?)`, `resolveValidation(requestId, result)`, `cancelValidation()`, `resetValidation()`, `focusControl(options?)`, `getValidity()`; events `validityChange`, `validationRequest`.
