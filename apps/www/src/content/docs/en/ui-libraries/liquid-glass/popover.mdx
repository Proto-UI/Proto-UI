Liquid Glass Popover displays a floating translucent surface anchored to a trigger with regular and prominent hierarchy, concentric corner geometry, and automatic Reduced Transparency, Forced Colors, and Reduced Motion fallbacks, without locking background scroll or trapping `Tab` navigation.

## Installation

Liquid Glass Popover is currently available from the workspace source and not yet included in the 0.2.0 stable CLI release. Import the prototypes directly from `@proto.ui/prototypes-liquid-glass/popover` and adapt them for your target runtime:

```ts
import {
  popoverRoot,
  popoverTrigger,
  popoverContent,
  popoverTitle,
  popoverDescription,
  popoverClose,
} from '@proto.ui/prototypes-liquid-glass/popover';
```

## Usage

```tsx
<LiquidGlassPopover>
  <LiquidGlassPopoverTrigger>Open Popover</LiquidGlassPopoverTrigger>
  <LiquidGlassPopoverContent align="start">
    <LiquidGlassPopoverTitle>Dimensions</LiquidGlassPopoverTitle>
    <LiquidGlassPopoverDescription>Set the dimensions for the layer.</LiquidGlassPopoverDescription>
  </LiquidGlassPopoverContent>
</LiquidGlassPopover>
```

### Composition

```text
LiquidGlassPopoverRoot
├── LiquidGlassPopoverTrigger
└── LiquidGlassPopoverContent
    ├── LiquidGlassPopoverTitle
    ├── LiquidGlassPopoverDescription
    └── LiquidGlassPopoverClose
```

- **Material layering (never stack glass-on-glass)**: `Content` activates the `liquid-glass` material only while open with `material="auto"`. `Close` stays an opaque concentric control (`rounded-xl` inside the `rounded-2xl` container) so nested controls never stack glass over glass.
- **Accessibility fallbacks**: When Reduced Transparency (`prefers-reduced-transparency: reduce`) or Forced Colors (`forced-colors: active`) is enabled, the material candidate withdraws automatically to the high-contrast opaque fallback surface. Reduced Motion (`prefers-reduced-motion: reduce`) disables enter/leave animations and transitions.
- **Positioning & dismissal**: Supports `side`, `align`, `sideOffset`, `alignOffset`, and `collisionPadding`. Outside presses, `Escape`, `Close`, and focus moving outside both `Trigger` and `Content` request dismissal.
