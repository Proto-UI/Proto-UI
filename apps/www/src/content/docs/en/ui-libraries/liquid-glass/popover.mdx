## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Parts**: `Root`, `Trigger`, `Content`, `Title`, `Description`, `Close`.
- **Positioning**: `Content` anchors against `Trigger` using `side`, `align`, `sideOffset`, `alignOffset`, and `collisionPadding`.
- **Dismissal and focus**: outside press, focus leaving both `Trigger` and `Content`, Escape, and `Close` request dismissal. Moving focus between `Trigger` and portaled `Content` counts as inside; closing due to focus leaving keeps focus on the newly focused outside element (`focusReason` is `'programmatic'`).
- **Controlled state**: supply `open` and handle `openChange` for controlled mode, or use `defaultOpen` for uncontrolled state. Refusing a close request keeps `Content` mounted without trapping focus.

## API

| Part | Prop / Event | Description |
| --- | --- | --- |
| Root | `open`, `defaultOpen` | Controlled / uncontrolled open state |
| Root | `openChange` | Emitted when open state changes are requested |
| Content | `side`, `align`, `sideOffset`, `alignOffset`, `collisionPadding` | Anchoring placement and collision padding relative to `Trigger` |
| Trigger / Title / Description / Close | — | Trigger button, title, description, and close control |
