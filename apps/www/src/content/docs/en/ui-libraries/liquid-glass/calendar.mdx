Liquid Glass Calendar provides Gregorian date selection in `single` (default), `multiple`, and `range` modes. Dates use `YYYY-MM-DD` strings and visible months use `YYYY-MM` strings; selection and month can each be controlled independently.

## Usage

### Composition and grid capacity

Calendar comprises ten parts: `Root`, `Caption`, `Heading`, `Previous`, `Next`, `Grid`, `Weekdays`, `Weekday`, `Row`, and `Day`.

- Place seven `Weekday` parts (`offset` `0–6`) inside `Weekdays`, and up to six indexed `Row` parts (`index` `0–5`) holding `Day` parts (`offset` `0–41`).
- By default the calendar renders the minimum 4, 5, or 6 complete weeks needed for the active month; set `fixedWeeks={true}` to always show six weeks. Unused capacity rows and days expose `hidden` and stay out of focus and selection.
- Weekday headings and full localized cell labels follow `weekStartsOn` (`0` = Sunday) and `locale`. `direction="rtl"` mirrors Left/Right navigation, and `a11yLabel` names icon-only Previous/Next buttons.

### Single, multiple, and range behavior

- **Multiple (`multiple`)**: activating a day toggles it in a deduplicated, sorted array. `minSelected` defaults to `0`, and omitting `maxSelected` leaves the upper bound open.
- **Range (`range`)**: the first activation sets `{ from }`, the second completes an inclusive `{ from, to }` (automatically sorting reversed endpoints), and a subsequent activation starts a new range. `{}` clears the range. `minNights` (default `0`, allowing single-day ranges) and `maxNights` bound the civil-day span between endpoints.
- `min`, `max`, and Root `unavailable` apply to every selected date; ranges spanning an unavailable date are rejected while keeping the starting anchor. Use Root `unavailable` for whole-date rules and Day `disabled` for individual cells.
- `readOnly` prevents selection changes while still allowing month navigation; `disabled` disables both.

### Clock ownership and month/year selectors

- Calendar does not read the system clock or timezone; pass `today` as a `YYYY-MM-DD` string to highlight the current date (`aria-current="date"`).
- Initial month precedence: `month` → `defaultMonth` → active mode's selected date → `today` → `1970-01`.
- To add month and year dropdowns, bind real family Select controls with `bindCalendarCaption(source, { month, year })` against Calendar's public `month`/`disabled` state and `requestMonth`, call `dispose()` on teardown, and pass stable names via Select's `accessibleLabel`.

## API

| Part / Mode | Props | Defaults and notes |
| --- | --- | --- |
| Root | `mode` | `'single' \| 'multiple' \| 'range'`, default `'single'` |
| Root (`single`) | `value`, `defaultValue` | `YYYY-MM-DD` string; emits `onValueChange({ value })` |
| Root (`multiple`) | `values`, `defaultValues` | Date array; pairs with `minSelected` (`0`), `maxSelected`, `onValuesChange({ values })` |
| Root (`range`) | `range`, `defaultRange` | `{ from?, to? }`; pairs with `minNights` (`0`), `maxNights`, `onRangeChange({ range })` |
| Root | `month`, `defaultMonth` | `YYYY-MM` string; independently controllable |
| Root | `today`, `min`, `max`, `unavailable` | Current-date marker and eligibility bounds (`unavailable` is a string array) |
| Root | `weekStartsOn`, `locale`, `direction`, `fixedWeeks` | `weekStartsOn` defaults to `0`; `fixedWeeks` defaults to `false` |
| Root | `disabled`, `readOnly` | Disables interaction or blocks selection edits |
| Previous / Next | `a11yLabel`, `disabled` | Accessible label and local disable |
| Row / Day | `index`, `offset`, `disabled` | Grid capacity indices and per-day disable |

### Methods and exposed states

- Root methods: `requestMonth(month)`, `requestValue(date)`, `requestValues(dates)`, `requestRange(range)`, `getValues()`, `getRange()`.
- Root states: `mode`, `weekCount`, `selectedCount`, `rangeComplete`.
- Day states: `selected`, `rangeStart`, `rangeEnd`, `rangeMiddle`, `rangePending`, `hidden`. Grid sets `aria-multiselectable` in multiple and range modes.
