Liquid Glass Calendar provides Gregorian date selection in `single` (default), `multiple`, and `range` modes. It pairs concentric corner geometry, specular inset edge highlights, and translucent layering with automatic opaque fallbacks under reduced-transparency or forced-colors preferences—without stacking nested glass when hosted inside a `Date Picker` popup.

## Usage

```tsx
import {
  CalendarRoot,
  CalendarCaption,
  CalendarPrevious,
  CalendarHeading,
  CalendarNext,
  CalendarGrid,
  CalendarWeekdays,
  CalendarWeekday,
  CalendarRow,
  CalendarDay,
} from '@proto.ui/prototypes-liquid-glass/calendar';

export function LiquidGlassCalendarExample() {
  return (
    <CalendarRoot mode="single" defaultMonth="2026-10" defaultValue="2026-10-12" today="2026-10-08">
      <CalendarCaption>
        <CalendarPrevious a11yLabel="Previous month" />
        <CalendarHeading />
        <CalendarNext a11yLabel="Next month" />
      </CalendarCaption>
      <CalendarGrid>
        <CalendarWeekdays>
          {Array.from({ length: 7 }, (_, offset) => (
            <CalendarWeekday key={offset} offset={offset} />
          ))}
        </CalendarWeekdays>
        {Array.from({ length: 6 }, (_, row) => (
          <CalendarRow key={row} index={row}>
            {Array.from({ length: 7 }, (_, col) => (
              <CalendarDay key={col} offset={row * 7 + col} />
            ))}
          </CalendarRow>
        ))}
      </CalendarGrid>
    </CalendarRoot>
  );
}
```

### Layering, anatomy, and caption pickers

- Compose `Calendar` from ten parts: `Root`, `Caption`, `Heading`, `Previous`, `Next`, `Grid`, `Weekdays`, `Weekday`, `Row`, and `Day`.
- To avoid glass-on-glass stacking, Calendar remains an ordinary non-material content surface; when hosted inside `Date Picker`, the popover content owns the single Liquid Glass material layer.
- Calendar does not read the system clock directly: pass a `YYYY-MM-DD` `today` prop from the host to mark today (`aria-current="date"`).
- `direction="rtl"` mirrors Left/Right navigation automatically. Bind family `Select` controls with `bindCalendarCaption(source, { month, year })` (and call `dispose()` on teardown) for month and year dropdowns.

### Selection modes

| Mode       | Controlled / initial props                       | Change event                 |
| ---------- | ------------------------------------------------ | ---------------------------- |
| `single`   | `value` / `defaultValue` (`YYYY-MM-DD`)          | `onValueChange({ value })`   |
| `multiple` | `values` / `defaultValues` (`readonly string[]`) | `onValuesChange({ values })` |
| `range`    | `range` / `defaultRange` (`{ from?, to? }`)      | `onRangeChange({ range })`   |

### Events, methods, and exposed states

- **Events (Root)**: `onValueChange({ value })`, `onValuesChange({ values })`, `onRangeChange({ range })`, `onMonthChange({ month })`.
- **Methods (Root)**: `requestValue(date)`, `requestValues(dates)`, `requestRange(range)`, `requestMonth(month)`, `getValues()`, `getRange()`.
- **Exposed states**: Root exposes `value`, `mode`, `selectedCount`, `rangeComplete`, `month`, `weekCount`, `disabled`, `direction`; Day exposes `date`, `selected`, `rangeStart`, `rangeEnd`, `rangeMiddle`, `rangePending`, `today`, `outside`, `disabled`, `hidden`.
