Liquid Glass Message Scroller separates the scrolling content layer from the floating navigation control: `Root` and `Viewport` remain clean, neutral surfaces with concentric corners (`rounded-2xl` outer frame with 4px inset around a `rounded-xl` viewport), while `Jump` floats above the transcript as a concentric capsule with `regular` and `prominent` prominence levels.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototypes directly from `@proto.ui/prototypes-liquid-glass/message-scroller` and adapt them for your target runtime.

```ts
import {
  messageScrollerRoot,
  messageScrollerViewport,
  messageScrollerJump,
} from '@proto.ui/prototypes-liquid-glass/message-scroller';
```

## Usage

Place `Root` inside a height-constrained container so messages scroll cleanly beneath the floating capsule control:

```tsx
<div className="h-80 w-full max-w-lg">
  <LiquidGlassMessageScrollerRoot a11yLabel="Design conversation">
    <LiquidGlassMessageScrollerViewport>
      <div className="flex flex-col gap-3 p-4 pb-16">
        {messages.map((message) => (
          <div key={message.id}>{message.text}</div>
        ))}
      </div>
    </LiquidGlassMessageScrollerViewport>
    <LiquidGlassMessageScrollerJump variant="regular">
      Jump to latest ↓
    </LiquidGlassMessageScrollerJump>
  </LiquidGlassMessageScrollerRoot>
</div>
```

### Layering & Contrast Guidelines

- **Keep content surfaces neutral**: `Root` and `Viewport` never apply glass over transcript text, keeping long threads legible and avoiding glass-on-glass stacking.
- **Prominence hierarchy (`regular` vs `prominent`)**: Use `variant="regular"` while caught up, and promote to `variant="prominent"` when `newContentCount > 0` while scrolled up.
- **Readable disabled contrast**: Disabling `Jump` withdraws shadow elevation and pointer interaction while keeping paired surface/ink contrast intact instead of applying `opacity-50`.
- **Focus preservation**: Activating `Jump` scrolls smoothly to the latest message without stealing keyboard focus.
