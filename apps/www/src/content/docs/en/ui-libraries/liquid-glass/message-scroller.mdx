Liquid Glass Message Scroller builds on Scroll Surface end-follow behavior: new messages auto-scroll into view while the reader is at the bottom, pause when the reader scrolls up to read history, and resume on demand via Jump to latest.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **New-item indicator**: pass `newContentCount` from your application state; the scroller does not infer application-level unread semantics.
- **Focus and accessibility**: jumping to the latest message scrolls smoothly without stealing focus. Customize the scrollable region's accessible name via Root's `a11yLabel` (default `'Messages'`).

## API

| Part | Prop              | Default      | Description                                           |
| ---- | ----------------- | ------------ | ----------------------------------------------------- |
| Root | `a11yLabel`       | `'Messages'` | Accessible label for the scrollable region            |
| Root | `newContentCount` | —            | Application-supplied count of newly appended messages |
