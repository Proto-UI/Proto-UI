Liquid Glass Dropdown Menu organizes menu actions into named groups with dividers and shortcut hints, pairing Liquid Glass material styling on the trigger and open menu panel with automatic opaque fallback.

## Usage

- **Grouping and passive parts**: `Group` and `Label` establish a live accessible naming relationship. `Separator` and `Shortcut` are passive parts excluded from keyboard action traversal; `Shortcut` displays hint text only without registering global keybindings.
- **Trigger and panel material**: `Trigger` declares `liquid-glass` optical intent with press deformation, and `Content` requests glass optics while open. When an in-app canvas backdrop is unavailable (including for portaled menus outside the canvas), or when contrast or preferences disallow glass, both fall back cleanly to readable opaque styling.
- Hover, focus-visible, disabled state, and menu activation are handled by Base Dropdown Menu.

## API

| Part                 | Description                                                           |
| -------------------- | --------------------------------------------------------------------- |
| Root                 | Manages menu open state and coordination                              |
| Trigger              | Menu trigger button supporting `disabled` and press material feedback |
| Content              | Menu panel with open-state glass material and automatic fallback      |
| Group / Label        | Groups related commands with an accessible group name                 |
| Item                 | Actionable menu command with optional disabled state                  |
| Separator / Shortcut | Passive divider and shortcut hint display                             |
