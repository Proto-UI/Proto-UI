Liquid Glass Dropdown Menu projects grouped command menus onto a floating translucent surface with concentric corner geometry, `regular` and `prominent` trigger hierarchy, `material="opaque"` opt-out, and Base keyboard navigation.

## Installation

Currently available from workspace source. Import all parts directly from `@proto.ui/prototypes-liquid-glass/dropdown`.

## Usage

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuGroup,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuSeparator,
  DropdownMenuShortcut,
  DropdownMenuTrigger,
} from '@/components/liquid-glass/dropdown-menu';
```

```tsx
<DropdownMenu>
  <DropdownMenuTrigger>Open</DropdownMenuTrigger>
  <DropdownMenuContent align="start">
    <DropdownMenuGroup>
      <DropdownMenuLabel>My Account</DropdownMenuLabel>
      <DropdownMenuItem value="profile">
        Profile
        <DropdownMenuShortcut>⇧⌘P</DropdownMenuShortcut>
      </DropdownMenuItem>
      <DropdownMenuItem value="billing">Billing</DropdownMenuItem>
    </DropdownMenuGroup>
    <DropdownMenuSeparator />
    <DropdownMenuItem value="logout">Log out</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```

- **Concentric geometry & layering**: The floating menu panel pairs a `rounded-2xl` outer container and `p-2` padding with `rounded-lg` items for concentric corner radii; menu items remain non-glass surfaces so glass is never stacked on glass.
- **Optical material & fallback**: `Trigger` and `Content` request `liquid-glass` optical material when an in-app backdrop source is available and fall back automatically to readable opaque surfaces when portaled outside the canvas or when accessibility preferences restrict transparency. Use `material="opaque"` to opt out explicitly.

## Examples

### Destructive & Inset

Combine `variant="destructive"` for irreversible actions with `inset` to align iconless items cleanly alongside icon rows.
