Liquid Glass Checkbox Group composes `Root`, `Item`, and `All` as compact content-layer 20×20 rounded checkboxes with clear non-color check/dash indicators, keeping form rows neutral (never stacking glass-on-glass) with readable muted disabled states.

## Installation

Available starting in `0.3.0-rc.1` and later releases.

## Usage

```tsx
import {
  LiquidGlassCheckboxGroupRoot,
  LiquidGlassCheckboxGroupAll,
  LiquidGlassCheckboxGroupItem,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <LiquidGlassCheckboxGroupRoot defaultValue={['email']} ariaLabel="Notification channels">
      <LiquidGlassCheckboxGroupAll>All notifications</LiquidGlassCheckboxGroupAll>
      <LiquidGlassCheckboxGroupItem value="email">Email updates</LiquidGlassCheckboxGroupItem>
      <LiquidGlassCheckboxGroupItem value="sms">SMS alerts</LiquidGlassCheckboxGroupItem>
    </LiquidGlassCheckboxGroupRoot>
  );
}
```

### Anatomy and surface hierarchy

- **Root**: Coordinates the selected `string[]` value (`value` / `defaultValue`), `orientation`, `disabled`, `readOnly`, and `ariaLabel`.
- **Item**: Compact content-list option with a 20×20 rounded checkbox indicator, focus feedback, its own `Tab` stop, and `Space` activation (`Enter` does not toggle).
- **All**: Derives checked, mixed (`aria-checked="mixed"`), or unchecked state across enabled items and toggles only enabled items while preserving disabled selections.
- **Content-layer contrast and forms**: Rows stay neutral without glass-on-glass card slabs and use semantic muted colors rather than host opacity when disabled. Inside [Field](/en/ui-libraries/liquid-glass/field/) or [Form](/en/ui-libraries/liquid-glass/form/), `Root` integrates with label activation, required validation, serialization, and reset.

### Events, Methods, and States

- **Root events**: `valueChange` (payload `{ value: string[] }`).
- **Root methods**: `getValue(): string[]`, `resetValue(): boolean`, `focusSelf(): void`.
- **Exposed states**: Root exposes `checked`, `indeterminate`, `disabled`, `readOnly`; Item and All expose `checked`, `indeterminate`, `disabled`, `readOnly`, `focused`, `focusVisible`.
