Liquid Glass Checkbox Group composes `Root`, `Item`, and `All` to manage a string-array selection with tri-state select-all toggling and clear visual indicators (check, dash, or empty box) that do not rely on color alone.

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Parts**: `Root`, `Item`, `All`.
- **Select-all and disabled items**: `All` derives checked, unchecked, or mixed state across enabled items and preserves disabled selections when toggling. Visual SVG indicators are `aria-hidden` and add no extra roles or Tab stops.
- **Keyboard**: every item has its own Tab stop and toggles with Space (Enter does not toggle).
- **Controlled state and forms**: supply `value` and handle `valueChange` for controlled state; `getValue()` returns a copy; duplicate item values are ignored. Inside [Field](/en/ui-libraries/liquid-glass/field/) or [Form](/en/ui-libraries/liquid-glass/form/), `Root` integrates with label activation, required validation, serialization, and reset without creating hidden HTML inputs.

## API

| Part | Prop / Method | Description |
| --- | --- | --- |
| Root | `value`, `defaultValue` | Controlled / uncontrolled array of selected strings |
| Root | `disabled`, `readOnly`, `ariaLabel` | Group-wide disabled/read-only state and accessible name |
| Root | `valueChange`, `getValue()` | Change proposal event and defensive copy getter |
| Item | `value`, `disabled` | Option identifier and local disabled state |
| All | — | Toggles all enabled items and reflects checked/mixed state |
