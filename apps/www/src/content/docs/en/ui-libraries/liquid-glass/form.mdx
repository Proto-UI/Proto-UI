## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Parts**: `Root`, `Field`, `Submit`, `Reset`.
- **Validation and submission**: activating `Submit` (or pressing Enter inside a focused single-line Field, Number Field, or Input OTP, excluding IME composition and modifiers) validates every enabled registered field and emits `submit` with values keyed by field name once valid. Disabled fields are excluded and duplicate names are ignored; in-flight async checks discard stale submissions on edit, cancel, or unmount. Form does not trigger network requests, navigation, or hidden HTML inputs.
- **Reset**: `Reset` or `requestReset()` restores uncontrolled initial values, proposes resets to controlled fields without overwriting them, cancels pending edits/validation, and emits `reset`. `resetValidation()` clears validation state only.
- **Action buttons**: `FormSubmit` and `FormReset` share Liquid Glass Button visual feedback and accept `material="auto"` or `"opaque"`, reverting to opaque styling when disabled.

## API

| Part | Prop / Method / Event | Description |
| --- | --- | --- |
| Root | `disabled` | Disables the form and propagates disabled state to contained fields |
| Root | `requestReset()`, `resetValidation()` | Resets values and validation / clears validation only |
| Root | `submit`, `reset` | Emits form values keyed by field name on valid submit / emitted on reset |
| Field | — | Registers a field for form validation and serialization |
| Submit / Reset | `material` | `'auto' \| 'opaque'`; exposes `disabled`, `hovered`, `pressed`, `focused`, `focusVisible`, and `focusSelf()` |
