Liquid Glass Image stays optically neutral in the content layer—never coating photos or illustrations with glass blur—while providing responsive framing and optional concentric corner radii so floating `regular` and `prominent` Liquid Glass controls can refract cleanly above it.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import `imageRoot` (aliased as `liquidGlassImageRoot`) and `LiquidGlassImageRootProps` directly from `@proto.ui/prototypes-liquid-glass/image`.

## Usage

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { liquidGlassImageRoot } from '@proto.ui/prototypes-liquid-glass/image';
import { liquidGlassButton } from '@proto.ui/prototypes-liquid-glass/button';

const adapt = createReactAdapter(React);
const GlassImage = adapt(liquidGlassImageRoot);
const GlassButton = adapt(liquidGlassButton);

export function MediaCard() {
  return (
    <div className="relative overflow-hidden rounded-2xl p-2">
      <GlassImage
        source="/images/base-image/landscape.svg"
        a11yMode="informative"
        alternativeText="Sunlit mountain ridge overlooking an alpine valley"
        fit="cover"
        radius="xl"
        surfaceStyle={{ width: '100%', height: '240px' }}
      />
      <div className="absolute right-4 bottom-4 flex gap-2">
        <GlassButton variant="regular">Switch</GlassButton>
        <GlassButton variant="prominent">Featured</GlassButton>
      </div>
    </div>
  );
}
```

### Material Hierarchy & Accessibility

Design choices align with Apple's [Materials](https://developer.apple.com/design/human-interface-guidelines/materials) guidance:

- **Optically neutral content layer**: Reserve Liquid Glass strictly for floating functional controls (navigation bars, toolbars, floating actions) above content. Do not coat images with glass or stack glass controls on top of another glass container.
- **Concentric corner radii**: Use `radius` so nested images match the curvature of their surrounding container (`outer radius = inner radius + padding`), while `block max-w-full h-auto` preserves natural aspect ratios.
- **Accessibility preferences**: Under Reduce Transparency, Increase Contrast, Reduce Motion, or Forced Colors—or when a floating control explicitly sets `material="opaque"`—overlay controls switch to high-contrast opaque surfaces while the underlying image stays sharp and unaltered.
- **Semantics and loading**: `a11yMode`, `alternativeText`, `fit`, `loadingStatus`, and `loadingStatusChange` are managed consistently by [Base Image](/en/ui-libraries/base/image/).
