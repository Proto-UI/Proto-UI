Root, List, Trigger and Content inherit the matching [Base Tabs protocol](/en/ui-libraries/base/tabs/). Root owns the selected value. Arrow keys and Home/End move through enabled triggers; Enter/Space activate a manually selected tab. Controlled requests wait for the owner's value.

Import `tabsRoot`, `tabsList`, `tabsTrigger`, `tabsContent` from `@proto.ui/prototypes-liquid-glass/tabs`. These remain private draft workspace source. No public registry release or native/Compiler support is implied.

List and Trigger accept `appearance="underline"` for the Runtime Box's transparent, text-width underline recipe. The default recipe remains this family's own presentation. Root uses `value`/`defaultValue`, `activationMode` and `orientation`; Trigger uses `value`/`disabled`; Content uses `value`/`keepMounted`. Runtime selection uses manual activation, so arrow navigation does not remount a demo.

Source and synthetic-DOM evidence are distinct from commit-bound native screenshots, narrow-screen geometry and independent visual acceptance. Those browser checks remain pending.

The rounded material segmented default is independently authored, using the existing material declaration and ordinary style fallback. It is not an official Apple Tabs reproduction.
