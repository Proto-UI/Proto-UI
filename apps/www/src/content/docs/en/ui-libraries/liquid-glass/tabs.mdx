Liquid Glass Tabs builds on [Base Tabs](/en/ui-libraries/base/tabs/) and scopes Liquid Glass translucency strictly to the navigation `TabsList` layer—never stacking glass onto `TabsTrigger` or `TabsContent`—with concentric capsule radii, `regular` / `prominent` hierarchy, and explicit `material="opaque"` fallback.

## Installation

Available directly from workspace source at `@proto.ui/prototypes-liquid-glass/tabs`.

```ts
import {
  tabsRoot,
  tabsList,
  tabsTrigger,
  tabsContent,
  tabsIndicator,
} from '@proto.ui/prototypes-liquid-glass/tabs';
```

## Usage

```html
<wc-liquid-glass-tabs-root default-value="overview">
  <wc-liquid-glass-tabs-list>
    <wc-liquid-glass-tabs-trigger value="overview">Overview</wc-liquid-glass-tabs-trigger>
    <wc-liquid-glass-tabs-trigger value="analytics">Analytics</wc-liquid-glass-tabs-trigger>
  </wc-liquid-glass-tabs-list>
  <wc-liquid-glass-tabs-content value="overview">Overview content.</wc-liquid-glass-tabs-content>
  <wc-liquid-glass-tabs-content value="analytics">Analytics content.</wc-liquid-glass-tabs-content>
</wc-liquid-glass-tabs-root>
```

### Composition

```text
TabsRoot
├── TabsList (Liquid Glass navigation layer)
│   ├── TabsTrigger (concentric active lens, non-glass)
│   └── TabsTrigger
├── TabsContent (neutral content layer, non-glass)
└── TabsContent
```

- **Material layering & fallback**: Only `TabsList` declares a `liquid-glass` material candidate when `appearance="default"` and `material="auto"`. Reduced-transparency environments, increased-contrast settings, or `material="opaque"` fall back cleanly to readable opaque fills.
- **Motion & accessibility**: Selection transitions respect `prefers-reduced-motion: reduce`, focus rings use high-contrast inset outlines with `forced-colors` support, and disabled items preserve contrast without dimming opacity.
