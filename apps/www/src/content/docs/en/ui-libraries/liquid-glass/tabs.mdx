Liquid Glass Tabs composes `Root`, `List`, `Trigger`, and `Content` over [Base Tabs](/en/ui-libraries/base/tabs/). It defaults to a rounded segmented glass appearance (with automatic opaque fallback) and includes a transparent underline variant (`appearance="underline"`).

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

```ts
import {
  tabsRoot,
  tabsList,
  tabsTrigger,
  tabsContent,
} from '@proto.ui/prototypes-liquid-glass/tabs';
```

## Usage

- **Selection and keyboard**: `Root` manages the active tab value. Arrow keys and `Home`/`End` move focus across enabled triggers; in manual activation mode, Enter or Space commits the switch so browsing does not remount panels unexpectedly. Controlled mode waits for the updated `value` prop.
- **Appearance variants**: use the default segmented style or pass `appearance="underline"` to `List` and `Trigger` for a transparent, text-width underline look.

## API

| Part | Prop | Description |
| --- | --- | --- |
| Root | `value`, `defaultValue` | Controlled / uncontrolled active tab value |
| Root | `activationMode`, `orientation` | Automatic or manual keyboard activation / horizontal or vertical layout |
| List | `appearance` | Default segmented look, or `'underline'` |
| Trigger | `value`, `disabled`, `appearance` | Tab key, disabled state, and appearance variant |
| Content | `value`, `keepMounted` | Associated tab key; keeps hidden node mounted when `true` |
