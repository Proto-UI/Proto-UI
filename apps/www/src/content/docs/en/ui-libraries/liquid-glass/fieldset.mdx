Liquid Glass Fieldset composes `Root`, `Legend`, and `Description` to group related form fields and cascade disabled state. As a content-layer container, Fieldset renders as an ordinary rounded, bordered surface (`gap-3`) without requesting glass material, leaving descendant controls to manage their own presentation.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Cascading disabled policy**: effective disabled equals local `disabled` OR any enclosing Fieldset's disabled state. For nested `outer → middle → inner` Roots:
  - Disabling `outer` disables all three.
  - Setting `middle` disabled and re-enabling `outer` keeps `middle` and `inner` disabled.
  - Re-enabling `middle` re-enables `inner` unless `inner` itself remains disabled.
- Participating Fields inside the group (including inside `Legend`) inherit disabled state and handle their own validation invalidation. Fieldset does not manage values, validation, or form submission.
- **Accessible relationships**: `Root` declares the `group` role and automatically links `Legend` and `Description` without manual DOM IDs. Supply at most one `Legend` and one `Description` per group (duplicates are ignored); nested groups stay scoped to their own children.

## API

| Part | Prop | Default | Description |
| --- | --- | --- | --- |
| Root | `disabled` | `false` | Disables participating fields in this group and nested groups |
| Root | `ariaLabel` | `''` | Accessible label for the group |
| Legend | — | — | Optional semibold passive group heading; exposes inherited `disabled` |
| Description | — | — | Optional muted passive help text; exposes inherited `disabled` |

All three parts expose read-only effective `disabled` state; update `Root`'s `disabled` prop to change policy.
