Liquid Glass Fieldset composes `Root`, `Legend`, and `Description` to group related form fields and cascade disabled state. As a content-layer container, Fieldset renders as an opaque grouped surface (`rounded-2xl bg-secondary p-4` at the top level, stepping down concentrically to `rounded-xl bg-background p-3` when nested) without requesting glass material, preventing glass-on-glass stacking while letting descendant controls manage their own presentation.

Available starting in `0.3.0-rc.1` and later releases.

## Usage

```tsx
import {
  FieldsetRoot,
  FieldsetLegend,
  FieldsetDescription,
} from '@/components/liquid-glass/fieldset';
import { FieldRoot, FieldLabel, FieldControl } from '@/components/liquid-glass/field';

export function Example() {
  return (
    <FieldsetRoot>
      <FieldsetLegend>Address Information</FieldsetLegend>
      <FieldsetDescription>We need your address to deliver your order.</FieldsetDescription>
      <FieldRoot required>
        <FieldLabel>Street Address</FieldLabel>
        <FieldControl placeholder="123 Main St" />
      </FieldRoot>
    </FieldsetRoot>
  );
}
```

- **Content-layer surface & concentric radii**: Top-level `Fieldset.Root` uses an opaque grouped surface (`rounded-2xl bg-secondary p-4`) and automatically steps down to a concentric inner radius and contrasting opaque fill (`rounded-xl bg-background p-3`) when nested, keeping crisp boundaries across light, dark, and increased-contrast settings. Disabled headings use semantic muted text (`text-muted-foreground`) rather than fading the container opacity.
- **Cascading disabled policy**: effective disabled equals local `disabled` OR any enclosing Fieldset's disabled state. For nested `outer → middle → inner` Roots:
  - Disabling `outer` disables all three.
  - Setting `middle` disabled and re-enabling `outer` keeps `middle` and `inner` disabled.
  - Re-enabling `middle` re-enables `inner` unless `inner` itself remains disabled.
- Participating Fields inside the group (including inside `Legend`) inherit disabled state and handle their own validation invalidation. Fieldset does not manage values, validation, or form submission.
- **Accessible relationships**: `Root` declares the `group` role and automatically links `Legend` and `Description` without manual DOM IDs. Supply at most one `Legend` and one `Description` per group (duplicates are ignored); nested groups stay scoped to their own children.

### Description

`Description` declares no props of its own; all three parts expose read-only effective `disabled` state (`ExposeState<boolean>`). Update `Root`'s `disabled` prop to change policy.
