## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Parts**: `Root`, `Input`, `Control`, `Slot`, `Separator`.
- **Single input and active slot**: editing lives in a single accessible `Input`; `Slot` elements are passive `aria-hidden` readouts that add no extra Tab stops. Active slot highlighting tracks the actual caret or selection range while focused and editable, clearing on blur, disable, or read-only.
- **Filtering and completion**: supports `numeric` and `alphanumeric` filtering for lengths `1–32` (default `6`), sanitizing and clamping length after IME composition completes. `valueChange` proposes updates in controlled mode, and `completed` emits once per accepted complete code.
- **Field and Form integration**: swap `Input` for `Control` inside [Field](/en/ui-libraries/liquid-glass/field/) or [Form](/en/ui-libraries/liquid-glass/form/) to connect `FieldLabel`, validation, IME cancellation, serialization, and reset.

## API

| Part | Prop / Event | Defaults and notes |
| --- | --- | --- |
| Root | `value`, `defaultValue` | Controlled / uncontrolled code string |
| Root | `length` | `6` (range `1–32`) |
| Root | `disabled`, `readOnly`, `name`, `ariaLabel` | Interaction state, field name, and accessible label |
| Root | `valueChange`, `completed` | Value proposal event / emitted once per accepted complete code |
| Input / Control | — | Standalone text editor / Field- and Form-integrated control |
| Slot / Separator | — | Passive character display cell and visual separator |
