Liquid Glass Input OTP uses one real text input to preserve native selection, paste, deletion, IME composition, and `one-time-code` autofill while projecting characters into passive visual `Slot` cells. Designed for the content layer so slots never stack glass-on-glass inside surrounding glass sheets, cells pair concentric radii, specular inset hairlines, and readable non-opacity disabled states.

Available starting in `0.3.0-rc.1` and later releases.

## Usage

```tsx
import {
  LiquidGlassInputOtpRoot,
  LiquidGlassInputOtpInput,
  LiquidGlassInputOtpSlot,
  LiquidGlassInputOtpSeparator,
} from '../proto-ui/components/react';

export function LiquidGlassVerificationCode() {
  return (
    <LiquidGlassInputOtpRoot length={6}>
      <LiquidGlassInputOtpInput placeholder="123456" />
      <div className="inline-flex items-center gap-1.5">
        <LiquidGlassInputOtpSlot index={0} />
        <LiquidGlassInputOtpSlot index={1} />
        <LiquidGlassInputOtpSlot index={2} />
      </div>
      <LiquidGlassInputOtpSeparator>–</LiquidGlassInputOtpSeparator>
      <div className="inline-flex items-center gap-1.5">
        <LiquidGlassInputOtpSlot index={3} />
        <LiquidGlassInputOtpSlot index={4} />
        <LiquidGlassInputOtpSlot index={5} />
      </div>
    </LiquidGlassInputOtpRoot>
  );
}
```

- **Content-layer clarity & concentric radii**: Input and slots stay optically neutral so they never stack glass-on-glass on floating sheets. Slots use concentric `rounded-xl` corners inside `rounded-2xl` surfaces with specular inset hairlines and elevated active focus rings.
- **Single input and active slot**: Editing lives in one accessible `Input`; `Slot` cells are passive `aria-hidden` readouts that track the real caret or selection range while focused and editable.
- **Field and Form integration**: Swap `Input` for `Control` inside [Field](/en/ui-libraries/liquid-glass/field/) or [Form](/en/ui-libraries/liquid-glass/form/) to bridge `FieldLabel`, validation error state, serialization, and reset.
