Liquid Glass Carousel combines an equal-size slide strip, a continuously scrollable viewport, and Previous/Next controls. Pointer/touch dragging, wheel, trackpad, scrollbar scrolling, and keyboard navigation all share the same snapping index model.

## Usage

- **Responsive capacity**: `slidesPerView` caps the number of equal-size items shown (default `1`) and `minSlideSize` sets their minimum logical pixel extent (default `0`). The final snap aligns flush with the strip end without empty trailing space.
- **Controlled index**: pass `index` to control the committed snap position and listen to `indexChange` for proposals. Drag previews do not mutate the committed index until accepted by your state.
- **Axis and looping**: `orientation="vertical"` requires an explicitly bounded viewport height. Horizontal `direction="rtl"` mirrors drag and arrow keys while preserving logical item order. `loop` wraps index requests between the first and last reachable stops without cloning slides.
- Carousel targets equal-size slides and user-driven navigation (no autoplay or variable-width slides).

## API

| Part | Prop / State | Defaults and notes |
| --- | --- | --- |
| Root | `slidesPerView` | `1`; maximum equal-size items visible at once |
| Root | `minSlideSize` | `0`; minimum slide extent in logical host pixels |
| Root | `index` | Controlled snap index; emits `indexChange` proposals |
| Root | `orientation`, `direction`, `loop` | Scroll axis, reading direction, and end-to-end index wrapping |
| Root (exposed) | `visibleSlides`, `maxIndex` | Observed viewport capacity and maximum reachable index |
| Viewport (exposed) | `dragging`, `scrolling`, `scrollPosition` | Drag/scroll activity and normalized scroll progress |
| Slide (exposed) | `current`, `hidden` | Active snap marker and offscreen visibility (layout extent is preserved) |
