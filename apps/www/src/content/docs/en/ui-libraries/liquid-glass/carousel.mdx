Liquid Glass Carousel separates solid, vivid slide content from floating circular Liquid Glass navigation controls. Slides stay crisp and unobstructed without glass-on-glass stacking, while Previous/Next controls project adaptive Liquid Glass chrome (`regular` / `prominent`) with automatic opaque fallback for reduced-transparency and high-contrast preferences.

## Installation

Available starting in `0.3.0-rc.1` and later releases.

## Usage

```tsx
import {
  LiquidGlassCarouselRoot,
  LiquidGlassCarouselViewport,
  LiquidGlassCarouselSlide,
  LiquidGlassCarouselPrevious,
  LiquidGlassCarouselNext,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <LiquidGlassCarouselRoot className="mx-auto w-full max-w-md">
      <LiquidGlassCarouselViewport>
        <LiquidGlassCarouselSlide>1</LiquidGlassCarouselSlide>
        <LiquidGlassCarouselSlide>2</LiquidGlassCarouselSlide>
        <LiquidGlassCarouselSlide>3</LiquidGlassCarouselSlide>
      </LiquidGlassCarouselViewport>
      <LiquidGlassCarouselPrevious aria-label="Previous slide">‹</LiquidGlassCarouselPrevious>
      <LiquidGlassCarouselNext aria-label="Next slide">›</LiquidGlassCarouselNext>
    </LiquidGlassCarouselRoot>
  );
}
```

- **Material & hierarchy**: `Previous` and `Next` float over the slide edge as `variant="regular"` circular Liquid Glass buttons; set `variant="prominent"` for an emphasized forward action or `material="opaque"` to force the opaque fallback surface.
- **Concentric geometry & responsive capacity**: `Viewport` uses `rounded-xl` to nest concentric `rounded-lg` cards inside; configure `slidesPerView` and `minSlideSize` for responsive multi-item layouts.
- **Orientation & controlled index**: Supports `orientation="vertical"` (with an explicit bounded viewport height), `direction="rtl"`, `loop={true}`, and controlled `index` / `indexChange`.

### Exposed states, methods, and events

- **Root**: states `index`, `slideCount`, `visibleSlides`, `maxIndex`; method `requestIndex(next)`; event `indexChange`.
- **Viewport**: states `focusVisible`, `dragging`, `scrolling`, `scrollPosition`.
- **Slide**: states `current`, `hidden`, `basis`, `minSize`.
