Liquid Glass Date Picker composes Popover and Calendar into a dropdown date selector supporting single-date, multiple-date, and range modes. `open`, selection values, and the visible `month` can each be controlled independently.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

- **Modes**: pass `mode="range"` with `range` / `defaultRange`, or `mode="multiple"` with `values` / `defaultValues`. All date bounds, unavailable dates, count limits, and night limits follow [Calendar](/en/ui-libraries/liquid-glass/calendar/).
- **Auto-close behavior**:
  - Single selection requests closing the popover once the selection is accepted.
  - Range selection keeps the popover open after the first endpoint and requests one close once the second endpoint completes the range.
  - Multiple selection stays open for consecutive toggles; dismiss normally via Escape, outside press, or a close trigger.
  - Rejected controlled requests keep the popover open, and external value updates alone do not dismiss it.
- **Value formatting**: `Value` renders a single `YYYY-MM-DD` date, a comma-separated sorted list, `from …` for an incomplete range, `from – to` for a complete range, or `placeholder` when empty. Dismissal and focus return follow Popover.

## API

| Prop                      | Description                                      |
| ------------------------- | ------------------------------------------------ |
| `open`, `defaultOpen`     | Controlled / uncontrolled popover visibility     |
| `mode`                    | `'single'` (default), `'multiple'`, or `'range'` |
| `value`, `defaultValue`   | Single-date selection                            |
| `values`, `defaultValues` | Multiple-date array                              |
| `range`, `defaultRange`   | Range selection `{ from?, to? }`                 |
| `month`, `defaultMonth`   | Visible calendar month (`YYYY-MM`)               |
| `placeholder`             | Fallback text shown in `Value` when empty        |
| `disabled`, `readOnly`    | Disables interaction or blocks selection edits   |

See [Calendar](/en/ui-libraries/liquid-glass/calendar/) for the full set of calendar props, callbacks, and grid parts.
