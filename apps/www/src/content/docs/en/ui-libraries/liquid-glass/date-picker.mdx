Liquid Glass Date Picker pairs a concentric pill trigger with a single floating `regular` Liquid Glass calendar popover and circular day cells, supporting single, multiple, and range modes with an explicit `material="opaque"` opt-out.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. `Date Picker` composes Liquid Glass `Popover` and `Calendar` parts directly from the workspace.

## Usage

```tsx
import {
  LiquidGlassDatePickerRoot,
  LiquidGlassDatePickerTrigger,
  LiquidGlassDatePickerValue,
  LiquidGlassDatePickerContent,
  LiquidGlassDatePickerDay,
  LiquidGlassCalendarCaption,
  LiquidGlassCalendarPrevious,
  LiquidGlassCalendarHeading,
  LiquidGlassCalendarNext,
  LiquidGlassCalendarGrid,
  LiquidGlassCalendarWeekdays,
  LiquidGlassCalendarWeekday,
  LiquidGlassCalendarRow,
} from '../proto-ui/components/react';

export function LiquidGlassDatePickerExample() {
  return (
    <LiquidGlassDatePickerRoot defaultMonth="2026-10">
      <LiquidGlassDatePickerTrigger className="w-56" variant="regular">
        <LiquidGlassDatePickerValue placeholder="Pick a date" />
        <span aria-hidden="true">▾</span>
      </LiquidGlassDatePickerTrigger>
      <LiquidGlassDatePickerContent side="bottom" align="start" sideOffset={6} material="auto">
        <LiquidGlassCalendarCaption>
          <LiquidGlassCalendarPrevious a11yLabel="Previous month">‹</LiquidGlassCalendarPrevious>
          <LiquidGlassCalendarHeading />
          <LiquidGlassCalendarNext a11yLabel="Next month">›</LiquidGlassCalendarNext>
        </LiquidGlassCalendarCaption>
        <LiquidGlassCalendarGrid>
          <LiquidGlassCalendarWeekdays>
            {[0, 1, 2, 3, 4, 5, 6].map((offset) => (
              <LiquidGlassCalendarWeekday key={offset} offset={offset} />
            ))}
          </LiquidGlassCalendarWeekdays>
          {[0, 1, 2, 3, 4, 5].map((row) => (
            <LiquidGlassCalendarRow key={row} index={row}>
              {[0, 1, 2, 3, 4, 5, 6].map((col) => (
                <LiquidGlassDatePickerDay key={col} offset={row * 7 + col} />
              ))}
            </LiquidGlassCalendarRow>
          ))}
        </LiquidGlassCalendarGrid>
      </LiquidGlassDatePickerContent>
    </LiquidGlassDatePickerRoot>
  );
}
```

- **Single-layer material and concentric geometry**: Only the open `DatePickerContent` requests the `regular` Liquid Glass material (never stacking glass-on-glass). `DatePickerTrigger` uses pill geometry with `regular` and `prominent` prominence levels, while day cells sit flat inside the `rounded-2xl` surface as circular targets.
- **Accessibility fallbacks**: When Reduced Transparency or Increased Contrast is active—or when `material="opaque"` is set—the popup falls back to its crisp `bg-secondary` / `text-secondary-foreground` surface. Disabled controls avoid `opacity-*` dimming to keep fallback contrast readable, and Reduced Motion disables popup entrance/exit animations.
- **Selection modes and dismissal**: Single selection and completed ranges request closing the popup; multiple mode stays open for consecutive picks. Date constraints inherit from [Calendar](/en/ui-libraries/liquid-glass/calendar/).
