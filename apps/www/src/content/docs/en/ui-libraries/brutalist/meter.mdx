Brutalist Meter displays a scalar measurement within a known range—such as storage usage, quota, or score—using 5px `rounded-base` geometry, 2px black borders, DM Sans medium typography, instant snap updates, and distinct `primary`, `canary`, and `destructive` status fills.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the meter parts from `@proto.ui/prototypes-brutalist/meter`:

```ts
import {
  meterRoot,
  meterLabel,
  meterTrack,
  meterIndicator,
  meterValue,
} from '@proto.ui/prototypes-brutalist/meter';
```

## Usage

```tsx
import { AdaptToReact } from '@proto.ui/adapter-react';
import {
  meterRoot,
  meterLabel,
  meterTrack,
  meterIndicator,
  meterValue,
} from '@proto.ui/prototypes-brutalist/meter';

const MeterRoot = AdaptToReact(meterRoot);
const MeterLabel = AdaptToReact(meterLabel);
const MeterTrack = AdaptToReact(meterTrack);
const MeterIndicator = AdaptToReact(meterIndicator);
const MeterValue = AdaptToReact(meterValue);

export function BrutalistStorageMeter() {
  return (
    <MeterRoot value={32} min={0} max={100} low={50} high={80} optimum={20} valueText="32%">
      <div className="flex items-center justify-between gap-2">
        <MeterLabel>Storage used</MeterLabel>
        <MeterValue />
      </div>
      <MeterTrack>
        <MeterIndicator />
      </MeterTrack>
    </MeterRoot>
  );
}
```

### Parts and thresholds

- **Root**: Manages `value`, finite `[min, max]` bounds, and optional `low`, `high`, and `optimum` thresholds. Values clamp to `[min, max]`, and equal bounds produce `0` percentage.
- **Label / Value**: Preserve authored text casing with DM Sans 500 typography; `Value` uses `tabular-nums` and displays `valueText` or the clamped numeric reading.
- **Track / Indicator**: The track uses `rounded-base`, `border-2 border-black`, and `bg-secondary-background`; the indicator maps `optimal` (`bg-primary`), `suboptimal` (`bg-canary`), and `critical` (`bg-destructive`) with instant snap updates.
- Meter is a passive readout (`role="meter"`) with no keyboard tab stop; all parts stay synchronized and expose `value`, `percentage`, `indeterminate`, and `status`.
