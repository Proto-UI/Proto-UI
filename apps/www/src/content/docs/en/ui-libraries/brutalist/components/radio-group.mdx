Radio Group lets users choose one option from a mutually exclusive set. Its Brutalist presentation lays out 16px circular 2px-bordered options in a vertical grid (`grid gap-2`), marking the checked option with a filled inner dot, dark-mode contrast adaptation, and an offset focus ring.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

<InstallCommandCard command="npx @proto.ui/cli@latest add wc brutalist-radio-group" manager="npm" />

Replace `wc` with `react`, `vue`, or `vue2` to generate framework facades, or import `Root`, `Item`, and `Indicator` from `@proto.ui/prototypes-brutalist/radio-group`.

## Usage

```tsx
import {
  BrutalistLabelRoot,
  BrutalistRadioGroupIndicator,
  BrutalistRadioGroupItem,
  BrutalistRadioGroupRoot,
} from '../proto-ui/components/react';

export function RadioGroupUsage() {
  return (
    <BrutalistRadioGroupRoot defaultValue="comfortable" a11yLabel="Display density">
      <div className="flex items-center gap-3">
        <BrutalistRadioGroupItem value="default">
          <BrutalistRadioGroupIndicator />
        </BrutalistRadioGroupItem>
        <BrutalistLabelRoot>Default</BrutalistLabelRoot>
      </div>
      <div className="flex items-center gap-3">
        <BrutalistRadioGroupItem value="comfortable">
          <BrutalistRadioGroupIndicator />
        </BrutalistRadioGroupItem>
        <BrutalistLabelRoot>Comfortable</BrutalistLabelRoot>
      </div>
      <div className="flex items-center gap-3">
        <BrutalistRadioGroupItem value="compact">
          <BrutalistRadioGroupIndicator />
        </BrutalistRadioGroupItem>
        <BrutalistLabelRoot>Compact</BrutalistLabelRoot>
      </div>
    </BrutalistRadioGroupRoot>
  );
}
```

### Anatomy & Interaction

```text
BrutalistRadioGroupRoot
├── BrutalistRadioGroupItem
│   └── BrutalistRadioGroupIndicator
└── BrutalistRadioGroupItem
    └── BrutalistRadioGroupIndicator
```

- `Root`: Manages the selected value, item order, roving arrow-key focus, disabled/read-only state, and `radiogroup` accessibility semantics.
- `Item`: Renders each 16px circular 2px-bordered `radio` option, switching ring and dot color to theme foreground in dark mode so contrast stays crisp on dark surfaces.
- `Indicator`: Passive visual mark rendering a `size-2` filled circular dot (`aria-hidden`) when its parent `Item` is checked.
- **Keyboard & Read-Only**: Arrow keys wrap and select across enabled items, and `Space` selects the focused item. `readOnly` keeps roving focus active while blocking updates; `disabled` removes focus participation.
- **Form Composition**: Compose `fieldRadioGroup` from `@proto.ui/prototypes-brutalist/field` inside `FormField` for validation, error linkage, and `resetValue()`. See the [Form choice recipe](../../form/).

### Indicator, Events & Methods

- **Indicator**: No props.
- **Events**: `valueChange` (`{ value: string }`) on Root; `select` (`{ value: string }`) on Item.
- **Methods**: `requestValue(value)`, `resetValue()`, `focusFirst()`, `focusLast()`, `focusNext()`, `focusPrev()`, `focusSelected()`, `focusSelf()` on Root.
