Brutalist Collapsible expands and collapses a single content section with `rounded-base` geometry, crisp 2px borders, and press-only hard-shadow snap, built on the [Base Collapsible](/en/ui-libraries/base/collapsible/) protocol.

## Installation

Available from workspace source and the CLI target:

<InstallCommandCard command="npx @proto.ui/cli@latest add wc brutalist-collapsible" manager="npm" />

Replace `wc` with `react`, `vue`, or `vue2` to generate the facade for your framework, or import the parts directly from `@proto.ui/prototypes-brutalist/collapsible`:

```ts
import {
  collapsibleRoot,
  collapsibleTrigger,
  collapsibleContent,
} from '@proto.ui/prototypes-brutalist/collapsible';
```

## Usage

```tsx
import {
  BrutalistCollapsibleRoot,
  BrutalistCollapsibleTrigger,
  BrutalistCollapsibleContent,
} from '@/components/ui/collapsible';

export function Example() {
  return (
    <BrutalistCollapsibleRoot>
      <BrutalistCollapsibleTrigger>Product details</BrutalistCollapsibleTrigger>
      <BrutalistCollapsibleContent>
        This panel expands and collapses to reveal additional content.
      </BrutalistCollapsibleContent>
    </BrutalistCollapsibleRoot>
  );
}
```

### Parts and Depth Grammar

```text
CollapsibleRoot
├── CollapsibleTrigger
└── CollapsibleContent
```

- **Raised-control feedback**: `default` and `neutral` triggers rest with a 4px hard shadow and settle `+4px, +4px` with `shadow-none` on press only (hover stays stationary without lift).
- **Theme-aware dark mode**: borders and hard shadows repaint via theme CSS variables across light and dark modes.
- **Controlled and mount lifecycle**: pass `open` and respond to `openChange` (`{ open, reason }`) for controlled mode; `Content` unmounts when closed unless `keepMounted={true}` is set.
