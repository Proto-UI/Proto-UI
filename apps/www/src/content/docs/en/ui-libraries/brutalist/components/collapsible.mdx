## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

- **CLI target**: `proto-ui add <react|vue|vue2|wc> brutalist-collapsible`
- **Package exports**:

```ts
import {
  collapsibleRoot,
  collapsibleTrigger,
  collapsibleContent,
} from '@proto.ui/prototypes-brutalist/collapsible';
```

## Usage

### Parts

Place one `Trigger` and one `Content` inside each `Root`. Nested and sibling collapsibles maintain independent state:

- **Root**: Manages open state via controlled `open` or uncontrolled `defaultOpen`, plus `disabled` (which blocks toggles without closing already-open content).
- **Trigger**: Accessible toggle button in the natural `Tab` order supporting `Enter` and `Space` activation.
- **Content**: Renders the collapsible panel body. Unmounts content when closed by default (set `keepMounted` to keep it mounted while hidden). Wraps long labels and shrinks cleanly within narrow containers; leave surrounding room for the focus ring and hard shadow.

### Controlled state

Pass `open` for controlled mode and update it in response to `openChange` (payload `{ open, reason }`). Ignored requests leave the panel unchanged.

## API

### Root

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}

    { name: 'disabled', type: 'boolean', default: 'false' },

Pass `open: boolean` to enable controlled mode.

### Other parts

- **Trigger**: `disabled?: boolean` (default `false`)
- **Content**: `keepMounted?: boolean` (default `false`)

### Methods and events

- **Root methods**: `openCollapsible()`, `close()`, `toggle()`; **Trigger method**: `focusSelf()`
- **Events**: `openChange` with payload `{ open, reason }`
