## Installation

Currently available from workspace source and not yet included in the 0.2.0 stable release; import the prototypes directly from `@proto.ui/prototypes-brutalist/menubar` and adapt them for your target runtime.

## Usage

```tsx
import {
  BrutalistMenubarRoot,
  BrutalistMenubarTrigger,
  BrutalistMenubarContent,
  BrutalistMenubarItem,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <BrutalistMenubarRoot a11yLabel="Workspace menu">
      <BrutalistMenubarTrigger value="file">File</BrutalistMenubarTrigger>
      <BrutalistMenubarContent value="file" a11yLabel="File menu">
        <BrutalistMenubarItem value="new-tab">New Tab</BrutalistMenubarItem>
        <BrutalistMenubarItem value="print">Print...</BrutalistMenubarItem>
      </BrutalistMenubarContent>
    </BrutalistMenubarRoot>
  );
}
```

### Composition

```text
MenubarRoot
├── MenubarTrigger (value="file")
├── MenubarContent (value="file")
│   ├── MenubarItem
│   └── MenubarItem
├── MenubarTrigger (value="edit")
└── MenubarContent (value="edit")
    └── MenubarItem
```

- `Root`: Framed bar container with 2px black border and 4px hard shadow managing active panel state and roving focus.
- `Trigger`: Top-level menu button paired with `Content` by `value`, highlighting with `bg-main` and a black border when active.
- `Content`: Floating menu panel following the design contract (`rounded-base`, 2px black border, and 3px foreground shadow).
- `Item`: Flat interactive menu row supporting `inset` alignment and `variant="destructive"` styling.

### Keyboard and accessibility

- The bar participates as a single roving `Tab` stop; `ArrowLeft` and `ArrowRight` move between triggers.
- `ArrowDown` and `ArrowUp` open a panel and move vertically through items, with typeahead character matching.
- Pressing `Escape` dismisses the open panel and returns focus to its matching `Trigger`; outside clicks and command selection also close the menu unless `closeOnSelect={false}`.
