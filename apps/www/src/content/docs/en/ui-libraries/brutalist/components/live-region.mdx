Brutalist Live Region is a single-part accessible announcement container that relays dynamic text updates to screen readers with clean, unboxed typography.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

- **CLI target**: `proto-ui add <react|vue|vue2|wc> brutalist-live-region`
- **Package exports**: import `Root` from `@proto.ui/prototypes-brutalist` or `@proto.ui/prototypes-brutalist/live-region`

## Usage

- **Politeness level**: `politeness="polite"` (default) sets `role="status"` and `aria-live="polite"` for routine status updates; `politeness="assertive"` sets `role="alert"` and `aria-live="assertive"` for urgent alerts.
- **Atomic updates**: `atomic` (default `true`) sets `aria-atomic` so the full announcement is read together. Update your children directly to deliver a new announcement.
- The container stays out of the keyboard tab order and applies only `min-w-0 max-w-full text-foreground` so text remains readable in light and dark modes.
