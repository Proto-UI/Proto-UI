Brutalist Live Region is a single-part accessible announcement container inheriting `role`, `aria-live`, and `aria-atomic` semantics from [Base Live Region](/en/ui-libraries/base/live-region/) with clean, unboxed typography.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Brutalist Live Region is not a `proto-ui add` CLI target — import it directly from `@proto.ui/prototypes-brutalist` or `@proto.ui/prototypes-brutalist/live-region`:

```ts
import { BrutalistLiveRegionRoot } from '@proto.ui/prototypes-brutalist/live-region';
```

## Usage

```tsx
import { AdaptToReact } from '@proto.ui/adapter-react';
import { BrutalistLiveRegionRoot } from '@proto.ui/prototypes-brutalist/live-region';

const LiveRegionRoot = AdaptToReact(BrutalistLiveRegionRoot);

export function StatusAnnouncement({ message }: { message: string }) {
  return (
    <LiveRegionRoot politeness="polite" atomic>
      {message}
    </LiveRegionRoot>
  );
}
```

- **Politeness level**: `politeness="polite"` (default) sets `role="status"` and `aria-live="polite"` for routine status updates; `politeness="assertive"` sets `role="alert"` and `aria-live="assertive"` for urgent alerts.
- **Atomic updates**: `atomic` (default `true`) sets `aria-atomic` so the full announcement is read together; set `false` to announce only changed descendant nodes. Update your children directly to deliver a new announcement.
- **Restrained presentation**: The container stays out of the keyboard tab order and applies only `min-w-0 max-w-full text-foreground` with no border, shadow, or notification chrome so text remains readable in light and dark modes.
