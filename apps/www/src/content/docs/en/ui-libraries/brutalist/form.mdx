Brutalist Form orchestrates explicitly registered `FormField` entries, validates all enabled fields, and emits form values keyed by field name on `submit`, with built-in support for async validation and reset.

- **CLI target**: `proto-ui add <react|vue|vue2|wc> brutalist-form`

## Usage

### Parts

Form is composed of `Root`, `Field` (`FormField`), `Submit` (`FormSubmit`), and `Reset` (`FormReset`):

- **Root**: Collects registered `FormField` items, runs built-in and async validation, and emits `submit` with named values when all enabled fields pass. Disabled fields are omitted, duplicate field names block serialization, and `disabled` cascades to contained fields.
- **Field**: Connects a supported control to the form using `name` as its submission key.
- **Submit / Reset**: Handle pointer and keyboard activation with Brutalist button styling, exposing `disabled`, `hovered`, `pressed`, `focused`, `focusVisible`, and `focusSelf()`.

Pressing `Enter` in a focused single-line `Field`, `Number Field`, or `Input OTP` triggers implicit submission (ignoring IME composition, modifier keys, and key repeats). `requestReset()` restores uncontrolled initial values, requests initial values from controlled owners, cancels pending edits and validation, and emits `reset`; `resetValidation()` clears validation state only.

When fields use external async validation, submission waits for each active `requestId` to resolve via `resolveValidation`. Stale results from edited, reset, read-only, or superseded submissions are automatically discarded. Nested `Fieldset` groups can disable sections at once and omit those fields from submitted values.

Import `fieldCheckbox`, `fieldRadioGroup`, and `fieldSwitch` from `brutalist-field`, place them inside `FormField`, and pair them with Brutalist Checkbox Indicator, Radio Items/Indicators, or Switch Thumb:

- `fieldCheckbox` submits its boolean `checked` value (mixed display does not satisfy `required` when `checked` is `false`).
- `fieldRadioGroup` submits the selected string value (an empty string counts as missing when `required`).
- In read-only mode, labels still focus their control and Radio arrow keys still rove focus without proposing value changes.
