Brutalist Form orchestrates explicitly registered `FormField` entries, validates all enabled fields, and emits form values keyed by field name on `submit`, with built-in support for async validation and reset.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

```bash
proto-ui add <react|vue|vue2|wc> brutalist-form
```

## Usage

```tsx
import {
  BrutalistFormRoot,
  BrutalistFormField,
  BrutalistFormSubmit,
  BrutalistFormReset,
  BrutalistFieldLabel,
  BrutalistFieldControl,
  BrutalistFieldError,
} from '../proto-ui/components/react';

export function ExampleBrutalistForm() {
  return (
    <BrutalistFormRoot ariaLabel="Profile form" onSubmit={({ values }) => console.log(values)}>
      <BrutalistFormField name="username" required>
        <BrutalistFieldLabel>Username</BrutalistFieldLabel>
        <BrutalistFieldControl placeholder="ada_lovelace" />
        <BrutalistFieldError />
      </BrutalistFormField>
      <div className="flex items-center gap-2">
        <BrutalistFormSubmit>Submit</BrutalistFormSubmit>
        <BrutalistFormReset>Reset</BrutalistFormReset>
      </div>
    </BrutalistFormRoot>
  );
}
```

### Anatomy & Behavior

- **Root**: Collects registered `FormField` items, runs synchronous and async validation, and emits `submit` with named values once all enabled fields pass. Disabled fields are excluded, duplicate field names throw `FORM_DUPLICATE_NAME` during serialization, and `disabled` cascades to contained fields.
- **Field**: Extends `FieldRoot` with a submission `name`, using DM Sans typography and high-contrast error ink.
- **Submit / Reset**: Apply Brutalist 2px black borders and 4px hard shadows, supporting pointer/keyboard activation and live `prefers-reduced-motion` timing.
- **Implicit Enter submit & reset**: Pressing `Enter` in a focused single-line `Field`, `Number Field`, or `Input OTP` triggers submission; `requestReset()` restores uncontrolled initial values and proposes resets to controlled owners, while `resetValidation()` clears validation state only.
