Resizable divides a container into two or more percentage-sized panels separated by indexed drag handles, with full keyboard support, collapsible stops, and independent nested layouts.

## Usage

### Anatomy & Indexing

- `Root`: Manages percentage panel sizes, constraints, orientation, and controlled/uncontrolled state.
- `Panel`: Indexed `0..N-1`; exposes its dimensionless size to `--pui-size` so static `flex-basis` CSS rules drive layout without runtime-generated CSS tokens.
- `Handle`: Indexed `0..N-2`; references its preceding panel and resizes only its adjacent pair (default accessible name: `Resize panels`).

### Multi-Panel Sizing & Constraints

- Pass `sizes` or `defaultSizes` on `Root` for a complete percentage vector (normalized to sum to `100`). The two-panel `value` / `defaultValue` props remain supported, with `sizes` taking precedence when provided.
- Use `constraints` to configure per-panel `min` (`0`), `max` (`100`), `collapsible` (`false`), and `collapsedSize` (`0`). Infeasible layouts ignore invalid updates and keep the previous valid state.
- Dragging a handle preserves the combined total of its adjacent pair and leaves every other panel untouched. Collapsing acts as a discrete stop subject to the adjacent panel's `max`.
- Nested `Root` layouts manage independent ratios, constraints, and orientations (for example, a vertical split inside a three-panel horizontal layout). Pointer drag math normalizes against panel border-box extents, excluding fixed handle widths.

### Keyboard & Controlled Mode

- Pointer drag, arrow keys, `Home`/`End`, `Shift`-accelerated steps, and collapse share one constrained request pipeline.
- Read `sizes` or invoke `requestResize(index, nextSize, commit)` / `requestSizes(nextSizes, commit)`. Both `sizesChange` and `sizesCommit` emit `{ sizes }`; cancelling a gesture emits no commit.
- Pass `sizes` for controlled mode: update it with the proposed vector to accept or keep the previous value to decline. Panels and ARIA attributes always reflect the committed sizes.

Other parts:

- **Panel**: `index` defaults to `0`.
- **Handle**: Indexed `0..N-2` for the preceding panel; default accessible name is `Resize panels`.
