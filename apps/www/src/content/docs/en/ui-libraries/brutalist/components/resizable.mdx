## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototypes directly from `@proto.ui/prototypes-brutalist/resizable` and adapt them for your target runtime:

```ts
import {
  resizableRoot,
  resizablePanel,
  resizableHandle,
} from '@proto.ui/prototypes-brutalist/resizable';
```

## Usage

```tsx
import {
  BrutalistResizableRoot,
  BrutalistResizablePanel,
  BrutalistResizableHandle,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <BrutalistResizableRoot defaultSizes={[50, 50]} className="h-56 w-full max-w-md">
      <BrutalistResizablePanel index={0}>One</BrutalistResizablePanel>
      <BrutalistResizableHandle index={0} withHandle />
      <BrutalistResizablePanel index={1}>Two</BrutalistResizablePanel>
    </BrutalistResizableRoot>
  );
}
```

### Composition

```text
BrutalistResizableRoot (variant="default" | "nested")
├── BrutalistResizablePanel (index: 0)
├── BrutalistResizableHandle (index: 0, withHandle?)
└── BrutalistResizablePanel (index: 1)
```

- Top-level `Root` renders the `rounded-base` 2px black frame and 4px hard shadow by default; pass `variant="nested"` on inner split groups to keep them borderless and shadowless.
- Place `N` `Panel` parts (`index: 0..N-1`) and `N - 1` `Handle` parts (`index: 0..N-2`). Each panel exposes `--pui-size` for static `flex-basis` sizing.
- `Handle` paints a 2px black divider with directional resize cursors; enable `withHandle` to show an accent-filled, black-bordered grip badge.
- Supports pointer drag, arrow keys, `Shift` 10× steps, `Home` / `End`, and `Enter` collapsing. Pass `sizes` for controlled mode and handle `sizesChange` / `sizesCommit`.

### Panel & Handle

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}

- **Exposed states**: Root exposes `value` and `sizes`; Panel exposes `size`; Handle exposes `value`, `focusVisible`, and `disabled`.
- **Events & methods**: Root emits `sizesChange`, `sizesCommit`, `valueChange`, and `valueCommit`, and exposes `requestResize(index, next, commit?)`, `requestSizes(next, commit?)`, `requestValue(next, commit?)`, and `cancelResize()`.
