Brutalist `Label` inherits the Base Label protocol with passive Brutalist typography from the [Brutalist Design Contract](../../design-contract/) (DM Sans 500, no shadow, no motion), pairing accessible naming and click activation with controls through an explicit reference.

> For form fields, use the [Field](../../field/) component for automatic `FieldLabel`, `FieldDescription`, and `FieldError` wiring and validation.

## Usage

Create one stable reference per pair with `createControlLabelRef()` from `@proto.ui/core` and pass it through the adapter association channel:

```tsx
import { useMemo } from 'react';
import { createControlLabelRef } from '@proto.ui/core';
import {
  BrutalistCheckboxIndicator,
  BrutalistCheckboxRoot,
  BrutalistLabelRoot,
} from '../proto-ui/components/react';

export function TermsCheckbox() {
  const termsRef = useMemo(() => createControlLabelRef(), []);

  return (
    <div className="flex items-center gap-2">
      <BrutalistCheckboxRoot instanceAssociations={{ controlLabel: termsRef }}>
        <BrutalistCheckboxIndicator />
      </BrutalistCheckboxRoot>
      <BrutalistLabelRoot instanceAssociations={{ controlLabel: termsRef }}>
        Accept terms and conditions
      </BrutalistLabelRoot>
    </div>
  );
}
```

In Web Components, bind both elements with `setElementAssociations()` from `@proto.ui/adapter-web-component`:

```ts
import { createControlLabelRef } from '@proto.ui/core';
import { setElementAssociations } from '@proto.ui/adapter-web-component';

const termsRef = createControlLabelRef();
setElementAssociations(checkboxEl, { controlLabel: termsRef });
setElementAssociations(labelEl, { controlLabel: termsRef });
```

### Naming, activation, and accessibility

- **`naming` (default `true`)**: Links the rendered `Label` as the target control's accessible name. If the target already sets a non-empty `ariaLabel` or `labelledBy`, set `naming={false}` for activation-only pairing.
- **`activation` (default `true`)**: Eligible clicks invoke the paired control's default operation (toggling `Checkbox`/`Switch`, selecting a `Radio Group Item`, or focusing `Input`/`Textarea`). Set `activation={false}` for a naming-only label.
- **`selection` (default `'policy'`)**: Actionable labels suppress accidental text selection by default; set `selection="text"` to keep copyable text.
- **Interaction boundaries**: `Label` adds no extra `Tab` stop, ignores nested interactive descendants, modified clicks, and drags, and remains a flat passive label without shadow or translation.

### Association helpers

- `createControlLabelRef()`: Imported from `@proto.ui/core` to create a stable one-to-one opaque reference.
- `instanceAssociations`: Adapter prop accepting `{ controlLabel: ref }` in React, Vue, and Vue 2.
- `setElementAssociations(element, { controlLabel: ref })`: Imported from `@proto.ui/adapter-web-component` for Web Components.
