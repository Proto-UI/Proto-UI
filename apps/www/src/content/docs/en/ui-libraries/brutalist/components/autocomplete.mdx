## Usage

### Parts

Autocomplete is composed of `Root`, `Input`, `Content`, `Item`, `Empty`, and `Trigger`:

- **Root**: Manages committed `value`, query `inputValue`, popup `open` state, built-in filtering, and keyboard looping. Each of `value`, `inputValue`, and `open` can be controlled independently.
- **Input**: Single-line editor that keeps focus during arrow-key navigation and skips selection during IME composition.
- **Content**: Anchored suggestion popup supporting placement, alignment, offset, and collision padding.
- **Item**: Individual suggestion matched case- and diacritic-insensitively across `textValue` and `keywords`. Selecting commits `textValue`; disabled or duplicate-valued items cannot be committed.
- **Empty**: Displayed when no items match the current query.
- **Trigger**: Optional toggle button for opening or closing the suggestion popup.

### Filtering and submission

- Pressing `Enter` commits the highlighted suggestion, or commits the current free text when no option is active.
- Set `filter={false}` to perform custom filtering in your application and render only matching `Item` elements.

Pass `value`, `inputValue`, or `open` to control each state independently.

### Other parts

- **Input**: `placeholder?: string`, `a11yLabel?: string`, `name?: string` (all default to `''`)
- **Content**: `side` (default `'bottom'`), `align` (default `'start'`), `sideOffset` (default `4`), `collisionPadding` (default `8`)
- **Item**: `value`, `textValue`, `keywords` (all default to `''`), `disabled?: boolean` (default `false`)
- **Empty**: No props
- **Trigger**: `disabled?: boolean` (default `false`)
