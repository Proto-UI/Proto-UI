## Usage

### Parts

Number Field consists of `Root`, `Label`, `Input`, `Control`, `Increment`, and `Decrement`:

- **Root**: Manages `number | null` via `value` / `defaultValue`, finite bounds `min` / `max` (default `0` / `100`), positive `step` (default `1`), formatting, and `disabled` / `readOnly` state.
- **Input**: Standalone text editor with `spinbutton` semantics. Allows incomplete drafts while typing and commits a valid number or restores the last accepted value on blur or `Enter`.
- **Control**: Use instead of `Input` inside `Field` or `FormField` to integrate `FieldLabel`, numeric validation, form serialization, and reset.
- **Increment / Decrement**: Stepper buttons sharing the same step logic as keyboard arrows.
- **Label**: Names the standalone input and doubles as a horizontal drag target when `scrub` is enabled.

### Formatting, empty values, and interaction

- **Keyboard**: `ArrowUp` / `ArrowDown` steps by `step`, holding `Shift` multiplies by 10, and `Home` / `End` jumps to `min` / `max`. Parsing, committing, stepping, and scrubbing pause automatically during IME composition.
- **Locale formatting**: Set `locale` and `formatOptions` for decimal, currency, or percent display and parsing. Display rounding never alters stored numeric precision; invalid formatting options set `formatInvalid` and fall back to ungrouped decimals.
- **Empty values**: Enable `allowEmpty` so clearing and committing the input requests `null`. Read `getValue(): number | null` and `empty` to inspect empty state. The first step from `null` initializes to snapped `0` within `[min, max]`.
- **Label scrubbing**: Enable `scrub` to drag across `Label` to adjust the value; `scrubSteps` (default `100`) sets how many steps equal one label width, and `direction="rtl"` reverses horizontal drag direction.
