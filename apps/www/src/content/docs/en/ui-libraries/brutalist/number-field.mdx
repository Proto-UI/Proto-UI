Brutalist Number Field follows the Brutalist design contract (DM Sans typography, `5px` `rounded-base` corners, `2px` borders, shadowless editable input paired with `2px` border-color offset steppers) while inheriting the complete Base Number Field protocol.

## Installation

Available starting in `0.3.0-rc.1` and later releases. Import the parts directly from `@proto.ui/prototypes-brutalist/number-field`:

```ts
import {
  numberFieldRoot,
  numberFieldLabel,
  numberFieldInput,
  numberFieldControl,
  numberFieldIncrement,
  numberFieldDecrement,
} from '@proto.ui/prototypes-brutalist/number-field';
```

## Usage

```tsx
<BrutalistNumberFieldRoot defaultValue={12} min={0} max={100} step={1} ariaLabel="Quantity">
  <BrutalistNumberFieldLabel>Quantity</BrutalistNumberFieldLabel>
  <BrutalistNumberFieldDecrement>
    <span aria-hidden="true">−</span>
    <span className="sr-only">Decrease Quantity</span>
  </BrutalistNumberFieldDecrement>
  <BrutalistNumberFieldInput />
  <BrutalistNumberFieldIncrement>
    <span aria-hidden="true">+</span>
    <span className="sr-only">Increase Quantity</span>
  </BrutalistNumberFieldIncrement>
</BrutalistNumberFieldRoot>
```

- **Parts**: `Root` owns the `number | null` value, bounds, formatting, and state; `Input` handles standalone editing (swap in `Control` inside `Field` or `FormField` for `FieldLabel`, invalid styling, serialization, and reset); `Label` names the editor and supports horizontal drag when `scrub` is enabled; `Increment` and `Decrement` share keyboard step logic.
- **Keyboard and IME**: `ArrowUp` / `ArrowDown` step by `step`, holding `Shift` multiplies by 10, and `Home` / `End` jump to `min` / `max`. IME composition automatically pauses parsing, commits, stepping, and scrubbing.
- **Formatting and nullability**: Use `locale` and `formatOptions` for decimal, currency, or percent display and parsing; set `allowEmpty` to allow clearing and committing `null`.
