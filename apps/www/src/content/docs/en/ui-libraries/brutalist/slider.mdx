Brutalist Slider lets users pick a single value or a multi-thumb range via pointer drag, touch, or keyboard stepping, with horizontal/vertical orientation and `Field` / `Form` integration.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

- **Package exports**: import scalar slider parts and multi-value `sliderValues*` parts from `@proto.ui/prototypes-brutalist/slider`

## Usage

### Single-value parts

The scalar slider consists of `Root`, `Label`, `Track`, `Indicator`, `Thumb`, `FieldThumb`, and `Value`:

- **Root**: Manages `value` / `defaultValue`, `min`, `max`, `step`, `disabled`, `readOnly`, `orientation`, and `direction`. Values snap to `step` from `min` and clamp within bounds.
- **Track / Indicator**: Handle pointer and touch dragging along the track and render the filled range.
- **Thumb**: Focusable slider thumb for standalone usage. Supports arrow keys, `Shift` ×10 stepping, `PageUp` / `PageDown`, and `Home` / `End` (with lateral arrows reversed in horizontal RTL).
- **FieldThumb**: Use instead of `Thumb` inside `Field` or `FormField` to integrate `FieldLabel` focusing, numeric validation, form serialization, and reset.
- **Label / Value**: Name the slider and display the current value.

Pass `value` for controlled mode. Dragging emits `valueChange`, release emits `valueCommit`, and cancelling restores the starting value in uncontrolled mode.

For range or multi-thumb sliders, import the `sliderValues*` parts from `@proto.ui/prototypes-brutalist/slider`:

- Pass an array such as `defaultValue={[20, 80]}` on `Values Root` and place one indexed `Thumb` per value inside `Values Track`.
- Clicking the track moves the nearest editable thumb, and grabbing a thumb preserves the pointer offset.
- `thumbCollisionBehavior` accepts `'push'`, `'swap'`, or `'none'`; `'swap'` transfers active focus when thumbs cross.
- `Values Root` integrates directly with `Field` / `FormField` as a grouped control reporting `number[]`, with `FieldLabel` focusing the first editable thumb.
