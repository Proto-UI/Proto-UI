Brutalist Slider renders single-value and multi-thumb range selection with 5px corners (`rounded-base`), 2px black borders, and crisp hard-shadow thumb feedback, supporting pointer drag, keyboard stepping, and `Field` / `Form` integration.

## Installation

Available starting in `0.3.0-rc.1` and later releases. Import scalar slider parts and multi-value `sliderValues*` parts from `@proto.ui/prototypes-brutalist/slider`.

## Usage

```tsx
import {
  BrutalistSliderRoot,
  BrutalistSliderTrack,
  BrutalistSliderIndicator,
  BrutalistSliderThumb,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <BrutalistSliderRoot defaultValue={33} min={0} max={100} step={1}>
      <BrutalistSliderTrack>
        <BrutalistSliderIndicator />
        <BrutalistSliderThumb />
      </BrutalistSliderTrack>
    </BrutalistSliderRoot>
  );
}
```

- **Scalar parts**: `Root`, `Label`, `Track`, `Indicator`, `Thumb`, `FieldThumb`, and `Value`. Use `FieldThumb` instead of `Thumb` inside `Field` or `FormField`.
- **Keyboard and controlled mode**: Supports arrow keys, `Shift` ×10 stepping, `PageUp`/`PageDown`, and `Home`/`End` (mirrored in horizontal RTL). Pass `value` for controlled mode with `valueChange` and `valueCommit` events.
- **Range and multi-thumb**: Compose `sliderValues*` parts and configure `thumbCollisionBehavior` as `'push'`, `'swap'`, or `'none'`.
