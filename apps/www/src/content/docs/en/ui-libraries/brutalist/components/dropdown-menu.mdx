## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

- **CLI target**: `proto-ui add <react|vue|vue2|wc> brutalist-dropdown` (generates `Root`, `Trigger`, `Content`, and `Item`)
- **Package exports**: import all parts—including `Group`, `Label`, `Separator`, and `Shortcut`—from `@proto.ui/prototypes-brutalist/dropdown`

## Usage

- **Groups and decorations**: `Group` and `Label` automatically wire accessible group naming, `Separator` divides sections, and `Shortcut` displays a keyboard hint (visual only; it does not register global keybindings).
- **Item variants and trigger indicators**: Set `variant="destructive"` on `Item` for destructive actions or `inset` to align with icon items. Enable `indicator` on `Trigger` to render a chevron indicator icon.

## API

Pass `open: boolean` to enable controlled mode.

The first five props belong to `Root`; `inset` and `variant` belong to `Item`; `indicator`, `indicatorIcon`, `indicatorSize`, and `indicatorStrokeWidth` belong to `Trigger`.

### Other parts

- **Content**: Supports Transition props, plus `side` (default `'bottom'`), `align` (default `'center'`), `sideOffset` (default `4`), `alignOffset` (default `0`), `collisionPadding` (default `0`), `avoidCollisions` (default `true`), and `excludeAnchorTranslation` (default `true`)
- **Item**: `disabled?: boolean` (default `false`), `value?: string` (default `''`), `textValue?: string` (default `''`), `closeOnCommit?: boolean` (inherits Root's `closeOnItemCommit` when omitted)
- **Group**: `a11yLabel?: string` (default `''`)
- **Label / Separator / Shortcut**: No props
