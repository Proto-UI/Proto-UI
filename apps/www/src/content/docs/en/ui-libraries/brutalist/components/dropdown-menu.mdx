## Installation

<InstallCommandCard command="npx @proto.ui/cli@0.2.0 add wc brutalist-dropdown" manager="npm" />

The published `0.2.0` CLI supports `wc`, `react`, and `vue`. For Vue 2.6 or the workspace examples below, install the CLI, Brutalist prototypes and adapter built from the same workspace revision. The CLI generates Root, Trigger, Content and Item. The workspace exports the additional Group, Label, Separator and Shortcut prototypes from `@proto.ui/prototypes-brutalist/dropdown`.

## Usage

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuGroup,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuSeparator,
  DropdownMenuShortcut,
  DropdownMenuTrigger,
} from '@/components/brutalist/dropdown-menu';
```

```tsx
<DropdownMenu>
  <DropdownMenuTrigger>Open</DropdownMenuTrigger>
  <DropdownMenuContent align="start" className="w-44">
    <DropdownMenuGroup>
      <DropdownMenuLabel>My Account</DropdownMenuLabel>
      <DropdownMenuItem value="profile">
        Profile
        <DropdownMenuShortcut>⇧⌘P</DropdownMenuShortcut>
      </DropdownMenuItem>
      <DropdownMenuItem value="billing">Billing</DropdownMenuItem>
    </DropdownMenuGroup>
    <DropdownMenuSeparator />
    <DropdownMenuItem value="logout">Log out</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```

- **Groups & decorative parts**: `Group` and `Label` automatically wire accessible group naming, `Separator` divides sections, and `Shortcut` displays a visual keyboard hint without registering global keybindings.
- **Anchored alignment**: `Content` defaults `excludeAnchorTranslation` to `true` so the popup anchors cleanly to the trigger's layout box without shifting when the trigger settles into its shadow.
