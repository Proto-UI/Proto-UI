## Grouped action composition (draft)

Group and Label provide a live accessible naming relationship; Separator and Shortcut are real passive parts. Shortcut only displays a hint and does not register a global binding. Decorative parts do not enter the action collection or add a press owner. The demo uses a 160px menu, grouped account/resources actions and a disabled API action. The real Invite users submenu is a separately pending protocol slice, not a simulated demo box. Checkbox/radio variants and complete native/GPUI, compiler, packed, visual and independent acceptance remain open.

## Package and generated facade

The package entry is `@proto.ui/prototypes-brutalist/dropdown`. The current source CLI registers `brutalist-dropdown` and generates Root, Trigger, Content, and Item for the selected host. Group, Label, Separator, and Shortcut are additional package exports; this CLI target does not generate their facades. Source registration does not establish installed-package or packed-consumer acceptance.

## API

Passing `open` selects controlled mode.

The first five props belong to Root. `inset` and `variant` belong to Item; `indicator`, `indicatorIcon`, `indicatorSize` and `indicatorStrokeWidth` belong to Trigger. Content accepts the Transition props and defaults `side` to `bottom`, `align` to `center`, `sideOffset` to `4`, `alignOffset` and `collisionPadding` to `0`, `avoidCollisions` to `true` and `excludeAnchorTranslation` to `true`. Item also defaults `disabled`, `value` and `textValue` to `false`, `''` and `''`; `closeOnCommit` has no default and falls back to the Root policy. Group defaults `a11yLabel` to `''`. Label, Separator and Shortcut have no props.
