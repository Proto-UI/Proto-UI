Brutalist Button pairs Base Button interaction and accessibility with Neo-Brutalist styling: 5px rounded corners (`rounded-base`), 2px black borders, 4px hard offset shadows, and settle-into-shadow feedback.

<InstallCommandCard
  commands={{
    npm: 'npx @proto.ui/cli@latest add wc brutalist-button',

Replace `wc` with `react`, `vue`, or `vue2` to generate the facade for your framework.

## Usage

```tsx
import { BrutalistButton } from '../proto-ui/components/react';

export function Example() {
  return <BrutalistButton>Button</BrutalistButton>;
}
```

Brutalist Button supports `solid`, `surface`, `destructive`, and `noShadow` variants alongside the `main`, `mint`, `lavender`, `coral`, and `sky` accent color pairs. Hover and press settle raised controls into their 4px shadow (snapping instantaneously under reduced motion), while keyboard focus displays a high-contrast offset focus ring.
