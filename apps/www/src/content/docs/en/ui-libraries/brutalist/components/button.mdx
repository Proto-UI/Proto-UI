The Button projection inherits Base Button semantics and adds only the Neo-Brutalist visual delta: 5px rounded geometry, hard borders, hard offset shadows, and flat fills.

</div>

## Usage

The Brutalist Button carries the Neo-Brutalist visual language: hard borders, offset shadows, and flat fills. The examples below use the family palette tokens (`mint`, `lavender`, `coral`, `sky`) to show the supported color range.

### Solid
