## Installation

Included in `@proto.ui/prototypes-brutalist@0.2.0`. Add it via the CLI target `brutalist-select`, or import directly from `@proto.ui/prototypes-brutalist/select`.

## Usage

### Trigger Appearance

The default `Trigger` renders flat with a 5px radius, 2px black border, and DM Sans 500 typography. When placing a Select alongside raised buttons (such as header Runtime and Style controls), set `appearance="elevated"` on `brutalist-select-trigger`:

- At rest, the trigger displays a 4px right/down hard black shadow; on hover or press, it shifts 4px right/down and flattens without adding a second press offset.
- Set `appearance="flat"` or omit the prop to restore the flat default. `size`, color contrast, focus ring, keyboard selection, and disabled behavior stay identical, and `Content` stays flat in both appearances.

## API

The first five props (`defaultOpen`, `defaultValue`, `disabled`, `readOnly`, `closeOnSelect`) belong to `Root` (pass `open` or `value` for controlled mode). `size` and `appearance` belong to `Trigger`:

    { name: 'size', type: "'sm' | 'default'", default: 'default' },
    { name: 'appearance', type: "'flat' | 'elevated'", default: 'flat' },
  ]}
/>

Other part props and defaults:

- **Trigger**: Also defaults `accessibleLabel` to `''`.
- **Value**: `placeholder` defaults to `''`.
- **Content**: Accepts Transition props; defaults `position` to `'popper'`, `side` to `'bottom'`, `align` to `'center'`, `sideOffset` to `4`, `alignOffset` to `0`, `avoidCollisions` to `true`, and `collisionPadding` to `10`.
- **Item**: Defaults `disabled` to `false`, `value` and `textValue` to `''`; `closeOnSelect` falls back to `Root` when omitted.
- **Group**, **Label**, **Surface**, **ItemText**, **Viewport**, **Separator**: No props.
