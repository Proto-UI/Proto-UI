## Installation

<InstallCommandCard command="npx @proto.ui/cli@latest add wc brutalist-select" manager="npm" />

Replace `wc` with `react`, `vue`, or `vue2` to generate the facade for your target framework, or import directly from `@proto.ui/prototypes-brutalist/select`.

## Usage

```tsx
import {
  BrutalistSelectContent,
  BrutalistSelectItem,
  BrutalistSelectRoot,
  BrutalistSelectTrigger,
  BrutalistSelectValue,
} from '../proto-ui/components/react';

export function FruitSelect() {
  return (
    <BrutalistSelectRoot>
      <BrutalistSelectTrigger className="w-48" accessibleLabel="Fruit selector">
        <BrutalistSelectValue placeholder="Select a fruit" />
      </BrutalistSelectTrigger>
      <BrutalistSelectContent>
        <BrutalistSelectItem value="apple" textValue="Apple">
          Apple
        </BrutalistSelectItem>
        <BrutalistSelectItem value="banana" textValue="Banana">
          Banana
        </BrutalistSelectItem>
        <BrutalistSelectItem value="blueberry" textValue="Blueberry">
          Blueberry
        </BrutalistSelectItem>
      </BrutalistSelectContent>
    </BrutalistSelectRoot>
  );
}
```

### Composition

Brutalist Select currently exports five core parts:

```text
BrutalistSelectRoot
├── BrutalistSelectTrigger
│   └── BrutalistSelectValue
└── BrutalistSelectContent
    └── BrutalistSelectItem
```

- **Appearance & motion**: The default `Trigger` renders flat. Setting `appearance="elevated"` adds a resting 4px hard black shadow that shifts +4px/+4px and flattens on hover or press (respecting `prefers-reduced-motion`). `Content` always stays flat with `popper` placement by default.
- **Keyboard & pointer**: Navigate with arrow keys or typeahead, commit with `Enter`, `Space`, or click, and press `Escape` to cancel and return focus to `Trigger`.
