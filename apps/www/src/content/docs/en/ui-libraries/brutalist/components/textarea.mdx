Replace `wc` with `react`, `vue`, or `vue2` to generate the facade for your target framework, or import directly from `@proto.ui/prototypes-brutalist/textarea`.

## Usage

```tsx
import { BrutalistTextareaRoot } from '../proto-ui/components/react';
```

```tsx
<BrutalistTextareaRoot placeholder="Type your message here." rows={4} />
```

- **Native editing semantics**: Supports controlled (`value`) and uncontrolled (`defaultValue`) modes, normalized `valueChange` and `change` events, IME composition-safe controlled value restoration, `focusSelf()`, `blurSelf()`, and `resetValue()` methods, and accessible naming via `ariaLabel`, `labelledBy`, and `describedBy`.
- **Visual details**: Ships with an 80px minimum height, 12px horizontal / 8px vertical padding, `text-sm` line height, DM Sans 500 typography, muted placeholder text, static accent selection highlight, and high-contrast foreground border adaptation in dark mode.
- **Form composition**: To connect labels, descriptions, error messages, and validation, import `fieldTextarea` from `@proto.ui/prototypes-brutalist/field`. See the [Form recipe](../../form/) for a complete example.

## API

The following props belong to `Root` (pass `value` for controlled mode; `minLength` and `maxLength` default to `-1` when unlimited):

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'value', type: 'string | undefined', default: 'uncontrolled' },
    { name: 'defaultValue', type: 'string', default: "''" },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'readOnly', type: 'boolean', default: 'false' },
    { name: 'placeholder', type: 'string', default: "''" },
    { name: 'rows', type: 'number', default: '2' },
    { name: 'required', type: 'boolean', default: 'false' },
    { name: 'name', type: 'string', default: "''" },
    { name: 'autoComplete', type: 'string', default: "''" },
    { name: 'minLength', type: 'number', default: '-1' },
    { name: 'maxLength', type: 'number', default: '-1' },
    { name: 'wrap', type: "'soft' | 'hard'", default: "'soft'" },
    { name: 'ariaLabel', type: 'string', default: "''" },
    { name: 'labelledBy', type: 'string', default: "''" },
    { name: 'describedBy', type: 'string', default: "''" },
  ]}
/>

- **Exposed states**: `value`, `disabled`, `readOnly`, `focused`, `focusVisible`, `composing` (plus `invalid` and `pending` on `FieldTextarea`).
- **Exposed methods**: `focusSelf(options?)`, `blurSelf()`, `resetValue()`.
- **Events**: `valueChange`, `change`, `compositionStart`, `compositionUpdate`, `compositionEnd`.
