## Usage

### Parts

Checkbox Group consists of `Root`, `Item`, and `All`:

- **Root**: Manages the selected string array via `value` / `defaultValue`, along with `disabled`, `readOnly`, and `ariaLabel`.
- **Item**: Represents an individual option with a unique `value` and optional `disabled` flag. Duplicate values ignore ambiguous toggle requests.
- **All**: Derives checked or mixed state from enabled registered items and toggles only enabled items while preserving disabled selections.

`Item` and `All` render decorative `aria-hidden` state icons (check for checked, dash for mixed, empty box for unchecked) so state never depends on color alone.

### Controlled usage and keyboard

- Pass `value` for controlled mode; toggling emits `valueChange` without overwriting external state. Call `getValue()` to read a defensive copy of the current value array.
- Each option is focusable in the `Tab` order and toggles with `Space` (`Enter` does not toggle).
- Inside `Field` or `Form`, `Root` reports the value array, group focus, and local policies for label activation, required validation, form serialization, and reset without creating hidden HTML inputs.
