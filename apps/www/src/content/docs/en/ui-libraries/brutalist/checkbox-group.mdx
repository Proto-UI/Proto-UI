Brutalist Checkbox Group coordinates a set of checkboxes backed by a string array, with select-all/mixed state, vertical or horizontal layout, square 2px borders, DM Sans 500 label typography, and high-contrast focus rings.

## Usage

```tsx
import {
  BrutalistCheckboxGroupRoot,
  BrutalistCheckboxGroupAll,
  BrutalistCheckboxGroupItem,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <BrutalistCheckboxGroupRoot defaultValue={['email']} ariaLabel="Notification channels">
      <BrutalistCheckboxGroupAll>All notifications</BrutalistCheckboxGroupAll>
      <BrutalistCheckboxGroupItem value="email">Email updates</BrutalistCheckboxGroupItem>
      <BrutalistCheckboxGroupItem value="sms">SMS alerts</BrutalistCheckboxGroupItem>
    </BrutalistCheckboxGroupRoot>
  );
}
```

### Anatomy and keyboard

- **Root**: Manages the selected `string[]` value (`value` / `defaultValue`), `orientation`, `disabled`, `readOnly`, and `ariaLabel`.
- **Item**: Individual option with a unique `value` and optional `disabled` flag. Each enabled option has its own `Tab` stop and toggles with `Space` (`Enter` does not toggle).
- **All**: Derives checked, mixed (`aria-checked="mixed"`), or unchecked state across enabled items and toggles only enabled items while preserving disabled selections.
- **Accessibility and forms**: The square 20×20 indicator box renders check/dash glyphs and owns the focus ring; inside `Field` or `FormField`, `Root` participates in label activation, required validation, serialization, and reset.

### Events, Methods, and States

- **Root events**: `valueChange` (payload `{ value: string[] }`).
- **Root methods**: `getValue(): string[]`, `resetValue(): boolean`, `focusSelf(): void`.
- **Exposed states**: Root exposes `checked`, `indeterminate`, `disabled`, `readOnly`; Item and All expose `checked`, `indeterminate`, `disabled`, `readOnly`, `focused`, `focusVisible`.
