## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototypes directly from `@proto.ui/prototypes-brutalist/toggle-group` and adapt them for your target runtime.

## Usage

### Anatomy

ToggleGroup is composed of `Root` and `Item`:

- `Root`: Manages the active value array, single/multiple mode, orientation, and roving focus.
- `Item`: Renders each toggle button identified by a unique `value`.

### Selection & Keyboard Navigation

- Both `value` and `defaultValue` are string arrays (`readonly string[]`). With `multiple={false}` (default), at most one item stays active and clicking it again clears the selection; set `multiple={true}` to allow multiple active items.
- Arrow keys move roving focus between items without toggling selection; press `Enter` or `Space` to toggle the focused item.
- Disabled items, `readOnly` groups, and items with duplicate values do not commit changes. Pass `value` for controlled mode and listen to `valueChange` to decide when to update state.
