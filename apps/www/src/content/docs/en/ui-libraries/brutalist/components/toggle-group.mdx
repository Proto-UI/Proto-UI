## Installation

Available starting in `0.3.0-rc.1` and later releases. Import the prototypes directly from `@proto.ui/prototypes-brutalist/toggle-group` and adapt them for your target runtime.

## Usage

```tsx
import { BrutalistToggleGroupItem, BrutalistToggleGroupRoot } from '../proto-ui/components/react';

export function Example() {
  return (
    <BrutalistToggleGroupRoot multiple defaultValue={['a']}>
      <BrutalistToggleGroupItem value="a">A</BrutalistToggleGroupItem>
      <BrutalistToggleGroupItem value="b">B</BrutalistToggleGroupItem>
      <BrutalistToggleGroupItem value="c">C</BrutalistToggleGroupItem>
    </BrutalistToggleGroupRoot>
  );
}
```

### Composition

```text
ToggleGroupRoot
├── ToggleGroupItem
└── ToggleGroupItem
```

- **Visual contract**: The group surface retains a 3px foreground offset shadow with no press translation; items follow Brutalist's flat toggle grammar with black hover/active borders and a persistent 2px inset frame when active.
- **Selection & keyboard**: Both `value` and `defaultValue` are string arrays. Arrow keys move roving focus without toggling; `Space` or `Enter` commits a toggle. Pass `value` for controlled mode and listen to `valueChange`.
