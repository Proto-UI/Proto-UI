Brutalist Carousel pairs an equal-size slide track with a continuously scrollable viewport and Previous/Next controls. It supports mouse and touch dragging, wheel and trackpad scrolling, and keyboard navigation, snapping to the nearest reachable slide boundary once motion stops.

## Usage

### Responsive viewport and layout

- Configure `slidesPerView` (default `1`) for the maximum visible equal-size slides and `minSlideSize` (default `0`) for their minimum extent in logical pixels. Narrower viewports automatically reduce visible capacity, and the final snap aligns cleanly to the end of the strip without trailing gaps.
- `Root` exposes `visibleSlides` and `maxIndex`; `Viewport` exposes `dragging`, `scrolling`, and normalized `scrollPosition`; each `Slide` exposes `current` and offscreen `hidden` without collapsing layout size.
- When using `orientation="vertical"`, give the viewport an explicit bounded height. Horizontal `direction="rtl"` mirrors physical dragging and arrow keys while keeping logical item order.
- Enable `loop={true}` to wrap index requests between the first and last reachable snap positions.

### Controlled and uncontrolled index

- **Uncontrolled**: Set `defaultIndex` to initialize the starting slide.
- **Controlled**: Pass `index` and listen to `indexChange` to commit new snap positions. Live drag previews never overwrite the committed index prematurely.

- **Viewport**: No props
- **Slide**: `index?: number` (defaults to document order when omitted; explicit indexes should match item order)
