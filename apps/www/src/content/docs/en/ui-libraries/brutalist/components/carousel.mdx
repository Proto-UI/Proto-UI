Brutalist Carousel pairs an equal-size slide track with a continuously scrollable viewport and high-contrast raised Previous/Next controls. It supports mouse and touch dragging, wheel and trackpad scrolling, and keyboard navigation, snapping cleanly to the nearest reachable slide boundary.

## Installation

Available starting in `0.3.0-rc.1` and later releases.

## Usage

```tsx
import {
  BrutalistCarouselRoot,
  BrutalistCarouselViewport,
  BrutalistCarouselSlide,
  BrutalistCarouselPrevious,
  BrutalistCarouselNext,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <BrutalistCarouselRoot className="mx-auto w-full max-w-xs">
      <BrutalistCarouselViewport>
        <BrutalistCarouselSlide>1</BrutalistCarouselSlide>
        <BrutalistCarouselSlide>2</BrutalistCarouselSlide>
        <BrutalistCarouselSlide>3</BrutalistCarouselSlide>
      </BrutalistCarouselViewport>
      <BrutalistCarouselPrevious aria-label="Previous slide">←</BrutalistCarouselPrevious>
      <BrutalistCarouselNext aria-label="Next slide">→</BrutalistCarouselNext>
    </BrutalistCarouselRoot>
  );
}
```

- **Responsive viewport and layout**: Configure `slidesPerView` (default `1`) and `minSlideSize` (default `0`) to adapt visible slide counts automatically as the container resizes.
- **Brutalist geometry and motion**: Viewport uses 5px `rounded-base` clipping while raised Previous/Next buttons pair 2px black borders with 4px zero-blur hard shadows that collapse into place on press.
- **Orientation and controlled state**: Provide an explicit height on `Viewport` for `orientation="vertical"`; pass `index` with `indexChange` for controlled navigation.
