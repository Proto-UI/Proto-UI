Brutalist Toggle inherits Base Toggle's `aria-pressed` semantics with a 5px rounded frame, 2px black border, and flat displacement-free geometry. When active, it switches to the paired main surface and displays a persistent 2px inset ink frame as a non-color cue.

## Usage

```tsx
import { BrutalistToggle } from '../proto-ui/components/react';
```

```tsx
<BrutalistToggle variant="outline">Toggle</BrutalistToggle>
```

- **Variants & sizes**: Choose `'default'` (filled neutral surface) or `'outline'` (transparent resting surface) via `variant`, and `'sm'` (36px), `'default'` (40px), or `'lg'` (44px) via `size`.
- **Flat interaction grammar**: Hover highlights with a muted neutral fill, press and active states co-select the main fill and ink pair, and active keeps its 2px inset frame without shifting position or casting an outer shadow.
- **Controlled & uncontrolled**: Use `defaultActive` for uncontrolled initialization, or pass `active` and listen to `activeChange` for controlled updates. Set `disabled` to block activation.

## API

The following props belong to `Root` (pass `active` for controlled mode):

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'active', type: 'boolean | undefined', default: 'uncontrolled' },
    { name: 'defaultActive', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'variant', type: "'default' | 'outline'", default: "'default'" },
    { name: 'size', type: "'default' | 'sm' | 'lg'", default: "'default'" },
  ]}
/>

- **Events**: `activeChange` (payload `{ active: boolean }`).
- **Methods**: `focusSelf(options?)` (no-op while disabled).
- **Exposed states**: `active`, `disabled`, `hovered`, `focused`, `focusVisible`, `pressed`.
