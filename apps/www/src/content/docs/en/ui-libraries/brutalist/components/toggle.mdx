Toggle keeps Base activation and `aria-pressed` ownership. Its latched active state adds a persistent inset ink frame as an explicit non-color accessibility extension; transient press keeps the flat geometry without movement. The pinned Neo size recipe uses 40px default, 36px small (0.8rem text), and 44px large (text-sm). Upstream icon-size/side-padding details and variants remain outside this bounded projection. ## API

Toggle is workspace source. There is no public `proto-ui add` target. Passing `active` selects controlled mode.
