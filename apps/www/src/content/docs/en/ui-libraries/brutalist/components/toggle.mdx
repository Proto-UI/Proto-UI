Toggle is a two-state button with `aria-pressed` semantics. Its Brutalist presentation marks the active state with a persistent inset ink frame as a clear non-color cue, while pressing keeps a flat geometry without shifting position.

## Installation

Included in `@proto.ui/prototypes-brutalist@0.2.0`. Add it via the CLI target `brutalist-toggle`, or import directly from `@proto.ui/prototypes-brutalist/toggle`.

## Usage

- **Sizes**: Choose `'sm'` (36px, `0.8rem` text), `'default'` (40px), or `'lg'` (44px, `text-sm`).
- **Controlled vs. uncontrolled**: Use `defaultActive` for uncontrolled initialization, or pass `active` to control the state externally. Set `disabled` to block activation.
