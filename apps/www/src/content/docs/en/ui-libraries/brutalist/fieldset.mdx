## Installation

## Usage

```tsx
import { FieldsetRoot, FieldsetLegend, FieldsetDescription } from '@/components/brutalist/fieldset';
import { FieldRoot, FieldLabel, FieldControl } from '@/components/brutalist/field';

export function Example() {
  return (
    <FieldsetRoot>
      <FieldsetLegend>Address Information</FieldsetLegend>
      <FieldsetDescription>We need your address to deliver your order.</FieldsetDescription>
      <FieldRoot required>
        <FieldLabel>Street Address</FieldLabel>
        <FieldControl placeholder="123 Main St" />
      </FieldRoot>
    </FieldsetRoot>
  );
}
```

### Parts

- **Root**: Establishes the `group` role and computes the effective disabled state from its own `disabled` prop and any enclosing `Fieldset`, arranged as an unboxed `gap-4` vertical stack using `font-sans font-medium`.
- **Legend**: Optional heading using `font-heading font-bold` per the Brutalist design contract, preserving authored casing, supporting `variant="legend"` (default) and `variant="label"`, and adding no tab stop.
- **Description**: Optional wrappable help copy rendered in crisp foreground text with disabled state feedback.

Each group accepts at most one `Legend` and one `Description`. ARIA labelling and description attributes are automatically linked and cleaned up on unmount without manual DOM IDs, and nested groups never leak targets across scopes.

### Nested disabled behavior

Effective disabled state cascades through nested `Fieldset` roots without clearing local disabled flags when an ancestor is re-enabled:

- Disabling `outer` disables `outer`, `middle`, and `inner`.
- Disabling `middle` and then re-enabling `outer` keeps `middle` and `inner` disabled.
- Re-enabling `middle` re-enables `inner` unless `inner` has `disabled={true}`.

Every participating `Field` inside the group—including fields placed inside `Legend`—inherits the group's disabled state.
