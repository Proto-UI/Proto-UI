## Usage

### Parts

- **Root**: Establishes the `group` role and computes the effective disabled state from its own `disabled` prop and any enclosing `Fieldset`, arranged as an unboxed `gap-4` vertical stack.
- **Legend**: Optional bold group heading that preserves authored casing and adds no tab stop.
- **Description**: Optional wrappable help copy rendered in crisp foreground text.

Each group accepts at most one `Legend` and one `Description`. ARIA labelling and description attributes are automatically linked and cleaned up on unmount without manual DOM IDs, and nested groups never leak targets across scopes.

### Nested disabled behavior

Effective disabled state cascades through nested `Fieldset` roots without clearing local disabled flags when an ancestor is re-enabled:

- Disabling `outer` disables `outer`, `middle`, and `inner`.
- Disabling `middle` and then re-enabling `outer` keeps `middle` and `inner` disabled.
- Re-enabling `middle` re-enables `inner` unless `inner` has `disabled={true}`.

Every participating `Field` inside the group—including fields placed inside `Legend`—inherits the group's disabled state.
