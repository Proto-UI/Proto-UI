Table displays passive structured data while maintaining [Base Table](/en/ui-libraries/base/table/) row/column indexing, header associations, and span metadata. Its Brutalist presentation frames the table with `border-2 border-black` and a `4px/4px` solid offset shadow, a main-accent header row, crisp black row dividers, a doubled top border on the footer, and an instant `bg-main/20` hover highlight on body rows.

For sorting, row selection, pagination, filtering, or interactive grid navigation, use [Data Table](/en/ui-libraries/brutalist/components/data-table/).

## Installation

Available starting in `0.3.0-rc.1` and later releases. Import the five parts from `@proto.ui/prototypes-brutalist` or `@proto.ui/prototypes-brutalist/table`:

```ts
import {
  brutalistTableRoot,
  brutalistTableCaption,
  brutalistTableRow,
  brutalistTableHeaderCell,
  brutalistTableCell,
} from '@proto.ui/prototypes-brutalist/table';
```

## Usage

```html
<div class="w-full overflow-x-auto">
  <brutalist-table-root>
    <brutalist-table-caption>A list of your recent invoices.</brutalist-table-caption>
    <brutalist-table-row section="header" last-in-section>
      <brutalist-table-header-cell header-key="invoice" header-kind="column" style="width: 100px">
        Invoice
      </brutalist-table-header-cell>
      <brutalist-table-header-cell header-key="status" header-kind="column"
        >Status</brutalist-table-header-cell
      >
      <brutalist-table-header-cell header-key="method" header-kind="column"
        >Method</brutalist-table-header-cell
      >
      <brutalist-table-header-cell header-key="amount" header-kind="column" style="text-align: end">
        Amount
      </brutalist-table-header-cell>
    </brutalist-table-row>
    <brutalist-table-row section="body" last-in-section>
      <brutalist-table-header-cell header-key="inv001" header-kind="row"
        >INV001</brutalist-table-header-cell
      >
      <brutalist-table-cell>Paid</brutalist-table-cell>
      <brutalist-table-cell>Credit Card</brutalist-table-cell>
      <brutalist-table-cell style="text-align: end">$250.00</brutalist-table-cell>
    </brutalist-table-row>
  </brutalist-table-root>
</div>
```

### Composition

```text
Root
├── Caption
├── Row (section="header")
│   └── HeaderCell (headerKind="column")
├── Row (section="body")
│   ├── HeaderCell (headerKind="row")
│   └── Cell (headers=[...])
└── Row (section="footer")
    ├── HeaderCell (headerKind="row")
    └── Cell (headers=[...])
```

- `Root`: Table container tracking ordered row/column structure and exposing `getStructure()`. Wrap `Root` in an outer scroll container when horizontal scrolling is required.
- `Row`: Accepts visual-only `section` (`'header' | 'body' | 'footer'`) and `lastInSection` props. Header rows paint `bg-main text-main-foreground`, body rows snap to `bg-main/20` on pointer hover, and footer rows paint a doubled top border with a contrasting summary fill.
- `HeaderCell`: Uses `font-heading font-semibold` and logical `text-start` alignment.

## API

### Root & Caption

`Root` and `Caption` declare no props. `Root` exposes `getStructure()` for inspecting rows, columns, and header relationships.
