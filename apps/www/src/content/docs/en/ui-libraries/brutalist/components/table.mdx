Table displays passive structured data while maintaining ordered row/column indexing, header relationships, and cell spans. Its Brutalist presentation frames the table with `border-2 border-black` and a `4px/4px` solid offset shadow, black row dividers, semibold headers, a doubled top border on the footer, and a `bg-main/20` hover highlight on body rows.

For sorting, row selection, pagination, filtering, or interactive grid navigation, use [Data Table](/en/ui-libraries/brutalist/components/data-table/).

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the parts from `@proto.ui/prototypes-brutalist` or `@proto.ui/prototypes-brutalist/table` (workspace CLI target: `brutalist-table`).

## Usage

### Anatomy

Table is composed of five parts: `Root`, `Caption`, `Row`, `HeaderCell`, and `Cell`.

- `Root`: Table container that tracks ordered row/column structure and exposes `getStructure()`. Wrap `Root` in an outer scroll container if you need horizontal scrolling.
- `Caption`: Accessible table caption.
- `Row`: Table row accepting two visual-only props—`section` (`'header' | 'body' | 'footer'`, default `'body'`) and `lastInSection` (default `false`)—to style header, body, and footer borders and row hover.
- `HeaderCell`: Declares column or row headers via `headerKey` and `headerKind`, and supports `headers`, `rowSpan`, and `columnSpan`.
- `Cell`: Standard data cell supporting `headers` references as well as `rowSpan` and `columnSpan`.

## API

`Root` declares no props (and exposes `getStructure()` for inspecting rows, columns, and header relationships):

<ApiPropsTable headers={{ name: 'Prop', type: 'Type', default: 'Default' }} rows={[]} />

Other part props and defaults:

- **Caption**: No props.
- **Row**: `section` defaults to `'body'`; `lastInSection` defaults to `false`.
- **Cell**: `headers` defaults to `[]`; `rowSpan` and `columnSpan` default to `1`.
- **HeaderCell**: `headerKey` defaults to `''`; `headerKind` defaults to `'column'`; `headers` defaults to `[]`; `rowSpan` and `columnSpan` default to `1`.
