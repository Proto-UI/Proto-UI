Brutalist Async Region is a single-part semantic container that projects `aria-busy` during asynchronous updates while keeping your children mounted and focused.

## Installation

Available directly through package exports; Async Region is not registered as a `proto-ui add` CLI target. Import from `@proto.ui/prototypes-brutalist` or its subpath:

```ts
import { asyncRegionRoot } from '@proto.ui/prototypes-brutalist/async-region';
```

## Usage

```tsx
import { useState } from 'react';
import { AdaptToReact } from '@proto.ui/adapter-react';
import { asyncRegionRoot } from '@proto.ui/prototypes-brutalist/async-region';

const BrutalistAsyncRegionRoot = AdaptToReact(asyncRegionRoot);

export function ReleaseFeed() {
  const [busy, setBusy] = useState(false);

  return (
    <BrutalistAsyncRegionRoot busy={busy}>
      <p>Authored descendants and focus stay intact during refresh.</p>
    </BrutalistAsyncRegionRoot>
  );
}
```

- **Busy semantics**: Setting `busy={true}` synchronously reflects `aria-busy="true"` on `brutalist-async-region-root` and exposes the same boolean through `getExposes().busy`.
- **Brutalist surface grammar**: The semantic container applies only `block min-w-0 max-w-full font-sans text-foreground` without adding borders, hard shadows, or motion tokens; 2px black borders and 4px shadows belong to surrounding cards and action controls.
- **Composition**: Style busy states using `[aria-busy="true"]` and compose with `Spinner`, `Skeleton`, `Progress`, or `Live Region` for visual or spoken updates.
