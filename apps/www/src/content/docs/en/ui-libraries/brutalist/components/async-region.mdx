Brutalist Async Region is a single-part semantic container that sets `aria-busy` on a region during asynchronous updates while keeping your children mounted and focused.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

- **CLI target**: `proto-ui add <react|vue|vue2|wc> brutalist-async-region`
- **Package exports**: import from `@proto.ui/prototypes-brutalist` or `@proto.ui/prototypes-brutalist/async-region`

## Usage

- Setting `busy={true}` sets `aria-busy="true"` on the region element and exposes the same boolean through `getExposes().busy`.
- When updating `busy`, your children stay mounted and keep focus. The Brutalist layer applies only `min-w-0 max-w-full text-foreground` without adding borders, shadows, or built-in loading visuals.
- Compose with `Spinner`, `Skeleton`, or `Progress` for visual loading indicators, and pair with `Live Region` when status updates should be announced to screen readers.
