Brutalist AlertDialog interrupts the user for critical or destructive confirmations. It traps focus inside a bold Brutalist panel, prevents outside-click dismissal, and focuses `Cancel` first by default.

## Installation

Available starting in `0.3.0-rc.1` and later releases (`@proto.ui/prototypes-brutalist`).

## Usage

```tsx
import {
  BrutalistAlertDialogRoot,
  BrutalistAlertDialogTrigger,
  BrutalistAlertDialogMask,
  BrutalistAlertDialogContent,
  BrutalistAlertDialogHeader,
  BrutalistAlertDialogTitle,
  BrutalistAlertDialogDescription,
  BrutalistAlertDialogFooter,
  BrutalistAlertDialogCancel,
  BrutalistAlertDialogAction,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <BrutalistAlertDialogRoot>
      <BrutalistAlertDialogTrigger>Open</BrutalistAlertDialogTrigger>
      <BrutalistAlertDialogMask />
      <BrutalistAlertDialogContent>
        <BrutalistAlertDialogHeader>
          <BrutalistAlertDialogTitle>Are you absolutely sure?</BrutalistAlertDialogTitle>
          <BrutalistAlertDialogDescription>
            This action cannot be undone. This will permanently delete your account.
          </BrutalistAlertDialogDescription>
        </BrutalistAlertDialogHeader>
        <BrutalistAlertDialogFooter>
          <BrutalistAlertDialogCancel>Cancel</BrutalistAlertDialogCancel>
          <BrutalistAlertDialogAction>Continue</BrutalistAlertDialogAction>
        </BrutalistAlertDialogFooter>
      </BrutalistAlertDialogContent>
    </BrutalistAlertDialogRoot>
  );
}
```

### Parts

- **Root**: Manages `alertdialog` semantics and open state via controlled `open` or uncontrolled `defaultOpen`.
- **Mask**: Flat scrim overlay with a 150ms fade transition that blocks outside-click dismissal.
- **Content**: Raised 5px-radius (`rounded-base`) panel with 2px border, 24px padding, and hard shadow. Supports `size="sm"`, traps focus, and focuses `Cancel` when available.
- **Header / Footer**: Optional layout containers for the heading stack and right-aligned action buttons (which reverse-wrap cleanly when space is tight).
- **Cancel / Action**: `Cancel` and `Escape` request dismissal; `Action` emits `action` before requesting close so your application performs the confirmed operation.
