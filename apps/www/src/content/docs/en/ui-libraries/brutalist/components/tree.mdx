## Usage

### Hierarchy & Branch Grouping

- Assign each `Item` a unique `nodeKey` and set `parentKey` to point to its parent branch. Duplicate keys, missing parents, and cycles are ignored to keep the hierarchy valid.
- Give each `TreeGroup` the same `nodeKey` as its parent branch `Item`, and place that branch's child `Item`s inside the group. `aria-controls` and `aria-labelledby` relationships are linked automatically and cleaned up whenever nodes unmount or change.
- Collapsing a branch hides its `Group` without deleting the hierarchy. If focus was inside the collapsed branch, focus moves to the visible ancestor while focus outside the Tree remains untouched.

### Keyboard Navigation & RTL

- `ArrowUp`/`ArrowDown`, `Home`/`End`, and first-letter typeahead move focus in logical visible order.
- In LTR mode, `ArrowRight` expands a branch or moves into its children, while `ArrowLeft` collapses or moves to the parent. Setting `direction="rtl"` on `Root` swaps the horizontal keys and mirrors group indentation.

### Read-Only & Controlled Mode

- `readOnly` blocks selection changes while allowing navigation and branch expansion.
- Pass `value` or `expandedKeys` on `Root` for controlled mode; committed state updates only when your handler accepts the request. Inserting, moving, or removing items updates the hierarchy without emitting synthetic user selection events.

## API

The following props belong to `Root` (pass `value` or `expandedKeys` for controlled mode):

Other part props and defaults:

- **Item**: `nodeKey`, `parentKey`, and `textValue` default to `''`; `disabled` defaults to `false`.
- **Group**: Accepts `nodeKey`.
- **Toggle**: Also accepts Button props.
