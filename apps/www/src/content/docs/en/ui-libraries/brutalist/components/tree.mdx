Tree renders an expandable, single-select hierarchy styled with Brutalist 5px corners, 2px black borders, zero-blur hard shadows, and DM Sans typography, paired with arrow-key, `Home`/`End`, first-letter typeahead, and LTR/RTL keyboard navigation.

## Installation

Available starting in `0.3.0-rc.1` and later releases. Import the prototypes directly from `@proto.ui/prototypes-brutalist/tree` and adapt them for your target runtime:

```ts
import { treeRoot, treeItem, treeGroup, treeToggle } from '@proto.ui/prototypes-brutalist/tree';
```

## Usage

```tsx
<BrutalistTreeRoot defaultValue="button" defaultExpandedKeys={['src', 'components']}>
  <div className="flex items-center gap-2">
    <BrutalistTreeToggle nodeKey="src" size="icon">
      ▾
    </BrutalistTreeToggle>
    <BrutalistTreeItem nodeKey="src" textValue="src" className="flex-1">
      src/
    </BrutalistTreeItem>
  </div>
  <BrutalistTreeGroup nodeKey="src">
    <BrutalistTreeItem nodeKey="button" parentKey="src" textValue="button.tsx">
      button.tsx
    </BrutalistTreeItem>
  </BrutalistTreeGroup>
</BrutalistTreeRoot>
```

### Structure, Keyboard Navigation & Visual Depth

- **Hierarchy & grouping**: Give each `Item` a unique `nodeKey` and set `parentKey` to its parent branch. Place child items inside a `TreeGroup` sharing the parent `nodeKey` to automatically maintain `aria-controls` / `aria-labelledby`.
- **Brutalist depth grammar**: `Root` acts as a raised 4px hard-shadow panel; `Item` rows stay flat and shift fill/border on hover and selection without displacement; `Toggle` acts as a raised control that snaps into its 4px hard shadow on press.
- **Keyboard & RTL**: Supports `ArrowUp` / `ArrowDown`, `Home` / `End`, and first-letter typeahead. Setting `direction="rtl"` swaps Left/Right expand/collapse keys and mirrors indentation guides.
