Message Scroller builds on Scroll Surface's end-follow behavior for chat logs and live feeds. It automatically follows appended items while the reader stays at the end, and lets readers who scroll up jump back to the latest messages on demand.

## Usage

### Anatomy

Message Scroller is composed of `Root`, `Viewport`, and `Jump`:

- `Root`: Coordinates end-follow state, the new-content count, and the scroll region's accessible name.
- `Viewport`: Renders the scrollable message list container.
- `Jump`: Action control that jumps back to the latest messages when the reader leaves the end (accepts Button props).

### Behavior Notes

- **End-follow policy**: New messages auto-scroll into view only while the reader is already at the end. Scrolling up pauses auto-follow until the reader returns or clicks `Jump`.
- **Application-owned count**: Pass `newContentCount` from your application state to reflect new arrivals; the component does not infer unread business logic.
- **Focus preservation**: Activating `Jump` scrolls to the end without stealing or requesting focus.
- **Accessible naming**: Set `a11yLabel` on `Root` to name the scrollable region (defaults to `'Messages'`).
