Message Scroller pairs Scroll Surface end-follow behavior with Brutalist 2px borders, `rounded-base` framing, and hard 4px offset shadows. New messages auto-scroll while the reader is at the bottom, pause when scrolling up into history, and snap back via the floating Jump control.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototypes directly from `@proto.ui/prototypes-brutalist/message-scroller` and adapt them for your target runtime.

```ts
import {
  messageScrollerRoot,
  messageScrollerViewport,
  messageScrollerJump,
} from '@proto.ui/prototypes-brutalist/message-scroller';
```

## Usage

Place `Root` inside a height-constrained container. `Root` owns the rounded outer frame and 4px shadow, `Viewport` handles square-cornered vertical scrolling, and `Jump` floats above the bottom-right corner with a crisp `+4px, +4px` press snap:

```tsx
<div className="h-96 w-full max-w-md">
  <BrutalistMessageScrollerRoot a11yLabel="Team chat messages">
    <BrutalistMessageScrollerViewport>
      <div className="flex flex-col gap-3 p-4 pb-16">
        {messages.map((message) => (
          <div key={message.id}>{message.text}</div>
        ))}
      </div>
    </BrutalistMessageScrollerViewport>
    <BrutalistMessageScrollerJump>Scroll to end ↓</BrutalistMessageScrollerJump>
  </BrutalistMessageScrollerRoot>
</div>
```

### Anatomy & Behavior

- **Root**: Styled `rounded-base` panel with 2px black border and 4px offset shadow; coordinates end-follow state, `newContentCount`, and `a11yLabel`.
- **Viewport**: Square-cornered `overflow-y-auto` scrollable region that preserves reading position while scrolled away from the end.
- **Jump**: Floating primary raised control that settles into its shadow on press and jumps to the end without stealing keyboard focus.
