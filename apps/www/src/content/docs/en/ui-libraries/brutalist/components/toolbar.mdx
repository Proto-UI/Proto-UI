## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototypes directly from `@proto.ui/prototypes-brutalist/toolbar` and adapt them for your target runtime.

## Usage

### Anatomy

Toolbar is composed of `Root`, `Button`, and `Separator`:

- `Root`: Manages toolbar-wide `disabled` state, `orientation`, `loop` navigation, and accessible naming (`a11yLabel`).
- `Button`: Emits an `action` event carrying its `value` when activated while enabled.
- `Separator`: Automatically aligns along the toolbar's cross axis.

### Keyboard Navigation

- Only one enabled button participates in the `Tab` sequence at a time.
- Arrow keys move focus between enabled buttons inside the toolbar; `loop={true}` (default) wraps from end to start.
