Brutalist Toolbar groups related action buttons inside a `rounded-base` 2px-bordered container with a crisp 3px foreground offset shadow, single-Tab roving focus, and instant-snap press feedback.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototypes directly from `@proto.ui/prototypes-brutalist/toolbar` and adapt them for your target framework:

```ts
import {
  toolbarRoot,
  toolbarButton,
  toolbarSeparator,
} from '@proto.ui/prototypes-brutalist/toolbar';
```

## Usage

```tsx
import {
  BrutalistToolbarRoot,
  BrutalistToolbarButton,
  BrutalistToolbarSeparator,
} from '../proto-ui/components/react';

export function EditorToolbar() {
  return (
    <BrutalistToolbarRoot a11yLabel="Document actions">
      <BrutalistToolbarButton value="undo">Undo</BrutalistToolbarButton>
      <BrutalistToolbarButton value="redo">Redo</BrutalistToolbarButton>
      <BrutalistToolbarSeparator />
      <BrutalistToolbarButton value="save" variant="solid">
        Save
      </BrutalistToolbarButton>
    </BrutalistToolbarRoot>
  );
}
```

Toolbar consists of `Root`, `Button`, and `Separator`:

- **Brutalist contract alignment**: `Root` acts as a passive grouping surface with a 3px foreground shadow and `rounded-base` corners; `Button` uses DM Sans medium typography (`14px/20px`), high-contrast accent hover fills, and instant-snap pressed feedback.
- **Keyboard navigation**: Only one enabled button participates in page `Tab` order at a time, while arrow keys move focus across commands (`loop={true}` by default).
- **Separators**: `Separator` renders a crisp 2px divider automatically aligned to the toolbar's cross axis.

### Separator and Events

- **Separator**: Takes no additional props and renders a 2px cross-axis divider automatically.
- **Events and exposes**: `Button` emits `action` (`{ value: string }`) on activation. `Root` exposes `disabled`, `focusFirst()`, `focusLast()`, and `setCurrent(id)`; `Button` exposes `disabled`, `focused`, `focusVisible`, and `focusSelf(options)`.
