Root owns disabled, orientation, loop and a11yLabel. Button emits action with its value on enabled activation. Only one enabled command participates in Tab; arrows move within the toolbar. Separator follows the cross axis.

Parts: Root, Button, Separator.

## API

Toolbar is workspace source. There is no public `proto-ui add` target. Separator has no props.
