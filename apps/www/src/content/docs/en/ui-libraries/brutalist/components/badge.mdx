Brutalist Badge is a static label for tagging roles, environments, or categories, styled with 5px rounded corners (`rounded-base`), a `2px` black border, DM Sans 500 typography (`12px/16px`), no drop shadow, and flat high-contrast tones.

## Usage

```tsx
import { BrutalistBadgeRoot } from '../proto-ui/components/react';
```

```tsx
<BrutalistBadgeRoot tone="accent">Badge</BrutalistBadgeRoot>
```

- Choose a visual tone via `tone`: `'accent'` (default, canary), `'info'` (sky), or `'danger'` (coral). Each tone pairs a flat background fill with its matching high-contrast foreground color.
- Badges use inline-flex layout with `whitespace-nowrap` and `gap-1`, keeping text and leading or trailing icon markers aligned on a single line.
- Badge is a passive, roleless, non-focusable label with no hover or press motion. Use `Live Region` for live status announcements, `Button` for actions, or `Toggle` for pressed states.
