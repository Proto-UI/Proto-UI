Brutalist Badge is a static label for tagging roles, environments, or categories, styled with 5px rounded corners, a `2px` black border, DM Sans 500 typography, and flat high-contrast tones.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

- **CLI target**: `proto-ui add <react|vue|vue2|wc> brutalist-badge`

## Usage

- Choose a visual tone via `tone`: `'accent'` (default), `'info'`, or `'danger'`. Each tone pairs a flat background fill with its matching foreground color.
- Badge is a passive, non-focusable label. Use `Live Region` for live status announcements, `Button` for actions, or `Toggle` for pressed states.
