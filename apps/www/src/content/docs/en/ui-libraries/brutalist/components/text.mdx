Text realizes [Base Text](/en/ui-libraries/base/text/) with Brutalist typography and ink tokens, giving you a consistent vocabulary for text scale, font family, weight, line height, tracking, and tone.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import `brutalistTextRoot` (also aliased as `textRoot` and `BrutalistTextRoot`) from `@proto.ui/prototypes-brutalist` or `@proto.ui/prototypes-brutalist/text` (workspace CLI target: `brutalist-text`).

## Usage

### Basic Example

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { brutalistTextRoot } from '@proto.ui/prototypes-brutalist/text';

const Text = createReactAdapter(React)(brutalistTextRoot, { rootTag: 'span' });

export function SectionTitle() {
  return (
    <h1>
      <Text size="4xl" font="heading" weight="semibold" leading="tight" tracking="tight">
        Account settings
      </Text>
    </h1>
  );
}
```

### Semantic Composition & Typography Rules

- **Keep native document semantics outside**: `rootTag: 'span'` is a Web Adapter option. Keep headings (`h1`–`h6`), paragraphs (`p`), labels (`label` with `htmlFor`/`for`), and links (`a` with `href`/`target`/`download`) on native outer elements—Text stays passive and adds no focus stop or activation handler.
- **Foreground inheritance & defaults**: Set `tone="inherit"` when placing Text inside a solid or accent `Surface` so it inherits the enclosing ink color. Removing any prop restores its default; an invalid initial `size` falls back to `'base'`, while an invalid update after a valid value retains the previous valid value.
- **Scale-matched leading & tight tracking**: Setting `leading="size"` keeps each size's built-in line height (`xs` through `5xl` map to `1rem`, `1.25rem`, `1.5rem`, `1.75rem`, `1.75rem`, `2rem`, `2.25rem`, `2.5rem`, and `1` respectively). `leading="tighter"` maps to `1.1` and `tracking="tighter"` maps to `-0.05em`.
