Brutalist Text realizes [Base Text](/en/ui-libraries/base/text/) with DM Sans font roles (`500` body, `700` heading) and high-contrast Brutalist ink tokens while remaining passive, shadowless, and free of extra motion per the Brutalist design contract.

## Installation

Available starting in `0.3.0-rc.1` and later releases. Generate local facades with the `brutalist-text` CLI target or import `brutalistTextRoot` (aliased as `textRoot` and `BrutalistTextRoot`) from `@proto.ui/prototypes-brutalist/text`:

<InstallCommandCard
  commands={{
    npm: 'npx @proto.ui/cli@latest add wc brutalist-text',
    pnpm: 'pnpm dlx @proto.ui/cli@latest add wc brutalist-text',
  }}
  manager="npm"
/>

Replace `wc` with `react`, `vue`, or `vue2` for your target framework.

## Usage

```tsx
import { BrutalistTextRoot } from '../proto-ui/components/react';

export function SectionTitle() {
  return (
    <h1>
      <BrutalistTextRoot size="4xl" font="heading" weight="bold" leading="tight" tracking="tight">
        Account settings
      </BrutalistTextRoot>
    </h1>
  );
}
```

### Semantics and design contract rules

- **DM Sans hierarchy**: Pair `font="body" weight="medium"` (DM Sans 500) for prose and control labels with `font="heading" weight="bold"` (DM Sans 700) for headings. Passive text never carries hard borders or offset shadows.
- **Native semantic wrappers**: Keep `h1`–`h6`, `p`, `label` (`htmlFor`/`for`), and `a` (`href`, `target`, `download`) on enclosing native elements. Text never adds tab stops or activation handlers.
- **Leading, tracking, and defaults**: `leading="size"` retains each size token's built-in line height (`xs` `1rem` through `5xl` `1`); `leading="tighter"` maps to `1.1`, and `tracking="tighter"` maps to `-0.05em`. Removing a prop restores its default; invalid initial `size` falls back to `base`, while invalid updates keep the previous valid value.
