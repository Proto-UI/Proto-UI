Brutalist Image displays images inside a `rounded-base` frame with a `2px` solid border and 4px hard offset shadow (automatically adapting to theme foreground tokens on dark canvases), supporting fit modes, informative/decorative accessibility, and loading status events.

## Installation

Available starting in `0.3.0-rc.1` and later releases. `Image` is not registered as a `proto-ui add` CLI target; import `BrutalistImageRoot` (aliased as `brutalistImageRoot`) directly from `@proto.ui/prototypes-brutalist` or `@proto.ui/prototypes-brutalist/image`.

## Usage

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { BrutalistImageRoot } from '@proto.ui/prototypes-brutalist/image';

const BrutalistImage = createReactAdapter(React)(BrutalistImageRoot);

export function FramedPhoto() {
  return (
    <BrutalistImage
      source="/images/base-image/landscape.svg"
      a11yMode="informative"
      alternativeText="Mountain ridge bathed in daylight"
      fit="cover"
      surfaceStyle={{ width: '100%', height: '200px' }}
    />
  );
}
```

- **Frame and sizing**: Applies `block max-w-full h-auto`, 5px `rounded-base` corners, a `2px` border, and a static `4px 4px` offset shadow (with no hover lift or press displacement). Dimensions remain consumer-owned.
- **Fit and accessibility**: Switch between `'contain'` (default), `'cover'`, and `'fill'` via `fit`. Keep `a11yMode="informative"` with descriptive `alternativeText` for meaningful images, or set `a11yMode="decorative"` when surrounding text carries the meaning.
- **Loading lifecycle**: Updating `source` begins a new load generation and reports `'idle'`, `'loading'`, `'loaded'`, or `'error'` through `loadingStatus` and `loadingStatusChange`. The frame stays intact on error so your app can render its own fallback UI.
