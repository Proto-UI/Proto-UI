Brutalist Image displays images inside a `rounded-base` frame with a `2px` black border and 4px hard offset shadow, supporting fit modes, informative/decorative accessibility, and loading status events.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

- **CLI target**: `proto-ui add <react|vue|vue2|wc> brutalist-image`
- **Package exports**: import `Root` from `@proto.ui/prototypes-brutalist` or `@proto.ui/prototypes-brutalist/image`

## Usage

- **Fit and sizing**: Choose `'contain'` (default), `'cover'`, or `'fill'` via `fit`. `block max-w-full h-auto` keeps the frame responsive while your layout controls dimensions.
- **Accessibility**: Keep `a11yMode="informative"` with `alternativeText` for meaningful images, or set `a11yMode="decorative"` when neighboring text carries the meaning.
- **Loading lifecycle**: Updating `source` starts a new load generation and reports `'idle'`, `'loading'`, `'loaded'`, or `'error'` via `loadingStatus` and `loadingStatusChange`. The outer frame remains intact on error so your app can render its own fallback UI.
