Virtual List decouples a stable logical key sequence (`itemKeys`) from mounted DOM rows so your application renders content only for the visible viewport and overscan buffer. The Brutalist family applies `rounded-base` (5px) corners, 2px black borders, clipped overflow, and DM Sans typography with no blurred drop shadows.

## Installation

Available starting in `0.3.0-rc.1` and later releases. Import the prototypes from `@proto.ui/prototypes-brutalist/virtual-list` and connect a Web scroll viewport through `@proto.ui/prototypes-base/virtual-list/web`.

## Usage

Virtual List consists of `Root`, `Viewport`, and `Content`. `Root` owns the ordered `itemKeys` collection and outer frame, `Viewport` handles scrolling and inset focus feedback, and `Content` hosts materialized row elements.

```ts
import { AdaptToWebComponent, setElementProps } from '@proto.ui/adapter-web-component';
import {
  virtualListRoot,
  virtualListViewport,
  virtualListContent,
} from '@proto.ui/prototypes-brutalist/virtual-list';
import { attachWebVirtualList } from '@proto.ui/prototypes-base/virtual-list/web';

AdaptToWebComponent(virtualListRoot);
AdaptToWebComponent(virtualListViewport);
AdaptToWebComponent(virtualListContent);

const list = document.querySelector('brutalist-virtual-list-root')!;
const viewport = document.querySelector('brutalist-virtual-list-viewport')!;
const content = document.querySelector('brutalist-virtual-list-content')!;

setElementProps(list, {
  itemKeys: Array.from({ length: 1000 }, (_, i) => `event-${i + 1}`),
  overscanItems: 3,
  maxMaterializedItems: 60,
});

const host = attachWebVirtualList({
  viewport,
  content,
  collection: list.getExposes().getCollection(),
  estimateSize: 68,
  renderItem(key) {
    const row = document.createElement('div');
    row.className = 'border-b-2 border-black px-4 py-3 text-sm';
    row.textContent = key;
    return row;
  },
});

// Scroll to a key on demand and dispose on teardown
host.ensureVisible('event-250', 'center');
// host.dispose();
```

### Anatomy & Accessibility

- `Root` sets `role="region"` with `a11yLabel` and clips overflowing rows inside its 2px black frame without nested double borders.
- `Viewport` inherits `Scroll Area` scrolling and keyboard focus state, showing a 2px inset focus ring on keyboard focus.
- `Content` sets `role="list"` and mounted rows automatically receive `role="listitem"`, `aria-posinset`, and `aria-setsize`.

### Advanced: Custom Materializers

- Each logical list allows one active materializer at a time; `attachWebVirtualList` manages the lease automatically and tears down nodes and observers when `Root` unmounts or disposes.
- Dispose an active materializer before attaching a replacement. Non-Web hosts can integrate through `collection.acquireMaterializer(onRetired)`.
