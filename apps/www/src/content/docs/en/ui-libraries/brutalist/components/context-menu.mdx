Brutalist Context Menu opens a crisp 2px-bordered floating menu with a 3px hard foreground shadow on right-click, a 600 ms touch/pen long press, or `ContextMenu` / `Shift+F10`, with arrow-key navigation, typeahead, and focus restoration.

## Installation

Available starting in `0.3.0-rc.1` and later releases (available in workspace source).

## Usage

```tsx
import {
  BrutalistContextMenuContent,
  BrutalistContextMenuItem,
  BrutalistContextMenuRoot,
  BrutalistContextMenuTrigger,
} from '@/components/proto-ui';

export function Example() {
  return (
    <BrutalistContextMenuRoot>
      <BrutalistContextMenuTrigger className="flex h-36 w-72 items-center justify-center rounded-base border-2 border-dashed border-black bg-secondary-background text-sm font-sans font-medium">
        Right click here
      </BrutalistContextMenuTrigger>
      <BrutalistContextMenuContent>
        <BrutalistContextMenuItem value="back">Back</BrutalistContextMenuItem>
        <BrutalistContextMenuItem value="forward" disabled>
          Forward
        </BrutalistContextMenuItem>
        <BrutalistContextMenuItem value="reload">Reload</BrutalistContextMenuItem>
      </BrutalistContextMenuContent>
    </BrutalistContextMenuRoot>
  );
}
```

### Composition

```text
ContextMenuRoot
├── ContextMenuTrigger
└── ContextMenuContent
    ├── ContextMenuItem
    └── ContextMenuItem
```

- **Headless trigger**: `Trigger` stays unframed so you can wrap any target surface or dashed box. Handled context triggers automatically suppress the browser context menu while leaving ordinary clicks and scrolling untouched.
- **Brutalist depth grammar**: `Content` uses `rounded-base`, a 2px black border, and a 3px hard foreground shadow; `Item` switches to the main accent fill and 2px border on hover, focus, or press without translation jitter.

## API

### Root

Pass `open` for controlled mode. Exposes the `openChange` event and `openContextMenu()`, `close()`, and `toggle()` methods.
