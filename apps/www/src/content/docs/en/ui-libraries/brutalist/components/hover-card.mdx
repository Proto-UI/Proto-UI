## Installation

<InstallCommandCard command="npx @proto.ui/cli@0.2.0 add wc brutalist-hover-card" manager="npm" />

The published `0.2.0` CLI supports `wc`, `react`, and `vue`. For Vue 2.6 or the workspace examples below, install the CLI, Brutalist prototypes and adapter built from the same workspace revision.

## Usage

```tsx
import {
  BrutalistHoverCardRoot,
  BrutalistHoverCardTrigger,
  BrutalistHoverCardContent,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <BrutalistHoverCardRoot openDelay={150} closeDelay={200}>
      <BrutalistHoverCardTrigger>@proto-ui</BrutalistHoverCardTrigger>
      <BrutalistHoverCardContent side="bottom" align="center">
        Host-neutral interaction protocols with bold Neo-Brutalist borders.
      </BrutalistHoverCardContent>
    </BrutalistHoverCardRoot>
  );
}
```

### Composition

```text
BrutalistHoverCardRoot
├── BrutalistHoverCardTrigger
└── BrutalistHoverCardContent
```

- **Root**: Manages open state (`open` or `defaultOpen`), `openDelay` / `closeDelay` timers, and shared `disabled` state.
- **Trigger**: Uses the `bg-main` accent fill with a 4px hard shadow and preserves its pointer hit envelope while settled on hover.
- **Content**: Renders a 2px black-bordered panel with a 3px zero-blur foreground shadow, directional enter animation, and collision avoidance.
