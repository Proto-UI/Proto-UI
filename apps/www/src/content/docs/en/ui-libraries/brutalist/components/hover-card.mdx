## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

- **CLI target**: `proto-ui add <react|vue|vue2|wc> brutalist-hover-card`

## Usage

- Configure `openDelay` (default `700ms`) and `closeDelay` (default `300ms`) on `Root`, or pass `open` for controlled mode.
- `Trigger` wraps the hover target and `Content` supports placement, alignment, offsets, collision avoidance, and Transition props.

### Root

Pass `open: boolean` to enable controlled mode.

### Other parts

- **Trigger**: `disabled?: boolean` (default `false`)
- **Content**: Supports Transition props, plus `side` (default `'bottom'`), `align` (default `'center'`), `sideOffset` (default `4`), `alignOffset` (default `0`), `collisionPadding` (default `0`), and `avoidCollisions` (default `true`)
