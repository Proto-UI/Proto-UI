## Usage

```tsx
import { BrutalistSeparatorRoot } from '../proto-ui/components/react';
```

```tsx
<BrutalistSeparatorRoot />
```

- Set `orientation` to `'horizontal'` or `'vertical'` to match your layout axis; vertical rules stretch automatically across flex containers (`self-stretch`).
- Keep `decorative={true}` (default) for purely visual dividers, or set `decorative={false}` to expose `role="separator"` and `aria-orientation` to assistive technologies.
- Separator is contentless, passive, and adds no built-in margin; control spacing in the surrounding layout.

## API

The following props belong to `Root`:

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default', description: 'Description' }}
  rows={[
    {
      name: 'orientation',
      type: "'horizontal' | 'vertical'",
      default: "'horizontal'",
      description: 'Divider orientation',
    },
    {
      name: 'decorative',
      type: 'boolean',
      default: 'true',
      description:
        'Hides the divider from assistive technologies when true; exposes semantic role="separator" when false',
    },
  ]}
/>

Exposes read-only `orientation` and `decorative` states with no focus or interaction channel.
