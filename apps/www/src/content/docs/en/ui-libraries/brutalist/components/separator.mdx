Separator renders a flat `2px` ink rule with horizontal or vertical orientation and decorative accessibility semantics. Use it between message date groups, Card sections, navigation lists, and form regions.

## Installation

Included in `@proto.ui/prototypes-brutalist@0.2.0`. Add it via the CLI target `brutalist-separator`, or import directly from `@proto.ui/prototypes-brutalist/separator`.

## Usage

- Set `orientation` to `'horizontal'` or `'vertical'` to match your layout axis.
- Keep `decorative={true}` (default) for purely visual dividers, or set `decorative={false}` to expose a semantic separator to assistive technologies.
- Separator adds no built-in margin; control spacing in the surrounding layout.
