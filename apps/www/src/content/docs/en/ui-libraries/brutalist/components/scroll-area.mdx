Scroll Area preserves native host scrolling while styling the scrollbars with 5px rounded paper surfaces and high-contrast Lavender/ink controls. It works well for chat histories, conversation lists, command output, logs, and dense panels.

## Installation

<InstallCommandCard command="npx @proto.ui/cli@latest add wc brutalist-scroll-area" manager="npm" />

Replace `wc` with `react`, `vue`, or `vue2` to generate framework wrappers, or import directly from `@proto.ui/prototypes-brutalist/scroll-area`.

## Usage

```ts
import {
  BrutalistScrollAreaRoot,
  BrutalistScrollAreaViewport,
  BrutalistScrollAreaScrollbar,
  BrutalistScrollAreaThumb,
} from '@proto.ui/prototypes-brutalist/scroll-area';
```

```html
<brutalist-scroll-area-root class="h-48 w-full max-w-80">
  <brutalist-scroll-area-viewport>
    <div class="p-4">Your scrollable content here.</div>
  </brutalist-scroll-area-viewport>
  <brutalist-scroll-area-scrollbar orientation="vertical">
    <brutalist-scroll-area-thumb></brutalist-scroll-area-thumb>
  </brutalist-scroll-area-scrollbar>
</brutalist-scroll-area-root>
```

### Anatomy

```text
Root
├── Viewport
└── Scrollbar
    └── Thumb
```

- `Root`: Shadow-free 5px rounded container with a 2px border; supply explicit dimensions from consumer layout.
- `Viewport`: Native scrollable content viewport that joins the `Tab` order only when overflow exists and draws an inset focus-visible ring with forced-colors outline support.
- `Scrollbar`: High-contrast vertical or horizontal track configured via `orientation`; when both axes mount, the horizontal bar paints a matching pointer-inert lavender corner intersection that releases automatically if the opposite bar unmounts.
- `Thumb`: Derives size and offset from live scroll metrics, maps pointer dragging directly to scroll updates, hides when there is no overflow, and keeps a crisp border in forced-colors mode.

## API

### Props

The following prop belongs to `Scrollbar` (`Root`, `Viewport`, and `Thumb` add no props):

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[{ name: 'orientation', type: "'horizontal' | 'vertical'", default: "'vertical'" }]}
/>

### Exposed States

- **Viewport**: `focused`, `focusVisible`, `scrollAxes`, `scrolling`, `scrollProjection`, `scrollXPosition`, `scrollXVisibleRatio`, `canScrollLeft`, `canScrollRight`, `scrollYPosition`, `scrollYVisibleRatio`, `canScrollUp`, `canScrollDown`.
- **Scrollbar**: `orientation`.
