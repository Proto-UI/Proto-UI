Scroll Area preserves native host scrolling while styling the scrollbars with 5px rounded paper surfaces and high-contrast Lavender/ink controls. It works well for chat histories, conversation lists, command output, logs, and dense panels.

## Installation

Included in `@proto.ui/prototypes-brutalist@0.2.0`. Add it via the CLI target `brutalist-scroll-area`, or import directly from `@proto.ui/prototypes-brutalist/scroll-area`.

## Usage

### Anatomy

Scroll Area is composed of `Root`, `Viewport`, `Scrollbar`, and `Thumb`:

- `Root`: Outer container; give it an explicit size in your layout (the preview uses a `12rem` height with a responsive `20rem` max width).
- `Viewport`: Native scrollable content viewport.
- `Scrollbar`: Horizontal or vertical track configured via `orientation`.
- `Thumb`: Continuously derives its size and offset from live scroll metrics and maps pointer dragging directly to scroll updates, without adding a separate scroll state or focus stop.

### Dual-Track Corner Handling

When both scrollbars are present, each track reserves the lower-right intersection (filled by the horizontal scrollbar with a pointer-inert lavender corner surface) without requiring a separate Corner component. If the opposite track is absent or hidden, that space is released automatically; when a track has no overflow, its surface remains visible while its `Thumb` hides.
