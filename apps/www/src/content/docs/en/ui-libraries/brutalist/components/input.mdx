Brutalist Input is a standalone single-line text input styled with `2.5rem` font-relative height, a 2px border, `rounded-base` corners, no resting shadow, and a crisp black focus ring.

## Preview

<PrototypePreviewer demoId="demo-brutalist-input" initialRuntime="wc" />

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

- **CLI target**: `proto-ui add <react|vue|vue2|wc> brutalist-input`
- **Package exports**: import `brutalistInputRoot` from `@proto.ui/prototypes-brutalist/input` or the package root

## Usage

- Supports uncontrolled `defaultValue` and controlled `value`, normalized text editing and IME composition events, `disabled` / `readOnly` states, and accessible naming via `ariaLabel`, `labelledBy`, and `describedBy`.
- Dimensions stay `rem`-based so the control scales cleanly with root font size. For built-in validation and error messaging, pair with `Field` and `Form`.
