Brutalist Input is a single-line text input built on [Base Input](../../../base/input/), styled with `2.5rem` font-relative height, a 2px border, `rounded-base` (5px) corners, no resting shadow, and a theme-adaptive focus ring across light and dark modes.

## Installation

<InstallCommandCard command="npx @proto.ui/cli@latest add wc brutalist-input" manager="npm" />

Currently available from workspace source. Replace `wc` with `react`, `vue`, or `vue2` to generate a local facade, or import `brutalistInputRoot` directly from `@proto.ui/prototypes-brutalist/input`.

## Usage

```tsx
import { BrutalistInputRoot } from '@/components/ui/brutalist-input';

export function Example() {
  return <BrutalistInputRoot placeholder="Email" inputMode="email" ariaLabel="Email" />;
}
```

- **Controlled and editing state**: Supports uncontrolled `defaultValue` and controlled `value`, normalized editing and IME composition events, `disabled` / `readOnly` states, and accessible naming via `ariaLabel`, `labelledBy`, and `describedBy`.
- **Typography and contrast**: Uses DM Sans (`font-sans font-medium`), muted placeholder ink, and `rem`-based sizing. In dark mode, the focus ring switches to `ring-ring` to maintain clear boundary contrast.
