Surface realizes [Base Surface](/en/ui-libraries/base/surface/) with Brutalist styling, providing a single content slot that renders backgrounds, borders, radii, elevation, and visual interaction states driven by its caller.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import `surfaceRoot` from `@proto.ui/prototypes-brutalist` or `@proto.ui/prototypes-brutalist/surface` (workspace CLI target: `brutalist-surface`).

## Usage

### Basic Example

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { surfaceRoot } from '@proto.ui/prototypes-brutalist/surface';

const Surface = createReactAdapter(React)(surfaceRoot);

export function Summary() {
  return (
    <Surface variant="muted" radius="md" border="none">
      <div style={{ padding: '1rem' }}>Saved locally</div>
    </Surface>
  );
}
```

Both the package root and `/surface` subpath export `surfaceRoot`, along with `SurfaceRootProps` and `SurfaceRootExposes`. Base also exports `asSurfaceRoot` and `SurfaceRootAsHookContract` for custom family styling.

### Passive State Inputs & Composition

- **Consumer-supplied state**: `hovered`, `focusVisible`, `pressed`, and `current` are purely visual inputs. Surface does not listen for events or set ARIA roles, `aria-current`, or tab stops.
- **Preserve native semantics**: When wrapping interactive controls or native anchors, keep roles, activation handlers, `href`, `target`, and `download` on the Button or anchor element itself.
- **Defaults & foreground inheritance**: Removing a prop restores its default. `secondary` applies the Brutalist secondary background independently of `elevation`. When nesting styled Text inside a solid or accent Surface, set `tone="inherit"` on Text to keep matching foreground contrast.

### Pairing with Transition

- Set `fade={true}` to map `transitionState` from an enclosing [Transition](/en/ui-libraries/base/transition/) to opacity (`closed` and `leaving` map to `0`; `entering` and `entered` map to `1`). When `fade={false}`, `transitionState` leaves opacity unchanged.
- On Web, forward a resolved transition duration (finite, non-negative milliseconds) via `--pui-surface-transition-duration` (defaults to `0ms`).
- `scrim` renders a standard dimming backdrop. Visual opacity `0` does not disable interaction or unmount content—keep interaction gating, presence, and focus management on the enclosing Dialog or Transition.
