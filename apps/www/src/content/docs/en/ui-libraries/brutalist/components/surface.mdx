Surface realizes [Base Surface](/en/ui-libraries/base/surface/) in Brutalist styling with 5px `rounded-base` corners, 2px theme borders, and hard offset shadows while keeping semantic and interaction ownership on the enclosing control.

## Usage

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { surfaceRoot } from '@proto.ui/prototypes-brutalist/surface';

const Surface = createReactAdapter(React)(surfaceRoot);

export function Summary() {
  return (
    <Surface variant="secondary" elevation="raised">
      <div className="p-4 font-medium">Saved locally</div>
    </Surface>
  );
}
```

### Passive state inputs and composition

- `hovered`, `focusVisible`, `pressed`, and `current` are caller-supplied visual inputs; Surface installs no event listeners, tab stops, or ARIA roles.
- `elevation="raised"` adds a 4px hard shadow that collapses with a `+4px, +4px` offset on hover or press, switching to static `transition-none` when reduced motion is preferred.
- Enable `fade` to map `transitionState` from [Transition](/en/ui-libraries/base/transition/) to opacity (`closed` and `leaving` -> `0`; `entering` and `entered` -> `1`), reading `--pui-surface-transition-duration` (default `0ms`) on Web.

## API

The following props belong to `Root` (removing a prop restores its default):

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    {
      name: 'variant',
      type: "'transparent' | 'outline' | 'secondary' | 'muted' | 'accent' | 'solid' | 'scrim'",
      default: 'outline',
    },
    {
      name: 'radius',
      type: "'default' | 'none' | 'sm' | 'md' | 'lg' | 'xl' | 'full'",
      default: 'default',
    },
    { name: 'border', type: "'all' | 'bottom' | 'none'", default: 'all' },
    { name: 'elevation', type: "'none' | 'raised'", default: 'none' },
    {
      name: 'transitionState',
      type: "'closed' | 'entering' | 'entered' | 'leaving'",
      default: 'entered',
    },
    { name: 'fade', type: 'boolean', default: 'false' },
    { name: 'hovered', type: 'boolean', default: 'false' },
    { name: 'focusVisible', type: 'boolean', default: 'false' },
    { name: 'pressed', type: 'boolean', default: 'false' },
    { name: 'current', type: 'boolean', default: 'false' },
  ]}
/>

`@proto.ui/prototypes-brutalist/surface` also exports `SurfaceRootProps`, `SurfaceRootExposes`, and the passive Web action composition helper `brutalistActionAppearance` (`BrutalistActionAppearanceOptions`).
