Brutalist Combobox combines a searchable text input with an anchored option list using 5px `rounded-base` corners, 2px black borders, and hard offset shadows. `value` always tracks a committed option key separately from the editable `inputValue`.

## Installation

Combobox will be available starting in `0.3.0-rc.1` and later releases (`@proto.ui/prototypes-brutalist/combobox`).

## Usage

```tsx
import {
  comboboxRoot,
  comboboxInput,
  comboboxTrigger,
  comboboxContent,
  comboboxItem,
  comboboxEmpty,
} from '@proto.ui/prototypes-brutalist/combobox';
```

```html
<brutalist-combobox-root a11y-label="Framework">
  <brutalist-combobox-input placeholder="Select framework..."></brutalist-combobox-input>
  <brutalist-combobox-trigger>▾</brutalist-combobox-trigger>
  <brutalist-combobox-content>
    <brutalist-combobox-item value="next.js" text-value="Next.js">Next.js</brutalist-combobox-item>
    <brutalist-combobox-item value="sveltekit" text-value="SvelteKit"
      >SvelteKit</brutalist-combobox-item
    >
    <brutalist-combobox-item value="astro" text-value="Astro">Astro</brutalist-combobox-item>
    <brutalist-combobox-empty>No framework found.</brutalist-combobox-empty>
  </brutalist-combobox-content>
</brutalist-combobox-root>
```

### Parts

- **Root**: Manages selected option `value`, search text `inputValue`, and popup `open` state, each independently controllable.
- **Input**: Flat editable field with crisp focus rings; keeps focus during arrow-key navigation and avoids selecting during IME composition.
- **Trigger**: Raised 4px hard-shadow button to toggle the option list.
- **Content**: Anchored floating popup panel with a 3px hard shadow and configurable placement, alignment, offset, and collision padding.
- **Item / Empty**: Matches case- and diacritic-insensitively against `textValue` and `keywords`. Set `filter={false}` to filter options in your own application logic.
