Brutalist Combobox combines a searchable text input with an anchored option list. `value` always tracks a committed option key separately from the editable `inputValue`, so unmatched query text is never silently accepted as a selection.

## Usage

### Parts

Combobox consists of `Root`, `Input`, `Content`, `Item`, `Empty`, and `Trigger`:

- **Root**: Manages selected option `value`, search text `inputValue`, and popup `open` state, each independently controllable.
- **Input**: Single-line editor that keeps focus during arrow-key navigation and avoids selecting during IME composition.
- **Content**: Anchored option popup with configurable placement, alignment, offset, and collision padding.
- **Item**: Selectable option matched case- and diacritic-insensitively against `textValue` and `keywords`. Disabled or duplicate-valued items cannot be selected.
- **Empty**: Shown automatically when no options match the query.
- **Trigger**: Button to open or close the option list.

### Custom filtering

Built-in filtering is enabled by default (`filter={true}`). Set `filter={false}` to filter options in your own application logic and render only matching `Item` children.

Pass `value`, `inputValue`, or `open` to control each state independently.

### Other parts

- **Input**: `placeholder?: string`, `a11yLabel?: string`, `name?: string` (all default to `''`)
- **Content**: `side` (default `'bottom'`), `align` (default `'start'`), `sideOffset` (default `4`), `collisionPadding` (default `8`)
- **Item**: `value`, `textValue`, `keywords` (all default to `''`), `disabled?: boolean` (default `false`)
- **Empty**: No props
- **Trigger**: `disabled?: boolean` (default `false`)
