Brutalist Command renders an inline, searchable list of commands. Activating an item with `Enter` or pointer emits `execute` so your application can perform the corresponding action.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

## Usage

### Parts

Command consists of `Root`, `Input`, `Content`, `Item`, and `Empty`:

- **Root**: Manages open state (`defaultOpen` defaults to `true`), query text `inputValue`, filtering, and keyboard looping. `value`, `inputValue`, and `open` can each be controlled independently.
- **Input**: Single-line search input that retains focus while navigating items with arrow keys and ignores selection during IME composition.
- **Content**: Inline panel displaying matching commands.
- **Item**: Executable command entry matched case- and diacritic-insensitively over `textValue` and `keywords`. Disabled or duplicate-valued items cannot execute.
- **Empty**: Shown when no commands match the query.

### Executing commands

Typing filters the command list without running anything; pressing `Enter` or clicking an item emits `execute` with the chosen command. Set `filter={false}` to filter items in your own code.

Pass `value`, `inputValue`, or `open` to control each state independently.

### Other parts

- **Input**: `placeholder?: string`, `a11yLabel?: string`, `name?: string` (all default to `''`)
- **Content**: `side` (default `'bottom'`), `align` (default `'start'`), `sideOffset` (default `4`), `collisionPadding` (default `8`)
- **Item**: `value`, `textValue`, `keywords` (all default to `''`), `disabled?: boolean` (default `false`)
- **Empty**: No props
