Brutalist Command renders a high-contrast searchable command menu with 2px borders, hard offset shadows, and crisp active highlights. Clicking an item or pressing `Enter` emits `execute`.

## Installation

Available starting in `0.3.0-rc.1` and later releases (`@proto.ui/prototypes-brutalist/command`).

## Usage

```tsx
import {
  commandRoot,
  commandInput,
  commandContent,
  commandItem,
  commandEmpty,
  commandDialogContent,
} from '@proto.ui/prototypes-brutalist/command';
```

### Composition

```text
CommandRoot
├── CommandInput
└── CommandContent
    ├── CommandItem
    └── CommandEmpty
```

- **Surface grammar**: `CommandRoot` owns the 2px border, `rounded-base` corners, and 4px hard shadow, while `CommandInput` uses a clean bottom divider without double inner borders.
- **Dialog composition**: Pair `DialogRoot`, `DialogTrigger`, `DialogMask`, and `CommandDialogContent` to present a Brutalist command modal.
- **Filtering and keyboard**: Matches case- and diacritic-insensitively over `textValue` and `keywords`, or set `filter={false}` for external filtering. Focus stays in `Input` during arrow navigation and IME composition never commits.

### Other Parts & Events

- **Input**: `placeholder`, `a11yLabel`, and `name` default to `''`.
- **Content**: `side="bottom"`, `align="start"`, `sideOffset={4}`, `collisionPadding={8}`.
- **Item**: `value`, `textValue`, and `keywords` default to `''`; `disabled` defaults to `false`.
- **Empty / DialogContent**: No public props; `DialogContent` inherits modal state from `DialogRoot`.
- **Events**: `Root` emits `execute`, `valueChange`, `inputValueChange`, and `openChange`.
