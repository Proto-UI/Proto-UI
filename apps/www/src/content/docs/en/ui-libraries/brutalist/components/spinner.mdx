Spinner is a visual loading indicator drawn as a 2px `currentColor` circular ring with an open arc and no fill or soft shadow, suited for inline button states and loading regions.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototype from `@proto.ui/prototypes-brutalist/spinner` (workspace CLI target: `brutalist-spinner`).

## Usage

- **Sizes**: `size` supports `'sm'` (16px), `'md'` (24px, default), and `'lg'` (32px); removing the prop restores `'md'`.
- **Reduced motion**: Rotates linearly once every 1000ms by default. Under `prefers-reduced-motion: reduce`, rotation stops while the open arc remains visible as a non-color cue.
- **Parent-owned semantics**: Spinner is `aria-hidden` and non-focusable. Compose it inside a parent Button or status/busy region that manages `aria-busy`, accessible text, timing, and focus continuity.
