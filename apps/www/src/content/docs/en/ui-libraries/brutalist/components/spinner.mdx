Spinner is a visual-only loading indicator in the Brutalist family drawn as a 2px `currentColor` open-arc circular ring with no fill or soft shadow, suited for inline buttons, badges, and async status regions.

## Installation

Available starting in `0.3.0-rc.1` and later releases. Import the prototype from `@proto.ui/prototypes-brutalist/spinner` (workspace CLI target: `brutalist-spinner`).

## Usage

```tsx
import { BrutalistSpinnerRoot } from '../proto-ui/components/react';

export function Example() {
  return <BrutalistSpinnerRoot size="md" />;
}
```

- **Sizes**: `size` accepts `'sm'` (16px), `'md'` (24px, default), and `'lg'` (32px); removing the prop restores `'md'`.
- **Reduced motion**: Rotates linearly once every 1000ms by default. Under `prefers-reduced-motion: reduce`, rotation stops while the open arc remains visible as a non-color orientation cue.
- **Parent-owned semantics**: Spinner is always contentless, `aria-hidden="true"`, roleless, and non-focusable. Compose it inside a parent Button, Badge, or `Async Region` that owns `aria-busy`, accessible text, timing, and focus continuity.
