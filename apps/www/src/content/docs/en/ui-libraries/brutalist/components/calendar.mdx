Calendar is a Gregorian control with `single` (default), `multiple` and `range` selection modes. `value` uses YYYY-MM-DD; the canonical visible `month` uses YYYY-MM. Selection and month can each be controlled. A successful `requestMonth` means a proposal was emitted, not that the owner accepted it. Refused or pending cross-month keyboard navigation keeps the current valid Tab entry; accepted navigation materializes and focuses only after canonical month changes and current availability is checked. Focus is not stolen back from an external control.

## Range and multiple selection

| Mode       | Controlled / initial selection              | Request callback             |
| ---------- | ------------------------------------------- | ---------------------------- |
| `single`   | `value` / `defaultValue`: YYYY-MM-DD string | `onValueChange({ value })`   |
| `multiple` | `values` / `defaultValues`: date array      | `onValuesChange({ values })` |
| `range`    | `range` / `defaultRange`: `{ from?, to? }`  | `onRangeChange({ range })`   |

Multiple selection toggles each activated day. Arrays are deduplicated, sorted by civil date and copied on input and output. `minSelected` defaults to 0; `maxSelected` is unbounded when omitted. Adding a day can build up from empty toward the minimum; removing a day must leave at least the minimum. Explicit `requestValues` replacements validate the complete array against both count limits. Range selection starts with `{ from }`; a second activation completes an inclusive `{ from, to }`, ordering reversed endpoints. Activating a day after completion starts a new range. `{}` clears a range. A same-day range is complete when `minNights=0` (the default). `minNights` and `maxNights` constrain the civil-day interval between endpoints; they do not count selected cells. Omitted maxima are unbounded. Limits must be nonnegative integers.

`min`, `max` and Root `unavailable` apply to every selected date. A completed range crossing an unavailable date is rejected and retains its anchor. Put whole-date restrictions on Root `unavailable`; local Day `disabled` only disables that authored control. Root `disabled` and `readOnly` reject selection requests. Changing eligibility never silently rewrites an owner's current selection.

`requestValue(date)` activates a date in the current mode. `requestValues(dates)` and `requestRange(range)` replace the corresponding selection only in that mode. A true result means a request was emitted; controlled rendering changes only after the matching owner prop is accepted. `getValues()` and `getRange()` return copies. `default*` inputs initialize once, and switching modes preserves each mode's separate selection. Root also exposes `mode`, `selectedCount` and `rangeComplete`.

Day exposes `rangeStart`, `rangeEnd`, `rangeMiddle` and `rangePending` alongside `selected`. A pending anchor has start/pending; a one-day complete range has start/end; interior days have middle. Every date in a complete range is selected. The family recipes distinguish endpoints from middle segments, and Grid projects `aria-multiselectable` for range and multiple modes. Keyboard navigation is unchanged; Enter or Space activates the focused date.

## Composition and clock ownership

The ten atoms are Root, Caption, Heading, Previous, Next, Grid, Weekdays, Weekday, Row and Day. Compose seven Weekday atoms with offsets 0–6 inside Weekdays, then optionally retain six indexed Rows (`index` 0–5) of Day atoms with offsets 0–41 as capacity. By default the canonical month displays the minimum complete 4, 5 or 6 weeks; Root `fixedWeeks=true` explicitly reserves six. Root exposes `weekCount`; indexed unused Rows and unused offset Days expose `hidden` and are hidden/disabled off the focus path. Unindexed rows and explicit dates remain application-authored. Weekday labels and date order follow Root `weekStartsOn` (0 = Sunday) and `locale`; full localized civil dates name the grid cells. `direction="rtl"` mirrors Left/Right navigation, leaving Up/Down and week boundaries unchanged. Navigation controls accept `a11yLabel` for icon-only accessible naming.

The host supplies `today` as a civil-date string. Base never reads a clock or timezone: no `today` means no current-date marker. Today and selected are independent, including unavailable dates; today projects `aria-current="date"`. Initial month priority is explicit `month`, explicit `defaultMonth`, the active mode’s selected date (single value, earliest multiple value, or range start), supplied `today`, then deterministic 1970-01. Later clock updates do not silently navigate. `unavailable` is a string array; invalid inputs retain their prior valid value/default. Root disabled combines with local Day/Previous/Next disabled policy; readOnly blocks selection while allowing browsing.

## Explicit month/year caption composition

The demo uses real family Select controls and `bindCalendarCaption(source, {month, year})` through public Calendar month/disabled state and `requestMonth`. Caption itself is only a semantic group. Month and year selectors are application composition, not an internal Calendar Select dependency. The helper always restores canonical control values after rejection or pending acceptance, subscribes to later commits, and exposes `dispose()` for teardown. The demo owns an explicit year option list (not a Calendar limit), local-clock today, midnight/visibility refresh and complete controlled prop records. The Month and Year triggers pass stable names through the public Select `accessibleLabel` prop; Select Value independently displays the current month or year. The demo does not write Adapter-owned ARIA attributes. Computed accessible names, name stability after selection, keyboard interaction and focus return still require current-source browser evidence; screen-reader acceptance remains separate.

Neo uses its own 36px date / 28px navigation geometry, 2px borders and hard-shadow root. Reference: neobrutalism-components Calendar at commit 3306a802724874a85f93079702b2795370a279d4, not the Shadcn compact recipe.

These props belong to Root. Day defaults `date` to `''`, `offset` to `0` and `disabled` to `false`. Grid and Heading have no props. Row `index` has no default. Caption defaults `a11yLabel` to `Calendar navigation`. Previous and Next accept the Button props and default `a11yLabel` to `Previous month` and `Next month`. Weekdays has no props. Weekday defaults `offset` to `0`.
