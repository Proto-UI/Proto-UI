## Usage

### Selection modes

<PrototypePreviewer
  demoId="demo-brutalist-calendar-selection"
  initialRuntime="wc"
  runtimes={['wc', 'react', 'vue', 'vue2']}
/>

| Mode       | Controlled / initial prop                     | Change event                 |
| ---------- | --------------------------------------------- | ---------------------------- |
| `single`   | `value` / `defaultValue`: `YYYY-MM-DD` string | `onValueChange({ value })`   |
| `multiple` | `values` / `defaultValues`: date string array | `onValuesChange({ values })` |
| `range`    | `range` / `defaultRange`: `{ from?, to? }`    | `onRangeChange({ range })`   |

- **Multiple mode**: Activating a day toggles it in a deduplicated, chronologically sorted array. Constrain counts with `minSelected` and `maxSelected`.
- **Range mode**: The first activation sets `{ from }` and the second completes an inclusive `{ from, to }` (automatically sorting reversed picks). Activating another day starts a new range, and `{}` clears it. `minNights` (default `0`, allowing single-day ranges) and `maxNights` constrain the interval between endpoints.
- **Constraints**: Use `min`, `max`, and `unavailable` to restrict selectable dates. Ranges crossing an unavailable date are rejected while keeping the start anchor. `readOnly` blocks selection changes while still allowing month navigation.
- **Range states**: `Day` exposes `rangeStart`, `rangeEnd`, `rangeMiddle`, and `rangePending` alongside `selected` for styling range endpoints and spans.

### Parts and month layout

Calendar is composed of `Root`, `Caption`, `Heading`, `Previous`, `Next`, `Grid`, `Weekdays`, `Weekday`, `Row`, and `Day`:

- By default, the grid shows the 4–6 weeks required for the active month and `weekStartsOn` (`0` = Sunday); set `fixedWeeks={true}` to always render 6 weeks. You can render 6 indexed `Row` containers (`0`–`5`) with 42 offset `Day` cells (`0`–`41`) and let unused rows and cells hide automatically off the focus path.
- Calendar does not read the system clock; pass `today` as a `YYYY-MM-DD` string to highlight the current date (`aria-current="date"`). Initial month priority is `month` > `defaultMonth` > active mode's selected date > `today` > `1970-01`.
- `direction="rtl"` mirrors Left/Right arrow navigation while keeping Up/Down and week boundaries intact.

### Month and year selectors

`Caption` is a semantic grouping container. To add month and year dropdown navigation, pair Calendar's `month`, `disabled`, and `requestMonth` with real family Select controls via `bindCalendarCaption(source, { month, year })`, and call `dispose()` on teardown.

Pass `value`, `values`, `range`, or `month` to control each state independently.

### Other parts

- **Day**: `date?: string` (default `''`), `offset?: number` (default `0`), `disabled?: boolean` (default `false`)
- **Row**: `index?: number`
- **Weekday**: `offset?: number` (default `0`)
- **Caption**: `a11yLabel?: string` (default `'Calendar navigation'`)
- **Previous / Next**: Accept Button props; `a11yLabel` defaults to `'Previous month'` and `'Next month'`
- **Grid / Heading / Weekdays**: No props

### Methods

- `requestValue(date)`, `requestValues(dates)`, `requestRange(range)`, `requestMonth(month)`, `getValues()`, `getRange()`
