## Installation

Brutalist Popover is currently available from the workspace source and not yet included in the 0.2.0 stable CLI release. Import the prototypes directly from `@proto.ui/prototypes-brutalist/popover` and adapt them for your target runtime:

```ts
import {
  popoverRoot,
  popoverTrigger,
  popoverContent,
  popoverTitle,
  popoverDescription,
  popoverClose,
} from '@proto.ui/prototypes-brutalist/popover';
```

## Usage

```tsx
<BrutalistPopover>
  <BrutalistPopoverTrigger>Open Popover</BrutalistPopoverTrigger>
  <BrutalistPopoverContent align="start">
    <BrutalistPopoverTitle>Dimensions</BrutalistPopoverTitle>
    <BrutalistPopoverDescription>Set the dimensions for the layer.</BrutalistPopoverDescription>
  </BrutalistPopoverContent>
</BrutalistPopover>
```

### Composition

```text
BrutalistPopoverRoot
├── BrutalistPopoverTrigger
└── BrutalistPopoverContent
    ├── BrutalistPopoverTitle
    ├── BrutalistPopoverDescription
    └── BrutalistPopoverClose
```

- **Brutalist visual grammar**: `Trigger` and `Close` use `rounded-base` (5px), 2px black borders, 4px zero-blur offset shadows, and instant press-only snap; `Content` uses a 3px foreground offset shadow without hover or press translation.
- **Positioning & dismissal**: Supports `side`, `align`, `sideOffset`, `alignOffset`, and `collisionPadding`. Outside presses, `Escape`, `Close`, and focus moving outside both `Trigger` and `Content` request dismissal.

## API

`Root` exposes read-only state `open`, methods `openPopover`, `close`, and `toggle`, and the `openChange` event.
