## Usage

### Anatomy

Popover is composed of `Root`, `Trigger`, `Content`, `Title`, `Description`, and `Close`:

- `Root`: Manages the open state of the popover.
- `Trigger`: Anchors and toggles the popover.
- `Content`: Positioned relative to `Trigger` with `side`, `align`, `sideOffset`, `alignOffset`, and `collisionPadding`.
- `Title` / `Description`: Provide accessible labelling and description for the floating dialog.
- `Close`: Requests dismissal when activated.

### Positioning, Focus & Dismissal

- Outside presses, focus leaving both `Trigger` and `Content`, `Escape`, and `Close` all request dismissal.
- Moving focus between `Trigger` and portalled `Content` is treated as staying inside the popover.
- When closed due to focus moving outside, focus stays on the newly focused external element instead of returning to `Trigger`, and the request reports `focusReason` as `'programmatic'`.

### Controlled vs. Uncontrolled

- Use `defaultOpen` on `Root` for uncontrolled state.
- Pass `open` and handle `openChange` for controlled mode. If your handler declines a `focus.outside` request, `Content` stays visible without trapping external focus, and later interactions can request dismissal again.

### Navigation Presentation

Set `presentation="navigation"` on `Trigger` and `Content` to use the available anchored area with internal scrolling for link lists while preserving native browser link activation.

## API

The first three props (`defaultOpen`, `disabled`, `a11yLabel`) belong to `Root` (pass `open` for controlled mode). `presentation` belongs to `Content` and `Trigger`:

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'a11yLabel', type: 'string', default: "''" },
    { name: 'presentation', type: "'default' | 'navigation'", default: 'default' },
  ]}
/>

Other part props and defaults:

- **Content**: Also accepts Transition props; `side` defaults to `'bottom'`, `align` to `'center'`, `sideOffset` to `4`, `alignOffset` to `0`, and `collisionPadding` to `8`.
- **Title**, **Description**, **Close**: No props.
