## Usage

```tsx
import {
  BrutalistButton,
  BrutalistDialogClose,
  BrutalistDialogCloseIcon,
  BrutalistDialogContent,
  BrutalistDialogDescription,
  BrutalistDialogFooter,
  BrutalistDialogHeader,
  BrutalistDialogMask,
  BrutalistDialogRoot,
  BrutalistDialogTitle,
  BrutalistDialogTrigger,
} from '@/components/proto-ui/brutalist';

export function BrutalistDialogExample() {
  return (
    <BrutalistDialogRoot>
      <BrutalistDialogTrigger>Edit Profile</BrutalistDialogTrigger>
      <BrutalistDialogMask />
      <BrutalistDialogContent>
        <div className="min-w-0 pe-12">
          <BrutalistDialogHeader>
            <BrutalistDialogTitle>Edit profile</BrutalistDialogTitle>
            <BrutalistDialogDescription>
              Make changes to your profile here. Click save when you&apos;re done.
            </BrutalistDialogDescription>
          </BrutalistDialogHeader>
        </div>
        <BrutalistDialogFooter>
          <BrutalistDialogClose>
            <BrutalistButton variant="neutral">Cancel</BrutalistButton>
          </BrutalistDialogClose>
          <BrutalistDialogClose>
            <BrutalistButton>Save changes</BrutalistButton>
          </BrutalistDialogClose>
        </BrutalistDialogFooter>
        <BrutalistDialogCloseIcon />
      </BrutalistDialogContent>
    </BrutalistDialogRoot>
  );
}
```

### Composition

```text
BrutalistDialogRoot
├── BrutalistDialogTrigger
├── BrutalistDialogMask
└── BrutalistDialogContent
    ├── BrutalistDialogHeader
    │   ├── BrutalistDialogTitle
    │   └── BrutalistDialogDescription
    ├── BrutalistDialogFooter
    │   └── BrutalistDialogClose
    └── BrutalistDialogCloseIcon
```

### Visual and interaction grammar

- **Trigger and close controls**: The opener renders as a sky-blue hard-shadow button, while the top-right close button (accessible name `Close`) is a canary-yellow control that switches to coral on hover, settles into its shadow on press, and displays a crisp offset focus ring.
- **Footer dismiss action**: `Close` provides dismissal semantics without adding its own chrome. Wrap a `BrutalistButton` child inside `Close` to keep standard button styling and a single `Tab` stop.
- **Mask behavior**: A non-passthrough `Mask` (`passthrough={false}`) prevents pointer defaults from stealing restored focus while `Content` governs dismissal rules.
