## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

- **CLI target**: `proto-ui add <react|vue|vue2|wc> brutalist-dialog`

## Usage

- **Trigger and close controls**: The opener uses a sky-blue hard-shadow button, while the top-right close control (accessible name `Close`) is a dedicated canary-yellow rounded button that turns coral on hover and removes its shadow on press while keeping a crisp focus outline.
- **Footer dismiss action**: `Close` provides dismissal semantics without adding its own button chrome. Wrap a `Button` child inside `Close` for footer dismiss actions while keeping a single `Tab` stop.
- **Mask behavior**: A non-passthrough `Mask` (`passthrough={false}`) prevents pointer defaults from stealing restored focus, while `Content` governs dismissal rules.

Pass `open: boolean` to enable controlled mode.

### Other parts

- **Mask**: `passthrough?: boolean` (default `false`) and Transition props
- **Content**: No own props. Compositions that need to choose an entry-focus policy can use [Base Dialog Content](/en/ui-libraries/base/dialog/); this does not extend the Brutalist Content prop boundary.
- **Trigger / Title / Description / Close**: No props
