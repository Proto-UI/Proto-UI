## Usage

### Anatomy

Toast is composed of `Root`, `Viewport`, `Title`, `Description`, `Action`, and `Close`:

- `Root`: Manages open state, transition durations, timer lifecycle, and live-region `politeness`.
- `Viewport`: Landmark region for notifications with a configurable `F8` focus hotkey.
- `Title` / `Description`: Notification heading and body copy.
- `Action`: Signals user action intent and requests dismissal (application code handles the side effect).
- `Close`: Dismisses the notification when activated.

### Timing & Dismissal

- Stays open for `5000ms` by default; set `duration={0}` to keep a notification open until dismissed.
- Hovering over the toast or focusing `Action` / `Close` pauses the remaining timer automatically.
- Activating `Close`, pressing `Escape` while focused, or activating `Action` requests dismissal. In controlled mode (`open`), timeout emits a single dismissal request until your state updates.
- Manage multi-toast queuing or global dispatch at the application level.

## API

The following props belong to `Root` (pass `open` for controlled mode):

    { name: 'paused', type: 'boolean', default: 'false' },
    { name: 'politeness', type: "'polite' | 'assertive'", default: 'polite' },
  ]}

Other part props and defaults:

- **Viewport**: `a11yLabel` defaults to `'Notifications'`; `hotkey` defaults to `'F8'`.
- **Title**, **Description**: No props.
- **Action**: `disabled` defaults to `false`; `a11yLabel` is optional with no default.
- **Close**: `disabled` defaults to `false`.
