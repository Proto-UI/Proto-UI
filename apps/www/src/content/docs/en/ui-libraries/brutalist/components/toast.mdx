Toast displays brief live notifications styled with Brutalist 5px corners, 2px borders, and 3px hard shadows, supporting auto-dismiss timers, pause on hover or focus, keyboard shortcuts, and explicit action buttons.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import the prototypes directly from `@proto.ui/prototypes-brutalist/toast` and adapt them for your target runtime.

```ts
import {
  toastViewport,
  toastRoot,
  toastTitle,
  toastDescription,
  toastAction,
  toastClose,
} from '@proto.ui/prototypes-brutalist/toast';
```

## Usage

```tsx
<BrutalistToastViewport a11yLabel="Notifications">
  <BrutalistToastRoot defaultOpen={false} duration={5000}>
    <BrutalistToastTitle>Event has been created</BrutalistToastTitle>
    <BrutalistToastDescription>Sunday, December 03, 2023 at 9:00 AM</BrutalistToastDescription>
    <BrutalistToastAction a11yLabel="Undo event creation">Undo</BrutalistToastAction>
    <BrutalistToastClose>Dismiss</BrutalistToastClose>
  </BrutalistToastRoot>
</BrutalistToastViewport>
```

Toast is composed of `Root`, `Viewport`, `Title`, `Description`, `Action`, and `Close`:

- Stays open for `5000ms` by default; set `duration={0}` to keep a notification open until dismissed.
- Hovering over the toast or focusing `Action` / `Close` pauses the remaining timer automatically.
- Activating `Close`, pressing `Escape` while focused, or activating `Action` requests dismissal. In controlled mode (`open`), timeout emits a single dismissal request until your state updates.
- `Viewport` provides a configurable `F8` focus hotkey; manage multi-toast queuing at the application level.

Events and exposed methods:

- **Events**: `Root` emits `openChange` (`{ open: boolean; reason: string }`); `Action` emits `action` (`void`).
- **Methods**: `Root` exposes `openToast()`, `close(reason?)`, `pause()`, and `resume()`; `Viewport` exposes `focusFirst()`.
