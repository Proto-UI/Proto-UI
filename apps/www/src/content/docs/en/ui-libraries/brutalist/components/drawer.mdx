## Usage

### Sizing, placement, and scrolling

- **Sizing**: `top` and `bottom` drawers size to fit their content by default (capped at the available height minus 6 root-text units), while `left` and `right` drawers use fractional width (default cap of 20 root-text units). Customize limits with `minExtent` and `maxExtent` using neutral units (`'logical'`, `'root-text'`, `'available'`, or `'available-minus-root-text'`), such as `maxExtent={{ unit: 'logical', value: 480 }}`, instead of overriding CSS `width`.
- **Scrolling and layout**: `Content` acts as an `overflow-y-auto` scroll container. When placing `Root` directly inside a CSS Grid, pass `hostStyle={{ display: 'contents' }}` in React (or `display: contents` on Web Components) to avoid an extra empty grid track.
- **Drag dismissal**: Set `dragDismissible={false}` on `Content` to disable drag-to-close while keeping `Close`, `Escape`, and outside dismissal active.

- Provide a non-empty `snapPoints` array of fractions in `(0, 1]` relative to the safe cap to enable multi-stop snapping, paired with `defaultSnapPoint` (uncontrolled) or `snapPoint` / `snapPointChange` (controlled).
- In content-fit mode, `Handle` acts as a pointer drag affordance; with explicit snap points enabled, `Handle` also exposes a named `separator` with arrow-key and `Home` / `End` resizing.

Pass `open: boolean` to enable controlled mode.

### Other parts

- **Mask**: `passthrough?: boolean` (default `false`) and Transition props
- **Content**: `side` (default `'bottom'`), `minExtent`, `maxExtent`, `snapPoints`, `snapPoint`, `defaultSnapPoint`, `dragDismissible`, and Transition props
- **Handle**: `disabled?: boolean` (default `false`), `a11yLabel?: string` (default `'Resize drawer'`)
- **Trigger / Title / Description / Header / Footer / Close / AcceptedSide**: No props
