Brutalist Drawer slides a crisp 2px black-bordered, 5px-rounded modal panel from any of the four screen edges with content-fit or fractional sizing, scrollable long content, drag dismissal, and optional snap points.

## Installation

Available starting in `0.3.0-rc.1` and later releases (`@proto.ui/prototypes-brutalist/drawer`).

## Usage

```tsx
import {
  BrutalistDrawerRoot,
  BrutalistDrawerTrigger,
  BrutalistDrawerMask,
  BrutalistDrawerContent,
  BrutalistDrawerHandle,
  BrutalistDrawerHeader,
  BrutalistDrawerTitle,
  BrutalistDrawerDescription,
  BrutalistDrawerFooter,
  BrutalistDrawerClose,
} from '../proto-ui/components/react';
```

```tsx
<BrutalistDrawerRoot>
  <BrutalistDrawerTrigger>Open Drawer</BrutalistDrawerTrigger>
  <BrutalistDrawerMask />
  <BrutalistDrawerContent side="bottom">
    <BrutalistDrawerHandle />
    <BrutalistDrawerHeader>
      <BrutalistDrawerTitle>Are you absolutely sure?</BrutalistDrawerTitle>
      <BrutalistDrawerDescription>
        Publish the latest build to the staging environment.
      </BrutalistDrawerDescription>
    </BrutalistDrawerHeader>
    <BrutalistDrawerFooter>
      <BrutalistDrawerClose>Cancel</BrutalistDrawerClose>
    </BrutalistDrawerFooter>
  </BrutalistDrawerContent>
</BrutalistDrawerRoot>
```

### Composition & visual grammar

```text
DrawerRoot
├── DrawerTrigger
├── DrawerMask
└── DrawerContent
    ├── DrawerHandle
    ├── DrawerHeader
    │   ├── DrawerTitle
    │   └── DrawerDescription
    └── DrawerFooter
        └── DrawerClose
```

- **Elevation and motion**: `Trigger` and `Close` render raised `4px 4px` hard shadows with `+4px, +4px` press snap. `Content` applies `5px` (`rounded-base`) rounding on its exposed edge with a 200ms slide transition, and `Mask` fades over 150ms.
- **Sizing and scrolling**: Vertical drawers fit their content height up to available height minus 6 root-text units; horizontal drawers cap at 20 root-text units by default. Wrap scrollable body regions in `flex-1 overflow-y-auto`.
- **Snap points and accessibility**: Supplying a non-empty `snapPoints` array in `(0, 1]` upgrades `Handle` to a named `separator` with arrow-key and `Home`/`End` resizing while preserving dark-mode contrast via semantic foreground tokens.

## API

### Root

Pass `open` for controlled mode and subscribe to `openChange`. Exposes `openDrawer()`, `close()`, and `toggle()`.

  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}

    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'a11yLabel', type: 'string', default: "''" },
  ]}
/>

### Content

Exposes `open`, `snapPoint`, `dragging`, `dragProgress`, `offsetPercentage`, `extentValid`, `requestSnapPoint()`, and `snapPointChange`.
