Brutalist Skeleton is a direct styled-only visual placeholder: a static square Yandu Lavender surface with an ink border and hard shadow. It is passive, contentless, excluded from the accessibility tree, and owns no repeating shimmer or pulse.

Use it inside a parent async/loading region when an unresolved layout benefits from visual shape feedback. The parent owns loading and `aria-busy` state, announcements, placeholder-to-content replacement timing, and focus continuity. Skeleton does not create those semantics; any added motion must also respect reduced-motion preferences.
