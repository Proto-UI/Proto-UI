Use Skeleton to show a static placeholder while content is loading. It renders a 5px rounded neutral surface with a `2px` black border, no outer shadow, and no built-in shimmer so layout geometry stays crisp and consumer-owned.

Included in `@proto.ui/prototypes-brutalist@0.2.0`. Add it via the CLI target `brutalist-skeleton` (replace `react` with `wc`, `vue`, or `vue2` for your target runtime), or import directly from `@proto.ui/prototypes-brutalist/skeleton`:

## Usage

```tsx
import { BrutalistSkeletonRoot } from '../proto-ui/components/react';

export function Example() {
  return <BrutalistSkeletonRoot className="h-5 w-48 rounded-full" />;
}
```

- **Consumer-owned sizing**: Skeleton emits no width or height tokens of its own; pass layout utilities such as `h-4 w-48` or `h-12 w-12 rounded-full` to match the incoming content shape.
- **Visual-only semantics**: Skeleton is contentless, non-focusable, and excluded from the accessibility tree (`aria-hidden="true"`). Let the parent loading region manage `aria-busy`, status announcements, replacement timing, and focus continuity.
- **Static motion contract**: No built-in pulse animation is applied. If you layer custom motion in your application, respect `prefers-reduced-motion`.
