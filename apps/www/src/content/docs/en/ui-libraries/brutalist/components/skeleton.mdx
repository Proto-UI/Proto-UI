## Installation

Included in `@proto.ui/prototypes-brutalist@0.2.0`. Add it via the CLI target `brutalist-skeleton`, or import directly from `@proto.ui/prototypes-brutalist/skeleton`.

## Usage

- Place Skeleton inside a parent loading region and size it via layout styles to match the expected content shape.
- Skeleton is excluded from the accessibility tree; let the parent container manage `aria-busy`, status announcements, placeholder replacement timing, and focus continuity.
- If you add custom motion, respect `prefers-reduced-motion`.
