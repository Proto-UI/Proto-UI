## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

- **CLI target**: `proto-ui add <react|vue|vue2|wc> brutalist-card`

## Usage

Card provides four parts: `Root`, `Header`, `Content`, and `Footer`:

- **Root**: Passive paper panel with 5px rounded corners, a `2px` black frame, and a 4px hard black shadow.
- **Header / Footer**: Handle header and footer layout and spacing with no section borders by default.
- **Content**: Provides horizontal padding for body content.

Render titles and descriptions as ordinary text elements, and place `Button` or link elements inside the card whenever interactive actions are needed.

## API

`Root`, `Header`, `Content`, and `Footer` render your children and declare no props of their own.
