Brutalist Card is a passive grouping surface styled with 5px rounded corners (`rounded-base`), a `2px` black border, and a 4px hard offset shadow, supporting default and compact densities plus optional section dividers.

Replace `wc` with `react`, `vue`, or `vue2` to generate framework facades, or import `BrutalistCardRoot`, `BrutalistCardHeader`, `BrutalistCardContent`, and `BrutalistCardFooter` directly from `@proto.ui/prototypes-brutalist/card` in workspace source.

<h2 id="usage">Usage</h2>

```tsx
import {
  BrutalistCardRoot,
  BrutalistCardHeader,
  BrutalistCardContent,
  BrutalistCardFooter,
} from '@proto.ui/prototypes-brutalist/card';
```

```tsx
<BrutalistCardRoot>
  <BrutalistCardHeader>
    <div className="flex flex-col gap-1">
      <h3 className="font-heading text-base font-bold">Card Title</h3>
      <p className="text-sm text-muted-foreground">Card Description</p>
    </div>
  </BrutalistCardHeader>
  <BrutalistCardContent>
    <p className="text-sm">Card Content</p>
  </BrutalistCardContent>
  <BrutalistCardFooter>
    <p className="text-xs text-muted-foreground">Card Footer</p>
  </BrutalistCardFooter>
</BrutalistCardRoot>
```

Composition:

```text
BrutalistCardRoot
├── BrutalistCardHeader
├── BrutalistCardContent
└── BrutalistCardFooter
```

- **Typography and frame**: `Root` projects a static raised panel with 5px corners, a `2px` black frame, and a 4px hard shadow (without press displacement). Style card headings with `font-heading font-bold` (DM Sans 700) while body text inherits `font-sans font-medium`.
- **Density and dividers**: Set `size="sm"` on `Root` for compact 16px spacing and insets. `Header` and `Footer` render without borders by default; pass `divider={true}` to display `2px` theme-adaptive dividers.
- **Passive semantics**: All four parts are roleless and non-focusable. Compose `BrutalistButton`, inputs, or native links inside the card for interactive actions.
