Tabs organize related views within a single region using 5px rounded flat list and trigger surfaces, supporting automatic or manual activation and descendant-first panel focus entry.

## Installation

Included in `@proto.ui/prototypes-brutalist@0.2.0`. Add it via the CLI target `brutalist-tabs`, or import directly from `@proto.ui/prototypes-brutalist/tabs`.

## Usage

- **Anatomy**: Compose `Root`, `List`, `Trigger`, `Content`, and `Indicator`, pairing each `Trigger` and `Content` by matching `value`.
- **Appearance**: Set `appearance` on `List` and `Trigger` to `'default'` or `'underline'`.
- **Activation & mounting**: `Root`'s `activationMode` supports `'automatic'` (selects on focus) and `'manual'` (selects on Enter/Space). Inactive `Content` unmounts its nodes by default; set `keepMounted={true}` to keep them mounted while hidden.
- **Controlled mode**: Pass `value` on `Root` for controlled state, or use `defaultValue` for uncontrolled initialization.

## API

The first three props (`defaultValue`, `orientation`, `activationMode`) belong to `Root` (pass `value` for controlled mode). `appearance` belongs to `List` and `Trigger`:

  ]}

Other part props and defaults:

- **List**: `orientation` defaults to `'horizontal'`; `loop` defaults to `false`; `a11yLabel` defaults to `''`.
- **Trigger**: `value` defaults to `''`; `disabled` defaults to `false`.
- **Content**: `value` defaults to `''`; `keepMounted` defaults to `false`.
- **Indicator**: No props.
