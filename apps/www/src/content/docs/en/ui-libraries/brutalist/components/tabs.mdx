## API

Tabs is workspace source. There is no public `proto-ui add` target. Passing `value` selects controlled mode.

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'defaultValue', type: 'string', default: "''" },
    { name: 'orientation', type: "'horizontal' | 'vertical'", default: 'horizontal' },
    { name: 'activationMode', type: "'automatic' | 'manual'", default: 'automatic' },
    { name: 'appearance', type: "'default' | 'underline'", default: 'default' },
  ]}
/>

The first three props belong to Root. `appearance` belongs to List and Trigger. List also defaults `orientation` to `horizontal`, `loop` to `false` and `a11yLabel` to `''`. Trigger also defaults `value` to `''` and `disabled` to `false`. Content defaults `value` to `''` and `keepMounted` to `false`. Indicator has no props.
