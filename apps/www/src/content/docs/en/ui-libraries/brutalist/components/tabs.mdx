Brutalist Tabs organizes switchable views using 5px rounded (`rounded-base`), 2px black-bordered flat tab strips and bold DM Sans triggers over [Base Tabs](/en/ui-libraries/base/tabs/) keyboard and accessibility semantics.

## Installation

<InstallCommandCard command="npx @proto.ui/cli@latest add wc brutalist-tabs" manager="npm" />

Replace `wc` with `react`, `vue`, or `vue2` for other framework facades, or import directly from `@proto.ui/prototypes-brutalist/tabs`.

## Usage

```tsx
import {
  BrutalistTabsContent,
  BrutalistTabsList,
  BrutalistTabsRoot,
  BrutalistTabsTrigger,
} from '../proto-ui/components/react';
```

```tsx
<BrutalistTabsRoot defaultValue="account">
  <BrutalistTabsList>
    <BrutalistTabsTrigger value="account">Account</BrutalistTabsTrigger>
    <BrutalistTabsTrigger value="password">Password</BrutalistTabsTrigger>
  </BrutalistTabsList>
  <BrutalistTabsContent value="account">Make changes to your account here.</BrutalistTabsContent>
  <BrutalistTabsContent value="password">Change your password here.</BrutalistTabsContent>
</BrutalistTabsRoot>
```

### Composition

```text
TabsRoot
├── TabsList
│   ├── TabsTrigger
│   └── TabsTrigger
├── TabsContent
└── TabsContent
```

- **Visual contract**: `TabsList` and `TabsTrigger` stay flat without shadows; the active trigger fills with `bg-main` and a 2px black border, while `TabsContent` omits a compulsory outer frame so cards or forms compose cleanly inside.
- **Keyboard navigation**: Arrow keys and `Home` / `End` move focus across enabled triggers with `activationMode="automatic"` or `"manual"`.
