Brutalist Checkbox supports unchecked, checked, and indeterminate (`mixed`) states in a crisp square 2px Brutalist frame with high-contrast check and dash indicators, accessible via pointer or `Space`.

## Installation

Available starting in `0.3.0-rc.1` and later releases. Import `BrutalistCheckboxRoot` and `BrutalistCheckboxIndicator` from `@proto.ui/prototypes-brutalist` or `@proto.ui/prototypes-brutalist/checkbox`.

## Usage

```tsx
import {
  BrutalistCheckboxIndicator,
  BrutalistCheckboxRoot,
  BrutalistLabelRoot,
} from '@proto.ui/prototypes-brutalist';

export function Example() {
  return (
    <div className="flex items-center gap-3">
      <BrutalistCheckboxRoot defaultChecked>
        <BrutalistCheckboxIndicator />
      </BrutalistCheckboxRoot>
      <BrutalistLabelRoot>Accept terms and conditions</BrutalistLabelRoot>
    </div>
  );
}
```

### Parts and Form composition

- **Root**: Manages `checked` and `indeterminate` state, `disabled` / `readOnly` policies, keyboard focus, and `checkbox` ARIA semantics (including `aria-checked="mixed"`).
- **Indicator**: Derives its state from the enclosing `Root` and renders the decorative check or mixed dash icon without taking focus. When both `checked` and `indeterminate` are `true`, the mixed dash takes precedence.
- **Read-only and Form**: `readOnly={true}` keeps the checkbox focusable while blocking value changes; `disabled={true}` also removes it from the tab order. For `Form` validation, labels, and reset, use `fieldCheckbox` from `@proto.ui/prototypes-brutalist/field` inside a `FormField` (see the [Form choice recipe](../../form/)).

## API

### Root

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'checked', type: 'boolean | undefined', default: 'uncontrolled' },
    { name: 'defaultChecked', type: 'boolean', default: 'false' },
    { name: 'indeterminate', type: 'boolean | undefined', default: 'uncontrolled' },
    { name: 'defaultIndeterminate', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'readOnly', type: 'boolean', default: 'false' },
    { name: 'required', type: 'boolean', default: 'false' },
  ]}
/>

`Root` exposes `checked`, `indeterminate`, `disabled`, `readOnly`, `required`, `hovered`, `focused`, `focusVisible`, and `pressed` states, `focusSelf(options?)` and `resetValue()` methods, and `checkedChange` (`{ checked, indeterminate }`) and `indeterminateChange` (`{ indeterminate }`) events.

### Indicator

`Indicator` declares no props of its own. It follows the enclosing `Root` context and exposes `checked`, `indeterminate`, `isChecked()`, and `isIndeterminate()`.
