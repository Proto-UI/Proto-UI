Brutalist Checkbox supports checked, unchecked, and indeterminate (`mixed`) states in a crisp square Brutalist frame with high-contrast check and dash indicators, accessible via pointer or `Space`.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

- **Package exports**: import `Root` and `Indicator` from `@proto.ui/prototypes-brutalist` or `@proto.ui/prototypes-brutalist/checkbox`

## Usage

### Parts

- **Root**: Manages `checked` and `indeterminate` state, `disabled` / `readOnly` policies, keyboard focus, and `checkbox` ARIA semantics (including `aria-checked="mixed"`).
- **Indicator**: Derives its state from the enclosing `Root` and renders the decorative check or mixed dash icon without taking focus. When both `checked` and `indeterminate` are `true`, the mixed dash takes precedence.

### Read-only and Form composition

- `readOnly={true}` keeps the checkbox focusable while blocking value changes; `disabled={true}` also removes it from the tab order.
- To integrate with `Form` validation, labels, and reset, use `fieldCheckbox` from `@proto.ui/prototypes-brutalist/field` inside a `FormField` (see the [Form choice recipe](../../form/)).
