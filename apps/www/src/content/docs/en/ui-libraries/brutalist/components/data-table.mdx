Brutalist Data Table layers stable sorting, global and per-column filtering, column visibility, pagination, and row selection over semantic table structure. Each item in `rows` must have a unique `id`.

## Usage

### Header and body rows

- Place sortable headers inside `DataTableHeaderRow` and body record slots in `DataTableRow`. Each `Cell` displays the field matching its `columnKey` for the current record.
- `sortKey`, `sortDirection`, `page`, and `selectedKeys` can each be controlled independently.

### Filtering, visibility, page selection, and custom cells

- **Filtering and column visibility**: `columnFilters` combines with global `filter` before sorting and pagination. `columnVisibility` hides a column's headers and cells (excluding them from keyboard sorting and assistive tech) while preserving component identity when shown again.
- **Page selection**: `requestPageSelection()` toggles selection for the current filtered page only while preserving selections on other pages, and exposes `pageSelection` as `'none'`, `'some'`, or `'all'`. `readOnly` blocks selection while keeping sorting and pagination active.
- **Custom cell formatting**: Set `renderValue={false}` on `Cell` to render your children and read `displayValue` to format the current record's value.

## API

### Root

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'rows', type: 'readonly DataRecord[]', default: '[]' },
    { name: 'defaultSortKey', type: 'string', default: "''" },
    { name: 'defaultSortDirection', type: "'none' | 'ascending' | 'descending'", default: 'none' },
    { name: 'filter', type: 'string', default: "''" },
    { name: 'columnFilters', type: 'Readonly<Record<string, string>>', default: '{}' },
    { name: 'columnVisibility', type: 'Readonly<Record<string, boolean>>', default: '{}' },
    { name: 'defaultPage', type: 'number', default: '0' },
    { name: 'pageSize', type: 'number', default: '10' },
    { name: 'defaultSelectedKeys', type: 'readonly string[]', default: '[]' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'readOnly', type: 'boolean', default: 'false' },
  ]}
/>

Pass `sortKey`, `sortDirection`, `page`, or `selectedKeys` to control each state independently.

### Other parts

- **Row**: `index?: number` (default `0`), `header?: boolean` (default `false`)
- **Header**: `sortable?: boolean` (default `true`)
- **Cell**: `columnKey?: string` (default `''`), `renderValue?: boolean` (default `true`)
- **Previous / Next**: Accept Button props
