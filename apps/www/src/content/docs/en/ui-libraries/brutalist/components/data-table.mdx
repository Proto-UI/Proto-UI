Brutalist Data Table layers stable sorting, global and per-column filtering, column visibility, pagination, and row or page selection onto semantic table structure with 5px `rounded-base` corners, 2px black borders, zero-blur 4px offset shadows, and DM Sans typography.

## Usage

```tsx
import {
  BrutalistDataTableCaption,
  BrutalistDataTableCell,
  BrutalistDataTableHeader,
  BrutalistDataTableHeaderRow,
  BrutalistDataTableNext,
  BrutalistDataTablePrevious,
  BrutalistDataTableRoot,
  BrutalistDataTableRow,
} from '../proto-ui/components/react';

const rows = [
  { id: 'm5gr84i9', status: 'Success', email: 'ken99@example.com', amount: 316 },
  { id: '3u1reuv4', status: 'Success', email: 'abe45@example.com', amount: 242 },
];

export function Example() {
  return (
    <BrutalistDataTableRoot rows={rows} pageSize={4}>
      <BrutalistDataTableCaption>Recent payments.</BrutalistDataTableCaption>
      <BrutalistDataTableHeaderRow>
        <BrutalistDataTableHeader headerKey="status">Status</BrutalistDataTableHeader>
        <BrutalistDataTableHeader headerKey="email">Email</BrutalistDataTableHeader>
        <BrutalistDataTableHeader headerKey="amount" className="text-right">
          Amount
        </BrutalistDataTableHeader>
      </BrutalistDataTableHeaderRow>
      {[0, 1].map((index) => (
        <BrutalistDataTableRow key={index} index={index}>
          <BrutalistDataTableCell columnKey="status" headers={['status']} />
          <BrutalistDataTableCell columnKey="email" headers={['email']} />
          <BrutalistDataTableCell columnKey="amount" headers={['amount']} className="text-right" />
        </BrutalistDataTableRow>
      ))}
      <div className="table-caption caption-bottom">
        <div className="flex justify-end gap-2 pt-3">
          <BrutalistDataTablePrevious>Previous</BrutalistDataTablePrevious>
          <BrutalistDataTableNext>Next</BrutalistDataTableNext>
        </div>
      </div>
    </BrutalistDataTableRoot>
  );
}
```

### Structure & Visual Grammar

- **Rows and cells**: Every item in `rows` requires a unique `id`. Place sortable column triggers in `DataTableHeaderRow`, map active page slots with `DataTableRow`, and bind fields with `DataTableCell` `columnKey`.
- **Brutalist contract**: Headers use `font-heading font-bold`, cells use `font-sans font-medium`, selected rows highlight with `bg-main text-main-foreground`, and `Previous`/`Next` use raised 4px hard shadows that settle `+4px, +4px` on press.

### Events, Methods & Exposed States

- **Events (Root)**: `sortChange`, `pageChange`, `selectionChange`.
- **Methods (Root)**: `getRows()`, `getRecord(id)`, `getSelectedKeys()`, `requestSort(key)`, `requestPage(next)`, `requestSelection(id)`, `requestPageSelection(selected?)`.
- **Exposed States**: Root exposes `filteredCount` and `pageSelection`; Row exposes `rowKey`, `selected`, `focused`, and `focusVisible`; Header exposes `sort`; Cell exposes `displayValue`.
