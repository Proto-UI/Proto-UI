Switch toggles a setting between on and off states. Its Brutalist presentation pairs a 2px black-bordered capsule track with a white circular thumb and no drop shadow for crisp, mechanical feedback.

## Installation

<InstallCommandCard command="npx @proto.ui/cli@latest add wc brutalist-switch" manager="npm" />

Replace `wc` with `react`, `vue`, or `vue2`, or import directly from `@proto.ui/prototypes-brutalist/switch`.

## Usage

```tsx
import { switchRoot, switchThumb } from '@proto.ui/prototypes-brutalist/switch';
```

```html
<proto-ui-brutalist-switch-root>
  <proto-ui-brutalist-switch-thumb></proto-ui-brutalist-switch-thumb>
  <span class="sr-only">Airplane Mode</span>
</proto-ui-brutalist-switch-root>
```

- **Geometry & colors**: The default track measures `24×48px` with a `16px` white circular thumb (`20px` travel); `size="sm"` measures `20×36px` with a `12px` thumb (`12px` travel). The track switches from neutral (off) to main blue (on).
- **State & motion**: Transitions run for `150ms` and turn off automatically under `prefers-reduced-motion: reduce`. Pressing does not shift the track or add shadow; keyboard focus displays an offset ring.
- **Interaction notes**: Supports click, `Space` key toggling, and controlled mode via `checked`. Pointer dragging is not yet enabled (`draggable` remains `false`).
