## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release.

- **Package exports**: import `progressRoot`, `progressLabel`, `progressTrack`, `progressIndicator`, and `progressValue` from `@proto.ui/prototypes-brutalist/progress`

## Usage

### Parts

- **Root**: Manages `value`, bounds `min` / `max` (default `0` / `100`), and `indeterminate` state. Values clamp to `[min, max]`, and equal bounds evaluate to `0` percentage.
- **Label**: Provides the accessible name for the progress bar.
- **Track / Indicator**: Render the track container and filled indicator bar.
- **Value**: Displays `valueText` when provided, otherwise the clamped numeric value.

### Indeterminate mode and accessibility

- Omitting `value` or setting `indeterminate={true}` puts the progress bar into an indeterminate state and withholds a concrete numeric value from assistive technologies.
- Progress is a passive display with no keyboard tab stop; updating `Root` props automatically synchronizes `value`, `percentage`, `indeterminate`, and `status` across all parts.
