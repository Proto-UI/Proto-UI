## Installation

Available starting in `0.3.0-rc.1` and later releases. Import the parts from `@proto.ui/prototypes-brutalist/progress`:

```ts
import {
  progressRoot,
  progressLabel,
  progressTrack,
  progressIndicator,
  progressValue,
} from '@proto.ui/prototypes-brutalist/progress';
```

## Usage

Place `Label` and `Value` before `Track` to align the label and percentage on a single header row above the bar. Labels use DM Sans `font-sans font-medium` and preserve original text casing:

```tsx
<BrutalistProgressRoot value={56} valueText="56%" className="w-full max-w-sm">
  <BrutalistProgressLabel>Upload progress</BrutalistProgressLabel>
  <BrutalistProgressValue />
  <BrutalistProgressTrack>
    <BrutalistProgressIndicator />
  </BrutalistProgressTrack>
</BrutalistProgressRoot>
```

```text
ProgressRoot
├── ProgressLabel
├── ProgressValue
└── ProgressTrack
    └── ProgressIndicator
```

- **Bounds and indeterminate mode**: `value` clamps to `[min, max]` (equal bounds produce `0%`). Omitting `value` or setting `indeterminate={true}` enters indeterminate mode and omits `aria-valuenow`.
- **Passive display**: Progress adds no keyboard tab stop; updating `Root` props keeps `value`, `percentage`, `indeterminate`, and `status` synchronized across all parts.
