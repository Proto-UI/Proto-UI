## Usage

### Single, range, and multiple modes

<PrototypePreviewer
  demoId="demo-brutalist-date-picker-selection"
  initialRuntime="wc"
  runtimes={['wc', 'react', 'vue', 'vue2']}
/>

- Select a mode via `mode="single"` (default), `mode="range"` (`range` / `defaultRange`), or `mode="multiple"` (`values` / `defaultValues`), using all the same constraints and callbacks documented on `Calendar`.
- **Popup dismissal**: Single mode requests close after an accepted pick. Range mode stays open after the first endpoint and requests close once the second endpoint completes the range. Multiple mode stays open for continued toggling until dismissed via standard Popover interactions.
- **Formatted readout**: `Value` renders a single ISO date, a comma-separated sorted list, `from …` for an in-progress range, or `from – to` for a completed range, falling back to `placeholder` when empty.
