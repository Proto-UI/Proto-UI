Brutalist Date Picker pairs `Popover` with `Calendar` for single-date, multi-date, and date-range selection, combining 5px `rounded-base` geometry, 2px black borders, a raised 4px hard-shadow trigger, and a 3px floating content panel.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. `Date Picker` composes Brutalist `Popover` and `Calendar` parts directly from the workspace.

## Usage

```tsx
import {
  BrutalistDatePickerRoot,
  BrutalistDatePickerTrigger,
  BrutalistDatePickerValue,
  BrutalistDatePickerContent,
  BrutalistDatePickerDay,
  BrutalistCalendarCaption,
  BrutalistCalendarPrevious,
  BrutalistCalendarHeading,
  BrutalistCalendarNext,
  BrutalistCalendarGrid,
  BrutalistCalendarWeekdays,
  BrutalistCalendarWeekday,
  BrutalistCalendarRow,
} from '../proto-ui/components/react';

export function BrutalistDatePickerExample() {
  return (
    <BrutalistDatePickerRoot defaultMonth="2026-10">
      <BrutalistDatePickerTrigger className="w-56">
        <BrutalistDatePickerValue placeholder="Pick a date" />
        <span aria-hidden="true">▾</span>
      </BrutalistDatePickerTrigger>
      <BrutalistDatePickerContent side="bottom" align="start" sideOffset={6}>
        <BrutalistCalendarCaption>
          <BrutalistCalendarPrevious a11yLabel="Previous month">‹</BrutalistCalendarPrevious>
          <BrutalistCalendarHeading />
          <BrutalistCalendarNext a11yLabel="Next month">›</BrutalistCalendarNext>
        </BrutalistCalendarCaption>
        <BrutalistCalendarGrid>
          <BrutalistCalendarWeekdays>
            {[0, 1, 2, 3, 4, 5, 6].map((offset) => (
              <BrutalistCalendarWeekday key={offset} offset={offset} />
            ))}
          </BrutalistCalendarWeekdays>
          {[0, 1, 2, 3, 4, 5].map((row) => (
            <BrutalistCalendarRow key={row} index={row}>
              {[0, 1, 2, 3, 4, 5, 6].map((col) => (
                <BrutalistDatePickerDay key={col} offset={row * 7 + col} />
              ))}
            </BrutalistCalendarRow>
          ))}
        </BrutalistCalendarGrid>
      </BrutalistDatePickerContent>
    </BrutalistDatePickerRoot>
  );
}
```

- **Depth and press grammar**: The trigger carries a resting `4px 4px` hard black shadow that collapses on press; the floating popup panel uses a stationary `3px 3px` foreground shadow; day cells stay flat and highlight via color without press translation.
- **Selection modes and dismissal**: Switch between `mode="single"` (default), `mode="range"`, and `mode="multiple"`. Single picks and completed ranges request closing the popup; multiple mode stays open for consecutive toggles.
- **Formatted readout**: `Value` renders an ISO date, a sorted comma-separated list, `from …` for an incomplete range, `from – to` for a completed range, or `placeholder` when empty.

## API

Open state belongs to `Popover`, and selection mode, values, constraints, and `month` belong to `Calendar`. `DatePickerValue` adds `placeholder`.

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'mode', type: "'single' | 'multiple' | 'range'", default: "'single'" },
    { name: 'open / defaultOpen', type: 'boolean', default: 'false' },
    { name: 'value / defaultValue', type: 'string (YYYY-MM-DD)', default: "''" },
    { name: 'values / defaultValues', type: 'readonly string[]', default: '[]' },
    { name: 'range / defaultRange', type: '{ from?: string; to?: string }', default: '{}' },
    { name: 'month / defaultMonth', type: 'string (YYYY-MM)', default: 'current month' },
    { name: 'min / max / unavailable', type: 'string / readonly string[]', default: '—' },
    { name: 'minSelected / maxSelected', type: 'number', default: '—' },
    { name: 'minNights / maxNights', type: 'number', default: '—' },
    { name: 'locale / direction', type: "string / 'ltr' | 'rtl'", default: "'en-US' / 'ltr'" },
    { name: 'disabled / readOnly', type: 'boolean', default: 'false' },
    {
      name: 'side / align / sideOffset',
      type: 'PopoverContentProps',

    },
    { name: 'placeholder (Value)', type: 'string', default: "'Pick a date'" },
  ]}
