Date Picker is a composition of the real Popover and Calendar atoms. A date request selects through Calendar and requests Popover closure. open, value and month retain their original controlled/uncontrolled boundaries. Calendar grid, row, heading and navigation atoms can be used inside the content.

WIP functional source. Full runtime/Compiler/native, packaging, browser and visual acceptance remain pending.

## API

Date Picker is workspace source. There is no public `proto-ui add` target. Open, value, and month stay on the composed Popover and Calendar. The only Date Picker prop is on Value.
