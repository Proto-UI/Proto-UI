## Usage

### Anatomy

NavigationMenu is composed of `Root`, `Trigger`, `Content`, `Item`, and `Link`:

- `Root`: Renders a navigation landmark and manages the currently open panel via `value`.
- `Trigger`: Disclosure button paired with a `Content` panel by `value`.
- `Content`: Labelled region displaying the open panel's links and commands.
- `Item`: Emits a command action when activated.
- `Link`: Renders a native anchor supporting `href`, `target`, `rel`, and `current` (sets `aria-current` for the active page).

### Link Behavior

- **Native browser semantics**: URL previews, `Enter` activation, and modifier/middle-click browsing are handled natively by the browser.
- **Read-only `navigate` event**: After native activation, `Link` emits a read-only `navigate` event with `{ href, target, rel, modified }` for observation.
- **Dismissal behavior**: A standard same-window activation closes the open panel unless `closeOnSelect` is `false`. Modified clicks, middle-clicks, and `_blank` targets keep the current page's panel open.
- **Disabled links**: Setting `disabled` removes the link destination and blocks activation.
- **Runtime rendering**: React, Vue, and Vue 2 render a native `<a>` root element; Web Components wrap your children inside an owned anchor element so focus, styles, and accessibility attributes stay aligned.

## API

Other part props and defaults:

- **Trigger**: `value` defaults to `''`; `disabled` defaults to `false`.
- **Content**: `value` and `a11yLabel` default to `''`; `sideOffset` defaults to `4`.
- **Item**: `value` and `textValue` default to `''`; `disabled` defaults to `false`; `closeOnSelect` defaults to `true`.
- **Link**: `href` and `rel` default to `''`; `current` defaults to `false`; `target` defaults to `'_self'`.
