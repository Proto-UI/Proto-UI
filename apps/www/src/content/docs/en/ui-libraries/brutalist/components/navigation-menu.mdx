Brutalist Navigation Menu builds site- or app-level navigation following the Brutalist design contract (`rounded-base` 5px corners, 2px black borders, DM Sans typography, and a 3px hard-offset floating panel shadow) with mutually exclusive panels and real native anchor links.

## Installation

Available starting in `0.3.0-rc.1` and later releases. Import the prototypes directly from `@proto.ui/prototypes-brutalist/navigation-menu` and adapt them for your target runtime:

```ts
import {
  navigationMenuRoot,
  navigationMenuTrigger,
  navigationMenuContent,
  navigationMenuItem,
  navigationMenuLink,
} from '@proto.ui/prototypes-brutalist/navigation-menu';
```

## Usage

```tsx
import {
  BrutalistNavigationMenuRoot,
  BrutalistNavigationMenuTrigger,
  BrutalistNavigationMenuContent,
  BrutalistNavigationMenuItem,
  BrutalistNavigationMenuLink,
} from '../proto-ui/components/react';

export function BrutalistSiteNav() {
  return (
    <BrutalistNavigationMenuRoot a11yLabel="Main navigation">
      <BrutalistNavigationMenuTrigger value="getting-started">
        Getting started
      </BrutalistNavigationMenuTrigger>
      <BrutalistNavigationMenuContent value="getting-started" a11yLabel="Getting started">
        <BrutalistNavigationMenuLink href="/docs" current>
          Introduction
        </BrutalistNavigationMenuLink>
        <BrutalistNavigationMenuItem value="copy-theme" textValue="Copy theme CSS">
          Copy theme CSS
        </BrutalistNavigationMenuItem>
      </BrutalistNavigationMenuContent>
    </BrutalistNavigationMenuRoot>
  );
}
```

### Composition

```text
NavigationMenuRoot (navigation)
├── NavigationMenuTrigger (button, paired by value)
└── NavigationMenuContent (region, paired by value)
    ├── NavigationMenuLink (native <a>)
    └── NavigationMenuItem (command action)
```

### Native Links & Keyboard

- **Native browser semantics**: URL previews, `Enter` activation, and modifier/middle-click tab opening are handled natively by the browser. React, Vue, and Vue 2 render a native `<a>` root; Web Components wrap children in an owned anchor element.
- **Read-only `navigate` event**: After native activation, `Link` emits a read-only `navigate` event with `{ href, target, rel, modified }`.
- **Dismissal & disabled links**: Ordinary same-window activations close the open panel unless `closeOnSelect={false}`; modified clicks, middle-clicks, and `_blank` targets keep the panel open. Disabled links remove `href` and block activation.
- **Keyboard roving**: Arrow keys move across top-level triggers, `ArrowDown` / `ArrowUp` enter the panel at the first or last entry, and `Escape` closes the panel and returns focus to the trigger.
