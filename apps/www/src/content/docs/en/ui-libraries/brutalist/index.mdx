Brutalist is Proto UI's Neo-Brutalist component library. Its components pair Base interaction and accessibility behavior with crisp black borders, hard offset shadows, tight spacing, and tactile press feedback. Read the [design contract](./design-contract/) alongside the components you use.

## Installation

Install the published 0.2.0 release in an existing application (Web Components example):

```sh
npx @proto.ui/cli@0.2.0 init --prototypes brutalist
npx @proto.ui/cli@0.2.0 add wc brutalist-button
```

With pnpm:

```sh
pnpm dlx @proto.ui/cli@0.2.0 init --prototypes brutalist
pnpm dlx @proto.ui/cli@0.2.0 add wc brutalist-button
```

The CLI installs `@proto.ui/prototypes-brutalist` along with the matching framework adapter and generates local wrapper files. Import the generated styles once as described in [Quick Start](/en/start-here/quick-start/), then follow the [Button usage guide](./components/button/). For React or Vue 3, replace `wc` with `react` or `vue`. Vue 2.6 support is currently available from workspace source.
