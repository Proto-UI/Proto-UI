Brutalist is a Proto UI-maintained, contributor-authored Neo-Brutalist design-language projection with visual recipes aligned to [neobrutalism.dev at 3306a802](https://github.com/ekmas/neobrutalism-components/tree/3306a802724874a85f93079702b2795370a279d4): DM Sans typography, component-owned rounded geometry, 2px structural borders, flat color and role-specific hard shadows. Its semantic implementation and documented extensions remain Proto UI-owned; no upstream API compatibility or certification is claimed.

The stable `@proto.ui/prototypes-brutalist@0.2.0` package combines projections over existing Base families—Button, Toggle, Switch, Tabs, Hover Card, Dropdown Menu, Select, Dialog, Scroll Area, Separator, and Textarea—with direct styled-only Badge, Card, and Skeleton prototypes. Textarea is a visual-only projection over Base Textarea. This is the same reviewed surface admitted in rc.7, now published without surface expansion as part of the exact 40-package 0.2.0 ecosystem release.

Each card below shows one basic demo for quickly browsing the component range and visual language. API documentation and code examples remain on the individual component pages.

## Status

- Provenance: contributor-authored Proto UI style family, with source-pinned visual adaptation and retained MIT attribution.
- Semantics: Button, Toggle, Switch, Tabs, Hover Card, Dropdown Menu, Select, Dialog, Scroll Area, Separator, and Textarea project their corresponding Base protocols. Textarea adds only resize-y, rounded neutral/ink, proportional sans styling. Badge and Card are direct passive styled-only prototypes with no Base counterparts. Skeleton is a direct styled-only, passive, contentless visual prototype; its parent owns loading, announcements, replacement timing, and focus continuity.
- Release status: `@proto.ui/prototypes-brutalist@0.2.0` is published under npm `latest` as part of the stable [v0.2.0 release](https://github.com/Proto-UI/Proto-UI/releases/tag/v0.2.0); rc.7 remains available only as [historical prerelease evidence](https://github.com/Proto-UI/Proto-UI/releases/tag/v0.2.0-rc.7).
- Lifecycle boundary: stable package publication does not promote every included prototype contract. Each catalog entity keeps its own active, draft, deprecated, or removed status; the individual pages and linked spec entities define the applicable guarantee.
- 0.2.0 package surface: root plus `./button`, `./badge`, `./card`, `./toggle`, `./switch`, `./tabs`, `./hover-card`, `./dropdown`, `./select`, `./dialog`, `./scroll-area`, `./separator`, `./skeleton`, and `./textarea` subpaths.
- Maintenance: admitted to the 0.2 launch-commitment set; later semantic changes and long-term ownership remain subject to Proto UI governance.

## Passive atoms

[Text](/en/ui-libraries/brutalist/components/text/) and [Surface](/en/ui-libraries/brutalist/components/surface/) are draft reusable presentation atoms in this workspace. They preserve the existing semantic owner and do not establish complete family or native/Compiler coverage.

[Collapsible (Draft)](/en/ui-libraries/brutalist/components/collapsible/) provides Root, Trigger and Content projections over the shared Base disclosure protocol.
