Transition manages mounting and a five-phase presence lifecycle (`closed → preparing → entering → entered → leaving`) following Brutalist's flat fade boundary: endpoint opacity only, with no zoom, slide, translate, or shadow choreography.

## Installation

Exported from `@proto.ui/prototypes-brutalist` and its `./transition` anatomy subpath. Transition is not registered as a `proto-ui add` CLI target:

```ts
import { transition } from '@proto.ui/prototypes-brutalist/transition';
// Or from the package root:
import { brutalistTransition } from '@proto.ui/prototypes-brutalist';
```

## Usage

```tsx
import { useState } from 'react';
import { BrutalistButton, BrutalistTransition } from '../proto-ui/components/react';

export function BrutalistBannerTransition() {
  const [open, setOpen] = useState(true);

  return (
    <div className="flex flex-col items-center gap-4">
      <BrutalistTransition
        open={open}
        appear
        className="block transition-opacity duration-150 ease-linear motion-reduce:transition-none"
      >
        <div className="rounded-[5px] border-2 border-black bg-[#dcebfe] p-5 font-sans font-medium text-black shadow-[4px_4px_0_0_#000]">
          Workspace synced
        </div>
      </BrutalistTransition>
      <BrutalistButton onClick={() => setOpen((value) => !value)}>Toggle</BrutalistButton>
    </div>
  );
}
```

- **Lifecycle & presence**: Exposes live `transitionState` and `isPresent` along with `enter`, `leave`, and `complete` controls. Content stays mounted throughout `leaving` and unmounts once `closed` is reached.
- **Flat fade boundary**: `brutalist-transition` binds endpoint opacity only (`opacity-0` during `closed`, `preparing`, and `leaving`; `opacity-100` during `entering` and `entered`) while keeping the authored slot transparent.
- **Interruption & reduced motion**: Configure mid-transition behavior via `interrupt` (`'reverse'`, `'wait'`, or `'immediate'`). Under `prefers-reduced-motion: reduce`, automatic waits collapse to `0ms` while keeping phase and event ordering intact.
- **Shared semantics**: Inherited directly from [Base Transition](/en/ui-libraries/base/transition/).
