Transition manages mounting and a five-phase presence lifecycle (`closed → preparing → entering → entered → leaving`) with Brutalist flat fade presentation and no extra slide, zoom, or shadow choreography.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. Import Transition from `@proto.ui/prototypes-brutalist` or `@proto.ui/prototypes-brutalist/transition` (workspace CLI target: `brutalist-transition`).

## Usage

- **Lifecycle & presence**: Exposes live `transitionState` and `isPresent` along with `enter`, `leave`, and `complete` controls. Content stays mounted while leaving and unmounts once the `closed` phase is reached.
- **Flat fade styling**: Binds endpoint opacity only (`opacity-0` during `closed`, `preparing`, and `leaving`; `opacity-100` during `entering` and `entered`) while keeping the content slot transparent.
- **Interruption & reduced motion**: Configure mid-transition behavior via `interrupt` (`'reverse'`, `'wait'`, or `'immediate'`). Under `prefers-reduced-motion: reduce`, durations collapse so phases complete immediately.
- **Controlled vs. uncontrolled**: Use `defaultOpen` for uncontrolled state or pass `open` for controlled mode; set `appear={true}` to animate on initial mount.
