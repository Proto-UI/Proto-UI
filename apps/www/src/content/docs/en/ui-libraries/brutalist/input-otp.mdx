Brutalist Input OTP pairs a single real text input with `rounded-base` (5px), 2px-bordered hard-shadow slots, preserving native paste, text selection, IME composition, and `one-time-code` autofill while highlighting active caret slots with Brutalist accent contrast.

## Usage

```tsx
import {
  BrutalistInputOtpRoot,
  BrutalistInputOtpInput,
  BrutalistInputOtpSlot,
  BrutalistInputOtpSeparator,
} from '../proto-ui/components/react';

export function BrutalistVerificationCode() {
  return (
    <BrutalistInputOtpRoot length={6}>
      <BrutalistInputOtpInput placeholder="123456" />
      <div className="inline-flex items-center gap-1.5">
        <BrutalistInputOtpSlot index={0} />
        <BrutalistInputOtpSlot index={1} />
        <BrutalistInputOtpSlot index={2} />
      </div>
      <BrutalistInputOtpSeparator>–</BrutalistInputOtpSeparator>
      <div className="inline-flex items-center gap-1.5">
        <BrutalistInputOtpSlot index={3} />
        <BrutalistInputOtpSlot index={4} />
        <BrutalistInputOtpSlot index={5} />
      </div>
    </BrutalistInputOtpRoot>
  );
}
```

### Parts and interaction

- **Root**: Manages `value` / `defaultValue`, `length` (`1`–`32`, default `6`), `pattern` (`'numeric'` or `'alphanumeric'`), `disabled`, `readOnly`, `invalid`, `name`, and `ariaLabel`.
- **Input / Control**: Use `Input` standalone for text entry, or `Control` inside `Field` / `FormField` for label focus, validation, serialization, and reset.
- **Slot / Separator**: Passive `aria-hidden` character slots styled with DM Sans typography, 2px borders, and 2px hard shadows without adding extra tab stops.
