Brutalist Input OTP pairs a single real text input with indexed Brutalist character slots, preserving native paste, text selection, IME composition, and `one-time-code` autofill while highlighting active caret slots.

## Usage

### Parts

Input OTP consists of `Root`, `Input`, `Control`, `Slot`, and `Separator`:

- **Root**: Manages `value` / `defaultValue`, `length` (1–32, default `6`), `pattern` (`'numeric'` or `'alphanumeric'`), `disabled`, `readOnly`, `name`, and `ariaLabel`.
- **Input**: Handles actual text entry for standalone usage, supporting selection, paste, deletion, IME composition, and `one-time-code` autofill. Disallowed characters are stripped and length is clamped after composition ends.
- **Control**: Use instead of `Input` inside `Field` or `FormField` to integrate label focusing, validation, form serialization, and reset.
- **Slot**: Renders the character at `index` as an `aria-hidden` display box without creating extra tab stops. Active slots reflect the real caret or selection range while the editable input is focused.
- **Separator**: Optional visual divider between slot groups.

### Events and validation

- Pass `value` for controlled mode; edits emit `valueChange`, and `completed` fires once for each accepted full-length code.
- Inside `Field`, `Control` triggers automatic change validation only after an accepted value actually changes; rejected or no-op filtered edits do not re-trigger change validation.

Pass `value: string` to enable controlled mode.

### Other parts

- **Input**: `placeholder?: string` (optional)
- **Slot**: `index?: number` (default `0`)
- **Control / Separator**: No props
