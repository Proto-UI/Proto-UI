Tooltip displays concise contextual descriptions on hover or keyboard focus using anchored portal positioning, `Escape` dismissal, and automatic `aria-describedby` / `role="tooltip"` wiring. Brutalist styles `Content` as a 5px rounded neutral surface that adapts live to Light and Dark themes.

## Installation

Currently available from workspace source; not yet included in the 0.2.0 stable release. For the published stable setup, see [Quick Start](/en/start-here/quick-start/).

Install the CLI, `@proto.ui/prototypes-brutalist`, and your host adapter (`@proto.ui/adapter-web-component`, `@proto.ui/adapter-react`, `@proto.ui/adapter-vue`, or `@proto.ui/adapter-vue2`) from the same workspace revision. Build local tarballs with [publish.mjs](https://github.com/Proto-UI/Proto-UI/blob/main/scripts/release/publish.mjs) and install the full `@proto.ui/*` dependency closure as shown in [consumer-smoke-cli.mjs](https://github.com/Proto-UI/Proto-UI/blob/main/scripts/release/consumer-smoke-cli.mjs). Vue 2 requires Vue `>=2.6.0 <2.7`.

After installing the matching packages, run the local CLI in your application directory and keep the generated `proto-ui-style.css` (required for Brutalist tokens as well as Base presence and positioning rules):

```sh
node node_modules/@proto.ui/cli/bin/proto-ui.js init --yes --no-interactive --prototypes brutalist
```

Brutalist Tooltip is imported directly from `@proto.ui/prototypes-brutalist/tooltip` and does not currently have a `proto-ui add` target.

## Usage

### Anatomy

Tooltip is composed of four parts:

- `Group`: Shares delay defaults, warm-window skip timing, and active-tooltip coordination across sibling tooltips.
- `Root`: Manages controlled or uncontrolled open state and per-tooltip delay overrides.
- `Trigger`: Routes hover and focus events and automatically links and cleans up `aria-describedby`.
- `Content`: Renders the 5px rounded neutral surface in a renderer-owned portal with anchored positioning, `Escape` dismissal, and `role="tooltip"`.

### Composing Tooltip on a Button

Keep a focusable button and its tooltip trigger on a single element rather than nesting a button inside a standalone `Trigger` (which creates two `Tab` stops). Compose `useTooltipTrigger()` alongside `asButton()`, then place the adapted button inside Tooltip `Root` next to `Content`:

```ts
import { definePrototype } from '@proto.ui/core';
import { asButton, type ButtonProps, type ButtonExposes } from '@proto.ui/prototypes-base/button';
import { useTooltipTrigger } from '@proto.ui/prototypes-base/tooltip';

export const tooltipButton = definePrototype<ButtonProps, ButtonExposes>({
  name: 'app-tooltip-button',
  setup() {
    asButton();
    useTooltipTrigger();
  },
});
```

- Button keeps its role, accessible name, click signal, disabled state, and single focus target; `useTooltipTrigger()` adds hover/focus intent and `aria-describedby` without adding extra exposes.
- Disabling Tooltip `Root` suppresses only the tooltip while keeping the button interactive; disabling the button suppresses both.
- When extending a styled Button prototype, preserve its static `modules` declaration, call its `setup(def)` followed by `useTooltipTrigger()`, and return its captured render function.
- When the button lives inside a `ShadowRoot`, use the [same-tree portal recipe](/en/ui-libraries/base/tooltip/#shadowroot) so `aria-describedby` resolves within the shadow tree.

## API

The following props belong to `Root` (pass `open` for controlled mode):

<ApiPropsTable
  headers={{ name: 'Prop', type: 'Type', default: 'Default' }}
  rows={[
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'openDelay', type: 'number', default: 'undefined' },
    { name: 'closeDelay', type: 'number', default: 'undefined' },
  ]}
/>

Other part props and defaults:

- **Group**: `openDelay` defaults to `700`; `closeDelay` defaults to `100`; `skipDelay` defaults to `300`.
- **Trigger**: `disabled` defaults to `false`.
- **Content**: Accepts Transition props; `side` defaults to `'top'`, `align` to `'center'`, `sideOffset` to `4`, `alignOffset` and `collisionPadding` to `0`, and `avoidCollisions` to `true`.
