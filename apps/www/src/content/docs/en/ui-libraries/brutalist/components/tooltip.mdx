Brutalist Tooltip projects the current three-part Base Tooltip protocol: Root owns controlled or uncontrolled open state and delays, Trigger owns hover/focus routing and accessible description linkage, and Content owns presence, anchored portal positioning, Escape dismissal, and `role="tooltip"`.

The Brutalist layer adds only the square high-contrast Content surface. It does not duplicate interaction, accessibility, presence, portal, or positioning behavior. Hover or focus the trigger below; Escape dismisses the open tooltip.
