Base Label 通过显式引用与目标控件建立一对一绑定，分别提供无障碍命名（`naming`）与点击激活（`activation`）能力，无需依赖手写 DOM ID。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。包入口为 `@proto.ui/prototypes-base/label`，工作区 CLI 目标为 `base-label`（支持 `wc`、`react`、`vue`、`vue2`）。

## 用法

### 独立控制命名与激活

- **`naming`**（默认 `true`）：自动将目标控件的可访问名称关联到实际渲染的 Label（若目标已设置非空 `ariaLabel` / `labelledBy`，则保留目标自有命名）。
- **`activation`**（默认 `true`）：点击已配对的 Label 会触发目标控件的默认操作——例如切换 Checkbox / Switch、选中 Radio Group Item、或聚焦 Input / Textarea（只读输入框仍可聚焦）。设为 `false` 可保留命名并关闭点击激活。
- **`selection`**（默认 `'policy'`）：默认避免短操作标签在点击时误选文字；若希望操作标签文本仍可自由复制，可设置为 `'text'`。
- Label 本身不增加 `button` 角色或额外 Tab 停靠点，且会自动忽略嵌套链接/按钮、带修饰键点击、拖拽手势与已取消的点击事件。

### 建立显式关联

通过 `@proto.ui/core` 的 `createControlLabelRef()` 为每一对标签和控件创建一个稳定引用（每个引用对应一个 Label 和一个目标控件）：

- **React / Vue / Vue 2**：向双方传入适配器属性 `instanceAssociations: { controlLabel: ref }`（不会混入普通组件 Props）。
- **Web Components**：通过 `@proto.ui/adapter-web-component` 的 `setElementAssociations(el, { controlLabel: ref })` 分别为目标控件和 Label 绑定同一引用。

支持配对的目标控件包括：`Checkbox`、`Switch`、`Radio Group Item`、`Input`、`Textarea`、`Button`、`Toggle` 与 `Toggle Group Item`。
