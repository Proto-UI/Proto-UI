## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。

## 用法

由 `Root`、`Viewport`、`Title`、`Description`、`Action` 和 `Close` 组成：

- **计时与暂停**：`Root` 默认显示 `5000ms`（设为 `duration={0}` 则保持常驻不自动关闭）。鼠标悬停在通知上，或焦点移入 `Action`/`Close` 时会自动暂停剩余计时，离开后继续。
- **关闭与操作**：触发 `Close`、在通知内聚焦时按 `Escape` 或点击 `Action` 都会请求关闭通知；具体业务操作由应用监听并执行。传入 `open` 进入受控模式时，超时仅发出一次关闭请求，等待外部更新 `open`。
- **快捷键与实时区域**：`Viewport` 提供 `F8`（可通过 `hotkey` 自定义）快捷聚焦通知区域，并通过 `politeness`（`'polite'` / `'assertive'`）控制辅助技术播报级别。

### Root

  headers={{ name: '属性', type: '类型', default: '默认值' }}

    { name: 'duration', type: 'number', default: '5000' },
    { name: 'paused', type: 'boolean', default: 'false' },
    { name: 'politeness', type: "'polite' | 'assertive'", default: 'polite' },
  ]}
/>

传入 `open` 可受控管理通知的显示状态。

### 其他部件属性

- **Viewport**：`a11yLabel`（默认 `'Notifications'`）、`hotkey`（默认 `'F8'`）。
- **Action**：`disabled`（默认 `false`）、`a11yLabel`（可选）。
- **Close**：`disabled`（默认 `false`）。
- **Title**、**Description**：无额外属性。
