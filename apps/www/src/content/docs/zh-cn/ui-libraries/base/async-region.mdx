`base-async-region-root` 是一个轻量的异步无障碍容器，负责根据 `busy` 属性同步 `aria-busy` 状态并暴露 `busy` 状态句柄。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。在工作区中对应的 CLI 目标为 `base-async-region`。

## 用法

`base-async-region-root` 仅接收单个 `busy` 属性（默认为 `false`），并将状态同步到 `aria-busy` 与 `getExposes().busy`：

- `busy={false}`（默认）：设置 `aria-busy="false"`。
- `busy={true}`：设置 `aria-busy="true"`。

### 保持子元素与焦点

仅更新属性时，区域内传入的子元素与当前焦点都会保持不变。例如在刷新收件箱列表时，可以将草稿输入框与重试按钮保留在同一个 Async Region 中，仅切换 `busy` 属性：

- `busy={true}` 不会自动禁用内部控件或将区域设为 inert；是否需要禁用特定按钮由应用自行控制。
- 如需向屏幕阅读器播报刷新结果，请在应用层组合使用 Live Region，并在内容更新完成后将 `busy` 复位为 `false`。
