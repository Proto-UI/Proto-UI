管理单个元素显隐生命周期（`closed → entering → entered → leaving → closed`）的底层状态机组件，在进出场动画期间保持视图挂载，让 CSS 或宿主动画系统可靠驱动过渡效果。

## 预览

### 命令式控制

通过暴露的 `controls` 手动推进状态机（典型链路：`Enter → Complete → Leave → Complete`）：

- **Enter**：从 `closed` 或 `leaving` 进入 `entering`（已在进入中或已显示时忽略）。
- **Leave**：从 `entered` 或 `entering` 进入 `leaving`（已在离开中或已关闭时忽略）。
- **Complete**：将 `entering` 推进至 `entered`，或将 `leaving` 推进至 `closed`。

### 受控模式

通过 `open` 属性受控驱动状态机：切换到 `open={true}` 会走 `entering → entered`，切换到 `open={false}` 会走 `leaving → closed`；点击方框本身与按钮具有相同效果。默认在 `enterDuration` / `leaveDuration` 到期后自动完成，也可在宿主动画事件触发时主动调用 `controls.complete()` 提前结束。

## 用法

### 状态机与挂载生命周期

```text
transitionState: closed → entering → entered → leaving → closed
ViewIntent:      detached ↔ present
view epoch:      detached ↔ mounting ↔ mounted ↔ unmounting
```

`asTransition()` 是 `@proto.ui/prototypes-base` 导出的单例 Hook（同一 setup 中重复调用返回同一句柄），通过 `run.lifecycle.setPresent()` 协调视图挂载：

- **进入**：先将 `ViewIntent` 置为 `present`，待新视图完成首次挂载与提交后再进入 `entering`，避免暴露未就绪的 DOM。
- **离开**：`leaving` 阶段全程保留当前视图，待完成进入 `closed` 后才请求卸载视图。
- **复原**：关闭时默认卸载内容节点，但不会销毁原型实例本身，`controls`、状态与属性监听保持存活，再次打开即可重建视图。

### 最佳实践

1. **配对过渡样式**：`Transition` 仅负责逻辑阶段，请为 `data-transition-state="entering"` 与 `data-transition-state="leaving"` 编写 CSS 过渡规则。
2. **可选接入宿主动画完成事件**：默认以 `enterDuration` / `leaveDuration` 兜底完成；若希望与实际动画精确同步，可监听 `transitionend` 并调用 `exposes.controls.complete()`（自动取消旧延时任务）：

```ts
el.addEventListener('transitionend', () => {
  exposes.controls.complete();
});
```

3. **首次挂载播放动画**：设置 `appear={true}` 可在初次挂载时播放进入动画，否则直接处于 `entered`。
4. **选择合适的中断策略（`interrupt`）**：
   - `'reverse'`（默认）：快速来回切换时平滑反向，适合菜单与提示框。
   - `'wait'`：等待当前阶段完整结束后再切换，适合分步面板。
   - `'immediate'`：丢弃当前过渡并立即切入新阶段，适合即时反馈场景。
5. **通过 `open` 或 `controls` 驱动**：始终使用 `open` 或 `controls.enter()` / `leave()` / `complete()`，不要直接改写 `transitionState`；在 `leaving` 期间保持子树稳定，待到达 `closed` 或真正卸载时再清理子资源。

`base-transition` 管理单个元素自身的存在生命周期；如需父子嵌套协调退出，请通过独立的边界/编组模式处理。

传入 `open`（`boolean`）可进入受控模式。

### 命令式方法（`controls`）

- `enter()`：触发进入过渡。
- `leave()`：触发离开过渡。
- `complete()`：结束当前过渡并推进到下一个稳定状态。
