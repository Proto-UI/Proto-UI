Base Data Table 在基础表格结构之上提供稳定排序、全局和按列筛选、列显隐、分页以及行选择能力。传入的每条记录需提供唯一的 `id`，行槽按当前页索引映射实际记录内容。

## 用法

### 表头与数据行组合

- 将可排序表头放在 `DataTableHeaderRow` 中，正文记录槽使用 `DataTableRow`（按 `index` 对应当前页的数据项）。
- 每个 `Cell` 通过 `columnKey` 读取当前记录的字段值；排序或翻页时会直接更新单元格数据。

### 筛选、列显隐、页选择与自定义渲染

- **筛选**：`columnFilters` 中的每个非空条件会与 `Root` 的全局 `filter` 同时生效，筛选后再执行排序与分页。
- **列显隐**：通过 `columnVisibility` 可隐藏指定列的 `Header` 与 `Cell`（隐藏列自动移出排序焦点和无障碍树），重新显示时保持原有组件与子元素状态。
- **整页选择**：调用 `requestPageSelection()` 可全选或清空当前筛选页（不影响其他页的已选记录），并通过 `pageSelection` 读取 `'none'`、`'some'` 或 `'all'`。`readOnly` 会禁止行选择与整页选择，但仍允许排序与翻页。
- **自定义单元格**：在 `Cell` 上设置 `renderValue={false}` 可保留传入的子元素，同时仍可订阅公开的 `displayValue` 状态来自定义格式化显示。

## API

### Root Props

传入 `sortKey`、`sortDirection`、`page` 或 `selectedKeys` 可分别控制对应状态。

### 其他组件属性

- **Row**：`index` 默认 `0`，`header` 默认 `false`。
- **Cell**：`columnKey` 默认 `''`，`renderValue` 默认 `true`。
- **Header**：`sortable` 默认 `true`。
- **Previous / Next**：继承 Button 属性。
