Base Input OTP 提供用于一次性验证码的输入组件：底层保留单个原生文本输入框以完整支持选区、粘贴、删除、`one-time-code` 自动填充及输入法组合，视觉上按槽位（`Slot`）逐位展示。

## 用法

### 组合结构

组件由 `Root`、`Input`（或表单内的 `Control`）、`Slot` 和 `Separator` 组成：

- **`Root`**：统一管理验证码值（`value` / `defaultValue`）、位数 `length`（`1`–`32`，默认 `6`）、字符过滤模式 `pattern`（`'numeric'` 或 `'alphanumeric'`）以及 `disabled`、`readOnly`、`name` 和 `ariaLabel`。
- **`Input`**：底层单行编辑器，在输入法组合完成后自动过滤非法字符并截断到指定长度。当输入值变更时发出 `valueChange`；每次形成完整的有效验证码时触发一次 `completed` 事件。
- **`Slot`**：按 `index` 展示对应字符的被动只读视图（对辅助技术隐藏，不增加额外 Tab 停靠点）。当可编辑的输入框持有焦点时，高亮槽位跟随真实光标或选区位置。
- **`Control`（表单集成）**：在 `Field` / `FormField` 内用 `Control` 替代 `Input`，即可自动接入 `FieldLabel`、字符串校验、表单序列化和重置。

### 其他组件属性

- **Input**：可选 `placeholder`（无默认值）。
- **Slot**：`index` 默认为 `0`。
- **Control、Separator**：无额外属性。
