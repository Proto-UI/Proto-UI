## 安装

0.2.0 稳定版包已导出 `@proto.ui/prototypes-base/switch`（包含 `switchRoot`、`switchThumb`、`asSwitchRoot()` 与 `asSwitchThumb()`），CLI 目标为 `base-switch`。如需带样式的版本，可使用 [Shadcn Switch](/zh-cn/ui-libraries/shadcn/switch/) 或 [Brutalist Switch](/zh-cn/ui-libraries/brutalist/components/switch/)。

## 用法

### 组件结构

- `base-switch-root`：唯一的可聚焦交互目标，管理 `checked` 状态、激活逻辑与 `role="switch"` 无障碍语义。
- `base-switch-thumb`（可选）：读取 `Root` 上下文的纯视觉滑块，不参与焦点或点击激活。

### 受控与非受控

- 非受控模式使用 `defaultChecked` 指定初始状态，点击或按键盘切换后在本地提交新状态并发出 `checkedChange`。
- 受控模式传入 `checked`，交互时仅发出 `checkedChange`，由外部更新 `checked` 后生效。
- `Switch` 仅表示二元开关；若需要不确定（indeterminate）三态，请使用 `Checkbox`。
