Base Button 是用于触发单次离散动作的可聚焦按钮组件。它统一处理激活、禁用状态、焦点与按压交互，样式完全由应用自定义。

## 预览

`P-BASE-BUTTON` 仍处于 **early draft**，协议仍在演进。预览使用 Web Components、React、Vue 3 与 Vue 2.6 的工作区源码；接入应用时，请按安装部分选择匹配的包和宿主版本。[当前 Button 测试覆盖](https://github.com/Proto-UI/Proto-UI/blob/main/spec/tests/T-BASE-BUTTON-0001.yaml)记录了已覆盖的行为与待完成的浏览器验证。

## 安装

先按照[快速开始](/zh-cn/start-here/quick-start/)初始化项目，然后通过 0.2.0 CLI 添加对应宿主的 Base Button：

<InstallCommandCard
  commands={{
    npm: 'npx @proto.ui/cli@0.2.0 add wc base-button',
    pnpm: 'pnpm dlx @proto.ui/cli@0.2.0 add wc base-button',
  }}
  manager="npm"
/>

React 或 Vue 3 项目请将命令中的 `wc` 替换为 `react` 或 `vue`。CLI 会自动安装匹配版本的 `@proto.ui/prototypes-base` 和对应适配器包，并生成本地 `BaseButton` 组件或 `proto-ui-base-button` 自定义元素。Vue 2.6（`>=2.6.0 <2.7`）需要匹配的工作区 CLI 与适配器源码；已发布的 0.2.0 CLI 支持 `wc`、`react` 和 `vue`。

### 交互与事件

- 支持通过 `Tab` 聚焦，并使用 `Enter`、`Space` 或指针激活；按下 `Space` 时会阻止页面默认滚动。
- 激活成功后发出 `click` 事件，各框架适配器会映射为原生监听方式（React 使用 `onClick`，Vue 使用 `@click`，Web Component 派发自定义事件）。
- `disabled={true}` 会阻止激活、清理瞬时交互状态并禁止主动聚焦；请始终通过 `disabled` 属性控制禁用状态，而不是仅靠降低透明度。
- 组件暴露 `disabled`、`hovered`、`focused`、`focusVisible`、`pressed` 状态以及 `focusSelf()` 方法；可访问名称由按钮内部文本提供。
- 如需页面跳转，请直接使用带真实 `href` 的原生 `<a>` 链接。带预设样式的按钮请参阅 [Shadcn Button](/zh-cn/ui-libraries/shadcn/button/) 与 [Brutalist Button](/zh-cn/ui-libraries/brutalist/components/button/)。

### 组合入口

`@proto.ui/prototypes-base/button` 同时导出直接可用的 `button` 原型与用于派生组件的 `asButton()` 钩子。

工作区源码还提供了可选的 `asFocusRetainedVisibility` 钩子（及 `FocusRetainedVisibilityProps`），此 API 尚未包含在已发布的 0.2.0 中：将其与 `asButton()` 组合后，可通过 `requestedVisible` 控制显隐；当 `requestedVisible` 变为 `false` 但按钮仍持有焦点时，控件会保持可见直到焦点离开（适合“回到最新”等悬浮操作按钮）。
