Base Button 是触发一次离散动作的可聚焦命令控件。它拥有激活、禁用门控、焦点、瞬时交互事实与向外发出的 `click` signal，视觉呈现由应用提供。

## 安装

先[初始化已有应用](/zh-cn/start-here/quick-start/)。已发布 0.2.0 的 Web Component 基线使用：

<InstallCommandCard command="npx @proto.ui/cli@0.2.0 add wc base-button" manager="npm" />

使用 pnpm 时执行：

```sh
pnpm dlx @proto.ui/cli@0.2.0 add wc base-button
```

稳定版 React、Vue 3 分别把 `wc` 换为 `react`、`vue`。CLI 按自身精确版本安装 `@proto.ui/prototypes-base` 与对应的 `@proto.ui/adapter-web-component`、`@proto.ui/adapter-react` 或 `@proto.ui/adapter-vue`，并生成本地 `BaseButton` 导出或 `proto-ui-base-button` 自定义元素。

Vue 2 示例要求配套的工作区 0.3 CLI/Adapter 源码与 Vue `>=2.6.0 <2.7`。已发布稳定版 CLI 不接受 `vue2`；不能换成 `@latest` 就假定安装结果与源码预览一致。工作区 manifest 的版本不能证明 registry 已发布。

## 用法

从对应宿主的已有 bundler 应用开始，复制下面的文件，并保留应用原有的框架挂载入口。Web Component 的 HTML 应加入现有文档，`src/main.ts` 只加载一次。注册 import 使用 CLI 生成的标签，而不是网站预览私有的 `wc-base-button` 标签。

两个控件与预览的组合一致。小型样式表由应用拥有，不依赖 Tailwind 设置；应用如果已导入 `proto-ui-style.css`，请把它保留在一个入口。

用 Tab 聚焦“Run action”，再通过 Enter、Space 或指针激活。“Disabled”必须抑制激活与主动焦点请求；仅用 CSS 降低透明度不会禁用控件。可访问名称来自内容文本。

## 协议与事件

`P-BASE-BUTTON` 为同一协议记录两个 authoring entry：

- direct `base-button` Prototype，由 `@proto.ui/prototypes-base/button` 导出为 `button`；
- authored `asButton()` hook，供需要 Button 语义的派生 Prototype 使用。

当前 Base prop 只有 `disabled`。公开事实包括 `disabled`、`hovered`、`focused`、`focusVisible` 与表示“正被按住”的 `pressed`；`focusSelf()` 请求焦点。成功激活后发出 `click` outward signal。框架 facade 将这个 signal 翻译为自己的监听语法：React 使用 `onClick`，Vue 使用 `@click`；它不是 Prototype 的 `onClick` prop。Web Component facade 以自定义事件投射 signal，与原生 DOM 输入分别处理。

Space 参与按压生命周期并阻止滚动默认行为。禁用 Button 会清理瞬时交互状态，不发出激活 signal。表单提交、`type`、`name`、loading 状态与视觉 variant 不属于当前 Base 保证。应用拥有的 busy 行为必须更新真实 `disabled` 输入并提供可理解的进度或状态；仅显示 spinner 或降低透明度不够。

导航应使用带真实 `href` 的原生 anchor。不要把 anchor 嵌入 Button，也不要用点击回调代替其导航。风格化投射另见 [Shadcn Button](/zh-cn/ui-libraries/shadcn/button/) 与 [Brutalist Button](/zh-cn/ui-libraries/brutalist/components/button/)。
