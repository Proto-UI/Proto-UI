## 用法

### 组件结构

- **Root**（1 个）：统一管理选中值（`value` / `defaultValue`）、方向（`orientation`）与激活模式（`activationMode`），变更时发出 `valueChange`。传入 `value` 进入受控模式。
- **List**（0–1 个）：管理漫游焦点，提供按方向自适应的箭头导航、`Home`/`End`、循环焦点（`loop`）与可选 `a11yLabel`。
- **Trigger**（多个）：声明自身 `value` 与 `disabled`，处理点击和键盘选中并发起切换请求。
- **Content**（多个）：按精确 `value` 与 `Trigger` 配对（如 `a+b` 与 `a b` 保持区分），暴露 `current` / `hidden` 状态。关闭时默认卸载内容节点（设置 `keepMounted` 可保留隐藏节点，同时对辅助技术不可见）。
- **Indicator**（可选）：纯视觉指示部件，读取当前选中值、活动值与方向供样式层实现滑动指示条。

### 激活模式与无障碍关联

- `activationMode="automatic"`（默认）下，方向键移动焦点时自动切换选中面板；`activationMode="manual"` 将焦点移动与确认选择分离。禁用的 `Trigger` 不参与选择。
- 组件自动维护 `tablist`、`tab` 与 `tabpanel` 之间的无障碍关联并在卸载时清理，保留调用方自定义的宿主 ID；应用逻辑应以 `value` 标识选项卡，无需依赖生成的 DOM ID。

### Root

传入 `value` 可受控管理当前选中值；状态变更时发出 `valueChange`。

### 其他部件属性

- **List**：`orientation`（默认 `'horizontal'`）、`loop`（默认 `false`）、`a11yLabel`（默认 `''`）。
- **Trigger**：`value`（默认 `''`）、`disabled`（默认 `false`）。
- **Content**：`value`（默认 `''`）、`keepMounted`（默认 `false`）。
- **Indicator**：无额外属性。
