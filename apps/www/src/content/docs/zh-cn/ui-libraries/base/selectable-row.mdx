用于文件列表、表格或集合中的受控可选行，提供按压、键盘、焦点与 `row` 无障碍语义，并将选择提案与激活动作明确分离。

## 预览

按 `Tab` 聚焦可用行，按 `Space` 提出选择请求；在 **Assets** 行按 `Enter`（或在 Web 端双击）会触发激活请求。

## 用法

### 受控选择与独立激活

- `selected` 为受控状态：点击或按 `Space` 时通过 `selectionChange` 发出 `{ value: itemKey }`，由外部决定是否更新 `selected`。
- 当 `activatable` 为 `true` 时，按 `Enter` 通过 `activate` 发出 `{ value: itemKey }`（不会同时触发选择）；在 Web 端，双击（`host:dblclick`）同样触发 `activate`。
- 聚焦且可用时会阻止 `Space` 的默认页面滚动，可激活时同时阻止 `Enter` 的默认行为；长按键盘重复触发不会重复提交。

### 焦点、无障碍与集合职责

- 组件自动设置 `role="row"`、`selected` 与 `disabled` 无障碍状态，默认插槽保留传入的子元素。
- 设置 `disabled` 会阻止选择、激活和 `focusSelf()`，并退出常规焦点顺序，但不会清除外部已选中的 `selected` 状态。
- 方向键导航、漫游焦点、范围选择与多选由外层集合组件统一协调。

- **暴露方法**：`focusSelf()`。
- **事件**：`selectionChange`、`activate`，载荷均为 `{ value: string }`。
