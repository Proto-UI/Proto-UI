`base-live-region-root` 是一个轻量的无障碍实时播报容器，负责将 `politeness` 和 `atomic` 属性同步为标准的 ARIA live-region 语义。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。在工作区中对应的 CLI 目标为 `base-live-region`。

## 用法

将需要向辅助技术播报的动态文本作为子元素放入 `base-live-region-root` 内，组件会根据两个属性自动维护三个 ARIA 属性：

- **`politeness`**：`'polite'`（默认）设置 `role="status"` 与 `aria-live="polite"`；`'assertive'` 设置 `role="alert"` 与 `aria-live="assertive"`。
- **`atomic`**：`true`（默认）设置 `aria-atomic="true"`（内容变化时播报完整区域）；`false` 设置 `aria-atomic="false"`。

仅更新属性时，三个 ARIA 属性会同步更新，且内部传入的子元素保持不变。如需在异步刷新数据时配合加载态使用，可将 Live Region 与 [Async Region](../async-region/) 组合。
