## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。

## 用法

由 `Root`、`Button` 和 `Separator` 组成：

- **焦点与导航**：状态由 `Root` 统一管理（`disabled`、`orientation`、`loop` 与 `a11yLabel`）。常规 Tab 顺序中仅保留一个可用命令按钮，通过方向键在工具栏内移动焦点。
- **操作与分隔**：点击或键盘激活可用 `Button` 时会发出携带其 `value` 的 `action` 事件；`Separator` 自动沿工具栏的交叉轴方向展示。

### 其他部件属性

- **Button**：`disabled`（默认 `false`）、`value`（默认 `''`）。
- **Separator**：无额外属性。
