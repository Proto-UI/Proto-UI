Base Calendar 是无样式公历组件，支持 `single`（默认）、`multiple` 和 `range` 三种日期选择模式，使用 `YYYY-MM-DD` 表示日期、`YYYY-MM` 表示显示月份，且选择状态与当前月份均可独立受控。

## 用法

### 组合结构

组件由十个部分组成：`Root`、`Caption`、`Heading`、`Previous`、`Next`、`Grid`、`Weekdays`、`Weekday`、`Row` 和 `Day`。

- 在 `Weekdays` 中放置 `offset` 为 `0`–`6` 的七个 `Weekday`；在 `Grid` 中可按需放置最多六个带 `index`（`0`–`5`）的 `Row` 及 `offset` 为 `0`–`41` 的 `Day`。
- 默认仅显示覆盖当月所需的最少 4、5 或 6 周；设置 `fixedWeeks={true}` 可固定显示 6 周。未使用的行与日期格自动隐藏且不可聚焦。
- 星期标题与日期顺序随 `weekStartsOn`（`0` 表示周日）和 `locale` 自动本地化；`direction="rtl"` 会镜像左右方向键。

### 选择模式与受控状态

- **单选（`single`）**：通过 `value` / `defaultValue`（`YYYY-MM-DD`）控制，变更时触发 `onValueChange({ value })`。
- **多选（`multiple`）**：通过 `values` / `defaultValues`（去重且升序排列的日期数组）控制，变更时触发 `onValuesChange({ values })`；可用 `minSelected` / `maxSelected` 限制选中数量。
- **范围（`range`）**：通过 `range` / `defaultRange`（`{ from?, to? }`）控制，变更时触发 `onRangeChange({ range })`。首次点击设定起点 `{ from }`，再次点击自动排序并完成 `{ from, to }`，传入 `{}` 清空；可用 `minNights` / `maxNights` 限制起止天数差（默认 `minNights=0` 允许单日范围）。

`min`、`max` 和 `Root` 的 `unavailable` 会作用于所有选择模式；若范围跨越不可用日期，本次选择会被拒绝并保留起点。`readOnly` 禁止更改选择但允许翻月浏览。

### 时钟与年月下拉组合

- Calendar 不主动读取系统时钟或时区：如需高亮“今天”（并设置 `aria-current="date"`），请由应用通过 `today` 传入 `YYYY-MM-DD` 字符串。
- 初始显示月份按 `month` → `defaultMonth` → 当前模式已选日期 → `today` → `1970-01` 的优先级确定。
- 需要月份/年份下拉切换时，可在 `Caption` 中组合真实 Select 组件，并通过 `bindCalendarCaption(source, { month, year })` 与 Calendar 的公开月份状态及 `requestMonth` 同步（卸载时调用 `dispose()` 清理）。

### 暴露状态与方法

- `Root` 暴露 `mode`、`weekCount`、`selectedCount`、`rangeComplete`，以及 `requestMonth`、`requestValue(date)`、`requestValues(dates)`、`requestRange(range)`、`getValues()`、`getRange()`。
- `Day` 除 `selected` 外还暴露 `rangeStart`、`rangeEnd`、`rangeMiddle`、`rangePending` 状态；多选与范围模式下 `Grid` 自动设置 `aria-multiselectable`。

### 其他组件属性

- **Day**：`date` 默认 `''`，`offset` 默认 `0`，`disabled` 默认 `false`。
- **Row**：`index`（无默认值）。
- **Caption**：`a11yLabel` 默认 `'Calendar navigation'`。
- **Previous / Next**：继承 Button 属性，`a11yLabel` 分别默认 `'Previous month'` 与 `'Next month'`。
- **Weekday**：`offset` 默认 `0`。
- **Grid、Heading、Weekdays**：无额外属性。
