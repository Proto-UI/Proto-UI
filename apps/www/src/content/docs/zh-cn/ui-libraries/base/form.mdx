## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。在工作区中对应的 CLI 目标为 `base-form`。

## 用法

### 组合结构

组件由 `Root`、`Field`、`Submit` 和 `Reset` 四个部分组成：

- **`Root`**：汇总带唯一 `name` 的启用 `Field` 字段，校验通过后在 `submit` 事件中返回按字段名组织的表单数据。禁用字段（包含被禁用 `Fieldset` 包裹的字段）会自动排除；重复字段名会阻止序列化并忽略非法配置。
- **`Field`**：显式绑定字段名并参与表单校验与重置。
- **`Submit` / `Reset`**：支持键盘与指针激活，暴露 `disabled`、`hovered`、`pressed`、`focused`、`focusVisible` 状态及 `focusSelf()` 方法。

### 隐式提交、异步校验与重置

- 聚焦在单行 `Field`、`Number Field` 或 `Input OTP` 编辑器内时，按下 `Enter` 可隐式触发表单提交（IME 组合输入、按住修饰键或长按重复触发时除外）。
- 异步校验会等待当前有效结果；当字段值变更、控件卸载、再次提交或取消提交时，旧结果会被自动丢弃。
- 调用 `requestReset()` 会恢复非受控字段的初始值、向受控字段发出恢复初始值的请求，同时取消进行中的校验并发出 `reset` 事件；`resetValidation()` 仅清理校验状态。
