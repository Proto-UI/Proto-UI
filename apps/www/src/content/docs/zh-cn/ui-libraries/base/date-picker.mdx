Base Date Picker 组合了 Popover 与 Calendar 组件，用于通过弹层选择单个日期、多个日期或日期范围。弹层开关、选中值与当前月份分别保持独立的受控/非受控状态。

## 用法

### 单日、范围与多选行为

- **单日选择**：选中有效日期后自动请求关闭弹层。
- **日期范围（`mode="range"`）**：通过 `range` / `defaultRange` 传入起止日期。选择首个端点时保持弹层打开；选择第二个有效端点形成完整范围后自动请求关闭一次。
- **多选模式（`mode="multiple"`）**：通过 `values` / `defaultValues` 管理多个日期；选择过程中弹层保持打开以便连续勾选，完成后按 Popover 常规方式关闭。
- 所有日期限制、数量/天数间隔规则（`min`、`max`、`unavailable`、`minSelected`、`maxSelected`、`minNights`、`maxNights`）与回调均直接继承 [Calendar](../calendar/)。

### 文本展示与焦点

- `Value` 根据当前值自动格式化展示：单日显示 ISO 日期，多选显示逗号分隔的有序日期，未完成范围显示 `from …`，完整范围显示 `from – to`；为空时显示 `placeholder`。
- 弹层的关闭交互与焦点恢复由 Popover 统一管理；在受控 `open` 模式下，调用方仍可决定是否接受关闭请求。

## API

开关状态属性（如 `open`）位于 Popover，日期与选择模式属性（如 `mode`、`value`、`values`、`range`、`month`）位于 Calendar。Date Picker 自身仅在 `Value` 上提供 `placeholder` 属性：
