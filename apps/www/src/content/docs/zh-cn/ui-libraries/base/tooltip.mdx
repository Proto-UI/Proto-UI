## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版（已发布版本的接入方式见[稳定版 Quick Start](/zh-cn/start-here/quick-start/)）。Base Tooltip 通过 `@proto.ui/prototypes-base/tooltip` 直接导出，无独立的 `proto-ui add` 目标。

从同一份源码修订安装 `@proto.ui/cli`、`@proto.ui/prototypes-base` 与对应宿主 Adapter（`@proto.ui/adapter-web-component`、`@proto.ui/adapter-react`、`@proto.ui/adapter-vue` 或 `@proto.ui/adapter-vue2`，Vue 2 需使用 Vue `>=2.6.0 <2.7`）。本地源码检出可通过仓库的[仅打包流程](https://github.com/Proto-UI/Proto-UI/blob/main/scripts/release/publish.mjs)与[干净消费者安装流程](https://github.com/Proto-UI/Proto-UI/blob/main/scripts/release/consumer-smoke-cli.mjs)准备本地包。

安装后在应用目录运行同版本 CLI 生成结构样式文件 `proto-ui-style.css`（如果入口已导入，保留一次即可）：

```sh
node node_modules/@proto.ui/cli/bin/proto-ui.js init --yes --no-interactive --prototypes shadcn
```

React 示例通过向 `createReactAdapter` 传入 `react-dom` 的 `createPortal` 来渲染传送门浮层；Web Components 通过 `setElementProps` 为自定义标签配置属性。

## 用法

### 交互与分组协调

由 `Root`、`Trigger`、`Content` 与可选的 `Group` 组成：

- **悬停与键盘聚焦**：首次指针悬停在 `openDelay` 后打开（提前移出会取消延迟）；键盘聚焦则立即打开，无需等待。
- **关闭延迟与无障碍关联**：`closeDelay` 允许指针从 `Trigger` 平滑移入 `Content`（`Content` 仅放非交互说明文本）。仅在打开时自动维护 `Trigger` 到 `Content`（`role="tooltip"`）的 `aria-describedby` 关联并在卸载或关闭时清理；按 `Escape` 可关闭提示并保留触发器焦点。
- **Group 预热窗口**：在 `Group` 的 `skipDelay` 预热窗口内切换到同组其他 Tooltip 时会立即打开，并同步收起前一个非受控提示以避免双浮层重叠；超过 `skipDelay` 后恢复首次悬停延迟。当前活动 `Root` 卸载或销毁时，`Group` 立即恢复冷启动延迟。

### 在 Button 上组合 Tooltip

让按钮与提示触发器共用同一个交互节点，使用 `useTooltipTrigger()` 与 `asButton()` 组合，避免用独立 `Trigger` 包裹可聚焦按钮导致双 Tab 停靠点：

```ts
import { definePrototype } from '@proto.ui/core';
import { asButton, type ButtonProps, type ButtonExposes } from '@proto.ui/prototypes-base/button';
import { useTooltipTrigger } from '@proto.ui/prototypes-base/tooltip';

export const tooltipButton = definePrototype<ButtonProps, ButtonExposes>({
  name: 'app-tooltip-button',
  setup() {
    asButton();
    useTooltipTrigger();
  },
});
```

`Button` 保留原有角色、点击信号、禁用态与焦点；`useTooltipTrigger()` 追加悬停/聚焦触发与 `aria-describedby` 关联。禁用 Tooltip `Root` 仅关闭提示，按钮仍可点击；禁用按钮则同时抑制两者。复用已有风格组件时，可在 `definePrototype` 中保留其静态 `modules` 声明，调用原 `setup(def)` 后再调用 `useTooltipTrigger()` 并返回捕获的渲染函数。

### 在 `ShadowRoot` 中使用

当触发元素位于 `ShadowRoot` 内时，`Content` 也需要挂载在同一棵 Shadow DOM 树中，否则跨 Shadow 边界的 `aria-describedby` 无法为命令元素建立无障碍描述。

在挂载组件前，通过 `@proto.ui/adapter-base` 导出的 `registerWebPortalDestination` 注册应用管理的容器与浮层挂载点（目标节点需位于 `scene` 内且在 `Content` 之外）：

```ts
import { registerWebPortalDestination } from '@proto.ui/adapter-base';

export function createTooltipScene(container: HTMLElement) {
  const shell = document.createElement('div');
  container.append(shell);
  const shadow = shell.attachShadow({ mode: 'open' });
  const scene = document.createElement('div');
  const appMount = document.createElement('div');
  const overlays = document.createElement('div');
  scene.append(appMount, overlays);
  shadow.append(scene);
  const releasePortal = registerWebPortalDestination(scene, overlays);

  return {
    shadow,
    appMount,
    async dispose(unmount: () => void | Promise<void>) {
      await unmount();
      shell.remove();
      releasePortal();
    },
  };
}
```

将 `Root`、组合命令和 `Content` 挂载到 `appMount`，并将生成的 CSS 放入 `shadow`。清理时调用 `dispose` 等待框架卸载完成，再移除节点并释放 portal 注册。

### Root

传入 `open` 可受控管理显示状态。

### 其他部件属性

- **Trigger**：`disabled`（默认 `false`）。
- **Content**：支持 `Transition` 属性，提供 `side`（默认 `'top'`）、`align`（默认 `'center'`）、`sideOffset`（默认 `4`）、`alignOffset`（默认 `0`）、`collisionPadding`（默认 `0`）、`avoidCollisions`（默认 `true`）。
- **Group**：`openDelay`（默认 `700`）、`closeDelay`（默认 `100`）、`skipDelay`（默认 `300`）。
