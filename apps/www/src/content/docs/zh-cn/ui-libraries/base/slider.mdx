## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `@proto.ui/prototypes-base/slider` 导入标量滑块部件或六个 `sliderValues*` 多值滑块入口。

## 用法

### 单滑块组合

由 `Root`、`Label`、`Track`、`Indicator`、`Thumb`、`FieldThumb` 和 `Value` 组成：

- **拖拽与键盘步进**：状态由 `Root` 统一管理。`Track` 处理指针与触摸拖拽；`Thumb` 支持方向键、`Shift` 十倍步进、`PageUp`/`PageDown`、`Home`/`End`，水平 `rtl` 模式下自动反转左右方向键。数值从 `min` 起按 `step` 对齐并限制在 `[min, max]` 内。
- **受控与提交**：传入 `value` 进入受控模式（交互发出 `valueChange`，由外部决定是否更新）；完成拖动或按键提交时发出 `valueCommit`，取消拖动则恢复非受控起始值。
- **表单集成**：在 `Field` / `FormField` 内使用 `FieldThumb` 替代 `Thumb`，自动联动 `FieldLabel` 聚焦、数值校验、表单序列化与复位；独立使用时配合 `Label` 与 `Thumb`。

### 范围与多值组合（`sliderValues*`）

从 `@proto.ui/prototypes-base/slider` 导入六个 `sliderValues*` 入口，在 `Values Root` 上传入数组值（如 `defaultValue={[20, 80]}`），并在 `Values Track` 内为每个数值放置一个带 `index` 的 `Thumb`：

- **轨道与碰撞策略**：点击轨道自动定位最近的可编辑滑块，偏离中心抓取滑块时保留抓取偏移。`thumbCollisionBehavior` 支持 `'push'`、`'swap'` 和 `'none'`（`'swap'` 在交错时转移活动焦点并保持轨道捕获）。
- **表单集成**：完整的 `Values Root` 可直接在 `Field` / `FormField` 中作为组合控件使用，上报 `number[]`、初始基线与组焦点，`FieldLabel` 会聚焦首个可编辑滑块；调用复位会取消当前拖动并请求恢复初始值。
