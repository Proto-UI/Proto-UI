Base AlertDialog 用于需要用户明确确认的关键决策。它默认阻止点击遮罩关闭，并将初始焦点优先落在取消操作上，避免误触发。

## 用法

### 组合结构

组件由 `Root`、`Trigger`、`Mask`、`Content`、`Title`、`Description`、`Cancel` 和 `Action` 组成：

- `Root` 管理打开状态并声明 alertdialog 语义。
- `Mask` 负责模态遮罩层；`Content` 负责焦点约束、禁用外部点击关闭，并在打开时优先聚焦 `Cancel`。
- 激活 `Action` 时会先发出 `action` 事件，再请求关闭对话框；实际业务逻辑由应用代码处理。
- 按下 `Escape` 或点击 `Cancel` 会请求关闭对话框。

### 受控与非受控模式

- 传入 `open` 进入受控模式：状态由调用方管理，通过监听 `openChange` 事件并传入新值来更新开关状态。
- 不传 `open` 时为非受控模式，可通过 `defaultOpen` 指定初始状态。
- 当 `disabled` 为 `true` 时，触发与确认指令均不会激活。

### 其他组件属性

- **Mask**：支持 `passthrough`（默认 `false`）以及 Transition 属性。
- **Content**：支持 Transition 属性。
- **Trigger、Title、Description、Cancel、Action**：无额外属性。
