## 用法

由 `Root`、`Viewport` 和 `Content` 组成：

- **逻辑模型与 Web 物化**：`Root` 负责管理完整键序列、按项 `overscanItems`、最大物化数量 `maxMaterializedItems`、修订号及 generation 绑定的提交。Web 端通过 `@proto.ui/prototypes-base/virtual-list/web` 的 `attachWebVirtualList` 测量可变条目高度、维护上下占位节点、按键复用视图、支持滚动定位到指定 key 并在销毁时清理监听。
- **单一物化租约与生命周期**：每个逻辑集合同一时刻只允许挂载一个物化宿主。`attachWebVirtualList` 会在挂载节点与监听器之前获取租约；重复挂载会失败且不干扰现有宿主，替换前需先调用旧宿主的 `dispose`。自定义宿主可通过 `acquireMaterializer(onRetired)` 获取租约（使用 `attachWebVirtualList` 时无需在外层重复申请）。
- **卸载与错误恢复**：`Root` 卸载或销毁时会自动注销当前物化宿主，使在途 generation 失效并清理视图与观察器，旧宿主延迟触发的刷新、滚动、测量或重复 `dispose` 不会影响新替换的宿主。若首次渲染或观察器安装失败，租约会自动释放以便重新挂载。
