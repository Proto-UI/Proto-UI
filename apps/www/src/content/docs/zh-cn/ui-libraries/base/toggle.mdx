## 安装

0.2.0 稳定版包已导出 `@proto.ui/prototypes-base/toggle`（`base-toggle` 原型与 `asToggle()`），CLI 目标为 `base-toggle`。如需带样式的版本，可使用 [Shadcn Toggle](/zh-cn/ui-libraries/shadcn/toggle/) 或 [Brutalist Toggle](/zh-cn/ui-libraries/brutalist/components/toggle/)。

## 用法

- **受控与非受控**：使用 `defaultActive` 配置非受控初始态，激活时自动翻转 `active`；传入 `active` 进入受控模式，激活时通过 `activeChange` 发出 `{ active }` 请求并等待外部更新。
- **单按钮职责与无障碍**：`base-toggle` 在 Web 上呈现带按下状态的按钮语义，图标与标签直接作为传入的子元素放置。设置 `disabled` 会阻止激活并清理瞬时按压态；需要一组互斥或多选按钮时，请使用 [Toggle Group](../toggle-group/)。
