## 用法

由 `Root`、`Trigger`、`Content`、`Item` 和 `Link` 组成：

- **角色与状态**：`Root` 作为 `navigation` 地标并通过 `value` 统一管理唯一展开的面板，`Trigger` 为展开按钮，`Content` 为命名区域。传入 `value` 进入受控模式。
- **命令与原生链接**：`Item` 触发普通命令；`Link` 渲染真实的锚点元素，支持 `href`、`target`、`rel` 以及 `current`（设置 `aria-current` 标识当前页）。URL 预览、`Enter` 激活、修饰键/中键新标签打开及实际跳转由浏览器原生处理。
- **导航观察与关闭规则**：`Link` 在原生激活后发出只读 `navigate` 事件，携带 `{ href, target, rel, modified }`（不拦截原生路由）。普通当前窗口点击会关闭展开面板（设置 `closeOnSelect={false}` 可保持打开）；修饰键/中键点击或 `target="_blank"` 会保留当前页面板。禁用的 `Link` 会移除目标地址并阻止激活。
- **宿主渲染**：React、Vue 与 Vue 2 直接使用原生锚点作为根节点；Web Components 在内部锚点中包裹传入的子元素，焦点、样式与无障碍属性作用在该锚点上。

传入 `value` 可受控管理当前展开面板。

### 其他部件属性

- **Trigger**：`value`（默认 `''`）、`disabled`（默认 `false`）。
- **Content**：`value`（默认 `''`）、`a11yLabel`（默认 `''`）、`sideOffset`（默认 `4`）。
- **Item**：`value`（默认 `''`）、`textValue`（默认 `''`）、`disabled`（默认 `false`）、`closeOnSelect`（默认 `true`）。
- **Link**：`href`（默认 `''`）、`rel`（默认 `''`）、`current`（默认 `false`）、`target`（默认 `'_self'`）。
