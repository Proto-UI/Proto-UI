## 用法

### 组件结构

| 部件         | 数量 | 职责                                                                |
| ------------ | ---- | ------------------------------------------------------------------- |
| `Root`       | 1    | 建立独立的表格结构域并维护只读结构快照。                            |
| `Caption`    | 0–1  | 提供表格标题与说明。                                                |
| `Row`        | 1+   | 表示一个有序逻辑行（每行至少包含一个 `HeaderCell` 或 `Cell`）。     |
| `HeaderCell` | 1+   | 声明列头或行头（`headerKind`）、域内唯一的 `headerKey` 及合并跨度。 |
| `Cell`       | 1+   | 声明合并跨度及所关联的有序表头键列表（`headers`）。                 |

`Caption`、`HeaderCell` 与 `Cell` 通过默认插槽原样保留传入的子元素。如需排序、选择、分页、虚拟滚动或键盘网格导航，请使用基于此结构组合的 [Data Table](../data-table/)。

### 拓扑布局与表头关联

- **确定性排布**：行列顺序遵循组件挂载顺序。每行首个单元格从第 0 列起排布，后续单元格紧随前一单元格右侧放入首个可容纳区间，不会回填前方空隙而打乱书写顺序。`rowSpan` 与 `columnSpan` 为正整数（默认 `1`），不得与已占区域重叠或越出当前总行数。
- **多表头与分层表头**：`HeaderCell` 声明非空且表内唯一的 `headerKey` 与 `headerKind`（`'column'` 或 `'row'`），并可通过 `headers` 声明前置上游表头以构建分层表头；`Cell` 通过 `headers` 引用一个或多个同表内的 `headerKey`。解析结果会自动映射为无障碍行列计数、索引、跨度以及 `columnHeaders` / `rowHeaders` 关联。
- **嵌套隔离与动态更新**：解析仅在当前 `Root` 内生效，嵌套或并列表格之间互不串名。增删或重排部件会自动重算结构；若结构暂时无效，表格保持挂载并清除无效结构属性，同时保留传入的子元素，待结构恢复有效后自动重新生效。

### 其他部件属性

- **Caption**、**Row**：无额外属性。
- **Cell**：`headers`（默认 `[]`）、`rowSpan`（默认 `1`）、`columnSpan`（默认 `1`）。
- **HeaderCell**：`headerKey`（默认 `''`）、`headerKind`（默认 `'column'`）、`headers`（默认 `[]`）、`rowSpan`（默认 `1`）、`columnSpan`（默认 `1`）。
