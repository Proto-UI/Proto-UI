Base Combobox 将单行搜索输入与下拉选项列表结合，其中已选选项值（`value`）与输入文本（`inputValue`）相互独立，未匹配任何选项的输入不会自动变成选中值。

将于 `0.3.0-rc.1` 及后续版本中提供。

## 用法

### 组合结构

组件由 `Root`、`Input`、`Content`、`Item`、`Empty` 和 `Trigger` 组成：

- `Root` 分别管理选中的选项键（`value`）、输入查询文本（`inputValue`）与弹层开关（`open`）。
- 内置过滤按 `Item` 的 `textValue` 和 `keywords` 匹配，忽略大小写与重音符号；设置 `filter={false}` 时可由应用自行过滤子项。
- `Empty` 根据实际匹配项数量自动显隐；禁用项与重复值项不可提交。

### 受控模式与键盘交互

- `value`、`inputValue` 与 `open` 均可独立受控，通过各自变更事件通知调用方。
- 上下方向键切换候选项时，焦点保留在输入框中；输入法（IME）组合输入期间不会误触发选择。

### 其他组件属性

- **Input**：`placeholder`、`a11yLabel`、`name` 默认均为 `''`。
- **Content**：`side` 默认 `'bottom'`，`align` 默认 `'start'`，`sideOffset` 默认 `4`，`collisionPadding` 默认 `8`。
- **Item**：`value`、`textValue`、`keywords` 默认均为 `''`，`disabled` 默认 `false`。
- **Empty**：无额外属性。
- **Trigger**：`disabled` 默认 `false`。
