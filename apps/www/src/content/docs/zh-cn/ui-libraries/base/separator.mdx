## 安装

0.2.0 稳定版包已导出 `@proto.ui/prototypes-base/separator`（`separatorRoot` 与 `asSeparatorRoot()`），CLI 目标为 `base-separator`。如需带样式的版本，可使用 [Brutalist Separator](/zh-cn/ui-libraries/brutalist/components/separator/)。

## 用法

- **方向与装饰性**：通过 `orientation` 指定水平（`'horizontal'`）或垂直（`'vertical'`）方向；通过 `decorative` 控制是否向辅助技术暴露语义。
- **无障碍语义**：默认 `decorative={true}` 时，分隔线对辅助技术隐藏，不输出 `separator` 角色；设置为 `decorative={false}` 时，输出 `role="separator"` 与对应的方向属性。
- **纯结构元素**：`separatorRoot` 不包含子内容插槽，也不参与焦点、键盘或事件交互，避免装饰性分隔线意外隐藏传入的子元素。
