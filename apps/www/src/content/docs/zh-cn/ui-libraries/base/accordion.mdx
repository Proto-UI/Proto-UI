Base Accordion 提供无样式的折叠面板交互与无障碍语义，由 `Root`、`Item`、`Heading`、`Trigger` 和 `Content` 五个部分组成，支持单选与多选展开模式。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。在工作区中可通过 `proto-ui add react base-accordion`（也支持 `vue`、`vue2`、`wc`）生成对应宿主包装，或直接从 `@proto.ui/prototypes-base/accordion` 导入 `accordionRoot`、`accordionItem`、`accordionHeading`、`accordionTrigger`、`accordionContent` 以及对应的 `asAccordion*` 组合钩子。

## 用法

### 组合结构

按 `Root → Item → Heading → Trigger` 的层级组织，并将 `Content` 与 `Heading` 并列放置在 `Item` 内。每个 `Item` 都需要一个唯一且非空的 `value`。

- 展开状态由 `Root` 统一管理，`Item`、`Trigger` 和 `Content` 自动同步对应状态。
- 嵌套的 `Root` 各自独立，互不干扰。
- `Heading` 中只放置控制当前面板的 `Trigger`，其他持久可见的辅助操作应放在 `Heading` 外侧。

### 受控与非受控模式

- 传入 `openItems` 即进入受控模式，由调用方持有当前展开项；交互时会触发 `openChange` 事件（事件数据为 `{ openItems, value, open, reason }`，其中 `reason` 为 `'pointer'`、`'keyboard'` 或 `'programmatic'`），需将新的 `openItems` 回传给 `Root` 才会更新状态。
- 不传 `openItems` 时为非受控模式，可通过 `defaultOpenItems` 设置初始展开项（仅在首次挂载时生效）。
- 输入数组中的重复键会自动去重；在 `single` 模式下仅保留首个有效键。对于尚未挂载的键，`Root` 会保留记录以支持异步或分步渲染 `Item`。

### 内容生命周期

折叠状态下，`Content` 默认卸载内容节点以减少渲染开销；若需在收起后保留内部子元素状态，请设置 `keepMounted`。折叠时不会自动抢占或移动焦点。

### 键盘与无障碍

- 每个启用的标题触发器及展开内容中的可聚焦元素都保持自然 Tab 顺序。
- `Enter` / `Space` 切换当前面板的展开状态。
- 纵向使用 `ArrowUp` / `ArrowDown`、横向使用 `ArrowLeft` / `ArrowRight`（在 `rtl` 下自动反转）在启用的标题间移动焦点，`Home` / `End` 跳转到首尾项；焦点移动不会改变展开状态。
- `Heading` 提供对应层级的标题语义，`Trigger` 自动关联 `aria-expanded`、`aria-disabled` 与 `aria-controls`，`Content` 默认由对应 `Trigger` 命名；需要将其声明为地标区域时，可显式设置 `region={true}`。

## API

### Root Props

传入 `openItems` 进入受控模式；`Root` 同时暴露 `getOpenItems()`、`openCount`、`requestOpen(value, open, reason?)` 方法与属性，以及 `openChange` 事件。

### 其他组件属性

- **Item**：必填非空字符串 `value`；`disabled` 默认为 `false`。
- **Heading**：`level` 为 `1`–`6` 的整数，默认为 `3`。
- **Trigger**：无额外属性，自动从所属 `Item` 和 `Root` 读取状态。
- **Content**：`keepMounted` 与 `region` 默认均为 `false`。
