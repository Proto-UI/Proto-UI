Base 提供不带预设视觉样式的跨框架交互组件，专注封装状态管理、键盘导航与无障碍语义。Shadcn 与 Brutalist 等风格组件库均基于 Base 构建外观。

## 安装与上手

在已有项目中初始化 Proto UI 并添加已发布的 0.2.0 组件（例如 Web Component 版本的 Button）：

```sh
npx @proto.ui/cli@0.2.0 init
npx @proto.ui/cli@0.2.0 add wc base-button
```

使用 pnpm：

```sh
pnpm dlx @proto.ui/cli@0.2.0 init
pnpm dlx @proto.ui/cli@0.2.0 add wc base-button
```

React 或 Vue 3 项目可将 `wc` 替换为 `react` 或 `vue`。初始化后请参照[快速开始](/zh-cn/start-here/quick-start/)导入生成的样式与组件包装，并查看完整的 [Button 用法](./button/)。
