Base 提供不携带视觉语言的交互协议。先选择拥有目标动作或值的家族，再按文档组合其部件。Shadcn 与 Brutalist 在这些协议上投射各自的视觉语言。

## 安装并渲染

下面是在已有 bundler 应用中使用已发布 0.2.0 Web Component 基线的命令：

```sh
npx @proto.ui/cli@0.2.0 init
npx @proto.ui/cli@0.2.0 add wc base-button
```

使用 pnpm 时执行：

```sh
pnpm dlx @proto.ui/cli@0.2.0 init
pnpm dlx @proto.ui/cli@0.2.0 add wc base-button
```

CLI 会按自身的精确版本安装 `@proto.ui/prototypes-base` 与所选 Adapter。按[快速开始](/zh-cn/start-here/quick-start/)导入生成的样式入口与宿主 facade，再采用完整的 [Button 用法](./button/)。React 与 Vue 3 分别把 `wc` 换为 `react`、`vue`。Vue 2.6 属于工作区 0.3 开发线，以上稳定版命令不能安装它。
