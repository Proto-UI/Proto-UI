Base Collapsible 表示单个可展开或折叠的内容面板。展开状态由 `Root` 统一管理，`Trigger` 负责触发切换，`Content` 负责控制内容的可见性与挂载周期。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。在工作区中可通过匹配版本的 CLI 生成对应宿主组件：

```sh
proto-ui add react base-collapsible
# 也支持 vue、vue2、wc
```

React / Vue / Vue 2 会生成 `BaseCollapsibleRoot`、`BaseCollapsibleTrigger`、`BaseCollapsibleContent`；Web Component 会注册 `proto-ui-base-collapsible-{root,trigger,content}`。也可以直接从 `@proto.ui/prototypes-base/collapsible` 导入 `collapsibleRoot`、`collapsibleTrigger`、`collapsibleContent` 及 `asCollapsible*` 钩子。

## 用法

### 组合结构

每个 `Root` 内包含一个 `Trigger` 和一个 `Content`（嵌套的 `Root` 各自独立，互不干扰）：

- **Root**：管理展开状态，暴露 `openCollapsible`、`close`、`toggle` 方法以及 `openChange` 事件。
- **Trigger**：继承按钮语义与自然 Tab 顺序，支持 `Enter` / `Space` 激活，自动派生 `expanded` 与有效 `disabled` 状态，并暴露 `focusSelf()`。
- **Content**：自动同步 `open` / `hidden` 状态。关闭时默认卸载内容节点；设置 `keepMounted` 可保留隐藏节点以维持内部子组件状态。

### 代码示例

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import {
  collapsibleRoot,
  collapsibleTrigger,
  collapsibleContent,
} from '@proto.ui/prototypes-base/collapsible';

const adapt = createReactAdapter(React);
const BaseCollapsibleRoot = adapt(collapsibleRoot);
const BaseCollapsibleTrigger = adapt(collapsibleTrigger);
const BaseCollapsibleContent = adapt(collapsibleContent);

export function ControlledDisclosure() {
  const [open, setOpen] = React.useState(false);
  return (
    <BaseCollapsibleRoot open={open} onOpenChange={(request) => setOpen(request.open)}>
      <BaseCollapsibleTrigger>Details</BaseCollapsibleTrigger>
      <BaseCollapsibleContent keepMounted>Additional details</BaseCollapsibleContent>
    </BaseCollapsibleRoot>
  );
}

export function UncontrolledDisclosure() {
  return (
    <BaseCollapsibleRoot defaultOpen>
      <BaseCollapsibleTrigger>Details</BaseCollapsibleTrigger>
      <BaseCollapsibleContent>Additional details</BaseCollapsibleContent>
    </BaseCollapsibleRoot>
  );
}
```

### 受控模式与无障碍

- 传入 `open` 进入受控模式：交互或命令调用会发出 `openChange`（数据为 `{ open, reason }`，`reason` 为 `'pointer'`、`'keyboard'` 或 `'programmatic'`），需由调用方更新传入的 `open` 才会改变显示状态。
- `Root` 或 `Trigger` 设为 `disabled` 时均会阻止激活；禁用已展开的面板不会强制收起内容。
- `Trigger` 自动维护 `aria-expanded` 与 `aria-controls` 关联，并在 `Content` 卸载或销毁时自动清理。

### 其他组件属性

- **Trigger**：`disabled` 默认为 `false`。
- **Content**：`keepMounted` 默认为 `false`。
