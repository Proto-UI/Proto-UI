## 安装

## 用法

### 组件结构

- `radio-group-root`：统一管理选中值、选项顺序、漫游焦点、整组禁用/只读状态以及 `role="radiogroup"` 语义。
- `radio-group-item`：声明单个选项的 `value` 与 `role="radio"`，从 `Root` 派生 `checked` 与有效 `disabled` 状态，仅发起选择请求而不自持选中态。
- `radio-group-indicator`：从最近的 `Item` 派生选中与禁用状态，仅负责视觉指示，不参与焦点或事件交互。

### 受控与非受控

- 非受控模式通过 `defaultValue` 指定初始值，选中变更时先更新状态再发出一次 `valueChange`。
- 受控模式传入 `value`，交互时仅发出 `valueChange` 请求，由外部回传的新 `value` 决定最终选中态。
- 空值或未匹配到任何选项的值会被原样保留，不会自动改选第一项；移除、禁用或修改当前选中项时也不会改写 `Root` 的值，后续重新出现匹配项时自动恢复选中状态。
- 每个 `Item` 的 `value` 应为非空且组内唯一；若存在重复值，仅首个匹配项会显示选中，针对歧义值的选择请求会被忽略。

### 键盘、焦点与无障碍

常规 Tab 顺序中仅保留一个可用 `Item`（优先为当前选中项，否则为首个可用项）；仅将焦点移入组内不会自动选中。

- `Space`：选中当前聚焦的可用项并阻止页面滚动。
- `ArrowRight` / `ArrowDown`：聚焦并选中下一个可用项（循环并跳过禁用项）。
- `ArrowLeft` / `ArrowUp`：聚焦并选中上一个可用项（循环并跳过禁用项）。
- `Home` / `End`：聚焦并选中首个或最后一个可用项。
- `focusSelf()` 仅移动焦点，不改变选中态；指针点击在完成提交后聚焦并选中，取消按压不会触发选择。

请通过 `a11yLabel` 或宿主属性为 `Root` 提供清晰的无障碍名称；每个 `Item` 会自动设置 `role="radio"`、`aria-checked` 和 `aria-disabled`。

### 只读与表单组合

- 设置 `readOnly` 后仍可聚焦并使用方向键浏览选项，但会拒绝更改选中值；设置 `disabled` 则同时退出常规焦点顺序。
- 普通 `radio-group-root` 不会自动注册到表单；若需接入必填校验、Label/Description/Error 关联与表单重置，请在 `FormField` 内使用 `@proto.ui/prototypes-base/field` 提供的 `fieldRadioGroup`（参考 [Form 选择控件示例](../form/)）。`resetValue()` 会请求恢复到实例创建时的初始值。

### 其他部件属性

- **Indicator**：无额外属性。
