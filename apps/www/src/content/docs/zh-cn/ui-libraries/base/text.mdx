## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版（工作区 CLI 目标为 `base-text`）。可从 `@proto.ui/prototypes-base/text` 或包根导入 `textRoot`（以及 `asTextRoot`、`TextRootProps`、`TextRootExposes`）。

## 用法

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { textRoot } from '@proto.ui/prototypes-base/text';

const Text = createReactAdapter(React)(textRoot, { rootTag: 'span' });

export function SectionTitle() {
  return (
    <h1>
      <Text size="4xl" font="heading" weight="semibold" leading="tight" tracking="tight">
        Account settings
      </Text>
    </h1>
  );
}
```

### 语义包裹与属性规则

- **保留原生语义元素**：`rootTag: 'span'` 为 Web Adapter 选项；文档结构与交互语义继续保留在外层原生 `<h1>`、`<p>`、`<label>`（`htmlFor`）或 `<a>`（`href`、`target`、`download`）上，`Text` 本身不添加焦点停靠点或点击事件。
- **颜色继承**：在 `solid` 或 `accent` 等深色 `Surface` 内部使用带样式的 `Text` 时，设置 `tone="inherit"` 可继承外层前景色以保持对比度。
- **字号与行高**：移除属性时恢复默认值；初始传入非法 `size` 回退为 `'base'`，已有合法值后再传入非法值则保持当前有效值。设置 `leading="size"` 时采用当前字号内建的行高（在 Shadcn 与 Brutalist 中，`xs` 至 `5xl` 分别对应 `1rem`、`1.25rem`、`1.5rem`、`1.75rem`、`1.75rem`、`2rem`、`2.25rem`、`2.5rem`、`1`）；`leading="tighter"` 对应 `1.1`，`tracking="tighter"` 对应 `-0.05em`。
