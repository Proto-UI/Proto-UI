Base Image（`base-image-root`）在 Web 端渲染原生 `<img>` 元素，统一管理图片源（`source`）、缩放填充模式（`fit`）、无障碍模式与实时加载状态。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。在工作区中可通过 `proto-ui add react base-image`（支持 `react`、`vue`、`vue2`、`wc`）生成宿主组件，或直接从 `@proto.ui/prototypes-base/image` 导入 `imageRoot` 与 `asImageRoot`。

## 用法

### 基础示例

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { imageRoot } from '@proto.ui/prototypes-base/image';

const Image = createReactAdapter(React)(imageRoot);

export function Cover() {
  return (
    <Image
      source="/images/cover.jpg"
      a11yMode="informative"
      alternativeText="倒映在湖中的山脊"
      fit="cover"
      surfaceStyle={{ width: '100%', height: '240px' }}
    />
  );
}
```

在其他宿主中，Vue 3 使用 `createVueAdapter(Vue)(imageRoot)`，Vue 2 使用 `createVue2Adapter(...)(imageRoot)`，Web Components 使用 `AdaptToWebComponent(imageRoot, { registerAs: 'app-image' })` 并通过 `setElementProps()` 设置属性。

### 无障碍语义与加载状态

- **`a11yMode` 与 `alternativeText`**：信息性图片（`a11yMode="informative"`，默认）必须提供非空 `alternativeText`；装饰性图片请显式设置 `a11yMode="decorative"`（不提供替代文本，输出空 `alt`）。
- **加载状态**：组件暴露 `source`、`fit` 与 `loadingStatus`（`'idle' | 'loading' | 'loaded' | 'error'`），状态变更时发出 `loadingStatusChange` 事件，数据为 `{ status, previousStatus, source }`。
- 省略或清空 `source` 时状态为 `'idle'`；替换 `source` 会清除旧画面并使未完成的旧请求失效；加载失败时可由应用自行渲染回退内容或重试操作。

### 尺寸控制与派生组合

`Root` 不接收子元素，容器尺寸、外框和说明文字由应用提供；Web Components 中可通过 `surfaceClassName` 与 `surfaceStyle` 直接为内部图片设置样式。派生原型复用 `asImageRoot` 时需同时声明其静态模块依赖：

```ts
import { definePrototype } from '@proto.ui/core';
import { asImageRoot } from '@proto.ui/prototypes-base/image';

const framedImage = definePrototype({
  name: 'framed-image',
  modules: asImageRoot.modules,
  setup() {
    asImageRoot();
  },
});
```
