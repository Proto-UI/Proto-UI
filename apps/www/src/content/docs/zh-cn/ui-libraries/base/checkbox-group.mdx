## 用法

### 组合结构

组件由 `Root`、`Item` 和 `All` 三个部分组成：

- `Root` 统一管理选中值数组（`value` / `defaultValue`）、禁用/只读状态与无障碍标签（`ariaLabel`），并通过 `getValue()` 返回当前值数组的副本。
- `Item` 通过唯一的 `value` 绑定单个选项，支持独立的 `disabled` 属性。重复值项会忽略歧义切换。
- `All` 根据当前启用的选项自动派生选中/半选（`mixed`）状态，并在切换全选时保留已禁用项的原有选择。

### 受控模式、键盘与表单集成

- 传入 `value` 进入受控模式：交互时仅触发 `valueChange` 事件，由调用方决定是否更新传入的值。
- 每个选项独立参与 Tab 顺序，按 `Space` 切换勾选状态（`Enter` 不会切换）。
- 放置在 `Field` / `FormField` 内时，`Root` 自动接入标签点击、必填校验、表单数据序列化与重置。

### 其他组件属性

- **Item**：接受 `value` 与 `disabled`。
- **All**：无额外属性，自动与组内启用项联动。
