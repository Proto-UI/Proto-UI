## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可从 `@proto.ui/prototypes-base/progress` 导入 `progressRoot`、`progressLabel`、`progressTrack`、`progressIndicator` 和 `progressValue`。

## 用法

由 `Root`、`Label`、`Track`、`Indicator` 和 `Value` 组成：

- **职责划分**：状态由 `Root` 统一管理；`Label` 提供名称，`Track` 容纳 `Indicator`，`Value` 显示 `valueText` 或规范化数值。
- **确定与不确定进度**：`value` 会限制在 `[min, max]` 内（上下界相等时比例为 `0`）。省略 `value` 或设置 `indeterminate={true}` 表示进度未知，此时不会向辅助技术上报具体当前值。
- **被动展示与状态暴露**：组件为纯展示控件，不引入键盘焦点停靠点或编辑事件；更新属性后自动同步所有部件。`Root` 及各部件暴露 `value`、`percentage`、`indeterminate` 和 `status`。
