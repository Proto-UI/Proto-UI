Base Dropdown Menu 是由 Trigger 打开的 compound action-menu。Root 拥有 visibility、request arbitration、collection order、entry policy 与 shared facts；瞬时 active navigation 永远不会变成 persistent selection。

## Family 与 request ownership

Canonical family 包含一个 Root、至多一个 Trigger 和 Content，以及最多 100 个 Items。所有 visibility 变化——methods、Trigger activation、dismissal 与 Item commit——都进入 Root 的 `openChange` request channel。

Root 接受 `open`、`defaultOpen`、`disabled`、`closeOnItemCommit`、`openEntry` 与 `openEntryValue`。它 expose open state、collection facts，以及 `openDropdown()`、`close()`、`toggle()`、`requestOpen()`。受控模式在新 input 到达前保持 owner 提供的 `open`。

Content 组合 overlay、transition、collection navigation、typeahead 与 anchor positioning。Item 接受 `value`、`textValue`、`disabled`、`closeOnCommit`，expose active/interaction facts，并发出 `select`。关闭会清空瞬时 active state，因此重新打开时服从新的 entry policy，而不会恢复虚假的“selection”。

## Accessibility 边界

这个 family 表示由按钮打开的一组 action/function。它不得把普通导航、任意 form 或 persistent selection 伪装成 menu。Group、Label、Separator 与 Shortcut 是下述有界草稿扩展。Checkbox Item、Radio Item 与 Submenu 不在本片交付范围。

## 包入口与生成的 facade

包入口是 `@proto.ui/prototypes-base/dropdown`。当前源码 CLI 注册了 `base-dropdown`，为所选宿主生成 Root、Trigger、Content 与 Item。Group、Label、Separator 与 Shortcut 是额外的包导出；这个 CLI 目标不会生成它们的 facade。

`T-BASE-DROPDOWN-MENU-0001` 把 family criteria 映射到 `packages/prototypes/base/test/dropdown.test.ts`。Preview 声明支持 Web Component、React 与 Vue；该声明不代表新 head 已运行，也不代表打包消费者验收。

## Lifecycle

`P-BASE-DROPDOWN-MENU` 及其 Trigger、Content、Item entities 当前都是 **draft**。Package 可用性不会把它们提升为 active guarantees。

## 分组动作组成（草稿）

Group 与 Label 建立实时辅助技术命名关系；Separator 和 Shortcut 是真实的被动部件。Shortcut 只显示提示，不注册全局快捷键。装饰部件不进入动作集合，也不增加 press owner。示例使用160px菜单、账户与资源分组和禁用的 API 动作。Invite users 的真实子菜单属于随后单独实现的协议片，不用演示盒子模拟。Checkbox/Radio变体及完整native/GPUI、Compiler、打包、视觉和独立验收仍未完成。

## API

传入 `open` 进入受控模式。

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'closeOnItemCommit', type: 'boolean', default: 'true' },
    { name: 'openEntry', type: 'string', default: 'active-or-first' },
    { name: 'openEntryValue', type: 'string', default: "''" },
  ]}
/>

这些属性属于 Root。Trigger 没有属性。Content 接受 Transition 属性，`side` 默认 `bottom`，`align` 默认 `center`，`sideOffset` 默认 `4`，`alignOffset` 与 `collisionPadding` 默认 `0`，`avoidCollisions` 默认 `true`，`excludeAnchorTranslation` 默认 `false`。Item 的 `disabled`、`value` 与 `textValue` 默认 `false`、`''` 与 `''`；`closeOnCommit` 没有默认值，回退到 Root 策略。Group 的 `a11yLabel` 默认 `''`。Label、Separator 与 Shortcut 没有属性。
