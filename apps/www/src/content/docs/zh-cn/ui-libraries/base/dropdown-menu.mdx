Base Dropdown Menu 是由按钮触发的复合操作菜单。`Root` 统一管理开关状态、菜单项顺序与进入焦点策略，`Content` 负责浮层定位、过渡动画、键盘导航与首字跳转。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。包入口为 `@proto.ui/prototypes-base/dropdown`；工作区 CLI 目标 `base-dropdown` 可生成 `Root`、`Trigger`、`Content` 和 `Item`，`Group`、`Label`、`Separator` 和 `Shortcut` 可直接从包中导入。

## 用法

### 组合结构

- **`Root`**：管理展开状态与菜单项集合，暴露 `openDropdown()`、`close()`、`toggle()`、`requestOpen()` 方法以及 `openChange` 事件。受控模式下由调用方传入 `open` 决定最终显示状态。
- **`Trigger`**：打开或切换菜单的触发按钮。
- **`Content`**：承载菜单浮层、定位、过渡、键盘导航和文字跳转。
- **`Item`**：单个可执行动作项，激活时发出 `select` 事件。关闭菜单时会自动清除瞬时高亮状态，避免下次打开误保留旧焦点。
- **`Group`、`Label`、`Separator`、`Shortcut`**：用于为菜单项提供分组无障碍命名、分隔线和静态快捷键提示文本（`Shortcut` 仅用于显示提示，不注册全局快捷键）。

### 使用建议

Dropdown Menu 适用于展示一组由按钮唤起的命令操作；如需带预设样式的菜单，请参阅 [Brutalist Dropdown Menu](/zh-cn/ui-libraries/brutalist/components/dropdown-menu/)。

### 其他组件属性

- **Trigger**：无额外属性。
- **Content**：支持 Transition 属性；`side` 默认 `'bottom'`，`align` 默认 `'center'`，`sideOffset` 默认 `4`，`alignOffset` 与 `collisionPadding` 默认 `0`，`avoidCollisions` 默认 `true`，`excludeAnchorTranslation` 默认 `false`。
- **Item**：`disabled` 默认 `false`，`value` 与 `textValue` 默认 `''`；可选 `closeOnCommit`，未设置时回退到 `Root` 的 `closeOnItemCommit`。
- **Group**：`a11yLabel` 默认 `''`。
- **Label、Separator、Shortcut**：无额外属性。
