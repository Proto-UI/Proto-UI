## 用法

由 `Root`、`Panel` 和 `Handle` 组成：

- **面板与分隔柄索引**：当配置 `N` 个面板时，为 `Panel` 依次设置 `index: 0..N-1`，为相邻面板间的 `N-1` 个 `Handle` 设置 `index: 0..N-2`（每个 `Handle` 调整其紧邻的前后两个面板，并保持其他面板尺寸不变，默认无障碍名称为 `Resize panels`）。
- **尺寸表示与布局**：`Root` 的 `sizes` / `defaultSizes` 表示总计为 `100` 的百分比数组；同时兼容旧的双面板 `value` / `defaultValue` 属性（同时传入时以 `sizes` 为准）。每个 `Panel` 导出无量纲 `size` 状态，Web 端可直接通过读取 `--pui-size` 的静态 `flex-basis` 规则驱动宽度或高度，拖拽计算基于面板实际总长度（不含固定分隔柄宽度）。
- **交互与约束**：拖拽、方向键、`Home`/`End`、`Shift` 加速步进与折叠均共用同一约束路径。通过 `constraints` 可逐面板配置 `min`（默认 `0`）、`max`（默认 `100`）、`collapsible`（默认 `false`）和 `collapsedSize`（默认 `0`）。若布局不可行则保留上一个有效状态并忽略非法调整；折叠为离散停点，受相邻面板上限约束。
- **受控模式与嵌套**：传入 `sizes` 进入受控模式，监听 `sizesChange` / `sizesCommit`（载荷均为 `{ sizes }`），回传提议即接受，保持原值即拒绝；取消手势不会触发 `sizesCommit`。嵌套的 `Root` 各自独立管理比例、方向和约束。

多面板模式支持 `sizes`、`defaultSizes` 与 `constraints`。`Panel` 与 `Handle` 支持 `index`（默认 `0`）。

- **公开状态与方法**：读取 `sizes`，或调用 `requestResize(index, nextSize, commit)` / `requestSizes(nextSizes, commit)`。
- **事件**：`sizesChange`、`sizesCommit`（载荷为 `{ sizes }`）。
