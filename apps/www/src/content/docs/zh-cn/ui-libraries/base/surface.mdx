用于包裹内容的被动视觉表面容器，统一规范背景层级、圆角、边框、抬升与交互视觉状态词汇，具体样式由各风格组件实现。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版（工作区 CLI 目标为 `base-surface`）。可从 `@proto.ui/prototypes-base/surface` 或包根导入 `surfaceRoot`（以及 `SurfaceRootProps`、`SurfaceRootExposes`、`asSurfaceRoot`、`SurfaceRootAsHookContract`）。

## 用法

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { surfaceRoot } from '@proto.ui/prototypes-base/surface';

const Surface = createReactAdapter(React)(surfaceRoot);

export function Summary() {
  return (
    <Surface variant="muted" radius="md" border="none">
      <div style={{ padding: '1rem' }}>Saved locally</div>
    </Surface>
  );
}
```

### 被动视觉状态

- `hovered`、`focusVisible`、`pressed` 与 `current` 均由外层交互组件传入，`Surface` 本身不监听指针/键盘事件，也不附加无障碍角色、焦点停靠点或点击行为。
- 移除某个属性时会恢复默认值；布局与内边距由调用方控制。当带样式的 `Text` 位于 `Surface` 内部且需要继承前景色时，可设置 `tone="inherit"`。
- 当需要真实按钮或链接交互时，应使用 `Button` 或原生 `<a>` 元素，而不是在 `Surface` 上添加交互事件。

### 联动 Transition 淡入淡出

- 设置 `fade={true}` 后，风格组件会根据传入的 `transitionState`（来自 [Transition](/zh-cn/ui-libraries/base/transition/)）映射透明度：`closed` 与 `leaving` 为 `0`，`entering` 与 `entered` 为 `1`。
- Web 端可通过 CSS 变量 `--pui-surface-transition-duration`（默认 `0ms`）同步既有过渡时长。
- `scrim` 变体用于常规遮罩层着色；透明度为 `0` 仅影响视觉显示，禁用、隐藏与焦点隔离仍由外层 `Dialog` 或 `Transition` 控制。
