## 用法

由 `Root`、`Label`、`Input`、`Control`、`Increment` 和 `Decrement` 组成：

- **输入与步进**：状态由 `Root` 统一管理。`Input` 提供带 `spinbutton` 语义的文本编辑体验，编辑期间允许保留未完成草稿，失焦或按 `Enter` 时提交合法数值或恢复上次有效值。点击 `Increment`/`Decrement` 或按上下方向键按 `step` 步进，按住 `Shift` 为十倍步进；`Home`/`End` 跳至上下界（未设对应边界时保留编辑器默认光标移动）。传入 `value` 进入受控模式。
- **本地化格式化与输入法**：通过 `locale` 和 `formatOptions` 支持十进制、货币和百分比格式化及对应小数点、分组符、本地数字与符号解析。显示舍入不影响底层数值精度，未编辑直接提交不会写回舍入值。若格式配置非法，会标记 `formatInvalid` 并回退为无分组十进制。IME 组合输入期间暂停解析、提交、步进与拖擦，切换 `locale` 时保留正在输入的组合文本。
- **空值支持**：显式 `null` 表示空值，`value={null}` 保持受控。默认 `allowEmpty={false}`；开启后清空输入并提交可请求 `null`。通过 `getValue(): number | null` 和 `empty` 读取真实状态（兼容数值属性 `value` 仅在 `empty` 为 `false` 时反映当前数值，事件及 `Field`/`Form` 始终接收真实 `null`）。从空值首次步进时会初始化为边界内对齐步长的 `0`。
- **标签拖擦调值**：开启 `scrub` 后可在 `Label` 上水平拖动连续调值，`scrubSteps`（默认 `100`）定义拖动一个初始标签宽度对应的步数，`direction="rtl"` 反转横向方向。释放且值变化时提交一次；取消则恢复非受控起始值，输入框本身保留正常文本选择。
- **表单集成**：在 `Field` / `FormField` 内使用 `Control` 替代 `Input`，自动联动 `FieldLabel`、必填状态、数值校验、表单序列化与复位；独立使用时配合 `Label` 与 `Input`。

`Label`、`Input`、`Control`、`Increment` 与 `Decrement` 无额外属性。

- **边界与步长**：省略 `min`/`max` 时默认使用 `0`/`100`，显式传入 `null` 可移除对应边界。设置 `snapToStep={false}` 可保留初始值与手动输入的任意有限数值，同时继续按 `step` 步进。
- **必填合并**：`required` 会与外层 `Field` 的必填设置合并，并同步应用到原生编辑器和无障碍属性。
