## 用法

由 `Root`、`Trigger`、`Content`、`Title`、`Description` 和 `Close` 组成：

- **定位与非模态行为**：`Content` 相对 `Trigger` 定位，支持 `side`、`align`、`sideOffset`、`alignOffset` 和 `collisionPadding`。作为非模态浮层，它不锁定背景滚动，也不限制页面内的 `Tab` 焦点流。
- **关闭与焦点管理**：点击外部、焦点移出 `Trigger` 与 `Content`、按 `Escape` 或触发 `Close` 都会请求关闭。在 `Trigger` 与传送后的 `Content` 之间切换焦点视为内部交互；焦点移出外部时关闭会将焦点保留在新的外部控件上，不会强行拉回 `Trigger`。
- **受控与非受控**：使用 `defaultOpen` 配置非受控初始状态；传入 `open` 进入受控模式，并通过监听 `openChange` 更新外部状态（纯焦点移出请求的 `focusReason` 为 `'programmatic'`）。若受控端拒绝 `focus.outside` 请求，`Content` 会保持显示且不限制外部焦点，后续交互仍可再次请求关闭。禁用状态下不会响应触发。

传入 `open` 可受控管理展开状态。

### 其他部件属性

- **Content**：支持 `Transition` 属性，并提供 `side`（默认 `'bottom'`）、`align`（默认 `'center'`）、`sideOffset`（默认 `4`）、`alignOffset`（默认 `0`）、`collisionPadding`（默认 `8`）。
- **Trigger**、**Title**、**Description**、**Close**：无额外属性。
