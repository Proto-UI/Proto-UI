Base Hover Card 在指针悬停或焦点进入触发元素后延迟显示预览浮层，适合展示补充信息。它由 `Root`、`Trigger` 和 `Content` 组成，内置 Portal、定位与碰撞回避以及离开过渡结束后再卸载内容节点的能力。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。在工作区中对应的 CLI 目标为 `base-hover-card`。

## 用法

### 组合结构与交互

- **`Root`**：统一管理打开状态（受控 `open` 或非受控 `defaultOpen`）、展开/关闭延迟（`openDelay`、`closeDelay`）与 `openChange` 事件，并暴露 `openHoverCard()`、`close()`、`toggle()` 以及用于部件协同的 `releaseInteraction(part, contributionId)` 方法。
- **`Trigger`**：监听悬停与焦点进入事件并触发延迟展开；设置 `disabled={true}` 时阻止触发。
- **`Content`**：通过 Portal 渲染浮层并自动处理相对锚点的 `side`、`align`、偏移量与碰撞回避；关闭时等待离开过渡完成后再卸载节点。

### 受控模式与视图生命周期

- 传入 `open` 进入受控模式：悬停或移出经过延迟后会触发 `openChange`，由调用方决定是否更新 `open`。
- 当 `Trigger` 或 `Content` 临时移除或重新挂载时，仅清理对应部件当前的悬停/焦点贡献，不会重放旧状态。

### 其他组件属性

- **Trigger**：`disabled` 默认为 `false`。
- **Content**：支持 Transition 属性；`side` 默认 `'bottom'`，`align` 默认 `'center'`，`sideOffset` 默认 `4`，`alignOffset` 与 `collisionPadding` 默认 `0`，`avoidCollisions` 默认 `true`。
