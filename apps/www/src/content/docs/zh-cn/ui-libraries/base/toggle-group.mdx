## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。

## 用法

由 `Root` 与 `Item` 组成：

- **单选与多选**：`value` / `defaultValue` 统一为字符串数组。默认 `multiple={false}` 时最多保留一个选中值，再次点击已选项可取消选中；开启 `multiple={true}` 可同时激活多项。
- **受控模式与交互**：传入 `value` 进入受控模式，`valueChange` 仅发出候选值数组而不修改外部状态。方向键在选项间移动焦点但不自动切换选中态；禁用、只读或组内重复值的选项不会提交变更。
