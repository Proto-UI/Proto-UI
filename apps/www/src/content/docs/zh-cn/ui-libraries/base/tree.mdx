## 用法

由 `Root`、`Item`、`Group` 和 `Toggle` 组成：

- **节点标识与分支结构**：每个节点在当前树内使用唯一的 `nodeKey`，并通过 `parentKey` 指向父节点（重复标识、缺失父节点或循环引用会被忽略并保持当前状态）。每个 `TreeGroup` 使用与所属分支 `Item` 相同的 `nodeKey`，其子项放在该 `Group` 内并以 `parentKey` 指向该分支。
- **键盘导航与 RTL 支持**：上下方向键、`Home`/`End` 与首字母跳转按可见逻辑顺序移动焦点；在默认 LTR 下，右键展开或进入子项、左键折叠或返回父项，设置 `direction="rtl"` 时左右键自动互换（Shadcn 与 Brutalist 的分支缩进也随之跟随文字方向）。
- **折叠与焦点恢复**：自动维护 `Item` 与 `Group` 之间的 `aria-controls` / `aria-labelledby` 关联并在目标移除或歧义时清理。折叠分支会隐藏其 `Group` 但保留完整层级数据；若焦点位于被折叠的分支内，焦点会安全移至最近的可见祖先节点，而不会干扰树外的焦点。
- **受控与只读**：传入 `value` 或 `expandedKeys` 进入对应状态的受控模式。`readOnly` 会阻止更改选中项，但保留键盘浏览与展开/折叠；动态增删或移动节点会自动更新层级结构，不触发伪造的用户选择事件。

传入 `value` 或 `expandedKeys` 可分别受控管理选中节点或展开节点集合。

### 其他部件属性

- **Item**：`nodeKey`（默认 `''`）、`parentKey`（默认 `''`）、`textValue`（默认 `''`）、`disabled`（默认 `false`）。
- **Group**：`nodeKey`。
- **Toggle**：额外支持与 `Button` 相同的属性。
