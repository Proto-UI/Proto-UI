## 用法

### 组合结构

组件由 `Root`、`Trigger`、`Content` 和 `Item` 组成：

- `Root` 管理开关状态（`open` / `defaultOpen`）、禁用状态与菜单项提交后的关闭策略（`closeOnItemCommit`）。
- `Trigger` 监听右键菜单、`ContextMenu` / `Shift+F10` 及触摸/手写笔长按（在移动容差内持续按住 600 ms），并自动阻止对应原生上下文菜单；普通左键点击与滚动保持默认行为。
- `Content` 提供浮层定位、焦点管理、文字跳转和过渡动画，默认从 `bottom` / `start` 展开。右键和长按锚定在输入点，键盘快捷键或程序调用 `openContextMenu()` 锚定在触发区域。

### 受控模式与焦点恢复

- 传入 `open` 进入受控模式：触发请求时会阻止原生菜单并通知调用方，最终显示与否由传入的 `open` 决定。
- 按 `Escape` 或完成菜单项选择后，焦点会自动回到原触发器。

### 其他组件属性

- **Trigger**：无额外属性。
- **Content**：支持 Transition 属性；`side` 默认 `'bottom'`，`align` 默认 `'start'`，`sideOffset` 与 `alignOffset` 默认 `0`，`avoidCollisions` 默认 `true`，`collisionPadding` 默认 `0`，`excludeAnchorTranslation` 默认 `false`。
- **Item**：`disabled` 默认 `false`，`value` 与 `textValue` 默认 `''`；可选 `closeOnCommit`，未设置时回退到 `Root` 的 `closeOnItemCommit`。
