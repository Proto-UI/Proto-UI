## 用法

### 尺寸与滚动布局

- `top` / `bottom` 方向的 `Content` 默认按内容自适应高度，并受当前安全可用高度限制；`left` / `right` 方向默认采用比例宽度（缺省上限为 20 个 `root-text` 单位）。
- 通过 `Content` 的 `minExtent` 与 `maxExtent` 设置尺寸（代替直接写 CSS 宽度/高度），支持的单位包括 `'logical'`、`'root-text'`、`'available'` 与 `'available-minus-root-text'`。例如 `maxExtent={{ unit: 'logical', value: 480 }}` 在空间允许且吸附比例为 `1` 时呈现 480 逻辑像素宽度。
- `Content` 默认作为纵向滚动容器（`overflow-y-auto`），在长内容场景下可直接滚动展示全部内容与底部关闭操作。
- 将 `Root` 直接放入 CSS Grid 容器时，可在 React 上设置 `hostStyle={{ display: 'contents' }}`（或在 Web Component 上设置 `display: contents`），避免额外占用网格行。

### 拖动关闭与显式吸附点

- `top` / `bottom` 未传 `snapPoints`（或传空数组）时保持内容自适应高度；传入由 `(0, 1]` 组成的非空比例数组即可启用多档位吸附（自动排序去重）。
- 吸附位置支持非受控（`defaultSnapPoint`）和受控（`snapPoint` + `snapPointChange`）模式；在显式吸附模式下，`Handle` 提供具名 `separator` 语义及方向键、`Home` / `End` 调整；在内容自适应模式下，`Handle` 仅作为指针拖动手柄。
- 设置 `Content` 的 `dragDismissible={false}` 可禁用拖动关闭，同时保留 `Close`、`Escape` 和外部点击关闭。
- 传入 `open` 进入受控模式：当调用方拒绝关闭请求或拖动中断时，面板会自动恢复到当前已提交状态。

### 其他组件属性

- **Mask**：`passthrough` 默认为 `false`，同时支持 Transition 属性。
- **Content**：`side` 默认为 `'bottom'`，同时支持 `minExtent`、`maxExtent`、`snapPoints`、`snapPoint`、`defaultSnapPoint`、`dragDismissible` 及 Transition 属性。
- **Handle**：`disabled` 默认为 `false`，`a11yLabel` 默认为 `'Resize drawer'`。
- **Trigger、Title、Description、Header、Footer、Close、AcceptedSide**：无额外属性。
