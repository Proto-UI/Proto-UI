## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `@proto.ui/prototypes-base/meter` 导入 `meterRoot`、`meterLabel`、`meterTrack`、`meterIndicator` 和 `meterValue`。

## 用法

由 `Root`、`Label`、`Track`、`Indicator` 和 `Value` 组成：

- **职责划分**：状态由 `Root` 统一管理；`Label` 提供名称，`Track` 容纳 `Indicator`，`Value` 显示 `valueText` 或规范化后的数值。
- **范围与区间分级**：`value` 会限制在 `[min, max]` 内（上下界相等时比例为 `0`）。设置 `low`、`high` 和 `optimum` 可将当前测量值归类为 `optimal`、`suboptimal` 或 `critical`，但不改变数值本身。
- **被动展示与状态暴露**：组件为纯展示控件，不引入键盘焦点停靠点或编辑事件；更新属性后会同步所有部件。`Root` 及各部件暴露 `value`、`percentage`、`indeterminate` 和 `status`。
