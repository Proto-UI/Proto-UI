## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版（工作区 CLI 目标为 `base-select`；已发布版本的接入方式见[稳定版 Quick Start](/zh-cn/start-here/quick-start/)）。

预览面板的完整代码使用 `@proto.ui/cli`、`@proto.ui/prototypes-base`、`@proto.ui/prototypes-lucide` 以及对应宿主的 Adapter 包（Vue 2 需使用 Vue `>=2.6.0 <2.7`）：

| 宿主           | Adapter 包                        | 示例入口文件  |
| -------------- | --------------------------------- | ------------- |
| Web Components | `@proto.ui/adapter-web-component` | `index.html`  |
| React          | `@proto.ui/adapter-react`         | `src/App.tsx` |
| Vue            | `@proto.ui/adapter-vue`           | `src/App.vue` |
| Vue 2          | `@proto.ui/adapter-vue2`          | `src/App.vue` |

首次接入时运行同版本 CLI 初始化结构样式文件 `src/styles/proto-ui-style.css`（若入口已导入，保留一次即可）：

```sh
node node_modules/@proto.ui/cli/bin/proto-ui.js init --yes --no-interactive --prototypes shadcn
```

在各宿主中，Web Components 在连接到文档前通过 `setElementProps` 设置 `accessibleLabel`、`placeholder` 与选项值；React 将 `react-dom` 的 `createPortal` 传入 `createReactAdapter` 以托管弹层传送门；Vue 与 Vue 2 注册所使用的各部件。通过 `Trigger` 的 `accessibleLabel` 可为控件设置独立于选中值的无障碍名称。

## 用法

### 组件结构

- `select-root`：统一管理受控或非受控的 `open`、`value` 与 `textValue`，并仲裁变更请求。
- `select-trigger`：独立触发器，提供 `combobox` 无障碍语义并处理指针与键盘开关。
- `select-value`：由组件内部渲染当前 `displayValue` 或 `placeholder`，无需应用手工拼接显示文本。
- `select-content`：组合弹层、过渡、漫游焦点与锚点定位。
- `select-item`：提供 `option` 语义，严格区分打开时的瞬时导航焦点（`active`）与已提交的持久选中态（`selected`）。
- **可选分组与结构部件**：`select-surface`、`select-viewport`、`select-item-text` 提供显式对齐容器；`select-group` 与 `select-label` 为选项分组提供独立的无障碍命名（缺少或重复标签时忽略命名，嵌套 Select 之间互不串名）；`select-separator` 为对辅助技术隐藏的纯装饰分隔线（组合 `asSelectSeparator` 时需显式返回空渲染器）。三者同时导出 `asSelectGroup`、`asSelectLabel`、`asSelectSeparator`。

### 键盘、指针与触摸交互

打开列表时优先聚焦当前选中项（无选中项时聚焦边界项），支持方向键、`Home`/`End` 与首字母跳转；按 `Escape`、`Tab` 或点击外部关闭并按需恢复焦点。

传入 `open` 或 `value` 可分别受控管理展开状态或选中值。

### 其他部件属性

- **Trigger**：`accessibleLabel`（默认 `''`）。
- **Value**：`placeholder`（默认 `''`）。
- **Content**：支持 `Transition` 属性，提供 `position`（默认 `'popper'`）、`side`（默认 `'bottom'`）、`align`（默认 `'center'`）、`sideOffset`（默认 `4`）、`alignOffset`（默认 `0`）、`avoidCollisions`（默认 `true`）、`collisionPadding`（默认 `10`）。
- **Item**：`disabled`（默认 `false`）、`value`（默认 `''`）、`textValue`（默认 `''`）、`closeOnSelect`（默认跟随 `Root` 设置）。
- **Group**、**Label**、**Surface**、**ItemText**、**Viewport**、**Separator**：无额外属性。
