## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。在工作区中对应的 CLI 目标为 `base-dialog`。

## 用法

### 组合结构

- **`dialog-root`**：统一管理 `open` 状态并向子组件提供上下文。
- **`dialog-trigger`**：点击时打开或切换对话框。
- **`dialog-mask`**：渲染背景遮罩层，随开关状态执行进入/离开过渡。默认会在 `pointer.down` 时阻止背景默认行为，避免干扰对话框关闭时的焦点恢复；若希望允许点击穿透，可设置 `passthrough={true}`。
- **`dialog-content`**：内容容器，负责焦点陷阱、关闭策略（`Escape`、外部点击）以及进入/离开过渡。
- **`dialog-title`**：语义标题，自动通过 `aria-labelledby` 与内容关联。
- **`dialog-description`**：语义说明，自动通过 `aria-describedby` 与内容关联。
- **`dialog-close`**：点击时请求关闭对话框。

### 警示模式与外观组合

- 在 `dialog-root` 上设置 `alert={true}` 可切换为警示对话框：自动应用 `role="alertdialog"` 并禁用外部点击关闭，同时保留 `Escape` 键关闭。
- 如需自定义背景或面板视觉层，可组合使用装饰性 [Surface](/zh-cn/ui-libraries/base/surface/) 读取过渡状态。

### 其他组件属性

- **Mask**：`passthrough` 默认为 `false`，同时支持 Transition 属性。
- **Content**：`focusEntry: 'auto' | 'content' | 'manual'` 默认为 `'auto'`，同时支持 Transition 属性。`'content'` 在打开时聚焦 Content 本身，但不把它加入 Tab 顺序；Tab 仍进入弹窗内的控件。`'manual'` 将初始焦点安排交给消费者。每次激活时读取策略，打开期间修改该属性不会移动焦点。三种模式均保留焦点约束和关闭后的恢复。
- **Trigger、Title、Description、Close**：无额外属性。
