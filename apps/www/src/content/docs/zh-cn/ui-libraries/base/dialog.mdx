Dialog 家族提供构建模态窗口的协议层基础部件。Root 持有 open 状态；本页不引入切换非模态的 `modal` prop。

- **dialog-root**：持有 `open` 状态，并向所有子部件提供上下文。
- **dialog-trigger**：点击时打开或切换对话框。
- **dialog-mask**：渲染背景遮罩层，跟随 open 状态进入/离开过渡。
- **dialog-content**：内容容器，负责焦点陷阱、浮层关闭策略（ESC、外部点击）以及进入/离开过渡。
- **dialog-title**：语义标题，自动通过 `aria-labelledby` 与 content 关联。
- **dialog-description**：语义描述，自动通过 `aria-describedby` 与 content 关联。
- **dialog-close**：点击时关闭对话框。

向 `dialog-root` 传入 `alert` 可将其转换为 alert dialog：它会设置 `role="alertdialog"`，并禁用外部点击关闭，同时保留 ESC 关闭行为。

## Draft 工作区中的 Mask 行为

工作区修订的 `P-BASE-DIALOG-MASK-DEFAULT-ACTION` 继续让 Content 独立拥有 focus/dismissal。participating Mask 对自身 root-scoped `pointer.down` 请求阻止默认动作，避免背景指针默认行为覆盖 Content 关闭时恢复的焦点；设置 `passthrough=true` 的 Mask 不请求这项阻止。Mask 不接管关闭、事件传播或键盘处理，也不承诺识别其内部任意缺少独立交互 owner 的原生后代。

这是 [PR #777](https://github.com/Proto-UI/Proto-UI/pull/777) 引入的 draft 工作区行为，不是对先前发布的 0.2 包的追加保证。装饰性 [Surface](/zh-cn/ui-libraries/base/surface/) 可以消费已有 Transition 事实来绘制，但不能成为另一份 Dialog、焦点或关闭 owner。

## API

Dialog 是工作区源码，没有公开的 `proto-ui add` 目标。传入 `open` 进入受控模式。

这些属性属于 Root。Mask 接受 `passthrough`（`false`）以及 Transition 属性。Content 的 `focusEntry` 默认 `auto`，同样接受 Transition 属性。Trigger、Title、Description 与 Close 没有属性。
