## 用法

### 组合结构

组件由 `Root`、`Legend` 和 `Description` 组成：

- **`Root`**：声明 `group` 语义并管理有效 `disabled` 状态，支持通过 `ariaLabel` 或子级 `Legend` 命名分组。
- **`Legend`**（可选）：分组标题，自动关联 `aria-labelledby`，不增加额外 Tab 停靠点。
- **`Description`**（可选）：分组帮助说明，自动关联 `aria-describedby`。
- 每个分组内最多包含一个 `Legend` 与一个 `Description`；嵌套的 Fieldset 各自维护独立的名称与说明关联，不会互相串扰。

### 嵌套禁用继承

任意层级的 `disabled` 状态会向下传递到所有子级 Fieldset 和内部参与的 `Field`（包括位于 `Legend` 内的字段）：

- 外层设为 `disabled` 时，所有内层分组均处于禁用状态。
- 中层和外层同时禁用时，重新启用外层后，中层及更内层仍保持禁用。
- 只有所有祖先与自身都未禁用时，该分组才恢复启用。
