## 用法

### 组合结构

组件由 `Root`、`Input`、`Content`、`Item`、`Empty` 和 `Trigger` 组成：

- `Root` 分别维护已提交的值（`value`）与当前输入查询（`inputValue`）。
- 选中建议项会提交该项的 `textValue`；当没有高亮候选项时，按 `Enter` 可直接提交当前输入的自由文本。
- 过滤默认基于 `Item` 的 `textValue` 与 `keywords`，忽略大小写和重音符号；设置 `filter={false}` 时可由应用自行过滤并渲染子项。
- `Empty` 根据实际匹配项数量自动显示或隐藏；禁用项和重复值项不可提交。

### 受控模式与键盘交互

- `value`、`inputValue` 和 `open` 均支持独立受控，状态变化通过对应事件通知调用方。
- 上下方向键导航候选项时，焦点始终保留在输入框内；输入法（IME）组合输入期间不会误触发选择。

### 其他组件属性

- **Input**：`placeholder`、`a11yLabel`、`name` 默认均为 `''`。
- **Content**：`side` 默认 `'bottom'`，`align` 默认 `'start'`，`sideOffset` 默认 `4`，`collisionPadding` 默认 `8`。
- **Item**：`value`、`textValue`、`keywords` 默认均为 `''`，`disabled` 默认 `false`。
- **Empty**：无额外属性。
- **Trigger**：`disabled` 默认 `false`。
