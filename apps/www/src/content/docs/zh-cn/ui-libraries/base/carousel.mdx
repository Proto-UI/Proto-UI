## 用法

### 响应式视口容量

通过 `Root` 的 `slidesPerView`（默认 `1`）设置每页最多显示的等尺寸项数，配合 `minSlideSize`（默认 `0`，逻辑像素）设定单一项的最小尺寸。视口变窄时会自动减少实际可见项数，同时保持所有项的布局尺寸不变。`Root` 暴露 `visibleSlides` 和 `maxIndex`，末尾吸附位置会自动贴齐内容末端，避免留白。

### 受控索引与交互状态

- 传入 `index` 进入受控模式，切换或吸附时会通过 `indexChange` 发出目标索引；拖动过程中不会提前修改已提交的 `index`，松手后根据调用方的新值决定停靠位置。
- `Viewport` 暴露 `dragging`、`scrolling` 与归一化 `scrollPosition`；`Slide` 暴露 `current`（跟随当前吸附项）与 `hidden`（反映屏外可见性且保留布局占位）。
- 使用 `orientation="vertical"` 时，请为视口容器设置明确高度；横向 `direction="rtl"` 会反转物理拖动与方向键，但保持逻辑顺序。
- `loop={true}` 会在首尾可达索引间循环切换（不克隆节点）。

### 其他组件属性

- **Viewport**：无额外属性。
- **Slide**：可选 `index`，省略时按 DOM 结构顺序自动分配。
