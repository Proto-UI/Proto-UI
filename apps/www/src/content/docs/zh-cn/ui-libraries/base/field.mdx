Base Field 将单个表单控件与标签（`Label`）、帮助说明（`Description`）、错误提示（`Error`）及状态读取器（`Validity`）组合在一起，自动维护无障碍属性关联，并支持内置校验与版本化异步校验。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `@proto.ui/prototypes-base/field` 导入 `fieldRoot`、`fieldLabel`、`fieldControl`、`fieldDescription`、`fieldError`、`fieldValidity` 以及通用控件接入桥 `asFieldControl`、`asFieldTextControl`。

## 用法

### 组合结构

每个 `Root` 内包含一个 `Control`，以及可选的 `Label`、`Description`、`Error` 和任意个 `Validity`（嵌套的 `Root` 各自独立）：

- **`Root`**：统一管理字段校验状态（`invalid`、`pending`、`dirty`、`touched`、`filled`、`focused`、`disabled`、`readOnly`、`required`），并暴露 `validate(reason?)`、`resolveValidation(requestId, result)`、`cancelValidation()`、`resetValidation()`、`focusControl(options?)` 和 `getValidity()`。
- **`Control`**：默认提供单行文本输入，也可通过 `asFieldControl` 将自定义控件（如复选框、单选组等）接入字段校验与标签聚焦。
- **`Label`**：自动为控件提供 `aria-labelledby`，并在 `activation={true}`（默认）时点击聚焦对应控件。
- **`Description`**：被动帮助说明文本，自动关联 `aria-describedby`。
- **`Error`**：校验失败时自动通过 `aria-errormessage` 与控件关联，按 `message` → 当前 `errors` → 内置提示的优先级展示文案。关闭时默认卸载内容节点，设置 `keepMounted` 可保留隐藏节点；如需屏幕阅读器主动播报，请按需组合 `LiveRegion`。
- **`Validity`**：被动读取并展示当前 `getValidity()` 状态快照。

### 内置校验与异步外部校验

- 内置约束支持 `required`、`minLength` 与 `maxLength`（按 UTF-16 码元计数），并按 `validationMode`（`'onBlur'`、`'onChange'` 或 `'manual'`）触发；`'onChange'` 会等待输入法组合（`compositionend`）完成后再校验。
- `required` 将 `null`、`false`、`''` 和空数组视为空值（`0` 和空白字符串视为已填，不自动裁剪）；可选字段为空时跳过长度检查。
- 启用 `externalValidation={true}` 后，内置约束通过时会发出 `validationRequest` 事件（数据为 `{ requestId, value, reason }`）。应用执行异步检查后调用 `resolveValidation(requestId, { invalid, errors })` 提交结果；若在此期间值变化、重新请求、取消或控件状态变更，过期结果会被自动忽略。
- 传入 `invalid` / `errors` 进入受控校验模式：校验完成后发出 `validityChange` 事件，由调用方更新传入属性；`resetValidation()` 仅清除校验与 `touched` 状态，不修改字段值或 `dirty` 基线。

### 无障碍关联与清理

组件自动维护 `aria-labelledby`、`aria-describedby`、`aria-errormessage` 以及 `aria-required`、`aria-invalid`、`aria-busy`、`aria-readonly`，无需手动分配 DOM ID，并在部件卸载时自动清理关联。

### 其他组件属性

- **Label**：`activation` 默认为 `true`。
- **Control**：接受文本输入属性：`value` / `defaultValue`、`placeholder`、`name`、`autoComplete`、`ariaLabel` 默认 `''`；`disabled`、`readOnly`、`required` 默认 `false`；可选 `inputMode` 与 `enterKeyHint`。
- **Error**：`message` 默认 `''`，`keepMounted` 默认 `false`。
- **Description、Validity**：无额外属性。
