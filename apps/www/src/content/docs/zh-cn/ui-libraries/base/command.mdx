Base Command 提供常驻内联展开的可搜索命令列表。用户按 `Enter` 或点击命令项时会发出 `execute` 事件，由应用执行对应操作。

## 用法

### 组合结构

组件由 `Root`、`Input`、`Content`、`Item` 和 `Empty` 组成：

- 列表默认保持展开（`defaultOpen` 默认为 `true`），输入关键词仅过滤候选项，不会直接触发命令。
- 过滤基于 `Item` 的 `textValue` 和 `keywords`，忽略大小写与重音符号；设置 `filter={false}` 时可由应用自行提供过滤后的子项。
- `Empty` 根据实际匹配项数量自动显示或隐藏；禁用项与重复值项不可执行。

### 受控模式与键盘交互

- `value`、`inputValue` 与 `open` 均支持独立受控。
- 上下方向键切换高亮命令时焦点保持在 `Input` 上；输入法（IME）组合期间不会误触命令执行。

### 其他组件属性

- **Input**：`placeholder`、`a11yLabel`、`name` 默认均为 `''`。
- **Content**：`side` 默认 `'bottom'`，`align` 默认 `'start'`，`sideOffset` 默认 `4`，`collisionPadding` 默认 `8`。
- **Item**：`value`、`textValue`、`keywords` 默认均为 `''`，`disabled` 默认 `false`。
- **Empty**：无额外属性。
