Base Input（`base-input-root`）在 Web 端渲染单个原生 `<input type="text">`，统一提供受控/非受控值管理、输入法组合（IME）事件、聚焦控制与无障碍属性，外观样式由应用自定义。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可从 `@proto.ui/prototypes-base/input` 导入默认 Root、`inputRoot` 或组合钩子 `asInputRoot`。带预设样式的输入框请参阅 [Shadcn Input](../../shadcn/input/)。

## 用法

### 值管理与输入事件

- **非受控模式**：使用 `defaultValue` 初始化文本；后续更新其他属性不会重置用户已输入的内容。
- **受控模式**：传入 `value` 即进入受控模式，用户输入会发出 `valueChange`，需由调用方将新值回传给 `value` 后才更新显示。所有权模式在实例创建时确定，不在运行中切换。
- **事件数据**：`valueChange` 携带 `{ value, composing, data, inputType }`，`change` 携带 `{ value }`，`compositionStart`、`compositionUpdate`、`compositionEnd` 携带 `{ value, data }`。

### 重置编辑器（`resetValue`）

已挂载的实例暴露 `resetValue(value?: string): boolean` 方法，用于重置当前编辑及 IME 组合会话（不会合成 `valueChange`、`change` 或 `compositionEnd` 事件）：

- **非受控模式传入字符串**：将文本重置为移除 CR/LF 换行后的单行字符串，返回 `true`。
- **非受控模式不传参数（或传 `undefined`）**：重置为最新的 `defaultValue`（同样归一化为单行），返回 `true`。
- **受控模式**：结束当前 IME 组合会话但保留调用方传入的 `value`，返回 `false`；节点未挂载、已卸载或传入非字符串参数时同样返回 `false`。

在预览中，可点击 **Set latest default**、**Reset to default**、**Reset to sample** 和 **Try controlled reset** 体验上述行为。

### 聚焦与暴露状态

组件暴露 `focusSelf()`、`blurSelf()`、`resetValue(value?)` 方法，以及 `value`、`disabled`、`readOnly`、`focused`、`focusVisible`、`composing` 状态。`inputMode` 与 `enterKeyHint` 用于向软键盘提供输入提示。
