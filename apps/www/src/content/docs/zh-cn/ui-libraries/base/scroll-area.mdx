## 用法

### 组件结构

- **Root**（1 个）：组织区域结构与范围，不管理滚动偏移或尺寸。
- **Viewport**（1 个）：管理逻辑滚动表面，暴露归一化后的滚动轴、位置、可见比例、可滚动方向、滚动中状态与当前滚动条策略，并将像素、物理惯性与输入识别交给宿主处理。
- **Scrollbar**（0–2 个）：水平或垂直自定义滚动条容器。
- **Thumb**（0–2 个）：`Scrollbar` 内的滑块交互区域，由宿主根据归一化状态计算几何位置并将拖拽动作交回滚动引擎处理。

`system`（系统滚动条）与 `composed`（自定义滚动条）共享同一套协议，默认策略由宿主与主题配置共同决定。

### 组合式末尾跟随（`endFollow`）

面向追加流场景（如日志或聊天记录），在自定义组合中通过 `asScrollSurface()` 可显式开启 `endFollow` 策略：配置 `{ mode: 'while-at-end', axis: 'vertical' }` 后，可读取各轴的 `atEnd`、`endFollow.state` 与 `endFollow.requestStatus`，并通过无障碍跳转按钮发送 `{ kind: 'to-end', axis: 'vertical' }` 回到末尾。

开启后，当用户停留在末尾时会自动跟随内容增长，离开末尾后暂停，高频追加会自动合并，自然回到底部或发送跳转请求后恢复跟随（不会移动焦点或干扰实时区域播报）。Base `Viewport` 默认关闭该策略，按需在自定义组合中启用即可。
