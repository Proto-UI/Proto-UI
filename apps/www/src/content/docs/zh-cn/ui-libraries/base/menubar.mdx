## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。

## 用法

由 `Root`、`Trigger`、`Content` 和 `Item` 组成：

- **面板配对**：状态由 `Root` 统一管理，`Root` 的 `value` 标识当前打开的面板，`Trigger` 与 `Content` 通过相同的 `value` 配对。
- **受控与非受控**：传入 `value` 进入受控模式（交互时发出变更请求，由外部决定是否更新）；使用 `defaultValue` 可设置非受控初始展开项。
- **键盘与焦点**：菜单栏采用单 Tab 入口，支持左右方向键在触发器之间切换、上下方向键进入面板，面板内支持纵向导航和首字母跳转。按 `Escape` 关闭面板并将焦点恢复到对应触发器；点击外部或选择命令项也会关闭面板。

传入 `value` 可受控管理当前打开的面板标识。

### 其他部件属性

- **Trigger**：`value`（默认 `''`）、`disabled`（默认 `false`）。
- **Content**：`value`（默认 `''`）、`a11yLabel`（默认 `''`）、`sideOffset`（默认 `4`）。
- **Item**：`value`（默认 `''`）、`textValue`（默认 `''`）、`disabled`（默认 `false`）、`closeOnSelect`（默认 `true`）。
