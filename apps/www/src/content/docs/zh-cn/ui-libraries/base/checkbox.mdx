## 结构

Checkbox 通过 anatomy 系统拆分为 root 和 indicator 两个部分。

- **Root** (`base-checkbox-root`) 拥有 `checked`、`checkedChange`、disabled 行为、`indeterminate` 状态和 `required` 事实。
- **Indicator** (`base-checkbox-indicator`) 通过 anatomy 运行时访问读取 root 的 `checked` 和 `indeterminate` 状态，并将这些状态反映给渲染层。它不独立拥有 checkbox 状态。

`base-checkbox` anatomy family 使用 root 到 indicator 的 `contains` 关系。Indicator 是可选部分；多个视觉区域可以通过各自的 indicator 读取同一份 root 状态。

在 Web Components 预览运行时中，prototype ID 会注册为带 `wc-` 前缀的标签：`wc-base-checkbox-root` 和 `wc-base-checkbox-indicator`。

## Indeterminate 行为

`indeterminate` 可以通过 `defaultIndeterminate` 作为非受控状态使用，也可以通过 `indeterminate` 作为受控状态使用。

当启用状态下的 indeterminate checkbox 被按下时：

1. 非受控 `checked` 在 `press.commit` 时切换；受控时则发出 `checkedChange`（`{ checked, indeterminate }`），由外部 owner 更新。
2. Root 通过 `indeterminateChange` 请求将 `indeterminate` 清为 `false`。
3. 如果 `indeterminate` 是非受控状态，root 会同时清除内部 indeterminate 状态。
4. 如果 `indeterminate` 是受控状态，外部 owner 需要处理 `indeterminateChange`，并重新传入 `indeterminate={false}`。

Disabled checkbox 在按下时不会改变 checked 或 indeterminate 状态。

## API

Checkbox 是工作区源码，没有公开的 `proto-ui add` 目标。传入 `checked` 或 `indeterminate` 会使对应事实进入受控模式。

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'defaultChecked', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'required', type: 'boolean', default: 'false' },
    { name: 'defaultIndeterminate', type: 'boolean', default: 'false' },
  ]}
/>

这些属性属于 Root。Indicator 没有属性。

Root 与 `asCheckboxRoot()` 暴露 `checked`、`indeterminate`、`disabled`、`required`、`hovered`、`focused`、`focusVisible`、`pressed`，以及 `checkedChange` 和 `indeterminateChange`。

`required` 属性初始化并更新同一个自有状态，可访问 required 也由该状态提供。它不改变 checked 值，也不阻止取消勾选。原生表单约束校验、提交和 Field 校验仍由显式组合负责；原子 Checkbox 不会自动创建 hidden input 或安装 Field 绑定。
