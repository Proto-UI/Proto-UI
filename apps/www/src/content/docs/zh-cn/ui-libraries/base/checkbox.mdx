## 用法

### 组合结构

Checkbox 由 `Root` 和可选的 `Indicator` 两部分组成：

- **Root**（`base-checkbox-root`）：统一管理 `checked`、`indeterminate`、`disabled`、`readOnly` 与 `required` 状态，并发出 `checkedChange` 和 `indeterminateChange` 事件。
- **Indicator**（`base-checkbox-indicator`）：自动读取所属 `Root` 的 `checked` 和 `indeterminate` 状态用于视觉呈现；一个 `Root` 下可放置多个 `Indicator`。

在 Web Components 预览运行时中，对应注册的标签为 `wc-base-checkbox-root` 与 `wc-base-checkbox-indicator`。

### 半选（Indeterminate）行为

`indeterminate` 支持非受控（`defaultIndeterminate`）或受控（`indeterminate`）两种方式：

- 当处于半选状态的复选框被激活时，`Root` 会先清除（或请求清除）`indeterminate` 并发出 `indeterminateChange`，随后再基于激活前的 `checked` 值请求取反并发出 `checkedChange`。
- 若调用方在处理 `indeterminateChange` 时已同步提交了新的 `checked` 值，则不会重复反转该值。
- `disabled` 或 `readOnly` 状态下会忽略所有变更请求。

### 只读与表单集成

- `readOnly` 允许控件继续保持可聚焦，但阻止修改勾选状态；`disabled` 同时移出焦点顺序。
- 单独使用的 `Root` 不会自动注册到表单。如需接入 `FormField` 的值管理、必填校验、标签/说明/错误关联与重置，请从 `@proto.ui/prototypes-base/field` 使用 `fieldCheckbox`（参见 [Form 选择控件示例](../form/)）。

## API

### Root Props

传入 `checked` 或 `indeterminate` 可分别控制对应状态。`Root` 与 `asCheckboxRoot()` 暴露 `checked`、`indeterminate`、`disabled`、`required`、`hovered`、`focused`、`focusVisible`、`pressed` 状态，以及 `checkedChange`、`indeterminateChange` 事件。
