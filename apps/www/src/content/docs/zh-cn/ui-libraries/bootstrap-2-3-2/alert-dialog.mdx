## 用法

由 `Root`、`Trigger`、`Mask`、`Content`、`Title`、`Description`、`Cancel` 和 `Action` 组成：

- **焦点与模态**：`Mask` 提供模态遮罩；`Content` 约束焦点在对话框内，不响应外部点击关闭，并在打开时优先聚焦 `Cancel`。
- **确认与关闭**：点击 `Action` 会先触发 `action` 事件，再请求关闭对话框，实际业务操作由应用监听事件执行；按 `Escape` 或点击 `Cancel` 直接请求关闭。
- **受控模式**：传入 `open` 进入受控模式，监听 `openChange` 后由父组件更新 `open`；非受控模式使用 `defaultOpen`。禁用状态下的按钮不会触发操作。

## API

| 部件                    | 属性 / 事件            | 说明                                          |
| ----------------------- | ---------------------- | --------------------------------------------- |
| `Root`                  | `open` / `defaultOpen` | 控制对话框的打开状态（受控或初始值）          |
| `Root`                  | `openChange`           | 打开或关闭请求事件                            |
| `Trigger`               | —                      | 触发打开对话框的按钮                          |
| `Mask`                  | —                      | 模态背景遮罩层                                |
| `Content`               | —                      | 对话框容器，承担焦点约束与 `alertdialog` 语义 |
| `Title` / `Description` | —                      | 对话框标题与辅助说明文本                      |
| `Cancel`                | —                      | 取消按钮，默认作为打开时的初始焦点目标        |
| `Action`                | `action`               | 确认按钮，触发 `action` 事件后请求关闭        |
