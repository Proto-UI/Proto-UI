## 用法

由 `Root`、`Trigger`、`Content` 和 `Item` 组成：

- **面板配对**：`Root` 的 `value` 表示当前打开的面板标识，与对应的 `Trigger.value` 和 `Content.value` 匹配；受控模式下仅发出变更请求，由父组件更新 `value`。
- **键盘导航**：整个菜单栏只占一个游走 Tab 焦点位；按左右方向键在菜单触发器间移动，按上下方向键进入菜单并浏览命令项，支持输入字符快速跳转。
- **关闭与焦点恢复**：按 `Escape` 关闭当前面板并将焦点交回对应 `Trigger`；点击外部区域或激活命令项时自动关闭面板。

## API

| 部件      | 属性    | 说明                              |
| --------- | ------- | --------------------------------- |
| `Root`    | `value` | 当前展开的菜单面板键（支持受控）  |
| `Trigger` | `value` | 菜单栏按钮，与同值 `Content` 配对 |
| `Content` | `value` | 对应的下拉命令面板                |
| `Item`    | —       | 面板内的可执行命令项              |
