Separator 使用归档分隔线的视觉语言，方向与装饰性语义由 Base 拥有。`orientation` 默认 `horizontal`，`decorative` 默认 `true`。

装饰性分隔线不暴露角色，并隐藏于无障碍树。设置 `decorative={false}` 后暴露 `separator` 角色及对应 `aria-orientation`。竖向外观是归档水平分隔线的设计语言适配。

该原型不渲染子内容且完全被动，没有焦点、tab stop、事件、激活或可变值。长度与间距由周围 composition 决定。通过页面运行时选择器比较 Web Components、React、Vue 3 与 Vue 2。

## API

- `orientation`：`horizontal` / `vertical`
- `decorative`：默认 `true`，语义分隔设置为 `false`
- 示例包含水平、竖向及语义分隔线
