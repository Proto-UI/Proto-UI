## 用法

- **装饰性与语义模式**：默认 `decorative={true}`，分隔线仅用于视觉区分并对无障碍树隐藏；当分隔线代表真实内容区块边界时，设置 `decorative={false}` 以暴露 `separator` 角色及对应的 `aria-orientation`。
- **尺寸与布局**：组件为纯被动元素，不占用焦点顺序，其长度与外边距由所在布局容器决定；竖向样式基于归档水平分隔线风格适配。

## API

| 属性 | 可选值 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `orientation` | `'horizontal'` \| `'vertical'` | `'horizontal'` | 分隔线方向 |
| `decorative` | `boolean` | `true` | 设为 `false` 时暴露语义 `separator` 角色与方向 |
