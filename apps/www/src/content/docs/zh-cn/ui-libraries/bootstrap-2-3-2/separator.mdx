Bootstrap 2.3.2 Separator 使用适配明暗主题家族边框色的单像素分隔线，由 Base Separator 统一管理水平/垂直方向与装饰性无障碍语义。这是基于归档分隔线语法与家族调色板的简化扩展。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可从 `@proto.ui/prototypes-bootstrap-2-3-2/separator` 导入 `separatorRoot`。[查看已实现的子集](../)。

```ts
import { separatorRoot } from '@proto.ui/prototypes-bootstrap-2-3-2/separator';
```

## 用法

```tsx
import { BootstrapSeparatorRoot } from '../proto-ui/components/react';
```

```tsx
<BootstrapSeparatorRoot />
```

- **家族边框样式**：水平方向高 `1px`，垂直方向宽 `1px` 并沿弹性容器交叉轴自动拉伸（`self-stretch`），两种方向均使用家族边框色。
- **装饰性与语义模式**：默认 `decorative={true}` 对辅助技术隐藏；当分隔线代表真实内容区块边界时，设置 `decorative={false}` 暴露 `role="separator"` 与 `aria-orientation`。
- **尺寸与布局**：组件无子内容且不占用焦点顺序，不内置外边距，长度与间距由外层容器控制。

## API

以下属性属于 `Root`：

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值', description: '说明' }}
  rows={[
    {
      name: 'orientation',
      type: "'horizontal' | 'vertical'",
      default: "'horizontal'",

    },
    {
      name: 'decorative',
      type: 'boolean',
      default: 'true',

    },
  ]}
