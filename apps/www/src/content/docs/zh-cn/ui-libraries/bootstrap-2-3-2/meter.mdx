Bootstrap 2.3.2 Meter 沿用经典的 20px 内阴影浅灰轨道与绿、琥珀、红三档线性渐变条，用于展示已知上下界范围内的标量测量值（如磁盘占用、配额或评分），并根据 `low`、`high` 和 `optimum` 自动分类状态。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `@proto.ui/prototypes-bootstrap-2-3-2/meter` 导入各部件原型：

```ts
import {
  meterRoot,
  meterLabel,
  meterTrack,
  meterIndicator,
  meterValue,
} from '@proto.ui/prototypes-bootstrap-2-3-2/meter';
```

## 用法

```tsx
import { AdaptToReact } from '@proto.ui/adapter-react';
import {
  meterRoot,
  meterLabel,
  meterTrack,
  meterIndicator,
  meterValue,
} from '@proto.ui/prototypes-bootstrap-2-3-2/meter';

const MeterRoot = AdaptToReact(meterRoot);
const MeterLabel = AdaptToReact(meterLabel);
const MeterTrack = AdaptToReact(meterTrack);
const MeterIndicator = AdaptToReact(meterIndicator);
const MeterValue = AdaptToReact(meterValue);

export function BootstrapStorageMeter() {
  return (
    <MeterRoot value={32} min={0} max={100} low={50} high={80} optimum={20} valueText="32%">
      <div className="flex items-center justify-between gap-2">
        <MeterLabel>Storage used</MeterLabel>
        <MeterValue />
      </div>
      <MeterTrack>
        <MeterIndicator />
      </MeterTrack>
    </MeterRoot>
  );
}
```

### 部件组成与状态区间

- **Root**：管理 `value` 与有限边界 `min`（默认 `0`）、`max`（默认 `100`），越界数值自动钳制在 `[min, max]`；当 `min === max` 时比例为 `0`。
- **Label / Value**：`Label` 提供无障碍名称，`Value` 使用 `tabular-nums` 等宽数字优先渲染 `valueText` 或规范数值。
- **Track / Indicator**：轨道保持 Bootstrap 2.3.2 经典的 `20px` 高度、`4px` 圆角与内凹阴影；指示条将 `optimal`、`suboptimal`、`critical` 分别映射为经典 `success`（绿色）、`warning`（琥珀色）与 `danger`（红色）渐变。
- Meter 为被动展示控件（`role="meter"`），不占用 Tab 焦点顺序，全部部件同步暴露只读状态。
