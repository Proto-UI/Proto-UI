Bootstrap 2.3.2 Meter 用于展示已知上下界范围内的标量测量值（如磁盘占用、配额或评分），并根据 `low`、`high` 和 `optimum` 自动区分正常、偏离与告警区间。

## 用法

由 `Root`、`Label`、`Track`、`Indicator` 和 `Value` 组成：

- **数值与区间**：`Root` 管理 `value` 以及 `min`（默认 `0`）、`max`（默认 `100`），越界数值会自动钳制到 `[min, max]`；当 `min === max` 时比例为 `0`。
- **区间状态分类**：配置 `low`、`high` 与 `optimum` 后，组件自动将当前值归类为 `'optimal'`、`'suboptimal'` 或 `'critical'`（不会修改数值本身）。
- **只读展示**：`Label` 提供无障碍名称，`Track` 与 `Indicator` 渲染比例条，`Value` 优先显示 `valueText` 或规范化后的数值。作为被动展示控件，不占用 Tab 焦点顺序。

## API

| 部件 | 属性 / 状态 | 说明 |
| --- | --- | --- |
| `Root` | `value` / `min` / `max` | 测量值与上下界（默认 `min=0`、`max=100`） |
| `Root` | `low` / `high` / `optimum` | 将当前值划分为 `optimal`、`suboptimal` 或 `critical` |
| `Root` | `ariaLabel` / `valueText` | 可访问名称与自定义格式化显示文本 |
| 全部部件 | `value` / `percentage` / `indeterminate` / `status` | 同步暴露的只读测量状态 |
| `Label` / `Track` / `Indicator` / `Value` | — | 名称、轨道、填充指示条与数值展示部件 |
