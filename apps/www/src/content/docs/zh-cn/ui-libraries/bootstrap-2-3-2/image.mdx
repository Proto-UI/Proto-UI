Bootstrap 2.3.2 Image 保留归档版本的 `.img-rounded`、`.img-polaroid` 与 `.img-circle` 视觉修饰，同时通过 Base Image 协议统一管理资源地址、填充模式、无障碍语义与实时加载状态。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可直接从 `@proto.ui/prototypes-bootstrap-2-3-2/image` 导入 `imageRoot`（别名 `bootstrap232ImageRoot`）与 `Bootstrap232ImageRootProps`。

## 用法

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { bootstrap232ImageRoot } from '@proto.ui/prototypes-bootstrap-2-3-2/image';

const BootstrapImage = createReactAdapter(React)(bootstrap232ImageRoot);

export function FramedPortrait() {
  return (
    <BootstrapImage
      source="/images/base-image/portrait.svg"
      a11yMode="informative"
      alternativeText="经典拍立得边框人像插图"
      fit="cover"
      appearance="polaroid"
      surfaceStyle={{ width: '160px', height: '160px' }}
    />
  );
}
```

- **外观变体（`appearance`）**：
  - `default`：响应式无边框图像（`max-w-full h-auto align-middle border-0`）。
  - `rounded`：经典 `6px` 圆角（`.img-rounded`）。
  - `polaroid`：`4px` 白色内边距、`1px rgba(0, 0, 0, 0.2)` 外框与柔和投影（`.img-polaroid`）。
  - `circle`：历史版本 `500px` 圆角（`.img-circle`），建议配合 1:1 正方形尺寸呈现正圆效果。
- **无障碍与加载状态**：`a11yMode`、`alternativeText`、`fit`、`loadingStatus` 与 `loadingStatusChange` 均继承自 [Base Image](/zh-cn/ui-libraries/base/image/)。
