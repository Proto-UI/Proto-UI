## 用法

- **尺寸与滚动**：上下方向的 `Content` 默认按内容高度展示，并自动受视口安全高度约束，超出时由面板内部 `overflow-y-auto` 滚动；左右方向默认限制在 `20rem` 宽度内。
- **自定义范围**：可通过 `Content` 的 `minExtent` 与 `maxExtent` 传入中立长度对象（`unit` 支持 `'logical'`、`'root-text'`、`'available'` 或 `'available-minus-root-text'`，`value` 为非负有限数值）；若最小高度超过安全上限，则自动钳制到安全上限。非法尺寸输入会保持上次有效配置并将 `extentValid` 置为 `false`。
- **吸附档位（`snapPoints`）**：未设置或传入空数组时采用内容自适应模式（此时 `Handle` 仅为指针拖拽把手）。传入 `(0, 1]` 范围内的比例数组后自动排序去重并启用显式吸附模式，`Handle` 同时支持方向键与 `Home` / `End` 调整档位。
- **关闭与受控状态**：传入 `open` 进入受控模式，若父组件拒绝关闭请求，拖拽松手后会自动弹回当前状态。设置 `dragDismissible={false}` 可禁用下滑拖拽关闭，同时保留关闭按钮、`Escape` 和遮罩点击关闭。

## API

| 部件 | 属性 / 事件 / 状态 | 说明 |
| --- | --- | --- |
| `Root` | `open` / `defaultOpen` | 受控或初始打开状态 |
| `Root` | `snapPoints` | `(0, 1]` 比例数组，启用显式吸附档位 |
| `Root` | `snapPoint` / `defaultSnapPoint` / `snapPointChange` | 受控或初始吸附档位及变更事件 |
| `Content` | `minExtent` / `maxExtent` | 上下抽屉的最小/最大尺寸限制对象 |
| `Content` | `dragDismissible` | 默认 `true`；设为 `false` 禁止拖拽关闭 |
| `Content` | `extentValid` | 指示当前尺寸配置是否合法 |
| `Handle` | — | 拖拽把手；显式吸附模式下提供无障碍 `separator` 语义与键盘调节 |
