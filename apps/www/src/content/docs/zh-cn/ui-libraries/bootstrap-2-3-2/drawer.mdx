Bootstrap 2.3.2 Drawer 复用经典 6px 圆角模态框视觉语法（页眉分割线、灰底右对齐页脚与渐变按钮），支持从视口上、下、左、右四个边缘滑出、内部滚动以及拖拽吸附档位。

## 用法

```tsx
import {
  BootstrapDrawerRoot,
  BootstrapDrawerTrigger,
  BootstrapDrawerMask,
  BootstrapDrawerContent,
  BootstrapDrawerHandle,
  BootstrapDrawerHeader,
  BootstrapDrawerTitle,
  BootstrapDrawerDescription,
  BootstrapDrawerFooter,
  BootstrapDrawerClose,
} from '../proto-ui/components/react';
```

```tsx
<BootstrapDrawerRoot>
  <BootstrapDrawerTrigger>Open Drawer</BootstrapDrawerTrigger>
  <BootstrapDrawerMask />
  <BootstrapDrawerContent side="bottom">
    <BootstrapDrawerHandle />
    <BootstrapDrawerHeader>
      <BootstrapDrawerTitle>Workspace Preferences</BootstrapDrawerTitle>
      <BootstrapDrawerDescription>
        Review default notification and digest rules for this project.
      </BootstrapDrawerDescription>
    </BootstrapDrawerHeader>
    <div className="p-[15px]">{/* Body content */}</div>
    <BootstrapDrawerFooter>
      <BootstrapDrawerClose>Close</BootstrapDrawerClose>
    </BootstrapDrawerFooter>
  </BootstrapDrawerContent>
</BootstrapDrawerRoot>
```

### 部件结构

```text
DrawerRoot
├── DrawerTrigger
├── DrawerMask
└── DrawerContent
    ├── DrawerHandle
    ├── DrawerHeader
    │   ├── DrawerTitle
    │   └── DrawerDescription
    └── DrawerFooter
        └── DrawerClose
```

- **尺寸与滚动**：上下方向的 `Content` 默认按内容高度展示并受视口安全区域约束；左右方向默认宽度上限为 `20` 个 `root-text` 单位。将长正文放入 `flex-1 overflow-y-auto` 容器，可保持经典 `Header` 与 `Footer` 固定在上下两端。
- **自定义范围与吸附**：在 `Content` 上配置 `minExtent` / `maxExtent`（单位支持 `'logical'`、`'root-text'`、`'available'`、`'available-minus-root-text'`）以及 `(0, 1]` 比例数组 `snapPoints`，`Handle` 会自动在显式吸附模式下提供 `separator` 语义与方向键、`Home` / `End` 调节。
- **关闭与动效**：`Content` 内置 300ms 滑入过渡，`Mask` 内置 150ms 淡入淡出，并自动响应系统的减少动态效果偏好。

## API

### Root

传入 `open` 进入受控模式，通过 `openChange` 监听状态变更请求；同时暴露 `openDrawer()`、`close()` 与 `toggle()` 方法。

    { name: 'disabled', type: 'boolean', default: 'false' },

/>

### Content

暴露 `open`、`snapPoint`、`dragging`、`dragProgress`、`offsetPercentage`、`extentValid`、`requestSnapPoint()` 及 `snapPointChange` 事件。
