Bootstrap 2.3.2 Autocomplete 将经典 30px 表单输入与 `.typeahead` 下拉建议面板结合，保留标志性的蓝色聚焦外光晕、渐变按钮反馈与列表高亮，同时共享完整的 Base 自动补全与自由文本提交语义。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供（`@proto.ui/prototypes-bootstrap-2-3-2/autocomplete`）。

## 用法

```html
<proto-ui-bootstrap-2-3-2-autocomplete-root a11y-label="Framework">
  <proto-ui-bootstrap-2-3-2-autocomplete-input
    placeholder="Search frameworks…"
  ></proto-ui-bootstrap-2-3-2-autocomplete-input>
  <proto-ui-bootstrap-2-3-2-autocomplete-trigger
    >Options</proto-ui-bootstrap-2-3-2-autocomplete-trigger
  >
  <proto-ui-bootstrap-2-3-2-autocomplete-content>
    <proto-ui-bootstrap-2-3-2-autocomplete-item
      value="next"
      text-value="Next.js"
      keywords="react ssr"
    >
      Next.js
    </proto-ui-bootstrap-2-3-2-autocomplete-item>
    <proto-ui-bootstrap-2-3-2-autocomplete-item
      value="astro"
      text-value="Astro"
      keywords="islands static"
    >
      Astro
    </proto-ui-bootstrap-2-3-2-autocomplete-item>
    <proto-ui-bootstrap-2-3-2-autocomplete-empty
      >No matching frameworks.</proto-ui-bootstrap-2-3-2-autocomplete-empty
    >
  </proto-ui-bootstrap-2-3-2-autocomplete-content>
</proto-ui-bootstrap-2-3-2-autocomplete-root>
```

### 部件与交互说明

- **部件组成**：由 `Root`、`Input`、`Trigger`、`Content`、`Item` 与 `Empty` 组成。
- **值与查询分离**：`value` 表示已提交文本，`inputValue` 表示当前输入查询；选择建议提交 `textValue`，无高亮项时按 `Enter` 提交自由文本。
- **过滤、键盘与输入法**：内置过滤匹配 `textValue` 与 `keywords` 并忽略大小写及重音；方向键导航期间焦点保持在 `Input` 内，IME 组合输入不会误触选择。
