Autocomplete 为单行输入框提供实时建议列表，既可以选择候选条目，也允许在无匹配项时按 `Enter` 直接提交自由文本。

## 用法

由 `Root`、`Input`、`Trigger`、`Content`、`Item` 和 `Empty` 组成：

- **值与查询分离**：`Root` 的 `value` 表示已提交文本，`inputValue` 表示当前输入的查询内容。选择建议项会提交其 `textValue`；无高亮建议时按 `Enter` 可直接提交自由文本。
- **过滤与空状态**：内置过滤同时匹配 `textValue` 和 `keywords`，忽略大小写与重音符号。如需由外部自行过滤，设置 `filter={false}`。`Empty` 在无匹配项时自动显示。
- **键盘与输入法**：使用方向键浏览建议时焦点始终保持在输入框内；中文等 IME 组合输入期间不会误触发选择。禁用项及重复值选项不可提交。
- **独立受控**：`open`、`value` 和 `inputValue` 均支持独立受控，并通过对应的变更事件通知父组件。

## API

| 部件 | 属性 | 说明 |
| --- | --- | --- |
| `Root` | `value` / `inputValue` / `open` | 分别控制已提交文本、查询文本与下拉展开状态 |
| `Root` | `filter` | 是否启用内置过滤；设为 `false` 时由调用方提供已过滤列表 |
| `Input` | — | 单行文本输入控件，保持键盘焦点 |
| `Trigger` | — | 切换建议列表展开状态的按钮 |
| `Content` | — | 建议列表容器 |
| `Item` | `value` / `textValue` / `keywords` / `disabled` | 单个候选项；重复值与禁用项不可提交 |
| `Empty` | — | 无匹配建议时的提示区域 |
