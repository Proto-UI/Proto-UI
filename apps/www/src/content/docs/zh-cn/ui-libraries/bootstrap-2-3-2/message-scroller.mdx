Message Scroller 面向聊天和实时日志流场景：当用户停留在列表底部时自动跟随新消息滚动，向上回看历史时暂停跟随，并提供“Jump to latest”操作显式回到最新内容。

## 用法

- **自动跟随与回底**：仅当视口位于末端时自动跟随追加内容；用户主动滚动离开底部后保持当前位置，点击“Jump to latest”即可平滑回底并恢复跟随，且不会抢夺当前键盘焦点。
- **新消息计数**：未读或新增条目数通过 `newContentCount` 由应用显式传入，组件不自行推断业务未读状态。
- **无障碍命名**：通过 `Root` 的 `a11yLabel` 为滚动区域命名，默认为 `'Messages'`。

## API

| 部件   | 属性              | 默认值       | 说明                         |
| ------ | ----------------- | ------------ | ---------------------------- |
| `Root` | `a11yLabel`       | `'Messages'` | 滚动区域的可访问名称         |
| `Root` | `newContentCount` | —            | 由应用提供的新增消息数量提示 |
