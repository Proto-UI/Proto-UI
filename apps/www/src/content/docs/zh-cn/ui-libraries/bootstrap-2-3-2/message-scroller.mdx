Message Scroller 面向聊天记录与实时活动日志场景，以经典 Bootstrap 2.3.2 的 4px 圆角边框面板、内阴影和渐变斜角按钮承载消息流：停留在底部时自动跟随新消息，向上回看历史时保持位置，并通过浮动回底按钮随时返回最新条目。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可直接从 `@proto.ui/prototypes-bootstrap-2-3-2/message-scroller` 导入原型并使用对应适配器封装。

```ts
import {
  messageScrollerRoot,
  messageScrollerViewport,
  messageScrollerJump,
} from '@proto.ui/prototypes-bootstrap-2-3-2/message-scroller';
```

## 用法

为外层容器设置固定高度，`Root` 提供 Bootstrap 2.3.2 边框面板，`Viewport` 承担纵向滚动，`Jump` 复用经典按钮视觉并浮动于底部右下角：

```tsx
<div className="h-72 w-full max-w-lg">
  <Bootstrap232MessageScrollerRoot a11yLabel="Release room messages">
    <Bootstrap232MessageScrollerViewport>
      <div className="flex flex-col pb-12">
        {messages.map((message) => (
          <div key={message.id}>{message.text}</div>
        ))}
      </div>
    </Bootstrap232MessageScrollerViewport>
    <Bootstrap232MessageScrollerJump>Jump to latest ↓</Bootstrap232MessageScrollerJump>
  </Bootstrap232MessageScrollerRoot>
</div>
```

### 行为说明

- **贴底自动跟随**：仅当视口已经位于底部时自动跟随追加条目；读者主动向上滚动后保持原位。
- **不抢占焦点**：点击回底按钮会滚动到末尾并恢复跟随，同时保留当前键盘焦点。
- **应用层计数与命名**：通过 `newContentCount` 显式传入新增消息数量，通过 `a11yLabel` 为滚动区域命名（默认为 `'Messages'`）。

## 示例

### 实时日志流

点击 **Append message** 追加新日志；先向上回看历史再追加即可观察阅读位置保持与未读计数变化。
