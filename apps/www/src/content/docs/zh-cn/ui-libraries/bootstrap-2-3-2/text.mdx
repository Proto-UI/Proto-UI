Bootstrap 2.3.2 Text 基于 [Base Text](/zh-cn/ui-libraries/base/text/) 提供全部八项独立排版属性，使用经典的 Helvetica Neue / Arial 正文与 Monaco / Menlo 等宽字体栈，并保留归档版本的 `2xl` 标题刻度与 `20/14` 正文行高比例。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `@proto.ui/prototypes-bootstrap-2-3-2/text` 导入 `textRoot`（也导出 `bootstrap232TextRoot` 与 `Bootstrap232TextRoot` 别名），或在工作区模式下通过 CLI 目标 `bootstrap-2-3-2-text` 生成四框架封装。

## 用法

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { bootstrap232TextRoot } from '@proto.ui/prototypes-bootstrap-2-3-2/text';

const Text = createReactAdapter(React)(bootstrap232TextRoot, { rootTag: 'span' });

export function PageHeading() {
  return (
    <h2>
      <Text size="2xl" font="heading" weight="bold" leading="relaxed">
        Overview
      </Text>
    </h2>
  );
}
```

### Bootstrap 2.3.2 排版指标与语义边界

- **归档刻度保留**：`size="2xl"` 对应 `1.53125rem`（16px 根字号下为 `24.5px`）；`leading="normal"` 采用经典的 `20/14`（约 `1.4286`）正文行高比例；同时设置 `size="2xl"` 与 `leading="relaxed"` 时对应 `2.5rem`（`40px`）经典标题行高。所有尺寸均以 `rem` 缩放。
- **行高覆盖与默认恢复**：显式传入 `leading`（除 `size` 外）会覆盖 `size` 的默认行高；`leading="size"` 保留所选字号自带行高，`leading="tighter"` 为 `1.1`，`tracking="tighter"` 为 `-0.05em`。移除任意属性即可恢复默认值。
- **前景色继承与文本选择**：在深色或彩色 `Surface` 内使用 `tone="inherit"` 可沿用外层前景色与文字阴影；Text 不强制改写 `user-select`，正文保持自然可选，控件标签遵循所属控件的选择策略。
- **原生语义**：标题（`h1`–`h6`）、段落（`p`）、表单标签（`label`）与链接（`a`）仍由外层原生元素负责。
