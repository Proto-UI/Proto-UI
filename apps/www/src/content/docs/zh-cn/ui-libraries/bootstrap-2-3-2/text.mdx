
## 用法

- **排版组合**：显式传入 `leading` 时会覆盖 `size` 的默认行高；移除属性即可恢复默认值。
- **颜色继承与文本选择**：在深色或彩色容器（如 `Surface`）内使用时，设置 `tone="inherit"` 即可跟随外层前景色。Text 不强制修改 `user-select`，文档正文保持自然可选中，控件内的标签则遵循对应控件的选择策略。
- **语义元素**：Text 仅负责排版样式，标题、段落、链接和按钮语义仍由原生 `h1`、`p`、`a`、`button` 等元素承担。

## API

| 属性 | 可选值 | 默认值 |
| --- | --- | --- |
| `size` | `xs` \| `sm` \| `base` \| `lg` \| `xl` \| `2xl` \| `3xl` \| `4xl` \| `5xl` | `base` |
| `tone` | `default` \| `muted` \| `inherit` | `default` |
| `weight` | `normal` \| `medium` \| `semibold` \| `bold` | `normal` |
| `font` | `body` \| `heading` \| `mono` | `body` |
| `leading` | `tight` \| `snug` \| `normal` \| `relaxed` | `normal` |
| `tracking` | `normal` \| `tight` | `normal` |
| `emphasis` | `normal` \| `italic` | `normal` |
| `decoration` | `none` \| `underline` \| `line-through` | `none` |
