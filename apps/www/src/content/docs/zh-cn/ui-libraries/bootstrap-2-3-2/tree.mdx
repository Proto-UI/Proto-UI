Tree 用于展示嵌套层级数据，采用 Bootstrap 2.3.2 经典的 `.well` / `.nav-list` 侧栏导航视觉与 `.btn-mini` 展开按钮，提供节点展开/收起、单选、双向文字方向以及完整的树视图键盘导航。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可直接从 `@proto.ui/prototypes-bootstrap-2-3-2/tree` 导入原型并使用目标框架适配器注册：

```ts
import {
  treeRoot,
  treeItem,
  treeGroup,
  treeToggle,
} from '@proto.ui/prototypes-bootstrap-2-3-2/tree';
```

## 用法

```tsx
<Bootstrap232TreeRoot defaultValue="button" defaultExpandedKeys={['src', 'components']}>
  <div className="flex items-center gap-1.5">
    <Bootstrap232TreeToggle nodeKey="src">▾</Bootstrap232TreeToggle>
    <Bootstrap232TreeItem nodeKey="src" textValue="src" className="flex-1">
      src/
    </Bootstrap232TreeItem>
  </div>
  <Bootstrap232TreeGroup nodeKey="src">
    <Bootstrap232TreeItem nodeKey="button" parentKey="src" textValue="button.tsx">
      button.tsx
    </Bootstrap232TreeItem>
  </Bootstrap232TreeGroup>
</Bootstrap232TreeRoot>
```

### 结构与交互语义

- **显式层级与分组**：每个 `Item` 使用树内唯一的 `nodeKey`，子节点通过 `parentKey` 指向父节点，并放入共享相同 `nodeKey` 的 `TreeGroup` 以自动维护 `aria-controls` / `aria-labelledby`。
- **经典视觉投影**：`Root` 采用 `.well` 内凹灰底与边框，`Item` 采用 `.nav-list` 的 `#08c` 链接色、`#eee` 悬停/聚焦底色及 `#08c` 选中高亮，`Toggle` 使用 `.btn-mini` 渐变立体按钮。
- **键盘导航与 RTL**：上下方向键、`Home` / `End` 与首字母输入移动焦点；设置 `direction="rtl"` 会自动镜像 `TreeGroup` 的 15px 缩进方向与左右方向键映射。
