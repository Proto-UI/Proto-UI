## 用法

- **显式层级结构**：每个节点通过树内唯一的 `nodeKey` 标识，并用 `parentKey` 指向父节点；若存在重复键、缺失父节点或循环引用，将忽略非法配置并保持当前状态。
- **键盘导航**：上下方向键、`Home` / `End` 与首字母输入移动焦点；右方向键展开折叠节点或移至首个子节点，左方向键收起展开节点或返回父节点。
- **受控状态**：`value`（当前选中节点）和 `expandedKeys`（展开节点集合）均支持受控模式，由父组件响应变更请求并更新。

## API

| 属性           | 说明                             |
| -------------- | -------------------------------- |
| `nodeKey`      | 节点在当前树中的唯一标识         |
| `parentKey`    | 指向父节点的 `nodeKey`           |
| `value`        | 当前选中节点键（支持受控）       |
| `expandedKeys` | 当前展开的节点键集合（支持受控） |
