## 用法

### 组合结构与日期格式

由 `Root`、`Caption`、`Heading`、`Previous`、`Next`、`Grid`、`Weekdays`、`Weekday`、`Row` 和 `Day` 组成：

- **日期格式**：日期值采用 `YYYY-MM-DD`，显示月份 `month` 采用 `YYYY-MM`，两者可分别受控。
- **周数与布局**：默认显示覆盖当月所需的 4–6 周；设置 `fixedWeeks={true}` 可固定显示 6 周。可在模板中固定放置 6 个 `Row`（`index` `0`–`5`）和 42 个 `Day`（`offset` `0`–`41`），多余行列会自动标记 `hidden` 并移出焦点顺序。
- **本地化与方向**：通过 `weekStartsOn`（`0` 表示周日）、`locale` 与 `direction="rtl"` 调整星期顺序、网格标签与方向键映射。纯图标导航按钮可通过 `a11yLabel` 提供可访问名称。
- **当前日期**：组件不读取系统时钟，由宿主通过 `today` 传入 `YYYY-MM-DD` 字符串标记“今天”（对应 `aria-current="date"`）。初始显示月份优先级为：`month` → `defaultMonth` → 当前模式选中日期 → `today` → `1970-01`。

### 范围与多选规则

- **多选（`multiple`）**：点击日期切换选中，结果自动去重并按日期升序排列。通过 `minSelected`（默认 `0`）和 `maxSelected` 限制数量；逐日增加时允许从空值逐步达到下限，取消选择时必须保留至少 `minSelected` 项。
- **范围（`range`）**：首次点击确定起点 `{ from }`，再次点击完成含两端点的 `{ from, to }`（反向选择自动排序）；完成后再点任意日期开启新范围，传入 `{}` 清空。`minNights`（默认 `0`，允许单日范围）与 `maxNights` 约束起止日期间的天数差。
- **日期限制**：使用 `min`、`max` 和 `Root` 的 `unavailable` 数组设置全局不可选日期（跨越不可用日期的范围会被拒绝并保留起点）；单个 `Day` 的 `disabled` 仅禁用该格。`readOnly` 允许浏览月份但禁止修改选择。
- **范围状态**：每个 `Day` 除 `selected` 外，还提供 `rangeStart`、`rangeEnd`、`rangeMiddle` 与 `rangePending` 状态，便于区分端点与中段样式。

### 组合月份/年份选择器

可使用 `bindCalendarCaption(source, { month, year })` 将两个 `Select` 与 `Calendar` 的 `month`、`disabled` 状态及 `requestMonth` 联动，并在卸载时调用 `dispose()` 清理订阅。月份/年份按钮可通过 `Select` 的 `accessibleLabel` 提供稳定名称。

## API

| 模式       | 受控 / 初始值属性                            | 变更事件                     |
| ---------- | -------------------------------------------- | ---------------------------- |
| `single`   | `value` / `defaultValue`（`YYYY-MM-DD`）     | `onValueChange({ value })`   |
| `multiple` | `values` / `defaultValues`（`string[]`）     | `onValuesChange({ values })` |
| `range`    | `range` / `defaultRange`（`{ from?, to? }`） | `onRangeChange({ range })`   |

- **常用 `Root` 属性**：`mode`、`month` / `defaultMonth`、`today`、`min`、`max`、`unavailable`、`minSelected`、`maxSelected`、`minNights`、`maxNights`、`fixedWeeks`、`weekStartsOn`、`locale`、`direction`、`disabled`、`readOnly`。
- **只读状态与方法**：`Root` 暴露 `mode`、`weekCount`、`selectedCount`、`rangeComplete`，以及 `requestMonth(month)`、`requestValue(date)`、`requestValues(dates)`、`requestRange(range)`、`getValues()`、`getRange()`。受控模式下，`request*` 返回 `true` 仅表示已发出变更请求，界面在父组件更新对应属性后生效。
