Bootstrap 2.3.2 Calendar 是支持 `single`（默认）、`multiple` 与 `range` 三种模式的公历控件，作为基于 Bootstrap 2.3.2 经典渐变按钮、面板边框与表格排版的家族扩展组件提供。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供；可在工作区中直接从 `@proto.ui/prototypes-bootstrap-2-3-2/calendar` 引入。

## 用法

```tsx
import {
  CalendarRoot,
  CalendarCaption,
  CalendarPrevious,
  CalendarHeading,
  CalendarNext,
  CalendarGrid,
  CalendarWeekdays,
  CalendarWeekday,
  CalendarRow,
  CalendarDay,
} from '@proto.ui/prototypes-bootstrap-2-3-2/calendar';

export function BootstrapCalendarExample() {
  return (
    <CalendarRoot mode="single" defaultMonth="2026-10" defaultValue="2026-10-12" today="2026-10-08">
      <CalendarCaption>
        <CalendarPrevious a11yLabel="Previous month" />
        <CalendarHeading />
        <CalendarNext a11yLabel="Next month" />
      </CalendarCaption>
      <CalendarGrid>
        <CalendarWeekdays>
          {Array.from({ length: 7 }, (_, offset) => (
            <CalendarWeekday key={offset} offset={offset} />
          ))}
        </CalendarWeekdays>
        {Array.from({ length: 6 }, (_, row) => (
          <CalendarRow key={row} index={row}>
            {Array.from({ length: 7 }, (_, col) => (
              <CalendarDay key={col} offset={row * 7 + col} />
            ))}
          </CalendarRow>
        ))}
      </CalendarGrid>
    </CalendarRoot>
  );
}
```

### 组合结构、时钟与年月选择

- Calendar 由十个部件组成：`Root`、`Caption`、`Heading`、`Previous`、`Next`、`Grid`、`Weekdays`、`Weekday`、`Row` 与 `Day`。
- 日期采用 `YYYY-MM-DD`，显示月份采用 `YYYY-MM`，两者可分别独立受控；默认渲染覆盖当月所需的 4–6 周，设置 `fixedWeeks={true}` 可固定显示 6 周。
- 组件不读取系统时钟：请由宿主传入 `YYYY-MM-DD` 格式的 `today` 字符串标记“今天”（对应 `aria-current="date"`）。
- `direction="rtl"` 自动镜像左右方向键；可通过 `bindCalendarCaption(source, { month, year })` 将两个同族 `Select` 与 Calendar 的 `month`、`disabled` 及 `requestMonth` 联动（退出时调用 `dispose()`）。

### 选择模式

| 模式       | 受控 / 初始值属性                                 | 变更事件                     |
| ---------- | ------------------------------------------------- | ---------------------------- |
| `single`   | `value` / `defaultValue`（`YYYY-MM-DD`）          | `onValueChange({ value })`   |
| `multiple` | `values` / `defaultValues`（`readonly string[]`） | `onValuesChange({ values })` |
| `range`    | `range` / `defaultRange`（`{ from?, to? }`）      | `onRangeChange({ range })`   |

### 事件、方法与暴露状态

- **事件（Root）**：`onValueChange({ value })`、`onValuesChange({ values })`、`onRangeChange({ range })`、`onMonthChange({ month })`。
- **方法（Root）**：`requestValue(date)`、`requestValues(dates)`、`requestRange(range)`、`requestMonth(month)`、`getValues()`、`getRange()`。
- **暴露状态**：Root 暴露 `value`、`mode`、`selectedCount`、`rangeComplete`、`month`、`weekCount`、`disabled`、`direction`；Day 暴露 `date`、`selected`、`rangeStart`、`rangeEnd`、`rangeMiddle`、`rangePending`、`today`、`outside`、`disabled`、`hidden`。
