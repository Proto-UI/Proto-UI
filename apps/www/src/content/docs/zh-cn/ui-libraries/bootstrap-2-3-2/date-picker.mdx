## 用法

- **弹层内容**：弹层内可自由组合 `Calendar` 的标题、月份切换与日期网格部件。`open`、选中值和 `month` 各自支持受控与非受控模式。
- **范围与多选**：传入 `mode="range"` 与 `range` / `defaultRange` 开启范围选择；传入 `mode="multiple"` 与 `values` / `defaultValues` 开启多选。日期禁用、数量与天数间隔规则与 [Calendar](/zh-cn/ui-libraries/bootstrap-2-3-2/calendar/) 完全一致。
- **自动关闭规则**：
  - 单选模式下，完成一次有效选择后请求关闭弹层。
  - 范围模式下，选择起点时保持打开，待第二个端点被接受并形成完整范围后请求关闭一次。
  - 多选模式下保持打开以便连续增减日期，可通过外部点击、按 `Escape` 或关闭按钮收起。
- **显示文本**：`Value` 会自动格式化为单个 ISO 日期、逗号分隔的有序日期列表、未完成范围 `from …` 或完整范围 `from – to`；未选择时显示 `placeholder`。

## API

| 属性                       | 说明                                          |
| -------------------------- | --------------------------------------------- |
| `mode`                     | `'single'`（默认）、`'range'` 或 `'multiple'` |
| `open` / `defaultOpen`     | 控制弹层展开状态                              |
| `value` / `defaultValue`   | 单选日期值（`YYYY-MM-DD`）                    |
| `range` / `defaultRange`   | 范围选择值（`{ from?, to? }`）                |
| `values` / `defaultValues` | 多选日期数组（`string[]`）                    |
| `month` / `defaultMonth`   | 当前显示的月份（`YYYY-MM`）                   |
| `placeholder`              | 未选中日期时 `Value` 显示的占位文本           |
| `disabled` / `readOnly`    | 禁用或只读控制                                |
