Bootstrap 2.3.2 Slider 沿用经典 20px 内凹渐变轨道、蓝色渐变进度条与凸起按钮滑块风格，支持单值与多值范围选择，并可无缝接入 `Field` 与 `Form`。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `@proto.ui/prototypes-bootstrap-2-3-2/slider` 导入单值滑块与多值滑块 `sliderValues*` 部件。

## 用法

```tsx
import {
  Bootstrap232SliderRoot,
  Bootstrap232SliderTrack,
  Bootstrap232SliderIndicator,
  Bootstrap232SliderThumb,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <Bootstrap232SliderRoot defaultValue={33} min={0} max={100} step={1}>
      <Bootstrap232SliderTrack>
        <Bootstrap232SliderIndicator />
        <Bootstrap232SliderThumb />
      </Bootstrap232SliderTrack>
    </Bootstrap232SliderRoot>
  );
}
```

- **部件组成**：单值滑块由 `Root`、`Label`、`Track`、`Indicator`、`Thumb`（表单内替换为 `FieldThumb`）和 `Value` 组成；多值范围使用 `sliderValues*` 入口。
- **拖动与键盘**：在 `Track` 上支持鼠标与触摸拖动；聚焦 `Thumb` 后支持方向键、`Shift`（10 倍步长）、`PageUp` / `PageDown` 与 `Home` / `End`（水平 RTL 自动反转）。
- **受控与表单**：受控模式下发出 `valueChange` 提议并在完成时触发 `valueCommit`；`FieldThumb` 与 `Values Root` 自动联动 `FieldLabel`、校验与重置。
