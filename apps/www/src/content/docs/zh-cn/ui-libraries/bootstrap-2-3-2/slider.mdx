Bootstrap 2.3.2 Slider 用于在连续或离散数值区间内通过拖动或键盘选择单个数值，并支持无缝接入 `Field` 与 `Form`。

## 用法

由 `Root`、`Label`、`Track`、`Indicator`、`Thumb`（在 `Field` / `FormField` 内替换为 `FieldThumb`）和 `Value` 组成：

- **拖动与键盘**：在 `Track` 上支持鼠标与触摸拖动；聚焦 `Thumb` 后可使用方向键、`Shift`（10 倍步长）、`PageUp` / `PageDown` 以及 `Home` / `End` 调整数值，水平 `direction="rtl"` 自动反转左右方向键。数值从 `min` 起按 `step` 对齐并限制在 `[min, max]` 内。
- **实时变更与提交**：受控模式下拖动发出 `valueChange` 请求但不直接覆盖外部值；操作完成时触发 `valueCommit`，取消拖动则恢复非受控拖动前的起值。
- **表单集成**：在 `Field` / `FormField` 内使用 `FieldThumb` 替换 `Thumb`，即可联动 `FieldLabel` 激活、数值校验、`Form` 序列化与重置。

## API

| 部件 | 属性 / 事件 | 说明 |
| --- | --- | --- |
| `Root` | `value` / `defaultValue` | 受控或初始滑块数值 |
| `Root` | `min` / `max` / `step` | 数值上下界与步长 |
| `Root` | `disabled` / `readOnly` / `orientation` / `direction` | 交互状态、方向与书写方向 |
| `Root` | `valueChange` / `valueCommit` | 拖动过程请求事件与操作完成事件 |
| `Label` / `Track` / `Indicator` / `Thumb` / `FieldThumb` / `Value` | — | 名称、轨道、进度指示、滑块手柄（表单内用 `FieldThumb`）与数值显示 |
