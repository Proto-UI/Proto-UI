Bootstrap 2.3.2 Radio Group 以归档 Bootstrap 2.3.2 的内凹浅灰选框、经典蓝渐变选中圆点与柔和蓝光焦点反馈呈现单选交互，同时由 Base Radio Group 统一提供 `radiogroup` / `radio` 无障碍语义、方向键漫游焦点与受控状态管理。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。

<InstallCommandCard
  command="npx @proto.ui/cli@latest add wc bootstrap-2-3-2-radio-group"
  manager="npm"
/>

将命令中的 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的组件代码，或从 `@proto.ui/prototypes-bootstrap-2-3-2/radio-group` 导入原型。

## 用法

```tsx
import {
  BootstrapLabelRoot,
  BootstrapRadioGroupIndicator,
  BootstrapRadioGroupItem,
  BootstrapRadioGroupRoot,
} from '../proto-ui/components/react';

export function RadioGroupUsage() {
  return (
    <BootstrapRadioGroupRoot defaultValue="comfortable" a11yLabel="Display density">
      <div className="flex items-center gap-2">
        <BootstrapRadioGroupItem value="default">
          <BootstrapRadioGroupIndicator />
        </BootstrapRadioGroupItem>
        <BootstrapLabelRoot>Default</BootstrapLabelRoot>
      </div>
      <div className="flex items-center gap-2">
        <BootstrapRadioGroupItem value="comfortable">
          <BootstrapRadioGroupIndicator />
        </BootstrapRadioGroupItem>
        <BootstrapLabelRoot>Comfortable</BootstrapLabelRoot>
      </div>
      <div className="flex items-center gap-2">
        <BootstrapRadioGroupItem value="compact">
          <BootstrapRadioGroupIndicator />
        </BootstrapRadioGroupItem>
        <BootstrapLabelRoot>Compact</BootstrapLabelRoot>
      </div>
    </BootstrapRadioGroupRoot>
  );
}
```

### 样式与无障碍

- 未选中项呈现经典浅灰内阴影凹槽（`#f5f5f5` → `#f9f9f9`），选中后切换为 Bootstrap 2.3.2 `#0088cc` → `#0077b3` 渐变与 6px 白色中心圆点。
- 键盘聚焦时显示 `rgba(82, 168, 236, 0.6)` 柔和蓝光阴影，并保留高对比度模式下的强制轮廓。
- 方向键在启用项之间循环移动并选中，`Home` / `End` 跳至首尾启用项，`Space` 选中当前聚焦项。

### Indicator、事件与方法

- **Indicator**：无额外属性，自动根据所属 `Item` 的选中与禁用状态更新视觉呈现。
- **事件**：Root 触发 `valueChange`（`{ value: string }`）；Item 触发 `select`（`{ value: string }`）。
- **方法**：Root 暴露 `requestValue(value)`、`resetValue()`、`focusFirst()`、`focusLast()`、`focusNext()`、`focusPrev()`、`focusSelected()`、`focusSelf()`。
