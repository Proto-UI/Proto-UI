Bootstrap 2.3.2 Field 将标签、输入控件、帮助说明、错误提示与校验状态整合为一个字段单元，保留经典的 4px 圆角、内阴影、蓝色聚焦光晕与静音辅助说明字色，并支持垂直与水平表单排列。

## 安装

当前仅在源码工作区提供，可从 `@proto.ui/prototypes-bootstrap-2-3-2/field` 导入核心部件与已绑定控件：

```ts
import {
  fieldRoot,
  fieldLabel,
  fieldControl,
  fieldDescription,
  fieldError,
  fieldValidity,
  fieldTextarea,
  fieldSelectTrigger,
  fieldSwitch,
} from '@proto.ui/prototypes-bootstrap-2-3-2/field';
```

## 用法

```tsx
import {
  FieldRoot,
  FieldLabel,
  FieldControl,
  FieldDescription,
  FieldError,
} from '@proto.ui/prototypes-bootstrap-2-3-2/field';

export function AccountField() {
  return (
    <FieldRoot required minLength={3}>
      <FieldLabel>Username</FieldLabel>
      <FieldControl placeholder="Max Leiter" />
      <FieldDescription>Choose a unique username for your account.</FieldDescription>
      <FieldError />
    </FieldRoot>
  );
}
```

### 组合与校验说明

- **自动无障碍关联**：`Label`、`Description` 与 `Error` 自动通过 `aria-labelledby`、`aria-describedby` 与（仅在无效时）`aria-errormessage` 关联到控件，卸载时自动清理。
- **已绑定控件**：除默认单行文本 `Control` 外，可直接组合 `fieldTextarea`、`fieldSelectTrigger` 与 `fieldSwitch`，或通过 Base 的 `asFieldControl` 桥接自定义值控件。
- **内置与异步校验**：支持 `required`、`minLength`、`maxLength`（按 UTF-16 码元计数）、`validationMode`（`'onBlur'` / `'onChange'` / `'manual'`）、受控 `invalid` 与 `externalValidation`。如需整组禁用或整表提交，请配合 [Fieldset](../fieldset/) 或 [Form](../form/) 使用。

### Control 与其他部件

- **Control**：`value` / `defaultValue`、`disabled`、`readOnly`、`required`、`placeholder`、`name`、`autoComplete`、`inputMode`、`enterKeyHint`、`ariaLabel`。
- **已绑定控件**：`fieldTextarea`、`fieldSelectTrigger`、`fieldSwitch`。
- **Label**：`activation?: boolean`（默认 `true`）。
- **Error**：`message?: string`、`keepMounted?: boolean`（默认 `false`）。
- **方法与事件（Root）**：`validate(reason?)`、`resolveValidation(requestId, result)`、`cancelValidation()`、`resetValidation()`、`focusControl(options?)`、`getValidity()`；事件 `validityChange`、`validationRequest`。
