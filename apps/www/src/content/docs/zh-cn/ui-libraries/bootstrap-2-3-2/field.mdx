Bootstrap 2.3.2 Field 将标签、输入控件、帮助说明、错误提示与校验状态整合为一个字段单元，采用归档 Bootstrap 2.3.2 的紧凑间距、4px 圆角、内阴影及清晰的焦点环样式。

## 用法

### 组合结构

每个 `Root` 内放置一个 `Control`，并可按需搭配一个 `Label`、一个 `Description`、一个 `Error` 以及任意个只读 `Validity`：

- **自动无障碍关联**：`Label`、`Description` 与 `Error` 会自动通过 `aria-labelledby`、`aria-describedby` 与 `aria-errormessage` 关联到控件，并在卸载时自动清理，无需手写 DOM ID。`aria-errormessage` 仅在校验无效时生效。
- **自定义控件接入**：默认 `Control` 为单行文本输入；如需接入其他值控件（如自定义选择器或数字输入），可使用 Base 导出的 `asFieldControl` 或 `asFieldTextControl` 进行桥接。
- **状态归属**：`Root` 管理 `invalid`、`pending`、`dirty`、`touched`、`filled`、`focused` 等字段状态；`Control` 管理当前值与编辑器本身。重复放置唯一部件时将忽略非法配置并保持当前状态。

### 校验与异步检查

- **内置校验**：支持 `required`、`minLength` 与 `maxLength`（按 UTF-16 字符单元计数，可选空字符串自动跳过长度校验）。`required` 将 `null`、`false`、空字符串和空数组视为空，`0` 与空白字符视为已填写且不自动 trim。内置错误标记为 `valueMissing`、`tooShort` 和 `tooLong`。
- **校验时机**：通过 `validationMode` 选择 `'onBlur'`（默认）、`'onChange'`（会等待 IME 组合输入结束）或 `'manual'`。
- **受控校验**：传入 `invalid` 进入受控模式，校验完成后发出 `validityChange` 事件，界面在父组件更新 `invalid` 后生效。
- **异步外部校验**：开启 `externalValidation={true}` 后，内置校验通过会触发 `validationRequest`（载荷为 `{ requestId, value, reason }`）；应用执行异步检查后调用 `resolveValidation(requestId, { invalid, errors })` 提交结果。值变更、新请求、禁用或重置都会自动作废过期的异步请求。
- **错误展示**：`Error` 优先展示显式 `message`，其次为 `errors` 列表，最后回退到内置英文提示（建议传入本地化文案）。关闭时默认卸载节点，设置 `keepMounted` 可保留隐藏节点。如需自动朗读错误，可结合 `LiveRegion` 使用。

> 如需整组禁用或整表提交/重置，请配合 `Fieldset` 或 `Form` 使用。

## API

| 部件 | 属性 | 说明与默认值 |
| --- | --- | --- |
| `Root` | `invalid` / `errors` | 传入 `invalid` 即为受控校验模式；`errors` 为错误文案数组 |
| `Root` | `defaultInvalid` / `defaultErrors` | 非受控模式的初始校验状态与错误文案 |
| `Root` | `disabled` / `readOnly` / `required` | 默认 `false`，与 `Control` 本地策略叠加 |
| `Root` | `minLength` / `maxLength` | 默认 `-1`（不限制），按 UTF-16 字符单元计数 |
| `Root` | `validationMode` | `'onBlur'`（默认）、`'onChange'` 或 `'manual'` |
| `Root` | `externalValidation` | 默认 `false`；设为 `true` 在内置校验通过后触发异步请求 |
| `Control` | `value` / `defaultValue` | 受控或非受控文本值（初始化时固定模式） |
| `Control` | `disabled` / `readOnly` / `required` | 本地策略，不能解除 `Root` 已启用的限制 |
| `Control` | `placeholder` / `name` / `autoComplete` / `inputMode` / `enterKeyHint` / `ariaLabel` | 文本输入提示与命名属性 |
| `Label` | `activation` | 默认 `true`；点击标签自动聚焦关联控件 |
| `Description` | — | 可选的帮助说明文本，支持用户选中复制 |
| `Error` | `message` / `keepMounted` | 自定义错误文本覆盖；`keepMounted` 默认 `false` |
| `Validity` | — | 只读校验状态展示与 `getValidity()` 读取器 |

- **方法**：`Root` 提供 `validate(reason?)`、`resolveValidation(requestId, result)`、`cancelValidation()`、`resetValidation()`（仅清空校验状态与 `touched`，不修改字段值与 `dirty` 基线）、`focusControl(options?)` 和 `getValidity()`。
- **事件**：`validityChange`、`validationRequest`（`{ requestId, value, reason }`）。
