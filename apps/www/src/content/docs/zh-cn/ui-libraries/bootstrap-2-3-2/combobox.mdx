Combobox 将可编辑的搜索框与选项列表结合起来，严格区分当前查询文本（`inputValue`）与已提交的选项值（`value`）。

## 用法

由 `Root`、`Input`、`Trigger`、`Content`、`Item` 和 `Empty` 组成：

- **选项值与输入文本分离**：`Root` 的 `value` 始终是已选选项的键，`inputValue` 是独立的编辑文本；不匹配的输入不会自动成为选中值。
- **搜索与过滤**：默认基于 `textValue` 和 `keywords` 进行忽略大小写与重音的过滤；如需自行过滤，传入 `filter={false}`。无匹配项时显示 `Empty`。
- **键盘与输入法**：使用方向键切换高亮选项时输入框保持焦点；IME 组合输入期间不会误选。禁用项和重复值选项不可提交。
- **独立受控**：`open`、`value` 和 `inputValue` 均可分别受控并通过对应事件更新。

## API

| 部件 | 属性 | 说明 |
| --- | --- | --- |
| `Root` | `value` / `inputValue` / `open` | 分别控制已选选项键、搜索文本与弹层展开状态 |
| `Root` | `filter` | 是否启用内置过滤；设为 `false` 时由调用方提供过滤后的选项 |
| `Input` | — | 单行搜索输入框 |
| `Trigger` | — | 打开或关闭下拉列表的触发按钮 |
| `Content` | — | 选项列表弹层 |
| `Item` | `value` / `textValue` / `keywords` / `disabled` | 单个可选项 |
| `Empty` | — | 无匹配选项时展示的内容 |
