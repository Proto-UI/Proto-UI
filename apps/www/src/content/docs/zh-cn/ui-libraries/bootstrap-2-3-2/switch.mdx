此 Switch 是设计语言扩展（design-language extension），不是 Bootstrap 2.3.2 的原版组件。Root / Thumb anatomy 借用归档版本的凸起控件语言，交互语义保持由 Base Switch 拥有。

Base Switch 拥有持久的 on/off `checked` 值、受控与非受控值归属、激活、禁用与焦点。Thumb 读取最近 Root 的 context，不拥有独立的值或事件。

通过页面运行时选择器比较 Web Components、React、Vue 3 与 Vue 2。可切换前两个开关，并检查禁用开关保持不变。

## API

- Root：`checked` / `defaultChecked`、`disabled`
- Root 继承 `checkedChange` 信号
- Thumb：放在对应 Root 内的派生展示部件
