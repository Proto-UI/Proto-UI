Bootstrap 2.3.2 Switch 是一项设计语言扩展（design-language extension），不是 Bootstrap 2.3.2 的原版组件。它借鉴归档版本的立体凸起控件风格构建 `Root` / `Thumb` 结构，同时完整保留 Base Switch 的交互语义与经典浅色配色。

## 预览

可切换前两个开关，并观察第三个禁用开关保持不可交互。

## 用法

- **状态由 Root 统一管理**：支持受控 `checked` 与非受控 `defaultChecked`，处理点击、键盘激活、焦点和禁用状态。
- **Thumb**：放置在 `Root` 内部，自动跟随开关状态滑动展示，无需额外绑定属性。

## API

| 部件    | 属性 / 事件                  | 说明                           |
| ------- | ---------------------------- | ------------------------------ |
| `Root`  | `checked` / `defaultChecked` | 受控或初始开关状态             |
| `Root`  | `disabled`                   | 禁用开关交互                   |
| `Root`  | `checkedChange`              | 开关状态变更事件               |
| `Thumb` | —                            | 放置在 `Root` 内的滑块指示部件 |
