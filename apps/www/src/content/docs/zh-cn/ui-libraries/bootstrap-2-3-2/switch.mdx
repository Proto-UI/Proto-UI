Bootstrap 2.3.2 Switch 是一项设计语言扩展（design-language extension），借鉴经典立体渐变与内嵌阴影风格构建 `Root` / `Thumb` 结构，同时完整继承 Base Switch 的键盘交互、RTL 镜像与拖动语义。

## 安装

当前仅在源码工作区提供，可从 `@proto.ui/prototypes-bootstrap-2-3-2/switch` 导入。[查看已实现的子集](../)。

## 用法

```tsx
import { switchRoot, switchThumb } from '@proto.ui/prototypes-bootstrap-2-3-2/switch';
```

```html
<proto-ui-bootstrap-2-3-2-switch-root default-checked>
  <proto-ui-bootstrap-2-3-2-switch-thumb></proto-ui-bootstrap-2-3-2-switch-thumb>
  <span class="sr-only">Release alerts</span>
</proto-ui-bootstrap-2-3-2-switch-root>
```

- **状态由 Root 统一管理**：支持受控 `checked` 与非受控 `defaultChecked`，处理点击、键盘激活、悬停/按压立体反馈、焦点与禁用状态。
- **Thumb 自动同步**：放置在 `Root` 内部，自动跟随开关状态、拖动百分比与 `direction` 滑动，并在 `prefers-reduced-motion: reduce` 下取消位移动画。
