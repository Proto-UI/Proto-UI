## 用法

- **三部件结构**：在每个 `Root` 内放置一个 `Trigger` 和一个 `Content`；嵌套或相邻的 `Collapsible` 各自独立维护状态。
- **状态由 Root 统一管理**：传入 `open` 进入受控模式，收到 `openChange` 事件（载荷为 `{ open, reason }`）后由父组件决定是否更新 `open`；禁用状态会阻止新的切换请求，但不会自动关闭已展开的内容。
- **内容挂载控制**：关闭时默认卸载内容节点；设置 `keepMounted` 可保留隐藏的 DOM 节点。
- **布局与缩放**：支持长标签与长单词自动换行，间距以 `rem` 表达以跟随字号缩放，外层容器建议为焦点环留出足够边距。

更多共享请求与生命周期细则请参考 [Base Collapsible](/zh-cn/ui-libraries/base/collapsible/)。

## API

| 部件 | 属性 / 方法 / 事件 | 说明 |
| --- | --- | --- |
| `Root` | `open` / `defaultOpen` / `disabled` | 受控或初始展开状态及禁用开关 |
| `Root` | `openCollapsible()` / `close()` / `toggle()` | 编程式发起展开、收起或切换请求 |
| `Root` | `openChange` | 状态变更请求事件，载荷为 `{ open, reason }` |
| `Trigger` | `disabled` / `focusSelf()` | 按钮触发器，支持自然 Tab 顺序与 `Enter`/`Space` 激活 |
| `Content` | `keepMounted` | 默认 `false`；设为 `true` 时收起后保留隐藏节点 |
