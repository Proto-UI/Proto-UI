Bootstrap 2.3.2 Collapsible 提供可展开/收起的单项内容区，忠实保留归档 Bootstrap 2.3.2 的像素圆角、经典链接色与 350ms 高度过渡，并完全基于 [Base Collapsible](/zh-cn/ui-libraries/base/collapsible/) 语义。

## 安装

当前仅在源码工作区提供，可直接从 `@proto.ui/prototypes-bootstrap-2-3-2/collapsible` 导入部件：

```ts
import {
  collapsibleRoot,
  collapsibleTrigger,
  collapsibleContent,
} from '@proto.ui/prototypes-bootstrap-2-3-2/collapsible';
```

## 用法

```tsx
import {
  Bootstrap232CollapsibleRoot,
  Bootstrap232CollapsibleTrigger,
  Bootstrap232CollapsibleContent,
} from '@/components/ui/collapsible';

export function Example() {
  return (
    <Bootstrap232CollapsibleRoot>
      <Bootstrap232CollapsibleTrigger>Order #4189 — Product details</Bootstrap232CollapsibleTrigger>
      <Bootstrap232CollapsibleContent>
        Status: Shipped · 100 Market St, San Francisco · 2x Studio Headphones.
      </Bootstrap232CollapsibleContent>
    </Bootstrap232CollapsibleRoot>
  );
}
```

### 部件结构与视觉特征

```text
CollapsibleRoot
├── CollapsibleTrigger
└── CollapsibleContent
```

- **经典像素度量与配色**：保留 Bootstrap 2.3.2 的 `14px/20px` 排版、`4px` 圆角、`15px × 8px` 触发器内边距、`15px × 9px` 内容区内边距，以及 `#08c` 静止链接色与 `#005580` 悬停/按压下划线反馈（暗色模式下自动切换至高可读边框与浅蓝高亮）。
- **350ms 高度折叠过渡**：`Content` 通过共享 `asTransition()` 绑定 `blockSize` 过渡，在内层容器绘制顶部分隔线与内边距，确保收起高度精确归零。
- **受控与内容卸载**：传入 `open` 与 `openChange` 即可外部受控；`Content` 默认关闭即卸载，设置 `keepMounted={true}` 可保留隐藏节点。
