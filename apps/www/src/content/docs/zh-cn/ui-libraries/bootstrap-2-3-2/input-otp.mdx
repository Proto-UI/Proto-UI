## 用法

由 `Root`、`Input`（或在 `Field` / `FormField` 中使用 `Control`）、`Slot` 和可选的 `Separator` 组成：

- **单一编辑器与分格显示**：所有输入、选择、粘贴和 IME 组合都在同一个 `Input` 内完成，并在组合结束后自动按数字或字母数字规则过滤并截断至 `length`（`1`–`32`，默认 `6`）。每个 `Slot` 为纯视觉展示格，聚焦且可编辑时根据实际光标或选区高亮对应格位。
- **完成事件**：受控模式下通过 `valueChange` 接收更新请求；每当输入达到完整长度并被接受时触发一次 `completed` 事件，由应用决定后续验证逻辑。
- **表单集成**：在 `Field` 或 `FormField` 内使用时，用 `Control` 替换 `Input`，即可自动桥接标签激活、校验、IME 取消、`Form` 序列化与重置。

## API

| 部件 | 属性 / 事件 | 说明 |
| --- | --- | --- |
| `Root` | `value` / `defaultValue` | 受控或初始验证码字符串 |
| `Root` | `length` | 验证码位数，`1`–`32`，默认 `6` |
| `Root` | `disabled` / `readOnly` / `name` / `ariaLabel` | 状态、表单字段名与可访问名称 |
| `Root` | `valueChange` / `completed` | 值变更请求与输入完成事件 |
| `Input` / `Control` | — | 实际输入编辑器（在 `Field`/`FormField` 内使用 `Control`） |
| `Slot` / `Separator` | — | 按索引展示字符的分格与可选分隔符 |
