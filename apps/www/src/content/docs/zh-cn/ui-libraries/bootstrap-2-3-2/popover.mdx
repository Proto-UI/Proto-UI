## 用法

由 `Root`、`Trigger`、`Content`、`Title`、`Description` 和 `Close` 组成：

- **定位与偏移**：`Content` 自动相对 `Trigger` 定位，支持通过 `side`、`align`、`sideOffset`、`alignOffset` 和 `collisionPadding` 调整方向、对齐与视口边缘留白。
- **关闭与焦点行为**：点击外部区域、焦点移出 `Trigger` 与 `Content`、按 `Escape` 或点击 `Close` 都会请求关闭。在 `Trigger` 与弹出内容之间切换焦点视为内部交互；当因焦点移出外部控件而关闭时，焦点保留在目标外部控件上而不强行拉回 `Trigger`。
- **受控模式**：传入 `open` 并监听 `openChange` 由父组件决定开关状态，非受控模式使用 `defaultOpen`。若受控模式拒绝外部焦点移出关闭请求，弹层保持打开且不限制外部焦点。

## API

| 部件 | 属性 / 事件 | 说明 |
| --- | --- | --- |
| `Root` | `open` / `defaultOpen` | 受控或初始打开状态 |
| `Root` | `openChange` | 打开或关闭请求事件 |
| `Trigger` | — | 切换弹层的锚点按钮 |
| `Content` | `side` / `align` / `sideOffset` / `alignOffset` / `collisionPadding` | 弹层定位与碰撞边距配置 |
| `Title` / `Description` | — | 弹层标题与说明文本 |
| `Close` | — | 请求关闭弹层的按钮 |
