## 安装

Bootstrap 2.3.2 Popover 目前在工作区源码中提供，将于 `0.3.0-rc.1` 及后续版本中提供 CLI。可直接从 `@proto.ui/prototypes-bootstrap-2-3-2/popover` 导入原型并使用对应框架适配器：

```ts
import {
  popoverRoot,
  popoverTrigger,
  popoverContent,
  popoverTitle,
  popoverDescription,
  popoverClose,
} from '@proto.ui/prototypes-bootstrap-2-3-2/popover';
```

## 用法

```tsx
<BootstrapPopover>
  <BootstrapPopoverTrigger>Open Popover</BootstrapPopoverTrigger>
  <BootstrapPopoverContent>
    <BootstrapPopoverTitle>Popover title</BootstrapPopoverTitle>
    <BootstrapPopoverDescription>
      And here is some helpful contextual information anchored to the right.
    </BootstrapPopoverDescription>
  </BootstrapPopoverContent>
</BootstrapPopover>
```

### 组件结构

```text
BootstrapPopoverRoot
├── BootstrapPopoverTrigger
└── BootstrapPopoverContent
    ├── BootstrapPopoverTitle
    ├── BootstrapPopoverDescription
    └── BootstrapPopoverClose
```

- **经典默认配置**：遵循 Bootstrap 2.3.2 历史规格，`Content` 默认弹出方向为 `side="right"`、`sideOffset={10}`，最大宽度 `276px`，圆角 `6px`，并自带 `150ms` 线性透明度淡入淡出过渡。
- **非模态交互与关闭**：点击外部区域、焦点移出 `Trigger` 与 `Content`、按下 `Escape` 或点击 `Close` 均会请求关闭；因外部焦点移出而关闭时，焦点保留在目标外部控件上。
