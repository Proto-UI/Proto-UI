Content 相对 Trigger 定位，提供 side、align、sideOffset、alignOffset、collisionPadding。非模态内容不锁定背景滚动或限制 Tab；外部点击、Escape 与 Close 请求关闭。

Root 支持受控 open 和非受控 defaultOpen。禁用命令不激活。传入 open 时，最终状态仍由调用方持有，通过 openChange 接收请求后再提供新值。

组成: Root, Trigger, Content, Title, Description, Close.

当前是草稿源码实现。完整 native/GPUI、编译器、打包消费、视觉及独立验收仍待完成；本页不表示 Finf 已完成。
