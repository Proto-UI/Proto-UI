Resizable 将两个或多个按百分比分配的面板与可拖拽分隔柄组合起来，支持指针拖动、方向键、`Shift` 加速、`Home` / `End` 与面板折叠，并可自由嵌套不同方向的面板组。

## 用法

- **多面板编号**：`N` 个 `Panel` 依次使用 `index: 0..N-1`，`N - 1` 个 `Handle` 使用 `index: 0..N-2`（每个 `Handle` 调整其前后相邻的两个面板，保持其余面板比例不变，默认无障碍名称为 `Resize panels`）。
- **约束与折叠**：通过 `constraints` 按面板索引配置 `min`、`max`、`collapsible` 与 `collapsedSize`（默认 `0`、`100`、`false`、`0`）。总比例自动归一化为 `100`；非法或不可行约束会保持上次有效布局。折叠是离散停靠点，若相邻面板已达 `max` 则阻止继续折叠。
- **受控与嵌套**：传入 `sizes` 进入受控模式，通过 `sizesChange` 与 `sizesCommit`（载荷为 `{ sizes }`）接收实时与最终比例；取消拖拽不触发 `sizesCommit`。嵌套 `Root` 各自独立管理比例、约束与方向。Web 样式通过 `--pui-size` 映射静态 `flex-basis` 规则，拖拽计算自动扣除固定分隔柄宽度。

## API

| 部件 | 属性 / 方法 / 事件 | 说明 |
| --- | --- | --- |
| `Root` | `sizes` / `defaultSizes` | 完整面板百分比数组（同时兼容旧双面板 `value` / `defaultValue`，传入 `sizes` 时优先） |
| `Root` | `constraints` | 逐面板约束对象数组：`min`、`max`、`collapsible`、`collapsedSize` |
| `Root` | `requestResize(index, nextSize, commit)` / `requestSizes(nextSizes, commit)` | 编程式发起单面板或整组尺寸调整 |
| `Root` | `sizesChange` / `sizesCommit` | 拖拽中与提交时的比例变更事件，载荷为 `{ sizes }` |
| `Panel` | `index` | `0..N-1` 面板编号，通过 `--pui-size` 应用当前百分比宽度/高度 |
| `Handle` | `index` | `0..N-2` 分隔柄编号，支持指针与键盘调整相邻面板 |
