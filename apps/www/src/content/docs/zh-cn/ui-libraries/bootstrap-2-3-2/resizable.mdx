基于 Base 语义构建的 Bootstrap 2.3.2 扩展分栏组件：分隔柄采用经典 `#fff → #e6e6e6` 垂直渐变、内嵌高光边框、可选凹刻抓握柄与 `#52a8ec` 蓝色焦点光晕，完整支持多面板比例分配、折叠停靠、RTL 与嵌套布局。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可直接从 `@proto.ui/prototypes-bootstrap-2-3-2/resizable` 导入原型并适配到目标宿主：

```ts
import {
  resizableRoot,
  resizablePanel,
  resizableHandle,
} from '@proto.ui/prototypes-bootstrap-2-3-2/resizable';
```

## 用法

```tsx
import {
  Bootstrap232ResizableRoot,
  Bootstrap232ResizablePanel,
  Bootstrap232ResizableHandle,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <Bootstrap232ResizableRoot
      defaultSizes={[50, 50]}
      className="h-56 w-full max-w-md rounded-[4px] border border-[#ccc] bg-background shadow-[0_1px_3px_rgb(0_0_0/5.5%)] overflow-hidden"
    >
      <Bootstrap232ResizablePanel index={0}>One</Bootstrap232ResizablePanel>
      <Bootstrap232ResizableHandle index={0} withHandle />
      <Bootstrap232ResizablePanel index={1}>Two</Bootstrap232ResizablePanel>
    </Bootstrap232ResizableRoot>
  );
}
```

### 组合结构

```text
Bootstrap232ResizableRoot
├── Bootstrap232ResizablePanel (index: 0)
├── Bootstrap232ResizableHandle (index: 0, withHandle?)
└── Bootstrap232ResizablePanel (index: 1)
```

- **多面板编号**：`N` 个 `Panel` 使用 `index: 0..N-1`，`N - 1` 个 `Handle` 使用 `index: 0..N-2`。每个分隔柄只调整相邻两个面板，并默认提供无障碍名称 `Resize panels`。
- **视觉与交互**：分隔柄在水平/垂直布局下自动切换 `ew-resize` / `ns-resize` 光标；键盘聚焦时呈现 Bootstrap 2.3.2 经典的 `#52a8ec` 外发光；禁用时切换为平铺 `#e6e6e6` 与 `opacity-65`。
- **约束与受控**：通过 `constraints` 按索引配置 `min`、`max`、`collapsible` 与 `collapsedSize`；传入 `sizes` 进入受控模式并响应 `sizesChange` / `sizesCommit`。

### Panel 与 Handle

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'Panel.index', type: 'number', default: '0' },
    { name: 'Handle.index', type: 'number', default: '0' },
    { name: 'Handle.withHandle', type: 'boolean', default: 'false' },
  ]}
/>

- **暴露状态**：Root 暴露 `value`、`sizes`；Panel 暴露 `size`；Handle 暴露 `value`、`focusVisible`、`disabled`。
- **事件与方法**：Root 触发 `sizesChange` / `sizesCommit` / `valueChange` / `valueCommit`，并暴露 `requestResize(index, next, commit?)`、`requestSizes(next, commit?)`、`requestValue(next, commit?)` 与 `cancelResize()`。
