Bootstrap 2.3.2 Select 是基于 Base Select 的设计语言扩展，借鉴归档 Bootstrap 2.3.2 按钮下拉菜单的圆角、阴影与间距，提供完整的受控单选、键盘导航与碰撞避让弹层。

## 预览

示例涵盖非受控选择、禁用态、受控选择（选中后点击 **Accept selection** 提交新值）以及 RTL 长文本换行。

## 用法

### 组合与交互

由 `Root`、`Trigger`、`Value`、`Content` 和 `Item` 五个部件组成：

- **状态由 Root 统一管理**：`open` 与 `value` 可分别独立进入受控模式，非受控初始值通过 `defaultOpen` 和 `defaultValue` 提供。
- **键盘与鼠标**：点击 `Trigger` 切换展开，`Enter` / `Space` 打开列表，`ArrowDown` / `ArrowUp` 定位到当前已选项或首末可用项；在列表中用方向键浏览不会提前改值，按 `Enter` / `Space` 或点击可用 `Item` 提交选择（禁用项自动跳过）。按 `Escape` 取消并将焦点交回 `Trigger`，按 `Tab` 或点击外部自动关闭。
- **文本展示与换行**：`Value` 按已选文本 → 原始 `value` → `placeholder` → 空内容依次回退，更新已选 `Item` 的 `textValue` 会自动刷新展示文本。长标签自动换行，弹层宽度与高度自动受视口可用空间约束。
- **风格细节**：由于归档 Bootstrap 2.3.2 原生依赖浏览器 `<select>`，本组件借鉴其 button-dropdown 视觉语法（4px 触发器圆角、6px 面板圆角、rem 缩放内边距，并加深选中蓝底以确保白字对比度）。

更多协议细节请参阅 [Base Select](/zh-cn/ui-libraries/base/select/)。

## API

| 部件 | 属性 / 事件 | 说明 |
| --- | --- | --- |
| `Root` | `open` / `defaultOpen`、`value` / `defaultValue` | 独立控制展开状态与选中值 |
| `Root` | `disabled` / `closeOnSelect` | 禁用控件 / 选中后是否自动关闭 |
| `Root` | `openChange` / `valueChange` | 展开状态与选中值变更请求事件 |
| `Trigger` | — | 带有 `combobox` 语义的触发按钮 |
| `Value` | `placeholder` | 显示当前选中标签或占位文案 |
| `Content` | `side` / `align` / `sideOffset` / `alignOffset` / `avoidCollisions` / `collisionPadding` | 锚定列表弹层与碰撞避让配置 |
| `Item` | `value` / `textValue` / `disabled` / `select` | 单个选项定义及选中事件 |
