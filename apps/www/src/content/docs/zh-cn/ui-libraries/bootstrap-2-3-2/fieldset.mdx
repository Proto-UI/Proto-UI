## 用法

由 `Root`、可选的 `Legend` 和可选的 `Description` 组成：

- **级联禁用**：`Root` 的实际禁用状态等于本地 `disabled` 与所有外层 `Fieldset` 禁用状态的逻辑或。重新启用外层 `Fieldset` 时，内层已设置的本地 `disabled` 仍会被保留。内部的 `Field`（包括位于 `Legend` 内的字段）会自动继承该禁用状态。
- **自动无障碍关联**：`Root` 声明 `group` 角色，并自动关联同一分组内的 `Legend` 与 `Description`，无需手写 DOM ID。每个分组最多包含一个 `Legend` 和一个 `Description`，重复配置时将忽略非法配置并保持当前状态。
- **样式说明**：`Root` 为无边框无内边距的块级容器；`Legend` 为全宽 `1.3125rem` 标题并带底边框；`Description` 为小号弱化帮助文本。

## API

| 部件          | 属性 / 状态 | 说明                                                    |
| ------------- | ----------- | ------------------------------------------------------- |
| `Root`        | `disabled`  | `boolean`，默认 `false`；向下级联禁用内部字段与嵌套分组 |
| `Root`        | `ariaLabel` | `string`，默认 `""`；无 `Legend` 时提供分组可访问名称   |
| `Legend`      | —           | 可选分组标题，只读暴露继承的 `disabled` 状态            |
| `Description` | —           | 可选分组说明文本，只读暴露继承的 `disabled` 状态        |
