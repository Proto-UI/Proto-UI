Bootstrap 2.3.2 Checkbox Group 用于管理一组关联的复选框值，保留经典 14px/20px 排版、内阴影边框与主色渐变选中态，并支持全选/半选以及与 `Field` / `Form` 的直接集成。

## 用法

```tsx
import {
  Bootstrap232CheckboxGroupRoot,
  Bootstrap232CheckboxGroupAll,
  Bootstrap232CheckboxGroupItem,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <Bootstrap232CheckboxGroupRoot defaultValue={['email']} ariaLabel="Notification channels">
      <Bootstrap232CheckboxGroupAll>All notifications</Bootstrap232CheckboxGroupAll>
      <Bootstrap232CheckboxGroupItem value="email">Email updates</Bootstrap232CheckboxGroupItem>
      <Bootstrap232CheckboxGroupItem value="sms">SMS alerts</Bootstrap232CheckboxGroupItem>
    </Bootstrap232CheckboxGroupRoot>
  );
}
```

### 部件结构与键盘交互

- **Root**：通过 `value` / `defaultValue` 管理字符串数组，支持 `orientation`（`horizontal` 对应 `.checkbox.inline` 水平排布）、`disabled`、`readOnly` 与 `ariaLabel`。
- **Item**：单个复选框选项，接收唯一的 `value` 与可选 `disabled`；每项独立参与 `Tab` 顺序，按 `Space` 切换选中（`Enter` 不切换）。
- **All**：自动汇总所有可用选项的勾选、半选横线或未选状态，点击时只切换可用项并保留已禁用项的原状态。
- **表单集成**：置于 `Field` 或 `FormField` 内时，自动支持标签点击聚焦、必填校验、序列化与重置。

### 事件、方法与状态

- **Root 事件**：`valueChange`（载荷 `{ value: string[] }`）。
- **Root 方法**：`getValue(): string[]`、`resetValue(): boolean`、`focusSelf(): void`。
- **暴露状态**：Root 暴露 `checked`、`indeterminate`、`disabled`、`readOnly`；Item 与 All 暴露 `checked`、`indeterminate`、`disabled`、`readOnly`、`focused`、`focusVisible`。
