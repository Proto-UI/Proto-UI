Root 通过 value/defaultValue 管理字符串数组，支持 disabled/readOnly/ariaLabel；Item 支持 value/disabled；All 汇总可用项并切换全部选择，保留已禁用项的选择。每项独立 Tab，空格切换，Enter 不切换。受控请求仅发 valueChange，不覆盖作者值；getValue 返回副本，重复值不含糊切换。原生隐藏表单项及 Field 控件桥接仍待补齐。

四家族继承同一 Base 行为。部件： root, item, all.
