Bootstrap 2.3.2 Checkbox Group 用于管理一组关联的复选框值，支持全选（含半选状态）以及与 `Field`、`Form` 的直接集成。

## 用法

由 `Root`、`Item` 和可选的 `All` 组成：

- **值管理**：`Root` 通过 `value` / `defaultValue` 管理字符串数组，受控模式下发出 `valueChange` 请求而不直接修改外部值；调用 `getValue()` 返回当前数组副本。重复 `value` 的选项会被忽略。
- **全选联动**：`All` 自动汇总所有未禁用选项的选中状态（勾选、半选横线或未选），点击时只切换可用项，保留已禁用项的既有选中状态。
- **键盘与无障碍**：每个选项独立参与 Tab 顺序，按 `Space` 切换选中（`Enter` 不触发切换）。指示图标使用勾选/横线/空框清晰表达状态，不仅依赖颜色区分。
- **表单集成**：置于 `Field` 或 `FormField` 内时，自动支持标签点击激活、必填校验、`Form` 序列化与重置。

## API

| 部件   | 属性 / 事件 / 方法                    | 说明                               |
| ------ | ------------------------------------- | ---------------------------------- |
| `Root` | `value` / `defaultValue`              | `string[]`，选中值数组             |
| `Root` | `disabled` / `readOnly` / `ariaLabel` | 禁用、只读与组级可访问名称         |
| `Root` | `valueChange` / `getValue()`          | 选中值变更请求事件与读取副本的方法 |
| `Item` | `value` / `disabled`                  | 选项唯一值与单项禁用               |
| `All`  | —                                     | 全选/半选联动控制项                |
