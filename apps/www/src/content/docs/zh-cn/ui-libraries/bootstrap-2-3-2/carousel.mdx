Carousel 组合等尺寸项目条、连续滚动视口与前后控制。鼠标或触摸拖动在松手前就移动内容；滚轮、触控板和滚动条使用同一个滚动表面。拖动结束或原生滚动静止后，内容吸附到最近的可达项目边界。键盘导航使用同一索引请求。

当前是功能源码 WIP。完整 Adapter/Compiler、原生 GPUI、包消费者、无障碍与绑定提交的视觉验收仍待补齐。

## 响应式视口与受控索引

Root 的 `slidesPerView` 设置最多显示的等尺寸项目数（默认 `1`），`minSlideSize` 设置项目最小逻辑宿主像素尺寸（默认 `0`）。演示请求显示两项，最小尺寸为 `180`；缩窄视口会减少实际容量，也允许部分项目露出。所有项目始终保留布局尺寸。Root 通过实际视口公开 `visibleSlides` 和 `maxIndex`，最后一个吸附位置贴齐内容末端，避免空白。

传入 `index` 进入受控模式，`indexChange` 提出新的吸附索引。拖动预览不会改变已提交的 `index`；松手时采用所有者同步接受的值，否则回到现有索引，延迟接受则在新的输入到达时再移动。Viewport 公开 `dragging`、`scrolling` 与归一化 `scrollPosition`；Slide 的 `current` 跟随已提交吸附项，`hidden` 跟随实际屏外可见性，且不会从布局移除项目。

`orientation="vertical"` 需要消费者为视口设置明确的有界高度。水平 `direction="rtl"` 反转物理拖动与方向键，但保留逻辑项目顺序。取消、禁用、切换轴和移除视图会丢弃未完成的拖动。`loop` 在可达两端循环索引，不通过克隆项目实现无缝无限条；自动播放和不同尺寸项目不属于当前契约。
