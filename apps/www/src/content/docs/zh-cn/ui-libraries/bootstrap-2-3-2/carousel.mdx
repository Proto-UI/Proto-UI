Carousel 将等尺寸滑块条、连续滚动视口与前后切换按钮组合在一起，支持鼠标/触摸拖拽、滚轮/触控板滚动与键盘导航，松手或滚动停止后自动吸附到最近的可达项。

## 用法

### 响应式视口与吸附

- 通过 `Root` 的 `slidesPerView`（默认 `1`）设置最多同时显示的等尺寸项数，`minSlideSize`（默认 `0`，逻辑像素）设置单项最小尺寸。当视口变窄时会自动减少可见项数，最后一个吸附位贴齐末端以避免多余空白。
- 示例配置为最多显示 2 项、最小宽度 `180`，缩小视口可观察容量自适应变化。
- 纵向模式（`orientation="vertical"`）需为视口设置明确高度；横向 `direction="rtl"` 会反转拖动和左右键方向，同时保留逻辑顺序。
- 开启 `loop` 后索引可在首尾之间循环（不会克隆额外节点）。

### 受控索引

- 传入 `index` 进入受控模式，通过 `indexChange` 接收新的吸附索引请求。
- 拖拽过程中已提交的 `index` 保持不变；松手时若父组件同步更新 `index` 则停留在目标位，否则平滑回到当前值。

## API

| 部件 | 属性 / 状态 | 说明 |
| --- | --- | --- |
| `Root` | `slidesPerView` / `minSlideSize` | 默认 `1` / `0`，控制响应式可见项数与最小尺寸 |
| `Root` | `index` / `indexChange` | 受控吸附索引与索引变更请求事件 |
| `Root` | `orientation` / `direction` / `loop` | 滚动方向、书写方向与首尾循环开关 |
| `Root` | `visibleSlides` / `maxIndex` | 根据实际视口计算的只读状态 |
| `Viewport` | `dragging` / `scrolling` / `scrollPosition` | 实时交互状态与归一化滚动进度 |
| `Slide` | `current` / `hidden` | 跟随当前吸附项与实际屏外可见性（不移除布局占位） |
