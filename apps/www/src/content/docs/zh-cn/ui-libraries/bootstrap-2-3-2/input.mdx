Bootstrap 2.3.2 Input 将归档版本的经典输入框样式应用于 Base Input，在 Web 上渲染单一原生 `input[type=text]` 编辑器，并在深色宿主中保持经典的归档浅色配色。

## 预览

可编辑输入框内容、聚焦只读输入框，并与禁用状态对比。

## 用法

- **值与输入事件**：支持受控 `value` 与非受控 `defaultValue`，统一处理输入、失焦提交与 IME 组合输入事件。
- **只读与禁用**：`readOnly` 允许聚焦和复制但禁止编辑；`disabled` 阻止聚焦与输入。
- **表单字段组合**：如需标签、帮助说明与错误提示，请与 `Field` 组合使用。

## API

| 分类 | 成员 | 说明 |
| --- | --- | --- |
| 值与状态 | `value` / `defaultValue`、`disabled`、`readOnly`、`placeholder` | 文本值与编辑状态 |
| 表单与输入提示 | `name`、`required`、`autoComplete`、`minLength`、`maxLength`、`inputMode`、`enterKeyHint` | 原生输入行为与软键盘提示 |
| 无障碍 | `ariaLabel`、`labelledBy`、`describedBy` | 可访问名称与关联说明 |
| 事件与方法 | `valueChange`、`change`、IME 组合事件、`focusSelf()`、`blurSelf()` | 变更通知与焦点控制 |
