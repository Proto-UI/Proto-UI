Bootstrap 2.3.2 Input 将经典 `forms.less` 视觉样式（4px 圆角、内阴影、蓝色焦点光晕与 `#eee` 禁用/只读填充）应用于 [Base Input](../../base/input/)，并在深色宿主中保持经典的归档浅色表单表面。

## 安装

当前以工作区源码提供，将于 `0.3.0-rc.1` 及后续版本中提供；可从 `@proto.ui/prototypes-bootstrap-2-3-2/input` 导入。[查看已实现的子集](../)。

## 用法

```tsx
import { Bootstrap232InputRoot } from '@/components/ui/bootstrap-2-3-2-input';

export function Example() {
  return <Bootstrap232InputRoot placeholder="Type something..." ariaLabel="Basic input" />;
}
```

- **值与输入事件**：支持受控 `value` 与非受控 `defaultValue`，统一处理输入、提交与 IME 组合事件。
- **只读与禁用**：`readOnly` 保持可聚焦与文本选中，`disabled` 阻止聚焦与编辑，两者均呈现经典的 `#eee` 背景与禁选光标。
- **表单字段组合**：如需标签、帮助说明与红色校验反馈，请与 Bootstrap 2.3.2 `Field` 组合使用。

### 暴露状态、方法与事件

- **状态**：`value`、`disabled`、`readOnly`、`focused`、`focusVisible`、`composing`
- **方法**：`focusSelf(options?)`、`blurSelf()`、`resetValue(value?: string): boolean`
- **事件**：`valueChange`、`change`、`compositionStart`、`compositionUpdate`、`compositionEnd`
