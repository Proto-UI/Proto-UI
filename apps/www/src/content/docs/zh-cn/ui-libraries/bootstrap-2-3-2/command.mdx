Bootstrap 2.3.2 Command 在保留经典蓝色焦点光晕与渐变高亮菜单项的基础上，提供实时过滤、键盘导航与弹窗组合能力。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供（`@proto.ui/prototypes-bootstrap-2-3-2/command`）。

## 用法

```tsx
import {
  commandRoot,
  commandInput,
  commandContent,
  commandItem,
  commandEmpty,
} from '@proto.ui/prototypes-bootstrap-2-3-2/command';
```

### 部件组合结构

```text
CommandRoot
├── CommandInput
└── CommandContent
    ├── CommandItem
    └── CommandEmpty
```

- **视觉风格**：输入框延续 Bootstrap 2.3.2 30px 高度与 `#52a8ec` 聚焦光晕；列表沿用 6px 圆角、柔和阴影与经典 `#08c -> #0077b3` 渐变选中态，并限定 `300px` 最大高度支持滚动。
- **搜索与执行**：按 `textValue` 与 `keywords` 忽略大小写和重音过滤，也可设置 `filter={false}` 接入外部过滤；按 `Enter` 或点击命令项发出 `execute` 事件。
- **键盘与输入法**：方向键移动高亮项时焦点保留在输入框内，IME 组合输入期间不触发执行，禁用项与重复值项不可提交。

### 其他部件与事件

- **Input**：`placeholder`、`a11yLabel`、`name` 均默认为 `''`。
- **Content**：`side="bottom"`、`align="start"`、`sideOffset={4}`、`collisionPadding={8}`。
- **Item**：`value`、`textValue`、`keywords` 均默认为 `''`，`disabled` 默认为 `false`。
- **Empty**：无独立属性，无匹配命令时自动显示。
- **事件**：`Root` 触发 `execute`、`valueChange`、`inputValueChange` 与 `openChange`。
