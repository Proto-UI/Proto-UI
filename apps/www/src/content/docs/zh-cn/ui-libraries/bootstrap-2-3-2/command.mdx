## 用法

由 `Root`、`Input`、`Content`、`Item` 和 `Empty` 组成：

- **命令执行**：列表保持内联显示。按下 `Enter` 或点击命令项时发出包含选中项的 `execute` 事件，由应用代码执行具体逻辑；单纯输入搜索文本不会触发命令。
- **搜索与过滤**：内置过滤按 `textValue` 与 `keywords` 匹配（忽略大小写和重音），也可通过 `filter={false}` 接入外部过滤。无匹配命令时显示 `Empty`。
- **键盘与输入法**：使用方向键移动高亮项时焦点保留在输入框内；IME 组合输入期间不会误执行命令。禁用项和重复值命令不可提交。

## API

| 部件 | 属性 / 事件 | 说明 |
| --- | --- | --- |
| `Root` | `value` / `inputValue` / `open` / `filter` | 支持受控状态管理与内置/外部过滤切换 |
| `Root` | `execute` | 激活命令项时发出的操作意图事件 |
| `Input` | — | 单行命令搜索框 |
| `Content` | — | 内联命令列表容器 |
| `Item` | `value` / `textValue` / `keywords` / `disabled` | 单个可执行命令项 |
| `Empty` | — | 无匹配命令时显示的提示 |
