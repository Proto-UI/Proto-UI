Bootstrap 2.3.2 Accordion 沿用经典 Bootstrap 2.3.2 的 `.accordion-group` 外观（4px 圆角、链接式蓝字标题与 350ms 平滑高度展开过渡），并完整复用 Base Accordion 的状态与无障碍语义。

## 安装

当前通过工作区源码包提供，可直接从 `@proto.ui/prototypes-bootstrap-2-3-2/accordion` 导入五个部件原型：

```ts
import {
  accordionRoot,
  accordionItem,
  accordionHeading,
  accordionTrigger,
  accordionContent,
} from '@proto.ui/prototypes-bootstrap-2-3-2/accordion';
```

## 用法

```tsx
import {
  Bootstrap232AccordionRoot,
  Bootstrap232AccordionItem,
  Bootstrap232AccordionHeading,
  Bootstrap232AccordionTrigger,
  Bootstrap232AccordionContent,
} from '@/components/proto-ui/react';

export function BootstrapAccordionUsage() {
  return (
    <Bootstrap232AccordionRoot defaultOpenItems={['item-1']}>
      <Bootstrap232AccordionItem value="item-1">
        <Bootstrap232AccordionHeading level={3}>
          <Bootstrap232AccordionTrigger>Collapsible Group Item #1</Bootstrap232AccordionTrigger>
        </Bootstrap232AccordionHeading>
        <Bootstrap232AccordionContent>
          Anim pariatur cliche reprehenderit, enim eiusmod high life accusamus terry richardson.
        </Bootstrap232AccordionContent>
      </Bootstrap232AccordionItem>
    </Bootstrap232AccordionRoot>
  );
}
```

### 部件结构

```text
AccordionRoot
└── AccordionItem
    ├── AccordionHeading
    │   └── AccordionTrigger
    └── AccordionContent
```

- **Root**：统一管理当前展开项集合与导航轴向，支持嵌套独立分组。
- **Item**：对应经典 `.accordion-group` 面板框（4px 圆角、浅色 `#e5e5e5` / 暗色自适应边框与主题底色），需提供唯一非空 `value`。
- **Heading**：声明标题层级（默认 `3`），内部仅放控制该项的 `Trigger`。
- **Trigger**：无额外折叠图标的经典链接式标题（默认 `#08c`、悬停 `#005580` 下划线，暗色模式自动切换高对比链接色），并在不可收起或禁用时给出明确光标提示。
- **Content**：绑定 `asTransition` 提供 350ms `blockSize` 高度过渡动画；关闭时默认卸载内容节点，设置 `keepMounted` 可保留隐藏节点。

### 键盘与无障碍

- 启用的 `Trigger` 与内容区可聚焦元素保持自然 `Tab` 顺序；`Enter` / `Space` 切换当前项。
- 纵向模式下按 `ArrowUp` / `ArrowDown`、横向模式下按 `ArrowLeft` / `ArrowRight`（RTL 自动反转）及 `Home` / `End` 在启用标题间移动焦点，不改变展开状态。
- 当 `allowEmpty={false}` 阻止收起最后一个已展开项时，该触发器仍可聚焦并通过 `aria-disabled` 提示不可关闭。

### 方法与事件（Root）

- **方法与属性**：`getOpenItems()` 返回当前展开键数组副本；`openCount` 表示展开键数量；`requestOpen(value, open, reason?)` 编程请求展开或收起。
- **事件**：`openChange`，载荷为 `{ openItems, value, open, reason }`（`reason` 为 `'pointer'`、`'keyboard'` 或 `'programmatic'`）。
