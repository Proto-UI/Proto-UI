## 用法

### 组合结构

按 `Root` → `Item` → `Heading` → `Trigger` 组合，将 `Content` 与 `Heading` 并列放置：

- **Root**：统一管理当前展开的项集合，支持嵌套独立分组。
- **Item**：每个面板项都需要唯一、稳定且非空的 `value`。
- **Heading**：声明标题语义层级，内部只放用于控制该项的 `Trigger`；如有持续显示的次级操作，放在 `Heading` 旁边。
- **Trigger**：从所属 `Item` 和 `Root` 读取展开与禁用状态。
- **Content**：关闭时默认卸载内容节点；设置 `keepMounted` 可在收起时保留隐藏节点。

### 受控与非受控

- 传入 `defaultOpenItems` 初始化非受控展开项；传入 `openItems` 进入受控模式。
- 受控模式下，`Root` 发出 `openChange` 事件（载荷为 `{ openItems, value, open, reason }`），界面仅在父组件更新 `openItems` 后改变。
- `single` 模式下只取第一个有效键；尚未挂载的键会保留待对应 `Item` 出现后生效。

### 键盘与无障碍

- 每个启用的 `Trigger` 和内容区内的可聚焦元素保持自然 Tab 顺序。
- `Enter` / `Space` 切换当前项；纵向模式下用上下方向键、横向模式下用左右方向键（RTL 自动反转）在启用的标题间移动，`Home` / `End` 跳到首末标题。
- 方向键只移动焦点，不改变展开状态；当 `allowEmpty={false}` 时，最后一个已展开项的触发器仍可聚焦，但通过 `aria-disabled` 阻止关闭。
- `Trigger` 自动关联其对应 `Content` 的 `aria-controls` 与命名关系；设置 `Content` 的 `region={true}` 可显式声明地标区域。

## API

| 部件 | 属性 | 说明与默认值 |
| --- | --- | --- |
| `Root` | `mode` | `'single'`（默认）或 `'multiple'` |
| `Root` | `openItems` / `defaultOpenItems` | `string[]`；传入 `openItems` 即为受控模式 |
| `Root` | `allowEmpty` | `boolean`，默认 `true`；设为 `false` 时阻止收起最后一个展开项 |
| `Root` | `disabled` | `boolean`，默认 `false`；禁用整组交互但不改写已有值 |
| `Root` | `orientation` / `direction` / `loop` | 默认 `'vertical'`、`'ltr'`、`true`，仅影响标题键盘导航 |
| `Item` | `value` / `disabled` | `value` 必填且唯一；`disabled` 默认 `false` |
| `Heading` | `level` | `1`–`6` 整数，默认 `3` |
| `Trigger` | — | 从 `Item` 与 `Root` 派生状态 |
| `Content` | `keepMounted` / `region` | 默认均为 `false`；分别控制隐藏保留与地标语义 |

- **方法与属性**：`Root` 提供 `getOpenItems()`（返回副本）、`openCount` 和 `requestOpen(value, open, reason?)`。
- **事件**：`openChange`，载荷为 `{ openItems, value, open, reason }`，其中 `reason` 为 `'pointer'`、`'keyboard'` 或 `'programmatic'`。
