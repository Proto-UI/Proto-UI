Bootstrap 2.3.2 Table 在 [Base Table](/zh-cn/ui-libraries/base/table/) 的结构化语义之上还原归档版本的 14px/20px 排版、8px 默认单元格内边距与顶部横线节奏，并提供经典的边框表格（`bordered`）、紧凑排版（`condensed`）、斑马纹（`striped`）、悬停高亮（`hoverable`）与语义状态行（`tone`）。

如需排序、过滤、分页与行选择，请使用 [Data Table](/zh-cn/ui-libraries/bootstrap-2-3-2/data-table/)。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可从 `@proto.ui/prototypes-bootstrap-2-3-2/table` 导入各部件：

```ts
import {
  tableRoot,
  tableCaption,
  tableRow,
  tableHeaderCell,
  tableCell,
} from '@proto.ui/prototypes-bootstrap-2-3-2/table';
```

## 用法

```html

  <bootstrap-2-3-2-table-root>
    <bootstrap-2-3-2-table-caption>A list of your recent invoices.</bootstrap-2-3-2-table-caption>
    <bootstrap-2-3-2-table-row section="header">
      <bootstrap-2-3-2-table-header-cell
        header-key="invoice"
        header-kind="column"
        style="width: 100px"
      >
        Invoice
      </bootstrap-2-3-2-table-header-cell>
      <bootstrap-2-3-2-table-header-cell header-key="status" header-kind="column"
        >Status</bootstrap-2-3-2-table-header-cell
      >
      <bootstrap-2-3-2-table-header-cell header-key="method" header-kind="column"
        >Method</bootstrap-2-3-2-table-header-cell
      >

        Amount

    </bootstrap-2-3-2-table-row>
    <bootstrap-2-3-2-table-row section="body">
      <bootstrap-2-3-2-table-header-cell header-key="inv001" header-kind="row"

      <bootstrap-2-3-2-table-cell style="text-align: end">$250.00</bootstrap-2-3-2-table-cell>
    </bootstrap-2-3-2-table-row>
  </bootstrap-2-3-2-table-root>
</div>
```

### 组件结构

```text
Root
├── Caption
├── Row (section="header")
│   └── HeaderCell (headerKind="column")
├── Row (section="body")
│   ├── HeaderCell (headerKind="row")
│   └── Cell (headers=[...])
└── Row (section="footer")
    ├── HeaderCell (headerKind="row")
    └── Cell (headers=[...])
```

- 默认基线严格保留 Bootstrap 2.3.2 `.table` 的首行无上边框规则（仅第一行的列表头省略 `border-t`）与 `8px` 单元格内边距。
- 分隔线绑定主题变量 `border-border`，在浅色与深色宿主下均与文字前景色保持清晰对比。

### Root

`Root` 暴露 `getStructure()` 方法读取当前表格结构快照。

### Caption

`Caption` 不声明额外属性，采用居中辅助文字样式并保留上下留白。
