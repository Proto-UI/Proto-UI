Bootstrap 2.3.2 Tooltip 保留归档版本的经典黑底白字（`#000` / `#fff`）、`200px` 最大宽度、`4px` 圆角、`11px` 字号与 `150ms` 线性淡入淡出（`0 → 0.8` 透明度），所有延迟协调、键盘聚焦与无障碍语义由 Base Tooltip 统一提供。

## 安装

Bootstrap 2.3.2 Tooltip 当前以工作区源码提供，可通过 `@proto.ui/prototypes-bootstrap-2-3-2/tooltip` 直接导入 `tooltipGroup`、`tooltipRoot`、`tooltipTrigger` 与 `tooltipContent`，配合任意宿主 Adapter 使用。

## 用法

```tsx
import {
  BootstrapTooltipGroup,
  BootstrapTooltipRoot,
  BootstrapTooltipTrigger,
  BootstrapTooltipContent,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <BootstrapTooltipGroup>
      <BootstrapTooltipRoot>
        <BootstrapTooltipTrigger>Account</BootstrapTooltipTrigger>
        <BootstrapTooltipContent side="top">View account settings</BootstrapTooltipContent>
      </BootstrapTooltipRoot>
    </BootstrapTooltipGroup>
  );
}
```

### 组件结构

```text
TooltipGroup (可选)
└── TooltipRoot
    ├── TooltipTrigger
    └── TooltipContent
```

- `Group` 协调相邻提示的冷启动延迟（默认 `700ms`）、关闭延迟（`100ms`）与热切换窗口（`300ms`）。
- `Trigger` 保持无多余装饰并应用经典聚焦轮廓；键盘 `Tab` 聚焦立即打开，按 `Escape` 关闭。
- `Content` 通过 Portal 渲染并自动维护 `aria-describedby` 与 `role="tooltip"`，系统启用减弱动态效果时自动关闭过渡。

### 事件、状态与方法

- **Root**：暴露状态 `open`，事件 `openChange`（`{ open, reason }`），方法 `openTooltip(reason?)`、`close(reason?)`、`toggle(reason?)`。
- **Trigger**：暴露状态 `disabled`、`hovered`、`focused`、`focusVisible`，方法 `focusSelf(options?)`。
- **Content**：暴露状态 `open` 与 Transition 状态（`transitionState`、`isPresent`、`controls`）。
