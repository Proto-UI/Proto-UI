Bootstrap 2.3.2 Async Region 为经典 Bootstrap 2.3.2 界面提供纯语义的 `aria-busy` 区域包装，由 [Base Async Region](/zh-cn/ui-libraries/base/async-region/) 统一驱动，不覆盖调用方已有的经典面板、Well 容器或焦点状态。

## 安装

当前仅在源码工作区提供，尚未进入 `0.2.0` 稳定版。可从子路径导入：

```ts
import { asyncRegionRoot } from '@proto.ui/prototypes-bootstrap-2-3-2/async-region';
```

## 用法

```tsx
import { useState } from 'react';
import { AdaptToReact } from '@proto.ui/adapter-react';
import { asyncRegionRoot } from '@proto.ui/prototypes-bootstrap-2-3-2/async-region';

const BootstrapAsyncRegionRoot = AdaptToReact(asyncRegionRoot);

export function OrdersPanel() {
  const [busy, setBusy] = useState(false);

  return (
    <BootstrapAsyncRegionRoot busy={busy}>
      <p>刷新订单列表期间保留现有内容与键盘焦点。</p>
    </BootstrapAsyncRegionRoot>
  );
}
```

- **语义投射**：Bootstrap 2.3.2 历史版本本身不包含 Async Region 控件，因此 `bootstrap-2-3-2-async-region-root` 仅透传 Base 的 `busy` 状态与 `aria-busy` 属性，不向宿主注入额外视觉样式或 jQuery 插件接口。
- **保留经典表面**：外层可继续使用 Bootstrap 2.3.2 的 `#f5f5f5` Well、`#ffffff` 面板、1px `#dddddd` 边框、4px 圆角与固定 14px 像素排版，并通过 `[aria-busy="true"]` 叠加需要的忙碌态反馈。
- **焦点与交互不变**：切换 `busy` 不会卸载子节点或禁用内部控件；需要向屏幕阅读器播报状态时，可组合 `bootstrap-2-3-2-live-region-root`。
