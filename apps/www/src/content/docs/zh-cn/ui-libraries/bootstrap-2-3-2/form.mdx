## 用法

由 `Root`、`FormField`、`FormSubmit` 和 `FormReset` 组成：

- **校验与提交**：`Root` 汇总内部显式注册的 `FormField`，校验通过后在 `submit` 事件中返回按字段名组织的表单数据。禁用的字段不参与序列化；存在重复字段名时忽略非法配置并阻止提交。若包含异步校验，会等待最新校验完成，期间值变更、取消或卸载会自动作废旧提交。
- **快捷提交**：焦点位于单行 `Field`、`Number Field` 或 `Input OTP` 内时，按 `Enter` 可直接触发表单提交（IME 组合输入、修饰键及长按重复触发除外）。
- **整表禁用与重置**：设置 `Form` 的 `disabled` 会自动传递到内部 `Field`。调用 `requestReset()` 或点击 `FormReset` 会将非受控字段恢复为挂载初值，向受控字段发送重置请求，取消进行中的编辑与校验并触发 `reset` 事件；若仅需清空错误提示，调用 `resetValidation()`。
- **按钮反馈**：`FormSubmit` 与 `FormReset` 复用 Bootstrap 2.3.2 按钮样式，并暴露 `disabled`、`hovered`、`pressed`、`focused`、`focusVisible` 状态及 `focusSelf()` 方法。表单本身不发起网络请求或页面跳转，由应用监听 `submit` 事件处理提交逻辑。

## API

| 部件 | 属性 / 方法 / 事件 | 说明 |
| --- | --- | --- |
| `Root` | `disabled` | 禁用整张表单及内部字段 |
| `Root` | `submit` / `reset` | 校验通过后提交表单数据事件 / 重置完成事件 |
| `Root` | `requestReset()` / `resetValidation()` | 重置表单值与状态 / 仅清除校验状态 |
| `FormField` | — | 向 `Form` 注册单个字段及其字段名 |
| `FormSubmit` | `focusSelf()` | 触发表单校验与提交的按钮 |
| `FormReset` | `focusSelf()` | 触发表单重置的按钮 |
