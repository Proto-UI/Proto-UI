Bootstrap 2.3.2 Form 协调表单内所有已注册字段的同步与异步校验，并在全部有效时通过 `submit` 事件输出按字段名组织的表单数据，同时保留经典 Bootstrap 2.3.2 像素节奏、按钮渐变与操作栏层次。

## 安装

当前组件在工作区源码中提供，尚未包含在 0.2.0 稳定版包中；可从 `@proto.ui/prototypes-bootstrap-2-3-2/form` 引入。

## 用法

```tsx
import {
  Bootstrap232FormRoot,
  Bootstrap232FormField,
  Bootstrap232FormSubmit,
  Bootstrap232FormReset,
  Bootstrap232FieldLabel,
  Bootstrap232FieldControl,
  Bootstrap232FieldError,
} from '../proto-ui/components/react';

export function ExampleBootstrapForm() {
  return (
    <Bootstrap232FormRoot ariaLabel="Profile form" onSubmit={({ values }) => console.log(values)}>
      <Bootstrap232FormField name="username" required>
        <Bootstrap232FieldLabel>Username</Bootstrap232FieldLabel>
        <Bootstrap232FieldControl placeholder="ada_lovelace" />
        <Bootstrap232FieldError />
      </Bootstrap232FormField>
      <div className="flex items-center gap-2 border-t border-border pt-3">
        <Bootstrap232FormSubmit variant="primary">Save changes</Bootstrap232FormSubmit>
        <Bootstrap232FormReset variant="default">Cancel</Bootstrap232FormReset>
      </div>
    </Bootstrap232FormRoot>
  );
}
```

### 部件结构与行为

- **校验与提交**：`Root` 汇总内部显式注册的 `FormField`，校验通过后在 `submit` 事件中返回按字段名组织的表单数据。禁用的字段不参与序列化；重复字段名会在序列化时抛出 `FORM_DUPLICATE_NAME` 错误。包含异步校验时，会等待当前版本的校验结果，并在编辑、取消或卸载时自动废弃旧提交。
- **快捷提交**：焦点位于单行 `Field`、`Number Field` 或 `Input OTP` 内时，按 `Enter` 可直接触发表单提交（IME 组合输入、修饰键与长按连发除外）。
- **整表禁用与重置**：设置 `Form` 的 `disabled` 会自动传递到内部字段与按钮。调用 `requestReset()` 或点击 `FormReset` 会恢复非受控字段初值、向受控字段发出重置提议并触发 `reset` 事件；调用 `resetValidation()` 仅清理校验状态。
- **按钮样式**：`FormSubmit` 与 `FormReset` 采用经典 Bootstrap 2.3.2 4px 圆角、线性渐变与内阴影反馈，支持 `variant`（`default`、`primary`、`danger`、`success`、`info`、`warning`、`inverse`）。
