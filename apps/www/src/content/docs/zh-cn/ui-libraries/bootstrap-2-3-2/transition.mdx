Bootstrap 2.3.2 Transition 提供透明的五阶段进出场状态机（`closed → preparing → entering → entered → leaving`）。原型本身刻意不替调用方隐式二选一 `.fade`（150ms 线性透明度）或 `.collapse`（高度折叠），从而让应用可以按需为经典的 Bootstrap 2.3.2 Alert、Well 或面板绑定最合适的过渡样式。

## 预览

下方示例在经典的 Bootstrap 2.3.2 Well 舞台与 Alert Info 表面上演示 `enter`、`leave`、`complete` 控制及 150ms 线性 `.fade` 淡入淡出，支持切换 Web Components、React、Vue 3 与 Vue 2。

## 安装

当前仅在源码工作区提供，将于 `0.3.0-rc.1` 及后续版本中提供或 CLI 安装列表。可直接从工作区源码导入：

```ts
import { transition } from '@proto.ui/prototypes-bootstrap-2-3-2/transition';
```

## 用法

```html
<wc-bootstrap-2-3-2-transition default-open appear class="bs-fade-host">
  <div class="rounded-[4px] border border-[#bce8f1] bg-[#d9edf7] px-4 py-3.5 text-[#3a87ad]">
    <strong>Workspace synced</strong> — Your classic alert surface stays mounted until leaving ends.
  </div>
</wc-bootstrap-2-3-2-transition>

<style>
  .bs-fade-host > * {
    transition: opacity 0.15s linear;
  }
  .bs-fade-host[data-transition-state='leaving'] > *,
  .bs-fade-host[data-transition-state='closed'] > * {
    opacity: 0;
  }
  @media (prefers-reduced-motion: reduce) {
    .bs-fade-host > * {
      transition: none;
    }
  }
</style>
```

- **保持透明插槽**：`bootstrap-2-3-2-transition` 不注入默认样式 token，也不覆盖 Base 默认时长，避免与业务自定义的 `.fade` 或 `.collapse` 轨迹冲突。
- **经典视觉搭配**：配合 4px 圆角、14px/20px 像素排版与 `#d9edf7` / `#f5f5f5` 经典表面即可呈现地道的 Bootstrap 2.3.2 过渡体验。
- **减少动态效果**：当宿主启用 `prefers-reduced-motion: reduce` 时，自动兜底延时坍缩为 `0ms`，同时保留完整事件与卸载顺序。所有核心语义由 [Base Transition](/zh-cn/ui-libraries/base/transition/) 统一提供。
