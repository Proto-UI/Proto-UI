Bootstrap 2.3.2 Live Region 继承 [Base Live Region](/zh-cn/ui-libraries/base/live-region/) 的无障碍实时播报语义，根据 `politeness` 与 `atomic` 自动维护 `role`、`aria-live` 与 `aria-atomic`，保持纯语义展示而不伪装为 Bootstrap 的视觉 Alert 提示框。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版或 CLI 安装目标。请直接从工作区包 `@proto.ui/prototypes-bootstrap-2-3-2/live-region` 导入 `liveRegionRoot`：

```ts
import { liveRegionRoot } from '@proto.ui/prototypes-bootstrap-2-3-2/live-region';
```

## 用法

```tsx
import { AdaptToReact } from '@proto.ui/adapter-react';
import { liveRegionRoot } from '@proto.ui/prototypes-bootstrap-2-3-2/live-region';

const BootstrapLiveRegionRoot = AdaptToReact(liveRegionRoot);

export function StatusBanner({ message }: { message: string }) {
  return (
    <BootstrapLiveRegionRoot politeness="polite" atomic>
      {message}
    </BootstrapLiveRegionRoot>
  );
}
```

- **播报优先级**：`politeness="polite"`（默认）投射 `role="status"` 与 `aria-live="polite"`；`politeness="assertive"` 投射 `role="alert"` 与 `aria-live="assertive"`。
- **原子播报**：`atomic={true}`（默认）投射 `aria-atomic="true"`；设为 `false` 时仅播报实际变更的子节点。
- **语义与视觉分离**：`Root` 保持无外框的纯语义容器，直接继承所在容器的可读前景排版，不附加 Bootstrap 2.3.2 的 `.alert` 背景、边框或关闭按钮，方便嵌入经典 Well、表单反馈行或 `.sr-only` 隐式播报区。
