固定 2.3.2 的经典渐变、凸起控件、输入框与分隔线视觉语言；交互与值归属全部继承 Base。

当前已实现的 draft 子集包括 Button、Checkbox Root / Indicator、Switch Root / Thumb、Toggle、Input、Textarea、Separator、Surface、Text、Label、Collapsible、Accordion 与五 part Select。这仍是 partial family，不等于完整 Bootstrap 或 Base 组件集，也不接入首页的完整族选择器。

Switch 与 Toggle 是设计语言扩展（design-language extensions），不是 Bootstrap 2.3.2 的原版组件。Checkbox 使用自定义 Root / Indicator 部件，不冒充归档版本的原生 checkbox 实现。不引入旧版 jQuery 运行时或 Glyphicons。

通过页面运行时选择器，让同一套共享 demo recipes 分别运行于 Web Components、React、Vue 3 或 Vue 2。深色宿主中仍固定使用归档浅色配色。源码包为 private、未发布；这些 draft Web 投射不代表通用 Prototype Compiler 或 GPUI、Flutter、Qt 一致性已经通过。
