## 用法

由 `Root`、`Label`、`Input`（在 `Field` / `FormField` 内替换为 `Control`）、`Increment` 和 `Decrement` 组成：

- **编辑与步进**：输入过程中允许保留未完成的草稿文本，失焦或按 `Enter` 时解析提交合法数值或恢复上次有效值。点击加减按钮或按上下方向键按 `step` 步进，按住 `Shift` 为 10 倍步进，`Home` / `End` 跳转到 `min` / `max`。IME 组合输入期间不会触发解析或步进。
- **本地化格式**：传入 `locale` 与 `formatOptions` 支持十进制、货币与百分比展示及解析；显示舍入不会修改内部精确数值。若格式配置非法，会标记 `formatInvalid` 并自动回退到无分组十进制。
- **空值支持**：默认 `allowEmpty={false}`；设为 `true` 后，清空输入框并提交会请求 `null`（`value={null}` 仍属于受控模式）。使用 `getValue()` 可读取准确的 `number | null`，`empty` 指示当前是否为空；从空值步进时先初始化为边界内对齐的 `0`。
- **标签拖拽调值（`scrub`）**：开启 `scrub` 后可在 `Label` 上左右拖动连续调值（`scrubSteps` 默认 `100`，表示拖动一个标签宽度对应的步数，`direction="rtl"` 自动反转方向），释放且值变化时提交一次；取消拖拽会恢复起值。
- **表单集成**：在 `Field` / `FormField` 内用 `Control` 替换 `Input`，即可与 `FieldLabel`、数值校验、`Form` 序列化与重置联动。

## API

| 部件 | 属性 / 方法 / 状态 | 说明 |
| --- | --- | --- |
| `Root` | `value` / `defaultValue` | `number \| null`，受控或初始数值 |
| `Root` | `min` / `max` / `step` | 默认 `0`、`100`、`1` |
| `Root` | `allowEmpty` | 默认 `false`；设为 `true` 允许清空提交 `null` |
| `Root` | `locale` / `formatOptions` | 本地化十进制、货币与百分比格式配置 |
| `Root` | `scrub` / `scrubSteps` / `direction` | 启用标签拖拽调值及灵敏度（默认 `100` 步） |
| `Root` | `disabled` / `readOnly` / `name` / `ariaLabel` | 交互状态、表单字段名与可访问名称 |
| `Root` | `getValue()` / `empty` / `formatInvalid` | 读取 `number \| null`、空值标记与格式校验状态 |
| `Label` / `Input` / `Control` / `Increment` / `Decrement` | — | 标签、输入框（表单内用 `Control`）及步进按钮 |
