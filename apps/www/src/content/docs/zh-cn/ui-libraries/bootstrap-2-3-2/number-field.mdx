Bootstrap 2.3.2 Number Field 将经典 `forms.less` 输入框与 `buttons.less` 渐变立体按钮外观投影到 Base Number Field 协议上，提供加减步进、键盘调值、本地化格式化、可空值与标签拖拽调值，并可直接接入 `Field` 与 `Form`。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可直接从 `@proto.ui/prototypes-bootstrap-2-3-2/number-field` 导入各部件原型：

```ts
import {
  numberFieldRoot,
  numberFieldLabel,
  numberFieldInput,
  numberFieldControl,
  numberFieldIncrement,
  numberFieldDecrement,
} from '@proto.ui/prototypes-bootstrap-2-3-2/number-field';
```

## 用法

```tsx
<Bootstrap232NumberFieldRoot defaultValue={12} min={0} max={100} step={1} ariaLabel="Quantity">
  <Bootstrap232NumberFieldLabel>Quantity</Bootstrap232NumberFieldLabel>
  <Bootstrap232NumberFieldDecrement>
    <span aria-hidden="true">−</span>
    <span className="sr-only">Decrease Quantity</span>
  </Bootstrap232NumberFieldDecrement>
  <Bootstrap232NumberFieldInput />
  <Bootstrap232NumberFieldIncrement>
    <span aria-hidden="true">+</span>
    <span className="sr-only">Increase Quantity</span>
  </Bootstrap232NumberFieldIncrement>
</Bootstrap232NumberFieldRoot>
```

- **编辑与步进**：输入过程中允许保留未完成的草稿文本，失焦或按 `Enter` 时提交合法数值或恢复上次有效值。步进按钮具备经典 Bootstrap 2.3.2 悬停与按压渐变内影反馈；方向键按 `step` 步进，按住 `Shift` 为 10 倍步进，`Home` / `End` 跳至 `min` / `max`。IME 组合输入期间暂停解析与步进。
- **本地化格式**：传入 `locale` 与 `formatOptions` 支持十进制、货币与百分比展示及解析，展示舍入不改变底层数值精度。
- **空值与表单**：开启 `allowEmpty` 允许清空提交 `null`；在 `Field` 或 `FormField` 中使用 `Control` 替代 `Input` 以自动联动标签、校验、序列化与重置。
