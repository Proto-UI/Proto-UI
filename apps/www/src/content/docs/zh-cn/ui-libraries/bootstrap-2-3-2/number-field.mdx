Root 管理 `number | null` 的 value/defaultValue、min/max（0/100）、正 step（1）、disabled/readOnly、name、ariaLabel。Input 使用 TextControl 唯一编辑器与 spinbutton 语义。未完成草稿可以保留；失焦/Enter 提交合法数值或恢复已接受的规范值。加减按钮与上下箭头共享步进，Shift 十倍，Home/End 达边界；受控提案不覆盖作者值。

`locale` 与 `formatOptions` 支持标准十进制、货币和百分比显示，以及对应的小数、分组、本地数字与符号解析。格式化只影响显示精度，无编辑的提交不会把格式舍入写回数值。非法格式配置通过 `formatInvalid` 报告，并回退无分组十进制；非法输入保留草稿并在提交时恢复。省略格式属性保持原有十进制显示。IME 组合期间不会解析、提交、步进或开始拖擦，切换 locale 也保留正在输入的组合文本。

显式 `null` 表示空值，`value={null}` 仍然受控。`allowEmpty` 默认 `false`，启用后清空编辑器并提交会请求 `null`。Root 与 Input/Control 的 `getValue()` 返回真实 `number | null`，`empty` 标记空值；兼容数值读口 `value` 仅在 `empty=false` 时表示规范数值，空值时保留最近有限值。事件及 Field/Form 始终传递真实空值。从空值步进先初始化为边界内对齐的零。

启用 `scrub` 后可在 Label 上连续拖动调值；`scrubSteps`（默认100）表示移动一个初始标签宽度对应多少个 step，`direction="rtl"` 反转横向。成功释放且值发生改变时提交一次；取消恢复非受控起值，受控值始终由作者决定。输入框保留普通文本选择，滚轮调整尚未实现。

在 Field/FormField 内用 Control 替代 Input，FieldLabel 命名并激活真实编辑器，联动 Field 策略、规范数值校验、IME 取消、Form 序列化及复位。独立 Input 仍使用 NumberFieldLabel。

部件: root, label, input, control, increment, decrement. 四个视觉家族继承同一 Base 行为。
