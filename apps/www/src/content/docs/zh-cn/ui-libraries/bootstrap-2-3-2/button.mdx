Bootstrap 2.3.2 Button 保留归档版本的渐变、边框和内阴影；Base Button 负责激活、键盘输入、焦点和禁用行为。

下面的示例包含当前支持的变体、四种尺寸和禁用状态。使用运行时选择器，可以在 Web Components、React、Vue 3 和 Vue 2 中运行同一个原型。

## 使用

Web Components：

```html
<wc-bootstrap-2-3-2-button variant="primary">继续</wc-bootstrap-2-3-2-button>
<wc-bootstrap-2-3-2-button disabled>不可用</wc-bootstrap-2-3-2-button>
```

React：

```tsx
import { BootstrapButton } from '../proto-ui/components/react';

export function Example() {
  return <BootstrapButton variant="primary">继续</BootstrapButton>;
}
```

Vue 3：

```vue
<template>
  <BootstrapButton variant="primary">继续</BootstrapButton>
</template>

<script setup>
import { BootstrapButton } from '../proto-ui/components/vue';
</script>
```

Vue 2：

```vue
<template>
  <BootstrapButton variant="primary">继续</BootstrapButton>
</template>

<script>
import { BootstrapButton } from '../proto-ui/components/vue2';

export default {
  components: { BootstrapButton },
};
</script>
```

## 变体与尺寸

- `variant`：`default`、`primary`、`warning`、`danger`、`success`、`info` 或 `inverse`。
- `size`：`default`、`large`、`small` 或 `mini`。
- `disabled`：默认为 `false`。禁用按钮不会发出激活请求。

归档配方使用固定像素尺寸，不会随文档根字体大小缩放。这个 Web 示例不构成 GPUI、Flutter 或 Qt 的一致性证据。

## 无障碍

按钮名称来自其内容。键盘激活、焦点和禁用输入抑制继承自 Base Button；Bootstrap 投影不建立第二套交互状态。
