## API

- variant: default / primary / warning / danger / success / info / inverse
- size: default / large / small / mini，默认 default
- 各尺寸保留 20px 行高与 1px 边框。large：11px 19px 内边距、17.5px 字号、6px 圆角（单行高 44px）；small：2px 10px、11.9px、3px（26px）；mini：0px 6px、10.5px、3px（22px）。
- disabled: boolean, default false
- 激活、焦点、键盘与禁用逻辑继承 Base Button，视觉层没有第二个状态拥有者。

这是 draft 状态的源码投射，源码包仍为 private、未发布。深色宿主中继续使用归档浅色配色。Web 示例不代表通用 Prototype Compiler 或 GPUI、Flutter、Qt 一致性已经通过。[查看已实现的子集](../)。

七种配色保留 v2.3.2 文字阴影与最终边框颜色。悬停或聚焦时保留上移后的渐变；按下或禁用时使用纯色终点，可见焦点环继续保留。原始 100ms 运动、对比度验收与完整目标证据仍待完成；静态状态终点不代表全部上游能力已对齐。
