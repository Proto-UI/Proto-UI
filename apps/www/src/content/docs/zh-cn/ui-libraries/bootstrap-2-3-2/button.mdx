Bootstrap 2.3.2 Button 保留归档版本的渐变背景、边框与内阴影样式，交互、键盘激活、焦点与禁用状态由 Base Button 统一提供。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

<InstallCommandCard
  command="npx @proto.ui/cli@latest add wc bootstrap-2-3-2-button"
  manager="npm"
/>

将命令中的 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的组件代码。

## 用法

Web Components：

```html
<wc-bootstrap-2-3-2-button variant="primary">继续</wc-bootstrap-2-3-2-button>
<wc-bootstrap-2-3-2-button disabled>不可用</wc-bootstrap-2-3-2-button>
```

React：

```tsx
import { BootstrapButton } from '../proto-ui/components/react';

export function Example() {
  return <BootstrapButton variant="primary">继续</BootstrapButton>;
}
```

Vue 3：

```vue
<template>
  <BootstrapButton variant="primary">继续</BootstrapButton>
</template>

<script setup>
import { BootstrapButton } from '../proto-ui/components/vue';
</script>
```

Vue 2：

```vue
<template>
  <BootstrapButton variant="primary">继续</BootstrapButton>
</template>

<script>
import { BootstrapButton } from '../proto-ui/components/vue2';

export default {
  components: { BootstrapButton },
};
</script>
```

### 样式与无障碍

- 归档样式采用固定像素尺寸，不会随文档根字号缩放，并在深色宿主中保持经典的浅色配色。
- 按钮的可访问名称来自其子内容，键盘激活、焦点管理与禁用拦截均继承自 Base Button。

## API

| 属性 | 可选值 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `variant` | `default` \| `primary` \| `warning` \| `danger` \| `success` \| `info` \| `inverse` | `default` | 按钮语义配色 |
| `size` | `default` \| `large` \| `small` \| `mini` | `default` | 按钮尺寸 |
| `disabled` | `boolean` | `false` | 禁用后不再响应点击与键盘激活 |
