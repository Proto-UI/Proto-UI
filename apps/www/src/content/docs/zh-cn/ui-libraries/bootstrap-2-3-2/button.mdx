Bootstrap 2.3.2 Button 保留归档版本的线性渐变、文字阴影、边框与固定像素尺寸，同时由 Base Button 统一提供键盘激活、焦点与禁用语义。

## 安装

当前以 Proto UI 工作区源码提供：

<InstallCommandCard
  commands={{
    npm: 'npx @proto.ui/cli@latest add wc bootstrap-2-3-2-button',
    pnpm: 'pnpm dlx @proto.ui/cli@latest add wc bootstrap-2-3-2-button',
  }}
  manager="npm"
/>

将命令中的 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的组件封装。

## 用法

```tsx
import { BootstrapButton } from '../proto-ui/components/react';

export function Example() {
  return <BootstrapButton variant="primary">Continue</BootstrapButton>;
}
```

- **固定像素尺寸与配色**：完整沿用 Bootstrap 2.3.2 的像素内边距、字号与圆角，不随根字号缩放，并在深色宿主中保持经典浅色按钮调色板。
- **悬停渐变与无障碍**：悬停或聚焦进入时执行经典的 100ms 线性背景位移动画（离开立即复位，减弱动态偏好下自动关闭）；键盘激活、焦点环与禁用语义继承自 [Base Button](../base/button/)。
