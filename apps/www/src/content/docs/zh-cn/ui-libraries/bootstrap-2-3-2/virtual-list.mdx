Virtual List 将完整的逻辑键序列与实际渲染的视图节点解耦，只为当前可见区域及缓冲区（overscan）创建列表项，轻松承载超长动态高度列表。

## 用法

- **有界渲染模型**：核心模型负责管理稳定的逻辑键序列、按项 `overscan` 缓冲数量与最大同时挂载数量上限，确保应用内容仅针对可见区间按需创建。
- **Web 宿主集成**：通过 `virtual-list/web` 入口自动测量可变高度列表项、维护上下占位空间、按 key 复用已挂载节点、支持滚动定位到指定 key，并在卸载时自动清理监听器。

## API

| 能力 / 入口        | 说明                                                        |
| ------------------ | ----------------------------------------------------------- |
| 核心模型           | 管理稳定逻辑键序列、按项 `overscan` 与最大挂载数上限        |
| `virtual-list/web` | 测量可变项尺寸、维护占位节点、支持按 key 滚动定位与自动清理 |
