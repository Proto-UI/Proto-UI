Virtual List 将完整的逻辑键序列与实际渲染的 DOM 节点解耦，仅为当前可见区域及缓冲区创建列表项。Bootstrap 2.3.2 版本采用经典的 4px 圆角边框容器、14px/20px 排版比例与柔和内阴影，保留传统表格/列表的清晰层次。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `@proto.ui/prototypes-bootstrap-2-3-2/virtual-list` 导入原型，并结合 `@proto.ui/prototypes-base/virtual-list/web` 完成 Web 滚动视口绑定。

## 用法

Virtual List 由 `Root`、`Viewport` 与 `Content` 三个子部件组成：`Root` 负责逻辑键集合与外框样式，`Viewport` 提供滚动视口与键盘内嵌焦点环，`Content` 承载动态挂载的行节点。

```ts
import { AdaptToWebComponent, setElementProps } from '@proto.ui/adapter-web-component';
import {
  virtualListRoot,
  virtualListViewport,
  virtualListContent,
} from '@proto.ui/prototypes-bootstrap-2-3-2/virtual-list';
import { attachWebVirtualList } from '@proto.ui/prototypes-base/virtual-list/web';

AdaptToWebComponent(virtualListRoot);
AdaptToWebComponent(virtualListViewport);
AdaptToWebComponent(virtualListContent);

const list = document.querySelector('bootstrap-2-3-2-virtual-list-root')!;
const viewport = document.querySelector('bootstrap-2-3-2-virtual-list-viewport')!;
const content = document.querySelector('bootstrap-2-3-2-virtual-list-content')!;

setElementProps(list, {
  itemKeys: Array.from({ length: 1000 }, (_, i) => `event-${i + 1}`),
  overscanItems: 3,
  maxMaterializedItems: 60,
});

const host = attachWebVirtualList({
  viewport,
  content,
  collection: list.getExposes().getCollection(),
  estimateSize: 62,
  renderItem(key) {
    const row = document.createElement('div');
    row.className = 'border-b border-border px-3 py-2 text-[14px] leading-[20px]';
    row.textContent = key;
    return row;
  },
});

// 定位到指定条目，卸载时清理监听与节点
host.ensureVisible('event-250', 'center');
// host.dispose();
```

### 结构与无障碍

- `Root` 提供 `role="region"` 与 `a11yLabel`，采用 4px 圆角、1px 边框与 `overflow-hidden` 裁切，避免内外双边框重叠。
- `Viewport` 默认启用 `overflow-auto` 滚动，键盘聚焦时呈现清晰的 2px 内嵌焦点环。
- `Content` 声明 `role="list"`，每条挂载行自动带有 `role="listitem"`、`aria-posinset` 与 `aria-setsize`。

### 进阶：自定义渲染宿主

- 每个逻辑列表实例同一时刻仅允许挂载一个活跃渲染宿主；`attachWebVirtualList` 会自动管理生命周期并在 `Root` 卸载或销毁时清理节点与观察器。
- 替换宿主前需先调用旧宿主的 `dispose()`；非 Web 宿主可通过 `collection.acquireMaterializer(onRetired)` 接入。
