## 用法

由 `Root`、`Button` 和 `Separator` 组成：

- **游走焦点**：整条工具栏仅占一个 Tab 入口，使用方向键在已启用的命令按钮之间移动；开启 `loop` 后可在首尾之间循环。
- **命令激活与分隔线**：点击或按键盘激活启用的 `Button` 时，发出包含其 `value` 的 `action` 事件；`Separator` 会自动沿工具栏的交叉轴方向渲染。

## API

| 部件 | 属性 / 事件 | 说明 |
| --- | --- | --- |
| `Root` | `disabled` / `orientation` / `loop` / `a11yLabel` | 禁用、方向、首尾循环与工具栏可访问名称 |
| `Button` | `value` / `action` | 命令标识与激活时发出的 `action` 事件 |
| `Separator` | — | 自动跟随交叉轴方向的分隔线 |
