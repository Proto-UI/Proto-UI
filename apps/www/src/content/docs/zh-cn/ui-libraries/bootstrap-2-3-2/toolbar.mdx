## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可直接从 `@proto.ui/prototypes-bootstrap-2-3-2/toolbar` 导入原型并适配到目标框架：

```ts
import {
  toolbarRoot,
  toolbarButton,
  toolbarSeparator,
} from '@proto.ui/prototypes-bootstrap-2-3-2/toolbar';
```

## 用法

```tsx
import {
  BootstrapToolbarRoot,
  BootstrapToolbarButton,
  BootstrapToolbarSeparator,
} from '../proto-ui/components/react';

export function EditorToolbar() {
  return (
    <BootstrapToolbarRoot a11yLabel="Document actions">
      <BootstrapToolbarButton value="undo">Undo</BootstrapToolbarButton>
      <BootstrapToolbarButton value="redo">Redo</BootstrapToolbarButton>
      <BootstrapToolbarSeparator />
      <BootstrapToolbarButton value="save" variant="primary">
        Save
      </BootstrapToolbarButton>
    </BootstrapToolbarRoot>
  );
}
```

Toolbar 由 `Root`、`Button` 和 `Separator` 三个部件组成：

- **经典按钮质感**：`Button` 保留 Bootstrap 2.3.2 的线性渐变、悬停背景位移与按压内阴影，同时在键盘聚焦时使用清晰的单一焦点环避免双重外框。
- **漫游焦点**：整条工具栏仅保留一个启用命令位于 `Tab` 顺序中，通过方向键在可用命令间移动，`loop={true}`（默认）时支持首尾循环。
- **交叉轴分隔线**：`Separator` 自动根据工具栏方向切换为 1px 纵向或横向分隔线。

### 经典变体与尺寸

支持 Bootstrap 2.3.2 的 `default`、`primary`、`success`、`info`、`warning`、`danger`、`inverse` 按钮变体，以及 `default`、`small`、`mini` 尺寸。

### Separator 与事件

- **Separator**：无额外属性，自动沿工具栏交叉轴方向绘制 1px 分隔线。
- **事件与暴露**：`Button` 激活时发出 `action`（`{ value: string }`）；`Root` 暴露 `disabled`、`focusFirst()`、`focusLast()` 与 `setCurrent(id)`；`Button` 暴露 `disabled`、`focused`、`focusVisible` 与 `focusSelf(options)`。
