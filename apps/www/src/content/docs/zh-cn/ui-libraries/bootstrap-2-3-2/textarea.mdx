Bootstrap 2.3.2 Textarea 将归档版本的经典文本框样式应用于 Base Textarea，在 Web 上渲染单一原生多行编辑器，并在深色宿主中保持经典的归档浅色配色。

## 预览

可编辑发布说明内容、聚焦只读文本框，并与禁用状态对比。

## 用法

- **值与输入事件**：支持受控 `value` 与非受控 `defaultValue`，统一处理 `input`、`change` 与 IME 组合输入事件。
- **行数与换行**：通过 `rows` 和 `wrap` 控制初始显示行数与换行策略。
- **表单字段组合**：如需标签、帮助说明与错误提示，请与 `Field` 组合使用。

## API

| 分类 | 成员 | 说明 |
| --- | --- | --- |
| 值与状态 | `value` / `defaultValue`、`disabled`、`readOnly`、`placeholder` | 多行文本值与编辑状态 |
| 布局与约束 | `rows`、`wrap`、`minLength`、`maxLength`、`name`、`required`、`autoComplete` | 原生多行编辑属性 |
| 无障碍 | `ariaLabel`、`labelledBy`、`describedBy` | 可访问名称与关联说明 |
| 事件与方法 | `valueChange`、`change`、IME 组合事件、`focusSelf()`、`blurSelf()` | 变更通知与焦点控制 |
