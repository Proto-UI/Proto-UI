自定义 Root / Indicator anatomy 将 Bootstrap 2.3.2 的视觉语言用于复选框。它不是归档版本原生 checkbox 的原样复刻，也不引入旧版 Bootstrap JavaScript 或 Glyphicons。

Base Checkbox 拥有受控与非受控 `checked`、`indeterminate`、指针与 Space 激活、禁用、焦点以及带 `mixed` 状态的 `checkbox` 角色。Indicator 从最近的 Root 派生勾号或横线，不拥有第二份值或激活逻辑。mixed 的展示优先于 checked。

通过页面运行时选择器比较 Web Components、React、Vue 3 与 Vue 2。可切换未选中、选中与 mixed 示例，并用 Tab 移到最后一个控件观察键盘焦点。

## API

- Root：`checked` / `defaultChecked`、`indeterminate` / `defaultIndeterminate`、`disabled`
- Root 继承 `checkedChange` 与 `indeterminateChange` 信号
- Indicator：只负责派生展示，放在对应 Root 内
