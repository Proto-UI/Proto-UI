Bootstrap 2.3.2 Checkbox 采用自定义 `Root` / `Indicator` 结构来呈现 Bootstrap 2.3.2 视觉语言，不是归档版本原生 checkbox 的直接复刻，也不依赖旧版 Bootstrap JavaScript 或 Glyphicons。

## 预览

可切换未选中、选中与半选（`mixed`）示例，并按 `Tab` 聚焦最后一个控件查看键盘焦点样式。

## 用法

- **状态由 Root 统一管理**：支持受控与非受控 `checked`、`indeterminate`，处理指针与 `Space` 键激活、禁用、焦点以及带 `mixed` 状态的 `checkbox` 无障碍角色。
- **Indicator**：放置在 `Root` 内部，自动根据所属 `Root` 状态显示勾号或横线；同时为半选和选中时优先显示半选横线。
- **配色说明**：在深色页面中保持经典的归档 Bootstrap 2.3.2 浅色配色。

## API

| 部件 | 属性 / 事件 | 说明 |
| --- | --- | --- |
| `Root` | `checked` / `defaultChecked` | 受控或初始选中状态 |
| `Root` | `indeterminate` / `defaultIndeterminate` | 受控或初始半选（`mixed`）状态 |
| `Root` | `disabled` | 禁用复选框交互 |
| `Root` | `checkedChange` / `indeterminateChange` | 选中与半选状态变更事件 |
| `Indicator` | — | 视觉指示器，放置在 `Root` 内自动跟随状态 |
