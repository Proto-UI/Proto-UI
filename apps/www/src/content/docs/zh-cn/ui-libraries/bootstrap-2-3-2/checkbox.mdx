Bootstrap 2.3.2 Checkbox 采用自定义 `Root` / `Indicator` 结构来呈现 Bootstrap 2.3.2 经典的 14px 斜面渐变控件与蓝色聚焦光晕，不依赖旧版 Bootstrap JavaScript 或 Glyphicons。

## 用法

```tsx
import {
  Bootstrap232CheckboxIndicator,
  Bootstrap232CheckboxRoot,
  Bootstrap232LabelRoot,
} from '@proto.ui/prototypes-bootstrap-2-3-2';

export function Example() {
  return (
    <div className="flex items-center gap-2.5">
      <Bootstrap232CheckboxRoot defaultChecked>
        <Bootstrap232CheckboxIndicator />
      </Bootstrap232CheckboxRoot>
      <Bootstrap232LabelRoot>Accept terms and conditions</Bootstrap232LabelRoot>
    </div>
  );
}
```

- **状态由 Root 统一管理**：支持受控与非受控 `checked`、`indeterminate`，处理指针与 `Space` 键激活、禁用、只读、焦点以及带 `mixed` 状态的 `checkbox` 无障碍角色。
- **Indicator**：放置在 `Root` 内部，自动根据所属 `Root` 状态显示深色勾号或横线；同时为半选和选中时优先显示半选横线。
- **经典视觉反馈**：悬停与按压延续 Bootstrap 2.3.2 斜面渐变响应，聚焦时显示 `#52a8ec` 蓝色外光晕，并在深色页面中保持经典的浅色控件配色。

## API

### Root

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'checked', type: 'boolean | undefined', default: '非受控' },

    { name: 'indeterminate', type: 'boolean | undefined', default: '非受控' },
    { name: 'defaultIndeterminate', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'readOnly', type: 'boolean', default: 'false' },
    { name: 'required', type: 'boolean', default: 'false' },
  ]}
/>

`Root` 暴露 `checked`、`indeterminate`、`disabled`、`readOnly`、`required`、`hovered`、`focused`、`focusVisible`、`pressed` 状态，`focusSelf(options?)` 与 `resetValue()` 方法，以及 `checkedChange`（`{ checked, indeterminate }`）与 `indeterminateChange`（`{ indeterminate }`）事件。

### Indicator

`Indicator` 不声明额外属性，放置在 `Root` 内部自动同步勾选与半选图标，暴露 `checked`、`indeterminate`、`isChecked()` 与 `isIndeterminate()`。
