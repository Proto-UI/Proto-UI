## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可直接从 `@proto.ui/prototypes-bootstrap-2-3-2/navigation-menu` 导入组件原型：

```ts
import {
  navigationMenuRoot,
  navigationMenuTrigger,
  navigationMenuContent,
  navigationMenuItem,
  navigationMenuLink,
} from '@proto.ui/prototypes-bootstrap-2-3-2/navigation-menu';
```

## 用法

```tsx
import {
  Bootstrap232NavigationMenuRoot,
  Bootstrap232NavigationMenuTrigger,
  Bootstrap232NavigationMenuContent,
  Bootstrap232NavigationMenuItem,
  Bootstrap232NavigationMenuLink,
} from '../proto-ui/components/react';

export function ClassicSiteNav() {
  return (
    <Bootstrap232NavigationMenuRoot a11yLabel="Main navigation">
      <Bootstrap232NavigationMenuTrigger value="getting-started">
        Getting started
      </Bootstrap232NavigationMenuTrigger>
      <Bootstrap232NavigationMenuContent value="getting-started" a11yLabel="Getting started">
        <Bootstrap232NavigationMenuLink href="/docs" current>
          Introduction
        </Bootstrap232NavigationMenuLink>
        <Bootstrap232NavigationMenuItem value="download" textValue="Download CSS">
          Download CSS
        </Bootstrap232NavigationMenuItem>
      </Bootstrap232NavigationMenuContent>
    </Bootstrap232NavigationMenuRoot>
  );
}
```

### 结构组成

```text
NavigationMenuRoot (navigation)
├── NavigationMenuTrigger (nav-pills toggle, paired by value)
└── NavigationMenuContent (dropdown-menu region, paired by value)
    ├── NavigationMenuLink (native <a>)
    └── NavigationMenuItem (command action)
```

### 原生链接与键盘交互

- **原生链接行为**：URL 预览、`Enter` 激活与中键/修饰键新标签页打开均由浏览器原生处理。
- **导航观察与关闭**：`Link` 激活后发出只读 `navigate` 事件（`{ href, target, rel, modified }`）；普通同窗激活自动关闭面板（设 `closeOnSelect={false}` 可保持打开），修饰键、中键或 `_blank` 打开则保持当前面板展开。
- **禁用状态**：禁用 `Link` 会清除跳转目标并阻止激活；禁用 `Trigger` 使用经典 `#999` 置灰样式。
