## 用法

由 `Root`、`Trigger`、`Content`、`Item` 和 `Link` 组成：

- **语义结构**：`Root` 声明 `navigation` 地标并通过 `value` 控制当前展开的唯一面板；`Trigger` 负责展开/收起，`Content` 作为带名称的 `region` 区域展示导航项。
- **原生链接与命令项**：`Item` 用于发出动作命令；`Link` 渲染真实原生 `<a>` 链接，完整支持 `href`、`target`、`rel` 及当前页标记 `current`（对应 `aria-current`）。URL 预览、`Enter` 跳转及中键/修饰键打开均由浏览器原生处理。
- **导航观察与关闭**：`Link` 激活后会发出只读的 `navigate` 事件（载荷为 `{ href, target, rel, modified }`）。普通同窗口点击会自动关闭当前面板（设置 `closeOnSelect={false}` 可保持打开）；中键、修饰键或 `_blank` 激活则保持当前面板打开。禁用状态的 `Link` 会移除跳转目标并阻止激活。

## API

| 部件 | 属性 / 事件 | 说明 |
| --- | --- | --- |
| `Root` | `value` | 当前展开的导航面板标识 |
| `Trigger` | — | 切换导航面板的按钮 |
| `Content` | — | 命名导航内容区域 |
| `Item` | — | 导航面板内的命令项 |
| `Link` | `href` / `target` / `rel` / `current` / `disabled` / `closeOnSelect` | 原生锚点链接属性；`current={true}` 标记当前页 |
| `Link` | `navigate` | 原生激活后发出的只读事件，载荷为 `{ href, target, rel, modified }` |
