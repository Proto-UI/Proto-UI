Bootstrap 2.3.2 Dialog 基于 [Base Dialog](../../base/dialog/) 构建，保留经典 `.modal` 的 560px 面板宽度、6px 圆角、300 ms 顶部滑入（`-25% → 10%`）过渡、80% 黑色遮罩与 `.modal-footer` 顶部 `1px` 白色内高光。

## 安装

当前仅在源码工作区中提供（`@proto.ui/prototypes-bootstrap-2-3-2/dialog`），尚未发布为独立稳定包。在工作区中可通过 `proto-ui add <wc|react|vue|vue2> bootstrap-2-3-2-dialog` 生成各宿主包装组件。

## 用法

```tsx
import {
  BootstrapDialogClose,
  BootstrapDialogCloseIcon,
  BootstrapDialogContent,
  BootstrapDialogDescription,
  BootstrapDialogFooter,
  BootstrapDialogHeader,
  BootstrapDialogMask,
  BootstrapDialogRoot,
  BootstrapDialogTitle,
  BootstrapDialogTrigger,
} from '@/components/proto-ui/bootstrap-2-3-2';

export function BootstrapDialogExample() {
  return (
    <BootstrapDialogRoot a11yLabel="Edit profile">
      <BootstrapDialogTrigger>Open Dialog</BootstrapDialogTrigger>
      <BootstrapDialogMask />
      <BootstrapDialogContent>
        <BootstrapDialogHeader>
          <BootstrapDialogTitle>Edit profile</BootstrapDialogTitle>
        </BootstrapDialogHeader>
        <div className="px-[15px] py-[15px]">
          <BootstrapDialogDescription>
            Make changes to your profile here. Click save when you&apos;re done.
          </BootstrapDialogDescription>
        </div>
        <BootstrapDialogFooter>
          <BootstrapDialogClose>Close</BootstrapDialogClose>
        </BootstrapDialogFooter>
        <BootstrapDialogCloseIcon />
      </BootstrapDialogContent>
    </BootstrapDialogRoot>
  );
}
```

### 组合结构

```text
BootstrapDialogRoot
├── BootstrapDialogTrigger
├── BootstrapDialogMask
└── BootstrapDialogContent
    ├── BootstrapDialogHeader
    │   └── BootstrapDialogTitle
    ├── BootstrapDialogDescription
    ├── BootstrapDialogFooter
    │   └── BootstrapDialogClose
    └── BootstrapDialogCloseIcon
```

### 视觉与交互特性

- **经典入场动效**：`Content` 沿用 Bootstrap 2.3.2 `.modal.fade` 的 300 ms 透明度与顶部 `-25% → 10%` 平滑下滑，`Mask` 使用 150 ms 淡入至 80% 不透明度。
- **层级与结构**：`Mask` 与 `Content` 分别声明 `z-40` 与 `z-50`；`Header` 提供 `9px 15px` 内边距与底部分割线，`Footer` 保留浅灰背景与 `inset 0 1px 0 #fff` 顶部高光。
- **焦点与无障碍**：自动管理模态焦点陷阱、焦点归还、`Escape` / 点击外部关闭，以及 `aria-labelledby` / `aria-describedby` 关联。
