## 用法

### 显式配对关联

Label 不依赖 DOM 嵌套或全局 ID 查找，而是通过 `@proto.ui/core` 的 `createControlLabelRef()` 为每一对标签与控件创建稳定引用：

- **React / Vue / Vue 2**：向 Label 和目标控件同时传入 `instanceAssociations: { controlLabel: ref }`。
- **Web Components**：使用 `@proto.ui/adapter-web-component` 导出的 `setElementAssociations(target, { controlLabel: ref })` 分别绑定到控件和 Label。

每个引用仅绑定一个在线 Label 与一个在线目标控件，且在 Web 中需位于同一 Document 与 Shadow Tree 内；缺失或重复绑定时会忽略非法配置并保持当前状态。

### 独立控制命名与激活

- **`naming`（默认 `true`）**：目标控件通过无障碍关系引用该 Label 作为名称，无需再额外书写重复的隐藏标签。若目标控件已显式提供非空 `ariaLabel` / `labelledBy`，则会保留其原有命名；此时可将 Label 设为 `naming={false}` 仅用于点击激活。
- **`activation`（默认 `true`）**：点击已配对的 Label 会触发目标控件的既有行为（例如切换 Checkbox/Switch、选中 Radio Item 或聚焦 Input/Textarea）。如只需被动命名、不希望点击触发控件，显式设置 `activation={false}`。
- **文本选择与交互保护**：Label 不增加额外 Tab 停靠点，不会转发嵌套链接/按钮、拖拽、取消或带修饰键的点击。`selection="policy"` 可防止短操作标签在点击时误选文字；需要允许复制时设置 `selection="text"`。

## API

| 属性 / 辅助方法 | 默认值 | 说明 |
| --- | --- | --- |
| `naming` | `true` | 是否为关联控件提供无障碍名称 |
| `activation` | `true` | 点击标签时是否触发关联控件的默认操作 |
| `selection` | `'policy'` | 可选 `'policy'`（防误选）或 `'text'`（允许选中复制） |
| `createControlLabelRef()` | — | 从 `@proto.ui/core` 导入，创建一对一控件关联引用 |
| `instanceAssociations` | — | React / Vue / Vue 2 传入 `{ controlLabel: ref }` 的适配器关联属性 |
| `setElementAssociations()` | — | 从 `@proto.ui/adapter-web-component` 导入，为 Web Components 绑定引用 |
