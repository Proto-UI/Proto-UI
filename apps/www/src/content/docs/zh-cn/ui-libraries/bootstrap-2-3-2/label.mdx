Bootstrap 2.3.2 `Label` 保留经典 `14px / 20px` Helvetica Neue 常规字重排版，并通过显式引用与目标控件配对，可独立控制无障碍命名（`naming`）与点击激活（`activation`）行为。

> 表单输入字段请优先使用 [Field](../field/) 组件，内置 `FieldLabel`、`FieldDescription` 与 `FieldError` 自动关联与校验支持。

## 安装

当前仅在源码工作区提供，可直接从工作区包导入：

```ts
import { labelRoot } from '@proto.ui/prototypes-bootstrap-2-3-2/label';
```

## 用法

通过 `@proto.ui/core` 的 `createControlLabelRef()` 为每对标签与控件创建稳定引用，并通过适配器通道传入：

```tsx
import { useMemo } from 'react';
import { createControlLabelRef } from '@proto.ui/core';
import {
  BootstrapCheckboxIndicator,
  BootstrapCheckboxRoot,
  BootstrapLabelRoot,
} from '../proto-ui/components/react';

export function TermsCheckbox() {
  const termsRef = useMemo(() => createControlLabelRef(), []);

  return (
    <div className="flex items-center gap-2">
      <BootstrapCheckboxRoot instanceAssociations={{ controlLabel: termsRef }}>
        <BootstrapCheckboxIndicator />
      </BootstrapCheckboxRoot>
      <BootstrapLabelRoot instanceAssociations={{ controlLabel: termsRef }}>
        Accept terms and conditions
      </BootstrapLabelRoot>
    </div>
  );
}
```

Web Components 通过 `@proto.ui/adapter-web-component` 的 `setElementAssociations()` 绑定同一引用：

```ts
import { createControlLabelRef } from '@proto.ui/core';
import { setElementAssociations } from '@proto.ui/adapter-web-component';

const termsRef = createControlLabelRef();
setElementAssociations(checkboxEl, { controlLabel: termsRef });
setElementAssociations(labelEl, { controlLabel: termsRef });
```

### 命名、激活与布局

- **`naming`（默认 `true`）**：让目标控件自动引用该 `Label` 作为无障碍名称；若目标已声明非空 `ariaLabel` 或 `labelledBy`，建议设为 `naming={false}` 仅用于点击激活。
- **`activation`（默认 `true`）**：点击已配对的 `Label` 会触发目标控件的默认操作（切换 `Checkbox` / `Switch`、选择 `Radio Group Item` 或聚焦 `Input` / `Textarea`）。如需仅被动命名，请设为 `activation={false}`。
- **`selection`（默认 `'policy'`）**：可激活标签默认防止误选文字；需要支持选中复制时可设为 `selection="text"`，或使用 `'auto'` / `'none'` 显式覆盖。
- **对齐与无障碍**：采用 `inline-flex` 布局且不附加硬编码下外边距，既能与行内勾选框垂直居中对齐，也便于在垂直表单容器中按容器间距排布；不增加额外 `Tab` 停靠点，并过滤嵌套交互元素、修饰键点击与拖拽。

### 关联辅助接口

- `createControlLabelRef()`：从 `@proto.ui/core` 导入，创建一对一控件关联引用。
- `instanceAssociations`：React / Vue / Vue 2 传入 `{ controlLabel: ref }` 的适配器关联属性。
- `setElementAssociations(element, { controlLabel: ref })`：从 `@proto.ui/adapter-web-component` 导入，为 Web Components 绑定引用。
