## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可直接从 `@proto.ui/prototypes-bootstrap-2-3-2/toggle-group` 导入组件原型并通过对应宿主 Adapter 适配。

## 用法

```tsx
import { BootstrapToggleGroupItem, BootstrapToggleGroupRoot } from '../proto-ui/components/react';

export function Example() {
  return (
    <BootstrapToggleGroupRoot defaultValue={['left']} a11yLabel="Text alignment">
      <BootstrapToggleGroupItem value="left">Left</BootstrapToggleGroupItem>
      <BootstrapToggleGroupItem value="middle">Middle</BootstrapToggleGroupItem>
      <BootstrapToggleGroupItem value="right">Right</BootstrapToggleGroupItem>
    </BootstrapToggleGroupRoot>
  );
}
```

### 组件结构

```text
ToggleGroupRoot
├── ToggleGroupItem
└── ToggleGroupItem
```

- **经典拼接几何**：首尾项根据尺寸保留 `4px` / `6px` / `3px` 外侧圆角，中间项保持直角并通过 `-1px` 负边距折叠公共边框；激活、悬停或聚焦项自动抬升层级（`z-[2]`）。
- **单选、多选与键盘**：`value` / `defaultValue` 始终为字符串数组。方向键移动焦点而不切换选中状态，按 `Space` 或 `Enter` 提交切换；传入 `value` 进入受控模式并监听 `valueChange`。
