## 用法

由 `Root` 和 `Item` 组成：

- **单选与多选**：`value` / `defaultValue` 始终为字符串数组。`multiple={false}` 时最多保留一个选中值，再次点击已选中项可清空选择；`multiple={true}` 时允许同时按下多个项。
- **受控与键盘**：受控模式下通过 `valueChange` 通知父组件更新状态。方向键仅在按钮间移动焦点，不自动改变选中状态；禁用、只读以及重复 `value` 的项不可提交。

## API

| 部件   | 属性 / 事件              | 说明                             |
| ------ | ------------------------ | -------------------------------- |
| `Root` | `value` / `defaultValue` | `string[]`，当前按下的按钮值数组 |
| `Root` | `multiple`               | `boolean`，是否允许多选          |
| `Root` | `disabled` / `readOnly`  | 禁用或只读状态                   |
| `Root` | `valueChange`            | 选中值变更请求事件               |
| `Item` | `value` / `disabled`     | 单个切换按钮的值与禁用开关       |
