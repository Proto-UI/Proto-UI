Bootstrap 2.3.2 Hover Card 将 Base Hover Card 的延迟触发与防碰撞定位同 Bootstrap 链接样式、276px 最大宽度、6px 圆角边框、经典投影及 150ms 线性淡入淡出过渡结合起来。

## 预览

悬停或聚焦 `@proto-ui` 150ms 后展开经典 Bootstrap 2.3.2 浮层，指针移入内容区时保持打开。

## 安装

请使用同一工作区版本的 `@proto.ui/prototypes-bootstrap-2-3-2/hover-card` 和目标宿主适配器。下方 React 示例通过 `@proto.ui/adapter-react` 直接适配导出的原型。

## 用法

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import * as proto from '@proto.ui/prototypes-bootstrap-2-3-2/hover-card';

const adapt = createReactAdapter(React);
const BootstrapHoverCardRoot = adapt(proto.hoverCardRoot);
const BootstrapHoverCardTrigger = adapt(proto.hoverCardTrigger);
const BootstrapHoverCardContent = adapt(proto.hoverCardContent);

export function Example() {
  return (
    <BootstrapHoverCardRoot openDelay={150} closeDelay={250}>
      <BootstrapHoverCardTrigger>@proto-ui</BootstrapHoverCardTrigger>
      <BootstrapHoverCardContent side="bottom" align="center" sideOffset={6}>
        Host-neutral interaction protocols rendered with Bootstrap 2.3.2 popover chrome.
      </BootstrapHoverCardContent>
    </BootstrapHoverCardRoot>
  );
}
```

### 结构组成与样式细节

```text
BootstrapHoverCardRoot
├── BootstrapHoverCardTrigger
└── BootstrapHoverCardContent
```

- 触发器默认使用 Bootstrap 2.3.2 的 `#08c` 链接色。浅色与深色主题下，悬停或聚焦时均使用主题前景色和下划线。
- 浮层面板保留归档 `.popover` 尺寸参数（`max-width: 276px`、`border-radius: 6px`、内层 `9px 14px` 留白）及 `150ms` 线性透明度过渡。
