Toast 以经典 Bootstrap 2.3.2 `.alert` 视觉样式呈现简短的非阻塞通知，支持自动倒计时关闭、鼠标悬停或焦点进入时暂停计时，以及经典的右上角 `×` 关闭与链接操作按钮。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可直接从 `@proto.ui/prototypes-bootstrap-2-3-2/toast` 导入组件原型并使用对应宿主 Adapter 适配。

```ts
import {
  toastViewport,
  toastRoot,
  toastTitle,
  toastDescription,
  toastAction,
  toastClose,
} from '@proto.ui/prototypes-bootstrap-2-3-2/toast';
```

## 用法

沿用 Bootstrap 2.3.2 `.alert` 标记约定，将 `Close`（`×`）放在 `Root` 内的第一位，以对齐右侧浮动偏移：

```tsx
<Bootstrap232ToastViewport a11yLabel="Notifications">
  <Bootstrap232ToastRoot defaultOpen={false} duration={5000}>
    <Bootstrap232ToastClose>×</Bootstrap232ToastClose>
    <Bootstrap232ToastTitle>Event has been created</Bootstrap232ToastTitle>
    <Bootstrap232ToastDescription>Sunday, December 03, 2023 at 9:00 AM</Bootstrap232ToastDescription>
    <Bootstrap232ToastAction a11yLabel="Undo event creation">Undo</Bootstrap232ToastAction>
  </Bootstrap232ToastRoot>
</Bootstrap232ToastViewport>
```

- **定时与暂停**：`Root` 默认显示 `5000ms` 后请求关闭；设置 `duration={0}` 可保持常驻显示。鼠标悬停在通知上，或焦点位于 `Action` / `Close` 上时，自动暂停剩余倒计时。
- **操作与关闭**：点击 `Close`、聚焦通知时按 `Escape` 或点击 `Action` 都会请求关闭通知；`Action` 对应的业务逻辑由应用监听处理。受控 `open` 模式下，超时后仅发出一次关闭请求并等待父组件更新。
- **快捷聚焦**：`Viewport` 支持按 `F8` 快速将焦点移至通知区域。全局队列编排由应用层自行管理。

事件与暴露方法：

- **事件**：`Root` 暴露 `openChange`（`{ open: boolean; reason: string }`）；`Action` 暴露 `action`（`void`）。
- **方法**：`Root` 暴露 `openToast()`、`close(reason?)`、`pause()`、`resume()`；`Viewport` 暴露 `focusFirst()`。
