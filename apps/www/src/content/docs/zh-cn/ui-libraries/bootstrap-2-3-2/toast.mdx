Toast 用于展示简短的非阻塞通知，支持自动倒计时关闭、鼠标悬停或焦点进入时自动暂停计时，以及明确的操作与关闭按钮。

## 用法

由 `Root`、`Viewport`、`Title`、`Description`、`Action` 和 `Close` 组成：

- **定时与暂停**：`Root` 默认显示 `5000ms` 后请求关闭；设置 `duration={0}` 可保持常驻显示。鼠标悬停在通知上，或焦点位于 `Action` / `Close` 上时，自动暂停剩余倒计时。
- **操作与关闭**：点击 `Close`、聚焦通知时按 `Escape` 或点击 `Action` 都会请求关闭通知；`Action` 对应的业务逻辑由应用监听处理。受控 `open` 模式下，超时后仅发出一次关闭请求并等待父组件更新。
- **快捷聚焦**：`Viewport` 支持按 `F8` 快速将焦点移至通知区域。全局队列编排由应用层自行管理。

## API

| 部件                    | 属性       | 默认值 | 说明                                          |
| ----------------------- | ---------- | ------ | --------------------------------------------- |
| `Root`                  | `open`     | —      | 受控显示状态                                  |
| `Root`                  | `duration` | `5000` | 自动关闭延时（毫秒）；设为 `0` 常驻不自动关闭 |
| `Viewport`              | —          | —      | 通知展示区域，支持 `F8` 快捷键聚焦            |
| `Title` / `Description` | —          | —      | 通知标题与正文说明                            |
| `Action` / `Close`      | —          | —      | 操作按钮与关闭按钮                            |
