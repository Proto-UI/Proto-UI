
## 用法

由 `Root`、`List`、`Trigger` 和 `Content` 组成：

- **状态与激活模式**：状态由 `Root` 统一管理，支持受控 `value` 与非受控 `defaultValue`。方向键与 `Home` / `End` 在可用标签间移动焦点；手动激活模式下（`activationMode="manual"`），按 `Enter` / `Space` 才会切换内容面板，适合避免在浏览标签时频繁卸载重挂面板。
- **外观变体**：`List` 与 `Trigger` 默认使用 Bootstrap 2.3.2 经典标签页外观，也可设置 `appearance="underline"` 切换为透明背景、与文字等宽的细下划线样式。
- **内容挂载**：未选中面板默认卸载内容节点；在 `Content` 上设置 `keepMounted` 可在切换时保留隐藏节点。

## API

| 部件      | 属性                                | 说明                                          |
| --------- | ----------------------------------- | --------------------------------------------- |
| `Root`    | `value` / `defaultValue`            | 受控或初始选中标签值                          |
| `Root`    | `activationMode` / `orientation`    | 切换激活模式（自动/手动）与标签栏方向         |
| `List`    | `appearance`                        | 可选 `'underline'` 切换为细下划线风格         |
| `Trigger` | `value` / `disabled` / `appearance` | 标签标识、禁用状态与外观变体                  |
| `Content` | `value` / `keepMounted`             | 对应面板标识；设置 `keepMounted` 保留隐藏节点 |
