Bootstrap 2.3.2 Tabs 沿用经典 Bootstrap 2.3.2 `nav-tabs` 的固定像素度量（`12px`/`8px` 内边距、`4px` 顶部/左侧圆角、`14px`/`20px` 字号与 `#08c`/`#005580` 链接态），同时适配暗色主题并基于 [Base Tabs](/zh-cn/ui-libraries/base/tabs/) 提供完整的键盘导航与受控切换能力。

## 安装

当前在源码工作区提供，可直接从 `@proto.ui/prototypes-bootstrap-2-3-2/tabs` 导入。

```ts
import {
  tabsRoot,
  tabsList,
  tabsTrigger,
  tabsContent,
  tabsIndicator,
} from '@proto.ui/prototypes-bootstrap-2-3-2/tabs';
```

## 用法

```html
<wc-bootstrap-2-3-2-tabs-root default-value="overview">
  <wc-bootstrap-2-3-2-tabs-list>
    <wc-bootstrap-2-3-2-tabs-trigger value="overview">Overview</wc-bootstrap-2-3-2-tabs-trigger>
    <wc-bootstrap-2-3-2-tabs-trigger value="analytics">Analytics</wc-bootstrap-2-3-2-tabs-trigger>
  </wc-bootstrap-2-3-2-tabs-list>
  <wc-bootstrap-2-3-2-tabs-content value="overview"
    >Overview content.</wc-bootstrap-2-3-2-tabs-content
  >
  <wc-bootstrap-2-3-2-tabs-content value="analytics"
    >Analytics content.</wc-bootstrap-2-3-2-tabs-content
  >
</wc-bootstrap-2-3-2-tabs-root>
```

### 组件结构

```text
TabsRoot
├── TabsList
│   ├── TabsTrigger
│   └── TabsTrigger
├── TabsContent
└── TabsContent
```

- **状态与键盘导航**：由 `Root` 统一管理受控 `value` 或非受控 `defaultValue`；方向键与 `Home` / `End` 在可用标签间移动焦点，手动模式（`activationMode="manual"`）下按 `Enter` / `Space` 确认切换。
- **暗色适配**：亮色模式保留经典 `#ddd` 边框与 `#08c` / `#005580` / `#555` 配色，暗色模式自动映射到主题语义变量确保可读对比度。
