Surface 是纯视觉展示表面组件，基于 [Base Surface](/zh-cn/ui-libraries/base/surface/) 提供 Bootstrap 2.3.2 风格的 4px 圆角、缩略图边框、经典渐变按钮外观与蓝色导航栏上下文适配，所有交互与语义状态均由外层控件负责。

## 安装

当前通过源码工作区包 `@proto.ui/prototypes-bootstrap-2-3-2/surface`（或包根）提供，暂未发布到公共 CLI 目录。

## 用法

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { surfaceRoot } from '@proto.ui/prototypes-bootstrap-2-3-2/surface';

const Surface = createReactAdapter(React)(surfaceRoot);

export function Summary() {
  return (
    <Surface variant="outline" elevation="raised">
      <div className="p-4">Saved locally</div>
    </Surface>
  );
}
```

### 外观属性与组合原则

- `hovered`、`focusVisible`、`pressed` 与 `current` 均由外层交互控件传入；Surface 不注册事件监听或无障碍角色。内部嵌套 `Text` 时可设置 `tone="inherit"` 继承文字色。
- `actionProfile="button"` 启用被动 `.btn` / `.btn-primary` 渐变外观（`solid` 对应主色按钮，其余非透明变体对应默认按钮）。
- `colorContext="navbar"` 仅在 `variant="transparent"` 且 `actionProfile="none"` 时生效，为蓝色导航栏提供白色文字、半透明悬停/按下反馈与白色焦点环。
- 开启 `fade` 后，Surface 会将来自 [Transition](/zh-cn/ui-libraries/base/transition/) 的 `transitionState` 映射为透明度（`closed` / `leaving` 为 `0`，`entering` / `entered` 为 `1`），读取 `--pui-surface-transition-duration`（默认 `0ms`）。
