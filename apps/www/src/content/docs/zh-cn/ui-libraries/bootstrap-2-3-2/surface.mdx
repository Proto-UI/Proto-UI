Surface 是纯视觉展示表面组件，基于 [Base Surface](/zh-cn/ui-libraries/base/surface/) 提供 Bootstrap 2.3.2 风格的边框、背景、圆角与层级样式。它不承担按钮、链接或导航等交互逻辑，所有交互与语义状态均由外层或原生控件提供。

## 预览

示例通过传入静态状态展示不同变体以及聚焦/按压外观，包含用于顶部蓝色导航栏的 `colorContext="navbar"` 与按钮外观 `actionProfile="button"` 对比。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { surfaceRoot } from '@proto.ui/prototypes-bootstrap-2-3-2/surface';

const Surface = createReactAdapter(React)(surfaceRoot);

export function Summary() {
  return (
    <Surface variant="muted" radius="md" border="none">
      <div style={{ padding: '1rem' }}>Saved locally</div>
    </Surface>
  );
}
```

## 用法

- **被动展示边界**：`hovered`、`focusVisible`、`pressed` 与 `current` 均作为视觉输入由外部传入，Surface 本身不监听事件，也不设置 ARIA 角色或 Tab 焦点。需要真实交互控件时，请使用 `Button` 或原生 `<a>` 等语义元素包裹或组合。内部嵌套 `Text` 时可设置 `tone="inherit"` 继承外层文字色。
- **Bootstrap 2.3.2 专属外观属性**：
  - `actionProfile="button"`：切换为静态按钮视觉样式（交互仍由外层语义控件处理）。
  - `colorContext="navbar"`：在 `variant="transparent"` 且 `actionProfile="none"` 时，为蓝色导航栏上的透明项提供白色文字与白色焦点环；普通面板或按钮外观会自动忽略此项。
- **配合 Transition 淡入淡出**：设置 `fade={true}` 并传入来自 [Transition](/zh-cn/ui-libraries/base/transition/) 的 `transitionState` 时，`closed` / `leaving` 映射为透明，`entering` / `entered` 映射为不透明。可通过 CSS 变量 `--pui-surface-transition-duration`（默认 `0ms`）传递过渡时长。透明度为 `0` 仅影响视觉，显示隐藏与焦点管理仍由外层组件控制。

## API

| 属性 | 可选值 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `variant` | `transparent` \| `outline` \| `secondary` \| `muted` \| `accent` \| `solid` \| `scrim` | `outline` | 背景与前景色变体 |
| `radius` | `default` \| `none` \| `sm` \| `md` \| `lg` \| `xl` \| `full` | `default` | 圆角档位 |
| `border` | `all` \| `bottom` \| `none` | `all` | 边框样式 |
| `elevation` | `none` \| `raised` | `none` | 阴影层级 |
| `transitionState` | `closed` \| `entering` \| `entered` \| `leaving` | `entered` | 来自外层 Transition 的阶段状态 |
| `fade` | `boolean` | `false` | 启用基于 `transitionState` 的透明度切换 |
| `hovered` / `focusVisible` / `pressed` / `current` | `boolean` | `false` | 外部传入的视觉状态 |
| `actionProfile` | `none` \| `button` | `none` | Bootstrap 2.3.2 专属：启用被动按钮外观 |
| `colorContext` | `default` \| `navbar` | `default` | Bootstrap 2.3.2 专属：适配蓝色导航栏的白色文字与焦点环 |
