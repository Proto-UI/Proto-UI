## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

```ts
import {
  progressRoot,
  progressLabel,
  progressTrack,
  progressIndicator,
  progressValue,
} from '@proto.ui/prototypes-bootstrap-2-3-2/progress';
```

## 用法

由 `Root`、`Label`、`Track`、`Indicator` 和 `Value` 组成：

- **确定与不确定进度**：`Root` 将 `value` 钳制在 `min`（默认 `0`）至 `max`（默认 `100`）之间；当 `min === max` 时比例为 `0`。省略 `value` 或设置 `indeterminate={true}` 进入不确定进度态，此时不向辅助技术上报具体进度百分比。
- **只读展示**：`Label` 提供无障碍名称，`Track` 与 `Indicator` 渲染进度条，`Value` 优先显示 `valueText` 或规范数值。作为被动显示组件，不引入键盘焦点停靠点。

## API

| 部件 | 属性 / 状态 | 说明 |
| --- | --- | --- |
| `Root` | `value` / `min` / `max` | 当前进度与范围上下界（默认 `0`–`100`） |
| `Root` | `indeterminate` | 设为 `true`（或省略 `value`）表示不确定进度 |
| `Root` | `ariaLabel` / `valueText` | 可访问名称与自定义进度文本 |
| 全部部件 | `value` / `percentage` / `indeterminate` / `status` | 同步暴露的只读进度状态 |
| `Label` / `Track` / `Indicator` / `Value` | — | 名称、轨道、进度填充条与数值显示部件 |
