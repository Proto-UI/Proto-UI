Bootstrap 2.3.2 Progress 保留了经典 20px 高度、4px 圆角、内阴影轨道、纵向渐变填充与 600ms 宽度平滑过渡，同时完整复用 Base Progress 的确定进度与不确定态语义。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `@proto.ui/prototypes-bootstrap-2-3-2/progress` 导入全部部件：

```ts
import {
  progressRoot,
  progressLabel,
  progressTrack,
  progressIndicator,
  progressValue,
} from '@proto.ui/prototypes-bootstrap-2-3-2/progress';
```

## 用法

由 `Root`、`Label`、`Track`、`Indicator` 与 `Value` 组成；将 `Label` 和 `Value` 放在 `Track` 之前可在轨道上方水平对齐显示：

```tsx
<Bootstrap232ProgressRoot variant="success" value={60} valueText="60%" className="w-full max-w-sm">
  <Bootstrap232ProgressLabel>Upload progress</Bootstrap232ProgressLabel>
  <Bootstrap232ProgressValue />
  <Bootstrap232ProgressTrack>
    <Bootstrap232ProgressIndicator />
  </Bootstrap232ProgressTrack>
</Bootstrap232ProgressRoot>
```

```text
ProgressRoot
├── ProgressLabel
├── ProgressValue
└── ProgressTrack
    └── ProgressIndicator
```

- **经典语义变体**：`Root` 与 `Indicator` 支持 `default`、`info`、`success`、`warning` 与 `danger` 五种 Bootstrap 2.3.2 渐变配色，并沿用 `600ms ease` 宽度过渡（自动遵循系统减少动效偏好）。
- **确定与不确定态**：`value` 限制在 `[min, max]` 之间（`min === max` 时比例为 `0`）。省略 `value` 或将 `indeterminate` 设为 `true` 时进入不确定加载态，不向辅助技术上报具体当前值。
- **只读无障碍**：Progress 为被动展示组件，不引入键盘焦点停靠点；全部部件同步暴露 `value`、`percentage`、`indeterminate` 与 `status`。

### Indicator 与暴露状态

- `ProgressIndicator` 支持可选的 `variant`（`'default' | 'info' | 'success' | 'warning' | 'danger' | 'inherit'`，默认 `'inherit'`）以局部覆盖 `Root` 的配色变体。
- 全部部件同步暴露只读状态 `value`、`percentage`、`indeterminate` 与 `status`。
