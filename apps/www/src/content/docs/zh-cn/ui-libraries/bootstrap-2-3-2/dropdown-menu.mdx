Dropdown Menu 通过经典 Bootstrap 2.3.2 斜面渐变按钮触发展开一组操作菜单，支持分组标题、分隔线、快捷键提示、危险操作样式与完整键盘导航。

## 安装

当前仅在源码工作区提供，可直接从 `@proto.ui/prototypes-bootstrap-2-3-2/dropdown` 导入全部部件。

## 用法

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuGroup,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuSeparator,
  DropdownMenuShortcut,
  DropdownMenuTrigger,
} from '@/components/bootstrap-2-3-2/dropdown-menu';
```

```tsx
<DropdownMenu>
  <DropdownMenuTrigger>Open</DropdownMenuTrigger>
  <DropdownMenuContent align="start">
    <DropdownMenuGroup>
      <DropdownMenuLabel>My Account</DropdownMenuLabel>
      <DropdownMenuItem value="profile">
        Profile
        <DropdownMenuShortcut>⇧⌘P</DropdownMenuShortcut>
      </DropdownMenuItem>
      <DropdownMenuItem value="billing">Billing</DropdownMenuItem>
    </DropdownMenuGroup>
    <DropdownMenuSeparator />
    <DropdownMenuItem value="logout">Log out</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```

- **分组与装饰部件**：`Group` 与 `Label` 自动建立无障碍分组命名关联；`Separator` 与 `Shortcut` 均为被动展示部件，不进入键盘焦点队列，`Shortcut` 仅展示快捷键文本。
- **经典视觉投射**：触发器保留 Bootstrap 2.3.2 渐变斜面与内嵌下拉三角；菜单项悬停与激活时呈现经典蓝色（或危险操作红色）渐变高亮。

## 示例

### 危险操作

在不可逆操作上设置 `variant="destructive"`，在激活或悬停时呈现 Bootstrap 2.3.2 经典危险渐变高亮。
