## 用法

- **分组与装饰部件**：使用 `Group` 和 `Label` 将相关操作分组并自动建立无障碍命名关联；使用 `Separator` 分隔区域，使用 `Shortcut` 展示快捷键提示。
- **装饰性提示**：`Separator` 与 `Shortcut` 均为被动展示部件，不参与键盘焦点顺序；`Shortcut` 仅用于显示快捷键文字，不会自动注册全局热键。
- 示例展示了一个宽度为 `160px` 的菜单，包含账户与资源两个分组以及禁用的 API 项。

## API

| 部件        | 说明                             |
| ----------- | -------------------------------- |
| `Group`     | 将相关菜单项归为一组并关联组标签 |
| `Label`     | 菜单分组的只读标题               |
| `Separator` | 分隔菜单分组的视觉分割线         |
| `Shortcut`  | 展示在菜单项右侧的快捷键提示文本 |
