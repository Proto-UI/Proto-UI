## 用法

- **数据与槽位**：应用传入的每条记录都需要唯一的 `id`。正文行（`DataTableRow`）按当前页 `index` 顺序呈现，每个单元格按 `columnKey` 渲染对应记录字段；排序时会直接更新单元格数据，保持真实的 DOM 表格顺序。
- **表头排序**：将可排序表头放在 `DataTableHeaderRow` 内，以保持独立的表头语义并支持多个排序触发器；正文数据行继续使用 `DataTableRow`。
- **职责边界**：数据请求、行内编辑和列拖拽重排由应用层自行管理。

## API

| 部件 / 属性          | 说明                                          |
| -------------------- | --------------------------------------------- |
| `DataTableHeaderRow` | 静态表头行容器，用于放置可排序列头            |
| `DataTableRow`       | 当前页的数据行槽位，通过 `index` 绑定对应记录 |
| `id` / `columnKey`   | 每条记录的唯一标识与单元格列键名              |
