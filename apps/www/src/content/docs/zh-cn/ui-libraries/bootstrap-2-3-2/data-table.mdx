Data Table 在标准表格结构上提供稳定排序、全局与按列筛选、列显隐、分页以及行/整页选择能力，保留 Bootstrap 2.3.2 经典的 `8px` 单元格内边距、水平分隔线、`.info` 选中色与渐变 `.btn` 翻页控件。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。

## 用法

```tsx
import {
  Bootstrap232DataTableCaption,
  Bootstrap232DataTableCell,
  Bootstrap232DataTableHeader,
  Bootstrap232DataTableHeaderRow,
  Bootstrap232DataTableNext,
  Bootstrap232DataTablePrevious,
  Bootstrap232DataTableRoot,
  Bootstrap232DataTableRow,
} from '../proto-ui/components/react';

const rows = [
  { id: 'm5gr84i9', status: 'Success', email: 'ken99@example.com', amount: 316 },
  { id: '3u1reuv4', status: 'Success', email: 'abe45@example.com', amount: 242 },
];

export function Example() {
  return (
    <Bootstrap232DataTableRoot rows={rows} pageSize={4}>
      <Bootstrap232DataTableCaption>Recent payments.</Bootstrap232DataTableCaption>
      <Bootstrap232DataTableHeaderRow>
        <Bootstrap232DataTableHeader headerKey="status">Status</Bootstrap232DataTableHeader>
        <Bootstrap232DataTableHeader headerKey="email">Email</Bootstrap232DataTableHeader>
        <Bootstrap232DataTableHeader headerKey="amount" className="text-right">
          Amount
        </Bootstrap232DataTableHeader>
      </Bootstrap232DataTableHeaderRow>
      {[0, 1].map((index) => (
        <Bootstrap232DataTableRow key={index} index={index}>
          <Bootstrap232DataTableCell columnKey="status" headers={['status']} />
          <Bootstrap232DataTableCell columnKey="email" headers={['email']} />
          <Bootstrap232DataTableCell
            columnKey="amount"
            headers={['amount']}
            className="text-right"
          />
        </Bootstrap232DataTableRow>
      ))}
      <div className="table-caption caption-bottom">
        <div className="flex justify-end gap-2 pt-3">
          <Bootstrap232DataTablePrevious>Previous</Bootstrap232DataTablePrevious>
          <Bootstrap232DataTableNext>Next</Bootstrap232DataTableNext>
        </div>
      </div>
    </Bootstrap232DataTableRoot>
  );
}
```

### 结构与交互说明

- **数据与槽位**：传入 `rows` 时每条记录需提供唯一 `id`。正文行（`DataTableRow`）按当前页 `index` 呈现，单元格通过 `columnKey` 读取字段；隐藏列与空行槽会自动移除 `table-row` / `table-cell` 显示样式以保持准确折叠。
- **表头排序与悬停**：将排序表头置于 `DataTableHeaderRow` 中，悬停与当前排序列采用经典浅灰背景高亮，数据行选中时采用 Bootstrap 2.3.2 的 `.info` 配色。

### 事件、方法与暴露状态

- **事件（Root）**：`sortChange`、`pageChange`、`selectionChange`。
- **方法（Root）**：`getRows()`、`getRecord(id)`、`getSelectedKeys()`、`requestSort(key)`、`requestPage(next)`、`requestSelection(id)`、`requestPageSelection(selected?)`。
- **暴露状态**：Root 暴露 `filteredCount`、`pageSelection`；Row 暴露 `rowKey`、`selected`、`focused`、`focusVisible`；Header 暴露 `sort`；Cell 暴露 `displayValue`。
