## 用法

由 `Root`、`Trigger`、`Content` 和 `Item` 组成：

- **触发与定位**：右键或触摸/手写笔长按（在移动容差内保持 `600ms`）会在指针位置打开菜单；`ContextMenu` / `Shift+F10` 或调用 `openContextMenu()` 时以触发区域作为锚点（默认 `bottom`/`start` 对齐）。普通左键点击与滚动仍由页面正常处理。
- **原生菜单处理**：当启用的 `Root` 接受触发请求时，会自动阻止浏览器默认右键菜单；长按触发同时阻止后续兼容点击事件。拖动、抬起、禁用或卸载都会取消进行中的长按。
- **受控模式**：传入 `open` 进入受控模式，由父组件决定是否打开；按 `Escape` 或选择命令项后会按焦点策略将焦点交回触发器。

## API

| 部件      | 属性 / 方法            | 说明                                                    |
| --------- | ---------------------- | ------------------------------------------------------- |
| `Root`    | `open` / `defaultOpen` | 受控或初始展开状态                                      |
| `Root`    | `disabled`             | 禁用上下文菜单触发                                      |
| `Root`    | `closeOnItemCommit`    | 激活菜单项后是否自动关闭                                |
| `Root`    | `openContextMenu()`    | 以触发区域为锚点编程式打开菜单                          |
| `Trigger` | —                      | 响应右键、长按与 `ContextMenu` / `Shift+F10` 的触发区域 |
| `Content` | —                      | 悬浮菜单面板，支持方向键导航与文字跳转                  |
| `Item`    | —                      | 单个可执行菜单命令                                      |
