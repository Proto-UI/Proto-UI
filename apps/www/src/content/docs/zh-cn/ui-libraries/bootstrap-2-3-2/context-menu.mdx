Bootstrap 2.3.2 Context Menu 在右键点击、触摸/手写笔长按（600 ms）或按下 `ContextMenu` / `Shift+F10` 时打开经典 `dropdown-menu` 风格的上下文命令菜单（6px 圆角、半透明边框投影、经典蓝色渐变高亮），并内置键盘导航与首字母跳转。

## 用法

```tsx
import {
  BootstrapContextMenuContent,
  BootstrapContextMenuItem,
  BootstrapContextMenuRoot,
  BootstrapContextMenuTrigger,
} from '@/components/proto-ui';

export function Example() {
  return (
    <BootstrapContextMenuRoot>
      <BootstrapContextMenuTrigger className="flex h-36 w-72 items-center justify-center rounded border border-dashed border-border bg-secondary text-sm">
        Right click here
      </BootstrapContextMenuTrigger>
      <BootstrapContextMenuContent>
        <BootstrapContextMenuItem value="back">Back</BootstrapContextMenuItem>
        <BootstrapContextMenuItem value="forward" disabled>Forward</BootstrapContextMenuItem>
        <BootstrapContextMenuItem value="reload">Reload</BootstrapContextMenuItem>
      </BootstrapContextMenuContent>
    </BootstrapContextMenuRoot>
  );
}
```

### 部件结构

```text
ContextMenuRoot
├── ContextMenuTrigger
└── ContextMenuContent
    ├── ContextMenuItem
    └── ContextMenuItem
```

- **触发与定位**：右键与长按锚定在指针位置；`ContextMenu` / `Shift+F10` 或调用 `openContextMenu()` 时锚定在触发区域，并自动阻止原生右键菜单。
- **经典视觉与受控模式**：保留 Bootstrap 2.3.2 的零时长即时开关与蓝色线性渐变高亮；传入 `open` 进入受控模式，按 `Escape` 或选中命令后焦点自动回到触发区域。
