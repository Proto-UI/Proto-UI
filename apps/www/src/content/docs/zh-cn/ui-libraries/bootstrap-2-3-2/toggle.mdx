Bootstrap 2.3.2 Toggle 是一项设计语言扩展（design-language extension），不是 Bootstrap 2.3.2 的原版组件。它将归档按钮外观与独立的 Base Toggle 协议结合，提供持久的按下/未按下双态切换，并在深色宿主中保持经典的归档浅色配色。

## 预览

示例中 Bold 初始未激活，Italic 初始激活，第三个禁用按钮无法切换。

## 用法

- 支持受控 `active` 与非受控 `defaultActive`，统一处理点击、键盘激活、禁用状态与 `aria-pressed` 无障碍信息。
- 如需一组互斥或多选的切换按钮，请使用 [ToggleGroup](/zh-cn/ui-libraries/bootstrap-2-3-2/toggle-group/)。

## API

| 属性 / 事件                | 说明               |
| -------------------------- | ------------------ |
| `active` / `defaultActive` | 受控或初始激活状态 |
| `disabled`                 | 禁用按钮交互       |
| `activeChange`             | 激活状态变更事件   |
