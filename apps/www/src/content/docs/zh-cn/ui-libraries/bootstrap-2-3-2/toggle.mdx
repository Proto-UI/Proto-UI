Bootstrap 2.3.2 Toggle 将经典 Bootstrap 2.3.2 按钮渐变与下凹阴影外观结合到独立的 Base Toggle 双态协议之上，提供持久的按下/未按下切换状态，并在深色页面中保持一致的经典按钮配色。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。[查看已实现的组件子集](../)。

## 用法

```tsx
import { BootstrapToggle } from '../proto-ui/components/react';
```

```tsx
<BootstrapToggle variant="primary" defaultActive>
  Bold
</BootstrapToggle>
```

- **经典变体与尺寸**：支持 Bootstrap 2.3.2 的七种配色变体（`default`、`primary`、`success`、`info`、`warning`、`danger`、`inverse`）以及四档像素尺寸（`mini`、`small`、`default`、`large`）。
- **受控与非受控**：支持受控 `active` 与非受控 `defaultActive`，统一处理点击、`Enter` / `Space` 激活、禁用状态与 `aria-pressed` 无障碍语义。
- **分组切换**：如需一组互斥或多选的切换按钮，请使用 [Toggle Group](/zh-cn/ui-libraries/bootstrap-2-3-2/toggle-group/)。

## API

以下属性属于 `Root`（传入 `active` 进入受控模式）：

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'active', type: 'boolean | undefined', default: '非受控' },
    { name: 'defaultActive', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    {
      name: 'variant',
      type: "'default' | 'primary' | 'warning' | 'danger' | 'success' | 'info' | 'inverse'",
      default: "'default'",
    },
    { name: 'size', type: "'default' | 'large' | 'small' | 'mini'", default: "'default'" },
  ]}
/>

- **事件**：`activeChange`（载荷 `{ active: boolean }`）。
- **方法**：`focusSelf(options?)`（禁用态忽略）。
- **暴露状态**：`active`、`disabled`、`hovered`、`focused`、`focusVisible`、`pressed`。
