此 Toggle 是设计语言扩展（design-language extension），不是 Bootstrap 2.3.2 的原版组件，也不是其 jQuery button plugin 的移植。它将归档按钮外观与独立的 Base Toggle 协议组合。

Base Toggle 拥有持久 `active` 状态、受控与非受控值归属、激活、禁用、焦点与按压态无障碍信息。视觉层不维护第二份 active 状态，也不将此控件解释成 Switch 或 Checkbox。

通过页面运行时选择器比较 Web Components、React、Vue 3 与 Vue 2。Bold 初始未激活，Italic 初始激活，禁用示例无法切换。

## API

- `active` / `defaultActive`：受控值或初始激活状态
- `disabled`：继承的禁用行为
- `activeChange`：继承的 outward signal
