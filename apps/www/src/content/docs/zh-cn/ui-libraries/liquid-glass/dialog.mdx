Liquid Glass Dialog 基于 [Base Dialog](../../base/dialog/) 构建，在悬浮面板上应用 `liquid-glass` 材质、细微边缘高光环、同心胶囊操作按钮与流畅的进出场过渡，并在减少透明度或高对比度环境下自动回退为高可读性不透明表面。

## 安装

当前仅在源码工作区中提供（`@proto.ui/prototypes-liquid-glass/dialog`）。可在工作区中使用 `proto-ui add <wc|react|vue|vue2> liquid-glass-dialog` 生成各宿主包装组件。

## 用法

```tsx
import {
  LiquidGlassDialogClose,
  LiquidGlassDialogContent,
  LiquidGlassDialogDescription,
  LiquidGlassDialogMask,
  LiquidGlassDialogRoot,
  LiquidGlassDialogTitle,
  LiquidGlassDialogTrigger,
} from '@/components/proto-ui/liquid-glass';

export function LiquidGlassDialogExample() {
  return (
    <LiquidGlassDialogRoot a11yLabel="Edit profile">
      <LiquidGlassDialogTrigger>Open Dialog</LiquidGlassDialogTrigger>
      <LiquidGlassDialogMask />
      <LiquidGlassDialogContent>
        <LiquidGlassDialogTitle>Edit profile</LiquidGlassDialogTitle>
        <LiquidGlassDialogDescription>
          Make changes to your profile here. Click save when you&apos;re done.
        </LiquidGlassDialogDescription>
        <div className="flex justify-end gap-2">
          <LiquidGlassDialogClose prominence="regular">Cancel</LiquidGlassDialogClose>
          <LiquidGlassDialogClose prominence="prominent">Save changes</LiquidGlassDialogClose>
        </div>
      </LiquidGlassDialogContent>
    </LiquidGlassDialogRoot>
  );
}
```

### 组合结构

```text
LiquidGlassDialogRoot
├── LiquidGlassDialogTrigger
├── LiquidGlassDialogMask
└── LiquidGlassDialogContent
    ├── LiquidGlassDialogTitle
    ├── LiquidGlassDialogDescription
    └── LiquidGlassDialogClose
```

### 材质与交互规范

- **避免玻璃叠玻璃**：仅 `Content` 浮层声明 `liquid-glass` 材质；内部的 `Close` 胶囊按钮始终渲染为清晰实色或高对比度表面，不在玻璃面板上重复叠加玻璃材质。
- **显著性分级与同心圆角**：`Trigger` 支持 `regular` / `prominent`，`Close` 支持 `regular` / `prominent` / `destructive`；`rounded-full` 胶囊控件嵌套在 `rounded-2xl` 面板内边距中，保持同心圆角节奏。
- **动态与无障碍回退**：进出场过渡（200 ms / 150 ms）遵循 `prefers-reduced-motion`；禁用态采用无阴影锁定样式而非降低不透明度，确保高对比度与不透明回退下仍清晰可读；需要强制不透明表面时可设置 `material="opaque"`。
