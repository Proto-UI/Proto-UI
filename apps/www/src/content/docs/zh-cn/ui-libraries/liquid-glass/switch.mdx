Liquid Glass Switch 采用圆角胶囊轨道与同心圆形滑块，在开启状态下以主色染色突出当前选中状态，并支持可选的指针拖动、RTL 方向镜像与 `material="opaque"` 不透明降级模式。

## 安装

当前以 Proto UI 工作区源码提供，可从 `@proto.ui/prototypes-liquid-glass/switch` 导入。

## 用法

```tsx
import { switchRoot, switchThumb } from '@proto.ui/prototypes-liquid-glass/switch';
```

```html
<proto-ui-liquid-glass-switch-root default-checked>
  <proto-ui-liquid-glass-switch-thumb></proto-ui-liquid-glass-switch-thumb>
  <span class="sr-only">Enable notifications</span>
</proto-ui-liquid-glass-switch-root>
```

- **材质与层级**：默认 `material="auto"` 在宿主提供可见背景源时请求 `liquid-glass` 材质；位于玻璃浮层容器内或密集表单中时，建议显式设置 `material="opaque"` 以避免玻璃叠玻璃并保持清晰对比度。
- **无障碍与回退**：开启系统减弱动态效果（`prefers-reduced-motion: reduce`）后自动关闭轨道颜色与滑块位移动画；开启减少透明度、增强对比度或处于禁用状态时，自动回退至可读的不透明表面且不降低对比度。
