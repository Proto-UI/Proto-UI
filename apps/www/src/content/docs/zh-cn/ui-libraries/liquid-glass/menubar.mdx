Liquid Glass 风格的横向菜单栏，采用同心圆角几何（外层 `rounded-2xl` 搭配 `p-1` 与内层 `rounded-xl` 控件），仅在展开的浮层命令面板上声明玻璃材质以避免玻璃叠玻璃，并在不支持材质或偏好不透明时自动保留高对比度实体回退。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供；可直接从 `@proto.ui/prototypes-liquid-glass/menubar` 导入原型并通过对应框架 Adapter 使用。

## 用法

```tsx
import {
  LiquidGlassMenubarRoot,
  LiquidGlassMenubarTrigger,
  LiquidGlassMenubarContent,
  LiquidGlassMenubarItem,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <LiquidGlassMenubarRoot a11yLabel="Workspace menu">
      <LiquidGlassMenubarTrigger value="file">File</LiquidGlassMenubarTrigger>
      <LiquidGlassMenubarContent value="file" a11yLabel="File menu">
        <LiquidGlassMenubarItem value="new-tab">New Tab</LiquidGlassMenubarItem>
        <LiquidGlassMenubarItem value="print">Print...</LiquidGlassMenubarItem>
      </LiquidGlassMenubarContent>
    </LiquidGlassMenubarRoot>
  );
}
```

### 组件结构与材质层级

```text
MenubarRoot (rounded-2xl p-1)
├── MenubarTrigger (rounded-xl, 常规/主色展开态)
├── MenubarContent (rounded-2xl p-1, 展开时启用 liquid-glass 材质)
│   ├── MenubarItem (rounded-xl, 同心内圆角)
│   └── MenubarItem
└── ...
```

- `Root` 与 `Trigger` 保持实体与清晰层级，不叠加玻璃材质；展开态 `Trigger` 使用主色填充突出当前活动菜单。
- `Content` 在展开且 `material="auto"` 时向宿主声明 `liquid-glass` 材质候选，带内嵌边缘高光环；可通过 `material="opaque"` 显式关闭材质请求。
- `Item` 采用同心 `rounded-xl` 圆角，禁用态通过柔和前景与去阴影表达而非整项半透明，确保在多彩背景与实体回退下均清晰可读。

### 键盘与无障碍

- 整条菜单栏占用一个游走 `Tab` 停靠点，按 `ArrowLeft` / `ArrowRight` 在顶层触发器之间切换。
- 按 `ArrowDown` / `ArrowUp` 展开面板并纵向浏览命令，支持输入首字符快速跳转（typeahead）。
- 按 `Escape` 关闭当前面板并恢复对应触发器焦点；点击外部区域或激活命令项默认关闭面板。
