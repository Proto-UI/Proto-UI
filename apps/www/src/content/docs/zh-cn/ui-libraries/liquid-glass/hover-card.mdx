Liquid Glass Hover Card 在非玻璃链接式触发器上方或下方弹出分层半透明玻璃预览面板，提供常规与强调层级、同心圆角排版，并在降低透明度、强制颜色或减弱动态效果模式下自动回退为高对比度不透明表面。

## 安装

Liquid Glass Hover Card 当前以 Proto UI 工作区源码提供，暂未通过 CLI 分发；业务应用可按目标框架直接引用工作区原型封装。

## 用法

```tsx
import {
  LiquidGlassHoverCardRoot,
  LiquidGlassHoverCardTrigger,
  LiquidGlassHoverCardContent,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <LiquidGlassHoverCardRoot openDelay={150} closeDelay={200}>
      <LiquidGlassHoverCardTrigger>@proto-ui</LiquidGlassHoverCardTrigger>
      <LiquidGlassHoverCardContent variant="regular" material="auto" side="bottom" align="center">
        Host-neutral interaction protocols layered over translucent Liquid Glass surfaces.
      </LiquidGlassHoverCardContent>
    </LiquidGlassHoverCardRoot>
  );
}
```

### 结构组成与材质准则

```text
LiquidGlassHoverCardRoot
├── LiquidGlassHoverCardTrigger
└── LiquidGlassHoverCardContent
```

- **避免玻璃叠加**：`Trigger` 保持轻量的非玻璃链接外观，仅由展开态的 `Content` 承载 Liquid Glass 材质，防止玻璃叠玻璃造成对比度下降。
- **同心圆角与层级**：`Content` 外层使用 `rounded-2xl` 与 `p-4`，内部次级信息块推荐搭配 `rounded-xl`；需要突出重点信息时可选用 `variant="prominent"`，或通过 `material="opaque"` 显式关闭光学材质。
- **无障碍回退**：系统开启减少透明度、强制颜色模式或减弱动态效果时，组件自动使用清晰边界的不透明表面与静态呈现；禁用态保留文字可读性而非粗暴半透明淡化。
