Liquid Glass Calendar 是公历日期选择组件，支持 `single`（默认）、`multiple` 与 `range` 三种选择模式。日期使用 `YYYY-MM-DD` 字符串，显示月份使用 `YYYY-MM` 字符串，两者均可独立受控。

## 用法

### 组成与网格布局

Calendar 由十个部件组成：`Root`、`Caption`、`Heading`、`Previous`、`Next`、`Grid`、`Weekdays`、`Weekday`、`Row`、`Day`。

- 在 `Weekdays` 中放置 `offset` 为 `0–6` 的七个 `Weekday`，再使用最多六个带 `index`（`0–5`）的 `Row` 与 `offset`（`0–41`）的 `Day` 作为网格容量。
- 默认按当月与 `weekStartsOn` 显示最少 4、5 或 6 周；传入 `fixedWeeks={true}` 可固定显示六周。多余的行和日期格会自动暴露 `hidden` 并退出焦点与选择路径。
- 星期标签与日期无障碍名称随 Root 的 `weekStartsOn`（`0` 为周日）与 `locale` 同步。`direction="rtl"` 会镜像左右方向键；纯图标导航按钮可通过 `a11yLabel` 提供名称。

### 单选、多选与范围规则

- **多选（`multiple`）**：每次激活切换该日期；数组自动去重并按日期升序排列。`minSelected` 默认 `0`，省略 `maxSelected` 表示不限上限。
- **范围（`range`）**：首次激活设定起点 `{ from }`，第二次激活完成闭区间 `{ from, to }`（反向选择会自动排序），再次激活则开始新范围；`{}` 表示清空。`minNights`（默认 `0`，允许单日范围）与 `maxNights` 限制起止日期之间的天数间隔。
- `min`、`max` 与 Root 的 `unavailable` 约束所有选中日期；跨越不可用日期的范围会被拒绝并保留起点。整组不可用日期请配置在 Root 的 `unavailable`，单个 `Day` 的 `disabled` 仅禁用该格。
- `readOnly` 禁止修改选择但允许继续翻月浏览；`disabled` 同时禁用选择与导航。

### 时钟与月份/年份下拉组合

- 组件不主动读取系统时钟或时区：请通过 `today` 传入 `YYYY-MM-DD` 字符串以标记今天（自动映射 `aria-current="date"`）。
- 初始显示月份优先级为：`month` → `defaultMonth` → 当前模式已有选中日期 → `today` → `1970-01`。
- 若需要月份与年份下拉框，可通过 `bindCalendarCaption(source, { month, year })` 将本家族的 Select 与 Calendar 的公开 `month`/`disabled` 状态及 `requestMonth` 组合，卸载时调用返回的 `dispose()` 清理，并通过 Select 的 `accessibleLabel` 为触发器提供稳定名称。

## API

| 部件 / 模式 | 属性 | 默认值与说明 |
| --- | --- | --- |
| Root | `mode` | `'single' \| 'multiple' \| 'range'`，默认 `'single'` |
| Root (`single`) | `value` / `defaultValue` | `YYYY-MM-DD` 字符串；变更回调 `onValueChange({ value })` |
| Root (`multiple`) | `values` / `defaultValues` | 日期数组；配合 `minSelected`（默认 `0`）、`maxSelected` 与 `onValuesChange({ values })` |
| Root (`range`) | `range` / `defaultRange` | `{ from?, to? }`；配合 `minNights`（默认 `0`）、`maxNights` 与 `onRangeChange({ range })` |
| Root | `month` / `defaultMonth` | `YYYY-MM` 字符串，可独立受控 |
| Root | `today` / `min` / `max` / `unavailable` | 今日标记与可选日期边界（`unavailable` 为日期字符串数组） |
| Root | `weekStartsOn` / `locale` / `direction` / `fixedWeeks` | `weekStartsOn` 默认 `0`；`fixedWeeks` 默认 `false` |
| Root | `disabled` / `readOnly` | 禁用或只读控制 |
| Previous / Next | `a11yLabel` / `disabled` | 导航按钮无障碍名称与局部禁用 |
| Row / Day | `index` / `offset` / `disabled` | 网格容量索引与单格禁用 |

### 方法与暴露状态

- Root 暴露方法：`requestMonth(month)`、`requestValue(date)`、`requestValues(dates)`、`requestRange(range)`、`getValues()`、`getRange()`。
- Root 暴露状态：`mode`、`weekCount`、`selectedCount`、`rangeComplete`。
- Day 暴露状态：`selected`、`rangeStart`、`rangeEnd`、`rangeMiddle`、`rangePending`、`hidden`。Grid 在多选与范围模式下自动设置 `aria-multiselectable`。
