Liquid Glass Alert Dialog 用于需要用户显式确认的重要或破坏性操作。弹窗打开时锁定焦点、阻止点击外部关闭，并优先将焦点落到安全的 `Cancel` 按钮。

## 用法

- **部件组成**：`Root`、`Trigger`、`Content`、`Title`、`Description`、`Cancel`、`Action`、`Mask`。
- **交互与焦点**：`Root` 固定 `alert` 语义，`Mask` 管理模态遮罩，`Content` 约束焦点并在打开时优先聚焦 `Cancel`。按下 Escape 或点击 `Cancel` 请求关闭。
- **操作意图**：点击 `Action` 会先触发 `action` 事件，再请求关闭弹窗；实际业务副作用由应用代码自行执行。
- **受控模式**：传入 `open` 进入受控模式（通过 `openChange` 接收关闭/打开请求后更新值），或使用 `defaultOpen` 进行非受控初始化。禁用的命令不会触发激活。

## API

| 部件           | 属性 / 事件            | 说明                                       |
| -------------- | ---------------------- | ------------------------------------------ |
| Root           | `open` / `defaultOpen` | 受控 / 非受控打开状态                      |
| Root           | `openChange`           | 打开或关闭请求事件                         |
| Action         | `action`               | 确认按钮激活时在关闭请求之前发出的事件     |
| Mask / Content | —                      | 管理模态遮罩、焦点约束与 `Cancel` 优先聚焦 |
