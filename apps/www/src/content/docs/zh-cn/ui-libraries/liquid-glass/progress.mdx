## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `progress` 子路径导入 `progressRoot`、`progressLabel`、`progressTrack`、`progressIndicator` 与 `progressValue`。

## 用法

- **部件组成**：`Root` 管理进度范围，`Label` 提供名称，`Track` 容纳 `Indicator`，`Value` 显示 `valueText` 或规范数值。
- **确定与不确定状态**：数值自动限制在 `[min, max]` 之间（上下界相等时比例为 `0`）。省略 `value` 或设置 `indeterminate={true}` 进入未知进度模式，并自动对辅助技术省略当前进度值。
- Progress 为被动展示组件，不引入键盘停靠点；更新属性时所有部件同步刷新。

## API

| 部件 | 属性 / 暴露状态 | 默认值与说明 |
| --- | --- | --- |
| Root | `value` | 当前进度数值；省略时进入不确定状态 |
| Root | `min` / `max` | `0` / `100` |
| Root | `indeterminate` | `false`；设为 `true` 时表示进度未知 |
| Root | `ariaLabel` / `valueText` | 可访问名称与格式化显示文本 |
| Root / 部件（暴露状态） | `value` / `percentage` / `indeterminate` / `status` | 归一化进度值、百分比与状态 |
