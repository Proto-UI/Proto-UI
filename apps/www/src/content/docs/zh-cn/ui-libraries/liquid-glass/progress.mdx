Liquid Glass Progress 用于展示确定范围或不确定状态的任务完成进度。遵循内容层分层原则，进度条使用同心胶囊轨道、内嵌高光描边与高对比度主色填充，避免在内容区域内重复叠加玻璃材质。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `@proto.ui/prototypes-liquid-glass/progress` 导入全部部件：

```ts
import {
  progressRoot,
  progressLabel,
  progressTrack,
  progressIndicator,
  progressValue,
} from '@proto.ui/prototypes-liquid-glass/progress';
```

## 用法

由 `Root`、`Label`、`Track`、`Indicator` 与 `Value` 组成；将 `Label` 与 `Value` 放在 `Track` 之前即可在轨道上方对齐标题行：

```tsx
<LiquidGlassProgressRoot
  prominence="prominent"
  value={74}
  valueText="74%"
  className="w-full max-w-sm"
>
  <LiquidGlassProgressLabel>Downloading system update</LiquidGlassProgressLabel>
  <LiquidGlassProgressValue />
  <LiquidGlassProgressTrack>
    <LiquidGlassProgressIndicator />
  </LiquidGlassProgressTrack>
</LiquidGlassProgressRoot>
```

```text
ProgressRoot
├── ProgressLabel
├── ProgressValue
└── ProgressTrack
    └── ProgressIndicator
```

- **层次与同心圆角**：支持 `prominence`（`regular`、`prominent`、`destructive`）区分常规、突出与配额预警层级。轨道与填充条共享同心全圆角（`rounded-full`），并通过基于前景色混合的半透明轨道与内嵌 1px 边缘描边在亮暗模式和彩色背景上保持清晰可读，不向内容层叠加第二层玻璃。
- **动效与无障碍**：宽度过渡使用共享 resident motion（`300ms`），自动响应系统减少动效偏好。`value` 限制在 `[min, max]` 之间；省略 `value` 或设置 `indeterminate={true}` 时进入不确定态，不向辅助技术上报具体数值。Progress 为只读组件，不引入键盘焦点停靠点。

### 子部件与暴露状态

- `ProgressTrack` 与 `ProgressIndicator` 支持可选的 `prominence` 覆盖（`'regular' | 'prominent' | 'destructive' | 'inherit'`，默认 `'inherit'`）。
- 全部部件同步暴露只读状态 `value`、`percentage`、`indeterminate` 与 `status`。
