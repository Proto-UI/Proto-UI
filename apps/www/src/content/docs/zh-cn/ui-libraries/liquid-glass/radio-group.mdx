Liquid Glass Radio Group 以通透的玻璃材质边界、柔和的高光边缘和同心圆点比例（`size-2` 圆点位于 `size-5` 圆形控件内）呈现单选交互，支持 `regular` 与 `prominent` 视觉层级以及 `material="opaque"` 显式退让，并由 Base Radio Group 统一管理单选语义与漫游焦点。

## 安装

Liquid Glass Radio Group 当前以 Proto UI 工作区源码提供，可从 `@proto.ui/prototypes-liquid-glass/radio-group` 导入 `radioGroupRoot`、`radioGroupItem` 与 `radioGroupIndicator` 并适配到目标运行时。

## 用法

```tsx
import {
  LiquidGlassLabelRoot,
  LiquidGlassRadioGroupIndicator,
  LiquidGlassRadioGroupItem,
  LiquidGlassRadioGroupRoot,
} from '../proto-ui/components/react';

export function RadioGroupUsage() {
  return (
    <LiquidGlassRadioGroupRoot defaultValue="comfortable" a11yLabel="Display density">
      <div className="flex items-center gap-3">
        <LiquidGlassRadioGroupItem value="default">
          <LiquidGlassRadioGroupIndicator />
        </LiquidGlassRadioGroupItem>
        <LiquidGlassLabelRoot>Default</LiquidGlassLabelRoot>
      </div>
      <div className="flex items-center gap-3">
        <LiquidGlassRadioGroupItem value="comfortable">
          <LiquidGlassRadioGroupIndicator />
        </LiquidGlassRadioGroupItem>
        <LiquidGlassLabelRoot>Comfortable</LiquidGlassLabelRoot>
      </div>
      <div className="flex items-center gap-3">
        <LiquidGlassRadioGroupItem value="compact">
          <LiquidGlassRadioGroupIndicator />
        </LiquidGlassRadioGroupItem>
        <LiquidGlassLabelRoot>Compact</LiquidGlassLabelRoot>
      </div>
    </LiquidGlassRadioGroupRoot>
  );
}
```

### 材质层次与无障碍

- **避免玻璃叠加玻璃**：只有单个 `Item` 声明 Liquid Glass 材质，`Root` 容器与 `Indicator` 圆点均不叠加玻璃层。若单选框组放置在已使用玻璃材质的面板或卡片中，请为 `Item` 设置 `material="opaque"`，改用高对比度实心回退表面。
- **层级区分**：日常选项使用默认 `variant="regular"`；需要突出关键选项时使用 `variant="prominent"`，配合主题主色边界与染色。
- **自适应回退**：当系统开启减少透明度、减弱动态效果、增强对比度或强制颜色模式，或宿主缺少可用背景源时，控件自动回退至可读的不透明色彩配对；禁用态不使用低透明度淡出（`opacity-50`），确保选中标记与文字在实心表面上依然清晰可辨。

### Indicator、事件与方法

- **Indicator**：无额外属性，自动继承所属 `Item` 的前景色绘制同心圆点。
- **事件**：Root 触发 `valueChange`（`{ value: string }`）；Item 触发 `select`（`{ value: string }`）。
- **方法**：Root 暴露 `requestValue(value)`、`resetValue()`、`focusFirst()`、`focusLast()`、`focusNext()`、`focusPrev()`、`focusSelected()`、`focusSelf()`。
