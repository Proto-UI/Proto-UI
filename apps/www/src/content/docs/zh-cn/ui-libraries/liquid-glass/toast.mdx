Liquid Glass Toast 在浮动通知表面上应用单一 `liquid-glass` 材质层与内嵌高光边缘，内部操作控件采用同心胶囊造型且不叠加嵌套玻璃，并支持不透明回退、自动倒计时关闭、悬停或聚焦暂停以及 `F8` 快捷键聚焦。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可直接从 `@proto.ui/prototypes-liquid-glass/toast` 导入组件原型并使用对应宿主 Adapter 适配。

```ts
import {
  toastViewport,
  toastRoot,
  toastTitle,
  toastDescription,
  toastAction,
  toastClose,
} from '@proto.ui/prototypes-liquid-glass/toast';
```

## 用法

```tsx
<LiquidGlassToastViewport a11yLabel="Notifications">
  <LiquidGlassToastRoot defaultOpen={false} duration={5000}>
    <LiquidGlassToastTitle>Event has been created</LiquidGlassToastTitle>
    <LiquidGlassToastDescription>Sunday, December 03, 2023 at 9:00 AM</LiquidGlassToastDescription>
    <LiquidGlassToastAction a11yLabel="Undo event creation">Undo</LiquidGlassToastAction>
    <LiquidGlassToastClose>Dismiss</LiquidGlassToastClose>
  </LiquidGlassToastRoot>
</LiquidGlassToastViewport>
```

- **部件组成**：`Root`、`Viewport`、`Title`、`Description`、`Action`、`Close`。仅 `Root` 声明 `liquid-glass` 材质候选，内部胶囊按钮保持高对比实色表面以避免玻璃叠玻璃。
- **材质回退**：通过 `material="opaque"` 可主动退出半透明材质，在降低透明度或高对比度场景下保持清晰的前景与容器区分。
- **计时与暂停**：`Root` 默认显示 `5000ms`，设置 `duration={0}` 可持续显示不自动关闭。指针悬停在通知上或焦点进入 `Action` / `Close` 时会自动暂停倒计时。受控模式下超时仅发出一次关闭请求，等待调用方更新 `open`。
- **关闭与快捷键**：点击 `Close`、聚焦时按 `Escape` 或触发 `Action` 均会请求关闭（实际操作副作用由应用处理）。`Viewport` 提供 `F8` 快捷键用于快速将焦点移至通知区域。

事件与暴露方法：

- **事件**：`Root` 暴露 `openChange`（`{ open: boolean; reason: string }`）；`Action` 暴露 `action`（`void`）。
- **方法**：`Root` 暴露 `openToast()`、`close(reason?)`、`pause()`、`resume()`；`Viewport` 暴露 `focusFirst()`。
