## 用法

- **部件组成**：`Root`、`Viewport`、`Title`、`Description`、`Action`、`Close`。
- **计时与暂停**：`Root` 默认显示 `5000ms`，设置 `duration={0}` 可持续显示不自动关闭。指针悬停在通知上或焦点进入 `Action` / `Close` 时会自动暂停倒计时。受控模式下超时仅发出一次关闭请求，等待调用方更新 `open`。
- **关闭与快捷键**：点击 `Close`、聚焦时按 Escape 或触发 `Action` 均会请求关闭（实际操作副作用由应用处理）。`Viewport` 提供 `F8` 快捷键用于快速将焦点移至通知区域。全局队列编排由应用层自行管理。

## API

| 部件 | 属性 | 默认值与说明 |
| --- | --- | --- |
| Root | `open` / `duration` | 受控开关状态 / 自动关闭毫秒数（默认 `5000`，`0` 为不自动关闭） |
| Viewport | — | 通知展示区域，支持 `F8` 聚焦快捷键 |
| Title / Description | — | 通知标题与正文内容 |
| Action / Close | — | 通知内操作按钮与手动关闭按钮 |
