Liquid Glass Input 基于 [Base Input](../../base/input/) 构建。遵循 Apple Liquid Glass 层级分离原则，文本输入属于内容编辑层，保持清晰、不透明的高对比度矩形编辑表面与同心圆角几何，不与玻璃材质叠加，同时可与浮层玻璃按钮自然搭配。

## 安装

当前以 Proto UI 工作区源码提供，尚未进入稳定版 CLI；可直接从 `@proto.ui/prototypes-liquid-glass/input` 导入。

## 用法

```tsx
import { LiquidGlassInputRoot } from '@/components/ui/liquid-glass-input';

export function Example() {
  return <LiquidGlassInputRoot placeholder="Enter text" ariaLabel="Text input" />;
}
```

- **层级与可读性**：采用 `h-11`、`rounded-2xl`、清晰边界与高对比度不透明背景，避免玻璃叠玻璃导致文字可读性下降；点击聚焦呈现柔和蓝环，键盘聚焦显示高对比度外偏焦点环与强制色彩回退。
- **状态反馈**：`readOnly` 与 `disabled` 通过语义中性表面和对比度墨色区分，不依赖降低整体不透明度，确保回退状态依然清晰可读。
- **表单组合**：搭配 Liquid Glass `Label`、`Field` 或浮层玻璃 `Button` 构建完整表单与搜索条。
