Liquid Glass Form 由 `Root`、`Field`、`Submit`、`Reset` 四个部件组成，负责协调组内所有已注册字段的同步/异步校验、按字段名汇总提交数据以及表单重置。

## 用法

- **部件组成**：`Root`、`Field`、`Submit`、`Reset`。
- **校验与提交**：激活 `Submit`（或在聚焦的单行 Field、Number Field、Input OTP 中按 Enter，自动忽略 IME 组合与修饰键）会校验所有启用的注册字段；全部通过后，在 `submit` 事件中返回按字段名组织的表单数据。禁用字段不参与提交，重复字段名会被忽略；异步校验等待当前结果并在值变更、取消或卸载时自动废弃旧提交。Form 不自动发起网络请求或页面跳转，也不创建隐藏 HTML 表单项。
- **重置**：调用 `requestReset()` 或点击 `Reset` 会恢复非受控字段的初始值、向受控字段发送恢复提议、取消未完成编辑与异步校验，并发出 `reset` 事件；`resetValidation()` 仅清理校验结果。
- **按钮材质**：`FormSubmit` 与 `FormReset` 复用 Liquid Glass Button 的视觉反馈，支持 `material="auto"` 与 `"opaque"`；禁用态自动关闭光学效果。

## API

| 部件 | 属性 / 方法 / 事件 | 说明 |
| --- | --- | --- |
| Root | `disabled` | 禁用表单并自动向下传递到内部字段 |
| Root | `requestReset()` / `resetValidation()` | 重置表单值与校验 / 仅清除校验状态 |
| Root | `submit` / `reset` | 校验通过后按字段名返回数据 / 重置完成后触发 |
| Field | — | 注册参与表单校验与序列化的字段 |
| Submit / Reset | `material` | `'auto' \| 'opaque'`；同时暴露 `disabled`、`hovered`、`pressed`、`focused`、`focusVisible` 与 `focusSelf()` |
