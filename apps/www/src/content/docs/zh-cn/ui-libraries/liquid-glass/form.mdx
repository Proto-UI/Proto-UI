Liquid Glass Form 由 `Root`、`Field`、`Submit`、`Reset` 四个部件组成，负责协调组内所有已注册字段的同步与异步校验、按字段名汇总提交数据以及表单重置；表单内容保留在清晰可读的内容层，玻璃材质集中在浮动操作控件上。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供；可从 `@proto.ui/prototypes-liquid-glass/form` 引入。

## 用法

```tsx
import {
  LiquidGlassFormRoot,
  LiquidGlassFormField,
  LiquidGlassFormSubmit,
  LiquidGlassFormReset,
  LiquidGlassFieldLabel,
  LiquidGlassFieldControl,
  LiquidGlassFieldError,
} from '../proto-ui/components/react';

export function ExampleLiquidGlassForm() {
  return (
    <LiquidGlassFormRoot
      ariaLabel="Workspace settings"
      onSubmit={({ values }) => console.log(values)}
    >
      <LiquidGlassFormField name="workspace" required>
        <LiquidGlassFieldLabel>Workspace name</LiquidGlassFieldLabel>
        <LiquidGlassFieldControl placeholder="Design Systems" />
        <LiquidGlassFieldError />
      </LiquidGlassFormField>
      <div className="flex items-center gap-2">
        <LiquidGlassFormSubmit variant="prominent" material="auto">
          Save workspace
        </LiquidGlassFormSubmit>
        <LiquidGlassFormReset variant="regular" material="auto">
          Reset
        </LiquidGlassFormReset>
      </div>
    </LiquidGlassFormRoot>
  );
}
```

### 材质层次与无障碍回退

- **避免玻璃叠玻璃**：表单字段与说明文本保持在中性可读内容层；浮动操作按钮默认使用 `material="auto"`（`Submit` 为 `prominent` 着色玻璃，`Reset` 为 `regular` 常规玻璃）。当表单嵌套在半透明面板或卡片内时，可将按钮设为 `material="opaque"` 避免多层玻璃叠加。
- **系统偏好回退**：当系统开启「降低透明度」（`reducedTransparency`）或「提高对比度」（`increasedContrast`）时，操作按钮自动回退为高对比度不透明填充；开启「减弱动态效果」（`reducedMotion`）时自动取消按压形变；禁用态自动撤回光学材质并保持清晰可读的前景/背景对比度。
- **校验与提交**：激活 `Submit` 或在聚焦的单行输入框中按 `Enter` 会校验所有启用的注册字段，全部通过后通过 `submit` 事件输出按字段名组织的数据；禁用字段自动排除，重复字段名在序列化时抛出 `FORM_DUPLICATE_NAME`。`FormField` 在无效态自动切换为 `text-destructive`。
