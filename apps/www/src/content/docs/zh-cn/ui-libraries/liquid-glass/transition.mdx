Liquid Glass Transition 为悬浮于内容之上的 Liquid Glass 面板与控制条提供透明的五阶段显隐状态机（`closed → preparing → entering → entered → leaving`）。原型仅绑定端点透明度（`opacity-100` / `opacity-0`），自身不申请第二层玻璃材质，从而避免违反 Apple Liquid Glass 指南中的“玻璃叠玻璃”反模式。

## 预览

## 安装

当前仅以 Proto UI 工作区源码提供，尚未加入 `@proto.ui/cli` 安装目标。可直接从工作区源码导入：

```ts
import { transition } from '@proto.ui/prototypes-liquid-glass/transition';
```

## 用法

```tsx
import { useState } from 'react';
import { LiquidGlassButton, LiquidGlassTransition } from '../proto-ui/components/react';

export function FloatingGlassPanel() {
  const [open, setOpen] = useState(true);

  return (
    <div className="rounded-2xl bg-gradient-to-br from-sky-500/25 via-indigo-500/20 to-fuchsia-500/25 p-5">
      <LiquidGlassTransition
        open={open}
        appear
        className="block transition-opacity duration-300 ease-out motion-reduce:transition-none"
      >
        <div className="rounded-2xl border border-white/55 bg-white/70 p-4 shadow-lg backdrop-blur-xl">
          Floating Liquid Glass overlay
        </div>
      </LiquidGlassTransition>
      <div className="mt-4">
        <LiquidGlassButton variant="prominent" onClick={() => setOpen((value) => !value)}>
          Toggle Panel
        </LiquidGlassButton>
      </div>
    </div>
  );
}
```

## 材质与无障碍

设计取舍参考 Apple Human Interface Guidelines 的 [Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 指南：

- **禁止玻璃叠玻璃**：`liquid-glass-transition` 本身保持完全透明、不挂载材质载体，只作为悬浮玻璃表面的存在性与端点透明度协调层。
- **同心圆角与层次**：外层浮层容器与内层徽章/控件保持同心圆角（如外层 `rounded-2xl` + 内边距 `p-4` 搭配内层 `rounded-xl`），同一视图组中只突出一个主要 `prominent` 操作。
- **辅助功能回退**：当系统开启“减少透明度”或“增强对比度”时，悬浮表面与按钮应切换至高对比度不透明样式（如 `material="opaque"`）；开启“减弱动态效果”（`prefers-reduced-motion: reduce`）时，Transition 自动将兜底时长缩短为 `0ms` 并保留完整阶段与事件顺序。
- **底层语义**：所有相位机、挂载与打断行为均由 [Base Transition](/zh-cn/ui-libraries/base/transition/) 统一提供。
