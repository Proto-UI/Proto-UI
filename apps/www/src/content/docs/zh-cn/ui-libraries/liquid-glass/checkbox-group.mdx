Liquid Glass Checkbox Group 由 `Root`、`Item` 与 `All` 组成，采用紧凑的内容层 20×20 圆角复选框与清晰的非颜色勾选/横线状态指示，避免在表单与卡片内容中叠加玻璃材质，确保高对比度与可读回退。

## 用法

```tsx
import {
  LiquidGlassCheckboxGroupRoot,
  LiquidGlassCheckboxGroupAll,
  LiquidGlassCheckboxGroupItem,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <LiquidGlassCheckboxGroupRoot defaultValue={['email']} ariaLabel="Notification channels">
      <LiquidGlassCheckboxGroupAll>All notifications</LiquidGlassCheckboxGroupAll>
      <LiquidGlassCheckboxGroupItem value="email">Email updates</LiquidGlassCheckboxGroupItem>
      <LiquidGlassCheckboxGroupItem value="sms">SMS alerts</LiquidGlassCheckboxGroupItem>
    </LiquidGlassCheckboxGroupRoot>
  );
}
```

### 部件结构与材质分层

- **Root**：管理选中字符串数组（`value` / `defaultValue`）、`orientation`、`disabled`、`readOnly` 与 `ariaLabel`。
- **Item**：单个复选框项，包含紧凑的 20×20 圆角指示框与聚焦反馈；每项独立参与 `Tab` 顺序，按 `Space` 切换（`Enter` 不切换）。
- **All**：根据全部可用项推导勾选、未选或混合（`mixed`）状态，切换时保留已禁用项的原状态。
- **内容层与无障碍**：复选框组作为内容层表单控件保持中性表面（不叠加玻璃卡片），禁用态采用低饱和度语义前景色而非整行透明度衰减，置于 [Field](/zh-cn/ui-libraries/liquid-glass/field/) 或 [Form](/zh-cn/ui-libraries/liquid-glass/form/) 内时自动联动标签激活、必填校验、序列化与重置。

### 事件、方法与状态

- **Root 事件**：`valueChange`（载荷 `{ value: string[] }`）。
- **Root 方法**：`getValue(): string[]`、`resetValue(): boolean`、`focusSelf(): void`。
- **暴露状态**：Root 暴露 `checked`、`indeterminate`、`disabled`、`readOnly`；Item 与 All 暴露 `checked`、`indeterminate`、`disabled`、`readOnly`、`focused`、`focusVisible`。
