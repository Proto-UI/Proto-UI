Liquid Glass Checkbox Group 由 `Root`、`Item`、`All` 三个部件组成，用于统一管理一组复选框的选中值数组，并提供全选/半选切换以及带勾选/横线图形的非颜色状态指示。

## 用法

- **部件组成**：`Root`、`Item`、`All`。
- **全选与禁用**：`All` 自动根据全部可用 `Item` 推导勾选、未选或混合（`mixed`）状态，切换全选时保留已禁用项的原状态。`Item` 与 `All` 均配有 `aria-hidden` 视觉图标（对勾、横线或空框），不只靠颜色区分状态。
- **键盘交互**：每一项拥有独立 Tab 停靠点，按 Space 切换选中（Enter 不切换）。
- **受控与表单联动**：传入 `value` 进入受控模式，交互仅发出 `valueChange` 请求；`getValue()` 返回当前值数组副本；重复值的选项会被忽略。置于 [Field](/zh-cn/ui-libraries/liquid-glass/field/) 或 [Form](/zh-cn/ui-libraries/liquid-glass/form/) 中时，自动支持标签激活、必填校验、表单序列化与重置（不创建隐藏 HTML 表单项）。

## API

| 部件 | 属性 / 方法                           | 说明                                 |
| ---- | ------------------------------------- | ------------------------------------ |
| Root | `value` / `defaultValue`              | 受控 / 非受控选中值字符串数组        |
| Root | `disabled` / `readOnly` / `ariaLabel` | 整组禁用、只读与可访问名称           |
| Root | `valueChange` / `getValue()`          | 变更请求事件与读取当前数组副本的方法 |
| Item | `value` / `disabled`                  | 选项唯一值与单项禁用开关             |
| All  | —                                     | 汇总可用选项状态并一键全选/取消全选  |
