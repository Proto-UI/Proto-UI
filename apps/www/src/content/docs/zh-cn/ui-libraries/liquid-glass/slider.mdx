Liquid Glass Slider 提供单滑块（single-thumb）连续或步进数值调节，支持在轨道上直接指针/触摸拖动，以及在滑块手柄上进行精细的键盘调节。

## 用法

- **部件组成**：`Root`、`Label`、`Track`、`Indicator`、`Thumb`、`FieldThumb`、`Value`。
- **拖拽与键盘交互**：`Track` 响应指针与触摸拖动；`Thumb` 作为单一可聚焦滑块支持方向键（水平 RTL 自动反向）、`Shift` 十倍步进、`PageUp` / `PageDown` 与 `Home` / `End`。数值自动从 `min` 对齐 `step` 并限制在 `[min, max]` 之间。
- **受控与提交事件**：传入 `value` 进入受控模式，交互发出 `valueChange` 提议并在拖拽结束时发出 `valueCommit`；取消拖动时非受控滑块自动恢复拖动前的值。
- **与 Field / Form 集成**：在 [Field](/zh-cn/ui-libraries/liquid-glass/field/) 或 [Form](/zh-cn/ui-libraries/liquid-glass/form/) 中使用 `FieldThumb` 替代 `Thumb`，即可桥接 `FieldLabel` 激活、数值校验、表单序列化与重置；独立使用时搭配 `SliderLabel`。

## API

| 部件 | 属性 / 事件 | 说明 |
| --- | --- | --- |
| Root | `value` / `defaultValue` | 受控 / 非受控当前数值 |
| Root | `min` / `max` / `step` | 数值上下界与对齐步长 |
| Root | `disabled` / `readOnly` / `orientation` / `direction` | 禁用、只读、方向与 RTL 镜像 |
| Root | `valueChange` / `valueCommit` | 调节过程中的变更提议 / 操作完成事件 |
| Track / Indicator / Label / Value | — | 拖拽轨道、进度填充、标签与被动数值展示 |
| Thumb / FieldThumb | — | 独立使用的可聚焦滑块手柄 / 用于 Field 与 Form 的桥接手柄 |
