Liquid Glass Slider 采用纤细连续轨道与高对比度胶囊滑块，支持单值与多值范围选择、键盘微调及 `Field` / `Form` 联动，并在按下拖拽时呈现瞬态 Liquid Glass 折射反馈。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `@proto.ui/prototypes-liquid-glass/slider` 导入单值滑块与多值滑块 `sliderValues*` 部件。

## 用法

```tsx
import {
  LiquidGlassSliderRoot,
  LiquidGlassSliderTrack,
  LiquidGlassSliderIndicator,
  LiquidGlassSliderThumb,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <LiquidGlassSliderRoot defaultValue={33} min={0} max={100} step={1}>
      <LiquidGlassSliderTrack>
        <LiquidGlassSliderIndicator />
        <LiquidGlassSliderThumb />
      </LiquidGlassSliderTrack>
    </LiquidGlassSliderRoot>
  );
}
```

- **材质层级与安全**：单值 `Thumb` / `FieldThumb` 静止时保持清晰不透明胶囊形态，仅在按下拖拽期间请求瞬态 `liquid-glass` 材质。当滑块放置在已是玻璃材质的工具栏或浮层面板内时，可显式设置 `material="opaque"` 以避免玻璃叠玻璃，并在禁用态或系统降低透明度时自动回退至可读的不透明表面。
- **拖拽与键盘**：`Track` 响应指针与触摸拖动；`Thumb` 支持方向键（水平 RTL 自动反向）、`Shift` 十倍步进、`PageUp` / `PageDown` 与 `Home` / `End`。
- **表单集成**：在 [Field](/zh-cn/ui-libraries/liquid-glass/field/) 或 [Form](/zh-cn/ui-libraries/liquid-glass/form/) 中使用 `FieldThumb` 替代 `Thumb`，或直接使用多值 `Values Root` 汇报 `number[]`。
