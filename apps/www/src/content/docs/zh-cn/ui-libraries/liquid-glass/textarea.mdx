Liquid Glass Textarea 遵循 Apple Liquid Glass 人机界面指南中的层次划分：将多行文本编辑区置于高可读性的不透明内容层（`bg-background`、`rounded-2xl`、清晰边框），不在文本输入表面叠加玻璃材质，从而与上方或旁侧的 Liquid Glass 操作按钮形成清晰视觉层级。

## 安装

当前以工作区源码提供，可从 `@proto.ui/prototypes-liquid-glass/textarea`（以及表单组合入口 `@proto.ui/prototypes-liquid-glass/field`）导入。

## 用法

```tsx
import { LiquidGlassTextareaRoot } from '../proto-ui/components/react';
```

```tsx
<LiquidGlassTextareaRoot placeholder="Type your message here." rows={4} />
```

- **内容层与材质层级**：文本编辑区始终保持不透明可读表面，避免玻璃叠玻璃或背景透出干扰阅读；将其置于外层 `rounded-3xl` 容器内时，`rounded-2xl` 内圆角保持同心圆角过渡。
- **可访问性与状态反馈**：键盘焦点显示 `forced-colors` 兼容的高对比度外偏焦点环；禁用态使用语义化的 `bg-muted` 与 `text-muted-foreground`，不降低整块不透明度以确保高对比度回退可读；校验错误通过 `FieldTextarea` 呈现语义化红色边框与光晕。
- **行为继承**：受控/非受控值、IME 组合事件、`resetValue()`、`focusSelf()` 与 `blurSelf()` 均由 [Base Textarea](/zh-cn/ui-libraries/base/textarea/) 统一提供。

## API

以下属性属于 `Root`（传入 `value` 可进入受控模式；未限制长度时 `minLength` 与 `maxLength` 为 `-1`）：

- **暴露状态**：`value`、`disabled`、`readOnly`、`focused`、`focusVisible`、`composing`（在 `FieldTextarea` 中额外暴露 `invalid` 与 `pending`）。
- **暴露方法**：`focusSelf(options?)`、`blurSelf()`、`resetValue()`。
- **事件**：`valueChange`、`change`、`compositionStart`、`compositionUpdate`、`compositionEnd`。
