Liquid Glass Popover 在触发按钮附近呈现半透明悬浮材质面板，支持常规与强调层级、同心圆角几何及降低透明度/高对比度/减少动态效果的自动回退，不锁定背景滚动或限制 `Tab` 导航。

## 安装

Liquid Glass Popover 目前在工作区源码中提供，将于 `0.3.0-rc.1` 及后续版本中提供 CLI。可直接从 `@proto.ui/prototypes-liquid-glass/popover` 导入原型并使用对应框架适配器：

```ts
import {
  popoverRoot,
  popoverTrigger,
  popoverContent,
  popoverTitle,
  popoverDescription,
  popoverClose,
} from '@proto.ui/prototypes-liquid-glass/popover';
```

## 用法

```tsx
<LiquidGlassPopover>
  <LiquidGlassPopoverTrigger>Open Popover</LiquidGlassPopoverTrigger>
  <LiquidGlassPopoverContent align="start">
    <LiquidGlassPopoverTitle>Dimensions</LiquidGlassPopoverTitle>
    <LiquidGlassPopoverDescription>Set the dimensions for the layer.</LiquidGlassPopoverDescription>
  </LiquidGlassPopoverContent>
</LiquidGlassPopover>
```

### 组件结构

```text
LiquidGlassPopoverRoot
├── LiquidGlassPopoverTrigger
└── LiquidGlassPopoverContent
    ├── LiquidGlassPopoverTitle
    ├── LiquidGlassPopoverDescription
    └── LiquidGlassPopoverClose
```

- **材质层级与禁止玻璃叠玻璃**：`Content` 仅在展开且 `material="auto"` 时声明 `liquid-glass` 材质；`Close` 采用同心圆角不透明控件（`rounded-xl` 嵌套在 `rounded-2xl` 外壳内），避免在玻璃浮层内部再次叠加玻璃材质控件。
- **无障碍自动回退**：当用户开启系统“降低透明度”（`prefers-reduced-transparency: reduce`）或“强制颜色模式”（`forced-colors: active`）时，自动撤回半透明材质并切换为高对比度不透明表面；开启“减少动态效果”（`prefers-reduced-motion: reduce`）时禁用缩放与过渡动效。
- **定位与关闭**：支持 `side`、`align`、`sideOffset`、`alignOffset` 与 `collisionPadding`；点击外部、按下 `Escape`、激活 `Close` 或焦点移出弹层均会请求关闭。
