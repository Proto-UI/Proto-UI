Liquid Glass Popover 用于承载与触发按钮关联的轻量交互内容。它是非模态弹层，打开时不会锁定页面滚动或限制 Tab 导航。

## 用法

- **部件组成**：`Root`、`Trigger`、`Content`、`Title`、`Description`、`Close`。
- **定位**：`Content` 相对 `Trigger` 锚定，支持 `side`、`align`、`sideOffset`、`alignOffset` 与 `collisionPadding`。
- **关闭与焦点行为**：点击外部、按 Escape、点击 `Close` 或焦点移出 `Trigger` 与 `Content` 时请求关闭。焦点在 `Trigger` 与 Portal 内的 `Content` 之间移动仍视为内部操作；因焦点移出而关闭时会保留新外部控件上的焦点，不会抢回 `Trigger`。纯焦点移出请求的 `focusReason` 为 `'programmatic'`。
- **受控模式**：传入 `open` 并监听 `openChange` 即可由外部控制开关（也可使用 `defaultOpen` 初始化非受控状态）。若拒绝关闭请求，内容会继续显示且不限制外部焦点。

## API

| 部件 | 属性 / 事件 | 说明 |
| --- | --- | --- |
| Root | `open` / `defaultOpen` | 受控 / 非受控打开状态 |
| Root | `openChange` | 打开或关闭请求事件 |
| Content | `side` / `align` / `sideOffset` / `alignOffset` / `collisionPadding` | 相对 `Trigger` 的锚点定位与避障边距 |
| Trigger / Title / Description / Close | — | 触发按钮、标题、说明与关闭按钮 |
