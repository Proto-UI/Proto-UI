Liquid Glass Number Field 提供符合 `spinbutton` 语义的数值编辑体验，支持加减按钮与键盘步进、基于 `locale` / `formatOptions` 的本地化显示与解析、可选空值 `null` 以及标签拖拽调值。

按照 Apple Liquid Glass 设计层次，普通内容层数值编辑器与内嵌步进按钮保持高对比度不透明表面（避免在内容层叠放玻璃材质），同时采用 `44×44` 最小触控尺寸、清晰的悬停/按压阴影反馈、高可读性的静音禁用填充以及 Forced Colors 焦点外框。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可直接从 `@proto.ui/prototypes-liquid-glass/number-field` 导入各部件原型：

```ts
import {
  numberFieldRoot,
  numberFieldLabel,
  numberFieldInput,
  numberFieldControl,
  numberFieldIncrement,
  numberFieldDecrement,
} from '@proto.ui/prototypes-liquid-glass/number-field';
```

## 用法

```tsx
<LiquidGlassNumberFieldRoot defaultValue={12} min={0} max={100} step={1} ariaLabel="Quantity">
  <LiquidGlassNumberFieldLabel>Quantity</LiquidGlassNumberFieldLabel>
  <LiquidGlassNumberFieldDecrement>
    <span aria-hidden="true">−</span>
    <span className="sr-only">Decrease Quantity</span>
  </LiquidGlassNumberFieldDecrement>
  <LiquidGlassNumberFieldInput />
  <LiquidGlassNumberFieldIncrement>
    <span aria-hidden="true">+</span>
    <span className="sr-only">Increase Quantity</span>
  </LiquidGlassNumberFieldIncrement>
</LiquidGlassNumberFieldRoot>
```

- **层次与无障碍**：编辑器与步进按钮保持不透明内容层表面；禁用态通过 `bg-muted` 与柔和前景色清晰区分（不使用低透明度降低对比度），焦点态提供带偏移环与 Forced Colors 回退外框。
- **编辑与步进**：输入过程中保留未完成草稿，失焦或按 `Enter` 时提交合法数值或恢复上次有效值。加减按钮与上下方向键共享步进规则，按住 `Shift` 步进 10 倍，`Home` / `End` 跳至最小/最大边界。IME 组合输入期间自动暂停解析、提交、步进与拖拽。
- **与 Field / Form 集成**：置于 [Field](/zh-cn/ui-libraries/liquid-glass/field/) 或 [Form](/zh-cn/ui-libraries/liquid-glass/form/) 内时，使用 `Control` 替代 `Input` 以自动联动 `FieldLabel`、校验错误态、表单序列化与重置。
