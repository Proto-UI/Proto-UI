Liquid Glass Number Field 提供符合 `spinbutton` 语义的数值编辑体验，支持加减按钮与键盘步进、基于 `locale` / `formatOptions` 的本地化显示与解析、可选空值 `null` 以及在标签上拖拽调值（scrub）。

## 用法

- **部件组成**：`Root`、`Label`、`Input`、`Control`、`Increment`、`Decrement`。
- **编辑与步进**：输入过程中允许保留未完成草稿，失焦或按 Enter 时提交有效数值或恢复原已接受值。加减按钮与上下方向键共享步进规则，按住 `Shift` 步进 10 倍，`Home` / `End` 跳至最小/最大边界。受控模式下变更仅作为提议发出，不提前覆盖调用方值。
- **格式化与解析**：传入 `locale` 与 `formatOptions` 可支持十进制、货币与百分比展示及本地化数字/符号解析；展示舍入不会改写内部精确值。配置非法时通过 `formatInvalid` 提示并回退到无分组十进制。IME 组合输入期间不会触发解析、提交、步进或拖拽。
- **空值支持**：开启 `allowEmpty={true}` 后，清空内容并提交会请求 `null`；`getValue()` 返回真实的 `number | null`，`empty` 标记是否为空。从空值首次步进会初始化为边界内对齐的 `0`。
- **标签拖拽调值（`scrub`）**：开启 `scrub` 后可在 `Label` 上横向拖动连续调值（`scrubSteps` 默认 `100`，`direction="rtl"` 反转方向）；松手且值变化时提交一次，取消拖动恢复原值。输入框内文本保持正常可选。
- **与 Field / Form 集成**：置于 [Field](/zh-cn/ui-libraries/liquid-glass/field/) 或 [Form](/zh-cn/ui-libraries/liquid-glass/form/) 内时，使用 `Control` 替代 `Input` 以自动联动 `FieldLabel`、校验、表单序列化与重置；独立使用时继续搭配 `NumberFieldLabel`。

## API

| 部件 | 属性 / 方法 / 状态 | 默认值与说明 |
| --- | --- | --- |
| Root | `value` / `defaultValue` | `number \| null`；`value={null}` 仍为受控空值 |
| Root | `min` / `max` / `step` | `0` / `100` / `1`（正数步长） |
| Root | `allowEmpty` | `false`；设为 `true` 允许清空提交 `null` |
| Root | `locale` / `formatOptions` | 本地化十进制、货币或百分比格式配置 |
| Root | `scrub` / `scrubSteps` / `direction` | 启用标签拖拽调值、`scrubSteps` 默认 `100` |
| Root | `disabled` / `readOnly` / `name` / `ariaLabel` | 交互控制、字段名与可访问名称 |
| Root / Input / Control | `getValue()` / `empty` / `formatInvalid` | 获取真实 `number \| null`、空值标记与格式配置诊断 |
