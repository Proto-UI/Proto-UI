Root 管理有限数值 value/defaultValue、min/max（0/100）、正 step（1）、disabled/readOnly、name、ariaLabel。Input 使用现有 TextControl 唯一编辑器与 spinbutton 语义。编辑允许未完成草稿，失焦/Enter 提交合法数值或恢复规范值；加减按钮与上下箭头共享步进，Shift 十倍，Home/End 达边界。受控提案不覆盖作者值；本地化格式、空/null、拖擦与滚轮尚未实现。

在 Field/FormField 内用 Control 替代 Input，FieldLabel 命名并激活真实编辑器，联动 Field 策略、规范数值校验、IME 取消、Form 序列化及复位。独立 Input 仍使用 NumberFieldLabel。

部件: root, label, input, control, increment, decrement. 四个视觉家族继承同一 Base 行为。

当前为 Draft 源码工作。原生、辅助技术、完整 Adapter/Compiler/GPUI、包消费及独立验收仍待完成，不宣称 Finf 验收通过。
