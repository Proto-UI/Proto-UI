Liquid Glass Text 基于 [Base Text](/zh-cn/ui-libraries/base/text/)（通过 `asTextRoot()`），提供完整的八个独立排版控制轴与默认内容槽。它仅负责排版样式，不引入标题层级、链接、标签、按钮或编辑交互。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

```ts
import { textRoot, LiquidGlassTextRoot } from '@proto.ui/prototypes-liquid-glass/text';
```

## 用法

- 显式传入的 `leading` 优先于 `size` 自带的默认行高；移除任意属性即可恢复默认值。
- 当文本嵌套在带前景色的容器（如 Surface）中时，设置 `tone="inherit"` 可自动继承外层文字颜色。
- Text 不覆盖 `user-select`：普通文档内容保持自然可选，交互控件内的文字遵循所在控件的选择策略。
- 需要语义元素时，请在外部组合原生的 `h1`、`p`、`label`、`a` 或 `button`。

Liquid Glass 主题内置 `body`、`heading` 与 `mono` 系统字体栈以及 `default`/`muted` 文本色，不额外捆绑第三方字体文件。

## API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `size` | `'xs' \| 'sm' \| 'base' \| 'lg' \| 'xl' \| '2xl' \| '3xl' \| '4xl' \| '5xl'` | `'base'` | 字号规格 |
| `tone` | `'default' \| 'muted' \| 'inherit'` | `'default'` | 文本颜色语义 |
| `weight` | `'normal' \| 'medium' \| 'semibold' \| 'bold'` | `'normal'` | 字重 |
| `font` | `'body' \| 'heading' \| 'mono'` | `'body'` | 字体族 |
| `leading` | `'tight' \| 'snug' \| 'normal' \| 'relaxed'` | `'normal'` | 行高，显式设置时优先于字号默认行高 |
| `tracking` | `'normal' \| 'tight'` | `'normal'` | 字距 |
| `emphasis` | `'normal' \| 'italic'` | `'normal'` | 倾斜样式 |
| `decoration` | `'none' \| 'underline' \| 'line-through'` | `'none'` | 文本装饰线 |
