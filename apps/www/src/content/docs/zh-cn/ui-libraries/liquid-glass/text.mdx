Liquid Glass Text 基于 [Base Text](/zh-cn/ui-libraries/base/text/) 提供全部八项独立排版控制轴，采用系统无衬线与等宽字体栈及清晰的前景层次，仅负责排版展示而不承载玻璃材质或交互语义。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可从 `@proto.ui/prototypes-liquid-glass/text` 导入 `textRoot`（同时导出 `liquidGlassTextRoot` 与 `LiquidGlassTextRoot` 别名），或在工作区模式下通过 CLI 目标 `liquid-glass-text` 生成四框架封装。

## 用法

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { liquidGlassTextRoot } from '@proto.ui/prototypes-liquid-glass/text';

const Text = createReactAdapter(React)(liquidGlassTextRoot, { rootTag: 'span' });

export function SheetHeading() {
  return (
    <h2>
      <Text size="2xl" font="heading" weight="semibold" leading="tight" tracking="tight">
        Display &amp; Clarity
      </Text>
    </h2>
  );
}
```

### Liquid Glass 材质层次与可读性规范

参考 Apple [Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 与 [Typography](https://developer.apple.com/design/human-interface-guidelines/typography) 指南：

- **文字不叠加玻璃**：长正文和内容标题应落在清晰的不透明内容画布上；位于悬浮 Liquid Glass 控件或工具栏内的标签通过 `tone="inherit"` 继承外层前景色，切勿给 Text 自身套用玻璃材质或在玻璃表面内再次叠加玻璃（避免 glass-on-glass）。
- **常规与强调层级**：常规透明控件（`material="auto"`）内部适合使用高对比度主色文字搭配弱化副标题（`tone="muted"`）；强调染色表面（`solid` / `prominent`）内部应使用 `tone="inherit"` 保持白色前景可读性。
- **减弱透明度与高对比度回退**：当用户开启减少透明度、增强对比度或外层容器切换为 `material="opaque"` 时，依靠主题语义前景色与 `tone="inherit"` 即可平滑保持清晰对比度，无需依赖半透明降暗。
- **行高、字距与选择策略**：`leading="size"` 保留字号内建行高，`leading="tighter"` 为 `1.1`，`tracking="tighter"` 为 `-0.05em`；Text 不覆盖 `user-select`，正文保持自然可选，标题与链接语义仍由外层原生 `h1`、`p`、`label`、`a` 或 `button` 负责。
