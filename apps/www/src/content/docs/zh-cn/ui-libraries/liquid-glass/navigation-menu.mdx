## 用法

- **部件组成**：`Root`、`Trigger`、`Content`、`Item`、`Link`。
- **面板与命令**：`Root.value` 标识当前唯一展开的命名 `region` 面板；`Trigger` 控制面板开关；`Item` 发出应用命令。
- **原生链接行为**：`Link` 在 React / Vue / Vue 2 中渲染为原生锚点根元素（Web Components 中托管于局部锚点内），支持 `href`、`target`、`rel` 与 `current`（自动映射 `aria-current`）。禁用 `Link` 会移除跳转目标并阻止激活。
- **导航观察与关闭**：原生链接激活后会发出只读 `navigate` 事件（包含 `href`、`target`、`rel`、`modified` 字段）。普通的当前窗口跳转默认自动关闭面板（设 `closeOnSelect={false}` 可保持打开）；按住修饰键、中键点击或 `_blank` 打开新窗口时保持当前面板展开。

## API

| 部件 | 属性 / 事件 | 说明 |
| --- | --- | --- |
| Root | `value` / `closeOnSelect` | 当前展开面板标识 / 普通同窗链接激活后是否自动关闭面板 |
| Trigger / Content | — | 展开按钮与命名导航面板（`region`） |
| Item | — | 可触发应用命令的菜单项 |
| Link | `href` / `target` / `rel` / `current` / `disabled` | 原生导航链接属性与当前页标记；激活后发出只读 `navigate` 事件 |
