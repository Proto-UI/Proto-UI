Liquid Glass Collapsible 由 Root、Trigger、Content 三个部件组成，继承 [Base Collapsible](/zh-cn/ui-libraries/base/collapsible/) 的展开语义，并为 Trigger 提供 Liquid Glass 材质外观。展开状态由 Root 统一管理。

## 用法

- **部件组合**：每个 `Root` 内放置一个 `Trigger` 与一个 `Content`；嵌套或并列的折叠区块各自独立维护状态。
- **受控与禁用**：受控模式下仅发出 `openChange` 请求，待调用方更新 `open` 后内容才展开或收起。`disabled` 会禁止新操作，但不会关闭已经展开的内容。
- **内容挂载与布局**：关闭时默认卸载内容节点（设置 `keepMounted={true}` 可保留隐藏节点）。组件内置可收缩宽度、长词换行与自适应高度，建议在容器外预留焦点环空间。
- **材质表现**：仅 `Trigger` 声明 `liquid-glass` 材质意图并响应按压状态，`Root` 与正文 `Content` 保持不透明可读样式；宿主不支持材质时自动使用声明的不透明回退色。参考 [Apple Materials 指南](https://developer.apple.com/design/human-interface-guidelines/materials)。

## API

| 部件 | 属性 | 默认值与说明 |
| --- | --- | --- |
| Root | `open` / `defaultOpen` | 受控展开状态 / 非受控初始展开状态 |
| Root | `disabled` | `false`；禁用全部切换请求但不关闭已展开内容 |
| Trigger | `disabled` | `false`；局部禁用触发按钮，支持自然 Tab 顺序与 Enter / Space 激活 |
| Content | `keepMounted` | `false`；设为 `true` 时关闭后保留隐藏节点 |

### 事件与方法

- Root 暴露：`open` 状态、`openCollapsible()`、`close()`、`toggle()` 以及 `openChange` 事件（载荷 `{ open, reason }`）。
- Trigger 暴露：展开、禁用、悬停、按压、焦点状态与 `focusSelf()`。
- Content 暴露：派生的 `open` / `hidden` 状态。
