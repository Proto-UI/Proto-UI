Liquid Glass Collapsible 由 `Root`、`Trigger` 与 `Content` 三个部件组成，继承 [Base Collapsible](/zh-cn/ui-libraries/base/collapsible/) 的展开语义，并仅在可交互的 `Trigger` 上声明 Liquid Glass 材质意图，保持 `Root` 与阅读正文 `Content` 不透明清晰可读。

## 安装

当前仅在源码工作区提供，可直接从 `@proto.ui/prototypes-liquid-glass/collapsible` 导入部件：

```ts
import {
  collapsibleRoot,
  collapsibleTrigger,
  collapsibleContent,
} from '@proto.ui/prototypes-liquid-glass/collapsible';
```

## 用法

```tsx
import {
  LiquidGlassCollapsibleRoot,
  LiquidGlassCollapsibleTrigger,
  LiquidGlassCollapsibleContent,
} from '@/components/ui/collapsible';

export function Example() {
  return (
    <LiquidGlassCollapsibleRoot>
      <LiquidGlassCollapsibleTrigger variant="regular">
        Order #4189 — Product details
      </LiquidGlassCollapsibleTrigger>
      <LiquidGlassCollapsibleContent>
        Status: Shipped · Content stays opaque for crisp legibility.
      </LiquidGlassCollapsibleContent>
    </LiquidGlassCollapsibleRoot>
  );
}
```

### 部件结构与材质分层

```text
CollapsibleRoot          (opaque container)
├── CollapsibleTrigger   (liquid-glass control, regular | prominent, material auto | opaque)
└── CollapsibleContent   (opaque reading surface — never glass on glass)
```

- **单层玻璃原则**：仅 `Trigger` 声明 `liquid-glass` 光学意图与按压形变；`Root` 与承载长文本的 `Content` 保持不透明，避免玻璃叠加玻璃导致对比度下降。
- **显著度分级与不透明退出**：`Trigger` 支持 `variant="regular"`（常规中性玻璃）与 `variant="prominent"`（主色强调玻璃），并可通过 `material="opaque"` 显式退出光学材质而保留完整不透明样式。
- **同心圆角与无障碍回退**：外层卡片采用 `rounded-2xl` 搭配内层 `rounded-xl` 控件形成同心圆角关系；禁用态通过撤回光学候选与阴影保持文字清晰可读，而非降低整体透明度。参考 [Apple Materials 指南](https://developer.apple.com/design/human-interface-guidelines/materials)。
