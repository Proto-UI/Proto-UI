Liquid Glass Tooltip 在悬停或键盘聚焦时以简洁的浮层展示补充说明。遵循 Apple Liquid Glass 层级原则，提示内容属于非交互式辅助信息，采用带同心圆角（`rounded-xl`）与细边高光的标准不透明材质，避免在玻璃控件之上再次叠加玻璃层。

## 安装

Liquid Glass Tooltip 当前以工作区源码提供，可通过 `@proto.ui/prototypes-liquid-glass/tooltip` 导入 `tooltipGroup`、`tooltipRoot`、`tooltipTrigger` 与 `tooltipContent`，配合任意宿主 Adapter 使用。

## 用法

```tsx
import {
  LiquidGlassTooltipGroup,
  LiquidGlassTooltipRoot,
  LiquidGlassTooltipTrigger,
  LiquidGlassTooltipContent,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <LiquidGlassTooltipGroup>
      <LiquidGlassTooltipRoot>
        <LiquidGlassTooltipTrigger>Account</LiquidGlassTooltipTrigger>
        <LiquidGlassTooltipContent side="top">View account settings</LiquidGlassTooltipContent>
      </LiquidGlassTooltipRoot>
    </LiquidGlassTooltipGroup>
  );
}
```

### 组件结构

```text
TooltipGroup (可选)
└── TooltipRoot
    ├── TooltipTrigger
    └── TooltipContent
```

### 材质与无障碍

- **不叠玻璃**：Liquid Glass 折射材质保留给按钮、工具栏等功能性控件；Tooltip 作为非交互说明采用高可读性的标准不透明表面与细微内描边高光。
- **同心几何**：面板圆角与胶囊触发器保持协调比例，支持浅色与深色模式自动切换。
- **系统偏好回退**：开启「减少透明度」或「强制颜色」时切换为高对比度实色边框并移除阴影；开启「减弱动态效果」时关闭淡入缩放动效。

### 事件、状态与方法

- **Root**：暴露状态 `open`，事件 `openChange`（`{ open, reason }`），方法 `openTooltip(reason?)`、`close(reason?)`、`toggle(reason?)`。
- **Trigger**：暴露状态 `disabled`、`hovered`、`focused`、`focusVisible`，方法 `focusSelf(options?)`。
- **Content**：暴露状态 `open` 与 Transition 状态（`transitionState`、`isPresent`、`controls`）。
