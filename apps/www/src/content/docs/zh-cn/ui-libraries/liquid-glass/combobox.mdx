Liquid Glass Combobox 将可编辑搜索框与下拉选项列表结合。与 Autocomplete 不同，Combobox 将已选选项标识 `value` 与输入文本 `inputValue` 严格区分，未匹配任何选项的输入不会自动成为已选值。

## 用法

- **部件组成**：`Root`、`Input`、`Content`、`Item`、`Empty`、`Trigger`。
- **独立状态**：`open`、`value`（选项标识）与 `inputValue`（搜索文本）均支持独立受控。
- **搜索与导航**：默认按 `textValue` 与 `keywords` 执行忽略大小写和重音的过滤，也可设置 `filter={false}` 由应用提供已过滤子项。方向键浏览时焦点留在 `Input`，IME 组合输入期间不会误选；`Empty` 反映实际匹配数，禁用项和重复值项不会提交。

## API

| 部件  | 属性                                  | 说明                                            |
| ----- | ------------------------------------- | ----------------------------------------------- |
| Root  | `value` / `inputValue` / `open`       | 独立受控的已选选项键、输入查询文本与弹层状态    |
| Root  | `filter`                              | 设为 `false` 时关闭内置过滤，使用外部已过滤子项 |
| Item  | `textValue` / `keywords` / `disabled` | 选项文本、匹配关键词与禁用开关                  |
| Empty | —                                     | 无匹配选项时显示的空状态                        |
