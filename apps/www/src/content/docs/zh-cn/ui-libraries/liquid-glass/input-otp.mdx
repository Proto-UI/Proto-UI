## 用法

- **部件组成**：`Root`、`Input`、`Control`、`Slot`、`Separator`。
- **单输入框与光标高亮**：所有文本编辑都发生在同一个可访问的 `Input` 中，`Slot` 仅为 `aria-hidden` 被动格子，不会产生多余 Tab 停靠点。当可编辑的输入框处于聚焦状态时，高亮槽位严格跟随真实光标或选区位置；失焦、禁用或只读时不显示活动槽。
- **字符过滤与完成事件**：支持 `numeric` 或 `alphanumeric` 过滤以及 `1–32` 位长度（默认 `6`），在 IME 组合结束后自动过滤非法字符并截断长度。每次接受完整验证码时触发一次 `completed` 事件（受控模式下 `valueChange` 仅发出提议）。
- **与 Field / Form 集成**：在 [Field](/zh-cn/ui-libraries/liquid-glass/field/) 或 [Form](/zh-cn/ui-libraries/liquid-glass/form/) 中使用 `Control` 替代 `Input`，即可自动桥接 `FieldLabel`、校验、IME 取消、表单序列化与重置；单独使用时继续使用 `Input`。

## API

| 部件 | 属性 / 事件 | 默认值与说明 |
| --- | --- | --- |
| Root | `value` / `defaultValue` | 受控 / 非受控验证码字符串 |
| Root | `length` | `6`（支持 `1–32`） |
| Root | `disabled` / `readOnly` / `name` / `ariaLabel` | 禁用、只读、字段名与可访问名称 |
| Root | `valueChange` / `completed` | 值变更请求事件 / 每次接受完整验证码后触发 |
| Input / Control | — | 独立使用的真实编辑器 / 用于 Field 与 Form 内的桥接控件 |
| Slot / Separator | — | 被动字符展示槽与视觉分隔符 |
