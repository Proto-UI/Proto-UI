## 用法

- **模式配置**：范围模式使用 `mode="range"` 与 `range` / `defaultRange`，多选模式使用 `mode="multiple"` 与 `values` / `defaultValues`。日期边界、不可用日期、数量与间隔天数规则完全继承 [Calendar](/zh-cn/ui-libraries/liquid-glass/calendar/)。
- **弹层关闭时机**：
  - 单日期选择被接受后，自动请求关闭弹层。
  - 范围模式选择第一个端点时保持打开，第二个端点被接受并形成完整范围后请求关闭一次。
  - 多选模式持续保持打开以便连续勾选，完成后按 Popover 的常规方式（点击外部、Escape 或关闭按钮）收起。
  - 若受控模式拒绝了选择请求，弹层会保持打开；外部单纯改值不会触发关闭。
- **值展示格式**：`Value` 分别显示单个 `YYYY-MM-DD` 日期、逗号分隔的有序日期列表、未完成范围的 `from …` 或完整范围的 `from – to`；为空时显示 `placeholder`。焦点返回与外部关闭由 Popover 管理。

## API

| 属性                       | 说明                                          |
| -------------------------- | --------------------------------------------- |
| `open` / `defaultOpen`     | 控制弹层开关（继承 Popover）                  |
| `mode`                     | `'single'`（默认）、`'multiple'` 或 `'range'` |
| `value` / `defaultValue`   | 单日期选择值                                  |
| `values` / `defaultValues` | 多选日期数组                                  |
| `range` / `defaultRange`   | 范围选择值 `{ from?, to? }`                   |
| `month` / `defaultMonth`   | 当前显示的日历月份（`YYYY-MM`）               |
| `placeholder`              | 无选中日期时在 `Value` 中显示的占位文本       |
| `disabled` / `readOnly`    | 禁用或只读控制                                |

完整的日期约束、回调与网格部件请参阅 [Calendar](/zh-cn/ui-libraries/liquid-glass/calendar/)。
