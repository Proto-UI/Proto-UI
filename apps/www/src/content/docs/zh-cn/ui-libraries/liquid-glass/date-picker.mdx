Liquid Glass Date Picker 将胶囊形触发器、单层 `regular` Liquid Glass 浮动弹层与同心圆形日历单元格组合在一起，支持单日期、多选与范围三种模式，并可通过 `material="opaque"` 显式退回到高可读性不透明表面。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。`Date Picker` 由 Liquid Glass 的 `Popover` 与 `Calendar` 部件组合构成。

## 用法

```tsx
import {
  LiquidGlassDatePickerRoot,
  LiquidGlassDatePickerTrigger,
  LiquidGlassDatePickerValue,
  LiquidGlassDatePickerContent,
  LiquidGlassDatePickerDay,
  LiquidGlassCalendarCaption,
  LiquidGlassCalendarPrevious,
  LiquidGlassCalendarHeading,
  LiquidGlassCalendarNext,
  LiquidGlassCalendarGrid,
  LiquidGlassCalendarWeekdays,
  LiquidGlassCalendarWeekday,
  LiquidGlassCalendarRow,
} from '../proto-ui/components/react';

export function LiquidGlassDatePickerExample() {
  return (
    <LiquidGlassDatePickerRoot defaultMonth="2026-10">
      <LiquidGlassDatePickerTrigger className="w-56" variant="regular">
        <LiquidGlassDatePickerValue placeholder="Pick a date" />
        <span aria-hidden="true">▾</span>
      </LiquidGlassDatePickerTrigger>
      <LiquidGlassDatePickerContent side="bottom" align="start" sideOffset={6} material="auto">
        <LiquidGlassCalendarCaption>
          <LiquidGlassCalendarPrevious a11yLabel="Previous month">‹</LiquidGlassCalendarPrevious>
          <LiquidGlassCalendarHeading />
          <LiquidGlassCalendarNext a11yLabel="Next month">›</LiquidGlassCalendarNext>
        </LiquidGlassCalendarCaption>
        <LiquidGlassCalendarGrid>
          <LiquidGlassCalendarWeekdays>
            {[0, 1, 2, 3, 4, 5, 6].map((offset) => (
              <LiquidGlassCalendarWeekday key={offset} offset={offset} />
            ))}
          </LiquidGlassCalendarWeekdays>
          {[0, 1, 2, 3, 4, 5].map((row) => (
            <LiquidGlassCalendarRow key={row} index={row}>
              {[0, 1, 2, 3, 4, 5, 6].map((col) => (
                <LiquidGlassDatePickerDay key={col} offset={row * 7 + col} />
              ))}
            </LiquidGlassCalendarRow>
          ))}
        </LiquidGlassCalendarGrid>
      </LiquidGlassDatePickerContent>
    </LiquidGlassDatePickerRoot>
  );
}
```

- **单层材质与同心几何**：仅展开后的 `DatePickerContent` 声明 `regular` 级别 Liquid Glass 材质（不叠加双层玻璃）；`DatePickerTrigger` 使用胶囊形轮廓并支持 `regular` / `prominent` 突出度层级；弹层内日期单元采用圆形同心布局。
- **材质回退与无障碍**：当宿主启用减少透明度、高对比度或开发者传入 `material="opaque"` 时，弹层回退为 `bg-secondary` + `text-secondary-foreground` 高对比表面；禁用态避免降低整体透明度以保持文字清晰可读；减弱动态效果偏好会自动关闭弹层动画。
- **选择模式与关闭时机**：单选与完成范围选择后自动请求关闭弹层，多选模式保持展开以便连续选择。日期边界、不可用日期与约束规则继承自 [Calendar](/zh-cn/ui-libraries/liquid-glass/calendar/)。
