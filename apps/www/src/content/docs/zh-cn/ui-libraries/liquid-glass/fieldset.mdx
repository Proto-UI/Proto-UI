Liquid Glass Fieldset 由 `Root`、`Legend`、`Description` 三个部件组成，用于将多个相关字段组织为语义分组，并向下级联禁用策略。它属于内容层分组容器，保持圆角边框的普通不透明表面（`gap-3`），不请求玻璃材质，内部交互控件保留各自的外观与材质策略。

## 用法

- **级联禁用**：有效禁用状态等于“自身 `disabled` 或外层 `Fieldset` 已禁用”。在三层嵌套（`outer → middle → inner`）中：
  - 仅禁用 `outer` 时，三层均处于禁用状态；
  - 将 `middle` 也设为禁用后重新启用 `outer`，`middle` 与 `inner` 仍保持禁用；
  - 再启用 `middle` 时，`inner` 恢复可用（除非自身仍设为 `disabled`）。
- 组内参与的 Field（包括位于 `Legend` 内的 Field）均会继承禁用状态并自行处理校验失效；Fieldset 本身不管理值、校验或表单提交。
- **无障碍关联**：`Root` 自动声明 `group` 角色并将 `Legend` 与 `Description` 关联为分组名称和描述，无需手写 DOM ID。每个分组最多包含一个 `Legend` 与一个 `Description`（重复声明会被忽略），且嵌套分组不会互相借用名称或说明。

## API

| 部件        | 属性        | 默认值  | 说明                                           |
| ----------- | ----------- | ------- | ---------------------------------------------- |
| Root        | `disabled`  | `false` | 禁用本组及嵌套子组内的参与字段                 |
| Root        | `ariaLabel` | `''`    | 分组的可访问名称                               |
| Legend      | —           | —       | 可选的半粗体分组标题，继承有效 `disabled` 状态 |
| Description | —           | —       | 可选的弱化色分组说明，继承有效 `disabled` 状态 |

三个部件均暴露只读的有效 `disabled` 状态；如需更改禁用策略，请更新 `Root` 的 `disabled` 属性。
