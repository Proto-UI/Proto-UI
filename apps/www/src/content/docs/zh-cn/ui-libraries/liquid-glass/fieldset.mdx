Liquid Glass Fieldset 由 `Root`、`Legend`、`Description` 三个部件组成，用于将多个相关字段组织为语义分组，并向下级联禁用策略。作为内容层分组容器，它采用圆角边框与不透明分组表面（顶层 `rounded-2xl bg-secondary p-4`，嵌套层自动收缩为同心 `rounded-xl bg-background p-3`），不请求玻璃材质，避免玻璃叠玻璃，并让内部交互控件保留各自的材质与外观层级。

## 用法

```tsx
import {
  FieldsetRoot,
  FieldsetLegend,
  FieldsetDescription,
} from '@/components/liquid-glass/fieldset';
import { FieldRoot, FieldLabel, FieldControl } from '@/components/liquid-glass/field';

export function Example() {
  return (
    <FieldsetRoot>
      <FieldsetLegend>Address Information</FieldsetLegend>
      <FieldsetDescription>We need your address to deliver your order.</FieldsetDescription>
      <FieldRoot required>
        <FieldLabel>Street Address</FieldLabel>
        <FieldControl placeholder="123 Main St" />
      </FieldRoot>
    </FieldsetRoot>
  );
}
```

- **内容层表面与同心圆角**：顶层 `Fieldset.Root` 渲染为不透明分组表面（`rounded-2xl bg-secondary p-4`），嵌套子 `Fieldset.Root` 自动收缩为同心内圆角与对比表面（`rounded-xl bg-background p-3`），保持亮暗模式与增强对比度环境下的清晰边界。禁用态通过语义前景色（`text-muted-foreground`）区分而非降低整块容器透明度。
- **级联禁用**：有效禁用状态等于“自身 `disabled` 或外层 `Fieldset` 已禁用”。在三层嵌套（`outer → middle → inner`）中：
  - 仅禁用 `outer` 时，三层均处于禁用状态；
  - 将 `middle` 也设为禁用后重新启用 `outer`，`middle` 与 `inner` 仍保持禁用；
  - 再启用 `middle` 时，`inner` 恢复可用（除非自身仍设为 `disabled`）。
- 组内参与的 Field（包括位于 `Legend` 内的 Field）均会继承禁用状态并自行处理校验失效；Fieldset 本身不管理值、校验或表单提交。
- **无障碍关联**：`Root` 自动声明 `group` 角色并将 `Legend` 与 `Description` 关联为分组名称和描述，无需手写 DOM ID。每个分组最多包含一个 `Legend` 与一个 `Description`（重复声明会被忽略），且嵌套分组不会互相借用名称或说明。

### Description

`Description` 不声明独立属性；三个部件均暴露只读的有效 `disabled` 状态（`ExposeState<boolean>`），如需更改禁用策略请更新 `Root` 的 `disabled` 属性。
