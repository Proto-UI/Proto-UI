## 用法

- **部件组成**：`Root`、`Trigger`、`Content`、`Item`。
- **触发与定位**：
  - 右键点击或触摸/笔在移动容差内按住 600ms 时，菜单锚定在输入点（默认 `bottom`/`start`，无额外间距）；长按中途移动、松开、取消、禁用或卸载会自动取消。普通左键点击与滚动不受影响。
  - 按下 `ContextMenu` 或 `Shift+F10`、或调用编程方法 `openContextMenu()` 时，菜单以触发区域作为后备锚点。
- **键盘与关闭**：`Content` 支持上下方向键导航、首字母输入跳转（typeahead）、外部点击关闭以及 Escape / 选中命令后恢复触发器焦点。
- **受控模式**：传入 `open` 时，菜单仍以请求方式通知调用方；若调用方延后打开，会自动复用最近有效的输入锚点。

## API

| 部件                     | 属性 / 方法            | 说明                                   |
| ------------------------ | ---------------------- | -------------------------------------- |
| Root                     | `open` / `defaultOpen` | 受控 / 非受控打开状态                  |
| Root                     | `disabled`             | 禁用菜单唤起                           |
| Root                     | `closeOnItemCommit`    | 选中菜单项后是否自动请求关闭           |
| Root                     | `openContextMenu()`    | 以触发区域为锚点以编程方式请求打开菜单 |
| Trigger / Content / Item | —                      | 触发区域、浮层菜单容器与可执行菜单项   |
