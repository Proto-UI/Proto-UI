Liquid Glass Command 提供始终展开的内联搜索命令列表。输入查询仅用于筛选候选命令，按下 Enter 或点击命令项时会发出携带选中项的 `execute` 事件，由应用执行对应操作。

## 用法

- **部件组成**：`Root`、`Input`、`Content`、`Item`、`Empty`。
- **搜索与执行**：按 `textValue` 与 `keywords` 忽略大小写和重音过滤，也可设置 `filter={false}` 传入已过滤列表。方向键在命令间移动时焦点保持在 `Input`，IME 组合输入期间不触发执行。
- **状态与边界**：`open`、`value` 与 `inputValue` 均支持独立受控；`Empty` 反映实际匹配数，禁用项和重复值项不会触发 `execute`。

## API

| 部件        | 属性 / 事件                           | 说明                                       |
| ----------- | ------------------------------------- | ------------------------------------------ |
| Root        | `value` / `inputValue` / `open`       | 独立受控的命令状态与查询文本               |
| Root        | `filter`                              | 设为 `false` 时关闭内置过滤                |
| Root / Item | `execute`                             | Enter 或点击可用命令项时发出的执行意图事件 |
| Item        | `textValue` / `keywords` / `disabled` | 命令名称、匹配关键词与禁用开关             |
| Empty       | —                                     | 无匹配命令时显示的空状态                   |
