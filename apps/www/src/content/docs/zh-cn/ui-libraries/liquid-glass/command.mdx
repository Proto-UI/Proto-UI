Liquid Glass Command 采用同心圆角与高可读表面层次提供实时过滤的命令面板；内联列表保持清晰不透明，仅由外层浮层 `Dialog` 承载液态玻璃材质，避免玻璃叠玻璃。

## 用法

```tsx
import {
  commandRoot,
  commandInput,
  commandContent,
  commandItem,
  commandEmpty,
} from '@proto.ui/prototypes-liquid-glass/command';
```

### 部件组合结构

```text
CommandRoot
├── CommandInput
└── CommandContent
    ├── CommandItem
    └── CommandEmpty
```

- **材质层次与同心圆角**：`CommandContent` 作为内联内容层保持常规不透明表面（`rounded-2xl` + `p-1`），内部命令项使用同心 `rounded-xl` 圆角；需要浮层液态玻璃质感时，将其放入 `liquid-glass-dialog-content` 浮层容器中。
- **无障碍偏好回退**：禁用项使用清晰低对比前景色而非降低整体透明度；动画受 `prefers-reduced-motion` 保护，降低透明度偏好下保持高对比实体面板。
- **过滤与键盘**：按 `textValue` 与 `keywords` 忽略大小写和重音匹配，设置 `filter={false}` 可接入外部过滤；方向键浏览时焦点留在输入框，IME 组合输入期间不触发执行。

### 其他部件与事件

- **Input**：`placeholder`、`a11yLabel`、`name` 均默认为 `''`。
- **Content**：`side="bottom"`、`align="start"`、`sideOffset={4}`、`collisionPadding={8}`。
- **Item**：`value`、`textValue`、`keywords` 均默认为 `''`，`disabled` 默认为 `false`。
- **Empty**：无独立属性，无匹配命令时自动显示。
- **事件**：`Root` 触发 `execute`、`valueChange`、`inputValueChange` 与 `openChange`。
