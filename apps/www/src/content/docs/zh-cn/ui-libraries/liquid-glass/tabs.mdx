Liquid Glass Tabs 由 `Root`、`List`、`Trigger`、`Content` 四个部件组成，继承 [Base Tabs](/zh-cn/ui-libraries/base/tabs/) 协议。默认呈现圆角分段材质样式（自动支持不透明回退），并额外提供透明背景细下划线变体（`appearance="underline"`）。

## 用法

- **状态与导航**：选中值由 `Root` 统一管理。方向键与 `Home` / `End` 在可用选项卡之间移动焦点；在手动激活模式下，按 Enter / Space 才切换选中面板（适合避免方向键浏览时频繁重挂内容）。受控模式下需由调用方更新 `value`。
- **外观变体**：默认使用 Liquid Glass 分段外观；在 `List` 与 `Trigger` 上传入 `appearance="underline"` 可切换为透明背景、与文字等宽的细下划线样式。

## API

| 部件    | 属性                                | 说明                                             |
| ------- | ----------------------------------- | ------------------------------------------------ |
| Root    | `value` / `defaultValue`            | 受控 / 非受控当前选中选项卡标识                  |
| Root    | `activationMode` / `orientation`    | 自动或手动键盘激活模式 / 水平或垂直排布          |
| List    | `appearance`                        | 默认分段样式；设为 `'underline'` 使用下划线外观  |
| Trigger | `value` / `disabled` / `appearance` | 选项卡标识、禁用态与外观变体                     |
| Content | `value` / `keepMounted`             | 对应选项卡标识；设为 `true` 时切换后保留隐藏节点 |
