Liquid Glass Tabs 基于 [Base Tabs](/zh-cn/ui-libraries/base/tabs/) 语义协议构建，将 Liquid Glass 半透明材质限定在导航层 `TabsList` 上（不在 `TabsTrigger` 或 `TabsContent` 上重复叠加玻璃层），提供胶囊同心圆角分段外观、`regular` / `prominent` 视觉层级以及 `material="opaque"` 显式不透明回退。

## 安装

当前在源码工作区提供，可直接从 `@proto.ui/prototypes-liquid-glass/tabs` 导入。

```ts
import {
  tabsRoot,
  tabsList,
  tabsTrigger,
  tabsContent,
  tabsIndicator,
} from '@proto.ui/prototypes-liquid-glass/tabs';
```

## 用法

```html
<wc-liquid-glass-tabs-root default-value="overview">
  <wc-liquid-glass-tabs-list>
    <wc-liquid-glass-tabs-trigger value="overview">Overview</wc-liquid-glass-tabs-trigger>
    <wc-liquid-glass-tabs-trigger value="analytics">Analytics</wc-liquid-glass-tabs-trigger>
  </wc-liquid-glass-tabs-list>
  <wc-liquid-glass-tabs-content value="overview">Overview content.</wc-liquid-glass-tabs-content>
  <wc-liquid-glass-tabs-content value="analytics">Analytics content.</wc-liquid-glass-tabs-content>
</wc-liquid-glass-tabs-root>
```

### 组件结构

```text
TabsRoot
├── TabsList (Liquid Glass 材质层)
│   ├── TabsTrigger (同心圆角选中透镜，不叠加玻璃)
│   └── TabsTrigger
├── TabsContent (中性内容层，不叠加玻璃)
└── TabsContent
```

- **材质分层与回退**：仅 `TabsList` 在 `appearance="default"` 且 `material="auto"` 时声明 `liquid-glass` 材质候选；遇到降低透明度、高对比度或显式 `material="opaque"` 时自动回退到高对比度不透明表面。
- **动效与无障碍**：选中与悬停过渡自动响应 `prefers-reduced-motion: reduce` 禁用过渡动效，焦点环采用内嵌高对比度轮廓并支持 `forced-colors`。

### 层级与不透明回退
