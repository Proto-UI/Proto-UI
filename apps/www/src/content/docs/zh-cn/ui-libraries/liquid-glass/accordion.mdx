## 用法

### 结构与状态管理

按 `Root → Item → Heading → Trigger` 组合，并将 `Content` 与 `Heading` 并列。每个 `Item` 需提供唯一且稳定的非空 `value`。展开集合由 Root 统一管理，嵌套的 Root 彼此独立。`Heading` 内仅放置控制该项的 `Trigger`，常驻次级操作应放在旁边。

- 重复的输入键会自动去重，重复注册的 `Item` 标识会被忽略。`single` 模式下只采用首个有效键。
- 尚未挂载的键会保留为待激活状态，便于渐进挂载；对不存在的项发起请求会被忽略。
- 受控模式下，触发交互仅发出 `openChange` 请求，不会提前修改状态；将新的 `openItems` 传回 Root 才算完成更新。

### 键盘与无障碍

- 每个启用的标题及传入的子元素内可聚焦元素保持自然的 Tab 顺序；Enter / Space 切换当前项。
- 纵向模式使用上下方向键、横向模式使用左右方向键（RTL 下自动反转）及 Home / End 在启用标题间移动焦点，移动焦点不会改变展开状态。
- 禁用标题会被导航跳过；当 `allowEmpty={false}` 且只剩最后一项展开时，该标题仍可聚焦并通过 `aria-disabled` 阻止关闭。
- `Heading` 声明标题层级，`Trigger` 自动维护按钮角色、展开状态与精确的 `aria-controls` 关联；需要地标语义时可在 `Content` 上开启 `region={true}`。

### 内容卸载与材质

- 关闭时默认卸载内容节点（设置 `keepMounted={true}` 可保留隐藏节点），但不自动移动焦点或添加延迟关闭定时器。
- 仅交互式的 `Trigger` 声明 `liquid-glass` 材质意图并响应按压状态，其余部件保持不透明可读外观；宿主不支持材质时自动回退到声明的不透明主题色。

## API

| 部件 | 属性 | 默认值与说明 |
| --- | --- | --- |
| Root | `mode` | `'single'`；设为 `'multiple'` 时允许多项独立展开 |
| Root | `openItems` / `defaultOpenItems` | 字符串数组；传入 `openItems` 即进入受控模式，`defaultOpenItems` 仅初始化一次 |
| Root | `allowEmpty` | `true`；设为 `false` 时禁止关闭最后一个展开项 |
| Root | `disabled` | `false`；禁用全部交互但不修改受控值 |
| Root | `orientation` / `direction` / `loop` | `'vertical'` / `'ltr'` / `true`；控制标题键盘导航方向与循环 |
| Item | `value` / `disabled` | `value` 为必填非空稳定键；`disabled` 默认 `false` |
| Heading | `level` | `1–6` 整数，默认 `3` |
| Trigger | — | 从 Item 与 Root 派生交互和无障碍状态 |
| Content | `keepMounted` / `region` | 均为 `false`；控制关闭后是否保留隐藏节点及是否声明 `region` 地标 |

### 事件与方法

- `getOpenItems()`：返回当前展开键数组的副本。
- `openCount`：当前展开键数量（含尚未挂载的键）。
- `requestOpen(value, open, reason?)`：请求展开或收起指定项，`reason` 为 `'pointer' | 'keyboard' | 'programmatic'`。
- `openChange`：载荷为 `{ openItems, value, open, reason }`；初始化、受控同步与无效请求不触发该事件。
