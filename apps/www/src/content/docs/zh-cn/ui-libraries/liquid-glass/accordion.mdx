## 解剖结构与所有权

组合 Root → Item → Heading → Trigger，Content 与 Heading 并列。每个 Item 必须有唯一、稳定、非空的 value。Root 拥有选中键集合，Item、Trigger、Content 派生事实。嵌套 Root 各有独立域。Heading 内只放控制它的 Trigger，持续显示的次级操作放在旁边。

风格投影消费对应 Base 原子，不另建私有 accordion，不在聚焦时改写展开，也不消费其他 Base 协议钩子。APG 和风格库仅为设计参考，不是实现上游。

## JSON Props

| Part | Props | 默认与边界 |
| --- | --- | --- |
| Root | mode | single；multiple 允许多项独立展开 |
| Root | openItems、defaultOpenItems | string 数组；提供 openItems 即受控，default 只初始化一次 |
| Root | allowEmpty | true；false 阻止关闭最后一个选择键 |
| Root | disabled | false；抑制激活但不改写 owner 输入 |
| Root | orientation、direction、loop | vertical、ltr、true；仅影响标题导航 |
| Item | value、disabled | 必填的非空稳定键；disabled 默认 false |
| Heading | level | 1–6 整数，默认 3；由作者选择页面层级 |
| Trigger | 无 | 从 Item 与 Root 派生状态 |
| Content | keepMounted、region | 均为 false；显式保留隐藏 view 与可选 landmark |

输入重复键去重，重复登记的 Item 身份拒绝。single 取首个唯一输入键。未知 owner/default 键保留休眠以支持逐步挂载，向缺失键发请求拒绝。非受控曾登记后移除的键退役，改名按删除/新增处理。空组 allowEmpty=false 不会凭空造内容，受控空输入仍由 owner 决定。

## Exposes 与受控用法

Root 暴露 getOpenItems()、openCount、requestOpen(value, open, reason?) 与 openChange signal，JSON payload 为 `{ openItems, value, open, reason }`。getOpenItems 返回副本，openCount 包含休眠 canonical 键；reason 为 pointer、keyboard 或 programmatic。重复无效或 disabled 请求不发事件。

受控请求不乐观改写任何 part。把请求的 openItems 传回 Root 才算接受。Adapter callback 是 expose signal 的宿主投影，不是 Proto UI callback Props。初始化、owner 同步、结构 fallback、后续 default 变更均不发 openChange。较新的同步 owner 接受（含请求时删除 Item）优于旧通知。

## 键盘与无障碍

每个启用 header 与作者内容中可聚焦元素保持自然 Tab 顺序。Enter/Space 仅 toggle 一次。纵向上下键或横向左右键在启用标题间移动；RTL 反转横向。Home/End 到首末标题，导航不改变 openItems。loop=false 保持边界焦点。disabled header 跳过，最后一个必开标题仍可聚焦但 aria-disabled 阻止关闭。

Heading 声明 heading/level；Trigger 声明 button、内容名称、expanded、disabled 与精确 item 域 controls。Content 由 Trigger 命名，region=true 显式启用 landmark。多开大量内容时谨慎使用地标。native 聚焦、辅助技术输出、平台保真度仍须各自实证。

## Presence、动画与安全布局

关闭的 Content 默认执行可重复 L1 detach。保留逻辑实例身份，不承诺宿主子组件状态或 native view 保留。keepMounted 保留完整但隐藏的 view。Content 不创建 autofocus、focus return 或 Tab stop。焦点在作者内容中时关闭，遵循宿主正常移除行为，Accordion 不代替作者移动焦点。

本协议不增加延迟关闭或动画计时 API。消费者动画必须保留 canonical open/hidden 所有权。投影支持长标签折行、容器收缩与横向内容溢出容纳，页面 safe-area 留白由容器布局承担。真实窄屏、200% 字号、焦点轮廓与溢出截图仍是独立验收要求。

## 使用与状态

从 @proto.ui/prototypes-liquid-glass/accordion 导入 accordionRoot、accordionItem、accordionHeading、accordionTrigger、accordionContent。Base 另导出同名 asAccordion\* authoring entries。Web Component、React、Vue、Vue 2 消费同一 API。

Bootstrap 2.3.2 与 LiquidGlass 包仍为 private 工作区源码；本页不表示 npm 发布。仅通过显式选择的 workspace-source 路径生成 facade。

Trigger 声明共享的显式 liquid-glass 光学意图，消费自身 Base pressed/rest 状态。只有交互标题请求材质，其他原子保留 opaque/可读表面。宿主缺少共享 visual sink 时保留声明的 opaque fill/foreground fallback，并报告 material-host-unavailable。adaptive 系统 blur 是另一意图，不会替代该请求。实际宿主光学渲染与 GPUI paint 验收仍未完成。
