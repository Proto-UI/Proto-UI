Liquid Glass Accordion 由 Root、Item、Heading、Trigger、Content 五个部件组成。仅交互式标题（`Trigger`）承载 Liquid Glass 光学材质与按压形变，内容面板保持不透明高对比可读表面，避免玻璃叠玻璃。

## 安装

当前通过工作区源码包提供，可直接从 `@proto.ui/prototypes-liquid-glass/accordion` 导入五个部件原型：

```ts
import {
  accordionRoot,
  accordionItem,
  accordionHeading,
  accordionTrigger,
  accordionContent,
} from '@proto.ui/prototypes-liquid-glass/accordion';
```

## 用法

```tsx
import {
  LiquidGlassAccordionRoot,
  LiquidGlassAccordionItem,
  LiquidGlassAccordionHeading,
  LiquidGlassAccordionTrigger,
  LiquidGlassAccordionContent,
} from '@/components/proto-ui/react';

export function LiquidGlassAccordionUsage() {
  return (
    <div className="rounded-2xl bg-gradient-to-br from-sky-500/20 via-indigo-500/15 to-fuchsia-500/20 p-6">
      <LiquidGlassAccordionRoot defaultOpenItems={['item-1']}>
        <LiquidGlassAccordionItem value="item-1">
          <LiquidGlassAccordionHeading level={3}>
            <LiquidGlassAccordionTrigger>How do I reset my password?</LiquidGlassAccordionTrigger>
          </LiquidGlassAccordionHeading>
          <LiquidGlassAccordionContent>
            Click on 'Forgot Password' on the login page to receive a reset link.
          </LiquidGlassAccordionContent>
        </LiquidGlassAccordionItem>
      </LiquidGlassAccordionRoot>
    </div>
  );
}
```

### 部件结构与材质层级

```text
AccordionRoot
└── AccordionItem (transparent structural frame)
    ├── AccordionHeading (paint reservation boundary)
    │   └── AccordionTrigger (optical Liquid Glass interactive surface)
    └── AccordionContent (opaque readable content surface)
```

- **单层光学边界**：`Item` 保持透明底色，避免遮挡背景采样或造成玻璃叠玻璃；`Content` 独立拥有不透明底色、柔和顶部分隔线与内边距，保证长正文可读性。
- **层级强调与回退**：`Trigger` 支持 `prominence="regular" | "prominent"` 区分常规与强调标题，并支持 `material="opaque"` 显式关闭光学候选。在系统开启降低透明度（`prefers-reduced-transparency: reduce`）、强制配色（`forced-colors: active`）、禁用或不可收起状态，以及宿主未接入材质能力时，组件自动撤回光学候选并保留高对比不透明表面。
- **无整宿半透明弱化**：禁用态通过撤回阴影与指针交互提示不可用，而非使用 `opacity-50` 降低不透明回退对比度。

### 键盘与无障碍

- 启用的 `Trigger` 与内容区可聚焦元素保持自然 `Tab` 顺序；`Enter` / `Space` 切换当前项。
- 纵向模式使用 `ArrowUp` / `ArrowDown`、横向模式使用 `ArrowLeft` / `ArrowRight`（RTL 自动反转）与 `Home` / `End` 在启用标题间移动焦点，不改变展开状态。
- 禁用标题会被方向键跳过；`allowEmpty={false}` 阻止收起最后一项时，标题仍可聚焦并通过 `aria-disabled` 提示不可关闭。

### 方法与事件（Root）

- `getOpenItems()`：返回当前展开键数组的副本。
- `openCount`：当前展开键数量（含尚未挂载的键）。
- `requestOpen(value, open, reason?)`：请求展开或收起指定项，`reason` 为 `'pointer' | 'keyboard' | 'programmatic'`。
- `openChange`：载荷为 `{ openItems, value, open, reason }`；初始化、受控同步与无效请求不触发该事件。
