## 用法

- **显式层级标识**：每个节点通过树内唯一的 `nodeKey` 标识，并用 `parentKey` 指向其父节点；重复标识、缺失父节点或循环引用都会被忽略并保持当前有效状态。
- **键盘导航**：上下方向键、`Home` / `End` 与首字母输入在可见节点间移动焦点；左右方向键分别用于折叠/定位父节点与展开/进入首个子节点。
- **受控状态**：`value`（选中节点）与 `expandedKeys`（展开节点集合）均支持受控请求模式。

## API

| 属性           | 说明                            |
| -------------- | ------------------------------- |
| `value`        | 受控当前选中节点的 `nodeKey`    |
| `expandedKeys` | 受控已展开节点的 `nodeKey` 集合 |
| `nodeKey`      | 节点在当前树中的唯一标识        |
| `parentKey`    | 指向父节点的 `nodeKey`          |
