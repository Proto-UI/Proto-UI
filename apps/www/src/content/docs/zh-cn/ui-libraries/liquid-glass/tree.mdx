Liquid Glass Tree 管理显式声明的层级节点树，提供单选、分支展开折叠以及完整的键盘与 RTL 导航。遵循 Apple Liquid Glass 人机界面指南，树形内容层保持中性可读表面而不叠加玻璃材质（避免在列表行内发生玻璃叠玻璃），同时采用同心圆角（外层 `rounded-2xl` 配合 `p-2` 与内层 `rounded-lg`）与高对比度禁用态。

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可直接从 `@proto.ui/prototypes-liquid-glass/tree` 导入原型并使用目标框架适配器注册：

```ts
import { treeRoot, treeItem, treeGroup, treeToggle } from '@proto.ui/prototypes-liquid-glass/tree';
```

## 用法

```tsx
<LiquidGlassTreeRoot defaultValue="button" defaultExpandedKeys={['src', 'components']}>
  <div className="flex items-center gap-1.5">
    <LiquidGlassTreeToggle nodeKey="src" size="icon">
      ▾
    </LiquidGlassTreeToggle>
    <LiquidGlassTreeItem nodeKey="src" textValue="src" className="flex-1">
      src/
    </LiquidGlassTreeItem>
  </div>
  <LiquidGlassTreeGroup nodeKey="src">
    <LiquidGlassTreeItem nodeKey="button" parentKey="src" textValue="button.tsx">
      button.tsx
    </LiquidGlassTreeItem>
  </LiquidGlassTreeGroup>
</LiquidGlassTreeRoot>
```

### 层次原则与交互语义

- **中性内容层与同心几何**：Tree 属于内容浏览视图，默认不申报 `liquid-glass` 材质候选，确保位于悬浮导航玻璃层之下的文本与图标始终清晰；外层容器圆角与内边距及子行圆角保持同心对应。
- **高对比度与无障碍**：聚焦使用内嵌焦点环并保留 `forced-colors` 系统高亮轮廓；禁用态使用语义弱化文字色而非整体降低不透明度，确保在高对比度与不透明回退环境下保持可读性。
- **键盘导航与 RTL**：支持上下方向键、`Home` / `End` 与首字母跳转；设置 `direction="rtl"` 自动镜像层级导轨与左右方向键映射。
