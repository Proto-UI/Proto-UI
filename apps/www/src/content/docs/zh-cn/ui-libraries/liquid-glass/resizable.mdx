Liquid Glass Resizable 支持将容器划分为两个或多个按百分比缩放的面板，并通过编号分隔柄（`Handle`）连续调整相邻面板比例。支持指针拖拽、方向键、Home / End、`Shift` 加速、面板折叠与嵌套不同方向的布局。

## 用法

- **面板与分隔柄配对**：放置 `N` 个 `Panel`（`index` 为 `0..N-1`）与 `N - 1` 个 `Handle`（`index` 为 `0..N-2`），每个 `Handle` 调整其相邻两个面板且保持其余面板大小与两者之和不变；`Handle` 默认可访问名称为 `Resize panels`。
- **约束与折叠**：`constraints` 按面板顺序提供 `min`（`0`）、`max`（`100`）、`collapsible`（`false`）与 `collapsedSize`（`0`）。所有面板比例自动归一化为总计 `100`；不可行配置会保留上一次有效布局。折叠属于离散停点，当相邻面板已达到 `max` 时会阻止折叠。
- **受控模式与嵌套**：传入 `sizes` 进入受控模式，`sizesChange` 与 `sizesCommit` 携带 `{ sizes }`（手势取消不触发 `sizesCommit`）；原有的双面板 `value` / `defaultValue` 接口仍可兼容使用，同时传入时以 `sizes` 为准。嵌套的 `Root` 各自独立管理比例、约束和方向，拖拽距离按面板边框盒总长度归一化（不计入固定分隔柄宽度）。

## API

| 部件 | 属性 / 方法 / 事件 | 默认值与说明 |
| --- | --- | --- |
| Root | `sizes` / `defaultSizes` | 受控 / 非受控百分比数组（总计 `100`）；优先于双面板 `value` / `defaultValue` |
| Root | `constraints` | 逐面板配置 `{ min, max, collapsible, collapsedSize }`，默认 `0` / `100` / `false` / `0` |
| Root | `requestResize(index, nextSize, commit)` / `requestSizes(nextSizes, commit)` | 以编程方式请求调整单个或全部面板比例 |
| Root | `sizesChange` / `sizesCommit` | 拖拽中与完成时触发，载荷 `{ sizes }` |
| Panel | `index` | 面板序号（`0..N-1`）；暴露无量纲 `size`（`--pui-size`） |
| Handle | `index` | 分隔柄序号（`0..N-2`），指向其前一个面板 |
