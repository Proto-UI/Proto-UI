Liquid Glass 风格的可调整分栏组件：内容面板保持中性不堆叠多层玻璃，外层容器使用同心 `rounded-2xl` 半透明高光表面（嵌套时通过 `variant="nested"` 去框），分隔柄提供 `regular` / `prominent` 胶囊抓握层次，并在减少透明度、高对比度或 `material="opaque"` 时自动回退为高对比度不透明表面。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可直接从 `@proto.ui/prototypes-liquid-glass/resizable` 导入原型并适配到目标宿主：

```ts
import {
  resizableRoot,
  resizablePanel,
  resizableHandle,
} from '@proto.ui/prototypes-liquid-glass/resizable';
```

## 用法

```tsx
import {
  LiquidGlassResizableRoot,
  LiquidGlassResizablePanel,
  LiquidGlassResizableHandle,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <div className="w-full max-w-lg rounded-2xl bg-gradient-to-br from-sky-500/20 via-indigo-500/15 to-fuchsia-500/20 p-6">
      <LiquidGlassResizableRoot defaultSizes={[50, 50]} className="h-56 w-full">
        <LiquidGlassResizablePanel index={0}>One</LiquidGlassResizablePanel>
        <LiquidGlassResizableHandle index={0} withHandle />
        <LiquidGlassResizablePanel index={1}>Two</LiquidGlassResizablePanel>
      </LiquidGlassResizableRoot>
    </div>
  );
}
```

### 组合结构

```text
LiquidGlassResizableRoot (variant="default" | "nested", material="auto" | "opaque")
├── LiquidGlassResizablePanel (index: 0)
├── LiquidGlassResizableHandle (index: 0, withHandle?, prominence?, material?)
└── LiquidGlassResizablePanel (index: 1)
```

- **层次与同心几何**：内容面板保持中性清晰，外层 `Root` 提供 `rounded-2xl` 外壳，内嵌 `Root` 传入 `variant="nested"` 避免多层边框堆叠；启用 `withHandle` 后在分隔线居中呈现 `rounded-full` 胶囊抓握柄。
- **材质回退与无障碍**：默认 `material="auto"` 仅在宿主允许透明且非强制配色时启用半透明层次，否则自动回退为不透明配色；禁用态不使用整块降透明度，确保文本与边界对比度清晰可读。
- **多面板、约束与键盘**：支持 `sizes` / `defaultSizes`、`constraints`、指针拖动、方向键、`Shift` 加速、`Home` / `End` 与 `Enter` 折叠，默认无障碍名称为 `Resize panels`。

### Panel 与 Handle

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}

    { name: 'Panel.index', type: 'number', default: '0' },

- **暴露状态**：Root 暴露 `value`、`sizes`；Panel 暴露 `size`；Handle 暴露 `value`、`focusVisible`、`disabled`。
- **事件与方法**：Root 触发 `sizesChange` / `sizesCommit` / `valueChange` / `valueCommit`，并提供 `requestResize(index, next, commit?)`、`requestSizes(next, commit?)`、`requestValue(next, commit?)` 与 `cancelResize()`。
