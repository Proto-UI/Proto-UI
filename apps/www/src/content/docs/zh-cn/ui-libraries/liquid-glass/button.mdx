V2 Liquid Glass 意图已接入可选 Web 自实现光学 provider。Previewer 的可见动态应用 canvas 就是被采样的背景本体。当前不捕获任意 DOM 或浏览器 compositor：介入的其他绘制、跨 scope portal、来源或偏好不可用时保留可读回退。减弱动态效果使用静态光学路径。此 draft provider 仍需 exact-head 浏览器证据后才能接纳；native、Apple 私有实现、group/morph 与完整 Compiler 等价性仍未验证。

## API

- variant: regular / prominent; material: auto / opaque
- disabled: boolean, default false
- 激活、焦点、键盘与禁用逻辑继承 Base Button，视觉层没有第二个状态拥有者。

目前已登记 Button。其他 Base 部件正在逐项补齐，不会借用其他族冒充；通用 Compiler 与 GPUI/Flutter/Qt 完整呈现尚未验证。源码包仍为 private/unreleased。
