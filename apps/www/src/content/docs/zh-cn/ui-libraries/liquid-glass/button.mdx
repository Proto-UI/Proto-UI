Liquid Glass Button 以胶囊几何、边缘高光与可选的光学材质层次将操作控件与内容区分开：`regular` 用于日常操作，`prominent` 以克制染色突出单一主操作，`destructive` 标识破坏性动作，交互与无障碍行为由 Base Button 统一提供。

## 用法

```tsx
import { LiquidGlassButton } from '../proto-ui/components/react';

export function Example() {
  return (
    <div className="flex items-center gap-4">
      <LiquidGlassButton>Cancel</LiquidGlassButton>
      <LiquidGlassButton variant="prominent">Continue</LiquidGlassButton>
    </div>
  );
}
```

### 材质层次与无障碍（Apple Liquid Glass HIG）

设计取舍参考 Apple [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Color](https://developer.apple.com/design/human-interface-guidelines/color) 与 [Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons) 指南：

- **层级与克制染色**：同一组操作中只使用一个 `variant="prominent"` 突出主操作，其余操作保持 `regular`；避免在玻璃容器内再叠加玻璃按钮（不堆叠 glass-on-glass）。
- **材质回退**：`material="auto"` 在宿主支持且具备可见背景源时提交 V2 光学材质意图并响应按压形变；设为 `material="opaque"` 或处于普通 DOM 背景时，保持高对比度不透明表面。
- **系统偏好适配**：系统开启减弱动态效果时关闭过渡与按压形变并保留静态材质；开启减少透明度、增强对比度或强制颜色模式时自动回退至可读的不透明配色。禁用态保持前景与轮廓可读（不降低整体不透明度），同时拦截所有激活事件。

常规玻璃胶囊适用于返回、详情与分享等次要或并列操作。
