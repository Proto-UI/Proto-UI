Liquid Glass Button 用柔和的边缘高光与背景折射，将操作控件与内容区分开。常规按钮适合返回等次要操作；强调按钮通过染色突出当前主要操作，两者保持相同尺寸。

预览背景保持静止，让注意力集中在按钮的悬停、按下和键盘焦点上。点击 Back 可观察激活次数，也可以用页面顶部的运行时选择器比较同一组件在四种 Web 适配器中的表现。

## 材质与无障碍

默认的 regular 材质用于可读的功能控件。仅为主要操作使用 `variant="prominent"`，避免在玻璃容器内再叠加玻璃按钮。这些取舍参考 Apple 的 [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Color](https://developer.apple.com/design/human-interface-guidelines/color) 与 [Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons) 指南。

`material="auto"` 在宿主支持时启用光学效果；`material="opaque"` 使用不透明表面。网页预览采样的是它实际显示的 canvas 背景。普通 DOM 背景或遮挡内容不在该来源内时，按钮保留可读的不透明样式。

减弱动态效果会关闭弹性形变并保留静态材质；减少透明度、增强对比度或强制颜色模式会使用可读回退。禁用按钮保留文字和轮廓，不响应激活。

## API

- variant: regular / prominent，默认 regular
- material: auto / opaque，默认 auto
- disabled: boolean，默认 false
- 激活、焦点、键盘与禁用逻辑继承 Base Button，视觉层没有第二个状态拥有者。

Liquid Glass 仍为 WIP / 实验性家族，源码包尚未发布。这里展示独立实现的 Web 效果；原生平台呈现、组件间融合与完整 Compiler 支持仍在开发中。
