Liquid Glass Button 用柔和的边缘高光与背景折射，将操作控件与内容区分开。常规按钮适合返回等次要操作；强调按钮通过染色突出当前主要操作，两者保持相同尺寸。

## 材质与无障碍

默认的 `regular` 材质用于常规操作控件；`variant="prominent"` 适合突出一组操作中的主要按钮，避免在玻璃容器内再叠加玻璃按钮。设计取舍参考 Apple [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Color](https://developer.apple.com/design/human-interface-guidelines/color) 与 [Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons) 指南。

- `material="auto"` 在宿主支持且存在可见 canvas 背景源时启用光学折射；当背景为普通 DOM、存在遮挡或设为 `material="opaque"` 时，按钮保持高对比度的不透明样式。
- 系统开启减弱动态效果时，会关闭弹性按压形变并保留静态材质；开启减少透明度、增强对比度或强制颜色模式时，自动切换为可读的不透明回退。
- 禁用态保留文字与轮廓，不响应激活事件。

## API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `variant` | `'regular' \| 'prominent'` | `'regular'` | 常规玻璃或强调染色样式 |
| `material` | `'auto' \| 'opaque'` | `'auto'` | 设为 `'opaque'` 时关闭光学效果，使用不透明表面 |
| `disabled` | `boolean` | `false` | 禁用按钮交互 |

激活、焦点、键盘与禁用语义均由 [Base Button](/zh-cn/ui-libraries/base/button/) 统一管理。
