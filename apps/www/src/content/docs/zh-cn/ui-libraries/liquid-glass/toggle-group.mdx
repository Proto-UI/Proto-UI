Liquid Glass Toggle Group 将一组相关的双态切换按钮组合为统一的游走焦点容器，支持单选（可清空）或多选模式。

## 用法

- **部件组成**：`Root`、`Item`。
- **单选与多选**：`value` 与 `defaultValue` 均为字符串数组。当 `multiple={false}` 时最多保留一个选中值，再次点击已选中项可清空选择。受控模式下交互仅发出 `valueChange` 请求，不会直接改写调用方状态。
- **键盘与边界**：方向键仅在选项间移动游走焦点而不改变选中状态；禁用、只读以及重复值的选项不会提交变更。

## API

| 部件 | 属性 / 事件 | 说明 |
| --- | --- | --- |
| Root | `value` / `defaultValue` | 受控 / 非受控选中值字符串数组 |
| Root | `multiple` | 是否允许多选；`false` 时为单选且支持再次点击清空 |
| Root | `disabled` / `readOnly` / `valueChange` | 禁用、只读与选中变更请求事件 |
| Item | `value` / `disabled` | 选项唯一值与单项禁用状态 |
