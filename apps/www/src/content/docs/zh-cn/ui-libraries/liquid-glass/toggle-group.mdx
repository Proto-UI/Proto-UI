Liquid Glass Toggle Group 将光学玻璃材质仅声明在浮空 `Root` 容器上，内部 `Item` 以无边框分段胶囊呈现，避免玻璃叠玻璃，并在水平与垂直布局中保持同心圆角几何。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可直接从 `@proto.ui/prototypes-liquid-glass/toggle-group` 导入组件原型并通过对应宿主 Adapter 适配。

## 用法

```tsx
import {
  LiquidGlassToggleGroupItem,
  LiquidGlassToggleGroupRoot,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <LiquidGlassToggleGroupRoot defaultValue={['week']} a11yLabel="Calendar range">
      <LiquidGlassToggleGroupItem value="day">Day</LiquidGlassToggleGroupItem>
      <LiquidGlassToggleGroupItem value="week">Week</LiquidGlassToggleGroupItem>
      <LiquidGlassToggleGroupItem value="month">Month</LiquidGlassToggleGroupItem>
    </LiquidGlassToggleGroupRoot>
  );
}
```

### 材质层次与无障碍

- **单层玻璃原则**：仅 `Root` 声明 v2 `liquid-glass` 材质与高光边缘；内部 `Item` 为无边框分段，避免在玻璃容器内再次叠加玻璃材质。
- **同心圆角**：水平排列时容器与分段均使用胶囊圆角（`rounded-full`）；垂直排列时容器为 `rounded-2xl`（16px）配 `p-1.5`（6px）内边距，内部项自动切换为同心 `rounded-[10px]`（16px − 6px）。
- **回退与减弱动效**：设置 `material="opaque"` 或系统开启减少透明度、强制颜色模式时，保持清晰高对比的不透明表面；禁用态采用无透明衰减的高可读样式；开启减弱动态效果时自动关闭颜色过渡。
