Liquid Glass Field 由 `Root`、`Label`、`Control`、`Description`、`Error`、`Validity` 六个部件组成，提供圆角编辑表面与静置材质风格，统一管理字段标签、帮助文本、校验状态与错误提示。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `@proto.ui/prototypes-liquid-glass/field` 导入 `fieldRoot`、`fieldLabel`、`fieldControl`、`fieldDescription`、`fieldError` 与 `fieldValidity`。

## 用法

### 组合与标签关联

- 每个 `Root` 包含一个 `Control`，可按需搭配一个 `Label`、一个 `Description`、一个汇总 `Error` 以及多个只读 `Validity`；嵌套的 `Root` 各自独立，重复的唯一部件会被忽略。
- `Control` 默认内置单行文本编辑器，也支持通过 Base 的 `asFieldControl` 与 `asControlLabel().target(..., FIELD_LABEL_PAIR)` 接入自定义值控件（Number Field、Input OTP、Slider、Checkbox Group 等）。
- 组件自动维护 `aria-labelledby`、`aria-describedby` 与（仅在有效 `invalid=true` 时）`aria-errormessage` 关联并在卸载时清理，无需手写 DOM ID；同时同步 `aria-required`、`aria-invalid`、`aria-busy` 与 `aria-readonly`。
- 点击 `Label` 会聚焦同一启用的 `Control`（不会增加额外 Tab 停靠点，并自动忽略拖拽、修饰键点击与嵌套按钮/链接）。

### 内置校验与异步校验

- **内置规则**：`required` 将 `null`、`false`、空字符串与空数组视为空（`0` 与纯空白字符视为有效，不自动 `trim`）；`minLength` / `maxLength` 按 UTF-16 码元计数（可选空字符串跳过长度检查）。内置校验标记为 `valueMissing`、`tooShort`、`tooLong`，外部错误使用 `customError`。
- **触发时机**：`validationMode` 默认 `onBlur`，可选 `onChange`（等待 IME 组合结束后触发）或 `manual`。受控传入 `invalid` 时，`validityChange` 仅提出建议，需由调用方更新 `invalid`；`resetValidation()` 仅清除校验和 `touched` 状态，不修改值或 `dirty` 基线。
- **异步校验**：设置 `externalValidation={true}` 后，内置规则通过时会发出 `validationRequest`（载荷 `{ requestId, value, reason }`）。完成后调用 `resolveValidation(requestId, { invalid, errors })` 提交结果；若期间值变更、发起了新请求、控件卸载或切换为禁用/只读，过期结果会自动被忽略。
- **错误展示**：`Error` 优先展示显式 `message`，其次是 `errors` 数组，最后回退为内置英文提示；默认关闭时卸载内容节点（设置 `keepMounted={true}` 可保留隐藏节点）。如需屏幕阅读器主动播报，请配合 LiveRegion 使用。

Field 专注于单字段校验；分组禁用请配合 [Fieldset](/zh-cn/ui-libraries/liquid-glass/fieldset/)，表单提交与重置请配合 [Form](/zh-cn/ui-libraries/liquid-glass/form/)。

## API

| 部件 | 属性 | 默认值与说明 |
| --- | --- | --- |
| Root | `invalid` / `errors` | 传入 `invalid` 即进入受控校验模式，`errors` 为错误文案数组 |
| Root | `defaultInvalid` / `defaultErrors` | 非受控初始校验状态（仅初始化一次） |
| Root | `disabled` / `readOnly` / `required` | 均为 `false`；与 Control 本地策略叠加生效 |
| Root | `minLength` / `maxLength` | 默认 `-1`（不限制）；非负整数按 UTF-16 码元限制文本长度 |
| Root | `validationMode` | `'onBlur'`（默认）、`'onChange'` 或 `'manual'` |
| Root | `externalValidation` | `false`；设为 `true` 时在内置校验通过后触发 `validationRequest` |
| Control | `value` / `defaultValue` | 文本值；初始化时固定受控或非受控模式 |
| Control | `disabled` / `readOnly` / `required` | 局部策略（不会解除 Root 已开启的约束） |
| Control | `placeholder` / `name` / `autoComplete` / `inputMode` / `enterKeyHint` / `ariaLabel` | 常用文本编辑器提示属性 |
| Label | `activation` | `true`；点击标签时请求聚焦同一启用的 Control |
| Description | — | 渲染传入的被动帮助文本（保持自然可选中） |
| Error | `message` / `keepMounted` | `message` 覆盖错误文案；`keepMounted` 默认 `false` |
| Validity | — | 被动读取当前校验状态与 `getValidity()` 快照 |

### 事件与方法

- Root 方法：`validate(reason?)`、`resolveValidation(requestId, result)`、`cancelValidation()`、`resetValidation()`、`focusControl(options?)`、`getValidity()`。
- Root 状态：`invalid`、`pending`、`dirty`、`touched`、`filled`、`focused`、`disabled`、`readOnly`、`required`。
- Root 事件：`validityChange`（含状态、flags 与 errors 快照）、`validationRequest`（载荷 `{ requestId, value, reason }`）。在宿主适配器中分别映射为 `onValidityChange`、`onValidationRequest` 与 `onValueChange`。
