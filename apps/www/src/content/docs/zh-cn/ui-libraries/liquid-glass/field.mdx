Liquid Glass Field 将标签、编辑控件、次级说明与错误提示组合为清晰的字段单元，采用 2xl 圆角、静置编辑材质与不透明回退表面，并遵循次级层次（`text-muted-foreground`）与语义化错误色（`text-destructive`）规范。

## 安装

当前仅在源码工作区提供，可从 `@proto.ui/prototypes-liquid-glass/field` 导入核心部件与已绑定控件：

```ts
import {
  fieldRoot,
  fieldLabel,
  fieldControl,
  fieldDescription,
  fieldError,
  fieldValidity,
  fieldTextarea,
  fieldSelectTrigger,
  fieldSwitch,
} from '@proto.ui/prototypes-liquid-glass/field';
```

## 用法

```tsx
import {
  FieldRoot,
  FieldLabel,
  FieldControl,
  FieldDescription,
  FieldError,
} from '@proto.ui/prototypes-liquid-glass/field';

export function ProfileField() {
  return (
    <FieldRoot required minLength={3}>
      <FieldLabel>Username</FieldLabel>
      <FieldControl placeholder="Max Leiter" />
      <FieldDescription>Choose a unique username for your account.</FieldDescription>
      <FieldError />
    </FieldRoot>
  );
}
```

### 材质与层次说明

- **静置编辑表面与不透明回退**：`Control` 声明静置 `liquid-glass` 材质候选，同时保留明确的 `bg-background` / `text-foreground` 回退；禁用态使用 `bg-muted` 与 `text-muted-foreground` 保持可读性，避免纯透明度叠加导致对比度下降。
- **语义层次**：帮助说明与校验状态使用次级文字层次（`text-muted-foreground`），校验错误统一使用 `text-destructive` 与 `border-destructive`。
- **自动无障碍关联**：自动维护 `aria-labelledby`、`aria-describedby` 与（仅在 `invalid` 时）`aria-errormessage`，卸载时自动清理。配合 [Fieldset](../fieldset/) 与 [Form](../form/) 实现整组禁用与表单提交。

### Control 与其他部件

- **Control**：`value` / `defaultValue`、`disabled`、`readOnly`、`required`、`placeholder`、`name`、`autoComplete`、`inputMode`、`enterKeyHint`、`ariaLabel`。
- **已绑定控件**：`fieldTextarea`、`fieldSelectTrigger`、`fieldSwitch`。
- **Label**：`activation?: boolean`（默认 `true`）。
- **Error**：`message?: string`、`keepMounted?: boolean`（默认 `false`）。
- **方法与事件（Root）**：`validate(reason?)`、`resolveValidation(requestId, result)`、`cancelValidation()`、`resetValidation()`、`focusControl(options?)`、`getValidity()`；事件 `validityChange`、`validationRequest`。
