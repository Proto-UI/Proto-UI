Liquid Glass Select 基于 [Base Select](/zh-cn/ui-libraries/base/select/)，由 Root、Trigger、Value、Content、Surface、Viewport、Item、ItemText、Group、Label、Separator 十一个部件组成，提供受控/非受控单选、锚定弹层与玻璃材质表面。

## 用法

### 部件职责与组合结构

推荐组合结构为 `Content > Surface > Viewport > Item > ItemText`；需要分组时在 `Viewport` 内放置 `Group`（内含 `Label` 与多个 `Item`）与 `Separator`：

- **Root**：统一管理 `open`、`value`、已选文本与选项集合；`open` 与 `value` 可独立受控。
- **Trigger & Value**：`Trigger` 提供 `combobox` 语义，点击切换开关、Enter / Space 打开、上下方向键定位到已选项或首/末可用项。`Value` 依次按已选文本、`value`、`placeholder` 回退展示。
- **Content / Surface / Viewport**：`Content` 负责 Portal、碰撞定位与关闭逻辑（不含背景绘制）；`Surface` 是弹层外观与玻璃材质的唯一载体；`Viewport` 作为唯一滚动视口并预留空间防止焦点轮廓被裁剪。
- **Item / ItemText / Group / Label / Separator**：点击、Enter 或 Space 提交可用选项（键盘导航与悬停不直接提交，禁用项自动跳过）；更新已选 `Item` 的 `textValue` 会自动刷新 `Value` 显示。Escape 取消并将焦点返回 `Trigger`，Tab 与外部点击关闭弹层。

### 布局与材质

- 长标签自动换行并支持容器收缩，弹层尺寸受可用视口边界约束，文本对齐和尾部指示符遵循书写方向；请为 `Trigger` 外部预留焦点环空间。
- `Trigger` 与展开态的 `Surface` 请求 `liquid-glass` 光学材质，缺少可见 canvas 源、发生重叠或系统偏好不允许时自动回退到高对比度不透明样式。
- Select 专注单选列表；如需搜索输入或自由文本请使用 [Combobox](/zh-cn/ui-libraries/liquid-glass/combobox/) 或 [Autocomplete](/zh-cn/ui-libraries/liquid-glass/autocomplete/)。

## API

| 部件 | 属性 / 事件 | 默认值与说明 |
| --- | --- | --- |
| Root | `open` / `defaultOpen` / `value` / `defaultValue` | 独立受控或非受控的弹层与选中值 |
| Root | `disabled` / `closeOnSelect` | 禁用控件 / 选中选项后是否自动关闭 |
| Root | `openChange` / `valueChange` | 弹层开关与选中值变更请求事件 |
| Value | `placeholder` | 无选中值时的占位文本 |
| Content | `position` / `side` / `align` / `sideOffset` / `alignOffset` / `avoidCollisions` / `collisionPadding` | 定位模式（默认 `'popper'`，也支持 `'item-aligned'`）与避障参数 |
| Item | `value` / `textValue` / `disabled` / `select` | 选项值、显示文本、禁用态与选中事件 |
