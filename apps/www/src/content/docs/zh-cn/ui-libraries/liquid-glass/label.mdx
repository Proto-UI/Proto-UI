Liquid Glass Label 继承 Base Label 协议，通过显式关联把“提供可访问名称”与“转发点击激活”拆分为两个可独立控制的开关，适用于复选框、开关、单选框、输入框、按钮及切换控件。

## 用法

### 独立控制命名与激活

- **`naming`**（默认 `true`）：让目标控件通过无障碍关系直接引用已渲染的 Label，无需额外放置隐藏文案。若目标控件已显式设置非空 `ariaLabel` 或 `labelledBy`，则会保留其原有命名并在冲突时给出诊断；此时可将 Label 设为仅激活。
- **`activation`**（默认 `true`）：完成配对后，点击或可信的非指针激活会触发目标控件的默认操作（Checkbox / Switch 遵循自身受控与禁用规则，Radio Group Item 向 Group 请求选值，Input / Textarea 请求聚焦而不修改内容或选区）。设为 `false` 可保留命名并关闭点击激活；未配对的 Label 不会隐式查找相邻控件。
- Label 不会增加额外的按钮角色或 Tab 停靠点，键盘交互留在目标控件上；嵌套链接/按钮、带修饰键的点击、拖拽和已取消的点击事件不会被转发。
- 仅用于命名的标签与长说明保持自然可选中；可点击标签在 `selection="policy"` 下会避免误选文字，如需允许复制可设为 `selection="text"`。

### 通过显式引用建立关联

控件与标签的配对不通过普通 JSON Props 或 DOM ID 传递，而是由 `@proto.ui/core` 的 `createControlLabelRef()` 为每组控件/标签创建一个稳定引用：

- **React / Vue / Vue 2**：向双方同时传入适配器专属的 `instanceAssociations: { controlLabel: ref }`。该字段会在解析组件 Props 之前由适配器剥离。
- **Web Components**：通过 `@proto.ui/adapter-web-component` 的 `setElementAssociations(el, { controlLabel: ref })` 分别绑定目标控件与 Label。

每个引用严格对应一个活动中的 Label 与一个活动中的目标控件（Web 端需位于同一 Document 与根节点树内）；引用缺失、重复或失效时会忽略关联，不会按 DOM 顺序猜测目标。

支持配对的控件包括：Checkbox、Switch、Radio Group Item、Input、Textarea、Button、Toggle 与 Toggle Group Item（纯图标按钮也可通过该机制关联独立标签）。

## API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `naming` | `boolean` | `true` | 是否为已配对目标提供可访问名称 |
| `activation` | `boolean` | `true` | 点击标签时是否触发已配对目标的默认操作 |
| `selection` | `'policy' \| 'text'` | `'policy'` | 文本选择策略；设为 `'text'` 可让可激活标签支持自由复制 |
