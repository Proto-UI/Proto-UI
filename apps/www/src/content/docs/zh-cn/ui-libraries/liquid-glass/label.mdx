Liquid Glass `Label` 继承 Base Label 协议，作为内容层文字与透光控件配对，通过显式引用独立控制可访问名称（`naming`）与点击激活（`activation`），并提供 `primary` / `secondary` 前景色层级。

> 表单输入字段请优先使用 [Field](../field/) 组件，内置 `FieldLabel`、`FieldDescription` 与 `FieldError` 自动关联与校验支持。

## 安装

当前仅在源码工作区提供，可直接从工作区包导入：

```ts
import { labelRoot } from '@proto.ui/prototypes-liquid-glass/label';
```

## 用法

通过 `@proto.ui/core` 的 `createControlLabelRef()` 为每对标签与控件创建稳定引用，并通过适配器通道传入：

```tsx
import { useMemo } from 'react';
import { createControlLabelRef } from '@proto.ui/core';
import {
  LiquidGlassCheckboxIndicator,
  LiquidGlassCheckboxRoot,
  LiquidGlassLabelRoot,
} from '../proto-ui/components/react';

export function TermsCheckbox() {
  const termsRef = useMemo(() => createControlLabelRef(), []);

  return (
    <div className="flex items-center gap-2">
      <LiquidGlassCheckboxRoot instanceAssociations={{ controlLabel: termsRef }}>
        <LiquidGlassCheckboxIndicator />
      </LiquidGlassCheckboxRoot>
      <LiquidGlassLabelRoot instanceAssociations={{ controlLabel: termsRef }}>
        Accept terms and conditions
      </LiquidGlassLabelRoot>
    </div>
  );
}
```

Web Components 通过 `@proto.ui/adapter-web-component` 的 `setElementAssociations()` 绑定同一引用：

```ts
import { createControlLabelRef } from '@proto.ui/core';
import { setElementAssociations } from '@proto.ui/adapter-web-component';

const termsRef = createControlLabelRef();
setElementAssociations(checkboxEl, { controlLabel: termsRef });
setElementAssociations(labelEl, { controlLabel: termsRef });
```

### 内容层材质与无障碍原则

- **避免玻璃叠玻璃**：遵循 Apple Liquid Glass 人机界面指南，`Label` 属于内容层文本，不附加玻璃底板，避免与相邻的透光控件形成多层玻璃叠加。
- **前景层级（`tone`）**：默认 `tone="primary"` 使用主前景色（`text-foreground`），`tone="secondary"` 使用次要前景色（`text-muted-foreground`），在开启减少透明度、增强对比度或强制颜色模式时保持高可读性。
- **独立控制命名、激活与选择**：`naming`（默认 `true`）、`activation`（默认 `true`）与 `selection`（默认 `'policy'`）均可按需独立调整；`Label` 不增加额外 `Tab` 停靠点，并忽略嵌套链接/按钮、修饰键点击与拖拽手势。

### 关联辅助接口

- `createControlLabelRef()`：从 `@proto.ui/core` 导入，创建一对一不透明引用。
- `instanceAssociations`：React / Vue / Vue 2 传入 `{ controlLabel: ref }` 的适配器关联通道。
- `setElementAssociations(element, { controlLabel: ref })`：从 `@proto.ui/adapter-web-component` 导入，用于 Web Components 绑定。
