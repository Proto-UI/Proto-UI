Liquid Glass Virtual List 将稳定的逻辑项标识序列与物理渲染节点分离，仅为当前可见窗口及其缓冲区（overscan）创建内容节点，适用于大数据集与可变高度列表项。

## 用法

- **逻辑模型与 Web 物化分离**：核心列表模型与宿主无关，负责按项 overscan、最大物化数量上限、修订号与基于 generation 的提交；Web 端通过显式 `virtual-list/web` 入口测量可变项尺寸、管理占位 spacer 与 DOM 节点复用、支持按键滚动定位，并在卸载时自动清理监听。
- **按需创建内容**：应用仅需为有界可见区间内的键渲染实际内容，复用已有键对应的视图以保持滚动流畅。

## API

- **核心模型能力**：稳定逻辑键序列、按项 overscan 缓冲、最大物化节点上限、修订追踪。
- **Web 宿主入口（`virtual-list/web`）**：可变项高度/宽度测量、占位管理、按键视图复用、滚动到指定键以及监听清理。
