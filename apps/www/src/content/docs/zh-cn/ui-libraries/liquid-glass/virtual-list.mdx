Liquid Glass Virtual List 将稳定的逻辑项标识序列与物理 DOM 节点分离，仅为当前可见窗口及其缓冲区创建内容节点。按照 Liquid Glass 层级原则，可滚动列表本身保持不透明的分组内容表面（`rounded-2xl` 同心圆角裁切），而半透明玻璃材质仅用于悬浮于内容之上的功能操作栏。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可从 `@proto.ui/prototypes-liquid-glass/virtual-list` 导入原型，并结合 `@proto.ui/prototypes-base/virtual-list/web` 完成 Web 滚动视口绑定。

## 用法

Virtual List 由 `Root`、`Viewport` 与 `Content` 组成：`Root` 维护有序逻辑键集合并提供 `rounded-2xl` 不透明分组容器，`Viewport` 承担纵向滚动与内嵌焦点环，`Content` 承载按需挂载的行节点。

```ts
import { AdaptToWebComponent, setElementProps } from '@proto.ui/adapter-web-component';
import {
  virtualListRoot,
  virtualListViewport,
  virtualListContent,
} from '@proto.ui/prototypes-liquid-glass/virtual-list';
import { attachWebVirtualList } from '@proto.ui/prototypes-base/virtual-list/web';

AdaptToWebComponent(virtualListRoot);
AdaptToWebComponent(virtualListViewport);
AdaptToWebComponent(virtualListContent);

const list = document.querySelector('liquid-glass-virtual-list-root')!;
const viewport = document.querySelector('liquid-glass-virtual-list-viewport')!;
const content = document.querySelector('liquid-glass-virtual-list-content')!;

setElementProps(list, {
  itemKeys: Array.from({ length: 1000 }, (_, i) => `event-${i + 1}`),
  overscanItems: 3,
  maxMaterializedItems: 60,
});

const host = attachWebVirtualList({
  viewport,
  content,
  collection: list.getExposes().getCollection(),
  estimateSize: 64,
  renderItem(key) {
    const row = document.createElement('div');
    row.className = 'border-b border-border/50 px-4 py-3 text-sm';
    row.textContent = key;
    return row;
  },
});

// 定位到指定条目，卸载时清理监听与节点
host.ensureVisible('event-250', 'center');
// host.dispose();
```

### 层级、动效与无障碍

- **内容层与控制层分离**：列表容器本身不叠加玻璃材质，避免在滚动内容上叠放玻璃或产生玻璃叠玻璃；搭配悬浮跳转/筛选按钮时，由上层 `Liquid Glass Button` 承担 `regular` / `prominent` 材质表现。
- **无障碍偏好回退**：启用减少透明度或高对比度模式时，容器自动强化边界并移除柔和阴影；启用减少动态效果时自动停用过渡动画。
- **语义角色**：`Root` 声明 `role="region"` 与 `a11yLabel`，`Viewport` 继承 `Scroll Area` 内嵌焦点环，`Content` 声明 `role="list"` 并为挂载行写入 `role="listitem"`、`aria-posinset` 与 `aria-setsize`。

### 进阶：自定义渲染宿主

- 每个逻辑列表实例同一时刻仅允许挂载一个活跃渲染宿主；`attachWebVirtualList` 会自动管理生命周期并在 `Root` 卸载或销毁时清理节点与观察器。
- 替换宿主前需先调用旧宿主的 `dispose()`；非 Web 宿主可通过 `collection.acquireMaterializer(onRetired)` 接入。
