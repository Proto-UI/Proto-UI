Liquid Glass Dropdown Menu 用于展示按组组织的下拉命令列表，支持分组标签、分隔线、快捷键文本提示，以及在触发按钮与展开面板上呈现 Liquid Glass 光学材质。

## 用法

- **分组与装饰部件**：`Group` 与 `Label` 自动建立分组的无障碍命名关联；`Separator` 与 `Shortcut` 属于被动装饰部件，不进入键盘焦点队列。`Shortcut` 仅展示提示文字，不注册全局快捷键。
- **触发器与面板材质**：`Trigger` 声明 `liquid-glass` 材质意图并随按压状态产生形变，`Content` 在展开时请求玻璃材质。当应用未提供合法可见 canvas 源、宿主不支持或对比度不安全时，自动保留高对比度不透明回退样式；若浮层传送（portal）到画布源之外，菜单面板同样会自动回退为不透明外观。
- 悬停、键盘焦点、禁用与菜单项激活均由 Base Dropdown Menu 统一管理。

## API

| 部件                 | 说明                                         |
| -------------------- | -------------------------------------------- |
| Root                 | 管理菜单打开状态与整体交互                   |
| Trigger              | 菜单触发按钮，支持 `disabled` 与按压材质反馈 |
| Content              | 下拉菜单容器，展开时启用玻璃材质并自动回退   |
| Group / Label        | 将相关命令分组并提供实时无障碍组名称         |
| Item                 | 可激活菜单命令项，支持禁用态                 |
| Separator / Shortcut | 被动分组分隔线与快捷键文本提示               |
