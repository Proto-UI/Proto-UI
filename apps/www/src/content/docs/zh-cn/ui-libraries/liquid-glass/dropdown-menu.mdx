Liquid Glass Dropdown Menu 将下拉命令列表投影到浮动光学表面之上，支持同心圆角几何、`regular` / `prominent` 触发层级、`material="opaque"` 显式回退，以及基于 Base 协议的完整键盘导航。

## 安装

当前仅在源码工作区提供，可直接从 `@proto.ui/prototypes-liquid-glass/dropdown` 导入全部部件。

## 用法

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuGroup,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuSeparator,
  DropdownMenuShortcut,
  DropdownMenuTrigger,
} from '@/components/liquid-glass/dropdown-menu';
```

```tsx
<DropdownMenu>
  <DropdownMenuTrigger>Open</DropdownMenuTrigger>
  <DropdownMenuContent align="start">
    <DropdownMenuGroup>
      <DropdownMenuLabel>My Account</DropdownMenuLabel>
      <DropdownMenuItem value="profile">
        Profile
        <DropdownMenuShortcut>⇧⌘P</DropdownMenuShortcut>
      </DropdownMenuItem>
      <DropdownMenuItem value="billing">Billing</DropdownMenuItem>
    </DropdownMenuGroup>
    <DropdownMenuSeparator />
    <DropdownMenuItem value="logout">Log out</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```

- **同心几何与材质层次**：菜单容器使用外层 `rounded-2xl` 配合 `p-2` 内边距与 `rounded-lg` 菜单项保持同心圆角关系；菜单项本身不重复叠加玻璃层，避免玻璃叠玻璃。
- **材质自动回退与显式控制**：`Trigger` 与 `Content` 默认在可用画布背景上请求 `liquid-glass` 光学材质，并在无画布源、浮层传送至画布外或对比度偏好要求不透明时自动保持高对比度不透明表面；也可通过 `material="opaque"` 主动关闭玻璃材质。

## 示例

### 危险操作与缩进对齐

为不可逆操作设置 `variant="destructive"`，并在混用图标项与纯文本项时通过 `inset` 保持对齐。

### 触发器层级与指示图标

使用 `prominence="regular"` 与 `prominence="prominent"` 区分常规菜单与主要操作入口，并可开启 `indicator` 显示下拉箭头。

### 不透明材质回退

当触发器或浮层位于另一层玻璃工具栏内时，设置 `material="opaque"` 抑制玻璃叠加；禁用态触发器同样自动撤回光学材质并保持可读对比度。
