Liquid Glass Toolbar 将一组命令按钮与视觉分隔线组织为单一 Tab 入口的工具栏，使用方向键在可用命令之间快速移动。

## 用法

- **部件组成**：`Root`、`Button`、`Separator`。
- **键盘导航与命令**：整条工具栏仅保留一个 Tab 停靠点，方向键在启用的命令之间循环移动（受 `orientation` 与 `loop` 控制）。点击或键盘激活可用 `Button` 时，发出携带其 `value` 的 `action` 事件。`Separator` 自动沿交叉轴排布。

## API

| 部件 | 属性 / 事件 | 说明 |
| --- | --- | --- |
| Root | `disabled` / `orientation` / `loop` / `a11yLabel` | 整条工具栏禁用、排列方向、首尾循环与可访问名称 |
| Button | `value` / `action` | 命令标识及激活时发出的操作事件 |
| Separator | — | 沿工具栏交叉轴显示的被动分隔线 |
