Liquid Glass Toolbar 将悬浮玻璃材质限定在 `Root` 功能层上，内部以同心胶囊几何承载常规、强调与危险操作按钮，避免玻璃叠玻璃并提供单一 `Tab` 入口与方向键漫游焦点。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可直接从 `@proto.ui/prototypes-liquid-glass/toolbar` 导入原型并适配到目标框架：

```ts
import {
  toolbarRoot,
  toolbarButton,
  toolbarSeparator,
} from '@proto.ui/prototypes-liquid-glass/toolbar';
```

## 用法

```tsx
import {
  LiquidGlassToolbarRoot,
  LiquidGlassToolbarButton,
  LiquidGlassToolbarSeparator,
} from '../proto-ui/components/react';

export function FloatingToolbar() {
  return (
    <LiquidGlassToolbarRoot a11yLabel="Document actions">
      <LiquidGlassToolbarButton value="undo">Undo</LiquidGlassToolbarButton>
      <LiquidGlassToolbarButton value="redo">Redo</LiquidGlassToolbarButton>
      <LiquidGlassToolbarSeparator />
      <LiquidGlassToolbarButton value="publish" variant="prominent">
        Publish
      </LiquidGlassToolbarButton>
    </LiquidGlassToolbarRoot>
  );
}
```

### 材质层级与无障碍

- **禁止玻璃叠玻璃**：只有 `Root` 声明 `liquid-glass` 材质层（通过 `material="opaque"` 可主动关闭光学材质）；子部件 `Button` 与 `Separator` 均不声明嵌套玻璃材质，确保前景可读性与层次清晰。
- **同心几何与层级**：水平工具栏使用胶囊外轮廓（`rounded-full`）与内层胶囊按钮，垂直工具栏采用 `rounded-2xl` 容器；同一组操作通常只保留一个 `variant="prominent"` 主操作，其余使用无边框 `regular` 悬停高亮胶囊。
- **系统偏好回退**：开启减少透明度或强制颜色模式时自动切换为高对比度不透明容器与可见焦点轮廓；开启减弱动态效果时移除过渡动画；禁用按钮保留清晰的不透明文字与背景对比度而不使用半透明叠淡。

### Separator 与事件

- **Separator**：无额外属性，自动沿工具栏交叉轴方向绘制分隔线且不声明嵌套材质。
- **事件与暴露**：`Button` 激活时发出 `action`（`{ value: string }`）；`Root` 暴露 `disabled`、`focusFirst()`、`focusLast()` 与 `setCurrent(id)`；`Button` 暴露 `disabled`、`focused`、`focusVisible` 与 `focusSelf(options)`。
