Liquid Glass Autocomplete 将清晰可读的单行输入表面与悬浮于内容层之上的同心圆角 Liquid Glass 建议弹层结合，支持 `regular` / `prominent` 触发器层级与 `material="opaque"` 显式回退，同时提供完整的实时过滤与自由文本提交语义。

## 用法

```html
<proto-ui-liquid-glass-autocomplete-root a11y-label="Framework">
  <proto-ui-liquid-glass-autocomplete-input
    placeholder="Search frameworks…"
  ></proto-ui-liquid-glass-autocomplete-input>
  <proto-ui-liquid-glass-autocomplete-trigger variant="regular" material="auto">
    Options
  </proto-ui-liquid-glass-autocomplete-trigger>
  <proto-ui-liquid-glass-autocomplete-content material="auto">
    <proto-ui-liquid-glass-autocomplete-item value="next" text-value="Next.js" keywords="react ssr">
      Next.js
    </proto-ui-liquid-glass-autocomplete-item>
    <proto-ui-liquid-glass-autocomplete-item
      value="astro"
      text-value="Astro"
      keywords="islands static"
    >
      Astro
    </proto-ui-liquid-glass-autocomplete-item>
    <proto-ui-liquid-glass-autocomplete-empty
      >No matching frameworks.</proto-ui-liquid-glass-autocomplete-empty
    >
  </proto-ui-liquid-glass-autocomplete-content>
</proto-ui-liquid-glass-autocomplete-root>
```

### 材质分层与交互说明

- **分层与同心圆角**：`Input` 保持不透明编辑表面以确保文本可读；`Trigger` 与 `Content` 作为悬浮功能层声明 `liquid-glass` 材质，`Content`（`rounded-2xl` + `p-1`）与内部 `Item`（`rounded-xl`）保持严格同心几何，避免玻璃叠玻璃。
- **材质回退与层级**：`Trigger` 支持 `variant="regular" | "prominent"`，`Trigger` 与 `Content` 均支持 `material="auto" | "opaque"`；禁用态撤回光学材质并使用高可读性的语义回退配色。
- **过滤与键盘**：内置过滤匹配 `textValue` 与 `keywords` 并忽略大小写和重音；无高亮建议时按 `Enter` 提交自由文本，IME 合成期间不会误触发选择。
