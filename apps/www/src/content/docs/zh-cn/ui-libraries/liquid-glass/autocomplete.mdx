Liquid Glass Autocomplete 在单行文本输入框的基础上提供可过滤的建议列表，既支持选中建议项提交其 `textValue`，也支持在无高亮建议时直接按 Enter 提交自由文本。

## 用法

- **部件组成**：`Root`、`Input`、`Content`、`Item`、`Empty`、`Trigger`。
- **值与查询分离**：`Root` 分别管理已提交文本 `value` 与当前输入查询 `inputValue`，两者以及弹层开关 `open` 均可独立受控并通过对应变更事件接收请求。
- **过滤与键盘**：内置过滤基于 `textValue` 与 `keywords` 并忽略大小写及重音；传入 `filter={false}` 时可由应用自行过滤选项。方向键浏览建议时焦点始终留在输入框内，IME 组合输入期间不会误触发选择。
- **边界处理**：`Empty` 根据实际匹配数量显示；禁用项与重复值的选项不会提交。

## API

| 部件 | 属性 | 说明 |
| --- | --- | --- |
| Root | `value` / `inputValue` / `open` | 已提交文本、当前查询文本与下拉开关，均支持独立受控 |
| Root | `filter` | 默认内置过滤；设为 `false` 时使用应用预先过滤的子项 |
| Item | `textValue` / `keywords` / `disabled` | 建议项展示与匹配文本、扩展关键词及禁用开关 |
| Empty | — | 当无匹配建议时展示空状态内容 |
