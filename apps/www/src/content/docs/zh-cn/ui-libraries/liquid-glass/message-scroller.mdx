Liquid Glass Message Scroller 基于 Scroll Surface 的末端跟随能力：当用户停留在消息底部时，新追加内容会自动滚动到底部；用户向上回看历史消息时保持当前位置，并可通过“Jump to latest”按钮主动恢复跟随。

## 用法

- **新消息计数**：`newContentCount` 由应用自行传入并控制未读业务含义，组件不会私自推断“未读”状态。
- **焦点与无障碍**：点击跳转最新按钮只滚动视口，不会抢夺当前键盘焦点。可通过 Root 的 `a11yLabel` 自定义滚动区域的可访问名称（默认 `'Messages'`）。

## API

| 部件 | 属性              | 默认值       | 说明                                     |
| ---- | ----------------- | ------------ | ---------------------------------------- |
| Root | `a11yLabel`       | `'Messages'` | 滚动区域的可访问名称                     |
| Root | `newContentCount` | —            | 应用传入的新增消息条数，用于提示跳转最新 |
