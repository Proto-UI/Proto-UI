Liquid Glass Message Scroller 遵循内容层与浮控层分离原则：消息列表所在的 `Root` 与 `Viewport` 保持清晰的中性内容表面与同心圆角（`rounded-2xl` 外框内嵌 4px 内边距与 `rounded-xl` 视口），`Jump` 作为浮动胶囊控件悬浮在消息流上方，支持 `regular` 与 `prominent` 层级切换。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可直接从 `@proto.ui/prototypes-liquid-glass/message-scroller` 导入原型并使用目标框架适配器封装。

```ts
import {
  messageScrollerRoot,
  messageScrollerViewport,
  messageScrollerJump,
} from '@proto.ui/prototypes-liquid-glass/message-scroller';
```

## 用法

为外层容器设置明确高度，让消息内容在中性视口内纵向滚动并从浮动胶囊按钮下方平滑穿过：

```tsx
<div className="h-80 w-full max-w-lg">
  <LiquidGlassMessageScrollerRoot a11yLabel="Design conversation">
    <LiquidGlassMessageScrollerViewport>
      <div className="flex flex-col gap-3 p-4 pb-16">
        {messages.map((message) => (
          <div key={message.id}>{message.text}</div>
        ))}
      </div>
    </LiquidGlassMessageScrollerViewport>
    <LiquidGlassMessageScrollerJump variant="regular">
      Jump to latest ↓
    </LiquidGlassMessageScrollerJump>
  </LiquidGlassMessageScrollerRoot>
</div>
```

### 层级与对比度原则

- **内容层保持中性**：`Root` 与 `Viewport` 始终不叠加额外玻璃材质，确保长对话文本具备清晰对比度并避免玻璃叠玻璃。
- **层级强调（`regular` 与 `prominent`）**：常规状态下使用 `variant="regular"`；当读者向上回看且 `newContentCount > 0` 时，可切换为 `variant="prominent"` 主色胶囊以突出未读提示。
- **禁用态清晰对比**：禁用 `Jump` 仅撤回阴影并阻止点击，不使用 `opacity-50` 模糊文字可读性。
- **不抢占焦点**：激活 `Jump` 仅滚动视口并恢复跟随，不会夺走当前键盘焦点。
