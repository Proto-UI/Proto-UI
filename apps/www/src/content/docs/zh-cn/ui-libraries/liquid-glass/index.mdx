Liquid Glass 族的初阶段回退：实时偏好与宿主能力允许时使用半透明填充和 4px 背景模糊。这只是透明与模糊，不是 Apple Liquid Glass 的透镜效果；随形状变化的折射、高光、自适应外观与流体形变尚未实现。未知、减弱透明度、减弱动态效果或对比度偏好使用不透明回退。

目前已登记 Button。其他 Base 部件正在逐项补齐，不会借用其他族冒充；通用 Compiler 与 GPUI/Flutter/Qt 完整呈现尚未验证。源码包仍为 private/unreleased。
