**WIP / 实验性——归入 0.4 工作流，不属于 0.3 发布承诺。** 保留现有源码与预览供评估，不将其表述为稳定的 0.3 支持。

V2 Liquid Glass 意图已接入可选 Web 自实现光学 provider。Previewer 的可见动态应用 canvas 就是被采样的背景本体。当前不捕获任意 DOM 或浏览器 compositor：介入的其他绘制、跨 scope portal、来源或偏好不可用时保留可读回退。减弱动态效果使用静态光学路径。此 draft provider 仍需 exact-head 浏览器证据后才能接纳；native、Apple 私有实现、group/morph 与完整 Compiler 等价性仍未验证。

Button、Surface、Text、Label、Collapsible、Accordion 和五 part Select 已有独立的直接 Base 投影。Select Trigger/Content 声明共享显式光学意图与不透明 fallback；实际光学绘制仍须 exact-head 浏览器证据接纳。其他 Base 部件正在逐项补齐，不会借用其他族冒充；通用 Compiler 与 GPUI/Flutter/Qt 完整呈现尚未验证。源码包仍为 private/unreleased。

[Toggle（草案）](/zh-cn/ui-libraries/liquid-glass/toggle/) 增加直接 Base 持久 active 投影：两态使用 regular 材质，选中态使用受界 style tint 与固定占位的勾形标记。染色必须保留有结构的背景响应，切换选择不改变控件几何尺寸。这是 Proto 扩展，不声明 Apple 完全等价。

## Hover 与按压（草案）

Button、Toggle、Form Submit/Reset、Accordion Trigger、Collapsible Trigger、Select Trigger 与 Dropdown Trigger 在 Base 拥有的状态上共享静态 hover 基础。Hover、按压、持久选择与键盘焦点保持独立；禁用或受阻控件不产生交互强调。配方使用克制的抬升与内缘，不缩放控件。这是参考 [iPadOS 26 指针设计](https://developer.apple.com/videos/play/wwdc2025/208/?time=560) 的 Proto 选择，尚未实现 Apple 随目标移动的折射高光层。既有按住指针接触是独立路径，扩大绘制边界无法安全采样时保留明确回退。精确版本的视觉验收仍待完成。Form 操作保留唯一 Base Form owner、继承 render 与 auto/opaque 材质默认值；禁用时抑制请求，不降低整个控件透明度。本次 Form 扩展依赖单独的 CLI 借用状态闭包修复，其他家族角色另行推进。
