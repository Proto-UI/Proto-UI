Liquid Glass Surface 基于 [Base Surface](/zh-cn/ui-libraries/base/surface/) 提供被动视觉容器，默认使用 `12px` 同心圆角（`rounded-xl`）与高可读性不透明绘制，并允许功能外壳通过 `material="auto"` 显式请求玻璃材质。交互逻辑与无障碍语义继续由外层控件负责。

## 用法

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { surfaceRoot } from '@proto.ui/prototypes-liquid-glass/surface';

const Surface = createReactAdapter(React)(surfaceRoot);

export function FloatingPanel() {
  return (
    <Surface variant="outline" material="auto" elevation="raised">
      <div className="p-1">
        <Surface variant="secondary" material="opaque" radius="lg" border="none">
          <div className="p-3">Opaque content nested with concentric corners</div>
        </Surface>
      </div>
    </Surface>
  );
}
```

### 玻璃材质与层级原则

- Surface 默认采用不透明绘制（`material="opaque"`）；仅对适合悬浮的功能或导航外壳显式设置 `material="auto"`，不要将玻璃材质直接叠加在另一层玻璃之上。
- 仅 `outline`、`secondary`、`muted` 三种变体参与 `regular` 玻璃材质请求；`transparent`、`accent`、`solid` 与 `scrim` 始终保持常规绘制。当系统开启减少透明度或高对比度时，自动回退为可读的不透明样式。
- 同心圆角建议遵循 `外层圆角 = 内层圆角 + 内边距`（例如外层 `radius="xl"` 12px 配合 `p-1` 4px 与内层 `radius="lg"` 8px）。
- 开启 `fade` 后，Surface 会将来自 [Transition](/zh-cn/ui-libraries/base/transition/) 的 `transitionState` 映射为透明度（`closed` / `leaving` 为 `0`，`entering` / `entered` 为 `1`），读取 `--pui-surface-transition-duration`（默认 `0ms`）。
