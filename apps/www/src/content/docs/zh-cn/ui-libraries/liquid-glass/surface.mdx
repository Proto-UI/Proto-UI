Liquid Glass Surface 基于 [Base Surface](/zh-cn/ui-libraries/base/surface/)（通过 `asSurfaceRoot()`），提供一个带单个内容槽的被动视觉容器。它负责呈现圆角、边框、阴影层次、可选材质与过渡透明度，不包含交互逻辑或无障碍角色；交互状态与语义继续由外层控件管理。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `@proto.ui/prototypes-liquid-glass/surface`（或包根）导入 `surfaceRoot`。

## 用法

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { surfaceRoot } from '@proto.ui/prototypes-liquid-glass/surface';

const Surface = createReactAdapter(React)(surfaceRoot);

export function Summary() {
  return (
    <Surface variant="muted" radius="md" border="none">
      <div style={{ padding: '1rem' }}>Saved locally</div>
    </Surface>
  );
}
```

### 显式启用玻璃材质

Surface 默认以普通不透明表面渲染（`material="opaque"`）。对于合适的功能或导航外壳，可以显式传入 `material="auto"` 请求 `regular` 玻璃材质：

- 仅 `outline`、`secondary`、`muted` 三种变体参与材质请求；`transparent`、`accent`、`solid`、`scrim` 始终保持普通绘制。
- 当宿主不支持材质、缺少可见画布源、对比度不足或系统开启减少透明度/高对比度时，会自动保持可读的不透明样式，并将 `material` 切回 `"opaque"` 或移除该属性即可随时退回普通样式。
- 若内部包含带样式的 Text 子项且希望继承当前 Surface 前景色，可为 Text 设置 `tone="inherit"`。
- 需要交互能力时，请直接组合 Button 或原生 `<a>` 等真实交互元素，不要把事件或角色附加在 Surface 上。

### 联动 Transition 透明度

将外层 [Transition](/zh-cn/ui-libraries/base/transition/) 的阶段传入 `transitionState` 并开启 `fade={true}` 时，`closed` 与 `leaving` 映射为不透明度 `0`，`entering` 与 `entered` 映射为 `1`。Web 端可通过 CSS 变量 `--pui-surface-transition-duration`（默认 `0ms`）传递非负有限毫秒时长。

`fade` 仅控制透明度表现，不改变交互门控、挂载状态或焦点行为；`scrim` 变体使用常规半透明遮暗绘制，不启用模糊或折射。

## API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `variant` | `'transparent' \| 'outline' \| 'secondary' \| 'muted' \| 'accent' \| 'solid' \| 'scrim'` | `'outline'` | 表面视觉变体 |
| `radius` | `'default' \| 'none' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| 'full'` | `'default'` | 圆角尺寸 |
| `border` | `'all' \| 'bottom' \| 'none'` | `'all'` | 边框范围 |
| `elevation` | `'none' \| 'raised'` | `'none'` | 阴影层级 |
| `material` | `'auto' \| 'opaque'` | `'opaque'` | 设为 `'auto'` 时在适用变体上请求玻璃材质 |
| `transitionState` | `'closed' \| 'entering' \| 'entered' \| 'leaving'` | `'entered'` | 来自外部 Transition 的当前阶段 |
| `fade` | `boolean` | `false` | 是否随 `transitionState` 切换不透明度 |
| `hovered` | `boolean` | `false` | 外部传入的悬停视觉态 |
| `focusVisible` | `boolean` | `false` | 外部传入的键盘焦点视觉态 |
| `pressed` | `boolean` | `false` | 外部传入的按压视觉态 |
| `current` | `boolean` | `false` | 外部传入的当前项视觉态（仅影响外观，不设置 `aria-current`） |

移除任意属性后会恢复其默认值。Surface 不暴露额外状态、事件或方法。
