Liquid Glass Toggle 继承 [Base Toggle](/zh-cn/ui-libraries/base/toggle/) 的持久选中语义与键盘交互，采用 Liquid Glass 玻璃外观：未激活时呈现中性 `regular` 玻璃（`secondary` 填色与前景色），激活时呈现基于主题主色的染色玻璃（`primary` 与 `primary-foreground`）。

组件内置等宽预留空间的小型 `currentColor` 装饰勾选，在切换状态时保持文字或图标居中、外框几何稳定，即使不依赖颜色或光学材质也能清晰区分激活状态。指针按压形变与持久 `active` 状态彼此独立。

## 用法

### 材质与无障碍

- 共享 Web 材质提供者仅采样应用显式提供的可见 canvas 背景，不会抓取任意 DOM。
- 当背景源不可用、存在绘制重叠、处于禁用态、`material="opaque"`，或系统启用减弱透明度、增强对比度、强制颜色模式时，按钮会自动回退到高对比度的不透明主题色对（激活态为 `primary`/`primary-foreground`，未激活态为 `secondary`/`secondary-foreground`），并保留勾选标记以清晰表达选中状态。
- 开启减弱动态效果时，会关闭弹性按压形变并保留静态材质效果。
- 多个玻璃控件之间应留出足够间距以容纳扩展的光学绘制（示例中为 `32px`，较宽的控件可按需增大），避免相互重叠。
- 纯图标按钮仍需提供明确的可访问名称（如 `aria-labelledby`）。设计原则参考 Apple [Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 与 [Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)。

## API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `active` | `boolean` | — | 受控激活状态；通过 `activeChange` 请求变更，由调用方决定是否更新 |
| `defaultActive` | `boolean` | `false` | 非受控初始激活状态 |
| `disabled` | `boolean` | `false` | 禁用交互并清除瞬时按压态，同时保留已有 `active` 状态 |
| `material` | `'auto' \| 'opaque'` | `'auto'` | 设为 `'opaque'` 时关闭光学增强，始终使用不透明样式 |

### 事件与状态

- `activeChange`：载荷为 `{ active: boolean }`。在宿主适配器中通常以 `onActiveChange` 监听该事件。
- 无障碍与暴露状态：通过 `role="button"` 与 `aria-pressed` 反映持久 `active` 状态；暴露的 `pressed` 表示短暂的指针按压状态。焦点与键盘交互继承自 Base Toggle。
