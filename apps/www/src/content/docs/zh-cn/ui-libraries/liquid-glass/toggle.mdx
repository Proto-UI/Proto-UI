Liquid Glass Toggle 继承 [Base Toggle](/zh-cn/ui-libraries/base/toggle/) 的持久开关语义，未激活时使用中性 `regular` 玻璃表面，激活时切换为主色染色玻璃，并通过对称预留空间的 `currentColor` 勾选标记在不改变胶囊尺寸的前提下提供非颜色选中提示。

```tsx

```

### 材质与无障碍

- **玻璃与不透明模式**：默认 `material="auto"` 在宿主提供有效背景源时启用光学折射；设为 `material="opaque"` 或处于禁用、减弱透明度、增强对比度、强制颜色模式时，自动使用高对比度的不透明色对，不降低整个控件的透明度。
- **减弱动态效果**：系统开启减弱动态效果时，会关闭弹性按压形变并保留静态材质表现。
- **避免玻璃叠玻璃**：避免在玻璃容器内再嵌套玻璃切换按钮，相邻玻璃控件之间保持足够间距以容纳光学边缘绘制。
- **无障碍命名**：纯图标切换按钮需提供明确的可访问名称（如视觉隐藏文本或 `aria-labelledby`）。设计参考 Apple [Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 与 [Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)。

## API

以下属性属于 `Root`（传入 `active` 进入受控模式）：

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'active', type: 'boolean | undefined', default: '非受控' },
    { name: 'defaultActive', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'material', type: "'auto' | 'opaque'", default: "'auto'" },
    { name: 'size', type: "'sm' | 'default' | 'lg'", default: "'default'" },
  ]}
/>

- **事件**：`activeChange`（载荷 `{ active: boolean }`，在宿主适配器中以 `onActiveChange` 监听）。
- **方法**：`focusSelf(options?)`（禁用态忽略）。
- **暴露状态**：`active`、`disabled`、`hovered`、`focused`、`focusVisible`、`pressed`。
