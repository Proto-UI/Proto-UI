Liquid Glass Drawer 将功能性液态玻璃材质、微弱内描边高光与柔和遮罩应用于四边缘滑出的模态抽屉面板，支持内容自适应高度、长内容滚动、多档位吸附以及不透明材质回退。

## 用法

```tsx
import {
  LiquidGlassDrawerRoot,
  LiquidGlassDrawerTrigger,
  LiquidGlassDrawerMask,
  LiquidGlassDrawerContent,
  LiquidGlassDrawerHandle,
  LiquidGlassDrawerHeader,
  LiquidGlassDrawerTitle,
  LiquidGlassDrawerDescription,
  LiquidGlassDrawerFooter,
  LiquidGlassDrawerClose,
} from '../proto-ui/components/react';
```

```tsx
<LiquidGlassDrawerRoot>
  <LiquidGlassDrawerTrigger variant="prominent">Open Drawer</LiquidGlassDrawerTrigger>
  <LiquidGlassDrawerMask />
  <LiquidGlassDrawerContent side="bottom">
    <LiquidGlassDrawerHandle />
    <LiquidGlassDrawerHeader>
      <LiquidGlassDrawerTitle>Spatial Audio</LiquidGlassDrawerTitle>
      <LiquidGlassDrawerDescription>
        Adaptive head tracking and studio clarity for nearby devices.
      </LiquidGlassDrawerDescription>
    </LiquidGlassDrawerHeader>
    <div className="flex-1 overflow-y-auto px-4">{/* Content */}</div>
    <LiquidGlassDrawerFooter>
      <LiquidGlassDrawerClose variant="prominent">Done</LiquidGlassDrawerClose>
    </LiquidGlassDrawerFooter>
  </LiquidGlassDrawerContent>
</LiquidGlassDrawerRoot>
```

### 部件结构与材质层次

```text
DrawerRoot
├── DrawerTrigger
├── DrawerMask
└── DrawerContent
    ├── DrawerHandle
    ├── DrawerHeader
    │   ├── DrawerTitle
    │   └── DrawerDescription
    └── DrawerFooter
        └── DrawerClose
```

- **单层玻璃原则**：`Content` 与页面上的 `Trigger` 声明 v2 液态玻璃材质；位于玻璃面板内部的 `Close`、`Header`、`Footer` 均保持非玻璃表面，避免玻璃叠玻璃。
- **层级与回退**：`Trigger` 与 `Close` 支持 `variant="regular" | "prominent"` 区分主次操作；在 `Content` 或 `Trigger` 上传入 `material="opaque"` 可显式切换为不透明回退外观，系统开启降低透明度或减少动态效果偏好时也会自动平滑降级。
- **动效与吸附**：`Content` 采用 320ms 展开 / 240ms 收起缓动，`Mask` 使用 30% 柔和暗色遮罩保留背景通透感；传入 `(0, 1]` 比例数组 `snapPoints` 即可启用多档拖拽与键盘方向键调节。
