## 用法

- **尺寸与滚动**：上下抽屉默认按内容高度自适应，上限受安全可用高度约束；左右抽屉默认上限为 `20rem`。`Content` 内置 `overflow-y-auto` 滚动容器，长内容与关闭按钮可留在同一滚动区域内。
- **自定义范围**：`Content` 的 `minExtent` 与 `maxExtent` 接受长度对象（`unit` 为 `'logical' | 'root-text' | 'available' | 'available-minus-root-text'`，`value` 为非负有限数字）。若最小高度超过安全上限，以上限为准；运行期间收到非法尺寸配置时，`extentValid` 变为 `false` 并保留上一次有效配置。
- **拖拽吸附（`snapPoints`）**：省略、`null` 或空数组表示内容自适应模式；传入由 `(0, 1]` 比例组成的非空数组时启用显式吸附（自动排序去重，比例相对于完整安全上限计算）。在显式吸附模式下，`Handle` 提供具名 `separator` 语义、方向键与 Home / End 档位调节；内容自适应模式下 `Handle` 仅为指针拖动把手（`aria-hidden`）。
- **受控与关闭**：`Root` 支持受控 `open` 或非受控 `defaultOpen`；`snapPoint` 搭配 `snapPointChange` 支持受控档位，`defaultSnapPoint` 用于非受控初始档位。设置 `Content.dragDismissible={false}` 可禁止拖动关闭，同时保留 Close 按钮、Escape 与点击外部关闭。若调用方拒绝关闭或手势中断，界面会恢复到当前已接受状态。

## API

| 部件 | 属性 | 说明 |
| --- | --- | --- |
| Root | `open` / `defaultOpen` | 受控 / 非受控展开状态 |
| Root | `snapPoints` | 非空 `(0, 1]` 比例数组；省略或为空时启用内容自适应高度 |
| Root | `snapPoint` / `defaultSnapPoint` | 受控 / 非受控当前吸附比例，受控时配合 `snapPointChange` 使用 |
| Content | `minExtent` / `maxExtent` | 中立长度约束（`unit` + 非负有限 `value`） |
| Content | `dragDismissible` | 设为 `false` 时禁止通过拖拽关闭抽屉 |
| Content（暴露状态） | `extentValid` | 指示当前尺寸约束是否有效 |
