Liquid Glass Meter 用于展示有界数值的度量结果（如存储占用、配额使用率或电量状态），支持通过 `low`、`high`、`optimum` 自动划分 `optimal`、`suboptimal` 与 `critical` 状态。遵循 Apple Liquid Glass 分层准则，Meter 轨道与指示条作为清晰可读的非材质内容层计量元素呈现，而非叠加玻璃面板。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可从 `@proto.ui/prototypes-liquid-glass/meter` 导入各部件原型：

```ts
import {
  meterRoot,
  meterLabel,
  meterTrack,
  meterIndicator,
  meterValue,
} from '@proto.ui/prototypes-liquid-glass/meter';
```

## 用法

```tsx
import { AdaptToReact } from '@proto.ui/adapter-react';
import {
  meterRoot,
  meterLabel,
  meterTrack,
  meterIndicator,
  meterValue,
} from '@proto.ui/prototypes-liquid-glass/meter';

const MeterRoot = AdaptToReact(meterRoot);
const MeterLabel = AdaptToReact(meterLabel);
const MeterTrack = AdaptToReact(meterTrack);
const MeterIndicator = AdaptToReact(meterIndicator);
const MeterValue = AdaptToReact(meterValue);

export function LiquidGlassStorageMeter() {
  return (
    <MeterRoot value={32} min={0} max={100} low={50} high={80} optimum={20} valueText="32%">
      <div className="flex items-center justify-between gap-2">
        <MeterLabel>Storage used</MeterLabel>
        <MeterValue />
      </div>
      <MeterTrack>
        <MeterIndicator />
      </MeterTrack>
    </MeterRoot>
  );
}
```

### 层级设计与部件组成

- **内容层非材质设计**：按照 Apple HIG Materials 规范，Liquid Glass 专用于内容层之上的浮动导航与交互控件；Meter 的 `Track` 与 `Indicator` 不申请玻璃材质，采用紧凑的同心胶囊轨道（`rounded-full`）、清晰边框与语义高对比填充，与上方的浮动 Liquid Glass 按钮自然分层，避免「玻璃叠玻璃」。
- **部件与范围**：`Root` 将数值自动钳制在 `[min, max]`（`min === max` 时比例为 `0`）；`Label` 提供名称，`Value` 以等宽数字显示 `valueText` 或规范数值；`Indicator` 针对 `optimal`、`suboptimal`、`critical` 分别应用主色、告警过渡色与危险色填充。
- Meter 为被动展示组件（`role="meter"`），不引入额外键盘焦点停靠点；属性变化时各子部件同步刷新暴露状态。
