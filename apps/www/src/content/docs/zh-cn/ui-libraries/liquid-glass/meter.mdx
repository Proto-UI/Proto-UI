Liquid Glass Meter 用于展示有界数值的度量结果（如存储占用、密码强度或配额使用率），支持通过 `low`、`high`、`optimum` 自动将读数划分为 `optimal`、`suboptimal` 或 `critical` 状态。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `meter` 子路径导入 `meterRoot`、`meterLabel`、`meterTrack`、`meterIndicator` 与 `meterValue`。

## 用法

- **部件组成**：`Root` 管理数值边界，`Label` 提供名称，`Track` 容纳 `Indicator`，`Value` 优先显示 `valueText` 或规范数值。
- **范围与区间分级**：输入数值会自动限制在 `[min, max]` 之间（当 `min === max` 时比例为 `0`）。`low`、`high`、`optimum` 仅决定状态分级，不改写原始数值。
- Meter 为纯被动展示组件，不引入额外键盘停靠点或编辑事件；更新属性时所有子部件同步刷新。

## API

| 部件 | 属性 / 暴露状态 | 默认值与说明 |
| --- | --- | --- |
| Root | `value` | 当前度量数值，自动限制在 `[min, max]` 范围内 |
| Root | `min` / `max` | `0` / `100` |
| Root | `low` / `high` / `optimum` | 区间阈值，用于将当前值归类为 `optimal`、`suboptimal` 或 `critical` |
| Root | `ariaLabel` / `valueText` | 可访问名称与可读文本格式化值 |
| Root / 部件（暴露状态） | `value` / `percentage` / `indeterminate` / `status` | 归一化数值、百分比与区间状态 |
