Liquid Glass Carousel 将清晰通透的内容滑块与悬浮其上的圆形液态玻璃翻页控制分层组合：内容区保持实体与高对比度，前后按钮作为浮动导航层使用 Liquid Glass 材质（支持 `regular` / `prominent` 层级与 `material="opaque"` 回退），不在玻璃之上叠放玻璃。

将于 `0.3.0-rc.1` 及后续版本中提供。

## 用法

```tsx
import {
  LiquidGlassCarouselRoot,
  LiquidGlassCarouselViewport,
  LiquidGlassCarouselSlide,
  LiquidGlassCarouselPrevious,
  LiquidGlassCarouselNext,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <LiquidGlassCarouselRoot className="mx-auto w-full max-w-md">
      <LiquidGlassCarouselViewport>
        <LiquidGlassCarouselSlide>1</LiquidGlassCarouselSlide>
        <LiquidGlassCarouselSlide>2</LiquidGlassCarouselSlide>
        <LiquidGlassCarouselSlide>3</LiquidGlassCarouselSlide>
      </LiquidGlassCarouselViewport>
      <LiquidGlassCarouselPrevious aria-label="Previous slide">‹</LiquidGlassCarouselPrevious>
      <LiquidGlassCarouselNext aria-label="Next slide">›</LiquidGlassCarouselNext>
    </LiquidGlassCarouselRoot>
  );
}
```

- **材质与层级**：`Previous` / `Next` 默认采用 `variant="regular"` 圆形液态玻璃控件悬浮在内容边缘，按需可为主要推进操作设置 `variant="prominent"`；当系统启用降低透明度、提高对比度或设置 `material="opaque"` 时自动回退为高可读性不透明表面。
- **同心圆角与响应式容量**：视口采用 `rounded-xl` 与卡片内边距形成同心圆角关系；通过 `slidesPerView` 与 `minSlideSize` 控制响应式可见项数。
- **方向与受控模式**：支持 `orientation="vertical"`、`direction="rtl"`、`loop={true}` 及 `index` / `indexChange` 受控索引。

### 暴露状态、方法与事件

- **Root**：状态 `index`、`slideCount`、`visibleSlides`、`maxIndex`；方法 `requestIndex(next)`；事件 `indexChange`。
- **Viewport**：状态 `focusVisible`、`dragging`、`scrolling`、`scrollPosition`。
- **Slide**：状态 `current`、`hidden`、`basis`、`minSize`。
