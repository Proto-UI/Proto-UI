Liquid Glass Carousel 组合等宽项目条、可连续滚动的视口以及前后翻页控制。支持鼠标/触摸拖动、滚轮、触控板、滚动条与键盘导航，松手或滚动静止后自动吸附到最近的可达项。

## 用法

- **响应式容量**：`slidesPerView` 设置最多显示的等尺寸项数（默认 `1`），`minSlideSize` 设置单项最小逻辑像素尺寸（默认 `0`）。最后一个吸附位自动贴齐末端，避免留下大片空白。
- **受控索引**：传入 `index` 进入受控模式，`indexChange` 提出目标吸附索引。拖动过程中不会提前改写已提交的 `index`；松手时若调用方未更新 `index`，会平滑回弹至当前值。
- **方向与循环**：使用 `orientation="vertical"` 时需为视口设置明确高度；水平模式下 `direction="rtl"` 会反转拖动和方向键，但保留逻辑项顺序。`loop` 在首尾索引间循环切换（不通过克隆节点实现无限循环）。
- 当前版本面向等尺寸项与手动/键盘导航，不包含自动播放或不等宽项。

## API

| 部件 | 属性 / 状态 | 默认值与说明 |
| --- | --- | --- |
| Root | `slidesPerView` | `1`；最多同时显示的等尺寸项目数 |
| Root | `minSlideSize` | `0`；单项最小逻辑宿主像素尺寸 |
| Root | `index` | 受控当前吸附索引，配合 `indexChange` 事件使用 |
| Root | `orientation` / `direction` / `loop` | 滚动轴向、文本方向与首尾循环开关 |
| Root（暴露状态） | `visibleSlides` / `maxIndex` | 根据实际视口计算的可见项数与最大可达索引 |
| Viewport（暴露状态） | `dragging` / `scrolling` / `scrollPosition` | 拖动状态、滚动状态与归一化滚动进度 |
| Slide（暴露状态） | `current` / `hidden` | 分别对应当前吸附项与屏外可见性（不移除布局尺寸） |
