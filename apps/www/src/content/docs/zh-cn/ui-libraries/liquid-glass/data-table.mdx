Liquid Glass Data Table 将语义化表格结构与稳定记录 ID、稳定排序、全局过滤、分页及行选择组合在一起。排序和翻页直接更新每个数据槽绑定的真实记录内容，保持 DOM 结构与视觉顺序一致。

## 用法

- **行与单元格映射**：传入的每条数据 `rows` 需包含唯一 `id`。正文行使用 `DataTableRow` 并按当前页 `index` 编排显示槽，单元格按 `columnKey` 读取当前槽位记录的字段值。
- **可排序表头行**：将排序表头放置在 `DataTableHeaderRow` 中。它继承被动表格行结构，不额外创建选择、焦点或触发器上下文，从而允许在同一表头行内放置多个排序触发器。
- Data Table 专注于本地数据的排序、过滤、分页与选择，不内置网络请求、行内编辑或列拖拽重排。

## API

| 部件               | 关键属性    | 说明                                 |
| ------------------ | ----------- | ------------------------------------ |
| DataTableRoot      | `rows`      | 记录数组，每条记录需提供唯一 `id`    |
| DataTableHeaderRow | —           | 表头行容器，可包含多个排序表头触发器 |
| DataTableRow       | `index`     | 当前页内的数据行显示槽               |
| DataTableCell      | `columnKey` | 指定单元格读取当前记录的字段键       |
