Proto UI 不是一套单一组件库，而是一套让你在共用交互协议之上，按产品气质选择视觉语言的基础设施。

0.3 发布范围为 Base、Shadcn、Brutalist（Neo-Brutalism）和 Lucide。Bootstrap 2.3.2、Liquid Glass 及其他 UI libraries 均为 **WIP / 实验性**，归入 0.4 工作流，不作为稳定的 0.3 覆盖承诺。纳入发布范围不等于自动提升 draft 原型的生命周期，也不代表已经通过验收。

下面的入口直接使用各组件库自身的原型；Lucide 用中性容器展示图标。来源信息区分设计参考、图标来源与 Proto UI 的原型实现。
