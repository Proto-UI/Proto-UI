## 用法

固定图标原型支持 `size`、`strokeWidth`、`stroke` 与 `fill` 属性；按名称选择的入口额外支持 `name` 属性。卡片内提供的是面向原型编写的代码片段。

如需查看完整安装包名、Web Components / React / Vue / Vue 2 宿主集成示例、属性默认值与无障碍说明，请参阅 [Lucide 图标库指南](../)。
