当前页面收录 Proto UI 已启用的 Lucide 图标。每个图标卡片支持：

- 复制 `asHook` 使用片段。
- 复制内联 `render` 片段。
- 图标卡片进入视口后才按需加载对应模块。

<LucideIconGallery locale="zh-cn" />

## API

Lucide 图标是从 `lucide-static` 生成的工作区源码。它们没有属性；每个图标都是一个渲染 SVG 的原型。从任意图标卡片复制 `asHook` 或 `render` 代码片段即可使用。
