当前页面收录 Proto UI 已启用的 Lucide 图标。每个图标卡片支持：

- 复制 `asHook` 使用片段。
- 复制内联 `render` 片段。
- 图标卡片进入视口后才按需加载对应模块。

<LucideIconGallery locale="zh-cn" />

## 使用图标

固定 glyph 原型接受 `size`、`strokeWidth`、`stroke` 与 `fill`，按名称选择的入口还接受 `name`。卡片片段面向 Prototype 编写，不是完整宿主应用。[Lucide 图标库指南](../)提供精确包名、完整 WC/React/Vue/Vue 2 源码示例、默认值、装饰性可见性与当前可访问名称边界。
