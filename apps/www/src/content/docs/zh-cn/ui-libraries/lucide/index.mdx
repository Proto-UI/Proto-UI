Proto UI 从 `lucide-static` 生成 Lucide 图标原型。这是该图标库的主要工作页面：可直接检索图标，打开图标卡片查看导入路径，并复制 `asHook` 或内联 `render` 片段。

图标以独立入口按需引入；网格分批渲染，每个 SVG 只在接近视口时加载，不需要为单个图标进入独立文档页。

## 安装

在已有 bundler 应用中使用已发布 0.2.0 Web Component 基线：

```sh
npm install @proto.ui/prototypes-lucide@0.2.0 @proto.ui/adapter-web-component@0.2.0
```

也可以使用 pnpm：

```sh
pnpm add @proto.ui/prototypes-lucide@0.2.0 @proto.ui/adapter-web-component@0.2.0
```

React 与 Vue 3 应用分别改用 `@proto.ui/adapter-react@0.2.0`、`@proto.ui/adapter-vue@0.2.0`，并保留已安装的框架。Vue 2.6（`>=2.6.0 <2.7`）使用配套的工作区 0.3 `@proto.ui/adapter-vue2` 源码，不属于稳定版 0.2.0 包集合。图标库使用当前工作区源码，其生成基线不能证明 registry 已提供更新版本。

## 属性与原型编写

按名称选择的 `lucideIcon` / `asLucideIcon` 入口接受 `name`，默认 `circle`。`lucideCheckIcon` 等固定 glyph 原型保留自身图形，并接受共享的视觉属性：

| 属性          | 类型     | 默认值         |
| ------------- | -------- | -------------- |
| `size`        | 有限正数 | `24`           |
| `strokeWidth` | 有限正数 | `2`            |
| `stroke`      | string   | `currentColor` |
| `fill`        | string   | `none`         |

无效名称回退到 `circle`；非有限值或非正数尺寸回退到各自默认值。SVG 使用 `viewBox="0 0 24 24"`，固定 glyph 不接受可变 `name`。

编写 Prototype 时，`renderLucideCheckIcon(renderer, { size: 18 })` 向现有 renderer 追加 SVG，`asLucideCheckIcon()` 是固定 glyph hook。卡片中的 `render` 片段属于 Prototype 的 render callback，本身不是独立的 React/Vue 组件，也不是完整应用。

当前图标协议没有 `decorative`、accessible label、`title` 或 `role` prop。有意义的文本或可访问名称属于拥有图标的控件，装饰性图标的可见性由宿主边界处理；SVG 渲染成功不能证明可访问性已完成。
