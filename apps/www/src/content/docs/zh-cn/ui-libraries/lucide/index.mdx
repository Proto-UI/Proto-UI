Proto UI 基于 `lucide-static` 提供按需加载的 Lucide 图标原型。你可以在下方直接搜索图标，打开任意卡片查看导入路径，并复制 `asHook` 或内联 `render` 片段。

每个图标都提供独立入口以支持按需引入；图标网格按视口分批懒加载 SVG，无需逐个跳转到独立详情页。

## 安装

在已有打包工具的 Web Component 项目中安装 0.2.0 稳定版：

```sh
npm install @proto.ui/prototypes-lucide@0.2.0 @proto.ui/adapter-web-component@0.2.0
```

或使用 pnpm：

```sh
pnpm add @proto.ui/prototypes-lucide@0.2.0 @proto.ui/adapter-web-component@0.2.0
```

- **React**：改用 `@proto.ui/adapter-react@0.2.0`
- **Vue 3**：改用 `@proto.ui/adapter-vue@0.2.0`
- **Vue 2.6**（`>=2.6.0 <2.7`）：`@proto.ui/adapter-vue2` 将于 `0.3.0-rc.1` 及后续版本中提供。

### 原型组合

编写自定义原型时，可通过以下两种方式复用图标：

- `asLucideCheckIcon()`：作为固定图标 Hook 组合到原型中。
- `renderLucideCheckIcon(renderer, { size: 18 })`：在原型的 `render` 回调中直接向当前 `renderer` 追加 SVG。

所有图标使用 `viewBox="0 0 24 24"`。通过名称动态选择的 `lucideIcon` / `asLucideIcon` 入口支持 `name` 属性（无效名称回退到 `circle`）；固定图标入口（如 `lucideCheckIcon`）绑定自身图形，不接受可变 `name`。

## API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `name` | `string` | `'circle'` | 仅 `lucideIcon` / `asLucideIcon` 支持；无效名称回退到 `circle` |
| `size` | 有限正数 | `24` | 图标宽高；非法或非正数回退到默认值 |
| `strokeWidth` | 有限正数 | `2` | 描边宽度；非法或非正数回退到默认值 |
| `stroke` | `string` | `'currentColor'` | 描边颜色 |
| `fill` | `string` | `'none'` | 填充颜色 |

图标原型当前不内置 `decorative`、`title`、`role` 或可访问标签属性，请在宿主元素或所属交互控件上配置无障碍属性。

图标资产派生自 `lucide-static@1.8.0`，使用时请保留 [Lucide/Feather 许可声明](https://github.com/Proto-UI/Proto-UI/blob/main/packages/prototypes/lucide/THIRD_PARTY_NOTICES.md)与[来源清单](https://github.com/Proto-UI/Proto-UI/blob/main/packages/prototypes/lucide/src/manifest.generated.ts)。
