Proto UI 从 `lucide-static` 生成 Lucide 图标原型。这是该图标库的主要工作页面：可直接检索图标，打开图标卡片查看导入路径，并复制 `asHook` 或内联 `render` 片段。

图标以独立入口按需引入；网格分批渲染，每个 SVG 只在接近视口时加载，不需要为单个图标进入独立文档页。

<LucideIconGallery locale="zh-cn" />

## API

Lucide 图标是从 `lucide-static` 生成的工作区源码。它们没有属性；每个图标都是一个渲染 SVG 的原型。从任意图标卡片复制 `asHook` 或 `render` 代码片段即可使用。
