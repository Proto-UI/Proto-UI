这是 Proto UI 维护的非官方 Shadcn 投射。交互由 Base 拥有，风格家族提供呈现与明确记录的视觉输入。它不是官方 shadcn/ui 发行包。

## 安装与使用

在已有应用中，已发布 0.2.0 的用法为：

```sh
npx @proto.ui/cli@0.2.0 init
npx @proto.ui/cli@0.2.0 add wc shadcn-button
```

使用 pnpm 时执行：

```sh
pnpm dlx @proto.ui/cli@0.2.0 init
pnpm dlx @proto.ui/cli@0.2.0 add wc shadcn-button
```

CLI 按自身精确版本安装 `@proto.ui/prototypes-shadcn` 与所选 Adapter，并生成本地宿主 facade。应用应导入一次生成的样式表。[快速开始](/zh-cn/start-here/quick-start/)说明应用设置，[Button](./button/)把预览与宿主代码配对。稳定版 React、Vue 3 分别使用 `react`、`vue`。Vue 2.6 与当前命名 style profile 需要配套的工作区 0.3 源码；`@latest` 不能证明已经交付这些能力。
