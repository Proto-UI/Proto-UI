Proto UI 独立维护的 Shadcn 风格组件库：底层交互与无障碍行为由 Base 协议统一提供，视觉层呈现 Shadcn 风格并支持在 Web Components、React、Vue 3 与 Vue 2 之间复用。

## 安装与使用

在已有应用中，先初始化项目并添加所需组件（以 0.2.0 稳定版为例）：

```sh
npx @proto.ui/cli@0.2.0 init
npx @proto.ui/cli@0.2.0 add wc shadcn-button
```

使用 pnpm：

```sh
pnpm dlx @proto.ui/cli@0.2.0 init
pnpm dlx @proto.ui/cli@0.2.0 add wc shadcn-button
```

将 `wc` 替换为 `react` 或 `vue` 即可为对应框架生成本地组件封装，并在应用入口导入一次生成的 `proto-ui-style.css`。完整配置步骤请参阅[快速开始](/zh-cn/start-here/quick-start/)，跨框架完整示例请参阅 [Button](./button/)。Vue 2.6 支持以及新增的命名风格预设（如 **Shadcn Rhea**）目前在源码工作区提供。

## 设计说明

- 各组件的交互状态、键盘导航与无障碍语义均与对应的 Base 原型保持一致。例如 [Button](./button/) 的 `link` 变体保留按钮操作语义，页面跳转请直接使用原生 `<a>` 标签。
- 不同组件的风格预设支持范围以各组件页说明为准，需要整体切换局部区域风格时可搭配 [Style Scope](./style-scope/) 使用。
