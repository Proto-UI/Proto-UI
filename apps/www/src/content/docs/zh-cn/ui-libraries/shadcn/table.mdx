Table 用于呈现结构化二维数据，完整保留 [Base Table](/zh-cn/ui-libraries/base/table/) 的行列与表头语义，并附带 Shadcn 边框、单元格内边距、表头强调及表尾样式。本页示例使用 **Shadcn Rhea** 风格。

## 用法

Table 由 `Root`、`Caption`、`Row`、`HeaderCell` 和 `Cell` 五个部件组成：

- `Root` 建立独立的表格域；`Caption` 提供表格说明文字。
- `Row` 定义有序逻辑行，并提供两个视觉属性用于控制边框样式：`section`（`'header' | 'body' | 'footer'`，默认 `'body'`）和 `lastInSection`（默认 `false`）。
- `HeaderCell` 声明 `headerKey` 与 `headerKind`（`'column' | 'row'`）；`Cell` 通过有序的 `headers` 键列表关联所属表头，支持正整数 `rowSpan` 和 `columnSpan`（默认均为 `1`）。
- 表格聚焦于静态结构化展示；横向滚动容器请在外层自行包裹，如需排序、筛选或行选择，请使用 Data Table。

## API

`Root`（`TableRootProps`）无额外属性。常用子部件属性如下：

- `Row`：`section`（`'header' | 'body' | 'footer'`，默认 `'body'`）、`lastInSection`（`boolean`，默认 `false`）。
- `HeaderCell`：`headerKey`（`string`）、`headerKind`（`'column' | 'row'`）、`rowSpan`（默认 `1`）、`columnSpan`（默认 `1`）。
- `Cell`：`headers`（有序表头键集合）、`rowSpan`（默认 `1`）、`columnSpan`（默认 `1`）。
