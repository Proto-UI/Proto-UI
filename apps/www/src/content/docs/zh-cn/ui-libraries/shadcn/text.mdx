Text 继承 [Base Text](/zh-cn/ui-libraries/base/text/) 的八项独立排版属性，使用 Shadcn 主题令牌管理字号、字重、行高、字距与前景色，同时把标题层级与交互语义交由外层原生元素承担。本页示例采用 **Shadcn Rhea** 风格。

## 安装

先[初始化你的应用](/zh-cn/start-here/quick-start/)，再添加 `shadcn-text` 组件（当前草案能力在工作区源码中提供）：

<InstallCommandCard
  commands={{
    npm: 'npx @proto.ui/cli@latest add wc shadcn-text',
    pnpm: 'pnpm dlx @proto.ui/cli@latest add wc shadcn-text',
  }}
  manager="npm"
/>

将命令中的 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的本地组件封装。

## 用法

CLI 生成的组件可直接配合原生 `h1`–`h4`、`p`、`blockquote`、`code`、`label` 与 `a` 使用：

```tsx
import { ShadcnTextRoot } from '../proto-ui/components/react';

export function SectionTitle() {
  return (
    <h1>
      <ShadcnTextRoot size="4xl" font="heading" weight="bold" leading="tight" tracking="tight">
        Account settings
      </ShadcnTextRoot>
    </h1>
  );
}
```

也可以直接从 `@proto.ui/prototypes-shadcn/text` 导入 `shadcnTextRoot`（提供 `textRoot` 与 `ShadcnTextRoot` 别名）并通过 Adapter 指定 `rootTag: 'span'`，或按需启用内置的 `SHADCN_TYPOGRAPHY` 字体主题预设（Geist 搭配系统与 CJK 回退链；字体文件与授权由应用自行托管）：

```ts
import { shadcnTextRoot, SHADCN_TYPOGRAPHY } from '@proto.ui/prototypes-shadcn/text';
```

### 语义边界与排版细节

- **外层原生语义**：Text 本身不添加角色、焦点停靠点或点击事件；标题层级、`label`（`htmlFor` / `for`）与链接（`href`、`target`、`download`）应由外层原生元素声明。
- **字号内建行高与紧凑刻度**：`leading="size"` 保留所选字号的内建行高（`xs` `1rem`、`sm` `1.25rem`、`base` `1.5rem`、`lg` `1.75rem`、`xl` `1.75rem`、`2xl` `2rem`、`3xl` `2.25rem`、`4xl` `2.5rem`、`5xl` `1`）；`leading="tighter"` 对应 `1.1`，`tracking="tighter"` 对应 `-0.05em`。
- **默认值与回退**：移除属性即可恢复默认值；初始传入非法 `size` 回退到 `base`，已有合法值后更新为非法值则保留上一个有效值。
- **操作排版预设（`actionProfile`）**：默认为 `'none'`，不会隐式订阅 `shadcn-style-scope`；显式传入 `'rhea'` 或 `'luma'` 等预设时应用对应的操作行高（`rhea` / `luma` / `vega` / `nova` / `maia` / `new-york-v4` 为 `1.25rem`，`lyra` / `sera` 为 `1rem`，`mira` 为 `1.625`，`sera` 额外启用大写与宽字距）。
