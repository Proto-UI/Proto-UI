Text 继承 [Base Text](/zh-cn/ui-libraries/base/text/) 的排版属性体系，以 Shadcn 主题令牌控制字号、行高、字距与文字颜色，不接管文档标题层级或交互语义。本页示例使用 **Shadcn Rhea** 风格。

## 用法

从 `@proto.ui/prototypes-shadcn/text`（或包根）导入 `shadcnTextRoot`（也提供 `textRoot` 和 `ShadcnTextRoot` 别名），并在适配时按需配置 Web 宿主元素标签：

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { shadcnTextRoot } from '@proto.ui/prototypes-shadcn/text';

const Text = createReactAdapter(React)(shadcnTextRoot, { rootTag: 'span' });

export function SectionTitle() {
  return (
    <h1>
      <Text size="4xl" font="heading" weight="semibold" leading="tight" tracking="tight">
        Account settings
      </Text>
    </h1>
  );
}
```

### 语义边界与颜色继承

- `rootTag: 'span'` 属于 Web Adapter 配置项而非组件属性。标题层级、段落、表单标签（`htmlFor` / `for`）和链接（`href`、`target`、`download`）仍由外层原生 `h1`、`p`、`label` 或 `a` 元素负责。
- 在深色或高对比度表面（如 `Surface` 的 `solid` / `accent` 变体）内部，可设置 `tone="inherit"` 让文字继承外层容器的前景色。

### 行高与字距细节

- 设置 `leading="size"` 时，使用所选字号内建的行高刻度：`xs` (`1rem`)、`sm` (`1.25rem`)、`base` (`1.5rem`)、`lg` (`1.75rem`)、`xl` (`1.75rem`)、`2xl` (`2rem`)、`3xl` (`2.25rem`)、`4xl` (`2.5rem`)、`5xl` (`1`)。
- `leading="tighter"` 对应 `1.1`，`tracking="tighter"` 对应 `-0.05em`。
- 省略属性或移除属性会恢复默认值；若传入非法字号，初始化时回退到 `base`，已有合法值后更新非法值则会保留上一个有效值。
- 在 Shadcn 操作按钮组合中，`actionProfile="rhea"` 或 `"luma"` 固定采用 `1.25rem` 行高。
