Progress 用于直观展示任务在有界范围内的完成进度，并支持未知进度的不确定状态（`indeterminate`）。本页示例采用 **Shadcn Rhea** 风格。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。注册包入口后可从 `@proto.ui/prototypes-shadcn/progress` 导入全部部件：

```ts
import {
  progressRoot,
  progressLabel,
  progressTrack,
  progressIndicator,
  progressValue,
} from '@proto.ui/prototypes-shadcn/progress';
```

## 用法

最小组合包含 `Root`、`Track` 和 `Indicator`；需要标签与数值显示时，将 `Label` 与 `Value` 放在 `Track` 之前以自动对齐同一标题行：

```tsx
<ShadcnProgressRoot styleProfile="rhea" value={56} valueText="56%" className="w-full max-w-sm">
  <ShadcnProgressLabel styleProfile="rhea">Upload progress</ShadcnProgressLabel>
  <ShadcnProgressValue styleProfile="rhea" />
  <ShadcnProgressTrack styleProfile="rhea">
    <ShadcnProgressIndicator styleProfile="rhea" />
  </ShadcnProgressTrack>
</ShadcnProgressRoot>
```

```text
ProgressRoot
├── ProgressLabel
├── ProgressValue
└── ProgressTrack
    └── ProgressIndicator
```

- **数值范围与不确定态**：`value` 自动限制在 `[min, max]` 之间（当 `min === max` 时百分比为 `0`）。省略 `value` 或设置 `indeterminate={true}` 时进入不确定进度态，此时不再向辅助技术报告具体当前值。
- **风格预设与方向**：支持 `styleProfile`（`vega`、`nova`、`maia`、`lyra`、`mira`、`luma`、`sera`、`rhea`、`new-york-v4` / `new-york` 或 `inherit`），并支持 `dir="ltr" | "rtl"` 与逻辑末尾对齐（`ms-auto`）。
- **无障碍与状态**：Progress 为只读展示组件，不引入键盘焦点停靠点。`Root` 及各部件同步暴露 `value`、`percentage`、`indeterminate` 与 `status`，并通过 `--pui-percentage` 驱动指示条宽度过渡。

### 子部件与暴露状态

- `ProgressLabel`、`ProgressTrack`、`ProgressIndicator`、`ProgressValue` 均支持可选的 `styleProfile` 覆盖。
- 所有部件同步暴露只读状态 `value`（`number`）、`percentage`（`number`，`0–100`）、`indeterminate`（`boolean`）与 `status`（`'indeterminate' | 'loading' | 'complete'`）。
