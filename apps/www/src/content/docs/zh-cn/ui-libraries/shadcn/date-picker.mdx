## 用法

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

### 选择模式与关闭时机

- **单选与范围模式**：`mode="single"` 在接受选中日期后请求关闭弹层；`mode="range"` 在选中起点时保持弹层打开，选中第二个端点并形成完整范围后自动请求关闭。受控模式下若本次选择被拒绝或尚未采纳，弹层保持打开。
- **多选模式**：`mode="multiple"` 每次切换日期后保持弹层打开，方便连续选择，完成后通过点击外部或按 `Escape` 关闭。
- **日期规则继承**：范围与多选模式下的 `range` / `defaultRange`、`values` / `defaultValues`、日期范围限制（`min`、`max`、`unavailable`）及数量/间隔约束均直接复用 [Calendar](../calendar/) 的属性与回调。

### 显示值（`Value`）

`Value` 部件会根据当前模式自动格式化展示内容：

- 单选：单个 `YYYY-MM-DD` 日期；
- 多选：按日期排序的逗号分隔列表；
- 范围：未完成时显示 `from …`，完成后显示 `from – to`；
- 空值：显示 `placeholder`。

弹层焦点恢复与关闭交互由 `Popover` 统一管理。

## API

弹层的 `open` 状态由 `Popover` 管理，选择模式、选中值、日期限制与显示月份由 `Calendar` 管理。`Date Picker` 仅在 `Value` 上额外提供一个属性：
