区域只拥有一个 `busy` prop（默认 `false`），在区域元素上投射 `aria-busy`，并通过 `getExposes().busy` 暴露同一事实。忙碌是语义事实，不是 spinner：该投射不添加 role、accessible name、加载计时器、替代状态机、公告通道或焦点路径。仅在 prop 变化时，作者后代保持挂载并保留焦点。需要公告时，在应用层与 Live Region 组合使用。
