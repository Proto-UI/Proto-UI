## 用法

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

`Async Region` 由单一 `Root` 部件组成，用于标记正在进行异步更新的区域：

- 设置 `busy={true}` 时，组件会在区域元素上同步设置 `aria-busy`，并通过 `getExposes().busy` 暴露同一状态。
- 仅更新属性时，传入的子元素会保持挂载且不丢失当前焦点。
- 组件专注于忙碌状态语义，本身不渲染骨架屏或加载指示器；需要向屏幕阅读器播报加载进度或结果时，请在应用层搭配 [Live Region](../live-region/) 使用。
