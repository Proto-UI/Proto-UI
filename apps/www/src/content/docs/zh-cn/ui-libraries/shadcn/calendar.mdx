支持单选（`single`）、多选（`multiple`）与日期范围（`range`）的公历日历组件，提供本地化星期标题、RTL 键盘导航与可组合年月选择器。本页示例采用 **Shadcn Rhea** 风格预设。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供；可在工作区中直接从 `@proto.ui/prototypes-shadcn/calendar` 引入。

## 用法

```tsx
import {
  CalendarRoot,
  CalendarCaption,
  CalendarPrevious,
  CalendarHeading,
  CalendarNext,
  CalendarGrid,
  CalendarWeekdays,
  CalendarWeekday,
  CalendarRow,
  CalendarDay,
} from '@proto.ui/prototypes-shadcn/calendar';

export function ExampleCalendar() {
  return (
    <CalendarRoot
      styleProfile="rhea"
      mode="single"
      defaultMonth="2026-10"
      defaultValue="2026-10-12"
      today="2026-10-08"
      className="rounded-lg border border-border"
    >
      <CalendarCaption>
        <CalendarPrevious a11yLabel="Previous month" />
        <CalendarHeading />
        <CalendarNext a11yLabel="Next month" />
      </CalendarCaption>
      <CalendarGrid>
        <CalendarWeekdays>
          {Array.from({ length: 7 }, (_, offset) => (
            <CalendarWeekday key={offset} offset={offset} />
          ))}
        </CalendarWeekdays>
        {Array.from({ length: 6 }, (_, row) => (
          <CalendarRow key={row} index={row}>
            {Array.from({ length: 7 }, (_, col) => (
              <CalendarDay key={col} offset={row * 7 + col} />
            ))}
          </CalendarRow>
        ))}
      </CalendarGrid>
    </CalendarRoot>
  );
}
```

### 部件结构与键盘导航

- `Calendar` 由十个部件组成：`Root`、`Caption`、`Heading`、`Previous`、`Next`、`Grid`、`Weekdays`、`Weekday`、`Row` 与 `Day`。
- 默认按当月最少需要的 4–6 周渲染；设置 `fixedWeeks={true}` 可固定显示六周，多余行与单元格自动隐藏并移出焦点路径。
- 方向键支持跨月连续移动，`Home` / `End` 跳至当周起止，`PageUp` / `PageDown` 翻月（配合 `Shift` 翻年）；`direction="rtl"` 自动镜像左右方向键。
- 组件不直接读取系统时钟或时区：为避免 SSR 水合偏移，请由宿主在客户端通过 `today` 传入 `YYYY-MM-DD` 字符串标记今天（自动映射 `aria-current="date"`）。
- 如需弹出式日期输入，可配合 `Date Picker` 组件使用；如需月份/年份下拉跳转，可通过 `bindCalendarCaption(source, { month, year })` 与同族 `Select` 组合（退出时调用 `dispose()`）。

### 选择模式

| 模式       | 受控值 / 初始值                                 | 变更事件                     |
| ---------- | ----------------------------------------------- | ---------------------------- |
| `single`   | `value` / `defaultValue`：`YYYY-MM-DD`          | `onValueChange({ value })`   |
| `multiple` | `values` / `defaultValues`：`readonly string[]` | `onValuesChange({ values })` |
| `range`    | `range` / `defaultRange`：`{ from?, to? }`      | `onRangeChange({ range })`   |

### 事件、方法与暴露状态

- **事件（Root）**：`onValueChange({ value })`、`onValuesChange({ values })`、`onRangeChange({ range })`、`onMonthChange({ month })`。
- **方法（Root）**：`requestValue(date)`、`requestValues(dates)`、`requestRange(range)`、`requestMonth(month)`、`getValues()`、`getRange()`。
- **暴露状态**：Root 暴露 `value`、`mode`、`selectedCount`、`rangeComplete`、`month`、`weekCount`、`disabled`、`direction`；Day 暴露 `date`、`selected`、`rangeStart`、`rangeEnd`、`rangeMiddle`、`rangePending`、`today`、`outside`、`disabled`、`hidden`。
