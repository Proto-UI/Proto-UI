## 用法

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

### 部件结构

`Calendar` 由十个部件组成：`Root`、`Caption`、`Heading`、`Previous`、`Next`、`Grid`、`Weekdays`、`Weekday`、`Row` 与 `Day`。

- 在 `Weekdays` 中放置 `offset` 为 `0`–`6` 的七个 `Weekday`，再使用最多六个带 `index`（`0`–`5`）的 `Row` 与 `offset` `0`–`41` 的 `Day` 组成日历网格。
- 默认只显示覆盖当月所需的 4、5 或 6 周；设置 `fixedWeeks={true}` 可固定显示六周。多余的行和日期格会自动隐藏并移出焦点路径，可通过 `Root` 的 `weekCount` 读取当前周数。
- 星期标签与日期排列随 `weekStartsOn`（`0` 为周日）与 `locale` 同步；日期格自动使用完整的本地化日期作为无障碍名称。
- `Previous` 与 `Next` 支持 `a11yLabel`，为纯图标导航按钮提供无障碍名称。`direction="rtl"` 会自动镜像左右方向键。

### 选择模式

| 模式       | 受控值 / 初始值                               | 变更事件                     |
| ---------- | --------------------------------------------- | ---------------------------- |
| `single`   | `value` / `defaultValue`：`YYYY-MM-DD` 字符串 | `onValueChange({ value })`   |
| `multiple` | `values` / `defaultValues`：日期数组          | `onValuesChange({ values })` |
| `range`    | `range` / `defaultRange`：`{ from?, to? }`    | `onRangeChange({ range })`   |

- **多选模式**：每次点击或按键激活日期都会切换选中状态，数组会自动去重并按日期升序排列。通过 `minSelected`（默认 `0`）与 `maxSelected` 限制可选数量；调用 `requestValues(dates)` 整组替换时会同时校验上下限。
- **范围模式**：首次选择确定起点 `{ from }`，第二次选择完成包含两端的 `{ from, to }`（反向选择会自动按先后排序），再次选择则开启新范围；传入 `{}` 可清空范围。`minNights`（默认 `0`，允许同日起止）与 `maxNights` 用于限制起止日期之间的天数间隔。
- **范围样式状态**：`Day` 在 `selected` 之外还会暴露 `rangeStart`、`rangeEnd`、`rangeMiddle` 与 `rangePending`，方便区分端点、中段和待完成起点。多选与范围模式下，`Grid` 会自动设置 `aria-multiselectable`。

### 可用日期与当前日期（`today`）

- `min`、`max` 与 `Root` 的 `unavailable` 会作用于所有选中日期；范围选择跨过不可用日期时会被拒绝并保留原有起点。单个日期格的 `disabled` 仅禁用该单元格；`Root` 的 `readOnly` 禁止修改选择但允许继续翻月浏览。
- 组件不直接读取系统时钟或时区：如需高亮“今天”（并设置 `aria-current="date"`），请由宿主传入 `YYYY-MM-DD` 格式的 `today` 字符串。
- 初始显示月份优先级为：`month` → `defaultMonth` → 当前模式下的已选日期 → `today` → `1970-01`。

### 受控月份与年月选择器

- `value` / `values` / `range`（选中状态）与 `month`（当前展示月份，格式 `YYYY-MM`）可分别独立受控。
- `Root` 暴露 `requestValue(date)`、`requestValues(dates)`、`requestRange(range)`、`requestMonth(month)`、`getValues()`、`getRange()`，以及 `mode`、`selectedCount`、`rangeComplete` 等只读状态。
- 如需在 `Caption` 中提供月份和年份下拉选择，可通过 `bindCalendarCaption(source, { month, year })` 将组件库自带的 `Select` 绑定到 `Calendar` 的 `month` 状态与 `requestMonth` 方法（退出时调用 `dispose()` 清理）。`Select` 的触发器通过 `accessibleLabel` 保持稳定的无障碍名称。
- Shadcn Rhea 风格采用 `h-8 w-8`（32px）日期与导航按钮和 `p-3` 内边距，聚焦环独立于选中状态显示。

## API

传入 `value`、`values`、`range` 或 `month` 即可分别控制对应状态。省略 `today` 时不显示“今天”标记。
