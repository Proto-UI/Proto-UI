Meter 用于在已知上下界的范围内展示测量值（如磁盘占用、配额余量或强度评分），并可根据阈值区间自动划分状态。本页示例使用 **Shadcn Rhea** 风格。

## 用法

在完成包入口注册后，可从 `meter` 子路径导入 `meterRoot`、`meterLabel`、`meterTrack`、`meterIndicator` 和 `meterValue`：

- `Root` 统一管理有界数值范围与状态计算。
- `Label` 为仪表提供可读名称。
- `Track` 与 `Indicator` 展示测量值在区间内的占比。
- `Value` 显示 `valueText`，未设置时显示规范化后的数值。

### 数值与阈值分段

- `value` 会自动限制在 `[min, max]` 合法范围内；当 `min` 等于 `max` 时，百分比为 `0`。
- `low`、`high` 和 `optimum` 用于将测量值划分为 `optimal`、`suboptimal` 或 `critical` 状态，不改变数值本身。
- Meter 为只读展示组件，不会引入额外的键盘焦点停靠点。`Root` 及各部件会随属性更新同步暴露 `value`、`percentage`、`indeterminate` 和 `status`。
