Meter 用于在已知上下界的范围内展示测量值（如磁盘占用、配额余量或电量评分），并根据阈值区间自动划分状态。本页示例默认采用 **Shadcn Rhea** 风格。

## 用法

```tsx
import { AdaptToReact } from '@proto.ui/adapter-react';
import {
  meterRoot,
  meterLabel,
  meterTrack,
  meterIndicator,
  meterValue,
} from '@proto.ui/prototypes-shadcn/meter';

const MeterRoot = AdaptToReact(meterRoot);
const MeterLabel = AdaptToReact(meterLabel);
const MeterTrack = AdaptToReact(meterTrack);
const MeterIndicator = AdaptToReact(meterIndicator);
const MeterValue = AdaptToReact(meterValue);

export function StorageMeter() {
  return (
    <MeterRoot value={32} min={0} max={100} low={50} high={80} optimum={20} valueText="32%">
      <div className="flex items-center justify-between gap-2">
        <MeterLabel>Storage used</MeterLabel>
        <MeterValue />
      </div>
      <MeterTrack>
        <MeterIndicator />
      </MeterTrack>
    </MeterRoot>
  );
}
```

### 部件组成

- **Root**：管理有限范围 `[min, max]`、当前值 `value` 与阈值计算。数值越界时自动钳制在 `[min, max]`；当 `min === max` 时百分比为 `0`。
- **Label**：通过 `aria-labelledby` 为仪表提供可读名称；未渲染 `Label` 时可通过 `ariaLabel` 命名。
- **Track / Indicator**：根据 `--pui-percentage` 呈现测量占比，并按 `status` 区分 `optimal`、`suboptimal` 与 `critical` 视觉填充。
- **Value**：优先显示 `valueText`，未设置时回退到规范化后的数值字符串。

### 阈值分段与无障碍

- `low`、`high` 和 `optimum` 将测量值划分为 `optimal`、`suboptimal` 或 `critical` 状态，不改变数值本身。当「越低越好」（如磁盘占用）时将 `optimum` 设在 `low` 以下；当「越高越好」（如电量）时将 `optimum` 设在 `high` 以上。
- Meter 为只读展示组件（`role="meter"`），不会引入额外的键盘焦点停靠点。`Root` 及各子部件会随属性更新同步暴露 `value`、`percentage`、`indeterminate` 和 `status`。

### 风格预设（`styleProfile`）

支持的预设包括 `vega`、`nova`、`maia`、`lyra`、`mira`、`luma`、`sera`、`rhea` 与 `new-york-v4`（`new-york` 作为兼容别名）。省略或设为 `inherit` 时优先继承最近的 [Style Scope](../style-scope/)（本页示例通过 Style Scope 设为 `rhea`），独立使用时回退到 `luma`。
