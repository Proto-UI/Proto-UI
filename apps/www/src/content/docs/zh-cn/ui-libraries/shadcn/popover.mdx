## 用法

Popover 由 `Root`、`Trigger`、`Content`、`Title`、`Description` 和 `Close` 组成：

- `Content` 相对 `Trigger` 定位，支持通过 `side`、`align`、`sideOffset`、`alignOffset` 和 `collisionPadding` 调整位置与防碰撞边距。
- 非模态设计不会锁定背景滚动或限制 `Tab` 键移动。
- 点击外部区域、焦点移出 `Trigger` 与 `Content`、按下 `Escape` 或触发 `Close` 都会请求关闭。焦点在 `Trigger` 与 Portal 中的 `Content` 之间切换仍视为内部操作；因焦点移出外部控件而关闭时，焦点保留在目标外部控件上。

### 受控与非受控

- `Root` 支持通过 `open` 受控或通过 `defaultOpen` 非受控管理展开状态。
- 传入 `open` 时，请监听 `openChange` 事件并在回调中更新状态。若拒绝 `focus.outside` 关闭请求，`Content` 会保持显示且不影响外部焦点。纯焦点移出触发的关闭请求中，`focusReason` 为 `'programmatic'`。

### 导航呈现

将 `Trigger` 和 `Content` 的 `presentation` 设为 `'navigation'`，可展示适配锚点可用空间并支持内部滚动的导航面板，内部链接保持浏览器原生交互语义：

## API

传入 `open` 可进入受控模式。`Root` 暴露 `open`、`openPopover`、`close`、`toggle` 和 `openChange`：

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'open', type: 'boolean | undefined', default: '非受控' },
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'a11yLabel', type: 'string', default: "''" },
    { name: 'side', type: "'top' | 'right' | 'bottom' | 'left'", default: 'bottom' },
    { name: 'align', type: "'start' | 'center' | 'end'", default: 'center' },
    { name: 'sideOffset', type: 'number', default: '4' },
    { name: 'alignOffset', type: 'number', default: '0' },
    { name: 'collisionPadding', type: 'number', default: '8' },
    { name: 'presentation', type: "'default' | 'navigation'", default: 'default' },
  ]}
/>

属性归属说明：

- `open`、`defaultOpen`、`disabled`、`a11yLabel` 属于 `Root`。
- `side`、`align`、`sideOffset`、`alignOffset`、`collisionPadding` 属于 `Content`。
- `presentation` 属于 `Trigger` 和 `Content`。
