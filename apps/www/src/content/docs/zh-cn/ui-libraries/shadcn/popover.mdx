## 安装

Popover 目前在工作区源码中提供，将于 `0.3.0-rc.1` 及后续版本中提供 CLI。可直接从 `@proto.ui/prototypes-shadcn/popover` 导入并使用对应框架适配器（Web Components、React、Vue 3 或 Vue 2）：

```ts
import {
  popoverRoot,
  popoverTrigger,
  popoverContent,
  popoverTitle,
  popoverDescription,
  popoverClose,
} from '@proto.ui/prototypes-shadcn/popover';
```

## 用法

```tsx
<Popover styleProfile="rhea">
  <PopoverTrigger>Open Popover</PopoverTrigger>
  <PopoverContent align="start">
    <PopoverTitle>Dimensions</PopoverTitle>
    <PopoverDescription>Set the dimensions for the layer.</PopoverDescription>
  </PopoverContent>
</Popover>
```

### 组件结构

```text
PopoverRoot
├── PopoverTrigger
└── PopoverContent
    ├── PopoverTitle
    ├── PopoverDescription
    └── PopoverClose
```

- **定位与防碰撞**：`Content` 相对 `Trigger` 自动定位，支持 `side`、`align`、`sideOffset`、`alignOffset` 与 `collisionPadding`。
- **非模态交互与焦点**：打开时不会锁定页面滚动或限制 `Tab` 键导航。点击外部区域、按下 `Escape`、激活 `Close` 或焦点移出 `Trigger` 与 `Content` 时均会请求关闭；因焦点移出到外部控件而关闭时，焦点保留在目标外部控件上。
- **风格预设**：支持 `vega`、`nova`、`maia`、`lyra`、`mira`、`luma`、`sera`、`rhea` 与 `new-york-v4`；可通过最近祖先 `shadcn-style-scope` 继承，也可在各部件上传入 `styleProfile` 单独指定。
