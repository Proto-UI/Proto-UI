## 用法

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

### 结构与数据模型

- 传入 `rows` 时，每条记录需要具备唯一的 `id`。表格按当前页索引渲染行槽位，单元格通过 `columnKey` 读取对应字段，排序会直接更新真实数据内容。
- 表头排序单元格请放在静态 `DataTableHeaderRow` 中，正文数据行使用 `DataTableRow`。

### 筛选、列显隐与分页选择

- **筛选**：`columnFilters` 中的每个非空条件会与 `Root` 的全局 `filter` 共同过滤数据，随后再执行排序与分页。
- **列显隐**：通过 `columnVisibility` 可隐藏指定列的表头与单元格（同时移出排序焦点与辅助技术树）；重新开启后原有节点与自定义内容会恢复显示。
- **行与整页选择**：调用 `requestPageSelection()` 仅勾选或清空当前筛选页的数据，同时保留其他页的选中状态；可通过 `pageSelection` 读取 `'none'`、`'some'` 或 `'all'`。`readOnly={true}` 会阻止行选择和整页选择，但仍允许排序与翻页。
- **自定义单元格渲染**：在 `Cell` 上设置 `renderValue={false}` 可保留传入的子元素，并通过订阅 `displayValue` 动态格式化当前记录的展示文本。

## API

传入 `sortKey`、`sortDirection`、`page` 或 `selectedKeys` 可分别控制对应状态。

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'rows', type: 'readonly DataRecord[]', default: '[]' },
    { name: 'defaultSortKey', type: 'string', default: "''" },
    { name: 'defaultSortDirection', type: "'none' | 'ascending' | 'descending'", default: 'none' },
    { name: 'filter', type: 'string', default: "''" },
    { name: 'columnFilters', type: 'Readonly<Record<string, string>>', default: '{}' },
    { name: 'columnVisibility', type: 'Readonly<Record<string, boolean>>', default: '{}' },
    { name: 'defaultPage', type: 'number', default: '0' },
    { name: 'pageSize', type: 'number', default: '10' },
    { name: 'defaultSelectedKeys', type: 'readonly string[]', default: '[]' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'readOnly', type: 'boolean', default: 'false' },
  ]}
/>

以上属性属于 `Root`。其他部件属性：

- **Row**：`index` 默认 `0`，`header` 默认 `false`。
- **Cell**：`columnKey` 默认 `''`，`renderValue` 默认 `true`。
- **Header**：`sortable` 默认 `true`。
- **Previous / Next**：接受与 `Button` 相同的属性。
