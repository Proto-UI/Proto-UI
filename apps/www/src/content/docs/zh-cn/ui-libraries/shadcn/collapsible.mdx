## 安装

此组件由工作区源码提供。请在应用中安装同一工作区提交构建的 CLI、Shadcn 原型包与目标适配器，用该 CLI 初始化项目，再运行本地命令生成组件封装。

<InstallCommandCard command="npm exec -- proto-ui add wc shadcn-collapsible" manager="npm" />

把 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的本地组件封装。

也可以直接从 `@proto.ui/prototypes-shadcn/collapsible` 导入部件：

```ts
import {
  collapsibleRoot,
  collapsibleTrigger,
  collapsibleContent,
} from '@proto.ui/prototypes-shadcn/collapsible';
```

## 用法

### 部件结构

每个 `Root` 内组合一个 `Trigger` 与一个 `Content`（嵌套或相邻的 `Root` 各自拥有独立状态）：

- **Root**：统一管理展开状态，支持 `open`、`defaultOpen` 与 `disabled`，并暴露 `open` 状态、`openCollapsible` / `close` / `toggle` 方法以及 `openChange` 事件（负载为 `{ open, reason }`）。
- **Trigger**：支持独立的 `disabled` 属性，自动关联展开状态、按钮无障碍语义、自然 `Tab` 顺序、`Enter` / `Space` 激活与 `focusSelf`。
- **Content**：关闭时默认卸载内容节点；设置 `keepMounted={true}` 可保留隐藏节点。

### 受控与禁用行为

- 传入 `open` 进入受控模式：用户点击或按键只触发 `openChange` 事件，直到外部将新的 `open` 传回 `Root` 才切换显示状态。
- 设置 `disabled={true}` 会阻止后续切换操作，但不会强制关闭已经展开的内容。
- 样式内置容器收缩与长词换行支持，内容高度随实际内容自适应。如果需要多项联动或方向键切换标题，请使用 [Accordion](../accordion/)。底层共享行为说明见 [Base Collapsible](/zh-cn/ui-libraries/base/collapsible/)。

## API

传入 `open` 进入受控模式。

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}

以上属性属于 `Root`。`Trigger` 的 `disabled` 默认为 `false`；`Content` 的 `keepMounted` 默认为 `false`。
