## 安装

此组件由工作区源码提供。请在应用中安装同一工作区提交构建的 CLI、Shadcn 原型包与目标适配器，用该 CLI 初始化项目，再运行本地命令生成组件封装。

<InstallCommandCard command="npm exec -- proto-ui add wc shadcn-collapsible" manager="npm" />

把 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的本地组件封装。

也可以直接从 `@proto.ui/prototypes-shadcn/collapsible` 导入部件：

```ts
import {
  collapsibleRoot,
  collapsibleTrigger,
  collapsibleContent,
} from '@proto.ui/prototypes-shadcn/collapsible';
```

## 用法

```tsx
import {
  ShadcnCollapsibleRoot,
  ShadcnCollapsibleTrigger,
  ShadcnCollapsibleContent,
} from '@/components/ui/collapsible';

export function Example() {
  return (
    <ShadcnCollapsibleRoot>
      <ShadcnCollapsibleTrigger>Can I use this in my project?</ShadcnCollapsibleTrigger>
      <ShadcnCollapsibleContent>
        Yes. Free to use for personal and commercial projects.
      </ShadcnCollapsibleContent>
    </ShadcnCollapsibleRoot>
  );
}
```

### 部件结构

```text
CollapsibleRoot
├── CollapsibleTrigger
└── CollapsibleContent
```

每个 `Root` 内组合一个 `Trigger` 与一个 `Content`，嵌套或相邻的 `Root` 各自拥有独立状态：

- **Root**：管理展开状态，支持 `open`、`defaultOpen`、`disabled` 与 `styleProfile`，并暴露 `open` 状态、`openCollapsible()` / `close()` / `toggle()` 方法及 `openChange` 事件（载荷 `{ open, reason }`）。
- **Trigger**：按钮触发器，支持 `disabled`、`variant`（`default` / `ghost` / `outline` / `plain`）与 `size`（`default` / `sm` / `icon`），内置自然 `Tab` 顺序、`Enter` / `Space` 激活、展开态表面反馈与 `focusSelf()`。
- **Content**：内容面板，关闭时默认卸载内容节点（设置 `keepMounted={true}` 可保留隐藏节点），支持 `variant="plain"` 用于卡片、设置面板或文件树等自由组合场景。

### 受控状态

传入 `open` 并监听 `openChange` 即可由外部接管展开状态；设置 `disabled={true}` 会阻止后续切换，但不会强制收起已展开的内容。

```tsx
import { useState } from 'react';

export function ControlledExample() {
  const [open, setOpen] = useState(false);

  return (
    <ShadcnCollapsibleRoot open={open} onOpenChange={(req) => setOpen(req.open)}>
      <ShadcnCollapsibleTrigger>Toggle details</ShadcnCollapsibleTrigger>
      <ShadcnCollapsibleContent>Panel content</ShadcnCollapsibleContent>
    </ShadcnCollapsibleRoot>
  );
}
```

如果需要多项联动或方向键切换标题，请使用 [Accordion](../accordion/)。底层共享行为说明见 [Base Collapsible](/zh-cn/ui-libraries/base/collapsible/)。

### 事件与方法

- **Root 事件**：`openChange`（载荷 `{ open: boolean, reason: 'pointer' | 'keyboard' | 'programmatic' }`）
- **Root 方法**：`openCollapsible(reason?)`、`close(reason?)`、`toggle(reason?)`
- **Trigger 方法**：`focusSelf(options?)`
