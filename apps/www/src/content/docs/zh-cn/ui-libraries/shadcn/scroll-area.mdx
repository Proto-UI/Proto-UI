## 安装

<InstallCommandCard command="npx @proto.ui/cli@latest add wc shadcn-scroll-area" manager="npm" />

将命令中的 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的组件封装。

## 用法

从 `@proto.ui/prototypes-shadcn/scroll-area` 导入该组件家族，包含四个部件：`Root`、`Viewport`、`Scrollbar` 和 `Thumb`：

- `Root` 提供外层裁切容器。
- `Viewport` 承载实际可滚动内容，支持通过 `Tab` 聚焦并展示焦点环。
- `Scrollbar` 提供纵向或横向轨道，通过 `orientation` 指定方向。
- `Thumb` 在轨道内反映滚动位置并支持拖动滚动；它是纯视觉控制元素，不进入 `Tab` 焦点序列，在高对比度（forced colors）模式下仍保持可见轮廓。

### 滚动条表现

- `Viewport` 会优先使用自定义滚动条；在不支持自定义滚动条的宿主中，会自动回退到系统原生滚动条。
- 在 Web 端同时存在纵向和横向滚动条时，两条轨道会自动避让右下角交汇处并保持该区域透明，无需额外放置角块组件；当另一条轨道未挂载或隐藏时，避让空间自动释放。
- 内容未溢出时，`Thumb` 自动隐藏。
