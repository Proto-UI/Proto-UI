Root.value 标识一个打开的面板；Trigger.value 与 Content.value 配对。菜单栏提供单一 Tab 入口、左右移动、上下箭头进入、命令纵向导航及文字跳转。Escape 恢复触发器焦点；外部点击与命令选择关闭。受控 value 只发出请求。

组成: Root, Trigger, Content, Item.

草稿源码。嵌套子菜单、完整 native/GPUI/编译器证据、消费/视觉验收与独立生命周期准入仍未完成。


## Source-bound appearance / 固定来源呈现

The demo explicitly selects `styleProfile="rhea"`. Root and the existing Trigger/Content/Item consume the shared Shadcn style scope; `new-york-v4` (alias `new-york`) remains separate. Only these two profiles are admitted by this bounded slice; others fail closed. Style changes retain the Base value, events and logical parts.

New York: [02cad611 menubar.tsx](https://github.com/shadcn-ui/ui/blob/02cad61166c4c20edbc8a3f71bd720eed4c1f49b/apps/v4/registry/new-york-v4/ui/menubar.tsx). Rhea: [3d98900 radix wrapper](https://github.com/shadcn-ui/ui/blob/3d98900e9b73c45f035f8109e9d41ba6a51685e7/apps/v4/registry/bases/radix/ui/menubar.tsx) and [style-rhea.css](https://github.com/shadcn-ui/ui/blob/3d98900e9b73c45f035f8109e9d41ba6a51685e7/apps/v4/registry/styles/style-rhea.css#L933-L986). These are distinct source identities, not a universal latest-style claim.

Existing Base expanded/focused/disabled facts drive paint. This does **not** complete Menubar: Rhea hover still needs a neutral Base fact; inset/destructive, group/checkbox/radio/submenu parts, exact alignment policy, translucent content and placement/presence motion remain tracked in #907. Four-Web native input, AT, narrow/font-scaled geometry and independent exact-head evidence are still required. No DOM selector or page-only behavior substitutes for those missing capabilities.

Rhea 在菜单关闭时仍保留既有键盘焦点环，并投射强制色模式轮廓。精确上游 focus/hover 与 `outline-hidden` 映射仍待闭环；展开背景不能替代焦点提示。
