## 用法

```tsx
import {
  ShadcnMenubarRoot,
  ShadcnMenubarTrigger,
  ShadcnMenubarContent,
  ShadcnMenubarItem,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <ShadcnMenubarRoot styleProfile="rhea" a11yLabel="Project commands">
      <ShadcnMenubarTrigger value="file">File</ShadcnMenubarTrigger>
      <ShadcnMenubarContent value="file" a11yLabel="File commands">
        <ShadcnMenubarItem value="new">New Tab</ShadcnMenubarItem>
        <ShadcnMenubarItem value="open">New Window</ShadcnMenubarItem>
        <ShadcnMenubarItem value="delete" variant="destructive">
          Delete
        </ShadcnMenubarItem>
      </ShadcnMenubarContent>
    </ShadcnMenubarRoot>
  );
}
```

### 组件结构

```text
MenubarRoot
├── MenubarTrigger (value="file")
├── MenubarContent (value="file")
│   ├── MenubarItem
│   └── MenubarItem
├── MenubarTrigger (value="edit")
└── MenubarContent (value="edit")
    └── MenubarItem
```

- `Root` 统一管理当前展开的面板标识（`value`）及所有触发器的游走焦点。
- `Trigger` 与 `Content` 通过相同的 `value` 一一配对。
- `Item` 表示面板内的可执行命令，支持 `inset` 缩进对齐、`variant="destructive"` 危险语义及 `closeOnSelect={false}` 保持面板展开。

### 受控与非受控

传入 `value` 并监听 `valueChange` 进入受控模式；使用 `defaultValue` 则进入非受控模式。

### 键盘与无障碍

- 整条菜单栏提供一个游走 `Tab` 焦点入口，按 `ArrowLeft` / `ArrowRight` 在触发器之间移动。
- 按 `ArrowDown` 或 `ArrowUp` 打开面板并在命令项之间纵向移动，支持输入字符快速跳转（typeahead）。
- 按 `Escape` 关闭当前面板并将焦点交回对应 `Trigger`；点击外部区域或激活命令项后默认关闭面板。
