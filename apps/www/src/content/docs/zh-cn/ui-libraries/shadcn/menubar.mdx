## 用法

Menubar 由 `Root`、`Trigger`、`Content` 和 `Item` 四个部分组成：

- `Root` 统一管理当前打开的面板标识（`value`）。
- `Trigger` 与 `Content` 通过相同的 `value` 配对。
- `Item` 表示面板中的可执行命令，支持 `inset` 缩进布局和 `variant="destructive"` 危险样式。

### 受控与非受控

传入 `value` 进入受控模式，状态更新由外部监听请求后决定；使用 `defaultValue` 则进入非受控模式。

### 键盘与无障碍

- 菜单栏提供单一 `Tab` 焦点入口，使用左右方向键在触发器之间移动。
- 按下 `ArrowDown` 或 `ArrowUp` 打开面板并进入纵向命令导航，支持输入字符快速跳转（typeahead）。
- 按 `Escape` 关闭当前面板并将焦点返回对应触发器；点击外部区域或选择命令后自动关闭。

### 视觉预设

可通过 `styleProfile` 切换风格预设，支持 `rhea`、`new-york-v4`（别名 `new-york`）、`vega`、`nova`、`maia`、`lyra`、`mira`、`luma` 和 `sera`。未识别的预设值会被忽略并保持当前状态，切换风格不会影响组件的值、事件和交互行为。

其他部件的默认属性：

- `Trigger`：`disabled` 默认 `false`。
- `Content`：`sideOffset` 默认 `4`。
- `Item`：`closeOnSelect` 默认 `true`。
