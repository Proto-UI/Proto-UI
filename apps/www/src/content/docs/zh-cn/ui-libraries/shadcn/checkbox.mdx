支持未选、已选与半选（`indeterminate`）三种状态的复选框组件，支持指针点击与 `Space` 键切换，并完整保留受控/非受控与无障碍 `checkbox` 语义。本页示例采用 **Shadcn Rhea** 风格。

## 用法

### 部件结构

`Checkbox` 由 `Root` 与 `Indicator` 组成：

- **Root**：管理 `checked`、`indeterminate`、`disabled`、`readOnly`、`required` 与焦点交互。
- **Indicator**：自动从最近的 `Root` 读取状态并绘制对勾或横线；当 `indeterminate` 与 `checked` 同时为 `true` 时，优先显示横线（`mixed`）。

### 只读与表单集成

- `readOnly={true}` 保留键盘聚焦能力但阻止修改值；`disabled={true}` 同时移出焦点顺序。
- 单独的 `Checkbox` 不会自动注册到表单。如需在表单中使用，请在 `FormField` 内组合 `@proto.ui/prototypes-shadcn/field` 导出的 `fieldCheckbox`，以接入必填校验、标签/错误关联与重置行为（完整示例见 [Form 选择控件示例](../form/)）。调用 `resetValue()` 会请求恢复初始值，受控模式下仍由外部状态决定是否采纳。
- 复选框的名称通过组合外部标签（如 [Label](../label/)）或文本内容提供。

## API

传入 `checked` 或 `indeterminate` 会使对应状态进入受控模式，二者可独立选择受控或非受控。

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'checked', type: 'boolean | undefined', default: '非受控' },
    { name: 'defaultChecked', type: 'boolean', default: 'false' },
    { name: 'indeterminate', type: 'boolean | undefined', default: '非受控' },
    { name: 'defaultIndeterminate', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'readOnly', type: 'boolean', default: 'false' },
    { name: 'required', type: 'boolean', default: 'false' },
  ]}
/>

`Root` 暴露 `checked`、`indeterminate`、`disabled`、`required`、`hovered`、`focused`、`focusVisible`、`pressed` 状态，以及 `checkedChange` 与 `indeterminateChange` 事件。更新 `required` 仅同步必填状态，不会改变当前勾选值。
