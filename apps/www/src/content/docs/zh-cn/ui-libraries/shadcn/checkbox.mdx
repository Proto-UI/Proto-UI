支持未选、已选与半选（`indeterminate`）三种状态的复选框组件，支持指针点击与 `Space` 键切换，并完整保留受控/非受控与无障碍 `checkbox` 语义。本页示例采用 **Shadcn Rhea** 风格。

## 用法

```tsx
import {
  ShadcnCheckboxIndicator,
  ShadcnCheckboxRoot,
  ShadcnLabelRoot,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <div className="flex items-center gap-3">
      <ShadcnCheckboxRoot styleProfile="rhea" defaultChecked>
        <ShadcnCheckboxIndicator styleProfile="rhea" />
      </ShadcnCheckboxRoot>
      <ShadcnLabelRoot styleProfile="rhea">Accept terms and conditions</ShadcnLabelRoot>
    </div>
  );
}
```

### 部件结构与键盘交互

- **Root**：管理 `checked`、`indeterminate`、`disabled`、`readOnly`、`required` 与焦点状态，支持点击与 `Space` 键切换。
- **Indicator**：自动从最近的 `Root` 读取状态并绘制对勾或横线；当 `indeterminate` 与 `checked` 同时为 `true` 时，优先显示横线（`aria-checked="mixed"`）。
- **只读与表单集成**：`readOnly={true}` 保留键盘聚焦但阻止修改值；`disabled={true}` 同时移出焦点顺序。需要表单校验与错误提示时，请在 `FormField` / `Field` 中组合 `@proto.ui/prototypes-shadcn/field` 导出的 `fieldCheckbox`（完整表单示例见 [Form](../form/)；多选分组见 [Checkbox Group](../checkbox-group/)）。
- **标签关联**：通过 [Label](../label/) 或 `shadcnCheckboxLabelComposition` 将可见标签与复选框关联，使点击标签文本也可切换状态。

## API

传入 `checked` 或 `indeterminate` 会使对应状态进入受控模式，二者可独立选择受控或非受控。

### Root

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'checked', type: 'boolean | undefined', default: '非受控' },
    { name: 'defaultChecked', type: 'boolean', default: 'false' },
    { name: 'indeterminate', type: 'boolean | undefined', default: '非受控' },
    { name: 'defaultIndeterminate', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'readOnly', type: 'boolean', default: 'false' },
    { name: 'required', type: 'boolean', default: 'false' },
    {
      name: 'styleProfile',
      type: "'inherit' | 'new-york-v4' | 'vega' | 'nova' | 'maia' | 'lyra' | 'mira' | 'luma' | 'sera' | 'rhea'",
      default: "'new-york-v4'",
    },
  ]}
/>

`Root` 暴露 `checked`、`indeterminate`、`disabled`、`readOnly`、`required`、`hovered`、`focused`、`focusVisible`、`pressed` 状态，`focusSelf(options?)` 与 `resetValue()` 方法，以及 `checkedChange`（载荷 `{ checked, indeterminate }`）与 `indeterminateChange`（载荷 `{ indeterminate }`）事件。

### Indicator

`Indicator` 不声明额外属性，自动订阅最近 `Root` 的状态，并暴露 `checked`、`indeterminate` 状态以及 `isChecked()`、`isIndeterminate()` 方法。
