## 安装

此组件由工作区源码提供。请在应用中安装同一工作区提交构建的 CLI、Shadcn 原型包与目标适配器，用该 CLI 初始化项目，再运行本地命令生成组件封装。

<InstallCommandCard command="npm exec -- proto-ui add wc shadcn-field" manager="npm" />

把 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的本地组件封装。

也可以直接从 `@proto.ui/prototypes-shadcn/field` 导入 `fieldRoot`、`fieldLabel`、`fieldControl`、`fieldDescription`、`fieldError` 与 `fieldValidity`。

## 用法

### 部件结构

每个 `Root` 内放置一个 `Control`，并按需组合 `Label`、`Description`、`Error` 以及一个或多个只读的 `Validity`（嵌套 `Root` 拥有独立作用域，重复的唯一角色会被忽略）：

- **Root**：统一管理字段校验状态（`invalid`、`pending`、`dirty`、`touched`、`filled`、`focused`）以及 `disabled`、`readOnly`、`required` 策略。
- **Control**：默认提供单行文本输入控件；若接入自定义值控件（如复选框、单选组等），可通过 `asFieldControl` 桥接上报字段值，并通过 `asControlLabel().target(..., FIELD_LABEL_PAIR)` 接入标签点击聚焦。
- **Label**：自动命名同字段下的 `Control`，点击时默认聚焦控件（可通过 `activation={false}` 关闭）。
- **Description**：自动关联 `aria-describedby` 的可选帮助文本。
- **Error**：仅在字段处于无效状态时通过 `aria-errormessage` 关联到控件；关闭时默认卸载内容节点（设置 `keepMounted` 可保留隐藏节点），自动维护 `aria-describedby` / `aria-errormessage` 关联并在卸载时清理。如需自动向屏幕阅读器播报错误，可搭配 [Live Region](../live-region/) 使用。
- **Validity**：只读状态展示部件，可通过 `getValidity()` 读取当前校验快照。

### 同步与异步校验

- **内置规则**：`required` 将 `null`、`false`、`''` 与 `[]` 视为空值（`0` 与空白字符视为有效）；`minLength` / `maxLength` 按 UTF-16 码元计数，非必填的空字符串会跳过长度检查。内置标记为 `valueMissing`、`tooShort`、`tooLong`，外部错误使用 `customError`。
- **触发时机**：`validationMode` 支持 `'onBlur'`（默认）、`'onChange'`（等待输入法组合结束后触发）与 `'manual'`。
- **异步校验**：设置 `externalValidation={true}` 后，内置规则通过时会发出 `validationRequest`（负载为 `{ requestId, value, reason }`）。应用层完成请求后调用 `resolveValidation(requestId, { invalid, errors })` 提交结果；若请求期间值发生变化、状态切换或调用了 `cancelValidation()` / `resetValidation()`，过期结果会被自动丢弃。
- **受控校验**：传入 `invalid` 与 `errors` 将校验结果交由外部状态控制，校验完成时通过 `validityChange` 提出更新建议。
- **与表单协作**：`resetValidation()` 仅清除校验状态与 `touched`，不重置控件值。若需要多字段提交、序列化与整表重置，请配合 [Form](../form/) 与 [Fieldset](../fieldset/) 使用。

### 其他部件属性

- **Control**：`value` / `defaultValue`、`disabled`、`readOnly`、`required`、`placeholder`、`name`、`autoComplete`、`inputMode`、`enterKeyHint`、`ariaLabel`（本地策略不能覆盖 `Root` 已启用的约束）。
- **Label**：`activation?: boolean`（默认 `true`，控制点击是否聚焦控件）。
- **Description**：无额外属性。
- **Error**：`message?: string`（显式本地化覆盖文案）、`keepMounted?: boolean`（默认 `false`）。
- **Validity**：无额外属性。

### 方法与事件（Root）

- **方法**：`validate(reason?)`、`resolveValidation(requestId, result)`、`cancelValidation()`、`resetValidation()`、`focusControl(options?)`、`getValidity()`。
- **事件**：`validityChange`（校验结果快照）、`validationRequest`（异步校验请求，负载 `{ requestId, value, reason }`）。
