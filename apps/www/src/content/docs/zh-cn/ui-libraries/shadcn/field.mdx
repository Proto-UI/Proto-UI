## 安装

此组件由工作区源码提供。请在应用中安装同一工作区提交构建的 CLI、Shadcn 原型包与目标适配器，用该 CLI 初始化项目，再运行本地命令生成组件封装。

<InstallCommandCard command="npm exec -- proto-ui add wc shadcn-field" manager="npm" />

把 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的本地组件封装。

也可以直接从 `@proto.ui/prototypes-shadcn/field` 导入 `fieldRoot`、`fieldLabel`、`fieldControl`、`fieldDescription`、`fieldError` 与 `fieldValidity`。

## 用法

```tsx
import {
  FieldRoot,
  FieldLabel,
  FieldControl,
  FieldDescription,
  FieldError,
} from '@/components/ui/shadcn-field';

export function ProfileField() {
  return (
    <FieldRoot required minLength={3}>
      <FieldLabel>Username</FieldLabel>
      <FieldControl placeholder="Max Leiter" />
      <FieldDescription>Choose a unique username for your account.</FieldDescription>
      <FieldError />
    </FieldRoot>
  );
}
```

### 部件结构

```text
FieldRoot
├── FieldLabel
├── FieldControl | FieldTextarea | FieldSelectTrigger | FieldSwitch | FieldCheckbox | FieldRadioGroup
├── FieldDescription
├── FieldError
└── FieldValidity (可选，可多个)
```

- **Root**：管理 `invalid`、`pending`、`dirty`、`touched`、`filled`、`focused` 状态以及 `disabled`、`readOnly`、`required`、`orientation` 与 `styleProfile`。嵌套 `Root` 保持独立作用域。
- **Control**：默认提供单行文本输入控件；也可直接使用同包导出的 `fieldTextarea`、`fieldSelectTrigger`、`fieldSwitch`、`fieldCheckbox`、`fieldRadioGroup`，或通过 Base 的 `asFieldControl` 接入自定义控件。
- **Label**：自动通过 `aria-labelledby` 命名同字段下的控件，点击时默认聚焦控件（可通过 `activation={false}` 关闭）。
- **Description / Error**：自动维护 `aria-describedby` 与（仅在 `invalid` 时）`aria-errormessage` 关联，并在卸载时清理。`Error` 默认在有效状态下卸载节点（设置 `keepMounted` 可保留隐藏节点）。
- **Validity**：只读状态观察部件，可通过 `getValidity()` 读取当前校验快照。

### 同步与异步校验

- **内置规则**：支持 `required`、`minLength` 与 `maxLength`（按 UTF-16 码元计数；非必填的空字符串跳过长度检查）。内置标记为 `valueMissing`、`tooShort`、`tooLong`，外部错误使用 `customError`。
- **触发时机**：`validationMode` 支持 `'onBlur'`（默认）、`'onChange'`（等待输入法组合结束）与 `'manual'`。
- **异步校验**：设置 `externalValidation={true}` 后，内置规则通过时会发出 `validationRequest`（负载 `{ requestId, value, reason }`），完成后调用 `resolveValidation(requestId, { invalid, errors })`；过期结果自动丢弃。
- **受控校验**：传入 `invalid` 与 `errors` 由外部管理校验状态，校验完成时通过 `validityChange` 发出更新建议。如需整组禁用或表单提交与重置，请配合 [Fieldset](../fieldset/) 与 [Form](../form/) 使用。

### 其他部件属性

- **Control**：`value` / `defaultValue`、`disabled`、`readOnly`、`required`、`placeholder`、`name`、`autoComplete`、`inputMode`、`enterKeyHint`、`ariaLabel`、`styleProfile`（本地策略不能覆盖 `Root` 已启用的约束）。
- **已绑定控件**：`fieldTextarea`、`fieldSelectTrigger`、`fieldSwitch`、`fieldCheckbox`、`fieldRadioGroup` 均复用对应组件属性并接入字段策略与无障碍关联。
- **Label**：`activation?: boolean`（默认 `true`，控制点击是否聚焦控件）、`styleProfile`。
- **Description / Validity**：`styleProfile`。
- **Error**：`message?: string`（显式本地化覆盖文案）、`keepMounted?: boolean`（默认 `false`）、`styleProfile`。

### 方法与事件（Root）

- **方法**：`validate(reason?)`、`resolveValidation(requestId, result)`、`cancelValidation()`、`resetValidation()`、`focusControl(options?)`、`getValidity()`。
- **事件**：`validityChange`（校验结果快照）、`validationRequest`（异步校验请求，负载 `{ requestId, value, reason }`）。
