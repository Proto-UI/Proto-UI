## 用法

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

### 部件结构

`Input OTP` 由 `Root`、`Input`（独立使用）或 `Control`（表单内使用）、`Slot` 与 `Separator` 组成：

- **Root**：管理 `value` / `defaultValue`、位数 `length`（`1`–`32`，默认 `6`）、字符集过滤（`numeric` 或 `alphanumeric`）、`disabled`、`readOnly`、`name` 与 `ariaLabel`。
- **Input / Control**：承载唯一的真实单行编辑器，在输入法组合结束后自动过滤非法字符并截断到 `length`。独立场景使用 `Input`；在 [Field](../field/) 或 [Form](../form/) 中使用 `Control` 替代 `Input`，以接入标签聚焦、表单校验、序列化与重置。
- **Slot / Separator**：`Slot` 按 `index` 展示对应字符且对辅助技术隐藏，不增加额外 `Tab` 顺序；当可编辑的输入框聚焦时，激活格严格跟随真实光标位置或选区范围（失焦、禁用或只读时不显示激活格）。

### 事件与校验行为

- 传入 `value` 进入受控模式时，输入修改会通过 `valueChange` 提出变更请求；每次接受完整位数的有效验证码时触发一次 `completed` 事件。
- 在表单中使用 `Control` 时，仅当值实际发生有效变化后才触发自动 `onChange` 校验；受控拒绝或过滤后无变化不会重复触发，重置、策略变更或卸载会自动取消排队中的校验。

## API

传入 `value` 进入受控模式。`Input` 可选接受 `placeholder`（无默认值）。
