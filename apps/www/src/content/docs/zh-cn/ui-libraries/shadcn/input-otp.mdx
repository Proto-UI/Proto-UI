用于输入一次性验证码（OTP）的分格输入框，底层使用单一真实文本输入控件以完整支持整段粘贴、删除、选区移动与 `one-time-code` 自动填充。本页示例采用 **Shadcn Rhea** 风格。

## 用法

```tsx
import {
  ShadcnInputOtpRoot,
  ShadcnInputOtpInput,
  ShadcnInputOtpSlot,
  ShadcnInputOtpSeparator,
} from '../proto-ui/components/react';

export function VerificationCode() {
  return (
    <ShadcnInputOtpRoot styleProfile="rhea" length={6}>
      <ShadcnInputOtpInput styleProfile="rhea" placeholder="123456" />
      <div className="inline-flex items-center">
        <ShadcnInputOtpSlot styleProfile="rhea" index={0} first />
        <ShadcnInputOtpSlot styleProfile="rhea" index={1} />
        <ShadcnInputOtpSlot styleProfile="rhea" index={2} last />
      </div>
      <ShadcnInputOtpSeparator styleProfile="rhea">–</ShadcnInputOtpSeparator>
      <div className="inline-flex items-center">
        <ShadcnInputOtpSlot styleProfile="rhea" index={3} first />
        <ShadcnInputOtpSlot styleProfile="rhea" index={4} />
        <ShadcnInputOtpSlot styleProfile="rhea" index={5} last />
      </div>
    </ShadcnInputOtpRoot>
  );
}
```

```text
InputOtpRoot
├── InputOtpInput (或表单内的 InputOtpControl)
├── InputOtpSlot (index 0..2)
├── InputOtpSeparator
└── InputOtpSlot (index 3..5)
```

### 部件与交互说明

- **Root**：管理 `value` / `defaultValue`、位数 `length`（`1`–`32`，默认 `6`）、字符过滤模式 `pattern`（`'numeric'` 或 `'alphanumeric'`）、`disabled`、`readOnly`、`invalid`、`name` 与 `ariaLabel`。
- **Input / Control**：承载唯一的真实单行编辑器，支持整段粘贴、选区编辑、IME 输入法合成过滤与 `one-time-code` 自动填充。独立场景使用 `Input`；在 [Field](../field/) 或 [Form](../form/) 中使用 `Control` 替代 `Input`，自动衔接标签聚焦、表单校验、序列化与重置。
- **Slot / Separator**：`Slot` 按 `index` 渲染对应字符并对辅助技术隐藏，不增加额外 `Tab` 焦点；输入框聚焦且可编辑时，激活格随真实光标或选区高亮。分段组合时可通过 `first` 与 `last` 控制各分组两端的圆角与左边框。
- **事件与校验**：输入变更会触发 `valueChange`；每次接受完整有效验证码时触发一次 `completed`。在表单内使用 `Control` 时，仅当值发生有效变化后触发自动变更校验。

### 事件与暴露方法

- **Root 事件**：`valueChange`（`{ value: string }`）、`completed`（`{ value: string }`）。
- **Root 暴露状态与方法**：状态 `value`、`complete`、`disabled`、`readOnly`、`focused`；方法 `requestValue(value)`、`clear()`、`resetValue()`、`focusInput()`。
- **Slot 暴露状态**：`character`、`active`、`filled`。
