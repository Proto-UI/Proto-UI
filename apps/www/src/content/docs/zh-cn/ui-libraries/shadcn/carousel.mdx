## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。

## 用法

```tsx
import {
  ShadcnCarouselRoot,
  ShadcnCarouselViewport,
  ShadcnCarouselSlide,
  ShadcnCarouselPrevious,
  ShadcnCarouselNext,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <ShadcnCarouselRoot styleProfile="rhea" className="mx-auto w-full max-w-xs">
      <ShadcnCarouselViewport>
        <ShadcnCarouselSlide>1</ShadcnCarouselSlide>
        <ShadcnCarouselSlide>2</ShadcnCarouselSlide>
        <ShadcnCarouselSlide>3</ShadcnCarouselSlide>
      </ShadcnCarouselViewport>
      <ShadcnCarouselPrevious aria-label="Previous slide">‹</ShadcnCarouselPrevious>
      <ShadcnCarouselNext aria-label="Next slide">›</ShadcnCarouselNext>
    </ShadcnCarouselRoot>
  );
}
```

### 组合结构

```text
CarouselRoot
├── CarouselViewport
│   ├── CarouselSlide
│   └── CarouselSlide
├── CarouselPrevious
└── CarouselNext
```

- **响应式视口与吸附**：`Root` 的 `slidesPerView` 控制同时展示的最大等尺寸项数（默认 `1`），`minSlideSize` 设置单项最小逻辑像素尺寸（默认 `0`）。容器变窄时自动减少实际可见数，且最后一个吸附位贴齐末端。
- **键盘与无障碍**：聚焦视口后支持 `ArrowLeft` / `ArrowRight`（纵向为 `ArrowUp` / `ArrowDown`）、`Home` 与 `End` 切换；纯图标翻页按钮请配合 `sr-only` 文案或 `aria-label` 提供可访问名称。
- **受控索引**：传入 `index` 进入受控模式并监听 `indexChange`；拖动过程中不提前改写已提交的 `index`，松手后按外部最新值落位或平滑回弹。

### 暴露状态、方法与事件

- **Root**：状态 `index`、`slideCount`、`visibleSlides`、`maxIndex`；方法 `requestIndex(next)`；事件 `indexChange`（载荷 `{ index }`）。
- **Viewport**：状态 `focusVisible`、`dragging`、`scrolling`、`scrollPosition`。
- **Slide**：状态 `current`、`hidden`、`basis`、`minSize`。
