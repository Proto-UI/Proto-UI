## 用法

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

### 响应式视口与吸附

- `Root` 的 `slidesPerView` 控制同时展示的最大等尺寸卡片数（默认 `1`），`minSlideSize` 设置每张卡片的最小逻辑像素尺寸（默认 `0`）。当容器变窄时会自动减少实际可见数量并允许边缘卡片部分露出。
- 鼠标或触摸拖动会即时跟随移动，松手或原生滚动停止后自动吸附到最近的可达卡片边界；最后一个吸附位置会贴齐内容末端，不留多余空白。
- 通过 `Root` 暴露的 `visibleSlides` 与 `maxIndex` 可读取当前视口实际容纳的项数与最大索引。

### 受控与非受控索引

- 传入 `index` 进入受控模式，交互时通过 `indexChange` 提出目标索引。拖动预览期间不会修改已提交的 `index`，松手后根据外部传入的新值更新或平滑回弹到原位置。
- `Viewport` 暴露 `dragging`、`scrolling` 与归一化 `scrollPosition`；每个 `Slide` 暴露 `current`（是否位于当前吸附位）与 `hidden`（是否完全在视口外，仍保留布局占位）。

### 方向与循环

- 设置 `orientation="vertical"` 时，请为视口容器指定明确的高度。
- 水平模式下设置 `direction="rtl"` 会反转物理拖动与左右方向键，同时保持逻辑顺序。
- 开启 `loop={true}` 后，在首尾两端继续切换会循环跳转索引（按索引循环，不克隆额外 DOM 节点）。
