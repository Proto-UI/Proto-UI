Switch 用于在开启与关闭两种状态之间切换，支持键盘操作、多种尺寸与风格预设、Field 选项卡片组合、RTL 方向镜像以及可选的指针拖动。本页示例使用 **Shadcn Rhea** 风格。

## 安装

以下命令使用 0.2.0 稳定版 CLI。Vue 2.6 需要使用版本匹配的预发布版或工作区 CLI、适配器和原型包。页面预览使用工作区版本。

<InstallCommandCard command="npx @proto.ui/cli@0.2.0 add wc shadcn-switch" manager="npm" />

将命令中的 `wc` 替换为 `react` 或 `vue`，即可生成对应框架的组件封装。

## 用法

```tsx
import { ShadcnSwitch } from '@/components/ui/switch';
```

```tsx
<ShadcnSwitch defaultChecked />
```

- **结构与状态**：`Root` 负责管理受控 `checked`、非受控 `defaultChecked`、键盘 `Space` 切换、焦点与禁用状态；`Thumb` 自动跟随所属 `Root` 的状态、尺寸、风格预设与方向，无需重复传参。
- **尺寸与预设**：通过 `size="sm"` 或 `size="default"` 切换尺寸，通过 `styleProfile`（或在父级使用 `StyleScope`）在 `rhea`、`nova`、`vega`、`maia`、`lyra`、`mira`、`luma`、`sera` 与 `new-york-v4` 之间切换外观。
- **自定义 Web Component 样式**：CLI 生成的组合组件 `ShadcnSwitchElement` 使用标签 `<proto-ui-shadcn-switch>` 并内置默认 `Thumb`，覆盖轨道样式时请以 `proto-ui-shadcn-switch` 为选择器；单独导出的原始 `Root` 使用标签 `<proto-ui-shadcn-switch-root>`。完整自定义尺寸示例可参考 [Web Component 样式指南](https://github.com/Proto-UI/Proto-UI/blob/main/packages/adapters/web-component/README.md#styling-the-composed-host)。

## API

以下属性与事件属于 `Root`（`shadcn-switch-root` / `shadcn-field-switch`；`Thumb` 无额外属性）：

<ApiPropsTable
  headers={{ name: '属性 / 事件', type: '类型', default: '默认值' }}
  rows={[
    { name: 'checked', type: 'boolean | undefined', default: '非受控' },
    { name: 'defaultChecked', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'draggable', type: 'boolean', default: 'false' },
    { name: 'direction', type: "'ltr' | 'rtl'", default: "'ltr'" },
    { name: 'size', type: "'default' | 'sm'", default: "'default'" },
    {
      name: 'styleProfile',
      type: "'inherit' | 'new-york-v4' | 'vega' | 'nova' | 'maia' | 'lyra' | 'mira' | 'luma' | 'sera' | 'rhea'",
      default: "'inherit'",
    },
    { name: 'checkedChange', type: 'event ({ checked: boolean })', default: '—' },
    { name: 'focusSelf', type: 'method (options?: FocusRequestOptions) => void', default: '—' },
  ]}
/>

当使用 `shadcn-field-switch` 搭配 `shadcn-field-root` 时，还可从所属 `Field` 继承 `invalid`、`readOnly`、`disabled` 与标签关联。
