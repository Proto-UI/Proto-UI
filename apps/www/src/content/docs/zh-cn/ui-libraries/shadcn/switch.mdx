当前页面展示 Proto UI 中 `shadcn` 风格的 `switch` 条目。

在 Root 上设置 `size="sm"` 使用小尺寸；省略 `size` 或设置 `size="default"` 使用默认尺寸。Thumb 从实际所属的逻辑 Switch Root 派生尺寸，没有独立 size prop。尺寸变化不会改变 checked 值或发出 `checkedChange`。

本页 Rhea 配方的默认Root为2rem × 1.25rem，小号为1.5rem × 1rem，Thumb分别为1rem/0.75rem，使用2px透明边框与家族`radius-2xl`；选中位移为Thumb宽减4px。来源为 [Rhea 样式源码](https://github.com/shadcn-ui/ui/blob/3d98900e9b73c45f035f8109e9d41ba6a51685e7/apps/v4/registry/styles/style-rhea.css)。独立 [02cad611 New York源码](https://github.com/shadcn-ui/ui/blob/02cad61166c4c20edbc8a3f71bd720eed4c1f49b/apps/v4/registry/new-york-v4/ui/switch.tsx) 仍保留2rem × 1.15rem / 1.5rem × 0.875rem与减2px位移，属于兼容profile；两者不混称跨宿主已视觉等价。

## 组合与可选拖动能力

默认 Switch 组合保持点击/Space 激活，拖动仅由 `draggable: true` 明确开启，不改上游默认。上方尺寸示例只有“Email alerts”启用拖动；下方两个独立增强示例分别展示 LTR 和 RTL 拖动。

下方真实页面组合复用现有 Field 的 Label、Description 和 Switch owner。Choice Card 的卡片空白区域可点击，但不创建第二个按钮或转发 click；卡内“Learn more”链接保持自己的操作。卡片选中色跟随已接受的 checked 值，受控 owner 拒绝请求时不乐观变色。disabled 和 readOnly 示例不得发出改值请求。

上游[Choice Card anatomy](https://github.com/shadcn-ui/ui/blob/96da9cc7f1aa10580a3741664e2a77c721206c00/apps/v4/examples/base/switch-choice-card.tsx)由 FieldLabel 包住 Field。Proto 保留自己的 Field anatomy 和独立 description 关联，不导入该框架，也不改变当前样式 profile。这不是 Liquid Glass Switch 的实现。

## 安装

<InstallCommandCard command="npx @proto.ui/cli@latest add wc shadcn-switch" manager="npm" />

把 `wc` 换成 `react`、`vue` 或 `vue2`，即可生成对应宿主的 facade。

## API

传入 `checked` 进入受控模式。

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'checked', type: 'boolean | undefined', default: '非受控' },
    { name: 'defaultChecked', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'draggable', type: 'boolean', default: 'false' },
    { name: 'direction', type: "'ltr' | 'rtl'", default: 'ltr' },
    { name: 'size', type: "'default' | 'sm'", default: 'default' },
  ]}
/>

`size` 是 Shadcn 的呈现属性。Thumb 没有属性。Root 仍是 checked 的唯一 owner。
