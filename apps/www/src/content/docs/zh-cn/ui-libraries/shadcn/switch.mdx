Switch 用于在开启与关闭两种状态之间切换，支持键盘操作、不同尺寸预设、选项卡片组合以及可选的指针拖动。本页示例使用 **Shadcn Rhea** 风格。

## 用法

### 尺寸与预设

- 在 `Root` 上设置 `size="sm"` 可切换为小号开关，省略或设置 `size="default"` 使用默认尺寸。`Thumb` 会自动跟随所属 `Root` 的尺寸，无需单独传参。
- 切换 `size` 仅更新视觉外观，不会改变 `checked` 值或触发 `checkedChange`。
- 在 **Shadcn Rhea** 预设中，默认尺寸为 `2rem × 1.25rem`（Thumb 为 `1rem`），小号为 `1.5rem × 1rem`（Thumb 为 `0.75rem`）；`new-york-v4` 预设则沿用 `2rem × 1.15rem` 与 `1.5rem × 0.875rem` 的尺寸比例。

### 组合模式与可选拖动

Switch 默认通过点击或按 `Space` 键切换；传入 `draggable={true}` 可按需开启滑块拖动。两种模式均可通过 `direction="rtl"` 镜像滑块位置与移动方向；方向缺省为 `ltr`，不随外层文档方向改变。下方示例展示了搭配 Field `Label`、`Description` 以及 Choice Card 的完整组合用法：卡片空白区域可直接点击切换，内部的“Learn more”链接保留自身跳转行为；受控模式下卡片高亮跟随已确认的 `checked` 状态，`disabled` 与 `readOnly` 状态不会发出变更请求。

### 自定义 Web Component 样式

- CLI 生成的组合组件 `ShadcnSwitchElement` 使用标签 `<proto-ui-shadcn-switch>` 并内置默认 `Thumb`，覆盖轨道样式时请以 `proto-ui-shadcn-switch` 为选择器。
- 单独导出的原始 `Root` 使用标签 `<proto-ui-shadcn-switch-root>`，其标签选择器不会命中上述组合元素。
- 自定义轨道尺寸、滑块尺寸和选中位移时请同步调整三者比例；完整示例可参考 [Web Component 样式指南](https://github.com/Proto-UI/Proto-UI/blob/main/packages/adapters/web-component/README.md#styling-the-composed-host)。使用内置预设时，只需在 `Root` 上设置 `styleProfile` 和 `size`，`Thumb` 会自动匹配。
