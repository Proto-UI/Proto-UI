用于组织关联内容的纯展示卡片容器，提供 `Root`、`Header`、`Content` 与 `Footer` 四个结构部件。本页示例采用 **Shadcn Rhea** 风格。

## 安装

<InstallCommandCard command="npx @proto.ui/cli@latest add wc shadcn-card" manager="npm" />

把 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的本地组件封装。

也可以直接从 `@proto.ui/prototypes-shadcn/card` 导入 `ShadcnCardRoot`、`ShadcnCardHeader`、`ShadcnCardContent`、`ShadcnCardFooter`（同时提供小写别名）。

<h2 id="card-contract">用法</h2>

- **结构与排版**：`Header`、`Content` 与 `Footer` 各自管理区域内边距与间距。标题和描述内容可直接使用原生标题/段落元素，或在嵌套 [Text](../text/) 时为标题与正文指定 `tone="inherit"`、为辅助说明指定 `tone="muted"`。
- **风格预设**：未显式指定风格时，`Root` 会继承最近的 [Style Scope](../style-scope/)；无外层作用域时默认使用 New York 风格（`rounded-xl`、边框、24px 间距与内边距、8px Header 间距）。在 **Shadcn Rhea** 风格下则使用无边框前景色 ring、20px 间距与内边距以及 6px Header 间距。
- **纯展示语义**：四个部件不附加交互角色、焦点或事件，卡片内部的链接和按钮保留各自的原生导航与点击行为。

## API

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'size', type: "'default' | 'sm'", default: 'default' },
    { name: 'divider', type: 'boolean', default: 'false' },
  ]}
/>

- `size` 作用于 `Root`，用于切换默认与紧凑间距。
- `divider` 作用于 `Header` 与 `Footer`，用于显示区域分隔线。
- `Content` 无额外属性；四个部件均不触发事件。
