## 安装

此组件由工作区源码提供。请在应用中安装同一工作区提交构建的 CLI、Shadcn 原型包与目标适配器，用该 CLI 初始化项目，再运行本地命令生成组件封装。

<InstallCommandCard
  manager="npm"
  commands={{
    pnpm: 'pnpm exec proto-ui add wc shadcn-card',
    npm: 'npm exec -- proto-ui add wc shadcn-card',
    yarn: 'yarn exec proto-ui add wc shadcn-card',
    bun: 'bun run proto-ui add wc shadcn-card',
  }}
/>

把 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的本地组件封装。也可以直接从 `@proto.ui/prototypes-shadcn/card` 导入 `ShadcnCardRoot`、`ShadcnCardHeader`、`ShadcnCardContent`、`ShadcnCardFooter`（同时提供小写别名）。

<h2 id="card-contract">用法</h2>

```tsx
import {
  ShadcnCardRoot,
  ShadcnCardHeader,
  ShadcnCardContent,
  ShadcnCardFooter,
} from '@proto.ui/prototypes-shadcn/card';
```

```tsx
<ShadcnCardRoot styleProfile="rhea">
  <ShadcnCardHeader>
    <h3 className="text-base font-medium">Card Title</h3>
    <p className="text-sm text-muted-foreground">Card Description</p>
  </ShadcnCardHeader>
  <ShadcnCardContent>
    <p className="text-sm">Card Content</p>
  </ShadcnCardContent>
  <ShadcnCardFooter>
    <p className="text-sm">Card Footer</p>
  </ShadcnCardFooter>
</ShadcnCardRoot>
```

结构组合方式：

```text
ShadcnCardRoot
├── ShadcnCardHeader
├── ShadcnCardContent
└── ShadcnCardFooter
```

- **结构与排版**：`Header`、`Content` 与 `Footer` 各自管理水平内边距与区域间距。标题和描述可直接使用原生标题/段落元素，或在嵌套 [Text](../text/) 时为标题使用 `size="base"`、`weight="medium"`、`tone="inherit"`，为辅助说明使用 `size="sm"`、`tone="muted"`。
- **风格预设**：未显式指定风格时，`Root` 会继承最近的 [Style Scope](../style-scope/)；无外层作用域时默认使用 `new-york-v4`（`rounded-xl`、边框、24px 间距与内边距、8px Header 间距）。在 **Shadcn Rhea** 风格下使用前景色 hairline ring、主题圆角上限 24px、20px 默认内边距与 16px `sm` 紧凑内边距；在 **Shadcn Luma** 风格下使用 `rounded-4xl` 大圆角、`shadow-md` 柔阴影、`ring-foreground/5`（暗色 `ring-foreground/10`）细腻轮廓与 24px 默认内边距（`sm` 为 16px）。
- **纯展示语义**：四个部件不附加交互角色、焦点或事件，卡片内部的链接、输入框与按钮保留各自的原生导航与交互行为。

## API

### ShadcnCardRoot

卡片外层容器，同时作为子树的风格与密度作用域边界。

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    {
      name: 'styleProfile',
      type: "'luma' | 'rhea' | 'new-york-v4' | 'new-york' | 'inherit'",
      default: "'inherit' → 最近 scope → 'new-york-v4'",
    },
    { name: 'size', type: "'default' | 'sm'", default: "'default'" },
  ]}
/>

### ShadcnCardHeader

卡片头部区域，默认使用两行自适应网格排版。

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}

  ]}
/>
