## 用法

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

### 部件结构

由 `Root`、`Input`、`Content`、`Item` 与 `Empty` 组合而成（内联展示，无 `Trigger`）：

- 列表默认保持展开（`defaultOpen={true}`），输入查询词只会过滤列表而不会自动执行命令。
- 点击或按 `Enter` 激活命令项时，组件触发携带选中项的 `execute` 事件，由应用层执行具体动作。

### 过滤与交互行为

- **内置过滤**：依据 `textValue` 与 `keywords` 过滤，忽略大小写及重音；设置 `filter={false}` 可由外部自行提供过滤后的子项。
- **空状态与禁用项**：`Empty` 根据实际匹配数量显隐；禁用项与重复 `value` 的项不可执行。
- **键盘与输入法**：方向键移动高亮项时焦点保持在单行输入框中，IME 组合输入期间不触发执行。
- **受控模式**：`open`、`value` 与 `inputValue` 各自独立支持受控。

## API

传入 `value`、`inputValue` 或 `open` 会使对应状态进入受控模式。由于命令列表默认内联展示，`defaultOpen` 默认为 `true`。

以上属性属于 `Root`。其他部件属性默认值：

- **Input**：`placeholder`、`a11yLabel`、`name` 均默认为 `''`。
- **Content**：`side="bottom"`、`align="start"`、`sideOffset={4}`、`collisionPadding={8}`。
- **Item**：`value`、`textValue`、`keywords` 均默认为 `''`，`disabled` 默认为 `false`。
