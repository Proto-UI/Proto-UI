支持实时搜索过滤和键盘导航的命令面板，点击或按下 `Enter` 即可发出 `execute` 事件由应用执行操作。本页示例采用 **Shadcn Rhea** 风格。

## 安装

当前仅在源码工作区 `@proto.ui/prototypes-shadcn/command` 提供，尚未进入 0.2.0 稳定版。

## 用法

```tsx
import {
  commandRoot,
  commandInputWrapper,
  commandInput,
  commandContent,
  commandItem,
  commandEmpty,
  commandDialogContent,
  commandDialogMask,
} from '@proto.ui/prototypes-shadcn/command';
import { inputShell } from '@proto.ui/prototypes-shadcn/input-shell';
```

### 部件组合结构

```text
CommandRoot
├── CommandInputWrapper
│   └── InputShell (focusIndicator="none")
│       └── CommandInput
└── CommandContent
    ├── CommandItem
    └── CommandEmpty
```

- **内联默认展开**：`defaultOpen` 默认为 `true`，输入文本只会过滤候选列表而不会自动执行命令；点击或按 `Enter` 时通过 `execute` 事件通知应用层。
- **弹窗组合**：可结合 `DialogRoot`、`DialogTrigger`、`CommandDialogMask` 与 `CommandDialogContent` 构成命令弹窗，按当前 `styleProfile` 传入对应 `enterDuration` / `leaveDuration`（Rhea 为 `100`，New York 为 `200`）。
- **过滤与键盘行为**：按 `textValue` 与 `keywords` 忽略大小写与重音匹配，设置 `filter={false}` 可接入外部过滤；方向键移动高亮项时焦点保留在输入框中，IME 组合输入期间不触发执行。

## API

### Root

传入 `value`、`inputValue` 或 `open` 可独立切换为受控模式；`styleProfile` 可通过外层 `shadcn-style-scope` 或部件属性指定 9 套内置风格。

### 其他部件与事件

- **InputWrapper**：输入区外层容器，支持 `styleProfile` 与 `presentation`（`'default' | 'menu'`）。
- **Input**：`placeholder`、`a11yLabel`、`name` 均默认为 `''`。
- **Content**：`side="bottom"`、`align="start"`、`sideOffset={4}`、`collisionPadding={8}`。
- **Item**：`value`、`textValue`、`keywords` 均默认为 `''`，`disabled` 默认为 `false`。
- **Empty**：无独立属性，根据可见匹配数量自动显隐。
- **DialogContent / DialogMask**：必填 `enterDuration: number` 与 `leaveDuration: number`；`DialogContent` 另支持 `styleProfile` 与 `presentation`。
- **事件**：`Root` 触发 `execute`、`valueChange`、`inputValueChange` 与 `openChange`。
