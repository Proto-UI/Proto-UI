Slider 允许用户通过拖动滑块或键盘步进在连续区间内选择单个数值或多个范围值。本页示例使用 **Shadcn Rhea** 风格。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可从 `@proto.ui/prototypes-shadcn/slider` 导入单值滑块与多值滑块 `sliderValues*` 部件。

## 用法

```tsx
import {
  ShadcnSliderRoot,
  ShadcnSliderTrack,
  ShadcnSliderIndicator,
  ShadcnSliderThumb,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <ShadcnSliderRoot defaultValue={33} min={0} max={100} step={1}>
      <ShadcnSliderTrack>
        <ShadcnSliderIndicator />
        <ShadcnSliderThumb />
      </ShadcnSliderTrack>
    </ShadcnSliderRoot>
  );
}
```

- **部件组成**：单值滑块包含 `Root`、`Label`、`Track`、`Indicator`、`Thumb`、`FieldThumb` 和 `Value`；多值滑块提供对应的六个 `sliderValues*` 入口。
- **指针与键盘交互**：`Track` 响应指针与触摸拖动；`Thumb` 支持方向键、`Shift` 十倍步进、`PageUp` / `PageDown` 与 `Home` / `End`（水平 RTL 模式下左右键自动反向）。
- **受控与提交**：传入 `value` 进入受控模式，交互过程中发出 `valueChange`，操作完成时触发 `valueCommit`；取消拖动时非受控滑块自动恢复起始值。
- **表单集成**：在 `Field` 或 `FormField` 内请使用 `FieldThumb` 替代 `Thumb`，自动衔接 `FieldLabel` 聚焦、数值校验、序列化与重置；多值 `Values Root` 可直接作为组合控件汇报 `number[]`。
