Root 管理 value/defaultValue、min/max/step、disabled/readOnly、方向。Track 通过共享 AxisInput 接入真实指针/触摸拖动；Thumb 支持箭头、Shift 十倍、PageUp/PageDown、Home/End，水平 RTL 反向。数值从 min 对齐步长并限制边界；受控请求不覆盖作者值，valueCommit 标记完成，取消恢复非受控拖动起点。当前实现单 thumb，多 thumb 约束待补。

在 Field/FormField 内用 FieldThumb 替代 Thumb，桥接 FieldLabel 激活、规范数值校验、策略、Form 序列化及复位。独立 Thumb 仍使用 SliderLabel。

部件: root, label, track, indicator, thumb, field-thumb, value. 四个视觉家族继承同一 Base 行为。

当前为 Draft 源码工作。原生、辅助技术、完整 Adapter/Compiler/GPUI、包消费及独立验收仍待完成，不宣称 Finf 验收通过。

本页选择Rhea scalar配方：4px轨道，16px被动白色Thumb，家族radius-2xl、shadow和静止1px ring；hover/focus使用4px ring。默认根字号下真实Thumb命中区为16px。未选profile时保留的Nova配方另为4px/12px绘制与28px命中区，不能混用。绘制仍是被动Proto Template；Track持有输入和几何，Thumb/FieldThumb仍各只有一个焦点目标。disabled降低透明度，readOnly保留focus/hover但禁止编辑；这些源码尺寸不冒称原生截图结果。

这还不是完整 shadcn 等价。当前数值区间仍将 Thumb 中心放在轨道端点，上游 thumbAlignment="edge" 需要先统一绘制与输入的通用几何契约，不能只挪视觉位置。范围/多 Thumb、所有原生捕获路径上的上游 active 精确行为、跨主题同态像素比较及原生宿主效果仍待完成。示例保留这些真实边界。

本条目是工作区源码，不在公开的 `proto-ui add` 目录里。

## 范围与多值

从 `@proto.ui/prototypes-shadcn/slider` 导入六个 `sliderValues*` 入口。Values Root 设置 `defaultValue={[20, 80]}`，每个值配一个带 index 的 Thumb，并将 Thumb 放入 Values Track。Track 独占共享输入 lease：点击轨道选择最近的可编辑槽，偏离中心抓取 Thumb 保留偏移。`thumbCollisionBehavior` 支持 `push`、`swap`、`none`；swap 转移活动焦点而 capture 始终属于 Track。键盘编辑保留原逐槽限制。

完整 Values Root 可作为 Field/FormField 的一个组合控件，报告 canonical 有限 `number[]`、初始基线、组焦点和关系，FieldLabel 聚焦首个可编辑 Thumb。受控拒绝保持 owner 值，不校验被拒绝的 candidate。取消只撤销提交；reset 撤销当前接触并请求初始基线，也适用于 disabled Form。原标量 Slider 部件保留独立契约。
