## 用法

单值 Slider 包含 `Root`、`Label`、`Track`、`Indicator`、`Thumb`、`FieldThumb` 和 `Value`：

- `Root` 统一管理数值、区间边界（`min` / `max`）、步长（`step`）、方向和交互状态。
- `Track` 处理指针与触摸拖动；`Thumb` 是键盘聚焦目标，支持方向键、`Shift` 十倍步进、`PageUp` / `PageDown` 以及 `Home` / `End`（水平 RTL 模式下左右键自动反向）。
- 数值会从 `min` 起按 `step` 对齐并限制在 `[min, max]` 内。受控模式下拖动发出 `valueChange` 请求，完成时触发 `valueCommit`；取消拖动时在非受控模式下恢复起始值。
- `disabled` 会降低控件透明度并禁用交互；`readOnly` 保留聚焦与悬停状态但阻止修改数值。

### 表单集成

在 `Field` 或 `FormField` 中使用时，请使用 `FieldThumb` 替代 `Thumb`，以自动衔接 `FieldLabel` 激活、数值校验、表单序列化与重置。独立使用时继续搭配 `SliderLabel` 和 `Thumb`。

### 范围与多值滑块

需要范围选择或多个滑块时，可从 `@proto.ui/prototypes-shadcn/slider` 导入六个 `sliderValues*` 入口：

- 在 Values `Root` 上通过 `defaultValue={[20, 80]}`（或受控 `value`）设置数值数组，并在 Values `Track` 内为每个数值放置一个带 `index` 的 `Thumb`。
- 点击轨道会自动移动最近的可编辑滑块，拖动滑块时保留抓取偏移。通过 `thumbCollisionBehavior` 可配置滑块碰撞行为：`push`（推动相邻滑块）、`swap`（交换顺序并跟随转移焦点）或 `none`（阻止越界）。
- 完整的 Values `Root` 也可直接作为 `Field` / `FormField` 的组合控件使用，报告有限 `number[]` 值并在点击 `FieldLabel` 时聚焦首个可编辑滑块。
