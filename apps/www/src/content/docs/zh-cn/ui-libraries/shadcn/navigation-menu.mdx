## 用法

Navigation Menu 由 `Root`、`Trigger`、`Content`、`Item` 和 `Link` 组成：

- `Root` 提供 `navigation` 地标语义，并由 `Root.value` 统一管理当前展开的面板。
- `Trigger` 作为展开按钮，`Content` 作为带名称的展开区域。
- `Item` 用于触发面板内的操作命令。
- `Link` 渲染带有 `href`、`target`、`rel` 和当前页语义（`current` -> `aria-current`）的原生锚点链接。

### 原生链接与导航事件

- 悬停 URL 预览、`Enter` 激活、修饰键或中键打开新标签页等行为完全由浏览器原生处理。
- 在原生激活完成后，`Link` 会发出只读的 `navigate` 事件，携带 `{ href, target, rel, modified }` 字段，适合用于观察与埋点统计。
- 普通当前窗口点击默认关闭展开面板（可通过 `closeOnSelect={false}` 保持打开）；使用修饰键、中键或 `target="_blank"` 打开时，当前页面的面板保持展开。
- 禁用 `Link` 会移除跳转目标并阻止激活。
- 在 React、Vue 和 Vue 2 中，`Link` 直接使用原生 `<a>` 作为根节点；在 Web Components 中，传入的子元素会保留在组件内部的锚点元素中，焦点、样式与无障碍属性随之保持一致。

其他部件的默认属性：

- `Trigger`：`disabled` 默认 `false`。
- `Content`：`sideOffset` 默认 `4`。
- `Item`：`closeOnSelect` 默认 `true`。
- `Link`：`href` 和 `rel` 默认 `''`，`current` 默认 `false`，`target` 默认 `'_self'`。
