Toggle 是一个可在按下（激活）与未按下状态之间切换的双态按钮，适用于富文本工具栏等开关操作场景。本页示例使用 **Shadcn Rhea** 风格。

## 预览

下方依次展示了默认图标按钮、已激活的 `outline` 按钮、小号按钮、禁用且已激活按钮、大号文字按钮以及 `outline` 切换按钮（纯图标按钮均配有视觉隐藏的无障碍名称）。

## 安装

<InstallCommandCard command="npx @proto.ui/cli@latest add wc shadcn-toggle" manager="npm" />

将命令中的 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的组件封装。

## 用法

- 通过 `variant` 选择 `'default'` 或 `'outline'` 外观，通过 `size` 选择 `'default'`、`'sm'` 或 `'lg'` 尺寸。
- 在 **Shadcn Rhea** 预设下，`default` / `sm` / `lg` 高度分别为 `2rem`、`1.75rem` 和 `2.25rem`，`outline` 变体使用无阴影边框，激活与悬停均呈现柔和的 muted 表面。切换到 `new-york-v4` 预设时，则采用 `36px` / `32px` / `40px` 高度与 accent 激活态样式。
- 传入 `active` 进入受控模式，监听 `activeChange` 响应状态变更；使用 `defaultActive` 进入非受控模式。

## API

以下属性属于 `Root`（传入 `active` 可进入受控模式）：

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'active', type: 'boolean | undefined', default: '非受控' },
    { name: 'defaultActive', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'variant', type: "'default' | 'outline'", default: 'default' },
    { name: 'size', type: "'default' | 'sm' | 'lg'", default: 'default' },
  ]}
/>

`Root` 暴露 `active`、`disabled`、`hovered`、`focused`、`focusVisible` 和 `pressed` 状态，以及 `activeChange` 事件。
