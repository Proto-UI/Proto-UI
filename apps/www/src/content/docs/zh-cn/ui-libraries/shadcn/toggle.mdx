## 用法

```tsx
import { ShadcnToggle } from '../proto-ui/components/react';
```

```tsx
<ShadcnToggle variant="outline">Toggle</ShadcnToggle>
```

- **变体与尺寸**：通过 `variant` 在 `'default'` 与 `'outline'` 之间切换，通过 `size` 选择 `'sm'`、`'default'` 或 `'lg'`。
- **风格预设（`styleProfile`）**：支持 `vega`、`nova`、`maia`、`lyra`、`mira`、`luma`、`sera`、`rhea` 与 `new-york-v4`（省略时优先继承最近的 [Style Scope](../style-scope/)）。
- **受控与非受控**：传入 `active` 并监听 `activeChange` 进入受控模式；使用 `defaultActive` 设置非受控初始状态。
- **键盘与无障碍**：支持点击、`Enter` 与 `Space` 切换 `aria-pressed` 状态；使用纯图标切换按钮时，请同时提供视觉隐藏的文本标签作为可访问名称。如需协调一组切换按钮，请使用 [Toggle Group](../toggle-group/)。

## API

以下属性属于 `Root`（传入 `active` 可进入受控模式）：

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'active', type: 'boolean | undefined', default: '非受控' },
    { name: 'defaultActive', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'variant', type: "'default' | 'outline'", default: "'default'" },
    { name: 'size', type: "'default' | 'sm' | 'lg'", default: "'default'" },
    {
      name: 'styleProfile',
      type: "'inherit' | 'vega' | 'nova' | 'maia' | 'lyra' | 'mira' | 'luma' | 'sera' | 'rhea' | 'new-york-v4'",
      default: "'inherit' → 最近 scope → 'new-york-v4'",
    },
  ]}
/>

- **事件**：`activeChange`（载荷 `{ active: boolean }`）。
- **方法**：`focusSelf(options?)`（禁用态忽略）。
- **暴露状态**：`active`、`disabled`、`hovered`、`focused`、`focusVisible`、`pressed`。
