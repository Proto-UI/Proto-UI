## 用法

### 部件结构

`Fieldset` 由 `Root`、`Legend` 与 `Description` 三个部件组成：

- **Root**：无外框竖排分组容器（`gap-4`），声明 `group` 角色并管理有效禁用状态。
- **Legend**：可选的分组标题，自动关联为组的 `aria-labelledby`。
- **Description**：可选的弱化色帮助说明，自动关联为组的 `aria-describedby`。

`Legend` 与 `Description` 均为纯展示部件，不增加焦点顺序；每组最多放置一个 `Legend` 与一个 `Description`（重复声明时忽略重复配置并保持当前状态），且嵌套分组不会借用彼此的标题或描述。

### 嵌套禁用策略

`Root` 的有效禁用状态由自身的 `disabled` 与外层 `Fieldset` 策略共同决定。以 `outer` → `middle` → `inner` 三层嵌套为例：

- 仅禁用 `outer` 时，三层均处于禁用状态；
- 同时禁用 `middle` 后再重新启用 `outer`，`middle` 与 `inner` 仍保持禁用；
- 再启用 `middle`，`inner` 恢复启用（除非 `inner` 自身 `disabled={true}`）。

组内所有参与的 [Field](../field/)（包括放在 `Legend` 内的字段）都会自动继承有效禁用状态并据此更新校验；表单提交与重置由 [Form](../form/) 负责。

## API

`Legend` 与 `Description` 无额外属性；三者均暴露只读的有效 `disabled` 状态，状态变更统一通过 `Root` 的属性驱动。
