Resizable 将容器划分为两个或多个按百分比分配尺寸的面板，支持通过指针拖动或键盘操作连续调整相邻面板比例，也支持嵌套分栏布局。本页示例使用 **Shadcn Rhea** 风格。

## 用法

Resizable 由 `Root`、`Panel` 和 `Handle` 组成：

- `Root` 统一管理面板尺寸比例、方向与约束。
- 布局包含 N 个 `Panel`（`index: 0..N-1`）与 N−1 个 `Handle`（`index: 0..N-2`）。每个 `Handle` 仅调整其相邻的两个面板，保持这两个面板的总比例及其他面板尺寸不变。
- `Panel` 会将无量纲尺寸暴露给静态 CSS 变量 `--pui-size`，用于 `flex-basis` 计算。

### 多面板与约束配置

- 通过 `sizes`（受控）或 `defaultSizes`（非受控）传入完整的百分比数组；若仅构建双面板，也可以继续使用 `value` / `defaultValue`（同时提供 `sizes` 时以 `sizes` 为准）。
- `constraints` 可按面板索引配置 `min`（默认 `0`）、`max`（默认 `100`）、`collapsible`（默认 `false`）和 `collapsedSize`（默认 `0`）。所有面板比例会归一化为总计 `100`；遇到不可行布局时，组件会保留上一次有效状态并忽略非法调整。
- 折叠是离散停靠点；如果相邻面板的 `max` 限制不允许继续扩大，则该面板保持当前展开状态。

### 交互与嵌套

- 指针拖动、方向键、`Shift` 加速、`Home` / `End` 和折叠共用同一套受约束的尺寸请求通道。拖动距离按面板自身实际总长度归一化，不计入分隔柄的固定宽度。
- 每个 `Handle` 的默认无障碍名称为 `Resize panels`。
- 嵌套的 `Root` 各自独立管理比例、约束和排列方向，可自由组合水平与垂直分栏。

### 受控模式与方法

- 传入 `sizes` 后进入受控模式：在 `sizesChange` 和 `sizesCommit` 事件中接收 `{ sizes }` 载荷，并回传新数组以接受变更（取消手势不会触发 `sizesCommit`）。
- 也可以通过 `requestResize(index, nextSize, commit)` 和 `requestSizes(nextSizes, commit)` 以编程方式请求调整。
