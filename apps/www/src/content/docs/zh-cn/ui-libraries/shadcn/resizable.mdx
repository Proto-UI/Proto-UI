## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可直接从 `@proto.ui/prototypes-shadcn/resizable` 导入原型并使用目标宿主 Adapter 适配：

```ts
import {
  resizableRoot,
  resizablePanel,
  resizableHandle,
} from '@proto.ui/prototypes-shadcn/resizable';
```

## 用法

```tsx
import {
  ShadcnResizableRoot,
  ShadcnResizablePanel,
  ShadcnResizableHandle,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <ShadcnResizableRoot
      orientation="horizontal"
      defaultSizes={[50, 50]}
      className="h-56 max-w-md rounded-lg border border-border overflow-hidden"
    >
      <ShadcnResizablePanel index={0}>One</ShadcnResizablePanel>
      <ShadcnResizableHandle index={0} withHandle />
      <ShadcnResizablePanel index={1}>Two</ShadcnResizablePanel>
    </ShadcnResizableRoot>
  );
}
```

### 组合结构

Proto UI 中的 `resizableRoot`、`resizablePanel` 与 `resizableHandle` 分别对应上游 shadcn/ui 的 `ResizablePanelGroup`、`ResizablePanel` 与 `ResizableHandle`：

```text
ResizableRoot
├── ResizablePanel (index: 0)
├── ResizableHandle (index: 0)
└── ResizablePanel (index: 1)
```

- 布局包含 `N` 个 `Panel`（`index: 0..N-1`）与 `N - 1` 个 `Handle`（`index: 0..N-2`）。每个 `Handle` 只调整其相邻的两个面板，保持这两个面板的总比例及其他面板尺寸不变。
- `Panel` 将无量纲百分比暴露到静态 CSS 变量 `--pui-size`，由 `flex-basis` 规则驱动布局；拖动距离按面板自身实际总长度归一化，不计入分隔柄宽度。
- `constraints` 可按面板索引配置 `min`（默认 `0`）、`max`（默认 `100`）、`collapsible`（默认 `false`）和 `collapsedSize`（默认 `0`）；传入 `sizes` 进入受控模式并监听 `sizesChange` / `sizesCommit`。
- 键盘支持方向键、`Shift` 10 倍步进、`Home` / `End` 与 `Enter` 折叠切换；每个 `Handle` 的默认无障碍名称为 `Resize panels`。

### Panel 与 Handle

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'Panel.index', type: 'number', default: '0' },
    { name: 'Panel.styleProfile', type: 'ShadcnStyleId', default: "'new-york-v4'" },
    { name: 'Handle.index', type: 'number', default: '0' },

- **暴露状态**：Root 暴露 `value` 与 `sizes`；Panel 暴露 `size`；Handle 暴露 `value`、`focusVisible` 与 `disabled`。
- **事件**：Root 触发 `sizesChange` / `sizesCommit`（载荷 `{ sizes }`）与双面板兼容事件 `valueChange` / `valueCommit`（载荷 `{ value }`）。取消拖拽不会触发 `*Commit`。
- **方法**：Root 暴露 `requestResize(index, next, commit?)`、`requestSizes(next, commit?)`、`requestValue(next, commit?)` 与 `cancelResize()`。
