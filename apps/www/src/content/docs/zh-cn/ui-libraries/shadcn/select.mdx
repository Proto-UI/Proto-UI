本页常规演示显式采用 **Shadcn Rhea** 外观，示例代码保持一致；这不修改公共组件的兼容默认值，也不代表全部浏览器、原生宿主和视觉验收已完成。Surface/Text 等中性原子仍保留各自公开语义，外观主题由消费组合提供。

当前条目把 shadcn 风格与 API 表面组合在已经编目的 Base Select 协议之上，并在 Web Components、React、Vue 三种适配器中共享同一套选择、焦点和 ARIA 语义。

## 当前范围

- `Root`、`Trigger`、`Value`、`Content`、`Item`、`Surface`、`Viewport`、`ItemText`、`Group`、`Label`、`Separator`
- `defaultValue` / `value`、`defaultOpen` / `open` 与对应变更事件
- `Trigger.size="sm | default"`
- `Trigger.appearance="default"`（Rhea）；`ghost` 仅 New York 支持
- `Content.position="item-aligned | popper"`，默认值与 shadcn/ui 一致为 `item-aligned`
- 单选、禁用项、键盘导航、typeahead、浮层关闭与焦点恢复

`Group` 是被动选项容器，`Label` 只命名所属分组，`Separator` 无内容且仅作装饰。它们与 Trigger、Content、Surface、Item 继承同一 Rhea scope，包含 Portal 的逻辑后代。现代外观参考是 [Rhea 样式源码](https://github.com/shadcn-ui/ui/blob/3d98900e9b73c45f035f8109e9d41ba6a51685e7/apps/v4/registry/styles/style-rhea.css)；[02cad611 New York Select](https://github.com/shadcn-ui/ui/blob/02cad61166c4c20edbc8a3f71bd720eed4c1f49b/apps/v4/registry/new-york-v4/ui/select.tsx) 保留为独立兼容/源码比较，不是本示例选择的皮肤。

完整的 `Surface` → `Viewport` → `Item` → `ItemText` 组合为 item-aligned 定位提供显式结构；旧组合与显式 `popper` 继续支持。这不等于完整 Radix 定位一致性。滚动按钮、`ItemIndicator` 与表单提交仍未完成。GPUI peer 已验证分组命名关系的传输，但当前 wire 未携带 Separator 的 hidden-tree 事实；原生辅助技术验收仍待完成。

## Trigger 外观

本页使用 `appearance="default"` 与 `styleProfile="rhea"`。可选 `ghost` 是仅 `new-york-v4`（别名 `new-york`）支持的 Proto UI 扩展；与 Rhea 或其他现代 profile 组合会拒绝，不静默转换。appearance 设在 Trigger，不设在 Root 或 Content。没有显式或继承 profile 时，Select 保留既有 New York 兼容默认值；Root 的 scope 为完整组合提供统一 profile，叶子的显式选择会覆盖继承，必须有意使用。外观切换不改变 Base 的选择、键盘或浮层协议。
