Select 提供符合无障碍规范的下拉单选列表，在 Web Components、React、Vue 和 Vue 2 之间共享一致的选择、焦点与键盘交互体验。本页示例使用 **Shadcn Rhea** 风格。

## 安装

以下命令使用 0.2.0 稳定版 CLI。Vue 2.6 需要使用版本匹配的预发布版或工作区 CLI、适配器和原型包。页面预览使用工作区版本。

<InstallCommandCard command="npx @proto.ui/cli@0.2.0 add wc shadcn-select" manager="npm" />

将命令中的 `wc` 替换为 `react` 或 `vue`，即可生成对应框架的组件封装。

## 用法

```tsx
import {
  ShadcnSelectContent,
  ShadcnSelectGroup,
  ShadcnSelectItem,
  ShadcnSelectItemText,
  ShadcnSelectLabel,
  ShadcnSelectRoot,
  ShadcnSelectSurface,
  ShadcnSelectTrigger,
  ShadcnSelectValue,
  ShadcnSelectViewport,
} from '../proto-ui/components/react';

export function ThemeSelect() {
  return (
    <ShadcnSelectRoot styleProfile="rhea">
      <ShadcnSelectTrigger styleProfile="rhea" className="w-48" accessibleLabel="Theme">
        <ShadcnSelectValue styleProfile="rhea" placeholder="Theme" />
      </ShadcnSelectTrigger>
      <ShadcnSelectContent styleProfile="rhea">
        <ShadcnSelectSurface styleProfile="rhea">
          <ShadcnSelectViewport styleProfile="rhea">
            <ShadcnSelectGroup styleProfile="rhea">
              <ShadcnSelectLabel styleProfile="rhea">Theme</ShadcnSelectLabel>
              <ShadcnSelectItem styleProfile="rhea" value="light" textValue="Light">
                <ShadcnSelectItemText styleProfile="rhea">Light</ShadcnSelectItemText>
              </ShadcnSelectItem>
              <ShadcnSelectItem styleProfile="rhea" value="dark" textValue="Dark">
                <ShadcnSelectItemText styleProfile="rhea">Dark</ShadcnSelectItemText>
              </ShadcnSelectItem>
            </ShadcnSelectGroup>
          </ShadcnSelectViewport>
        </ShadcnSelectSurface>
      </ShadcnSelectContent>
    </ShadcnSelectRoot>
  );
}
```

### 组合结构

使用完整的十一部件结构以启用 `rhea` 等现代半透明预设与 `item-aligned` 对齐：

```text
SelectRoot
├── SelectTrigger
│   └── SelectValue
└── SelectContent
    └── SelectSurface
        └── SelectViewport
            ├── SelectGroup
            │   ├── SelectLabel
            │   └── SelectItem
            │       └── SelectItemText
            └── SelectSeparator
```

- **键盘与无障碍**：点击或按 `Enter` / `Space` / `ArrowDown` / `ArrowUp` 展开列表；方向键与类型预查浏览选项，按 `Enter` / `Space` 提交，`Escape` 取消并将焦点返回 `Trigger`。可通过 `accessibleLabel` 或配合 `Field` 为 `Trigger` 提供无障碍名称。
- **风格预设**：支持 `styleProfile`（`new-york-v4` / `new-york`、`vega`、`nova`、`maia`、`lyra`、`mira`、`luma`、`sera`、`rhea`），Portal 弹层自动继承 `Root` 的样式作用域。`Trigger` 的 `appearance="ghost"` 仅在 `new-york-v4` 预设下可用。
