<InstallCommandCard command="npx @proto.ui/cli@latest add wc shadcn-select" manager="npm" />

将命令中的 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的组件封装。

## 用法

Select 包含以下部件：

- `Root`、`Trigger`、`Value`、`Content`、`Surface`、`Viewport`、`Item`、`ItemText`、`Group`、`Label` 和 `Separator`。
- `Group` 用于分组选项，`Label` 为所属分组命名，`Separator` 作为无内容的装饰分隔线。所有部件（包括 Portal 弹出的内容）自动继承 `Root` 的样式作用域。

### 外观与定位

- `Trigger` 支持 `size="sm | default"` 以及 `appearance` 属性。在 `styleProfile="rhea"` 等现代预设下使用 `appearance="default"`；`appearance="ghost"` 仅在 `new-york-v4`（别名 `new-york`）预设下可用。
- `Content` 支持 `position="item-aligned | popper"`，默认为 `item-aligned`。使用完整的 `Surface` → `Viewport` → `Item` → `ItemText` 结构可获得精确的 `item-aligned` 定位，同时也兼容 `popper` 定位。

### 输入设备与焦点分离

下方示例展示了可滚动下拉列表如何区分聚焦项与已提交值：无按键按住时的鼠标移动可高亮导航选项，而触摸、触控笔和拖动滚动不会误触悬停导航；受控模式下拒绝变更时，当前已提交值保持不变。
