Surface 是一个纯视觉表面容器，继承 [Base Surface](/zh-cn/ui-libraries/base/surface/) 的输入约定，根据外部传入的视觉变体与交互状态渲染背景、边框、圆角与阴影，同时保持语义和交互控制权归外层组件所有。本页示例使用 **Shadcn Rhea** 风格。

将命令中的 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的组件封装。

## 用法

从 `@proto.ui/prototypes-shadcn/surface`（或包根）导入 `surfaceRoot` 并适配到目标运行时：

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { surfaceRoot } from '@proto.ui/prototypes-shadcn/surface';

const Surface = createReactAdapter(React)(surfaceRoot);

export function Summary() {
  return (
    <Surface variant="muted" radius="md" border="none">
      <div style={{ padding: '1rem' }}>Saved locally</div>
    </Surface>
  );
}
```

### 视觉状态与组合原则

- `hovered`、`focusVisible`、`pressed` 和 `current` 均由外层交互组件或语义容器传入，Surface 自身不监听指针、焦点或键盘事件，也不添加无障碍角色。需要可交互按钮或原生链接时，请直接使用 Button 组件或原生 `<a>` 元素。
- 内部内容与布局间距由调用方控制。当内部嵌套的 `Text` 需要继承外层 Surface（如 `solid` 或 `accent`）的前景色时，请在 `Text` 上设置 `tone="inherit"`。
- 当 `actionProfile` 保持默认 `'none'` 时，`pressed` 不会产生位移动画；显式配置 `rhea` 或 `luma` 操作外观时，按压状态会呈现 1px 按下位移。

### 配合 Transition 使用淡入淡出

- 开启 `fade` 后，Surface 会响应来自 [Base Transition](/zh-cn/ui-libraries/base/transition/) 的 `transitionState`：`closed` 和 `leaving` 映射为透明（opacity `0`），`entering` 和 `entered` 映射为不透明（opacity `1`）。
- 在 Web 端，淡入淡出时长读取 CSS 变量 `--pui-surface-transition-duration`（默认 `0ms`），可由外层组件传入合法的非负毫秒值。
- `scrim` 变体提供常规半透明遮罩底色。透明度为 `0` 仅影响视觉呈现，禁用、卸载和焦点管理仍由外层 Dialog 或 Transition 控制。
