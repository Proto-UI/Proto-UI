Surface 是一个纯视觉表面容器，继承 [Base Surface](/zh-cn/ui-libraries/base/surface/) 的输入约定，根据外层组件传入的变体、圆角、边框与交互状态渲染视觉外观，同时将语义与事件所有权完全留给调用方。本页示例使用 **Shadcn Rhea** 风格。

将命令中的 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的组件封装。

## 用法

从 `@proto.ui/prototypes-shadcn/surface`（或包根）导入 `surfaceRoot` 并适配到目标运行时：

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { surfaceRoot } from '@proto.ui/prototypes-shadcn/surface';

const Surface = createReactAdapter(React)(surfaceRoot);

export function Summary() {
  return (
    <Surface variant="muted" radius="md" border="none">
      <div className="p-4">Saved locally</div>
    </Surface>
  );
}
```

### 组合与被动边界

- `hovered`、`focusVisible`、`pressed` 和 `current` 均由外层交互控件传入；Surface 自身不监听指针、焦点或键盘事件，也不附加无障碍角色。需要可交互按钮或原生链接时，请直接使用 `Button` 或原生 `<a>`。
- 布局与内边距由调用方负责。当内部嵌套的 `Text` 需要继承 `solid` 或 `accent` 表面的前景色时，在 `Text` 上传入 `tone="inherit"`。
- 开启 `fade` 后，Surface 会将来自 [Base Transition](/zh-cn/ui-libraries/base/transition/) 的 `transitionState` 映射为透明度（`closed` / `leaving` 为 `0`，`entering` / `entered` 为 `1`），并在 Web 端读取 `--pui-surface-transition-duration`（默认 `0ms`）。

## API

以下属性属于 `Root`（移除属性时恢复默认值）：

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    {
      name: 'variant',
      type: "'transparent' | 'outline' | 'secondary' | 'muted' | 'accent' | 'solid' | 'scrim'",
      default: 'outline',
    },
    {
      name: 'radius',
      type: "'default' | 'none' | 'sm' | 'md' | 'lg' | 'xl' | 'full'",
      default: 'default',
    },
    { name: 'border', type: "'all' | 'bottom' | 'none'", default: 'all' },
    { name: 'elevation', type: "'none' | 'raised'", default: 'none' },
    {
      name: 'actionProfile',
      type: "'none' | 'vega' | 'nova' | 'maia' | 'lyra' | 'mira' | 'luma' | 'sera' | 'rhea' | 'new-york-v4' | 'new-york'",
      default: 'none',
    },
    {
      name: 'transitionState',
      type: "'closed' | 'entering' | 'entered' | 'leaving'",
      default: 'entered',
    },
    { name: 'fade', type: 'boolean', default: 'false' },
    { name: 'hovered', type: 'boolean', default: 'false' },
    { name: 'focusVisible', type: 'boolean', default: 'false' },
    { name: 'pressed', type: 'boolean', default: 'false' },
    { name: 'current', type: 'boolean', default: 'false' },
  ]}
/>

`@proto.ui/prototypes-shadcn/surface` 同时导出 `ShadcnSurfaceRootProps`、`SurfaceRootProps`、`SurfaceRootExposes`，以及用于原生链接/操作标签组合的 Web 辅助配方 `shadcnActionAppearance` 与 `ShadcnActionAppearanceOptions`。
