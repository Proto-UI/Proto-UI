单行文本输入框，基于 [Base Input](../../base/input/) 提供受控/非受控值管理、规范化的输入法（IME）事件、禁用/只读状态与无障碍属性，并在 Web 端渲染为原生 `input[type="text"]`。本页示例采用 **Shadcn Rhea** 风格。

## 安装

此组件由工作区源码提供。请在应用中安装同一工作区提交构建的 CLI、Shadcn 原型包与目标适配器，用该 CLI 初始化项目，再运行本地命令生成组件封装。

<InstallCommandCard command="npm exec -- proto-ui add wc shadcn-input" manager="npm" />

把 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的本地组件封装。也可以直接从 `@proto.ui/prototypes-shadcn/input` 导入 `shadcnInputRoot`。

## 用法

- **外观预设**：在 **Shadcn Rhea** 风格下采用 `h-8`（32px 高）、`radius-2xl`、`bg-input/50`、`px-2.5 py-1` 与 `border-ring ring-3 ring-ring/30` 焦点环，在视口宽度 `>= 768px` 时自动切换为小号字号；未设置外层 [Style Scope](../style-scope/) 时保留默认兼容外观。
- **表单校验与标签**：独立的 `Input` 专注于文本输入；如需校验错误状态、帮助文本与标签点击聚焦，请搭配 [Field](../field/) 使用。
- **重置值**：`Root` 暴露继承自 Base Input 的 `resetValue(value?: string): boolean` 方法，用于将编辑器恢复到初始值或指定值（受控与 IME 生命周期细节见 [Base Input](../../base/input/)）。

## API
