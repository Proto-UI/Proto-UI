用于表单与用户数据录入的单行文本输入框，基于 [Base Input](../../base/input/) 提供受控/非受控值管理、规范化的输入法（IME）事件、禁用与只读状态以及无障碍命名属性。本页示例采用 **Shadcn Rhea** 风格。

## 安装

此组件由工作区源码提供。请在应用中安装同一工作区提交构建的 CLI、Shadcn 原型包与目标适配器，用该 CLI 初始化项目，再运行本地命令生成组件封装。

<InstallCommandCard command="npm exec -- proto-ui add wc shadcn-input" manager="npm" />

把 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的本地组件封装。也可以直接从 `@proto.ui/prototypes-shadcn/input` 导入 `shadcnInputRoot`。

## 用法

```tsx
import { ShadcnInputRoot } from '@/components/ui/shadcn-input';

export function Example() {
  return <ShadcnInputRoot placeholder="Enter text" ariaLabel="Text input" />;
}
```

- **外观预设**：通过外层 [Style Scope](../style-scope/) 或 `styleProfile` 切换预设；在 **Shadcn Rhea** 风格下采用 `h-8`（32px）、`radius-2xl`、`bg-input/50`（暗色模式 `bg-input/30`）与 `border-ring ring-3 ring-ring/30` 焦点环，在视口宽度 `>= 768px` 时自动切换为小号字号。
- **表单校验与标签**：独立的 `Input` 专注于单行文本编辑；如需标签点击聚焦、帮助说明与校验错误状态，请搭配 [Field](../field/) 使用。
- **无障碍与控制方法**：`Root` 暴露 `focusSelf()`、`blurSelf()` 与 `resetValue(value?: string)`，并支持 `ariaLabel`、`labelledBy` 与 `describedBy`。

### 暴露状态、方法与事件

- **状态**：`value`、`disabled`、`readOnly`、`focused`、`focusVisible`、`composing`
- **方法**：`focusSelf(options?)`、`blurSelf()`、`resetValue(value?: string): boolean`
- **事件**：`valueChange`、`change`、`compositionStart`、`compositionUpdate`、`compositionEnd`
