Toolbar 将一组相关操作按钮和分隔线组织在一个无障碍工具栏容器中，通过单一 `Tab` 入口和方向键提供流畅的键盘操作。本页示例使用 **Shadcn Rhea** 风格。

## 用法

Toolbar 由 `Root`、`Button` 和 `Separator` 三个部件组成：

- `Root` 统一管理禁用状态、排列方向（`orientation`）、是否循环导航（`loop`）及工具栏的无障碍名称（`a11yLabel`）。
- 同一时刻仅有一个启用的命令按钮位于 `Tab` 序列中，使用方向键在工具栏内移动焦点。
- `Button` 在启用状态下激活时会发出携带其 `value` 的 `action` 事件。
- `Separator` 自动沿工具栏的交叉轴方向绘制分隔线。
