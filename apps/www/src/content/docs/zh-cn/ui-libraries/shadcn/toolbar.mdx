Toolbar 将一组相关操作按钮和分隔线组织在一个无障碍工具栏容器中，通过单一 `Tab` 入口与方向键提供流畅的键盘操作。本页示例使用 **Shadcn Rhea** 风格。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可直接从 `@proto.ui/prototypes-shadcn/toolbar` 导入原型并适配到 Web Components、React、Vue 3 或 Vue 2：

```ts
import { toolbarRoot, toolbarButton, toolbarSeparator } from '@proto.ui/prototypes-shadcn/toolbar';
```

## 用法

```tsx
import {
  ShadcnToolbarRoot,
  ShadcnToolbarButton,
  ShadcnToolbarSeparator,
} from '../proto-ui/components/react';

export function EditorToolbar() {
  return (
    <ShadcnToolbarRoot styleProfile="rhea" a11yLabel="Document actions">
      <ShadcnToolbarButton value="undo">Undo</ShadcnToolbarButton>
      <ShadcnToolbarButton value="redo">Redo</ShadcnToolbarButton>
      <ShadcnToolbarSeparator />
      <ShadcnToolbarButton value="save" variant="default">
        Save
      </ShadcnToolbarButton>
    </ShadcnToolbarRoot>
  );
}
```

Toolbar 由 `Root`、`Button` 和 `Separator` 三个部件组成：

- **焦点与键盘导航**：同一时刻仅有一个启用的 `Button` 参与页面 `Tab` 序列；水平布局下使用左右方向键、垂直布局下使用上下方向键在可用命令间移动，`loop={true}`（默认）时会在首尾循环。
- **命令触发**：激活启用状态的 `Button` 时会发出 `action` 事件，载荷为 `{ value: string }`。
- **分隔线**：`Separator` 会自动根据 `Root` 的 `orientation` 切换到交叉轴方向绘制。

### 风格预设（`styleProfile`）

`Root`、`Button` 与 `Separator` 均支持全部 9 种 Shadcn 风格预设（`vega`、`nova`、`maia`、`lyra`、`mira`、`luma`、`sera`、`rhea` 与 `new-york-v4`，`new-york` 作为兼容别名）。省略或设为 `inherit` 时优先继承最近的 `StyleScope` 或 `Root`，否则回退到 `rhea`。

### 按钮变体

`Button` 支持 `ghost`（默认）、`outline`、`secondary`、`default` 与 `destructive` 五种视觉变体，可在工具栏中区分普通操作、主要提交与危险操作。

### 事件与暴露接口

- **Button `action` 事件**：启用状态激活时触发，载荷为 `{ value: string }`。
- **Root 暴露**：`disabled` 状态以及 `focusFirst()`、`focusLast()`、`setCurrent(id)` 方法。
- **Button 暴露**：`disabled`、`focused`、`focusVisible` 状态以及 `focusSelf(options)` 方法。
