## 安装

以下命令使用 0.2.0 稳定版 CLI。Vue 2.6 需要使用版本匹配的预发布版或工作区 CLI、适配器和原型包。页面预览使用工作区版本。

<InstallCommandCard command="npx @proto.ui/cli@0.2.0 add wc shadcn-dropdown" manager="npm" />

把 `wc` 替换为 `react` 或 `vue`，即可生成对应框架的本地组件封装。注意 CLI 的组件标识为 `shadcn-dropdown`。

CLI 默认生成 `Root`、`Trigger`、`Content` 与 `Item` 的封装；`Group`、`Label`、`Separator` 与 `Shortcut` 可直接从 `@proto.ui/prototypes-shadcn/dropdown` 导入使用。

## 用法

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuGroup,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
} from '@/components/ui/dropdown-menu';
```

```tsx
<DropdownMenu>
  <DropdownMenuTrigger>Open</DropdownMenuTrigger>
  <DropdownMenuContent align="start">
    <DropdownMenuGroup>
      <DropdownMenuLabel>My Account</DropdownMenuLabel>
      <DropdownMenuItem value="profile">Profile</DropdownMenuItem>
      <DropdownMenuItem value="billing">Billing</DropdownMenuItem>
    </DropdownMenuGroup>
    <DropdownMenuSeparator />
    <DropdownMenuGroup>
      <DropdownMenuItem value="team">Team</DropdownMenuItem>
      <DropdownMenuItem value="subscription">Subscription</DropdownMenuItem>
    </DropdownMenuGroup>
  </DropdownMenuContent>
</DropdownMenu>
```

### 组合结构

```text
DropdownMenu (Root)
├── DropdownMenuTrigger
└── DropdownMenuContent
    ├── DropdownMenuGroup
    │   ├── DropdownMenuLabel
    │   ├── DropdownMenuItem
    │   │   └── DropdownMenuShortcut
    │   └── DropdownMenuItem
    └── DropdownMenuSeparator
```

- **无障碍与键盘导航**：支持 `ArrowDown` / `ArrowUp` / `Home` / `End` 逐项导航、`Enter` / `Space` 确认、`Escape` 或外部点击关闭并恢复触发器焦点。
- **分组与装饰部件**：`Group` 与 `Label` 自动建立无障碍分组命名关系；`Separator` 与 `Shortcut` 为被动展示部件（`Shortcut` 仅显示提示文本，不注册全局快捷键）。
