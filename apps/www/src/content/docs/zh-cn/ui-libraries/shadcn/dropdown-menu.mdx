由按钮触发的下拉命令菜单，基于 Base 协议提供键盘方向导航、分组命名与焦点恢复，并内置危险操作与图标缩进等常见样式变体。本页示例采用 **Shadcn Rhea** 风格。

## 预览

下方展示包含分组、标签、快捷键提示与禁用项的常规菜单：

<PrototypePreviewer demoId="demo-shadcn-dropdown-menu" initialRuntime="wc" />

### 危险操作（Destructive）

参考 `DropdownMenuWithDestructive` 模式，使用 16px Lucide 图标，并为 Delete 设置 `variant="destructive"`（浅色模式 10% 底色、深色模式 20% 底色）。末尾的 **Delete (disabled)** 用于演示禁用项仍可聚焦但不触发选择或关闭菜单。

<PrototypePreviewer demoId="demo-shadcn-dropdown-destructive" initialRuntime="wc" />

### 缩进对齐（Inset）

参考 `DropdownMenuWithInset`，当同组菜单项混用带图标与无图标项时，可为无图标的 `Item` 或 `Label` 设置 `inset={true}` 实现文字左对齐：

- **Shadcn Rhea**：`inset={false}` 时左右内边距均为 8px；`inset={true}` 时左侧 28px、右侧 8px。
- **New York 兼容预设**：`inset={false}` 时左右均为 `0.5rem`；`inset={true}` 时物理左侧 `2rem`、右侧 `0.5rem`。

点击示例中的 **Toggle inset** 按钮可切换缩进属性后重新打开菜单对比效果。

## 安装

以下命令使用 0.2.0 稳定版 CLI。Vue 2.6 需要使用版本匹配的预发布版或工作区 CLI、适配器和原型包。页面预览使用工作区版本。

<InstallCommandCard command="npx @proto.ui/cli@0.2.0 add wc shadcn-dropdown" manager="npm" />

把 `wc` 替换为 `react` 或 `vue`，即可生成对应框架的本地组件封装。注意 CLI 的组件标识为 `shadcn-dropdown`。

CLI 默认生成 `Root`、`Trigger`、`Content` 与 `Item` 的封装；`Group`、`Label`、`Separator` 与 `Shortcut` 可直接从 `@proto.ui/prototypes-shadcn/dropdown` 导入使用。

## 用法

- **分组与装饰部件**：`Group` 与 `Label` 自动建立无障碍分组命名关系；`Separator` 与 `Shortcut` 属于纯展示部件（`Shortcut` 仅展示快捷键文本，不注册全局快捷键）。
- **示例源码**：[My Account](https://github.com/Proto-UI/Proto-UI/blob/main/apps/www/src/content/docs/zh-cn/demo-shadcn-dropdown-menu.demo.ts)、[Destructive 动作](https://github.com/Proto-UI/Proto-UI/blob/main/apps/www/src/content/docs/demo-shadcn-dropdown-destructive.demo.ts)、[Inset 动作](https://github.com/Proto-UI/Proto-UI/blob/main/apps/www/src/content/docs/demo-shadcn-dropdown-inset.demo.ts)。
- **说明**：子菜单与复选/单选菜单项将在后续版本中提供。
