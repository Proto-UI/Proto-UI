## 安装

当前组件在工作区源码中提供，尚未包含在 0.2.0 稳定版包中；可从 `@proto.ui/prototypes-shadcn/form` 引入。

## 用法

```tsx
import {
  ShadcnFormRoot,
  ShadcnFormField,
  ShadcnFormSubmit,
  ShadcnFormReset,
  ShadcnFieldLabel,
  ShadcnFieldControl,
  ShadcnFieldError,
} from '../proto-ui/components/react';

export function ExampleForm() {
  return (
    <ShadcnFormRoot
      styleProfile="rhea"
      ariaLabel="Account settings"
      onSubmit={({ values }) => console.log(values)}
    >
      <ShadcnFormField styleProfile="rhea" name="username" required>
        <ShadcnFieldLabel styleProfile="rhea">Username</ShadcnFieldLabel>
        <ShadcnFieldControl styleProfile="rhea" placeholder="ada_lovelace" />
        <ShadcnFieldError styleProfile="rhea" />
      </ShadcnFormField>
      <div className="flex items-center gap-2">
        <ShadcnFormSubmit styleProfile="rhea">Save</ShadcnFormSubmit>
        <ShadcnFormReset styleProfile="rhea" variant="outline">
          Reset
        </ShadcnFormReset>
      </div>
    </ShadcnFormRoot>
  );
}
```

### 部件结构

- **Root**：收集内部显式注册的 `FormField`，全部启用字段校验通过后通过 `submit` 事件输出按字段名组织的数据。禁用字段（含被父级 `Fieldset` 禁用的字段）自动排除；重复字段名会在序列化时抛出 `FORM_DUPLICATE_NAME` 错误。设置 `disabled` 会向下级联禁用所有内部字段与操作按钮。
- **Field**：继承 `FieldRoot` 能力并声明提交键名 `name`。独立的 `Checkbox`、`RadioGroup` 或 `Switch` 不会自动注册，如需接入表单请使用 `@proto.ui/prototypes-shadcn/field` 导出的 `fieldCheckbox`、`fieldRadioGroup` 或 `fieldSwitch`。
- **Submit / Reset**：支持指针与键盘激活，支持 `variant`、`size` 与 `styleProfile`，并暴露 `disabled`、`hovered`、`pressed`、`focused`、`focusVisible` 与 `focusSelf()`。

### 键盘与无障碍

- **隐式回车提交**：在聚焦的单行 `Field`、`Number Field` 或 `Input OTP` 内按 `Enter` 可直接触发表单提交（自动排除输入法组合、修饰键与长按连发）。
- **校验失败聚焦**：校验不通过时触发 `invalid` 事件并自动将焦点移至首个无效字段控件。
- **重置与清理**：`Reset` 或 `requestReset()` 还原非受控字段初值、向受控字段发出初值提议、取消进行中的校验并触发 `reset` 事件；`resetValidation()` 仅清除校验状态而不改动值。
