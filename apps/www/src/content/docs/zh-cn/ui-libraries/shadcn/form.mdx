## 用法

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

### 部件结构

`Form` 由 `Root`、`Field`、`Submit` 与 `Reset` 四个部件组成：

- **Root**：汇总内部显式注册的 `FormField`，校验通过后在 `submit` 事件中返回按字段名组织的表单数据。重复字段名会被拒绝序列化，禁用字段（含被父级 `Fieldset` 禁用的字段）自动从提交数据中排除；`Root` 的 `disabled` 会同步传递到内部所有字段。
- **Field**：为单个字段声明 `name` 并将其接入表单提交与重置流程。普通独立的 `Checkbox`、`RadioGroup` 或 `Switch` 不会自动注册，如需参与表单请使用 `fieldCheckbox`、`fieldRadioGroup` 或 `fieldSwitch`。
- **Submit / Reset**：复用本套按钮视觉样式，支持键盘与指针激活，并暴露 `disabled`、`hovered`、`pressed`、`focused`、`focusVisible` 与 `focusSelf`。

### 提交、异步校验与重置

- **隐式回车提交**：在聚焦的单行 `Field`、`Number Field` 或 `Input OTP` 中按 `Enter` 可直接触发提交（自动排除输入法组合、修饰键与长按重复触发）。
- **异步提交协调**：存在异步校验字段时，表单会等待当前版本的校验结果；若期间值变更、字段移除、取消提交或发起新提交，旧尝试会自动失效。
- **表单重置**：调用 `requestReset()` 或点击 `Reset` 会恢复非受控字段的初始值，向受控字段发出恢复初值的请求，并取消进行中的编辑与校验，最后触发 `reset` 事件（不触发 `onChange` 校验）。若仅需清除校验错误而不还原值，请使用 `resetValidation()`。
