Tree 用于展示和浏览层级结构数据（如文件目录或大纲列表），支持单项选择、分支展开折叠以及完整的键盘导航。本页示例使用 **Shadcn Rhea** 风格。

## 用法

Tree 由 `Root`、`Item`、`Group`（`TreeGroup`）和 `Toggle` 组成：

- 每个 `Item` 使用树内唯一的 `nodeKey`，并通过 `parentKey` 指向父节点；若出现重复 key、缺失父节点或循环引用，非法节点配置会被忽略并保持当前有效结构。
- 将分支子项放入与父 `Item` 共享相同 `nodeKey` 的 `TreeGroup` 中，组件会自动维护 `aria-controls` / `aria-labelledby` 关联并在节点卸载时清理。
- 折叠分支时仅隐藏 `TreeGroup` 而保留完整层级；若折叠前焦点位于分支内部，焦点会自动回到可见祖先节点，而不会抢走树外的焦点。

### 嵌入式外观与文字方向

- 在侧边栏或现有卡片表面内展示文件导航时，可在 `Root` 和 `Item` 上同时设置 `appearance="embedded"`，启用更柔和的选中底色并支持放大字号时的自动换行。
- 在 `Root` 上设置 `direction="rtl"` 会自动镜像缩进方向与左右方向键映射（左键展开/进入子项，右键折叠/返回父项）；上下方向键、`Home` / `End` 和首字母跳转继续按逻辑可见顺序工作。

### 受控与只读

- 传入 `value` 或 `expandedKeys` 可分别进入受控模式，组件发出变更请求并在外部更新后提交。动态增删或移动节点会更新层级而不会伪造用户选择事件。
- 设置 `readOnly` 会阻止修改选中项，同时保留键盘导航与展开/折叠功能。

## API

以下属性属于 `Root`（传入 `value` 或 `expandedKeys` 可分别进入受控模式）：

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'defaultValue', type: 'string', default: "''" },
    { name: 'defaultExpandedKeys', type: 'readonly string[]', default: '[]' },
    { name: 'direction', type: "'ltr' | 'rtl'", default: 'ltr' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'readOnly', type: 'boolean', default: 'false' },
    { name: 'a11yLabel', type: 'string', default: 'Tree' },
  ]}
/>

其他部件属性：

- `Item`：`nodeKey`、`parentKey`、`textValue` 默认 `''`，`disabled` 默认 `false`（支持 `appearance="embedded"`）。
- `Group`：接受 `nodeKey`。
- `Toggle`：接受 Button 属性。
