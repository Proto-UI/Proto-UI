本页常规演示显式采用 **Shadcn Rhea** 外观，示例代码保持一致；这不修改公共组件的兼容默认值，也不代表全部浏览器、原生宿主和视觉验收已完成。Surface/Text 等中性原子仍保留各自公开语义，外观主题由消费组合提供。

Tree 管理完整显式层级的单选与展开。nodeKey 在当前树唯一，parentKey 指向父项；重复标识、缺失父项和环路均拒绝。方向键、Home/End 与首字母移动焦点；左右键展开、折叠或定位父子项。value 与 expandedKeys 支持受控请求。

当前是功能源码 WIP。完整 Adapter/Compiler、原生 GPUI、包消费者、无障碍与绑定提交的视觉验收仍待补齐。

Shadcn Root 与 Item 可显式设置 `appearance="embedded"`，用于已有表面内的文件导航。两个部分分别设置，默认外观保持不变。嵌入态采用较轻的选中背景，保留键盘焦点与禁用语义，并允许放大文字换行；它只是设计族外观选项，不新增选择或展开负责人。

## API

Tree 是工作区源码，没有公开的 `proto-ui add` 目标。传入 `value` 或 `expandedKeys` 会使对应事实进入受控模式。

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'defaultValue', type: 'string', default: "''" },
    { name: 'defaultExpandedKeys', type: 'readonly string[]', default: '[]' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'readOnly', type: 'boolean', default: 'false' },
    { name: 'a11yLabel', type: 'string', default: 'Tree' },
  ]}
/>

这些属性属于 Root。Item 的 `nodeKey`、`parentKey`、`textValue` 默认 `''`，`disabled` 默认 `false`。Group 接受 `nodeKey`。Toggle 额外接受 Button 的属性。
