Tree 用于展示和浏览层级结构数据（如文件浏览器或文档大纲），支持单项选择、分支展开折叠以及完整的键盘导航。本页示例使用 **Shadcn Rhea** 风格。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可直接从 `@proto.ui/prototypes-shadcn/tree` 导入原型并通过目标框架适配器注册使用：

```ts
import { treeRoot, treeItem, treeGroup, treeToggle } from '@proto.ui/prototypes-shadcn/tree';
```

## 用法

```tsx
<ShadcnTreeRoot defaultValue="button" defaultExpandedKeys={['src', 'components']}>
  <div className="flex items-center gap-1">
    <ShadcnTreeToggle nodeKey="src" size="icon">
      ▾
    </ShadcnTreeToggle>
    <ShadcnTreeItem nodeKey="src" textValue="src" className="flex-1">
      src/
    </ShadcnTreeItem>
  </div>
  <ShadcnTreeGroup nodeKey="src">
    <ShadcnTreeItem nodeKey="button" parentKey="src" textValue="button.tsx">
      button.tsx
    </ShadcnTreeItem>
  </ShadcnTreeGroup>
</ShadcnTreeRoot>
```

### 结构与无障碍语义

- 每个 `Item` 需提供树内唯一的 `nodeKey`，并通过 `parentKey` 指向父节点；若出现重复键、缺失父节点或循环引用，非法节点配置会被忽略并保持当前有效结构。
- 将分支子项放入与父 `Item` 共享相同 `nodeKey` 的 `TreeGroup` 中，组件会自动维护 `aria-controls` / `aria-labelledby` 关联并在节点卸载时清理。
- 折叠分支时仅隐藏 `TreeGroup` 而保留完整层级；若折叠前焦点位于分支内部，焦点会自动回到可见祖先节点，而不会抢走树外焦点。
- **键盘导航**：支持 `ArrowUp` / `ArrowDown`、`Home` / `End` 和首字母跳转；LTR 模式下 `ArrowRight` 展开分支或进入首个子节点，`ArrowLeft` 折叠分支或返回父节点；`direction="rtl"` 会自动镜像缩进导轨与左右键方向。

### 风格预设（`styleProfile`）

支持 `vega`、`nova`、`maia`、`lyra`、`mira`、`luma`、`sera`、`rhea` 与 `new-york-v4`（`new-york` 作为兼容别名）。省略或设为 `inherit` 时优先继承最近的 [Style Scope](../style-scope/)，否则回退到 `nova`。

## 示例

### 嵌入式侧边栏外观

在侧边栏或现有卡片表面内使用 `appearance="embedded"` 时，`Root` 会自动将嵌入式外观向下传递给未显式覆盖的 `Item`，启用无外框透明容器与更柔和的选中/悬停层次。

<PrototypePreviewer
  demoId="demo-shadcn-tree-embedded"
  initialRuntime="wc"
  runtimes={['wc', 'react', 'vue', 'vue2']}
/>

### 受控选择与展开

传入 `value` 或 `expandedKeys` 可分别进入受控模式；监听 `valueChange` 与 `expandedChange` 并在外部状态确认后提交更新。

<PrototypePreviewer
  demoId="demo-shadcn-tree-controlled"
  initialRuntime="wc"
  runtimes={['wc', 'react', 'vue', 'vue2']}
/>

### 禁用与只读状态

支持在 `Root` 或单个 `Item` 上设置 `disabled`；在 `Root` 上设置 `readOnly` 会锁定当前选中项，同时保留分支展开折叠与键盘导航。

<PrototypePreviewer

/>

### 从右到左（RTL）

设置 `direction="rtl"` 会自动翻转层级缩进与导轨边，并交换左/右方向键的展开与折叠语义。
