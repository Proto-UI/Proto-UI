Message Scroller 适用于聊天记录、日志流等持续追加内容的滚动区域，支持在底部自动跟随新消息以及一键跳回最新位置。本页示例使用 **Shadcn Rhea** 风格。

## 用法

Message Scroller 由 `Root`、`Viewport` 和 `Jump` 组成：

- 当读者位于滚动区域底部时，新追加的内容会自动跟随滚入视野。
- 向上回看历史内容时，自动跟随暂停；用户可通过 `Jump` 控件主动跳回最新位置，且跳转不会抢占当前键盘焦点。
- `newContentCount` 由应用自行传入，用于展示新增消息提示，组件不会自动推断未读业务状态。
- 通过 `Root` 的 `a11yLabel` 为滚动区域提供无障碍名称，默认值为 `Messages`。

### 历史位置与选区恢复

如果需要基于稳定 key 恢复历史阅读位置或文本选区，可在自定义组合中于 Shadcn `Viewport` 之后调用公开的 Base Hook `asMessageScrollerReading`。该 Hook 基于同一滚动容器管理锚点捕获、按 key 或前驱恢复位置以及选区恢复，同时应用继续负责内容标识、DOM/Range 操作与持久化存储。详细配置请参阅 [Base Message Scroller](/zh-cn/ui-libraries/base/message-scroller/)。
