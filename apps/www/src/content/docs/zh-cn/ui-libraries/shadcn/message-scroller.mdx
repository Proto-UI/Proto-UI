Message Scroller 面向聊天记录与流式回复场景，在读者位于底部时自动跟随新追加内容，向上回看历史时保持当前阅读位置，并通过浮动跳转按钮一键回到最新消息。本页示例使用 **Shadcn Rhea** 风格。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可直接从 `@proto.ui/prototypes-shadcn/message-scroller` 导入原型并使用目标框架适配器封装。

```ts
import {
  messageScrollerRoot,
  messageScrollerViewport,
  messageScrollerJump,
} from '@proto.ui/prototypes-shadcn/message-scroller';
```

## 用法

`Message Scroller` 会填满父容器高度，请将其放入有明确高度约束的容器内：

```tsx
<div className="flex h-80 flex-col overflow-hidden rounded-xl border border-border">
  <ShadcnMessageScrollerRoot styleProfile="rhea" a11yLabel="Assistant conversation">
    <ShadcnMessageScrollerViewport styleProfile="rhea">
      <div className="flex flex-col gap-3 p-4 pb-14">
        {messages.map((message) => (
          <div key={message.id}>{message.text}</div>
        ))}
      </div>
    </ShadcnMessageScrollerViewport>
    <ShadcnMessageScrollerJump styleProfile="rhea">
      <span aria-hidden="true">↓</span>
      <span className="sr-only">Jump to latest</span>
    </ShadcnMessageScrollerJump>
  </ShadcnMessageScrollerRoot>
</div>
```

### 组件结构与核心原则

Message Scroller 由 `Root`、`Viewport` 和 `Jump` 三个部件组成：

- **仅在跟随状态自动滚底**：当读者已经停留在列表底部时，新追加内容会自动进入视野；一旦向上滚动翻阅历史，自动跟随立即暂停并保留阅读位置。
- **不抢占焦点的跳转控制**：点击 `Jump` 会滚动到最新位置并恢复自动跟随，同时不会把键盘焦点从输入框等控件上移走。默认 `size="icon"` 适合图标按钮，传入 `size="pill"` 可容纳文本标签与未读计数。
- **应用层持有未读语义**：`newContentCount` 由业务状态显式传入，组件不会擅自推断未读规则。
- **无障碍命名**：通过 `Root` 的 `a11yLabel` 为可滚动区域设置无障碍名称，默认值为 `Messages`。
- **风格预设（`styleProfile`）**：全部三个部件支持 `vega`、`nova`、`maia`、`lyra`、`mira`、`luma`、`sera`、`rhea` 与 `new-york-v4`；省略或设为 `inherit` 时优先继承最近的 [Style Scope](../style-scope/)。

### 历史位置与选区恢复

如果需要基于稳定 key 恢复历史阅读位置或文本选区，可在自定义组合中于 Shadcn `Viewport` 之后调用公开的 Base Hook `asMessageScrollerReading`。该 Hook 基于同一滚动容器管理锚点捕获、按 key 或前驱恢复位置以及选区恢复，同时应用继续负责内容标识、DOM/Range 操作与持久化存储。详细配置请参阅 [Base Message Scroller](/zh-cn/ui-libraries/base/message-scroller/)。
