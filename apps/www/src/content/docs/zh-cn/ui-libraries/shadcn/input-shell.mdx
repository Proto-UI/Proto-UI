`Input Shell` 将输入框的外框样式（边框、背景、圆角、校验态与可选聚焦环）与内部文本编辑器的交互逻辑分离：普通单行输入搭配 `inputShellControl`，命令搜索场景搭配 [Command](/zh-cn/ui-libraries/shadcn/command/) 的 `commandInput`。本页默认示例采用 **Shadcn Rhea** 风格。

## 安装

当前通过工作区源码导入（尚未进入 0.2.0 稳定版 CLI 模板），从 `@proto.ui/prototypes-shadcn/input-shell` 或包根入口引入：

```ts
import {
  inputShell,
  inputShellControl,
  bindInputShellControl,
  INPUT_SHELL_PROJECTED_STYLES,
} from '@proto.ui/prototypes-shadcn/input-shell';
import type {
  InputShellProps,
  InputShellControlProps,
  InputShellControlExposes,
  InputShellOwner,
  InputShellTarget,
  InputShellControlInstance,
} from '@proto.ui/prototypes-shadcn/input-shell';
```

| 导出项 | 职责 |
| --- | --- |
| `inputShell`（`shadcn-input-shell`） | 纯展示外框容器，提供单个内容插槽，自身不创建编辑器或焦点节点。 |
| `inputShellControl`（`shadcn-input-shell-control`） | 无边框单行文本编辑器，继承完整的 [Base Input](/zh-cn/ui-libraries/base/input/) 交互与无障碍协议。 |
| `bindInputShellControl(owner, target, control)` | 将控件的 `focusVisible` 与 `disabled` 状态实时同步到外框，并随视图生命周期自动清理。 |

## 用法

使用外层 [Style Scope](/zh-cn/ui-libraries/shadcn/style-scope/) 包裹 `inputShell`，可让外框与内部编辑器自动继承同一风格预设：

```tsx
<ShadcnStyleScope styleProfile="rhea">
  <ShadcnInputShell focusIndicator="ring">
    <ShadcnInputShellControl ariaLabel="笔记标题" placeholder="未命名笔记" />
  </ShadcnInputShell>
</ShadcnStyleScope>
```

在真实外框与控件实例挂载后，调用 `bindInputShellControl` 同步控件的 `focusVisible` 与 `disabled` 状态，并在 `setFacts` 中保留原有外框属性：

```ts
import { setElementProps } from '@proto.ui/adapter-web-component';
import {
  bindInputShellControl,
  type InputShellControlInstance,
  type InputShellOwner,
  type InputShellProps,
} from '@proto.ui/prototypes-shadcn/input-shell';

export function attachShell(
  shell: HTMLElement,
  control: InputShellControlInstance,
  shellProps: InputShellProps = { styleProfile: 'inherit', focusIndicator: 'ring' }
) {
  let current = true;
  const cleanups: VoidFunction[] = [];
  const owner: InputShellOwner = {
    isCurrent() {
      return current;
    },
    onDispose(dispose) {
      cleanups.push(dispose);
      return function remove() {
        const index = cleanups.indexOf(dispose);
        if (index >= 0) cleanups.splice(index, 1);
      };
    },
  };

  bindInputShellControl(
    owner,
    {
      instance: shell,
      setFacts(facts) {
        setElementProps(shell, { ...shellProps, ...facts });
      },
    },
    control
  );

  return function detach() {
    if (!current) return;
    current = false;
    for (const dispose of cleanups.splice(0)) dispose();
  };
}
```

关键约定：

- **每次同步保留已有外框属性**：`setFacts` 应合并已声明的 `styleProfile`、`focusIndicator` 与 `invalid`，避免覆盖已有配置。
- **交互状态始终写在控件上**：`disabled`、`readOnly` 与无障碍名称（`ariaLabel` / `labelledBy` / `describedBy`）直接设置在控件上；每个外框内只放置一个内联编辑器。独立输入框请直接使用 [Input](/zh-cn/ui-libraries/shadcn/input/)。
- **绑定生命周期**：每个外框或控件同一时刻最多保持一个活跃绑定。返回的句柄提供 `sync()`、`replace(nextControl)` 与幂等的 `dispose()`；视图卸载或控件断开连接（`disconnect`）时会自动清理。

`InputShellControlExposes` 完整继承 [Base Input](/zh-cn/ui-libraries/base/input/) 的 `InputRootExposes`：

- **暴露状态**：`value`、`disabled`、`readOnly`、`focused`、`focusVisible`、`composing`。
- **暴露方法**：`focusSelf(options?)`、`blurSelf()`、`resetValue(value?: string): boolean`。
- **暴露事件**：`valueChange`、`change`、`compositionStart`、`compositionUpdate`、`compositionEnd`。

### `bindInputShellControl(owner, target, control)`

返回 `{ sync(), replace(nextControl), dispose() }` 句柄，用于按视图生命周期同步外框状态并在替换控件或卸载时释放所有订阅。
