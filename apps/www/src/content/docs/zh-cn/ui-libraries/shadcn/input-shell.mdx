`Input Shell` 将输入框的外框样式（边框、背景、圆角与可选焦点环）与内部文本编辑器的交互逻辑分离：普通单行输入搭配 `inputShellControl`，命令搜索场景搭配 `Command` 的 `commandInput`。

## 安装与导入

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

从 `@proto.ui/prototypes-shadcn/input-shell`（或包根入口）导入：

```ts
import {
  inputShell,
  inputShellControl,
  bindInputShellControl,
  INPUT_SHELL_PROJECTED_STYLES,
} from '@proto.ui/prototypes-shadcn/input-shell';
import type {
  InputShellProps,
  InputShellControlProps,
  InputShellControlExposes,
  InputShellOwner,
  InputShellTarget,
  InputShellControlInstance,
} from '@proto.ui/prototypes-shadcn/input-shell';
```

| 导出项 | 职责 |
| --- | --- |
| `inputShell`（`shadcn-input-shell`） | 纯展示外框容器，提供单个内容插槽，自身不创建编辑器或焦点节点。 |
| `inputShellControl`（`shadcn-input-shell-control`） | 无边框单行文本编辑器，继承完整的 [Base Input](/zh-cn/ui-libraries/base/input/) 交互与无障碍协议。 |
| `bindInputShellControl(owner, target, control)` | 将控件的 `focusVisible` 与 `disabled` 状态实时同步到外框，并随视图生命周期自动清理。 |

## 用法

### 组合普通单行输入框

将外层 [Style Scope](/zh-cn/ui-libraries/shadcn/style-scope/) 包裹在 `inputShell` 之外，可让外框与内部编辑器自动保持相同风格预设（直接在 `inputShell` 上设置 `styleProfile` 仅影响外框本身）。以下为 Web Components 完整挂载与卸载示例：

```ts
import { AdaptToWebComponent, setElementProps } from '@proto.ui/adapter-web-component';
import { styleScope } from '@proto.ui/prototypes-shadcn/style-scope';
import {
  inputShell,
  inputShellControl,
  bindInputShellControl,
  type InputShellProps,
  type InputShellOwner,
} from '@proto.ui/prototypes-shadcn/input-shell';

const Scope = AdaptToWebComponent(styleScope);
const Shell = AdaptToWebComponent(inputShell);
const Control = AdaptToWebComponent(inputShellControl);

export function mountTitleInput(host: HTMLElement) {
  const scope = new Scope();
  const shell = new Shell();
  const control = new Control();
  const shellProps: InputShellProps = {
    styleProfile: 'inherit',
    focusIndicator: 'ring',
  };

  setElementProps(scope, { styleProfile: 'rhea' });
  setElementProps(shell, shellProps);
  setElementProps(control, {
    ariaLabel: '笔记标题',
    placeholder: '未命名笔记',
    defaultValue: '',
  });
  shell.append(control);
  scope.append(shell);
  host.append(scope);

  let current = true;
  const disposers = new Set<() => void>();
  const owner: InputShellOwner = {
    isCurrent: () => current,
    onDispose(dispose) {
      disposers.add(dispose);
      return () => {
        disposers.delete(dispose);
      };
    },
  };

  bindInputShellControl(
    owner,
    {
      instance: shell,
      setFacts(facts) {
        setElementProps(shell, { ...shellProps, ...facts });
      },
    },
    control
  );

  return () => {
    if (!current) return;
    current = false;
    try {
      for (const dispose of [...disposers]) dispose();
    } finally {
      disposers.clear();
      scope.remove();
    }
  };
}
```

关键使用约定：

- **每次同步保留已有外框属性**：因为 `setElementProps` 会整体替换属性，所以在 `setFacts` 中应合并 `shellProps` 与新状态，保留 `styleProfile` 与 `focusIndicator`。
- **交互状态始终写在控件上**：`disabled`、`readOnly` 与无障碍名称（`ariaLabel` / `labelledBy` / `describedBy`）请直接设置在内层控件上；每个外框内只放一个编辑器。如果只需要独立输入框，可直接使用 [Input](/zh-cn/ui-libraries/shadcn/input/)。

### 风格预设

两部件均默认 `styleProfile="inherit"`（优先本地显式值 → 最近的 `Style Scope` → `new-york-v4`；`new-york` 归一化为 `new-york-v4`）。切换风格预设时会保持编辑器节点、输入值、选区与焦点不变：

| 预设 | 外层 `inputShell` | 内层 `inputShellControl` |
| --- | --- | --- |
| `new-york-v4` / `new-york` | `h-9`、`rounded-md`、`border-input`、`shadow-xs`（深色模式 `bg-input/30`），键盘焦点为 `border-ring ring-3 ring-ring/50`。 | `h-9`、`px-3 py-1`，无内层边框与焦点环。 |
| `rhea` | `h-8`、`radius-2xl`、静止透明边框、`bg-input/50`、200ms 过渡，键盘焦点为 `border-ring ring-3 ring-ring/30`。 | `h-8`、`px-2.5 py-1`，透明无边框内层编辑面。 |

两种预设在视口宽度 `>= 768` 时都会将正文字号调整为小号字号，禁用透明度由内层控件统一控制，避免外框重复变暗。

### 与 Command 组合

在 [Command](/zh-cn/ui-libraries/shadcn/command/) 中，保留原有的 `commandInput`（无需替换为 `inputShellControl`），将其放入可选的 `commandInputWrapper` 与单编辑器 `inputShell` 中，通过 `bindInputShellControl` 同步状态并将 `focusIndicator` 设为 `'none'`。

### 绑定生命周期

- 在真实外框与控件实例创建后再调用 `bindInputShellControl`；每个外框或控件同一时刻最多保持一个活跃绑定。
- 返回的句柄提供 `sync()`、`replace(nextControl)` 与幂等的 `dispose()`；视图卸载或控件断开连接（`disconnect`）时会自动解绑，避免向已销毁节点写入属性。

## API

### `inputShell` 属性

| 属性             | 类型                        | 默认值      |
| ---------------- | --------------------------- | ----------- |
| `styleProfile`   | `ShadcnStyleChoice`         | `'inherit'` |
| `focusVisible`   | `boolean`（由控件状态同步） | `false`     |
| `disabled`       | `boolean`（由控件状态同步） | `false`     |
| `focusIndicator` | `'ring' \| 'none'`          | `'ring'`    |

### `inputShellControl` 属性、状态与事件

`InputShellControlProps` 为 `InputRootProps & ShadcnStyleProps`，`InputShellControlExposes` 为 `InputRootExposes`，完整保留 [Base Input](/zh-cn/ui-libraries/base/input/) 的接口：

- **受控与编辑属性**：`value`、`defaultValue`、`disabled`、`readOnly`、`placeholder`、`required`、`name`、`autoComplete`、`minLength`、`maxLength`、`inputMode`、`enterKeyHint`、`ariaLabel`、`labelledBy`、`describedBy`。
- **状态与方法**：`value`、`disabled`、`readOnly`、`focused`、`focusVisible`、`composing`，以及 `focusSelf()`、`blurSelf()`。
- **事件**：`valueChange`、`change`、`compositionStart`、`compositionUpdate`、`compositionEnd`。
