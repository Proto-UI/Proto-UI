用于重要或不可逆操作确认的模态对话框，提供明确的操作意图、安全取消焦点并阻止点击外部意外关闭。本页示例采用 **Shadcn Rhea** 风格。

## 安装

将于 `0.3.0-rc.1` 及后续版本中通过 `@proto.ui/prototypes-shadcn` 与 CLI 提供（当前可从源码工作区直接使用）。

## 用法

```tsx
import {
  ShadcnAlertDialogRoot,
  ShadcnAlertDialogTrigger,
  ShadcnAlertDialogMask,
  ShadcnAlertDialogContent,
  ShadcnAlertDialogHeader,
  ShadcnAlertDialogTitle,
  ShadcnAlertDialogDescription,
  ShadcnAlertDialogFooter,
  ShadcnAlertDialogCancel,
  ShadcnAlertDialogAction,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <ShadcnAlertDialogRoot styleProfile="rhea">
      <ShadcnAlertDialogTrigger variant="outline">Show Dialog</ShadcnAlertDialogTrigger>
      <ShadcnAlertDialogMask />
      <ShadcnAlertDialogContent>
        <ShadcnAlertDialogHeader>
          <ShadcnAlertDialogTitle>Are you absolutely sure?</ShadcnAlertDialogTitle>
          <ShadcnAlertDialogDescription>
            This action cannot be undone. This will permanently delete your account.
          </ShadcnAlertDialogDescription>
        </ShadcnAlertDialogHeader>
        <ShadcnAlertDialogFooter>
          <ShadcnAlertDialogCancel>Cancel</ShadcnAlertDialogCancel>
          <ShadcnAlertDialogAction>Continue</ShadcnAlertDialogAction>
        </ShadcnAlertDialogFooter>
      </ShadcnAlertDialogContent>
    </ShadcnAlertDialogRoot>
  );
}
```

### 组合结构

```text
AlertDialogRoot
├── AlertDialogTrigger
├── AlertDialogMask
└── AlertDialogContent
    ├── AlertDialogHeader
    │   ├── AlertDialogTitle
    │   └── AlertDialogDescription
    └── AlertDialogFooter
        ├── AlertDialogCancel
        └── AlertDialogAction
```

- **Root**：管理打开状态并固定启用 `alertdialog` 模态语义。
- **Trigger / Cancel / Action**：各自持有独立命令状态，支持 `variant`、`size`、`wrap` 与 `disabled`。点击 `Action` 会先发出 `action` 事件，再请求关闭对话框。
- **Mask / Content**：提供模态遮罩、焦点锁定与 150ms 出入场过渡；打开时优先聚焦 `Cancel`，并阻止点击外部意外关闭。
- **风格预设（`styleProfile`）**：支持 `vega`、`nova`、`maia`、`lyra`、`mira`、`luma`、`sera`、`rhea` 与 `new-york-v4`（`new-york` 兼容别名），省略时继承最近的 [Style Scope](../style-scope/)。

### 键盘与无障碍

- `Escape` 或点击 `Cancel` 请求关闭并将焦点归还触发器。
- `Tab` / `Shift + Tab` 在对话框内循环焦点。
- 打开时默认优先聚焦安全的 `Cancel` 操作；禁用的按钮不会激活。
