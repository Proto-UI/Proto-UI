Root 固定 alert 语义。Mask 管理模态遮罩；Content 约束焦点、拒绝外部点击关闭并优先聚焦 Cancel。Action 先发出 action，再请求关闭，实际操作由应用处理。Escape 与 Cancel 请求关闭。

Root 支持受控 open 和非受控 defaultOpen。禁用命令不激活。传入 open 时，最终状态仍由调用方持有，通过 openChange 接收请求后再提供新值。

组成: Root, Trigger, Content, Header, Footer, Title, Description, Cancel, Action, Mask.

当前是草稿源码实现。完整 native/GPUI、编译器、打包消费、视觉及独立验收仍待完成；本页不表示 Finf 已完成。

本页选择Rhea Content：p-6、gap-6、上限24px的家族radius-4xl、popover主题色及其ring/shadow。New York仍是未选profile时的兼容默认值，不是本页皮肤。Header/Footer是可复用被动分组。现代Trigger为headless；可复用的被动Rhea action-body组合仍是明确演示依赖，不能用页面paint猜造。响应式布局、small/media变体、原生presence及完整上游一致性仍未验收。

## API

Alert Dialog 是工作区源码，没有公开的 `proto-ui add` 目标。传入 `open` 进入受控模式。与 Dialog 不同，这个 Root 没有 `alert` 属性：原型 context 固定保持 alert 行为。
