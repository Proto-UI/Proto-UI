## 用法

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

### 部件结构

`AlertDialog` 由以下部件组合而成：`Root`、`Trigger`、`Mask`、`Content`、`Header`、`Footer`、`Title`、`Description`、`Cancel`、`Action`。

- **Root**：统一管理打开状态并固定启用 alert 模态语义。
- **Mask**：提供模态背景遮罩层。
- **Content**：将焦点限制在对话框内，阻止点击外部关闭，打开时优先将焦点移至 `Cancel`。采用 Shadcn Rhea 面板样式（`p-6`、`gap-6`、圆角上限 24px、popover 配色及阴影）。
- **Header / Footer / Title / Description**：组织对话框头部、底部操作区以及无障碍标题与描述。
- **Cancel / Action**：`Cancel` 与 `Escape` 键请求关闭；点击 `Action` 会先触发 `action` 事件，再请求关闭对话框，具体的业务或破坏性操作由应用层在事件回调中执行。禁用的按钮不会触发操作。

### 受控与非受控

- 通过 `defaultOpen` 设置初始打开状态。
- 传入 `open` 进入受控模式：监听 `openChange` 事件并将新值传回 `Root` 即可更新显示状态。

## API

传入 `open` 进入受控模式。与 `Dialog` 不同，`AlertDialog` 的 `Root` 不提供 `alert` 属性，而是始终保持 alert 确认模式。
