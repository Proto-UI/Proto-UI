## 安装

以下命令使用 0.2.0 稳定版 CLI。Vue 2.6 需要使用版本匹配的预发布版或工作区 CLI、适配器和原型包。页面预览使用工作区版本。

<InstallCommandCard command="npx @proto.ui/cli@0.2.0 add wc shadcn-tabs" manager="npm" />

将命令中的 `wc` 替换为 `react` 或 `vue`，即可生成对应框架的组件封装。

## 用法

### 风格预设与实时切换

Tabs 支持八种现代预设（`vega`、`nova`、`maia`、`lyra`、`mira`、`luma`、`sera`、`rhea`）以及独立的 `new-york-v4` 预设；传入未识别的预设 ID 会被拒绝。

在下方示例中，你可以先切换到 **Password** 标签，再点击切换 Nova、Rhea 或 New York v4。更新外层样式作用域时，Tabs 会保留当前选中项和内部节点而不会重建实例。若想在标签保持键盘焦点时切换，请在示例区域内按 **Alt+1**、**Alt+2** 或 **Alt+3**。

### 面板挂载策略

`TabsContent` 默认采用按需挂载策略：

- 仅当前激活的面板会渲染内容节点；关闭或切换离开时默认卸载内容节点（设置 `keepMounted={true}` 可保留隐藏节点）。
- 卸载非活动面板的视图时，其组件实例、内部状态与暴露接口依然保持存活；重新切回该面板时会自动恢复渲染。
- 在 Web Components 中，外层自定义元素保持挂载并在非激活时隐藏，再次激活时在同一个元素内重新渲染内容。

## API

以下属性属于 `Root`（传入 `value` 可进入受控模式）：

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'defaultValue', type: 'string', default: "''" },
    { name: 'orientation', type: "'horizontal' | 'vertical'", default: 'horizontal' },
    { name: 'activationMode', type: "'automatic' | 'manual'", default: 'automatic' },
  ]}
/>

其他部件的默认属性：

- `List`：`orientation` 默认 `'horizontal'`，`loop` 默认 `false`，`a11yLabel` 默认 `''`。
- `Trigger`：`value` 默认 `''`，`disabled` 默认 `false`。
- `Content`：`value` 默认 `''`，`keepMounted` 默认 `false`。
