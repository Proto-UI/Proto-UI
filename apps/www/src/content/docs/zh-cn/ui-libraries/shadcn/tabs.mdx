Tabs 将关联内容分组到可切换的标签面板中，同一时刻展示一个活动面板，支持水平或垂直布局、线条变体及自动/手动键盘激活。本页示例默认使用 **Shadcn Rhea** 风格。

## 安装

以下命令使用 0.2.0 稳定版 CLI。Vue 2.6 需要使用版本匹配的预发布版或工作区 CLI、适配器和原型包。页面预览使用工作区版本。

<InstallCommandCard command="npx @proto.ui/cli@0.2.0 add wc shadcn-tabs" manager="npm" />

将命令中的 `wc` 替换为 `react` 或 `vue`，即可生成对应框架的组件封装。

## 用法

```tsx
import {
  ShadcnTabsContent,
  ShadcnTabsList,
  ShadcnTabsRoot,
  ShadcnTabsTrigger,
} from '../proto-ui/components/react';
```

```tsx
<ShadcnTabsRoot styleProfile="rhea" defaultValue="account">
  <ShadcnTabsList styleProfile="rhea">
    <ShadcnTabsTrigger styleProfile="rhea" value="account">
      Account
    </ShadcnTabsTrigger>
    <ShadcnTabsTrigger styleProfile="rhea" value="password">
      Password
    </ShadcnTabsTrigger>
  </ShadcnTabsList>
  <ShadcnTabsContent styleProfile="rhea" value="account">
    Make changes to your account here.
  </ShadcnTabsContent>
  <ShadcnTabsContent styleProfile="rhea" value="password">
    Change your password here.
  </ShadcnTabsContent>
</ShadcnTabsRoot>
```

### 组件结构

```text
TabsRoot
├── TabsList
│   ├── TabsTrigger
│   └── TabsTrigger
├── TabsContent
└── TabsContent
```

- **键盘与无障碍**：水平模式支持 `ArrowLeft` / `ArrowRight`，垂直模式支持 `ArrowUp` / `ArrowDown`，配合 `Home` / `End` 在可用标签间移动焦点；禁用项会自动跳过。
- **按需挂载**：非活动 `TabsContent` 默认卸载内部视图，传入 `keepMounted={true}` 可保留隐藏节点。
