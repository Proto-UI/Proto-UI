## Style Profile 预设展示

上游 Shadcn Registry 为 Tabs 定义了多个 style profile（`vega`、`nova`、`maia`、`lyra`、`mira`、`luma`、`sera`、`rhea`、`new-york-v4`）。当前仅 `nova`、`rhea`、`new-york-v4` 完成 bounded text-default 投影（见 `internal/fixtures/shadcn-tabs-style/coverage.json`），其余 profile 尚未支持，会在运行时拒绝。

## Content mount 策略

`TabsContent` 默认采用 lazy L1 view：

- 只有当前 panel 会物化 host view。
- panel 失活时会 detach view，但保留 Proto instance、状态与 exposes。
- `keepMounted={true}` 是唯一的 view retention 选项，会让 inactive panel 继续保留完整 view。

Web Component 会保留 custom element 作为 owner，并在 internal view detached 时隐藏该 owner；重新激活后，同一个 Proto instance 会在该 owner 内物化新的 view。

## API

传入 `value` 进入受控模式。

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'defaultValue', type: 'string', default: "''" },
    { name: 'orientation', type: "'horizontal' | 'vertical'", default: 'horizontal' },
    { name: 'activationMode', type: "'automatic' | 'manual'", default: 'automatic' },
  ]}
/>

这些属性属于 Root。List 的 `orientation` 默认 `horizontal`，`loop` 默认 `false`，`a11yLabel` 默认 `''`。Trigger 的 `value` 默认 `''`，`disabled` 默认 `false`。Content 的 `value` 默认 `''`，`keepMounted` 默认 `false`。
