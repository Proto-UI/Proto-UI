## 用法

```tsx
import { ShadcnSeparatorRoot } from '../proto-ui/components/react';
```

```tsx
<ShadcnSeparatorRoot styleProfile="rhea" />
```

- `orientation` 默认为 `'horizontal'`，设为 `'vertical'` 可切换为垂直分隔线；在现代预设（如 `rhea`、`nova`）中垂直分隔线会自动沿弹性容器交叉轴拉伸（`self-stretch`），`new-york-v4` 则沿用 `h-full`。
- `decorative` 默认为 `true`，此时分隔线仅用于视觉装饰，对辅助技术隐藏；设为 `false` 时会暴露 `role="separator"` 及对应的 `aria-orientation`。
- Separator 为无内容元素，不接受子元素，也不参与键盘焦点或事件交互；外边距与间距由外层布局组合控制。
