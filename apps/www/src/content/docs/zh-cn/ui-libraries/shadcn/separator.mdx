Separator 以 1px 细线在视觉或语义上划分相邻内容区域，支持水平和垂直两种方向。本页示例使用 **Shadcn Rhea** 风格。

## 安装

<InstallCommandCard command="npx @proto.ui/cli@latest add wc shadcn-separator" manager="npm" />

将命令中的 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的组件封装。

## 用法

- `orientation` 默认为 `'horizontal'`，设为 `'vertical'` 可切换为垂直分隔线。分隔线的长度由外层容器布局决定，间距由组合方式控制。
- `decorative` 默认为 `true`，此时分隔线仅用于视觉装饰，对辅助技术隐藏；设为 `false` 时会暴露 `separator` 角色及对应的 `aria-orientation`。
- Separator 为无内容元素，不接受子元素，也不参与键盘焦点或事件交互。
