Root.value 为选项标识，inputValue 为独立编辑文本。不匹配的输入不会自动成为已选择选项。

宿主管理真实单行编辑器。箭头导航保持输入焦点；IME 组合期间不选择。过滤依据 textValue 与 keywords，忽略大小写及重音。Empty 反映真实匹配数；禁用项不可提交。open、value、inputValue 分别支持受控请求；filter=false 允许调用方提供已过滤子项。重复值选项拒绝提交。

组成: Root, Input, Content, Item, Empty, Trigger.

草稿源码；共享 Web A11y 活动后代投影、native/GPUI、编译器、消费、视觉及独立验收仍是独立要求。

## API

Combobox 是工作区源码，没有公开的 `proto-ui add` 目标。传入 `value`、`inputValue` 或 `open` 会使对应事实进入受控模式。它复用共享搜索家族的属性。`defaultOpen` 为 `false`。

这些属性属于 Root。Input 的 `placeholder`、`a11yLabel`、`name` 默认 `''`。Content 默认 `side="bottom"`、`align="start"`、`sideOffset` `4`、`collisionPadding` `8`。Item 的 `value`、`textValue`、`keywords` 默认 `''`，`disabled` 默认 `false`。Trigger 的 `disabled` 默认 `false`。
