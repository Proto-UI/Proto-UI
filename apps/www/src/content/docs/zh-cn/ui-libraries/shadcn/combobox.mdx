## 用法

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

### 部件结构

由 `Root`、`Input`、`Content`、`Item`、`Empty` 与 `Trigger` 组合而成：

- `Root` 的 `value` 保存已选中的选项键，`inputValue` 保存当前输入框内的查询文本；未匹配到有效选项的自由文本不会被自动提交为选中值。
- 如需允许直接提交自由文本，请使用 [Autocomplete](../autocomplete/)。

### 过滤与交互行为

- **内置过滤**：默认按 `textValue` 与 `keywords` 过滤，忽略大小写及重音符号。设置 `filter={false}` 可交由应用层自行过滤列表项。
- **空状态与禁用项**：`Empty` 根据实时匹配数显隐；禁用项及重复 `value` 的选项不可提交。
- **键盘与输入法**：使用方向键在候选项中移动时，焦点始终停留在单行输入框内；输入法（IME）组合输入期间不会触发选中。
- **受控模式**：`open`、`value` 与 `inputValue` 可各自独立受控，传入对应属性即可切换为受控状态。

## API

传入 `value`、`inputValue` 或 `open` 会使对应状态进入受控模式。

以上属性属于 `Root`。其他部件属性默认值：

- **Input**：`placeholder`、`a11yLabel`、`name` 均默认为 `''`。
- **Content**：`side="bottom"`、`align="start"`、`sideOffset={4}`、`collisionPadding={8}`。
- **Item**：`value`、`textValue`、`keywords` 均默认为 `''`，`disabled` 默认为 `false`。
- **Trigger**：`disabled` 默认为 `false`。
