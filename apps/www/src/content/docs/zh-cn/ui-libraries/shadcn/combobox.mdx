结合单行搜索输入框与下拉选项列表的组合选择框，将已选选项标识（`value`）与当前输入查询文本（`inputValue`）分离管理。本页示例采用 **Shadcn Rhea** 风格。

## 安装

当前 Combobox 仅在源码工作区（`@proto.ui/prototypes-shadcn/combobox`）提供，尚未发布至 `0.2.0` 稳定版 CLI 注册表。

## 用法

```tsx
import {
  comboboxRoot,
  comboboxInput,
  comboboxTrigger,
  comboboxContent,
  comboboxItem,
  comboboxEmpty,
} from '@proto.ui/prototypes-shadcn/combobox';
```

```html
<shadcn-combobox-root a11y-label="Framework">
  <shadcn-combobox-input placeholder="Select a framework..."></shadcn-combobox-input>
  <shadcn-combobox-trigger>▾</shadcn-combobox-trigger>
  <shadcn-combobox-content>
    <shadcn-combobox-item value="next.js" text-value="Next.js">Next.js</shadcn-combobox-item>
    <shadcn-combobox-item value="sveltekit" text-value="SvelteKit">SvelteKit</shadcn-combobox-item>
    <shadcn-combobox-item value="astro" text-value="Astro">Astro</shadcn-combobox-item>
    <shadcn-combobox-empty>No frameworks found.</shadcn-combobox-empty>
  </shadcn-combobox-content>
</shadcn-combobox-root>
```

### 部件结构

```text
ComboboxRoot
├── ComboboxInput
├── ComboboxTrigger (optional)
└── ComboboxContent
    ├── ComboboxItem
    └── ComboboxEmpty (optional)
```

- `Root` 的 `value` 保存已选中的选项键，`inputValue` 保存输入框内的实时查询文本；未匹配到有效选项的自由文本不会被自动提交为选中值。
- 如需允许直接提交自由文本，请使用 [Autocomplete](../autocomplete/)。
- **内置过滤**：默认按 `textValue` 与 `keywords` 过滤，忽略大小写及重音符号；设置 `filter={false}` 可交由应用层自行过滤。
- **键盘与输入法**：使用方向键在候选项中移动时，焦点始终停留在单行输入框内；输入法（IME）组合输入期间不会触发选中。
