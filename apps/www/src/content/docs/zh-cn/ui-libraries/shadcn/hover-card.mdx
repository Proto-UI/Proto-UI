把 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的本地组件封装。

## 用法

`Hover Card` 由 `Root`、`Trigger` 与 `Content` 三个部件组成：

- **Root**：统一管理打开状态（受控 `open` 或非受控 `defaultOpen`）以及 `openDelay` / `closeDelay` 延迟时间。
- **Trigger**：悬停或聚焦时向 `Root` 发起打开请求；支持独立的 `disabled` 属性。
- **Content**：将鼠标移入卡片内部时会保持卡片打开，支持方位、对齐、偏移及碰撞检测配置。

## API

传入 `open` 进入受控模式。`openDelay` 与 `closeDelay` 须为非负有限数值，非法值会自动回退到默认值。

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'open', type: 'boolean | undefined', default: '非受控' },
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'openDelay', type: 'number', default: '700' },
    { name: 'closeDelay', type: 'number', default: '300' },
    { name: 'side', type: "'top' | 'right' | 'bottom' | 'left'", default: 'bottom' },
    { name: 'align', type: "'start' | 'center' | 'end'", default: 'center' },
    { name: 'sideOffset', type: 'number', default: '4' },
    { name: 'alignOffset', type: 'number', default: '0' },
    { name: 'avoidCollisions', type: 'boolean', default: 'true' },
    { name: 'collisionPadding', type: 'number', default: '0' },
  ]}
/>

- `open`、`defaultOpen`、`disabled`、`openDelay` 与 `closeDelay` 属于 `Root`；`Root` 暴露 `open` 状态、`openHoverCard` / `close` / `toggle` 方法以及 `openChange` 事件。
- `side` 至 `collisionPadding` 属于 `Content`。
- `Trigger` 仅提供 `disabled` 属性（默认 `false`）。
