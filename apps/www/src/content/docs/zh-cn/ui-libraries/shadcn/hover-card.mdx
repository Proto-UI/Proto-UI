在用户悬停或聚焦触发元素时延迟展示预览信息的浮层卡片，适合账号名片、链接摘要等补充信息场景。本页示例采用 **Shadcn Rhea** 风格。

## 预览

悬停或聚焦 `@proto-ui` 150ms 后展开浮层，指针移入卡片内部时会保持打开，移开 200ms 后自动收起。

## 安装

以下命令使用 0.2.0 稳定版 CLI。Vue 2.6 需要使用版本匹配的预发布版或工作区 CLI、适配器和原型包。页面预览使用工作区版本。

把 `wc` 替换为 `react` 或 `vue`，即可生成对应框架的本地组件封装。

## 用法

```tsx
import {
  ShadcnHoverCardRoot,
  ShadcnHoverCardTrigger,
  ShadcnHoverCardContent,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <ShadcnHoverCardRoot openDelay={150} closeDelay={200}>
      <ShadcnHoverCardTrigger>@proto-ui</ShadcnHoverCardTrigger>
      <ShadcnHoverCardContent side="bottom" align="center">
        Host-neutral interaction protocols for adaptable UI components.
      </ShadcnHoverCardContent>
    </ShadcnHoverCardRoot>
  );
}
```

### 结构组成

```text
ShadcnHoverCardRoot
├── ShadcnHoverCardTrigger
└── ShadcnHoverCardContent
```

- **Root**：管理打开状态（受控 `open` 或非受控 `defaultOpen`）、`openDelay` / `closeDelay` 时序以及全局 `disabled`。
- **Trigger**：响应指针悬停与键盘聚焦并向 `Root` 发起打开请求，不抢占链接或按钮的点击激活语义。
- **Content**：通过 Portal 渲染定位浮层，支持四个方位、对齐、偏移与视口碰撞翻转，指针移入内容区时保持展开。

## API

### Root

传入 `open` 进入受控模式。`openDelay` 与 `closeDelay` 须为非负有限数值，非法值会自动回退到默认值。
