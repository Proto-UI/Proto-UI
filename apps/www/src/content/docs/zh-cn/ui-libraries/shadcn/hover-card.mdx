本页常规演示显式采用 **Shadcn Rhea** 外观，示例代码保持一致；这不修改公共组件的兼容默认值，也不代表全部浏览器、原生宿主和视觉验收已完成。Surface/Text 等中性原子仍保留各自公开语义，外观主题由消费组合提供。

Base Hover Card 持有 open。Root 接受受控 `open` 或非受控 `defaultOpen`，以及 `openDelay` 与 `closeDelay`。Trigger 的 hover/focus 和 Content 的 hover 只提交请求，不能绕过这个 owner。Content 另有 `side`、`align` 和下表的数值偏移。Arrow 与 `forceMount` 不是这个 surface 的属性。

演示在 150ms 后打开 `@proto-ui`，300ms 后关闭。Content 为 `side="bottom"`、`align="center"`。

## 安装

<InstallCommandCard command="npx @proto.ui/cli@latest add wc shadcn-hover-card" manager="npm" />

把 `wc` 换成 `react`、`vue` 或 `vue2`，即可生成对应宿主的 facade。

## API

传入 `open` 进入受控模式。延时必须是有限数且不小于 0，否则回落到默认值。

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'open', type: 'boolean | undefined', default: '非受控' },
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'openDelay', type: 'number', default: '700' },
    { name: 'closeDelay', type: 'number', default: '300' },
    { name: 'side', type: "'top' | 'right' | 'bottom' | 'left'", default: 'bottom' },
    { name: 'align', type: "'start' | 'center' | 'end'", default: 'center' },
    { name: 'sideOffset', type: 'number', default: '4' },
    { name: 'alignOffset', type: 'number', default: '0' },
    { name: 'avoidCollisions', type: 'boolean', default: 'true' },
    { name: 'collisionPadding', type: 'number', default: '0' },
  ]}
/>

`side` 到 `collisionPadding` 属于 Content。Trigger 只增加 `disabled`，默认 `false`。Root 暴露 `open`、`openHoverCard`、`close`、`toggle` 和 `openChange`。
