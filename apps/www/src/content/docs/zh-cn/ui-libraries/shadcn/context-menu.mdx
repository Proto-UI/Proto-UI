在触发区域通过右键点击、触摸/手写笔长按（600 ms）或键盘快捷键（`ContextMenu` / `Shift+F10`）唤起的上下文命令菜单，内置键盘导航、首字母快速跳转与碰撞感知定位。本页示例采用 **Shadcn Rhea** 风格预设。

将于 `0.3.0-rc.1` 及后续版本中提供（当前可在源码工作区预览）。

## 用法

```tsx
import {
  ShadcnContextMenuContent,
  ShadcnContextMenuItem,
  ShadcnContextMenuRoot,
  ShadcnContextMenuTrigger,
} from '@/components/proto-ui';

export function Example() {
  return (
    <ShadcnContextMenuRoot styleProfile="rhea">
      <ShadcnContextMenuTrigger className="flex h-36 w-72 items-center justify-center rounded-xl border border-dashed text-sm">
        Right click here
      </ShadcnContextMenuTrigger>
      <ShadcnContextMenuContent>
        <ShadcnContextMenuItem value="profile">Profile</ShadcnContextMenuItem>
        <ShadcnContextMenuItem value="billing">Billing</ShadcnContextMenuItem>
        <ShadcnContextMenuItem value="team">Team</ShadcnContextMenuItem>
        <ShadcnContextMenuItem value="subscription">Subscription</ShadcnContextMenuItem>
      </ShadcnContextMenuContent>
    </ShadcnContextMenuRoot>
  );
}
```

### 部件结构

```text
ContextMenuRoot
├── ContextMenuTrigger
└── ContextMenuContent
    ├── ContextMenuItem
    └── ContextMenuItem
```

- **触发与定位**：右键点击或 600 ms 触摸/手写笔长按（超过移动容差、抬起或取消时中止）会锚定在输入点；按下 `ContextMenu` / `Shift+F10` 或调用 `openContextMenu()` 时锚定在触发区域。普通左键点击与滚动不受影响。
- **受控模式与焦点恢复**：传入 `open` 进入受控模式，启用态下的触发器会抑制浏览器原生右键菜单并将打开请求交给外部处理。按 `Escape` 或选中命令关闭菜单时，焦点自动恢复至触发区域。
