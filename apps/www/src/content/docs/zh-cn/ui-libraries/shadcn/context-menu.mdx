## 用法

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

### 部件结构

由 `Root`、`Trigger`、`Content` 与 `Item` 组合而成：

- **Trigger**：响应右键菜单事件、`ContextMenu` / `Shift+F10` 快捷键以及持续 600 ms 的触摸/手写笔长按（移动、抬起或取消会中止长按，普通左键点击与滚动不受影响）。
- **Content**：通过右键或长按打开时自动定位在输入点；通过键盘快捷键或编程方式 `openContextMenu` 打开时定位在触发区域。支持方向键导航、字符快速跳转与边界碰撞翻转。
- **Item**：菜单命令项，激活后默认自动关闭菜单（可通过 `closeOnItemCommit={false}` 保持打开）。

### 受控模式与焦点恢复

- 传入 `open` 进入受控模式：触发区域会抑制浏览器原生右键菜单并向外部发出打开请求，外部可自行决定是否将 `open` 更新为 `true`。
- 按 `Escape` 或选中命令关闭菜单时，焦点会自动回到触发区域。

## API

传入 `open` 进入受控模式。

  headers={{ name: '属性', type: '类型', default: '默认值' }}

    },
    { name: 'openEntryValue', type: 'string', default: "''" },
  ]}

以上属性属于 `Root`。`Content` 默认配置为 `side="bottom"`、`align="start"`、`sideOffset={0}`、`alignOffset={0}`、`avoidCollisions={true}`、`collisionPadding={0}`、`excludeAnchorTranslation={false}`。
