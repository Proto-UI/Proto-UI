Radio Group 用于在一组互斥选项中进行单项选择，提供完整的 `radiogroup` / `radio` 无障碍语义、键盘方向键导航以及焦点环和禁用态样式。本页示例使用 **Shadcn Rhea** 风格。

## 安装

此组件由工作区源码提供。请在应用中安装同一工作区提交构建的 CLI、Shadcn 原型包与目标适配器，用该 CLI 初始化项目，再运行本地命令生成组件封装。

<InstallCommandCard command="npm exec -- proto-ui add wc shadcn-radio-group" manager="npm" />

将命令中的 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的组件封装。

## 用法

从 `@proto.ui/prototypes-shadcn/radio-group`（或包根）导入 `shadcnRadioGroupRoot`、`shadcnRadioGroupItem` 和 `shadcnRadioGroupIndicator`，并适配到目标运行时：

| 部件 | 属性 | 职责 |
| --- | --- | --- |
| `Root` | `value?`、`defaultValue?`、`disabled?`、`readOnly?`、`a11yLabel?` | 统一管理当前选中值与选项集合。 |
| `Item` | 必填 `value`、可选 `disabled?` | 表示单个选项，请求选值并派生选中与禁用状态。 |
| `Indicator` | 无 | 放置在 `Item` 内部，用于渲染选中圆点（可省略或按需自定义）。 |

### 标签关联与可访问性

- 为 `Root` 设置清晰的 `a11yLabel`，为每个 `Item` 提供同组内唯一且非空的 `value`。
- 搭配 `@proto.ui/prototypes-shadcn/label` 中的 `labelRoot` 时，可通过 `createControlLabelRef()` 创建共享引用并绑定到双方的 `InstanceAssociations.controlLabel`，让可见标签直接作为选项的无障碍名称并支持点击激活。若仅用于命名而不触发选择，可在 `Label` 上设置 `activation={false}`。

### 受控与非受控

- 非受控模式下，`Root` 通过 `defaultValue` 初始化，并在选值变化时触发 `valueChange`。
- 传入 `value` 后进入受控模式，`Root` 仅发出变更请求，由外部决定下一次 `value`。空值或未匹配项的值会被保留，已选中的选项变为禁用后仍可保持选中状态。
- 设置 `readOnly` 会保留键盘焦点漫游能力，同时阻止更改选中值；`disabled` 则会禁用交互并移出焦点序列。

### 键盘交互

- 按 `Tab` 进入单选组时，焦点优先落在当前已选中且启用的 `Item` 上。
- 方向键在启用项之间循环移动并自动选中，`Home` / `End` 跳转到首尾启用项，禁用项会被自动跳过。
- `Space` 可选中当前聚焦项，`Enter` 不触发选择。

### 表单组合

普通的 `Root` 不会自动注册到表单。在 `FormField` 中使用时，请使用 `@proto.ui/prototypes-shadcn/field` 导出的 `fieldRadioGroup`，即可自动衔接必填校验、Label/Description/Error 关联与重置（`resetValue()` 请求恢复实例初始值）。更多用法见 [Form 示例](../form/)。

## API

以下属性属于 `Root`（传入 `value` 可进入受控模式）：

其他部件属性：

- `Item`：`value`（必填），`disabled`（默认 `false`）。
- `Indicator`：无额外属性。
