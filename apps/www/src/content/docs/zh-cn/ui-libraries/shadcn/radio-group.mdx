Radio Group 用于在一组互斥选项中进行单项选择，提供完整的 `radiogroup` / `radio` 无障碍语义、方向键漫游焦点以及焦点环和禁用态样式。本页示例使用 **Shadcn Rhea** 风格。

## 安装

此组件由工作区源码提供。请在应用中安装同一工作区提交构建的 CLI、Shadcn 原型包与目标适配器，用该 CLI 初始化项目，再运行本地命令生成组件封装。

<InstallCommandCard command="npm exec -- proto-ui add wc shadcn-radio-group" manager="npm" />

将命令中的 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的组件封装。

## 用法

```tsx
import {
  ShadcnLabelRoot,
  ShadcnRadioGroupIndicator,
  ShadcnRadioGroupItem,
  ShadcnRadioGroupRoot,
} from '../proto-ui/components/react';

export function RadioGroupUsage() {
  return (
    <ShadcnRadioGroupRoot styleProfile="rhea" defaultValue="option-one" a11yLabel="Options">
      <div className="flex items-center gap-3">
        <ShadcnRadioGroupItem styleProfile="rhea" value="option-one">
          <ShadcnRadioGroupIndicator styleProfile="rhea" />
        </ShadcnRadioGroupItem>
        <ShadcnLabelRoot styleProfile="rhea">Option One</ShadcnLabelRoot>
      </div>
      <div className="flex items-center gap-3">
        <ShadcnRadioGroupItem styleProfile="rhea" value="option-two">
          <ShadcnRadioGroupIndicator styleProfile="rhea" />
        </ShadcnRadioGroupItem>
        <ShadcnLabelRoot styleProfile="rhea">Option Two</ShadcnLabelRoot>
      </div>
    </ShadcnRadioGroupRoot>
  );
}
```

### 组件结构

```text
RadioGroupRoot
├── RadioGroupItem
│   └── RadioGroupIndicator
└── RadioGroupItem
    └── RadioGroupIndicator
```

- **标签关联**：为 `Root` 设置 `a11yLabel`，为每个 `Item` 提供同组内唯一且非空的 `value`。搭配 `shadcn-label-root` 时通过 `createControlLabelRef()` 绑定 `InstanceAssociations.controlLabel`，即可让可见标签直接命名选项并支持点击选中（仅命名而不激活时在 `Label` 上设 `activation={false}`）。
- **受控与非受控**：传入 `defaultValue` 为非受控模式；传入 `value` 进入受控模式，`Root` 仅发出 `valueChange` 变更请求。`readOnly` 保留方向键漫游但阻止修改选值，`disabled` 则同时移出焦点序列。
- **键盘交互**：`Tab` 优先聚焦当前已选中且启用的 `Item`；方向键在启用项间循环移动并自动选中；`Home` / `End` 跳到首尾启用项；`Space` 选中当前聚焦项，`Enter` 不触发选择。
- **表单组合**：在 `FormField` 中请使用 `@proto.ui/prototypes-shadcn/field` 导出的 `fieldRadioGroup`，自动衔接必填校验、Label / Description / Error 关联与 `resetValue()`。详见 [Form 示例](../form/)。

### Indicator

`Indicator` 无额外属性，从最近的 `Item` 派生 `checked` 与 `disabled` 状态并呈现选中圆点。

### 事件与暴露方法

- **Root 事件**：`valueChange`（`{ value: string }`）
- **Item 事件**：`select`（`{ value: string }`）
- **Root 方法**：`requestValue(value)`、`resetValue()`、`focusFirst()`、`focusLast()`、`focusNext()`、`focusPrev()`、`focusSelected()`、`focusSelf()`
