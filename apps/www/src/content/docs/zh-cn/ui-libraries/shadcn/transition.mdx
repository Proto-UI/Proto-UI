Transition 为传入的子元素提供透明的五阶段显隐状态机（`closed → preparing → entering → entered → leaving`），将端点透明度绑定到感知阶段，并把具体动效曲线交给应用或宿主样式表自由控制。本页示例使用 **Shadcn Rhea** 风格。

## 预览

使用下方的命令按钮手动驱动 `enter`、`leave` 与 `complete`，观察五个阶段状态与挂载（`Mounted` / `Detached`）的实时变化；预览卡片放置在固定高度舞台中，离场卸载不会引起布局跳动。

## 安装

当前仅在源码工作区提供，将于 `0.3.0-rc.1` 及后续版本中提供，也尚未加入 `@proto.ui/cli` 安装目标。可直接从工作区源码导入：

```ts
import { transition } from '@proto.ui/prototypes-shadcn/transition';
```

## 用法

```tsx
import { useState } from 'react';
import { ShadcnButton, ShadcnStyleScope, ShadcnTransition } from '../proto-ui/components/react';

export function NotificationTransition() {
  const [open, setOpen] = useState(true);

  return (
    <ShadcnStyleScope styleProfile="rhea" className="contents">
      <ShadcnTransition
        open={open}
        appear
        className="block transition-opacity duration-300 ease-out motion-reduce:transition-none"
      >
        <div className="rounded-lg border border-border bg-card p-5 text-card-foreground shadow-sm">
          Workspace synced
        </div>
      </ShadcnTransition>
      <ShadcnButton styleProfile="rhea" onClick={() => setOpen((value) => !value)}>
        Toggle
      </ShadcnButton>
    </ShadcnStyleScope>
  );
}
```

- **端点透明度投影**：`shadcn-transition` 在 `entering` 与 `entered` 阶段输出 `opacity-100`，在 `closed`、`preparing` 与 `leaving` 阶段输出 `opacity-0`，同时保持子内容插槽透明。配合 CSS `transition-opacity` 或 `[data-transition-state]` 选择器即可实现平滑过渡。
- **五个阶段与冷准备**：默认路径为 `closed → entering → entered → leaving → closed`；当高层组合启用 `coldEntryPreparation` 并调用 `capturePreparation()` 时，会在进入前先经过 `preparing` 阶段以完成布局或测量准备。
- **减少动态效果（Reduced Motion）**：当宿主环境启用 `prefers-reduced-motion: reduce` 时，自动兜底延时自动缩短为 `0ms`，同时完整保留阶段顺序、边界事件与视图卸载时序；建议在应用样式中配合 `motion-reduce:transition-none`。
- **底层语义**：所有阶段排序、资源保留与打断语义均继承自 [Base Transition](/zh-cn/ui-libraries/base/transition/)。

## 示例

### 受控模式与 `transitionend` 同步

传入 `open` 进入受控模式。默认在 `enterDuration` / `leaveDuration` 到期后自动推进状态，也可以监听宿主 `transitionend` 并调用 `controls.complete()` 与真实动画精准同步。

### 中途打断策略（`interrupt`）

对比 `'reverse'`（立即反向）、`'wait'`（等待当前阶段结束后切换至最新目标）与 `'immediate'`（立即丢弃当前阶段并切入新阶段）在中途打断时的表现。

<PrototypePreviewer
  demoId="demo-shadcn-transition-interrupt"
  initialRuntime="wc"
  runtimes={['wc', 'react', 'vue', 'vue2']}
/>

### 生命周期事件与 `appear`

将 `appear` 设为 `true` 可在初次挂载时执行入场过渡；监听 `beforeEnter`、`afterEnter`、`beforeLeave` 与 `afterLeave` 即可在每个边界时机同步副作用，并读取实时的 `isPresent` 状态。
