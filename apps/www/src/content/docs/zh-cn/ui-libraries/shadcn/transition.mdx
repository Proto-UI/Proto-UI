覆盖作者内容的透明相位机 presence，不发明动效。

该投射是透明的：作者槽位的 presence 由精确的 Base 相位机（`closed → preparing → entering → entered → leaving`）治理，相位通过 `transitionState` expose 与 `isPresent` 可观察，`beforeEnter`/`afterEnter`/`beforeLeave`/`afterLeave` 事件标记边界。`enter`/`leave`/`complete` 命令（也可经 `controls` 到达）驱动状态机；`complete` 将 `entering → entered` 或 `leaving → closed` 推进。`open`（受控）或 `defaultOpen: false` 决定初始 presence；`appear`（默认 `false`）允许首次挂载即进入；`enterDuration`（默认 300）、`leaveDuration`（默认 200）与 `interrupt: 'reverse' | 'wait' | 'immediate'`（默认 `reverse`）塑造每次尝试。该投射不添加宿主动画引擎或 Shadcn 动效外观——视觉动效仍是应用关注点。

组成: Transition.

## API

传入 `open` 进入受控模式。

相位机是 `closed → preparing → entering → entered → leaving`。`complete` 把 `entering` 推进到 `entered`，或把 `leaving` 推进到 `closed`。
