## 安装

此组件由工作区源码提供。请在应用中安装同一工作区提交构建的 CLI、Shadcn 原型包与目标适配器，用该 CLI 初始化项目，再运行本地命令生成组件封装。

<InstallCommandCard command="npm exec -- proto-ui add wc shadcn-accordion" manager="npm" />

把 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的本地组件封装。

也可以直接从 `@proto.ui/prototypes-shadcn/accordion` 导入 `accordionRoot`、`accordionItem`、`accordionHeading`、`accordionTrigger` 与 `accordionContent`。

## 用法

```tsx
import {
  ShadcnAccordionRoot,
  ShadcnAccordionItem,
  ShadcnAccordionHeading,
  ShadcnAccordionTrigger,
  ShadcnAccordionContent,
} from '@/components/proto-ui/react';

export function AccordionUsage() {
  return (
    <ShadcnAccordionRoot defaultOpenItems={['item-1']}>
      <ShadcnAccordionItem value="item-1">
        <ShadcnAccordionHeading level={3}>
          <ShadcnAccordionTrigger>Is it accessible?</ShadcnAccordionTrigger>
        </ShadcnAccordionHeading>
        <ShadcnAccordionContent>
          Yes. It adheres to the WAI-ARIA Accordion design pattern.
        </ShadcnAccordionContent>
      </ShadcnAccordionItem>
    </ShadcnAccordionRoot>
  );
}
```

### 部件结构

```text
AccordionRoot
└── AccordionItem
    ├── AccordionHeading
    │   └── AccordionTrigger
    └── AccordionContent
```

- **Root**：统一管理当前展开的项集合、展开模式与方向键导航轴向。嵌套的 `Root` 各自拥有独立状态。
- **Item**：代表单个折叠项，必须提供唯一、稳定、非空的 `value`。
- **Heading**：声明标题语义层级（`level` 1–6，默认 `3`），内部仅放控制当前项的 `Trigger`；如需常驻辅助按钮，请放在 `Heading` 旁。
- **Trigger**：从 `Item` 与 `Root` 派生展开、禁用和防收起状态，自动维护 `aria-expanded`、`aria-disabled` 与 `aria-controls`。
- **Content**：存放展开后显示的内容。关闭时默认卸载内容节点；设置 `keepMounted` 可保留隐藏节点，设置 `region` 可按需声明为地标区域。

### 键盘交互与无障碍

- `Tab` / `Shift + Tab`：按自然文档顺序在各启用的 `Trigger` 与展开内容区的可聚焦元素间移动。
- `Enter` / `Space`：切换当前项的展开状态。
- `ArrowUp` / `ArrowDown`（纵向）或 `ArrowLeft` / `ArrowRight`（横向，RTL 自动反转）与 `Home` / `End`：在已启用的标题间移动焦点，不改变展开状态；`loop={false}` 时在首尾停住。
- 禁用的标题会在方向键导航中被跳过；当 `allowEmpty={false}` 阻止关闭最后一个展开项时，该标题仍可聚焦并通过 `aria-disabled` 提示不可收起。

### 方法与事件（Root）

- `getOpenItems()`：返回当前展开项 `value` 数组的副本。
- `openCount`：当前已展开项数量（包含尚未挂载对应 `Item` 的保留键）。
- `requestOpen(value, open, reason?)`：以编程方式请求展开或收起指定项。
- `openChange`：状态请求事件，负载为 `{ openItems, value, open, reason }`（`reason` 为 `'pointer'`、`'keyboard'` 或 `'programmatic'`）。
