## 安装

此组件由工作区源码提供。请在应用中安装同一工作区提交构建的 CLI、Shadcn 原型包与目标适配器，用该 CLI 初始化项目，再运行本地命令生成组件封装。

<InstallCommandCard command="npm exec -- proto-ui add wc shadcn-accordion" manager="npm" />

把 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的本地组件封装。

也可以直接从 `@proto.ui/prototypes-shadcn/accordion` 导入 `accordionRoot`、`accordionItem`、`accordionHeading`、`accordionTrigger` 与 `accordionContent`。

## 用法

### 部件结构

按 `Root` → `Item` → `Heading` → `Trigger` 组合，并将 `Content` 与 `Heading` 并列放置：

- **Root**：统一管理当前展开的项集合与键盘导航方向。嵌套的 `Root` 各自拥有独立状态。
- **Item**：代表单个折叠项，必须提供唯一、稳定、非空的 `value`。
- **Heading**：声明标题语义与层级（`level` 1–6，默认 `3`），内部只放控制当前项的 `Trigger`；如需常驻的辅助操作按钮，请放在 `Heading` 旁。
- **Trigger**：从 `Item` 与 `Root` 派生展开与禁用状态，自动关联对应的 `Content`。
- **Content**：存放展开后显示的内容。关闭时默认卸载内容节点；设置 `keepMounted` 可保留隐藏节点。

### 受控与非受控

- **非受控**：通过 `defaultOpenItems` 设置初始展开项（仅在首次挂载时生效）。
- **受控**：传入 `openItems` 将展开状态交由外部管理。组件在用户交互时触发 `openChange` 事件（负载为 `{ openItems, value, open, reason }`，其中 `reason` 为 `'pointer'`、`'keyboard'` 或 `'programmatic'`），应用层接收后把新的 `openItems` 传回 `Root` 即可完成更新。

状态变更规则：

- 传入重复的 `value` 会自动去重；`mode="single"` 下取首个唯一键。
- 尚未挂载对应 `Item` 的键会先保留，待该 `Item` 挂载后自动展开；对不存在的键发起 `requestOpen` 请求会被忽略。
- 非受控模式下移除已展开的 `Item` 会自动清理该键；`allowEmpty={false}` 阻止关闭最后一个展开项。

### 键盘交互与无障碍

- `Tab` / `Shift + Tab`：按自然文档顺序在各启用的 `Trigger` 与内容区可聚焦元素间移动。
- `Enter` / `Space`：切换当前项的展开状态。
- `ArrowUp` / `ArrowDown`（纵向）或 `ArrowLeft` / `ArrowRight`（横向，RTL 自动反转）：在已启用的标题间移动焦点，不改变展开状态；`loop={false}` 时在首尾停住。
- `Home` / `End`：跳转到首个或最后一个已启用的标题。
- 禁用的标题会在方向键导航中被跳过；当 `allowEmpty={false}` 阻止关闭最后一项时，该标题仍可聚焦并通过 `aria-disabled` 提示不可收起。
- `Content` 默认由对应 `Trigger` 命名；设置 `region={true}` 可显式声明为地标区域（大量同时展开项时建议保持默认 `false`）。

### 动画与布局

- 如需为展开/收起添加过渡动画，可在消费层结合 `keepMounted` 与 `open` 状态自行控制，避免破坏开关状态同步。
- 样式内置长标题自动换行与容器收缩适配，水平溢出内容会限制在面板内部。

### 其他部件属性

- **Item**：`value: string`（必填，唯一非空键）、`disabled?: boolean`（默认 `false`）。
- **Heading**：`level?: 1 | 2 | 3 | 4 | 5 | 6`（默认 `3`）。
- **Trigger**：无独立属性，状态自动从 `Item` 与 `Root` 派生。
- **Content**：`keepMounted?: boolean`（默认 `false`，关闭时保留隐藏节点）、`region?: boolean`（默认 `false`，显式添加 landmark 角色）。

### 方法与事件（Root）

- `getOpenItems()`：返回当前展开项 `value` 数组的副本。
- `openCount`：当前已展开项数量（包含尚未挂载对应 `Item` 的保留键）。
- `requestOpen(value, open, reason?)`：以编程方式请求展开或收起指定项。
- `openChange`：状态请求事件，负载为 `{ openItems, value, open, reason }`。
