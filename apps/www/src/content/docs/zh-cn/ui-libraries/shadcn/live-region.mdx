用于向辅助技术播报状态更新或紧急提示的 ARIA live region 组件，根据 `politeness` 与 `atomic` 自动配置无障碍角色与播报级别。本页示例采用 **Shadcn Rhea** 风格。

## 用法

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

`Live Region` 由单一 `Root` 部件组成，传入的子元素文本即为播报内容——更新子元素即可触发播报：

- `politeness="polite"`（默认）：设置 `role="status"` 与 `aria-live="polite"`，适用于非打断性的状态提示。
- `politeness="assertive"`：设置 `role="alert"` 与 `aria-live="assertive"`，适用于需要立即播报的重要提醒。
- `atomic={true}`（默认）：设置 `aria-atomic="true"`，使内容变化时整段播报而非仅播报差异部分。

组件保持纯语义展示，不增加焦点、事件或额外暴露方法，常与 [Async Region](../async-region/) 或表单校验错误搭配使用。
