区域由两个 prop 推导 `role`、`aria-live` 与 `aria-atomic`：`politeness: 'polite'`（默认）投射 `role=status` 与 `aria-live=polite`，`politeness: 'assertive'` 投射 `role=alert` 与 `aria-live=assertive`；`atomic`（默认 `true`）投射 `aria-atomic`。作者子内容即公告负载——修改它是投递更新的方式。区域本身不声明焦点、事件、命令、选择或 accessible name 覆盖通道，exposes 表面为空；也没有隐式队列或通知传输。

组成: Root.
