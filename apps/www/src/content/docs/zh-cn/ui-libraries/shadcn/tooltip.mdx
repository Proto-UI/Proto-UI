Tooltip 在指针悬停或键盘聚焦触发元素时展示简短的补充说明，并支持同组内多个提示之间的延迟协调。本页示例使用 **Shadcn Rhea** 风格。

## 安装

在应用中安装由同一源码版本构建的 `@proto.ui/cli`、`@proto.ui/prototypes-shadcn` 和目标宿主适配器（`@proto.ui/adapter-web-component`、`@proto.ui/adapter-react`、 `@proto.ui/adapter-vue` 或 `@proto.ui/adapter-vue2`；Vue 2 要求 Vue `>=2.6.0 <2.7`）。本地源码安装请使用仓库的 [仅打包流程](https://github.com/Proto-UI/Proto-UI/blob/main/scripts/release/publish.mjs) 和[干净消费者安装流程](https://github.com/Proto-UI/Proto-UI/blob/main/scripts/release/consumer-smoke-cli.mjs)。完成初始化后，使用应用内的 CLI。

<InstallCommandCard command="npm exec -- proto-ui add wc shadcn-tooltip" manager="npm" />

目标宿主也可以使用 `react`、`vue` 或 `vue2`。请在应用入口引入一次生成的 `proto-ui-style.css`。

## 用法

```tsx
import {
  ShadcnTooltipGroup,
  ShadcnTooltipRoot,
  ShadcnTooltipTrigger,
  ShadcnTooltipContent,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <ShadcnTooltipGroup>
      <ShadcnTooltipRoot>
        <ShadcnTooltipTrigger styleProfile="rhea">Hover</ShadcnTooltipTrigger>
        <ShadcnTooltipContent side="top" styleProfile="rhea">
          Add to library
        </ShadcnTooltipContent>
      </ShadcnTooltipRoot>
    </ShadcnTooltipGroup>
  );
}
```

### 组件结构

```text
TooltipGroup (可选)
└── TooltipRoot
    ├── TooltipTrigger
    └── TooltipContent
```

- `Group` 协调同组多个 Tooltip 的显示延迟：冷启动悬停默认 `700ms` 后打开，关闭延迟 `100ms`；在 `300ms` 跳过窗口内移动到相邻触发器时立即切换，且同组最多保持一个提示打开。
- 通过键盘 `Tab` 聚焦 `Trigger` 时立即显示提示，按 `Escape` 关闭并保持焦点在触发器上。
- `Content` 默认通过 Portal 渲染并自动维护 `aria-describedby` 关联，适用于不可聚焦的补充文本；需要包含交互控件时请使用 Popover 或非模态 Dialog。

### 在 Button 上组合 Tooltip

当触发元素本身是可聚焦按钮时，应让按钮与提示触发器共享同一个元素，避免嵌套产生两个 `Tab` 焦点停靠点。使用 `useTooltipTrigger()` 与 `asButton()` 组合即可：

```ts
import { definePrototype } from '@proto.ui/core';
import { asButton, type ButtonProps, type ButtonExposes } from '@proto.ui/prototypes-base/button';
import { useTooltipTrigger } from '@proto.ui/prototypes-base/tooltip';

export const tooltipButton = definePrototype<ButtonProps, ButtonExposes>({
  name: 'app-tooltip-button',
  setup() {
    asButton();
    useTooltipTrigger();
  },
});
```

- 按钮保留自身角色、名称、点击事件、禁用状态与焦点管理，`useTooltipTrigger()` 仅叠加悬停/聚焦意图与 `aria-describedby` 关联。禁用 Tooltip `Root` 仅关闭提示而不禁用按钮；禁用按钮则会同时抑制提示。
- 如需复用已有的 Shadcn 风格按钮原型，可在 `definePrototype` 中保留其静态 `modules` 声明，在 `setup(def)` 中先调用原按钮的 `setup(def)` 再调用 `useTooltipTrigger()`，并返回原 render 函数。
- 当触发元素位于 `ShadowRoot` 内部时，请使用 [同树 Portal 配方](/zh-cn/ui-libraries/base/tooltip/#shadowroot)，以确保 `aria-describedby` 跨 Shadow 边界正确生效。

### 事件、状态与方法

- **Root**：暴露只读状态 `open`，事件 `openChange`（`{ open, reason }`），以及方法 `openTooltip(reason?)`、`close(reason?)`、`toggle(reason?)`。
- **Trigger**：暴露只读状态 `disabled`、`hovered`、`focused`、`focusVisible`，以及方法 `focusSelf(options?)`。
- **Content**：暴露只读状态 `open` 与 Transition 状态（`transitionState`、`isPresent`、`controls`）。
