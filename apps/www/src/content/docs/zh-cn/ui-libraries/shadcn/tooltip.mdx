## 安装

当前完整源码示例基于工作区 0.3 源码包（包含 Vue 2.6 Adapter）。如需安装已发布的 0.2.0 稳定版，请参阅 [Quick Start](/zh-cn/start-here/quick-start/)。

在现有宿主应用中从本地源码包安装时，请从同一源码修订安装 CLI、`@proto.ui/prototypes-shadcn` 以及对应宿主的 Adapter（`@proto.ui/adapter-web-component`、`@proto.ui/adapter-react`、`@proto.ui/adapter-vue` 或 `@proto.ui/adapter-vue2`，其中 Vue 2 要求 Vue `>=2.6.0 <2.7`）。本地打包与安装流程可参考 [scripts/release/publish.mjs](https://github.com/Proto-UI/Proto-UI/blob/main/scripts/release/publish.mjs) 和 [scripts/release/consumer-smoke-cli.mjs](https://github.com/Proto-UI/Proto-UI/blob/main/scripts/release/consumer-smoke-cli.mjs)。

安装配套包后，在应用目录运行本地 CLI 生成组件封装（请保留生成的 `proto-ui-style.css`，其中包含定位与显隐所需的结构样式）：

```sh
node node_modules/@proto.ui/cli/bin/proto-ui.js init --yes --no-interactive --prototypes shadcn
node node_modules/@proto.ui/cli/bin/proto-ui.js add wc shadcn-tooltip --no-install --no-interactive
```

将 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的组件文件。

## 用法

Tooltip 由 `Group`、`Root`、`Trigger` 和 `Content` 组成：

- `Group` 协调同组多个 Tooltip 的显示延迟：冷启动悬停默认 `700ms` 后打开，关闭延迟 `100ms`；在 `300ms` 跳过窗口内移动到相邻触发器时会立即切换，且同组最多保持一个提示打开。
- 通过键盘 `Tab` 聚焦 `Trigger` 时立即显示提示，按 `Escape` 关闭并保持焦点在触发器上。
- `Content` 默认通过 Portal 渲染并自动维护 `aria-describedby` 关联，适用于不可聚焦的补充文本；需要包含交互控件时请使用 Popover 或非模态 Dialog。

### 在 Button 上组合 Tooltip

当触发元素本身是可聚焦按钮时，应让按钮与提示触发器共享同一个元素，避免嵌套产生两个 `Tab` 焦点停靠点。使用 `useTooltipTrigger()` 与 `asButton()` 组合即可：

```ts
import { definePrototype } from '@proto.ui/core';
import { asButton, type ButtonProps, type ButtonExposes } from '@proto.ui/prototypes-base/button';
import { useTooltipTrigger } from '@proto.ui/prototypes-base/tooltip';

export const tooltipButton = definePrototype<ButtonProps, ButtonExposes>({
  name: 'app-tooltip-button',
  setup() {
    asButton();
    useTooltipTrigger();
  },
});
```

- 按钮保留自身角色、名称、点击事件、禁用状态与焦点管理，`useTooltipTrigger()` 仅叠加悬停/聚焦意图与 `aria-describedby` 关联。禁用 Tooltip `Root` 仅关闭提示而不禁用按钮；禁用按钮则会同时抑制提示。
- 如需复用已有的 Shadcn 风格按钮原型，可在 `definePrototype` 中保留其静态 `modules` 声明，在 `setup(def)` 中先调用原按钮的 `setup(def)` 再调用 `useTooltipTrigger()`，并返回原 render 函数。
- 当触发元素位于 `ShadowRoot` 内部时，请使用 [同树 Portal 配方](/zh-cn/ui-libraries/base/tooltip/#shadowroot)，以确保 `aria-describedby` 跨 Shadow 边界正确生效。

## API

在 `Root` 上传入 `open` 进入受控模式；`Root` 未单独设置延迟时自动沿用 `Group` 的配置：

  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'openDelay', type: 'number', default: '700' },
    { name: 'closeDelay', type: 'number', default: '100' },
    { name: 'skipDelay', type: 'number', default: '300' },
    { name: 'side', type: "'top' | 'right' | 'bottom' | 'left'", default: 'top' },
    { name: 'align', type: "'start' | 'center' | 'end'", default: 'center' },
    { name: 'sideOffset', type: 'number', default: '4' },
    { name: 'alignOffset', type: 'number', default: '0' },
    { name: 'avoidCollisions', type: 'boolean', default: 'true' },
    { name: 'collisionPadding', type: 'number', default: '0' },
  ]}
/>

属性归属说明：

- `defaultOpen`、`disabled` 属于 `Root`（`Trigger` 也支持 `disabled`）。
- `openDelay`、`closeDelay`、`skipDelay` 属于 `Group`。
- `side`、`align`、`sideOffset`、`alignOffset`、`avoidCollisions`、`collisionPadding` 属于 `Content`。
