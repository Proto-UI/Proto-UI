本页以 **Shadcn Rhea** 为目标，支持profile的parts均显式选择Rhea；下文headless触发器/action-body缺口仍开放，尚不称整页外观统一。这不修改公共组件的兼容默认值，也不代表全部浏览器、原生宿主和视觉验收已完成。Surface/Text 等中性原子仍保留各自公开语义，外观主题由消费组合提供。

这个 draft family 包含 Group、Root、Trigger 与 Content。open state、controlled ownership、disabled、pointer/focus intent、delay 与 dismissal sequencing、`aria-describedby`、presence、Escape、renderer-owned Portal projection 与 anchored positioning 继续只由 Base Tooltip 持有。shadcn 层仅增加 Group layout、Trigger feedback 与紧凑 Content surface。

历史 API 比较来源为 shadcn-ui/ui `f31ed81983653919dd4fe77aee4b4859f610f1dc` 的 `apps/v4/registry/new-york-v4/ui/tooltip.tsx`，不是本页选择的外观 profile。该 Provider 默认 pointer delay 为0ms；Proto UI 保留 Base Group 的700ms open、100ms close和300ms skip。该 Content 默认 sideOffset 为0，Proto UI 保留4。Portal 仍归 renderer，Arrow 在受治理的几何通道缺失时仍不可用。

Content 选择 [Rhea 样式源码](https://github.com/shadcn-ui/ui/blob/3d98900e9b73c45f035f8109e9d41ba6a51685e7/apps/v4/registry/styles/style-rhea.css)：inline-flex、fit-content、20rem最大宽度、6px gap和`rounded-xl`，使用foreground/background主题色反转形成提示表面。2026-10-10 的 [base-nova snapshot](https://ui.shadcn.com/r/styles/base-nova/tooltip.json)（SHA256 `2f55867faecee2d3616cfd8c6a80b538909a21e62fdfa2788b1ead56093e5395`）只保留为未选profile时的兼容参考。Trigger是带既有Proto反馈的headless语义owner，不是Button；替换演示旧作者paint仍需公共Rhea被动action-body组合，不能再增加焦点/激活owner。Arrow、transform-origin、方向motion、kbd后代样式及原生视觉验收仍开放。

从 `@proto.ui/prototypes-shadcn/tooltip` 导入该 family，或使用 `proto-ui add react shadcn-tooltip` 生成 React facade。Content 保持 supplementary、不可聚焦且非任务必要；交互式任务内容应使用 Popover 或 non-modal Dialog。

## 建议验收路径

1. hover Account，确认 cold Tooltip 约 700ms 后打开；提前离开时不得闪现。
2. 在 300ms warm window 结束前移动到 Notifications，确认 sibling 立即打开且始终只有一个 active owner。
3. 用 Tab 聚焦任一 Trigger，确认立即打开、focus ring 可见，且 Trigger 没有 button role。
4. 确认 Content portal 到 preview frame 外，仍通过 `aria-describedby` 关联，且没有可聚焦 control 或 Arrow。
5. 按 Escape，确认 Content 关闭且焦点留在 Trigger。
6. 在 Web Components、React、Vue 与 Vue 2 的 Light/Dark 模式中重复检查。

相关 entities 仍为 `draft`；本页描述当前 cataloged direction，而不是稳定 compatibility guarantee。

## API

Root 传入 `open` 进入受控模式。Root 未自设延时时使用 Group 的延时。

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'openDelay', type: 'number', default: '700' },
    { name: 'closeDelay', type: 'number', default: '100' },

    { name: 'side', type: "'top' | 'right' | 'bottom' | 'left'", default: 'top' },
    { name: 'align', type: "'start' | 'center' | 'end'", default: 'center' },
    { name: 'sideOffset', type: 'number', default: '4' },
    { name: 'alignOffset', type: 'number', default: '0' },
    { name: 'avoidCollisions', type: 'boolean', default: 'true' },
    { name: 'collisionPadding', type: 'number', default: '0' },
  ]}
/>

`openDelay`、`closeDelay`、`skipDelay` 属于 Group。`side` 到 `collisionPadding` 属于 Content。Trigger 只增加 `disabled`。
