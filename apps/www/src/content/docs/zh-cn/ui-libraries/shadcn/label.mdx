通过显式配对为关联控件提供无障碍名称（`naming`）与点击激活/聚焦能力（`activation`），无需手写 DOM `id` 或嵌套隐式查找。本页示例采用 **Shadcn Rhea** 风格。

## 用法

### 命名与激活（可独立开关）

- **`naming`（默认 `true`）**：为目标控件建立无障碍命名关联，无需重复放置视觉隐藏文本。如果目标控件本身已有非空 `ariaLabel` 或 `labelledBy`，建议将该标签设为 `naming={false}`（仅激活模式）以免命名冲突。
- **`activation`（默认 `true`）**：点击配对标签时同步触发目标控件的对应操作——切换 `Checkbox` / `Switch`、选择 `Radio Group Item`，或聚焦 `Input` / `Textarea`（不修改文本内容或选区）。设为 `false` 可保留命名并关闭点击激活。
- **`selection`（默认 `'policy'`）**：当标签可激活时自动抑制误选文字；仅命名的标签和长文本说明保持可复制。如需可激活标签也能选中复制文字，请设为 `selection="text"`。
- `Label` 不增加额外的 `Tab` 顺序，点击标签内嵌的链接/按钮、带修饰键的点击或拖拽手势不会误触控件。

### 创建显式关联

每对标签与控件使用 `@proto.ui/core` 的 `createControlLabelRef()` 创建一个稳定引用，通过框架适配器通道传入（不放入普通 JSON Props）：

- **React / Vue / Vue 2**：向标签与控件双方传入 `instanceAssociations: { controlLabel: ref }`。
- **Web Components**：使用 `@proto.ui/adapter-web-component` 的 `setElementAssociations(target, { controlLabel: ref })` 分别绑定目标控件与标签。
- **DemoSpec**：通过 `associations: { controlLabel: 'row-key' }` 声明纯数据配对键。

每个引用对应唯一的在线标签与目标控件（在 Web 端须位于同一 Document 与根节点下），重复、缺失或过期的配对会自动忽略。支持的关联目标包括 `Checkbox`、`Switch`、`Radio Group Item`、`Input`、`Textarea`、`Button`、`Toggle` 与 `Toggle Group Item`（包括纯图标按钮的独立命名）。

## API

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'naming', type: 'boolean', default: 'true' },
    { name: 'activation', type: 'boolean', default: 'true' },
    { name: 'selection', type: "'policy' | 'auto' | 'text' | 'none'", default: 'policy' },
  ]}
/>

以上属性属于 `Root`。`selection="policy"` 仅在 `Label` 处于可激活状态时抑制误选文字。
