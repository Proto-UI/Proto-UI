`Label` 通过显式引用关联为控件提供无障碍名称（`naming`）与点击激活/聚焦能力（`activation`），无需手写 DOM `id` 或隐式查找相邻节点。本页示例采用 **Shadcn Rhea** 风格。

> 表单输入字段请优先使用 [Field](../field/) 组件，内置 `FieldLabel`、`FieldDescription` 与 `FieldError` 自动关联与校验支持。

## 用法

每对标签与控件通过 `@proto.ui/core` 的 `createControlLabelRef()` 创建唯一引用，并通过适配器通道传入（不放入普通 JSON Props）：

```tsx
import { useMemo } from 'react';
import { createControlLabelRef } from '@proto.ui/core';
import {
  ShadcnCheckboxIndicator,
  ShadcnCheckboxRoot,
  ShadcnLabelRoot,
} from '../proto-ui/components/react';

export function TermsCheckbox() {
  const termsRef = useMemo(() => createControlLabelRef(), []);

  return (
    <div className="flex items-center gap-2">
      <ShadcnCheckboxRoot styleProfile="rhea" instanceAssociations={{ controlLabel: termsRef }}>
        <ShadcnCheckboxIndicator styleProfile="rhea" />
      </ShadcnCheckboxRoot>
      <ShadcnLabelRoot styleProfile="rhea" instanceAssociations={{ controlLabel: termsRef }}>
        Accept terms and conditions
      </ShadcnLabelRoot>
    </div>
  );
}
```

Web Components 通过 `@proto.ui/adapter-web-component` 的 `setElementAssociations()` 绑定同一引用：

```ts
import { createControlLabelRef } from '@proto.ui/core';
import { setElementAssociations } from '@proto.ui/adapter-web-component';

const termsRef = createControlLabelRef();
setElementAssociations(checkboxEl, { controlLabel: termsRef });
setElementAssociations(labelEl, { controlLabel: termsRef });
```

### 命名、激活与无障碍

- **`naming`（默认 `true`）**：为目标控件建立无障碍命名关联，无需重复放置隐藏文本。如果目标控件本身已有非空 `ariaLabel` 或 `labelledBy`，建议设为 `naming={false}`（仅激活模式）。
- **`activation`（默认 `true`）**：点击标签会同步请求目标控件的既有操作——切换 `Checkbox` / `Switch`、选择 `Radio Group Item`，或聚焦 `Input` / `Textarea`（不修改文本内容或选区）。设为 `false` 可保留命名并关闭点击激活。
- **`selection`（默认 `'policy'`）**：可激活标签默认抑制误选文字；仅命名标签与长说明保持自然可选中。需要可激活标签也能复制文字时请设为 `selection="text"`。
- **键盘与指针边界**：`Label` 不增加额外 `Tab` 停靠点，点击嵌套链接/按钮、带修饰键的点击、拖拽或已取消的指针手势不会误触控件。
- **支持的关联目标**：`Checkbox`、`Switch`、`Radio Group Item`、`Input`、`Textarea`、`Button`、`Toggle`、`Toggle Group Item`、独立 `Select Trigger` 与 `Number Field Input`。
- **风格预设（`styleProfile`）**：支持 `vega`、`nova`、`maia`、`lyra`、`mira`、`luma`、`sera`、`rhea` 与 `new-york-v4`；默认 `'inherit'` 会继承最近的 [Style Scope](../style-scope/)，否则回退到 `new-york-v4`。

### 关联辅助接口

- `createControlLabelRef()`：从 `@proto.ui/core` 导入，为每对标签与控件创建一对一不透明引用。
- `instanceAssociations`：React / Vue / Vue 2 传入 `{ controlLabel: ref }` 的适配器关联通道。
- `setElementAssociations(element, { controlLabel: ref })`：从 `@proto.ui/adapter-web-component` 导入，用于 Web Components 绑定。
