Number Field 提供符合 `spinbutton` 语义的数值输入框，支持加减按钮、键盘步进、本地化格式化、空值处理以及标签拖动调值。本页示例使用 **Shadcn Rhea** 风格。

## 用法

Number Field 由 `Root`、`Label`、`Input`、`Control`、`Increment` 和 `Decrement` 组成：

- `Root` 统一管理数值（`number | null`）、上下界（默认 `0` 到 `100`）、步长（默认 `1`）及交互状态。
- `Input` 提供独立数值编辑体验；在 `Field` 或 `FormField` 中使用时，请改用 `Control` 以自动衔接 `FieldLabel`、校验、IME 取消、表单序列化与重置。
- `Increment` 与 `Decrement` 按钮与键盘方向键共享同一套步进逻辑。

### 键盘与输入编辑

- 编辑过程中允许保留尚未输完的草稿文本；按下 `Enter` 或失焦时，会提交合法数值，若输入无效则恢复为上一次有效值。
- `ArrowUp` / `ArrowDown` 按 `step` 增减，按住 `Shift` 以 10 倍步长调整，`Home` / `End` 直接跳至最小或最大边界。
- 传入 `value` 进入受控模式，交互操作会发出变更请求，由外部决定最终值。
- 在输入法（IME）组合输入期间，解析、提交、步进和拖动调值会自动暂停，切换 `locale` 时也会保留当前组合文本。

### 本地化格式化

通过 `locale` 和 `formatOptions` 支持十进制、货币和百分比格式展示，并能解析对应的本地数字、小数点、分组符和正负号。格式化仅影响显示，未做编辑的提交不会将显示舍入写回底层数值。如果格式配置无效，组件会标记 `formatInvalid` 并自动回退到无分组十进制显示。

### 空值支持

- 显式传入 `null` 表示空值，`value={null}` 仍处于受控模式。
- 默认 `allowEmpty` 为 `false`；将其设为 `true` 后，清空输入框并提交即可请求空值 `null`。
- `Root`、`Input` 和 `Control` 的 `getValue()` 返回真实的 `number | null`，`empty` 属性标识是否为空；兼容属性 `value` 仅在非空时表示当前值，空值状态下保留最近一次有限数值。事件与 Field/Form 始终传递真实的 `null`。
- 从空值状态首次步进时，会先初始化为处于上下界内并对齐步长的 `0`。

### 标签拖动调值（Scrub）

设置 `scrub` 后，可在 `Label` 上按住并水平拖动来连续调整数值：

- `scrubSteps`（默认 `100`）控制拖动一个初始标签宽度所对应的步数；`direction="rtl"` 会反转水平方向。
- 释放指针且数值发生变化时提交一次；取消拖动时在非受控模式下恢复起始值。输入框内部仍保持正常的文本选择体验。
