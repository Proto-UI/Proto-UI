Number Field 提供符合 `spinbutton` 语义的数值输入框，支持加减步进按钮、键盘步进、基于 `Intl` 的本地化格式化、可空值以及标签拖动调值。本页示例使用 **Shadcn Rhea** 风格。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可直接从 `@proto.ui/prototypes-shadcn/number-field` 导入各部件原型：

```ts
import {
  numberFieldRoot,
  numberFieldLabel,
  numberFieldInput,
  numberFieldControl,
  numberFieldIncrement,
  numberFieldDecrement,
} from '@proto.ui/prototypes-shadcn/number-field';
```

## 用法

Number Field 由 `Root`、`Label`、`Input`、`Control`、`Increment` 和 `Decrement` 组成：

```tsx
<ShadcnNumberFieldRoot defaultValue={12} min={0} max={100} step={1} ariaLabel="Quantity">
  <ShadcnNumberFieldLabel>Quantity</ShadcnNumberFieldLabel>
  <ShadcnNumberFieldDecrement>
    <span aria-hidden="true">−</span>
    <span className="sr-only">Decrease Quantity</span>
  </ShadcnNumberFieldDecrement>
  <ShadcnNumberFieldInput />
  <ShadcnNumberFieldIncrement>
    <span aria-hidden="true">+</span>
    <span className="sr-only">Increase Quantity</span>
  </ShadcnNumberFieldIncrement>
</ShadcnNumberFieldRoot>
```

在 `Field` 或 `FormField` 内使用时，请将 `Input` 替换为 `Control` 以自动联动 `FieldLabel`、校验错误状态、表单序列化与重置：

```tsx
<ShadcnFieldRoot required>
  <ShadcnFieldLabel>Quantity</ShadcnFieldLabel>
  <ShadcnNumberFieldRoot defaultValue={1} min={1} max={99}>
    <ShadcnNumberFieldDecrement>−</ShadcnNumberFieldDecrement>
    <ShadcnNumberFieldControl />
    <ShadcnNumberFieldIncrement>+</ShadcnNumberFieldIncrement>
  </ShadcnNumberFieldRoot>
  <ShadcnFieldError />
</ShadcnFieldRoot>
```

- **键盘与编辑**：输入期间保留未完成草稿，按 `Enter` 或失焦时提交合法数值或恢复上次有效值；`ArrowUp` / `ArrowDown` 按 `step` 步进（按住 `Shift` 以 10 倍步长调整），`Home` / `End` 跳至 `min` / `max` 边界。IME 组合输入期间自动暂停解析、提交、步进与拖动。
- **本地化格式化**：通过 `locale` 和 `formatOptions` 支持十进制、货币和百分比展示及解析；展示舍入不会修改底层数值精度，格式配置非法时标记 `formatInvalid` 并回退无分组十进制。
- **空值与拖动**：开启 `allowEmpty` 允许清空输入框提交 `null`（通过 `getValue()` 读取精确的 `number | null`，通过 `empty` 判空）；开启 `scrub` 可在 `Label` 上水平拖动连续调值。

## API

### Root 属性
