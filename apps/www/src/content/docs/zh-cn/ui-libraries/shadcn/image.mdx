Root 声明一个宿主自有图片目标。`source` 指向资源，`a11yMode` 选择 `informative`（默认，消费 `alternativeText`）或 `decorative`（含义由文本承载），`fit` 选择 `contain`（默认）、`cover` 或 `fill`。当前加载状态通过 `loadingStatus`（`idle`、`loading`、`loaded`、`error`）暴露，并经由 `loadingStatusChange` 事件携带前后状态。演示通过加载、替换、损坏和清除真实来源观察这些转换；控件与日志属于演示，不属于原型。Web 投射为每个实例渲染一个物理 `<img>`。

组成: Root.
