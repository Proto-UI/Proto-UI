## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可直接从 `@proto.ui/prototypes-shadcn/image` 导入 `imageRoot`（别名 `shadcnImageRoot`）及相关类型。

## 用法

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { imageRoot } from '@proto.ui/prototypes-shadcn/image';

const ShadcnImage = createReactAdapter(React)(imageRoot);

export function CoverPhoto() {
  return (
    <ShadcnImage
      styleProfile="rhea"
      source="/images/base-image/landscape.svg"
      a11yMode="informative"
      alternativeText="晨光中的山脊"
      fit="cover"
      radius="default"
      surfaceStyle={{ width: '100%', height: '220px' }}
    />
  );
}
```

`Image` 由单一 `Root` 部件组成（在 Web 环境下渲染为原生 `<img>`）：

- **响应式与圆角**：默认提供 `block max-w-full h-auto` 响应式约束，`radius="default"` 自动跟随当前 `styleProfile`（`rhea` / `maia` / `luma` 为 `rounded-xl`，`nova` 为 `rounded-lg`，`vega` / `mira` / `new-york-v4` 为 `rounded-md`，`lyra` / `sera` 为 `rounded-none`），也可显式传入具体圆角档位。
- **缩放与无障碍**：通过 `fit` 选择 `'contain'`（默认）、`'cover'` 或 `'fill'`；信息性图片使用 `a11yMode="informative"` 并提供有意义的 `alternativeText`，纯装饰性图片设为 `a11yMode="decorative"`。
- **加载与回退**：`Root` 暴露 `loadingStatus`（`'idle' | 'loading' | 'loaded' | 'error'`），状态切换时触发 `loadingStatusChange`，方便外层容器按需渲染占位骨架或错误重试界面。
