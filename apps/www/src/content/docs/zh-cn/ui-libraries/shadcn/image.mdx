## 用法

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

`Image` 由单一 `Root` 部件组成（在 Web 环境下渲染为原生 `<img>`）：

- **图片地址与缩放**：通过 `source` 指定资源地址，`fit` 选择 `'contain'`（默认）、`'cover'` 或 `'fill'`。
- **无障碍模式**：`a11yMode="informative"`（默认）使用 `alternativeText` 作为替代文本；当图片仅作装饰且含义已由周围文本表达时，设为 `a11yMode="decorative"`。
- **加载状态追踪**：实时暴露 `loadingStatus`（`'idle'`、`'loading'`、`'loaded'`、`'error'`），状态切换时通过 `loadingStatusChange` 发出前后状态，方便应用层自行渲染占位或错误回退界面。
