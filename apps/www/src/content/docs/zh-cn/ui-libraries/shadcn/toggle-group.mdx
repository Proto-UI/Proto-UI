Toggle Group 将一组可切换的双态按钮组织为支持方向键漫游焦点的选择组，支持单选与多选模式。本页示例使用 **Shadcn Rhea** 风格。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可直接从 `@proto.ui/prototypes-shadcn/toggle-group` 导入组件原型并通过对应宿主 Adapter 适配。

## 用法

```tsx
import { ShadcnToggleGroupItem, ShadcnToggleGroupRoot } from '../proto-ui/components/react';

export function Example() {
  return (
    <ShadcnToggleGroupRoot variant="outline" defaultValue={['a']}>
      <ShadcnToggleGroupItem value="a">A</ShadcnToggleGroupItem>
      <ShadcnToggleGroupItem value="b">B</ShadcnToggleGroupItem>
      <ShadcnToggleGroupItem value="c">C</ShadcnToggleGroupItem>
    </ShadcnToggleGroupRoot>
  );
}
```

### 组件结构

```text
ToggleGroupRoot
├── ToggleGroupItem
└── ToggleGroupItem
```

- **值与模式**：`value` 与 `defaultValue` 均为字符串数组（`readonly string[]`）。当 `multiple={false}`（默认）时，组内最多保留一个选中值，再次激活已选中项可清空选择；设为 `multiple={true}` 允许同时选中多项。
- **受控更新**：传入 `value` 进入受控模式，交互通过 `valueChange`（载荷 `{ value: readonly string[] }`）提交候选值，由外部更新状态。
- **键盘与无障碍**：方向键根据 `orientation` 在选项间移动焦点而不自动切换选中态，按 `Space` 或 `Enter` 切换当前聚焦项；纯图标按钮应搭配视觉隐藏文本（如 `sr-only`）提供可访问名称。
- **风格预设**：支持通过 `styleProfile` 或外层 [Style Scope](../style-scope/) 切换 `vega`、`nova`、`maia`、`lyra`、`mira`、`luma`、`sera`、`rhea` 与 `new-york-v4`。
