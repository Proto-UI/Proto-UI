value/defaultValue 为数组。multiple=false 最多保留一个值，再次点击可以清除。受控 valueChange 不修改调用方状态。禁用、只读以及重复值选项不能提交；箭头导航仅移动焦点。

组成: Root, Item.

## API

Toggle Group 是工作区源码，没有公开的 `proto-ui add` 目标。传入 `value` 进入受控模式。
