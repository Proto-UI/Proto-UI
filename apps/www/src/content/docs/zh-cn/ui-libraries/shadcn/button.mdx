Shadcn Button 继承 Base Button 的激活、键盘交互、焦点与禁用语义，并提供六种变体、完整尺寸阶梯与多种风格预设。本页示例采用 **Shadcn Rhea** 风格。

## 安装

使用 0.2.0 稳定版 CLI [初始化应用](/zh-cn/start-here/quick-start/)并添加按钮。预览展示工作区 Button 的 Rhea 样式和扩展尺寸。使用 Vue 2.6 时，请安装版本匹配的预发布版或工作区 CLI、适配器和原型包。

<InstallCommandCard
  commands={{
    npm: 'npx @proto.ui/cli@0.2.0 add wc shadcn-button',
    pnpm: 'pnpm dlx @proto.ui/cli@0.2.0 add wc shadcn-button',
  }}
  manager="npm"
/>

将 `wc` 替换为 `react` 或 `vue` 可生成对应框架的组件入口。CLI 会安装匹配的 `@proto.ui/prototypes-shadcn` 与适配器包，并生成样式表与本地封装。

## 用法

在应用入口导入一次生成的 `proto-ui-style.css` 后即可直接渲染按钮：

```tsx
import { ShadcnButton } from '../proto-ui/components/react';

export function Example() {
  return <ShadcnButton variant="outline">Button</ShadcnButton>;
}
```

- **键盘与无障碍**：继承自 [Base Button](../../base/button/)，支持 `Enter` 与 `Space` 激活、焦点环与禁用拦截。纯图标按钮请使用视觉隐藏文本（如 `sr-only`）提供可访问名称。
- **光标行为（Cursor）**：默认遵循 Tailwind v4 的按钮光标规范，不在基础样式中强制指定 `cursor: pointer`。若应用希望所有可用按钮统一使用手形光标，可在全局 CSS 中按需设置：

```css
@layer base {
  button:not(:disabled),
  [role='button']:not([aria-disabled='true']) {
    cursor: pointer;
  }
}
```

## 常见组合模式

- **页面导航**：需要跳转 URL 时请直接使用原生 `<a>` 元素，保留语义链接角色与浏览器导航能力，不要用按钮模拟链接。
- **工具栏分组**：独立操作可直接放在弹性布局容器中；需要方向键 roving focus 时，请使用 [Toolbar](../toolbar/)。
