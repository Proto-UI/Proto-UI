Shadcn Button 在 Base Button 的基础上提供视觉变体与尺寸。本页示例采用 **Shadcn Rhea** 风格。

## 预览

## 安装

先[初始化你的应用](/zh-cn/start-here/quick-start/)，然后添加按钮组件：

<InstallCommandCard
  commands={{
    npm: 'npx @proto.ui/cli@0.2.0 add wc shadcn-button',
    pnpm: 'pnpm dlx @proto.ui/cli@0.2.0 add wc shadcn-button',
  }}
  manager="npm"
/>

将 `wc` 替换为 `react` 或 `vue` 可生成对应宿主的组件。CLI 会安装匹配的 `@proto.ui/prototypes-shadcn` 与适配器包，并生成本地组件入口。Vue 2.6（`>=2.6.0 <2.7`）及下方的 `styleProfile` 预设需要匹配的工作区 CLI、适配器和原型源码；已发布的 0.2.0 CLI 支持 `wc`、`react` 和 `vue`。

## 用法

每个代码示例都包含组件注册或导入代码以及示例样式。在应用入口处导入一次生成的 `proto-ui-style.css` 即可，无需额外配置 Tailwind：

- **Web Components**：使用生成的 `proto-ui-shadcn-button` 标签。
- **React**：直接渲染导出的组件。
- **Vue**：以单文件组件形式导入使用。

### 风格预设（`styleProfile`）

本页示例显式设置了 `styleProfile="rhea"`。当前支持的预设包括 `vega`、`nova`、`maia`、`lyra`、`mira`、`luma`、`sera`、`rhea` 与 `new-york-v4`（`new-york` 作为兼容别名）。省略或设为 `inherit` 时，会优先继承最近的 [Style Scope](../style-scope/)，否则回退到 `rhea`。

## 常见组合模式

- **页面导航**：需要跳转链接时请直接使用原生 `<a>` 元素，保留真实 URL 与完整链接文本，例如 [阅读快速开始](/zh-cn/start-here/quick-start/)：

```html
<a href="/zh-cn/start-here/quick-start/">阅读快速开始</a>
```

- **异步加载状态**：在应用层管理请求中的状态，驱动 `disabled` 并保留有意义的按钮名称；需要向辅助技术播报进度时，可搭配 [Async Region](../async-region/) 或 [Live Region](../live-region/) 使用。
- **按钮分组**：普通操作按钮可直接用常规容器排版；需要工具栏方向键导航时，请使用 [Toolbar](../toolbar/)。
