## 安装

先[初始化已有应用](/zh-cn/start-here/quick-start/)。已发布的稳定版 0.2.0 基线使用：

<InstallCommandCard command="npx @proto.ui/cli@0.2.0 add wc shadcn-button" manager="npm" />

```sh
pnpm dlx @proto.ui/cli@0.2.0 add wc shadcn-button
```

稳定版 React、Vue 3 分别把 `wc` 换为 `react`、`vue`。CLI 按自身精确版本安装 `@proto.ui/prototypes-shadcn` 与对应 Adapter，并生成本地 facade。Vue 2.6（`>=2.6.0 <2.7`）与下面的命名 style profile 需要配套的工作区 0.3 CLI/Adapter/Prototype 源码。稳定版 `@latest` 不能证明这些能力已交付，工作区 `0.3.0-alpha.1` manifest 也不能证明 registry 已发布。

## 用法与呈现

每个 Code 面板都包含注册或 import 与应用示例样式表。生成的 `proto-ui-style.css` 应在应用入口导入一次。WC 使用生成的 `proto-ui-shadcn-button` 标签；React 导出具名示例供已有应用渲染，Vue 示例是单文件组件。相对路径应与初始化后的项目布局一致。少量布局与隐藏标签样式由应用拥有，不要求额外配置 Tailwind。

示例显式请求 `styleProfile="rhea"`，与预览的公开 Shadcn style scope 选择一致。当前源码识别 `vega`、`nova`、`maia`、`lyra`、`mira`、`luma`、`sera`、`rhea` 与 `new-york-v4`，`new-york` 是旧风格别名。省略或使用 `inherit` 时先读取最近 scope，再回退到 Button 的 Rhea 配方。这些示例展示 Rhea，不代表每个 profile 或组件都已完成视觉验收。

## 导航、分组与 busy 状态

导航使用原生 anchor，保留真实 URL 与完整文本：[阅读快速开始](/zh-cn/start-here/quick-start/)。等价的应用组合为：

```html
<a href="/zh-cn/start-here/quick-start/">阅读快速开始</a>
```

不要把 anchor 放进 Button，也不要发明 `asChild`、`href`、`loading` 或 `isLoading` prop。Base 始终拥有激活与禁用。真实异步动作由应用维护 pending 状态、驱动 `disabled`、保留有意义的名称并报告进度与完成；仅显示 spinner 既不是 busy 状态，也不是激活门控。

普通布局可以把独立动作排列成组；需要相应键盘模型时采用文档中的 [Toolbar](../toolbar/)。专门的 Button Group API、loading/spinner 组合、图标与文本矩阵、全 profile 证据和原生链接视觉对比仍是 [#1042](https://github.com/Proto-UI/Proto-UI/issues/1042) 的独立条件，本试点不声称已完成这些条件。
