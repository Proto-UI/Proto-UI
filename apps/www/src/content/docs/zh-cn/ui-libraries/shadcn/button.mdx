按钮用于触发操作。同一个原型可以在所有受支持的 Web 宿主中运行；使用运行时选择器切换实现，交互契约不变。

## 安装

<InstallCommandCard command="npx @proto.ui/cli@latest add wc shadcn-button" manager="npm" />

把 `wc` 换成 `react`、`vue` 或 `vue2`，生成对应宿主的 facade。

### 尺寸

可以使用 `sm`、`default`、`lg`、`icon` 或扩展的 `icon-compact`。`icon-compact` 固定为 1.75rem 正方形，启用 `wrap` 后也不会改变。
