## 安装

先按[快速开始](../../../start-here/quick-start/)完成初始化并在应用入口引入生成的 `proto-ui-style.css`，然后生成 Dialog 组件：

<InstallCommandCard command="npx @proto.ui/cli@0.2.0 add wc shadcn-dialog" manager="npm" />

将 `wc` 替换为 `react`、`vue` 或 `vue2` 即可生成对应框架的包装组件；命令会同时生成带默认关闭图标的 `ShadcnDialogContent` 与无默认关闭图标的 `ShadcnDialogContentRaw`。

## 用法

```tsx
import {
  ShadcnButton,
  ShadcnDialogContent,
  ShadcnDialogDescription,
  ShadcnDialogHeader,
  ShadcnDialogMask,
  ShadcnDialogRoot,
  ShadcnDialogTitle,
  ShadcnDialogTrigger,
} from '@/components/proto-ui/shadcn';

export function DialogExample() {
  return (
    <ShadcnDialogRoot>
      <ShadcnDialogTrigger>
        <ShadcnButton variant="outline">Open</ShadcnButton>
      </ShadcnDialogTrigger>
      <ShadcnDialogMask />
      <ShadcnDialogContent>
        <ShadcnDialogHeader>
          <ShadcnDialogTitle>Are you absolutely sure?</ShadcnDialogTitle>
          <ShadcnDialogDescription>
            This action cannot be undone. This will permanently delete your account and remove your
            data from our servers.
          </ShadcnDialogDescription>
        </ShadcnDialogHeader>
      </ShadcnDialogContent>
    </ShadcnDialogRoot>
  );
}
```

### 组合结构

```text
ShadcnDialogRoot
├── ShadcnDialogTrigger
├── ShadcnDialogMask
└── ShadcnDialogContent
    ├── ShadcnDialogHeader
    │   ├── ShadcnDialogTitle
    │   └── ShadcnDialogDescription
    ├── ShadcnDialogFooter
    │   └── ShadcnDialogClose
    └── ShadcnDialogCloseIcon
```

### 部件职责与交互说明

- **打开与关闭**：`ShadcnDialogTrigger` 与 `ShadcnDialogClose` 默认无样式，内嵌 `ShadcnButton` 即可保持单次 `Tab` 停靠与按钮外观。
- **自定义关闭图标**：`ShadcnDialogContent` 默认渲染右上角 `ShadcnDialogCloseIcon`；可通过子元素、React `close` 属性或 Vue `#close` 插槽替换，也可使用 `close={null}`、空 `#close` 插槽、`data-pui-no-default-close` 或 `ShadcnDialogContentRaw` 隐藏。
- **焦点与关闭策略**：打开期间焦点限制在面板内循环，关闭后归还至触发器；按 `Escape` 或点击遮罩可关闭。设置 `alert={true}` 会切换为 `role="alertdialog"` 并禁止点击外部关闭。
- **无障碍命名**：`Title` 与 `Description` 自动建立 `aria-labelledby` / `aria-describedby` 关联；缺少标题时可通过 `Root` 的 `a11yLabel` 提供兜底名称。
