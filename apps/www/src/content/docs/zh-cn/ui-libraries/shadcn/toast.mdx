Toast 用于以非打断方式展示限时实时通知，支持悬停或聚焦时暂停倒计时、键盘快捷键定位以及可选操作按钮。本页示例使用 **Shadcn Rhea** 风格。

## 用法

Toast 由 `Root`、`Viewport`、`Title`、`Description`、`Action` 和 `Close` 六个部件组成：

- `Root` 默认持续显示 `5000ms` 后自动请求关闭；将 `duration` 设为 `0` 可保持常驻不自动关闭。
- 指针悬停在通知上，或键盘焦点位于 `Action` / `Close` 上时，剩余倒计时会自动暂停，离开后继续计时。
- 点击 `Close`、在获得焦点时按下 `Escape` 或激活 `Action` 都会发出关闭请求，实际业务副作用由应用事件回调处理。
- 受控模式下（传入 `open`），超时后只会发出一次关闭请求并等待外部状态更新。
- `Viewport` 提供无障碍区域命名（默认 `Notifications`）以及 `F8` 快捷键快速聚焦通知区域。多条通知的排队管理由应用层控制。

## API

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'defaultOpen', type: 'boolean', default: 'true' },
    { name: 'duration', type: 'number', default: '5000' },
    { name: 'paused', type: 'boolean', default: 'false' },
    { name: 'politeness', type: "'polite' | 'assertive'", default: 'polite' },
    { name: 'a11yLabel', type: 'string', default: 'Notifications' },
    { name: 'hotkey', type: 'string', default: 'F8' },
    { name: 'disabled', type: 'boolean', default: 'false' },
  ]}
/>

属性归属说明：

- `defaultOpen`、`duration`（设为 `0` 时常驻）、`paused`、`politeness` 属于 `Root`（传入 `open` 进入受控模式）。
- `a11yLabel`、`hotkey` 属于 `Viewport`。
- `disabled` 属于 `Action` 与 `Close`。
