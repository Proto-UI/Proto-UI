Toast 用于以非打断方式展示限时实时通知，支持悬停或聚焦时暂停倒计时、键盘快捷键定位以及可选操作按钮。本页示例使用 **Shadcn Rhea** 风格。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可直接从 `@proto.ui/prototypes-shadcn/toast` 导入组件原型并使用对应宿主 Adapter 适配。

```ts
import {
  toastViewport,
  toastRoot,
  toastTitle,
  toastDescription,
  toastAction,
  toastClose,
} from '@proto.ui/prototypes-shadcn/toast';
```

## 用法

```tsx
<ShadcnToastViewport a11yLabel="Notifications">
  <ShadcnToastRoot defaultOpen={false} duration={5000}>
    <ShadcnToastTitle>Event has been created</ShadcnToastTitle>
    <ShadcnToastDescription>Sunday, December 03, 2023 at 9:00 AM</ShadcnToastDescription>
    <ShadcnToastAction a11yLabel="Undo event creation">Undo</ShadcnToastAction>
    <ShadcnToastClose>Dismiss</ShadcnToastClose>
  </ShadcnToastRoot>
</ShadcnToastViewport>
```

Toast 由 `Root`、`Viewport`、`Title`、`Description`、`Action` 和 `Close` 六个部件组成：

- `Root` 默认持续显示 `5000ms` 后自动请求关闭；将 `duration` 设为 `0` 可保持常驻不自动关闭。
- 指针悬停在通知上，或键盘焦点位于 `Action` / `Close` 上时，剩余倒计时会自动暂停，离开后继续计时。
- 点击 `Close`、在获得焦点时按下 `Escape` 或激活 `Action` 都会发出关闭请求，实际业务副作用由应用事件回调处理。
- 受控模式下（传入 `open`），超时后只会发出一次关闭请求并等待外部状态更新。
- `Viewport` 提供无障碍区域命名（默认 `Notifications`）以及 `F8` 快捷键快速聚焦通知区域。多条通知的排队管理由应用层控制。

事件与暴露方法：

- **事件**：`Root` 暴露 `openChange`（`{ open: boolean; reason: string }`）；`Action` 暴露 `action`（`void`）。
- **方法**：`Root` 暴露 `openToast()`、`close(reason?)`、`pause()`、`resume()`；`Viewport` 暴露 `focusFirst()`。
