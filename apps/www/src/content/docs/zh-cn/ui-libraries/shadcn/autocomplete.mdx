## 用法

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

### 部件结构

由 `Root`、`Input`、`Content`、`Item`、`Empty` 与 `Trigger` 组合而成：

- `Root` 的 `value` 表示已提交的文本，`inputValue` 表示当前输入框内的查询内容。
- 选中某条建议时会提交该项的 `textValue`；当没有高亮的匹配项时，按 `Enter` 可直接提交当前输入的自由文本。

### 过滤与交互行为

- **内置过滤**：默认按 `textValue` 与 `keywords` 过滤，忽略大小写及重音符号。设置 `filter={false}` 时可由应用层自行传入过滤后的子项。
- **空状态与禁用项**：`Empty` 根据实际匹配数量自动显隐；禁用项不可提交，重复值的选项也会被忽略。
- **键盘与输入法**：使用方向键浏览建议列表时，焦点始终停留在单行输入框内；输入法（IME）组合输入期间不会误触选择。
- **受控模式**：`open`、`value`、`inputValue` 各自独立支持受控，传入对应属性即可进入受控模式。

## API

传入 `value`、`inputValue` 或 `open` 会使对应状态进入受控模式。

以上属性属于 `Root`。其他部件属性默认值：

- **Input**：`placeholder`、`a11yLabel`、`name` 均默认为 `''`。
- **Content**：`side="bottom"`、`align="start"`、`sideOffset={4}`、`collisionPadding={8}`。
- **Item**：`value`、`textValue`、`keywords` 均默认为 `''`，`disabled` 默认为 `false`。
- **Trigger**：`disabled` 默认为 `false`。
