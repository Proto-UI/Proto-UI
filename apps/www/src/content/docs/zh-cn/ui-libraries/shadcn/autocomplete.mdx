## 安装

Autocomplete 当前仅在源码工作区提供，尚未进入 0.2.0 稳定版；可在工作区内直接引入 `@proto.ui/prototypes-shadcn/autocomplete` 并适配到 Web Components、React、Vue 3 或 Vue 2。

## 用法

```html
<proto-ui-shadcn-autocomplete-root a11y-label="Framework">
  <proto-ui-shadcn-autocomplete-input
    placeholder="Search frameworks…"
  ></proto-ui-shadcn-autocomplete-input>
  <proto-ui-shadcn-autocomplete-trigger size="icon">
    <span class="sr-only">Toggle suggestions</span>
  </proto-ui-shadcn-autocomplete-trigger>
  <proto-ui-shadcn-autocomplete-content>
    <proto-ui-shadcn-autocomplete-item value="next" text-value="Next.js" keywords="react ssr">
      Next.js
    </proto-ui-shadcn-autocomplete-item>
    <proto-ui-shadcn-autocomplete-item value="astro" text-value="Astro" keywords="islands static">
      Astro
    </proto-ui-shadcn-autocomplete-item>
    <proto-ui-shadcn-autocomplete-empty>No matching frameworks.</proto-ui-shadcn-autocomplete-empty>
  </proto-ui-shadcn-autocomplete-content>
</proto-ui-shadcn-autocomplete-root>
```

### 部件结构与交互行为

- **部件组成**：由 `Root`、`Input`、`Trigger`、`Content`、`Item` 与 `Empty` 组合而成。所有部件自动继承 `Root` 或外层 [Style Scope](../style-scope/) 的 `styleProfile`。
- **值与查询分离**：`Root` 的 `value` 表示已提交的文本，`inputValue` 表示当前输入框内的查询内容。选中建议项时提交其 `textValue`；无高亮匹配项时按 `Enter` 可直接提交自由文本。
- **内置过滤与空状态**：默认按 `textValue` 与 `keywords` 过滤，忽略大小写及重音符号；设置 `filter={false}` 时由应用层提供已过滤子项。`Empty` 按实际匹配数量自动显隐，禁用项与重复值选项不可提交。
- **键盘与输入法**：方向键浏览建议时焦点始终停留在输入框内，IME 组合输入期间不会误触选择。

## 示例

### 关键词与忽略重音匹配

内置过滤会同时匹配 `textValue` 与 `keywords`，并自动折叠重音符号（输入 `cafe`、`coffee` 或 `brazil` 均可命中对应条目）。

### 无触发器的自由文本提交

省略 `Trigger` 即可作为纯输入联想框使用；当输入内容不在建议列表中时，按 `Enter` 直接提交自定义文本。

### 禁用与只读状态

`disabled` 会禁用输入与弹层交互；`readOnly` 保留可读值并阻止修改或弹出建议。

### Root 事件与方法

- **事件**：`valueChange`（`{ value, textValue, reason }`）、`inputValueChange`（`{ value, composing }`）、`openChange`（`{ open, reason }`）。
- **方法**：`openPopup()`、`close()`、`setInputValue(value, composing?)`、`select(value, reason?)`。
