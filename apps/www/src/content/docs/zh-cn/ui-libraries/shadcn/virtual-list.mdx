Virtual List 将完整的逻辑条目序列与物理 DOM 节点分离，仅在可见视口及预渲染缓冲区间内创建列表项，适用于超长列表和可变高度内容。本页示例使用 **Shadcn Rhea** 风格。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `@proto.ui/prototypes-shadcn/virtual-list` 导入组件原型，并结合 `@proto.ui/prototypes-base/virtual-list/web` 接入 Web 滚动视口。

## 用法

Virtual List 由 `Root`、`Viewport` 与 `Content` 三个部件组成：`Root` 负责维护有序逻辑键集合（`itemKeys`）与风格上下文，`Viewport` 承担滚动与键盘聚焦，`Content` 作为列表容器接收按需挂载的行节点。

```ts
import { AdaptToWebComponent, setElementProps } from '@proto.ui/adapter-web-component';
import {
  virtualListRoot,
  virtualListViewport,
  virtualListContent,
} from '@proto.ui/prototypes-shadcn/virtual-list';
import { attachWebVirtualList } from '@proto.ui/prototypes-base/virtual-list/web';

AdaptToWebComponent(virtualListRoot);
AdaptToWebComponent(virtualListViewport);
AdaptToWebComponent(virtualListContent);

const list = document.querySelector('shadcn-virtual-list-root')!;
const viewport = document.querySelector('shadcn-virtual-list-viewport')!;
const content = document.querySelector('shadcn-virtual-list-content')!;

setElementProps(list, {
  styleProfile: 'rhea',
  itemKeys: Array.from({ length: 1000 }, (_, i) => `event-${i + 1}`),
  overscanItems: 3,
  maxMaterializedItems: 60,
});

const host = attachWebVirtualList({
  viewport,
  content,
  collection: list.getExposes().getCollection(),
  estimateSize: 64,
  renderItem(key) {
    const row = document.createElement('div');
    row.className = 'border-b border-border/60 px-4 py-3 text-sm';
    row.textContent = key;
    return row;
  },
});

// 滚动定位到指定条目，卸载时清理监听与节点
host.ensureVisible('event-250', 'center');
// host.dispose();
```

### 结构与无障碍

- `Root` 声明 `role="region"` 并绑定 `a11yLabel`，同时自动适配当前 `styleProfile` 的圆角、边框与外环。
- `Viewport` 继承 `Scroll Area` 的滚动与焦点管理，聚焦时显示与当前风格一致的内嵌焦点环。
- `Content` 声明 `role="list"`；Web 宿主挂载的每一行会自动写入 `role="listitem"`、`aria-posinset` 与 `aria-setsize`。

### 进阶：自定义渲染宿主

- 每个逻辑列表实例同一时刻仅允许挂载一个活跃渲染宿主；`attachWebVirtualList` 会自动管理生命周期并在 `Root` 卸载或销毁时清理节点与 `ResizeObserver`。
- 替换宿主前需先调用旧宿主的 `dispose()`；非 Web 自定义宿主可通过 `collection.acquireMaterializer(onRetired)` 接入同一边界。

## 示例

### 滚动到指定条目

调用 `ensureVisible(key, align)` 可按 `start`、`center`、`end` 或 `nearest` 将任意逻辑键滚动到可见区域内。
