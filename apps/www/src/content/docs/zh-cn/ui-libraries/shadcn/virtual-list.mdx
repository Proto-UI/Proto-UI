Virtual List 将完整的逻辑条目序列与物理渲染节点分离，仅在可见窗口及预渲染缓冲区间内创建列表项，适用于超长列表和可变高度内容。本页示例使用 **Shadcn Rhea** 风格。

## 用法

Virtual List 由 `Root`、`Viewport` 和 `Content` 组成：

- 核心逻辑模型管理有序的稳定 `itemKeys`、`overscanItems` 缓冲项数、`maxMaterializedItems` 渲染上限以及基于 generation 的状态提交。
- 在 Web 端，通过 `virtual-list/web` 导出的 `attachWebVirtualList` 连接真实滚动视口，自动处理可变项高度测量、占位间距、按 key 复用行节点、滚动定位到指定 key 以及监听清理。

### 渲染宿主生命周期

- 每个逻辑列表实例同一时刻仅允许挂载一个活跃的渲染宿主。`attachWebVirtualList` 会在挂载节点与监听前自动获取独占租约；若需替换宿主，请先调用旧宿主的 dispose 方法再挂载新宿主。
- 自定义非 Web 宿主可通过模型的 `acquireMaterializer(onRetired)` 接口注册租约（使用 `attachWebVirtualList` 时无需重复获取）。
- 当 `Root` 卸载或销毁时，组件会自动退休当前宿主、清理已渲染节点与观察器并忽略旧宿主的延迟回调；若首次渲染或观察器安装失败，租约会自动释放以便重试。
