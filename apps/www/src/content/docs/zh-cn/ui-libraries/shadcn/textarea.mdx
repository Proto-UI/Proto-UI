Textarea 封装单个原生多行文本编辑器，提供统一的受控/非受控值管理、输入法组合事件、无障碍关联以及焦点环与禁用样式。本页示例使用 **Shadcn Rhea** 风格。

## 安装

0.2.0 稳定版 CLI 的组件清单尚未收录此组件。要在应用中复现工作区预览，请安装同一提交构建的 CLI、Shadcn 原型包与目标适配器，用该 CLI 初始化项目，再运行本地命令生成组件封装。

<InstallCommandCard command="npm exec -- proto-ui add wc shadcn-textarea" manager="npm" />

将命令中的 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的组件封装。

## 用法

```tsx
import { ShadcnTextareaRoot } from '../proto-ui/components/react';
```

```tsx
<ShadcnTextareaRoot placeholder="Type your message here." rows={4} />
```

- **内容边界与属性**：Textarea 直接管理单个原生 `<textarea>` 控件，不接受额外子元素，支持 `rows`、`maxLength`、`minLength`、`wrap`、`placeholder`、`readOnly` 与 `disabled` 等常见属性。
- **风格预设（`styleProfile`）**：支持 `vega`、`nova`、`maia`、`lyra`、`mira`、`luma`、`sera`、`rhea` 与 `new-york-v4`（`new-york` 作为兼容别名）；省略或设为 `inherit` 时优先继承最近的 [Style Scope](../style-scope/)，否则回退到 `new-york-v4`。
- **重置与焦点方法**：`resetValue()` 可将非受控编辑器恢复为初始值，在受控模式下发出恢复初始值的请求，即使处于 `readOnly` 或 `disabled` 状态也可调用并结束进行中的输入法组合；`focusSelf()` 与 `blurSelf()` 用于程序化焦点管理。
- **表单字段组合**：在表单中使用时，可从 `@proto.ui/prototypes-shadcn/field` 导入 `fieldTextarea`，与 `Field`、`FieldLabel`、`FieldDescription` 及 `FieldError` 组合以自动关联标签、说明与校验状态；完整示例见 [Form 配方](../form/)。

## API

以下属性属于 `Root`（传入 `value` 可进入受控模式；未限制长度时 `minLength` 与 `maxLength` 为 `-1`）：

    { name: 'autoComplete', type: 'string', default: "''" },

    { name: 'describedBy', type: 'string', default: "''" },

/>

- **暴露状态**：`value`、`disabled`、`readOnly`、`focused`、`focusVisible`、`composing`（在 `FieldTextarea` 中额外暴露 `invalid` 与 `pending`）。
- **暴露方法**：`focusSelf(options?)`、`blurSelf()`、`resetValue()`。
- **事件**：`valueChange`、`change`、`compositionStart`、`compositionUpdate`、`compositionEnd`。
