可从屏幕上下左右四个边缘滑出的模态抽屉面板，支持内容自适应高度、纵向滚动以及可拖拽吸附档位。本页示例采用 **Shadcn Rhea** 风格。

当前仅在源码工作区 `@proto.ui/prototypes-shadcn/drawer` 中提供，尚未随 0.2.0 稳定版 CLI 发布。

## 用法

```tsx
import {
  ShadcnButton,
  ShadcnDrawerRoot,
  ShadcnDrawerTrigger,
  ShadcnDrawerMask,
  ShadcnDrawerContent,
  ShadcnDrawerHandle,
  ShadcnDrawerHeader,
  ShadcnDrawerTitle,
  ShadcnDrawerDescription,
  ShadcnDrawerFooter,
  ShadcnDrawerClose,
} from '../proto-ui/components/react';
```

```tsx
<ShadcnDrawerRoot styleProfile="rhea">
  <ShadcnDrawerTrigger styleProfile="rhea">
    <ShadcnButton styleProfile="rhea" variant="outline">Open Drawer</ShadcnButton>
  </ShadcnDrawerTrigger>
  <ShadcnDrawerMask styleProfile="rhea" />
  <ShadcnDrawerContent styleProfile="rhea" side="bottom">
    <ShadcnDrawerHandle styleProfile="rhea" />
    <ShadcnDrawerHeader styleProfile="rhea">
      <ShadcnDrawerTitle styleProfile="rhea">Move Goal</ShadcnDrawerTitle>
      <ShadcnDrawerDescription styleProfile="rhea">
        Set your daily activity goal.
      </ShadcnDrawerDescription>
    </ShadcnDrawerHeader>
    <div className="flex-1 overflow-y-auto px-4">{/* Content */}</div>
    <ShadcnDrawerFooter styleProfile="rhea">
      <ShadcnButton styleProfile="rhea">Submit</ShadcnButton>
      <ShadcnDrawerClose styleProfile="rhea">
        <ShadcnButton styleProfile="rhea" variant="outline">Cancel</ShadcnButton>
      </ShadcnDrawerClose>
    </ShadcnDrawerFooter>
  </ShadcnDrawerContent>
</ShadcnDrawerRoot>
```

### 部件结构

```text
DrawerRoot
├── DrawerTrigger
├── DrawerMask
└── DrawerContent
    ├── DrawerHandle
    ├── DrawerHeader
    │   ├── DrawerTitle
    │   └── DrawerDescription
    └── DrawerFooter
        └── DrawerClose
```

- **触发与关闭按钮**：在 `rhea` 等现代风格下，`Trigger` 与 `Close` 保持无样式语义封装，直接嵌套 `Button` 提供交互外观；在 `new-york-v4` 下默认自带 outline 按钮外观（长文案可启用 `wrap`）。
- **尺寸约束**：通过 `Content` 的 `minExtent` / `maxExtent` 控制面板尺寸（支持 `'logical'`、`'root-text'`、`'available'` 与 `'available-minus-root-text'`）。上下抽屉默认自适应内容高度并受安全可用区域限制；左右抽屉默认宽度上限为 `20` 个 `root-text` 单位。
- **吸附与无障碍**：提供 `(0, 1]` 比例数组 `snapPoints` 后，`Handle` 具备具名 `separator` 语义并支持方向键及 `Home` / `End` 调整档位；按下 `Escape` 或点击遮罩可关闭抽屉，关闭后焦点自动归还触发器。

## API

### Root

传入 `open` 进入受控模式，并通过 `openChange` 监听状态变更请求；同时暴露 `openDrawer()`、`close()` 与 `toggle()` 方法。
