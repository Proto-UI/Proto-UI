## 用法

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

### 部件组合与触发按钮

- **Trigger 与 Close**：在 Rhea 风格下，`Trigger` 与 `Close` 保持无样式语义封装，直接内嵌公开的 `Button`（如 `outline` 样式，长文本可加 `wrap`）作为物理交互与焦点表面，并将暴露的有效 `disabled` 状态透传给内部按钮。
- **网格布局兼容**：`Root` 会渲染包装节点；当直接放入 CSS Grid 时，可在 React 中设置 `hostStyle={{ display: 'contents' }}`（Web Components 中设置 `display: contents`）避免产生多余网格行。
- **样式细节**：Rhea `Content` 在外层包裹 `p-4` 透明边距并内嵌圆角上限 24px 的弹出面板，底部 `Handle` 宽 100px、高 `0.375rem`、上间距 `1rem`。

### 尺寸约束（`minExtent` / `maxExtent`）

通过 `Content` 的 `minExtent` 与 `maxExtent` 控制面板尺寸（推荐使用它而非单独的 CSS `width`）：

- 支持的长度单位包括 `logical`、`root-text`、`available` 与 `available-minus-root-text`（`value` 为非负有限数值），例如 `maxExtent={{ unit: 'logical', value: 480 }}`。
- 上下抽屉默认按内容高度自适应，最大高度自动限制在安全可用区域内；左右抽屉默认按比例宽度展示，默认上限为 20 个 `root-text` 单位。
- 运行中若传入非法尺寸配置，组件会忽略非法配置并保持最后有效的尺寸约束（`extentValid` 为 `false`）。

### 吸附档位与拖动关闭

- **内容自适应模式**：上下抽屉未传 `snapPoints`（或为空数组）时按内容高度展示，此时 `Handle` 作为纯指针拖拽把手使用。
- **显式吸附模式**：传入大于 `0` 且不超过 `1` 的比例数组（如 `[0.5, 1]`，自动排序去重）即可开启多档吸附，通过 `defaultSnapPoint`（非受控）或 `snapPoint` + `snapPointChange`（受控）管理当前档位；此时 `Handle` 支持方向键及 `Home` / `End` 调整。
- 设置 `dragDismissible={false}` 可禁止通过拖动关闭，同时保留 `Close` 按钮、`Escape` 键与点击外部关闭。受控模式下若外部拒绝关闭请求，拖动预览会自动回弹至当前已提交状态。

## API

传入 `open` 进入受控模式。

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'a11yLabel', type: 'string', default: "''" },
  ]}
/>

以上属性属于 `Root`。其他部件属性默认值：

- **Content**：`side` 默认 `'bottom'`（可选 `'top' | 'right' | 'bottom' | 'left'`），另支持 `minExtent`、`maxExtent`、`snapPoints`、`snapPoint`、`defaultSnapPoint`、`dragDismissible`。
- **Trigger / Close**：`disabled` 默认 `false`。
- **Handle**：`disabled` 默认 `false`，`a11yLabel` 默认 `'Resize drawer'`。
- **Overlay**：`passthrough` 默认 `false`。
- **Title / Description / Header / Footer**：无额外属性。
