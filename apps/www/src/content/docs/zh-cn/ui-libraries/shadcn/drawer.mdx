本页以 **Shadcn Rhea** 为目标，支持profile的parts均显式选择Rhea；下文headless触发器/action-body缺口仍开放，尚不称整页外观统一。这不修改公共组件的兼容默认值，也不代表全部浏览器、原生宿主和视觉验收已完成。Surface/Text 等中性原子仍保留各自公开语义，外观主题由消费组合提供。

Rhea Content以透明外层`p-4`包围自己的inset popover表面；圆角上限24px与shadow均归公共原型。Header/Footer保留各自profile的padding。底部Handle仍是真实resize控件：共用100px宽、1rem上间距，并采用Rhea的0.375rem高，而非旧New York的0.5rem。非底部方向的resize控件仍保留；它尚不是上游仅底部的装饰条或整块Content拖动表面，既有extent/side语义及剩余交互差异保持明示。

短示例使用上游demo的居中、全宽max-w-sm内容列，这是消费组合，不是所有Drawer的最大宽度。历史New York Trigger/Close按钮paint（默认高2.25rem、水平padding1rem、可选wrap）仅保留在该兼容profile。现代Rhea Trigger/Close是headless语义owner；必须先组合共享被动Rhea action body，才能称本页按钮外观完整Rhea。不能加入第二个Button hook或嵌套焦点owner掩盖此缺口。

top/bottom Content 默认按内容高度显示；目前保留的兼容最大高度为可用高度减去 6 个根文本单位，始终受安全可用区域约束。它尚未实现 New York 的 viewport 相对 max-h-80vh 及独立 mt-24/mb-24 间距。Content.minExtent/maxExtent 接受中立长度：unit 为 logical、root-text、available 或 available-minus-root-text，value 为非负有限数字。最小高度超过安全上限时以上限优先。本纵向草稿中，left/right 保留既有受限 20rem 呈现。

本项目将 Content 组合为纵向 Scroll surface；固定 New York DrawerContent wrapper 本身未声明 overflow utility。长内容示例的 Close 仍在同一滚动区域内。

Root 支持受控 open 或非受控 defaultOpen。禁用命令不激活。调用方拒绝关闭请求时，拖动预览恢复到实际受控状态。

snapPoints 缺省、null 或空数组时按内容高度显示；非空有效数组启用显式吸附，点为大于 0 且不超过 1 的比例，并排序去重。单独 snapPoint 不开启吸附。显式比例的分母为完整安全上限，不再隐含乘以 85%。defaultSnapPoint 为本地状态；snapPoint 与 snapPointChange 为受控状态。非法纵向 points 或长度记录会被拒绝，不转成满高度。

内容自适应模式的 Handle 是 aria-hidden 的专用指针把手，不提供键盘 resize，也不会因 Enter/Space 变成 Close。显式 snap 保留有名称的 separator、方向键、Home/End 和范围值。Content.dragDismissible=false 禁止拖动关闭；独立 Close、Escape 和外部关闭仍遵循既有协议。接触中断和受控请求拒绝会恢复已接受的呈现。

运行中非法尺寸更新令 extentValid=false，取消 Handle 输入并保留最后有效意图，宿主仍按当前安全约束重算。初始非法输入会在呈现前被拒绝：Root 保留逻辑 open 值，Mask 等待唯一有效的 Content 声明。这些示例使用静态验证的合法输入；本草稿不宣称任意输入安全，也不代表 native、编译器、打包消费或完整 Finf 验收完成。

## API

Drawer 是工作区源码，没有公开的 `proto-ui add` 目标。传入 `open` 进入受控模式。

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'a11yLabel', type: 'string', default: "''" },
  ]}
/>

这些属性属于 Root。Content 的 `side` 默认 `bottom`。Trigger 与 Close 的 `disabled` 默认 `false`。Handle 的 `disabled` 默认 `false`，`a11yLabel` 默认 `Resize drawer`。Overlay 的 `passthrough` 默认 `false`。Title、Description、Header、Footer 没有属性。
