## 用法

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

### 部件结构

`Checkbox Group` 由 `Root`、`Item` 与 `All` 三个部件组成：

- **Root**：统一管理选中值数组（`value` / `defaultValue`）、禁用、只读与无障碍名称（`ariaLabel`）。
- **Item**：单个复选框项，接收 `value` 与 `disabled`；每个选项独立参与 `Tab` 顺序，按 `Space` 切换（`Enter` 不切换）。
- **All**：汇总全部可用项的选中状态（勾选、横线半选或未选），点击时批量切换可用项并保持禁用项的原有状态。

### 受控与表单集成

- 传入 `value` 进入受控模式：切换操作触发 `valueChange` 事件，由外部决定是否更新；`getValue()` 返回当前值数组的副本，重复 `value` 的项会被忽略。
- 置于 `Field` 或 `FormField` 内时，`Root` 会自动上报数组值、组焦点与校验状态，支持标签点击激活、必填校验、表单提交序列化与重置。
- 样式部件内置 `aria-hidden` 视觉指示图标（勾选为对勾、混合为横线、未选为空框），不依赖单一颜色区分状态。
