Root 通过 value/defaultValue 管理字符串数组，支持 disabled/readOnly/ariaLabel。Item 使用 value/disabled；All 汇总可用项并切换全选，保留禁用项的选择。每项独立 Tab，空格切换，Enter 不切换。受控请求只发 valueChange，不覆盖作者值；getValue 返回副本，重复值拒绝含糊切换。在 Field/FormField 内，Root 上报规范数组、组合焦点及本地策略，支持标签激活、必填校验、Form 序列化和复位。不创建隐藏 HTML 表单项。

四家族继承同一 Base 行为。部件： root, item, all.

视觉家族的 Item/All 使用 aria-hidden 被动指示器：选中为勾、混合为横线、未选中为空框，不只靠颜色区分。SVG 不添加交互拥有者、语义角色或 Tab 停靠点。
