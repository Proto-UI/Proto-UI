## 用法

```tsx
import {
  ShadcnCheckboxGroupRoot,
  ShadcnCheckboxGroupAll,
  ShadcnCheckboxGroupItem,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <ShadcnCheckboxGroupRoot
      styleProfile="rhea"
      defaultValue={['email']}
      ariaLabel="Notification channels"
    >
      <ShadcnCheckboxGroupAll>All notifications</ShadcnCheckboxGroupAll>
      <ShadcnCheckboxGroupItem value="email">Email updates</ShadcnCheckboxGroupItem>
      <ShadcnCheckboxGroupItem value="sms">SMS alerts</ShadcnCheckboxGroupItem>
    </ShadcnCheckboxGroupRoot>
  );
}
```

### 部件结构与键盘交互

- **Root**：管理选中字符串数组（`value` / `defaultValue`）、排列方向（`orientation`）、禁用、只读与组级无障碍名称（`ariaLabel`）。
- **Item**：单个复选框项，接收唯一的 `value` 与可选 `disabled`；每个可用项独立参与 `Tab` 顺序，按 `Space` 切换选中（`Enter` 不切换）。
- **All**：根据所有可用项自动推导勾选、横线半选（`aria-checked="mixed"`）或未选状态，点击时仅批量切换可用项并保留已禁用项的原状态。
- **表单与无障碍**：内置 `aria-hidden` 视觉指示图标（对勾、横线与空框），焦点环直接作用在复选框本体上，并自动接入 `Field` / `FormField` 的标签点击聚焦、必填校验、提交序列化与重置。

### 事件、方法与状态

- **Root 事件**：`valueChange`（载荷 `{ value: string[] }`）。
- **Root 方法**：`getValue(): string[]`（返回当前选中数组副本）、`resetValue(): boolean`、`focusSelf(): void`。
- **Root 状态**：`checked`、`indeterminate`、`disabled`、`readOnly`（及来自 `Field` 绑定的 `invalid`、`fieldRequired`、`fieldDisabled`、`fieldReadOnly`）。
- **Item / All 状态**：`checked`、`indeterminate`、`disabled`、`readOnly`、`focused`、`focusVisible`。
