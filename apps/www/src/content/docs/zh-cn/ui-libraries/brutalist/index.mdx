Brutalist 是 Proto UI 的新粗野主义（Neo-Brutalism）风格组件库。它在复用 Base 交互与无障碍行为的基础上，提供高对比度的黑色粗边框、硬阴影、紧实间距与利落的按压反馈。使用组件时建议配合阅读[设计契约](./design-contract/)。

## 安装与使用

在已有项目中安装 0.2.0 稳定版（以 Web Component 为例）：

```sh
npx @proto.ui/cli@0.2.0 init --prototypes brutalist
npx @proto.ui/cli@0.2.0 add wc brutalist-button
```

使用 pnpm：

```sh
pnpm dlx @proto.ui/cli@0.2.0 init --prototypes brutalist
pnpm dlx @proto.ui/cli@0.2.0 add wc brutalist-button
```

CLI 会安装 `@proto.ui/prototypes-brutalist` 及对应的框架 Adapter，并在项目中生成本地封装文件。按[快速开始](/zh-cn/start-here/quick-start/)引入一次生成的样式，即可按 [Button 用法](./components/button/)开始使用。使用 React 或 Vue 3 时，将 `wc` 替换为 `react` 或 `vue`；Vue 2.6 支持目前位于源码工作区。
