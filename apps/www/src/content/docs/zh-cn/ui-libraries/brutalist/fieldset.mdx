Brutalist Fieldset 为一组关联表单字段提供语义分组、标题、说明文本以及可嵌套继承的禁用状态管理，默认采用无外框的竖排布局与清晰字重层级。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。

## 用法

```tsx
import { FieldsetRoot, FieldsetLegend, FieldsetDescription } from '@/components/brutalist/fieldset';
import { FieldRoot, FieldLabel, FieldControl } from '@/components/brutalist/field';

export function Example() {
  return (
    <FieldsetRoot>
      <FieldsetLegend>Address Information</FieldsetLegend>
      <FieldsetDescription>We need your address to deliver your order.</FieldsetDescription>
      <FieldRoot required>
        <FieldLabel>Street Address</FieldLabel>
        <FieldControl placeholder="123 Main St" />
      </FieldRoot>
    </FieldsetRoot>
  );
}
```

### 部件组成

- **Root**：定义 `group` 语义容器并管理实际禁用状态（结合自身 `disabled` 与外层 `Fieldset` 状态），采用无外框 `gap-4` 竖排布局与 `font-sans font-medium` 正文角色。
- **Legend**：可选的组标题，使用符合 Brutalist 设计契约的 `font-heading font-bold` 标题字体角色并保留原文大小写，支持 `variant="legend"`（默认）与 `variant="label"`，不添加 Tab 停靠点。
- **Description**：可选的组说明文本，支持换行并在启用与禁用状态下提供清晰的视觉反馈。

每个分组内最多放置一个 `Legend` 和一个 `Description`。组件会自动维护 `aria-labelledby` 与 `aria-describedby` 关联并在卸载时清理，无需手写 DOM ID，嵌套分组的关联也彼此隔离。

### 嵌套禁用策略

`Fieldset` 支持多层嵌套，实际禁用状态为自身 `disabled` 与祖先 `Fieldset` 禁用状态的逻辑或；重新启用外层不会覆盖内层显式设置的 `disabled`：

- 仅禁用最外层 `outer` 时，`outer`、`middle`、`inner` 均处于禁用状态。
- 将 `middle` 设为禁用后再启用 `outer`：`middle` 与 `inner` 保持禁用。
- 再启用 `middle`：`inner` 随之恢复启用（除非自身 `disabled` 仍为 `true`）。

组内的 `Field`（包括位于 `Legend` 内部的 `Field`）都会自动继承 `Fieldset` 的禁用状态。
