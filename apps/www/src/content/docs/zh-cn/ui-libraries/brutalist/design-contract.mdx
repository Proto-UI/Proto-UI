Brutalist 的视觉系统参考 [neobrutalism.dev](https://www.neobrutalism.dev/)，并以 [neobrutalism-components (`3306a802724874a85f93079702b2795370a279d4`)](https://github.com/ekmas/neobrutalism-components/tree/3306a802724874a85f93079702b2795370a279d4) 的 MIT 许可样式方案为基础；Proto UI 在此之上维护基于 Base 的独立语义实现。

## 字体

参考设计默认使用 DM Sans，而非全站等宽或全大写排版。各组件通过生成的样式 token 绑定字体角色：

- 普通控件、菜单项、说明与正文：`font-sans font-medium`（DM Sans 500）
- Dialog 标题、Tabs Trigger 与 Toggle：`font-heading font-bold`（DM Sans 700）
- 常用字号：默认标签 14px/20px，Badge 12px/16px，Dialog 标题 18px（紧凑行高与字距）
- 大小写保留开发者传入的原文；代码与快捷键标签可使用独立的等宽字体

主题通过 `--pui-font-sans` 与 `--pui-font-heading` 声明 `"DM Sans", ui-sans-serif, system-ui, sans-serif`。文档站自托管未经修改的 DM Sans 可变字体（保留 [DM Sans 版权与 SIL OFL 1.1 许可](/fonts/dm-sans-OFL.txt)）。组件本身不发起网络字体请求；业务应用可自行加载 DM Sans，未加载时回退到系统无衬线字体，中文字符使用系统 CJK 字体渲染。

## 几何与嵌套表面

- 普通控件与面板：5px 圆角（`rounded-base`）搭配 2px 黑色边框
- Switch 轨道/滑块与 Scroll Area 滑块：完整胶囊形或圆形；Checkbox 保持方形
- Tabs List 与内层 Trigger 各自保持圆角，通过内边距分隔
- Card 的 Header、Content、Footer 以及 Tabs Content 默认不叠加额外内框
- Scroll Area Root 负责圆角裁切溢出，Viewport 保持直角，滚动条几何由宿主处理
- Spinner 保留居中的圆形开口环

圆角属于这套视觉语言的基础特征，无需全局改成直角，也无需给每个内部区块重复套边框。

## 层级与动效

Brutalist 按组件类别定义静止阴影与交互反馈，而不是套用单一的悬停或按压规则：

| 类别（包含组件） | 静止阴影 | 悬停 / 按压反馈 |
| --- | --- | --- |
| 抬起型操作控件 — Button、raised Surface、Dialog / Dropdown / Select / Collapsible Trigger、Accordion Item | 4px 4px 零模糊黑影 | 按压时沿阴影方向位移 `+4px, +4px` 并收起外影，无额外悬停抬升 |
| 抬起型面板 — Card、Dialog / Alert Dialog / Command Dialog / Drawer Content、Calendar | 4px 4px 零模糊黑影 | 保持静止，不添加按压位移 |
| 浮层内容面板 — Dropdown / Context / Menubar / Navigation Menu Content、Autocomplete / Combobox / Select Content、Popover | 3px 3px 零模糊前景影 | 无悬停或按压位移，由浮层定位决定位置 |
| 浮层内容例外 — Hover Card Content | 无硬阴影 | 保留组件的 200ms 进入/退出过渡与浮层定位 |
| 扁平选择控件 — Toggle、Tabs Trigger | 无阴影、无位移 | Toggle 悬停与按压保持 `border-black`，激活态 2px 内框在按压期间持续显示；未选中 Tabs Trigger 在悬停时显示填充与边框，选中项保持配色不变 |
| 二态胶囊开关 — Switch | Root 与 Thumb 均无阴影 | 悬停与按压保持几何不变，仅 Thumb 以 150ms 过渡滑动 20px |
| 可编辑表面 — Input、Textarea、Number Field、Input OTP | Input / Textarea 无阴影；Number Field / Input OTP 辅控为 2px 2px 边框色阴影 | 无位移反馈，聚焦时显示 focus ring |
| 被动标签 — Badge、Text、Label、Kbd | 无阴影 | 无交互动效 |
| 加载占位 — Skeleton | 无阴影 | 保持静态，不启用闪烁脉冲动画 |
| 滚动装饰与分隔线 — Scroll Area 各部件、Separator | 无阴影 | 无交互动效，Root 保持圆角溢出裁切 |
| 扁平遮罩 — Dialog Mask | 无阴影 | 打开与关闭时执行 150ms 淡入淡出 |
| 扁平交互项 — Dropdown / Context / Menubar / Select Item | 无阴影 | 仅切换背景色，无位移或阴影变化 |

分组容器（Toolbar Root、Toggle Group Root、Toast Root）作为被动表面保留 3px 3px 前景阴影，不应用控件按压位移。

按钮类控件默认采用即时落位（instant snap）反馈；Switch 的滑块单独使用 150ms 平滑位移。Toggle 在按压期间持续显示 2px 内框，确保激活状态不仅依赖颜色区分。

## 配色与暗色模式

默认沿用参考设计的蓝色调色板：主色 `#5294ff`、浅蓝背景 `#dcebfe`、白色中性表面与黑色文字边框。内置的 `canary`、`mint`、`lavender`、`coral`、`sky` 强调色对同样可用，并统一搭配黑色前景文字。

由于上游参考样式表未包含暗色方案，Proto UI 额外维护了一套配套的暗色主题（暗色画布、浅色正文、高可读性 destructive 文本色及随主题自适应的 focus ring）。组件全部通过主题 CSS 变量动态重绘，自定义主题时请成对调整背景色与前景色。

## 主题交付与无障碍

- **主题来源**：`BRUTALIST_THEME` 是包内 Light/Dark 配色、字体角色与圆角变量的统一定义。使用 `proto-ui init --prototypes brutalist` 初始化项目即可引入；若启用 `--no-styles`，则由应用自行提供对应的语义变量与字体。
- **焦点与对比度**：交互控件提供高可见度的外偏焦点环（相邻对比度不低于 3:1）；Tabs Content 保留原生焦点提示；Portal 渲染的浮层自动继承主题与字体变量。
- **可读性细节**：Select 主色填充上的占位符使用黑色前景文字（保证亮暗模式下对比度均不低于 4.5:1）；Textarea 使用主题前景色边框，确保编辑边界在亮暗模式下与相邻表面均保持至少 3:1 的对比度。
- **许可署名**：改编的视觉样式配方保留 Samuel Breznjak 的 MIT 版权声明与许可；分发的 DM Sans 字体保留 SIL OFL 1.1 许可。
