Brutalist Form 协调组内所有显式注册的 `FormField`，在全部启用字段通过校验后按字段名汇总数据并触发 `submit` 事件，同时提供配套的 Brutalist 提交、重置与异步校验取消机制。

## 安装

当前组件在工作区源码中提供，将于 `0.3.0-rc.1` 及后续版本中提供。

```bash
proto-ui add <react|vue|vue2|wc> brutalist-form
```

## 用法

```tsx
import {
  BrutalistFormRoot,
  BrutalistFormField,
  BrutalistFormSubmit,
  BrutalistFormReset,
  BrutalistFieldLabel,
  BrutalistFieldControl,
  BrutalistFieldError,
} from '../proto-ui/components/react';

export function ExampleBrutalistForm() {
  return (
    <BrutalistFormRoot ariaLabel="Profile form" onSubmit={({ values }) => console.log(values)}>
      <BrutalistFormField name="username" required>
        <BrutalistFieldLabel>Username</BrutalistFieldLabel>
        <BrutalistFieldControl placeholder="ada_lovelace" />
        <BrutalistFieldError />
      </BrutalistFormField>
      <div className="flex items-center gap-2">
        <BrutalistFormSubmit>Submit</BrutalistFormSubmit>
        <BrutalistFormReset>Reset</BrutalistFormReset>
      </div>
    </BrutalistFormRoot>
  );
}
```

### 部件组成与交互

- **Root**：收集所有显式注册的 `FormField`，统一执行同步与异步校验，校验通过后通过 `submit` 事件返回按字段名组织的数据。已禁用的字段自动排除，重复字段名在序列化时抛出 `FORM_DUPLICATE_NAME`；设置 `disabled` 会级联到内部字段。
- **Field**：继承 `FieldRoot` 能力并通过 `name` 标识提交键名，使用 DM Sans 字体与高对比度错误提示色。
- **Submit / Reset**：采用 Brutalist 2px 黑色边框与 4px 零模糊硬阴影，支持指针与键盘激活，并响应 `prefers-reduced-motion` 偏好。
- **隐式回车提交与重置**：在聚焦的单行 `Field`、`Number Field` 或 `Input OTP` 内按 `Enter` 可触发表单提交；`requestReset()` 还原非受控初值并向受控所有者提议重置，`resetValidation()` 仅清理校验错误。
