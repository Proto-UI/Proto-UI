## 用法

### 部件组成

Combobox 由 `Root`、`Input`、`Content`、`Item`、`Empty` 和 `Trigger` 组成：

- **Root**：分别管理已选选项值 `value`、搜索框文本 `inputValue` 和弹层状态 `open`，三者均可独立受控。
- **Input**：承载单行搜索编辑器；使用方向键切换高亮选项时焦点始终保持在输入框内，输入法合成期间不会触发误选。
- **Content**：锚定在输入框下方的选项浮层，支持方向、对齐、偏移与碰撞留白配置。
- **Item**：候选项，按 `textValue` 与 `keywords` 执行忽略大小写和重音的匹配；禁用项或重复值不可提交。
- **Empty**：无匹配项时自动显示的空状态提示。
- **Trigger**：展开或收起下拉列表的触发按钮。

### 自定义过滤

默认开启内置过滤（`filter={true}`）。如需在外部执行异步搜索或自定义匹配规则，将 `filter` 设为 `false` 并直接传入过滤后的 `Item` 列表即可。

分别传入 `value`、`inputValue` 或 `open` 可独立控制对应状态。

### 其他部件属性

- **Input**：`placeholder?: string`、`a11yLabel?: string`、`name?: string`（默认均为 `''`）
- **Content**：`side`（默认 `'bottom'`）、`align`（默认 `'start'`）、`sideOffset`（默认 `4`）、`collisionPadding`（默认 `8`）
- **Item**：`value`、`textValue`、`keywords`（默认均为 `''`）、`disabled?: boolean`（默认 `false`）
- **Empty**：无独立属性
- **Trigger**：`disabled?: boolean`（默认 `false`）
