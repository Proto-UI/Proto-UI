Brutalist Button 继承 Base Button 的完整交互与无障碍行为，搭配 5px 圆角（`rounded-base`）、2px 黑色结构边框、4px 硬偏移阴影与悬停/按压落位反馈。

## 安装

<InstallCommandCard
  commands={{
    npm: 'npx @proto.ui/cli@latest add wc brutalist-button',
    pnpm: 'pnpm dlx @proto.ui/cli@latest add wc brutalist-button',
  }}
  manager="npm"
/>

将 `wc` 替换为 `react`、`vue` 或 `vue2` 即可生成对应框架的本地组件入口。

## 用法

```tsx
import { BrutalistButton } from '../proto-ui/components/react';

export function Example() {
  return <BrutalistButton>Button</BrutalistButton>;
}
```

Brutalist Button 支持 `solid`、`surface`、`destructive` 与 `noShadow` 四种变体，`solid` / `noShadow` 可搭配 `main`、`mint`、`lavender`、`coral`、`sky` 强调配色对。悬停与按压时，抬起型按钮沿 4px 硬阴影方向落位（减弱动态偏好下即时切换）；键盘聚焦显示高对比度外偏焦点环。
