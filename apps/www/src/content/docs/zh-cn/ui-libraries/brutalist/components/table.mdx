Table 用于展示静态结构化数据，完整维护 [Base Table](/zh-cn/ui-libraries/base/table/) 的行列索引、表头关系与跨度元数据。Brutalist 风格采用 2px 黑色外框与 4px 实心偏移阴影、主色表头行、黑色行分隔线与双线上边框表尾，并在正文行悬停时提供即时浅色高亮。

如需排序、选择、分页、过滤或键盘网格导航等交互能力，请使用 [Data Table](/zh-cn/ui-libraries/brutalist/components/data-table/)。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可从 `@proto.ui/prototypes-brutalist` 或 `@proto.ui/prototypes-brutalist/table` 导入全部五个部件：

```ts
import {
  brutalistTableRoot,
  brutalistTableCaption,
  brutalistTableRow,
  brutalistTableHeaderCell,
  brutalistTableCell,
} from '@proto.ui/prototypes-brutalist/table';
```

## 用法

```html
<div class="w-full overflow-x-auto">
  <brutalist-table-root>
    <brutalist-table-caption>A list of your recent invoices.</brutalist-table-caption>
    <brutalist-table-row section="header" last-in-section>
      <brutalist-table-header-cell header-key="invoice" header-kind="column" style="width: 100px">
        Invoice
      </brutalist-table-header-cell>
      <brutalist-table-header-cell header-key="status" header-kind="column"
        >Status</brutalist-table-header-cell
      >
      <brutalist-table-header-cell header-key="method" header-kind="column"
        >Method</brutalist-table-header-cell
      >
      <brutalist-table-header-cell header-key="amount" header-kind="column" style="text-align: end">
        Amount
      </brutalist-table-header-cell>
    </brutalist-table-row>
    <brutalist-table-row section="body" last-in-section>
      <brutalist-table-header-cell header-key="inv001" header-kind="row"
        >INV001</brutalist-table-header-cell

      <brutalist-table-cell style="text-align: end">$250.00</brutalist-table-cell>
    </brutalist-table-row>
  </brutalist-table-root>
</div>
```

### 组件结构

```text
Root
├── Caption
├── Row (section="header")
│   └── HeaderCell (headerKind="column")
├── Row (section="body")
│   ├── HeaderCell (headerKind="row")
│   └── Cell (headers=[...])
└── Row (section="footer")
    ├── HeaderCell (headerKind="row")
    └── Cell (headers=[...])
```

- `Root`：表格容器，管理有序行列索引并通过 `getStructure()` 暴露结构快照；横向滚动容器请在外层自行包裹。
- `Row`：提供 `section`（`'header' | 'body' | 'footer'`）与 `lastInSection` 两个视觉属性，表头采用主色填充（`bg-main text-main-foreground`），正文行在指针悬停时即时切换 `bg-main/20`，表尾使用双线黑边与对比表面。
- `HeaderCell`：采用 `font-heading font-semibold` 与逻辑 `text-start` 对齐。

## API

### Root & Caption

`Root` 与 `Caption` 不声明额外属性；`Root` 通过 `getStructure()` 暴露当前行列结构与诊断快照。
