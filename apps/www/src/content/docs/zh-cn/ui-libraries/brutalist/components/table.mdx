Table 用于展示静态结构化数据，完整维护行列索引、表头关系与跨行列属性。Brutalist 风格采用 2px 黑边加 4px 实心偏移阴影外框、黑色行分隔线、加粗表头与双线上边框表尾，并在正文行悬停时提供浅色强调高亮。

如需排序、选择、分页、过滤或键盘网格导航等交互能力，请使用 [Data Table](/zh-cn/ui-libraries/brutalist/components/data-table/)。

## 用法

### 组件结构

Table 由五个部件组成：`Root`、`Caption`、`Row`、`HeaderCell` 和 `Cell`。

- `Root`：表格容器，管理有序行列索引并通过 `getStructure()` 暴露结构快照。如需横向滚动，可在外层自行包裹滚动容器。
- `Caption`：表格标题。
- `Row`：表格行，提供 `section`（`'header' | 'body' | 'footer'`，默认 `'body'`）和 `lastInSection`（默认 `false`）两个纯视觉属性，用于控制表头、正文与表尾的边框和悬停着色。
- `HeaderCell`：表头单元格，通过 `headerKey` 与 `headerKind` 声明列/行表头，支持 `headers`、`rowSpan` 与 `columnSpan`。
- `Cell`：普通数据单元格，支持通过 `headers` 关联对应表头以及 `rowSpan` / `columnSpan` 跨度。

## API

`Root` 不声明属性（提供 `getStructure()` 方法读取当前行列与表头结构）：

<ApiPropsTable headers={{ name: '属性', type: '类型', default: '默认值' }} rows={[]} />

其余子部件属性默认值：

- **Caption**：无属性。
- **Row**：`section` 默认 `'body'`，`lastInSection` 默认 `false`。
- **Cell**：`headers` 默认 `[]`，`rowSpan` 与 `columnSpan` 默认 `1`。
- **HeaderCell**：`headerKey` 默认 `''`，`headerKind` 默认 `'column'`，`headers` 默认 `[]`，`rowSpan` 与 `columnSpan` 默认 `1`。
