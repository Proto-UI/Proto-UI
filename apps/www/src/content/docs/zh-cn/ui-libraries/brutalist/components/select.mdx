## 安装

已包含在 `@proto.ui/prototypes-brutalist@0.2.0` 中。可通过 CLI 目标 `brutalist-select` 添加，或从 `@proto.ui/prototypes-brutalist/select` 导入。

## 用法

### Trigger 外观

默认的 `Trigger` 保持扁平样式（5px 圆角、2px 黑边、DM Sans 500）。当选择器与带硬影的按钮并排放置（例如页头工具条中的 Runtime / Style 切换控件）时，可在 `brutalist-select-trigger` 上设置 `appearance="elevated"`：

- 静止状态下呈现向右/下 4px 的黑色硬影；悬停或按下时向右下位移 4px 并收起阴影，按下不会叠加第二次位移。
- 设置 `appearance="flat"`、省略或移除该属性可恢复扁平外观。两种外观下 `size`、配色、焦点环、键盘选择与禁用行为保持一致，弹层 `Content` 始终保持扁平，无需通过额外 CSS 补影。

- 下拉列表区分当前高亮焦点项与已提交选中值；未按住鼠标键的指针移动可更新高亮项，触摸、手写笔滚动与拖拽则交由浏览器原生滚动与捕获处理。
- 在受控模式下，传入 `open` 或 `value` 即可接管对应状态；即使拒绝选中提议，当前已提交值依然保持稳定。弹层默认采用 popper 定位并支持碰撞避让。

## API

以下前五个属性（`defaultOpen`、`defaultValue`、`disabled`、`readOnly`、`closeOnSelect`）属于 `Root`（传入 `open` 或 `value` 进入受控模式），`size` 与 `appearance` 属于 `Trigger`：

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'defaultValue', type: 'string', default: "''" },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'readOnly', type: 'boolean', default: 'false' },
    { name: 'closeOnSelect', type: 'boolean', default: 'true' },
    { name: 'size', type: "'sm' | 'default'", default: 'default' },
    { name: 'appearance', type: "'flat' | 'elevated'", default: 'flat' },
  ]}
/>

其余子部件属性默认值：

- **Trigger**：另支持 `accessibleLabel`（默认 `''`）。
- **Value**：`placeholder` 默认 `''`。
- **Content**：支持 Transition 属性；`position` 默认 `'popper'`，`side` 默认 `'bottom'`，`align` 默认 `'center'`，`sideOffset` 默认 `4`，`alignOffset` 默认 `0`，`avoidCollisions` 默认 `true`，`collisionPadding` 默认 `10`。
- **Item**：`disabled` 默认 `false`，`value` 与 `textValue` 默认 `''`；`closeOnSelect` 未设置时继承 `Root` 配置。
- **Group**、**Label**、**Surface**、**ItemText**、**Viewport**、**Separator**：无属性。
