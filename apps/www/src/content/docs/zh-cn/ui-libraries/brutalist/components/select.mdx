## 安装

<InstallCommandCard command="npx @proto.ui/cli@latest add wc brutalist-select" manager="npm" />

将命令中的 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的组件封装，或直接从 `@proto.ui/prototypes-brutalist/select` 导入。

## 用法

```tsx
import {
  BrutalistSelectContent,
  BrutalistSelectItem,
  BrutalistSelectRoot,
  BrutalistSelectTrigger,
  BrutalistSelectValue,
} from '../proto-ui/components/react';

export function FruitSelect() {
  return (
    <BrutalistSelectRoot>
      <BrutalistSelectTrigger className="w-48" accessibleLabel="Fruit selector">
        <BrutalistSelectValue placeholder="Select a fruit" />
      </BrutalistSelectTrigger>
      <BrutalistSelectContent>
        <BrutalistSelectItem value="apple" textValue="Apple">
          Apple
        </BrutalistSelectItem>
        <BrutalistSelectItem value="banana" textValue="Banana">
          Banana
        </BrutalistSelectItem>
        <BrutalistSelectItem value="blueberry" textValue="Blueberry">
          Blueberry
        </BrutalistSelectItem>
      </BrutalistSelectContent>
    </BrutalistSelectRoot>
  );
}
```

### 组合结构

当前 Brutalist Select 导出以下五个核心部件：

```text
BrutalistSelectRoot
├── BrutalistSelectTrigger
│   └── BrutalistSelectValue
└── BrutalistSelectContent
    └── BrutalistSelectItem
```

- **外观与动效**：默认 `Trigger` 保持扁平外观；设置 `appearance="elevated"` 时静止呈现 4px 黑色硬影，悬停或按下时向右下位移 4px 并收起阴影（受 `prefers-reduced-motion` 控制）。弹层 `Content` 始终保持扁平，默认采用 `popper` 定位。
- **键盘与指针**：方向键与类型预查浏览选项，`Enter` / `Space` 或点击提交选中，`Escape` 取消并将焦点返回 `Trigger`。
