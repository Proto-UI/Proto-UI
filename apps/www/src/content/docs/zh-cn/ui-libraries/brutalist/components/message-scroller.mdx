Message Scroller 面向聊天与实时日志流场景，采用 2px 粗黑边框、5px 基础圆角与 4px 硬阴影的 Brutalist 表面规范：当用户停留在底部时自动跟随新消息，向上翻阅历史后可通过浮动跳转按钮快速回到末尾。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可直接从 `@proto.ui/prototypes-brutalist/message-scroller` 导入原型并使用目标框架适配器封装。

```ts
import {
  messageScrollerRoot,
  messageScrollerViewport,
  messageScrollerJump,
} from '@proto.ui/prototypes-brutalist/message-scroller';
```

## 用法

为 `Root` 的父容器提供明确高度，`Root` 负责圆角与 4px 阴影外框，`Viewport` 负责内部直角纵向滚动，`Jump` 浮动在右下角并在按压时沿阴影方向落位 `+4px, +4px`：

```tsx
<div className="h-96 w-full max-w-md">
  <BrutalistMessageScrollerRoot a11yLabel="Team chat messages">
    <BrutalistMessageScrollerViewport>
      <div className="flex flex-col gap-3 p-4 pb-16">
        {messages.map((message) => (
          <div key={message.id}>{message.text}</div>
        ))}
      </div>
    </BrutalistMessageScrollerViewport>
    <BrutalistMessageScrollerJump>Scroll to end ↓</BrutalistMessageScrollerJump>
  </BrutalistMessageScrollerRoot>
</div>
```

### 组件结构与行为

- **Root**：提供 `rounded-base`、2px 黑框与 4px 硬阴影外框，并协调末端跟随状态、`newContentCount` 与无障碍名称 `a11yLabel`。
- **Viewport**：保持直角内边界与 `overflow-y-auto`，负责纵向滚动与历史位置保持。
- **Jump**：主色抬起型操作按钮，按压即时落入阴影；点击回到底部且不抢占键盘焦点。
