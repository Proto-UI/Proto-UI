Message Scroller 面向聊天与实时消息流场景，复用 Scroll Surface 的末端跟随能力：当用户停留在列表底部时自动跟随新消息，向上翻阅历史记录后可通过跳转按钮回到最新内容。

## 用法

### 组件结构

Message Scroller 由 `Root`、`Viewport` 和 `Jump` 组成：

- `Root`：管理末端跟随状态、新消息计数与滚动区域的无障碍名称。
- `Viewport`：承载消息列表内容的可滚动视图容器。
- `Jump`：用户离开底部时用于快速返回最新消息的按钮（接受 Button 属性）。

### 关键行为

- **末端自动跟随**：只有当用户当前位于底部时，追加的新内容才会触发自动滚底；用户主动向上浏览时不会强行拉回。
- **新消息计数**：`newContentCount` 由应用层按自身业务规则传入，组件不会自行猜测未读数量。
- **焦点保持**：点击 `Jump` 回到底部时不会主动抢占或移动当前焦点。
- **无障碍名称**：通过 `Root` 的 `a11yLabel` 为滚动区域提供无障碍名称，默认值为 `'Messages'`。
