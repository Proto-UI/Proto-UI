Brutalist Input 是独立的单行纯文本输入框组件，采用 `2.5rem` 相对字号高度、2px 边框、5px 圆角与无静止阴影设计，聚焦时显示清晰的黑色焦点环。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

- **CLI 目标**：`proto-ui add <react|vue|vue2|wc> brutalist-input`
- **包导出**：从 `@proto.ui/prototypes-brutalist/input` 或包根导入 `brutalistInputRoot`

## 用法

- 支持非受控 `defaultValue` 与受控 `value`，完整保留原生单行编辑、输入法合成事件、`disabled` / `readOnly` 状态以及无障碍命名属性（`ariaLabel`、`labelledBy`、`describedBy`）。
- 高度与内边距基于 `rem` 定义，可随根字号自适应缩放。需要内置校验与错误提示时，可配合 `Field` 与 `Form` 使用。
