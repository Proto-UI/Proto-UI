Brutalist Input 是基于 [Base Input](../../../base/input/) 的单行文本输入框，采用 `2.5rem` 相对字号高度、2px 粗边框、`rounded-base`（5px）圆角与无静止阴影设计，并在亮暗模式下提供随主题自适应的高对比度焦点环。

## 安装

<InstallCommandCard command="npx @proto.ui/cli@latest add wc brutalist-input" manager="npm" />

当前在工作区源码中提供；将 `wc` 替换为 `react`、`vue` 或 `vue2` 可生成对应框架封装，也可直接从 `@proto.ui/prototypes-brutalist/input` 导入 `brutalistInputRoot`。

## 用法

```tsx
import { BrutalistInputRoot } from '@/components/ui/brutalist-input';

export function Example() {
  return <BrutalistInputRoot placeholder="Email" inputMode="email" ariaLabel="Email" />;
}
```

- **受控与编辑状态**：支持非受控 `defaultValue` 与受控 `value`，保留原生单行编辑、输入法组合事件、`disabled` / `readOnly` 状态以及无障碍命名属性。
- **对比度与排版**：采用 DM Sans（`font-sans font-medium`）、柔和占位符配色（`placeholder:text-muted-foreground`）与 `rem` 相对尺寸；在暗色模式下焦点环自动切换为浅色 `ring-ring` 以维持清晰边界。

### 暴露状态、方法与事件

- **状态**：`value`、`disabled`、`readOnly`、`focused`、`focusVisible`、`composing`
- **方法**：`focusSelf(options?)`、`blurSelf()`、`resetValue(value?: string): boolean`
- **事件**：`valueChange`、`change`、`compositionStart`、`compositionUpdate`、`compositionEnd`
