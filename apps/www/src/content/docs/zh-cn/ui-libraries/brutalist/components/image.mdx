Brutalist Image 为图像展示提供统一的 `rounded-base`、`2px` 黑色边框与 4px 偏移硬阴影画框，并支持适应方式、无障碍替代文本与加载生命周期事件。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

- **CLI 目标**：`proto-ui add <react|vue|vue2|wc> brutalist-image`
- **包导出**：从 `@proto.ui/prototypes-brutalist` 或 `@proto.ui/prototypes-brutalist/image` 导入 `Root`

## 用法

- **适应模式与响应式**：通过 `fit` 在 `'contain'`（默认）、`'cover'` 与 `'fill'` 之间切换；组件默认应用 `block max-w-full h-auto` 以适应容器宽度，具体尺寸由外层布局或消费者指定。
- **无障碍模式**：信息型图像使用 `a11yMode="informative"` 并提供 `alternativeText`；装饰性图像设为 `a11yMode="decorative"` 以对辅助技术隐藏。
- **加载状态**：每次更换 `source` 会开启新的加载周期，通过 `loadingStatus`（`'idle' | 'loading' | 'loaded' | 'error'`）与 `loadingStatusChange` 事件追踪加载结果；加载失败时画框保持完整，应用可按需在外层叠加占位或错误提示。
