Brutalist Image 为图像展示提供统一的 `rounded-base`、`2px` 实线画框与 4px 偏移硬阴影（在暗色画布下自动切换为主题前景色边框与阴影），并保留完整的缩放适配、无障碍模式与加载生命周期事件。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。`Image` 不通过 `proto-ui add` CLI 注册；请直接从 `@proto.ui/prototypes-brutalist` 或 `@proto.ui/prototypes-brutalist/image` 导入 `BrutalistImageRoot`（别名 `brutalistImageRoot`）。

## 用法

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { BrutalistImageRoot } from '@proto.ui/prototypes-brutalist/image';

const BrutalistImage = createReactAdapter(React)(BrutalistImageRoot);

export function FramedPhoto() {
  return (
    <BrutalistImage
      source="/images/base-image/landscape.svg"
      a11yMode="informative"
      alternativeText="日光下的山脊"
      fit="cover"
      surfaceStyle={{ width: '100%', height: '200px' }}
    />
  );
}
```

- **画框与尺寸边界**：组件默认提供 `block max-w-full h-auto`、5px `rounded-base`、`2px` 边框与静止 `4px 4px` 硬偏移阴影，属于被动抬起型表面（无悬停抬升或按压位移）；宽高由外层容器或消费者决定。
- **适应模式与无障碍**：通过 `fit` 在 `'contain'`（默认）、`'cover'` 与 `'fill'` 之间切换；信息型图像使用 `a11yMode="informative"` 与非空 `alternativeText`，装饰性图像设为 `a11yMode="decorative"`。
- **加载状态追踪**：每次更新 `source` 会创建新的加载周期，通过 `loadingStatus` 与 `loadingStatusChange` 报告状态；加载失败时画框保持完整，由应用按需叠加回退提示或重试操作。
