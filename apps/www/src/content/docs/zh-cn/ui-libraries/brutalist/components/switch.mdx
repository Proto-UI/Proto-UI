Switch 用于在开启与关闭两种状态之间切换。Brutalist 风格采用 2px 黑边的胶囊轨道与白色圆形滑块，无外侧阴影，强调清晰的机械式状态切换。

## 安装

已包含在 `@proto.ui/prototypes-brutalist@0.2.0` 中。可通过 CLI 目标 `brutalist-switch` 添加，或从 `@proto.ui/prototypes-brutalist/switch` 导入。

## 用法

### 外观与动效

- **几何与配色**：在 16px 根字号下，轨道尺寸为 `24×48px`，白色圆形滑块为 `16px`。关闭时轨道呈中性底色，开启时切换为主色蓝；滑块保持白色，仅沿水平轴移动 `1.25rem`（20px，两端各留白 6px）。
- **状态反馈**：过渡时长为 `150ms`，开启 `prefers-reduced-motion: reduce` 后立即切换位置；按下时轨道不位移、不增加阴影；键盘聚焦时显示外偏移焦点环；禁用状态下保持外观并阻止激活。
- **文字与方向**：可见标签文本放在 Switch `Root` 内即可作为无障碍名称并支持点击切换，默认采用 DM Sans 字体（缺省字形回退到宿主字体）。滑块使用物理左右定位，在 RTL 父容器中同样保持居中且不越界。

### 交互说明

- 点击与键盘激活均可正常切换状态；传入 `checked` 可进入受控模式。
- 当前版本暂未启用滑动手势拖动，`draggable` 默认为 `false`（传入 `true` 会自动回退为 `false`）。
