Switch 用于在开启与关闭两种状态之间切换。Brutalist 风格采用 2px 黑色边框的胶囊轨道与白色圆形滑块，无外侧阴影，强调清晰的机械式状态切换。

## 安装

<InstallCommandCard command="npx @proto.ui/cli@latest add wc brutalist-switch" manager="npm" />

将命令中的 `wc` 替换为 `react`、`vue` 或 `vue2`，也可直接从 `@proto.ui/prototypes-brutalist/switch` 导入。

## 用法

```tsx
import { switchRoot, switchThumb } from '@proto.ui/prototypes-brutalist/switch';
```

```html
<proto-ui-brutalist-switch-root>
  <proto-ui-brutalist-switch-thumb></proto-ui-brutalist-switch-thumb>
  <span class="sr-only">Airplane Mode</span>
</proto-ui-brutalist-switch-root>
```

- **几何与配色**：默认尺寸轨道为 `24×48px`（`16px` 白色圆形滑块，位移 `20px`）；`size="sm"` 轨道为 `20×36px`（`12px` 滑块，位移 `12px`）。关闭时轨道为中性底色，开启时切换为主色蓝。
- **状态与动效**：滑块与轨道过渡时长为 `150ms`，开启 `prefers-reduced-motion: reduce` 后自动取消过渡动画；按下时轨道不位移、不增加阴影；键盘聚焦时显示外偏移焦点环。
- **交互说明**：支持点击与 `Space` 键切换及受控模式 `checked`。当前版本暂未启用滑动手势拖动，`draggable` 固定为 `false`。
