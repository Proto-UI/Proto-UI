## 安装

已包含在 `@proto.ui/prototypes-brutalist@0.2.0` 中。可通过 CLI 目标 `brutalist-textarea` 添加，或从 `@proto.ui/prototypes-brutalist/textarea` 导入。

## 用法

### 输入行为与外观

- **完整原生输入体验**：支持受控（`value`）与非受控（`defaultValue`）模式、归一化的 `valueChange` 与 `change` 事件、IME 组合输入安全的受控值恢复、`focus()` / `blur()` 方法，以及 `ariaLabel` / `labelledBy` / `describedBy` 无障碍关联。
- **视觉规格**：默认最小高度 80px、水平 12px / 垂直 8px 内边距、`text-sm` 行高与 DM Sans 500 字体，选区采用静态主色高亮；尺寸拖拽由浏览器或外层样式控制，不自动测量高度。

### 重置与表单集成

- 工作区源码中的 `resetValue()` 可将非受控输入框恢复为实例创建时的初始值（受控模式下提出变更请求），在 `readOnly` 或 `disabled` 状态下仍可调用，并会结束进行中的输入法组合。
- 如需接入表单标签、描述、错误信息与校验，请从 `@proto.ui/prototypes-brutalist/field` 导入 `fieldTextarea`，完整用法见 [Form 配方](../../form/)。
