## 安装

<InstallCommandCard
  commands={{
    npm: 'npx @proto.ui/cli@latest add wc brutalist-textarea',
    pnpm: 'pnpm dlx @proto.ui/cli@latest add wc brutalist-textarea',
  }}
  manager="npm"
/>

将命令中的 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的组件封装；也可直接从 `@proto.ui/prototypes-brutalist/textarea` 导入。

## 用法

```tsx
import { BrutalistTextareaRoot } from '../proto-ui/components/react';
```

```tsx
<BrutalistTextareaRoot placeholder="Type your message here." rows={4} />
```

- **输入与焦点语义**：支持受控（`value`）与非受控（`defaultValue`）模式、归一化的 `valueChange` 与 `change` 事件、IME 组合输入安全的受控值恢复、`focusSelf()` / `blurSelf()` / `resetValue()` 方法，以及 `ariaLabel` / `labelledBy` / `describedBy` 无障碍关联。
- **视觉规格**：默认最小高度 80px、水平 12px / 垂直 8px 内边距、`text-sm` 字号与 DM Sans 500 字体，选区采用静态主色高亮，暗色模式下边框自动切换为前景色以保持高对比度。
- **表单集成**：如需接入标签、描述、错误信息与校验状态，请从 `@proto.ui/prototypes-brutalist/field` 导入 `fieldTextarea`，完整用法见 [Form 配方](../../form/)。

## API

以下属性属于 `Root`（传入 `value` 可进入受控模式；未限制长度时 `minLength` 与 `maxLength` 为 `-1`）：

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'value', type: 'string | undefined', default: '非受控' },
    { name: 'defaultValue', type: 'string', default: "''" },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'readOnly', type: 'boolean', default: 'false' },
    { name: 'placeholder', type: 'string', default: "''" },
    { name: 'rows', type: 'number', default: '2' },
    { name: 'required', type: 'boolean', default: 'false' },
    { name: 'name', type: 'string', default: "''" },
    { name: 'autoComplete', type: 'string', default: "''" },
    { name: 'minLength', type: 'number', default: '-1' },
    { name: 'maxLength', type: 'number', default: '-1' },
    { name: 'wrap', type: "'soft' | 'hard'", default: "'soft'" },
    { name: 'ariaLabel', type: 'string', default: "''" },
    { name: 'labelledBy', type: 'string', default: "''" },
    { name: 'describedBy', type: 'string', default: "''" },
  ]}
/>

- **暴露状态**：`value`、`disabled`、`readOnly`、`focused`、`focusVisible`、`composing`（在 `FieldTextarea` 中额外暴露 `invalid` 与 `pending`）。
- **暴露方法**：`focusSelf(options?)`、`blurSelf()`、`resetValue()`。
- **事件**：`valueChange`、`change`、`compositionStart`、`compositionUpdate`、`compositionEnd`。
