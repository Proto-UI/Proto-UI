## 用法

### 选择模式（单选、多选与范围）

<PrototypePreviewer
  demoId="demo-brutalist-calendar-selection"
  initialRuntime="wc"
  runtimes={['wc', 'react', 'vue', 'vue2']}

| 模式       | 受控值 / 初始值                               | 变更事件                     |
| ---------- | --------------------------------------------- | ---------------------------- |
| `single`   | `value` / `defaultValue`：`YYYY-MM-DD` 字符串 | `onValueChange({ value })`   |
| `multiple` | `values` / `defaultValues`：日期字符串数组    | `onValuesChange({ values })` |
| `range`    | `range` / `defaultRange`：`{ from?, to? }`    | `onRangeChange({ range })`   |

- **多选模式**：点击或按 `Enter` / `Space` 切换日期，数组自动去重并按日期升序排列；可通过 `minSelected` / `maxSelected` 限制选中数量。
- **范围模式**：首次选择确定起点 `{ from }`，第二次选择完成含两端的 `{ from, to }`（反向选择自动按时间排序），再次点击则开启新范围，`{}` 表示清空。`minNights`（默认 `0`，允许单日范围）与 `maxNights` 限制起止日之间的天数差。
- **日期限制**：通过 `min`、`max` 与 `unavailable` 限制可选日期；跨越不可用日期的范围选择会被拒绝并保留原起点。`readOnly` 禁止更改选中值但保留翻月浏览。
- **范围状态**：`Day` 除 `selected` 外还暴露 `rangeStart`、`rangeEnd`、`rangeMiddle` 与 `rangePending`，用于区分端点、起止待定与中段高亮。

### 部件组成与月份显示

Calendar 由 `Root`、`Caption`、`Heading`、`Previous`、`Next`、`Grid`、`Weekdays`、`Weekday`、`Row` 和 `Day` 十个部件组成：

- 默认按当前月份与 `weekStartsOn`（`0` 表示周日）渲染覆盖整月所需的 4–6 周；设置 `fixedWeeks` 可固定渲染 6 周。可以预先放置 6 个带 `index`（0–5）的 `Row` 与 42 个带 `offset`（0–41）的 `Day`，多余行与日期格会自动隐藏并移出焦点路径。
- 日历不读取系统时钟；如需高亮“今天”，请由应用通过 `today` 传入 `YYYY-MM-DD` 字符串（自动输出 `aria-current="date"`）。初始显示月份优先级为：`month` > `defaultMonth` > 当前模式的选中日期 > `today` > `1970-01`。
- `direction="rtl"` 会镜像左右方向键，上下键与周边界语义保持不变。纯图标翻月按钮可通过 `a11yLabel` 设置无障碍名称。

### 年月选择器组合

`Caption` 本身是语义分组容器。如需提供月份/年份下拉跳转，可使用 `bindCalendarCaption(source, { month, year })` 将 Calendar 的 `month`、`disabled` 状态及 `requestMonth` 与真实 Select 组合，并在卸载时调用 `dispose()` 清理订阅。

传入 `value`、`values`、`range` 或 `month` 可分别控制对应状态。

### 其他部件属性

- **Day**：`date?: string`（默认 `''`），`offset?: number`（默认 `0`），`disabled?: boolean`（默认 `false`）
- **Row**：`index?: number`
- **Weekday**：`offset?: number`（默认 `0`）
- **Caption**：`a11yLabel?: string`（默认 `'Calendar navigation'`）
- **Previous / Next**：支持 Button 属性，`a11yLabel` 分别默认 `'Previous month'` 与 `'Next month'`
- **Grid / Heading / Weekdays**：无独立属性

### 方法

- `requestValue(date)`、`requestValues(dates)`、`requestRange(range)`、`requestMonth(month)`、`getValues()`、`getRange()`
