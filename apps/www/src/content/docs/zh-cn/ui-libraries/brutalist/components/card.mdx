Brutalist Card 是用于视觉分组内容的静态面板组件，由 5px 圆角、`2px` 黑色外框与 4px 硬黑阴影构成。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

- **CLI 目标**：`proto-ui add <react|vue|vue2|wc> brutalist-card`

## 用法

Card 提供 `Root`、`Header`、`Content` 和 `Footer` 四个部件：

- **Root**：外层容器，提供 5px 圆角、`2px` 黑色外框与 4px 偏移硬阴影，本身为被动布局容器。
- **Header / Footer**：负责头部与底部区域排布和间距，默认不加分段边框。
- **Content**：提供主体内容区域的水平间距。

标题与说明直接使用普通文本元素即可；如需在卡片内放置交互操作，请在内部组合 `Button` 或链接组件。

## API

Card 的 `Root`、`Header`、`Content` 与 `Footer` 仅接收传入的子元素，不声明独立属性。
