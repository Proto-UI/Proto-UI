Brutalist Card 是用于视觉分组内容的静态面板组件，采用 5px 圆角（`rounded-base`）、`2px` 黑色外框与 4px 零模糊硬黑阴影，支持默认与紧凑尺寸以及可选的区域分隔线。

把 `wc` 替换为 `react`、`vue` 或 `vue2` 即可生成对应框架封装；当前亦可在源码工作区直接从 `@proto.ui/prototypes-brutalist/card` 导入 `BrutalistCardRoot`、`BrutalistCardHeader`、`BrutalistCardContent` 与 `BrutalistCardFooter`。

<h2 id="usage">用法</h2>

```tsx
import {
  BrutalistCardRoot,
  BrutalistCardHeader,
  BrutalistCardContent,
  BrutalistCardFooter,
} from '@proto.ui/prototypes-brutalist/card';
```

```tsx
<BrutalistCardRoot>
  <BrutalistCardHeader>
    <div className="flex flex-col gap-1">
      <h3 className="font-heading text-base font-bold">Card Title</h3>
      <p className="text-sm text-muted-foreground">Card Description</p>
    </div>
  </BrutalistCardHeader>
  <BrutalistCardContent>
    <p className="text-sm">Card Content</p>
  </BrutalistCardContent>
  <BrutalistCardFooter>
    <p className="text-xs text-muted-foreground">Card Footer</p>
  </BrutalistCardFooter>
</BrutalistCardRoot>
```

结构组合方式：

```text
BrutalistCardRoot
├── BrutalistCardHeader
├── BrutalistCardContent
└── BrutalistCardFooter
```

- **排版与几何**：`Root` 作为抬起型面板保持 5px 圆角、`2px` 黑色外框与 4px 静止硬黑阴影（不添加按压位移）。标题推荐使用 `font-heading font-bold`（DM Sans 700），正文与辅助信息保留 `font-sans font-medium`。
- **尺寸与分隔线**：`Root` 支持 `size="sm"`（16px 间距与内边距）；`Header` 与 `Footer` 默认不加分段边框，按需传入 `divider={true}` 启用 `2px` 主题前景色分隔线。
- **纯展示语义**：四个部件均无交互角色、焦点或事件；交互操作请在卡片内组合 `BrutalistButton`、输入框或原生链接。
