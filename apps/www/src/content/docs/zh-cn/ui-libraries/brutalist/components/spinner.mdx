> 可用状态：Spinner 是仅工作区可用的 draft。npm 中的 `@proto.ui/prototypes-brutalist@0.2.0` 和 `@proto.ui/prototypes-brutalist@0.3.0-alpha.1` 单包均不导出 `./spinner`。生态发行 [V-PROTO-UI-0010](https://github.com/Proto-UI/Proto-UI/blob/main/spec/versions/V-PROTO-UI-0010.yaml) 仍为 `draft`；单包存在不构成生态发行激活或不可变 snapshot 的证据。生命周期：[P-BRUTALIST-SPINNER](https://github.com/Proto-UI/Proto-UI/blob/main/spec/prototypes/P-BRUTALIST-SPINNER.yaml) 仍为 `draft`；本页描述仓库内实现，不构成 active 协议保证。

Brutalist Spinner 是一个直接定义的 styled-only 视觉指示原型：2px `currentColor` 方形 ring，带一个开口 leading edge，无填充、圆角或柔和阴影。仅在未请求 reduced motion 时以 1000ms 一周线性旋转；`prefers-reduced-motion: reduce` 移除动画并保留开口 edge 作为非颜色方向提示。

Spinner 是 passive、contentless、从 accessibility tree 隐藏的（`aria-hidden`、无 role、不可聚焦），也不拥有 loading、busy、progress、completion、announcement 或 live-region 语义。

`size` 提供 `sm | md | lg` 三档（16 / 24 / 32 CSS pixel），默认 `md`，prop 移除后恢复默认值。

把它放在父级 Button 内或父级 status/busy region 中时，操作状态、accessible text、placement、alignment、delay、replacement 与 focus 连续性均由父级拥有；Spinner 不创建这些语义。
