Spinner 是一个纯视觉加载指示器，采用 2px `currentColor` 开口圆环设计，无背景填充和柔和阴影，可在按钮内联或状态区域中使用。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `@proto.ui/prototypes-brutalist/spinner` 导入组件原型（当前工作区 CLI 目标为 `brutalist-spinner`）。

## 用法

- **尺寸档位**：`size` 支持 `'sm'`（16px）、`'md'`（24px，默认值）与 `'lg'`（32px）；移除该属性会恢复为 `'md'`。
- **动态与无障碍偏好**：默认以 1000ms 为周期线性旋转；当用户开启 `prefers-reduced-motion: reduce` 时停止旋转，并保留开口弧段作为非颜色视觉提示。
- **状态归属**：Spinner 默认设置 `aria-hidden` 且不可聚焦。将其放在按钮内或加载文案旁时，由父级按钮或状态区域统一管理加载态、`aria-busy`、可访问文本与焦点衔接。
