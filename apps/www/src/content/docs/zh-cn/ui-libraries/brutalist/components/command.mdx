Brutalist Command 以 2px 黑色边框、硬投影和高对比高亮提供可搜索命令面板，点击或按下 `Enter` 即可发出 `execute` 事件。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供（`@proto.ui/prototypes-brutalist/command`）。

## 用法

```tsx
import {
  commandRoot,
  commandInput,
  commandContent,
  commandItem,
  commandEmpty,
  commandDialogContent,
} from '@proto.ui/prototypes-brutalist/command';
```

### 部件组合结构

```text
CommandRoot
├── CommandInput
└── CommandContent
    ├── CommandItem
    └── CommandEmpty
```

- **外框与层级**：`CommandRoot` 拥有统一的 2px 边框、`rounded-base` 圆角与 4px 硬投影，`CommandInput` 使用底部分隔线避免双层内框。
- **弹窗组合**：结合 `DialogRoot`、`DialogTrigger`、`DialogMask` 与 `CommandDialogContent` 可直接构建 Brutalist 命令弹窗。
- **过滤与键盘**：按 `textValue` 与 `keywords` 忽略大小写及重音匹配，设置 `filter={false}` 可改为外部过滤；方向键移动高亮时焦点留在输入框，IME 组合输入期间不触发执行。

### 其他部件与事件

- **Input**：`placeholder`、`a11yLabel`、`name` 均默认为 `''`。
- **Content**：`side="bottom"`、`align="start"`、`sideOffset={4}`、`collisionPadding={8}`。
- **Item**：`value`、`textValue`、`keywords` 均默认为 `''`，`disabled` 默认为 `false`。
- **Empty / DialogContent**：无独立公开属性；`DialogContent` 复用外层 `DialogRoot` 的打开与关闭状态。
- **事件**：`Root` 触发 `execute`、`valueChange`、`inputValueChange` 与 `openChange`。
