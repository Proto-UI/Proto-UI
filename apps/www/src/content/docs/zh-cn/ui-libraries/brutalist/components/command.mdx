## 用法

### 部件组成

Command 由 `Root`、`Input`、`Content`、`Item` 和 `Empty` 组成：

- **Root**：管理默认展开状态（`defaultOpen` 默认为 `true`）、查询文本 `inputValue`、过滤开关与循环导航配置；`value`、`inputValue` 与 `open` 均可独立受控。
- **Input**：单行搜索框；方向键浏览命令项时焦点保留在输入框内，输入法合成期间不会触发误执行。
- **Content**：承载命令列表的内联面板。
- **Item**：单个可执行命令，根据 `textValue` 和 `keywords` 执行忽略大小写及重音的过滤；禁用项或重复值不可触发。
- **Empty**：无匹配命令时显示的空状态区域。

### 命令执行

输入查询仅过滤候选列表，不会自动执行命令；用户点击某项或按 `Enter` 时触发 `execute` 事件并携带对应命令项信息。设置 `filter={false}` 可改为由应用层自行过滤列表。

分别传入 `value`、`inputValue` 或 `open` 可独立控制对应状态。

### 其他部件属性

- **Input**：`placeholder?: string`、`a11yLabel?: string`、`name?: string`（默认均为 `''`）
- **Content**：`side`（默认 `'bottom'`）、`align`（默认 `'start'`）、`sideOffset`（默认 `4`）、`collisionPadding`（默认 `8`）
- **Item**：`value`、`textValue`、`keywords`（默认均为 `''`）、`disabled?: boolean`（默认 `false`）
- **Empty**：无独立属性
