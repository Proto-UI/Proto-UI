Brutalist Meter 用于直观展示已知范围内的标量度量值（如磁盘占用、配额或健康评分），遵循 5px 圆角（`rounded-base`）、2px 黑框、DM Sans 正文排版与即时落位反馈，并按 `low`、`high` 与 `optimum` 将填充色划分为主蓝、金丝雀黄与警示红三档状态。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `@proto.ui/prototypes-brutalist/meter` 导入各部件原型：

```ts
import {
  meterRoot,
  meterLabel,
  meterTrack,
  meterIndicator,
  meterValue,
} from '@proto.ui/prototypes-brutalist/meter';
```

## 用法

```tsx
import { AdaptToReact } from '@proto.ui/adapter-react';
import {
  meterRoot,
  meterLabel,
  meterTrack,
  meterIndicator,
  meterValue,
} from '@proto.ui/prototypes-brutalist/meter';

const MeterRoot = AdaptToReact(meterRoot);
const MeterLabel = AdaptToReact(meterLabel);
const MeterTrack = AdaptToReact(meterTrack);
const MeterIndicator = AdaptToReact(meterIndicator);
const MeterValue = AdaptToReact(meterValue);

export function BrutalistStorageMeter() {
  return (
    <MeterRoot value={32} min={0} max={100} low={50} high={80} optimum={20} valueText="32%">
      <div className="flex items-center justify-between gap-2">
        <MeterLabel>Storage used</MeterLabel>
        <MeterValue />
      </div>
      <MeterTrack>
        <MeterIndicator />
      </MeterTrack>
    </MeterRoot>
  );
}
```

### 部件组成与状态区间

- **Root**：管理度量值 `value`、范围 `min` / `max` 以及阈值 `low`、`high`、`optimum`。数值自动钳制在 `[min, max]` 区间内；当 `min === max` 时比例为 `0`。
- **Label / Value**：保留原始大小写并使用 DM Sans 500 排版，`Value` 采用等宽数字（`tabular-nums`）展示 `valueText` 或规范化后的数值。
- **Track / Indicator**：轨道使用 5px 圆角、2px 黑色边框与 `bg-secondary-background` 表面；指示条随 `status` 分别切换 `bg-primary`（`optimal`）、`bg-canary`（`suboptimal`）与 `bg-destructive`（`critical`），保持即时切换无多余缓动。
- Meter 为被动展示组件（`role="meter"`），不增加键盘 Tab 停靠点，各部件同步暴露 `value`、`percentage`、`indeterminate` 与 `status`。
