Brutalist Meter 用于直观展示已知范围内的标量度量值（如磁盘占用、配额或健康评分），支持按 `low`、`high` 与 `optimum` 划分状态区间。

## 用法

### 部件组成

- **Root**：管理度量值 `value`、范围 `min` / `max` 以及阈值 `low`、`high`、`optimum`。数值会自动约束在 `[min, max]` 区间内；当 `min` 与 `max` 相等时比例为 `0`。
- **Label**：提供可读的计量名称。
- **Track / Indicator**：轨道与填充指示条，根据计算出的百分比呈现当前占比。
- **Value**：显示 `valueText` 或格式化后的当前数值。

### 状态区间与无障碍

- 配置 `low`、`high` 与 `optimum` 可将当前度量值自动分类为 `'optimal'`、`'suboptimal'` 或 `'critical'`，且不会改动原始数值。
- Meter 为被动展示组件，不增加键盘 Tab 停靠点，各部件自动同步暴露 `value`、`percentage`、`indeterminate` 与 `status`。
