## 用法

### 组件结构

Menubar 由 `Root`、`Trigger`、`Content` 和 `Item` 四个部分组成：

- `Root`：统一管理当前展开的面板状态和菜单栏范围的键盘协调。
- `Trigger`：菜单栏中的触发按钮，通过 `value` 与对应的 `Content` 配对。
- `Content`：展开后的命令面板容器，通过 `value` 对应触发器。
- `Item`：面板中的具体命令项。

### 键盘与焦点交互

- 整个菜单栏作为单个 `Tab` 停靠点，使用 `ArrowLeft` / `ArrowRight` 在触发器之间切换。
- 使用 `ArrowDown` / `ArrowUp` 打开面板并在命令项之间纵向移动，支持输入首字符快速跳转（typeahead）。
- 按 `Escape` 关闭当前面板并将焦点恢复到对应的 `Trigger`；点击外部区域或选择命令项也会关闭面板（可在 `Item` 上设置 `closeOnSelect={false}` 保持展开）。

### 受控与非受控模式

- 非受控模式：通过 `Root` 的 `defaultValue` 指定初始展开的面板。
- 受控模式：向 `Root` 传入 `value` 并监听变更请求事件，由外部状态决定是否切换展开面板。

其余子部件属性默认值：

- **Trigger**：`value` 默认 `''`，`disabled` 默认 `false`。
- **Content**：`value` 与 `a11yLabel` 默认 `''`，`sideOffset` 默认 `4`。
- **Item**：`value` 与 `textValue` 默认 `''`，`disabled` 默认 `false`，`closeOnSelect` 默认 `true`。
