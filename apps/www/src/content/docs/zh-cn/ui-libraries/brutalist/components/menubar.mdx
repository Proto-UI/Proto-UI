Brutalist 风格的横向菜单栏，采用 5px 圆角（`rounded-base`）、2px 黑色边框、DM Sans 字体与零模糊硬阴影层级，在顶部或操作区组织一组互斥展开的命令面板。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供；可直接从 `@proto.ui/prototypes-brutalist/menubar` 导入组件原型并通过对应宿主 Adapter 适配。

## 用法

```tsx
import {
  BrutalistMenubarRoot,
  BrutalistMenubarTrigger,
  BrutalistMenubarContent,
  BrutalistMenubarItem,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <BrutalistMenubarRoot a11yLabel="Workspace menu">
      <BrutalistMenubarTrigger value="file">File</BrutalistMenubarTrigger>
      <BrutalistMenubarContent value="file" a11yLabel="File menu">
        <BrutalistMenubarItem value="new-tab">New Tab</BrutalistMenubarItem>
        <BrutalistMenubarItem value="print">Print...</BrutalistMenubarItem>
      </BrutalistMenubarContent>
    </BrutalistMenubarRoot>
  );
}
```

### 组件结构

```text
MenubarRoot
├── MenubarTrigger (value="file")
├── MenubarContent (value="file")
│   ├── MenubarItem
│   └── MenubarItem
├── MenubarTrigger (value="edit")
└── MenubarContent (value="edit")
    └── MenubarItem
```

- `Root`：带 2px 黑框与 4px 硬影的菜单栏容器，管理当前展开面板和游走焦点。
- `Trigger`：菜单栏触发按钮，通过 `value` 与对应 `Content` 配对；聚焦或展开时切换至主色高亮与黑框。
- `Content`：遵循设计契约的浮层面板（`rounded-base`、`border-2 border-black` 与 3px 前景硬影）。
- `Item`：扁平交互命令项，支持 `inset` 缩进与 `variant="destructive"` 危险语义。

### 键盘与无障碍

- 整条菜单栏作为单个游走 `Tab` 停靠点，按 `ArrowLeft` / `ArrowRight` 切换触发器。
- 按 `ArrowDown` / `ArrowUp` 打开面板并在命令项之间纵向移动，支持首字符快速跳转（typeahead）。
- 按 `Escape` 关闭面板并将焦点交回对应 `Trigger`；点击外部或选择命令项后自动关闭（`closeOnSelect={false}` 可保持展开）。
