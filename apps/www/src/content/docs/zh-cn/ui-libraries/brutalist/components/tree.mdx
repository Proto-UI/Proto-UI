Tree 用于展示可展开、可单选的层级结构数据，遵循 Brutalist 的 5px 圆角、2px 黑色边框、零模糊硬阴影与 DM Sans 排版规范，并提供完整的方向键、首字符跳转与双向文字方向（LTR / RTL）导航。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可直接从 `@proto.ui/prototypes-brutalist/tree` 导入组件原型并使用对应宿主 Adapter 适配：

```ts
import { treeRoot, treeItem, treeGroup, treeToggle } from '@proto.ui/prototypes-brutalist/tree';
```

## 用法

```tsx
<BrutalistTreeRoot defaultValue="button" defaultExpandedKeys={['src', 'components']}>
  <div className="flex items-center gap-2">
    <BrutalistTreeToggle nodeKey="src" size="icon">
      ▾
    </BrutalistTreeToggle>
    <BrutalistTreeItem nodeKey="src" textValue="src" className="flex-1">
      src/
    </BrutalistTreeItem>
  </div>
  <BrutalistTreeGroup nodeKey="src">
    <BrutalistTreeItem nodeKey="button" parentKey="src" textValue="button.tsx">
      button.tsx
    </BrutalistTreeItem>
  </BrutalistTreeGroup>
</BrutalistTreeRoot>
```

### 结构、键盘导航与 Brutalist 视觉层次

- **层级关系**：每个 `Item` 提供树内唯一 `nodeKey` 并通过 `parentKey` 指向父节点；分支子项放在共享相同 `nodeKey` 的 `TreeGroup` 中，自动维护 `aria-controls` / `aria-labelledby`。
- **视觉层次**：`Root` 作为抬起面板携带 4px 零模糊黑影；`Item` 作为扁平交互项在悬停与选中时切换底色与黑框而不位移；`Toggle` 作为抬起操作控件在按压时沿阴影方向即时落位。
- **键盘导航与 RTL**：支持 `ArrowUp` / `ArrowDown`、`Home` / `End` 和首字母跳转；设置 `direction="rtl"` 会自动对调左右键并镜像层级缩进边线。
