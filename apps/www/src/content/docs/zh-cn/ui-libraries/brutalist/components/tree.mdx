## 用法

### 层级结构与分组关系

- 每个 `Item` 需提供树内唯一的 `nodeKey`，子节点通过 `parentKey` 指向所属父节点；重复键、缺失父节点或循环引用会被忽略以保持层级有效。
- 为每个 `TreeGroup` 设置与对应分支 `Item` 相同的 `nodeKey`，并将该分支的子 `Item` 放入分组中。组件会自动维护 `Item` 与 `Group` 之间的 `aria-controls` / `aria-labelledby` 关联，并在节点移除或变化时自动清理。
- 折叠分支会隐藏对应的 `Group` 但保留逻辑层级。如果折叠时焦点位于该分支内部，焦点会自动回到最近的可见祖先节点；树外焦点不受影响。

### 键盘导航与 RTL 适配

- `ArrowUp` / `ArrowDown`、`Home` / `End` 和首字母跳转按逻辑可见顺序移动焦点。
- 默认 LTR 模式下，`ArrowRight` 展开分支或进入子节点，`ArrowLeft` 折叠分支或返回父节点；在 `Root` 上设置 `direction="rtl"` 会自动对调左右键映射，并让分组缩进跟随文字方向。

### 只读与受控模式

- `readOnly` 阻止更改选中项，但仍允许键盘导航与展开/折叠分支。
- 向 `Root` 传入 `value` 或 `expandedKeys` 可分别进入受控模式，外部状态接受请求后再更新提交值。动态增删或移动节点会同步更新层级，不会触发伪造的用户选择事件。

## API

以下属性属于 `Root`（传入 `value` 或 `expandedKeys` 进入受控模式）：

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'defaultValue', type: 'string', default: "''" },
    { name: 'defaultExpandedKeys', type: 'readonly string[]', default: '[]' },
    { name: 'direction', type: "'ltr' | 'rtl'", default: 'ltr' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'readOnly', type: 'boolean', default: 'false' },
    { name: 'a11yLabel', type: 'string', default: 'Tree' },
  ]}
/>

其余子部件属性默认值：

- **Item**：`nodeKey`、`parentKey`、`textValue` 默认 `''`，`disabled` 默认 `false`。
- **Group**：接受 `nodeKey`。
- **Toggle**：额外接受 Button 的属性。
