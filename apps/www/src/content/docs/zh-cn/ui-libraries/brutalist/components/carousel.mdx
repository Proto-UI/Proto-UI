Brutalist Carousel 将等宽滑块条、连续可滚动视口与前后切换控制结合在一起，支持鼠标/触摸拖拽、滚轮/触控板滚动与键盘切换，松手或滚动停止后自动吸附至最近的项目边界。

## 用法

### 响应式视口与布局

- 通过 `slidesPerView`（默认 `1`）设置视口最多同时展示的等尺寸项数，通过 `minSlideSize`（默认 `0`）设定单项最小宽度（逻辑像素）。容器变窄时会自动缩减可见项数；最后一个吸附位置会贴齐内容末端，避免留下大片空白。
- `Root` 根据实际视口暴露 `visibleSlides` 与 `maxIndex`；`Viewport` 暴露 `dragging`、`scrolling` 与归一化 `scrollPosition`；`Slide` 的 `current` 对应当前吸附项，`hidden` 反映屏外可见性且保留布局尺寸。
- 使用 `orientation="vertical"` 时，请为视口设置明确的高度；水平方向下 `direction="rtl"` 会反转物理拖动与左右键方向，并保持逻辑项顺序。
- 设置 `loop={true}` 可在首尾可达索引之间循环切换。

### 受控与非受控索引

- **非受控**：使用 `defaultIndex` 指定初始吸附项。
- **受控**：传入 `index` 并监听 `indexChange` 更新外部状态。拖动过程中不会提前改写已提交索引，松手时按外部最新值落位。

### 其他部件属性

- **Viewport**：无独立属性
- **Slide**：`index?: number`（省略时按顺序自动分配；显式指定时应与项目顺序一致）
