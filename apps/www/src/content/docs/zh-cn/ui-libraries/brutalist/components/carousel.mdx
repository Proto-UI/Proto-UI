Brutalist Carousel 将等宽滑块条、连续可滚动视口与高对比度硬影翻页控制结合在一起，支持鼠标/触摸拖拽、滚轮/触控板滚动与键盘切换，松手或滚动停止后自动吸附至最近的项目边界。

## 用法

```tsx
import {
  BrutalistCarouselRoot,
  BrutalistCarouselViewport,
  BrutalistCarouselSlide,
  BrutalistCarouselPrevious,
  BrutalistCarouselNext,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <BrutalistCarouselRoot className="mx-auto w-full max-w-xs">
      <BrutalistCarouselViewport>
        <BrutalistCarouselSlide>1</BrutalistCarouselSlide>
        <BrutalistCarouselSlide>2</BrutalistCarouselSlide>
        <BrutalistCarouselSlide>3</BrutalistCarouselSlide>
      </BrutalistCarouselViewport>
      <BrutalistCarouselPrevious aria-label="Previous slide">←</BrutalistCarouselPrevious>
      <BrutalistCarouselNext aria-label="Next slide">→</BrutalistCarouselNext>
    </BrutalistCarouselRoot>
  );
}
```

- **响应式视口与布局**：通过 `slidesPerView`（默认 `1`）与 `minSlideSize`（默认 `0`）控制同时显示的等尺寸卡片数量，容器变窄时自动缩减可见项数并贴齐末端。
- **Brutalist 几何与反馈**：视口保持 5px 圆角（`rounded-base`），前后按钮采用 2px 黑色边框与 4px 硬阴影，按压时沿阴影方向即时落位。
- **方向与受控模式**：纵向模式（`orientation="vertical"`）需为视口设置明确高度；传入 `index` 并监听 `indexChange` 可进入受控模式。
