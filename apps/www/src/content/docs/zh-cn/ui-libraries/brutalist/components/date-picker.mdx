Brutalist Date Picker 将 `Popover` 浮层与 `Calendar` 日历组合为完整的日期选择控件，支持单日、多日和日期范围选择，并各自保持独立的受控/非受控边界。

## 用法

### 单选、范围与多选模式

<PrototypePreviewer
  demoId="demo-brutalist-date-picker-selection"
  initialRuntime="wc"
  runtimes={['wc', 'react', 'vue', 'vue2']}
/>

- 通过 `mode="single"`（默认）、`mode="range"`（`range` / `defaultRange`）或 `mode="multiple"`（`values` / `defaultValues`）切换选择模式，所有日期约束与回调均继承自 `Calendar`。
- **自动关闭时机**：单选模式下选中有效日期后自动请求关闭弹层；范围模式下选中第一个端点时保持打开，完成第二个端点后自动请求关闭；多选模式下保持打开以便连续勾选，完成后按常规 Popover 方式关闭即可。
- **展示文本**：`Value` 自动格式化显示单个 ISO 日期、逗号分隔的有序多日期、未完成范围（`from …`）或完整范围（`from – to`）；未选中时显示 `placeholder`。
