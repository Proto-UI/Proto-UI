## 安装

<InstallCommandCard command="npx @proto.ui/cli@latest add wc brutalist-dropdown" manager="npm" />

当前在源码工作区提供。CLI 默认生成 `Root`、`Trigger`、`Content` 与 `Item` 的封装；`Group`、`Label`、`Separator` 与 `Shortcut` 可直接从 `@proto.ui/prototypes-brutalist/dropdown` 导入使用。

## 用法

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuGroup,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuSeparator,
  DropdownMenuShortcut,
  DropdownMenuTrigger,
} from '@/components/brutalist/dropdown-menu';
```

```tsx
<DropdownMenu>
  <DropdownMenuTrigger>Open</DropdownMenuTrigger>
  <DropdownMenuContent align="start" className="w-44">
    <DropdownMenuGroup>
      <DropdownMenuLabel>My Account</DropdownMenuLabel>
      <DropdownMenuItem value="profile">
        Profile
        <DropdownMenuShortcut>⇧⌘P</DropdownMenuShortcut>
      </DropdownMenuItem>
      <DropdownMenuItem value="billing">Billing</DropdownMenuItem>
    </DropdownMenuGroup>
    <DropdownMenuSeparator />
    <DropdownMenuItem value="logout">Log out</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```

- **分组与装饰部件**：`Group` 与 `Label` 自动建立菜单分组的无障碍命名关系；`Separator` 分隔区块；`Shortcut` 展示快捷键提示（仅作视觉标注，不注册全局快捷键）。
- **视觉与定位**：触发按钮具备硬阴影与按压落位反馈，`Content` 默认启用 `excludeAnchorTranslation` 使浮层紧贴触发器的布局位置，避免抖动。
