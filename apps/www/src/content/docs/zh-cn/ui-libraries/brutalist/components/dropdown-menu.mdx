## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

- **CLI 目标**：`proto-ui add <react|vue|vue2|wc> brutalist-dropdown`（生成 `Root`、`Trigger`、`Content`、`Item`）
- **包导出**：从 `@proto.ui/prototypes-brutalist/dropdown` 导入全部部件（含 `Group`、`Label`、`Separator`、`Shortcut`）

## 用法

- **分组与装饰部件**：`Group` 与 `Label` 自动建立菜单分组的无障碍命名关系；`Separator` 用于分隔菜单区块；`Shortcut` 用于展示键盘快捷键提示（仅作视觉标注，不注册全局快捷键）。
- **菜单项变体与触发图标**：在 `Item` 上设置 `variant="destructive"` 高亮危险操作，设置 `inset` 对齐带图标的菜单项；在 `Trigger` 上开启 `indicator` 显示下拉箭头指示图标。

传入 `open: boolean` 进入受控模式。

前五个属性属于 `Root`；`inset` 与 `variant` 属于 `Item`；`indicator`、`indicatorIcon`、`indicatorSize` 与 `indicatorStrokeWidth` 属于 `Trigger`。

### 其他部件属性

- **Content**：支持 Transition 属性；`side`（默认 `'bottom'`）、`align`（默认 `'center'`）、`sideOffset`（默认 `4`）、`alignOffset`（默认 `0`）、`collisionPadding`（默认 `0`）、`avoidCollisions`（默认 `true`）、`excludeAnchorTranslation`（默认 `true`）
- **Item**：`disabled?: boolean`（默认 `false`）、`value?: string`（默认 `''`）、`textValue?: string`（默认 `''`）、`closeOnCommit?: boolean`（默认继承 Root 的 `closeOnItemCommit`）
- **Group**：`a11yLabel?: string`（默认 `''`）
- **Label / Separator / Shortcut**：无独立属性
