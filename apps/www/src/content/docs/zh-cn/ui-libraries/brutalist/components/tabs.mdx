Tabs 用于在同一区域内切换多组关联内容面板，提供 5px 圆角扁平标签栏与选项卡样式，并支持自动或手动激活以及面板优先子元素聚焦语义。

## 安装

已包含在 `@proto.ui/prototypes-brutalist@0.2.0` 中。可通过 CLI 目标 `brutalist-tabs` 添加，或从 `@proto.ui/prototypes-brutalist/tabs` 导入。

## 用法

- **组件结构**：由 `Root`、`List`、`Trigger`、`Content` 和 `Indicator` 组成，通过相同的 `value` 将 `Trigger` 与对应的 `Content` 关联。
- **外观切换**：`List` 与 `Trigger` 支持 `appearance="default"` 和 `appearance="underline"` 两种样式。
- **激活与挂载**：`Root` 的 `activationMode` 可选 `'automatic'`（焦点移动即激活）或 `'manual'`（按 Enter / Space 确认激活）。关闭的 `Content` 默认卸载内容节点，设置 `keepMounted={true}` 可保留隐藏节点。
- **受控模式**：向 `Root` 传入 `value` 进入受控模式，否则使用 `defaultValue` 进行非受控初始化。

## API

以下前三个属性（`defaultValue`、`orientation`、`activationMode`）属于 `Root`（传入 `value` 进入受控模式），`appearance` 属于 `List` 与 `Trigger`：

其余子部件属性默认值：

- **List**：`orientation` 默认 `'horizontal'`，`loop` 默认 `false`，`a11yLabel` 默认 `''`。
- **Trigger**：`value` 默认 `''`，`disabled` 默认 `false`。
- **Content**：`value` 默认 `''`，`keepMounted` 默认 `false`。
- **Indicator**：无属性。
