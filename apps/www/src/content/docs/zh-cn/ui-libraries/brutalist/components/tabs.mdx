Brutalist Tabs 将关联内容组织在可切换的面板区域内，遵循 5px 圆角（`rounded-base`）、2px 黑色边框与扁平无阴影标签栏的 Brutalist 视觉规范，并继承 [Base Tabs](/zh-cn/ui-libraries/base/tabs/) 的完整键盘导航与无障碍语义。

## 安装

<InstallCommandCard command="npx @proto.ui/cli@latest add wc brutalist-tabs" manager="npm" />

将 `wc` 替换为 `react`、`vue` 或 `vue2` 可生成对应框架封装，也可直接从 `@proto.ui/prototypes-brutalist/tabs` 导入。

## 用法

```tsx
import {
  BrutalistTabsContent,
  BrutalistTabsList,
  BrutalistTabsRoot,
  BrutalistTabsTrigger,
} from '../proto-ui/components/react';
```

```tsx
<BrutalistTabsRoot defaultValue="account">
  <BrutalistTabsList>
    <BrutalistTabsTrigger value="account">Account</BrutalistTabsTrigger>
    <BrutalistTabsTrigger value="password">Password</BrutalistTabsTrigger>
  </BrutalistTabsList>
  <BrutalistTabsContent value="account">Make changes to your account here.</BrutalistTabsContent>
  <BrutalistTabsContent value="password">Change your password here.</BrutalistTabsContent>
</BrutalistTabsRoot>
```

### 组件结构

```text
TabsRoot
├── TabsList
│   ├── TabsTrigger
│   └── TabsTrigger
├── TabsContent
└── TabsContent
```

- **视觉规范**：`TabsList` 与 `TabsTrigger` 采用无阴影扁平表面，选中项切换为主色填充（`bg-main`）与黑框；`TabsContent` 默认不叠加额外边框，便于直接承载卡片或表单内容。
- **键盘导航**：支持方向键、`Home` / `End` 移动焦点，以及 `activationMode="automatic" | "manual"` 两种激活模式。
