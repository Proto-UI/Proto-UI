## 用法

### 部件组成

Autocomplete 由 `Root`、`Input`、`Content`、`Item`、`Empty` 和 `Trigger` 组成：

- **Root**：管理已提交值 `value`、当前查询输入 `inputValue`、弹层开关 `open` 以及内置过滤和循环导航配置。三项状态均可独立受控。
- **Input**：承载真实单行文本编辑器，使用方向键浏览建议列表时焦点始终保留在输入框内，输入法合成期间不会误触发选择。
- **Content**：锚定在输入框下方的浮层建议面板，支持方向、对齐与碰撞留白配置。
- **Item**：单个建议选项，通过 `textValue` 和 `keywords` 参与忽略大小写与重音的匹配；选中时提交 `textValue`，禁用项或重复值不可提交。
- **Empty**：当没有匹配建议时自动展示的空态提示。
- **Trigger**：可选的展开/收起触发按钮。

### 过滤与提交行为

- 按 `Enter` 时，若有高亮候选项则提交该项文本；若无高亮项则可直接提交当前输入的自由文本。
- 如需自行在外部过滤数据，将 `filter` 设为 `false` 并直接渲染已过滤的 `Item` 列表。

分别传入 `value`、`inputValue` 或 `open` 可独立控制对应状态。

### 其他部件属性

- **Input**：`placeholder?: string`、`a11yLabel?: string`、`name?: string`（默认均为 `''`）
- **Content**：`side`（默认 `'bottom'`）、`align`（默认 `'start'`）、`sideOffset`（默认 `4`）、`collisionPadding`（默认 `8`）
- **Item**：`value`、`textValue`、`keywords`（默认均为 `''`）、`disabled?: boolean`（默认 `false`）
- **Empty**：无独立属性
- **Trigger**：`disabled?: boolean`（默认 `false`）
