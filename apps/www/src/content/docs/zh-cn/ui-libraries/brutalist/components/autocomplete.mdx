Brutalist Autocomplete 遵循 Brutalist 设计契约（5px `rounded-base`、2px 黑色描边、DM Sans 字体与分级硬阴影），将单行文本输入与实时过滤的建议面板结合，既可选中候选项，也允许直接提交自由文本。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供（`@proto.ui/prototypes-brutalist/autocomplete`）。

## 用法

```html
<proto-ui-brutalist-autocomplete-root a11y-label="Framework">
  <proto-ui-brutalist-autocomplete-input
    placeholder="Search frameworks…"
  ></proto-ui-brutalist-autocomplete-input>
  <proto-ui-brutalist-autocomplete-trigger>Options</proto-ui-brutalist-autocomplete-trigger>
  <proto-ui-brutalist-autocomplete-content>
    <proto-ui-brutalist-autocomplete-item value="next" text-value="Next.js" keywords="react ssr">
      Next.js
    </proto-ui-brutalist-autocomplete-item>
    <proto-ui-brutalist-autocomplete-item
      value="astro"
      text-value="Astro"
      keywords="islands static"
    >
      Astro
    </proto-ui-brutalist-autocomplete-item>
    <proto-ui-brutalist-autocomplete-empty
      >No matching frameworks.</proto-ui-brutalist-autocomplete-empty
    >
  </proto-ui-brutalist-autocomplete-content>
</proto-ui-brutalist-autocomplete-root>
```

### 部件与交互说明

- **部件组成**：由 `Root`、`Input`、`Trigger`、`Content`、`Item` 与 `Empty` 组成。
- **层级动效**：`Input` 为可编辑平面表面，`Trigger` 采用 4px 抬起黑影与按压落位反馈，`Content` 浮层面板使用 3px 前景硬阴影，`Item` 高亮时切换为 `bg-main` / `text-main-foreground`。
- **过滤与提交**：内置过滤支持忽略大小写、重音符号与 `keywords`；设 `filter={false}` 可切换为外部过滤。无高亮候选项时按 `Enter` 提交当前自由文本，IME 合成期间不会误触选择。
