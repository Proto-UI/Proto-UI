Popover 在触发元素附近展示带有硬边阴影与 2px 黑框的 Brutalist 非模态浮动面板，适合放置快捷表单、筛选控件或轻量级导航内容，不锁定背景滚动或限制 `Tab` 键移动。

## 安装

Brutalist Popover 目前在工作区源码中提供，尚未进入 0.2.0 稳定版 CLI。可直接从 `@proto.ui/prototypes-brutalist/popover` 导入原型并使用对应框架适配器：

```ts
import {
  popoverRoot,
  popoverTrigger,
  popoverContent,
  popoverTitle,
  popoverDescription,
  popoverClose,
} from '@proto.ui/prototypes-brutalist/popover';
```

## 用法

```tsx
<BrutalistPopover>
  <BrutalistPopoverTrigger>Open Popover</BrutalistPopoverTrigger>
  <BrutalistPopoverContent align="start">
    <BrutalistPopoverTitle>Dimensions</BrutalistPopoverTitle>
    <BrutalistPopoverDescription>Set the dimensions for the layer.</BrutalistPopoverDescription>
  </BrutalistPopoverContent>
</BrutalistPopover>
```

### 组件结构

```text
BrutalistPopoverRoot
├── BrutalistPopoverTrigger
└── BrutalistPopoverContent
    ├── BrutalistPopoverTitle
    ├── BrutalistPopoverDescription
    └── BrutalistPopoverClose
```

- **Brutalist 视觉语法**：`Trigger` 与 `Close` 遵循 5px 圆角（`rounded-base`）、2px 黑色边框、4px 零模糊硬影及按压即时落位；`Content` 浮层使用 3px 零模糊前景影，无悬停或按压位移。
- **定位与关闭**：支持 `side`、`align`、`sideOffset`、`alignOffset` 和 `collisionPadding`；点击外部、按下 `Escape`、点击 `Close` 或焦点移出弹层时请求关闭。
