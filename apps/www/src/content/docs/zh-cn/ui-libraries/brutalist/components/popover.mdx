## 用法

### 组件结构

Popover 由 `Root`、`Trigger`、`Content`、`Title`、`Description` 和 `Close` 六个部分组成：

- `Root`：管理弹层的展开与关闭状态。
- `Trigger`：打开或切换弹层的锚点触发器。
- `Content`：相对 `Trigger` 定位的弹层内容，支持 `side`、`align`、`sideOffset`、`alignOffset` 和 `collisionPadding`。
- `Title` / `Description`：为弹层提供无障碍标题与描述关联。
- `Close`：关闭当前弹层的按钮。

### 定位、焦点与关闭

- 点击外部区域、焦点移出 `Trigger` 与 `Content`、按 `Escape` 或点击 `Close` 都会请求关闭弹层。
- 焦点在 `Trigger` 与经由 Portal 渲染的 `Content` 之间切换时仍视为停留在弹层内部。
- 因焦点移出而关闭时，焦点保留在新的外部元素上而不会拉回 `Trigger`；此类纯焦点移出请求上报的 `focusReason` 为 `'programmatic'`。

### 受控与非受控模式

- 非受控模式通过 `Root` 的 `defaultOpen` 设置初始状态。
- 受控模式传入 `open` 并监听 `openChange` 事件，由外部状态决定是否应用新值；即使拒绝了 `focus.outside` 关闭请求，`Content` 也会保持展开且不限制外部焦点，后续交互仍可再次请求关闭。

### 导航呈现

在 `Trigger` 和 `Content` 上显式设置 `presentation="navigation"`，可让弹层使用锚点下方的可用区域并在内部滚动，适合承载导航链接列表（链接保持浏览器原生导航行为）。

## API

以下前三个属性（`defaultOpen`、`disabled`、`a11yLabel`）属于 `Root`（传入 `open` 进入受控模式），`presentation` 属于 `Content` 与 `Trigger`：

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'defaultOpen', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'a11yLabel', type: 'string', default: "''" },
    { name: 'presentation', type: "'default' | 'navigation'", default: 'default' },
  ]}
/>

其余子部件属性默认值：

- **Content**：额外接受 Transition 属性；`side` 默认 `'bottom'`，`align` 默认 `'center'`，`sideOffset` 默认 `4`，`alignOffset` 默认 `0`，`collisionPadding` 默认 `8`。
- **Title**、**Description**、**Close**：无属性。
