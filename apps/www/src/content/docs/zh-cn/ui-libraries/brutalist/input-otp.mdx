## 用法

### 部件组成

Input OTP 由 `Root`、`Input`、`Control`、`Slot` 和 `Separator` 组成：

- **Root**：管理 `value` / `defaultValue`、位数 `length`（1–32，默认 `6`）、字符过滤模式 `pattern`（`'numeric'` 或 `'alphanumeric'`）、`disabled`、`readOnly`、`name` 与 `ariaLabel`。
- **Input**：独立使用时承载真实文本输入，自动处理粘贴、删除、选区与输入法合成，并启用 `one-time-code` 自动填充；合成结束后过滤非法字符并截断至设定长度。
- **Control**：在 `Field` 或 `FormField` 内替代 `Input` 使用，自动衔接标签点击聚焦、表单校验、序列化与重置。
- **Slot**：按 `index` 展示对应字符的只读视觉格，对辅助技术隐藏，不增加额外的 Tab 停靠点。输入框聚焦且可编辑时，根据真实光标或选区高亮当前活动槽位。
- **Separator**：可选的视觉分隔符。

### 事件与校验

- 传入 `value` 进入受控模式，输入变更通过 `valueChange` 发出提议；每次填满并接受完整验证码时触发一次 `completed` 事件。
- 在 `Field` 内使用 `Control` 时，仅在外部接受了有效的值变化后触发自动变更校验，被拒绝或过滤后未变化的输入不会重复触发校验。

  ]}
/>

传入 `value: string` 可切换为受控模式。

### 其他部件属性

- **Input**：`placeholder?: string`（可选）
- **Slot**：`index?: number`（默认 `0`）
- **Control / Separator**：无独立属性
