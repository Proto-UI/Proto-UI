Brutalist Input OTP 使用单个真实输入框搭配 5px 圆角（`rounded-base`）、2px 实线边框与硬阴影槽位，完整支持粘贴、选区编辑、输入法合成与 `one-time-code` 自动填充，并以主色填充和高对比度焦点环突出当前激活槽位。

## 用法

```tsx
import {
  BrutalistInputOtpRoot,
  BrutalistInputOtpInput,
  BrutalistInputOtpSlot,
  BrutalistInputOtpSeparator,
} from '../proto-ui/components/react';

export function BrutalistVerificationCode() {
  return (
    <BrutalistInputOtpRoot length={6}>
      <BrutalistInputOtpInput placeholder="123456" />
      <div className="inline-flex items-center gap-1.5">
        <BrutalistInputOtpSlot index={0} />
        <BrutalistInputOtpSlot index={1} />
        <BrutalistInputOtpSlot index={2} />
      </div>
      <BrutalistInputOtpSeparator>–</BrutalistInputOtpSeparator>
      <div className="inline-flex items-center gap-1.5">
        <BrutalistInputOtpSlot index={3} />
        <BrutalistInputOtpSlot index={4} />
        <BrutalistInputOtpSlot index={5} />
      </div>
    </BrutalistInputOtpRoot>
  );
}
```

### 部件组成与交互

- **Root**：管理 `value` / `defaultValue`、位数 `length`（`1`–`32`，默认 `6`）、字符过滤模式 `pattern`（`'numeric'` 或 `'alphanumeric'`）、`disabled`、`readOnly`、`invalid`、`name` 与 `ariaLabel`。
- **Input / Control**：独立场景使用 `Input` 承载真实文本输入；在 `Field` 或 `FormField` 内用 `Control` 替代 `Input`，自动衔接标签聚焦、校验、序列化与重置。
- **Slot / Separator**：`Slot` 按 `index` 渲染被动字符格（`aria-hidden`），不增加额外 Tab 焦点，遵循 DM Sans 排版与 2px 边框硬阴影规范。

### 事件与暴露方法

- **Root 事件**：`valueChange`（`{ value: string }`）、`completed`（`{ value: string }`）。
- **Root 暴露状态与方法**：状态 `value`、`complete`、`disabled`、`readOnly`、`focused`；方法 `requestValue(value)`、`clear()`、`resetValue()`、`focusInput()`。
