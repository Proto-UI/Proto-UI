Toast 用于展示短暂的实时通知消息，采用 Brutalist 5px 圆角、2px 粗边框与 3px 前景硬阴影表面，并支持自动倒计时关闭、悬停或聚焦暂停、快捷键定位以及显式操作按钮。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可直接从 `@proto.ui/prototypes-brutalist/toast` 导入组件原型并使用对应宿主 Adapter 适配。

```ts
import {
  toastViewport,
  toastRoot,
  toastTitle,
  toastDescription,
  toastAction,
  toastClose,
} from '@proto.ui/prototypes-brutalist/toast';
```

## 用法

```tsx
<BrutalistToastViewport a11yLabel="Notifications">
  <BrutalistToastRoot defaultOpen={false} duration={5000}>
    <BrutalistToastTitle>Event has been created</BrutalistToastTitle>
    <BrutalistToastDescription>Sunday, December 03, 2023 at 9:00 AM</BrutalistToastDescription>
    <BrutalistToastAction a11yLabel="Undo event creation">Undo</BrutalistToastAction>
    <BrutalistToastClose>Dismiss</BrutalistToastClose>
  </BrutalistToastRoot>
</BrutalistToastViewport>
```

Toast 由 `Root`、`Viewport`、`Title`、`Description`、`Action` 和 `Close` 六个部件组成：

- 默认展示 `5000ms`；将 `duration` 设为 `0` 可保持常驻不自动关闭。
- 鼠标悬停在通知上，或焦点位于 `Action` / `Close` 按钮上时，剩余倒计时会自动暂停。
- 点击 `Close`、在通知聚焦时按 `Escape` 或触发 `Action` 都会请求关闭。受控模式（传入 `open`）下，超时后仅发出一次关闭请求并等待调用方更新状态。
- `Viewport` 提供默认的 `F8` 快捷键用于快速将焦点移入通知区；多条通知队列由应用层自行编排。

事件与暴露方法：

- **事件**：`Root` 暴露 `openChange`（`{ open: boolean; reason: string }`）；`Action` 暴露 `action`（`void`）。
- **方法**：`Root` 暴露 `openToast()`、`close(reason?)`、`pause()`、`resume()`；`Viewport` 暴露 `focusFirst()`。
