Root 默认显示 5000ms，duration=0 持续显示。悬停以及 Toast Action/Close 焦点会暂停剩余时长。受控 open 只发出一次超时关闭请求，等待调用方更新。Close、有焦点时的 Escape、Action 请求关闭；实际副作用归应用处理。Viewport 提供 F8 聚焦快捷键；不包含全局队列或系统通知传输。

组成: Root, Viewport, Title, Description, Action, Close.

## API

Toast 是工作区源码，没有公开的 `proto-ui add` 目标。传入 `open` 进入受控模式。

这些属性属于 Root。Viewport 的 `a11yLabel` 默认 `Notifications`，`hotkey` 默认 `F8`。Title 与 Description 没有属性。Action 的 `disabled` 默认 `false`，`a11yLabel` 没有默认值。Close 的 `disabled` 默认 `false`。
