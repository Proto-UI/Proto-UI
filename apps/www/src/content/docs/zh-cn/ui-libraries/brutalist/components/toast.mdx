## 用法

### 组件结构

Toast 由 `Root`、`Viewport`、`Title`、`Description`、`Action` 和 `Close` 六个部分组成：

- `Root`：管理单条通知的打开状态、过渡时长、倒计时与播报礼貌级别（`politeness`）。
- `Viewport`：通知停靠区域，提供默认的 `F8` 快捷键用于快速将焦点移入通知区。
- `Title` / `Description`：通知标题与说明文案。
- `Action`：触发应用层操作意图并请求关闭（实际业务逻辑由应用处理）。
- `Close`：手动关闭当前通知的按钮。

### 计时与关闭行为

- 默认展示 `5000ms`；将 `duration` 设为 `0` 可保持常驻不自动关闭。
- 鼠标悬停在通知上，或焦点位于 `Action` / `Close` 按钮上时，剩余倒计时会自动暂停。
- 点击 `Close`、在通知聚焦时按 `Escape` 或触发 `Action` 都会请求关闭。受控模式（传入 `open`）下，超时后仅发出一次关闭请求并等待调用方更新状态。
- 如需多条通知排队或跨页面调度，请在应用层管理通知队列。

以下属性属于 `Root`（传入 `open` 进入受控模式）：

  ]}

其余子部件属性默认值：

- **Viewport**：`a11yLabel` 默认 `'Notifications'`，`hotkey` 默认 `'F8'`。
- **Title**、**Description**：无属性。
- **Action**：`disabled` 默认 `false`，`a11yLabel` 可选（无默认值）。
- **Close**：`disabled` 默认 `false`。
