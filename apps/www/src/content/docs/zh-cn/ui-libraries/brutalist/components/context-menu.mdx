## 用法

```tsx
import {
  BrutalistContextMenuContent,
  BrutalistContextMenuItem,
  BrutalistContextMenuRoot,
  BrutalistContextMenuTrigger,
} from '@/components/proto-ui';

export function Example() {
  return (
    <BrutalistContextMenuRoot>
      <BrutalistContextMenuTrigger className="flex h-36 w-72 items-center justify-center rounded-base border-2 border-dashed border-black bg-secondary-background text-sm font-sans font-medium">
        Right click here
      </BrutalistContextMenuTrigger>
      <BrutalistContextMenuContent>
        <BrutalistContextMenuItem value="back">Back</BrutalistContextMenuItem>
        <BrutalistContextMenuItem value="forward" disabled>Forward</BrutalistContextMenuItem>
        <BrutalistContextMenuItem value="reload">Reload</BrutalistContextMenuItem>
      </BrutalistContextMenuContent>
    </BrutalistContextMenuRoot>
  );
}
```

### 部件结构

```text
ContextMenuRoot
├── ContextMenuTrigger
└── ContextMenuContent
    ├── ContextMenuItem
    └── ContextMenuItem
```

- **无样式触发容器**：`Trigger` 保持无外框结构，允许调用方自由包裹文本、卡片或虚线交互区域；右键、长按或键盘唤起时自动抑制原生右键菜单。
- **浮层与菜单项规范**：`Content` 采用 `rounded-base`、`2px` 边框与 `3px` 前景硬阴影；`Item` 在悬停、焦点或按压时切换主色高亮与 2px 黑框，无位移弹跳。
