## 用法

### 部件组成

ContextMenu 由 `Root`、`Trigger`、`Content` 和 `Item` 组成：

- **Root**：管理开关状态（受控 `open` 或非受控 `defaultOpen`）、整体禁用 `disabled`、选中后关闭策略 `closeOnItemCommit` 以及打开时的默认焦点落点。
- **Trigger**：定义上下文菜单的触发区域，在右键、触摸/手写笔长按（持续 600ms 且未超过移动容差）或 `ContextMenu` / `Shift+F10` 时请求打开菜单并抑制浏览器原生右键菜单；普通左键点击与滚动保持默认行为。
- **Content**：浮层菜单面板，右键与长按时锚定在触发点，键盘唤起或调用 `openContextMenu()` 时锚定在触发区域；支持键盘漫游、字符跳转、过渡动画与碰撞检测。
- **Item**：菜单命令项，支持单独配置 `disabled`、`value`、`textValue` 与 `closeOnCommit`。

### 焦点与受控行为

- 按 `Escape` 或完成菜单项选择后，焦点会自动恢复至触发区域。
- 传入 `open` 进入受控模式：菜单打开请求触发时仍会自动阻止原生右键菜单，实际显示状态由外部传入的 `open` 决定。

传入 `open: boolean` 进入受控模式。

### 其他部件属性

- **Trigger**：无独立属性
- **Content**：支持 Transition 属性；`side`（默认 `'bottom'`）、`align`（默认 `'start'`）、`sideOffset`（默认 `0`）、`alignOffset`（默认 `0`）、`avoidCollisions`（默认 `true`）、`collisionPadding`（默认 `0`）、`excludeAnchorTranslation`（默认 `false`）
- **Item**：`disabled?: boolean`（默认 `false`）、`value?: string`（默认 `''`）、`textValue?: string`（默认 `''`）、`closeOnCommit?: boolean`（默认继承 Root 的 `closeOnItemCommit`）
