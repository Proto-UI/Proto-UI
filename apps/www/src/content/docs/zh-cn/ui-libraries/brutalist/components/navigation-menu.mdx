## 用法

### 组件结构

NavigationMenu 由 `Root`、`Trigger`、`Content`、`Item` 和 `Link` 五个部分组成：

- `Root`：作为 navigation 地标容器，通过 `value` 管理当前唯一展开的导航面板。
- `Trigger`：切换对应面板展开状态的按钮，与 `Content` 通过 `value` 配对。
- `Content`：带无障碍名称的 region 面板容器。
- `Item`：触发普通命令操作的菜单项。
- `Link`：渲染真实的原生锚点链接，支持 `href`、`target`、`rel` 和 `current`（设置 `aria-current` 标识当前页）。

### 链接导航行为

- **原生浏览体验**：URL 预览、`Enter` 激活以及修饰键/中键打开新标签页均由浏览器原生处理；如需接入应用路由，可在外层监听事件或结合路由方案处理。
- **只读 `navigate` 事件**：`Link` 在原生激活后发出只读 `navigate` 事件，载荷包含 `{ href, target, rel, modified }`，用于观察导航行为。
- **自动关闭规则**：普通当前窗口激活默认关闭当前面板（设置 `closeOnSelect={false}` 可保持打开）；使用修饰键、中键点击或 `target="_blank"` 打开时保留当前页面的展开面板。
- **禁用状态**：设置 `disabled` 后，`Link` 会移除跳转目标并阻止激活。
- **跨宿主渲染**：React、Vue 与 Vue 2 直接使用原生 `<a>` 根节点；Web Components 会将自定义内容保留在内部持有的锚点元素中，焦点、样式与无障碍属性同步作用在该元素上。

其余子部件属性默认值：

- **Trigger**：`value` 默认 `''`，`disabled` 默认 `false`。
- **Content**：`value` 与 `a11yLabel` 默认 `''`，`sideOffset` 默认 `4`。
- **Item**：`value` 与 `textValue` 默认 `''`，`disabled` 默认 `false`，`closeOnSelect` 默认 `true`。
- **Link**：`href` 与 `rel` 默认 `''`，`current` 默认 `false`，`target` 默认 `'_self'`。
