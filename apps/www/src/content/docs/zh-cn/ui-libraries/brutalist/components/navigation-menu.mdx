Brutalist Navigation Menu 用于构建站点级或应用级导航栏，遵循 Brutalist 设计契约（5px `rounded-base` 圆角、2px 黑色描边、DM Sans 字体与 3px 零模糊浮层硬阴影），并将可展开的命名面板与原生浏览器链接结合在一起。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可直接从 `@proto.ui/prototypes-brutalist/navigation-menu` 导入组件原型并使用对应宿主 Adapter 适配：

```ts
import {
  navigationMenuRoot,
  navigationMenuTrigger,
  navigationMenuContent,
  navigationMenuItem,
  navigationMenuLink,
} from '@proto.ui/prototypes-brutalist/navigation-menu';
```

## 用法

```tsx
import {
  BrutalistNavigationMenuRoot,
  BrutalistNavigationMenuTrigger,
  BrutalistNavigationMenuContent,
  BrutalistNavigationMenuItem,
  BrutalistNavigationMenuLink,
} from '../proto-ui/components/react';

export function BrutalistSiteNav() {
  return (
    <BrutalistNavigationMenuRoot a11yLabel="Main navigation">
      <BrutalistNavigationMenuTrigger value="getting-started">
        Getting started
      </BrutalistNavigationMenuTrigger>
      <BrutalistNavigationMenuContent value="getting-started" a11yLabel="Getting started">
        <BrutalistNavigationMenuLink href="/docs" current>
          Introduction
        </BrutalistNavigationMenuLink>
        <BrutalistNavigationMenuItem value="copy-theme" textValue="Copy theme CSS">
          Copy theme CSS
        </BrutalistNavigationMenuItem>
      </BrutalistNavigationMenuContent>
    </BrutalistNavigationMenuRoot>
  );
}
```

### 结构组成

```text
NavigationMenuRoot (navigation)
├── NavigationMenuTrigger (button, paired by value)
└── NavigationMenuContent (region, paired by value)
    ├── NavigationMenuLink (native <a>)
    └── NavigationMenuItem (command action)
```

### 原生链接与键盘交互

- **原生浏览体验**：URL 预览、`Enter` 激活以及修饰键/中键打开新标签页均由浏览器原生处理。React、Vue 与 Vue 2 直接渲染原生 `<a>` 根节点；Web Components 将内容托管在内部锚点元素中。
- **只读 `navigate` 事件**：`Link` 激活后发出只读 `navigate` 事件，携带 `{ href, target, rel, modified }`。
- **自动关闭与禁用**：普通同窗口点击默认关闭面板（设 `closeOnSelect={false}` 可保持打开）；修饰键、中键或 `target="_blank"` 保持面板展开。禁用状态的 `Link` 移除跳转目标并阻止激活。
- **键盘导航**：顶层 `Trigger` 支持左右方向键漫游，`ArrowDown` / `ArrowUp` 展开并聚焦面板首尾项，`Escape` 关闭并返回焦点。
