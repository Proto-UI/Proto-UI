Brutalist Data Table 在静态表格结构之上提供稳定排序、全局与按列筛选、列可见性控制、分页及行选择能力。表格行按当前页索引映射实际记录，每条记录需提供唯一的 `id`。

## 用法

### 表头与数据行

- 排序表头放置在 `DataTableHeaderRow` 内，正文记录槽使用 `DataTableRow`；单元格按 `columnKey` 读取当前行对应字段。
- 排序、筛选与分页都会更新实际单元格内容，支持受控 `sortKey`、`sortDirection`、`page` 与 `selectedKeys`。

### 筛选、列显隐、整页选择与自定义渲染

- **筛选与列显隐**：`columnFilters` 与全局 `filter` 叠加生效（全部非空条件均匹配后再排序和分页）。通过 `columnVisibility` 可隐藏指定列的表头与单元格，同时保留逻辑结构与子组件状态，重新显示时自动恢复。
- **整页选择**：调用 `requestPageSelection()` 仅勾选或清空当前筛选后的当前页，保留其他页的选择；`pageSelection` 暴露 `'none'`、`'some'` 或 `'all'`。`readOnly` 会禁止行选择与整页选择，同时保留排序和分页。
- **自定义单元格**：在 `Cell` 上设置 `renderValue={false}` 可保留传入的子元素，并通过 `displayValue` 读取当前记录值来自定义格式化内容。

传入 `sortKey`、`sortDirection`、`page` 或 `selectedKeys` 可分别控制对应状态。

### 其他部件属性

- **Row**：`index?: number`（默认 `0`），`header?: boolean`（默认 `false`）
- **Header**：`sortable?: boolean`（默认 `true`）
- **Cell**：`columnKey?: string`（默认 `''`），`renderValue?: boolean`（默认 `true`）
- **Previous / Next**：支持 Button 属性
