Brutalist Data Table 在静态表格结构之上提供稳定排序、全局与按列筛选、列显隐、分页及行/整页选择能力，并遵循 5px 圆角（`rounded-base`）、2px 黑色描边、4px 零模糊硬阴影与 DM Sans 字体规范。

## 用法

```tsx
import {
  BrutalistDataTableCaption,
  BrutalistDataTableCell,
  BrutalistDataTableHeader,
  BrutalistDataTableHeaderRow,
  BrutalistDataTableNext,
  BrutalistDataTablePrevious,
  BrutalistDataTableRoot,
  BrutalistDataTableRow,
} from '../proto-ui/components/react';

const rows = [
  { id: 'm5gr84i9', status: 'Success', email: 'ken99@example.com', amount: 316 },
  { id: '3u1reuv4', status: 'Success', email: 'abe45@example.com', amount: 242 },
];

export function Example() {
  return (
    <BrutalistDataTableRoot rows={rows} pageSize={4}>
      <BrutalistDataTableCaption>Recent payments.</BrutalistDataTableCaption>
      <BrutalistDataTableHeaderRow>
        <BrutalistDataTableHeader headerKey="status">Status</BrutalistDataTableHeader>
        <BrutalistDataTableHeader headerKey="email">Email</BrutalistDataTableHeader>
        <BrutalistDataTableHeader headerKey="amount" className="text-right">
          Amount
        </BrutalistDataTableHeader>
      </BrutalistDataTableHeaderRow>
      {[0, 1].map((index) => (
        <BrutalistDataTableRow key={index} index={index}>
          <BrutalistDataTableCell columnKey="status" headers={['status']} />
          <BrutalistDataTableCell columnKey="email" headers={['email']} />
          <BrutalistDataTableCell columnKey="amount" headers={['amount']} className="text-right" />
        </BrutalistDataTableRow>
      ))}
      <div className="table-caption caption-bottom">
        <div className="flex justify-end gap-2 pt-3">
          <BrutalistDataTablePrevious>Previous</BrutalistDataTablePrevious>
          <BrutalistDataTableNext>Next</BrutalistDataTableNext>
        </div>
      </div>
    </BrutalistDataTableRoot>
  );
}
```

### 结构与设计规范

- **表格结构与行槽位**：每条记录需提供唯一 `id`，排序表头放在 `DataTableHeaderRow` 中，正文行槽使用 `DataTableRow`，单元格通过 `columnKey` 绑定字段。
- **视觉与动效**：表头使用 `font-heading font-bold`，单元格使用 `font-sans font-medium`；翻页按钮采用抬起型控件（4px 硬阴影，按压时沿阴影方向位移 `+4px, +4px` 并收起外影）；选中行使用 `bg-main text-main-foreground` 高对比配色。

### 事件、方法与暴露状态

- **事件（Root）**：`sortChange`、`pageChange`、`selectionChange`。
- **方法（Root）**：`getRows()`、`getRecord(id)`、`getSelectedKeys()`、`requestSort(key)`、`requestPage(next)`、`requestSelection(id)`、`requestPageSelection(selected?)`。
- **暴露状态**：Root 暴露 `filteredCount`、`pageSelection`；Row 暴露 `rowKey`、`selected`、`focused`、`focusVisible`；Header 暴露 `sort`；Cell 暴露 `displayValue`。
