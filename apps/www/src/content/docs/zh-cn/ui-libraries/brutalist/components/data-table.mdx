Data Table 将被动 Table 结构与稳定记录 ID、稳定排序、全局过滤、分页及行选择组合。行是当前页按 index 编排的显示槽；单元格按 columnKey 显示当前记录，排序会更新真实内容，不用 CSS 顺序冒充 Table 结构排序。应用 rows 的 id 必须唯一。本组合不管理请求、编辑或列重排。

当前为功能源码 WIP。完整运行时、Compiler、原生、打包、浏览器与视觉验收仍待补齐。

排序表头应放在静态 `DataTableHeaderRow` 组合内。它继承被动 Table Row topology，没有 Props 或 instance exposes，不创建 selection、focus 或 Trigger owner；正文数据槽仍使用 `DataTableRow`。旧 `DataTableRow.header` prop 保留 runtime 数据槽策略，但不会移除该行 setup 期的 Trigger 身份，不能包含多个直接 Trigger 子项。示例已迁移到新静态组合，连续链规则没有放宽。

## API

Data Table 是工作区源码，没有公开的 `proto-ui add` 目标。传入 `sortKey`、`sortDirection`、`page` 或 `selectedKeys` 会使对应事实进入受控模式。

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'rows', type: 'readonly DataRecord[]', default: '[]' },
    { name: 'defaultSortKey', type: 'string', default: "''" },
    { name: 'defaultSortDirection', type: "'none' | 'ascending' | 'descending'", default: 'none' },
    { name: 'filter', type: 'string', default: "''" },
    { name: 'defaultPage', type: 'number', default: '0' },
    { name: 'pageSize', type: 'number', default: '10' },
    { name: 'defaultSelectedKeys', type: 'readonly string[]', default: '[]' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'readOnly', type: 'boolean', default: 'false' },
  ]}
/>

这些属性属于 Root。Row 的 `index` 默认 `0`，`header` 默认 `false`。Cell 的 `columnKey` 默认 `''`。Header 的 `sortable` 默认 `true`。Previous 与 Next 接受 Button 的属性。
