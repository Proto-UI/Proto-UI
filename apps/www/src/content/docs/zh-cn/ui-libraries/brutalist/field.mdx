Brutalist Field 将表单控件与其标签、帮助说明、错误提示和校验状态组合为一体，支持同步内置校验与外部异步校验，并采用粗边框与清晰排版层级呈现。

## 用法

### 部件组成

- **Root**：统一管理校验结果（`invalid`、`errors`）、`dirty`、`touched` 以及禁用/只读/必填策略。每个 `Root` 内包含一个 `Control`，可选配一个 `Label`、`Description`、`Error` 以及多个只读 `Validity` 展示节点。嵌套 `Root` 彼此独立。
- **Control**：承载实际值与输入编辑器，默认复用单行文本输入能力；也可以通过 Base 的 `asFieldControl` 桥接自定义值控件，并配合 `asControlLabel().target(..., FIELD_LABEL_PAIR)` 支持标签点击聚焦。
- **Label**：为控件命名，默认开启 `activation`，点击标签时自动聚焦同一可用控件（自动过滤拖拽、辅助键点击及嵌套交互元素）。
- **Description**：可选的被动帮助文本，支持文本选中。
- **Error**：优先显示 `message` 属性，其次显示当前 `errors` 列表或内置英文兜底提示；关闭时默认卸载内容节点（设置 `keepMounted` 可保留隐藏节点）。
- **Validity**：只读状态观察节点，可通过 `getValidity()` 读取当前校验快照。

### 内置校验与受控结果

- `validationMode` 支持 `'onBlur'`（默认）、`'onChange'`（输入法合成期间等待 `compositionend`）和 `'manual'`。
- 内置约束检查支持 `required`、`minLength` 与 `maxLength`（按 UTF-16 code units 计算；可选的空字符串跳过长度检查）。`required` 将 `null`、`false`、`""` 与空数组视为空值，`0` 和空白字符串视为已填写且不自动裁剪。内置标志位为 `valueMissing`、`tooShort`、`tooLong`，外部校验错误使用 `customError`。
- 传入 `invalid` 进入受控校验模式：校验完成时触发 `validityChange`，由外部决定是否更新 `invalid` 与 `errors`。
- `resetValidation()` 仅重置校验结果与 `touched` 标记，不会清空输入值或修改 `dirty` 基线；如需整表提交或重置，请配合 `Form` 使用。

### 外部异步校验

开启 `externalValidation` 后，内置约束通过时会触发 `validationRequest` 事件（负载为 `{ requestId, value, reason }`）。应用在异步检查完成后调用 `resolveValidation(requestId, { invalid, errors })` 提交结果。若期间输入值变化、控件替换、策略变更或发起了新请求，过期结果会自动被忽略。

### 无障碍关联

- 组件自动维护 `Control` 与 `Label`、`Description` 的无障碍命名与描述关联，并仅在 `invalid` 为 `true` 时关联 `Error`（`aria-errormessage`），在卸载时自动清理，无需手写 DOM ID。
- Web 宿主同步输出 `aria-required`、`aria-invalid`、`aria-busy` 与 `aria-readonly`。`Error` 不会自动创建 live region；如需屏幕阅读器即时播报，可结合 `LiveRegion` 使用。

### 其他部件属性

- **Label**：`activation?: boolean`（默认 `true`）
- **Description**：无独立属性
- **Error**：`message?: string`（默认 `''`），`keepMounted?: boolean`（默认 `false`）
- **Validity**：无独立属性

### 方法与事件

- **Root 方法**：`validate(reason?)`、`resolveValidation(requestId, result)`、`cancelValidation()`、`resetValidation()`、`focusControl(options?)`、`getValidity()`
- **事件**：`validityChange`（返回校验状态与快照）、`validationRequest`（负载为 `{ requestId, value, reason }`）
