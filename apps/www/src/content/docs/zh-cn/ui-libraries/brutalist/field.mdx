Brutalist Field 将表单控件与其标签、帮助说明、错误提示与校验状态组合为一体，支持垂直与水平布局、同步内置校验与外部异步校验，并遵循 5px 圆角（`rounded-base`）、2px 边框与 DM Sans 排版规范。

## 安装

当前仅在源码工作区提供，可从 `@proto.ui/prototypes-brutalist/field` 导入核心部件与已绑定控件：

```ts
import {
  fieldRoot,
  fieldLabel,
  fieldControl,
  fieldDescription,
  fieldError,
  fieldValidity,
  fieldTextarea,
  fieldCheckbox,
  fieldRadioGroup,
  fieldSwitch,
} from '@proto.ui/prototypes-brutalist/field';
```

## 用法

```tsx
import {
  FieldRoot,
  FieldLabel,
  FieldControl,
  FieldDescription,
  FieldError,
} from '@proto.ui/prototypes-brutalist/field';

export function ProfileField() {
  return (
    <FieldRoot required>
      <FieldLabel>Name</FieldLabel>
      <FieldControl placeholder="Jane Doe" />
      <FieldDescription>Displayed on your public profile.</FieldDescription>
      <FieldError />
    </FieldRoot>
  );
}
```

### 部件组成与校验

- **Root**：管理校验状态（`invalid`、`errors`）、`dirty`、`touched`、`orientation`（`vertical` / `horizontal`）以及禁用/只读/必填策略。嵌套 `Root` 彼此独立。
- **Control 与绑定控件**：默认 `Control` 为单行文本输入；也可组合 `fieldTextarea`、`fieldCheckbox`、`fieldRadioGroup` 与 `fieldSwitch`，或通过 Base 的 `asFieldControl` 桥接自定义控件。
- **自动无障碍关联**：自动维护 `aria-labelledby`、`aria-describedby` 与（仅在 `invalid` 为 `true` 时）`aria-errormessage`，并在卸载时自动清理。
- **内置与异步校验**：支持 `required`、`minLength`、`maxLength`、`validationMode`（`'onBlur'` / `'onChange'` / `'manual'`）、受控 `invalid` 与 `externalValidation`。

### 其他部件与方法事件

- **Label**：`activation?: boolean`（默认 `true`）
- **Error**：`message?: string`（默认 `''`），`keepMounted?: boolean`（默认 `false`）
- **Description / Validity**：无独立属性
- **Root 方法**：`validate(reason?)`、`resolveValidation(requestId, result)`、`cancelValidation()`、`resetValidation()`、`focusControl(options?)`、`getValidity()`
- **事件**：`validityChange`、`validationRequest`（`{ requestId, value, reason }`）
