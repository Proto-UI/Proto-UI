Brutalist Drawer 是可从屏幕四个边缘滑出的模态面板，支持内容自适应尺寸、拖拽关闭、多档吸附高度（snap points）以及垂直滚动长内容。

## 用法

### 尺寸、边缘与滚动

- **尺寸策略**：`top` / `bottom` 抽屉默认按内容高度自适应（最大不超过可用高度减去 6 个根文本单位）；`left` / `right` 抽屉使用比例宽度（默认上限 20 个根文本单位）。可通过 `Content` 的 `minExtent` / `maxExtent` 传入中立长度配置尺寸（`unit` 支持 `'logical'`、`'root-text'`、`'available'` 或 `'available-minus-root-text'`），例如 `maxExtent={{ unit: 'logical', value: 480 }}`，无需额外覆盖 CSS `width`。
- **长内容滚动**：`Content` 内置 `overflow-y-auto` 滚动容器；若直接将 `Root` 放进 CSS Grid 布局，可在 React 中设置 `hostStyle={{ display: 'contents' }}`（或在 Web Component 上设置 `display: contents`）避免产生空网格轨道。
- **拖拽关闭**：设置 `Content` 的 `dragDismissible={false}` 可禁用拖拽关闭，同时保留 `Close` 按钮、`Escape` 键与点击外部关闭。

- 在 `top` / `bottom` 抽屉上提供非空的 `snapPoints` 数组（取值范围 `(0, 1]`，相对完整安全上限）可启用多档吸附，配合 `defaultSnapPoint`（非受控）或 `snapPoint` / `snapPointChange`（受控）管理当前档位。
- 在内容自适应模式下，`Handle` 为纯指针拖拽把手；启用显式吸附点后，`Handle` 同时提供具名 `separator` 语义及方向键、`Home` / `End` 调整支持。

传入 `open: boolean` 进入受控模式。

### 其他部件属性

- **Mask**：`passthrough?: boolean`（默认 `false`）及 Transition 属性
- **Content**：`side`（默认 `'bottom'`）、`minExtent`、`maxExtent`、`snapPoints`、`snapPoint`、`defaultSnapPoint`、`dragDismissible` 及 Transition 属性
- **Handle**：`disabled?: boolean`（默认 `false`），`a11yLabel?: string`（默认 `'Resize drawer'`）
- **Trigger / Title / Description / Header / Footer / Close / AcceptedSide**：无独立属性
