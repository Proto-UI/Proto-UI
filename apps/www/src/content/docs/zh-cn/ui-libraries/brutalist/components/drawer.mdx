Brutalist Drawer 是采用 2px 硬黑边框、5px 圆角与 4px 零模糊阴影的模态抽屉面板，支持四个屏幕边缘滑出、内容自适应高度、长内容滚动与多档拖拽吸附。

## 用法

```tsx
import {
  BrutalistDrawerRoot,
  BrutalistDrawerTrigger,
  BrutalistDrawerMask,
  BrutalistDrawerContent,
  BrutalistDrawerHandle,
  BrutalistDrawerHeader,
  BrutalistDrawerTitle,
  BrutalistDrawerDescription,
  BrutalistDrawerFooter,
  BrutalistDrawerClose,
} from '../proto-ui/components/react';
```

```tsx
<BrutalistDrawerRoot>
  <BrutalistDrawerTrigger>Open Drawer</BrutalistDrawerTrigger>
  <BrutalistDrawerMask />
  <BrutalistDrawerContent side="bottom">
    <BrutalistDrawerHandle />
    <BrutalistDrawerHeader>
      <BrutalistDrawerTitle>Are you absolutely sure?</BrutalistDrawerTitle>
      <BrutalistDrawerDescription>
        Publish the latest build to the staging environment.
      </BrutalistDrawerDescription>
    </BrutalistDrawerHeader>
    <BrutalistDrawerFooter>
      <BrutalistDrawerClose>Cancel</BrutalistDrawerClose>
    </BrutalistDrawerFooter>
  </BrutalistDrawerContent>
</BrutalistDrawerRoot>
```

### 部件结构与设计规则

```text
DrawerRoot
├── DrawerTrigger
├── DrawerMask
└── DrawerContent
    ├── DrawerHandle
    ├── DrawerHeader
    │   ├── DrawerTitle
    │   └── DrawerDescription
    └── DrawerFooter
        └── DrawerClose
```

- **抬起与按压反馈**：`Trigger` 与 `Close` 均具备 `4px 4px` 硬黑阴影与按压落位（`+4px, +4px`）反馈；`Content` 在暴露边缘保持 `5px`（`rounded-base`）圆角与 200ms 滑入动效，`Mask` 采用 150ms 淡入淡出。
- **尺寸与滚动**：`top` / `bottom` 抽屉默认按内容高度自适应（最大不超过可用高度减去 6 个根文本单位）；`left` / `right` 抽屉默认上限为 20 个根文本单位。将正文区域设为 `flex-1 overflow-y-auto` 即可在长内容时保持标题与底部按钮可见。
- **吸附与无障碍**：提供 `(0, 1]` 比例数组 `snapPoints` 后，`Handle` 具备具名 `separator` 语义并支持方向键及 `Home` / `End` 调节，暗色模式下使用语义前景色保持高对比度。

### Root

传入 `open` 进入受控模式，通过 `openChange` 监听状态变更请求；同时暴露 `openDrawer()`、`close()` 与 `toggle()` 方法。
