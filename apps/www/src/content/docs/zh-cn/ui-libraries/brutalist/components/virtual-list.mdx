Virtual List 将完整稳定逻辑标识序列与物理视图区分。按项 overscan、最大物化数量、修订号与 generation 绑定的提交由宿主无关模型负责。显式 virtual-list/web 入口测量可变项尺寸、管理占位与 Web 节点、保留键对应视图、定位项并清理监听。此 demo 使用该 Web 宿主边界，不代表原生 GPUI 或 Compiler 一致性。应用内容仅按有界可见区间创建。

## 物化宿主的所有权与退休

每个逻辑集合只接受一个物化宿主租约。`attachWebVirtualList` 在添加占位、行视图或监听之前取得租约；第二个宿主的挂载会失败，且不干扰当前宿主。替换宿主前先 dispose 旧宿主。可移植模型向其他宿主实现提供 `acquireMaterializer(onRetired)`；调用 Web 入口时无需在外层再取得一次租约。

Root 卸载或销毁时会让物化宿主退休：在途 generation 失效，已持有视图与观察器被清理；旧宿主晚到的 refresh、滚动、测量或重复 dispose 不能撤销替代宿主。首次渲染或观察器安装失败也释放租约，同一逻辑集合可以重试。这些所有权规则补充 generation 绑定的 request／commit 协议，不代表非 Web 物化器或原生辅助技术已验收。
