Virtual List 将完整的逻辑项标识序列（`itemKeys`）与实际挂载的 DOM 节点分离，只为可见视口及缓冲区创建行内容。Brutalist 版本采用 5px 圆角（`rounded-base`）、2px 黑色边框、圆角溢出裁切与 DM Sans 排版，无模糊投影。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `@proto.ui/prototypes-brutalist/virtual-list` 导入列表原型，并结合 `@proto.ui/prototypes-base/virtual-list/web` 完成 Web 视口挂载。

## 用法

Virtual List 由 `Root`、`Viewport` 与 `Content` 组成。`Root` 管理有序 `itemKeys` 与圆角裁切容器，`Viewport` 承担滚动与内嵌键盘焦点环，`Content` 承载动态挂载的行节点。

```ts
import { AdaptToWebComponent, setElementProps } from '@proto.ui/adapter-web-component';
import {
  virtualListRoot,
  virtualListViewport,
  virtualListContent,
} from '@proto.ui/prototypes-brutalist/virtual-list';
import { attachWebVirtualList } from '@proto.ui/prototypes-base/virtual-list/web';

AdaptToWebComponent(virtualListRoot);
AdaptToWebComponent(virtualListViewport);
AdaptToWebComponent(virtualListContent);

const list = document.querySelector('brutalist-virtual-list-root')!;
const viewport = document.querySelector('brutalist-virtual-list-viewport')!;
const content = document.querySelector('brutalist-virtual-list-content')!;

setElementProps(list, {
  itemKeys: Array.from({ length: 1000 }, (_, i) => `event-${i + 1}`),
  overscanItems: 3,
  maxMaterializedItems: 60,
});

const host = attachWebVirtualList({
  viewport,
  content,
  collection: list.getExposes().getCollection(),
  estimateSize: 68,
  renderItem(key) {
    const row = document.createElement('div');
    row.className = 'border-b-2 border-black px-4 py-3 text-sm';
    row.textContent = key;
    return row;
  },
});

// 按需滚动到目标键，卸载时释放监听与行节点
host.ensureVisible('event-250', 'center');
// host.dispose();
```

### 结构与无障碍

- `Root` 提供 `role="region"` 与 `a11yLabel`，采用 2px 黑色外框与 `overflow-hidden` 裁切内部滚动内容，不叠加多余内边框。
- `Viewport` 继承 `Scroll Area` 滚动与键盘聚焦状态，聚焦时显示 2px 内嵌焦点环。
- `Content` 声明 `role="list"`，挂载行自动补充 `role="listitem"`、`aria-posinset` 与 `aria-setsize`。

### 进阶：自定义渲染宿主

- 每个逻辑列表实例同一时刻仅允许挂载一个活跃渲染宿主；`attachWebVirtualList` 会自动接管并在 `Root` 卸载或销毁时清理节点与观察器。
- 替换宿主前请先调用旧宿主的 `dispose()`；非 Web 宿主可通过 `collection.acquireMaterializer(onRetired)` 接入同一租约协议。
