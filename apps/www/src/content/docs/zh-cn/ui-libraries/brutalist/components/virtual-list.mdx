## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `@proto.ui/prototypes-brutalist/virtual-list` 导入列表原型，并结合 `virtual-list/web` 入口完成 Web 宿主挂载。

## 用法

### 逻辑模型与 Web 物化挂载

- 宿主无关模型管理 `itemKeys`、缓冲区数量（`overscanItems`）、最大物化项数（`maxMaterializedItems`）以及按代次绑定的提交。
- `virtual-list/web` 提供的 `attachWebVirtualList` 负责测量可变行高、维护上下占位空间、按 key 复用行视图、滚动定位指定 key 以及销毁监听器。

### 物化宿主生命周期

- 每个逻辑列表实例同一时间只允许一个活跃的物化宿主租约。`attachWebVirtualList` 会自动获取租约（自定义其他宿主时可调用 `acquireMaterializer(onRetired)`，使用 Web 入口无需重复获取）。
- 若已有活跃宿主，再次挂载第二个宿主会失败且不会影响当前宿主；替换前请先销毁（`dispose`）旧宿主。
- 当 `Root` 卸载或销毁时，当前物化宿主会自动退休，失效在途代次并清理已持有的行视图与观察器；旧宿主晚到的刷新、滚动、测量或重复销毁调用不会影响后续新宿主。首次渲染或观察器初始化失败也会自动释放租约，便于重试。
