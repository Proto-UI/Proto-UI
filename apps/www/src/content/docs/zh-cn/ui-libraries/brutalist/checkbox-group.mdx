Brutalist Checkbox Group 用于管理一组多选框的选中值数组，支持全选/半选联动与垂直/水平排布，遵循 Brutalist 的 2px 实线方框、DM Sans 500 正文字重与高对比度焦点环规范。

## 用法

```tsx
import {
  BrutalistCheckboxGroupRoot,
  BrutalistCheckboxGroupAll,
  BrutalistCheckboxGroupItem,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <BrutalistCheckboxGroupRoot defaultValue={['email']} ariaLabel="Notification channels">
      <BrutalistCheckboxGroupAll>All notifications</BrutalistCheckboxGroupAll>
      <BrutalistCheckboxGroupItem value="email">Email updates</BrutalistCheckboxGroupItem>
      <BrutalistCheckboxGroupItem value="sms">SMS alerts</BrutalistCheckboxGroupItem>
    </BrutalistCheckboxGroupRoot>
  );
}
```

### 部件结构与键盘交互

- **Root**：通过 `value` / `defaultValue` 管理选中值字符串数组，支持 `orientation`、`disabled`、`readOnly` 与 `ariaLabel`。
- **Item**：表示单个选项，需提供唯一 `value` 并支持独立的 `disabled`。每个可用项拥有独立 `Tab` 停靠点，按 `Space` 切换（`Enter` 不切换）。
- **All**：根据全部可用选项自动推导勾选、半选（`mixed`）或未选状态，点击时仅切换未禁用项并保留已禁用项的原状态。
- **无障碍与表单**：20×20 方形指示器绘制对勾或横线图标，焦点环直接作用在指示框上；置于 `Field` 或 `FormField` 内时自动支持标签点击聚焦、必填校验、序列化与重置。

### 事件、方法与状态

- **Root 事件**：`valueChange`（载荷 `{ value: string[] }`）。
- **Root 方法**：`getValue(): string[]`、`resetValue(): boolean`、`focusSelf(): void`。
- **暴露状态**：Root 暴露 `checked`、`indeterminate`、`disabled`、`readOnly`；Item 与 All 暴露 `checked`、`indeterminate`、`disabled`、`readOnly`、`focused`、`focusVisible`。
