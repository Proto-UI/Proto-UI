Brutalist Checkbox Group 用于管理一组多选框的选中值数组，支持“全选/半选”联动，并内置清晰的勾选与横线状态指示器。

## 用法

### 部件组成

Checkbox Group 由 `Root`、`Item` 和 `All` 三个部件组成：

- **Root**：通过 `value` / `defaultValue` 统一管理选中项的字符串数组，支持 `disabled`、`readOnly` 与 `ariaLabel`。
- **Item**：表示单个选项，需提供唯一的 `value`，支持独立的 `disabled` 属性。重复的 `value` 会忽略含糊的切换请求。
- **All**：根据已注册的可用选项自动推导全选或半选（mixed）状态，切换时仅操作未禁用选项，并保留禁用选项的当前选中态。

`Item` 与 `All` 内置装饰性状态图标（选中为勾、半选为横线、未选中为空框），确保状态表达不仅依赖颜色。

### 受控模式与交互

- 传入 `value` 进入受控模式，切换操作触发 `valueChange` 事件，不直接覆盖外部状态；调用 `getValue()` 可获取当前值数组的副本。
- 每个选项拥有独立的 `Tab` 停靠点，按 `Space` 切换选中态，按 `Enter` 不会触发切换。
- 放入 `Field` 或 `Form` 中时，`Root` 自动同步数组值、焦点与策略，支持标签点击聚焦、必填校验、表单序列化与重置（不生成隐藏的原生 HTML 表单项）。

### 其他部件属性

- **Item**：`value: string`，`disabled?: boolean`（默认 `false`）
- **All**：无独立属性
