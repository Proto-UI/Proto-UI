Resizable 将容器划分为两个或多个按百分比分配空间的面板，并通过带索引的分隔柄连续调整相邻面板的比例，同时支持嵌套不同方向的独立分栏。

## 用法

### 组件结构与索引

- `Root`：统一管理各面板的百分比尺寸、约束、方向与受控/非受控状态。
- `Panel`：按 `index`（`0..N-1`）标识各个面板，并将无量纲尺寸导出到 `--pui-size`，由静态 `flex-basis` CSS 规则驱动布局。
- `Handle`：按 `index`（`0..N-2`）标识分隔柄，每个分隔柄指向其前一个面板并调整相邻两面板的比例（默认无障碍名称为 `Resize panels`）。

### 多面板尺寸与约束

- 通过 `Root` 的 `sizes` / `defaultSizes` 传入完整百分比数组（自动归一化使总和为 `100`）；原有双面板的 `value` / `defaultValue` 属性继续可用，显式传入 `sizes` 时以数组为准。
- `constraints` 可为每个面板单独配置 `min`（默认 `0`）、`max`（默认 `100`）、`collapsible`（默认 `false`）和 `collapsedSize`（默认 `0`）。非法或不可行布局会忽略变更并保持上一个有效状态。
- 拖动分隔柄或按键调整时，只改变相邻两个面板的分配并保持其余面板尺寸不变。折叠作为离散停点生效，并受相邻面板上限约束。
- 嵌套 `Root` 各自独立管理尺寸比例、约束与水平/垂直方向。拖动计算按面板实际边框尺寸归一化，不把固定分隔柄宽度计入分母。

### 键盘交互与受控模式

- 指针拖动、方向键、`Home` / `End`、`Shift` 加速步进和折叠均走同一套受约束请求路径。
- 读取 `sizes` 或调用 `requestResize(index, nextSize, commit)` / `requestSizes(nextSizes, commit)` 进行程序化调整。`sizesChange` 与 `sizesCommit` 事件载荷为 `{ sizes }`；取消手势不会触发 `sizesCommit`。
- 传入 `sizes` 进入受控模式：父级采纳提议值则更新，保持原值则拒绝，面板尺寸与 ARIA 属性始终与当前已提交值一致。

## API

以下属性属于 `Root`（传入 `sizes` 或 `value` 进入受控模式）：

其余子部件：

- **Panel**：`index` 默认 `0`。
- **Handle**：按 `index`（`0..N-2`）对应前一个面板，无障碍名称默认为 `Resize panels`。
