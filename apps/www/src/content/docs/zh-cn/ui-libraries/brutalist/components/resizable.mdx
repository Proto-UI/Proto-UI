Brutalist 风格的可调整分栏组件：外层面板组采用 `5px` 圆角（`rounded-base`）、`2px` 黑色边框、零模糊 `4px 4px` 硬影与 `DM Sans` 字体，内嵌分组通过 `variant="nested"` 保持无重复边框。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可直接从 `@proto.ui/prototypes-brutalist/resizable` 导入原型并使用目标宿主 Adapter 适配：

```ts
import {
  resizableRoot,
  resizablePanel,
  resizableHandle,
} from '@proto.ui/prototypes-brutalist/resizable';
```

## 用法

```tsx
import {
  BrutalistResizableRoot,
  BrutalistResizablePanel,
  BrutalistResizableHandle,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <BrutalistResizableRoot defaultSizes={[50, 50]} className="h-56 w-full max-w-md">
      <BrutalistResizablePanel index={0}>One</BrutalistResizablePanel>
      <BrutalistResizableHandle index={0} withHandle />
      <BrutalistResizablePanel index={1}>Two</BrutalistResizablePanel>
    </BrutalistResizableRoot>
  );
}
```

### 组合结构

```text
BrutalistResizableRoot (variant="default" | "nested")
├── BrutalistResizablePanel (index: 0)
├── BrutalistResizableHandle (index: 0, withHandle?)
└── BrutalistResizablePanel (index: 1)
```

- 顶层 `Root` 默认附带 `rounded-base`、2px 黑框与 4px 硬阴影；在面板内部嵌套另一个 `Root` 时传入 `variant="nested"`，避免双重边框与阴影堆叠。
- 布局包含 `N` 个 `Panel`（`index: 0..N-1`）与 `N - 1` 个 `Handle`（`index: 0..N-2`），通过 `--pui-size` 驱动静态 `flex-basis`。
- `Handle` 默认绘制 2px 黑色分隔线并提供方向性拖拽光标；设置 `withHandle` 可显示主色带黑框的 Brutalist 抓握徽章。
- 支持指针拖动、方向键、`Shift` 加速、`Home` / `End` 与 `Enter` 折叠；传入 `sizes` 进入受控模式并通过 `sizesChange` / `sizesCommit` 响应变更。

### Panel 与 Handle

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'Panel.index', type: 'number', default: '0' },
    { name: 'Handle.index', type: 'number', default: '0' },
    { name: 'Handle.withHandle', type: 'boolean', default: 'false' },
  ]}
/>

- **暴露状态**：Root 暴露 `value`、`sizes`；Panel 暴露 `size`；Handle 暴露 `value`、`focusVisible`、`disabled`。
- **事件与方法**：Root 触发 `sizesChange` / `sizesCommit` / `valueChange` / `valueCommit`，并提供 `requestResize(index, next, commit?)`、`requestSizes(next, commit?)`、`requestValue(next, commit?)` 与 `cancelResize()`。
