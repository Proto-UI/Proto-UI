Resizable 支持两个或多个比例面板及逐个编号的分隔柄。每个柄连续调整相邻两个面板；嵌套 Root 独立管理自己的比例和方向。指针、方向键、Home/End、Shift 加速与折叠走同一条约束请求路径。

当前是功能源码 WIP。完整 Adapter/Compiler、原生 GPUI、包消费者、无障碍与绑定提交的视觉验收仍待补齐。

Panel 通过既有 exposed-state 投影导出无量纲 size；Web CSS 使用读取 --pui-size 的静态 flex-basis 规则，不再依赖运行时动态百分比 token。

## API

Root 的 `sizes` / `defaultSizes` 表示完整百分比数组。N 个 Panel 使用 `index: 0..N-1`，N−1 个 Handle 使用 `index: 0..N-2`；Handle 的 index 指向其前一个面板，无障碍名称仍是 `Resize panels`。原有 `value` / `defaultValue` 双面板 API 保留；显式提供 `sizes` 时以数组为准。

### 多面板所有权

`constraints` 逐面板提供 `min`、`max`、`collapsible`、`collapsedSize`，默认分别为 0、100、false、0。比例归一化为总计 100；不可行布局保留上一个有效状态并拒绝调整。分隔柄保留相邻两面板的总量和其他面板的大小。折叠是离散停点，相邻面板的上限可能阻止折叠。

读取 `sizes`，或调用 `requestResize(index, nextSize, commit)` / `requestSizes(nextSizes, commit)`。`sizesChange`、`sizesCommit` 的载荷为 `{ sizes }`。传入 `sizes` 进入受控模式，父级回传提议表示接受，保持原值表示拒绝；面板与 ARIA 始终跟随已提交值。取消手势不发 commit。

嵌套 Root 独立管理所有权、约束和几何。示例包含三个水平面板，以及内部两个垂直面板；拖动按面板实际总长度归一化，不把固定分隔柄宽度计入分母。
