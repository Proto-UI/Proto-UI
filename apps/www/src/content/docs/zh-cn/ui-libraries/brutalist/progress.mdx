Brutalist Progress 用于展示任务的确定完成进度或不确定加载状态，采用 5px `rounded-base` 圆角、2px 黑色描边轨道与带分隔边的主色填充条呈现。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。注册包入口后可从 `@proto.ui/prototypes-brutalist/progress` 导入：

```ts
import {
  progressRoot,
  progressLabel,
  progressTrack,
  progressIndicator,
  progressValue,
} from '@proto.ui/prototypes-brutalist/progress';
```

## 用法

将 `Label` 与 `Value` 置于 `Track` 之前即可在轨道上方自动形成左右对齐的标题行；标签默认采用 DM Sans `font-sans font-medium` 并保留原始大小写：

```tsx
<BrutalistProgressRoot value={56} valueText="56%" className="w-full max-w-sm">
  <BrutalistProgressLabel>Upload progress</BrutalistProgressLabel>
  <BrutalistProgressValue />
  <BrutalistProgressTrack>
    <BrutalistProgressIndicator />
  </BrutalistProgressTrack>
</BrutalistProgressRoot>
```

```text
ProgressRoot
├── ProgressLabel
├── ProgressValue
└── ProgressTrack
    └── ProgressIndicator
```

- **范围与不确定态**：`value` 自动限制在 `[min, max]` 内（`min === max` 时百分比为 `0`）。省略 `value` 或将 `indeterminate` 设为 `true` 时进入不确定加载态，并向辅助技术隐藏具体当前数值。
- **被动展示**：Progress 不引入键盘停靠点；更新 `Root` 属性会自动同步所有部件暴露的 `value`、`percentage`、`indeterminate` 与 `status`。
