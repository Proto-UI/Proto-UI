## 用法

### 部件组成

- **Root**：管理当前进度 `value`、范围 `min` / `max`（默认 `0` / `100`）与 `indeterminate` 状态。数值自动约束在 `[min, max]` 内；当 `min` 与 `max` 相等时比例为 `0`。
- **Label**：提供可读的进度条名称。
- **Track / Indicator**：进度轨道与填充条，根据计算百分比渲染进度。
- **Value**：展示 `valueText` 或当前进度数值。

### 不确定进度与无障碍

- 省略 `value` 或将 `indeterminate` 设为 `true` 时，组件进入不确定进度状态，此时不会向辅助技术报告具体进度值。
- Progress 为被动展示组件，不引入键盘停靠点；更新 `Root` 属性会自动同步所有子部件暴露的 `value`、`percentage`、`indeterminate` 与 `status`。
