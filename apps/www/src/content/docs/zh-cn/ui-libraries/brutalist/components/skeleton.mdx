Skeleton 用于在内容加载前展示静态占位轮廓。它采用 5px 圆角中性表面与 `2px` 黑色边框，不带外阴影与内置闪烁动画，由外层布局决定宽高与圆角形态。

## 安装

已包含在 `@proto.ui/prototypes-brutalist@0.2.0` 中。可通过 CLI 目标 `brutalist-skeleton` 添加（将命令中的 `react` 替换为 `wc`、`vue` 或 `vue2` 以匹配目标框架），或直接从 `@proto.ui/prototypes-brutalist/skeleton` 导入：

  }}

## 用法

```tsx
import { BrutalistSkeletonRoot } from '../proto-ui/components/react';

export function Example() {
  return <BrutalistSkeletonRoot className="h-5 w-48 rounded-full" />;
}
```

- **由消费端控制尺寸**：Skeleton 本身不声明宽高，通过外层布局与 `className`（如 `h-4 w-48`、`h-12 w-12 rounded-full`）贴合目标内容的形状。
- **纯视觉占位语义**：Skeleton 不渲染子节点且默认设置 `aria-hidden="true"`、不可聚焦；加载态（`aria-busy`）、状态播报、内容替换时机与焦点衔接应由父级加载区域统一管理。
- **静态动效契约**：默认不附带脉冲闪烁动画；如需自行扩展过渡或动画，请遵循 `prefers-reduced-motion`。

## API

### Root
