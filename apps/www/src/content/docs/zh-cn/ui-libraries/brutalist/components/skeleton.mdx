Skeleton 是一个纯视觉占位表面，采用静态 5px 圆角中性底色与黑色边框，不带阴影或内置闪烁动画，用于在内容加载前勾勒布局形状。

## 安装

已包含在 `@proto.ui/prototypes-brutalist@0.2.0` 中。可通过 CLI 目标 `brutalist-skeleton` 添加，或从 `@proto.ui/prototypes-brutalist/skeleton` 导入。

## 用法

- 将 Skeleton 放在父级加载区域内，通过外层样式控制宽高与圆角形态，以匹配真实内容的布局轮廓。
- Skeleton 默认从无障碍树中隐藏；加载态（`aria-busy`）、状态播报、内容替换时机与焦点衔接应由父级容器统一管理。
- 如需为占位块添加自定义动画，请配合 `prefers-reduced-motion` 偏好设置。
