> 状态：公开 rc.7 草案候选。package 与 CLI 条目已进入本 release train，但在正式发布完成前仍不可安装。

Brutalist Skeleton 是一个直接定义的 styled-only 视觉占位原型：静态方形 Yandu 薰衣草紫表面，带有 ink 边框和硬阴影。它是 passive、contentless、从 accessibility tree 隐藏的，也不拥有重复 shimmer 或 pulse。

当未解析布局需要视觉形状反馈时，可以把它放在父级 async/loading region 中。loading 与 `aria-busy` 状态、announcement、占位内容替换时机和焦点连续性均由父级拥有；Skeleton 不创建这些语义。若应用额外添加 motion，也必须尊重 reduced-motion 偏好。
