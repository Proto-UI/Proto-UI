Surface 是基于 [Base Surface](/zh-cn/ui-libraries/base/surface/) 的 Brutalist 被动视觉容器，默认使用 5px 圆角（`rounded-base`）、2px 主题边框与 4px 零模糊硬影，由外层组件驱动视觉状态并保持原有语义与交互所有权。

<InstallCommandCard command="npx @proto.ui/cli@latest add wc brutalist-surface" manager="npm" />

将命令中的 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的组件封装。

## 用法

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { surfaceRoot } from '@proto.ui/prototypes-brutalist/surface';

const Surface = createReactAdapter(React)(surfaceRoot);

export function Summary() {
  return (
    <Surface variant="secondary" elevation="raised">
      <div className="p-4 font-medium">Saved locally</div>
    </Surface>
  );
}
```

### 状态输入与组合原则

- `hovered`、`focusVisible`、`pressed` 和 `current` 均由外层交互控件传入，Surface 本身不监听事件，也不设置 ARIA 角色或焦点停靠点。
- `elevation="raised"` 提供 4px 硬影并在悬停或按压时沿 `+4px, +4px` 落位；当系统偏好 `prefers-reduced-motion: reduce` 时自动切换为无过渡静态反馈。
- 开启 `fade` 后，Surface 会将来自 [Transition](/zh-cn/ui-libraries/base/transition/) 的 `transitionState` 映射为透明度（`closed` / `leaving` 为 `0`，`entering` / `entered` 为 `1`），Web 端读取 `--pui-surface-transition-duration`（默认 `0ms`）。

## API

以下属性属于 `Root`（移除属性时恢复默认值）：

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    {
      name: 'variant',
      type: "'transparent' | 'outline' | 'secondary' | 'muted' | 'accent' | 'solid' | 'scrim'",
      default: 'outline',
    },
    {
      name: 'radius',
      type: "'default' | 'none' | 'sm' | 'md' | 'lg' | 'xl' | 'full'",
      default: 'default',
    },
    { name: 'border', type: "'all' | 'bottom' | 'none'", default: 'all' },
    { name: 'elevation', type: "'none' | 'raised'", default: 'none' },
    {
      name: 'transitionState',
      type: "'closed' | 'entering' | 'entered' | 'leaving'",
      default: 'entered',
    },
    { name: 'fade', type: 'boolean', default: 'false' },
    { name: 'hovered', type: 'boolean', default: 'false' },
    { name: 'focusVisible', type: 'boolean', default: 'false' },
    { name: 'pressed', type: 'boolean', default: 'false' },
    { name: 'current', type: 'boolean', default: 'false' },
  ]}
/>

`@proto.ui/prototypes-brutalist/surface` 同时导出 `SurfaceRootProps`、`SurfaceRootExposes`，以及被动操作外观组合辅助函数 `brutalistActionAppearance` 与 `BrutalistActionAppearanceOptions`。
