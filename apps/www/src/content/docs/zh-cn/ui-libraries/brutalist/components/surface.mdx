Surface 是基于 [Base Surface](/zh-cn/ui-libraries/base/surface/) 的 Brutalist 被动视觉容器，提供一个内容插槽并消费视觉外观与状态输入，适合为面板、卡片和交互控件提供统一的表面表现。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `@proto.ui/prototypes-brutalist` 或 `@proto.ui/prototypes-brutalist/surface` 导入 `surfaceRoot`（当前工作区 CLI 目标为 `brutalist-surface`）。

## 用法

### 基础示例

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { surfaceRoot } from '@proto.ui/prototypes-brutalist/surface';

const Surface = createReactAdapter(React)(surfaceRoot);

export function Summary() {
  return (
    <Surface variant="muted" radius="md" border="none">
      <div style={{ padding: '1rem' }}>Saved locally</div>
    </Surface>
  );
}
```

`/surface` 子路径与包根均导出 `surfaceRoot`，配套类型 `SurfaceRootProps` 与 `SurfaceRootExposes` 描述共用契约；如需自定义风格封装，可结合 Base 导出的 `asSurfaceRoot` 与 `SurfaceRootAsHookContract`。

### 状态输入与语义组合

- **纯被动视觉输入**：`hovered`、`focusVisible`、`pressed` 和 `current` 均由外层交互组件或状态管理方传入，Surface 本身不监听事件，也不设置 ARIA role、`aria-current` 或焦点停靠点。
- **保留原生语义**：当与原生链接或按钮组合时，将 `href`、`target`、`download` 或点击行为保留在原生元素或 Button 组件上，不要在 Surface 上重复叠加交互角色。
- **颜色与继承**：移除属性后会恢复默认值。`secondary` 使用 Brutalist 次级背景与常规前景色，不受 `elevation` 影响。当内部包含带样式的 Text 子元素并希望沿用 Surface 前景色时，可在 Text 上设置 `tone="inherit"`。

### 配合 Transition 使用

- 将 `fade` 设为 `true` 时，Surface 会根据来自 [Transition](/zh-cn/ui-libraries/base/transition/) 的 `transitionState` 映射透明度：`closed` 与 `leaving` 对应 `0`，`entering` 与 `entered` 对应 `1`；`fade={false}` 时不启用透明度映射。
- 在 Web 端，可通过 CSS 变量 `--pui-surface-transition-duration`（默认 `0ms`，需传入有限非负毫秒值）传递过渡时长。
- `scrim` 变体用于常规遮暗背景层。透明度为 `0` 仅影响视觉表现，交互禁用、焦点管理与挂载状态仍由外层 Dialog 或 Transition 负责。
