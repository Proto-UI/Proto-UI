## 用法

### 部件组成

每个 `Root` 内放置一个 `Trigger` 和一个 `Content`，嵌套或相邻的 `Collapsible` 彼此独立：

- **Root**：管理展开状态，支持受控 `open` 与非受控 `defaultOpen`，以及整体禁用 `disabled`（禁用后阻止切换，但不会强制收起已展开的内容）。
- **Trigger**：按钮触发器，支持自然 `Tab` 顺序与 `Enter` / `Space` 切换，自动同步展开与禁用状态。
- **Content**：承载折叠内容；关闭时默认卸载内容节点（设置 `keepMounted` 可保留隐藏节点）。支持长文本折行与容器收缩，布局外围建议为焦点环与硬阴影预留空间。

### 受控模式

传入 `open` 进入受控模式，监听 `openChange` 事件（负载为 `{ open, reason }`）后更新外部状态；若外部未接受该变更，面板保持原状态。

传入 `open: boolean` 进入受控模式。

### 其他部件属性

- **Trigger**：`disabled?: boolean`（默认 `false`）
- **Content**：`keepMounted?: boolean`（默认 `false`）

### 方法与事件

- **Root 方法**：`openCollapsible()`、`close()`、`toggle()`；**Trigger 方法**：`focusSelf()`
- **事件**：`openChange`（负载 `{ open, reason }`）
