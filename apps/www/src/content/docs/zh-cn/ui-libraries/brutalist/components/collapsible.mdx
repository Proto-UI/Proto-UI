Brutalist Collapsible 用于控制单个内容区块的展开与收起，采用 `rounded-base` 圆角、2px 粗边框与按压即落位的硬阴影设计，并完整继承 [Base Collapsible](/zh-cn/ui-libraries/base/collapsible/) 的交互语义。

## 安装

当前通过工作区源码与 CLI 目标提供：

<InstallCommandCard command="npx @proto.ui/cli@latest add wc brutalist-collapsible" manager="npm" />

将 `wc` 替换为 `react`、`vue` 或 `vue2` 即可生成对应框架封装，也可以直接从 `@proto.ui/prototypes-brutalist/collapsible` 导入部件：

```ts
import {
  collapsibleRoot,
  collapsibleTrigger,
  collapsibleContent,
} from '@proto.ui/prototypes-brutalist/collapsible';
```

## 用法

```tsx
import {
  BrutalistCollapsibleRoot,
  BrutalistCollapsibleTrigger,
  BrutalistCollapsibleContent,
} from '@/components/ui/collapsible';

export function Example() {
  return (
    <BrutalistCollapsibleRoot>
      <BrutalistCollapsibleTrigger>Product details</BrutalistCollapsibleTrigger>
      <BrutalistCollapsibleContent>
        This panel expands and collapses to reveal additional content.
      </BrutalistCollapsibleContent>
    </BrutalistCollapsibleRoot>
  );
}
```

### 部件结构与视觉规范

```text
CollapsibleRoot
├── CollapsibleTrigger
└── CollapsibleContent
```

- **抬起控件反馈**：默认与 `neutral` 变体的 `Trigger` 带有 4px 硬阴影，仅在按压（pressed）时沿阴影方向位移 `+4px, +4px` 并收起外影，悬停保持静止，符合 [Brutalist 设计契约](../../design-contract/)。
- **暗色主题适配**：边框与硬阴影通过主题变量在明暗模式下自适应重绘。
- **受控与卸载策略**：传入 `open` 并响应 `openChange`（载荷 `{ open, reason }`）进入受控模式；`Content` 默认关闭即卸载，设置 `keepMounted={true}` 可保留隐藏节点。

### 方法与事件

- **Root 方法**：`openCollapsible(reason?)`、`close(reason?)`、`toggle(reason?)`
- **Trigger 方法**：`focusSelf(options?)`
- **事件**：`openChange`（载荷 `{ open, reason }`）
