Brutalist Hover Card 在悬停或聚焦触发器时以可配置的延迟展开预览浮层，保留 Base Hover Card 的时序与碰撞定位语义，并以 5px 圆角、2px 黑框与 3px 零模糊前景硬阴影呈现浮层面板。

已发布的 `0.2.0` CLI 支持 `wc`、`react` 和 `vue`。使用 Vue 2.6 或下方工作区示例时，请安装同一工作区版本构建的 CLI、Brutalist 原型和适配器。

## 用法

```tsx
import {
  BrutalistHoverCardRoot,
  BrutalistHoverCardTrigger,
  BrutalistHoverCardContent,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <BrutalistHoverCardRoot openDelay={150} closeDelay={200}>
      <BrutalistHoverCardTrigger>@proto-ui</BrutalistHoverCardTrigger>
      <BrutalistHoverCardContent side="bottom" align="center">
        Host-neutral interaction protocols with bold Neo-Brutalist borders.
      </BrutalistHoverCardContent>
    </BrutalistHoverCardRoot>
  );
}
```

### 结构组成

```text
BrutalistHoverCardRoot
├── BrutalistHoverCardTrigger
└── BrutalistHoverCardContent
```

- **Root**：通过 `openDelay`（默认 `700ms`）与 `closeDelay`（默认 `300ms`）控制悬停展开与收起节奏，也支持传入 `open` 进入受控模式。
- **Trigger**：采用 `bg-main` 主色对与 4px 硬阴影，悬停落位时保留原始指针命中包络以避免边缘闪烁。
- **Content**：浮层面板遵循 Brutalist 设计契约，使用 `rounded-base`、`border-2 border-black` 与 `3px 3px` 前景硬阴影，支持四向滑入与碰撞翻转。
