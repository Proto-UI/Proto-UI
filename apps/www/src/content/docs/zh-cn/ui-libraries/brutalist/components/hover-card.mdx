Brutalist Hover Card 在悬停触发器时以可配置的延迟展开预览浮层，保留 Base Hover Card 的开合时序与定位逻辑，并以高对比度的硬边框与阴影面板呈现内容。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

- **CLI 目标**：`proto-ui add <react|vue|vue2|wc> brutalist-hover-card`

## 用法

- `Root` 通过 `openDelay`（默认 `700ms`）与 `closeDelay`（默认 `300ms`）控制悬停展开与收起节奏，也支持传入 `open` 进入受控模式。
- `Trigger` 承载触发区域，`Content` 支持定位方向、对齐、偏移、碰撞避让与过渡动画属性。

传入 `open: boolean` 进入受控模式。

### 其他部件属性

- **Trigger**：`disabled?: boolean`（默认 `false`）
- **Content**：支持 Transition 属性；`side`（默认 `'bottom'`）、`align`（默认 `'center'`）、`sideOffset`（默认 `4`）、`alignOffset`（默认 `0`）、`collisionPadding`（默认 `0`）、`avoidCollisions`（默认 `true`）
