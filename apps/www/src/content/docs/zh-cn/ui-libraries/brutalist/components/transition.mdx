Transition 负责管理内容的挂载与显隐过渡阶段（`closed → preparing → entering → entered → leaving`），Brutalist 风格采用简洁的扁平淡入淡出样式，不附加缩放、位移或阴影编排。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `@proto.ui/prototypes-brutalist` 或 `@proto.ui/prototypes-brutalist/transition` 导入（当前工作区 CLI 目标为 `brutalist-transition`）。

## 用法

- **显隐阶段与挂载**：组件暴露实时阶段 `transitionState` 与 `isPresent`，以及 `enter`、`leave`、`complete` 控制方法。离场期间内容节点保持挂载直至 `leaving` 结束，关闭后默认卸载内容节点。
- **扁平淡入淡出**：Brutalist 样式仅按阶段绑定端点透明度（`closed`、`preparing`、`leaving` 为 `opacity-0`；`entering`、`entered` 为 `opacity-100`），内容插槽保持透明。
- **中断策略与减少动态效果**：通过 `interrupt` 配置中途反转（`'reverse'`）、等待完成（`'wait'`）或立即切换（`'immediate'`）。当系统启用 `prefers-reduced-motion: reduce` 时，过渡时长自动折叠并即时完成。
- **受控与非受控**：使用 `defaultOpen` 初始化非受控状态，或传入 `open` 进入受控模式；设置 `appear={true}` 可在初次挂载时执行入场过渡。
