Transition 负责管理内容的挂载与五阶段显隐生命周期（`closed → preparing → entering → entered → leaving`）。Brutalist 风格严格遵循[设计契约](/zh-cn/ui-libraries/brutalist/design-contract/)的扁平淡入淡出边界，只绑定端点透明度，不叠加缩放、位移或阴影编排。

## 预览

## 安装

当前从公开包 `@proto.ui/prototypes-brutalist` 及其 `./transition` 子路径导出，不进入 `proto-ui add` CLI 目标列表：

```ts
import { transition } from '@proto.ui/prototypes-brutalist/transition';
// 或从包根导出：
import { brutalistTransition } from '@proto.ui/prototypes-brutalist';
```

## 用法

```tsx
import { useState } from 'react';
import { BrutalistButton, BrutalistTransition } from '../proto-ui/components/react';

export function BrutalistBannerTransition() {
  const [open, setOpen] = useState(true);

  return (
    <div className="flex flex-col items-center gap-4">
      <BrutalistTransition
        open={open}
        appear
        className="block transition-opacity duration-150 ease-linear motion-reduce:transition-none"
      >
        <div className="rounded-[5px] border-2 border-black bg-[#dcebfe] p-5 font-sans font-medium text-black shadow-[4px_4px_0_0_#000]">
          Workspace synced
        </div>
      </BrutalistTransition>
      <BrutalistButton onClick={() => setOpen((value) => !value)}>Toggle</BrutalistButton>
    </div>
  );
}
```

- **显隐阶段与挂载**：组件暴露实时阶段 `transitionState` 与 `isPresent`，以及 `enter`、`leave`、`complete` 控制方法。离场期间内容节点保持挂载直至 `leaving` 结束，关闭后默认卸载内容节点。
- **扁平淡入淡出边界**：`brutalist-transition` 仅按阶段绑定端点透明度（`closed`、`preparing`、`leaving` 为 `opacity-0`；`entering`、`entered` 为 `opacity-100`），内容插槽保持透明且不添加缩放或位移动效。
- **中断策略与减少动态效果**：通过 `interrupt` 配置中途反转（`'reverse'`）、等待完成（`'wait'`）或立即切换（`'immediate'`）。当系统启用 `prefers-reduced-motion: reduce` 时，过渡等待自动缩短为 `0ms` 并保持事件顺序不变。
- **底层语义**：相位机与视图存在性治理继承自 [Base Transition](/zh-cn/ui-libraries/base/transition/)。
