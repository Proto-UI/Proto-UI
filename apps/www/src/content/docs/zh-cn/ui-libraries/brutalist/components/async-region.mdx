Brutalist Async Region 是一个单部件语义容器，用于在区域内容处于异步更新期间同步输出 `aria-busy` 状态，同时保持内部自定义内容挂载与焦点不中断。

## 安装

当前通过工作区包导出提供，不进入 `proto-ui add` CLI 注册表。可直接从 `@proto.ui/prototypes-brutalist` 或子路径导入：

```ts
import { asyncRegionRoot } from '@proto.ui/prototypes-brutalist/async-region';
```

## 用法

```tsx
import { useState } from 'react';
import { AdaptToReact } from '@proto.ui/adapter-react';
import { asyncRegionRoot } from '@proto.ui/prototypes-brutalist/async-region';

const BrutalistAsyncRegionRoot = AdaptToReact(asyncRegionRoot);

export function ReleaseFeed() {
  const [busy, setBusy] = useState(false);

  return (
    <BrutalistAsyncRegionRoot busy={busy}>
      <p>异步刷新期间保留现有内容与焦点。</p>
    </BrutalistAsyncRegionRoot>
  );
}
```

- **语义边界**：设置 `busy={true}` 会在 `brutalist-async-region-root` 上同步输出 `aria-busy="true"`，并通过 `getExposes().busy` 暴露同一布尔状态。
- **Brutalist 视觉约束**：遵循 [Brutalist 设计契约](/zh-cn/ui-libraries/brutalist/design-contract/)，语义容器自身仅提供 `block min-w-0 max-w-full font-sans text-foreground` 的块级基础排版与墨色，不额外叠加边框、硬阴影或加载动效；2px 黑框与 4px 阴影由外层卡片与操作按钮承载。
- **按需组合**：可通过 `[aria-busy="true"]` 定制忙碌态表现，或按需搭配 `Spinner`、`Skeleton`、`Progress` 与 `Live Region` 使用。
