Brutalist Async Region 是一个单部件语义容器，用于在区域内容处于异步更新期间同步输出 `aria-busy` 状态，同时保持内部自定义内容挂载与焦点不中断。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

- **CLI 目标**：`proto-ui add <react|vue|vue2|wc> brutalist-async-region`
- **包导出**：从 `@proto.ui/prototypes-brutalist` 或 `@proto.ui/prototypes-brutalist/async-region` 导入

## 用法

- 设置 `busy={true}` 会在容器上输出 `aria-busy="true"`，并通过 `getExposes().busy` 暴露相同状态。
- 仅更新 `busy` 属性时，内部传入的子元素保持挂载且不丢失焦点；容器本身只提供 `min-w-0 max-w-full text-foreground` 的基础可读样式，不附加边框、阴影或加载动画。
- 如需显示视觉加载提示，可在内部自行组合 `Spinner`、`Skeleton` 或 `Progress`；如需屏幕阅读器实时播报状态变化，请配合 `Live Region` 使用。
