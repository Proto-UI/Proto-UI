Brutalist Tooltip 投影当前的三部件 Base Tooltip 协议：Root 负责受控或非受控 open state 与 delay，Trigger 负责 hover/focus 路由和无障碍描述关联，Content 负责 presence、锚定 portal 定位、Escape dismissal 与 `role="tooltip"`。

Brutalist 层只增加方形高对比 Content surface，不重复 interaction、accessibility、presence、portal 或 positioning behavior。悬停或聚焦下方 Trigger 可以打开 Tooltip，Escape 会关闭它。
