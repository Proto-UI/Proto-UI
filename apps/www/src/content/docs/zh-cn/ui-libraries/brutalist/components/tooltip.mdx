Tooltip 在悬停或键盘聚焦时展示简短的辅助说明文字，通过 Portal 锚定定位并自动维护 `aria-describedby` 与 `role="tooltip"` 无障碍关联。Brutalist 风格为 `Content` 提供 5px 圆角中性表面与 2px 主题前景色边框，并在浅色与深色模式间自动重绘。

## 安装

在应用中安装由同一源码版本构建的 `@proto.ui/cli`、`@proto.ui/prototypes-brutalist` 和目标宿主适配器（`@proto.ui/adapter-web-component`、`@proto.ui/adapter-react`、 `@proto.ui/adapter-vue` 或 `@proto.ui/adapter-vue2`；Vue 2 要求 Vue `>=2.6.0 <2.7`）。本地源码安装请使用仓库的 [仅打包流程](https://github.com/Proto-UI/Proto-UI/blob/main/scripts/release/publish.mjs) 和[干净消费者安装流程](https://github.com/Proto-UI/Proto-UI/blob/main/scripts/release/consumer-smoke-cli.mjs)。下方 React 示例从 `@proto.ui/prototypes-brutalist/tooltip` 导入原型，并通过 `@proto.ui/adapter-react` 直接适配。

使用配套的本地 CLI 初始化 Brutalist 样式，并在应用入口引入生成的 `proto-ui-style.css`。

## 用法

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import * as proto from '@proto.ui/prototypes-brutalist/tooltip';

const adapt = createReactAdapter(React);
const BrutalistTooltipGroup = adapt(proto.BrutalistTooltipGroup);
const BrutalistTooltipRoot = adapt(proto.BrutalistTooltipRoot);
const BrutalistTooltipTrigger = adapt(proto.BrutalistTooltipTrigger);
const BrutalistTooltipContent = adapt(proto.BrutalistTooltipContent);

export function Example() {
  return (
    <BrutalistTooltipGroup>
      <BrutalistTooltipRoot>
        <BrutalistTooltipTrigger>Hover</BrutalistTooltipTrigger>
        <BrutalistTooltipContent side="top">Add to library</BrutalistTooltipContent>
      </BrutalistTooltipRoot>
    </BrutalistTooltipGroup>
  );
}
```

### 组件结构

```text
TooltipGroup (可选)
└── TooltipRoot
    ├── TooltipTrigger
    └── TooltipContent
```

- `Group`：统一协调同组相邻 Tooltip 的打开/关闭延迟、热切换窗口（`skipDelay`）与当前激活项。
- `Root`：管理单个 Tooltip 的受控或非受控打开状态及单实例延迟覆盖。
- `Trigger`：透明触发器，负责路由悬停与焦点事件并自动维护 `aria-describedby`。
- `Content`：通过宿主 Portal 渲染 5px 圆角中性提示面板，支持浅色/深色主题边框自适应与 `Escape` 关闭。

### 在 Button 上组合 Tooltip

不要用独立 `Trigger` 包裹可聚焦的 Button，否则会产生两个 `Tab` 停靠点。应将 `useTooltipTrigger()` 与按钮原型组合到同一个元素上，再与 `Content` 并列放入 Tooltip `Root` 中：

```ts
import { definePrototype } from '@proto.ui/core';
import { asButton, type ButtonProps, type ButtonExposes } from '@proto.ui/prototypes-base/button';
import { useTooltipTrigger } from '@proto.ui/prototypes-base/tooltip';

export const tooltipButton = definePrototype<ButtonProps, ButtonExposes>({
  name: 'app-tooltip-button',
  setup() {
    asButton();
    useTooltipTrigger();
  },
});
```

- Button 保留自身角色、名称、点击事件、禁用态与单一焦点管理；`useTooltipTrigger()` 仅附加悬停/聚焦意图与 `aria-describedby` 关联。
- 禁用 Tooltip `Root` 仅关闭提示，按钮本身仍可点击；禁用按钮则同时抑制提示。
- 若按钮位于真实 `ShadowRoot` 内，请参考 [同树 Portal 配方](/zh-cn/ui-libraries/base/tooltip/#shadowroot)。

### 事件、状态与方法

- **Root**：暴露状态 `open`，事件 `openChange`（`{ open, reason }`），方法 `openTooltip(reason?)`、`close(reason?)`、`toggle(reason?)`。
- **Trigger**：暴露状态 `disabled`、`hovered`、`focused`、`focusVisible`，方法 `focusSelf(options?)`。
- **Content**：暴露状态 `open` 与 Transition 状态（`transitionState`、`isPresent`、`controls`）。
