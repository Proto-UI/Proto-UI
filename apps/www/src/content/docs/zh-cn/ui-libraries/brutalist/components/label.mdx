Brutalist `Label` 继承 Base Label 协议，采用 [Brutalist 设计契约](../../design-contract/) 中的被动标签排版（DM Sans 500、无外影、无交互动效），通过显式引用为控件提供无障碍命名与点击激活能力。

> 表单输入字段请优先使用 [Field](../../field/) 组件，内置 `FieldLabel`、`FieldDescription` 与 `FieldError` 自动关联与校验支持。

## 用法

从 `@proto.ui/core` 调用 `createControlLabelRef()` 为每对标签与控件创建稳定引用，并通过适配器通道传入：

```tsx
import { useMemo } from 'react';
import { createControlLabelRef } from '@proto.ui/core';
import {
  BrutalistCheckboxIndicator,
  BrutalistCheckboxRoot,
  BrutalistLabelRoot,
} from '../proto-ui/components/react';

export function TermsCheckbox() {
  const termsRef = useMemo(() => createControlLabelRef(), []);

  return (
    <div className="flex items-center gap-2">
      <BrutalistCheckboxRoot instanceAssociations={{ controlLabel: termsRef }}>
        <BrutalistCheckboxIndicator />
      </BrutalistCheckboxRoot>
      <BrutalistLabelRoot instanceAssociations={{ controlLabel: termsRef }}>
        Accept terms and conditions
      </BrutalistLabelRoot>
    </div>
  );
}
```

Web Components 通过 `@proto.ui/adapter-web-component` 的 `setElementAssociations()` 绑定同一引用：

```ts
import { createControlLabelRef } from '@proto.ui/core';
import { setElementAssociations } from '@proto.ui/adapter-web-component';

const termsRef = createControlLabelRef();
setElementAssociations(checkboxEl, { controlLabel: termsRef });
setElementAssociations(labelEl, { controlLabel: termsRef });
```

### 命名、激活与无障碍

- **`naming`（默认 `true`）**：目标控件自动关联真实渲染的 `Label` 作为无障碍名称；如果目标已显式声明非空 `ariaLabel` 或 `labelledBy`，可设置 `naming={false}` 仅用于点击激活。
- **`activation`（默认 `true`）**：点击标签会在同一次点击时机触发目标控件的默认操作（切换 `Checkbox` / `Switch`、选择 `Radio Group Item` 或聚焦 `Input` / `Textarea`）；如需仅命名，请设为 `activation={false}`。
- **`selection`（默认 `'policy'`）**：可激活标签默认抑制误选文字；需要允许复制时请设为 `selection="text"`。
- **交互边界**：`Label` 不增加额外 `Tab` 停靠点，自动忽略嵌套链接/按钮、修饰键点击与拖拽手势，且保持无阴影、无位移的被动标签表现。

### 关联辅助接口

- `createControlLabelRef()`：从 `@proto.ui/core` 导入，创建一对一不透明引用。
- `instanceAssociations`：React / Vue / Vue 2 传入 `{ controlLabel: ref }` 的适配器关联属性。
- `setElementAssociations(element, { controlLabel: ref })`：从 `@proto.ui/adapter-web-component` 导入，用于 Web Components 绑定。
