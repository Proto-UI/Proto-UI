Brutalist Label 通过显式引用关联为 `Checkbox`、`Switch`、`Radio Group Item`、`Input`、`Textarea`、`Button`、`Toggle` 和 `Toggle Group Item` 提供无障碍命名与点击激活能力，而无需手动维护 DOM ID。

## 用法

### 独立控制命名与激活

- **`naming`（默认 `true`）**：目标控件自动关联真实渲染的 `Label` 作为无障碍名称，无需额外放置隐藏文本。
- **`activation`（默认 `true`）**：配对后，点击标签会在同一次点击时机触发目标控件的对应操作——`Checkbox` / `Switch` 遵循自身的受控与禁用规则，`Radio Item` 向分组请求选中，`Input` / `Textarea` 请求聚焦（只读文本框仍可聚焦，禁用控件保留名称但忽略激活）。如仅需命名而不希望点击激活，请显式设置 `activation={false}`。
- **`selection`（默认 `'policy'`）**：可激活标签默认避免点击时误选文字；若需要允许用户复制标签文案，可设为 `'text'`。嵌套链接/按钮、修饰键点击与拖拽手势不会误触发激活，未配对的 `Label` 也不会自动吸附附近控件。

### 建立显式关联

从 `@proto.ui/core` 调用 `createControlLabelRef()` 为每对标签与控件创建一个稳定引用（一对一绑定，且需位于同一文档/Shadow 树内）：

- **React / Vue / Vue 2**：向双方组件传入 `instanceAssociations: { controlLabel: ref }`（由 Adapter 层处理，不进入普通 JSON Props）。
- **Web Components**：从 `@proto.ui/adapter-web-component` 调用 `setElementAssociations(element, { controlLabel: ref })` 分别绑定目标控件与 `Label`。

如果目标控件已显式设置非空的 `ariaLabel` 或 `labelledBy`，则会保留该命名并提示冲突；此时可将 `Label` 设为 `naming={false}` 仅用于点击激活。
