## 安装

已包含在 `@proto.ui/prototypes-brutalist@0.2.0` 中。可通过 CLI 目标 `brutalist-scroll-area` 添加，或从 `@proto.ui/prototypes-brutalist/scroll-area` 导入。

## 用法

### 组件结构

Scroll Area 由 `Root`、`Viewport`、`Scrollbar` 和 `Thumb` 四个部分组成：

- `Root`：外层滚动容器，需由外围布局提供明确的尺寸约束（示例使用 `12rem` 高度和响应式 `20rem` 最大宽度）。
- `Viewport`：实际的宿主滚动视口。
- `Scrollbar`：水平或垂直滚动轨道，通过 `orientation` 指定方向。
- `Thumb`：根据实时滚动指标连续同步尺寸与位置的滑块；拖动滑块会直接映射为滚动请求，不会创建第二套滚动状态或额外的焦点停靠点。

### 双轴交点处理

同时显示水平与垂直两条轨道时，两者会自动为右下交点预留避让区域（由水平滚动条绘制匹配的浅紫底色与边框），无需额外的 Corner 组件；当另一条轨道未渲染或隐藏时，预留空间会自动释放。没有内容溢出时，轨道保持可见而滑块自动隐藏。
