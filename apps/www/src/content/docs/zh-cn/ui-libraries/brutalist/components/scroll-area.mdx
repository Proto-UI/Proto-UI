Brutalist Scroll Area 保留 Base 的宿主滚动面、归一化 viewport facts、orientation 与已解析 projection。它偏好 composed chrome，并增加方形 paper 表面和高对比 Lavender/ink 控件。家族级 host session 会根据实际 scroll facts 连续投射 Thumb 尺寸与位置，并把 Thumb 上的 pointer 拖动映射回归一化 scroll request。抓取 Thumb 不会创建第二份 scroll state，也不会使其成为独立 focus/ARIA control。track page press 与完整 Drag and Drop 仍不属于当前 passing guarantee。

用于 ChatUI conversation history、会话列表、命令结果、日志和密集 SaaS 面板。外围 layout 必须给 Root 明确尺寸。参考 demo 保留 12rem 高度，并把响应式宽度上限设为 20rem：桌面 composition 不变，同时完整 Root 与 visual scrollbar 在手机 preview frame 内保持可见。
