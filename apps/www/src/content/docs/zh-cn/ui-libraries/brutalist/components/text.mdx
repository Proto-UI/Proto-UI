Brutalist Text 基于 [Base Text](/zh-cn/ui-libraries/base/text/) 提供全部八项独立排版属性，使用 DM Sans 字体族（正文 `500`、标题 `700`）与高对比度前景色，并遵循 Brutalist 设计契约保持纯被动、无阴影与无多余动效。

## 安装

当前在源码工作区提供，将于 `0.3.0-rc.1` 及后续版本中提供。可使用工作区 CLI 目标 `brutalist-text` 生成本地封装，或直接从 `@proto.ui/prototypes-brutalist/text` 导入 `brutalistTextRoot`（同时提供 `textRoot` 与 `BrutalistTextRoot` 别名）：

<InstallCommandCard
  commands={{
    npm: 'npx @proto.ui/cli@latest add wc brutalist-text',
    pnpm: 'pnpm dlx @proto.ui/cli@latest add wc brutalist-text',
  }}
  manager="npm"
/>

将命令中的 `wc` 替换为 `react`、`vue` 或 `vue2`，即可生成对应框架的封装。

## 用法

```tsx
import { BrutalistTextRoot } from '../proto-ui/components/react';

export function SectionTitle() {
  return (
    <h1>
      <BrutalistTextRoot size="4xl" font="heading" weight="bold" leading="tight" tracking="tight">
        Account settings
      </BrutalistTextRoot>
    </h1>
  );
}
```

### 语义包裹与设计契约

- **DM Sans 层级规范**：常规正文与控件标签推荐 `font="body" weight="medium"`（DM Sans 500），标题与突出标签推荐 `font="heading" weight="bold"`（DM Sans 700）；Text 自身不添加硬边框或阴影。
- **外层原生语义**：标题层级（`h1`–`h6`）、段落（`p`）、表单标签（`label`）与链接（`a`）由外层原生元素负责，Text 保持自然可选且不添加焦点停靠点。
- **字号行高与默认值**：`leading="size"` 保留字号内建行高（`xs` `1rem` 至 `5xl` `1`）；`leading="tighter"` 对应 `1.1`，`tracking="tighter"` 对应 `-0.05em`。移除属性会恢复默认值；初始非法 `size` 回退为 `base`，已有合法值后更新非法值则保留上一个有效值。
