## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `@proto.ui/prototypes-brutalist` 或 `@proto.ui/prototypes-brutalist/text` 导入 `brutalistTextRoot`（同时提供 `textRoot` 与 `BrutalistTextRoot` 别名；当前工作区 CLI 目标为 `brutalist-text`）。

## 用法

### 基础示例

```tsx
import * as React from 'react';
import { createReactAdapter } from '@proto.ui/adapter-react';
import { brutalistTextRoot } from '@proto.ui/prototypes-brutalist/text';

const Text = createReactAdapter(React)(brutalistTextRoot, { rootTag: 'span' });

export function SectionTitle() {
  return (
    <h1>
      <Text size="4xl" font="heading" weight="semibold" leading="tight" tracking="tight">
        Account settings
      </Text>
    </h1>
  );
}
```

### 语义包裹与排版规则

- **保留外层原生语义**：`rootTag: 'span'` 属于 Web Adapter 配置项。请将标题层级（`h1`–`h6`）、段落（`p`）、表单标签（`label` 及 `htmlFor`/`for`）或链接（`a` 及 `href`/`target`/`download`）保留在原生外层元素上；Text 本身不创建焦点停靠点或事件处理器。
- **前景色继承**：在深色或强调色 `Surface` 内使用时，可设置 `tone="inherit"` 沿用外层前景色以确保对比度。移除任意属性将恢复默认值；初始传入非法 `size` 会回退为 `'base'`，若已有合法值后传入空值或非法值则保持上一个合法值。
- **字号与行高**：设置 `leading="size"` 可直接使用所选字号自带的行高（`xs` 至 `5xl` 依次对应 `1rem`、`1.25rem`、`1.5rem`、`1.75rem`、`1.75rem`、`2rem`、`2.25rem`、`2.5rem`、`1`）；`leading="tighter"` 对应 `1.1`，`tracking="tighter"` 对应 `-0.05em`。
