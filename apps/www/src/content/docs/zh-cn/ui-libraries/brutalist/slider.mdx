Brutalist Slider 以 5px 圆角（`rounded-base`）、2px 黑色描边与硬阴影滑块呈现单值与多值范围调节，完整支持指针拖动、键盘步进与 `Field` / `Form` 表单集成。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可从 `@proto.ui/prototypes-brutalist/slider` 导入标量滑块部件与多值滑块 `sliderValues*` 部件。

## 用法

```tsx
import {
  BrutalistSliderRoot,
  BrutalistSliderTrack,
  BrutalistSliderIndicator,
  BrutalistSliderThumb,
} from '../proto-ui/components/react';

export function Example() {
  return (
    <BrutalistSliderRoot defaultValue={33} min={0} max={100} step={1}>
      <BrutalistSliderTrack>
        <BrutalistSliderIndicator />
        <BrutalistSliderThumb />
      </BrutalistSliderTrack>
    </BrutalistSliderRoot>
  );
}
```

- **单值部件**：`Root`、`Label`、`Track`、`Indicator`、`Thumb`、`FieldThumb`、`Value`。在 `Field` 或 `FormField` 内用 `FieldThumb` 替换 `Thumb`。
- **键盘与受控模式**：支持方向键、`Shift` 十倍步进、`PageUp` / `PageDown`、`Home` / `End`（横向 RTL 自动反转）。传入 `value` 进入受控模式，交互触发 `valueChange` 与 `valueCommit`。
- **多值范围**：使用 `sliderValues*` 系列部件，通过 `thumbCollisionBehavior` 配置 `'push'`、`'swap'` 或 `'none'` 碰撞行为。
