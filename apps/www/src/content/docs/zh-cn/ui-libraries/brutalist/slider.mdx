## 用法

### 单值滑块部件

单值滑块由 `Root`、`Label`、`Track`、`Indicator`、`Thumb`、`FieldThumb` 和 `Value` 组成：

- **Root**：管理 `value` / `defaultValue`、`min`、`max`、`step`、`disabled`、`readOnly`、`orientation` 与 `direction`。数值从 `min` 对齐步长并约束在边界内。
- **Track / Indicator**：轨道响应指针与触摸拖动，填充条显示当前进度区间。
- **Thumb**：独立使用时承载可聚焦滑块，支持方向键、`Shift` 10 倍步进、`PageUp` / `PageDown`、`Home` / `End`（横向 RTL 下左右键自动反转）。
- **FieldThumb**：在 `Field` 或 `FormField` 内替代 `Thumb` 使用，自动衔接 `FieldLabel` 聚焦、数值校验、表单序列化与重置。
- **Label / Value**：分别为滑块命名和展示当前值。

传入 `value` 进入受控模式：拖动过程中触发 `valueChange`，释放确认时触发 `valueCommit`，取消拖动则恢复非受控起始值。

### 范围与多值滑块

需要范围选择或多滑块时，从 `@proto.ui/prototypes-brutalist/slider` 导入 `sliderValues*` 系列部件：

- 在 `Values Root` 上设置数组初始值（例如 `defaultValue={[20, 80]}`），并在 `Values Track` 内为每个数值放置一个带 `index` 的 `Thumb`。
- 点击轨道会自动定位到最近的可编辑滑块；拖动滑块时保留抓取偏移量。
- `thumbCollisionBehavior` 支持 `'push'`、`'swap'` 和 `'none'`，在 `'swap'` 模式下交换位置时会自动转移焦点。
- `Values Root` 可直接放入 `Field` / `FormField`，提交有限的 `number[]` 数组，`FieldLabel` 点击时聚焦首个可编辑滑块。
