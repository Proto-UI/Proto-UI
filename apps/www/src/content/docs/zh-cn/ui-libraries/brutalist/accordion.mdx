Brutalist Accordion 用于在一组可折叠面板之间展开或收起内容，基于 Base Accordion 语义并搭配 5px 圆角、2px 粗边框与随主题自适应的 4px 硬偏移阴影。

把 `wc` 替换为 `react`、`vue` 或 `vue2` 即可生成对应框架的本地组件封装，也可以直接从 `@proto.ui/prototypes-brutalist/accordion` 导入五个部件原型。

## 用法

```tsx
import {
  BrutalistAccordionRoot,
  BrutalistAccordionItem,
  BrutalistAccordionHeading,
  BrutalistAccordionTrigger,
  BrutalistAccordionContent,
} from '@/components/proto-ui/react';

export function BrutalistAccordionUsage() {
  return (
    <BrutalistAccordionRoot defaultOpenItems={['item-1']}>
      <BrutalistAccordionItem value="item-1">
        <BrutalistAccordionHeading level={3}>
          <BrutalistAccordionTrigger>Is it accessible?</BrutalistAccordionTrigger>
        </BrutalistAccordionHeading>
        <BrutalistAccordionContent>
          Yes. It adheres to the WAI-ARIA design pattern.
        </BrutalistAccordionContent>
      </BrutalistAccordionItem>
    </BrutalistAccordionRoot>
  );
}
```

### 部件结构

```text
AccordionRoot
└── AccordionItem
    ├── AccordionHeading
    │   └── AccordionTrigger
    └── AccordionContent
```

- **Root**：统一管理当前展开的项集合、单选/多选模式与键盘导航方向。嵌套的 `Root` 彼此独立。
- **Item**：代表单个折叠条目，提供 `rounded-base` 圆角、2px 边框与主题自适应 4px 硬阴影，需传入唯一非空 `value`。
- **Heading**：提供语义标题层级（`level` 1–6，默认 `3`），内部仅放控制该项的 `Trigger`。
- **Trigger**：采用 `font-heading font-bold` 主色标题栏，提供内嵌高可见焦点环、按压内框反馈与展开状态底部分隔线。
- **Content**：使用 `bg-secondary-background` 与 `font-sans font-medium` 承载正文；关闭时默认卸载内容节点（设置 `keepMounted` 可保留隐藏节点）。

### 键盘与无障碍

- 所有启用的标题与展开面板内的可聚焦元素保持自然 `Tab` 顺序；聚焦标题后按 `Enter` 或 `Space` 切换展开状态。
- 纵向模式下使用 `ArrowUp` / `ArrowDown`（横向模式下使用 `ArrowLeft` / `ArrowRight`，RTL 自动反转）与 `Home` / `End` 在启用标题间移动焦点，不改变展开状态。
- `Trigger` 自动维护 `aria-expanded`、`aria-disabled` 与 `aria-controls`；当 `allowEmpty={false}` 阻止收起最后一项时，标题保持可聚焦并通过 `aria-disabled` 提示不可关闭。

### 方法与事件（Root）

- **方法**：`getOpenItems()` 返回当前展开键数组的副本；`requestOpen(value, open, reason?)` 以编程方式请求展开或收起；`openCount` 为当前展开键数量。
- **事件**：`openChange` 在状态变更请求时触发，返回 `{ openItems, value, open, reason }`。
