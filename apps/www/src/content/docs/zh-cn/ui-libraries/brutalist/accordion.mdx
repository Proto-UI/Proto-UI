Brutalist Accordion 用于在一组可折叠面板之间展开或收起内容，支持单展开与多展开模式，并搭配高对比度黑色粗边框与硬阴影视觉风格。

## 用法

### 部件组成

按 `Root -> Item -> Heading -> Trigger` 嵌套结构组织，并将 `Content` 与 `Heading` 并列放置在 `Item` 内：

- **Root**：统一管理当前展开的项列表、模式（单选/多选）、禁用状态与键盘导航方向。嵌套的 `Root` 彼此独立。
- **Item**：代表单个折叠条目，需提供唯一且非空的 `value`。
- **Heading**：为折叠标题提供语义标题层级（`level` 1–6，默认为 `3`）。内部仅放置对应的 `Trigger`，常驻次级操作按钮放在旁边。
- **Trigger**：点击或按键切换所属条目的展开状态，不声明独立属性。
- **Content**：承载展开后的面板内容。关闭时默认卸载内容节点（设置 `keepMounted` 可保留隐藏节点）。

### 受控与非受控模式

- **非受控**：通过 `defaultOpenItems` 指定初始展开项。
- **受控**：传入 `openItems` 进入受控模式，并监听 `openChange` 事件（负载为 `{ openItems, value, open, reason }`）同步更新外部状态。`reason` 取值为 `'pointer'`、`'keyboard'` 或 `'programmatic'`。
- **边界行为**：`mode="single"` 下仅保留首个唯一有效键；设置 `allowEmpty={false}` 可阻止关闭最后一个展开项；尚未挂载的条目键会保持待命并在对应 `Item` 挂载后自动生效。

### 键盘与无障碍

- 所有启用的标题与展开内容内的可聚焦元素保持自然 `Tab` 顺序。
- 聚焦标题后按 `Enter` 或 `Space` 切换展开状态。
- 纵向模式下按 `ArrowUp` / `ArrowDown`（横向模式下按 `ArrowLeft` / `ArrowRight`，RTL 自动反转）在启用标题之间移动焦点，`Home` / `End` 跳至首末标题；移动焦点不会改变展开状态。
- `Trigger` 自动维护 `aria-expanded`、`aria-disabled` 与 `aria-controls`；`Content` 由对应 `Trigger` 命名，设置 `region` 可在需要时将其声明为区域地标（多面板同时展开时建议按需开启）。

### 其他部件属性

- **Item**：`value: string`（必填、唯一且非空），`disabled?: boolean`（默认 `false`）
- **Heading**：`level?: 1 | 2 | 3 | 4 | 5 | 6`（默认 `3`）
- **Trigger**：无独立属性
- **Content**：`keepMounted?: boolean`（默认 `false`），`region?: boolean`（默认 `false`）

### 方法与事件

- **方法**：`getOpenItems()` 返回当前展开键数组的副本；`requestOpen(value, open, reason?)` 以编程方式请求展开或收起；`openCount` 为当前展开键数量。
- **事件**：`openChange` 在状态变更请求时触发，返回 `{ openItems, value, open, reason }`。
