Separator 渲染一条平涂 `2px` 实线分隔线，使用随亮暗模式自适应的 `foreground` 语义色，不叠加阴影或动效，由 Base Separator 统一提供方向与无障碍语义。

将命令中的 `wc` 替换为 `react`、`vue` 或 `vue2` 生成对应框架组件，也可直接从 `@proto.ui/prototypes-brutalist/separator` 导入。

## 用法

```tsx
import { BrutalistSeparatorRoot } from '../proto-ui/components/react';
```

```tsx
<BrutalistSeparatorRoot />
```

- 通过 `orientation` 切换水平（`'horizontal'`）或垂直（`'vertical'`）方向；垂直分隔线会自动沿弹性布局交叉轴拉伸（`self-stretch`）。
- 默认 `decorative={true}` 仅作视觉分隔并从无障碍树隐藏；当分隔线需要传达语义分组时，设为 `false` 以暴露 `role="separator"` 与 `aria-orientation`。
- Separator 为无内容、无交互元素，不内置外边距，间距由外围布局控制。

## API

以下属性属于 `Root`：

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值', description: '说明' }}
  rows={[
    {
      name: 'orientation',
      type: "'horizontal' | 'vertical'",
      default: "'horizontal'",
      description: '分隔线方向',
    },
    {
      name: 'decorative',
      type: 'boolean',
      default: 'true',
      description: '为 true 时对辅助技术隐藏；为 false 时暴露语义 separator 角色与方向',
    },
  ]}
/>

暴露只读状态 `orientation` 与 `decorative`，不声明焦点或交互事件。
