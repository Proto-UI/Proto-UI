Separator 渲染一条平涂 `2px` 墨黑分隔线，支持水平与垂直方向及装饰性无障碍语义，适合消息日期分组、Card 分区、导航列表和表单区域。

## 安装

已包含在 `@proto.ui/prototypes-brutalist@0.2.0` 中。可通过 CLI 目标 `brutalist-separator` 添加，或从 `@proto.ui/prototypes-brutalist/separator` 导入。

## 用法

- 通过 `orientation` 切换水平（`'horizontal'`）或垂直（`'vertical'`）分隔线。
- 默认 `decorative={true}` 仅作视觉分隔并从无障碍树隐藏；当分隔线需要传达语义分组时，将其设为 `false`。
- Separator 本身不内置外边距，间距由外围布局控制。
