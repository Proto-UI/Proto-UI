Brutalist Separator 保留 Base orientation 与 decorative accessibility 语义，并渲染为平涂 `2px` ink 分隔线。

用于消息日期分组、Card 分区、导航列表和表单区域。Separator 不拥有 spacing 策略；周围组合负责间距。
