Brutalist Live Region 是一个单部件无障碍实时播报容器，继承 [Base Live Region](/zh-cn/ui-libraries/base/live-region/) 的 `role`、`aria-live` 与 `aria-atomic` 语义，同时遵循 [Brutalist 设计契约](../../design-contract/) 保持简洁可读的前景排版，不附加多余边框或阴影。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。Brutalist Live Region 不进入 `proto-ui add` CLI 目标列表，请直接从 `@proto.ui/prototypes-brutalist` 或 `@proto.ui/prototypes-brutalist/live-region` 导入：

```ts
import { BrutalistLiveRegionRoot } from '@proto.ui/prototypes-brutalist/live-region';
```

## 用法

```tsx
import { AdaptToReact } from '@proto.ui/adapter-react';
import { BrutalistLiveRegionRoot } from '@proto.ui/prototypes-brutalist/live-region';

const LiveRegionRoot = AdaptToReact(BrutalistLiveRegionRoot);

export function StatusAnnouncement({ message }: { message: string }) {
  return (
    <LiveRegionRoot politeness="polite" atomic>
      {message}
    </LiveRegionRoot>
  );
}
```

- **播报优先级**：`politeness="polite"`（默认）输出 `role="status"` 与 `aria-live="polite"`，适合常规状态反馈；`politeness="assertive"` 输出 `role="alert"` 与 `aria-live="assertive"`，适合需要立即播报的紧急提醒。
- **原子播报**：`atomic`（默认 `true`）输出 `aria-atomic`，确保整段文本作为完整语义播报；设为 `false` 时仅播报变更片段。直接更新传入的子元素文本即可触发播报。
- **视觉克制**：容器本身不进入键盘 Tab 顺序，只应用 `min-w-0 max-w-full text-foreground` 保证在亮暗模式下清晰可读，不附加 `border-2`、`rounded-base` 或阴影等通知外框。
