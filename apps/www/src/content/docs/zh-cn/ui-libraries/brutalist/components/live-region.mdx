Brutalist Live Region 是一个单部件无障碍实时播报容器，用于在内容变化时向屏幕阅读器播报动态通知，同时保持简洁可读的排版样式，不附加多余边框或阴影。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

- **CLI 目标**：`proto-ui add <react|vue|vue2|wc> brutalist-live-region`
- **包导出**：从 `@proto.ui/prototypes-brutalist` 或 `@proto.ui/prototypes-brutalist/live-region` 导入 `Root`

## 用法

- **播报优先级**：`politeness="polite"`（默认）输出 `role="status"` 与 `aria-live="polite"`，适合常规状态反馈；`politeness="assertive"` 输出 `role="alert"` 与 `aria-live="assertive"`，适合需要立即打断播报的紧急提醒。
- **原子播报**：`atomic`（默认 `true`）输出 `aria-atomic`，确保整段文本作为完整语义播报。直接更新传入的子元素文本即可触发播报。
- 容器本身不进入键盘 Tab 顺序，只应用 `min-w-0 max-w-full text-foreground` 保证内容在亮暗模式下清晰可读。
