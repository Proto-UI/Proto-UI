Toggle 保留 Base 的 activation 与 `aria-pressed` 所有权。锁存 active state 使用持续 inset ink frame 作为非颜色无障碍扩展；瞬时 press 保持平面几何，不产生位移。固定 Neo 尺寸 recipe 为默认 40px、small 36px（0.8rem 文字）与 large 44px（text-sm）；上游 icon-size/side-padding 与 variants 仍不在此限定投射范围。当前真实浏览器视觉验证待完成。
