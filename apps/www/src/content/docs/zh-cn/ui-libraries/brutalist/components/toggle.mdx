Toggle 是一个可在激活与未激活之间切换的双态按钮，内置 `aria-pressed` 语义。Brutalist 风格在激活态添加持久的内嵌墨黑边框作为非颜色视觉提示，按下时保持扁平几何且不发生位移。

## 安装

已包含在 `@proto.ui/prototypes-brutalist@0.2.0` 中。可通过 CLI 目标 `brutalist-toggle` 添加，或从 `@proto.ui/prototypes-brutalist/toggle` 导入。

## 用法

- **尺寸档位**：`size` 支持 `'sm'`（36px、`0.8rem` 字号）、`'default'`（40px）与 `'lg'`（44px、`text-sm`）。
- **受控与非受控**：使用 `defaultActive` 设置初始状态，或传入 `active` 进入受控模式；设置 `disabled` 可阻止交互。
