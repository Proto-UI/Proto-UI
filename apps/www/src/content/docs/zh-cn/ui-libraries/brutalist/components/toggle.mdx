Brutalist Toggle 继承 Base Toggle 的 `aria-pressed` 开关语义，以 5px 圆角、2px 黑色边框与扁平无位移几何呈现。激活态同时切换为主色配对表面并保留 2px 持久内嵌黑框，确保不依赖颜色也能清晰辨识。

## 用法

```tsx
import { BrutalistToggle } from '../proto-ui/components/react';
```

```tsx
<BrutalistToggle variant="outline">Toggle</BrutalistToggle>
```

- **变体与尺寸**：通过 `variant` 选择 `'default'`（中性表面填充）或 `'outline'`（透明背景）；通过 `size` 选择 `'sm'`（36px）、`'default'`（40px）或 `'lg'`（44px）。
- **扁平交互反馈**：悬停时呈现中性高对比表面，按压与激活态切换为主色配对，激活态持久保留 2px 内嵌边框且不产生外影或位移。
- **受控与非受控**：使用 `defaultActive` 初始化非受控状态，或传入 `active` 并监听 `activeChange` 进行外部受控管理；设置 `disabled` 阻止激活。

## API

以下属性属于 `Root`（传入 `active` 进入受控模式）：

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}
  rows={[
    { name: 'active', type: 'boolean | undefined', default: '非受控' },
    { name: 'defaultActive', type: 'boolean', default: 'false' },
    { name: 'disabled', type: 'boolean', default: 'false' },
    { name: 'variant', type: "'default' | 'outline'", default: "'default'" },
    { name: 'size', type: "'default' | 'sm' | 'lg'", default: "'default'" },
  ]}
/>

- **事件**：`activeChange`（载荷 `{ active: boolean }`）。
- **方法**：`focusSelf(options?)`（禁用态忽略）。
- **暴露状态**：`active`、`disabled`、`hovered`、`focused`、`focusVisible`、`pressed`。
