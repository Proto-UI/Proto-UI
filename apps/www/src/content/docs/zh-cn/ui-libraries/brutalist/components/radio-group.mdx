Radio Group 用于在一组互斥选项中进行单项选择。Brutalist 风格以纵向网格排布 16px 圆形 2px 边框选项，选中时通过内部实心圆点标识状态，并在亮暗模式下均保持清晰对比度与焦点偏移环。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。

<InstallCommandCard command="npx @proto.ui/cli@latest add wc brutalist-radio-group" manager="npm" />

将命令中的 `wc` 替换为 `react`、`vue` 或 `vue2` 可生成对应框架封装，或从 `@proto.ui/prototypes-brutalist/radio-group` 导入 `Root`、`Item` 与 `Indicator`。

## 用法

```tsx
import {
  BrutalistLabelRoot,
  BrutalistRadioGroupIndicator,
  BrutalistRadioGroupItem,
  BrutalistRadioGroupRoot,
} from '../proto-ui/components/react';

export function RadioGroupUsage() {
  return (
    <BrutalistRadioGroupRoot defaultValue="comfortable" a11yLabel="Display density">
      <div className="flex items-center gap-3">
        <BrutalistRadioGroupItem value="default">
          <BrutalistRadioGroupIndicator />
        </BrutalistRadioGroupItem>
        <BrutalistLabelRoot>Default</BrutalistLabelRoot>
      </div>
      <div className="flex items-center gap-3">
        <BrutalistRadioGroupItem value="comfortable">
          <BrutalistRadioGroupIndicator />
        </BrutalistRadioGroupItem>
        <BrutalistLabelRoot>Comfortable</BrutalistLabelRoot>
      </div>
      <div className="flex items-center gap-3">
        <BrutalistRadioGroupItem value="compact">
          <BrutalistRadioGroupIndicator />
        </BrutalistRadioGroupItem>
        <BrutalistLabelRoot>Compact</BrutalistLabelRoot>
      </div>
    </BrutalistRadioGroupRoot>
  );
}
```

### 组件结构与交互

```text
BrutalistRadioGroupRoot
├── BrutalistRadioGroupItem
│   └── BrutalistRadioGroupIndicator
└── BrutalistRadioGroupItem
    └── BrutalistRadioGroupIndicator
```

- `Root`：统一管理单项选中值、选项顺序、方向键漫游焦点、禁用/只读策略以及 `radiogroup` 无障碍语义。
- `Item`：单个 `radio` 选项，保持 16px 圆形 2px 边框轮廓与 DM Sans 排版体系；亮色模式使用黑色圆环与圆点，暗色模式自动切换至主题前景色确保高对比度。
- `Indicator`：纯视觉指示器，选中时于圆内渲染 `size-2` 实心圆点（SVG 为 `aria-hidden`）。
- **键盘与只读**：方向键循环移动并选中启用项，`Space` 选中当前聚焦项；`readOnly` 保留漫游焦点但阻止改值，`disabled` 移出焦点序列。
- **表单集成**：如需接入必填校验、错误关联与重置能力，请在 `FormField` 中使用 `@proto.ui/prototypes-brutalist/field` 的 `fieldRadioGroup`，详见 [Form 选择控件示例](../../form/)。

### Indicator 与事件

- **Indicator**：无额外属性。
- **事件**：Root 触发 `valueChange`（`{ value: string }`）；Item 触发 `select`（`{ value: string }`）。
- **方法**：Root 暴露 `requestValue(value)`、`resetValue()`、`focusFirst()`、`focusLast()`、`focusNext()`、`focusPrev()`、`focusSelected()`、`focusSelf()`。
