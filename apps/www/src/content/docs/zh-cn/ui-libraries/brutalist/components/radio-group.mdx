## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。可从 `@proto.ui/prototypes-brutalist` 或 `@proto.ui/prototypes-brutalist/radio-group` 导入 `Root`、`Item` 与 `Indicator`（当前工作区 CLI 目标为 `brutalist-radio-group`）。

## 用法

### 组件结构

Radio Group 由 `Root`、`Item` 和 `Indicator` 组成：

- `Root`：统一管理单项选中值、选项顺序、漫游焦点、禁用/只读策略以及 `radiogroup` 无障碍语义。
- `Item`：单个 `radio` 选项，维护 `aria-checked`、指针与键盘激活行为；选中时保持外圆底色与边框不变。
- `Indicator`：纯视觉指示器，在选中状态下于圆内绘制一个 `size-2` 实心圆点（SVG 为 `aria-hidden`）。

### 键盘交互与只读状态

- 支持使用方向键在启用选项间漫游焦点并完成单选，初始焦点落在已选中项或第一个可用项上。
- `readOnly` 保留键盘焦点与方向键漫游能力，但阻止修改当前选中值；`disabled` 则同时阻止选中与焦点参与。

### 表单集成

普通 `Root` 不会自动注册到 Field 或 Form。如需接入必填校验、标签/描述/错误关联与重置能力，请在 `FormField` 中使用 `@proto.ui/prototypes-brutalist/field` 提供的 `fieldRadioGroup`，完整示例见[Form 选择控件示例](../../form/)。调用 `resetValue()` 会恢复实例创建时的初始值（受控模式下以变更请求发出）。
