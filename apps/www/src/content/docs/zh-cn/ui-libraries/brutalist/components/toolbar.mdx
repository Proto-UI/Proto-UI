Brutalist Toolbar 以 5px 圆角、2px 黑色实线边框与 3px 前景阴影构建分组操作栏，支持单一 `Tab` 入口、方向键漫游焦点与即时落位交互反馈。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可直接从 `@proto.ui/prototypes-brutalist/toolbar` 导入原型并适配到目标框架：

```ts
import {
  toolbarRoot,
  toolbarButton,
  toolbarSeparator,
} from '@proto.ui/prototypes-brutalist/toolbar';
```

## 用法

```tsx
import {
  BrutalistToolbarRoot,
  BrutalistToolbarButton,
  BrutalistToolbarSeparator,
} from '../proto-ui/components/react';

export function EditorToolbar() {
  return (
    <BrutalistToolbarRoot a11yLabel="Document actions">
      <BrutalistToolbarButton value="undo">Undo</BrutalistToolbarButton>
      <BrutalistToolbarButton value="redo">Redo</BrutalistToolbarButton>
      <BrutalistToolbarSeparator />
      <BrutalistToolbarButton value="save" variant="solid">
        Save
      </BrutalistToolbarButton>
    </BrutalistToolbarRoot>
  );
}
```

Toolbar 由 `Root`、`Button` 和 `Separator` 三个部件组成：

- **设计契约对齐**：`Root` 作为被动分组容器保留 3px 前景阴影与 `rounded-base` 几何；`Button` 使用 DM Sans 中等字重（14px/20px），悬停切换高对比度主题填充并在按压时提供即时落位内影。
- **键盘导航**：整条工具栏仅占一个 `Tab` 停靠点，方向键在启用的命令按钮间依次移动；默认开启 `loop={true}` 循环导航。
- **分隔线**：`Separator` 保持 2px 清晰分隔厚度，并自动沿工具栏交叉轴排布。

### 变体与尺寸

`Button` 支持 `surface`（默认）、`solid` 与 `destructive` 三种变体，以及 `default`、`sm`、`icon` 三种尺寸。

### Separator 与事件

- **Separator**：无额外属性，自动跟随 `Root` 的交叉轴方向渲染 2px 分隔线。
- **事件与暴露**：`Button` 激活时发出 `action`（`{ value: string }`）；`Root` 暴露 `disabled`、`focusFirst()`、`focusLast()` 与 `setCurrent(id)`；`Button` 暴露 `disabled`、`focused`、`focusVisible` 与 `focusSelf(options)`。
