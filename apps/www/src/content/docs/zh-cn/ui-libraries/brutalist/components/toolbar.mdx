Toolbar 将一组相关操作按钮组织为单个键盘漫游焦点区域，支持水平或垂直排列以及交叉轴分隔线。

## 用法

### 组件结构

Toolbar 由 `Root`、`Button` 和 `Separator` 三个部分组成：

- `Root`：统一管理整体禁用状态、主轴方向（`orientation`）、循环导航（`loop`）与工具栏无障碍名称（`a11yLabel`）。
- `Button`：工具栏内的操作按钮，启用状态下激活时会发出携带 `value` 的 `action` 事件。
- `Separator`：自动沿工具栏交叉轴方向显示的分隔线。

### 键盘导航

- 工具栏整体仅保留一个启用命令作为 `Tab` 停靠点，避免长工具栏占用过多 Tab 步数。
- 使用方向键在工具栏内依次移动焦点；设置 `loop={true}`（默认）可在首尾之间循环。
