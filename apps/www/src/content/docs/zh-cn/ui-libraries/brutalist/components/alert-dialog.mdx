Root 固定 alert 语义。Mask 管理模态遮罩；Content 约束焦点、拒绝外部点击关闭并优先聚焦 Cancel。Action 先发出 action，再请求关闭，实际操作由应用处理。Escape 与 Cancel 请求关闭。

Root 支持受控 open 和非受控 defaultOpen。禁用命令不激活。传入 open 时，最终状态仍由调用方持有，通过 openChange 接收请求后再提供新值。

组成: Root, Trigger, Content, Header, Title, Description, Footer, Cancel, Action, Mask。Header、Footer 是可选的被动布局部件，Props/Exposes 为空；保留作者提供的子项，不增加命令或状态。

桌面组合遵循[固定的 Neo-Brutalist 源码](https://github.com/ekmas/neobrutalism-components/blob/3306a802724874a85f93079702b2795370a279d4/src/components/ui/alert-dialog.tsx)：面板圆角 5px、内边距 24px，标题与说明间隔 8px，按钮保持内容宽度、右对齐且间隔 12px。Footer 在内容放不下时自然反向换行；它不等同于上游 640px 以下的全宽反向纵排。窄屏文本居中、545–639px 的面板宽度仍有差异。既有零时长 transition、主题相对 focus offset 与深色主题保留为 Proto UI 行为或扩展；暂未提供上游 small-size 与 Media 部件。

当前是草稿源码实现。完整 native/GPUI、编译器、打包消费、视觉及独立验收仍待完成；本页不表示 Finf 已完成。
