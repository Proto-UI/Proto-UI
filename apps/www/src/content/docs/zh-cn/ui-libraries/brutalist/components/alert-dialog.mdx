Brutalist AlertDialog 用于需要用户明确确认的关键或破坏性操作，默认锁定焦点、禁止点击遮罩关闭，并在打开时优先将焦点落在安全取消按钮上。

## 用法

### 部件组成

AlertDialog 由 `Root`、`Trigger`、`Mask`、`Content`、`Header`、`Title`、`Description`、`Footer`、`Cancel` 和 `Action` 组成：

- **Root**：管理 `alertdialog` 语义与开关状态，支持受控 `open` 与非受控 `defaultOpen`。
- **Mask**：模态遮罩层，阻止外部点击关闭弹窗。
- **Content**：5px 圆角、24px 内边距与硬黑阴影的模态面板，负责焦点锁定并优先聚焦 `Cancel`。
- **Header / Footer**：可选布局容器，分别组织标题说明与右对齐操作按钮，空间不足时按钮自动反向换行。
- **Cancel / Action**：`Cancel` 与按 `Escape` 会请求关闭；`Action` 先触发 `action` 事件再请求关闭，实际业务逻辑由应用层执行。

### 受控与非受控模式

- **非受控**：通过 `defaultOpen` 设置初始开关状态。
- **受控**：传入 `open` 并监听 `openChange` 事件同步更新状态；已禁用的操作按钮不会触发事件。

传入 `open: boolean` 进入受控模式。

### 其他部件属性

- **Mask**：`passthrough?: boolean`（默认 `false`）及 Transition 属性
- **Content**：支持 Transition 属性
- **Trigger / Header / Title / Description / Footer / Cancel / Action**：无独立属性
