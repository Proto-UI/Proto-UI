Brutalist Badge 是用于标注角色、环境或分类信息的静态徽标组件，采用 5px 圆角（`rounded-base`）、`2px` 黑色边框、DM Sans 500 排版（`12px/16px`）、无外影与平涂高对比度配色。

## 安装

当前仅在源码工作区提供，可通过 CLI 按目标适配器生成 `brutalist-badge`：

<InstallCommandCard
  manager="wc"
  commands={{

    react: 'proto-ui add react brutalist-badge',
    vue: 'proto-ui add vue brutalist-badge',
    vue2: 'proto-ui add vue2 brutalist-badge',
  }}
/>

## 用法

```tsx
import { BrutalistBadgeRoot } from '../proto-ui/components/react';
```

```tsx
<BrutalistBadgeRoot tone="accent">Badge</BrutalistBadgeRoot>
```

- 通过 `tone` 选择配色风格：`accent`（默认，明黄 `canary`）、`info`（天蓝 `sky`）或 `danger`（珊瑚红 `coral`），每种配色均内置对应的平涂背景与黑色前景文字。
- 徽标默认采用 `whitespace-nowrap` 与 `gap-1` 行内弹性布局，可直接组合文本与前置或后置图标标记。
- Badge 是无 `role`、不可聚焦的被动静态标签，不附加悬停或按压位移。需要实时状态播报请使用 `Live Region`，需要交互点击请使用 `Button` 或 `Toggle`。
