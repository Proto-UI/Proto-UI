Brutalist Badge 是用于标注角色、环境或分类信息的静态徽标组件，采用 5px 圆角、`2px` 黑色边框、无外影与平涂高对比度配色。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

- **CLI 目标**：`proto-ui add <react|vue|vue2|wc> brutalist-badge`

## 用法

- 通过 `tone` 选择配色风格：`accent`（默认）、`info` 或 `danger`，每种配色均内置对应的平涂背景与前景文字色。
- Badge 是不可聚焦的静态标签，适合展示状态词、角色或环境标识。需要动态播报请使用 `Live Region`，需要交互点击请使用 `Button` 或 `Toggle`。
