Brutalist Toggle Group 采用 `rounded-base` 圆角、2px 黑色描边、DM Sans 粗体字形与持久 2px 激活内框，支持单选或多选及方向键焦点漫游。

## 安装

将于 `0.3.0-rc.1` 及后续版本中提供。可直接从 `@proto.ui/prototypes-brutalist/toggle-group` 导入组件原型并使用对应宿主 Adapter 适配。

## 用法

```tsx
import { BrutalistToggleGroupItem, BrutalistToggleGroupRoot } from '../proto-ui/components/react';

export function Example() {
  return (
    <BrutalistToggleGroupRoot multiple defaultValue={['a']}>
      <BrutalistToggleGroupItem value="a">A</BrutalistToggleGroupItem>
      <BrutalistToggleGroupItem value="b">B</BrutalistToggleGroupItem>
      <BrutalistToggleGroupItem value="c">C</BrutalistToggleGroupItem>
    </BrutalistToggleGroupRoot>
  );
}
```

### 组件结构

```text
ToggleGroupRoot
├── ToggleGroupItem
└── ToggleGroupItem
```

- **外观契约**：分组容器保留 3px 前景硬阴影而不产生按压位移；内部按钮遵循扁平切换控件规范，悬停与激活态维持黑色边框，激活态持续显示 2px 黑色内框作为非颜色区分信号。
- **选择与键盘**：`value` / `defaultValue` 均为字符串数组；方向键仅在组内移动焦点，`Space` 或 `Enter` 切换当前项；传入 `value` 进入受控模式并监听 `valueChange`。

使用 `variant="outline"` 为每个选项显示独立的 2px 黑色描边，单选模式下可再次点击清空。
