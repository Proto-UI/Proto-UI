## 用法

### 组件结构

ToggleGroup 由 `Root` 和 `Item` 两个部分组成：

- `Root`：统一管理选中的值数组、单选/多选策略、方向与漫游焦点。
- `Item`：组内的单个切换按钮，通过唯一 `value` 标识自身。

### 选择模式与键盘交互

- `value` 与 `defaultValue` 均为字符串数组（`readonly string[]`）。当 `multiple={false}`（默认）时，最多保持一个选中项，再次点击当前选中项可取消选择；设置 `multiple={true}` 可同时激活多项。
- 方向键仅在按钮间移动焦点，不会自动切换选中状态；按 `Enter` 或 `Space` 提交切换。
- 禁用项、`readOnly` 状态以及具有重复 `value` 的项不会提交变更。传入 `value` 进入受控模式，通过监听 `valueChange` 决定是否更新外部状态。
