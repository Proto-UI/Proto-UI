Brutalist Checkbox 提供二态勾选与半选（`indeterminate`）状态，采用方形硬边框与高对比度勾选/横线图标，支持指针点击与键盘 `Space` 切换。

## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

- **包导出**：从 `@proto.ui/prototypes-brutalist` 或 `@proto.ui/prototypes-brutalist/checkbox` 导入 `Root` 与 `Indicator`

## 用法

### 部件组成

- **Root**：管理 `checked` 与 `indeterminate` 状态、禁用/只读策略、焦点环与无障碍 `checkbox` 角色（半选态同步 `aria-checked="mixed"`）。
- **Indicator**：从所属 `Root` 派生状态并渲染装饰性勾选或半选横线图标，不接收焦点。当 `checked` 与 `indeterminate` 同时为 `true` 时，优先显示半选横线。

### 只读模式与表单集成

- 设置 `readOnly={true}` 时控件保留焦点但阻止值变更；设置 `disabled={true}` 同时将其移出焦点顺序。
- 如需接入 `Form` 的必填校验、标签关联与表单重置，请在 `FormField` 中使用 `@proto.ui/prototypes-brutalist/field` 导出的 `fieldCheckbox`（示例见 [Form 选择控件示例](../../form/)）。
