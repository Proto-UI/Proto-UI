Brutalist Checkbox 提供未选、已选与半选（`indeterminate`）三种状态，采用方形 2px 硬边框与高对比度对勾/横线图标，支持指针点击与键盘 `Space` 切换。

## 安装

当前以工作区源码提供，尚未进入 0.2.0 稳定版。从 `@proto.ui/prototypes-brutalist` 或 `@proto.ui/prototypes-brutalist/checkbox` 导入 `BrutalistCheckboxRoot` 与 `BrutalistCheckboxIndicator`。

## 用法

```tsx
import {
  BrutalistCheckboxIndicator,
  BrutalistCheckboxRoot,
  BrutalistLabelRoot,
} from '@proto.ui/prototypes-brutalist';

export function Example() {
  return (
    <div className="flex items-center gap-3">
      <BrutalistCheckboxRoot defaultChecked>
        <BrutalistCheckboxIndicator />
      </BrutalistCheckboxRoot>
      <BrutalistLabelRoot>Accept terms and conditions</BrutalistLabelRoot>
    </div>
  );
}
```

### 部件组成与表单集成

- **Root**：管理 `checked` 与 `indeterminate` 状态、禁用/只读策略、焦点环与无障碍 `checkbox` 角色（半选态同步 `aria-checked="mixed"`）。
- **Indicator**：从所属 `Root` 派生状态并渲染装饰性勾选或半选横线图标，不接收焦点。当 `checked` 与 `indeterminate` 同时为 `true` 时，优先显示半选横线。
- **只读与表单**：设置 `readOnly={true}` 时控件保留焦点但阻止值变更；设置 `disabled={true}` 同时将其移出焦点顺序。如需接入 `Form` 校验、标签关联与表单重置，请在 `FormField` 中组合 `@proto.ui/prototypes-brutalist/field` 导出的 `fieldCheckbox`（示例见 [Form 选择控件示例](../../form/)）。

## API

### Root

<ApiPropsTable
  headers={{ name: '属性', type: '类型', default: '默认值' }}

    { name: 'required', type: 'boolean', default: 'false' },
  ]}

`Root` 暴露 `checked`、`indeterminate`、`disabled`、`readOnly`、`required`、`hovered`、`focused`、`focusVisible`、`pressed` 状态，`focusSelf(options?)` 与 `resetValue()` 方法，以及 `checkedChange`（`{ checked, indeterminate }`）与 `indeterminateChange`（`{ indeterminate }`）事件。

### Indicator

`Indicator` 不声明独立属性，自动从最近的 `Root` 同步状态并暴露 `checked`、`indeterminate`、`isChecked()` 与 `isIndeterminate()`。
