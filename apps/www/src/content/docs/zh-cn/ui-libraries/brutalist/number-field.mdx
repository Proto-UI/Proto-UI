## 用法

### 部件组成

Number Field 由 `Root`、`Label`、`Input`、`Control`、`Increment` 和 `Decrement` 组成：

- **Root**：管理 `number | null` 类型的 `value` / `defaultValue`、`min` / `max`（默认 `0` / `100`）、步长 `step`（默认 `1`）、格式化配置与禁用/只读状态。
- **Input**：独立使用时承载带 `spinbutton` 语义的文本输入框；编辑过程中允许保留未完成草稿，失焦或按 `Enter` 时提交合法数值，非法输入则恢复上次有效值。
- **Control**：在 `Field` 或 `FormField` 内替代 `Input` 使用，自动衔接 `FieldLabel`、数值校验、表单序列化与重置。
- **Increment / Decrement**：步进增减按钮，与方向键共享步进规则。
- **Label**：命名独立输入框；开启 `scrub` 后支持在标签上水平拖拽连续调值。

### 格式化、空值与交互

- **键盘操作**：`ArrowUp` / `ArrowDown` 按步长增减，按住 `Shift` 以 10 倍步长调整，`Home` / `End` 跳至 `min` / `max` 边界。输入法合成期间自动暂停解析、提交、步进与拖拽。
- **本地化格式**：配置 `locale` 与 `formatOptions` 可呈现十进制、货币或百分比格式并解析对应分隔符与符号。格式化仅影响展示，不改变内部数值精度；若格式配置非法，组件会设置 `formatInvalid` 并回退为无分组十进制。
- **空值支持**：传入 `allowEmpty` 后，清空输入框并提交会请求 `null`；通过 `getValue()` 获取 `number | null`，通过 `empty` 判断当前是否为空。从空值开始步进时，首次会初始化为边界内对齐的 `0`。
- **标签拖拽**：开启 `scrub` 后可在 `Label` 上拖动调值，`scrubSteps`（默认 `100`）控制移动一个标签宽度对应的步数，`direction="rtl"` 反转横向方向。
