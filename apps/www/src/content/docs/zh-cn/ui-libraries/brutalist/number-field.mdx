Brutalist Number Field 遵循 Brutalist 设计契约（DM Sans 字体、`5px` `rounded-base` 圆角、`2px` 边框、无影编辑框搭配 `2px` 边框色阴影步进按钮），完整继承 Base Number Field 的步进、本地化格式化、空值与标签拖拽调值能力。

## 安装

当前从源码工作区提供，尚未进入 0.2.0 稳定版。可直接从 `@proto.ui/prototypes-brutalist/number-field` 导入各部件原型：

```ts
import {
  numberFieldRoot,
  numberFieldLabel,
  numberFieldInput,
  numberFieldControl,
  numberFieldIncrement,
  numberFieldDecrement,
} from '@proto.ui/prototypes-brutalist/number-field';
```

## 用法

```tsx
<BrutalistNumberFieldRoot defaultValue={12} min={0} max={100} step={1} ariaLabel="Quantity">
  <BrutalistNumberFieldLabel>Quantity</BrutalistNumberFieldLabel>
  <BrutalistNumberFieldDecrement>
    <span aria-hidden="true">−</span>
    <span className="sr-only">Decrease Quantity</span>
  </BrutalistNumberFieldDecrement>
  <BrutalistNumberFieldInput />
  <BrutalistNumberFieldIncrement>
    <span aria-hidden="true">+</span>
    <span className="sr-only">Increase Quantity</span>
  </BrutalistNumberFieldIncrement>
</BrutalistNumberFieldRoot>
```

- **部件组成**：`Root` 管理数值与格式化配置，`Input` 承载独立编辑（在 `Field` 或 `FormField` 内替换为 `Control` 以联动 `FieldLabel`、校验错误边框与表单重置），`Label` 命名控件并在 `scrub` 模式下支持水平拖拽，`Increment` / `Decrement` 与键盘方向键共享步进规则。
- **键盘与输入法**：`ArrowUp` / `ArrowDown` 按 `step` 增减，按住 `Shift` 以 10 倍步长调整，`Home` / `End` 跳至 `min` / `max` 边界。IME 合成期间自动暂停解析、提交、步进与拖拽。
- **本地化与空值**：传入 `locale` 与 `formatOptions` 支持十进制、货币与百分比格式；开启 `allowEmpty` 后清空并提交可请求 `null`。
