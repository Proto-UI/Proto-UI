# Dialog

面板保持 Base Dialog 语义和命令连接，并使用工业海报式处理。

- 触发器使用天空蓝色块与硬阴影。
- 右上角 X 是独立金丝雀黄色方形控件，不是无边框图标；其 glyph 取金丝雀填充的配对前景，因此在两个主题下都可读。
- Hover 变珊瑚红并保持 4px 硬阴影；Pressed 移除阴影。
- footer dismiss 动作保留明确关闭语义，不伪装成普通文本链接。Close 自身不带 control surface、只拥有 dismissal，因此 footer 动作组合一个 Button child，组合后保持单一 tab stop。
- 保留硬轮廓 Focus 和可访问名称 `Close`。

## Draft 工作区继承

当前工作区还继承有界的 [Base Mask 指针默认行为](/zh-cn/ui-libraries/base/dialog/)：participating Mask 阻止自身 root-scoped 指针默认动作夺走已恢复焦点，passthrough 不阻止，关闭策略仍归 Content。这项 draft 修订与先前发布的家族版本分开，不新增风格化 Dialog props。

## API

Dialog 是工作区源码，没有公开的 `proto-ui add` 目标。传入 `open` 进入受控模式。

这些属性属于 Root。Mask 接受 `passthrough`（`false`）以及 Transition 属性。Content 的 `focusEntry` 默认 `auto`，同样接受 Transition 属性。Trigger、Title、Description 与 Close 没有属性。
