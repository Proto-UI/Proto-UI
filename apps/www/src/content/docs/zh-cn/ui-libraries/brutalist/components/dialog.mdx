## 安装

当前从源码工作区提供，可通过 CLI 生成对应运行时包装：

<InstallCommandCard command="npx @proto.ui/cli@latest add wc brutalist-dialog" manager="npm" />

将 `wc` 替换为 `react`、`vue` 或 `vue2` 即可生成对应宿主组件。

## 用法

```tsx
import {
  BrutalistButton,
  BrutalistDialogClose,
  BrutalistDialogCloseIcon,
  BrutalistDialogContent,
  BrutalistDialogDescription,
  BrutalistDialogFooter,
  BrutalistDialogHeader,
  BrutalistDialogMask,
  BrutalistDialogRoot,
  BrutalistDialogTitle,
  BrutalistDialogTrigger,
} from '@/components/proto-ui/brutalist';

export function BrutalistDialogExample() {
  return (
    <BrutalistDialogRoot>
      <BrutalistDialogTrigger>Edit Profile</BrutalistDialogTrigger>
      <BrutalistDialogMask />
      <BrutalistDialogContent>
        <div className="min-w-0 pe-12">
          <BrutalistDialogHeader>
            <BrutalistDialogTitle>Edit profile</BrutalistDialogTitle>
            <BrutalistDialogDescription>
              Make changes to your profile here. Click save when you&apos;re done.
            </BrutalistDialogDescription>
          </BrutalistDialogHeader>
        </div>
        <BrutalistDialogFooter>
          <BrutalistDialogClose>
            <BrutalistButton variant="neutral">Cancel</BrutalistButton>
          </BrutalistDialogClose>
          <BrutalistDialogClose>
            <BrutalistButton>Save changes</BrutalistButton>
          </BrutalistDialogClose>
        </BrutalistDialogFooter>
        <BrutalistDialogCloseIcon />
      </BrutalistDialogContent>
    </BrutalistDialogRoot>
  );
}
```

### 组合结构

```text
BrutalistDialogRoot
├── BrutalistDialogTrigger
├── BrutalistDialogMask
└── BrutalistDialogContent
    ├── BrutalistDialogHeader
    │   ├── BrutalistDialogTitle
    │   └── BrutalistDialogDescription
    ├── BrutalistDialogFooter
    │   └── BrutalistDialogClose
    └── BrutalistDialogCloseIcon
```

### 交互与视觉规则

- **触发器与关闭按钮**：触发按钮使用天蓝色块与 4px 硬阴影；右上角关闭按钮（可访问名称 `Close`）为独立金丝雀黄圆角控件，悬停切换为珊瑚红，按压时沿阴影方向落位并收起阴影，聚焦时保持清晰外偏焦点环。
- **底部关闭操作**：`Close` 部件仅负责关闭语义，不自带按钮外观；在底部内嵌 `BrutalistButton` 即可获得标准按钮样式并保持单一 `Tab` 停靠点。
- **遮罩交互**：非穿透 `Mask`（默认 `passthrough={false}`）阻止指针默认行为夺走已恢复的焦点，关闭策略由 `Content` 统一控制。
