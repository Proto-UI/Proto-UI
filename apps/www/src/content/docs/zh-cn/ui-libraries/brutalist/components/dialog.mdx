## 安装

当前仅在源码工作区提供，尚未进入 0.2.0 稳定版。

- **CLI 目标**：`proto-ui add <react|vue|vue2|wc> brutalist-dialog`

## 用法

- **触发器与关闭按钮**：触发按钮使用天蓝色块与硬阴影；右上角关闭按钮（可访问名称 `Close`）为独立金丝雀黄圆角控件，悬停切换为珊瑚红，按压时移除阴影并保持清晰硬焦点轮廓。
- **底部关闭操作**：`Close` 部件仅负责关闭语义，不自带按钮外观；在弹窗底部组合 `Button` 子元素即可获得标准按钮样式并保持单一 `Tab` 停靠点。
- **遮罩交互**：非穿透 `Mask`（默认 `passthrough={false}`）会阻止指针默认行为夺走已恢复的焦点，点击外部的关闭策略由 `Content` 统一控制。

### 其他部件属性

- **Mask**：`passthrough?: boolean`（默认 `false`）及 Transition 属性
- **Content**：无自有属性。需要选择初始焦点策略的组合可以使用 [Base Dialog Content](/zh-cn/ui-libraries/base/dialog/)；这不会扩展 Brutalist Content 的属性边界。
- **Trigger / Title / Description / Close**：无独立属性
