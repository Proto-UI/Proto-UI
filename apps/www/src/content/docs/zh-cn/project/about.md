# Proto UI

## Proto UI 是什么？

Proto UI 是一个面向多种运行环境的组件交互协议。它尝试将组件行为定义为一种可以被不同 Runtime 翻译和实现的中立形式。

---

## 项目信息

- 仓库地址：https://github.com/Proto-UI/Proto-UI
- 开源协议：MIT
- 维护者：Proto UI Team

---

## 项目范围

Proto UI 关注的是 UI 组件交互语义的定义、表达与跨宿主翻译。  
它既包括原型本身，也包括将原型映射到不同 Runtime 与宿主能力的适配层设计。

Proto UI 不预设唯一的渲染实现方式，但会为适配器生态提供必要的约束、参考与指导。

---

## 当前阶段

v0 项目阶段；当前稳定 package release 为 0.2.0

当前公开 package line 是通过 npm `latest` 发布的 [Proto UI 0.2.0](https://github.com/Proto-UI/Proto-UI/releases/tag/v0.2.0)。Proto UI 仍在持续稳定核心交互语义并建设基础能力，因此部分 API 与实现细节在后续迭代中仍可能变化。Package 可用性不会覆盖单个 spec entity 的 active 或 draft 生命周期状态。
