Hover Card 在用户悬停或聚焦触发元素时，延迟展示一段轻量预览内容，适合账号名片、链接摘要等场景。本页示例使用 **Shadcn Rhea** 风格。

## 预览

演示在悬停或聚焦 `@proto-ui` 后延迟 `150ms` 打开卡片，移出后延迟 `300ms` 关闭，浮层默认位于下方居中（`side="bottom"`、`align="center"`）。

## 用法

Hover Card 由三个协作部件组成：

- **Root**：统一管理展开状态（`open`）、开关延时与禁用状态。
- **Trigger**：响应指针悬停与键盘聚焦，向 Root 请求打开或关闭。
- **Content**：渲染浮动卡片面板，控制定位与防碰撞，并在指针移入内容区时保持卡片展开。

### 受控与非受控

- **非受控模式**：通过 `defaultOpen` 设置初始状态，由 Root 根据悬停、聚焦及延时自动切换。
- **受控模式**：传入 `open` 并监听 Root 的 `openChange` 事件，由外部状态驱动展开与收起。

### 延时与禁用

- `openDelay`（默认 `700` ms）与 `closeDelay`（默认 `300` ms）支持取消：指针快速划过触发器或在关闭延时内移入卡片内容区时，不会意外闪烁或关闭。
- 传入负数或非有限数值作为延时参数时，会自动回退到默认值。
- 在 Root 或 Trigger 上设置 `disabled` 可禁用交互触发。

### 暴露状态、方法与事件

- **Root**：暴露 `open` 状态、`openHoverCard(reason?)`、`close(reason?)`、`toggle(reason?)` 方法，以及 `openChange` 事件（载荷为 `{ open: boolean; reason: string | null }`）。
- **Trigger**：暴露 `disabled`、`hovered`、`focused`、`focusVisible` 状态与 `focusSelf(options?)` 方法。
- **Content**：暴露 `open` 状态。
