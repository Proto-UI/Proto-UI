## 使用相同的原子定义

`@proto.ui/prototypes-shadcn/checkbox` 导出 `shadcnCheckboxLabelComposition` 与 `createShadcnCheckboxLabelComposition()`。公开 recommendation 给出真实的 Root、Indicator、Label 定义、关系与短名称默认选项。Indicator 放在 Root 内，Label 与 Root 同级。Indicator 替换仍遵循原有 Checkbox preset；这不是“标签 slot 模式”。原有 raw atoms 导出保持不变。

只冻结 helper 新建的容器与 Label 默认值；引用的 prototype 和共享 preset 保持原有 identity 与可变性，不作 deep-freeze 承诺，也不修改它们。

在一个组合挂载时创建一次实例，并在该宿主的重渲染期间保留它；不要放入模块全局供多个控件共用，也不要每次 render 都生成新关联。

下面是 adapter-neutral 输入示意，不是完整可运行的宿主示例。完整 host examples、native 输入、terminal disposal 与 packed/install 验收仍未完成。

```ts
import { createShadcnCheckboxLabelComposition } from '@proto.ui/prototypes-shadcn/checkbox';

const pair = createShadcnCheckboxLabelComposition();
// Adapt pair.recipe.parts.control / indicator / label using the chosen adapter.
// Root input: pair.control.instanceAssociations
// Label input: pair.label.instanceAssociations and pair.label.props
// Checkbox props and outward handlers remain owned by the existing Checkbox.
```

React/Vue/Vue2 通过现有 `instanceAssociations` 输入传递关联，并把 `pair.label.props` 作为 Label 的 props。Web Component 使用公开 `setElementAssociations(element, ...)`，Label props 通过 `setElementProps` 提供。不要把 opaque reference 放进 Props、HTML attribute 或 JSON。绑定与卸载由现有 adapter 管理；构造器不安装监听器，也不提供虚假的 dispose API。换用新关联时同时更新 Root 与 Label。

## 富内容不等于任意交互内容

标签使用宿主本来支持的 children/slots，可以包含合法的强调文本、显式标记为装饰性的图标等非交互名称内容，不局限为字符串。它不提供 `asChild` 或另一套 slot 协议，也不会自动修正非法内容。名称来自实际 Label，不要添加隐藏重复名称。

链接、Button、编辑器等独立动作优先放在相邻内容区域；若嵌入，仍须符合宿主内容模型及既有交互后代排除规则，点击不能同时切换 Checkbox。不能把另一个 Label 或无关 labelable control 当作无限制内容。长说明、错误信息应与短名称分离并保留选择能力；只有实际建立描述关系时才能宣称它被读作说明。

短 actionable label 默认 naming 与 activation 都启用，Checkbox 继续拥有 checked、mixed、disabled、controlled 与 focus 行为。需要 naming-only 时用公开 raw Label 显式关闭 activation，而不是修改共享 recipe。没有新增 Checkbox readOnly。

## 有限的 Web Components 安装后使用路径

下面是 #1000 的 candidate 验收路径，不表示当前 npm 发布版已经包含这个 draft helper。使用本次候选真实打包产物安装 `@proto.ui/cli`、`@proto.ui/adapter-web-component`、`@proto.ui/prototypes-shadcn` 及其声明依赖后，在消费者项目执行既有命令。正式发布前不要把旧 registry 包与本页新 API 混用。

```sh
npx proto-ui init --prototypes shadcn --yes --no-interactive
npx proto-ui add wc shadcn-checkbox --no-interactive
npx proto-ui add wc shadcn-label --no-interactive
```

这两条 add 分别提供 Checkbox（默认 Indicator）与独立 Label，不存在一个内置固定标签文案的 Checkbox。项目已有另一套 style preset 时，应先按 CLI 提示显式迁移，不能静默混用 family。下面代码置于支持 TypeScript/CSS import 的消费者入口；JavaScript 项目使用 CLI 实际生成的 `index.js` 路径。宿主打包器处理生成的样式入口，不用网站的源码 alias。

```ts
import './src/styles/proto-ui-style.css';
import {
  ShadcnCheckboxElement,
  ShadcnLabelRootElement,
} from './proto-ui/components/wc/index.ts';
import { createShadcnCheckboxLabelComposition } from '@proto.ui/prototypes-shadcn/checkbox';
import {
  setElementAssociations,
  setElementProps,
} from '@proto.ui/adapter-web-component';

// Called once for this mounted pair, not once per render and not globally.
const pair = createShadcnCheckboxLabelComposition();
const control = new ShadcnCheckboxElement();
const label = new ShadcnLabelRootElement();
const emphasis = document.createElement('strong');
emphasis.textContent = '接收更新';
label.append(emphasis);
setElementProps(label, pair.label.props);
setElementAssociations(control, pair.control.instanceAssociations);
setElementAssociations(label, pair.label.instanceAssociations);
const container = document.createElement('div');
container.append(control, label);
document.body.append(container);

// Remove the complete mounted pair when the owning host view is removed.
// Actual adapter cleanup owns resources; the helper has no dispose method.
// container.remove();
```

使用 `ShadcnCheckboxElement` 时不要再额外追加默认 Indicator；需要显式替换或关闭时沿用原 preset 规则。`ShadcnCheckboxRootElement` 仍是 raw Root，不会自动补 Indicator。Label 可以承载合法的非交互富名称，独立按钮/链接优先放相邻区域。不要另加隐藏重复名称、页面 `.click()` 转发或第二套 checked 状态。

现有 PR CI 的 `cli-smoke` 会从真实 tarball 新建独立消费者，用已安装 CLI 生成这两个 facade，执行 public helper 导入、声明、缺失 Label 产物负控和 WC 合成行为。此证据不会自动证明浏览器原生输入、辅助技术名称计算、布局像素或正式 registry 发布；通过情况须查看对应精确提交的 CI，未运行不能标为通过。
