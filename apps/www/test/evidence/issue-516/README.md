# Private Message browser evidence

Generated by `apps/www/test/message-composition.browser.test.ts` against the shared private Message entry and real Code Block. Each runtime has a 1280px and 390px PNG/JSON pair. The JSON records the initial user/assistant placement, end placement, compact spacing, light-theme state, and final state. The screenshots show the final dark, compact, streamed, App-retried presentation.

The suite verifies App-authored article names, normal-block start/end/stretch placement and RTL direction, density changes, long-word containment, stable transcript/part nodes, independent Code Block content, neutral Message accessibility attributes, and exactly one App retry callback. This is evidence for the accepted private slice, not public package or general accessibility certification.

Regenerate from the repository root:

```sh
corepack pnpm@10.32.1 exec vitest run apps/www/test/message-composition.browser.test.ts
```

The test prints a disposable evidence directory. After inspecting the rendered screenshots, copy its six PNG/JSON pairs here without editing them. No public documentation route or navigation is created by the fixture.
